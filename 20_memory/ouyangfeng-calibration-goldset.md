# 欧阳锋审查校准黄金集（Gold Set）

> **用途**：测审查严格度与用户/独立判断的一致性——LLM-as-judge 2026 调研落地（人类黄金集锚定 + 漂移监测）。
> **依据**：LLM 法官"分数内部一致但外部无意义"；无校准则漂移 60-90 天不可见。
> **频率**：每月抽 5-10 张重审（先重审再翻基线结论，避免记忆污染）。

---

## 一、选择标准

1. **有明确终审结论**（PASS+等级 或 FAIL+退回）
2. **有独立对照**：用户复核 / 王语嫣核查 / 飞书端印证 / 事后被事实证伪
3. **覆盖 PASS 与 FAIL 两侧**（同时测 leniency 和 strictness 两个方向）

## 三、自测流程

1. **每月抽 5-10 张**（随机 + 优先近期漂移高发批），**先重审再翻基线**——重审时不得先看本文档结论
2. 记录本轮结论（verdict + 等级）与基线结论对照
3. 统计两个方向：
   - **Leniency**（宽松）：我 PASS/放行，但对照是 FAIL/应阻断的
   - **Strictness**（过严）：我 FAIL/阻断，但对照是 PASS/应放行的
4. **漂移触发线**：一致率 <80% 或连续 2 月同方向偏差 >20% → 触发严格度复盘（写 daily-context）
5. 结果写回下方「月度校准记录」表
