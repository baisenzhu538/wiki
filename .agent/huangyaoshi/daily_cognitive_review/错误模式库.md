# 错误模式库

> 诚实优先。无新错误就写"无"，不编造。

## 错误记录

### E4: Agent只挖结构化笔记，跳过口述稿Q&A闲聊——暗知识遗漏（2026-06-19，次数：1）
**症状**：老顽童产出王欢AI实践域20张卡，全部基于结构化工整笔记(127行)。口述稿末尾250行Q&A闲聊中的暗知识未被独立成卡——至少还缺2-3张dk。**根因**：笔记过滤效应——结构化笔记不覆盖Q&A；入口把关人也未标注Q&A部分。**对策**：P-31——口述稿末尾20%必须单独标注可能的暗知识；结构化材料是入口不是全集。

### E3: 批量操作未声明变更范围（2026-06-17，次数：1）
**症状**：470 skill 重分类导致 486 文件变更，欧阳锋无法快速审查。**根因**：执行前未在任务文件写明预期变更范围。**对策**：P-30——任何批量操作前声明影响文件数+修改字段+修改前后值。

### E1: Provider 迁移时协议不匹配（2026-06-14，次数：1）

**症状**：Hermes 切到 DeepSeek 后功能降级，模型显示为 `deepseek-chat` 而非 `deepseek-v4-pro`。

**根因**：`models_dev_cache` 标注 deepseek provider 走 `@ai-sdk/openai-compatible`，但 config 配了 `/anthropic` URL。

**对策**：改 provider 前先查 `models_dev_cache.json` 确认 `npm` 字段。

### E2: 模型发布日不查公告（2026-06-14，次数：1）

**症状**：Kimi API 全线 400 + tool call 截断 48 字符，3 小时改 model/temperature/base_url 无效。

**根因**：K2.7 当天发布，Anthropic 协议 tool call 未适配。WebSearch 在第 30 步才触发。

**对策**：API 大规模异常→第 3 步内 `WebSearch "<provider> update"`。
