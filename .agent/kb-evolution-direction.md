## 一、当前进化方法论（2 个模型）

### 1. 对话驱动知识库进化五环模型

- **文件**：`60_feedback/methods/method-dialogue-driven-kb-evolution.md`
- **核心**：高质量咨询对话是知识库进化的上游引擎。
- **五环**：触发 → 第一轮深挖 → 关键拐点（元反馈） → 跨域桥接补深挖 → 生产触发与进化。
- **适用场景**：用户给出跨域/角色/方法论层面的元反馈时。

### 2. 冷热混合进化模型

- **文件**：`60_feedback/methods/method-systematic-dialogue-kb-evolution-hybrid.md`
- **核心**：系统扫描发现机会，对话创造高价值桥接。
- **冷进化**：机械健康度、结构缺口、内容衰减、跨域候选发现。
- **热进化**：真实问题映射、跨域框架设计、角色重定义、价值判断。
- **适用场景**：日常持续进化，每周自动生成进化信号报告。

## 四、进化信号周报机制

- **频率**：每周一 9:07（本地时间）自动生成
- **位置**：`60_feedback/auto/kb-evolution-signals-weekly.md`
- **内容**：
  1. 本周机械错误总览
  2. Top 5 跨域桥接候选
  3. Top 3 需要 enrich 的薄卡
  4. Top 3 长期未 review 卡片
  5. 用户上周元反馈的沉淀情况
- **决策方式**：用户回复「挖第 X、Y 个 / 跳过 / 降级」

## 五、桥接卡生产规范

当进化信号进入热进化阶段，桥接卡必须满足：

1. `related ≥ 7`（复杂桥接 ≥ 8）；
2. 必须同时回答「域 A 能给域 B 带来什么」和「域 B 能给域 A 带来什么」；
3. 必须包含外部证据或跨域案例；
4. 必须明确 When NOT to Use 和失败模式；
5. 必须跑 `kdo pre-submit`。

## 七、长期方向原则（2026-06-28 用户确认）

> 以下原则由用户明确提出，所有 Agent 在处理知识库进化任务时必须遵守。

1. **追求知识库的深度和边界**
   - 每张卡不是信息搬运，而是经过 Condense / Critique / Synthesis 的理解产物。
   - 跨域连接要回答「为什么相关」和「何时组合用」，而非薄标签。

2. **无限追求知识库的健壮和发展**
   - 结构健康（lint、link、frontmatter）与内容健康（深度、边界、失败模式）并重。
   - 系统扫描 + 对话驱动双轮进化，不依赖单次对话透支未来。

3. **提高 Agent 的咨询能力边界**
   - 知识库进化的终点是提升 Agent 面对真实商业问题时的咨询质量。
   - 每张卡必须包含可执行的行动触发器（Action Triggers），而不只是概念说明。

4. **反对急功近利**
   - 用户明确：世界有规律，不能因急就跨越规律做不合适决策。
   - 若用户后续提出压缩质量、跳过审查、插队生产等急功近利要求，Agent 应主动阻止并给出基于规律的建议。
   - 任务按队列顺序执行；临时插队只发生在 P0 阻塞或用户明确战略优先时。
