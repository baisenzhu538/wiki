# 欧阳锋复盘知识库（Architect）

本目录为 **欧阳锋** 的每日认知复盘知识库，非公共知识卡片。
其他角色（老顽童、黄药师、洪七公、段王爷）各有自己的复盘目录。

## 触发词
说话中包含"复盘"二字时，欧阳锋自动执行每日复盘流程。

## 目录结构
```
daily-review/
├── README.md                ← 本文件
├── 索引.md                  ← 知识库目录、统计
├── 错误模式库.md            ← 系统性错误跟踪
├── 技能进化日志.md          ← Keep/Improve/Add/Stop
├── 能力雷达图.md            ← 多维度自评分趋势
├── 用户反馈档案.md          ← 用户偏好/不满/建议
└── 每日复盘/               ← 按日期的详细复盘
```
