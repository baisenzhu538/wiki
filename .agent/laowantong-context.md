## 铁律

### 扫描器审核规则

**扫描器批量产出 ≠ 成品。** 扫描器（黄药师的工具）产出的卡片必须经过审核精选后才能入库：

1. 从批量产出中逐张过——挑出有实际价值的（≤50% 保留率）
2. 保留的卡片标注 `source_person: "扫描器产出-老顽童精修"`
3. 不保留的标记 `status: needs-review` 或移出 concepts/
4. **禁止整批直接入库**——dashboard 上的"待老顽童审核精选"是硬约束，不是状态描述

### 质量铁律

**操作步骤不能等于原文复述。** 每张 skill 卡必须让读者比读原文多获得东西：

1. **必须有"判断标准"小节**：读者看完能判断自己做对了没有。例——"什么算一条好清单条目？→ (1) 可独立执行不依赖上下文 (2) 有明确的完成标准 (3) 不超过 3 个动作"
2. **适用/不适用场景必须具体**：不能写"适合需要框架的场景"，要写"适合连续 3 次以上发现自己分析中遗漏了某个步骤的场景"
3. **常见失败模式不能是模板话**："步骤跳过或省略 → 严格按步骤执行"是废话。必须写这个技能特有的失败模式

### 操作铁律

1. **写新卡前先查旧卡**：`kdo cards --domain <domain>` 看同域已有卡。新卡覆盖旧卡→旧卡加 `superseded_by` + Synthesis 加 →[[新卡]]
2. **新域素材第一步**：`Get-ChildItem -Recurse *.png, *.jpg` 扫描 → 有图先 OCR → 再读文本
3. **素材搜索不能只靠文件名**：`grep -r "主题词" --include="*.txt" --include="*.md"` 全文搜索，文件名是人起的，内容才是机器能找到的
4. **产新卡同步更新 index**：写完后跑 `kdo index --rebuild`
5. **每 5 张卡至少引入 1 位新攻击者**：纯 Kahneman+Taleb 组合需替换一位

## 产出标准（三步编译法）

1. **浓缩（Condense）**：把原文压缩为 3-5 条核心观点。只保留核心结论和关键证据。
2. **质疑（Question）**：评估每条结论的前提假设、边界与反例、可靠性（高/中/低，附理由）。**至少引入 2 位真实外部学者进行独立攻击**。
3. **对标（Synthesize）**：创建与现有卡片的双向链接，标注冲突/互补/可迁移场景。

每张卡必须包含：Claims → Key Evidence → Critique（内部局限 + 外部攻击 + 不要用场景）→ Synthesis → Action Triggers。
