# deep-research Skill

**数字侦察特工 · 深度调研方法论**

本 Skill 源自"一堂"认证调研方法论，提供框架化、结构化、可验证的深度调研能力。

## 调研主题澄清

### 5W2H 分析框架

拿到调研主题后，先用 5W2H 澄清边界：

| 维度 | 问题 |
|------|------|
| **What** | 是什么？具体要调研什么？定义清楚调研对象 |
| **Why** | 为什么？为什么需要做这个调研？解决什么问题？ |
| **Who** | 谁？目标用户是谁？决策者是谁？ |
| **Where** | 在哪？应用场景是什么？线上/线下？ |
| **When** | 什么时候？时间范围是什么？ |
| **How** | 怎么做？用户现在怎么完成的？ |
| **How much** | 多少？市场规模多大？预算多少？ |

### 五类问题边界

在 5W2H 基础上，明确五类边界：

1. **时间边界**：历史/现在/未来（预测多久？）
2. **空间边界**：全球/全国/特定区域/特定渠道
3. **主体边界**：要调研哪些玩家？行业龙头/初创/全部？
4. **信息边界**：二手信息为主还是需要一手调研？
5. **输出边界**：要输出什么？报告/决策建议/还是只是了解？

## 信息搜集

### 五步搜索法

按照以下顺序逐步深入，不停留在表面：

**Step 1：扫盲（10分钟）**
- 用 3-5 个关键词搜索"是什么"类基础问题
- 快速了解行业定义、基础术语、基本分类
- 找到 3-5 篇高质量科普文章

**Step 2：建立框架（20分钟）**
- 搜索"[行业名] 市场分析报告"
- 搜索"[行业名] 行业报告"
- 下载或在线阅读艾瑞、36kr、头豹等机构报告（即使只是摘要）
- 找到行业基本数据：市场规模、增长率、主要玩家

**Step 3：深挖玩家（30分钟）**
- 列出行业前 5-10 名玩家
- 逐个搜索每个玩家的官网、融资历史、产品介绍
- 阅读至少 3 篇针对头部玩家的深度分析
- 阅读至少 5 篇竞品官方博客/公众号文章

**Step 4：交叉验证（15分钟）**
- 用 3-5 个核心数据点，交叉验证不同来源
- 注意数据差异较大的地方，标记为"待验证"
- 搜索"XX行业 骗局/问题/失败/坑"
- 阅读失败案例，理解行业暗面

**Step 5：找专家（可选）**
- 在行行查、知乎、知识星球找行业专家
- 阅读专家的过往判断和预测
- 如有必要，在行/在行一点约专家电话咨询

### 五类信息源

| 类型 | 来源 | 优先级 |
|------|------|--------|
| **官方资料** | 公司官网、招股书、年报、财报 | ⭐⭐⭐⭐⭐ |
| **行业报告** | 艾瑞、36kr、头豹、国信、慧博 | ⭐⭐⭐⭐ |
| **媒体报道** | 虎嗅、36kr、钛媒体、晚点、极客公园 | ⭐⭐⭐ |
| **用户声音** | 知乎、豆瓣、微博、小红书、App评价 | ⭐⭐⭐ |
| **一手调研** | 深度访谈、问卷调查、实地体验 | ⭐⭐⭐⭐⭐ |

## 竞品分析

### 10维度深度对比矩阵

对每个竞品，从以下10个维度分析：

| 维度 | 调研要点 |
|------|----------|
| **1. 公司背景** | 成立时间、融资阶段、团队规模、创始人背景 |
| **2. 产品定位** | 核心功能、目标用户、价值主张、差异化 |
| **3. 商业模式** | 收费模式、价格体系、盈利情况 |
| **4. 市场规模** | 营收规模、用户规模、市场份额 |
| **5. 增长策略** | 获客渠道、留存策略、扩品路径 |
| **6. 技术实力** | 核心技术、专利布局、研发投入 |
| **7. 运营数据** | DAU/MAU、留存率、转化率、 NPS |
| **8. 用户评价** | App Store评分、用户口碑、主要抱怨 |
| **9. 融资历史** | 轮次、金额、投资方、估值 |
| **10. 未来规划** | 近期动态、产品路线图、战略方向 |

### 竞品分析输出模板

```
## 竞品分析总览

| 维度 | 竞品A | 竞品B | 竞品C | 我们的产品 |
|------|-------|-------|-------|------------|
| 公司背景 | ... | ... | ... | ... |
| 产品定位 | ... | ... | ... | ... |
| 商业模式 | ... | ... | ... | ... |
| ... | ... | ... | ... | ... |

## 关键洞察

1. **差异化机会**：...
2. **市场空白**：...
3. **风险警示**：...
```

## 市场分析

### PEST 分析框架

| 维度 | 分析要点 |
|------|----------|
| **P 政治/政策** | 监管政策、政府补贴、行业准入口、贸易政策 |
| **E 经济** | 人均收入、消费趋势、支付能力、成本结构 |
| **S 社会** | 人口结构、消费习惯、文化趋势、生活方式 |
| **T 技术** | 技术成熟度、创新速度、专利壁垒、替代威胁 |

### 波特五力模型

| 五力 | 分析问题 |
|------|----------|
| **行业内现有竞争** | 主要玩家有哪些？竞争格局如何？ |
| **潜在进入者** | 什么阻止新进入者？壁垒有多高？ |
| **替代品威胁** | 有哪些替代方案？用户转换成本多高？ |
| **供应商议价能力** | 核心供应商是谁？集中度如何？ |
| **买家议价能力** | 用户集中度？价格敏感度？信息透明度？ |

### 市场地图

按以下结构绘制市场地图：

```
[产业链位置]
  ├── 上游：...
  ├── 中游：...
  └── 下游：...

[核心玩家]
  ├── 龙头：...
  ├── 成长期：...

[市场规模估算]
  ├── 总体市场：...
  ├── 可服务市场（SAM）：...
  └── 可获得市场（SOM）：...
```

## 深度洞察提炼

### 五步洞察提炼法

**Step 1：收集事实**
- 列出所有收集到的关键事实和数据
- 每个事实标注来源和置信度

**Step 2：寻找规律**
- 哪些事实之间有联系？
- 哪些模式反复出现？
- 哪些趋势正在形成？

**Step 3：提出假设**
- 基于规律，提出 2-3 个核心假设
- 每个假设能解释多个事实

**Step 4：验证假设**
- 用剩余事实验证每个假设
- 找出假设的反例或漏洞
- 修正或放弃不成立的假设

**Step 5：形成洞察**
- 用一句话总结每个经过验证的洞察
- 洞察应该是可行动的

### 洞察输出格式

```
## 核心洞察

### 洞察1：...
**支撑事实**：...
**行动建议**：...

### 洞察2：...
**支撑事实**：...
**行动建议**：...
```

## 报告生成

### 五步成稿法

**Step 1：明确受众**
- 谁会读这份报告？
- 他们关心什么？
- 他们的决策压力是什么？

**Step 2：设计结构**
- 结论先行（Executive Summary）
- 逻辑清晰（按重要性排序，而非时间顺序）
- 数据支撑（每个观点有数据支撑）
- 行动导向（每个章节有小结和建议）

**Step 3：填充内容**
- 按结构逐章撰写
- 图表结合（数据可视化）
- 引用标注（来源透明）

**Step 4：交叉检查**
- 数据是否自相矛盾？
- 逻辑是否有漏洞？
- 假设是否经过验证？

**Step 5：打磨呈现**
- 标题是否清晰？
- 摘要是否在1页内？
- 关键信息是否突出？

### 五类输出格式

| 格式 | 适用场景 | 输出路径 |
|------|----------|----------|
| **Markdown 报告** | 通用场景、快速分享 | `{workspace}/deep-research-report.md` |
| **Word 文档** | 正式交付、客户汇报 | `{workspace}/deep-research-report.docx` |
| **Excel 表格** | 数据对比、竞品矩阵 | `{workspace}/competitive-analysis.xlsx` |
| **PPT 演示** | 会议汇报、融资展示 | `{workspace}/research-deck.pptx` |
| **数据包** | 深度分析、二次加工 | `{workspace}/research-data/` |

## 调研质量检查清单

完成调研后，逐项检查：

- [ ] **来源可信度**：每个数据点都有来源吗？来源权威吗？
- [ ] **时效性**：数据是否是最新的？（一年内为佳）
- [ ] **交叉验证**：核心数据是否经过2个以上来源验证？
- [ ] **代表性**：样本是否足够代表整体？
- [ ] **逻辑自洽**：结论与事实是否一致？
- [ ] **反例思考**：有没有考虑反面案例？
- [ ] **不确定性**：是否标注了不确定性和风险？
- [ ] **可操作性**：建议是否具体可执行？
