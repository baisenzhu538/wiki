## 核心芯片方案

```
A板 MCU: STM32F103RCT7（LQFP-64）
A板 电源: 24V → TPS54360 → 5V → AMS1117-3.3 → 3.3V

发射链路：STM32 → SN74LVC2G07(电平转换) → SN74LV595(级联×2)
         → AP2302B(MOSFET×16) → IR333C-A(红外发射管×16)

接收链路：PT334-6B(红外接收管×16) → LMV358IDR(运放)
         → CD4051BPWR(8选1多路器×2) → STM32
```

## 已知问题

| # | 问题 | 影响 | 状态 |
|:-:|:----|:----|:----:|
| 1 | SN74LVC2G07 开漏输出导致 RCLK 上升沿变缓，595 锁存不可靠 | 通道错位、绿灯常亮 | ✅ 已修复（RCLK 后加 Ir_Delay(200)） |
| 2 | 接收判断需分段检测 | 全通道检测失败 | ✅ 已修复（no<8→IN1&&IN3, no>=8→IN2&&IN4） |

## 硬件改进建议（下次改版）

1. RCLK/SRCLK 上拉电阻从 10kΩ 改为 1kΩ（加速上升沿）
2. 或改用推挽输出电平转换器（TXS0108）替代 SN74LVC2G07
3. 原理图/BOM/PCB 统一版本号标注，避免 V2.1 vs V2.2 混淆
