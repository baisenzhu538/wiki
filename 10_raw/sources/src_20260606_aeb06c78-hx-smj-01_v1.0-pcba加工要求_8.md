# HX-SMJ-01_V1.0 PCBA加工要求_8

# HX-SMJ-01_V1.0 PCBA加工要求_8

             

                  PCBA加工要求

PCBA焊接工艺

对于贴片器件的焊接，需采用自动SMT工艺，包括：自动锡膏印刷、SMT自动贴片、回流焊。

包装

PCBA板采用真空包装，防止焊盘氧化。

ESD管控

板卡生产过程应采用防静电管控措施。防止静电对电路板及电子元器件寿命造成影响。

三防漆

PCBA板需双面喷涂三防漆，可参照标准IPC-A-610F CLASS III要求执行，建议使用自动化喷涂。

部分关键器件需要保护避免沾上三防漆的，已经在BOM表中备注提及，一定要注意！。

控制焊脚高度

插件类器件应尽量控制焊脚高度小于等于2mm。

PCBA焊接过程要有AOI自动光学检测，对于焊接缺陷要及时处理，避免流入下一加工环节。

PCBA飞针测试或在线针床测试。

供应商需提供PCBA相应的生产过程质量检测记录或报告。
