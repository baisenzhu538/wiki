## 交付物 1：会议纪要模板（冰山画布四段）

**用途**：会前写框架、会中填内容、会后沉淀——纪要自带会议设计结构。

```
# 会议纪要：{会议名} · {日期}

## 一、目标（冰山最底层——先写）
- 本次会议要解决的问题：[1-3 条具体目标]
- 反向推导：如果不开会会出现什么问题？[写 1 条]

## 二、原则（冰山中层——会议姿势）
- 选中的原则：[务实/高效/良性/点燃/落实…选 3-5 条 + 一句话理由]
- 会议类型×原则匹配：[头脑风暴→激发/投入/民主 等]

## 三、流程（冰山表层——会前/会中/会后）
### 会前
- 已发材料：{提前 24h 文档 + "已读完"确认}
- 参会/知会名单：{谁必须到、谁邮件同步}
### 会中
- 开场一分钟：{目标/边界/时间声明}
- 关键讨论：[议题 → 结论 → 分歧点]
- 蓝军/追问：{务实追问记录}
### 会后
- 共识二次确认：[逐条复述确认]
- to do 反述：[每人复述自己的行动项]

## 四、行动清单
| 谁 | 做什么 | 交付物 | 时间 |
|:--|:--|:--|:--|

## 已知边界
- {未覆盖的议题（停车场）/ 数据缺口 / 需专项会的}
```

## 交付物 2：议程文档（该不该开决策单 + 会前/会中/会后）

**用途**：开会前 10 分钟决策 + 准备——防止"该不该开"都说不清就拉人。

```
# 议程文档：{会议名} · {发起人} · {日期}

## 该不该开（ROI 决策单）
- 会议成本：{人数} × {时长}h × 时薪 ≈ {X 元}
- 三层价值判断：同步信息(1) / 单向推动(2) / 多方决策(3)——本会是 {N}
- 结论：[✅ 开 / ❌ 不开——不开用：知识库/周报/看板/1v1/碰头会]
- 理由：{一句话}

## 会前准备
- 材料：[提前 24h 发什么]
- 参会人：[必须到/知会名单]
- 结束条件：[什么达成就可以散会]

## 会中流程
- 开场：{目标/边界/角色/时间——开头一分钟话术}
- 议题 1：{议题} → 发言顺序 {设计} → 时间 {X min}
- 议题 2：…
- 停车场：[发散议题记录处]

## 会后落实
- 纪要：{录音/备忘/完整版——三级选一}
- 二次确认：{话术："我们来回顾一下今天的结论…"}
- 跟踪：{下次会议回顾 to do}

## 已知边界
- {本议程不覆盖的：如需要专项会的复杂议题}
```

## 交付物 3：该不该开决策单（清单）

**用途**：快速决策——任何"要不要开会"的念头先过这张单。

```
# 该不该开决策单

## 会议成本（算账）
- 人数：{N} × 时长：{N}h × 时薪：{X 元} = 约 {Y 元}
- 占团队产能：{约 N%}

## 价值判断（三层）
- 本会要达成：同步信息 / 单向推动 / 多方决策？——{选一个}
- 是否"深度讨论/多方决策"才值得开？{是/否}

## 替代方案检查（非必要不开会）
- [ ] 知识库/文档异步同步？
- [ ] 周报/看板/数据报表？
- [ ] 1v1 或 3-5 人碰头会？
- [ ] 邮件/飞书消息？

## 决策
- [ ] ❌ 不开——用：{替代方案}
- [ ] ✅ 开——进入议程文档（交付物 2）

## 备注
- {一句话理由}
```
