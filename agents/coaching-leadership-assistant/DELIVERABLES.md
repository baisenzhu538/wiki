## 交付物 1：一页纸复盘模板（五阶梯自检版）

**用途**：用户做完一个带团队动作/沟通后自检——"我在哪一层、硬币加减、下一步"。

```
# 一页纸复盘：{场景名}

## 我的层级自检（五阶梯 L0-L5）
- 当前层级：[L0-L5 + 一句话依据——例：L2 结果层（能拿结果但决策是黑盒）]
- 目标层级：[想去的层级 + 为什么]

## 硬币账本（加减币 10+10）
- 加币：{做了什么} → 硬币 +1
- 减币：{做了什么} → 硬币 -N（高危项标红：情绪失控/甩锅/压制异议）
- 本周净变化：+/-N

## 关键沟通回顾（21 卡牌维度）
- 倾听：{用了几步：专注/3F/静默…} 效果如何
- 提问：{问出什么/漏问什么}
- 反馈：{给了什么反馈（BASIC 达标吗）}

## 下一步（可执行）
- [ ] {1 个加币动作}——{预期硬币变化}
- [ ] {1 个减币风险规避}——{防什么}

## 已知边界
- {这个复盘看不到的：如团队深层情绪/长期趋势——建议 1v1 或月度再看}
```

## 交付物 2：1v1 沟通纪要模板（倾听/提问/反馈三栏）

**用途**：1v1 前准备 + 后记录——让沟通有结构、有沉淀。

```
# 1v1 沟通纪要：{员工名} · {日期}

## 会前（三分钟准备）
- 本次意图（L0）：{我要达成什么——了解状态/给反馈/定目标}
- 预期角色（TCPR）：{C 咨询/ P 实践…}

## 倾听记录（信任层——先懂人）
- 他说了什么：[事实/情绪/意图——3F 分层]
- 我听到的卡点：{他没说的：挣扎/需求}

## 提问记录（共识层——让他自己想）
- 我问的关键问题：{1-2 个出口式问题}
- 他答出的出口：{他自己找到的答案}

## 反馈记录（成长层）
- 给的反馈：{基于事实 + 具体 + 及时——BASIC}
- 他的反应：{接受/防御——判断反馈是否有效}

## 行动项
| 谁 | 做什么 | 何时 |
|:--|:--|:--|

## 待确认
- {下轮 1v1 要追的事/他没说完的}
```

## 交付物 3：硬币自检清单（10+10 可勾选）

**用途**：快速自检工具——每次互动前后过一遍，防减币。

```
# 领导力硬币自检清单

## 加币（做一项 +1）——今日做了几项？
- [ ] 关键决策讲道理
- [ ] 以身作则带团队（我先做出来）
- [ ] 一次胜利/里程碑分享
- [ ] 巨大压力下情绪稳定
- [ ] 提出好问题引发思考
- [ ] 失败中公开反思
- [ ] 唤醒个体闪光点
- [ ] 培养下属成为领导者
- [ ] 赞扬团队贡献（不抢功）
- [ ] 及时报销/资源支持

## 减币（碰一项 -N）——今日避开了吗？
- [ ] 情绪失控（高危！一次抵数月）
- [ ] 甩锅下属
- [ ] 拒绝承认错误
- [ ] 滥用职权压制异议
- [ ] 过度依赖短期 KPI
- [ ] 言行不一致
- [ ] 自己不成长 push 团队
- [ ] 对愿景动摇

## 今日净硬币：+/-N ｜ 一句话依据：{...}
```
