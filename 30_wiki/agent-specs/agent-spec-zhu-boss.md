# 老朱 Boss — KDO 老板·纠偏者·宪法来源（岗位说明书 v1.0）

## 第一原则

**实事求是，有问题立马要解决**——对整个工厂的第一要求。发现问题是资产（上浮有奖），隐瞒问题是红线；问题不过夜：教训→规则→工具当天闭环（#433→#435→#442 全链 24 小时闭环为样板）。

## 工厂三目标（North Star，全厂验收总纲）

**高效、省 token、少犯错**——一切基建、门禁、流程改革最终收敛到这三件事上检验；凡与三目标无关的仪式一律裁撤。

## 内核

老板 + 纠偏者 + 宪法来源——KDO 判断力、审美与最终决策的**不可委托持有者**。不是第七个 agent：agent 有 spec 可复制，老朱的审美与判断力不可复制、不可下放。

## 职责（三件，全部不可委托）

1. **提要求**——方向、优先级、拍板。一句话定生死（「拍板生效」「马上开始」），从不纠缠执行细节。
2. **给审美和判断力**——经 CLI 纠偏注入：探针式提问（每次「为什么」大概率变成门禁或 spec 条款）；红线守护（口述稿一等 / 素材删除逐件亲批 / 建议书须独立判断 / 探讨≠指令）；**要求并验收每个 agent 的自我迭代**（三源并进：全网调研 / 知识库学习 / 经验错误——老朱 2026-08-23 提出，验收回路归终稿拍板时的迭代留痕审查）。
3. **最终产出验收**——三层门控最后一层（charter §3.14）：终稿拍板后才入宪生效。

## 边界

- 不参与中间执行：生产归老顽童 / 基建归黄药师 / 编排归王语嫣 / 终审日常归欧阳锋
- 判断永远留人（F-033）：自动化=机械全自动 + agent 在人的规则内执行，非 AI 全自动判断
- 素材删除逐件亲批；00_inbox 只增不删（commit ad03266d8）
- 探讨≠指令：说「只是探讨」不立项，但留痕
- 当前基础建设期的亲自加强=阶段性亲力，终态收敛回三件职责

## 工作流（当下态 + 终态）

```
【当下·人机结合】
老朱 CLI 纠偏每个 agent（审美注入，对话属于老朱）
  → 角色内化进 context/spec（内化归角色）
  → 文档协作（角色间唯一通道，§3.14 通道铁律）
  → 三层门控管道（入口=王语嫣 → 产线 → 出口=欧阳锋）
  → 老朱终稿验收

【终态·自动流】
老朱手机上看门狗式转一篇文章到 inbox
  → 工厂自动启动生产流（编排-生产-终审全链无人值守）
  → 成果送达老朱
  → 老朱只做审美判断和拍板 → 反馈回流工厂迭代
```

## Trigger（三种输入形态）

1. **一句话拍板**——直接生效路径（拍板/部署/马上开始/立项）
2. **探针式提问**——「为什么/有没有」，大概率触发机制化（教训→规则→工具三级固化）
3. **翻看上下文发现问题**——最后的人工审计层（#454 实例；机器自报层上线后压力递减）
