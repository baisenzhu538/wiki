# 品牌资产：认知与信任

> 一堂五步法：品牌是长期的壁垒。品牌资产 = 认知度 × 信任度 × 联想度。

## 核心框架

品牌资产的3个维度：

```
认知度（Awareness）→ 信任度（Trust）→ 联想度（Association）
```

| 维度 | 说明 | 建设 |
|:---|:---|:---|
| **认知度** | 用户知道品牌 | 广告、内容、口碑 |
| **信任度** | 用户信任品牌 | 质量、服务、承诺 |
| **联想度** | 用户联想到什么 | 定位、符号、体验 |

## 关键洞察

### 1. 品牌资产的层次

| 层次 | 说明 | 示例 | 价值 |
|:---|:---|:---|:---|
| **产品品牌** | 单个产品品牌 | iPhone | 产品溢价 |
| **公司品牌** | 公司整体品牌 | 苹果 | 信任背书 |
| **个人品牌** | 创始人品牌 | 乔布斯 | 影响力 |
| **生态品牌** | 生态系统品牌 | 苹果生态 | 锁定效应 |

### 2. 品牌建设的方法

| 方法 | 说明 | 适用 | 周期 |
|:---|:---|:---|:---:|
| **广告** | 付费曝光 | 快速认知 | 短 |
| **内容** | 内容营销 | 深度认知 | 中 |
| **口碑** | 用户推荐 | 信任建立 | 长 |
| **事件** | 热点事件 | 快速引爆 | 短 |
| **体验** | 产品体验 | 深度信任 | 长 |

### 3. 品牌定位的框架

| 维度 | 问题 | 示例 |
|:---|:---|:---|
| **目标用户** | 为谁服务 | 年轻人 |
| **品类** | 在什么品类 | 智能手机 |
| **差异化** | 与竞品不同 | 创新、设计 |
| **信任状** | 为什么可信 | 销量、奖项 |
| **品牌人格** | 品牌像什么 | 创新者 |

### 4. 品牌资产的评估

| 指标 | 说明 | 方法 |
|:---|:---|:---|
| **品牌认知度** | 目标受众知道品牌的比例 | 调研 |
| **品牌偏好度** | 用户首选品牌的比例 | 调研 |
| **品牌溢价** | 用户愿意付溢价的程度 | 价格测试 |
| **品牌NPS** | 用户推荐品牌的意愿 | NPS调查 |
| **品牌联想** | 用户联想到的关键词 | 自由联想 |

### 5. 品牌资产的维护

| 维护方式 | 说明 | 注意 |
|:---|:---|:---|
| **一致性** | 品牌信息一致 | 不要变来变去 |
| **质量** | 产品质量稳定 | 质量是品牌基础 |
| **服务** | 服务体验一致 | 服务是品牌延伸 |
| **创新** | 品牌持续创新 | 品牌不能老化 |
| **保护** | 法律保护品牌 | 商标、专利 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **品牌定位模糊** | 用户不知道品牌代表什么 | 明确定位 |
| **品牌不一致** | 品牌信息混乱 | 统一品牌 |
| **忽视质量** | 产品质量下降 | 质量优先 |
| **品牌老化** | 品牌跟不上时代 | 品牌更新 |
| **品牌过度延伸** | 品牌延伸到不相关品类 | 聚焦核心 |
| **忽视法律保护** | 品牌被侵权 | 法律保护 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 品牌建设 | 技术架构 |
| 长期战略 | 短期促销 |
| 竞争策略 | 一次性决策 |
| 溢价能力 | 纯公益 |
