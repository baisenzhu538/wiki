# YC 放出一套「AI-NATIVE 公司」组织方法论

> **来源：** YC Startup School，主讲 Diana Hu（YC 合伙人）
> **归档日期：** 2026-04-30
> **老朱判断：** 值得做——传统行业+小微企业视角，借 AI 原生组织弯道超车。

---

## Claims

1. **公司变成"可查询的"（Queryable Company）**：每个重要动作都产出 artifact，整家公司变成一个持续运行的学习系统。AI 能从公司历史决策中学习，而非每次从零开始。

2. **中层管理被重写，而非消灭**：管理没有消失，而是从口头指令+会议纪要变成了文档、约束文件（CLAUDE.md/AGENTS.md）、共享上下文和 agent 协作流程。Human middleware became markdown。

3. **Token Maxing——未来拼 token 投入强度而非人头数**：竞争维度从"多少人"转变为"多少高质量上下文被模型消费"。上下文质量、agent 覆盖率、模型调用密度成为核心 KPI。

4. **Software Factories 模式**：人写 spec 和测试，AI 生成实现和代码，循环迭代直到测试通过。人的角色从"执行者"变为"定义者+验证者"。

5. **初创公司的后发优势**：没有 legacy systems、没有既有组织架构、没有"我们以前一直是这么做的"——可以从 Day 1 按 AI-native 逻辑设计。

6. **Closed-loop Company**：重要流程变成智能闭环——信息被捕捉→反馈→再训练下一轮动作。公司本身成为持续优化的系统。
