# 行业分析画布：五维快速扫描+二维定位

> 来源：一堂《调研武器库》《调研行动营》课程 | 独立可用的行业分析套件：10分钟定性一个行业——规模/增速/集中度/政策/技术五维扫描 + 竞争象限定位，解决"进不进这个行业"的决策难题。

## What It Is

行业分析画布是一套独立可用的行业快速分析工具，包含两个核心组件：(1)五维扫描——用5个维度（市场规模、增速、集中度、政策环境、技术趋势）在10分钟内对一个行业建立基本认知；(2)二维定位——将行业内的关键玩家放入竞争象限，找到空白机会区。核心价值：解决"要不要进这个行业""这个行业还有没有空间"的决策难题。

## When to Use

- 考虑进入一个新行业，但不确定"值不值得、有没有空间"。
- 投资人/合伙人质疑"这个行业到底能不能做"。
- 已经在行业内，需要快速向团队说明行业格局与机会空白区。
- 发现某个"空白象限"，需要判断它是真实机会还是伪需求。
- 行业政策/技术发生突变，需要重新评估进入决策。

> **不适用**：行业数据极度匮乏、已在行业内深耕多年且信息远超公开数据、或决策 stakes 极高（如All-in全部身家）——这些情况应转用深度 OSL 调研或关系网络调研。

## How to Use

### 组件一：五维快速扫描

对目标行业，按以下5个维度快速收集信息（每个维度5-10分钟）：

| 维度 | 核心问题 | 信息来源 | 判断标准 |
|------|---------|---------|---------|
| **市场规模** | 这个行业有多大？ | 行业报告、统计局数据、上市公司财报 | TAM/SAM/SOM估算 |
| **增速** | 这个行业增长多快？ | 历史数据、增长率、融资热度 | CAGR > GDP增速 = 增长行业；CAGR < GDP = 成熟/衰退 |
| **集中度** | 行业是垄断还是分散？ | CR5/CR10、HHI指数 | 高集中度（CR5>60%）→ 壁垒高、机会少；低集中度→ 碎片化、有机会 |
| **政策环境** | 政策是支持、中性还是限制？ | 监管文件、政策解读、行业新闻 | 支持性→ 红利期；限制性→ 合规成本；中性→ 市场驱动 |
| **技术趋势** | 技术正在怎么改变这个行业？ | 专利数据、技术报告、产品迭代 | 技术加速期→ 颠覆机会；技术稳定期→ 运营效率竞争 |

**操作流程**：
1. 对每个维度，用[[yt-research-intelligence-map]]中的渠道快速获取信息
2. 每个维度用一句话总结现状
3. 五句话合成一个"行业快照"

### 组件二：竞争象限定位

将行业内的关键玩家放入二维坐标系，常用轴组合：

| 纵轴 | 横轴 | 适用场景 |
|------|------|---------|
| 价格（高→低） | 体验/品质（高→低） | 消费品、服务业 |
| 专业度（高→低） | 覆盖范围（广→窄） | B2B、专业服务 |
| 技术领先（高→低） | 市场渗透（高→低） | 科技行业 |
| 品牌力（强→弱） | 渠道力（强→弱） | 零售、快消 |

**操作流程**：
1. 选择适合你行业的二维度
2. 列出行业内TOP10玩家，在坐标系中标注位置
3. 观察空白区——哪个象限没有强玩家？
4. 评估自己是否有可能进入该空白区

### 组件三：进入决策检查清单

基于五维扫描+二维定位的结果，回答：

| 问题 | 如果答案是"是" | 如果答案是"否" |
|------|--------------|---------------|
| 市场规模是否足够大（>10亿）？ | 值得进入 | 可能太小，谨慎 |
| 增速是否为正？ | 有增长空间 | 可能需要从存量中抢 |
| 集中度是否低（CR5<40%）？ | 有机会切入 | 壁垒高，需要差异化 |
| 政策是否支持或中性？ | 环境友好 | 需要评估合规成本 |
| 技术趋势是否对你有利？ | 有技术红利 | 可能需要技术突破 |
| 是否有空白象限可以占据？ | 有差异化空间 | 需要和现有玩家正面竞争 |

## Critique

### 内部局限

行业分析画布的边界声明揭示了工具的张力：

- **"快速"与"准确"的权衡**：画布为了"10分钟"牺牲了深度。它可以告诉你"这个行业看起来不错"，但不能告诉你"进入这个行业后具体会碰到什么问题"。
- **过度依赖公开信息**：五维扫描主要依赖公开报告和数据，但行业的真正关键信息（如真实利润率、核心壁垒、地下竞争规则）通常不在公开信息中。
- **静态快照 vs 动态演化**：画布产出的是一个时间点的快照，但行业是动态演化的。今天的高增速可能明天就饱和，今天的空白区可能明天就被占据。

### 外部攻击

#### Nassim Taleb 的"黑天鹅"：批判

**Nassim Taleb**（《黑天鹅》《反脆弱》作者）对行业扫描的"历史依赖"提出根本性质疑：

- **行业扫描基于历史数据，无法预测从未发生过的结构性断裂**：Taleb证明，几乎所有重大行业变革（如iPhone颠覆诺基亚、新冠疫情颠覆旅游业）都是"不可预测的"——它们在历史数据中没有任何先兆。五维扫描看的是"过去发生了什么"，但决定你成败的是"未来会发生什么"。Taleb警告：当你用画布"确认"一个行业"安全"时，你可能正站在一个即将崩塌的行业上。
- **"平均数"的幻觉**：Taleb指出，行业报告中的"平均增速""平均利润率"是危险的指标——因为行业内的分布往往是"极端偏态"的。头部玩家可能赚取了120%的利润，而长尾玩家在亏损。平均数让你误以为"这个行业能赚钱"，但你进入后可能发现自己在亏损的长尾里。
- **"已知的未知"vs"未知的未知"**：画布帮你识别"已知的未知"（如政策风险、技术替代），但Taleb认为真正的风险是"未知的未知"——你连它的存在都不知道。画布无法帮你识别这些。
- **替代方案**：Taleb建议采用"杠铃策略"——不试图"预测"行业，而是设计"无论行业怎么变都能生存"的策略。与其花10分钟做行业扫描，不如花10分钟问自己"如果这个行业明天消失，我的能力还能用在哪"。

#### Karl Popper 的"归纳陷阱"：批判

**Karl Popper**（科学哲学家、证伪主义创始人）对行业"规律"的归纳提出质疑：

- **行业"规律"是归纳陷阱**：Popper证明，任何基于有限观察得出的"规律"都是不可证明的——你只能证明它是错的，不能证明它是对的。五维扫描告诉你"这个行业过去5年增速20%"，但Popper会问："这能证明未来也会增速20%吗？"不能。过去的规律不保证未来。
- **"确认偏见"的危险**：Popper指出，人倾向于寻找"支持自己假设"的证据。当你用画布"扫描"一个行业时，你可能 unconsciously 只关注支持你"想进入"的证据，而忽略反证。画布的结构化框架反而可能强化这种偏见——因为它让你觉得自己"已经全面考虑过了"。
- **行业画布给人虚假安全感**：Popper认为，科学决策的关键不是"收集支持证据"，而是"主动寻找反证"。但画布的设计是"收集信息→形成判断"，而非"提出假设→尝试证伪"。这可能导致"确认偏见"。
- **替代方案**：Popper建议在每个维度上增加"证伪问题"——不是问"这个行业的增速是多少"，而是问"什么样的证据会让我相信这个行业不值得进入"。主动寻找反证，而非收集支持。

## diagnostic_signals

- signal: "用户说'我做了行业画布扫描，但还是不知道该不该进这个行业'"
  framework_lens: "画布太泛——行业画布的范围界定得太宽太泛，覆盖了太多维度和数据，但没有聚焦到具体决策点上。用户填完了画布感觉'什么都知道了'又'什么都不知道'——信息密度高但决策密度低。"
  follow_up_question: "在用画布之前，你最想回答的那个核心问题是什么？画布填完后，这个问题有答案了吗？"

- signal: "用户说'我的行业画布覆盖了5个维度，但每个维度都很浅'"
  framework_lens: "广度代替了深度——画布的五个维度设计鼓励广泛扫描而不是深度挖掘。当用户在估个维度上花同样时间，最终每个维度的结论都停留在'大概'层面，没有一个维度能支撑决策。"
  follow_up_question: "在这五个维度中，哪一个维度对你的决策最关键？如果只让你深入做其中1-2个，你会选哪几个？"

## Constraints & Boundaries

| 边界 | 说明 |
|------|------|
| **适合** | 考虑进入新行业或评估行业机会 |
| **适合** | 需要向团队/投资人快速说明行业格局 |
| **不适合** | 已经在行业内深耕多年、五维信息了然于胸 |
| **不适合** | 行业数据极度匮乏、无法做有效扫描 |

## Common Failure Modes

| 症状（真实表现） | 根因 | 可执行修复 |
|------|------|-----------|
| 画布填满形容词，如"市场很大""增长不错"，但给不出数字或来源 | 数据缺失 | 每个维度至少标注 1 个数据来源或估算依据；无法找到数据的维度标为"未验证" |
| 看到行业规模过千亿就判断"值得做"，忽略已有巨头 | 忽视竞争结构 | 同步计算 CR5/CR10 或 HHI，画出竞争象限，确认是否存在可获胜的空白区 |
| 画布做完后结论仍然是"再研究研究"，没有进入/观望/放弃的决策 | 分析决策脱节 | 强制输出"进入方式 + 时机 + 差异化定位"三要素；若无法输出，说明信息不足，回到情报地图补数据 |
| 用半年前的政策/技术判断当前机会，遇到突变措手不及 | 静态快照 | 每次使用画布时增加"未来 12 个月政策/技术情景"一栏，给出乐观/中性/悲观三种假设 |
| 把"空白象限"直接当机会，未验证真实需求 | 定位≠需求 | 用 [[yt-research-user-jtbd]] 找到至少 3 个目标用户验证该象限需求；否则列为"待验证假设" |

## Examples

### 示例：用行业画布快速评估"现制茶饮"行业

**行业快照（5句话）**
1. 市场规模：中国现制茶饮 2024 年市场规模约 3,000–3,500 亿元（来源：艾媒咨询/窄门餐眼）。
2. 增速：行业 CAGR 约 8–10%，已高于 GDP 但低于前几年的 20%+，进入成熟早期。
3. 集中度：CR5（蜜雪、古茗、茶百道、喜茶、奈雪）约占 35–40%，中低集中度，仍有区域碎片化空间。
4. 政策：食品安全监管趋严，但无限制性牌照；地方政府对茶饮加盟/环保合规要求提高。
5. 技术：自动化萃茶、智能 POS、会员数字化已普及；AI 选品/供应链预测开始渗透。

**二维定位示例**
- 选择纵轴：价格（高→低）；横轴：门店覆盖密度（高→低）。
- 关键玩家大致位置：
  - 蜜雪冰城：低价 + 高密度
  - 喜茶/奈雪：高价 + 中高密度（一二线城市）
  - 区域单店：高价/低价 + 低密度
- 观察到的空白区：**中低价格 + 高社群粘性/主题化**（如健康轻乳茶、地方文化 IP）在三四线城市密度不足。

**进入决策检查清单结果**
| 问题 | 结论 |
|------|------|
| 市场规模 >10 亿？ | ✅ 足够大 |
| 增速为正？ | ✅ 但已从高速放缓 |
| 集中度低？ | ⚠️ 中等，头部已出现但未垄断 |
| 政策支持或中性？ | ⚠️ 合规成本上升 |
| 技术趋势有利？ | ✅ 数字化降低运营门槛 |
| 有空白象限？ | ⚠️ 需用 JTBD 验证主题化/健康化需求 |

**决策输出**：可进入，但不应以纯低价规模战切入；建议先锁定 1–2 个三线城市，用"健康轻乳茶 + 强社群"验证空白象限，3 个月内跑通单店模型后再扩张。

## Synthesis

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **行业处于技术颠覆期（如AI对教育的冲击）** | 历史数据完全失效，五维扫描基于的"规律"可能明天就被推翻。 | 转用"技术成熟度曲线+场景实验"——不预测行业，而是快速测试新技术在具体场景中的可行性。 |
| **决策 stakes 极高（如投入全部身家）** | 10分钟的扫描不足以支撑高 stakes 决策。 | 转用完整OSL调研（[[yt-research-osl-framework]]），投入2-4周做深度调研。 |
| **行业信息极度不透明（如某些B2G业务）** | 公开信息几乎不可用，五维扫描无法获取真实数据。 | 转用"关系网络调研"——通过行业内部人脉获取一手信息，而非依赖公开报告。 |

| **考虑进入一个新行业，但不确定值不值得** | 打开行业画布，30分钟内完成五维扫描+竞争象限草图 | 能写出"行业快照"（5句话）和"竞争格局图"（标注至少5个关键玩家） |
| **投资人对"行业空间"提出质疑** | 用画布中的TAM/SAM/SOM估算+增速数据，快速回应 | 能用具体数字（即使是大致估算）说明市场空间，而非模糊描述 |
| **发现行业内某个"空白象限"，考虑切入** | 不要直接切入，先用[[yt-research-user-jtbd]]验证该象限是否有真实用户需求 | 能找到至少3个目标用户验证"这个空白区的需求确实存在" |
| **行业政策突然变化（如监管收紧）** | 重新扫描"政策维度"，评估对五维判断的影响 | 能判断政策变化是"短期冲击"还是"结构性改变"，并调整策略 |
