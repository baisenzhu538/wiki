# 业务公式参数冰山（L1-L6）

> **一句话**：一堂把业务公式里的参数按挖掘深度分成六层——水面上 L1 基础、L2 财务（初阶·靠经验），水面下 L3 分层、L4 转化（进阶·靠分析），最深处 L5 创新、L6 魔法（高阶·靠创新）；配「自上拆解 + 自下涌现」两条研究路径。市场上 95-99% 的参数都在这六类里（参数探索篇-口述 L1184-L1186），这张图「可以用十年二十年，可以把完全不同业务的负责人拉在一起培训同一套东西」（L1372-L1374）。  
> 一等准：参数冰山原图 + 参数挖掘武器库原图（见 source_refs 两条 VLM）。

---

## 一、冰山模型总览（以原图为一等准）

```
                 ┌──────────────────────┐
   初阶·靠经验   │ L1 基础参数（直觉）   │  粗流量 / 粗线索 / 粗订单 / 粗收入
                 │ L2 财务参数（算）     │  算单元模型 / 算关键指标 / 算财务模型
  ———————————————┴——————————————————————┴—————————————————— 水面
   进阶·靠分析   │ L3 分层参数（切·加法）│  切用户 / 切渠道 / 切行为 / 切场景 / 切SKU
                 │ L4 转化参数（拆·乘法）│  拆首单 / 拆LTV / 拆动作 / 拆筛选
  ———————————————┴——————————————————————┴——————————————————
   高阶·靠创新   │ L5 创新参数（探）     │  探索动作 / 探索数值 / 探索组合
                 │ L6 魔法参数（本质）   │  销售本质 / 留存本质 / 复购本质
                 └──────────────────────┘
```

| 层级 | 名称（动词） | 段位 | 内容（武器库 6 策略→22 动作） | 心法（原图金句） |
|:--|:--|:--|:--|:--|
| L1 | 基础参数（直觉） | 初阶·靠经验 | 1.1 粗流量 / 1.2 粗线索 / 1.3 粗订单 / 1.4 粗收入 | 先用经验和直觉，找出几个大的数字 |
| L2 | 财务参数（算） | 初阶·靠经验 | 2.1 算单元模型 / 2.2 算关键指标 / 2.3 算财务模型 | 从财务视角理解，挖掘围绕「钱」的参数 |
| L3 | 分层参数（切） | 进阶·靠分析 | 3.1 切用户 / 3.2 切渠道 / 3.3 切行为 / 3.4 切场景 / 3.5 切SKU（加法为主） | 充分理解加法，看不同切片的参数规律 |
| L4 | 转化参数（拆） | 进阶·靠分析 | 4.1 拆首单 / 4.2 拆LTV / 4.3 拆动作 / 4.4 拆筛选（乘法为主） | 充分理解乘法，挖掘 2-3 倍的转化率参数 |
| L5 | 创新参数（探） | 高阶·靠创新 | 5.1 探索动作 / 5.2 探索数值 / 5.3 探索组合 | 不要拘泥经验，试着自己定义参数 |
| L6 | 魔法参数（本质） | 高阶·靠创新 | 6.1 销售本质 / 6.2 留存本质 / 6.3 复购本质 | 找到一个神奇数字，价值百万千万 |

三个关键读图点（参数探索篇-口述 L1224-L1294）：

- **冰山逻辑**：L1-L2 在水面上，多数公司靠常识和经验七七八八都能找到；L3-L4 要靠分析往下挖；L5-L6「没有路，自己找路」，要自定义参数甚至挖出属于你自己的魔法参数。
- **动词是操作手册**：直觉→算→切→拆→探→本质，每个动词告诉你「在这一层该怎么动手」。切是把西瓜切成五块、五块相加等于整体（加法）；拆是把整体拆成一节一节的点（乘法）（L1272-L1278）。
- **段位即深度**：初阶靠经验、进阶靠分析、高阶靠创新——你只有到某一层级的参数，才能做那个层级的决策、提那个层级的假设、做那个层级的管理和分工（L870-L872）。

22 个动作下的 100+ 具体参数全量清单见 `[[yt-tool-business-formula-parameter-arsenal]]`。

## 二、各层详解

### L1. 基础参数（直觉·粗数据）

四个「粗」：粗流量（体验课用户数/客流量/注册用户数/DAU-MAU/曝光点击/下载激活）、粗线索（SaaS 体验客户数/小 B 商机线索/大 B 潜在客户/ToG 采购线索）、粗订单（客单量/成交笔数/正式课用户数/订单量）、粗收入（营收/GMV/佣金/广告收入）。

- **价值**：知道业务大概规模，是所有人都能想到的大块数字。
- **局限**：无法指导动作。看到流量低，不知道是该优化渠道还是优化落地页——「模模糊糊的几个大数，什么事都没法做」（L872）。

### L2. 财务参数（算·算得清）

三阶算账（L1456-L1686）：①算单元模型（收入侧：客单价/转化率/LTV/ARPU；成本侧：CAC/货损率/退费率/坏账率）→②算关键指标（ROI/坪效/人效/翻台率/产能利用率入住率/复购续费率）→③算财务模型（毛利率利润率/四费费用率/存货资金周转率/应收账款天数；最终关注回本周期、盈亏平衡点）。

- **价值**：判断业务是否健康、赚不赚钱。
- **局限**：只回答「赚不赚钱」，回答不了「怎么改变」。

### L3. 分层参数（切·切得细，加法）

把粗参数按维度切成切片，五块相加等于整体。五个切法（L2026-L2058）：

| 切分维度 | 课程示例（课程案例口径） |
|:--|:--|
| 切用户 | ToC：基础属性（收入/性别/成绩/年龄/学历/婚育/城市/职业）+ 认知深度（资深-小白/入行年限）；ToB：公司水平/公司特性/决策因素 |
| 切渠道 | 空间（线上/线下）/付费（付费/免费/转介绍）/平台（抖音/小红书/视频号）/类型（直播/加盟/代理）/转化（私域/推送/广告/直销/分销） |
| 切行为 | 生命周期（新/活跃/流失）/活跃（近 7/30/60 日）/使用深度（作业/学分/好友数）/信任深度（是否电话/见面/吃饭）/交易消费（累计付费/消费频次） |
| 切场景 | 续费/门店促销/ToB 会销面销/直播销售/卖货场景 |
| 切 SKU | 价格（高中低）/版本（基础/旗舰/大客定制）/品类/属性（流量/利润/爆款产品） |

- **价值**：定位问题出在哪个人群/渠道/场景，找到「异常子群体」——数据一切开，就能清楚知道是哪一个参数引起了总参数的变化（L2050-L2052）。
- **边界**：不同出身的一号位有不同切片盲区（销售缺 L5-L6、运营缺 L1-L2、产品离钱远、财务缺现场，L1144-L1154），切片维度要互补着看。

### L4. 转化参数（拆·拆得透，乘法）

把分层后的指标沿转化链路拆成一节一节的点，四种拆法（L1276-L1278、L2358-L2628）：

1. **拆首单（漏斗）**：页面（停留率/点击率/付费率）、门店（捕获率/试衣率/付费率）、线上（到场率/意向率/成交率）、ToB（沟通率/定金率/尾款率）
2. **拆 LTV（收入）**：续转（二次/三次转化率）、升单（连带率/升客单率）、复购（复购率/续费率/续签率）、传播（推荐率/转介绍率）
3. **拆动作（细节）**：草稿提交率/现场拍照率/伸手接传单率/进店提篮率/页面加载成功率/好友页面点击率/支付成功率/帮忙试穿率
4. **拆筛选（减法节点）**：投票通过率/试讲通过率/赛马入围率/重点线索率/试吃入围率/备选教练试讲通过率——这些不是要提升的，是做工业化生产用的筛选节点（L2616-L2618）

- **课程示例**（课程案例口径）：服装店不是「客流×进店×购买」就完了——进店率可拆停留，试穿至少两个动作（先拿衣服再试穿），客单价里还藏着可运营的连带率（L2178-L2192）。
- **价值**：找到漏斗里的具体断点，优化断点而不是平均用力。
- **心法**：「充分理解乘法，挖掘 2-3 倍的转化率参数」——主路径乘法参数涨 30%，全局就涨 30%（见实操篇乘法杠杆论述）。

### L5. 创新参数（探·探得新）

L3-L4 靠分析，L5 靠自定义：用数据分析或对业务的理解，挖出属于你业务的、别人没有的参数（L1196-L1198）。三个探索维度（L1280-L1284、L2630-L2828）：

- **探索动作**（人无我有）：PC 学习率作业率/已购会员直播留存率/公众号单阅价值/踩点率/商品拿起率/投屏连接率/现场哭泣率/带团队学习率/1v1 夸孩子率
- **探索数值**（关键数字）：30-150 分钟听课率/3 分钟响应率/1 分钟接单率/48 小时首单完成率/千次曝光购买率
- **探索组合**（复合参数）：30 天 20 学分率/14 天 4 作品率/45 天 2 次对接率/21 天 3 次面试

- **发现路径**：现有漏斗参数解释不了营收变化 → 从行为数据里挖「做了 X 的人转化显著更高」 → 用假设驱动验证因果（而非相关）。
- **案例锚点**（课程案例口径）：服装店「二次试穿」——试穿 2 次的客户转化率显著高于 1 次（约 89%），3 次以上不再提升；围绕「第一次试穿后怎么让他再试第二件」轰假设，门店转化率约 11%→18%（↑约 63%）。见 `[[case-yitang-xiezefeng-clothing-innovation-param]]`。
- **判据**：创新参数不是普通指标，必须能提出可验证假设、配 3-5 个行为指标、找得到基准。

### L6. 魔法参数（本质·看得透）

最深层，也叫魔法数字（Magic Number，《增长黑客》的概念，L2830-L2836）：一个前置动作/节点一旦达成，你最想要的那个率（销售/留存/复购）就质变级提升。三大本质（L2830-L3210）：

- **销售本质**（高转化）：3 次作业率/亲子相互感谢率/免费章节读完率/试衣服率
- **留存本质**（持续使用）：30 天 3 个订单率/7 天 30 个订单率/7 天 10 个好友率/团队交换 2000 条消息率
- **复购本质**（持续付费）：180 天 50 学分率/1 次非标沟通率/学习档案领取率/60 天系统部署率

- **案例锚点**（课程案例口径，强情境依赖）：服装店门口音响「音量 80」——音量从 30 提到 80 最大程度提升「看到率」（听觉穿透视觉盲区），主讲自述为 Magic Number；进店率约 19%→30%。见 `[[case-yitang-xiezefeng-clothing-innovation-param]]`。**注意**：音量 80 是特定门店/商圈的情境化魔法数字，迁移必须重测，不可当普适本质。
- **稀缺性**：「多数业务在多数时间找不到魔法数字，特别稀缺」（L3142-L3144）；找到且是因果、还能藏住，就是竞争力壁垒（L3200）。
- **辨伪**：L6 容易与 L5 混淆——能提出可验证假设的就停在 L5；只有贴近「为什么信任/为什么留存/为什么复购」本质、且动作与结果之间是质变级跃迁的，才归 L6。且「多数魔法数字经不起推敲，可能不是因果只是相关」（L3184-L3186），因果判定见 `[[yt-business-formula-six-level-logic]]`。

## 三、两个底层逻辑（参数探索篇-口述 L1012-L1058）

1. **公式递归嵌套，参数是下一级的目标**：所有业务公式都是递归、分形、嵌套的——目标拆成参数，参数往下一展开就是下一级的目标。公司增长→收入增长→销售增长→投放→抖音→自播→主播，一路拆下去。所以「好的业务拆解带来好的分工和 OKR」：参数找得越准、因果关系越扎实，分工质量越高（L1032-L1038）。
2. **每一个参数都是假设，但假设不一定是参数**：每个参数都在假设「A 会影响/决定 B」（PC 率会不会提升销售转化率、flag 率会不会影响 K 系数），找到足够多参数就等于找到一批待验证的假设；但「涨价」这类具体策略是假设却不是参数（L1042-L1058）。这决定了冰山的使用姿势：挖参数就是储备假设弹药。

## 四、两条研究路径（原图两侧，L1298-L1320）

| 从上往下拆解（演绎） | 从下往上涌现（归纳） |
|:--|:--|
| ①流程梳理：把现有流程理顺，参数自然浮现 | ①异常分析：数据突然变了/掉了，及时跟进 |
| ②已有经验：启用过去验证过的经验 | ②变化归因：找到显著超预期变化的原因 |
| ③逻辑推理：推理「这里应该有个节点」 | ③范式迁移：别的行业的参数能不能迁过来 |
| ④最佳实践：找实例、找行业标杆 | ④大胆假设：灵感闪现勇敢提，提完去验证 |

- 从上往下适用于已有成熟业务模式、需要优化执行；从下往上适用于创新业务或异常分析。两条路要并用：「多用这四招往下拆，同时及时跟进随机涌现」。
- 自下涌现的典型产物就是 L5/L6：FB 的「7天10个好友率」就是数据分析涌现出的拐点指标（L1330-L1346 口述早期版本有「十天十好友」口误，以参数挖掘武器库图原字为准）。

## 五、三条使用纪律（课程反复强调）

1. **「我可以先不拆，但我不能不会拆」**（L2018）：拆不拆是阶段问题和 ROI 问题（参数管理有统计/定量/协作/报表成本，多数时候不需要拆那么细）；能不能拆开是能力问题。健身不是为了打架，是有一天必须打的时候能打赢（L2002-L2024）。
2. **默认相信丢了 3-5 倍转化率**（L2290-L2304）：找到一个转化率就以为够了是条件反射式的误判——用户的每个动作、每个细节本质都是转化率，你关不关注而已；拆不出参数，脑子里根本不会有那根弦，连假设都提不出来。
3. **统计不到的参数也必须留着**（L2306-L2356；实操篇-口述 L2586-L2616）：三条理由——①不管统不统计，它是客观已经发生的事实，统计不出来是你的能力问题；②它提升了一定会呈现在上层可统计的目标里（进店率统计不到，收入统计得到）；③留着它才能源源不断涌现假设。「公式归公式，数字归数字」，在相当长时间内公式不完整、节点没有统计意义，写上去依然非常有价值。

## 七、When NOT to Use（边界）

| 场景 | 为什么失效 | 替代 |
|:--|:--|:--|
| 新业务刚起步、样本极少 | 拆细的成本高于收益，参数管理本身有成本（L2004-L2010） | 保留 L1-L2 粗参数 + 留着统计不到的关键参数，螺旋着拆 |
| 想给参数排优先级、判断相关/因果 | 冰山只管「把参数展开」（加法），不管减法和排序（L1448-L1454） | 接 `[[yt-business-formula-six-level-logic]]`（逻辑关系冰山）做因果与定量 |
| 把别家的魔法数字当自己的 | L6 强情境依赖（音量 80 只在那个门店成立） | 迁移必须重测，用自下涌现路径自己挖 |
| 只有一两个大数就想提假设 | 参数层级不到，做不了那个层级的决策（L870-L872） | 先补 L3 切片或 L4 拆解，再谈假设 |
| 指望一次找齐六层 | 参数构建就是认知进步的过程，是多年迭代出来的（一堂从 8-9 个参数到 200+，L608-L610） | 按「先有能力展开，再逐步加深」的节奏走 |

## 八、Failure Modes（症状 → 根因 → 修复）

| # | 症状 | 根因 | 修复 |
|:--|:--|:--|:--|
| 1 | 公式里只有三五个大数，提不出假设 | 停在 L1-L2 水面，脑子里「没那根弦」（L2280-L2288） | 强制做一次 L3 五维切 + L4 四法拆，默认自己丢了 3-5 倍转化率 |
| 2 | 加法越列越多（四五十个参数），执行效率反而变差 | 只展开不收敛，把加法当成了目的 | 冰山负责展开，排序/减法交给逻辑关系冰山；日常只看 30-50 个参数，其余报表留存追溯 |
| 3 | 「这个率统计不出来，删掉吧」 | 把统计能力误当成存在性 | 三条理由留参（第五节第 3 条）：客观存在/上层可统计/催生假设 |
| 4 | 把 L5 相关关系当 L6 魔法数字，资源全压上去 | 没做因果验证——相关可预测不可提升，因果才可提升（L3186-L3192） | 用控制变量/AB 测试验证因果后再倾斜资源（见 `[[yt-business-formula-six-level-logic]]`） |
| 5 | 照搬同行/别家参数清单 | 同行做法本质是假设不是答案；武器库清单「不一定能覆盖你的业务」（L1396-L1398） | 清单只用于举一反三，自己业务的 L5/L6 必须自己定义 |
| 6 | 拆到 L6 回不来了，变成哲学讨论 | 忘记拆是为了行动 | 停钻标准：能提出可验证假设就停，回退到 L4 可操作层执行 |

## 九、Critique（外部攻击与回应）

**1. 「分层模型是事后归纳，不是预测理论」**：L1-L6 确实来自一堂对十几种业务、几百份作业的「案例大爆炸」合并同类项（L1180-L1184），是经验分类学而非公理化理论。回应：它的定位是「检查清单 + 能力地图」而非预测模型——价值在于保证展开时不漏层、且让不同岗位的人用同一套语言，课程也明示「不敢说 100%，95-99% 的参数在这六类里」（L1186）。

**2. Goodhart 定律（指标成为目标就不再是好指标）**：魔法数字一旦被团队当成 KPI 猛刷，可能被博弈（如刷消息数凑 2000 条）。回应：课程对 L6 的使用要求是「找到魔法级因果并藏住」（L3200）——魔法数字是资源倾斜的决策依据，不是公开考核指标；且必须先证因果，相关关系只可用于预测不可用于提升（L3186-L3192）。

**3. 与经典漏斗模型（AARRR 等）的关系**：AARRR 类模型大致覆盖 L1-L4，且在课程十大范式中就是「用户周期型」。冰山的增量在 L5-L6：既有范式找不到解释时的自定义探索。冰山不替代漏斗，是漏斗挖不动时的下钻地图。
