# 业务公式参数冰山（L1-L6）

> 一堂把业务公式中的参数按深度分为 6 层：水面上的 L1-L2 是「靠经验」的基础/财务参数，水面下的 L3-L4 是「靠分析」的分层/转化参数，最深层的 L5-L6 是「靠创新」的创新/魔法参数。  
> 来源：一堂 2026-06-13 业务公式拆解培训（孔阳），「一堂业务公式实操·参数冰山」图。

---

## 冰山模型总览

```
                    直觉
                   L1 基础参数
                   L2 财务参数
    ———————————————————————————— 水面
                   L3 分层参数
                   L4 转化参数
    ————————————————————————————
                   L5 创新参数
                   L6 魔法参数
                    本质
```

| 层级 | 名称 | 能力要求 | 典型问题 |
|---|---|---|---|
| L1 | 基础参数 | 初阶：靠经验 | 流量、线索、订单、收入 |
| L2 | 财务参数 | 初阶：靠经验 | 单元模型、关键指标、财务模型 |
| L3 | 分层参数 | 进阶：靠分析 | 切用户、切渠道、切行为、切场景、切 SKU |
| L4 | 转化参数 | 进阶：靠分析 | 拆首单、拆 LTV、拆动作、拆筛选 |
| L5 | 创新参数 | 高阶：靠创新 | 探索动作、探索数值、探索组合 |
| L6 | 魔法参数 | 高阶：靠创新 | 销售本质、留存本质、复购本质 |

---

## 各层详解

### L1. 基础参数（粗数据）

- **粗流量**：总访问、总曝光
- **粗线索**：总留资、总咨询
- **粗订单**：总订单数
- **粗收入**：总 GMV、总营收

**价值**：知道业务大概规模。  
**局限**：无法指导动作。看到流量低，不知道是该优化渠道还是优化落地页。

### L2. 财务参数（算得清）

- **单元模型**：单客模型、单店模型、单渠道模型
- **关键指标**：CAC、LTV、毛利率、回本周期
- **财务模型**：收入、成本、利润、现金流

**价值**：判断业务是否健康。  
**局限**：只能回答「赚不赚钱」，不能回答「怎么改变」。

### L3. 分层参数（切得细）

把粗参数按维度切分：

| 切分维度 | 示例 |
|---|---|
| 切用户 | 新客/老客、高价值/低价值、活跃/沉睡 |
| 切渠道 | 自然流量/付费流量/推荐流量 |
| 切行为 | 点击/收藏/加购/下单 |
| 切场景 | 工作日/周末、白天/夜间、线上/线下 |
| 切 SKU | 爆款/利润款/引流款 |

**价值**：定位问题出在哪个人群/渠道/场景。  
**关键动作**：找到「异常子群体」。

### L4. 转化参数（拆得透）

把分层后的指标继续拆到转化链路：

- **拆首单**：访问 → 详情页 → 加购 → 结算 → 支付
- **拆 LTV**：首单 → 复购 → 增购 → 推荐
- **拆动作**：点击广告 → 进入落地页 → 填写表单 → 接听电话 → 到店
- **拆筛选**：线索 → MQL → SQL → 商机 → 成交

**价值**：找到漏斗中的具体断点。  
**关键动作**：优化断点，而不是平均用力。

### L5. 创新参数（探得新）

当现有参数无法解释业务变化时，需要探索新参数：

- **探索动作**：用户做了什么之前没关注过的行为？
- **探索数值**：哪个数值区间是临界拐点？
- **探索组合**：哪些参数组合能预测未来结果？

**价值**：发现新的增长杠杆。  
**风险**：容易陷入数据挖掘陷阱，需要假设驱动。

### L6. 魔法参数（看得透本质）

最深层的参数，通常与业务本质相关：

- **销售本质**：用户为什么现在买？为什么跟你买？
- **留存本质**：用户为什么留下？什么场景下必然想起你？
- **复购本质**：用户为什么再次购买？什么信任被建立？

**价值**：决定长期竞争壁垒。  
**局限**：难以量化，需要定性研究和长期观察。

---

## 两个拆解方向

### 从上往下拆解

适用于：已有成熟业务模式，需要优化执行。

1. 流程梳理
2. 已有经验
3. 逻辑推理
4. 最佳实践

### 从下往上涌现

适用于：创新业务或异常分析。

1. 异常分析
2. 变化归因
3. 范式迁移
4. 大胆假设

> 培训原话：「不断研究参数，是每一个高段位管理者的必修课。」

---

## 应用示例：ToC 消费品电商

| 层级 | 参数示例 |
|---|---|
| L1 | 流量 1W UV/天，转化率 2%，复购率 5% |
| L2 | 投流成本 200W，营收 300W，毛利率 40% |
| L3 | 新客转化率 1.5%，老客转化率 5%；付费流量转化率 1%，自然流量转化率 4% |
| L4 | 访问 → 商品页 40% → 结算 10% → 支付 5% |
| L5 | 详情页下滑完成率、评论区停留时长、试听课完课率 |
| L6 | 用户为什么信任一个新品牌？什么场景触发复购？ |
