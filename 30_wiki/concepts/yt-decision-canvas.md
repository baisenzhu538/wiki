# Y模型决策画布（一页纸工具）

> 来源：一堂《科学决策》落地篇。与[[yt-decision-y-model]]配套使用的一页纸落地工具，将"宽度-深度-高度"框架转化为可填写的结构化画布，支持独自决策、团队共识和AI辅助三种场景。

## Summary

Y模型决策画布是一堂科学决策方法论的核心落地工具。它将抽象的"宽度-深度-高度"三维度转化为可直接填写的一页纸结构，通过"列推查"三步法（列清单→推演业务→查盲区）系统化梳理决策要素。画布包含四层深度层级（L0-L4）的停车选择模型，帮助决策者匹配"恰好的深度"而非"最深的深度"。

### ROI决策评估画布结构（源于源图像结构化提取）

画布是一个**三列表格**，强制决策者从**三个维度**和**两个隐性变量**系统性地梳理收益与成本：

| 维度 | 收益项 | 成本项 | 核心问题 |
|:---|:---|:---|:---|
| **基础ROI** | 短期可量化收益 | 短期可量化成本 | 这个决策的直接财务投入产出比是多少？ |
| **长期视角** | 品牌积累、技术壁垒、可持续性 | 长期资源占用、机会成本 | 放到3年/10年后，这个决策的收益和成本会怎么变？ |
| **公司视角** | 协同效应、组织能力提升、战略alignment | 跨部门成本、管理成本、文化冲击 | 从整个公司而非单一部门看，这个决策的网络效应是什么？ |
| **机会成本**（隐性变量） | 被放弃的最佳替代方案的价值 | — | 做这个决策意味着放弃什么？那个放弃的选项值多少？ |
| **时间窗口**（隐性变量） | — | 市场时机、资金占用周期、决策延迟风险 | 红利期是否过期？时间本身是不是最大成本？ |
| **最终结论**（跨列总结） | 综合以上所有维度的收益与成本，给出明确决策判断 | — | — |

## 填了画布但决策没变

画布最常见的失败不是"填错了"，而是"填完了但没什么变化"。

### 原因一：画布成了"填完存档"的装饰品

**问题**：创始人花 30 分钟填了画布，结论贴在墙上。下周开周会时没人再看它，做决策时还是靠直觉。

**修复**：画布必须有"决策出口"——填完后写一句"基于画布分析，我的决策是XXX"。下次回头看时先看决策，再看画布是否支持该决策。

### 原因二：画布暴露了冲突但没解决冲突

**问题**：画布分析显示方案A收益大但风险也大，方案B收益小但稳定。团队看完后僵住了——都知道"选A吧"和"选B吧"各有道理，但不做决断。

**修复**：画布不只是分析工具，也是"决策制造器"。填完后必须设定一个硬截止时间——"我们再用30分钟讨论分歧点，30分钟后无论是否达成一致，决策者拍板。"

### 原因三：画布结论和直觉打架时，人选择相信直觉

**问题**：画布分析说方案A的ROI是B的两倍。但创始人的直觉一直告诉他选B。犹豫了一周后，选了B。

**修复**：不是画布错了，是画布的分析漏掉了某个关键的定性因素（创始人知道的但没写在画布上的）。这种情况的修复不是"更精确地填画布"，而是**把漏掉的那条隐性因素找出来并显式化**——写在画布的成本栏或收益栏里，让它在分析中占一席之地。

## 案例：B2B 机票服务转型决策

> 素材来源：一堂 To B 五步法优秀作业合集（张林：B2B 机票服务拆解）。本案例展示如何把"感觉应该转型"变成"按画布逐项判断、给出可执行结论"。

**背景**：公司原业务为 B2B 机票服务，已是行业前三，增长遇到瓶颈。团队手握航司价格优势与 20 万 B 端客户资源，考虑转型为"企业一站式差旅服务解决方案"。

**第一步：宽度区——列推查**（调用 [[yt-decision-width-method]] 的"列推建查"思路）

| 维度 | 收益项 | 成本项 |
|:---|:---|:---|
| 直接财务 | 年差旅费 100 万+企业可省 20% 费用；新增酒店/火车票佣金 | 300 人研发团队投入、售前成本、SaaS 运维 |
| 战略价值 | 从机票代理商升级为差旅管理平台，客户 LTV 提升 | 传统机票业务被平台化侵蚀 |
| 组织价值 | 复用航司资源与 B 端客户基础 | 机票部门与新业务部门的目标冲突、销售资源分流 |
| 隐性价值 | 客户数据沉淀，未来可做供应链金融 | 数据合规成本、客户隐私风险 |

## 画布落地检查清单

填完画布后，用下面 7 个问题自检。若"是"<5 个，回到对应区域补全，不要急着执行。

| 检查项 | 是 | 否 | 说明 |
|:---|:---:|:---:|:---|
| 1. 画布顶端写明了具体决策命题（A vs B 或做 vs 不做） | ☐ | ☐ | 避免"分析某个方向"这类模糊命题 |
| 2. 宽度区列出 ≥5 条收益和 ≥5 条成本 | ☐ | ☐ | 调用 [[yt-decision-width-method]] 的三层盲区清单 |
| 3. 已圈出前 3 个关键项，并标注置信度和数据来源 | ☐ | ☐ | 高/中/低置信度 + 来源（如"行业 benchmark""内部数据"） |
| 4. 深度区选择了与决策价值匹配的 L1-L4 层级 | ☐ | ☐ | 小决策停在 L1/L2，重大决策下探 L3/L4 |
| 5. 高度区填写了长期视角、机会成本、时间窗口 | ☐ | ☐ | 缺任意一项，高度区即不完整 |
| 6. 关键数字 ±30% 时，结论不会翻转 | ☐ | ☐ | 若翻转，说明该数字是决策关键，需进一步验证 |
| 7. 画布底部有明确决策结论、负责人、截止时间 | ☐ | ☐ | 决策出口是画布区别于分析报告的标志 |

**通过标准**：≥5 个"是"可进入执行；3-4 个"是"需补全对应项；≤2 个"是"建议重填，或改用 [[yt-decision-ai-partner]] 做结构化对话。

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:------|
| ✅ 决策者领域认知≥中 | 对涉及的领域有基本了解，知道关键变量在哪里。零基础者填的画布是"虚假精确" |
| ✅ 决策时效≥1天 | 画布分析需15-30分钟+后续讨论。2小时内要决策的场景来不及 |
| ✅ 决策有可比较的备选方案 | 画布需要"换不换"或"A vs B"的对比对象；只有一个方案时容易陷入"做不做"的单一视角 |
| ❌ 价值观冲突型决策 | 当分歧在价值观层面（如"是利润优先还是社会价值优先"），画布无法解决——先做价值观澄清 |
| ❌ 高频微决策 | 每天调整的小决策，画布的分析成本高于决策边际价值——设规则替代逐案分析 |

#| 模式 | 症状 | 修复 |
|:-----|:------|:------|
| **"填完即存档"** | 画布填完贴在墙上，后续会议/决策未引用，下次仍凭直觉 | 画布必须带"决策出口"：填完后写出具体决策结论、负责人、截止时间，并放入决策追踪表 |
| **"暴露冲突不解决"** | 画布显示A收益大但风险高、B稳定，团队僵持30分钟以上不拍板 | 设定硬截止时间：再讨论15分钟后决策者必须拍板；若仍不一致，选择"可撤回成本最低"的方案先跑 |
| **"直觉胜于画布"** | 画布结论选A，但创始人/关键人凭直觉选B，一周后B被执行 | 把直觉中"没说出来的隐性因素"显式化：写在画布的收益/成本栏，并标注其证据来源；若无法显式化，承认是偏好差异 |
| **"过度分析症"** | 午餐吃什么、A/B测试按钮颜色也填完整画布，团队疲劳 | 设定决策阈值：投入<1万、影响<3人、2小时内可撤回的决策，用简单规则或直觉 |
| **"深度与价值错配"** | 关键收购决策停在L1定性，午餐吃什么却算到L3定量 | 决策前先用"投入金额×影响人数×不可逆程度"打分，>阈值才进入L3/L4；小决策强制停在L1/L2 |
| **"话语权污染画布"** | 创始人/高管的项全保留，其他人的项被快速否定 | 采用"匿名预写→公开贴条→独立投票"三步：关键项由证据强弱决定，而非职位高低 |

## Synthesis

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **决策者缺乏足够的领域认知来识别关键变量**（如一个从未管过团队的员工突然要决定"是否接受管理岗"） | 画布的核心是"找全→找关键"，但如果你连"管理岗涉及哪些维度"都没有概念，画布填充会变成"虚假精确性"——把"我以为"包装成"我分析过"。每个填进去的数字都是拍脑袋，只是拍得更整齐。 | 先不做画布，做"领域体验式学习"——在1个月内找3个现任管理者做深度访谈（问"你当初接受管理岗后，最意外的成本和收益是什么"），再用他们的答案作为画布的输入。没有输入质量，画布只是空壳。 |
| **决策收益和成本高度依赖主观价值判断、各方价值体系差异极大**（如家庭内部关于子女教育的决策、合伙人关于"公司要不要追求社会影响力"的分歧） | 画布要求把不同价值体系统一到同一货币单位（或同一评分标准），但"孩子的幸福感"和"升学率"之间不存在可通约的换算率。强行量化会让争论从"什么对孩子更好"变成"你的权重为什么给0.3而不是0.4"——偏离了真正的分歧点。 | 改用"价值观澄清对话"：双方各自独立写出"这个决策中我最不能妥协的3个底线"，然后比较底线是否冲突。如果冲突，分歧在价值观层面，任何分析工具都无法解决；如果不冲突，再对非底线部分用画布分析。 |
| **需要快速迭代、频繁调整的运营决策**（如每日广告投放预算分配、每周内容发布排期） | 画布分析耗时15-30分钟/次，而运营决策可能每天调整。工具的分析成本远高于决策本身的边际价值，导致"用大刀切黄油"——过度分析拖慢执行节奏。 | 设定"决策规则"替代"逐案分析"：如"单日预算波动<20%时，直接按上周数据*1.05执行；只有波动>20%或连续3天ROI<阈值时，才启动画布分析"。把认知资源留给异常值。 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **老板要求"明天给我方案"，自己只有模糊直觉** | 打开画布，强制用L1定性层填完宽度区——不追求定量，只要求"列出所有能想到的收益和成本，圈出前3个最关键的"。把"定量焦虑"推迟到第二轮 | 15分钟内完成宽度区填写，至少列出5条收益+5条成本，其中≥1条是"写的时候才想到的"而非"早就知道的"。如果全是早就知道的，说明列推查查得不够 |
| **团队一起填画布时，某人的项总是被打压或忽略** | 暂停填写，引入"匿名预写"规则：每个人先独立写5分钟，再贴到白板上。消除现场话语权差异后再讨论 | 匿名阶段的项数量 ≥ 公开讨论阶段的2倍；至少有1条匿名项在讨论中被升级为"关键项" |
| **填完画布后仍然无法判断，因为关键项的量化差距太大**（如一边300万成本，一边全是定性收益） | 启动"替代成本折算"：把定性收益翻译成"如果不用这个方案，替代方案要花多少钱实现同等效果"。如"员工士气"→"士气低落导致离职，替换1个员工的招聘培训成本是X万" | 至少把2条定性收益折算为可比较的数字；如果某条定性收益"找不到任何替代成本"，标注为"不可量化因子"，由决策者直接判断 |
| **做完决策后复盘，发现漏掉了关键成本项** | 检查盲区清单：对照个人/团队/企业三类盲区清单，逐项问"这次我查了哪几项？漏了哪几项？"把漏掉的项加入个人定制化盲区清单 | 生成≥3条"个人专属盲区"（如"我总是忽略跨部门沟通成本"），下次决策前强制检查 |
