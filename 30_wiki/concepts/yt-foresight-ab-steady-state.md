---# AB点稳态模型：行业预判的核心框架

## Core Claims

1. **行业预判研究的是"稳态之间的过渡"**——一个行业通常会长期处于稳态A（格局稳定、头部明确、利润率可预期），直到被某个变化（技术/政策/消费习惯/人口）打破，经历一段动荡期后进入稳态B。真正的大机会出现在A→B的过渡过程中。

2. **"没有变化就没有大机会"**——如果行业长期稳定，靠个人能力去突破几乎不可能。"大变化带来大机会，价值链重构就是你的窗口。"这就是为什么AI时代让所有人兴奋——它可能在几乎所有行业触发A→B的过渡。

3. **行业分析的六要素**——拆产业链 → 洞察变化 → 预判下一个稳态 → 判断周期 → 判断天花板 → 判断集中度。六个要素填出来，就完成了对行业的系统分析。

4. **不同终局目标需要不同深度的行业预判**——L2-L3（单体/小规模）只需要看周期和基本红利；L4-L5（体系增长/细分头部）必须做商业预判和团队预判；L6（做大上市）必须做行业预判，不会行业预判就是重大硬伤。

## The AB Model

```
稳态A ──[变化]──→ 动荡期 ──[收敛]──→ 稳态B
(旧格局)          (机会窗口)          (新格局)

你的工作：
1. 识别当前处于哪个位置（稳态A的末期？动荡期？）
2. 预判下一个稳态B长什么样
3. 在动荡期中找到你能切入的环节
```

### 行业分析六要素

| 要素 | 核心问题 | 方法 |
|:-----|---------|------|
| **拆产业链** | 这个行业从上游到下游有哪些环节？利润集中在哪个环节？ | 画出产业链图谱，标注每个环节的利润率、集中度、关键玩家 |
| **洞察变化** | 产业链的什么环节在发生什么变化？（技术/政策/消费/人口） | 追踪行业新闻、政策文件、头部公司动向、用户行为数据 |
| **预判稳态** | 变化结束后，行业格局大概会长成什么样？ | 参考成熟市场的行业结构，结合本地特性做推演 |
| **判断周期** | 这个变化从开始到结束大概多长？你现在处于什么阶段？ | 对标类似行业的历史演变时间线 |
| **判断天花板** | 新稳态下这个市场的总规模有多大？ | TAM/SAM/SOM 三层测算 |
| **判断集中度** | 这个行业天然是分散的还是集中的？头部能占多少份额？ | 参考该行业在成熟市场（如美国/日本）的CR3/CR5数据 |

### 外部攻击

**Clayton Christensen**（《创新者的窘境》）会补充：有些最大的行业变化来自边缘市场的低端颠覆，而非产业链内部的变化。AB模型关注产业链内的稳态切换，可能忽略来自产业链外的颠覆性力量。

**Nassim Nicholas Taleb**会警告：行业变化往往不是渐进的A→B过渡，而是跳跃性的"黑天鹅"事件。用稳态思维去预测非稳态过程，本质上是用线性模型去预测非线性现象。

## Action Triggers

1. **追求头部的项目在立项前必须完成六要素分析**——缺一个要素就是预判盲区。
2. **定期（每季度）更新行业变化信号**：追踪12大变化模型中与本行业相关的维度，评估是否触发了新的A→B过渡。
3. **做产业链拆解时画出来**——光在脑子里想不够，必须可视化到一张图上，标注每个环节的利润率和玩家。
