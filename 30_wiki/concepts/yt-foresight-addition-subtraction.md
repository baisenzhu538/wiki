# 加法减法实操：从100个选项到3个高概率方向

## Core Claims

1. **加法有三条轴**——横向拆行业（选哪个大行业？）、纵向拆产业链（选产业链的哪个环节？）、按要素拆商业模式（定价/渠道/产品/人群/城市怎么组合？）。三条轴交叉笛卡尔积，一个idea可以拆出几十到上百个细分选项。

2. **加法的质量标准是"充分"**——不是随便列几个选项就叫加法。Truman的标准：**做出来的选项池要让别人看了觉得"原来还有这么多可能性"**。古董做奶茶时每一步都在20-30个选项中筛选，最终选项池覆盖了4-5层维度。

3. **减法有层次，不能一步到位**——第一层：排除明显不靠谱的（能力完全不匹配、资源明显不够、市场明显不存在）；第二层：用商业逻辑深入分析剩余选项的硬伤；第三层：只保留逻辑上"无硬伤"的2-3个选项进试错阶段。

4. **减法的核心能力是"识别硬伤"**——不是凭感觉"觉得不行"，而是能具体说出"这个选项在哪个维度上有什么硬伤，为什么这个硬伤是致命的"。这需要积累行业经验和对商业模式的理解。

5. **菱形钻石模型**——整个预判过程是发散（加法）再收敛（减法）：从模糊想法发散到100个选项，再收敛到3-5个高概率方向，最后锁定1个Plan A + 2个Plan B。

### 外部攻击

**Gary Klein**（自然决策理论）会指出：经验丰富的创业者做决策时不是"先发散再收敛"，而是通过**模式识别**直接跳到少数几个可行选项。加法减法框架适合新手，但对老手可能过度工程化了。

**Barry Schwartz**（《选择的悖论》）会警告：选项太多会导致决策瘫痪和决策后满意度下降。100个选项里选出3个的过程本身可能耗尽决策者的认知资源，导致最终选择反而质量下降。

## Action Triggers

1. **接到新项目时，第一步不是想"怎么做"，而是拿一张白纸列出三根轴**（行业/产业链环节/商业模式要素），逐个填满选项。
2. **做完加法后问自己**："我列出来的选项数量是不是让一个外行看了觉得超乎想象？"如果不是，回去继续加。
3. **做完减法后逐条记录排除理由**：每个被排除的选项都要写"排除原因：属于哪类硬伤？"，防止情绪化排除。
