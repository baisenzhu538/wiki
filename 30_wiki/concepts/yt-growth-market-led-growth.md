# 市场驱动增长：MLG模式

> 一堂五步法：市场驱动增长不是做广告，而是系统化的品牌建设和需求生成。市场为销售提供弹药。

## 核心框架

市场驱动增长的核心流程：

```
品牌认知 → 需求生成 → 线索培育 → 线索交接 → 销售跟进 → 成交
```

| 阶段 | 市场职责 | 销售职责 |
|:---|:---|:---|
| **品牌认知** | 品牌建设、内容营销 | 配合 |
| **需求生成** | 广告、活动、SEO | 配合 |
| **线索培育** | 内容、邮件、社群 | 配合 |
| **线索交接** | 评分、筛选 | 接收 |
| **销售跟进** | 配合 | 主导 |
| **成交** | 配合 | 主导 |

## 关键洞察

### 1. MLG的适用条件

| 条件 | 说明 | 评估 |
|:---|:---|:---|
| **品牌重要** | 品牌影响购买决策 | 适合MLG |
| **需求教育** | 用户需要教育才能理解价值 | 适合MLG |
| **内容驱动** | 内容能影响用户决策 | 适合MLG |
| **规模化获客** | 需要规模化获客 | 适合MLG |
| **长期价值** | 品牌建设长期价值 | 适合MLG |

### 2. 市场活动的类型

| 类型 | 说明 | 适用 | 示例 |
|:---|:---|:---|:---|
| **内容营销** | SEO、博客、白皮书 | B2B | 行业报告 |
| **社交媒体** | 社交账号运营 | B2C/B2B | 微信公众号 |
| **付费广告** | SEM、信息流 | 所有 | 百度推广 |
| **活动营销** | 展会、 webinar | B2B | 行业峰会 |
| **公关传播** | 媒体报道、新闻稿 | 品牌 | 融资报道 |
| **社群运营** | 用户社群 | 社区 | 微信群 |

### 3. 线索评分模型

| 维度 | 说明 | 评分 |
|:---|:---|:---:|
| **人口统计** | 公司规模、行业 | 1-10 |
| **行为** | 网站访问、内容下载 | 1-10 |
| **参与度** | 邮件打开、活动参与 | 1-10 |
| **意向** | 试用、询价 | 1-10 |
| **总分** | 综合评分 | 40+ → 销售跟进 |

### 4. 市场与销售的协同

| 协同点 | 说明 | 机制 |
|:---|:---|:---|
| **目标一致** | 共同对收入负责 | 共同KPI |
| **线索交接** | 清晰定义MQL、SQL | SLA协议 |
| **反馈闭环** | 销售反馈线索质量 | 定期会议 |
| **内容协同** | 销售需要的内容市场提供 | 内容需求 |
| **数据共享** | 共用CRM数据 | 系统打通 |

### 5. MLG的评估指标

| 指标 | 说明 | 健康标准 |
|:---|:---|:---|
| **MQL数量** | 市场合格线索 | 持续增长 |
| **MQL到SQL转化率** | 线索质量 | > 30% |
| **SQL到成交转化率** | 销售效率 | > 20% |
| **市场贡献收入** | 市场带来的收入 | 可衡量 |
| **品牌认知度** | 目标受众认知 | 提升 |
| **CAC** | 市场获客成本 | < LTV/3 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **市场与销售脱节** | 目标不一致 | 共同KPI |
| **忽视线索质量** | 只追求MQL数量 | 线索评分 |
| **市场活动不衡量** | 不知道ROI | 数据驱动 |
| **品牌建设滞后** | 只追求短期线索 | 长期品牌投入 |
| **内容不匹配** | 内容不对用户旅程 | 用户旅程分析 |
| **忽视培育** | 线索直接交给销售 | 线索培育 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 品牌建设 | 纯技术架构 |
| 规模化获客 | 纯关系销售 |
| 需求教育 | 纯产品驱动 |
| 长期价值 | 短期投机 |

## 行动触发器

- 当品牌重要时 → 市场驱动
- 当需要规模化获客时 → 市场活动
- 当用户需要教育时 → 内容营销
- 当市场与销售脱节时 → 建立协同机制
