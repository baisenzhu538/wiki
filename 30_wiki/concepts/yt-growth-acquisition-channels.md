# 获客渠道：流量获取的6大类型

> 一堂五步法：获客渠道不是越多越好，而是需要匹配产品和用户。每个渠道都有成本、质量、规模的权衡。

## 核心框架

获客渠道的6大类型：

| 类型 | 说明 | 成本 | 质量 | 规模 | 可控性 |
|:---|:---|:---:|:---:|:---:|:---:|
| **付费广告** | SEM、信息流、展示广告 | 高 | 中 | 高 | 高 |
| **内容营销** | SEO、博客、视频、播客 | 中 | 高 | 中 | 中 |
| **社交传播** | 社交媒体、社群、KOL | 低 | 中 | 高 | 低 |
| **口碑推荐** | 老用户推荐、裂变 | 低 | 高 | 中 | 低 |
| **渠道合作** | 合作伙伴、分销 | 中 | 中 | 中 | 中 |
| **直销** | 销售团队直接获客 | 高 | 高 | 低 | 高 |

## 关键洞察

### 1. 渠道选择矩阵

| 维度 | 评估 | 决策 |
|:---|:---|:---|
| **用户匹配度** | 渠道用户是否匹配目标用户 | 匹配→选择 |
| **CAC** | 渠道获客成本 | 低于LTV→选择 |
| **转化率** | 渠道用户转化率 | 高于平均→选择 |
| **规模化** | 渠道能否规模化 | 能→优先 |
| **可持续性** | 渠道是否可持续 | 是→长期投入 |

### 2. 渠道组合策略

| 策略 | 说明 | 示例 |
|:---|:---|:---|
| **单一渠道深耕** | 聚焦一个渠道做到极致 | 早期小红书 |
| **多渠道组合** | 多个渠道互补 | 广告+内容+口碑 |
| **渠道迁移** | 从低成本渠道到高成本渠道 | 从口碑到广告 |
| **渠道创新** | 发现新渠道 | 抖音早期 |

### 3. 渠道ROI评估

```
渠道ROI = (渠道带来的收入 - 渠道成本) / 渠道成本

渠道LTV/CAC = 渠道用户LTV / 渠道CAC
```

| 指标 | 说明 | 健康标准 |
|:---|:---|:---|
| **CAC** | 单用户获客成本 | < LTV的1/3 |
| **ROI** | 投资回报率 | > 1 |
| **LTV/CAC** | 用户生命周期价值/获客成本 | > 3 |
| **回收周期** | CAC回收时间 | < 12个月 |

### 4. 渠道的窗口期

| 阶段 | 特征 | 策略 |
|:---|:---|:---|
| **红利期** | 成本低，竞争少 | 快速规模化 |
| **成熟期** | 成本上升，竞争加剧 | 优化效率 |
| **衰退期** | 成本过高，ROI下降 | 寻找新渠道 |

### 5. 渠道与产品匹配

| 产品类型 | 适合渠道 | 不适合渠道 |
|:---|:---|:---|
| **B2B SaaS** | 内容营销、直销、渠道合作 | 社交传播 |
| **B2C电商** | 付费广告、社交传播 | 直销 |
| **内容产品** | 社交传播、内容营销 | 直销 |
| **工具产品** | 产品驱动、口碑推荐 | 付费广告 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **渠道选择不当** | 渠道用户不匹配 | 用户调研，匹配渠道 |
| **过度依赖单一渠道** | 渠道风险高 | 多元化渠道 |
| **忽视渠道质量** | 流量大但转化低 | 关注转化率 |
| **渠道成本失控** | CAC持续上升 | 优化渠道效率 |
| **错过窗口期** | 渠道红利期已过 | 快速识别新渠道 |
| **渠道与产品不匹配** | 渠道用户不是目标用户 | 重新评估渠道 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 获客策略设计 | 技术架构设计 |
| 渠道优化 | 品牌传播策略 |
| 增长实验 | 运营活动评估 |
| 规模化获客 | 纯公益项目 |
