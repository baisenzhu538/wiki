# OKR 制定与复盘罗盘

> 来源：一堂《目标管理》课程工具化升级。OKR 是管理者将模糊战略转化为可执行目标的核心工具——本罗盘提供一套包含"目标设定→关键结果量化→周度脉搏→季度复盘"的完整周期流程，防止 OKR 滅为 KPI 换皮或"写完就忘"。

## Summary

OKR 制定与复盘罗盘是一套周期性目标管理工具，核心目标是：让团队每个季度都有清晰的"往哪里突破"方向，每周都有可追踪的进展脉搏，每次复盘都能产生"下一季度怎么做得更好"的行动。本工具不求"完美的 OKR"——它求"能跑起来的 OKR"，跑起来了才能迭代。

## Claims

### 进入标准：什么时候需要用本工具

以下任何一条触发，即需使用本工具：

1. **季度初需要制定团队/公司级目标**
2. **上一个周期 OKR 完成率 <60%或 >100%**（过低说明目标设得不切实际，过高说明目标设得太低）
3. **团队每天忙碌但不知道"终极目标是什么"**
4. **多部门协作时频繁出现"各自为政"或"目标冲突"**

**如果以下情况，不用本工具：**
- 公司处于 0→1 探索期，方向每天都在变（用"假设验证"替代 OKR）
- 团队 <3 人且业务稳定（用简化的"每周 3 件事"清单替代）
- 只需要维护现状不需要突破（用 KPI 而非 OKR）

### 操作步骤：OKR 周期罗盘

#### Step 1：目标设定（O）（季度第一周，2-3 小时）

**目标**：产出 3-5 个方向清晰、激励人心的 Objectives。

**进入标准**：只有当"战略方向已确定"时才开始设定 OKR。如果战略方向不确定，先用[[yt-tool-strategy-workshop]]开战略会。

**操作流程**：

```
OKR 设定流程
┌──────────────────────────────────────┐
│ Step 1.1 上层对齐（顶层发布公司级 OKR）          │
│ Step 1.2 团队头脑风暴（各团队提交 3-5 个 O 候选）      │
│ Step 1.3 一对一对齐（经理与下属讨论每个 O）        │
│ Step 1.4 锁定公开（全员可见，接受质询）          │
└──────────────────────────────────────┘
```

**关键约束**：
- 每个团队 3-5 个 O，每个 O 3-5 个 KR，超出就是"没有重点"
- 30-50% 的 O 应来自团队自下而上的提案（而非全部上级拆解）
- O 必须是定性的、激励人心的，不能含数字

#### Step 2：关键结果量化（KR）（与 Step 1 同期完成）

**目标**：为每个 O 配备可量化、有挑战性、有时限的 KR。

**好 KR 的检查清单**（每个 KR 必须通过所有 5 项）：

| 检查项 | 通过标准 | 失败例子 |
|--------|---------|---------|
| Specific | 具体指向什么 | "提升用户满意度"→太模糊 |
| Measurable | 有明确数字 | "努力做好"→不可测量 |
| Achievable | 有挑战但可实现（完成 70% 即为优秀） | "NPS 从 30 提升到 90"→不可能 |
| Relevant | 与 O 直接相关 | "重新设计 logo"→与"提升用户留存"无直接关系 |
| Time-bound | 有截止日期 | "提升 NPS"→没有时间节点 |

**关键约束**：
- KR 必须是"结果"而非"任务"——不是"发布新功能"，是"新功能上线后日活跃用户增加 X%"
- 每个 KR 必须有"基准值"和"目标值"，否则无法判断是否达成
- 最好的 KR 直接来源于业务公式（见[[yt-management-business-formula]]）

#### Step 3：周度脉搏（每周/每双周，30 分钟）

**目标**：每周都有可视化的进展追踪，及时发现偏航。

**周度脉搏模板**：

```
周度脉搏（___月___日）
┌──────────────────────────────────────┐
│ O1: _______________________________ │
│   KR1: ___% → ___% → 目标 ___%     │
│   KR2: ___% → ___% → 目标 ___%     │
│   本周进展：●/○/○○               │
│   封锁事项：_______________________  │
│                                    │
│ O2: _______________________________ │
│   KR1: ___% → ___% → 目标 ___%     │
│   本周进展：●/○/○○               │
│   封锁事项：_______________________  │
└──────────────────────────────────────┘

进展标记：●=按计划推进 / ○=比计划慢 / ○○=明显偏航
封锁事项：本周最需要解决的 1 个阻碍
```

**关键约束**：
- 脉搏不是"汇报"——不是"我做了什么"，是"目标进展到哪里了、遇到什么阻碍"
- 每个脉搏必须产出 ≥1 个"封锁事项"——如果没有封锁事项，说明 OKR 定得太保守了
- 脉搏时间固定（如每周一上午 10:00），不能被其他会议挤掉

#### Step 4：季度复盘（季度末，2-3 小时）

**目标**：检查完成率、分析偏差原因、产出下一季度改进动作。

**复盘流程**：

| 步骤 | 时长 | 核心动作 | 产出 |
|------|------|---------|------|
| 数据展示 | 15min | 每个 KR 的实际完成率 | 完成率分布图 |
| 偏差分析 | 30min | 对每个未达成的 KR 问"为什么"——是目标不切实际、资源不足、还是执行问题 | 偏差分类统计（目标问题/资源问题/执行问题） |
| 经验抽取 | 30min | 对每个完成率 >80% 的 KR 问"做对了什么"——是否可复制 | 可复制成功因素清单 |
| 下季改进 | 45min | 针对偏差分析产出的问题，制定下一季度的 1-2 个改进动作 | 改进动作清单（含负责人+截止日期） |
| 示例传播 | 15min | 选择本季度最好的 1 个 KR 和最失败的 1 个 KR，在全公司分享 | 复盘文档 |

**关键约束**：
- 复盘不考核人——不问"谁的责任"，只问"下次怎么做对"
- 复盘必须产出"下季度改进动作"——没有改进动作的复盘是"表演"
- 完成率只是参考，不是目标——70% 完成率通常是最佳状态（说明目标有挑战性且没有严重偏离）

### 退出标准

**当以下情况发生时，本工具需要被修订或替换**：
- 连续 2 个季度完成率 >100% → OKR 设得太保守，需要提高挑战度
- 连续 2 个季度完成率 <30% → OKR 设得不切实际，需要降低难度或增加资源
- 周度脉搏连续 3 周被取消 → 脉搏时间保护机制失效，需要重新调整
- 团队反馈"OKR 是额外负担"→ 需要检查 OKR 与日常工作的链接是否清晰

### 常见陷阱

| 陷阱 | 现象 | 防御方案 |
|------|------|---------|
| **OKR 变 KPI** | OKR 与奖金挂钩，团队自然压低目标 | 明确宣布"本季度 OKR 不与奖金挂钩"，且第一季度只用来"练习"，不考核 |
| **任务清单化** | KR 写成"完成 XX 功能"而非"达成 XX 效果" | 每个 KR 必须有"基准值"和"目标值"，且目标值是"结果"而非"任务" |
| **过度拆解** | 一个公司级 O 被拆成 50 个部门级 OKR | 拆解到部门级即止，不再往下拆——个人目标用"支持我的部门 OKR"来定义 |
| **写完就忘** | 季度初写完，季度末才想起来 | 周度脉搏必须有"固定时间+固定主持人+固定模板" |
| **只有加法没有减法** | 每个季度都是"做更多"，从来不"停掉什么" | 每季度至少 1 个 O 是"停止做 XX"或"不再投入 XX" |

## Constraints & Boundaries

- claim:boundary-01 [conf=0.85] **OKR 与绩效脱钩在中国创业公司现实中难以执行**：课程主张 OKR 不与奖金挂钩，但大多数创业公司的创始人和 HR 难以放弃"用数据考核人"的本能。OKR 自然滑向 KPI 化是高概率事件。
- claim:boundary-02 [conf=0.80] **探索期业务不适合 OKR**：OKR 假设方向基本清晰、只需要量化执行。但在还在探索 PMF 的早期团队，方向每天都在变——写完的 OKR 第二天就过时了。
- claim:boundary-03 [conf=0.80] **创造性工作者对指标的抵触**：设计师、研究人员、内容创作者等创造性岗位对"数量化目标"天然抵触——KR 的"产出 X 个方案"会挤出内在动机。
- claim:boundary-04 [conf=0.75] **"好的 KR"不等于"好的业务结果"**：KR 可以被操纵（如调整统计口径、提前确认订单）来达成，但业务价值未必同步增长。

## Critique

### 外部攻击

#### Henry Mintzberg：战略不是定出来的——是涌现出来的，OKR 在假装战略是可计划的

**Henry Mintzberg**（McGill University，"Managers Not MBAs"作者）在战略管理领域提出了"趋然战略"（Emergent Strategy）理论——这对 OKR 的核心假设发起了直接攻击。Mintzberg 区分了两种战略：

- **意图战略（Deliberate Strategy）**：领导者制定的、明确的、有计划的战略——OKR 假设的正是这种战略。
- **趋然战略（Emergent Strategy）**：在实际运营中自然涌现的、未被预计划的战略——Mintzberg 认为这种战略往往比意图战略更有效。

Mintzberg 的核心论点：

1. **真实的战略是"做出来的"而非"写出来的"**：你在季度初写下的 OKR 是一套"意图"——但真正决定公司命运的可能是某个销售代表在与客户通话时偶然发现的新需求，或某个工程师在修 bug 时偶然想到的新解决方案。这些"趋然"的事情不会出现在你的 OKR 里——但它们可能比你的 OKR 更重要。

2. **OKR 的"定期复盘"可能正好压制了趋然战略**：每周的脉搏会比你的 OKR 偏离发出警报——"我们走偏了，回到 OKR 上来"。但 Mintzberg 会说：偏离可能是好事。偏离可能意味着你正在发现一个比原计划更有价值的方向。用 OKR 来"守护方向"，你可能正在守护一个错误的方向。

3. **最成功的公司往往"没有很好的计划"**：Mintzberg 研究了大量成功企业的战略路径，发现它们的战略往往是"回应性"的——根据环境变化快速调整，而非"预先计划好然后严格执行"。OKR 的"写完就锁定"与这种回应性文化存在内在张力。

> **Mintzberg 让 OKR 使用者睡不着觉的问题**：你今年 Q1 写了"聚焦企业级市场"的 OKR，团队每周脉搏都在追踪这个目标的进展。但三月中旬，一个销售代表偶然发现了一个从未想过的客户群体，需求极大。你面临两个选择：A. 按照 OKR 继续聚焦企业级市场，把新发现当作"噪音"；B. 调整 OKR 去追踪新机会。如果你选 A——Mintzberg 会问你：你是在执行战略，还是在执行一套年前写下的文档？如果选 B——你的 OKR 流程在"开放性"上的设计是什么？如果没有这种设计，你的 OKR 可能正在强迫你选择 A。

#### Lisa Ordonez：目标有副作用——而且这些副作用让你的组织更危险

**Lisa Ordonez**（University of Arizona，*目标副作用* 研究者）对目标管理的副作用发起了第二道攻击。Ordonez 系统性地整理了"目标设定"带来的负面后果，得出了一个让所有 OKR 使用者不寒而栗的结论：**目标设定不是无价值的——但它的代价很大，而大多数组织根本不知道自己在付什么代价。**

Ordonez 的核心发现：

1. **目标导致风险偏好下降**（Risk Aversion）：当人们有明确的目标时，他们会避开任何可能威胁目标完成率的行为——即使这些行为可能有长期价值。你设了"客户满意度 90%"的 OKR，团队会避开所有"有风险但有突破性"的创新——因为创新可能导致客户不满意。

2. **目标导致不道德行为增加**：Ordonez 的实验表明，当目标难度提高时，人们更可能采用不道德方式来达成目标——不是因为他们是"坏人"，而是因为目标本身创造了这种压力。你的 OKR 越有挑战性，你的团队越可能在"数据上做手脚"。

3. **目标挤出创造性和内在动机**：当人们被"强制设定目标"时，他们的内在动机（好奇心、自主性、成就感）会被外在动机（完成目标的压力）挤出。长期来看，这会降低团队的创造力和工作满足度。

> **Ordonez 让 OKR 使用者睡不着觉的问题**：你的团队今年 Q2 OKR 完成率 95%。你觉得很成功。但 Ordonez 问你：这 95% 的完成率里，有多少是通过"避开有风险的创新"换来的？有多少是通过"数据操纵"换来的？有多少是通过"让最优秀的员工加班到煽烧"换来的？如果你诚实回答，这个数字可能让你重新考虑"成功"的定义。

### 内部局限

- **周度脉搏变成"形式主义"**：团队可能在脉搏时只报告"好的"信息，避开"坏的"信息——脉搏变成了"演出"。
- **"改进动作"的执行率被低估**：季度复盘产出的"改进动作"很少被真正执行，因为下一季度开始时又被新的 OKR 覆盖了。
- **KR 的"基准值"设定被忽视**：很多团队只设定"目标值"不设定"基准值"，导致无法判断"是否真的进步了"。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **公司处于 0→1 探索期，方向不确定度极高**（如每周都在 pivot 的早期创业团队） | OKR 假设"方向基本清晰，只需要量化执行"。但在探索期，你连"正确方向"都不知道，KR 是建在流沙上的。Deming 的制度主义：在没有稳定过程的系统中引入目标管理，你不会得到更好的结果——你会得到更聪明的借口。 | 用"假设驱动"替代 OKR：每周列 3-5 条关于产品的关键假设（"用户会因为 X 付费"），每条配一个"验证方法"和一个"本周要做的验证动作"。目标是"学得快"而非"做到某个数字"。验证速度是唯一需要追踪的指标。 |
| **面对高度创造性工作（如研发、设计、内容创作）且产出质量比产出速度更重要** | Muller 指出：创造性工作最有效的激励是内在动机（自主性+专精+目的），外在指标会挤出内在动机。如果设计师的 OKR 是"产出 20 个方案"，他会产出 20 个平庸方案并在 2 个月内离职——因为他来不是为了批量生产方案，是为了做出自己骄傲的作品。 | 去量化，用"作品集回顾"替代 KR：每月底做一次"这个月我最好的作品是什么"的团队分享。不看数量看质量，不评估"完成率"而是互相给反馈。如果团队做不出任何自己骄傲的东西，不是目标不够明确，是工作环境出了问题。 |
| **团队 OKR 已经变成 KPI 换皮，且组织政治不允许脱钩** | 如果 OKR 与奖金/晋升已经硬性挂钩，任何"改进 OKR 方法"都只会被当作"更精致的 KPI 工具"——根本问题是制度设计，不是工具设计。 | 不改 OKR 流程，改制度：先做"一个季度的实验"——明确宣布这个季度的 OKR 与绩效完全脱钩，只用来"练习和对齐"。如果管理层连这个实验都不敢做——问题不在 OKR，在管理层信任缺失。 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **第一次在团队推行 OKR，担心"弄成变相 KPI"** | 第一个周期不与任何奖惩挂钩——明确向全员宣布"这个季度的 OKR 只用来练习。季末如果某个 KR 完成了，我们会问'学到了什么'；如果没完成，我们会问'学到了什么'——而不问'谁的责任'" | Q1 结束后团队对"OKR 与绩效脱钩"的信任度 >70%（匿名投票），且至少 2 个 KR 在季度中被主动上调（说明团队不怕设高目标） |
| **周度脉搏时发现某个 KR 连续 3 周没有进展** | 做"阻碍分解"：是目标设得不切实际？是资源不足？是存在未被识别的外部依赖？还是负责人不是合适的人？ | 在第 4 周脉搏时提出具体的解决方案（调整目标/增加资源/更换负责人），而不是只是"再看看"。 |
| **季度复盘时发现 OKR 完成率 100%，但业务实际进展不明显** | 做"KR 拆谎"——逐个 KR 问"这个数字的提升真的创造了用户/客户价值，还是只是数字变好看了？"剔除以操作手段达成的 KR | 至少 1 个 KR 被标记为"完成但无真实价值"——这一条出现在复盘中的频率直接反映了你的团队在"指标游戏"中的投入程度 |
| **团队反馈"OKR 是额外负担，影响正常工作"** | 检查 OKR 与日常工作的链接是否清晰：如果 OKR 描述的事情不是团队"正常工作"的一部分——而是"额外的任务"——说明 OKR 设计有问题。 | 下一季度 OKR 中，至少 80% 的 KR 是团队"本来就在做的事"的量化表达，而非"额外增加的任务"。 |
