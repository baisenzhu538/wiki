# 销售驱动增长：SLG模式

> 一堂五步法：高客单价产品需要销售驱动。销售不是打电话，而是价值传递和信任建立。

## 核心框架

销售漏斗的5个阶段：

```
线索（Lead）→ 商机（Opportunity）→ 演示（Demo）→ 谈判（Negotiation）→ 成交（Close）
```

| 阶段 | 转化率 | 关键动作 |
|:---|:---:|:---|
| **线索** | 100% | 获客、筛选 |
| **商机** | 20-30% | 需求确认 |
| **演示** | 40-60% | 价值展示 |
| **谈判** | 60-80% | 方案定制 |
| **成交** | 20-40% | 签约 |

## 关键洞察

### 1. SLG的适用条件

| 条件 | 说明 | 评估 |
|:---|:---|:---|
| **高客单价** | 客单价 > $5000/年 | 适合SLG |
| **复杂产品** | 产品需要解释和演示 | 适合SLG |
| **长销售周期** | 销售周期 > 1个月 | 适合SLG |
| **定制化** | 需要定制化方案 | 适合SLG |
| **关系重要** | 客户关系影响决策 | 适合SLG |

### 2. 销售团队的设计

| 角色 | 职责 | 指标 |
|:---|:---|:---|
| **SDR** | 线索开发、初步筛选 | 线索数量、质量 |
| **AE** | 需求挖掘、演示、谈判 | 成交率、客单价 |
| **CSM** | 客户成功、续费 | 留存率、NPS |
| **销售经理** | 团队管理、目标达成 | 团队业绩 |

### 3. 销售流程标准化

| 阶段 | 标准动作 | 工具 |
|:---|:---|:---|
| **线索筛选** | BANT评估 | CRM |
| **需求确认** | 发现需求 | 问卷、访谈 |
| **价值展示** | 演示产品价值 | 演示工具 |
| **方案定制** | 定制解决方案 | 提案模板 |
| **谈判签约** | 价格谈判、合同 | 合同管理 |
| **客户成功** |  onboarding、续费 | CSM工具 |

### 4. 销售效率优化

| 优化方向 | 说明 | 方法 |
|:---|:---|:---|
| **线索质量** | 提升线索质量 | 精准营销、筛选标准 |
| **转化率** | 提升各环节转化率 | 培训、工具、流程 |
| **客单价** | 提升客单价 |  upsell、cross-sell |
| **销售周期** | 缩短销售周期 | 标准化、自动化 |
| **人效** | 提升人均产出 | 工具、培训、激励 |

### 5. SLG与PLG的结合

| 结合方式 | 说明 | 示例 |
|:---|:---|:---|
| **PLG获客，SLG变现** | 产品获客，销售转化高价值客户 | 免费试用→销售跟进 |
| **SLG获客，PLG留存** | 销售获客，产品自助留存 | 企业版→自助使用 |
| **分层策略** | 小客户PLG，大客户SLG | SMB自助，Enterprise销售 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **销售流程不标准** | 每个销售做法不同 | 标准化流程 |
| **忽视客户成功** | 签约后不管 | 建立CSM |
| **销售与产品脱节** | 销售承诺产品做不到 | 销售产品协同 |
| **关系销售依赖** | 靠个人关系，不可复制 | 系统化销售 |
| **销售成本失控** | CAC过高 | 优化销售效率 |
| **忽视数据** | 销售数据不透明 | CRM数据驱动 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 高客单价B2B | 低客单价C端 |
| 复杂产品 | 简单自助产品 |
| 长销售周期 | 即时决策产品 |
| 关系驱动 | 纯产品驱动 |
