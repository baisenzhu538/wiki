# 产品内核十大典型指标

> 来源：一堂五步法·解决方案篇 | 洪七公 OCR 整合 | [[yt-product-kernel-cultivation]] | [[yt-customer-acquisition-toolkit]] | [[yt-unit-model-three-tools]]

## Summary

一堂将产品内核质量量化为**获客、服务、复购**三个环节的十大典型指标。这些指标是判断产品内核是否成立的"体检表"，也是单元模型中最重要的参数输入。指标好坏可能相差**10倍以上**，直接决定商业成败。

## Claims

### 指标体系总览

| 环节 | 指标 | 定义 | 典型场景 |
|:---|:---|:---|:---|
| **获客环节** | 销转率 | 潜在客户转化为实际购买客户的比例 | 销售驱动型业务 |
| **获客环节** | 动销率 | 有销售的商品品种数 / 所有商品总品种数 | 零售/电商 |
| **获客环节** | 捕获率 | 进店消费人数 / 总经过人流量 | 线下门店 |
| **服务环节** | 留存率 | N天/周/月后还在持续使用的用户比例 | SaaS/APP |
| **服务环节** | 完课率 | 用户完成履约和学习的比例 | 教育/培训 |
| **服务环节** | 退款率 | 服务履约中用户退款的比例 | 服务/教育 |
| **服务环节** | 满意率 | 用户接受完服务后的满意度比例/打分 | 所有服务业 |
| **复购环节** | 复购率 | 消费购买后继续购买的比例 | 快消/零售 |
| **复购环节** | 续费率 | 续费用户数 / 现有用户数 | 订阅/SaaS |
| **复购环节** | 推荐率 | 用户愿意主动推荐的比例 | 口碑驱动型业务 |

### 核心原则

1. **环节决定指标选择**：不同行业的关键指标不同，但都可以归入获客/服务/复购三大环节
2. **指标是内核质量的温度计**：指标差的根本原因通常是内核定义错误
3. **对比才有意义**：必须和行业基准、历史数据、竞品数据对比
4. **警惕虚荣指标**：流量、注册用户等不等于内核质量

## Critique

### 外部攻击：Alistair Croll 与 Benjamin Yoskovitz（精益数据分析）

Croll 和 Yoskovitz 在《精益数据分析》中提出**"唯一关键指标"（OMTM）**概念：每个阶段只有一个真正重要的指标，其他都是干扰。一堂的"十大指标"虽然全面，但可能导致团队陷入"监控所有指标，优化 none"的困境。实际操作中，初创团队应该根据当前阶段选择一个**北极星指标**，而非同时优化十个。

### 外部攻击：John Bogle（指数基金与长期指标）

Bogle 的投资理念强调"短期指标波动是噪音，长期价值才是信号"。产品内核指标如果只看月度/季度数据，容易陷入"过度优化短期指标"的陷阱。例如过度优化转化率可能损害长期品牌信任，过度优化完课率可能降低学习深度。指标体系需要和**长期用户价值（LTV）**挂钩，而非孤立优化。

### 根因修正

十大指标的价值不在于"十个都要看"，而在于**提供一套诊断框架**——当业务出问题时，能快速定位是哪个环节的内核出了问题。使用时应根据业务阶段选择 1-3 个核心指标深度跟踪，其余作为参考。

## Constraints & Boundaries

| 边界 | 说明 |
|------|------|
| **适合** | 产品已经上线、需要数据驱动迭代 |
| **适合** | 需要向团队/投资人说明产品健康状况 |
| **不适合** | 产品尚未发布、没有数据可跟踪 |
| **不适合** | 业务模型与十大指标差异极大的特殊行业 |

### 失败模式

1. **同时追踪所有指标，看不到重点**
   - **原因**：指标过载
   - **修复**：限制核心指标≤5个，其他作为观察指标

2. **只看虚荣指标（如注册数），不看转化/留存**
   - **原因**： vanity metrics
   - **修复**：每个指标必须能关联到商业结果或用户价值

3. **指标好看但不影响决策**
   - **原因**：指标与行动脱节
   - **修复**：为每个核心指标设定‘正常/预警/危险’阈值和对应动作

4. **没有行业基准，不知道指标好坏**
   - **原因**：缺少参照
   - **修复**：定期收集同行业同阶段公司的指标基准

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| 产品上线后不知道看什么数据 | 从十大指标中选择1-3个与当前阶段最相关的指标 | 团队对北极星指标达成一致 |
| 转化率明显低于行业水平 | 用"内核四要素"反推：需求、解决方案、差异化、付费意愿哪个出了问题 | 定位到具体内核问题 |
| 留存率低但获客成本高 | 先停止获客，集中优化服务环节的完课率/满意率 | 留存率提升后再扩量 |
| 要做融资路演 | 用3-5个核心指标展示产品内核质量 | 投资人能听懂数据背后的故事 |
