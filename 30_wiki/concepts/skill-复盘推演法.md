# 技能：复盘推演法

## 原始表述
> L3.复盘推演 √复盘过去：复盘过去的成败得失 √推演未来：推演下一步具体工作 √角色扮演：带入角色解决高难问题

## 操作步骤
1. 复盘过去：系统回顾成败得失
2. 推演未来：基于复盘推演下一步具体工作
3. 角色扮演：代入特定角色解决高难度问题

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 项目/阶段结束后，需要系统回顾成败得失 |
| ✅ 适合 | 面临重大决策前，需要推演降低风险 |
| ✅ 适合 | 需要突破能力瓶颈时，角色扮演突破视角局限 |
| ✅ 适合 | 团队学习，需要萃取可复制的因果链 |
| ❌ 不适合 | 日常微任务 → 复盘成本超过收益 |
| ❌ 不适合 | 情绪未平复时 → 归因会带有情绪偏差 |
| ❌ 不适合 | 没有行动验证条件 → 推演变成纸上谈兵 |
| ❌ 不适合 | 团队缺乏心理安全感 → 复盘变成追责大会 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **复而不盘** | 复盘只是描述做了什么，没有追问为什么做对了做错了 | 复盘的价值在盘不在复，必须找到'因为X所以Y'的可复制因果逻辑 |
| **归因太浅** | 失败归结为不够努力，成功归结为运气好 | 没有找到可复制的因果链，停留在情绪层面而非认知层面 |
| **只复不推** | 复盘了但不推演，知道哪里错了但下一步计划模糊 | 推演的价值在'下周具体做什么'，必须产出具体行动清单 |
| **无验证闭环** | 上次复盘后的行动，这次没有检查效果 | 没有检查的复盘等于没做，复盘必须形成'复盘→行动→验证→再复盘'的循环 |
| **成功忽视** | 只复盘失败不复盘成功，对成功一笔带过 | 成功的因果链同样需要萃取，成功中的可复制因素往往比失败教训更有价值 |
| **角色扮演失真** | 代入角色时带着自己的偏见，没有真正切换视角 | 角色扮演前先写下"这个角色和我的三个关键差异"，强制视角切换 |
| **推演过度乐观** | 推演未来时只考虑理想路径，忽略风险 | 推演必须包含'最坏情况'和'Plan B'，否则不是推演是许愿 |
| **复盘频率不当** | 复盘太频繁导致行动时间被压缩，或太稀疏导致经验丢失 | 项目复盘在项目结束后48小时内进行，日常复盘每周一次，不超过30分钟 |

## 判断标准

**什么算一次好的复盘推演**：

| 标准 | 好的复盘 | 坏的复盘 |
|:---|:---|:---|
| 有因果链 | 找到了"因为 X 所以 Y"的可复制因果逻辑，而不是"不够努力" | 停留于描述"做了什么"——复而不盘 |
| 正反都复盘 | 成功案例也拆解因果链：什么因素导致了成功？可复制吗？ | 只复盘失败——成功的因果链同样需要萃取 |
| 推演具体 | 复盘最后产出了"下周具体做什么"的行动清单 | 知道哪里错了但下一步计划模糊到"以后要注意" |
| 有验证闭环 | 推演的行动被实践了，并且下次复盘时检查了效果 | 复盘完了没有动作——复盘的价值在行动不在记录 |

**自检问题**：
1. 这次复盘我找到了几个"可复用的因果逻辑"？如果不到 1 个，说明复盘太浅。
2. 推演的行动中，最具体的那个是什么？如果写不出来"下周一做 X"，就是不够具体。
3. 上次复盘后的行动，这次检查了吗？——没有检查的复盘等于没做。

## 常见失败模式
- 复而不盘：只是描述"做了什么"，没有追问"为什么做对了/做错了"——复盘的价值在盘不在复
- 归因太浅：失败归结为"不够努力"，成功归结为"运气好"——没有找到可复制的因果链
- 只复盘失败不复盘成功：对失败复盘很积极，对成功一笔带过——成功的因果链同样需要萃取
- 复盘了但不推演：知道哪里错了但下一步计划没有具体到行动——推演的价值在"下周具体做什么"
