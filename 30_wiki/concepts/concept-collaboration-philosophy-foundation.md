> **定位**：属于 management 域·协作管理底层哲学。不教具体管理工具——教的是「为什么协作工具会失效」的底层逻辑。来源：莫非口述解读赵汀阳《坏世界研究》（二手来源）。

## 核心主张

**协作不是意愿问题，是博弈结构问题。** 赵汀阳《坏世界研究》的核心论证：在一个自利+稀缺+差异三方条件同时成立的世界里，协作失败是默认状态，协作成功才是需要特殊条件的例外。改善协作的关键不是「找更好的人」，而是「设计更好的博弈结构」——让人在追求自身利益时，协作是最优策略。

## 分层自洽结构

> 解放思想模式：底层原则 → 中层方法 → 上层执行。三层之间必须可推导——中层方法必须能从底层原则推出来，上层执行必须能用中层方法解释为什么有效。

```
【底层原则】赵汀阳政治哲学
  坏世界假设（自利+稀缺→冲突必然）
  ├── 他者悖论 → 不能消灭他者只能改造关系
  ├── 合作悖论 → 制度通过"分"配置利益与权力
  ├── 制度悖论 → 人会学习利用侵蚀制度 → 需要博弈条件改善
  └── 和而不同 → 兼容差异而非消灭差异（共在先于存在）
        ↓ 推导
【中层方法】六条实操映射（逐字稿 §5.1-5.6）
  ├── 规则正当+可信（←从合作悖论+制度悖论推导）
  ├── 公议≠投票（←从公议悖论推导）
  ├── 激励让好行为占优（←从博弈条件改善推导）
  ├── 和≠同（←从和而不同推导）
  ├── 权力=形成合作（←从权力悖论推导）
  └── 应用边界（←从世界悖论推导）
        ↓ 推导
【上层执行】两张工具卡
  ├── 地位互换测试（←中层·规则正当+公正优先 → 用对方尺子量规则）
  └── 博弈环境自检清单（←中层·激励让好行为占优 → 五问设计博弈结构）
```

**自洽检验**：中层每条映射必须对应至少一条底层原则；上层每个工具必须对应至少一条中层映射。三层之间的推导链不能断裂——如果某个工具无法追溯到底层原则，说明它是经验堆积而非逻辑推导。

## 七层悖论链

> 来源：逐字稿 §2，莫非精炼版

```
自利+稀缺+差异+力量不平等 → 自我中心
  ① 他者悖论：他者限制我，又是利益/幸福/意义来源 → 不能消灭只能改造关系
  ② 合作悖论：必须合作，但收益分配制造冲突 → 制度通过"分"配置利益与权力
  ③ 公议悖论：共同决定需公共表达，但被接受的意见未必正确 → 公正优先于投票
  ④ 权力悖论：合作需权力执行规则，但权力也能破坏合作 → 制度化
  ⑤ 制度悖论：制度限制坏行为，但行为者会学习利用侵蚀制度 → 博弈环境+普遍模仿
  ⑥ 边界悖论→世界悖论：边界保护也制造排斥 → 和而不同
```

**使用方式**：协作出问题时，从①往下逐层诊断——问题出在哪一层？你的规则卡在哪一层的悖论里？

## 六条实操映射

> 来源：逐字稿 §5.1-5.6

| # | 原文 | 一人公司映射 |
|:--|:--|:--|
| 5.1 规则正当+可信 | 正当回答"为什么这样分配"，可信回答"规则是否稳定执行" | 分钱方案既要讲得通（正当），也要执行得稳定（可信） |
| 5.2 公议≠投票 | 先确保信息充分、方案完整表达，再表决 | 重大决策不要开局就投票——先充分讨论再决断 |
| 5.3 激励让好行为占优 | 口头赞美协作，奖励却给短期抢功→真正被模仿的是后者 | 检查你的激励体系：真正被奖励的行为和你说的重要行为是否一致 |
| 5.4 和≠同 | 共同语言降低协作成本但也可能演变成意识形态 | 允许不同专业/经验/偏好参与纠错，不要追求"所有人说一样的话" |
| 5.5 权力=形成合作 | 判断权力是否有效看共同目标是否更可实现 | 团队表面安静≠协作好——可能只是异议退出了 |
| 5.6 应用边界 | 不能把"天下"类比集团管控，不能用"预付人权"解释员工权利 | ⚠️ 涉及公民权利、国家强制的结论必须留在政治语境 |

| 场景 | 原因 | 替代 |
|:--|:--|:--|
| 纯执行层SOP场景 | 不需要哲学框架——按SOP执行即可 | 直接参考对应工具卡 |

| 强制环境（员工无法退出） | 退出权是博弈的前提——无法退出时框架不适用 | 先解决退出权问题 |
| 需要立即行动（1h内） | 哲学框架需要思考时间 | 先行动，事后复盘时参考 |

## Critique

### 内部局限

1. **二手来源**：莫非口述解读赵汀阳，存在解读偏差可能。笔记全篇"赵天旸"=赵汀阳——连名字都写错了，任何引用以逐字稿为准。
2. **从政治哲学到管理域的跨域映射未经验证**：赵汀阳讨论的是国家/世界制度，本卡将其映射到一人公司/团队管理——5.6已标注应用边界，但不能保证所有映射都成立。
3. **「坏世界」假设可能过度悲观**：自利+稀缺+差异是充分条件但非必要条件——存在基于信任和共同愿景的协作，本框架对此解释力有限。

### 外部攻击者

**Elinor Ostrom（公共资源治理·诺奖2009）**：Ostrom的核心发现是——社区可以在没有自上而下制度的情况下自组织管理公共资源。这与赵汀阳「坏世界必须靠制度」的假设形成张力。Ostrom 式的攻击：很多成功的协作不是靠制度设计，而是靠信任、规范和社区自组织——你的框架是否低估了「自下而上」的力量？

**Adam Smith（道德情操论）**：Smith 在《道德情操论》中强调「同情」（sympathy）是协作的天然基础——人天生能感受他人的情感。这与「坏世界」的人性假设冲突：如果人有天然的共情能力，协作就不需要那么重的制度设计。

| 触发条件 | 动作 | 成功指标 |

| 协作出现反复摩擦 | 逐层走七层悖论链——问题出在哪一层？ | 定位到具体悖论层 |
| 新规则设计 | 过三关：正当性（为什么这么分）+ 可信性（能稳定执行吗）+ 互换测试（换位置还接受吗） | 三关全部通过 |

| 规则执行不稳定 | 检查博弈环境——当前规则下，坏行为是否仍然是优势策略？ | 调整到好行为=优势策略 |

## L1-L5 深挖

### L1 业务公式

**协作质量 = f（博弈结构，而非人品）**。关键变量：
- 收益对称性：各方从合作中获得的利益是否与其投入匹配？
- 退出成本对称性：各方退出合作的代价是否对等？
- 信息透明度：各方对规则的理解和执行是否一致？
- 时间视野：各方预期合作持续多久？（时间越长→越倾向合作）

**一人公司公式化**：好制度 = （正当性 × 可信性）/（执行成本 + 漏洞空间）。分子越大越好，分母越小越好。

### L2 假设审计

| 假设 | 验证 | 风险 |
|:--|:--|:--|
| 坏世界=自利+稀缺→冲突必然 | ✅ 经济学+博弈论共识 | 低估了非自利行为（利他/互惠/声誉） |
| 制度可改善博弈条件 | ✅ Axelrod 囚徒困境锦标赛实证 | 制度过度设计会增加摩擦成本 |
| 地位互换可检验公正性 | ⚠️ 心理换位不完美（你不可能真的变成对方） | 互换可能强化制定者的偏见（"我觉得他应该..."） |
| 普遍模仿可检验策略优劣 | ✅ 赵汀阳原创验证工具 | 有些策略只在特定条件下是坏的（非普遍适用） |

### L3 边界

| 条件 | 适用？ | 原因 |
|:--|:--:|:--|
| 平等主体（双方有大致对等的退出权） | ✅ | 框架的核心前提 |
| 权力极不对称（如大公司对小个体） | ⚠️ | 部分适用——地位互换可暴露不公正，但无法单方面改变 |
| 强制关系（无法退出） | ❌ | 退出权是博弈的前提 |
| 单次交易（无未来） | ❌ | 框架假设重复博弈——“未来”是合作的最大杠杆 |
| 非理性主体（情绪/面子>利益计算） | ⚠️ | 框架基于理性自利假设——情绪决策超出模型 |

### L4 失败模式（协作层面）

| 失败模式 | 信号 | 根因 |
|:--|:--|:--|
| **规则自欺** | 制定者觉得规则很公正但执行方默默不满 | 只用自己尺子量→没做地位互换 |
| **激励错配** | 口头提倡协作/长期主义，实际奖励短期抢功/信息垄断 | 博弈条件没改善——坏行为仍是优势策略 |
| **制度老化** | 规则刚上线有效，3-6个月后失效 | 制度悖论——人学会了漏洞 |
| **假共识** | 团队"一致同意"的决策，执行时无人负责 | 公议≠投票——速度快但牺牲了充分讨论 |
| **权力正当性真空** | 创始人靠"我是老板"管人→骨干离职 | 权力没转化为正当性→金句6"公正才是权力维持的条件" |

### L5 隐性成本

| 成本 | 估算 | 说明 |
|:--|:--|:--|
| **谈判成本** | 地位互换+博弈环境检查≈30-60分钟/规则 | 用本框架设计规则的前期投入 |
| **制度维护成本** | 每季度复盘一次≈2小时 | 制度需要自我修正机制——这本身就是成本 |
| **过度设计风险** | 规则太复杂→执行成本>收益→大家找捷径 | 典型失败：照搬大公司制度到一人公司 |
| **信任替代成本** | 过度依赖制度→关系中的自发信任被挤出→关系变交易 | Ostrom 攻击的本意——制度不应完全替代信任 |
