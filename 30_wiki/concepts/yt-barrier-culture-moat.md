# 文化护城河：难以复制

> 一堂五步法：文化是最难复制的壁垒。文化不是口号，是行为模式。

## 核心框架

文化的3个层次：

```
 artifacts（表象）→ espoused values（价值观）→ basic assumptions（基本假设）
```

| 层次 | 说明 | 示例 |
|:---|:---|:---|
| **表象** | 可见的行为、符号 | 办公环境、仪式 |
| **价值观** | 宣称的价值观 | 使命、愿景 |
| **基本假设** | 深层信念 | 对人性、世界的假设 |

## 关键洞察

### 1. 文化护城河的类型

| 类型 | 说明 | 示例 | 壁垒强度 |
|:---|:---|:---|:---:|
| **创新文化** | 鼓励创新、容忍失败 | 谷歌 | 高 |
| **执行文化** | 强调执行、结果导向 | 华为 | 高 |
| **客户文化** | 客户第一 | 亚马逊 | 高 |
| **人才文化** | 重视人才 | Netflix | 高 |
| **敏捷文化** | 快速迭代 | 字节 | 中 |

### 2. 文化建设的阶段

| 阶段 | 说明 | 关键 | 示例 |
|:---|:---|:---|:---|
| **创始人文化** | 创始人价值观 | 创始人行为 | 早期公司 |
| **制度化** | 文化制度化 | 制度、流程 | 成长期 |
| **传承** | 文化传承 | 故事、仪式 | 成熟期 |
| **演化** | 文化演化 | 适应变化 | 变革期 |

### 3. 文化护城河的评估

| 维度 | 说明 | 评估 |
|:---|:---|:---|
| **独特性** | 文化是否独特 | 独特→强 |
| **一致性** | 言行一致 | 一致→强 |
| **深度** | 文化是否深入 | 深→强 |
| **稳定性** | 文化是否稳定 | 稳定→强 |
| **适应性** | 文化能否适应变化 | 适应→强 |

### 4. 文化护城河的维护

| 维护方式 | 说明 | 示例 |
|:---|:---|:---|
| **招聘** | 招聘符合文化的人 | 文化面试 |
| **考核** | 考核文化行为 | 价值观考核 |
| **故事** | 传播文化故事 | 创始人故事 |
| **仪式** | 文化仪式 | 年会、团建 |
| **符号** | 文化符号 | 口号、标志 |

### 5. 文化护城河的误区

| 误区 | 说明 | 避免 |
|:---|:---|:---|
| **文化口号化** | 文化只是口号 | 行为化 |
| **文化僵化** | 文化不变化 | 演化 |
| **文化复制** | 复制别人的文化 | 独特 |
| **文化忽视** | 忽视文化 | 重视 |
| **文化与战略脱节** | 文化不支持战略 | 对齐 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **文化稀释** | 扩张后文化稀释 | 强化 |
| **文化僵化** | 文化阻碍变化 | 演化 |
| **文化口号化** | 文化只是口号 | 行为化 |
| **文化复制** | 复制别人的文化 | 独特 |
| **文化与战略脱节** | 文化不支持战略 | 对齐 |
| **文化忽视** | 忽视文化 | 重视 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 组织建设 | 技术架构 |
| 长期竞争 | 短期项目 |
| 人才吸引 | 流程优化 |
| 创新驱动 | 成本领先 |

## 行动触发器

- 当文化稀释时 → 强化文化
- 当文化僵化时 → 文化演化
- 当文化口号化时 → 行为化
- 当文化与战略脱节时 → 对齐
