# AI Style 新型知识文档 10-11 种

> 本卡属于「AI×知识管理」体系（楚门探索营进步三，015515 图 + 批注 221751/221853）：把项目资产化，让人和 Agent 随时读、写、调用——AI Style 的新型知识文档类型约 10-11 种，按"能力/数据/设计/复盘"四个方向组织。讲师当天下午让 Claude 巡查 Obsidian 补文档类型的实景演示（批注 221853 是提示词截图）。

## 1. 核心洞察

传统文档给人看；**AI Style 文档给 AI 用**（015515 图题："把项目资产化，让人和 Agent 随时读、写、调用"）。文档类型从"记录"扩展到"定义 AI 能做什么、喂什么数据、按什么宪法设计、怎么复盘"——10-11 种新型文档：

| 方向 | 文档类型 | 作用 |
|:--|:--|:--|
| 能力方向 | 技能文档 | 定义 AI 能做什么（可调用能力） |
| | 最佳指南文档 | 最佳实践/质量标准 |
| | 调用路由文档 | 何时调用什么（路由逻辑） |
| 数据方向 | DataPack 文档 | 背景数据包（喂养 AI） |
| | 角色配置文档 | 稳定角色（内核/边界/职能） |
| 设计方向 | 设计宪法文档 | 设计原则/风格底线（DESIGN CONSTITUTION） |
| | 设计审美文档 | 审美基准（作品/风格参照） |
| 复盘方向 | 全量复盘文档 | 5 万字全量复盘（之后 Session 可扔） |
| 其他 | 双三角模型文档 | 场景-数据-能力映射 |
| | case 打底文档 | 案例库（打底参照） |

## 2. 为什么是"10-11 种"

- 015515 图按四方向（能力/数据/设计/复盘）展开 + 双三角模型/case 打底
- 批注 221751 是四方向图（AI Style 新型知识文档四方向）
- 批注 221853：讲师当天下午给 Claude 的提示词——巡查 Obsidian 补文档类型（实景演示：让 AI 自己发现缺什么文档类型）
- 数字以图为准（10-11 种，口述有波动）

## 3. 使用步骤

1. **识别你的文档缺口**：让 AI 巡查现有知识库，对照 10-11 种类型找缺口（批注 221853 的做法）
2. **能力方向优先**：技能文档/最佳指南/调用路由——定义 AI 能做什么
3. **数据方向配套**：DataPack/角色配置——喂背景数据和稳定角色
4. **设计方向收尾**：设计宪法/审美——一致性保障
5. **复盘方向闭环**：全量复盘沉淀（Session 可扔）

## 4. When NOT to Use

1. **纯人用文档**——给人看的文档保持传统形态（双中心原则）。
2. **一次性项目**——10-11 种类型是资产级标准，临时任务不用全配。
3. **AI 协作未启动**——不用 AI 时 DataPack/角色配置/路由无意义。

## 5. 失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 文档类型单一 | 只有笔记没有技能/路由 | 对照 10-11 种类型补缺口（AI 巡查） |
| 有 DataPack 无宪法 | AI 输出风格漂移 | 补设计宪法/审美文档 |
| 有技能无数据 | Skill 干不好活 | 配 DataPack/角色配置 |
| 不复盘 | 项目做完就扔 | 全量复盘文档沉淀（Session 可扔） |

## 6. Action Triggers

- 知识库给 AI 用时 → 对照 10-11 种类型检查缺口
- AI 输出不稳定 → 补设计宪法/角色配置（稳定上下文）
- 项目收官 → 写全量复盘文档（资产化）
