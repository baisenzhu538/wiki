# 暗知识：五步法中的主要认知偏差

> 来源：一堂五步法·序言篇及落地实操篇 | [[yt-five-step-method]] | [[yt-five-step-common-pitfalls]] | [[yt-demand-analysis-hiking-map]] | [[master-cognitive-bias-checklist]] | [[case-five-step-fake-vs-real-barriers]]

## Summary

Truman 在课上做过一个实验：讲课前让学员给自己的五步法水平打分，7-8 分的人占多数，但课后大都自觉"不到 60 分"。这个现象的背后是一系列**系统性认知偏差**在作祟。五步法作为分析框架，本身不能克服这些偏差，反而可能被偏差"利用"——用严谨的框架包装原有的偏见。本卡把五种最常见的偏差、它们的商业分析症状、可执行的修复动作，以及一套快速自查 Checklist 集中呈现，让"我知道自己有偏差"真正变成"我能检查并减弱偏差"。

## 原始表述

Truman 的原话大意是："五步法不是万能药。很多人觉得把五个步骤填完就叫科学分析，其实最大的风险是，你用五步法把自己的偏见重新写了一遍。" 课程中反复出现的警示包括：

这些表述指向同一个暗知识：**框架提供的是结构，不是免疫力；分析质量取决于使用者能否识别并对抗自身的认知偏差。**

## 深度洞察

1. **框架不会自动降噪，反而可能放大偏差**。当创业者把"我直觉认为对"的结论塞进五步法时，每一步的"结构化"都在给偏见披上科学外衣。表面看是"用五步法推导出的结论"，实际是"用五个框重新排版后的直觉"。
2. **证实性偏差是五步法的头号敌人**。需求分析、产品内核、单元模型、增长假设、壁垒判断，每一步都存在"只找支持证据"的诱惑。它是跨步骤的，不像锚定效应或幸存者偏差只集中在某一步。
3. **团队一致性可能是危险信号**。当所有人迅速达成共识，往往不是分析充分，而是确认偏差在团队层面被放大了。真正健康的讨论应该先独立、后聚合。
4. **过度自信与框架熟练度正相关**。越熟悉五步法的人，越容易误以为"我已经用框架了，所以我对了"。这是一种"工具安全感"带来的二次偏差。

## 使用场景

| 场景 | 为什么需要这张卡 |
|------|-----------------|
| 即将用五步法做重大决策 | 提前给自己做"认知体检"，避免填完框架后直接强化直觉 |
| 团队已经讨论完方案并高度一致 | 用"恶魔辩护人"和"独立判断"机制打破假性共识 |
| 需求调研后信心满满 | 检查是否只采访了"友好用户"，是否主动寻找过反例 |
| 做完单元模型发现数据很好看 | 检查是否用了最好情况数据、是否计入机会成本和折旧 |
| 宣称有壁垒但说不清别人为何抄不了 | 检查是否把"先发""技术""品牌"等假壁垒当真壁垒 |
| 复盘失败项目 | 区分"决策错误"与"运气不好"，避免后见之明偏差 |

## 操作方法

### 四步减弱偏差流程

```
1. 独立预判：在共享信息前，每个人先独立写下自己的判断和关键假设
2. 主动找反：为每个核心结论至少找到 2 个反对证据或反例
3. 引入异见：指定一名"恶魔辩护人"，其 KPI 是提出最强反对意见
4. 时间位移：把决策放在"三年后的我"和"三个月前的我"两个视角下审视
```

### 与五步法的对应关系

| 五步法步骤 | 最高发偏差 | 最小成本修复动作 |
|-----------|-----------|-----------------|
| 需求分析 | 证实性偏差 | 至少访谈 3 个"非目标用户"或"拒绝过你的人" |
| 产品内核 | 锚定效应 | 先让两人独立估算，再对比差异 |
| 商业模式/单元模型 | 现在偏误 | 强制计入三年期成本、折旧和机会成本 |
| 增长策略 | 幸存者偏差 | 研究 3 个同渠道失败案例后再决定投入 |
| 壁垒分析 | 过度自信 | 用"六个月测试"：资金是你 10 倍的对手进来，你还能活吗？ |

## 新增：认知偏差快速自查 Checklist

**适用时机**：填完五步法任意一步后、团队拍板前、重大决策前夜。

| 检查项 | 如果答案是"是"，执行修复 |
|--------|------------------------|
| 我的结论和最初直觉几乎一致？ | 强制找 2 个反对证据，重写结论 |
| 我只收集了支持我假设的数据/访谈？ | 补充 3 个反方样本或失败案例 |
| 团队讨论时没有人提出反对意见？ | 指定恶魔辩护人，重新开会 |
| 我对这个判断的自信度高于证据支持度？ | 把置信度写成百分比，再减 20% |
| 我用了第一个看到的数字作为基准？ | 换两个完全不同的来源重新估算 |
| 我只研究了成功者，没研究失败者？ | 找出 3 个同赛道失败案例并分析死因 |
| 我更关注短期收益而非三年后的影响？ | 列出三年后看仍正确的 3 个理由 |
| 我觉得"我用了五步法，所以我对了"？ | 回到第一步，独立重做一次 |

## 为什么值钱

1. **防止"框架滥用"导致的昂贵错误**。很多创业项目的失败不是因为没做分析，而是因为分析被偏差污染。这张卡把"偏差识别"从玄学变成可操作的检查动作。
2. **提升团队决策质量**。个人偏差靠自己很难克服，但团队可以通过结构化流程（独立判断、恶魔辩护人）显著降低集体误判的概率。
3. **在复盘时区分"运气"与"能力"**。Annie Duke 的核心洞见是：好决策不一定带来好结果。没有这张卡，团队容易把成功归因为"我们五步法用得好"，把失败归因为"运气差"。
4. **与具体工具形成组合拳**。它和 [[master-cognitive-bias-checklist]] 形成"dk 理解 + 工具清单"的组合；和 [[case-five-step-fake-vs-real-barriers]] 形成"认知偏差 + 真实案例"的互补；和 [[yt-five-step-method]]、[[yt-five-step-common-pitfalls]] 构成"主框架 + 误区 + 偏差"的完整学习路径。

## Constraints & Boundaries

### 适用边界

| 适用情境 | 不适用的情境 |
|----------|-------------|
| 已学习五步法但发现落地困难、结论总与直觉一致 | 完全没有决策经验的新人（需要先累积基本经验） |
| 团队需要做重大商业决策，希望降低集体误判 | 寻找"克服偏差"快捷方式的人（偏差只能减弱不能消除） |
| 希望提升决策质量的管理者和业务负责人 | 把本卡当"指责他人偏差"武器的人 |
| 复盘失败项目、区分决策质量与运气成分 | 信息极度匮乏、无法验证任何假设的早期探索 |
| 已在真实决策中反复练习、有具体案例可对照 | 单独学习理论但不在真实场景中应用 |

### 失败模式

| 失败模式 | 真实症状 | 可执行修复 |
|----------|---------|-----------|
| **框架包装偏见** | 填完五步法后结论与最初直觉完全一致；别人说"你这分析只是把你原来的想法重新排版" | 第一步前先独立写下原始直觉；完成后对比"框架结论"与"原始直觉"的差异，差异应 ≥30% |
| **只找支持证据** | 访谈对象全是潜在支持者；PPT 里只有正面数据；提到竞品只讲它们的弱点 | 强制添加"反例页"：每个核心结论配 2 个反对证据；访谈名单中必须包含 3 个"拒绝过你的人" |
| **团队假性共识** | 会议 10 分钟内达成一致；没人举手反对；讨论后大家觉得"本来就这么想" | 会前独立写判断并匿名提交；指定一名"恶魔辩护人"，其发言时间不少于总会议时间的 20% |
| **过度自信陷阱** | "我一眼就看清楚了""这个行业我熟""五步法我学过"；不愿意花时间重填框架 | 做"置信度校准"：把判断写成带概率的预测，3 个月后回看准确率，连续 3 次低于 60% 暂停拍板 |
| **把知道当做到** | 能背出五种偏差名称，但遇到真实决策时仍按本能反应 | 把本卡 Checklist 打印成 A4，重大决策前强制勾选；每季度复盘一次自己在真实决策中的偏差触发次数 |

## Critique

### 外部攻击：Daniel Kahneman（快思维与慢思维）

Kahneman 在《思考，快与慢》中将人类思维分为**系统 1（快思维）和系统 2（慢思维）**。五步法的价值在于强制启用**系统 2**，让创业者从"直觉跳跃"转变为"逻辑推演"。但 Kahneman 也警告，系统 2 是**懒惰的**——如果没有外部约束（如团队审查、数据验证），大多数人会自然回到系统 1 的惯性中。

### 外部攻击：Annie Duke（对决定与不确定性的思考）

Annie Duke 在《对决定》中论证，好的决策不一定带来好的结果，坏的决策也可能被好运气拯救。这对五步法的启示是：**不能用结果好坏来评价决策过程**。一个填完了五步法但失败的项目，可能仍然比一个没有使用五步法但偶然成功的项目更值得学习。
