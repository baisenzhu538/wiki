# 技能：短视频自动化上传工作流

## 原始表述

短视频自动化上传工作流是Truman在AI工具应用AMA中提出的实操方法。

## 操作步骤

1. 明确需求：固定时间自动上传已制作好的视频到视频号
2. 尝试用AI（如菲菲/龙虾）获取详细步骤指导
3. 方案一：使用RPA工具（如八爪鱼）实现自动化
4. 方案二：让AI写Python脚本/API调用实现
5. 方案三：使用无头浏览器/有头浏览器方案
6. 方案四：尝试AIGC工作流中的智能体封装功能
7. 评估风险（如平台监测封号）并选择可接受方案

## 适用场景

- 需要定时自动化发布短视频
- 重复性上传工作耗时
- 有一定技术基础或愿意学习RPA/脚本

## 不适用场景

- 对账号安全要求极高无法承担风险
- 完全无技术基础且不愿学习

## 工具/环境

- 八爪鱼RPA
- Python
- 无头浏览器（Selenium/Playwright）
- AIGC工作流
- 菲菲/龙虾AI助手

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

这是确定性任务（数学题），应通过代码/RPA等稳定方式实现而非依赖AI自由发挥；分层递进尝试可找到成本与效果的平衡点
