# 战略画布（Strategy Canvas）：把竞争格局画成一张价值曲线

> 来源：蓝海战略核心工具，与一堂「做替代者而非进入者」「避免同质化竞争」的战略观高度契合。常与[[yt-entrepreneur-opportunity-selection]]、[[concept-一堂-product-kernel]]配合使用。

## 用一句话讲清楚

战略画布是把“目标买家在意的竞争要素”作为横轴、把“各玩家在这些要素上的投入/表现”作为纵轴，画出的一条条价值曲线；**它让你一眼看出：谁在红海肉搏、谁有可能通过价值创新打开蓝海。**

## Summary

战略画布（Strategy Canvas）是 Kim & Mauborgne 在《蓝海战略》中提出的可视化工具。它把复杂的竞争格局压缩成一张二维图：横轴列出产业中被默认争夺的竞争要素（价格、功能、服务、渠道、品牌、速度等），纵轴表示各玩家在这些要素上的相对投入水平。通过绘制自己和主要竞争对手的价值曲线，团队可以直观发现：

1. **同质化陷阱**：所有曲线形状趋同，说明行业深陷红海；
2. **差异化机会**：某些要素被过度投入，某些买家真正在意却被忽视；
3. **价值创新方向**：通过“减少/剔除/提升/创造”四动作重构曲线，形成难以复制的战略轮廓。

一堂在战略培训中反复强调：小团队资源有限，**不要去做潜在进入者（在同一赛道里硬卷），而要努力成为潜在替代者（用不同价值组合满足同一需求）**。战略画布正是识别“替代者空间”的快捷工具。

## 核心要点

- **横轴不是功能清单，而是买方价值要素**：必须是目标买家在做购买决策时真正比较、愿意为之付费或传播的因素；内部技术参数如果买家无感，就不该出现在横轴上。
- **曲线形状比绝对数值更重要**：战略画布的纵轴通常用相对高低（低/中/高或 1-5 分）而非精确数字，目的是暴露“投资结构”而非计算精确 ROI。
- **四条重构动作是画布的实战口诀**：
  - **减少**：哪些要素投入远高于买家所需？（如过度包装、冗余功能）
  - **剔除**：哪些行业默认要素其实买家不在乎？（如传统渠道的豪华门店）
  - **提升**：哪些被低估的要素应该大幅加强？（如响应速度、透明价格）
  - **创造**：哪些买家需要但行业内无人提供的价值应该新增？（如订阅制、社区陪伴）
- **价值创新≠技术创新**：战略画布的目标是用新的价值组合让既有竞争要素变得不相关，而不是在原有要素上比谁做得更好。
- **画布需要定期重画**：随着替代品出现、买方偏好迁移、技术周期变化，价值曲线会失效；建议每 6-12 个月或在重大市场变化后重画一次。

## 边界

| 场景 | 说明 |
|:-----|:------|
| ✅ 行业存在多条价值曲线可供比较 | 战略画布的价值在于“对比”；如果市场处于完全空白、没有任何参照系，画布退化为单纯的假设清单。 |
| ✅ 目标买家群体相对明确 | 不同买家群体（如价格敏感型 vs 体验敏感型）会画出完全不同的曲线；群体模糊时，画布结论会互相打架。 |
| ✅ 用于战略方向选择而非战术细节优化 | 画布解决“我们在哪些维度上和别人不一样”，不解决“这个功能按钮放左边还是右边”。 |
| ❌ 买方需求极不稳定或无法归纳 | 若市场处于极早期，买家自己也不知道要什么，强行画布会过早固化错误假设。 |
| ❌ 团队无法诚实面对自身曲线 | 如果团队把自家曲线画得“处处高于竞品”，画布会变成自我陶醉工具，失去诊断意义。 |
| ❌ 用来替代定量验证 | 画布只能指出“可能有机会”，具体机会是否成立，仍需用[[yt-entrepreneur-key-hypotheses]]和最小成本实验验证。 |

## 失败模式

### 失败模式一：把“内部功能”当成“竞争要素”

**症状**：横轴列的是技术栈、专利数量、团队背景等内部优势，而不是买家能感知到的价值。

**后果**：画出的曲线无法解释“为什么买家选你”，战略沟通时内部自嗨、外部无感。

**修复**：每条横轴要素都要能通过一句话问买家——“如果竞品在这个点上比你强，你会不会换？”如果买家无所谓，就删掉。

### 失败模式二：曲线画得“全都要”，没有取舍

**症状**：自家曲线在所有要素上都处于中高位，不敢在任何维度上“减少”或“剔除”。

**后果**：资源平均分配，没有尖锐差异化，最终变成“什么都做、什么都一般”的中间态。

**修复**：强制要求团队选出 1-2 个要“剔除/减少”的要素和 1-2 个要“大幅提升/创造”的要素；没有取舍的画布不合格。

### 失败模式三：画完不验证，直接按图执行

**症状**：团队把画布当成结论，认为“曲线不同就等于战略成功”。

**后果**：价值曲线只是假设，若买家并不认可新的价值组合，投入会打水漂。

**修复**：画布完成后，必须找到 5-10 个目标买家或早期用户，分别让他们看三条曲线（现状、竞品、你的新曲线），验证他们是否愿意为“新增/提升的要素”付费或改变行为。

## 行动 Checklist

- [ ] **明确目标买家群体**：先回答“这个画布是为哪一类买家画的”，不同群体应分别出图。
- [ ] **列出 6-10 个竞争要素**：要素必须来自买方视角，能覆盖购买决策的主要比较维度。
- [ ] **绘制 3-5 条价值曲线**：至少包含行业头部、直接竞品、替代品/潜在新进入者，以及你自己（现状+设想）。
- [ ] **执行四动作重构**：明确写出要“减少/剔除/提升/创造”的要素，并标注理由。
- [ ] **找买家做视觉验证**：让目标用户看新旧曲线，收集他们对新增价值的付费意愿证据。
- [ ] **沉淀为团队共识语言**：把最终曲线打印出来，作为后续产品、营销、组织决策的过滤器——凡是不能强化曲线差异化的事，优先不做。

## Critique

### 内部局限

- **“竞争要素”列表本身具有主观性**：不同团队列出的要素差异巨大，列出什么、不列出什么，已经隐含了战略假设。画布无法自动纠正要素选择偏差。
- **静态快照难以捕捉动态博弈**：战略画布呈现的是某一时刻的价值曲线，但竞争对手会模仿、买家偏好会迁移、替代品会出现；一次画图不能替代持续监测。
- **容易把“不同”当成“更好”**：曲线形状独特只是差异化的必要条件，不是充分条件；独特但买家不买单的曲线毫无意义。

### 外部攻击

#### Michael Porter：差异化战略的经典挑战

**Michael Porter**（哈佛商学院，竞争战略理论奠基人）会质疑战略画布对“竞争要素”的处理过于买方中心化，而忽视了产业结构对利润的长期约束。Porter 的论证：即使你在买家视角下画出了漂亮的差异化曲线，如果行业存在高固定成本、低进入壁垒、强势供应商或买方议价能力极强，超额利润也会被产业结构侵蚀。战略画布告诉你“如何看起来不同”，但波特五力告诉你“这种不同能否转化为可持续利润”。

> 对战略画布的直接挑战：春秋航空和蜜雪冰城并不是简单地“价值创新”，而是把低成本做到极致后，在产业结构允许的缝隙中建立了系统能力壁垒。画布如果没有配合产业结构分析（如蓝海战略中对五力的讨论）或一堂的“壁垒”分析，容易把“创新”浪漫化。

#### 一堂“替代者”视角的放大

一堂战略培训进一步强调：战略画布最大的价值不是“在现有要素上重新分配权重”，而是**发现被行业默认忽略的全新要素**。例如零食量贩店的崛起，不是因为传统要素做得更好，而是因为“去经销商化+社区近场+低价白牌”这一组合创造了传统商超从未提供的价值。战略画布若只比较现有玩家，会漏掉这种替代者革命。

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:------|
| ✅ 市场已有 2 个以上可参照玩家 | 需要参照曲线才能诊断同质化程度。 |
| ✅ 团队能区分“买家感知价值”和“内部能力” | 否则横轴会被内部 KPI 污染。 |
| ✅ 用于战略共创和沟通 | 画布作为可视化语言，能统一团队对“我们要打哪几个点”的认知。 |
| ❌ 完全空白市场 | 没有参照系，画布无法发挥对比价值。 |
| ❌ 买方需求高度碎片化 | 若每个买家的要素权重都不同，单张画布会掩盖真实分歧。 |
| ❌ 替代方案评估需要精确财务模型 | 画布只给方向，ROI 计算需回到[[yt-decision-canvas]]。 |

### 常见误用

| 误用 | 后果 | 纠正 |
|:-----|:------|:-----|
| 用“我们比别人好”代替“我们和别人不一样” | 团队陷入性能竞赛，忽视价值重构 | 强制四动作：必须写出要减少/剔除什么 |
| 横轴要素过多（>12 个） | 曲线复杂、重点模糊 | 合并同类项，聚焦影响购买决策的 6-8 个要素 |
| 只画自己和直接竞品 | 漏掉替代品和潜在进入者 | 必须加入 1 条“替代品/新进入者”曲线 |
| 画完不更新 | 战略画布变成过时的装饰品 | 每 6-12 个月重画，或在市场重大变化后即时更新 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| 团队争论“我们和竞品有什么不同”超过 30 分钟 | 立刻画战略画布：列出买家要素→画 3 条曲线→找差异化空白 | 15 分钟内形成一张可讨论的视觉图 |
| 发现获客成本持续上升、转化率下降 | 用画布检查是否已陷入同质化：若自家曲线与头部高度重合，启动四动作重构 | 找出至少 1 个可剔除和 1 个可提升的要素 |
| 考虑进入新市场或新品类 | 先画目标市场的现有曲线，再画自己的“假设曲线”，验证新增要素是否被买家认可 | 获得 ≥5 个目标买家的正向反馈或付费意向 |
| 战略规划会产出过多目标、资源分散 | 用最终价值曲线作为过滤器：凡是不能强化曲线差异化的项目，直接降级或砍掉 | 资源项目数减少 30%-50%，剩余项目与曲线强相关 |
