# 病毒传播：自增长机制设计

> 一堂五步法：病毒传播不是运气，而是机制设计。K因子 > 1，增长自循环。

## 核心框架

病毒传播的核心公式：

```
K因子 = 每个用户带来的新用户数

K = 邀请率 × 邀请转化率

K > 1：自增长
K = 1：持平
K < 1：衰减
```

## 关键洞察

### 1. 病毒传播的3种类型

| 类型 | 说明 | 示例 | 特点 |
|:---|:---|:---|:---|
| **原生病毒** | 产品使用自然带来传播 | 微信消息、Zoom会议链接 | 产品内生，成本低 |
| **口碑病毒** | 用户主动推荐 | 好用到忍不住推荐 | 质量驱动，可信度高 |
| **激励病毒** | 激励用户分享 | 邀请奖励、裂变海报 | 成本驱动，可持续性差 |

### 2. 病毒传播的设计要素

| 要素 | 说明 | 设计要点 |
|:---|:---|:---|
| **传播动机** | 用户为什么分享 | 利己（奖励）、利他（帮朋友）、炫耀（展示） |
| **传播内容** | 分享什么 | 内容有价值、能展示分享者品味 |
| **传播渠道** | 在哪里分享 | 用户常用的社交平台 |
| **传播转化** | 被邀请者如何转化 | 降低 friction，快速体验价值 |
| **传播反馈** | 分享后得到什么 | 即时反馈，强化行为 |

### 3. 病毒系数K的评估

| 指标 | 说明 | 计算 |
|:---|:---|:---|
| **邀请率** | 多少用户会邀请 | 邀请用户数/总用户数 |
| **邀请转化率** | 被邀请者多少注册 | 注册数/邀请数 |
| **K因子** | 每个用户带来的新用户 | 邀请率 × 邀请转化率 |
| **病毒周期** | 完成一次传播的时间 | 从分享到注册的时间 |

### 4. 病毒传播的衰减

| 衰减因素 | 说明 | 管理 |
|:---|:---|:---|
| **时间衰减** | 传播效果随时间下降 | 持续优化传播机制 |
| **用户疲劳** | 用户对分享机制疲劳 | 创新分享方式 |
| **渠道饱和** | 渠道用户被多次触达 | 拓展新渠道 |
| **竞品模仿** | 竞品复制传播机制 | 持续创新 |

### 5. 病毒传播与产品设计的结合

| 产品类型 | 病毒机制 | 示例 |
|:---|:---|:---|
| **通讯工具** | 用户邀请好友使用 | WhatsApp |
| **协作工具** | 邀请同事协作 | Notion、Figma |
| **内容平台** | 分享内容 | 小红书、抖音 |
| **金融工具** | 邀请返利 | 支付宝红包 |
| **游戏** | 邀请组队 | 王者荣耀 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **传播动机不足** | 用户不愿分享 | 设计强传播动机 |
| **传播内容无价值** | 分享内容没人看 | 提升内容价值 |
| **传播渠道不对** | 分享后无转化 | 匹配用户常用渠道 |
| **转化 friction 高** | 被邀请者不注册 | 降低注册门槛 |
| **忽视时间衰减** | K因子持续下降 | 持续优化机制 |
| **激励依赖** | 停止激励就停止传播 | 设计原生病毒机制 |

## 适用边界

| 适用场景 | 不适用场景 |

## 行动触发器

- 当希望自增长时 → 设计病毒传播机制
- 当分享功能没人用时 → 优化传播动机
- 当K因子下降时 → 分析衰减因素
- 当获客成本高时 → 考虑病毒传播
