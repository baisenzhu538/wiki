# 清单体故事线⑤：对比分析线——用结构暴露被忽视的差异维度

## Condense

对比分析线不是"列出A和B的区别"，而是**"用对比作为认知透镜，暴露单一视角看不到的东西"**。它的核心是：任何比较都必须在明确的维度上进行，否则就是情绪化的站队。

**核心操作**：
1. **定义对比维度**：先列出"我们用哪些维度来比较"，再列出"被比较的对象"
2. **横向对比**：同一维度下，不同对象的差异
3. **纵向对比**：同一对象，在不同时间点的变化
4. **关键要素提取**：哪些维度是决定性差异的来源

## Question

**为什么"维度先于对象"如此重要？** 因为人类的认知偏差之一是"先选立场、再找证据"。当你先确定"要比A和B"，你潜意识里已经有了偏好，维度选择会被这个偏好污染。"维度先于对象"强制你先建立一个"中立的裁判框架"，再让对象进入框架。

**对比分析线和简单列表的区别是什么？** 简单列表是"A有1、2、3，B有4、5、6"；对比分析线是"在X维度上A=3 B=5，在Y维度上A=2 B=2"。前者是特征枚举，后者是结构化的差异量化。

## Critique

### 攻击者1：比较教育学专家——"对比分析线假设了'可比性'，但可比性本身就是权力"

比较教育学研究揭示了一个被忽视的维度：**"什么可以被比较"本身就是一种文化建构**。当我们说"用同一套维度比较中国和美国的教育"时，我们已经假设了"教育可以用一套通用维度衡量"——但中国的教育逻辑和美国的教育逻辑可能根本不在同一个认知框架里。

对比分析线隐含了一个危险的假设：**所有对象都可以被归约到同一套维度上**。这可能导致"用一把尺子量所有东西"的认知暴力。真正的差异可能恰恰在于"不可比性"本身。

### 攻击者2：产品经理——"对比分析线在商业中经常被用作' justify 已有决策'的工具"

在实际工作中，对比分析线最常见的用途不是"发现真相"，而是"说服别人我的选择是对的"。产品经理做竞品分析时，80%的时间花在"选择对自己有利的维度"上。

结果是：对比分析线变成了一种**修辞武器**——它不是暴露差异，而是操纵差异的呈现方式。"维度先于对象"的设计本意是消除偏见，但实际操作中，维度的选择本身就是最大的偏见来源。

## Synthesis

对比分析线的真正价值不在于"发现差异"，而在于**"暴露维度的盲区"**。

[[yt-skill-storyline-timeline]] 中的时间线暴露的是"发生了什么"，对比分析线暴露的是"我忽略了什么维度"。当两个对象在同一维度上差异巨大，但你不觉得这个差异重要时——这本身就是一个值得记录的认知盲区。

dk-note-human-creativity-ai-data 的核心分工在这里得到体现：AI擅长"在同一维度上比较大量对象"（数据层面），人类擅长"发现新的比较维度"（场景层面）。对比分析线的精髓不是"比得有多细"，而是"选的维度有多准"。

## Constraints & Boundaries

| 边界 | 适用 | 不适用 |
|---|---|---|
| 问题类型 | 需要比较多个对象、理解差异来源 | 只有一个对象或无需比较 |
| 对象关系 | 对象可被同一套维度衡量 | 对象定义根本不同、不可比 |
| 决策阶段 | 暴露盲区、辅助判断 | 已有强烈立场、用于 justify |
| 复杂度 | 维度数 5-10 个、对象 2-4 个 | 高维非线性系统 |

### Common Failure Modes
1. **维度选择偏袒** → 症状：让我方选项得分系统性更高；原因：先选立场再选维度；修复：在列出对象前先独立脑暴维度并外审
2. **强行比较不可比对象** → 症状：同一维度下数值/定义不一致；原因：忽视对象间语义差异；修复：先验证维度对所有对象同时适用
3. **只发现已知差异** → 症状：输出没有意外、读者反应'果然如此'；原因：维度或对象选择保守；修复：强制加入'反直觉差异'检查点
4. **把对比当决策证据** → 症状：用对比结果直接拍板，忽略执行可行性；原因：混淆'差异发现'与'决策依据'；修复：对比后必须接目标取舍线或五步法验证
5. **维度过多导致瘫痪** → 症状：表格巨大、无法收敛；原因：未做维度筛选；修复：先列出全部维度，再删除无法同时适用或权重过低的
## Action Protocol

| 阶段 | 操作 | 标准 |
|:---|:---|:---|
| **进入标准** | 需要"比较多个对象"或"理解差异来源"时 | 如果只有一个对象，用时间线而非对比分析线 |
| **Step 1** | 列出所有可能的对比维度（≥5个） | 维度必须是可以量化的或至少可以明确判断的 |
| **Step 2** | 删除"无法对两个对象同时适用"的维度 | 如果维度对A适用但对B不适用，这个维度不是"通用维度" |
| **Step 3** | 为每个对象在每个维度上赋值 | 值可以是数字、等级、或明确的描述 |
| **Step 4** | 标记"反直觉差异" | 哪个差异和你最初的假设相反？ |
| **Step 5** | 提取"关键要素"——哪个维度解释了最大的差异 | 关键要素必须可以用一句话解释"为什么这个维度决定了结果" |
| **退出标准** | 对比结果产生了≥1个"反直觉发现"或"认知盲区暴露" | 如果只是证实了已知结论，说明维度选择或对象选择有问题 |

## Attacker

### Attacker 1：后殖民理论家——"对比分析线是认知帝国主义"

Edward Said的"东方主义"理论揭示了一个深层问题：**"比较"本身就是一种权力关系**。当西方用"民主/自由/市场经济"等维度"比较"东西方时，它已经在假设"西方维度是普适的"。对比分析线的设计者（通常是有知识优势的一方）选择维度，被比较者（通常是知识弱势方）被动接受维度。

在商业中，这意味着：当管理层用"代码产出量"对比"内容产出量"时，技术团队永远是输家——因为维度是为"可见产出"设计的，而技术工作的价值在"不可见的系统稳定性"上。对比分析线如果不审视"谁有权力定义维度"，就会沦为**维持现有权力结构的工具**。

**当用这张卡的人睡不着觉时**：他们会想——"我定义的维度，是不是恰好让'我认可的东西'得分高？我的对比分析，是不是只是一场精心设计的自我证明？"

### Attacker 2：复杂系统科学家——"线性对比在复杂系统中是幻觉"

在复杂系统中，**对象之间的关系是涌现的，而非可分解的**。当你用4个维度对比两个产品时，你假设了"产品的价值 = f(维度1, 维度2, 维度3, 维度4)"——但真实世界中，产品的价值可能来自维度之间的**非线性交互**。

更危险的是：对比分析线创造了一种"可计算性幻觉"——它让你觉得"我已经全面考虑了"，而实际上你只是在一个极度简化的模型里打转。真正重要的差异可能恰恰是"不在任何维度上"的——比如品牌情感、文化共鸣、时机运气。

**当用这张卡的人睡不着觉时**：他们会想——"我的对比分析看起来完美无缺，但真正的决策因素是不是恰恰在我列出的4个维度之外？我是不是用'系统分析'的幻觉，掩盖了'本质上不可分析'的复杂性？"
