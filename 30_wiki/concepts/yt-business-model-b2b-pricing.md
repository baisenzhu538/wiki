# B2B定价策略：从SMB到Enterprise

> 一堂五步法：B2B定价不是单一价格，而是分层定价体系。从SMB到Enterprise，定价策略完全不同。

## 核心框架

B2B客户分层定价：

```
SMB（中小型企业）
  - 自助服务
  - 标准化产品
  - 低客单价，高数量
  - 定价：透明、简单

Mid-Market（中型企业）
  - 轻度销售
  - 部分定制
  - 中等客单价，中等数量
  - 定价：灵活、可协商

Enterprise（大型企业）
  - 重度销售
  - 高度定制
  - 高客单价，低数量
  - 定价：定制、保密
```

## 关键洞察

### 1. B2B定价的维度

| 维度 | SMB | Mid-Market | Enterprise |
|:---|:---|:---|:---|
| **定价方式** | 公开定价 | 联系销售 | 定制报价 |
| **销售模式** | 自助/ inside sales | Inside sales | Field sales |
| **定制程度** | 无 | 轻度 | 重度 |
| **合同周期** | 月付/年付 | 年付 | 多年 |
| **客单价** | 低 | 中 | 高 |
| **获客成本** | 低 | 中 | 高 |
| **LTV** | 低 | 中 | 高 |

### 2. B2B定价策略

| 策略 | 说明 | 适用场景 |
|:---|:---|:---|
| **按用户定价** | 每用户/每座位 | 协作工具 |
| **按功能定价** | 基础/专业/企业版 | 功能差异大 |
| **按用量定价** | 调用次数/存储量 | 用量差异大 |
| **按价值定价** | 基于客户价值 | 价值差异大 |
| **定制定价** | 根据客户需求定制 | Enterprise |

### 3. B2B定价的心理学

| 心理学 | 说明 | 应用 |
|:---|:---|:---|
| **锚定效应** | 先报高价，再协商 | Enterprise报价 |
| **社会认同** | "同行都在用" | 案例、评价 |
| **损失厌恶** | "不现在签，优惠失效" | 限时优惠 |
| **框架效应** | "每天只需XX元" | 价格分解 |
| **禀赋效应** | 试用后，觉得是自己的 | 免费试用 |

### 4. B2B定价的谈判

| 谈判策略 | 说明 | 示例 |
|:---|:---|:---|
| **捆绑销售** | 多个产品打包 | 买A送B |
| **阶梯折扣** | 用量越大，折扣越多 | 年付折扣 |
| **长期合同** | 多年合同，价格优惠 | 3年合同8折 |
| **试用期** | 免费试用，降低门槛 | 30天试用 |
| **POC** | 概念验证，降低风险 | 小规模试点 |

### 5. B2B定价的常见错误

| 错误 | 症状 | 修复 |
|:---|:---|:---|
| **定价不透明** | SMB客户无法自助购买 | 公开SMB定价 |
| **忽视TCO** | 客户考虑总拥有成本 | 展示TCO优势 |
| **定价僵化** | 所有客户一个价 | 分层定价 |
| **忽视采购流程** | 客户采购流程复杂 | 适配采购流程 |
| **销售与定价脱节** | 销售随意定价 | 制定定价权限 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **单一定价** | 所有客户一个价 | 分层定价 |
| **SMB定价过高** | SMB客户流失 | 降低SMB定价 |
| **Enterprise定价过低** | Enterprise利润低 | 提升Enterprise定价 |
| **忽视定制成本** | 定制服务亏损 | 定制定价覆盖成本 |
| **销售随意定价** | 价格混乱 | 制定定价权限 |
| **忽视客户价值** | 定价脱离客户价值 | 价值定价 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| B2B产品 | B2C产品 |
| 企业级服务 | 个人服务 |
| 分层客户 | 单一客户 |
| 长期合同 | 一次性交易 |

## 行动触发器

- 当设计B2B定价时 → 分层定价
- 当面对SMB客户时 → 透明、简单定价
- 当面对Enterprise客户时 → 定制、协商定价
- 当销售周期长时 → 设计试用、POC等降低门槛
