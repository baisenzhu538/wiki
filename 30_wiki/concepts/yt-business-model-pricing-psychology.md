# 定价心理学：让用户觉得值

> 一堂五步法：定价不是成本+利润，而是让用户觉得"值"。定价心理学帮助设计让用户愿意付费的价格。

## 核心框架

定价的3个层次：

| 层次 | 说明 | 方法 |
|:---|:---|:---|
| **成本定价** | 成本+利润 | 成本×(1+利润率) |
| **价值定价** | 用户感知价值 | 用户愿意付多少钱 |
| **心理定价** | 利用心理效应 | 锚定、对比、框架 |

## 关键洞察

### 1. 定价心理学效应

| 效应 | 说明 | 应用 |
|:---|:---|:---|
| **锚定效应** | 第一个看到的价格影响后续判断 | 先展示高价版本 |
| **对比效应** | 通过对比突出目标选项 | 设计3个版本，中间为目标 |
| **框架效应** | 同样的价格，不同描述感受不同 | "每天1元" vs "每年365元" |
| **禀赋效应** | 拥有的东西估值更高 | 免费试用，让用户"拥有"后付费 |
| **损失厌恶** | 失去比得到感受更强烈 | 限时优惠，"不现在买就失去" |
| **社会认同** | 看别人买什么就跟着买 | "90%用户选择专业版" |

### 2. 版本设计策略

| 版本 | 定价策略 | 目的 |
|:---|:---|:---|
| **基础版** | 低价或免费 | 获客，降低门槛 |
| **标准版** | 目标价格 | 主要收入来源 |
| **高级版** | 高价 | 锚定，让标准版显得值 |
| **企业版** | 定制价格 | 高客单价，个性化 |

### 3. 定价测试方法

| 方法 | 说明 | 适用场景 |
|:---|:---|:---|
| **A/B测试** | 不同价格，看转化率 | 线上产品 |
| **Van Westendorp** | 价格敏感度测试 | 新产品定价 |
| **Gabor-Granger** | 价格-需求曲线 | 确定最优价格 |
| **预售测试** | 预售看付费意愿 | 创业早期 |

### 4. 定价与内核的关系

| 内核价值 | 定价策略 | 示例 |
|:---|:---|:---|
| 高价值，差异化 | 溢价定价 | 苹果、特斯拉 |
| 中等价值，竞争激烈 | 价值定价 | 大多数SaaS |
| 低价值，同质化 | 成本定价 | 日用品 |
| 平台型 | 免费+抽成 | 淘宝、美团 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **成本定价陷阱** | 只算成本+利润，忽视用户价值感知 | 做价值定价 |
| **低价竞争** | 定价低于竞品，利润微薄 | 找到差异化，价值定价 |
| **定价脱离价值** | 定价远高于用户感知价值 | 提升价值感知或降低定价 |
| **版本设计混乱** | 用户不知道选哪个版本 | 简化版本，明确差异 |
| **忽视定价测试** | 定价是拍脑袋定的 | 做定价测试 |
| **定价僵化** | 市场变化，定价不变 | 定期评估定价 |
