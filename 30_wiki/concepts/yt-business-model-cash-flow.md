# 现金流管理：商业模式的血液循环

> 一堂五步法：现金流是商业模式的血液循环。利润高但现金流断裂，企业照样死。

## 核心框架

现金流的三要素：

```
现金流 = 经营活动现金流 + 投资活动现金流 + 筹资活动现金流

经营活动现金流 = 收入 - 成本 - 应收账款 + 应付账款 - 库存

现金周期 = 应收账款天数 + 库存天数 - 应付账款天数

现金周期越短，现金流越健康
```

## 关键洞察

### 1. 现金周期分析

| 要素 | 说明 | 优化方向 |
|:---|:---|:---|
| **应收账款天数** | 从销售到收款的时间 | 缩短：预付款、加速收款 |
| **库存天数** | 库存持有时间 | 缩短：JIT、优化库存 |
| **应付账款天数** | 从采购到付款的时间 | 延长：协商账期 |
| **现金周期** | 应收账款+库存-应付账款 | 越短越好 |

### 2. 不同商业模式的现金流特点

| 商业模式 | 现金流特点 | 风险 |
|:---|:---|:---|
| **订阅制** | 预收款，现金流好 | 退款风险 |
| **项目制** | 按里程碑收款 | 应收账款风险 |
| **电商** | 库存占用资金 | 库存风险 |
| **平台** | 撮合交易，现金流轻 | 交易纠纷 |
| **SaaS** | 月付/年付，现金流可预测 | 流失风险 |

### 3. 现金流优化策略

| 策略 | 说明 | 效果 |
|:---|:---|:---|
| **预收款** | 提前收款 | 改善现金流 |
| **加速收款** | 缩短应收账款周期 | 改善现金流 |
| **优化库存** | 降低库存水平 | 释放现金 |
| **延长账期** | 延长应付账款周期 | 保留现金 |
| **融资租赁** | 租赁替代购买 | 减少现金支出 |
| **保理** | 应收账款融资 | 提前变现 |

### 4. 现金流预警指标

| 指标 | 说明 | 预警线 |
|:---|:---|:---|
| **现金储备** | 现金/月支出 | <3个月 |
| **现金周期** | 现金周转天数 | >60天 |
| **应收账款占比** | 应收账款/收入 | >30% |
| **库存占比** | 库存/收入 | >20% |
| **经营现金流** | 经营现金流/净利润 | <1 |

### 5. 增长与现金流

| 增长策略 | 现金流影响 | 管理 |
|:---|:---|:---|
| **快速增长** | 消耗大量现金 | 控制增长节奏 |
| **有机增长** | 现金流压力小 | 优先有机增长 |
| **并购增长** | 一次性现金支出 | 评估ROI |
| **国际化** | 前期投入大 | 分阶段投入 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **利润幻觉** | 利润高，现金流差 | 关注现金流 |
| **应收账款失控** | 应收账款周期长 | 加速收款 |
| **库存积压** | 库存占用资金 | 优化库存 |
| **过度扩张** | 增长消耗现金 | 控制增长节奏 |
| **忽视现金储备** | 现金储备不足 | 保持3-6个月储备 |
| **融资依赖** | 过度依赖融资 | 优化经营现金流 |
