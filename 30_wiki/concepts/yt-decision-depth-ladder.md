# 深度阶梯工具：L1-L4停车场模型 + 三点预测法

## Summary

任何决策都不该"一刀切"地追求最深分析。深度阶梯工具把ROI评估拆成四级（L1定性→L2部分定量→L3定量公式→L4严格财务），配合"停车场"机制——从浅层开始试，够了就停，不够再往下走。工具同时提供三个数据策略（攒经验值、交叉类比、三点预测法），解决"知道模型但没数据"的实操困境。

**一句话定位**：决策前先问"这车该停在哪一层"，而不是一上来就拆单元模型。

---

## Claims

### 一、四级深度阶梯（What）

| 层级 | 核心动作 | 适合决策类型 | 典型耗时 | 停车信号 |

|------|----------|-------------|---------|----------|

| **L1 优先级定性** | 列收益/成本项，纯文字描述价值与风险 | 简单管理动作、短平快试错（几百~几千元） | 5-15分钟 | 团队一看就懂，无分歧 |

| **L2 部分定量** | 关键收益/成本项转成数字/钱，大差不差估算 | 资源投入类（办公室、涨薪、打车、午餐） | 15-45分钟 | 关键项定量后ROI明显>1或<1 |

| **L3 定量公式** | 把最关键指标拆成转化率漏斗/公式，代入经验值范围 | 获客渠道、运营策略、商业模式验证 | 45-120分钟 | 最好情况都不可接受，或明显可接受 |

| **L4 严格财务ROI** | 完整单元模型：全量成本+收益+退款+履约+复购的财务精算 | 重大投资、融资决策、生死级战略 | 数小时~数天 | 即使最好情况单元模型<1，或明显>安全线（如1.6-2.5） |

> **停车原则**：每层分析完后问自己"这决策能做吗？"——能，停车执行；不能，继续往深走。**不要在浅层吵架**。

#### 三层递进：定性 < 定量 < 定钱

四级深度的本质不是"复杂度递增"，而是**参数的可信度递进**。每一层用颜色编码表示参数的量化成熟度：

| 层级 | 定性（黑） | 定量（绿） | 定钱（红） | 核心特征 |

|------|-----------|-----------|-----------|---------|

| **L1** | A,B,C,D,X,Y,Z 全部为定性描述 | — | — | 只问"有没有"，不问"是多少" |

| **L2** | 部分参数仍为定性 | 关键参数给出数字区间 | 核心成本/收益折算为钱 | "大差不差"的估算，够用就停 |

| **L3** | 极少数边缘参数保留定性 | 转化率漏斗等核心指标定量 | 关键产出折算为财务指标 | 拆公式、代入经验值、证伪判断 |

| **L4** | 无 | 辅助参数定量 | **所有参数全部定钱** | 完整单元模型，财务级精度 |

> **单元模型公式**：`ROI = (A + B + C + D) / (X + Y + Z)` —— 产出端四项，投入端三项。L1时所有字母都是黑色（定性）；L4时所有字母都是红色（定钱）。从L1到L4的过程，就是把字母逐个从黑变绿再变红的过程。

### 二、停车场操作流（How）

```

遇到决策 → L1定性列项 → 能判断？→ 停车

                ↓ 不能

         L2部分定量（关键项变钱）→ 能判断？→ 停车

                ↓ 不能

         L3拆公式漏斗（A×B×C×D）→ 能判断？→ 停车

                ↓ 不能

         L4完整单元模型 → 能判断？→ 停车

                ↓ 还不能

         转化为关键假设 → 设计MVP/MAP实验

```

**关键口诀**："先在黑板上成功，再在现实里成功。"

### 三、L3公式化实操（核心难点）



#### L3定量公式的视觉化表达（源于源图像提取）



L3的核心是“定量”——将关键假设用数字表达，但不强求精确到“定钱”。其公式结构可表达为：



```
投入成本 = A + B + C + D
单位产出 = X
总产出 = Y
```



**变量语义**（源于图像色彩编码）：

- **A, B, C, D**（红色）：投入成本的各组成部分，如固定成本、变动成本、人力成本、运营成本等。
- **X**（红色=定钱）：关键转化率或单位数量，是连接投入与产出的“钱”维度变量。
- **Y**（绿色=定量）：总产出或总收益，是“量”的维度——不一定是财务数字，但必须是可计数的。



**定量与定钱的区别**：

| 层级 | 核心差异 | 示例 |
|:---|:---|:---|
| L3 定量 | 关键项有数字，但可能是区间估算或经验值 | “每个客户获取成本约100-200元”、“转化率约3%-5%” |
| L4 定钱 | 完整财务公式，连边角成本都计算 | “单元交易ROI = 142.6万 / 55万 = 2.59x”、“内部收益率IRR = 18.7%” |



> 视觉标记语义：浅绿色标题栏=L3标识；黑底=权威性声明；红色变量=产出分子/定钱终点；绿色Y=投入分母/定量过程。色彩编码暗示：红色是“终点——要赚多少钱”，绿色是“过程——要做多少个”。





L3是多数复杂决策的"分水岭"。操作步骤：

1. **锁定关键指标**：找到最影响ROI的那一个指标（如获客成本、订单量、收入）

2. **拆转化率漏斗**：把指标展开为乘积公式。例如：

   ```

   有效体验课用户 = 总线索 × 真实率A × 匹配率B × 接通率C × 意向率D × 添加率E

   ```

3. **代入经验值范围**：每个转化率给出一个合理区间（如接通率50%-70%），先用**最高值**算一遍

4. **证伪判断**：如果最好情况都不满足预期→直接关掉；如果最好情况可以→再算中等/悲观

> **案例**：一堂评估"电话外呼10万线索"项目。L2估算"20%×20%=4%转化率"太糙；L3拆成6层漏斗后发现即使每层取最高值，最终转化率仅1.4%，获客成本远高于现有渠道。项目在黑板上被证伪，避免了一个合伙人季度+几十万试错的损失。

### 四、三个数据策略（没数据怎么办）

| 策略 | 适用场景 | 操作步骤 |

|------|---------|----------|

| **① 攒经验值/benchmark** | 长期积累，用于日常决策 | 建立"决策经验值清单"：记录行业常识、竞争对标、历史数据。定期更新（如一堂记录"课程打磨6-18个月"、"转化漏斗通常5-20%"、"教育SaaS年增速50-200%"等） |

| **② 交叉类比** | 新业务缺乏直接数据 | 三步法：①找背后因素（客户密度/付费意愿/竞争程度/品牌基础）；②按影响力排序；③对比多个参照物（头部同行+相邻赛道+自己历史），调整估算，不直接抄数 |

| **③ 三点预测法** | 数字范围很大，不知该用哪个 | 算三遍：①**乐观版**（成本最低、价格最高、转化率最高）→证伪用；②**合理版**→正常预期；③**悲观版**→底线测试。如果乐观版都不成，项目关掉；如果悲观版会死，谨慎推进 |

### 五、深度选择参考表

| 决策特征 | 建议最低深度 | 原因 |

|----------|-------------|------|

| 试错成本<1万，可快速撤回 | L1 | 不值得分析成本 |

| 资源投入（人力/资金/时间） | L2 | 需要钱vs钱的比较 |

| 获客渠道/运营策略/产品方案 | L3 | 转化率漏斗是核心 |

| 融资/重大投资/商业模式验证 | L4 | 必须全量财务精算 |

| 团队有严重分歧 | 比当前深一层 | 吵架是因为讨论太浅 |

### 六、案例：从L2到L3的实际推演

**案例一：是否全员涨薪20%（美容连锁企业）**

| 类别 | 具体项 | 定量估算 | 补充说明 |

|------|--------|----------|---------|

| 关键成本 | 增加人力预算 | 300万/年 | 人力预算上调20% |

| 关键收益 | 保留优质员工 | 30-50万/年 | 培养成熟员工成本3-5万/人，预期多保留10个老员工 |

| | 提升员工士气 | 150万/年 | 基本盘1亿销售额，士气提升3%销售额，净利润50% |

| | 压迫竞争对手 | 100万+/年 | 对手跟进损失5000元/月·店，我们主观评估值100万+ |

| | 提升品牌声誉 | 定性 | 对当地市场品牌知名度、口碑、雇主形象有很好的帮助 |

>评估结果：总收益280-300万/年，总成本300万/年。看似ROI接近1，但"品牌声誉"是定性收益未进入计算，加上后实际ROI>1。这是一个典型的**L2部分定量**案例——关键项转成钱，大差不差估算，已足以支撑决策。

**案例二：一堂租办公室（v3.0版本）**

| 类别 | 具体项 | 定量估算 | 计算过程 |

|------|--------|----------|---------|

| 关键成本 | 装修投入 | 50万（一次性） | — |

| | 房租成本 | 增加50万/年 | — |

| | 水电成本 | 增加5万/年 | — |

| | **总成本** | **55万/年（第一年100万）** | — |

| 关键收益 | 磨课会 | 22万/年 | 每月12场×12月=144场，每场等效1500元研发成本 |

| | 线下活动 | 9.6万/年 | 每月4场×12月=48场，每场节省2000元场地费 |

| | 磨课小屋 | 45万/年 | 3个研发文案类工作效率翻倍，占研发工作50% |

| | 创新实验 | 66万/年（模糊定量） | 3年测出千万利润级业务，场地贡献占20% |

| | 品牌提升 | 定性 | 很难评估新办公室对品牌提升的影响 |

| | **总收益** | **142.6万/年** | — |

>评估结果：第一年净收益42.6万，第二年起净收益87.6万/年。这是一个典型的**L2到L3过渡**案例——大部分项目定量了，但"创新实验"和"品牌提升"仍是模糊定量或定性。L3的价值在于把"磨课会"和"磨课小屋"的收益结构拆到了"次数×单价"的级别，但"创新实验"因为是未知业务，只能做模糊定量。这正是正常的L2停车点——不用等到所有参数都精确才做决策。

## Constraints & Boundaries

1. **循环困境**：判断"该停在哪一层"本身需要预判决策价值，但预判价值又需要一定深度。新手容易在"杀鸡用牛刀"和" underestimating 风险"之间摇摆。

2. **经验值依赖**：L3/L4严重依赖benchmark和经验值。新业务、新市场、新模式缺乏可参考数据时，公式再漂亮也是"拍脑袋的数学伪装"。

3. **时间成本指数增长**：L1→L2→L3→L4耗时从5分钟→数天递增。组织环境中，深度分析容易被视为"拖延"或"过度分析"。

4. **停车焦虑**：决策者可能有心理惯性——"都拆到L3了，不继续到L4不甘心"，导致过度分析沉没成本。

## Critique

### 内部局限

- **"定性<定量<定钱"的颜色编码是理想态，实际决策中很少有"纯黑"或"纯红"的层级**：L1时你心里其实已经在用经验值做定量判断了，L4时仍有部分参数靠假设填充。颜色编码是为了教学清晰，真实决策是一片混色。

- **"停车场"的判断标准不可操作**："能判断吗？"这个问题本身就需要判断力。新手经常在"已经分析了很多，不继续不甘心"和"再深一层可能更清晰"之间犯惑。工具没有提供"停车的具体信号检查清单"。

- **L3公式拆解对"非标准化"业务失效**：转化率漏斗适合营销、电商等标准化漏斗，但对于创意型、定制化、重关系型业务，公式越精确越离谱。拆公式不是目的，是手段——当手段成为目的时候，决策就变成了数字游戏。

### 外部攻击

#### Daniel Kahneman：噪声理论

Kahneman在《Noise》中证明：即便是受过严格训练的专家，其数值估计也充满不可约减的"噪声"。深度阶梯从L2开始就需要大量数字估计（转化率、成本、效率提升），而每一个估计都可能带有±30%-50%的误差。**当你把10个带噪声的数字相乘，最终结果的误差不是30%，而是可能高达300%-500%**。L4的"严格财务ROI"本质上只是"噪声的精确加总"——它给你一种虚假的笃定感，让你相信自己"算清楚了"，但真实值可能在你计算的0.88和你以为的1.2之间剧烈波动。**你在黑板上推演出的"确定性"，可能只是噪声的错觉。**

> **Kahneman的拷问**："你CEO在黑板上算的单元模型，每个数字都经过了'努力调整'来显得合理。但噪声不会因为你的努力而消失——它只是因为乘法而被放大了。你凭什么认为0.88不是0.4？"

#### Friedrich Hayek：知识分散理论

Hayek在《知识在社会中的利用》中证明：经济系统中的关键知识分散在无数个体中，没有任何中央计划者能完整掌握。L4单元模型假设你能枚举所有成本收益——但销售知道客户真实需求、一线员工知道操作成本、供应商知道真实价格、财务知道隐藏现金流风险。**你CEO在黑板上构建的'全量模型'，永远只是你能看到的部分，不是商业真实的全部。**模型越完整，你对"残缺"的盲区越盲目——因为你已经花了数天"完善"它，反而更难质疑它的基础假设。那些真正决定成败的信息，根本不在你的模型里。

> **Hayek的拷问**："你的单元模型有20个变量，但真实业务有200个。你花了三天优化那20个变量的精度，却对那些从未进入你视野的180个变量一无所知。这不是决策，这是用Excel自慰。"

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |

|------|-----------|---------|

| **决策试错成本极低（几百元、几天时间）** | L1就足够了，上L2/L3/L4是分析浪费。拉高了决策成本，降低了执行速度。 | 直接用L1定性列项，5-15分钟定论。 |

| **团队没有Y型决策习惯** | 深度分析会变成"用数据包装立场"的工具——先有了结论，再找数据支撑。 | 先用[[yt-decision-habit-shift]]诊断并转换团队决策习惯，再上深度工具。 |

| **关键数据完全缺失且无类比可能** | 硬拆L3/L4只是"拍脑袋的数学伪装"，公式越复杂越有迶导性。 | 不要硬拆，直接转为MAP实验设计，用小规模实践获取真实数据。 |

| **情绪决策（涉及个人情感、面子、权力斗争）** | 深度工具对"不讲道理"的决策无效，数字不能解决价值观冲突。 | 换用沟通或决策者独裁（如你是老板，直接拍板）。 |

### 常见误用

| 误用 | 后果 | 纠正 |

|------|------|------|

| 所有决策都上L4 | 分析瘫痪，团队疲惫，小事大做 | 按试错成本和决策价值选择层级 |

| L3只算中值，不算最好/最坏 | 错过证伪机会，或低估下行风险 | 强制三点预测：乐观→证伪→悲观→底线 |

| 直接抄同行数据做类比 | 忽略用户画像、竞争环境、品牌差异等关键变量 | 交叉类比三步：找因素→排序→调数字 |

| 把公式当真理，不验证 | 黑板推演与现实脱节，造成重大损失 | "先在黑板上成功，再在现实里成功"——黑板成功后仍需小规模验证 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |

|---------|-----------|---------|

| **需要对重大决策做定量分析时** | 花30分钟建立个人经验值清单：把过去1年最常用的5-10个数字写下来（获客成本、转化率、人效、毛利率等），注明口径和适用条件 | 清单不少于5个关键指标，每个指标有明确的数字范围和适用场景 |

| **想要检查团队过去的决策深度时** | 选一个最近的重大决策，反推"当时停在L几？"——如果实际该L3但做了L2，计算损失；如果该L2但做了L4，计算浪费的时间 | 产出1份"深度诊断报告"，明确标注"应该做到的层级"和"实际做到的层级" |

| **团队为某个方案争执时** | 不急着表态，在白板上说："我们先不争论观点，把关键项列出来，尝试变成数字。"——从L1推进到L2，多数争论会自然消解 | 至少1个原本"观点对立"的争论项被转化为可量化的数字对比，团队从"觉得"转变为"算得" |

| **新业务/新市场缺乏benchmark时** | 不要硬拃L3/L4，先用MAP实验设计获取真实数据：设计一个最小可行实验，用实际结果替代假设 | 实验在2周内跑完，获得至少1个关键数据点用于后续分析 |
