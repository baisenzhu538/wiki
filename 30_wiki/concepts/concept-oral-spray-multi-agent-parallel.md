# 多 Agent 并行口喷 + OPT

## 一句话

口喷使**多 Agent 并行**成为可能——人脑力拉满同时指挥 3-5 个（甚至 8-10 个）Agent，构成 OPT（One Person Team）一人团队协作范式。

## 多 Agent 并行的关键（Live260 L181-197）

第二次飞跃（被动→主动，通往 L3）的核心：从"被动等 AI 回答"到"主动像嘱咐人一样派活"——5 个关键补充逻辑（示例）：
1. 背景定位：你的定位是 xx、职责是 xx
2. 对象区分：一定要搞清楚两个对象，不要搞错
3. 知识库利用：后台 Obsidian 知识库有没有类似经验
4. 最佳实践判断：哪些必须二选一/可以统一
5. 逻辑追问：如果可以统一，其逻辑到底是什么

**像和人协作的方式嘱咐**——全面增加 AI 工作表现和准确度。

## OPT 一人团队（Live260 L255-269）

L5（第四次飞跃：单项→流淌）OPT 状态的工具栈：一个飞书（交付文稿 + Feishu2Slide 自动 PPT）+ 一个 Obsidian（核心文档）+ 一个 Codex（5-7 个 Agent 随时待命）+ 笔记本备用 + 沉浸 BGM。**脑力拉满 + 多 Agent 并行 = 一个人一支队伍**。

## 实证案例：一晚做 360 内训课（L255-269）

- 20 分钟灵感闪现的澡（yy 出美好想象/训练故事线/魂儿惊喜）
- 10 个 Codex 交叉分工，全程口喷
- 3-10 小时连续工作，交付完整课程

## 边界与反例

- 多 Agent 并行依赖口喷能力（L1-L2 基础）——直接跳级会乱
- "AI 能闲人不能闲"——并行是脑力驱动不是挂机
- 并行数量有上限（8-10 个打地鼠式管理），非越多越好

## 为什么值钱

把"一个人做不完的项目"变成"一个人 + 多 Agent 的口喷协作"——**产能上限从线性变并行**，是 AI 时代个人杠杆的核心机制。

## 补强：00 顶层文档工作法 + 设备贡献度（#529 口述补充，2026-08-25）

**00 顶层文档工作法（B5812-5840）**：多 Agent 协作开局第一件事——把项目设想一口气喷成 00 文档（实证：洗澡灵感 20 分钟喷 3500 字→AI 整理成顶层文档）。此后每个新拉起的 Agent 先读 00 文档再干活，**免除逐窗反复交接**：「有了这个文档，所有 AI 读完就能自由工作；没有它，每个 AI 干活都缺必要信息。」目录里所有文档从 00 读起。

**设备贡献度 <10%（B6126-6128）**：远程按键/蓝牙口喷/罗技鼠标/自研多线程硬件等设备，加一起对产出的贡献不超过 10%——更多是仪式感、沉浸感和习惯。新手期不必拘泥，遇到多线程天花板再找设备解法。
