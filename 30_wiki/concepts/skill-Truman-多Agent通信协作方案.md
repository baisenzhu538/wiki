# 技能：多Agent通信协作方案

## 原始表述

多Agent通信协作方案是Truman在AI工具应用AMA中提出的实操方法。

## 操作步骤

1. 反思需求：是否必须多Agent？尝试单一Agent配多Skill
2. 简单方案：人在环，人工艾特补全，不纠结自动化
3. 进阶方案一：构建楚门类系统实现Agent间通信
4. 进阶方案二：设置定时任务，让多个Agent访问共同资源
5. 分布式方案：学习蜂群战术等复杂对抗通道的分布式系统设计
6. 评估复杂度与成本，选择最简可行方案

## 适用场景

- 多个Agent需要协同工作
- Agent间信息传递失败或不回消息
- 构建复杂AI系统时

## 不适用场景

- 简单任务可用单Agent完成
- 时间精力不足以支撑复杂开发

## 工具/环境

- 楚门系统
- 定时任务机制
- 共享资源池
- 分布式系统设计
- Codex/Cloud Code

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

多Agent通信是业界难题，不应过度纠结；核心是用最小成本解决问题，人在环往往是最务实的选择
