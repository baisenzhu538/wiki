# 商业模式定义：从内核到变现

> 一堂五步法：商业模式是产品内核的变现路径。内核是价值，商业模式是让用户为这个价值付费的方式。

## 核心框架

```
产品内核（价值）
    ↓
"用户为什么选我们"
    ↓
商业模式（变现）
    ↓
"用户如何为这个价值付费"
    ↓
单元模型（验证）
    ↓
"LTV > CAC？"
```

## 关键洞察

### 1. 商业模式的组成

| 要素 | 说明 | 示例 |
|:---|:---|:---|
| **价值主张** | 用户为什么付费 | "有效去屑+专业形象" |
| **目标客户** | 谁付费 | 有头皮屑问题的成年人 |
| **收费方式** | 怎么收费 | 按瓶、订阅、按次 |
| **定价策略** | 收多少钱 | 高价、中价、低价 |
| **渠道** | 怎么触达 | 线上、线下、分销 |
| **成本结构** | 花多少钱 | 研发、营销、运营 |

### 2. 商业模式与内核的关系

| 关系 | 说明 | 错误 | 正确 |
|:---|:---|:---|:---|
| **内核支撑定价** | 价值高，定价高 | 价值低定价高 | 价值高定价高 |
| **商业模式强化内核** | 收费方式强化价值 | 收费方式削弱价值 | 订阅制强化持续服务 |
| **单元模型验证** | LTV > CAC | 只看收入不看成本 | 完整单元模型 |

### 3. 常见商业模式类型

| 类型 | 说明 | 适用场景 | 示例 |
|:---|:---|:---|:---|
| **一次性销售** | 一次性购买 | 实体产品 | 洗发水 |
| **订阅制** | 定期付费 | 服务、内容 | SaaS、会员 |
| **免费增值** | 基础免费，高级付费 | 工具、平台 | 钉钉、Dropbox |
| **平台抽成** | 撮合交易，收取佣金 | 平台、市场 | 淘宝、美团 |
| **广告模式** | 免费使用，广告变现 | 流量产品 | 抖音、微信 |
| **企业定制** | 按项目收费 | B2B服务 | 咨询、开发 |

### 4. 商业模式选择原则

| 原则 | 说明 | 检查问题 |
|:---|:---|:---|
| **匹配内核** | 商业模式强化内核价值 | "这个收费方式让用户更认可价值吗？" |
| **用户接受** | 用户愿意按此方式付费 | "用户测试过这种付费方式吗？" |
| **单元模型成立** | LTV > CAC | "获客成本多少？用户生命周期价值多少？" |
| **可规模化** | 能大规模复制 | "这个模式能支撑100万用户吗？" |
| **可持续** | 长期可持续 | "这个模式3年后还成立吗？" |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **内核成功但商业模式失败** | 用户用但不付费 | 验证付费意愿，调整定价 |
| **免费陷阱** | 免费用户多，付费少 | 设计付费转化路径 |
| **定价脱离价值** | 定价远高于价值感知 | 调整定价或提升价值感知 |
| **忽视单元模型** | 只看收入，不看成本 | 计算完整单元模型 |
| **商业模式与内核冲突** | 收费方式削弱内核 | 调整商业模式 |
| **模式不可规模化** | 单元模型成立但无法规模化 | 检查获客渠道和转化效率 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 商业模式设计 | 技术架构设计 |
| 定价策略 | 品牌传播策略 |
| 单元模型验证 | 运营活动评估 |
| 产品商业化 | 纯公益项目 |
