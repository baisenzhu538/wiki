---# 技能：AI输出三层防护检查法

> **来源**：基于 master-ai-info-literacy 框架提炼
> **核心**：用AI做调研时，三层防护网——先辨别是不是幻觉，再验证是不是真的，最后追溯到原始来源。

---

## 原始表述
> "AI生成内容的成本趋于零，但真实性的成本没有下降。当AI能在10秒内生成一份看似专业的行业分析报告时，用户的危险不是'用不好AI'，而是'把AI的幻觉当真理'。"
> —— 基于一堂课程提炼

---

## 操作步骤

### 第一层：Detect — "这是幻觉吗？"

对任何AI输出，先问三个问题：

| 检查项 | 问题 | 警报信号 |
|:------|:-----|:--------|
| 事实性幻觉 | 它给了具体数据吗？ | "根据2024年X报告"→但你找不到这个报告 |
| 逻辑性幻觉 | 推理链条完整吗？ | A→B听起来对，但中间缺了关键步骤 |
| 引用性幻觉 | 引用的来源真实吗？ | 引用了一篇"看起来很对"的文章但查无此文 |
| 置信度幻觉 | 确定语气是否过度？ | "显然——"、"当然——"、数字过于整齐 |

**快速诊断法**：
1. 无数据→更容易幻觉
2. 无来源→必须下一层
3. 过多"显然/当然"→置信度幻觉

### 第二层：Verify — "这是真的吗？"

对"可能有问题"的结论，用四种方法验证：

| 方法 | 操作 | 适用场景 |
|:-----|:-----|:--------|
| 交叉验证 | 换一个AI/搜索引擎问同一个问题 | 任何关键数据或结论 |
| 常识验证 | 用领域常识判断"数值太大/太小/太整齐" | 数据看起来"太正好" |
| 时效验证 | 检查信息的时间戳 | 市场数据、政策、竞品动态 |
| 一致性验证 | 同一问题换种问法问两遍 | 定性推断/判断 |

### 第三层：Trace — "来源在哪？"

对验证为真的信息，追到原始来源：

| 方法 | 操作 | 解决什么 |
|:-----|:-----|:--------|
| 主动索要来源 | "请给出这个结论的具体出处" | AI综合多个来源后"忘了"分别是谁 |
| 反向搜索 | 用关键词/作者名/机构名搜索 | 验证"据XX研究"是否存在 |
| 一手/二手区分 | 判断是直接来源还是被转介 | 信息传递中的污染 |
| 信源质量评级 | 对每个来源打"权威性/偏见性/时效性"分 | 来源本身是否可靠 |

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 用AI做调研后，检查输出质量 |
| ✅ 适合 | 准备引用AI输出时，必须执行第三层 |
| ✅ 适合 | AI给出关键数据/结论时，立即执行第一层 |
| ✅ 适合 | 多个AI给出矛盾答案时，用交叉验证找共同基础 |
| ❌ 不适合 | 日常闲聊/创意发散 → 不需要验证 |
| ❌ 不适合 | 已验证过的已知信息 → 不需要重复检查 |
| ❌ 不适合 | 时间极度紧迫 → 至少执行第一层（3秒） |
| ❌ 不适合 | AI明确标注"这是推测/不确定"的内容 → 已经自我标记 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **自动化偏差** | AI说的应该就是对的，不做任何审查 | 强制条件反射：如果这是初级员工写的，你会怎么审查？AI输出不是知识，是待验证的假设 |
| **流畅性启发** | 回答很有道理，误以为真实，被流畅性欺骗 | 让AI用不确定语气重说，看结论是否变化。丝滑不等于正确 |
| **引用光环** | AI引用了论文所以是真的，不查原文 | 不管多少引用，先检查第一个是否能找到原文。引用可能是幻觉 |
| **验证过载** | 每条都验证，时间不够，验证疲劳 | 分层：高风险结论全检，低风险结论只检第一层。不是每条都需要三层 |
| **追溯缺失** | 验证为真就够了，不追到原始来源 | 必须追到原始来源，防止综合后的信息丢失来源。第三层不可跳过 |
| **层级跳跃** | 跳过第一层直接验证，浪费时间在已知的幻觉上 | 必须先做第一层Detect，发现幻觉直接丢弃，不需要验证 |
| **来源迷信** | 追到来源就认为可靠，不评估来源质量 | 对来源打权威性/偏见性/时效性分。来源本身也可能不可靠 |
| **验证后遗忘** | 验证完不记录，下次重复同样验证 | 建立验证记录，标记已验证内容，避免重复劳动 |

## 为什么有效

AI的幻觉不是"偶尔出错"，而是**系统性偏差**——AI被训练成"给出流畅、完整的答案"，而不是"给出准确的答案"。三层防护的本质是：**把"被动信任"变为"主动验证"**。

**金句**：一个AI的答案不是知识，是一个待验证的假设。

## 工具/环境

- **必需**：无（纯思维工具）
- **推荐**：搜索引擎（Google/百度）——第三层追溯用
- **备用方案**：如果无法搜索，要求AI"用不确定的语气重说一遍"，看结论是否变化
