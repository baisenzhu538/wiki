# 一堂创业地图：高潜力创业者修炼全景图

> 来源：一堂《创业地图：高潜力创业者修炼全景图》。[[一堂]] | [[yt-model-progress-map]] | yt-system-course-catalog#创业必修

## Summary

创业地图是进步大地图中「创业修炼」的完整展开，以「概率」为核心追求。按创业生命周期分为三个阶段：预判阶段（高水准选择）、起盘阶段（低成本创业）、增长阶段（可持续发展），底层是「实事求是 解放思想」的 Y 模型支撑。一句话：创业是个概率游戏，科学方法论帮你把自己修炼成概率高手。

## Claims

### 三阶段结构

| 阶段 | 核心命题 | 关键动作 | 对应课程模块 |
|------|---------|---------|-------------|
| **预判阶段** | 高水准选择 | 预判项目方向、预判行业机会、预判长期集中度、拆解关键假设 | 五步法体系、机会预判、行业画布 |
| **起盘阶段** | 低成本创业 | 高水平拆假设、十倍速验证假设 | 产品内核、单元模型、情报调研、精益实验 |
| **增长阶段** | 可持续发展 | 增长飞轮、融资加速、构建壁垒、战略取舍 | 融资必修、科学销售、科学抖音、渠道探索 |

### 起盘阶段双轨并行

| 轨道 | 目标 | 方法 |
|------|------|------|
| **商业拆解** | 把项目拆明白 | 挖需求 → 找内核 → 算模型 → 挖常识 |
| **高效验证** | 低成本证伪 | 找情报 → 做测试 |

### 增长阶段核心模块

| 模块 | 核心命题 |
|------|---------|
| 战略取舍 | 选择不做什么比选择做什么更重要 |
| 打造文化 | 公司文化的基因塑造 |
| 学习型组织 | 让组织具备持续进化能力 |
| 增长飞轮 | 找到增长的底层逻辑和杠杆点 |
| 融资加速 | 融资认知+实操体系 |
| 构建壁垒 | 项目壁垒的五步法分析 |

### 科学专项工具箱

六项成熟 + 五项研发中：

| 成熟专项 | 研发中专项 |
|---------|-----------|
| 科学决策、业务提升、关键转化 | 科学选品*、科学投放* |
| 科学销售、科学抖音、科学起名 | 科学选址*、科学定价*、科学私域* |
| 科学送礼 | |

### 底层逻辑

底部是八字方针的循环：**实事求是 ↔ 解放思想** → 持续练内功 → Y 模型：科学理念和追求

### 核心追求

**这张图的核心修炼目标是：概率**——创业是个概率游戏，不靠运气，靠把每一步的成功概率用科学方法提到最高。

## Synthesis

创业修炼地图以「概率」为核，与个人修炼域（刻意练习、深度复盘、知识萃取、IPO学习、AI能力、Y模型探索）形成「内功→外功」闭环——前者训练创业者个体认知与技能，后者将这些能力投射到创业场景的具体决策与执行中。管理修炼域（管理地图、工具箱总览、OKR、会议设计、招聘打分卡）覆盖团队放大阶段的组织能力，是创业地图中「增长阶段」的进阶支撑。终局光谱图与项目壁垒提供预判阶段的行业格局分析工具，Y模型提供底层思维引擎。六大域协同构成创业者从个体能力→创业实战→组织管理的完整修炼链。

## Constraints & Boundaries

### 适用边界

| 场景 | 说明 |
|:-----|:------|
| ✅ **0→1 探索期创业团队** | 地图核心方法论（拆假设→低成本实验→求证）面向需求未验证、商业模式未跑通的早期创业，此时工具链价值最高。 |
| ✅ **资源受限、需低成本验证的创业者** | 地图强调情报调研与关键假设验证，对资金有限、必须精打细算的团队尤为适用。 |
| ✅ **有行业经验但缺系统框架的创业者** | 能把碎片经验整合到"预判→起盘→增长"的结构中，避免凭感觉跳跃决策。 |
| ✅ **创业教育与方法论学习场景** | 作为导航图，适合训练营、课程设计、个人自学，帮助按阶段选择工具。 |
| ❌ **已有 PMF 且进入规模复制的公司** | 此时核心问题是组织放大与效率优化，精益实验、情报调研等工具会拖慢执行节奏。应改用[[yt-model-management-map]]。 |
| ❌ **硬科技/深科技创业** | 起盘即低成本验证的假设在需要大量前置 R&D 和监管审批的领域失效。应改用 IP 驱动框架与技术里程碑验证。 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:------|:-----|
| **地图当收藏夹** | 收藏后三个月未打开，遇到关键决策仍凭直觉；说不清当前处在哪个阶段。 | 把地图嵌入工作流：每次关键决策前强制对照当前阶段，先用 Action Triggers 的第一个动作启动。 |
| **跨阶段跳跃学习** | 刚学完起盘阶段就跳到壁垒阶段，工具用不上；学了很多但业务没变化。 | 用"当前最大痛点在哪个阶段"锁定学习范围，完成当前阶段 Action Trigger 的成功指标再进入下一阶段。 |
| **增长阶段仍用低成本验证思维** | 该扩张时过度谨慎，反复做小实验；窗口期被耽误，竞争对手抢先。 | 切换到"高压验证"或"组织复制"模式：核心指标从验证成功率转为单元模型 ROI 和复制成功率。 |
| **概率追求无量化指标** | 口头说"提升概率"，但团队无 dashboard；关键假设成立与否只有主观感觉。 | 为每个关键假设建立概率评估机制，定期更新并对比历史基线，让概率从口号变成可追踪的指标。 |
| **线性叙事误导** | 忽视真实创业的回环迭代，预判错误到增长阶段才暴露，回头重判成本极高。 | 在每个阶段末设置"回判检查点"，允许返回上一阶段修正核心假设，明确写下什么信号会触发回退。 |

## 落地模板：创业地图阶段自评 Checklist

> 用下面 6 个问题判断你当前处于创业地图的哪个阶段，以及应该优先调用哪些工具。建议每两周复评一次。

| 序号 | 问题 | 如果你的答案是"是/高" | 对应阶段 | 优先工具 |
|:---:|:-----|:--------------------|:---------|:---------|
| 1 | 你是否还不确定这个需求是否真实存在、用户是否愿意付费？ | 是 | 预判阶段 | [[yt-entrepreneur-five-step-method]]、[[yt-entrepreneur-key-hypotheses]]、[[yt-foresight-business-spectrum]] |
| 2 | 你是否已经找到一个具体方向，但还没有验证核心商业模式？ | 是 | 起盘阶段 | [[yt-entrepreneur-lean-validation]]、[[yt-entrepreneur-key-hypotheses]]、[[yt-research-osl-framework]] |
| 3 | 你的单用户/单门店/单 SKU 模型是否在真实环境中跑通？ | 否 | 起盘阶段 | [[yt-unit-model-overview]]、[[yt-lean-growth-stage-gate]] |
| 4 | 你是否已经找到一条可放量、可复制的增长渠道？ | 否 | 起盘→增长过渡期 | [[yt-entrepreneur-channel-exploration]]、[[yt-growth-cycle-model]] |
| 5 | 你的核心单元模型是否成立且增长渠道已验证？ | 是 | 增长阶段 | [[yt-lean-growth-stage-gate]]、[[yt-entrepreneur-growth-flywheel]]、[[yt-entrepreneur-barriers]] |
| 6 | 你是否面临组织放大、文化建设和人才密度问题？ | 是 | 增长阶段→管理修炼 | [[yt-model-management-map]]、[[yt-management-toolkit-overview]] |

### 使用规则

1. **从上往下依次回答**，停在第一个让你产生犹豫的问题上，那就是你当前最该聚焦的阶段。
2. **不要同时处理两个阶段**：完成当前阶段的 Action Trigger 指标后，再进入下一阶段。
3. **每两周复评一次**：创业阶段会快速变化，定期复评防止工具错配。
4. **遇到回退信号时允许回退**：如果增长阶段发现单元模型其实不成立，回到起盘阶段重新验证，而不是在错误前提上继续放大。

## Action Triggers

以下触发场景提供可操作的"第一个动作"和可验证的成功指标，帮助你将地图的方法论落地执行。

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **你有一个创业想法但不确定是否值得做** | 打开"五步法"工具，完成第一步：写出你为谁解决什么问题的单句陈述，然后列出支撑这个需求存在的 3 条客观证据（非自己的主观判断）。 | 3 条客观证据中至少有 1 条来自直接客户访谈记录或第三方行业数据；若 24 小时内无法收集到任何客观证据，标记该项目为"高风险未验证假设"。 |
| **项目已启动但进展缓慢，不确定卡在哪里** | 画出当前项目的"关键假设树"（把商业模型拆成 ≤10 个可独立验证的假设节点），对每个节点标注当前验证状态：已证真（有数据支撑）/ 已证伪 / 未验证。 | 假设树上 ≥80% 的节点都有明确的验证状态标注（不能出现大量"未验证"——那说明你根本还没开始验证）；找到至少 1 个"已证伪"节点并写下纠正动作。 |
| **产品已上线但增长停滞，不知从何处突破** | 选择"增长阶段核心模块"中的一个模块（建议从"增长飞轮"开始），画出你当前业务的飞轮图：标注每个节点当前的转化率或效率数据，找出最薄弱的那个节点。 | 飞轮图上的每个节点都有定量数据（不能是"感觉还不错"），且最薄弱节点的转化率数据与行业基准对比有明确差距（差距 ≥30% 则该节点即为优先改进项）。 |
| **面对多个创业方向，不确定应该选哪一个** | 对每个候选方向用"行业画布"做快速扫描（≤2 小时/方向）：画出行业结构、集中度趋势、你在其中的可能位置。然后做一张对比矩阵表，行=方向，列=市场规模/集中度趋势/自身优势匹配度/可验证性。 | 每个方向都完成了行业画布扫描（不允许"这个方向还没想清楚就先不列"），矩阵中至少有一个方向在"可验证性"列被评为"高"（即 2 周内可以设计出一个关键假设验证实验）。 |
