---# 业务公式六层逻辑关系（L1 模糊 → L6 动态）

> 一堂把人对业务公式的理解深度分为 6 层：从 L1「模糊」的安慰剂，到 L6「动态」的导航仪。每一层不仅对应公式的复杂度，更对应管理者的决策能力。  
> 来源：一堂 2026-06-13 业务公式拆解培训（孔阳），「一堂业务公式·6层逻辑关系」图。

---

## 六层逻辑总览

| 层级 | 名称 | 比喻 | 获得价值 | 如何提升 |
|---|---|---|---|---|
| L1 | 模糊 | 安慰剂 | 有模糊答案，内心踏实 | — |
| L2 | 相关 | 体温计 | 有确定性规律可预测监控 | 找相关性 |
| L3 | 因果 | 方向盘 | 有因果规律判断，找到业务抓手 | 找因果性 |
| L4 | 公式 | X 光片 | 有完备公式，抓主要矛盾路径 | 参数尽量完备 |
| L5 | 定量 | 刻度尺 | 有定量和判断空间，预判增长空间 | 找基准值/空间 |
| L6 | 动态 | 导航仪 | 自己建立模型，动态理解公式 | 动态理解公式 |

---

## 各层详解

### L1. 模糊（Fuzzy）

**特征**：没有公式，凭感觉讨论业务。

> "最近势头不错""转化好像有点低""用户粘性还行"

**价值**：内心踏实，但无法指导决策。  
**风险**：每个人都在用不同的直觉做判断，团队无法对齐。

### L2. 相关（Correlation）

**特征**：发现变量之间的相关性，但不确定因果。

```
R ~ r
```

**示例**：发现投放量增加时，营收也增加。  
**价值**：可以监控趋势。  
**风险**：把相关当因果，做出错误干预（如加大投放后发现 ROI 下降）。

**提升方法**：找相关性 → 控制变量验证 → 确认因果。

### L3. 因果（Causation）

**特征**：明确变量之间的因果关系。

```
R = f(A, B, C)
```

**示例**：转化率低是因为落地页信任信号不足，而不是流量不精准。  
**价值**：知道该动哪个变量。  
**风险**：因果链太短，忽略了中间变量。

**提升方法**：找因果性 → 拆解中间机制。

### L4. 公式（Formula）

**特征**：有完备的业务公式，能抓主要矛盾路径。

```
R = (A + B) × C × D
```

**示例**：
```
营收 = （新客收入 + 老客收入）× 渠道效率 × 转化率
```

**价值**：可以定位短板，分配资源。  
**风险**：公式完备但参数不准，导致虚假确定性。

**提升方法**：参数尽量完备 → 验证每个参数的可测量性。

### L5. 定量（Quantification）

**特征**：公式中的每个参数都有数值、基准和判断空间。

```
R = (A + B) × C × D
A=400, B=850, C=25%, D=5%
```

**价值**：可以预判增长空间，做 ROI 决策。  
**风险**：数字来自假设而非事实，容易自我欺骗。

**提升方法**：找基准值/空间 → 用历史数据和行业对标校准。

### L6. 动态（Dynamic）

**特征**：不仅知道当前公式，还能理解公式如何随业务阶段变化。

```
R_t = f(A_t, B_t, C_t, 外部变量_t)
```

**示例**：知道早期业务看转化率，成熟期看复购率，衰退期看成本结构。  
**价值**：能主动调整公式，而不是被公式锁死。  
**风险**：过度复杂，失去可操作性。

**提升方法**：动态理解公式 → 建立「公式版本迭代」机制。

## 六层逻辑与管理段位

| 段位 | 典型表现 | 对应层级 |
|---|---|---|
| 初级操盘手 | 看大盘，凭感觉 | L1-L2 |
| 中级操盘手 | 会拆公式，找短板 | L3-L4 |
| 高级操盘手 | 定量判断，预测增长 | L4-L5 |
| 业务负责人 | 动态调整公式，驾驭变化 | L6 |

---

## 常见陷阱

1. **L2 陷阱**：把相关当因果。看到两个变量同向变化就加大投入。
2. **L4 陷阱**：公式完美但参数不准。形式正确，结论错误。
3. **L6 陷阱**：公式过于复杂，团队无法执行。动态性变成不确定性。

---

## 自检清单：当前业务公式拆到哪一层才够

| 检查项 | 达标标准 | 未达标的风险 |
|---|---|---|
| **1. 当前业务应拆到哪一层** | 新业务/找方向 → L3-L4；成熟业务/做预算 → L4-L5；战略调整 → L6 | 层级过低：拍脑袋；层级过高：过度复杂 |
| **2. 每个定性参数是否找到 3-5 个行为指标** | 如“信任度”拆为详情页完成率、评论停留时长、完课率、咨询发起率等 | 定性参数无法验证，沦为口号 |
| **3. 公式是否可验证、可执行** | 每个参数都有数据来源、责任人和迭代节奏 | 公式停留在 PPT，无法落地 |
| **4. 加减乘除是否与业务关系一致** | 同一维度内用加法（+），漏斗环节用乘法（×），监控用相关（~），干预用因果（→） | 关系写错，资源错配 |
| **5. 是否建立了公式版本迭代机制** | 每季度复盘：公式是否还描述当前业务的主要矛盾 | 业务变了，公式没变 |

---

## 如何提升一层

| 当前层级 | 下一步动作 |
|---|---|
| L1 → L2 | 列出所有可能影响目标的变量，找相关性 |
| L2 → L3 | 对关键相关关系做控制变量实验 |
| L3 → L4 | 把因果关系写成完整公式，标注运算符号 |
| L4 → L5 | 为每个参数找基准值，计算提升空间 |
| L5 → L6 | 建立公式版本管理机制，随业务阶段更新 |
