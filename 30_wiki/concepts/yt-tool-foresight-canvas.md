# 预判画布：从加法到减法的标准化工作台

## 用途

在做新项目机会预判时，把十五字法诀（主动定中局→充分做加法→专业做减法）标准化到一张可操作的画布上。替代"脑子里想想"的模糊预判。

## Protocol

### Step 1：定中局（5分钟）

```
我的终局预期：
  保A（最低可接受结果）：___________
  争B（理想目标）：___________
  时间跨度：3年 / 5年 / 10年
  光谱位置：L1-L7（副业-上市）
```

### Step 2：做加法——选项池（30-60分钟）

三条轴展开，列出所有组合：

```
轴1：行业/赛道
  └─ 选项1: ____  选项2: ____  选项3: ____  ...（至少5个）

轴2：产业链环节/切入方式
  └─ 选项1: ____  选项2: ____  选项3: ____  ...（至少3个）

轴3：商业模式要素（价格带/客群/渠道/城市/产品形态）
  价格带: ____ / ____ / ____
  客群: ____ / ____ / ____
  渠道: ____ / ____ / ____
  城市: ____ / ____ / ____
  产品形态: ____ / ____ / ____
```

**自检**：选项总数是否≥20？如果不够，回去继续列。

### Step 3：做减法——硬伤排除（30-60分钟）

对每个候选选项逐条对照十大硬伤：

| 硬伤维度 | 选项A | 选项B | 选项C |
|:---------|:-----:|:-----:|:-----:|
| 需求不刚需 | | | |
| 天花板太低 | | | |
| 产品内核不强 | | | |
| 单元模型不成立 | | | |
| 缺少增长路径 | | | |
| 初心不匹配 | | | |
| 核心能力缺失 | | | |
| 关键资源不够 | | | |
| 无变化无大机会 | | | |
| 窗口期已过 | | | |

标记：✅ 无硬伤 / ⚠️ 有风险但可解 / ❌ 致命硬伤

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:------|
| ✅ 适合条件 | 创始人/团队需要在多个方向中做出选择、面临行业或市场层面的不确定性、有足够的时间（2-4小时）做系统思考的场景 |
| ❌ 不适合条件 | 纯执行阶段不需要方向选择、紧急决策无法等待完整画布流程、极端早期（连选项都列不出来）的阶段 |

#| 模式 | 症状 | 修复 |
|:-----|:------|:------|
| **预判了但没行动** | 创始人做了完整预判，趋势判断正确，但产品方向迟迟未调整——团队按惯性继续执行旧方向 | 预判画布的最后一步必须加上\"行动承诺\"：每个预判结论对应一个具体的决策deadline和负责人。画布不产出行动承诺等于没做。 |
| **填完了但没想透** | 画布每个格子都填满了，但CEO说不出\"哪个选项是真正想选的\"——填表格替代了思考 | 在画布完成后增加\"口头测试\"：让创始人不用看画布，口头说一遍三个选项的优劣。说不清楚说明没想透。 |

## When NOT to Use
| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **创业者已经有强直觉判断、方向已很明确**（如连续创业者回到自己最熟悉的赛道） | 画布的加法环节（列举≥20个选项）强迫有明确方向的人去重新考虑明显不适合的选项——这是认知资源的浪费。更糟的是，过多的选项列表会让本来坚定的方向看起来"只是20个选项之一"，消解了应该被保留的专注力 | 跳过预判画布，直接用"假设驱动验证"——写下你的直觉假设（"我相信X方向是对的因为Y"），然后设计最小实验去挑战它。画布的加法减法对明确方向的创业者不是帮助，是噪音 |
| **极端早期阶段，连行业基本结构都不了解的探索期** | 加法环节要求"轴1：列出≥5个行业/赛道"——但如果你连行业的基本格局、玩家、经济特性都不了解，列表是凭空想象。加法质量=0时，后续的减法只是在无效选项上做无用功 | 先用"行业速描法"：找3个该行业老兵做深度访谈，每人问5个结构化问题（市场规模、利润池分布、关键成功因素、常见死法、未来3年最大变量）。至少拿到≥2个独立验证的观点后再回来做加法 |
| **市场条件快速变化、窗口期极短（<1个月）的场景** | 画布全过程（加法30-60分钟+减法30-60分钟）需要至少2小时的专注思考时间。当窗口期短于1个月时，用2小时做画布不如用2小时去打第一个客户验证需求——在窗口期面前，认知速度优先于认知全面性 | 使用"极速预判三问"替代完整画布：① 这个方向最可能怎么死？（致命风险检查）② 我最不确定的一个核心变量是什么？（关键假设提取）③ 我能在1周内用最少资源测试什么？（最小验证设计）。把2小时拆成4个30分钟的迭代周期 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **面临3个以上方向选择，团队意见分歧大，谁都不想先表态** | 要求每个成员独立填画布的Step 2（加法选项池），不讨论不交流，10分钟内每人列出≥5条选项。收上来后合并去重，再做Step 3减法 | 合并后的选项池≥15条；至少3条来自不同成员的选项在合并后进入了最终Plan A/B/C候选圈 |
| **做完加法后选项池膨胀到40+，感觉更乱了** | 不是继续列——立即切到Step 3减法。用十大硬伤表做第一轮快速排除：每个选项只花30秒判断"有没有明显的致命硬伤"，有就划掉，不纠结 | 第一轮减法后选项池缩减到≤15个。如果减不下来，说明硬伤表用得不对——把"有风险但可解"和"致命硬伤"混淆了 |
| **减法做完后剩下3-5个选项，感觉都不差但不知道怎么选** | 引入"信心排序"而非"优劣排序"——不是问"哪个最好"，而是问"对哪个选项的判断最不需要依赖假设"。需要依赖假设越少的那个，选为Plan A | 每个选项列出它依赖的≥2个核心假设，标注每个假设的当前验证状态（已验证/部分验证/零验证）。选零验证假设最少的那个为Plan A |
| **团队按照画布选出了Plan A，但执行中发现预判有误** | 不是"抛弃画布"——是"回到减法自检"：Plan A在硬伤表上是否被正确评估过？如果当初标记✅（无硬伤）的项后来被证明是错的——把这个"误判型硬伤"加入团队专属硬伤清单 | 每次预判失误后，累积≥1条新硬伤进入团队专属清单。团队的预判能力来自专属硬伤的积累，而非通用框架的重复使用 |

## 质疑

**Eric Ries**（精益创业作者）：预判画布最大的问题是"静态分析动态世界"——你花 2 小时做加法减法，但市场在这 2 小时里已经变了。画布产出的 Plan A/B/C 是"基于当前信息的最优解"，但创业者真正需要的是"快速试错并迭代"的能力。画布越精致，越容易产生"我已经想清楚了"的幻觉，反而降低了行动速度。前提假设：市场信息是静态的、可被完整收集的——这在现实中不成立。

**Annie Duke**（扑克冠军 + 决策心理学作者）：画布的"硬伤排除"环节隐含一个危险假设——你能识别所有硬伤。但真正的致命风险往往是"你不知道你不知道的"。十大硬伤表覆盖的是"已知未知"，而非"未知未知"。建议在画布最后加一列："如果我的判断完全错了，最可能的原因是什么？"反例：很多创业失败不是因为"有明显硬伤没排除"，而是因为出现了硬伤表上没有的新维度。

### 前提与边界

- **前提假设**：预判画布假设创始人有足够的信息和判断力来填充画布的每个格子。在极端早期阶段（连行业基本结构都不了解），画布的产出质量为零。边界：画布适合"有行业认知但需要系统化梳理"的创业者，不适合"完全陌生领域"的探索。
- **适用边界**：画布适合"有多个可选方向"的决策场景。如果方向已经明确（如连续创业者回到熟悉赛道），画布的加法环节是认知资源的浪费。
- **反例**：某创始人用画布分析后选择了 Plan A，但 6 个月后发现真正的机会在画布完全没覆盖的新方向——画布的"全面性"给了虚假的安全感，反而限制了发散思维。
