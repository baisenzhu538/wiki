# 预判画布：从加法到减法的标准化工作台

## 用途

在做新项目机会预判时，把十五字法诀（主动定中局→充分做加法→专业做减法）标准化到一张可操作的画布上。替代"脑子里想想"的模糊预判。

## Protocol

### Step 1：定中局（5分钟）

```
我的终局预期：
  保A（最低可接受结果）：___________
  争B（理想目标）：___________
  时间跨度：3年 / 5年 / 10年
  光谱位置：L1-L7（副业-上市）
```

### Step 2：做加法——选项池（30-60分钟）

三条轴展开，列出所有组合：

```
轴1：行业/赛道
  └─ 选项1: ____  选项2: ____  选项3: ____  ...（至少5个）

轴2：产业链环节/切入方式
  └─ 选项1: ____  选项2: ____  选项3: ____  ...（至少3个）

轴3：商业模式要素（价格带/客群/渠道/城市/产品形态）
  价格带: ____ / ____ / ____
  客群: ____ / ____ / ____
  渠道: ____ / ____ / ____
  城市: ____ / ____ / ____
  产品形态: ____ / ____ / ____
```

**自检**：选项总数是否≥20？如果不够，回去继续列。

### Step 3：做减法——硬伤排除（30-60分钟）

对每个候选选项逐条对照十大硬伤：

| 硬伤维度 | 选项A | 选项B | 选项C |
|:---------|:-----:|:-----:|:-----:|
| 需求不刚需 | | | |
| 天花板太低 | | | |
| 产品内核不强 | | | |
| 单元模型不成立 | | | |
| 缺少增长路径 | | | |
| 初心不匹配 | | | |
| 核心能力缺失 | | | |
| 关键资源不够 | | | |
| 无变化无大机会 | | | |
| 窗口期已过 | | | |

标记：✅ 无硬伤 / ⚠️ 有风险但可解 / ❌ 致命硬伤

### Step 4：排序——选出Plan A/B/C

从无硬伤（✅）的选项中，按信心排序：
- **Plan A**（最优先执行）：_____
- **Plan B**（A不通立刻切）：_____
- **Plan C**（最后备选）：_____

### Step 5：关键假设提取

为每个Plan提取2-3个关键假设（最高不确定性的环节），进入下一步验证。

## Example

以咖啡馆为例（Truman课堂推演）：

**定中局**：保3争5（单体→体系增长），5年，在西安做。

**加法选项池**（部分）：
- 城市选择：一线/二线/三四线/学校周边/商务区
- 价格带：中低价/中价/高价
- 品类：专注咖啡/咖啡+奶茶/咖啡+简餐/咖啡+烘焙
- 选址：街边店/社区店/学校店/mall店/便利店/办公店
- 面积：20平小店/20-100平中店/100-300平大店
- 店员：专业咖啡师/一般咖啡师/普通店员
- 扩张：自营/放加盟/加盟品牌
- 环境：网红晒点/普通调性/私密空间/社交空间

**减法过程**（咖啡案例的实际推演）：
1. 先排除明显不靠谱的：学校店（咖啡需求弱）、社交空间（这个城市没这个文化）、网红店（没钱做推广）、便利店（没资源）
2. 能力角度排除：咖啡师不懂咖啡→排除专业咖啡师路线、没加盟经验→排除加盟品牌
3. **最终锁定**：中低客单价×办公室区域×20平小店×普通店员×自营专注咖啡
4. **Plan B**：往里面加代餐
5. **Plan C**：空间做大一点+加点产品内核

## Validation

- **加法自检**：选项总数≥20？横跨了至少3个维度？
- **减法自检**：每个被排除的选项都标注了排除原因（属于哪类硬伤）？
- **Plan B自检**：B和C是否真的有独立可行性，不是"A的弱化版"？
- **完整度自检**：是否产出了L3以上的交付物？

## Constraints

- **不是所有维度在所有项目上都相关**：做小生意不需要行业预判，做纯技术产品不需要城市选择。根据实际情况增减维度。
- **画布是思维脚手架，不是填空题**：填完了不代表预判做好了——关键在于每个选项的"为什么选/为什么不选"的逻辑质量。
- **与五步法画布的区别**：预判画布用于"选哪个方向"，五步法画布用于"选定方向后怎么执行"。先预判画布，再五步法画布。
