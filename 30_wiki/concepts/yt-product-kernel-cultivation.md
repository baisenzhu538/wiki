# 产品内核修炼段位图

> 来源：一堂五步法·解决方案篇 | 视觉来源：`00_inbox/ocr_ingest/src_ocr_一堂产品内核_十大典型指标.md`（洪七公 OCR 整合） | [[yt-five-step-method]] | [[yt-product-ten-metrics]] | [[case-shampoo-product-kernel]]

## Summary

产品内核是一堂五步法的第二步，也是Truman认为"最容易被忽略但最关键"的一步。定义：**用户愿意选择你的最小解决方案**。跳过内核直接做商业模式是创业失败的主要原因之一。

## Claims

### 六级进阶

| 层级 | 修炼能力 | 常见问题 |
|:---:|:---|:---|
| L1 | 缺价值意识 | 不在乎价值、只谈产品愿景、价值非常模糊 |
| L2 | 有价值意识 | 不断做加法、追求大而全、缺思考框架 |
| L3 | 有最小意识 | 做减法但做不到位、最小化程度不够、定位模糊 |
| L4 | 有专业评估 | 缺定性研究、缺定量方法、缺评估指标 |
| L5 | 有系统意识 | 缺少叠代规划、缺少基准值对比、缺少动态迭代 |
| L6 | 有战略意识 | 能跨领域创新、能构建护城河、能预判行业变化 |

### 产品内核四要素

| 要素 | 含义 | 常见错误 | 案例 |
|:---|:---|:---|:---|
| **用户** | 必须锁定具体用户和场景 | 同时面向儿童、成人、外国人 | 汉字动画片项目因定位混乱失败 |
| **愿意选择** | 提供显著优于现有方案的体验 | 忽略替换成本，以为界面简洁一点就能让用户迁移 | 小鹅通用户不会因界面简洁就迁移 |
| **最小** | 3-5个关键特性，不能再小 | 要点过多或过少 | 在线练字训练营的"肉眼可见进步"和"家长省心" |
| **解决方案** | 用户视角的决策逻辑，不仅是功能 | 把功能清单当内核 | 通信模组项目通过"价格领先+80分服务+长期稳定"提升转化率 |

### 十大典型指标

| 环节 | 指标 | 一句话说明 |
|:---|:---|:---|
| 获客 | 销转率 | 看潜在客户转化为实际购买客户的比例 |
| 获客 | 动销率 | 看有销售的商品品种数与所有商品总品种数的比例 |
| 获客 | 捕获率 | 看进店消费人数占总经过人流量的比例 |
| 服务 | 留存率 | 看使用产品的用户N天/周/月后还在持续使用的比例 |
| 服务 | 完课率 | 看用户能不能完成履约和最后学习 |
| 服务 | 退款率 | 看服务履约中，用户退款的比例 |
| 服务 | 满意率 | 看用户接受完服务，满意度的比例和打分 |
| 复购 | 复购率 | 看消费购买后，会继续购买的比例 |
| 复购 | 续费率 | 看续费用户数占现有用户数的比例 |
| 复购 | 推荐率 | 看用户是否愿意主动推荐的比例 |

## Critique

### 外部攻击：Marty Cagan（Inspired）

Marty Cagan 强调"产品发现"需要同时考虑可行性、可用性、价值性三维度。一堂的"四要素"框架偏重"用户视角的价值交付"，而对"技术可行性"和"业务可行性"的显性考虑较少。建议在验证内核时同步检查"能不能做得出来"和"能不能持续做"。

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| 产品数据不好看但不知道问题在哪 | 对照十大指标，找到最差的那个环节 | 明确指出是获客/服务/复购哪个环节出了问题 |
| 团队讨论产品方案时一直做加法 | 用"最小"要素轻量化：如果只能保留3个功能，保哪3个？ | 5分钟内达成3人以上共识 |
| 要做MVP验证 | 先验证内核而非完整产品：内核通过了才扩展其他功能 | MVP完成前已明确内核四要素 |
