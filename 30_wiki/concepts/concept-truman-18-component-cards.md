# Truman 原 18 组件源框架：五维度 × 每维 4 张牌

> 一句话：Truman 把建模过程中反复交学费的地方归纳为五个维度（事实/目标/方案/过程/协作），每个维度 4 张牌，共 18 张。每张牌是一个「先X后Y」的依赖对。

> ⚠️ 本卡忠实提取 Truman 口述稿原文。KDO 域内改编版（17 组件，维度名和牌名均有调整）见 `concept-kdo-component-library`。

---

## 1. 五维度 × 18 张牌

> 口述 L2934-L3010

Truman 原话："五个方向分别是事实、目标、方案、过程、协作。前四个刚好对齐，每一个都是四个。"

| 维度 | # | 牌名 | Truman 口述原话 |
|:---|:---:|:---|:---|
| **事实** | 1 | 客观→主观 | "是不是应该先客观再主观？" |
| | 2 | 输入→输出 | "是不是应该先输入再输出？" |
| | 3 | 定性→定量 | "是不是应该先大概了解定性再定量？" |
| | 4 | 用户需求→产品 | "是不是应该先了解用户的需求然后再做产品？" |
| **目标** | 5 | 问题→解法 | "是不是应该先研究过去的问题，再思考未来的解法？" |
| | 6 | 目标→路径 | "是不是应该定了目标再定路径？" |
| | 7 | 全局→局部 | "是不是应该定了全局再定局部？" |
| | 8 | 内容→形式 | "是不是应该变了内容再定形式？" |
| **方案** | 9 | 内核→边界 | "是不是应该先思考那块再思考边界？" |
| | 10 | 发散→收敛 | "是不是应该先发散再收敛？" |
| | 11 | 审美→设计 | "是不是应该先审美再做设计？" |
| | 12 | 框架→细节 | "是不是应该先框架细节？" |

## 2. 使用方式

Truman 原话："为了搭工作流，你可以反复的练——拉一条卡牌出来，就是工作流，再拉一个卡牌出来，它就是个工作流。每一个卡牌都是你这个业务有可能会踩的坑。"

```
1. 面对一个建模任务时，从五个维度中选当前最核心的维度
2. 从该维度的牌中选出任务需要的几张
3. 按「先X后Y」顺序排列——这就是流程骨架
4. 每张牌都是一个"如果不先X就做Y，会踩的坑"
```

Truman 还提到每张牌有 3 种语言习惯的变种（共 54 种表述），并以颜色分组做成实体卡牌。

## 3. 与 KDO 17 组件对照

| Truman 原 18 组件 | KDO 改编版 | 改编理由 |
|:---|:---|:---|
| 维度：事实/目标/方案/过程/协作 | 维度：素材/边界/结构/过程/质量 | KDO 场景不同——素材=事实泛化，边界=目标+约束合并，质量=协作的成果导向 |
| 18 张牌 | 17 张牌 | KDO 省略部分牌、新增部分牌 |

详见 `concept-kdo-component-library` 的对照说明。
