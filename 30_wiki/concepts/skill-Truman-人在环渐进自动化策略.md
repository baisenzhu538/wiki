# 技能：人在环渐进自动化策略

## 原始表述

人在环渐进自动化策略是Truman在AI工具应用AMA中提出的实操方法。

## 操作步骤

1. 评估任务确定性和容错度：高确定性低容错→工作流/代码；高容错→可用AI原生
2. 选择协作模式：建构模式（人主AI辅）→智能体模式（AI主人辅）→AI原生模式（纯AI）
3. 根据业务成熟度和质量要求动态调整人在环的介入点
4. 最终目标：逐步从纯人过渡到纯AI，但现阶段大量场景需混合使用

## 适用场景

- 不确定AI自动化程度
- AI输出质量不稳定
- 业务要求与AI能力不匹配
- 选择工具和实施层级时

## 不适用场景

- 任务完全标准化可用纯代码解决
- 完全不可预测需全人工处理

## 工具/环境

- 双三角模型
- 工作流工具
- 智能体平台
- RPA
- Web Coding

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

现阶段大量场景需混合使用，核心是根据业务认知和审美体系判断阶段；盲目追求全自动化或拒绝AI都会降低效率
