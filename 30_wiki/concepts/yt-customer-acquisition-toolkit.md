# 获客工具合集

> 来源：一堂五步法·增长篇 | [[yt-growth-cycle-model]] | [[yt-unit-model-three-tools]] | [[case-toy-cabinet-business-model]]

## Summary

增长篇包含5张获客工具小抄+2张警示图，系统覆盖从获客到转化的全渠道类型。本卡片整合为"五大获客类型+5步销售法+两大警示灯"，作为增长团队的快速检索手册。

## Claims

### 五大获客类型（核心渠道方向）

| 渠道方向 | 具体分类 | 执行举例 | 适用阶段 |
|:---|:---|:---|:---|
| **用户裂变** | 老带新机制（名利权情/CPS/各送代金券/内部推荐） | 推荐有奖、组队PK、分销体系 | 有了初期用户后 |
| | 分销体系（一级分销/二级分销/有赞分销） | SaaS产品常用 | |
| | 裂变活动（拼团/众筹/组队PK/助力裂变） | 社交电商常用 | |
| **同行互换** | 同行互推（网站友情链接/大号互推/互补商家/行业协会） | 自媒体互推、异业联盟 | 有行业资源时 |
| | 异业联盟（联合会员卡/联合福利卡/互相赠送） | 线下门店常用 | |
| | 联名活动（赞助/品牌联名营销/推广配套产品） | 品牌合作 | |
| **线上获客** | 有购流量（信息流/搜索流/展示流/弹窗流） | 投放广告、SEO、SEM | 有预算时 |
| | 无购流量（自媒体/社群/软文/种草/转发） | 短视频、公众号、知乎 | |
| | 线上工具（SEO工具/群推工具/打扫工具） | 脚本化获客、模板化内容 | |
| **线下获客** | 自然流量（选址/引流/店铺门头/地推地摊） | 线下门店、展会会 | 有线下场地时 |
| | 托管流量（加盟/代理/归属/出租） | 加盟商参与 | |
| | 线下工具（地推工具/展示工具/服务工具） | 地推人员、展架、试吃 | |
| **获客转化** | 销售流程（骗客/接待/探需/说明/成交/客户） | 门店销售SOP | 有销售场景时 |
| | 转化工具（价值包/试用装/体验装/礼品装） | SaaS免费试用、体验装 | |
| | 促销活动（限时/满减/满送/加价购/抽奖） | 电商常用促销 | |

### 科学销售五步法

1. **招呼**：建立信任感
2. **探需**：了解需求和痛点
3. **讲解**：介绍解决方案
4. **成交**：转化为购买
5. **服务**：跟进售后与复购

### 两大警示灯

| 警示灯 | 含义 | 如何避免 |
|:---|:---|:---|
| **虚荣指标** | 装饰性数据（如总注册用户、总PV），看起来好看但不指导行动 | 关注"好的第一指标"：能指导行动、可达成、可量化 |
| **里程碑复盘跑偏** | 里程碑设定合理，但复盘时只看结果不看过程，无法提取可复制的经验 | 使用标准化复盘模板，分析"目标vs结果vs原因vs行动" |

## Critique

### 外部攻击：Brian Balfour（Reforge）

Reforge 的增长课程强调"growth loops"（增长循环）不是简单的"渠道类型列表"，而是**自增长的系统**。一堂的获客工具集偏重"分类检索"，对渠道之间的正交性和迭代优化考虑较少。建议在选择渠道后，建立自己的"获客→转化→留存→收入→推荐"闭环。

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| 要选择获客渠道但不知道从哪里开始 | 对照五大类型，判断当前阶段最适合的是哪类 | 在5分钟内筛选出到2-3个优先试验渠道 |
| 销售团队业绩不稳定 | 将销售流程标准化为五步法SOP | 新人上手时间缩短50%以上 |
| 数据好看但业务没增长 | 检查是否追逐虚荣指标，重新定义"好的第一指标" | 第一指标与收入成正相关 |
