# 战略研讨会引导手册

> 来源：一堂《经营必修：重新理解"战略会"》课程工具化升级。战略研讨会是创业团队一年中最重要的会议类型——它决定团队"往哪里走、不往哪里走、资源往哪放"。本手册提供一套包含"会前四件套+会中五段式+会后三检查"的完整引导流程，防止战略会沦为汇报大会或老板想法的精致包装。

## Summary

战略研讨会引导手册是一套高利害会议 facilitation 工具，核心目标是：让核心团队在远离日常运营干扰的环境中，对方向性问题做出真正的讨论和决策，并以"共识+书面纪要"的方式锁定。本工具不追求"一次战略会解决所有问题"——它追求"每次战略会都比上次更好"，通过标准化的会前准备、会中节奏控制和会后跟进，逐步提升组织的战略思考质量。

## Claims

### 进入标准：什么时候需要用本工具

以下任何一条触发，即需使用本工具：

1. **公司需要制定/调整年度或季度战略方向**
2. **团队对"我们要做什么、不做什么"存在分歧，需要集中讨论**
3. **上一周期战略执行效果不佳，需要诊断原因**
4. **业务进入新阶段（如从探索期进入增长期），需要重新评估方向**
5. **核心团队新增/减少关键成员，需要重新对齐战略共识**

**如果以下情况，不用本工具：**
- 公司现金流只够 3-6 个月，处于"生存模式"（用"生存三问"替代，见下文）
- 战略方向已经明确，只需要执行层面的对齐（用 OKR 工具替代）
- 团队 <3 人且方向清晰（直接一对一沟通即可）

### 操作步骤：战略研讨会完整流程

#### Step 0：会前四件套（战略会前 2 周完成）

**目标**：确保所有参会者在进入会议室前拥有共享的信息基础和独立的战略思考。

| 套件 | 时间 | 负责人 | 具体内容 | 产出 |
|------|------|--------|---------|------|
| **信息包** | 会前 2 周 | 运营/数据团队 | 外部变化（市场/竞品/用户趋势）+ 内部事实（财务/运营/团队数据） | 1 份结构化信息文档 |
| **独立作业** | 会前 1 周 | 每个参会者 | 独立回答 3 个问题（不超过 1 页纸）：① 当前最大瓶颈是什么？② 我们拥有什么独特的不对称优势？③ 如果立刻砍掉 50% 业务，保留哪一半？ | 每人 1 页独立答案 |
| **差异地图** | 会前 3 天 | 会议主持人 | 将所有人的独立答案匿名汇总，标注"观点差异最大的领域" | 1 张差异热力图 |
| **议程锁定** | 会前 1 天 | 会议主持人 | 基于差异地图设计具体议程——差异最大的领域分配最多时间 | 1 份详细议程 |

**关键约束**：
- "独立作业"必须匿名提交——参会者不能提前互相看答案，防止"老板的想法影响我的判断"
- "差异地图"是会议最有价值的部分——如果三个人的答案完全一致，战略会时间压缩到 2 小时
- 如果有人不做独立作业，不允许参加战略会——没有独立思考的参会者是噪音源

#### Step 1：会中五段式（战略会当天，1-3 天）

```
战略研讨会五段式
┌─────────────────────────────────────────────────┐
│ 段 1：信息校准（30% 时间）                          │
│   → 快速过信息包，确认"我们站在哪里"的共享事实基础      │
│   → 规则：不讨论"怎么办"，只确认"是什么"              │
├─────────────────────────────────────────────────┤
│ 段 2：差异暴露（20% 时间）                          │
│   → 展示独立作业的匿名答案和差异地图                   │
│   → 核心问题："为什么我们对同一件事的判断完全不同？"    │
│   → 规则：不急于收敛，先充分理解差异来源                │
├─────────────────────────────────────────────────┤
│ 段 3：诊断深度（30% 时间）← 最重要的一段              │
│   → 回答 Rumelt 的核心问题："当前局势中的关键瓶颈是什么？│
│     我们拥有什么独特的不对称优势？"                    │
│   → 使用[[yt-decision-y-model]]的 Y 模型结构：        │
│     现象 → 本质（瓶颈诊断）→ 方针 → 行动              │
│   → 规则：没有完成诊断，不允许进入方向选择              │
├─────────────────────────────────────────────────┤
│ 段 4：方向选择（15% 时间）                          │
│   → 基于诊断，讨论 2-3 个可能的方向选项                │
│   → 每个选项必须包含：做什么 + 不做什么 + 资源倾斜      │
│   → 规则：必须记录"放弃的方向"——没有减法的战略不是战略   │
├─────────────────────────────────────────────────┤
│ 段 5：决策锁定（5% 时间）                           │
│   → 明确拍板：最终方向 + 3 个关键动作 + 3 个撤销条件    │
│   → 记录异议：谁有不同意见、什么条件下可能错            │
│   → 规则：72 小时内发出战略决策纪要                    │
└─────────────────────────────────────────────────┘
```

**关键约束**：
- 段 3（诊断）必须分配至少 30% 时间——没有诊断的方向选择是掷骰子
- 段 5 的"3 个撤销条件"是必须的产出——没有撤销条件的战略决策是押注
- 每个段之间必须有明确的"段间信号"——主持人宣布"我们完成了信息校准，现在进入差异暴露"

#### Step 2：会后三检查（战略会后 72 小时内完成）

| 检查 | 时间 | 负责人 | 具体内容 | 成功标准 |
|------|------|--------|---------|---------|
| **纪要检查** | 24h 内 | 会议主持人 | 发送战略决策纪要，包含：① 诊断结论 ② 最终方向 ③ 3 个关键动作 ④ 3 个撤销条件 ⑤ 异议记录 | 所有参会者确认"纪要准确反映了我的理解" |
| **传达检查** | 48h 内 | 一号位/CEO | 向全公司传达战略决策——不是"通知"，是"解释为什么" | 非参会者能用自己的话复述"我们的战略方向是什么" |
| **活动检查** | 72h 内 | 各部门负责人 | 各部门列出"为支持新战略，我的部门需要改变什么活动" | 至少识别 3 个"战略选了 A 但活动仍在为旧方向 B 服务"的错位 |

**关键约束**：
- "传达"不是发邮件——需要面对面的解释和答疑
- "活动检查"是 Porter 活动系统理论的应用——战略方向必须转化为具体活动的改变
- 如果 72 小时内三检查没有完成，本次战略会的产出价值衰减 50% 以上

### 退出标准

**当以下情况发生时，本工具需要被修订或替换**：
- 连续两次战略会产出的方向在 3 个月内被推翻 → 诊断环节质量不足，需要引入外部顾问
- 战略会后团队执行率 <50% → 活动检查环节失效，需要加强战略-执行的链接机制
- 参会者反馈"战略会只是老板想法的包装" → 独立作业和差异暴露环节没有真正执行
- 战略会时长从 2 天压缩到 4 小时 → 时间不足导致诊断被跳过，需要重新争取时间资源

### 常见陷阱

| 陷阱 | 现象 | 防御方案 |
|------|------|---------|
| **汇报大会** | 各部门轮流讲 PPT，老板点评几句 | 禁止 PPT——用信息包替代，会议中只讨论不汇报 |
| **一言堂** | 老板讲愿景，其他人听 | 独立作业+匿名差异地图——让老板也知道自己的判断和团队有差异 |
| **只有加法没有减法** | 讨论了什么都要做 | 段 4 必须记录"放弃的方向"——没有减法的战略不是战略 |
| **开完就算了** | 激情澎湃两天，两周后一切照旧 | 会后三检查——纪要+传达+活动检查，缺一不可 |
| **跳过诊断** | 直接进入"选 A 还是选 B" | 段 3 必须分配 ≥30% 时间——主持人有权拒绝提前进入方向选择 |
| **伪共识** | 表面上达成一致，实际上理解不同 | 段 5 必须记录异议——保护异议者的声音 |
| **没有撤销条件** | 定了方向就一条路走到黑 | 段 5 必须产出"3 个撤销条件"——什么信号意味着需要重新讨论 |

## Critique

### 外部攻击

#### Clayton Christensen：你的战略会正在系统性地杀死创新

**Clayton Christensen**（哈佛商学院教授，*创新者的窘境* 作者）对"战略决策会议"发起了最尖锐的攻击——不是攻击会议本身，而是攻击会议中"成功企业"做战略决策的深层逻辑。

Christensen 的核心洞见：

1. **好公司的战略会天然排斥颠覆性创新**：你的战略会讨论的是"如何在现有业务上做得更好"——优化现有客户体验、提升现有产品指标、扩大现有市场份额。但 Christensen 发现，**颠覆性创新从不来自"服务好现有客户"**——它来自服务"被现有客户嫌弃的低利润客户"或"目前不存在的市场"。你的战略会根本不会讨论这些人——因为他们不在你的数据仪表盘上。

2. **"基于数据的战略决策"是创新的敌人**：你的战略会要求"信息包"——市场数据、竞品分析、财务预测。但 Christensen 证明，**颠覆性市场在诞生时没有数据**——因为市场还不存在。如果你要求"有数据才决策"，你永远不会投资颠覆性创新。IBM 的数据告诉他们个人电脑市场不存在（1970 年代），Blockbuster 的数据告诉他们流媒体不挣钱（2000 年代）——他们的战略会都做出了"数据支持"的正确决策。

3. **资源分配机制在战略会中被固化**：战略会的最终产出是"资源往哪倾斜"。但 Christensen 指出，**成熟企业的资源分配机制天然倾向于现有业务**——因为现有业务有收入、有客户、有 KPI。战略会上的"理性讨论"只会让资源越来越集中于现有业务，直到被颠覆者消灭。

> **Christensen 让战略会使用者睡不着觉的问题**：你今年的战略会确定了"聚焦高端客户、提升客单价"的方向。所有人都觉得这个方向很对——数据支持、客户反馈积极、利润率可观。但 Christensen 会问你："你们的战略会花了多少时间讨论'如果我们被一个从低端市场切入的颠覆者攻击，该怎么办'？答案是零——因为低端市场不在你们的 OKR 里，不在你们的数据包里，不在你们的客户调研里。但它可能正在某个车库发生。你们的战略会设计是否系统性地让团队忽视了这个方向？"

#### Nassim Taleb：战略规划是伪科学——你的战略会只是在制造幻觉

**Nassim Taleb**（*黑天鹅*、*反脆弱* 作者）对"战略规划"本身提出了哲学层面的攻击——这个攻击直接动摇了"战略会"的存在价值。

Taleb 的核心洞见：

1. **"预测"是伪科学**：战略会的核心假设是"我们可以通过分析当前局势来预测未来并制定计划"。但 Taleb 证明，**复杂系统中的重大事件是不可预测的**——不是因为信息不足，而是因为预测本身就是不可能的。你花两天时间分析市场趋势、竞品动向、用户需求——但真正的游戏规则改变者（iPhone 的发布、COVID-19、ChatGPT）从来不在任何人的预测模型里。

2. **"规划"制造了脆弱性**：战略会产出"3 个关键动作+季度目标"——这是一个刚性计划。Taleb 指出，**刚性计划在遇到黑天鹅时会崩溃**——因为你的资源已经按原计划分配了，你没有冗余来应对意外。战略会不是在增强组织的适应能力，而是在用"虚假的控制感"替代真正的适应能力。

3. **"共识"是危险的信号**：战略会追求"团队共识"。但 Taleb 认为，**共识往往是错误的信号**——当所有人都同意一个方向时，这个方向的风险被系统性低估（因为反对声音被压制了）。真正的风险管理需要"建设性异议"，而战略会的"共识锁定"机制可能在消除这种异议。

> **Taleb 让战略会使用者睡不着觉的问题**：你的战略会达成了完美的共识——所有人都同意"今年聚焦企业级市场"。你们花了两天时间分析、讨论、辩论，最终方向清晰、士气高涨。但 Taleb 会问："如果 6 个月后市场发生了一件你们今天完全无法预料的事情（一个新技术、一个新政策、一个竞品动作），你们的'3 个撤销条件'能捕捉到它吗？大概率不能——因为撤销条件基于的是你们今天能想象到的风险，而真正的风险是你们今天想象不到的。你们的战略会不是在为未知做准备，它是在让你们更确信已知的东西。这种确信本身就是最大的风险。"

### 内部局限

- **"独立作业"的执行率被高估**：很多参会者会敷衍了事——因为日常工作太忙，或者因为"反正老板会定"。
- **"差异暴露"可能变成政治博弈**：当差异地图显示"我和老板观点不同"时，参会者可能在会议中隐藏真实想法。
- **"撤销条件"很少被真正执行**：即使有撤销条件，当信号出现时，团队往往因为沉没成本而拒绝承认"我们需要重新讨论"。
- **战略会的成本被低估**：1-3 天核心团队脱产 = 巨大的机会成本，如果会议质量不高，损失不仅仅是时间。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **公司处于"生存模式"——现金流只够 3-6 个月** | Rumelt 指出：战略需要"有选择余地"才能生效。当公司只有一条路可走时，战略讨论是伪命题——你需要的是最快的收入进来。"生存期开战略会"会制造虚假的控制感。 | 不开战略会。用"生存三问"替代：① 接下来 30 天哪 3 个客户最可能付钱？② 哪些成本可以立即砍掉？③ 如果有机会把 runway 延长 2 个月——愿意付出什么代价？三个问题一个下午出答案，然后所有人去执行。活下来以后才配开战略会。 |
| **战略会产出了清晰决策，但执行 3 个月后当初的假设全错了** | Porter 的活动系统理论提供重新理解：你做的不是"执行战略"，是做"战略实验"。实验失败不是问题——问题是战略会没有预先定义"撤销条件"。 | 每次战略会的最后一个产出不是"3 个关键动作"，而是"3 个撤销条件"：如果 Q1 结束时 _____ 没有发生，说明战略假设错误，立即重新召集战略会。同时定义"看什么数据来判断"——不是等季度末才发现偏航。 |
| **团队已经有明确战略方向，只是执行层面的协作问题** | 战略会解决"方向选择"问题，不解决"执行协作"问题。用战略会讨论执行问题是资源错配。 | 用[[yt-tool-okr-cycle]]的周度脉搏和[[yt-tool-meeting-designer]]的会议设计来解决执行协作问题，而非召集战略会。 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **第一次组织战略会，不确定方向是否正确——担心"花一天时间开完发现产出的只是老板想法的精致包装"** | 严格执行"会前独立作业"——每个参会者（包括一号位）独立回答 3 个问题并匿名提交。开会时先贴所有人的答案，看差异有多大——差异本身才是最该被讨论的战略议题 | 三个人对"最大瓶颈"的回答指向完全不同的方向——这本身就是最大收获。如果三个人的回答完全一致——你不需要开战略会，直接执行，会议时间压缩到 2 小时 |
| **上季度的战略决策执行得很差——团队说"方向没问题，是执行的问题"** | 做 Porter 式活动系统诊断：画一张图——中间写战略方向，四周列出所有组织活动的卡片。逐条问"这个活动为这个战略方向改变了什么？"如果 ≥50% 的活动在战略会后没有任何改变——不是"执行的问题"，是你的战略从未被翻译成活动系统 | 至少识别出 3 个"战略选了 A 但活动的设计仍然在为旧方向 B 服务"的错位。下个季度至少纠正 2 个 |
| **战略会讨论激烈、每个人都有不同意见——最终一号位拍板"就这么定了"，但散会后有人小声说"我觉得不对但我懒得说了"** | 不用"Disagree and Commit"口号（喊多了变成"闭嘴照做"的礼貌版）。做"异议档案"——在战略会结束前，让每个有异议的人公开说"我的异议是什么、我判断在什么条件下这个决策可能会错"。把这些异议写进战略决策纪要，下季度复盘时第一条就过 | 下一季度复盘时，至少有 1 条"异议被事后证明是对的"被公开承认——不是为了打脸，是为了证明"提异议是安全的、有价值的"。如果连续两个季度"一条对的异议都没有"——要么异议者不够诚实，要么没人真的在思考 |
| **战略会开完后，非参会者（基层员工）对战略方向完全不理解** | 检查"会后三检查"中的"传达检查"——不是发邮件，是一号位亲自做面对面的解释和答疑。测试：随机抽 3 个非参会者，让他们用自己的话复述"我们的战略方向是什么" | 3 个非参会者中至少有 2 个能准确复述战略方向的核心逻辑（不需要复述细节，但需要理解"为什么选这个方向"） |
