# 技能：案例池构建法

- **纪浩体系**：[[concept-纪浩-ai-collaboration-methodology]] — 纪浩 AI 协作方法论总纲

## 原始表述

案例池构建法是纪浩在AI协作方法论分享中提出的具体方法，用于案例池构建法。

## 操作步骤

1. 建立专门的案例收集池
2. 将收集案例融入日常信息收集和复盘流程
3. 定期用案例池验证方法论提炼是否更清晰
4. 用案例块打磨小单元课程
5. 验证案例块能否降低故事线打磨成本

## 适用场景

- 平时积累案例较少
- 需要持续输出高质量内容
- 希望形成稳定PDCA循环

## 不适用场景

- 没有稳定的信息输入来源
- 缺乏复盘习惯

## 工具/环境

- Cubox
- 笔记软件
- Markdown
- AI工具

## 判断标准

| 标准 | 自检问题 |
|:-----|:---------|
| 操作步骤执行到位 | 每个操作步骤都有明确的产出物和验证标准吗？ |
| 数据/事实支撑 | 操作结论有具体的数据或用户反馈支撑，而非个人感觉吗？ |
| 失败模式排查 | 本次操作中有没有触发常见失败模式中的某一条？ |
| 迭代闭环完整 | 这次的结果是否引导了下一步的明确动作？ |

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未先确认场景是否适用 → 方法无效 → **先对照“适用场景”确认本方法适用**

## 为什么有效

案例是连接抽象与具体的锚点，持续积累案例才能让方法论有血有肉，避免空中楼阁。
