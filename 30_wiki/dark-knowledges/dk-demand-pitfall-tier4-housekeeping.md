# 踩坑：四线家政——天花板误判。普遍性高≠能做大

## 原始表述

**坑**：需求旺盛→市场空白→实际单价起不来，天花板很低。

**真相**：评估三角形的刚性维度必须细化到"愿意付多少钱"。四线城市"愿意付"的上限可能是20元/小时。

**修复**：刚性≠"有没有需求"；刚性="愿意付多少钱"+"愿意付多少次"。

## 使用场景

- **需求评估**：评估需求时，不仅看普遍性，还要看刚性（愿意付多少钱）
- **市场进入决策**：进入新市场时，评估天花板高度
- **定价策略**：定价时，考虑目标市场的支付意愿上限
- **创业机会判断**：判断机会时，避免"普遍性高=能做大"的误区
- **一堂五步法学习**：理解评估三角形刚性维度的细化方法

## 操作方法

1. **刚性细化**：
   - 刚性≠"有没有需求"
   - 刚性="愿意付多少钱"+"愿意付多少次"
   - 四线城市"愿意付"的上限可能是20元/小时
2. **天花板评估**：
   - 需求旺盛≠市场空白≠能做大
   - 评估单价上限和频次上限
   - 计算天花板=单价×频次×用户数量
3. **评估三角形应用**：
   - 普遍性：这个问题有多少人遇到？
   - 频次：这个问题多久遇到一次？
   - 刚性：愿意付多少钱？愿意付多少次？
   - 三个维度都高才是真需求，但刚性必须细化到金额
4. **市场进入决策**：
   - 不仅看需求旺盛，还要看单价能否支撑商业模式
   - 天花板低的行业，需要差异化或规模化

## 适用边界

| 场景 | 是否适用 | 说明 |
|:---|:---|:---|
| 需求评估 | ✅ 适用 | 刚性维度必须细化到"愿意付多少钱" |
| 市场进入决策 | ✅ 适用 | 评估天花板高度，避免进入低天花板市场 |
| 定价策略 | ✅ 适用 | 考虑目标市场的支付意愿上限 |
| 创业机会判断 | ✅ 适用 | 避免"普遍性高=能做大"的误区 |
| 一堂五步法学习 | ✅ 适用 | 理解评估三角形刚性维度的细化方法 |
| 高端市场 | ⚠️ 部分适用 | 高端市场刚性高，但仍需细化 |
| 公益项目 | ❌ 不适用 | 公益项目不关注付费意愿 |

## 为什么值钱

1. **反直觉洞察**：普遍性高≠能做大，刚性（付费意愿）才是天花板
2. **评估细化**：评估三角形的刚性维度必须细化到金额
3. **天花板识别**：提前识别低天花板市场，避免进入陷阱
4. **定价指导**：定价时考虑目标市场的支付意愿上限

## 失败模式 / 常见走偏

| 失败模式 | 症状 | 纠正 |
|:---|:---|:---|
| 普遍性幻觉 | "需求旺盛，市场空白" | 刚性="愿意付多少钱"+"愿意付多少次" |
| 天花板忽视 | 进入低天花板市场 | 评估单价上限和频次上限 |
| 刚性模糊 | "有需求" | 细化到"愿意付多少钱" |
| 定价脱离市场 | 定价高于市场支付意愿 | 考虑目标市场的支付意愿上限 |
| 规模假设 | "普遍性高，规模一定大" | 天花板=单价×频次×用户数量 |
