# 战略内核四要素：细分市场+竞争优势+资源配置+范围经济

## 原始表述

**四要素检测**：
1. **细分市场**明确了吗？不是"中国市场"，是具体的谁
2. **竞争优势**可持续吗？不是"我们服务好"，是客户为什么非选你不可
3. **资源配置**聚焦了吗？不是"全都要"，是砍掉了什么
4. **范围经济**存在吗？不是"什么赚钱做什么"，是业务之间的协同

## 使用场景

- **战略制定**：制定战略时，用四要素检查战略完整性
- **战略评估**：评估现有战略时，检查四要素是否齐全
- **创业战略设计**：创业时，用四要素定义战略内核
- **团队战略讨论**：统一团队对战略内核的认知
- **战略咨询**：评估咨询方案时，检查四要素是否完整

## 操作方法

1. **细分市场检测**：
   - 不是"中国市场"，是具体的谁
   - 定义：年龄、性别、收入、地域、行为特征
   - 检测：能否用一句话描述目标客户？
2. **竞争优势检测**：
   - 不是"我们服务好"，是客户为什么非选你不可
   - 定义：差异化优势、护城河、壁垒
   - 检测：优势是否可持续？竞争对手能否复制？
3. **资源配置检测**：
   - 不是"全都要"，是砍掉了什么
   - 定义：聚焦核心资源，放弃非核心
   - 检测：资源是否集中在关键优势上？
4. **范围经济检测**：
   - 不是"什么赚钱做什么"，是业务之间的协同
   - 定义：业务之间的协同效应
   - 检测：业务之间是否有1+1>2的效应？

## 适用边界

| 场景 | 是否适用 | 说明 |
|:---|:---|:---|
| 战略制定 | ✅ 适用 | 用四要素检查战略完整性 |
| 战略评估 | ✅ 适用 | 检查现有战略四要素是否齐全 |
| 创业战略设计 | ✅ 适用 | 用四要素定义战略内核 |
| 团队战略讨论 | ✅ 适用 | 统一团队对战略内核的认知 |
| 战略咨询 | ✅ 适用 | 评估咨询方案四要素是否完整 |
| 战术执行 | ⚠️ 部分适用 | 战术执行需要具体方案，四要素是战略框架 |
| 个人职业规划 | ⚠️ 部分适用 | 个人规划四要素较弱 |

## 为什么值钱

1. **系统框架**：四要素提供战略制定的系统检查框架
2. **聚焦工具**：帮助团队聚焦核心，避免"全都要"
3. **差异化指导**：竞争优势检测帮助找到真正的差异化
4. **协同意识**：范围经济检测帮助发现业务协同
