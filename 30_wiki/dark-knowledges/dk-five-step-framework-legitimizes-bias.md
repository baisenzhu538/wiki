# 暗知识：框架不会自动降噪，反而可能「合法化」偏见

> 用了五步法不代表科学分析——可能只是把直觉结论套进五个框重新排版。

## 原始表述

> 框架不会自动降噪，反而可能「合法化」偏见。用了五步法不代表科学分析，可能只是把直觉结论套进五个框重新排版。

——第二十二节批次4精修，提炼自 Truman 五步法培训

## 核心洞察

这是使用结构化框架时最隐蔽的陷阱：**框架本身不提供客观性，只提供结构。** 如果输入框架的是偏见，框架会把它包装成"科学分析"而不改变结论。

这个陷阱有三个层次：

1. **结构合法化**。直觉结论放进五步法的五个框后，看起来像经过了"系统分析"——但每一框里填的仍然是直觉。框架只是重新排版了偏见，没有检验它。

2. **群体确认放大**。当一群人一起用框架时，不是互相检验，而是互相强化。十分钟达成一致、没人反对——往往不是分析充分，而是所有人的偏见在框架的掩护下完成了一次集体确认。

3. **仪式化替代科学化**。当"跑完五步法"变成仪式（做了=做了科学分析），团队就不会问那个关键问题：**这次分析有哪一步让我们对原有假设产生了怀疑？** 如果从来没有，说明方法论已经失效。

**与段位盲区的区别**：段位盲区是"不知道高段位长什么样"；框架合法化偏见是"以为用了框架就是在做科学分析"。前者是能力问题，后者是认知陷阱——而且是框架使用者最容易掉进去的陷阱。

## 操作方法

1. **强制"反例冲击"**
   每次框架分析结束后，追加一个步骤：找一个与结论相反的数据点或案例，尝试用框架重新解释它。如果框架解释不了，说明框架或结论有问题。

2. **用"数据溯源"检验"框填充"**
   不是看框有没有填满，而是看每个框里的数字：从哪来？可信度多高？如果错了怎么办？填满 ≠ 验证。

3. **魔鬼代言人制度化**
   每次框架讨论必须有人扮演反对者，且反对者必须引用数据或具体案例，不能只说"我觉得不对"。

## 适用边界

| 边界 | 说明 |
|:-----|:-----|
| **适用于框架使用者的自我警惕** | 不适用于还不会用框架的初学者——先学会用，再学防滥用。 |
| **不反对框架本身** | 框架极其有用，前提是用它来检验假设而非包装结论。 |
| **需要团队有心理安全感** | 魔鬼代言人和反例冲击需要安全感，否则变成走过场。 |
| **不替代数据驱动决策** | 框架是思维工具，不能替代 A/B 测试、用户调研、财务建模。 |

| 失败模式 | 典型症状 | 修复方法 |
|---|---|---|
| 框架当橡皮图章 | 每次分析结论都和直觉一致，"框架验证了我们的判断" | 强制找反例，问"上次分析推翻预期是什么时候" |
| "填表"替代"思考" | 大量时间花在"把框填满"和"画布好看"，不花时间质疑数字 | 用数据溯源+魔鬼代言人替代完整性检查 |
| 一致即正确的幻觉 | "讨论很顺利，大家一致同意"被理解为"分析方向正确" | 一人扮演反对者，必须引数据/案例，不能只说感觉 |
| 结构化 = 科学的错觉 | 只要用了五步法就觉得是科学分析，不检验输入质量 | 输入框架之前先问：这个假设如果我错了会怎样 |
| 框架疲劳 | 第 10 次跑五步法，团队已经自动化填表，不再真正思考 | 引入外部评审、换题、或用对立框架（如用波特五力验证你的五步法结论） |
