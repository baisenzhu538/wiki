# 教练式沟通边界暗知识

> 定位：属于 `framework-coaching-leadership-core` 的边界暗知识卡——回答"什么时候**不该**用教练式沟通"（边界三情况）+ 拆穿"信任 = 讨好"的误区。与 `tool-coaching-communication-four-layers`（矩阵卡）配套：矩阵讲"怎么用"，本卡讲"什么时候不用"。

## 原始表述

> "不是教练式沟通不是万能的，所以我先要把它的边界先跟大家讲一下。这大概三种情况下不合适，真的不合适。"（口述 02 L550-552）

> "信任不是放任。信任不代表没有原则的包容，我们要去做一个讨好型的领导，这个就过了。"（L1758-1762）

> "信任层最特殊的地方在于，不管你攒了多少硬币，你一旦失去信任账户就需要重来。"（L1782）

## 使用场景

- 学习教练式沟通后过度使用、所有对话都"先问你觉得呢"时——对照边界三情况刹车
- 评估一次对话该用教练式还是直接给答案时——ROI 判断
- 团队管理中出现"讨好式领导"倾向时——信任与规范的平衡
- 信任破裂后的修复期——理解"账户重来"的代价

## 操作方法

### 边界三情况（L552-570）

**情况 1：时间紧急**——没有时间完成教练式引导，以完成任务/解决问题为主（L554）。

**情况 2：无信任基础**——教练式领导力需要信任作为基础（L556-558），信任需要一点点积累（与攒硬币概念一致）。没有信任时教练式提问不好用。

**情况 3：ROI 低**——评估这件事的投入产出：如果直接给答案 ROI 更高，就用原来的方式（L562-566）。

**判断标准**（L570）：
> "你对效率的需求跟长期视角来讲，哪一个对你价值更高。"

但注意反例（L572-576）：有些情况下"直接给答案真的没有办法解决"——此时教练式沟通必不可少。边界不是教条，是评估维度。

### 信任不是放任（L1758-1770）

- **信任 ≠ 没有原则的包容**：下属想法明显不切实际或有风险时，不能盲目认同
- **正确做法**：理性态度指出问题 + 探讨修正方案
- **误区警告**："不要把让下属信任你这件事情变成你要去讨好下属"——直接给反馈有时反而加深信任，讨好反而削弱（L1770）

### 信任账户（L1772-1784）

- 信任建立需要时间，持续互动积累，短时间没效果不要放弃（L1774-1776）
- 信任是攒硬币的过程——但**一旦失去，账户清零需重来**（L1782）
- 维护比建立更重要：无心的不当言行会破坏信任（L1780）

## 适用边界

| 场景 | 边界 |
|:--|:--|
| 时间充足+有信任+ROI合理 | 适用教练式沟通 |
| 时间紧急 | 直接给答案，事后补讲道理 |
| 无信任基础 | 先建信任（倾听/支持式提问），再谈共识 |
| ROI 明显低于直接给答案 | 用直接方式 |
| 讨好式维护信任 | 不适用——信任与规范平衡 |
| 信任破裂后 | 账户重来，接受更高修复成本 |

## 为什么值钱

1. **防止"万能论"滥用**：教练式沟通不是万能——边界三情况避免"所有对话都绕圈子"
2. **拆穿讨好误区**：信任≠讨好——这个误区会同时毁掉信任和领导力
3. **账户重来的警示**：一次不当言行清零数月积累——预防 > 修复

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 万能论滥用 | 所有对话都用教练式，效率崩 | 对照边界三情况评估 |
| 讨好型领导 | 有求必应，下属不切实际的想法也认同 | 理性指出问题 + 探讨修正 |
| 忽视信任基础 | 对新人直接教练式提问 | 先建信任（倾听/支持） |
| 信任破裂不自知 | 一次不当言行后团队变冷 | 识别清零信号，启动重建 |
| 只建不维 | 信任建立后放松警惕 | 持续维护：加减币清单每周复盘 |

## Critique

### 攻击者 1：情境领导力——"边界三情况与下属发展阶段的关系未展开"

**攻击论点**：边界三情况（时间/信任/ROI）是领导者视角，但下属发展阶段（Blanchard D1-D4）同样是边界——D1 新人（低能力）用教练式提问会懵，D4 成熟下属用直接指令会反感。边界清单缺少下属维度。

**回应**：下属维度在 `tool-leadership-three-stubborn-subordinates`（能力×意愿矩阵）中处理。承认：卡内应补"边界判断还要加第四维——下属发展阶段：D1 给指令，D4 给空间"。

### 攻击者 2：管理现实——"ROI 判断在实践中难以量化"

**攻击论点**：ROI 低时用直接方式——但 ROI 怎么算？一次教练对话的时间成本 vs 下属未来自主解决问题的收益，很难在当下量化。判断标准模糊可能导致"什么都用直接方式"的偷懒。

**回应**：ROI 判断的本质是"效率需求 vs 长期视角"（L570）——这是价值权衡不是精确计算。口述也给了反例："直接给答案真的没有办法解决"时教练式必不可少（L574）。承认：卡内应补"ROI 判断的实战参考：同一类问题反复出现 = 值得教练式投入；一次性小问题 = 直接给答案"。

### 攻击者 3：信任理论——"'账户清零需重来'可能过度悲观"

**攻击论点**：信任账户清零需重来（L1782）暗示信任破坏后完全回到原点——但心理学的信任修复研究（如 betrayal 后的 reconciliation）证明修复后的信任可以超越原有水平，不是简单的"重来"。

**回应**：口述强调的是一旦失去需要**重来**的成本警示（防破坏），不是修复可能性的上限。承认：卡内应补"清零是警示——但修复路径存在（公开反思+持续加币），且修复后的信任可能更坚固（与硬币模型'失败中公开反思是加币'呼应）"。

## Synthesis

- **不要用的场景**：把边界当偷懒借口（什么事都直接给答案）；把信任当讨好；忽视下属发展阶段维度；信任破裂后放弃重建
- **关联表**：
  - `[[framework-leadership-coin-model]]`：信任账户=硬币模型；边界=应用前提
  - `[[tool-coaching-communication-four-layers]]`：矩阵卡（怎么用）+本卡（何时不用）
  - `[[tool-leadership-three-stubborn-subordinates]]`：下属发展阶段维度
  - `[[framework-leadership-five-ladders]]`：L0 安全氛围=信任基础
  - `[[management-domain-digest]]`：管理域边界对照
- **Action Triggers**：
  - 所有对话都用教练式 → 对照边界三情况刹车
  - 想讨好下属 → 停，信任≠讨好
  - 一次不当言行 → 识别清零，启动重建（公开反思+加币）
  - 新人对话 → 先建信任再教练式

## 可迁移场景

1. **管理者决策**：每次对话前快速三问——时间够吗？信任有吗？ROI 值吗？
2. **团队文化**：防讨好型领导——直接反馈反而加深信任
3. **信任修复**：账户清零后的重建路径（公开反思 + 持续加币）
4. **KDO 工厂（Agent 管理）**：给 agent 反馈也适用边界——紧急 bug 直接给答案，能力培养用教练式；"讨好式"纵容 agent 产出差 = 信任变放任
