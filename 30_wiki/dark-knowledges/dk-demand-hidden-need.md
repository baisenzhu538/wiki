# 隐性需求伪装：用户说的≠用户要的

## 原始表述

> 用户说"我需要更快的马"，他真正需要的是"更快的交通工具"。用户表达的需求往往是他们已经知道的解决方案，而非问题本身。

**L5的价值**：功能任务是用户说出来的（"更快的马"），情感和社交任务才是驱动决策的隐性需求（"不想被时代抛弃""要让邻居觉得我先进"）。

**防御**：永远多问一层——"如果这个问题解决了，对你意味着什么？"

## 使用场景

- **用户访谈设计**：用户说"需要更快的马"时，追问真正的交通工具需求
- **需求分析**：区分功能任务（用户说的）和情感/社交任务（隐性需求）
- **产品设计**：设计产品时，不仅满足功能需求，还要满足隐性需求
- **营销策略**：营销时，触动隐性需求比宣传功能更有效
- **一堂五步法学习**：理解L5（情感和社交任务）的价值

## 操作方法

1. **多问一层**：
   - 用户说"我需要更快的马"
   - 追问："如果这个问题解决了，对你意味着什么？"
   - 挖掘："不想被时代抛弃""要让邻居觉得我先进"
2. **需求分层**：
   - L1 现象：用户表面行为
   - L2 需求：用户说的功能
   - L3 核心任务：用户真正要完成的事
   - L4 问题：问题的本质
   - L5 情感和社交任务：驱动决策的隐性需求
3. **隐性需求识别**：
   - 功能任务：用户说出来的（"更快的马"）
   - 情感任务：用户感受到的（"不想被时代抛弃"）
   - 社交任务：用户想展示的（"要让邻居觉得我先进"）
4. **设计应用**：
   - 产品功能满足功能任务
   - 产品体验满足情感任务
   - 品牌传播满足社交任务

## 适用边界

| 场景 | 是否适用 | 说明 |
|:---|:---|:---|
| 用户访谈设计 | ✅ 适用 | 用户说的往往是已知解决方案，不是真正需求 |
| 需求分析 | ✅ 适用 | 区分功能任务和情感/社交任务 |
| 产品设计 | ✅ 适用 | 不仅满足功能需求，还要满足隐性需求 |
| 营销策略 | ✅ 适用 | 触动隐性需求比宣传功能更有效 |
| 一堂五步法学习 | ✅ 适用 | 理解L5（情感和社交任务）的价值 |
| B2B 产品 | ⚠️ 部分适用 | B2B决策更理性，但情感需求仍然存在 |
| 工具型产品 | ⚠️ 部分适用 | 工具型产品功能需求为主，但用户体验仍有情感需求 |

## 为什么值钱

1. **反直觉洞察**：用户说的≠用户要的，需求往往被解决方案包装
2. **需求分层**：L5（情感和社交任务）是驱动决策的真正动力
3. **设计指导**：产品不仅要功能正确，还要体验正确
4. **营销杠杆**：触动隐性需求比宣传功能更有效

## 失败模式 / 常见走偏

| 失败模式 | 症状 | 纠正 |
|:---|:---|:---|
| 直接实现用户说的 | 用户说"更快的马"就做马 | 追问"真正需要什么交通工具" |
| 忽略情感需求 | 产品功能正确但用户不买 | 识别L5情感和社交任务 |
| 功能导向设计 | 只关注功能任务 | 设计时同时考虑情感任务和社交任务 |
| 营销功能宣传 | 宣传"更快的马" | 宣传"不被时代抛弃""让邻居觉得你先进" |
| 需求分层缺失 | 不做L1-L5分层 | 用冰山模型或五步法分层分析 |
