# 王欢暗知识：创造力重新分配到问题描述与验收审美

> **Burn line**: 未来人的创造力，不再主要放在执行上，而是放在“把问题描述清楚”和“判断结果好不好”上。

## 原始表述

王欢在课后问答中回答了一个关键问题：“人机协作里人到底要做什么？”

他的答案：**把创造力放在两个地方——问题描述和验收审美。** 中间执行环节，尽量交给 AI。

人的创造力从“怎么做”转向“做什么”和“做成什么样”。

## 使用场景

- **创意/设计/策略/内容类工作**：需要人类审美判断的任务，AI 执行+人验收
- **招聘 JD 撰写**：从简单需求描述到结构化 BITCOE 框架的创造力迁移
- **海报/视觉验收**：从“不好看”到具体维度（配色、排版、语气）的审美显性化
- **团队角色转型**：告诉团队成员“人负责描述问题和审美判断，执行交给 AI”
- **建立不可替代性**：培养把隐性审美显性化的能力

## 操作方法

1. **问题描述的四个层次**：
   - 第一层：说清楚任务是什么
   - 第二层：说清楚背景、约束、红线
   - 第三层：把隐含的业务意图和审美标准显性化
   - 第四层：设计一个让 AI 能持续正确执行的系统
2. **验收审美的具体化**：
   - 普通验收：“这个海报不好看”
   - 有审美的验收：“视觉符号太扁平，与文章气质不匹配。建议：去掉象征性图标，改用有张力的排版；配色从蓝色系改为对比更强烈的黑金；标题字号层级需要再拉开”
3. **审美标准翻译**：把审美判断翻译成具体标准，AI 就能在下一轮做得更好
4. **创造力重新分配**：
   - 传统：定义问题 → 执行 → 执行 → 执行 → 微调 → 交付（人做全部）
   - 人机协作：定义问题 → AI 执行 → 人验收 → AI 修改 → 人最终验收（人做描述和审美）

## 适用边界

| 适用 | 不适用 |
|:---|:---|
| 创意、设计、策略、内容类工作 | 纯执行、有标准 SOP 的工作 |
| 需要人类审美判断的任务 | 完全可量化、可自动化的任务 |
| 探索性、创新性项目 | 高度合规、低风险偏好的项目 |

## 为什么值钱

1. **创造力重新分配**：人的创造力从“怎么做”转向“做什么”和“做成什么样”
2. **审美显性化**：当你能把审美判断翻译成具体标准，AI 就能持续学习并提升
3. **问题描述的层次**：从简单表达需求到设计 AI 执行系统，创造力高一个维度
4. **效率跃迁**：人专注高价值的描述和验收，AI 处理低价值的执行和修改

## 失败模式 / 常见走偏

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| **只描述不验收** | AI 输出很多，但不知道哪个好 | 建立明确的审美标准 |
| **只验收不描述** | 反复说“不对”，但说不清要什么 | 用 BITCOE 把需求结构化 |
| **审美无法言传** | 只能说“感觉不对” | 强制自己用三个具体维度描述 |
| **过度干预执行** | AI 每做一步都要指导 | 把干预放在验收节点 |
