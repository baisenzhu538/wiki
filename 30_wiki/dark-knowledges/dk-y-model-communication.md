# Y模型沟通版暗知识

> 定位：属于 `framework-coaching-leadership-core` 的沟通模型暗知识卡——**Y 模型（目标/现况/参与/行动/反思）的教练式沟通版**。与 `framework-yitang-y-model-cross-domain-fusion`（Y 模型共识）同源，本卡是 Y 模型在教练沟通场景的应用版；与 `tool-coaching-communication-four-layers`（四层级矩阵）配套：矩阵讲"用哪层牌"，本卡讲"完整对话的流程框架"。

## 原始表述

> "很多模型模板都是国外来的。但在中国的团队演化里面……主观能动性跟自我觉察这两个维度，是我们目前为止遇到组织里面最最常见最缺乏，但是也是最需要的一个核心能力。"（口述 02 L3116-3118）

## 使用场景

- 需要一次完整、较长的教练式沟通（共识层/成长层）时——用 Y 模型作为对话流程框架
- 信任层用碎片化提问/反馈积累，越往上（共识/成长）越需要完整模型（L3086-3090）
- 国外教练模型（GROW/OSCAR/FEEL/ABCDEF）在中国团队水土不服时——本土化改进
- 下属被动（等安排）、老油条推诿时——参与环节的针对性应用

## 操作方法

### Y 模型五环节（L3106-3116）

| 环节 | 含义 | 沟通侧重 | 可用卡牌 |
|:--|:--|:--|:--|
| **目标（Goal）** | 要达成什么 | 深入倾听（L3192） | 倾听卡：专注/3F |
| **现况（Reality）** | 当前真实情况 | 请利益相关方提问了解背后情况（L3108） | 提问卡：引发思考 |
| **参与（Engagement）** | 激发主动承担（**本土化新增**） | 引导员工主动解决的内在驱动力（L3112） | 提问卡：关心/支持式 |
| **行动（Action）** | 行动方案 | 提问偏重（L3194） | 提问卡：明确出口 |
| **反思（Over）** | 复盘提炼经验（**本土化新增**） | 固化行为习惯、强化认知（L3196） | 反馈卡：BASIC/刻意练习 |

### 为什么加 engaging + over（L3116-3120）

- **主观能动性（engaging）**：中国团队最常见最缺乏——员工被动等安排
- **自我觉察（over）**：中国团队最需要——缺乏复盘反思能力
- 国外模型（GROW/OSCAR 等）落地中国团队时缺这两个维度，Y 模型补齐

### 案例 1：从"教他做到他想做"（L3124-3152）

**背景**：业务新人能力强但推进被动，每次开会忍不住拍板给答案。

**Y 模型应用**：
1. 忍住拍板 → 让他理清挑战目标（"独立完成一个客户 brief 算一个项目"）
2. 问"你觉得卡在哪里？" → 他说对客户内部流程不熟
3. 问"如果可能你会怎么尝试解决？" → 他想到私聊客户助理问流程
4. 一起制定小行动计划 → 结束复盘

**结果**：他自己发现"以前对客户流程不熟就停住了，其实可以再往前多想一步"——项目做得好，归属感成就感提升，总结能力提高，不再等安排主动出击（L3144-3152）。

### 案例 2：从"执行者到引导师"（L3154-3188）

**背景**：老油条队员能力强但动力不行，想跳槽，推任务没人接。以前用权威压制"事实证明没用，只会激化矛盾"（L3160）。

**Y 模型应用（转折点 = 现况 + 参与）**：
1. 请教式提问："你怎么看这个任务老是没人接？"（L3168）
2. 老油条："这个任务没意思，不出成果，不会有人接"
3. 追问："如果让它变得更有体感，你就有机会吗？有什么办法？"（L3174-3176）
4. 他想出：跟另一个客户合并操作，流程优化就能出成果（L3178-3180）

**结果**：从"推任务"变成"互相讨论共同解决方案"——他牵头做了新项目流程，赢得客户表扬，把它当个人成长里程碑（L3182-3188）。

## 适用边界

| 场景 | 边界 |
|:--|:--|
| 完整较长的教练对话 | 适用——Y 模型五环节全流程 |
| 碎片化信任积累 | 不适用——用简短倾听/提问/反馈即可（L3086） |
| 紧急决策 | 不适用——直接给答案 |
| 无信任基础 | 先建信任再走模型 |
| 国外模型水土不服 | 用 Y 模型（本土化） |

## 为什么值钱

1. **本土化洞察**：主观能动性 + 自我觉察是中国团队最缺的两维——国外模型落地失效的根因
2. **完整流程框架**：信任层碎片化 → 共识/成长层完整模型的衔接（L3086-3090）
3. **两案例验证**：被动新人（教他做到他想做）+ 老油条（执行者到引导师）——覆盖两类最难下属
4. **环节侧重明确**：目标/现况靠倾听，参与/行动靠提问，反思靠反馈（L3192-3198）

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 跳过参与环节 | 目标行动都问了但下属仍被动 | 补 engaging：激发主动承担 |
| 跳过反思环节 | 每次对话重新开始，经验不积累 | 补 over：复盘提炼经验 |
| 权威压制替代 | 老油条推诿时用命令 | 用请教式提问（"你怎么看"） |
| 全程只提问 | 忽视目标/现况的倾听侧重 | 目标现况靠倾听，参与行动靠提问 |
| 模型机械套用 | 五环节逐一打卡 | 按情境侧重，模型是流程不是教条 |

## Critique

### 攻击者 1：教练模型谱系——"Y 模型与 GROW 无本质区别"

**攻击论点**：Y 模型（目标/现况/参与/行动/反思）与 GROW（目标/现实/选项/意愿）结构高度相似——只是加了"参与"和"反思"，本质是 GROW 的变体，无独立方法论地位。

**回应**：差异在**本土化动机**——口述明言"很多模型模板都是国外来的"，Y 模型的创新点不在结构而在"为什么加 engaging+over"：主观能动性和自我觉察是中国团队最缺的两维（L3116-3118）。这不是结构创新，是**适配创新**。承认：卡内应标注"结构血缘与 GROW 相近，价值在本土化适配逻辑"。

### 攻击者 2：实践检验——"两案例的结果归因可能过度归功于 Y 模型"

**攻击论点**：案例 1 新人"项目做得好"、案例 2 老油条"牵头新流程"——这些结果可能来自其他因素（项目本身/客户关系/时间推移），Y 模型的应用只是同期发生，因果性未被证明。

**回应**：口述呈现的是对话过程的**行为变化信号**（新人"不再等安排主动出击"L3152、老油条"从推任务到共同解决方案"L3182）——这些是对话后的即时行为转变，归因于模型应用合理但长期效果待验证。承认：卡内应标注"案例为过程性证据（对话→行为转变），长期效果未做对照实验"。

### 攻击者 3：文化研究——"'中国团队最缺主观能动性'是过度概括"

**攻击论点**：主观能动性和自我觉察是**个人差异**而非文化差异——把"中国团队"整体贴上"缺乏主观能动性"的标签是文化刻板印象，且可能让管理者忽视个体差异。

**回应**：口述的表述（"我们目前为止遇到组织里面最最常见最缺乏"）是基于**组织实践观察**（莫非服务大量 CEO/业务一把手）而非文化本质论——"最常见"是经验统计不是文化定性。承认：卡内应补"主观能动性缺失是个体/组织现象，Y 模型的两维改进适用于任何团队，不限于中国"。

## Synthesis

- **不要用的场景**：机械套用五环节；跳过参与/反思；用 Y 模型做文化定性；忽视信任前提

- **Action Triggers**：
  - 完整教练对话 → 用 Y 模型五环节
  - 下属被动 → 补 engaging（激发主动承担）
  - 老油条推诿 → 请教式提问（"你怎么看"）
  - 对话结束 → 补 over（复盘提炼经验）

## 可迁移场景

1. **一对一辅导**：Y 模型作为完整对话流程（尤其共识/成长层）
2. **团队激励**：参与环节激发主动性（中国团队最缺）
3. **复盘文化**：over 环节固化反思习惯
4. **KDO 工厂（Agent 管理）**：引导 agent 复盘产出 = over 环节；"教他做到他想做" = 让 agent 自己定位卡点（素材/格式/深度）而非代写
