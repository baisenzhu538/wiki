# 商业模式转型信号：何时该 pivot

## 原始表述

一堂五步法：转型不是失败，而是学习后的调整。识别转型信号，及时转型，比坚持错误方向更明智。

转型的5个信号：

| 信号 | 说明 | 紧急程度 |
|:---|:---|:---:|
| **单元模型不成立** | LTV < CAC，长期无法优化 | 高 |
| **市场变化** | 市场从蓝变红，竞争格局变化 | 高 |
| **内核验证失败** | 产品内核无法验证 | 高 |
| **团队失去信心** | 团队对产品/商业模式失去信心 | 中 |
| **增长停滞** | 所有增长方法都无效 | 中 |

## 使用场景

- **商业模式评估**：评估商业模式时，识别转型信号
- **战略决策**：战略决策时，判断是否需要转型
- **创业方向调整**：创业方向调整时，识别转型时机
- **产品方向调整**：产品方向调整时，判断是否需要转型
- **团队管理**：团队管理时，识别团队信心变化

## 操作方法

1. **单元模型检测**：
   - LTV < CAC：每获客一个，亏损一个
   - 回本周期太长：现金流无法支撑
   - 规模化后恶化：规模越大，亏损越大
   - 优化无效：尝试所有优化方法，单元模型仍不成立
   - 行动：优化单元模型或转型
2. **市场变化检测**：
   - 市场从蓝变红：新进入者增多，竞争加剧
   - 技术变革：新技术颠覆现有模式
   - 政策变化：政策限制或禁止
   - 用户习惯变化：用户需求变化
   - 行动：重新评估差异化或转型
3. **内核验证检测**：
   - 需求假设错误：用户不需要
   - 价值假设错误：用户不感知价值
   - 付费假设错误：用户不愿意付费
   - 增长假设错误：无法规模化增长
   - 行动：重新定义需求、价值、商业模式或增长策略
4. **转型决策流程**：
   - 识别信号→分析原因→定义转型方向→验证新假设→执行转型→验证转型效果

## 为什么值钱

1. **转型信号识别**：系统化的转型信号识别框架
2. **转型时机判断**：及时转型比坚持错误方向更明智
3. **转型类型指导**：Zoom-in、Zoom-out、客户细分、客户需求、平台、商业模式
4. **转型决策流程**：识别信号→分析原因→定义方向→验证假设→执行→验证效果

## 失败模式 / 常见走偏

| 失败模式 | 症状 | 纠正 |
|:---|:---|:---|
| 忽视信号 | 信号明显，但不转型 | 建立信号监测机制 |
| 转型过早 | 还没充分验证就转型 | 充分验证后再转型 |
| 转型过晚 | 坚持错误方向太久 | 及时识别信号 |
| 转型不彻底 | 转型不彻底，半吊子 | 彻底转型 |
| 忽视团队 | 转型不考虑团队 | 团队参与转型决策 |
| 转型后不验证 | 转型后不验证效果 | 验证转型效果 |
