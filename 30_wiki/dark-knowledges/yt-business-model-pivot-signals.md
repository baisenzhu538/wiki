# 商业模式转型信号：何时该 pivot

> 一堂五步法：转型不是失败，而是学习后的调整。识别转型信号，及时转型，比坚持错误方向更明智。

## 核心框架

转型的5个信号：

| 信号 | 说明 | 紧急程度 |
|:---|:---|:---:|
| **单元模型不成立** | LTV < CAC，长期无法优化 | 高 |
| **市场变化** | 市场从蓝变红，竞争格局变化 | 高 |
| **内核验证失败** | 产品内核无法验证 | 高 |
| **团队失去信心** | 团队对产品/商业模式失去信心 | 中 |
| **增长停滞** | 所有增长方法都无效 | 中 |

## 关键洞察

### 1. 单元模型不成立

| 情况 | 说明 | 行动 |
|:---|:---|:---|
| **LTV < CAC** | 每获客一个，亏损一个 | 优化单元模型或转型 |
| **回本周期太长** | 现金流无法支撑 | 优化或转型 |
| **规模化后恶化** | 规模越大，亏损越大 | 停止增长，优化或转型 |
| **优化无效** | 尝试所有优化方法，单元模型仍不成立 | 转型 |

### 2. 市场变化

| 变化 | 说明 | 行动 |
|:---|:---|:---|
| **市场从蓝变红** | 新进入者增多，竞争加剧 | 重新评估差异化 |
| **技术变革** | 新技术颠覆现有模式 | 拥抱新技术或转型 |
| **政策变化** | 政策限制或禁止 | 合规或转型 |
| **用户习惯变化** | 用户需求变化 | 调整产品或转型 |

### 3. 内核验证失败

| 失败 | 说明 | 行动 |
|:---|:---|:---|
| **需求假设错误** | 用户不需要 | 重新定义需求 |
| **价值假设错误** | 用户不感知价值 | 重新定义价值 |
| **付费假设错误** | 用户不愿意付费 | 重新定义商业模式 |
| **增长假设错误** | 无法规模化增长 | 重新定义增长策略 |

### 4. 转型的类型

| 转型类型 | 说明 | 示例 |
|:---|:---|:---|
| **Zoom-in** | 聚焦某个功能成为产品 | Instagram从Burbn聚焦照片 |
| **Zoom-out** | 从功能扩展为平台 | 从工具到平台 |
| **客户细分** | 换目标客户 | 从C端到B端 |
| **客户需求** | 换需求场景 | 从社交到电商 |
| **平台** | 从工具到平台 | 从软件到平台 |
| **商业模式** | 换商业模式 | 从广告到订阅 |

### 5. 转型的决策流程

```
识别信号
    ↓
分析原因
    ↓
定义转型方向
    ↓
验证新假设
    ↓
执行转型
    ↓
验证转型效果
```

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **忽视信号** | 信号明显，但不转型 | 建立信号监测机制 |
| **转型过早** | 还没充分验证就转型 | 充分验证后再转型 |
| **转型过晚** | 坚持错误方向太久 | 及时识别信号 |
| **转型不彻底** | 转型不彻底，半吊子 | 彻底转型 |
| **忽视团队** | 转型不考虑团队 | 团队参与转型决策 |
| **转型后不验证** | 转型后不验证效果 | 验证转型效果 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 商业模式评估 | 技术架构设计 |
| 战略决策 | 品牌传播策略 |
| 创业方向调整 | 运营活动评估 |
| 产品方向调整 | 纯公益项目 |
