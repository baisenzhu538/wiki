# Agent 并行设计系统：五 Agent 同时做图 + 设计规范=能力复制介质

## 原始表述

> 「我是五个设计师同时上班的，就光做图这件事儿，我是五个设计师同时完成工作。就是 A 做这张图，B 做这个图，按照系列把它都拆开，然后就大家都一起分工，五个设计师同时做。」（口述 L2222-2226）
> 「你在我全程每一个 session 打开，我只需要跟他说一句话，叫你给我看一下设计规范，熟悉一下这个项目就可以干活。」（L2230）
> 「做完之后，我就跟他说一句话，我说你帮我把那个复盘一下，就我写一个设计规范，大概的思路，然后一些通用性的东西……然后他其他的人就可以接着干活了。」（L2246-2248）
> 「我不只是把我的一个设计师的能力，我还可以用一个设计规范把我这边的设计师几乎一秒钟变成是另外一个同学的设计师的能力。」（L2262）

## 使用场景

- **批量做图/设计任务**（多张系列图、100 张稿子）——需要并行产能
- **新人/新 Agent 加入设计任务**——需要快速达到团队设计水准
- **设计风格一致性要求高**（品牌、课程、演示系列）——需要统一规范
- **多项目并行**（带宽管理）——L2222"我现在主要就是整个包括现在这些可能都是能做的"

## 操作方法

1. **拆任务**：按系列把图拆开（"A 做这张图，B 做这个图，按照系列拆开"——L2226）
2. **并行召唤**：五个 Agent 同时上班（L2224）——每个 session 打开只说一句话："看一下设计规范，熟悉一下项目就可以干活"（L2230）
3. **补上下文**：新 session 只需补两个上下文——项目基本介绍 + 设计规范（L2236-2238）——"相当于你可以用很短的时间，把一个新手设计师训练成一个能干这个活的设计师"
4. **复盘沉淀规范**：做完系列图后，让 Agent 复盘写设计规范（思路+通用性）——"写一个设计规范……然后他其他的人就可以接着干活了"（L2246-2248）
5. **顺序下达**：规范成型后做完整顺序下达，甩给团队——"顺下来做完了很完整的一个顺序下达……他们再做图，遵循我……跟我做的几乎都是一样的"（L2256-2258）

## 适用边界

| 边界 | 说明 |
|:--|:--|
| ✅ 适合 | 批量系列图/设计（同风格多张） |
| ✅ 适合 | 设计规范可沉淀的任务（规则明确可复盘） |
| ✅ 适合 | 多 Agent 并行产能需求（带宽管理） |
| ❌ 不适合 | 单张高创意一次性图（无系列拆分价值） |
| ❌ 不适合 | 无明确设计规范可提取的任务（复盘不出通用规则） |
| ⚠️ 注意 | 依赖"设计规范"作为能力复制介质——规范质量决定并行一致性（L2248/L2262） |

## 为什么值钱

把"一个设计师的能力"变成"可复制的团队产能"——核心机制是**设计规范=能力复制介质**（L2262：一秒钟把设计师变成另一个人的设计师能力）。这解决了 AI 协作时代最贵的问题：**能力不是靠人带人复制，而是靠规范文档复制**。结合并行（五 Agent）实现产能乘数——100 张稿子靠"一个设计师+五个 Agent 分工"做出来（L2264）。

## Critique

- **反驳**：设计规范能完全复制审美吗？——不能。规范复制的是"可描述的执行规则"（配色/布局/风格），复制不了"品味判断"（什么好看）；本卡是"执行一致性"方案，不是"审美能力"方案——高创意部分仍需人/主设计师把关。
- **反驳**：五 Agent 并行会不会质量失控？——会，如果规范没沉淀到位。本卡的操作顺序（先做→复盘→规范→并行）把"规范沉淀"放在并行之前，是防失控的关键——但复盘质量依赖 Agent 的总结能力，需抽查。
- **条件**：此卡前提=任务可拆分为系列（多张同风格）；单张一次性任务无并行价值。
- **注意**：L2264"100 张稿子怎么做出"是楚门本人产出规模，属"口述待独立核实"级数字——机制可复制，规模数字勿当普适标准。
