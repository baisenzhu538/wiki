# 信任硬币敏感性（暗知识）

> **定位**：属于 [[framework-leadership-coin-model]] 的觉察层暗知识（清单是模型，敏感性是使用）。与 [[framework-coaching-leadership-core]] 的"起点能力"、[[framework-leadership-five-ladders]] 的 L0/L5 层呼应。

## 原始表述

> "领导力其实就是每年成百上千次一对一的互动中形成的，每一次信任的积累都非常重要。这个区别在于你有没有领导力的意识，你会不会对成百上千次的那种信任硬币有敏感性，到底是加的还是减的？"（口述 01 L1072-1074）

> "我开始有了这个黑盒的评价模型之后，我就发现了团队大量的我在前两年都没有观察到的那些规律或者现象。"（L776）

## 使用场景

- 刚获得领导力定义（心甘情愿解决难题）但不知道怎么落地时——敏感性是把定义变成日常觉察的开关
- 团队氛围微妙变化（士气/汇报频率/主动性）却说不清原因时
- 每次一对一、会议、冲突处理前后——判断这次互动是加币还是减币
- 讲愿景没人响应时——检查希望表达是否分场景

## 操作方法

### 敏感性三步建立

1. **先建黑盒评价模型**：不是先观察，而是先知道"什么行为加币/减币"（对照硬币模型卡清单）——有了标准才能看到规律（L776）
2. **微观观察**：在每次互动中标记加减——"到这儿要对他好一点，到这儿要秀一下肌肉，到这儿要让他觉得我挺厉害"（L1148-1152）
3. **时间复利**：主动构建意识约两年，敏感性显著增强，每年有几十上百次觉察（L1148）

### 2×5 耐心标准（安全空间有期限）

- 第一个项目改 5 轮，第二个 4 轮，第三个 3 轮，五个项目内学会（L2250-2258）
- "我可以给你安全空间，但是安全空间我先跟你说清楚了，我希望五次之内你能学会"（L2258）
- **暗知识**：安全空间 ≠ 无限空间——给期限的安全感才是真安全

### 希望表达库三维度方法

- 分文化类/相信类/故事类三维度建库（L3100），至少 20 多条（L3094）
- 不同场景讲不同希望——"面对不同人不同职位不同场景，我讲的希望都不太一样"（L3096）
- 小目标即可："你可以先从小的开始，一个个小的愿景，大家依然是喜欢的"（L3040）

## 适用边界

| 场景 | 边界 |
|:--|:--|
| 敏感性用于自我觉察 | 适用——清单是镜子不是剧本 |
| 敏感性用于表演 | 不适用——表演攒的是防备不是信任 |
| 2×5 用于高潜力培养 | 适用——防无限安全空间 |
| 2×5 用于压力威胁 | 不适用——必须事先沟通标准，不事后翻旧账 |
| 希望表达库用于真诚愿景 | 适用 |
| 希望表达库用于画饼 | 不适用——自己不信的故事别讲（L1132） |

## 为什么值钱

1. **领导力从玄学变可操作**：敏感性把"领导力"变成可逐次判断的加减币过程
2. **预防减币 > 攒加币**：加币一枚一枚攒，减币一次清零（L1114）——敏感性让你在减币前踩刹车
3. **2×5 平衡两个极端**：无限安全（养废）vs 无限压力（崩盘）——期限给安全感
4. **希望表达库解决"讲愿景没人听"**：不是愿景不好，是没分场景

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 无模型硬观察 | 天天看但看不出规律 | 先建加减币清单（黑盒模型）再观察 |
| 敏感性变算计 | 每个互动都在算得失 | 回归真诚——清单是镜子不是剧本 |
| 无限耐心 | 改 20 轮还学不会 | 用 2×5 设期限，事先说清 |
| 一套愿景走天下 | 讲愿景团队没反应 | 建三维度表达库，分场景讲 |
| 2×5 变威胁 | 事后翻旧账 | 事先沟通标准 + 给足安全空间 |

## Critique

### 攻击者 1：行为经济学（Kahneman）——"加减币的线性假设忽略损失厌恶的个体差异"

**攻击论点**：敏感性假设加减币可被客观标记，但损失厌恶系数（约 2-2.5 倍）因人而异——同一句批评，有人减 1 币，有人减 10 币。敏感性如果不包含"个体权重校准"，标记的加减币只是领导自己的想象。

**回应**：硬币模型的"清零不对称"已隐含损失厌恶（L1114），敏感性进阶确实需要校准个体权重——这依赖识人能力（framework-how-to-know-a-person）。承认：敏感性分两层——通用清单（入门）+ 个体校准（进阶），卡内应标注。

### 攻击者 2：组织行为学——"2×5 标准的数字武断，无实证依据"

**攻击论点**：2×5（5 轮/5 项目）是 Truman 个人经验，没有学习科学研究支持"5 次是合理阈值"。不同任务复杂度、不同人学习速度，固定 5 次可能过快（打击信心）或过慢（浪费资源）。

**回应**：2×5 的意图是"给安全空间设期限"（对抗无限空间），数字本身可调——关键机制是"事先说清 + 有期限"。承认：卡内应补"数字按任务复杂度调整，机制（设期限）不变"。

### 攻击者 3：传播学——"希望表达库可能被当成'话术库'滥用"

**攻击论点**：三维度（文化/相信/故事）表达库与销售话术库结构相似，管理者可能把它当"讲什么最能打动下属"的操纵工具——这恰恰违背领导力的真诚底色。

**回应**：口述明确"自己都不信的故事别讲"（L1132）+ "真诚是基础"。表达库是"把真实希望组织好"，不是"制造虚假希望"。承认：卡内应补"表达库的素材必须来自真实信念，只做组织不做编造"。

## Synthesis

- **不要用的场景**：把敏感性当算计工具；2×5 当威胁工具；表达库当话术库；忽略个体权重差异
- **关联表**：
  - `[[framework-leadership-coin-model]]`：加减币清单 = 敏感性的觉察标准
  - `[[framework-coaching-leadership-core]]`：敏感性是起点能力
  - `[[framework-leadership-five-ladders]]`：2×5 属 L0，表达库属 L5
  - `[[tool-leadership-feedback-cards]]`：反馈 = 高频加减币动作
  - `[[framework-how-to-know-a-person]]`：个体校准依赖识人能力
- **Action Triggers**：
  - 每次互动后 → 标记加减币（30 秒复盘）
  - 给下属耐心时 → 用 2×5 设期限并说清
  - 讲愿景无反应 → 检查表达库是否分场景
  - 想表演加币时 → 停止，回归真诚

## 可迁移场景

1. **带团队**：加减币敏感性 + 2×5 期限标准
2. **个人成长**：对自我互动复盘（自己也是自己的被领导者）
3. **家庭关系**：日常互动加减币觉察（最亲的人最容易被忽视）
4. **KDO 工厂（Agent 协作）**：给 agent 反馈 = 加减币动作——讲道理加币，强压减币
