# 暗知识：「7-8 分幻觉」是结构性盲区

> 低段位者高估自己是因为没见过高段位的具体打法。校准必须引入外部高质量反馈。

## 原始表述

> Truman 在课上做过一个令人震惊的实验：讲课前让学员给自己的五步法水平打分，大多数人打 7-8 分。但课后大都自觉不到 60 分（按百分制）。每个段位都有自己看不到的东西。

——Truman，一堂五步法课堂实验

## 核心洞察

这个洞察可以拆成三层：

**第一层：自评高估是结构性的，不是态度问题。** 低段位者不是"谦虚不够"——他们真诚地认为自己有 7-8 分。问题在于：他们用自己知道的全部标准来衡量自己，而他们不知道高段位的标准长什么样。就像只见过乡村乒乓球的人，无法想象世界冠军的旋转速度和战术体系——他用"我打赢了村里所有人"来给自己打 7-8 分，合情合理。

**第二层：唯一打破盲区的方法是看到比自己高 2+ 个段位的具体打法。** 听别人说"你要提高逻辑链深度"没用——你听不懂什么是"逻辑链深度"。你需要的是亲眼看到一份 L5 的分析报告，然后发现："原来还能这样想问题。"这种"原来还能这样"的瞬间，是段位跃迁的唯一信号。

**第三层：内部互评会强化盲区。** 同一段位的人互相评审，就像一群 3 分的人互相打分——大家都觉得彼此不错，因为没人见过 7 分的标准。所以"团队感觉良好"不是好事，是危险信号。

**这条暗知识的通用性远超五步法**——编程、写作、设计、管理、销售、演讲……任何依靠"段位"的能力领域，「7-8 分幻觉」和「外部反馈是唯一校准器」同时成立。

## 操作方法

1. **引入跨段位观摩**
   每季度安排一次：让团队成员看比自己高 2+ 段位的人做同一个任务。不要讲方法论，直接看产物——报告、代码、设计稿。让差距"可见"。

2. **问"说出 3 个高段位打法"**
   这是最快的段位检测题。如果一个人说不出具体的高段位打法（不是"要更深入"这种模糊表述，而是"他们会先做 X，再做 Y，然后检查 Z"），那他还不知道高段位长什么样。

3. **外部评审制度化**
   不要让同一个段位的人互相评审。引入跨团队、跨公司、或客户视角的评审。评审结论必须包含具体反例——不是"这里不够好"，而是"这里如果是我做，我会这么做"。

4. **用"原来还能这样"频率衡量进步**
   记录团队成员最近一次说出或感到"原来还能这样"的时间。如果超过 3 个月没有，安排跨段位观摩或换一个完全不同的任务类型。

5. **段位自评必须对标**
   自评时不能只给分数。必须附带：这个分数的对标参考是谁？你和参考对象的差距在哪三个具体维度？没有对标的自评不具信息量。

## 适用边界

| 边界 | 说明 |
|:-----|:-----|
| **适用于有段位差异的能力领域** | 不适用于纯知识性领域（如"知道某个法规"）——知道≠会用。 |
| **需要存在比当前团队高 2+ 段位的外部参照** | 如果团队已经是行业顶尖，这个工具失效。 |
| **不替代刻意练习** | 看到差距后还需要针对性训练，观摩只是打开盲区的第一步。 |
| **需要心理安全感** | 如果团队有"护面子"文化，外部评审可能适得其反。 |

## 常见失败模式

| 失败模式 | 典型症状 | 修复方法 |
|---|---|---|
| 同段位互评 | 评分都是 3.5-4.0 分，没有区分度 | 必须引入至少一个高 2+ 段位的评审者 |
| 模糊反馈 | "逻辑链不够深""数据支撑不足"等抽象反馈 | 要求反馈附带"如果是我做，我会这么改"的具体示例 |
| 看了一次高段位就以为够了 | 看完高段位报告后兴奋了两天，行为没变 | 看完后立刻用新标准重做自己最近一个任务，对比差异 |
| 段位焦虑 | 外部反馈让人感到"自己很差"而丧失动力 | 强调段位差距 = 成长空间，不是价值评判；设定"下次比这次好一点"的目标 |
| 只看不打 | 观摩了但没动手试 | 观摩后必须跟一个实战任务——用新标准重做一个旧任务 |
