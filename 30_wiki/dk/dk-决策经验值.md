# 暗知识：决策经验值

## 反直觉洞察

**老手和新手在决策时最大的差距不是「知识量」，而是「经验值」——老手见过足够多的样本，知道什么是正常波动、什么是真正的异常信号。** 新手容易对每次波动都过度反应 [conf=0.75, source=原图/一堂原创]。

## 经验值的本质

| 新手 | 老手 |
|:---|:---|
| 看到数据波动 → 分析原因 | 看到数据波动 → 先判断是否在正常范围内 |
| 每个异常都要解释 | 知道哪些异常值得关注 |
| 用理论推导 | 用模式匹配（这个像上次那个...） |

## 如何加速积累经验值

1. **建「决策日志」**：每次重大决策记录前提假设和预期结果，3个月后复盘
2. **看别人的决策日志**：一堂的案例库 = 别人的经验值
3. **小决策多练**：在低风险决策上刻意练习，积累模式库

## 失败模式 / 边界 / 反例

1. **经验过度泛化，把过去成功案例套用到新场景**  
   上次靠低价策略打赢了，这次市场环境不同，仍然复制低价策略，结果陷入价格战。[conf=0.80, source=战略管理常见反例]

2. **经验僵化，忽视环境变化**  
   老手的"我见过"可能变成"我只见过这一种"，对新变量（如 AI、政策变化）视而不见。[conf=0.75, source=组织行为学常见观察]

3. **用"经验"掩盖懒惰，不做定量分析**  
   "凭经验判断"有时是不愿意收集数据、建立模型的借口，导致决策停留在直觉层。[conf=0.75, source=决策科学批评]
