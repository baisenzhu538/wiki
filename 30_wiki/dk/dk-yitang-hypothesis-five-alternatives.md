# 假设思维不是唯一道路：五条替代路径与适用边界

> **一句话定义**：假设思维不是唯一解。抄同行、降预期、靠牛人、靠经验、外包出去，都是合法路径。假设思维的本质是**靠科学认知拿结果**，它对人要求高、周期长、难度大，只在追求超预期目标时才最值得用 [conf=0.85, source=管理篇口述 L488-L552]。

## 原始表述

课程里开宗明义："假设思维不是我们唯一的道路，还有很多条路都可以解决问题。" [conf=0.85, source=管理篇口述 L488]

五条常见替代路径：

1. **抄同行**：直接复制已被验证的做法 [conf=0.85, source=管理篇口述 L492]。
2. **降预期**：不追求三倍增长，翻 50% 就行 [conf=0.85, source=管理篇口述 L494-L498]。
3. **靠人**：招所谓厉害的人，他能解决就解决，不行就换人 [conf=0.85, source=管理篇口述 L502]。
4. **靠经验**：用已有的经验直接判断 [conf=0.85, source=管理篇口述 L502]。
5. **外包出去**：把活交给外包，不追究内部逻辑 [conf=0.85, source=管理篇口述 L502]。

这些路径在特定场景下都成立，但课程指出它们的共同问题：

> "假设思维本质上是靠科学认知拿结果的策略。" [conf=0.85, source=管理篇口述 L510]

不是靠运气、不是靠人脉、不是靠"别人也这么做"。

## 使用场景

- 团队一号位纠结"到底要不要用假设思维"
- 顾问/教练被问到"为什么不用更简单的方法"
- 团队资源有限，需要判断哪条路径ROI更高
- 设计 agent-spec 边界条款时，明确告诉用户何时不用假设思维

## 操作方法

1. **先列出五条替代路径**：抄同行、降预期、靠人、靠经验、外包。
2. **评估目标性质**：
   - 目标是"过得去"还是"超预期"？
   - 周期是短还是长？
   - 难度是常规还是高难度？
3. **按以下规则选路径**：

| 场景 | 推荐路径 | 不推荐 |
|:---|:---|:---|
| 短期、容易、临时目标 | 抄同行 / 降预期 / 靠经验 | 假设思维（大材小用） |
| 长期、高难度、追求行业顶尖 | 假设思维 | 纯靠人 / 外包 |
| 团队缺乏假设思维基础 | 先补认知，再谈假设 | 强行上假设流程 |
| 一号位没有决心 | 替代路径 | 假设思维（推不动） |

4. **不贬低替代路径**：课程的态度是"辩证地看" [conf=0.85, source=管理篇口述 L488]，不是"假设思维最高级"。

## 适用边界

| 适用 | 不适用 |
|:---|:---|
| 判断"什么时候用假设思维" | 已经决定用假设思维后，用它指导具体操作 |
| 一号位做路径选择 | 团队没有基本科学认知基础 |
| 顾问做边界条款 | 把替代路径当借口逃避深度思考 |

## 为什么值钱

这条暗知识值钱，是因为它**防止假设思维被滥用**。很多团队把"假设思维"当成万能钥匙，结果在不适合的场景硬上，造成：

- 短期目标被过度复杂化；
- 团队因流程繁琐而抵触；
- 一号位因看不到快速结果而弃用。

课程明确说："如果你们就是一个临时的、短期的、相对容易的，随便搞一搞就能搞成的，那些没必要非得用。" [conf=0.85, source=管理篇口述 L546-L548]

但反过来，"你们想追求比行业可能最 top 的水平还要往上再走一走" [conf=0.85, source=管理篇口述 L550]，假设思维就几乎不可替代。

## 支撑案例

| 替代路径 | 适用场景 | 风险 |
|:---|:---|:---|
| 抄同行 | 行业成熟、差异化不重要 | 同质化竞争，拿不到超额收益 |
| 降预期 | 资源有限、风险厌恶 | 长期降预期会锁定低增长 |
| 靠人 | 关键问题高度依赖个人经验 | 人走了，能力也没留下 |
| 靠经验 | 业务稳定、变化慢 | 经验失效时无预警 |
| 外包 | 非核心能力 | 核心认知被外部垄断 |

## 预警信号

1. 团队把"假设思维"挂在嘴边，但目标只是常规增长。
2. 一号位想用假设思维，但团队连基本的数据意识都没有。
3. 顾问/教练把替代路径一律贬低为"不科学"。

## 可迁移场景

- 战略选择：判断公司是"跟随者策略"还是"突破者策略"。
- 培训设计：针对不同层级的团队，选择不同的能力提升路径。
- 产品设计：判断新功能是"抄竞品"还是"做验证"。

## 行动建议

1. **今晚就做**：列出你当前最重要的 3 个目标，分别判断它们适合"替代路径"还是"假设思维"。
2. **本周内完成**：如果决定用假设思维，确认一号位决心、团队基础、周期容忍度三个条件是否齐备。
