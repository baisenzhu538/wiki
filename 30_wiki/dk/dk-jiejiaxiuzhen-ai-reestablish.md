# 借假修真在 AI 时代重立

> 一句话：**借假修真 = "做事奔着攒能力和资产去，事是假的，变强是真的"；但 AI 工具过时快，让"攒的能力"失效（AI 全是反串的）——直到找到 Feature（最小原子）才重立：攒 Feature 而非攒工具，用 10 年尺度的不变因素完成今天的决策。**

---

## 原始表述

> 「我不知道你们在做事的时候，更追求一种状态叫'借假修真'？追求吗？我解释一下，我这么多年之所以成长比较快的一个最重要的原因就是'借假修真'，就是我认为我做的所有事都是假的。我真正能留下来的，我的能力和我的资产才是真的。所以，所有做事我都是奔着我的能力和资产去做，所以我就很开心？所有事都可以扔掉，但是我变强了呀！成了败了，好了坏了，我都变强了呀！但是，我发现其实不行，这个 AI 全是反串的，全是反串的，所以咋办啊？」（口述 L1002-1004）

> 「后来直到有一天，我突然间想到，科学有个最基本的方法叫结构，我把它拆解成一个更小的单位，有没有可能拿这个更小的积木去做？后来我就找到了一个思路，叫特性，或者叫 Feature……Feature 是每一个技术工具背后的一个最小的一个小的原子，就是一个一个可操作的一个特性单位……就是工具都可以拆成一堆 Feature。就是我们把它找到一个最小的原子之后，这个原子是能够无限复用和迁移的。」（口述 L1010-1014）

> 「虽然我买了一个玩具，这个玩具变成另外一个玩具很难。但是如果它是个乐高呢？我是不是就能把乐高玩具拆开变成另外一个玩具，那就很容易。所以我能不能用乐高的心态来看待 AI？」（口述 L1016）

> 「决策，永远不要单纯的从眼下出发，努力的拉到五到十年的尺度，用一种攒牌的心态去构建它，借假修真，用十年的尺度的不变因素来完成今天的决策，这就是最重要的。」（口述 L1500）

## 使用场景

- 长期主义者面对快速变化的领域（AI 工具月月变、理念季季变），想积累"不会过时"的系统性优势
- 学了大量工具但发现"学新忘旧"，产生能力焦虑
- 需要回答"我该攒什么"——攒什么才能在 5-10 年后依然有效
- 做今天的决策时，想用长期不变因素来锚定

## 操作方法（≥3 步，照着能做）

1. **承认"事是假的"**：每个项目/工具使用都只是载体，真正留下来的是"能力和资产"。项目成功或失败都变强了——先建立这个心态。（锚点 L1002-1004）
2. **识别"AI 反串"**：AI 时代工具过时太快，攒下的"工具使用能力"很快失效——这就是"全是反串的"。此时不要停在焦虑里，进入下一步。（锚点 L1004）
3. **拆到最小原子（Feature）**：把工具/技术/框架拆成最小可操作的特性单位（Feature）——像把玩具拆成乐高积木，积木能无限复用和迁移。（锚点 L1010-1016）
4. **攒 Feature 而非攒工具**：从"学工具"转向"维护 Feature 集"——每次项目萃取有效 Feature 入库，用积木心态看待 AI，工具随便换，积木库是资产。（锚点 L1018：写了一个巨长的单子，保 30 争 50 个 Feature）
5. **用 10 年尺度做今天的决策**：面对选择时，问"哪个因素 5-10 年后依然不变"——用不变因素锚定今天的决策，这就是攒牌心态。（锚点 L1500）

## 适用边界

- **不适用于纯执行性任务**：只求快速交付（打短工）时不需要思考"攒什么"，直接干就行
- **Feature 抽取需要练习**：不是所有人一开始就能把工具拆成 Feature——需要刻意练习（口述 L1018：爆炸式灵感闪现，把 12 年经验逼着爆 30 争 50）
- **不适用于价值观/使命问题**：借假修真管"能力资产积累"，不管"该不该做某件事"（那是战略/价值观问题）
- **Feature 也会过时**：攒 Feature 比攒工具耐久，但 Feature 本身也在进化——需要持续更新 Feature 集

## 为什么值钱

- 直接解决长期主义者的核心焦虑：AI 变化太快，怎么积累"不会过时"的优势？（口述 L122 原问题：作为一个不愿意妥协的长期主义者，我们有办法积累系统性的优势吗）
- 反直觉点：**攒工具是"反串"的陷阱**——工具使用能力随工具迭代销毁；攒 Feature（最小原子）才能跨工具复用，是"不随模型/平台升级销毁"的资产（L1228）
- 与战略笃定直接挂钩：用 10 年不变因素完成今天的决策，就是"攒牌心态"——借假修真从个人能力哲学升级为战略决策方法

## Critique

**内部局限：**

1. 借假修真→Feature 的路径是 Truman 个人经验的归纳（12 年职场+1 年 AI），"拆到 Feature"不是唯一解法——有人可能通过"领域知识"或"人脉资产"获得长期复利。
2. "10 年不变因素"判断本身很难：今天认为不变的（如 Feature 思维）10 年后可能被新范式替代——需要周期性重估（Truman 的 Feature 集也是从保 30 争 50 迭代来的）。
3. 攒 Feature 有前期成本：爆炸式灵感闪现、逐次萃取都要时间，短期 ROI 为负——不适合急需短期结果的人。

**外部攻击者：**

**[工具实用主义者]**
> "攒 Feature 太抽象了，不如直接学好当下最好用的工具——工具能立刻出活，Feature 攒了半天也用不上。"

**回应**：这是"短期出活 vs 长期资产"的权衡。Truman 的实践是两者都要：当下任务照常用最好的工具（L1392：抓来就用），但**每做完一个项目就萃取 Feature 入库**——出活时不耽误，做完后资产沉淀。攒 Feature 不是替代学工具，是给工具使用加"资产化收尾"。

**[教育学者（迁移悖论）]**
> "把技能拆成最小原子再组合，是还原论——真实技能是整体涌现的，原子化组合未必能迁移（比如口喷基本功拆成 Feature 后还能练吗）。"

**回应**：Truman 的回应是"取长补短"（L1022-1024）：Feature 思维比原理派更具体、比模板派更抽象，恰好补在中间层——它不替代整体练习，而是给练习提供"可以刻意练的单元"。口喷基本功本身也是 Feature 组合（口喷是 Feature 之一，L888：口喷基本功、双三角能力、上下文知识库管理这些要素的占比越来越高）。还原论风险存在，但 Feature 是"练习单元"而非"能力本身"。

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 攒工具 | 学一个工具忘一个，工具更新就焦虑 | 转向攒 Feature——每个项目结束萃取有效 Feature 入库 |
| 只攒不练 | Feature 清单写了但从不刻意练 | 给 Feature 设练习计划（保 30 争 50 单子 + 逐项练） |
| Feature 抽取失败 | 拆了半天还是"提示词/上下文"这种大词，不是最小原子 | 用"乐高"标准自检：能不能和别的积木自由组合？不能就继续拆 |
| 被"反串"打击 | 发现攒的能力失效就全盘否定，停止积累 | 识别反串是信号不是终点——进入第 3 步拆 Feature |
| 用短期结果否定长期积累 | "学了 Feature 还是做不好当下项目" | 分清当下出活（用工具）和长期资产（攒 Feature）两条线，不混为一谈 |
| 把"10 年不变"当口号 | 嘴上说攒牌，决策还是看眼前 | 每个重大决策前强制问：这个因素 5-10 年后还在吗？（L1500） |
