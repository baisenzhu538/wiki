# 单元模型对抗小抄

## 原始表述

对抗小抄是规模对抗环节的速查工具，把 30 种常见对抗策略按「升级人工 / 升级管理 / 升级业务」三类整理成卡片，帮助创业者在识别规模不利要素后快速找到可参考的对冲动作 [conf=0.85, source=原图]。

## 使用场景

- 完成规模对抗要素扫描后，需要快速生成候选对策；
- 团队头脑风暴时，用结构化清单避免遗漏策略方向；
- 向投资人/高管汇报时，展示对冲策略的系统性与可操作性；
- 设计组织升级/业务升级方案时，作为策略灵感库。

## 操作方法

对抗小抄分为 A/B/C 三类，使用时按以下步骤：

1. **识别不利要素属于哪一类**：是人太贵/太稀缺？管理跟不上？还是业务结构本身规模不经济？
2. **在对应类别中挑选候选策略**：A 类（升级人工）10 条、B 类（升级管理）10 条、C 类（升级业务）10 条。
3. **评估策略与自身业务的匹配度**：不是每条都适用，需要结合行业、阶段、资源判断。
4. **组合 2-3 条策略形成对冲方案**：单一策略往往不够，需要人工+管理+业务的组合。
5. **为每条选中策略设定追踪指标**：如替代率、SOP 覆盖率、标准化产品占比等。

## A 类：升级人工策略 Top10

| 策略 | 一句话解释 | 典型操作 |
|:---|:---|:---|
| A1 拆解一号位 | 把创始人/关键人物的核心能力拆解为可复制的流程或模板 | 复制 Truman、复制做课能力、复制创意能力 |
| A2 替代顶级 IP | 降低对单一真人 IP 的依赖 | 真人 IP 动漫化、IP 矩阵、IP 逐字稿 |
| A3 替代顶级专家 | 把专家经验转化为可复制的判断能力 | 复制选品能力、复制选址能力 |
| A4 替代专家顾问 | 把咨询式服务转化为标准流程 | 复制咨询式销售、复制 FA 顾问 |
| A5 替代职场白领 | 把白领工作工业化 | 工业化复制主播、复制售后客服 |
| A6 自动化 | 用自动化工具替代重复人工 | 自动发货、自动客服、自动检测 |
| A7 算法化 | 用算法替代经验判断 | 算法预测房产估价、算法预测农业亩产 |
| A8 系统化 | 用系统承载业务流 | 量化交易系统、爬虫系统、论文查重、学分激励系统 |
| A9 AI 化 | 用 AI 替代人工交互 | AI 文字客服、AI 电话客服 |
| A10 机器化 | 用硬件替代人工劳动 | 仓库机器人、餐厅机器人、ETC 收费设备 |

| 策略 | 一句话解释 | 典型操作 |
|:---|:---|:---|
| B1 做文化建设 | 让员工保持文化一致，塑造做事文化 | 使命/愿景/价值观落地 |
| B2 苦练基本功 | 拆解基本功并全员统一练习 | 销售团队、连锁门店、社群运营基本功训练 |
| B3 做培训体系 | 实施新人落地与日常培训 | 新员工第一天落地、团队每月培训 |
| B4 做目标管理 | 让员工清晰理解目标，更好完成业绩 | OKR/KPI/OGSM 制度 |
| B5 做耕耘绩效 | 公平的收入制度，激励员工持续提升 | 职级划分、岗位晋升、绩效制度 |
| B6 搭建 IT 系统 | 用系统搭建业务流，提升效率 | 分解任务节点、流程化、数据化 |
| B7 搭建数据库 | 收集关键数据，为决策提供依据 | 内部字典、线索库、统一数据库 |
| B8 搭建知识库 | 把团队能力沉淀在知识库里 | 萃取知识、流程、模板、方法论 |
| B9 工业化流程 | 拆解关键环节，用加/减法替代经验和手感 | 选品、选址、做课、做脚本、写文案 |
| B10 善用 SOP | 把确定性工作 SOP 化，稳定执行 | 班主任服务 SOP、奶茶制作 SOP |

## 适用边界

- 不适合未验证单元模型的业务：策略再丰富，也救不了基本盘不成立的模式。
- 不适合一次性套利业务：不需要体系化升级，只需抓住窗口期。
- 不适合高度依赖个人品牌的业务：A 类替代策略可能损害品牌价值。

## 为什么值钱

规模对抗时，创业者容易陷入「只会加人加钱」或「只会砍成本」的二元思维。对抗小抄的价值在于：它把 30 种已被验证的对冲策略结构化呈现，帮助团队快速跳出本能反应，找到更适合的组合方案 [conf=0.75, source=一堂原创]。
