# 技能：设计对抗效果追踪看板

## 原始表述
> 设计「对抗效果追踪看板」：选定2-3个核心指标（如人均服务带宽、标准化覆盖率、管理杠杆率），定期追踪策略实施前后的变化

## 操作步骤
1. 选定2-3个核心指标（如人均服务带宽、标准化覆盖率、管理杠杆率）
2. 建立基线数据（策略实施前）
3. 实施对抗策略
4. 定期追踪指标变化
5. 对比前后数据判断策略有效性
