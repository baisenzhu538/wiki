# 技能：销售智能体体系搭建路径

## 原始表述

销售智能体体系搭建路径是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 明确边界：放弃'面向全体销售的一个智能体'，接受需要数千个细分智能体
2. 提炼方法论：将销售方法转化为可数据化、可反馈验证的体系（如N销售法）
3. 解决数据采集：通过销售工牌等硬件实现过程数据自动化录入
4. 数据处理：清洗、标注、建立反馈闭环（哪些方法有效/无效）
5. 模型微调：基于行业特定数据训练专用模型
6. 持续实验验证：大量实验验证方法有效性，非讲课可替代
