# 讲香十指模型：超级武器库

## 一句话定义

**讲香十指模型**是把表达力拆解为十种可训练的具体技能，像十根手指一样各有分工，组合使用形成完整的表达武器库 [conf=0.78, source=原图]。

## 十指武器

| 手指 | 技能 | 作用 |
|:---|:---|:---|
| 拇指 | 结构化框架 | 搭骨架，让表达有逻辑 |
| 食指 | 故事力 | 指方向，让人跟着你的思路走 |
| 中指 | 数据力 | 撑场面，数字最有说服力 |
| 无名指 | 类比力 | 建立连接，把陌生的变熟悉 |
| 小指 | 节奏感 | 控制情绪起伏，不让人走神 |
| + 五感具象、金句提炼、画面感、悬念设置、互动设计 | | |
