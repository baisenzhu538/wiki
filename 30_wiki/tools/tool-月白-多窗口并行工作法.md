# 技能：多窗口并行工作法

## 原始表述

多窗口并行工作法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 产品图生成一个窗口
2. 风格参考/提示词优化另开新窗口
3. 改图/扩图再开新窗口
4. 遇到生成效果偏离预期时，不纠结调整，直接新开窗口重来
