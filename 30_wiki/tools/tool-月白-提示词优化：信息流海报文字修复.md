# 技能：提示词优化：信息流海报文字修复

## 原始表述

提示词优化：信息流海报文字修复是月白在AI设计基础中提出的实操方法。

## 操作步骤

1. 生成基础海报后发现中文文字错误
2. 不修改其他提示词
3. 直接追加一句：'用最高分辨率重新生成这张图，修改中文中的文字错误'
4. 重新生成

## 为什么有效
