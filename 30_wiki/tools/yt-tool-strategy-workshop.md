# 战略研讨会引导手册

> 来源：从 [[yt-management-strategy-meeting]] 概念卡萃取的工具内核。一套完整的战略研讨会开会指南——从会前准备到会中引导到会后产出，防止战略会沦为汇报大会或老板一言堂。

## Summary

战略研讨会引导手册是一套完整的开会指南。核心主张：大多数公司的战略会要么没开（用日常运营替代战略思考），要么开错了（陷入细节讨论、变成汇报大会、会后没有结论）。本工具卡交付：会前四件套 → 会中五段式 → 会后三检查——每个阶段都有进入标准、操作步骤和退出标准。

---

## 进入标准（When to Use）

| 场景 | 信号 |
|------|------|
| 新年度/新半年开始前 2 周 | 日历提醒"下月是 QX 第一个月" |
| 公司或业务 pivot 后，需要重新定向 | "我们是不是走偏了"、"竞品的动作我们没预料到" |
| 上一轮战略执行到中途发现根本假设错误 | 季度末复盘时"方向 A 的撤销条件触发了" |
| 融资前/合伙人分歧前，需要形成方向共识 | 开年会/投资人会议前夕 |

**不满足进入标准**：公司处于"生存模式"——现金流只够 3-6 个月（不是"战略有问题"是"活不活得下去"的问题）、上一次战略会的决策还没有执行完（先执行再讨论，否则战略会变成干讨论）。

---

## 操作步骤（Step-by-Step）

### 第一部分：会前四件套（会议前 2 周）

**目的**：确保战略会不是"现场活动局胃口"，而是"有了深入准备后的有效讨论"。

#### 四件套 #1：Rumelt 式前置诊断

会议前 1 周，让每个参会者（包括一号位）独立写下三个问题的答案（不超过 1 页纸）：

```
【Rumelt 前置诊断】
Q1：你认为我们当前最大的瓶颈是什么？_____
Q2：你认为我们拥有什么独特的不对称优势？_____
Q3：如果现在立刻砍掉我们 50% 的业务——你会保留哪一半、砍掉哪一半？_____
```

**会上第一个动作：先贴所有人的答案。看差异有多大**——差异本身才是最该被讨论的战略议题。

- 三个人对"最大瓶颈"的回答指向完全不同的方向 → 最大收获，讨论这个差异
- 三个人的回答完全一致 → 可以压缩会议时间到 2 小时，直接执行

#### 四件套 #2：信息预备

会议前 1 周，准备以下材料（不是 PPT，是"信息背景版"）：

- 市场数据：行业规模、增长率、竞品动态（非自己公司的数据，是外部世界的数据）
- 用户信息：近 6 个月最重要的 3 条用户反馈
- 财务情况：现金流、收入结构、成本趋势
- 组织能力：团队规模、关键人员能力评估、技术债务

**禁止**：不准带部门工作汇报。这不是汇报大会。

#### 四件套 #3：参会者筛选

| 角色 | 数量 | 作用 |
|------|------|------|
| 一号位（最终决策者） | 1 | 拍板权，会议结束时做最终决定 |
| 核心管理层 | 3-5 人 | 参与讨论和质询 |
| 中立方（可选） | 0-1 人 | 外部视角，投资人/顾问 |

**红线**：参会者 >8 人 = 汇报大会；参会者 <3 人 = 缺乏多元视角。

#### 四件套 #4：场地选择

- **必须离开办公室**——熟悉的环境触发熟悉的思维模式
- 安静、可以集中注意力的空间（不是餐厅）
- 可以写字/贴便利贴的墙面或白板
- 会议室规格：能容纳所有参会者的圆桌或 U 形排座（不是老板在台上的会议室）

---

### 第二部分：会中五段式（会议当天，1-2 天）

**核心策略："发散要足够发散，收敛要足够收敛"。**开会不是演讲，是——让每个人的智慧都被调动起来。

#### 第一段：设定规则（15 min）

老板开场：
1. 明确会议目标："今天我们要产出什么"——不是"讨论战略"，是"讨论并锁定下一阶段的战略方向"
2. 明确决策机制："谁有最终拍板权？如果最终决定不能获得全员认同，如何处理？"
3. 明确反弹规则：打断要么用数据、要么用逻辑——不能用"我觉得"
4. 禁止手机：会议期间手机放在另一个房间

#### 第二段：信息输入（1-2 hours）

**目的**：建立"我们站在哪里"的共享事实基础。

**流程**：
1. 外部环境（20 min）：一个人分享行业趋势/竞品动态/市场数据
2. 内部现实（20 min）：一个人分享公司最新财务/业务数据
3. 用户声音（20 min）：分享 3 条最重要的用户反馈
4. 围绕白板（30-40 min）：每个人写 1 张便利贴"我觉得我们的最大机会是 X，最大威胁是 Y"，全部贴上墙，所有人看一遍所有便利贴（不讨论，只观看）

**红线**：信息输入阶段不讨论、不评论、不辩论——只是信息共享。

#### 第三段：战略讨论（主要时间，3-5 hours）

**目的**：从发散到收敛，产出 2-3 个核心选项及其利弊分析。

**发散阶段（第一小时）**：
- 第一问："如果我们什么都不做——只做一件事，这件事应该是什么？"
- 第二问："如果我们有无限的资源，我们会做什么？"
- 第三问："如果我们只有现在 50% 的资源，我们会剪掉什么？"
- 每个人写出 3 个方向建议，贴上墙，所有人看

**收敛阶段（第二小时起）**：
1. 分类：将墙上的所有建议分类——相似的放在一起
2. 聚焦：投票出 Top 3 方向（不是最终决定，是收敛圈子）
3. 利弊分析：对每个 Top 3 方向，全体讨论：
   - 如果我们走这个方向，成功的关键因素是什么？（我们控制得了吗？）
   - 如果这个方向失败，最可能的失败模式是什么？（我们能提前翇制吗？）
   - 这个方向和我们的能力匹配度如何？
4. 强迫取舍："如果我们必须砍掉 2/3 的方向——只留 1 个，哪一个？"

**关键原则**：
- 讨论中不准说"我觉得"——要么用数据，要么用逻辑
- 正反方论证：每个方向必须有一个人担任"恶魔提醒"——专门负责说这个方向为什么不对
- 不许人身攻击：可以攻击观点，不能攻击人

#### 第四段：决策锁定（1-2 hours）

**目的**：明确拍板，产出"战略决策纪要"。

**决策仪式**：
1. 一号位总结三个选项的核心利弊（不是重复讨论，是总结）
2. 一号位发表最终决定："我们选择方向 A。理由是：X。我了解方向 B 和 C 也有价值，但在当前资源约束下，A 是最优解。"
3. 异议录入：让每个有异议的人公开说："我的异议是 ____，我判断如果 X 发生，这个决策可能是错的"
4. “不同意但执行"（Disagree and Commit）：最终决策锁定后，所有人承诺全情投入执行（即使之前有异议）

**禁止**：不准说"我们再讨论讨论"——必须有结论。有异议没关系，没决策是级别错误。

#### 第五段：行动计划（30 min）

**目的**：将方向转化为具体行动。

1. 在答应下半年/下一季度的 3 个关键动作
2. 财务对比：这些动作需要多少资源？我们有吗？
3. 责任人分配：每个关键动作的负责人是谁？
4. 撤销条件："我们选择了方向 A，如果 Q2 结束时 ____ 没有发生，我们重新开战略会"——**每次战略会的最后一个产出不是"关键动作"，是"撤销条件"。**

---

### 第三部分：会后三检查（会议结束后 72 小时内）

**目的**：确保战略会的产出不是"开完就算了"，而是"真正进入执行"。

#### 会后检查 #1：战略决策纪要（会后 24h 内）

**必须包含**：
- 战略方向（一句话）
- 选择理由（3-5 条）
- 放弃的方向（为什么不选）
- 异议档案（每个异议的内容和判断条件）
- 撤销条件（3 条）
- 下一步行动（3 个关键动作 + 负责人 + DDL）

**发布**：发给全体参会者确认，修改完成后再发给全公司。

#### 会后检查 #2：传达计划（会后 48h 内）

如何向全公司传达战略决策？

- **全体大会**（必须）：一号位親自讲解，不是发邮件。讲清楚"为什么选这个方向"、"放弃了什么"、"对你们意味着什么"
- **部门会议**（必须）：每个部门用 1 小时讨论"这个战略对我们部门意味着什么"，产出部门级行动计划
- **OKR 对齐**（必须）：将战略方向转化为公司级 OKR（[[yt-tool-okr-cycle]]）

**红线**：战略会的决策如果只停留在参会者脑子里——它等于没有被做出来。

#### 会后检查 #3：撤销条件监控（每周）

**设置 3 个信号灯**，每周团队会议首项议程：

```
撤销条件监控仪式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
周会第一个议题（5 min）：

红灯：如果 ____ 发生了 → 立即重新召集战略会
黄灯：如果 ____ 的趋势继续 → 下周讨论是否需要调整
绿灯：如果 ____ 指标在轨 → 不需要额外讨论，继续执行

规则：
- 红灯触发了必须停下所有事情重新讨论
- 黄灯继续两周后自动变成红灯
- 绿灯不能让人安心——绿灯只是"暂时不需要讨论"，不是"我们对了"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 退出标准（Done When）

| 检查项 | 标准 |
|--------|------|
| 会前 | Rumelt 前置诊断已完成，参会者答案差异已记录 |
| 信息 | 会议前已准备市场数据、用户反馈、财务情况、组织能力信息 |
| 参与 | 参会者 3-8 人，离开办公室，有中立方人员 |
| 会中 | 完成五段式：设定规则 → 信息输入 → 战略讨论 → 决策锁定 → 行动计划 |
| 异议 | 异议已被记录，并录入战略决策纪要 |
| 撤销 | 已设定 3 个撤销条件，并开始周度监控 |
| 会后 | 战略决策纪要已发布（会后 24h 内） |
| 传达 | 全体大会 + 部门会议 + OKR 对齐已完成（会后 48h 内） |

**最小可行版本**：第一次使用只做"会前 Rumelt 诊断" + "会中第三段战略讨论"（只问一个问题："如果只做一件事，是什么？"）+ "会后纪要"（只写方向 + 撤销条件）。跑通一次后再加载完整流程。

## 常见陷阱（Pitfalls）

| 陷阱 | 信号 | 对策 |
|------|------|------|
| **汇报大会化** | 每个部门轮流讲 PPT | 禁止部门工作汇报；只对外部信息做整体输入 |
| **一言堂化** | 老板讲一半，其他人听 | Rumelt 前置诊断确保每个人都在会前提交了独立思考；会个人必须贡献观点 |
| **只有加法没有减法** | 讨论了很多方向，但没有明确放弃什么 | 强迫取舍："如果只能选 1 个，是哪个？"——战略的本质是跟别人"不一样"，不是"都一样好" |
| **开完就算了** | 会后没有纪要、没有传达、没有行动计划 | 会后 72h 内必须发纪要 + 完成传达 + 设置撤销条件 |
| **无撤销条件** | 战略会产出了方向 + 行动计划，但没有"什么信号意味着我们错了" | 每次战略会最后一个产出必须是"撤销条件"，并且每周监控 |
| **异议被打压** | "Disagree and Commit"变成“闭嘴照做”的礼貌版 | 异议档案：每个异议必须写进纪要，下季度复盘第一条过这些异议 |
| **信息不对称下的伪共识** | 表面上一致，实际上每个人对共识的理解不同 | 会后让每个人用自己的话重复战略方向——如果重复版本有轨迹不同，回来补充传达 |
| **日常浸入战略会** | 会议在办公室开，随时被拉走处理"紧急事务" | 必须离开办公室；手机放另一个房间 |

## 外部攻击

### Clayton Christensen：你的战略会可能正在加深你的"创新者困境"

**Clayton Christensen**（哈佛商学院，*创新者的困境* 作者）的核心论点：成功的公司之所以失败，不是因为管理层变笨了，而是因为它们循环了一套完美合理的决策流程——在每个关键节点都做了正确的决策，但累积结果是死亡。

对战略研讨会手册的攻击：你的手册设计了一套精美的流程来制定战略：信息输入 → 讨论 → 决策 → 执行。但 Christensen 会问：你的流程有没有一个环节是"如果我们现在做的一切都是错的，那个行业里有什么小幾率事件正在发生但被我们忽视了？"？如果没有这个环节，你的战略会会系统性地护卫现有业务——而忽视低端市场的威胁（就是这个威胁杀死了几乎所有大公司）。每个战略会的第一个问题不应该是"我们往哪走"——应该是"什么东西正在杀死我们，但我们还没看到"。

> **Christensen 的拷问**："你的战略会产出了一个精彩的战略方向，团队加油打气。但 Christensen 会问：这个方向是不是只是你现有业务的延续和强化？如果是——你已经在创新者困境的通道上了。每次战略会，请特意留出 30 分钟给这个问题："如果有一个在我们视角之外、但能夠消灭我们的威胁正在发生——它是什么？"如果你们无法回答这个问题，你们开的不是战略会，是自我安慰会。"

### Nassim Taleb：你的战略是在假装预测未来——而未来是不可预测的

**Nassim Taleb**（＊The Black Swan* 作者）的核心论点：战略规划的本质是"基于对未来的预测做出资源配置"。但 Taleb 指出：我们的预测能力在复杂系统中几乎为零，特别是对于"黑天鹅"事件（低概率、高影响、事后被“带赤化”为可预见）。

对战略研讨会手册的攻击：你的手册设计了"信息输入 → 讨论 → 决策 → 执行"的线性流程，并交付了"撤销条件"来应对不确定性。但 Taleb 会问：你的"撤销条件"是不是只是"如果 X 发生了就停止"？而不是"如果 X 发生了，我们有多少反鞭能力"？Taleb 的核心区分：不是说不要做战略规划，而是说**战略的核心不是"跟战略对赌"，是"让自己在任何战略都失败的情况下都能活下来"——即反鞭性（antifragile）。**你的战略会不是在讨论"我们选哪个方向"，它应该是在讨论"我们怎么让自己在无论选哪个方向失败的情况下都有回旋余地"。

> **Taleb 的拷问**："你交付了一个精彩的战略研讨会手册，会前有诊断、会中有论证、会后有撤销条件。但 Taleb 会问：你的撤销条件是不是讨论了'如果方向错了怎么办'？还是讨论了'我们有多少避免死亡的红线'？如果是前者——你还在假装未来是可预测的。如果是后者——你还在假装未来是可预测的，但至少你知道自己在假装。"

## 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **公司处于"生存模式"——现金流只够 3-6 个月** | Rumelt 指出：战略需要"有选择余地"才能生效。当公司只有一条路可走时，战略讨论是个伪命题——你需要的不是诊断局势中的不对称性，你需要的是最快的收入进来。 | 不开战略会。用"生存三问"替代：① 接下来 30 天哪 3 个客户最有可能付钱？② 哪些成本可以立即砍掉？③ 如果有机会把 runway 延长 2 个月——我们愿意付出什么代价？三个问号在一个下午内出答案，然后所有人去执行。活下来以后才配开战略会。 |
| **战略会产出了清晰的决策，但执行 3 个月后发现当初的假设全错了** | Porter 的活动系统理论在此刻提供一个重新理解：你做的不是"执行战略"，你做的是一个"战略实验"。实验失败了不是问题——问题是你的战略会没有预先定义"什么信号意味着我们应该重新讨论"。 | 每次战略会的最后一个产出不是"3 个关键动作"，而是"3 个撤销条件"：如果 Q1 结束时 ____ 没有发生，说明我们的战略假设是错误的，我们立即重新召集战略会。同时定义"看什么数据来判断"——不是等季度末才发现偏航，是每周盯住那 3 个信号的趋势。 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---------|-----------|---------|
| **第一次组织战略会，不确定方向是否正确——担心"花一天时间开完发现产出的只是老板想法的精致包装"** | Rumelt 式前置：在开会前 1 周，让每个参会者（包括一号位）独立写下三个问题的答案（不超过 1 页纸）——"① 你认为我们当前最大的瓶颈是什么？② 你认为我们拥有什么独特的不对称优势？③ 如果现在立刻砍掉我们 50% 的业务——你会保留哪一半、砍掉哪一半？"开会时先贴所有人的答案，看差异有多大——差异本身才是最该被讨论的战略议题 | 三个人对"最大瓶颈"的回答指向完全不同的方向——这本身就是最大收获。如果三个人的回答完全一致——你不需要开战略会，你需要直接执行，会议时间压缩到 2 小时 |
| **上季度的战略决策执行得很差——团队说"方向没问题，是执行的问题"** | Porter 式活动系统诊断：画一张图——中间写战略方向，四周列出所有组织活动的卡片（产品、销售、市场、客服、招聘、财务）。逐条问"这个活动为这个战略方向改变了什么？"如果 ≥50% 的活动在战略会后没有任何改变——不是"执行的问题"，是你的战略从未被翻译成活动系统。方向没有带动执行 → 方向是空气 | 至少识别出 3 个"战略选了 A 但活动的设计仍然在为旧方向 B 服务"的错位。下个季度至少纠正 2 个 |
| **战略会讨论激烈、每个人都有不同意见——最终一号位拍板"就这么定了"，但散会后有人小声说"我觉得不对但我懒得说了"** | 不用"Disagree and Commit"口号（喊多了变成"闭嘴照做"的礼貌版）。做"异议档案"——在战略会结束前，让每个有异议的人公开说"我的异议是什么、我判断在什么条件下这个决策可能会错"。把这些异议写进战略决策纪要，下季度复盘时第一条就过——"当初张三说如果 X 发生这个决策就会错——X 发生了吗？" | 下一季度复盘时，至少有 1 条"异议被事后证明是对的"被公开承认——不是为了打谁的脸，是为了证明"当时提异议是安全的、有价值的"。如果连续两个季度"一条对的异议都没有"——要么异议者不够诚实，要么没人真的在思考 |
