# AI辅助分析

> 把大量数据/文本输入AI，让它做模式识别、异常检测、趋势分析，再由人类核验关键数据点和商业归因。

**适用场景**：批量评论情感分析、竞品功能对比矩阵、财报数据的跨公司横向比较、销售线索聚类、用户行为异常检测。

**核心原则**：AI负责「算得快、看得宽」，人类负责「问对问题、判对因果」。

## Purpose

本工具用于把结构化或非结构化的大规模数据交给AI进行模式识别、分类、聚类、异常检测与趋势归纳，帮助研究者或决策者快速从噪音中提取信号。它特别适合重复性强、维度多、人工处理成本高的分析任务，例如批量评论情感分类、多竞品参数对比、财报横向比较等。AI辅助分析不能替代人类的商业判断，但能显著压缩「从原始数据到可讨论假设」的时间。

## Protocol

1. **定义分析目标与假设**：在喂数据前，先用一句话说清要回答什么问题、验证什么假设、输出什么形式。例如：「对比5家竞品在2024年的毛利率变化，并标注异常波动」。
2. **准备并清洗原始数据**：将数据整理成表格、文本块或CSV格式，删除明显错误、重复或敏感字段。 humans 先确认数据质量，再交给AI。
3. **选择分析框架并写提示词**：给AI明确的维度、分类标准、输出格式和约束。例如：「按A/B/C三个维度对比，输出Markdown表格，并标注数据来源」。
4. **执行AI分析并获取初稿**：让AI按框架输出结果，同时要求它列出关键数据点的出处或依据。
5. **人工核验与攻击性审查**：检查AI输出的数字、归因和结论。追问：「如果这个结论是错的，最可能的原因是什么？」「有没有反例？」
6. **迭代优化与归档**：根据核验结果补充数据、调整框架或重新运行，最终把可信结论写入研究笔记。

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|:---|:---|:---|
| 数据样本量极小（<30条） | AI的模式识别优势无法发挥，人工反而更快更准确 | 人工逐条阅读+简单Excel统计 |
| 数据质量差、缺失严重 | AI会被偏差和噪声误导，输出「精致的错误」 | 先补数据清洗或补充一手采集 |
| 需要严格因果推断 | AI擅长相关性归纳，不擅长识别因果机制 | 引入统计回归、实验设计或专家访谈 |
| 涉及高度敏感商业机密 | 上传至外部AI服务存在泄露风险 | 使用本地部署模型或脱敏后分析 |
| 分析框架本身需要重新设计 | 如果人类自己都说不清楚维度，AI只会套模板 | 先用 [[framework-yitang-high-level-plan]] 锁定目标 |

## 质疑

- **具体假设是否被显式列出？** AI分析容易隐藏前提。例如「评论情感整体偏正面」可能假设了评论样本没有水军刷单。
- **边界在哪里？** 本工具适用于可量化、可分类的数据，但不适用于需要深度因果解释或实地体感的复杂商业问题。
- **反例是否被主动寻找？** AI倾向于给出最显著的 pattern，可能忽略小概率但高影响的异常。必须要求它输出「不符合该模式的案例」。
- **前提是否成立？** AI辅助分析的前提是「人有判断力」。如果研究者本身不了解业务上下文，AI的输出再漂亮也只是正确的废话。

> **外部攻击者：Michael Porter** 会指出，AI辅助分析只能告诉你「现在有什么模式」，但无法告诉你「为什么这个模式能形成可持续竞争优势」。竞争优势来自价值链活动和进入壁垒，而不是数据聚类结果。
