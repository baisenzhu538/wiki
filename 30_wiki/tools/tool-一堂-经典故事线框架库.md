# 一堂经典故事线框架库：N个为什么/清单体/时间线/BP模板/顾问式销售

> **一句话**：不要老想着发明故事线，先用 proven 框架——**N 个为什么、清单体、时间线、一堂 BP 模板、顾问式销售**；努力在“假山”上探索，不要在模板上创新。（`组合篇-口述:3234-3384`）

---

## Purpose

解决“做转化内容时从零开始写故事线”的低效问题。提供高频、经过验证的叙事框架，让团队把精力放在填内容，而不是造结构。

适用场景：
- 写招生文案、销售话术、路演 PPT、短视频脚本
- 一对一咨询/销售
- 融资 BP 或项目路演

---

## Protocol

### 五种经典框架

| 框架 | 结构 | 最适合 |
|---|---|---|
| **ABACC** | Attention → B → A → C → C | 非标品/非高科技短视频/短文案 |
| **N 个为什么** | 为什么需要？为什么靠学习？为什么选你？为什么现在？ | 逻辑说服、复杂产品 |
| **清单体** | N 个理由 / N 个特权 / N 个加速器 | 续费、招募、特权说明 |
| **时间线** | 先怎样，再怎样，最后怎样 | 讲故事、案例、历程 |
| **一堂 BP 模板** | 融资级商业故事线 | 融资、要资源、项目路演 |
| **顾问式销售** | 现状 → 问题 → 后果 → 价值 → 成交 | 一对一销售、咨询、问诊 |

> “一堂官方的 BP 模板……帮助小 1000 个项目拿到融资……不要老惦记着在模板上创新。”（`组合篇-口述:3334-3370`）

### 选择建议

1. 先判断受众已有需求程度：无需求→ABACC；有需求→N 个为什么/清单体。
2. 判断信息复杂度：简单→清单体/时间线；复杂→BP 模板/顾问式销售。
3. 先套现有框架，填满、测完，再考虑微调。

---

## Anti-patterns

| 反模式 | 症状 | 修复 |
|---|---|---|
| **硬发明新模板** | 团队自己造故事线，效果远不如 proven 框架 | 先套 5 个经典框架 |
| **一个框架走天下** | 所有物料都用清单体，缺乏变化 | 按受众/场景/复杂度选 |
| **套用但不理解** | 套了 BP 模板，但讲不清楚核心问题 | 先回答 N 个为什么 |
| **忽视时间线** | 复杂价值没有先后次序 | 用时间线/ABACC 拉节奏 |

---

## When NOT to Use

- 品牌广告需要强烈差异化形式时：可以突破模板，但需先证明现有框架真的不够用。
- 时间极紧、团队不熟悉任何框架时：先用最熟的清单体。
- 内部框架尚未被充分验证时：不要把它当成“内部最佳实践”推广。

## Critique


**Peter Drucker**（管理学大师）会质疑：模板提供的是纪律，但战略传播需要的恰恰是“对情境的敏感判断”。过度依赖模板会让组织丧失应对新受众的能力。
- 经典框架是归纳出来的，不一定覆盖未来的新媒介（如 AI 生成内容）。
- “不要在模板上创新”是对初学者的保护，但对高手可能是束缚。
- 内部框架陷阱：团队容易把“熟悉”当成“最好”。

## 案例区：经典故事线框架库口述案例

### 案例 1：N 个为什么——说服用户选择一堂

> 四个问题：你真的需要学吗？有短板为什么要靠学习解决？为什么靠一堂而不是同行？为什么今天立刻马上？（`组合篇-口述:3276-3308`）

### 案例 2：清单体——续费理由

> “续费的三个理由：理由一、理由二、理由三”“MA 专属特权：全一、全二”——最简单，不会犯大错。（`组合篇-口述:3312-3320`）

### 案例 3：一堂 BP 模板

> “如果你们真正想去讲融资类项目故事，这个模板应该是全网最好的故事线……帮助小 1000 个项目拿到融资。”（`组合篇-口述:3334-3338`）

### 案例 4：顾问式销售

> “先了解现状，再挖掘背后问题和挑战，再理解挑战带来的后果，最后探讨价值……通过提问一层层去挖。”（`组合篇-口述:3340-3342`）

### 案例 5：不要发明模板

> “努力在假山上探索，不要在模板上创新……你们都不能解读商业计划书到底好在哪，自己发明出来不可能超过我们的模板。”（`组合篇-口述:3364-3380`）
