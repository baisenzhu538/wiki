# 武器库策略11：第三方数据库

> 公开可访问的数据库——整理成清单，随用随查。

## 15类核心数据源

| 类型 | 代表 | 能查到什么 |
|:---|:---|:---|
| 国家数据 | 国家统计局/工信部 | 宏观数据 |
| 趋势数据 | 行业指数/趋势报告 | 行业走向 |
| 行业报告 | 艾瑞/易观/QuestMobile/Gartner | 行业分析 |
| PC数据 | PC端行业资讯 | 传统互联网 |
| APP数据 | 应用宝/360/小米/AppStore | 移动端数据 |
| 行业数据 | 七麦/点点数据 | 应用排名 |
| 微信指数 | 微信指数/微小宝/新榜 | 社交热度 |
| 百度指数 | 百度搜索/关键词 | 搜索趋势 |
| 工商数据 | 天眼查/企查查 | 公司信息 |
| 融资数据 | IT桔子/Crunchbase | 融资动态 |
| 电商数据 | 蝉妈妈/灰豚/飞瓜 | 电商销售 |
| 专利数据 | 国家知识产权局 | 技术布局 |
| 法院公告 | 裁判文书网 | 法律风险 |
| 招投标 | 政府采购网 | 客户和订单 |
| 社交媒体 | 微博/小红书/抖音 | 舆情和口碑 |
