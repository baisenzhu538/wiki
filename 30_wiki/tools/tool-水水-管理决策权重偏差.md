---# 技能：管理决策权重偏差

> 水水在拆书会中提出的决策改进方法。解决"明明列出了所有决策因素，但权重分配完全是自我服务"这个普遍但少有人正视的问题。

## 操作步骤

1. **显式列出所有决策因素**：把影响因素全部写出来——不要筛选，越多越好。包括"说不清为什么但感觉很重要"的因素。这一步的目标是穷尽，不是精确。

2. **三次独立分配权重**：给每个因素分配 1-10 的权重，做三次——(a) 第一次凭直觉 (b) 第二次想象"一个比你年长 10 岁、阅历更丰富的人会怎么加权" (c) 第三次想象"10 年后的你自己回头看这个决策会怎么加权"。三次结果取中位数。

3. **邀请外部视角评估权重合理性**：找一个了解你但不在你的处境中的朋友。不要问他"我该选哪个"，而是问他"你看我列的这些因素，有没有哪个因素我给得太高了？有没有哪个给得太低了？"——后者更难被"讨好你"的动机污染。

4. **用时间距离检验**：对权重最高的前 3 个因素，问自己："如果把这个决策推迟 1 年再做，这 3 个因素的权重会变吗？如果会，怎么变？"如果某个因素的权重随时间大幅下降（如"现在的老板答应给我涨 20%"），警惕——这是短期偏差在主导。

5. **记录决策时的权重分配**：把最终权重写下来，标注日期。6 个月或 1 年后回看——"我当时认为最重要的 3 个因素，现在看还是最重要的吗？"这个回看本身就是偏差校准训练。

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 职业选择（换工作、转行、创业 vs 打工） |
| ✅ 适合 | 投资决策（买房、大额投资、创业投入） |
| ✅ 适合 | 重大人生决定（搬家、结婚、生育） |
| ✅ 适合 | 团队资源分配（多个项目抢资源时的优先级排序） |
| ❌ 不适合 | 日常微决策（今天吃什么、穿什么） → 权重分配成本超过收益 |
| ❌ 不适合 | 纯技术决策（选A还是B有客观指标） → 用数据而不是权重 |
| ❌ 不适合 | 紧急决策（10分钟内必须决定） → 没时间走五步流程 |
| ❌ 不适合 | 不可通约的价值观冲突（薪资 vs 意义感） → 强行量化制造偏差 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **权重偏差** | 列出决策因素但权重分配明显偏向短期收益 | 执行三次独立分配权重：直觉版/年长者版/十年后版，取中位数校准 |
| **分析替代直觉** | 做了分析但最后还是凭直觉选 | 分析的价值不在替代直觉而在让直觉被充分检视，只要发现偏见就有价值 |
| **视角切换失败** | 直觉版、年长版、十年后版权重几乎相同 | 第三次时先闭眼10秒，真正想象自己老了十岁的生活状态，再开始加权 |
| **因素遗漏** | 只列了3-4个显而易见的因素，遗漏隐性因素 | 强制至少列出8个因素，不够8个去看别人做类似决策时考虑了哪些因素 |
| **不可通约量化** | 薪资和意义感被强行放在同一个1-10量表上衡量 | 对于truly hard choices，不要试图用权重计算，而是问"我想成为什么样的人" |
| **外部视角污染** | 找了一个和你想法一致的朋友来"验证"权重 | 明确要求朋友："请至少找出一个我给得太高或太低的因素"，找不出来就换人 |
| **时间距离失效** | 25岁的人难以想象35岁的自己，时间距离法无效 | 年龄<28岁时，用"年长者版"替代"十年后版"，找35+的朋友做外部视角 |
| **因素屏蔽偏差** | 大脑自动屏蔽与直觉结论相悖的因素 | 先列出所有因素再排序，不要边列边筛选；用外部视角检查遗漏 |

## 常见失败模式

| 失败模式 | 症状 | 预防 |
|:---------|:-----|:-----|
| **因素列得太少** | 只列了 3-4 个"显而易见的"因素，遗漏了真正影响长期满意度的隐性因素（如自主权、学习曲线、价值观匹配） | 强制至少列出 8 个因素。不够 8 个→去看别人在做类似决策时考虑了哪些因素 |
| **外部视角选了"同意我的人"** | 找了一个和你想法一致的朋友来"验证"你的权重分配 | 明确要求朋友："请至少找出一个我给得太高或太低的因素"。如果朋友找不出来，换一个人 |
| **三次权重完全一样** | 直觉版、年长版、十年后版的结果几乎相同——说明后两次没有真正切换视角 | 心理技巧：第三次（十年后）时先闭上眼睛 10 秒，真正想象自己老了十岁的生活状态，再开始加权 |
| **做了分析但最后还是凭直觉选** | 花了 1 小时做完五步，然后说"但我感觉还是 A 好" | 这是正常的——分析的价值不在于"替代直觉"，而在于"让直觉被充分检视"。只要分析过程让你看到了之前没看到的偏见，就已经有价值了 |

## Example

**场景**：30 岁产品经理面临两个 offer——A 公司（大厂，薪资高 30%，但业务边缘）vs B 公司（创业公司，薪资持平，但负责核心产品从 0 到 1）。

**因素列表**（8 个）：薪资、职位 title、学习成长、工作强度、团队氛围、公司前景、通勤时间、自主权。

**三次权重**：
| 因素 | 直觉版 | "年长者"版 | "十年后的我"版 | 中位数 |
|:-----|:------:|:----------:|:-------------:|:------:|
| 薪资 | 9 | 5 | 3 | **5** |
| 学习成长 | 6 | 9 | 9 | **9** |
| 自主权 | 5 | 8 | 8 | **8** |
| ... | | | | |

**关键发现**：薪资的权重从直觉版的 9 跌到"十年后"版的 3——说明当前对涨薪 30% 的兴奋在十年尺度上几乎不重要。学习成长的权重从 6 升到 9——十年后的自己更在乎能力积累。

**外部视角反馈**：朋友指出"工作强度"的权重（7）给太高了——"你单身没孩子，身体也健康，高强度工作两年对你不是真问题。你上次抱怨工作的 80% 是因为做的事情没意义，不是太累了。"

**结论**：权重校准后，B 公司在"长期重要因素"（学习成长+自主权+公司前景）上的得分大幅领先。选了 B。18 个月后 A 公司那个部门被裁撤了。

## 为什么有效

权重设定隐含了决策者的价值观、害怕什么、渴望什么——这些心理状态本身就有系统性偏差：我们高估马上到手的收益（Hyperbolic discounting），高估可量化维度（Availability heuristic），低估'感觉'但长期重要的维度（如意义感、自主权、关系质量）。外部视角和时间距离是两种低成本的方法，可以在一定程度上对冲这些偏差。

### 外部攻击

**Daniel Kahneman**（《思考，快与慢》）会认可这套方法的核心逻辑——权重偏差确实是"系统 1 以系统 2 无法察觉的方式劫持了决策"。但他会指出一个更深层的问题：**即使你意识到了权重偏差并进行了校准，你在"选择哪些因素进入列表"这一步就已经有偏差了**。大脑会自动屏蔽与直觉结论相悖的因素——这个屏蔽发生在意识层面之前，你无法校准你看不到的东西。

**Ruth Chang**（罗格斯大学哲学家，"Hard Choices"理论）会从另一个角度质疑：有些决策的"因素"之间是**不可通约的（incommensurable）**——薪资和意义感不能用同一个 1-10 的量表来衡量。强行量化不可通约的价值观，不是在"减少偏差"，而是在"制造偏差"——你让薪资和意义感看起来可以互相抵消，但实际上它们不可以。Chang 的建议：对于 truly hard choices，不要试图用权重计算；而是问自己"我想成为什么样的人"——然后用这个答案来为自己"commit"到某个选项。
