# 新人 90 天融入加速器

> 从 [[yt-management-team-knowledge]] 萃取的团队管理工具。不是"发员工手册+安排导师"的形式主义，而是一套有节奏、有反馈、有退出标准的"社会化工程"——让新人在 90 天内从"外部人"变成"有贡献的内部人"，同时保留他们带来的外部视角。

## Summary

新人 90 天融入加速器是一套结构化的新成员融入工具。核心主张：**融入不是信息的单向灌输，而是关系的双向建立**。本工具卡交付：三阶段融入路线图（第 1 周→第 2-4 周→第 2-3 个月）→ 每阶段进入标准/操作步骤/退出标准 → 导师匹配框架 → 90 天复盘模板。

---

## 进入标准（When to Use）

| 场景 | 信号 |
|------|------|
| 团队新成员入职（全职/核心兼职） | 劳动合同签署后、到岗前 1 周 |
| 团队扩张期，同时有多人入职 | 需要统一融入节奏，防止"老人带新人"变成"坏习惯传递" |
| 新人入职 2 周后仍"找不到北" | 新人开始沉默、不参与讨论、或频繁问基础问题 |
| 团队文化出现稀释迹象 | 新老人行为差异大，"我们以前不这样"的抱怨增加 |
| 关键岗位新人离职率高 | 过去 6 个月同岗位流失 >2 人 |

**不满足进入标准**：短期实习生（<3 个月）、高度自治的远程协作（见面频率 <1 次/月）、创始人亲自带教的早期团队（<5 人，口传心授效率更高）。

## 操作步骤（Step-by-Step）

### Phase 1：第 1 周——生存期（不要饿死）

**目的**：让新人"安全着陆"——知道找谁、用什么工具、不被基本问题困住。

**进入标准**：到岗前 1 周启动（不要等第一天）。

**操作步骤**：

1. **导师匹配**（到岗前 3 天）
   - 待补充链接
   - 待补充链接
   - 待补充链接

2. **信息包发送**（到岗前 1 天）
   - 待补充链接
   - 待补充链接

3. **第 1 天仪式**（30 分钟）
   - 待补充链接
   - 待补充链接

4. **第 3 天检查点**（15 分钟）
   - 待补充链接
   - 待补充链接

5. **第 5 天轻量任务**（可选）
   - 待补充链接
   - 待补充链接

**退出标准**：新人能独立预定会议室、找到关键文档、说出 3 个关键协作对象的名字。

### Phase 2：第 2-4 周——观察期（理解游戏规则）

**目的**：让新人理解"这里的人怎么做事"——不是写在手册上的，是实际运行的潜规则。

**进入标准**：Phase 1 退出标准达成。

**操作步骤**：

1. **影子跟随**（第 2 周）
   - 待补充链接
   - 待补充链接
   - 待补充链接

2. **文化故事会**（第 3 周，1 小时）
   - 待补充链接
   - 待补充链接

3. **第一次真实任务**（第 3-4 周）
   - 待补充链接
   - 待补充链接

4. **第 4 周 1-on-1**（30 分钟）
   - 待补充链接
   - 待补充链接

**退出标准**：新人能描述团队的 3 条"潜规则"、完成 1 个真实任务、提出 1 个"这里可以改进"的观察。

---

### Phase 3：第 2-3 个月——贡献期（产生价值）

**目的**：让新人从"学习者"变成"贡献者"，同时保留外部视角。

**进入标准**：Phase 2 退出标准达成。

**操作步骤**：

1. **独立项目**（第 2 个月）
   - 待补充链接
   - 待补充链接

2. **外部视角萃取**（第 2 个月末，1 小时）
   - 待补充链接
   - 待补充链接
   - 待补充链接

3. **导师退出**（第 2 个月末）
   - 待补充链接
   - 待补充链接

4. **90 天复盘**（第 3 个月初，1 小时）
   - 待补充链接
   - 待补充链接
   - 待补充链接

**退出标准**：新人独立完成 1 个项目、提出 1 个被团队采纳的改进建议、能说出"如果这件事我做主，我会怎么做"。

## 退出标准（When to Stop）

| 信号 | 行动 |
|------|------|
| 新人在 Phase 1 就表现出"不需要融入"（自带资源、自驱极强） | 简化为"导师+第 1 天 1-on-1+90 天复盘"即可 |
| 新人在 Phase 2 仍无法完成基础任务 | 触发"能力-岗位匹配度"评估，而非延长融入期 |
| 团队规模 <5 人且扁平化 | 用"每周团队午餐+即时反馈"替代结构化流程 |
| 90 天后新人仍感到"不被接纳" | 问题不在融入流程，而在团队文化或直属上级——需要更高层介入 |
| 新人提出的"外部视角"100% 被拒绝 | 团队已封闭——融入工具无效，需要文化诊断 |

---

## Constraints

1. **不能替代直属上级的管理责任**：导师是指南针，直属上级才是舵手。如果上级把新人"丢给导师就不管"，融入必然失败。
2. ** mentor 选择比 mentor 培训更重要**：选错 mentor（控制欲强、喜欢抱怨、自己也在边缘化）比不选 mentor 更糟。
3. **"外部视角萃取"容易流于形式**：如果团队文化不鼓励质疑，这个环节会变成"新人说废话、老人表面点头"的仪式。需要直属上级带头接受批评。
4. **对高度专业化岗位适配性低**：如高级算法工程师、资深设计师，他们的"融入"更多是"理解业务上下文"而非"学习协作规则"，流程需要大幅简化。
5. **不能解决"招聘错误"**：如果新人本身不适合这个岗位，90 天融入只是在延迟承认错误。

## 外部攻击

#### ChatGPT — 新

组织行为学家 John Van Maanen 和 Edgar Schein 研究组织社会化发现：**过度结构化加速同化，但也消灭了 outsider perspective**。新人在 Day 1 看到的问题可能在 Day 30 后就不"看见"了——不是因为问题消失了，而是因为他们已经被"训练成不看见"。90 天融入加速器假设"结构化、分阶段、有导师"是最好的社会化方式，但某些组织文化恰恰依赖**非正式、随机、甚至略带冲击**的融入方式（如早期创业团队、特种部队式的精英团队）。强行标准化会破坏原有的文化传递机制，让新人误把"流程"当成"文化"——遵守了 90 天流程，但没理解团队真正的价值观。

**紧迫感**：如果你的团队是一个"靠默契而非流程"运转的高绩效团队，90 天加速器可能是在用工业时代的流水线逻辑，破坏一个有机生态。新人在第 90 天完美地完成了所有 checklist，但仍然不是"我们的人"。

#### Edmondson — 没有心理安全的 onboarding 是沉默孵化器

哈佛商学院教授 Amy Edmondson 研究表明，**团队心理安全**（psychological safety）是高效团队的最强预测因子——成员敢于承认错误、提出质疑、承认"我不知道"。心理安全不是"人际关系好"，而是"容错的文化信号"。90 天融入加速器强调"快速产出证明价值"，这可能无意中传递了一个信号：**你的价值取决于你能多快证明有用**。结果是：新人隐藏自己的无知、不敢问"愚蠢问题"、把外部视角（"这里好像有问题"）懶在心里——因为说出来可能被视为"不融入"。Edmondson 的研究表明，心理安全需要"长期、一致、非评判性的容错信号"，而 90 天的结构化流程可能太短、太 performance-oriented，反而破坏了这种信号的建立。

**紧迫感**：如果你的新人入职 90 天后"表现得很好、产出很高、从不抱怨"，Edmondson 会问你——他们是真的融入了，还是学会了"在心理不安全的环境中生存"？如果是后者，你失去的不仅是他们的真实反馈，还有他们本可以带来的外部创新。

## Synthesis

### 核心洞察

新人 90 天融入加速器的本质不是"教新人怎么做事"，而是"让新人从外部人变成内部人，同时保留外部视角"。这个目标本身就是矛盾的：你既要让新人“懂得规则”，又要让他们“看破规则”。解决这个矛盾的关键不是流程本身，而是“第 2 个月末的外部视角萃取会议”——这是唯一一个专门设计来保留新人"非内部人视角"的环节。如果这个会议流于形式或被取消，整个工具就退化成了"标准化的同化机器"。

另一个洞察是：**导师制本身就是一个矛盾。** 导师帮助新人融入，但导师本身就是"内部人"——他们无意识地会把新人“训练成“和自己一样的人”。这就是为什么建议选择"入职 6-12 个月的半新人"作为导师——他们还记得新人疼痛，还没完全被"内部化"。

## 不要用的场景（When Not to Use）

1. **团队 <5 人且扁平化**：口传心授比结构化流程效率更高，强行上流程反而是负担。
2. **短期实习生（<3 个月）**：融入回报周期太长，不值得投入。
3. **高度专业化岗位**（高级算法工程师、资深设计师）：他们的"融入"是理解业务上下文，不是学习协作规则。
4. **团队文化已经封闭**：如果新人的外部视角 100% 被拒绝，融入工具无效，需要文化诊断。
5. **招聘错误的情况**：如果新人本身不适合这个岗位，90 天融入只是在延迟承认错误。
6. **高度自治的远程协作团队**（见面频率 <1 次/月）：结构化融入需要高频次的互动来支撑。

## Action Triggers

| 触发时机 | 动作 | 负责人 |
|---------|------|---------|
| 到岗前 1 周 | 启动融入流程，完成导师匹配 | 直属上级 |
| 到岗前 1 天 | 发送"生存必需"信息包 | HR/行政 |
| 到岗第 1 天 | 直属上级 1-on-1 + 团队简介 | 直属上级 |
| 到岗第 3 天 | 检查点："还有什么基础问题让你卡住的？" | 导师 |
| 到岗第 5 天 | 分配第一个低 stakes 任务 | 导师 |
| 第 2 周 | 影子跟随：参加 2-3 个典型会议 | 导师 |
| 第 3 周 | 文化故事会：分享失败史 | 直属上级/创始人 |
| 第 3-4 周 | 分配第一个真实任务 | 直属上级 |
| 第 4 周 | 1-on-1："最困惑的 3 件事" | 直属上级 |
| 第 2 个月 | 分配第一个独立项目 | 直属上级 |
| 第 2 个月末 | **外部视角萃取会议**（工具核心） | 直属上级 |
| 第 2 个月末 | 导师从日常指导转为需要时咨询 | 导师 |
| 第 3 个月初 | **90 天复盘**：自评+上级反馈+团队反馈 | 直属上级 |
| 90 天后 | 根据复盘结果调整第 4 个月目标 | 直属上级 |

> **核心触发点提醒**：外部视角萃取会议和 90 天复盘是本工具的两个"不可省略节点"。前者决定了新人是否能够保留“外部人视角”，后者决定了整个融入流程是否有效。如果这两个节点被跳过，整个工具就退化成了"形式主义 checklist"。
