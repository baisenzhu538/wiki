# SWOT 分析工具：从四象限到行动策略

> SWOT 是最基础的战略分析工具，将内部优势（S）、劣势（W）与外部机会（O）、威胁（T）交叉，形成四种行动策略。

---

## 一、SWOT 矩阵

```
              内部环境
         优势 S        劣势 W
       ┌─────────┬─────────┐
  机会 │  SO     │  WO     │
   O   │ 增长型  │ 扭转型  │
       ├─────────┼─────────┤
  威胁 │  ST     │  WT     │
   T   │ 多元化  │ 防御型  │
       └─────────┴─────────┘
```

| 策略 | 含义 | 典型问题 |
|--|--|--|
| **SO 战略** | 最大限度发挥优势和机会 | 如何利用优势抓住最大机会？ |
| **WO 战略** | 利用机会，规避弱点 | 哪些机会能弥补我们的劣势？ |
| **ST 战略** | 利用优势，降低威胁 | 如何用优势抵御外部威胁？ |
| **WT 战略** | 收缩、合并或防御 | 如何最小化劣势并避免威胁？ |

---

## 二、使用步骤

1. **梳理 S（优势）**：内部的有利因素，如品牌、技术、渠道、人才、资金。
2. **梳理 W（劣势）**：内部的不利因素，如成本高、组织慢、数字化弱。
3. **梳理 O（机会）**：外部有利趋势，如政策支持、市场空白、技术变革。
4. **梳理 T（威胁）**：外部不利因素，如竞争加剧、替代品、监管收紧。
5. **交叉生成策略**：每个象限至少生成 2-3 条策略。
6. **优先级排序**：结合影响力、可行性和资源约束排序。

## 四、与 KSF 的衔接

KSF 分析输出“必须赢的要素”，SWOT 则将这些要素转化为“我们的位置”和“该做什么”。

```
KSF 维度 → 我司强弱 → SWOT 分类 → 行动策略
```

| KSF | 我司表现 | 外部环境 | SWOT | 策略 |
|--|--|--|--|--|
| 渠道掌控力 | 强 | 线上流量红利 | S+O → SO | 加大线上投入 |
| 供应链 | 弱 | 供应商集中 | W+T → WT | 寻找替代供应商 |

## 五、Agent 执行指令

```python
def swot_analysis(context: str):
    """生成 SWOT 分析并推导策略"""
    prompts = {
        "优势": f"基于「{context}」，列出3-5个内部优势。",
        "劣势": "列出3-5个内部劣势。",
        "机会": "列出3-5个外部机会。",
        "威胁": "列出3-5个外部威胁。",
        "策略矩阵": "生成SO/WO/ST/WT策略，每个象限至少2条。",
        "优先级": "按影响力、可行性、资源需求排序，选出Top 5行动。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 清单冗长 | 每个象限列十几条 | 强制每个象限不超过 5 条，聚焦关键 |
| 内外不分 | 把外部因素放进 S/W | 先判断因素是内部还是外部 |
| 只有分析没有策略 | 停留在四象限 | 必须生成交叉策略和行动计划 |
| 策略不可执行 | “抓住机遇” | 每条策略必须有负责人、资源、时间 |
