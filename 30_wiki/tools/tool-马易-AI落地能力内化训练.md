# 技能：AI落地能力内化训练

## 原始表述

AI落地能力内化训练是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 完成一次完整项目落地（任意规模场景）
2. 亲自执行拆场景、判断、验证、开发、上线全流程
3. 体验'游戏化'AI项目（如coco鱼游戏）建立体感
4. 尝试独立承接30-100个AI落地咨询项目
5. 持续在实战中迭代方法

## 适用场景

- 希望从学习者转变为能独立交付者
- 需要建立AI落地的真实体感
- 计划从事AI咨询/实施服务

## 不适用场景

- 仅想了解概念、不准备动手
- 无实际业务场景可练习

## 工具/环境

- AI落地游戏（如coco鱼）
- 咨询项目实践机会
- 复盘模板

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

AI落地千变万化，抄智能体无意义；必须通过完整项目建立体感；游戏化体验可降低认知门槛；实战30+项目后具备独立咨询能力
