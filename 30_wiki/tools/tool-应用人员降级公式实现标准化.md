# 技能：应用人员降级公式实现标准化

## 原始表述
> 遵循「人员降级公式」：顶级专家→咨询师→白领/销售→流水线工人→机器人→程序，逐级拆解替代

## 操作步骤
1. 识别当前依赖顶级专家的核心环节
2. 分析该环节能否降级为咨询师级别完成
3. 继续评估能否进一步降级为白领/销售、流水线工人
4. 最终探索机器人或程序替代的可能性
5. 逐级实施替代，而非一步到位

## 目的

通过"顶级专家 → 咨询师 → 白领/销售 → 流水线工人 → 机器人/程序"的逐级降级公式，把依赖少数高端人才的不可规模业务，转化为依赖标准化流程和工具的规模可复制业务。核心价值是：让企业不被关键人绑架，同时大幅降低人力成本。适用于专业服务规模化（咨询/设计/医疗）、连锁加盟体系建设、或任何"老师傅/大销售"是增长瓶颈的场景。

## 不要用的场景

- 核心价值恰恰在于顶级专家不可替代性的业务（如高端诉讼律师、顶级医疗专家），强制降级会摧毁竞争力
- 降级过程中需要的"标准化文档/SOP/工具"本身就要花大量高端人力去建，如果业务量不够大，得不偿失
- 文化或监管不允许"降级"的行业（如某些高监管金融业务要求特定资质人员签字），公式本身不可执行

## 质疑

- **具体假设**：该工具假设结构化方法论本身能产生正确结论，但方法论只是框架——结论质量取决于输入数据的质量和执行者的判断力。
- **边界**：在数据稀缺或快速变化的新兴领域，已有经验框架可能完全失效——工具的有效性高度依赖场景的稳定性。
- **反例**：一个团队完整执行了所有步骤，产出了漂亮的文档，但核心假设从一开始就是错的——流程的完整性掩盖了判断的缺陷。
- **前提**：使用者已具备该领域的基础认知，能正确理解和执行工具规则，且数据来源具有代表性。

**Clayton Christensen**: 降级公式本质上是"效率创新"（efficiency innovation）——它优化的是已有价值的交付成本，而不是发现新价值。过度追求降级会让企业擅长做"更便宜的已有东西"，而不擅长发现"下一个该做什么"。很多被降级公式改造过的行业，最终陷入了价格战。

**David Autor**: 从劳动经济学的角度看，降级公式描述的是"任务偏向型技术变革"（task-biased technical change）——把可编码的任务交给更低成本执行者或机器。但这个过程有一个隐性成本：被"降级"掉的那部分工作，往往是初级人员积累判断力的训练场。系统性降级可能导致"中级技能空心化"，长期损害组织能力。
