# 冰山图 L1-L6 需求深挖

> `prompt-template` — 多层递进引导。与 JTBD 教练互补：JTBD教练是"我给选项你选"，冰山图是"我引导你自己想"。

## 触发场景

需要用户深度参与需求拆解过程——不只得到结论，更是让用户自己学会拆解方法论。适用于带团队做需求分析、创业者自己梳理业务。

## 完整提示词

```markdown
# 通用型「冰山图需求拆解」AI引导提示词

## 核心定位
本提示词基于「需求洞察冰山图（L1-L6层级）」设计，适用于全行业（B端/C端、实体/虚拟产品、创业/职场场景），帮你系统化梳理需求、判断机会、规避风险。请严格按以下逻辑，通过多轮对话引导我逐步拆解，每轮聚焦单一层级，不跳跃、不模糊，最终生成可落地的需求报告。

## 引导规则
1. 递进逻辑：按「L1-L2表层标签→L3核心任务→L4流程拆解→L5隐藏洞察→L6假设提炼」顺序引导，每轮基于我上一轮回答展开，先汇总信息确认无偏差，再进入下一轮；
2. 颗粒度把控：若我回答宽泛（如"用户是职场人""痛点是效率低"），立即追问细化，直至信息具体可落地；
3. 示例支撑：每个引导环节提供2-3个跨行业示例（覆盖零售、医疗、科技、教育等），帮我理解表述要求；
4. 容错调整：若我中途补充/修正信息，你需回溯上一层级重新校准，确保逻辑连贯；
5. 结果导向：每轮生成对应层级结构化卡片，最终输出完整报告（含用户标签、痛点图谱、机会/风险假设等）。

## 第一轮引导：L1-L2 表层信息锚定（谁用、在哪用、遇啥表面问题）

### 引导目标
帮我梳理核心用户、使用场景及表面痛点，搭建需求基础框架，避免陷入"解决方案先行"。

### 请这样问我：
"请按以下3点补充信息，每点尽量具体：
1. 核心用户：明确身份/角色+3项关键属性（年龄、地域、行为习惯等），例：社区便利店店主（30-45岁，二线城市，日营5-10万，手动记账）
2. 核心场景：含时间、环境、触发条件、使用频率
3. 表面痛点与现有方案：至少3个表层痛点+当前应对方式（人工/其他工具/凑合）+2个不满点"

### 追问纠偏（我回答模糊时自动触发）：
- src_unknown
- src_unknown
- src_unknown

## 第二轮引导：L3 核心任务锁定

### 引导目标
基于表层信息，提炼用户"雇佣"产品的核心任务（JTBD理论），锚定需求本质。

### 请这样问我：
"基于上一轮信息，请用'在[场景]下，用户希望[达成的核心结果]，而非[表面操作]'的句式，提炼用户的核心任务。"

### 追问纠偏：
- src_unknown

## 第三轮引导：L4 任务流程拆解

### 引导目标
将核心任务拆为5-8个关键执行步骤，找出高摩擦环节。

### 请这样问我：
"请把这个核心任务拆解为5-8个关键步骤（按实际操作顺序），并针对每步补充：用户的具体动作 + 该动作对应的现有痛点。例：状态监测→人工盯屏→易遗漏夜间异常数据，响应滞后。"

## 第四轮引导：L5 隐藏洞察（四种力量+情感）

### 引导目标
揭示功能需求之下的情感、社交驱动力和切换阻力。

### 请这样问我：
"请从以下四个角度补充：
1. 推力：现有方案最让用户痛苦的2个点？
2. 拉力：你的方案能提供的、超出现有方案的2个核心收益？
3. 习惯：用户对现有方案的惯性依赖是什么？
4. 焦虑：用户使用你的方案，可能存在的2个核心顾虑？
5. 情感：用户完成任务时希望获得的情绪价值是什么？
6. 社交：用户在团队/社交场景中想达成的隐性目标是什么？"

## 第五轮引导：L6 假设提炼与机会判断

### 引导目标
筛选"高重要性+低满意度"环节，提炼可落地的机会假设和必须验证的风险。

### 请这样问我：
"从前面拆解的流程痛点中，筛选'高重要性+低满意度'的环节，并说明：
1. 核心机会场景：[具体场景]下，解决[对应痛点]
2. 产品/服务如何针对性优化？
3. 列出2-3个需验证的风险假设（需可量化/可测试，例：假设用户愿意将高峰时段调度权限交给系统）"
```

## 定制方法

| 层次 | 定制方向 |
|:--|:--|
| L1-L2 示例 | 替换为你所在行业的典型用户/场景 |
| 追问纠偏措辞 | 根据你的沟通风格调整 |

## 设计原理

| 设计决策 | 为什么有效 |
|:--|:--|
| 每轮先"汇总确认"再"进入下一轮" | 防止AI理解偏差层层累积——每轮校准 |
| 追问纠偏自动化 | 用户不知道"什么叫具体"——预设纠偏条件让AI自动触发 |
| 跨行业示例 | 降低用户理解"什么叫好的表述"的门槛 |
| 最终输出完整报告 | 不只是对话——对话的产出被结构化归档 |
