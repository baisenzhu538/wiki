# 团队复盘引导清单：8部分完整流程+话术+标记位

> 一句话：拿到这份清单，主持人不需要是复盘专家——按8部分流程走、照读引导话术，就能开一场从"心理安全"到"三件套产出"的完整复盘会。

---

## 使用条件

| 条件 | 要求 |
|:---|:---|
| 参与者 | 项目核心成员 2-5 人（含决策者） |
| 时长 | 90 分钟（可弹性 ±20 分钟） |
| 场景 | 项目结束后/阶段节点/出了重大问题 |
| 主持人 | 团队leader本人（不可委托——12策略"以身作则"要求） |

---

## 8部分流程

### Part 0：开场定调（5分钟，决定成败）

> "今天我们复盘的目的只有一个——把这次的经验变成我们团队的能力。不是追责，不是找谁的问题。我先说——这次我自己至少有3个决策做得不对……"

**核心动作**：
1. 三要素定调（真实经验+面向未来+学习）
2. 心理安全声明（"不记过、不扣分"）
3. **反向汇报**——leader先自曝3个自己的决策失误（示范深度，员工才知道"深度长什么样"）

### Part 1：事实还原（15分钟，冰山第2层）

> 规则：每人说一个事实，不许重复、不许评价。leader先示范。

**拦截话术**："这句话是事实还是判断？'他不靠谱'是判断，'7月7号客户来看机那天方案还没做完'是事实。先把事实说全。"

**为什么重要**：员工手里有leader不知道的现场细节——这一轮就是挖这些。观点天然为了赢，事实才能对齐（L1760-1786）。

### Part 2：成败认定（10分钟）

> 规则：**员工先表态，leader最后说**——领导先定调，员工就只会跟风了。

每人说：最成功的一点 + 最失败的一点。对照后的差异本身就是认知金矿——"领导觉得失败的点员工觉得成功"。

### Part 3：冰山穿透（20分钟，核心环节）

逐层下探：

| 层 | 问题 |
|:---|:---|
| L3 原因 | "当初为什么选这个方案/这个供应商？我们当时有没有做对比验证？为什么没有？" |
| L4 模型 | "这个合作模式里，哪条假设其实没验证过？" |
| L5 能力 | "**假设换一家完全新的合作方——哪些问题会消失，哪些还会重演？**如果重演的是多数→问题不在对方，在我们" |

**L5是关键转折**：让团队自己得出"不是甩锅给对方"的结论，比leader说出来有力十倍。

### Part 4：9宗罪姿势自检（5分钟）

> "刚才的讨论，有没有这些情况？有的就说。"

- 一团和气？（不敢说问题）
- 背锅会？（把责任推给某个人）
- 停在"感觉不行"？（没有具体事实）
- 主持人先定调了？（leader先表态=员工闭嘴）

**主持人也被查**——这是"以身作则"的延续。

### Part 5：三件套产出（20分钟，没有产出的复盘不算完）

| 产出 | 内容 | 格式 |
|:---|:---|:---|
| go/no-go决策 | 三选项（继续/降级/退出），每个标注成立条件+谁去验证 | 条件表 |
| 管理规范 | 3-5条KSF → 展开为"怎么做+红线" | KSF→规范表 |
| 分阶段清单 | 本周·止血 / 本月·建机制 / 季度·成体系，各有牵头人 | 三阶段表 |

### Part 6：三分钟复盘（复盘会本身）

> "最后三分钟，复盘我们这个会——这个会开得怎么样？下次怎么开更好？每人说一条。"

主持人记三条——"记三条，可比下一次回去复盘质量高多了"（L3432）。

## 引导者核心话术速查

| 场景 | 话术 |
|:---|:---|
| 开场定调 | "目的只有一个——把经验变成能力。不是追责。我先说——我自己至少有3个决策不对……" |
| 拦截主观判断 | "这是事实还是判断？先说事实，判断等一下。" |
| 员工不敢说话 | "你当时心里的第一反应是什么？不用怕说错。" |
| 归因停在表面 | "为什么？那为什么会有那个原因？再往下，那个原因的原因是什么？" |
| 最后收束 | "如果换一家还会重演——问题不在对方，在我们。我们还没有这个基本功。" |

---

## 标记位机制

每个问题后面标【】，引导者边问边记关键词。会后回来按标记归类到冰山五层——标出"哪层穿透了、哪层停着"。这是"黑盒变白盒"的实操手段。

---

## When NOT to Use

| 误用 | 后果 | 正确做法 |
|:---|:---|:---|
| 主持人不是leader本人 | 违反"以身作则"——团队不会认真对待 | leader必须亲自主持 |
| 跳过Part 0直接进事实还原 | 心理安全没建立——后面全是假话 | Part 0三句定调话术不加不减 |
| 用模板替代思考 | "引导清单"变成"填表任务" | 话术是开口句式，不是标准答案——根据实际调整 |

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 清单式填表 | 主持人机械读问题，不根据回答追问 | 每个Part最多追问一次——"为什么？""能举个例子吗？" |
| 批斗会顾虑 | 员工说"我觉得还行"——明显在回避 | 回到Part 0——重申"不记过不扣分"，或者leader再自曝一个错误 |
| 心理安全不足 | 全程只有leader在说话 | 换顺序——让最junior的员工先说 |
| 跳过L5能力层 | 复盘停在"下次注意"——没有可迁移的规范产出 | Part 5强制出三件套——没有产出不算完 |

## Critique

本清单在千惠一次实战中验证有效，但样本量=1。不同行业、不同团队规模、不同问题类型下的适用性需更多验证。清单的"话术"部分以老朱的风格为蓝本——其他leader需根据自己的表达习惯调整，但开场三句（目的+安全+自曝）不可删减。
