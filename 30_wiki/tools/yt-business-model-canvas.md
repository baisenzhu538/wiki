# 商业模式画布：一堂版

> 一堂五步法：商业模式画布是梳理商业模式的工具，9个要素缺一不可，帮助发现矛盾和对齐团队。

## 核心框架

一堂版商业模式画布（基于Alexander Osterwalder的Business Model Canvas，优化为一堂语境）：

```
┌─────────────────────────────────────────────────────────────┐
│  价值主张 (Value Proposition)                                │
│  "用户为什么选我们？"                                         │
├──────────────┬──────────────┬──────────────┬────────────────┤
│ 客户群体     │ 渠道通路      │ 客户关系      │ 收入来源        │
│ (Customer    │ (Channels)    │ (Customer     │ (Revenue       │
│  Segments)   │              │  Relationships)│  Streams)     │
│ "谁付费？"   │ "怎么触达？"  │ "怎么维护？"  │ "怎么赚钱？"    │
├──────────────┴──────────────┴──────────────┴────────────────┤
│ 关键资源 (Key Resources)          关键活动 (Key Activities)  │
│ "需要什么资源？"                    "需要做什么？"              │
├─────────────────────────────────────────────────────────────┤
│ 合作伙伴 (Key Partnerships)                                  │
│ "需要谁的帮助？"                                            │
├─────────────────────────────────────────────────────────────┤
│ 成本结构 (Cost Structure)                                    │
│ "花多少钱？"                                                │
└─────────────────────────────────────────────────────────────┘
```

## 关键洞察

### 1. 9个要素详解

| 要素 | 核心问题 | 示例（洗发水） |
|:---|:---|:---|
| **价值主张** | 用户为什么选我们？ | 有效去屑+专业形象 |
| **客户群体** | 谁付费？ | 有头皮屑问题的成年人 |
| **渠道通路** | 怎么触达用户？ | 超市、电商、药店 |
| **客户关系** | 怎么维护关系？ | 会员、客服、社群 |
| **收入来源** | 怎么赚钱？ | 按瓶销售、套装 |
| **关键资源** | 需要什么资源？ | 品牌、配方、渠道 |
| **关键活动** | 需要做什么？ | 研发、营销、分销 |
| **合作伙伴** | 需要谁的帮助？ | 代工厂、渠道商 |
| **成本结构** | 花多少钱？ | 研发、营销、生产 |

### 2. 要素之间的匹配检查

| 检查项 | 问题 | 不匹配的风险 |
|:---|:---|:---|
| 价值主张 ↔ 客户群体 | 价值主张是否匹配客户需求？ | 用户不需要 |
| 价值主张 ↔ 收入来源 | 用户是否愿意为价值付费？ | 用户用但不付费 |
| 渠道通路 ↔ 客户群体 | 渠道是否触达目标客户？ | 触达成本高 |
| 收入来源 ↔ 成本结构 | 收入是否覆盖成本？ | 亏损 |
| 关键资源 ↔ 关键活动 | 资源是否支撑活动？ | 资源不足 |

### 4. 画布的迭代

画布不是一次性的，需要随业务迭代：

| 阶段 | 迭代频率 | 重点 |
|:---|:---|:---|
| 验证期 | 每周 | 价值主张和客户群体 |
| 增长期 | 每月 | 渠道和收入来源 |
| 成熟期 | 每季度 | 成本结构和效率 |
| 转型期 | 随时 | 全面重构 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **要素缺失** | 画布缺少某个要素 | 检查9个要素是否完整 |
| **要素不匹配** | 要素之间矛盾 | 检查要素之间的匹配关系 |
| **假设未验证** | 画布中的假设未验证 | 对每个假设设计验证方法 |
| **团队未对齐** | 每个人填的画布不同 | 团队一起填写，对齐认知 |
| **画布僵化** | 市场变化，画布不变 | 定期迭代画布 |
| **过于复杂** | 每个要素写太多 | 每个要素一句话描述 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 商业模式梳理 | 技术架构设计 |

| 商业模式验证 | 运营活动评估 |
| 创业计划 | 纯公益项目 |
