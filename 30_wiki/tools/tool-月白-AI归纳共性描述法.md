# 技能：AI归纳共性描述法

## 原始表述

AI归纳共性描述法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 收集多张同一类型的目标图片（5-10张）
2. 将这批图片一起丢给AI
3. 要求AI总结归纳这些图片的共性特征
4. 用AI生成的共性描述作为生成提示词
