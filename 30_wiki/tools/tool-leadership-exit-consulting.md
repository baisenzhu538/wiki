# 出口式咨询卡

> 定位：属于 `framework-coaching-leadership-core` 的教练沟通武器库增量工具，服务于五阶梯 L2 共识层（讲道理/共识）→ L3 出口的衔接。**Truman 原创方法**（"实在找不着对应的名词，我自己起了个名叫出口式咨询"L2580-2582）——借教练的提问方法（不直接给答案）+ 咨询的核心价值（真实帮你解决问题）。

## 一句话定义

出口式咨询 = **找出口 → 换视角 → 探究解法**三步法：先帮对方锁定一个"高价值的出口"（如"业务想翻 3-5 倍卡在什么环节"），站在对方鞋子里用 TA 的眼睛走一遍流程，用提问引导 TA 自己得出解法——"全程不给答案，用共识带着他自己讲"（L2718）。

## 为什么重要

1. **解决"给答案不服、不给答案不会"的困境**：借教练提问 + 咨询解决问题，两者结合（L2584-2588）
2. **出口定生死**："找到出口之后，这件事情就解决了一半了，特别难找到"（L2640）
3. **一对一辅导的核武器**：一堂内部 20-30 个常见出口、几十套方法、一百多个出口（L2742-2744）；"这是你们可能进入我们这个世界最好的一把钥匙"（L2748）
4. **高价值但极难**："包括一堂内部，我也不太确定我们内部的员工有几个人会"（L2734）

## 核心机制：三步法

### 第 1 步：找出口

**核心**：帮对方锁定一个 TA 真正在意的、有推动力的目标——"找到出口之后，这件事情就解决了一半"（L2640）。

**出口模板**（增长场景）：
> "你的业务如果想翻大概 3 到 5 倍，到底卡在什么环节？"（L2644）

**要点**：
- 不能光问"遇到什么问题"——得先假设一个前提："你想不想增长 3 到 5 倍？"（L2648）
- 然后拆解：3-5 倍到底是规模经济问题 / 团队问题 / 渠道问题 / 你自己的问题（L2650）
- 出口要有"机会感"："有机会增长到 X" 是很好的出口（L2646）

### 第 2 步：换视角

**核心**：站在对方的位置，用 TA 的眼睛看问题。

> "我站在他的鞋子里，用他的眼睛走一遍流程"（L2706）
> "有点像是你跟他一起附到他的身上，跟他一起用他的眼睛走一遍这个解决问题过程"（L2592）

**要点**：
- 明确告知角色："假设现在我是你的合伙人，完全听你的，没有任何指点你的意思"（L2706）
- 带 TA 梳理：想实现这个目标，应该有几个基本前提（L2708-2714）

### 第 3 步：探究解法

**核心**：用提问引导对方自己得出解法，全程不给答案。

**要点**：
- "我全程不说任何答案，我全程是用共识带着他自己讲"（L2718）
- "他自己就发现了一些大概 5 到 7 个之前的关键假设是粗略的"（L2720）
- "你去研究一下，如果这个假设行，你就继续做；如果不太行，你最好考虑一下"（L2720-2722）

## 共识前提（公理级）

出口式咨询需要双方共享以下公理（缺一则聊不下去）：

| 公理 | 含义 | 若不被认同 |
|:--|:--|:--|
| 需求是事实 | 需求不是凭空捏造的 | "你们这俩不用聊了"（L2658） |
| 商业可以预判 | 商业是客观的、可分析的 | "这件事儿就不用聊了"（L2666） |
| 终局预判有价值 | 单元模型可以提前测算 | 无法分析成功率（L2668） |

## 经典案例：奶茶店辅导（L2672-2724）

**场景**：MBA 案例小组给一个景区奶茶店（收入健康但卡在 7 个店）提建议，七嘴八舌不欢而散——一半人说"能开 7 个店很厉害了"，另一半说"起始点不行"。

**出口式咨询介入**：
1. **找出口**：先问"开 7 个店还是 50 个店算你成功？"→ 对方答"至少 100 个店，20-50 个店算创业失败"（L2692-2696）→ 锁定出口"奔着 100-200 个店"
2. **换视角**："我是你的合伙人，我来带你推一下"（L2706）
3. **探究解法**：拆前提——市场规模撑得住？规模经济到复制水平？模型标准化解决？（L2708-2714）→ 对方自己发现 5-7 个粗略假设

**结果**："我几乎没给你答案，我只是用一些基础的定理来给你做"（L2724）——对方自己得出结论。

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 对方不认公理 | 没有共识地基 | 先对齐前提，不对齐不进入 |
| 紧急决策 | 出口式咨询节奏慢 | 权力快断 + 事后讲道理 |
| 对方经验不足 | 拆解需要对方有足够经验（L2652） | 先补经验/知识再咨询 |
| 纯指令任务 | 不需要探索解法 | 直接给答案 + 讲逻辑 |
| 你自己不熟领域 | 出口式咨询要求你充分掌握（L2652） | 先学习领域再辅导 |

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 找不到出口 | 讨论七嘴八舌无共识 | 先锁定"什么算成功"（奶茶店案例） |
| 出口太低价值 | 目标无推动力 | 用"3-5 倍"式出口模板提升价值感 |
| 给答案冲动 | 说着说着就给方案 | 记住"他一边解一边说服自己"（L2594） |
| 公理未对齐 | 对方不认需求是事实 | 停止，先对齐前提 |
| 跳步 | 没找出口直接拆解 | 三步严格顺序：出口→视角→解法 |

## 行动 Checklist

- [ ] 开始前：确认双方公理（需求是事实/商业可预判）
- [ ] 找出口：问"你想翻几倍卡在什么环节"（或等价出口）
- [ ] 锁定出口：对方确认"这是我最想要的"
- [ ] 换视角：声明角色（"我是你的合伙人"）+ 站在 TA 鞋子里
- [ ] 探究解法：只问不答，拆前提（市场规模/规模经济/标准化）
- [ ] 收尾：让对方列出自己发现的粗略假设

## Critique

### 攻击者 1：咨询方法论——"出口式咨询是苏格拉底式提问的翻版，无新意"

**攻击论点**：找出口→换视角→探究解法本质是苏格拉底式提问（产婆术）的咨询化包装，与经典教练/咨询方法论没有本质区别。

**回应**：差异在**出口的锚定作用**——传统提问帮对方"想清楚"，出口式咨询先帮对方"锁定高价值目标"再拆解，这是"目标导向的引导"而非"纯粹的发问"。奶茶店案例中，"至少 100 个店"这个出口直接终止了七嘴八舌的争论。承认：方法论血缘相近，创新点在出口锚定。

### 攻击者 2：实用主义——"出口式咨询对咨询师要求极高，不可复制"

**攻击论点**：口述自认"内部员工没几个人会"（L2734），要求咨询师充分掌握课程 + 对方有足够经验——门槛高到不可规模化，作为"超级小抄"名不副实。

**回应**：口述也给了出路——"到时候给自己整一个小抄，你能悟到多少，这个得练，一遍遍练好，这个很值钱"（L2740）。门槛高 ≠ 不可学：三步法是可练习的框架，一堂有 20-30 个常见出口可复用（L2742）。承认：卡内应标注"先掌握 3-5 个高频出口（增长/规模/团队）再扩展"。

### 攻击者 3：教练伦理——"全程不给答案可能违背'直接沟通'的 ICF 能力"

**攻击论点**：ICF 八项能力包含"直接沟通"（能力 8）——教练在适当时候应直接分享观察和反馈。出口式咨询"全程不给答案"（L2718）可能矫枉过正，让教练回避必要的直接沟通。

**回应**：口述已给边界——"在希望不给答案的前提下"（L484-486）+ 共识前提可作"基础定理"直接使用（"我用一些基础的定理来给你做"L2724）。出口式咨询不排斥直接沟通，排斥的是"未经思考的答案投喂"。承认：卡内应补"公理可以直接给，解法必须引导"。

## Synthesis

- **不要用的场景**：公理未对齐；紧急决策；对方经验不足；自己不熟领域；把"全程不给答案"当教条（公理可直接给）

  - 辅导前 → 检查公理是否对齐

## 可迁移场景

1. **一对一辅导**：增长/规模/团队 3-5 个高频出口起步
2. **创业辅导**：奶茶店案例模式（先锁定"什么算成功"）
3. **方案评审**：让作者自己拆前提（"要达到这个目标需要哪些前提"）
4. **KDO 工厂（Agent 辅导）**：帮 agent 定位"卡在哪个环节"（素材/格式/深度）再引导自查
