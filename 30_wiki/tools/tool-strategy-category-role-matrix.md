# 零售品类角色矩阵

> 按品类对门店/企业的战略贡献度进行分类，明确不同品类的价位段、产品结构、沟通重点和推广方式，避免"什么都卖、什么都没定位"。

---

## 一、矩阵结构

```
              生鲜商品              非生鲜商品
         ┌─────────────────┬─────────────────┐
  核心   │ 禽类、猪肉、蛋类  │ 烘焙、熟食、奶制品 │
         │ 未来主打品类      │                  │
         ├─────────────────┼─────────────────┤
  获客   │ 蔬菜、水果        │ 冷冻冷藏、零食、饮料│
         │ 吸引客流主体      │                  │
         ├─────────────────┼─────────────────┤
  增利   │ 牛羊肉、水产      │ 酒、米面、食用油   │
         │ 单次消费利润高    │ 厨房用品（非食品） │
         ├─────────────────┼─────────────────┤
  补充   │ （空）            │ 调味品、零食、冲调 │
         │                  │ 纸制品、洗涤清洁   │
         │                  │ 小百货、糖奶       │
         └─────────────────┴─────────────────┘
```

---

## 二、四类角色定义

| 角色 | 战略功能 | 管理重点 | 示例 |
|--|--|--|--|
| **核心** | 未来主打品类，贡献高客流和高收入 | 突出高端化、差异化，实现溢价 | 生鲜：禽类、猪肉、蛋类；非生鲜：烘焙、熟食、奶制品 |
| **获客** | 吸引客流的主体品类 | 高频、刚需、价格敏感，用来拉新和复购 | 生鲜：蔬菜、水果；非生鲜：冷冻冷藏、零食、饮料 |
| **增利** | 顾客单次消费贡献利润高的商品 | 提升客单价和利润率 | 生鲜：牛羊肉、水产；非生鲜：酒、米面、食用油、厨房用品 |
| **补充** | 业绩贡献不明显，但补全商品类型 | 控制 SKU 和库存，满足一站式购物 | 非生鲜：调味品、零食、冲调、纸制品、洗涤清洁、小百货、糖奶 |

## 四、使用步骤

1. **列出品类**：按企业实际经营的商品列出全部品类。
2. **选择维度**：横向可按生鲜/非生鲜、食品/非食品、高频/低频等；纵向为战略角色。
3. **定位角色**：为每个品类打上核心/获客/增利/补充标签。
4. **配置资源**：根据角色决定 SKU 深度、陈列面积、定价策略、促销力度。
5. **动态复盘**：根据销售数据调整品类角色（例如获客品是否带来足够关联购买）。

---

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 角色混同 | 把获客品当增利品卖，导致客流下降 | 明确每个品类的核心 KPI |
| 增利品过度促销 | 利润率被牺牲 | 促销重点放在获客品和补充品清库存 |
| 补充品占面积过大 | 坪效低 | 按贡献度压缩补充品陈列 |
| 角色长期不变 | 市场环境变化后矩阵失效 | 每季度按销售数据重审角色 |

def category_role_matrix(categories: list[str]):
    """为零售品类分配战略角色"""
    prompts = {
        "列出品类": f"将{categories}按生鲜/非生鲜等维度分类。",
        "分配角色": "为每个品类标注核心/获客/增利/补充角色，并说明理由。",
        "定价策略": "针对不同角色给出定价建议。",
        "陈列促销": "给出陈列面积、促销力度、SKU 深度建议。",
        "复盘指标": "定义每个角色的关键复盘指标。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}

## 质疑

> 待补充：这个工具的内在局限是什么？外部反对者会怎么批评？

**Michael Porter** 可能会质疑：这个工具依赖的 **品类定义、角色冲突、资源分配、市场动态** 是否已经被充分验证？

- 品类角色一旦固化，可能错过新兴品类机会。
- 不同角色的 SKU 若用同一 KPI 考核，会导致行为和战略目标错位。

- 使用前应明确本工具的 **具体假设**、适用 **边界**、潜在 **反例** 和隐含 **前提**，避免把模板输出直接当成战略结论。
