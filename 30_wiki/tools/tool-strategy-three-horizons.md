# 三个地平线

> 所有公司都在同时做三件事：养活今天、投资明天、赌后天。问题是多数公司只做了第一件。

## Purpose

帮助企业同时管理三种不同时间维度的业务组合：今天就产生现金的成熟业务、1–3 年内可规模化的增长业务、3–5 年后可能成为新引擎的种子业务，避免"只活在今天"。

## 三层定义

| 地平线 | 时间维度 | 核心动作 | 资源占比 |
|:---|:---|:---|:---:|
| H1 现金流 | 现在 | 优化效率，榨取利润 | 70% |
| H2 增长 | 1-3年 | 规模化已验证的增长引擎 | 20% |
| H3 种子 | 3-5年 | 探索全新机会，允许失败 | 10% |

## Protocol

### Step 1：盘点当前业务组合

列出公司全部产品、业务线或收入流，按成熟度与收入贡献归类到 H1 / H2 / H3。

| 分类标准 | H1 现金流 | H2 增长 | H3 种子 |
|---|---|---|---|
| 收入规模 | 当前主要收入来源 | 已验证，快速放大 | 尚未验证，探索中 |
| 时间窗口 | 现在 | 1–3 年 | 3–5 年 |
| 管理重点 | 利润、效率、成本控制 | 增速、市场份额、复制 | 学习、验证、试错 |

### Step 2：设定资源分配目标

根据行业周期与公司阶段，确定三条地平线的理想资源比例。成熟企业建议 70/20/10；高增长创业公司可适当提高 H2 与 H3 的占比。

### Step 3：识别失衡信号

| 失衡信号 | 含义 | 干预动作 |
|---|---|---|
| H1 占比 >85% | 只有今天，没有明天 | 强制划出 10% 资源给 H3 |
| H2 项目 >3 个 | 增长引擎过多，资源分散 | 砍掉尾部，聚焦 1–2 个 |
| H3 项目为 0 | 缺乏长期赌注 | 建立小步快跑的创新实验池 |
| H3 项目过早要求盈利 | 用 H1 逻辑扼杀探索 | 为 H3 单独设定学习指标 |

### Step 4：建立差异管理机制

对 H1 用 KPI 与利润表管理，对 H2 用增长指标与里程碑管理，对 H3 用假设验证与学习指标管理。避免用同一把尺子量三件事。

## Agent执行指令

```python
def horizon_audit(company):
    h1 = [p for p in company.products if p.stage == "cash_cow"]
    h2 = [p for p in company.products if p.stage == "growth"]
    h3 = [p for p in company.products if p.stage == "seed"]
    return f"H1={len(h1)} H2={len(h2)} H3={len(h3)}"
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| H3=0 | 只有今天没有明天 | 每年强制投入10%资源到H3 |
| H2太多 | 同时做5个增长项目，资源分散 | 聚焦1-2个，其余砍掉 |
| H1失血 | 为保短期利润，砍掉所有未来投资 | 区分"可削减成本"与"战略投资" |
| H3被 KPI 化 | 种子业务背负短期盈利压力 | 为 H3 单独设定学习里程碑 |

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|---|---|---|
| 单一产品初创公司 | 业务组合尚未形成，只有 H1 或 H2 | 先用精益创业验证单一机会 |
| 极端现金流危机 | 生存优先，顾不上 3–5 年种子 | 集中止血，用危机现金流工具 |
| 业务高度同质化 | 难以区分三条地平线 | 先用业务组合矩阵或战略定位工具 |
| 组织缺乏分权机制 | H3 会被 H1 的管理逻辑吞没 | 先建立独立孵化单元或投资委员会 |

## Critique

### 内部局限

1. **具体假设：公司拥有可明确拆分的多条业务线**
   单一业务或平台型公司很难把同一产品生硬拆成 H1/H2/H3。**边界**：本工具更适合多业务组合或大型组织的组合管理。

2. **前提：管理层能抵抗短期利润压力**
   三个地平线的本质是"用今天的利润养明天的可能性"。**反例**：某上市公司 CEO 口头上支持 H3，但季度财报压力下连续削减创新预算，最终 H3 名存实亡。

3. **资源比例 70/20/10 并非普适**
   该比例来自成熟行业经验。高科技、医药研发或初创公司可能需要把 H3 提升到 20% 甚至更高。**边界**：比例应根据行业周期与资本可得性动态调整。

4. **容易忽视业务之间的协同与冲突**
   三条地平线不是孤立容器。H3 的探索可能侵蚀 H1 的核心市场，H2 的增长可能依赖 H1 的渠道与品牌，简单分桶会掩盖这些张力。

### 外部攻击

#### **Michael Porter**

**攻击**：三个地平线过于关注时间维度和资源分配，却回避了"竞争优势从何而来"这一战略核心问题。一家公司可以完美分配 70/20/10，但如果在 H1、H2、H3 中都没有独特的竞争定位，仍然会被对手击败。

**回应**：本工具是业务组合与资源分配的诊断框架，不是竞争战略的全部。它应当与波特的竞争定位分析、价值链分析等工具配合使用。
