# 数量×大胆二维诊断矩阵

> 一句话：你的团队创新能力在哪个象限？数量（有多少想法）vs 大胆（敢不敢跟别人不一样）。知道了位置才知道该补哪里。

---

## 四象限

```
大胆 ↑
     │  少而大胆        │  多而大胆
     │  (缺广度)        │  ★ 目标象限
     │                  │
     ├──────────────────┼──→ 数量
     │  少而保守        │  多而保守
     │  (缺一切)        │  (缺突破)
     │                  │
```

| 象限 | 特征 | 改善策略 |
|:---|:---|:---|
| **多而大胆** ★ | 想法多且敢突破行业惯例 | 保持，进入闪电模型第2步（底层自洽） |
| **多而保守** | 想法多但都是微创新 | 刻意练习"跟同行反着来"——每个想法追问"如果反过来呢？" |
| **少而大胆** | 有突破性想法但数量少 | 增加数量——用"10个疯狂想法"练习，每周产出10个 |
| **少而保守** | 既没有数量也没有突破 | 先练数量（目标：每周10个想法），再练大胆 |

---

## 自评方法

```
1. 回顾过去3个月你的团队提出的创新想法
2. 数量打分（1-5）：平均每月有多少个新想法？
3. 大胆打分（1-5）：这些想法有多少是"同行不会这么做"的？
4. 落到四象限→按改善策略执行
```
