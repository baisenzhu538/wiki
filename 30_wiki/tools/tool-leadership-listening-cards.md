# 教练倾听卡（6步）

> 定位：属于 `framework-coaching-leadership-core` 的教练沟通武器库第 1 组（倾听组），服务于五阶梯 L2 共识层（建立信任）。与 `tool-yitang-listening-37-rule`（阿里铁军三七法则，销售说服场景）的关系：**场景不同**——三七法则是销售对话的倾听配比，本卡是教练对话的深度倾听，二者互补不重叠。

## 一句话定义

倾听不是"听对方说话"，而是全方位关注对方（语言+肢体+情绪+意图），通过克制表达欲、策略性留白、识别分歧与卡点，让对方"被看见、被理解"，从而建立信任。

## 为什么重要

1. **信任是教练式领导力的根基**（口述 02 L470-472）：领导力在尽量不使用职权的情况下影响他人，信任是唯一土壤
2. **倾听是信任的第一动作**：真诚倾听让下属感到被尊重被理解，信任在一次次的互动中悄然而生（L472）
3. **领导表达欲是陷阱**：领导面对下属有势能差，会激发更多表达欲（L910）——克制表达欲是倾听的第一关
4. **深度倾听 ≠ 停止询问**：而是全方位关注对方（L932, L980）

## 核心机制：倾听 6 步

### 第 1 步：保持专注 ✅（VLM 已校对）

**核心**：让对方感受到你的注意力都在他身上。

**3 个策略**：
- 避免打扰：营造不受干扰的封闭环境
- 肢体语言：起身拉椅子、身体前倾、眼神接触、侧耳倾听（口述 02 L904-906）
- 做好笔记：纸笔随时记录关键信息；**建议非电子设备**（打断对方接收专注度）+ 清单体笔记（便于结构化提问）

**进阶细节**（口述 02 L950-962）：
- 空间：坐到对方旁边（L 型座位），不隔着桌子
- 眼神：专注看双眼；不适则看鼻梁三角区
- 反应：积极信息及时点头、微笑、赞同

### 第 2 步：3F 倾听（Fact 事实 / Feeling 情绪 / Focus 意图）

**核心**：识别对方表达的信息、情绪，挖掘背后的真实意图与需求。

| 层 | 要点 |
|:--|:--|
| 事实层 Fact | 记录客观事实，避免过早加入主观解读 |
| 情绪层 Feeling | 注意情绪表达用词（如"我很焦虑"） |
| 意图层 Focus | 通过追问、反向确认，挖掘对方意图 |

### 第 3 步：大智若愚

**核心**：不要让自己的 ego 阻碍对方沟通意愿。

- 即使经验丰富、已经有了答案，听的时候尽量呈现"我不知道"的状态（口述 02 L1644）
- **"你知道不一定得要让对方知道"**（L1640-1642）：不让自己的预设挡住对方沟通空间
- "只有对方说出来的，才是他自己的"；有时候等一等，他比你想的更有智慧

### 第 4 步：善用静默

**核心**：策略性设置对话留白，反而让沟通更深度（口述 02 L1648-1650）。

| 场景 | 操作 |
|:--|:--|
| 预留思考 | 对方讲完不要马上回应，稍做停留给思考空间 |
| 消化情绪 | 对方情绪激烈时，给时间沉默处理情绪 |
| 提示暂停 | 对方一直讲停不下来：看着对方微笑不讲话，撑不到两分钟 TA 会自己停下（L1664-1666） |

> "适当的沉默也是一种有效沟通的工具"（L930）；静默时不但能更好地听见对方，有时更能让对方听见自己（L1670）。

### 第 5 步：识别分歧

**核心**：有效沟通的基点，是理解不同意见背后的分歧点。

- 最糟糕的"共识"是对方"没意见"——参与感和主动性是"有意义共识"的重要信号
- 对方有不同意见不一定直接表达；语气和肢体语言是重要信号

### 第 6 步：识别卡点 ✅（VLM 已校对）

**核心**：在理解基础上，协助对方意识到成长卡点。

- 多数情况下，对方不知道自己不知道，所以被卡住
- 有时也知道能力不足，但缺乏提升方法
- 理解对方成长渴望和真正被卡住的瓶颈，才能更好地带领对方无限进步

## 关键技巧：克制表达欲

- 每个人有表达欲，领导面对下属的势能差会放大表达欲（L908-912）
- 最直接方法：**克制自己的表达欲**——忍住，不然猴子就到你这儿了（L912）
- 相信下属能自己解决问题；就算不能，也只是需要引导（L916-918）
- 过度表达源于焦虑：怕冷场、怕失控、怕显得无能（L924）
- 能接纳沉默也是沟通工具，就能耐着性子听完（L926）

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 紧急决策/危机处理 | 深度倾听时间成本高 | 快速收集关键事实 + 决策 |
| 对方只需明确指令 | 已确认执行型任务 | 直接下达指令，不必教练式引导 |
| 销售说服场景 | 三七法则更适用（配比策略） | tool-yitang-listening-37-rule |
| 对方拒绝沟通 | 倾听需要双方意愿 | 先处理关系/意愿问题 |
| 用倾听拖延决策 | 倾听不是逃避拍板的借口 | 听够 → 讲道理 → 拍板 |

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 表达欲失控 | 领导说 80% 下属说 20% | 定"先听三分钟"规则，克制表达欲 |
| 假倾听 | 点头但眼神飘/看手机 | 放下设备，L 型座位，眼神专注 |
| 预设挡路 | 心中已有答案，听不进对方 | 呈现"我不知道"状态（大智若愚） |
| 静默恐惧 | 一冷场就急于填补 | 接纳沉默，给思考空间 |
| 只听事实 | 忽略情绪和意图 | 3F 三层都听，追问意图 |

## 行动 Checklist

- [ ] 一对一前：清空桌面、准备纸笔（非电子）
- [ ] 对方进门：起身、拉椅子、L 型座位
- [ ] 倾听中：眼神专注（鼻梁三角区）、适时点头微笑
- [ ] 对方讲完：停顿 2-3 秒再回应（预留思考）
- [ ] 用 3F 自检：事实听到了吗？情绪注意到了吗？意图确认了吗？
- [ ] 对话后：复盘这次互动是加币还是减币

## Critique

### 攻击者 1：ICF 教练认证体系——"倾听卡缺'强有力提问'的衔接"

**攻击论点**：ICF 八项核心能力中，积极倾听（能力 6）与强有力提问（能力 7）是连续动作，本卡只讲倾听不讲提问衔接，容易让学习者"听而不问"或"问而不听"。

**回应**：衔接在提问卡（tool-leadership-questioning-cards）中处理——本卡定位为武器库第 1 组，与提问卡（第 2 组）配合使用。承认：卡内应补一句"倾听的产出是提问的输入——3F 的意图层追问就是听→问的衔接点"。

### 攻击者 2：效率管理视角——"深度倾听是奢侈品，日常不可行"

**攻击论点**：每个下属都做 6 步深度倾听，管理者时间不够。日常运营中"头不抬"式倾听才是常态，深度倾听只能用于少数关键对话。

**回应**：口述 02 已给频率答案——"重要的时刻给击穿式的反馈，日常保持一定频率"（口述 01 L2964-2972）。对应地，深度倾听用于关键对话（一对一/复盘/分歧处理），日常用简版（专注+3F）。承认：卡内应标注"6 步全流程用于高价值对话，日常可压缩为专注+3F"。

### 攻击者 3：行为学派——"肢体语言清单有文化差异风险"

**攻击论点**：眼神专注、竖大拇指、点头微笑在东亚语境下可能被解读为压迫（盯视）或敷衍（机械点头）。清单化的肢体语言在不同文化下含义不同。

**回应**：口述 02 已给变通（"眼对眼看着不舒服，可以看鼻梁三角区"L958），说明非机械执行。承认：肢体语言应"真诚优先、清单为参考"，机械执行会适得其反。

## Synthesis

- **不要用的场景**：紧急决策、纯指令任务、销售说服场景（三七法则）、对方拒绝沟通
- **关联表**：
  - `[[tool-leadership-questioning-cards]]`：听→问衔接（3F 意图层追问）
  - `[[tool-leadership-feedback-cards]]`：反馈前先倾听
  - `[[framework-leadership-coin-model]]`：倾听是加币行为，打断是减币
  - `[[tool-yitang-listening-37-rule]]`：销售场景对照
  - `[[framework-how-to-know-a-person]]`：认识他人的入口
- **Action Triggers**：
  - 对方汇报时你打开手机 → 放下，眼神专注
  - 对话中你说话超过对方 → 启动"先听三分钟"
  - 对方情绪激动 → 用静默场景 2 给消化时间
  - 对方一直讲不停 → 用静默场景 3 策略性暂停
  - 讨论僵持 → 用"识别分歧"找真正的分歧点

## 可迁移场景

1. **一对一辅导**：6 步全流程
2. **周会/复盘**：简版（专注 + 3F + 识别分歧）
3. **客户沟通**：听需求 → 提问（出口式咨询的前置）
4. **家庭沟通**：克制表达欲 + 静默场景 2（处理情绪）
5. **Agent 协作**：理解用户的真实意图（3F）再行动，避免误解需求
