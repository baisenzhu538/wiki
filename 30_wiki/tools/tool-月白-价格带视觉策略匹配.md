# 技能：价格带视觉策略匹配

## 原始表述

价格带视觉策略匹配是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 明确产品所在价格带（如10元/19元/200元以下）
2. 分析客群类型：价格敏感型or品质追求型
3. 选择对应视觉语言：低价=真实朴素/高亮食欲；高价=精致质感/氛围营造
4. 检查图片与门店实际是否一致，避免'精致图配小店'的错配
5. 输出匹配解决方案的视觉物料
