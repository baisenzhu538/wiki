# 技能：关键假设识别与验证

## 原始表述

关键假设识别与验证是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 将项目方案完整梳理为假设集合
2. 区分一般假设与关键假设（项目成败的决定性前提）
3. 优先验证关键假设是否成立
4. 关键假设不成立时及时调整方案或终止
5. 该过程可独立借助业务创新方法完成，不必然依赖AIGC
