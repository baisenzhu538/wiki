# Y模型STEPS策略集

## 一句话定义

**STEPS** 是 Y 模型的五步策略框架：Scope(范围)→Target(目标)→Evaluate(评估)→Plan(计划)→Sync(同步) [conf=0.78, source=一堂原创]。

## STEPS 五步

| 步骤 | 做什么 |
|:---|:---|
| S-Scope | 定义问题的范围和边界 |
| T-Target | 设定可量化的目标 |
| E-Evaluate | 评估可选方案的收益/成本/风险 |
| P-Plan | 制定执行计划（谁/什么时候/做什么） |
| S-Sync | 和相关方同步对齐 |

## 与决策三角形的关系

决策三角形提供三维诊断框架（宽度×高度×深度），STEPS提供五步执行流程。前者帮你「看清楚」，后者帮你「动起来」。
