# 华为五看三定

> 五看三定是BRM框架中"战略规划"环节的实战工具。源自IBM BLM，被华为深度适配后成为中国企业最常用的战略规划方法之一。

## 五看

| 看什么 | 关键问题 |
|:---|:---|
| 看行业 | 行业趋势？技术变革？政策变化？ |
| 看市场 | 市场规模？增速？细分机会？ |
| 看客户 | 客户需求变化？购买决策变化？ |
| 看竞争 | 对手在做什么？他们的优劣势？ |
| 看自己 | 我们的核心能力？资源？差距？ |

## 三定

| 定什么 | 关键问题 |
|:---|:---|
| 定控制点 | 我们靠什么赢？护城河在哪？ |
| 定目标 | 3-5年做到什么程度？ |
| 定路径 | 分几步走？每一步的里程碑？ |
