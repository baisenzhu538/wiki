# 华为五看三定

> **Burn line**: 五看三定是华为从 IBM BLM 适配而来的战略规划工具：先看清楚行业、市场、客户、竞争、自己，再定控制点、目标和路径。

## Purpose

为企业战略规划提供一个结构化思考框架，避免战略制定停留在口号和目标层面。

## Protocol

### 第一步：五看

| 看什么 | 关键问题 | 输出物 |
|---|---|---|
| 看行业 | 行业趋势？技术变革？政策变化？价值链如何演变？ | 行业趋势报告 |
| 看市场 | 市场规模？增速？细分机会？进入壁垒？ | 市场机会地图 |
| 看客户 | 客户需求变化？购买决策变化？痛点和爽点？ | 客户画像与 JTBD |
| 看竞争 | 对手在做什么？他们的优劣势？可能的反应？ | 竞争格局分析 |
| 看自己 | 核心能力？资源？差距？组织适配性？ | 能力差距分析 |

### 第二步：三定

| 定什么 | 关键问题 | 输出物 |
|---|---|---|
| 定控制点 | 我们靠什么赢？护城河在哪？ | 控制点清单 |
| 定目标 | 3-5 年做到什么程度？ | 战略目标体系 |
| 定路径 | 分几步走？每一步的里程碑？ | 战略路线图 |

### 第三步：闭环

将三定结果分解为年度经营计划、预算、KPI，并每季度复盘五看假设是否仍然成立。

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|---|---|---|
| 0-1 早期创业 | 没有足够数据和市场认知跑完五看 | 用精益画布或商业模式画布 |
| 个人职业规划 | 个人不需要五力全景分析 | 用个人 IKIGAI 或职业锚定工具 |
| 单一功能优化 | 局部优化不需要战略级框架 | 用 A/B 测试或流程优化工具 |
| 危机求生存 | 时间窗口不允许完整五看三定 | 用危机决策框架或战时指挥部机制 |

## 质疑

### 内部局限

1. **具体假设：企业有数据和能力完成五看**
   五看需要大量行业研究、客户调研、竞争情报。**边界**：本工具更适合有专门战略部门或外脑支持的中大型企业。

2. **容易变成"填表运动"**
   如果只是为了输出 PPT 而做五看，容易流于形式。**反例**：某企业每年做五看三定，但三定结果与年度预算脱节，战略和执行两张皮。

3. **周期较长**
   完整五看三定通常需要 1-3 个月，快速变化的市场中可能刚做完就过时。

### 外部攻击

#### **Henry Mintzberg**

**攻击**：战略规划框架往往假设战略是"制定"出来的，但真实战略很多是在执行中涌现的。五看三定可能扼杀适应性。

**回应**：本工具定位为"战略思考的起点"，不是战略的终点。定出的目标和路径应作为假设，在执行中根据新信息迭代。

### Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---|---|---|
| 年度战略规划启动 | 组建跨部门团队，制定五看计划 | 2 周内完成五看分工 |
| 行业发生重大变化 | 重新跑一遍五看，更新三定 | 1 个月内更新战略假设 |
| 战略目标无法落地 | 检查三定是否与预算/KPI 挂钩 | 100% 目标有对应执行计划 |
