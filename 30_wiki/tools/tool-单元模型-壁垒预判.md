# 壁垒预判工具：六维竞争壁垒自评

## 1. 一句话定义

壁垒预判工具是从**无形资产、转化成本、技术壁垒、网络效应、规模效应、成本优势**六个维度，对业务当前护城河强弱进行结构化自评的诊断表，用以回答"别人抄我怎么办"之前置问题。[conf=0.70, source=一堂原创]

## 2. 为什么重要

1. **识别伪壁垒**：在单元模型跑通前把"品牌口号""技术领先"等光环与真护城河区分开，避免战略误判。[conf=0.70, source=一堂原创]
2. **团队对齐与投资排序**：把"我感觉有壁垒"转化为可逐项打分的强弱矩阵，便于统一语言、聚焦资源。[conf=0.70, source=一堂原创]
3. **与单元模型咬合**：能判断壁垒是否落在最小经济单元上；若壁垒无法体现在单元模型的成本或收入结构中，则难以规模化复制。[conf=0.70, source=一堂原创]

## 3. 核心机制 / 结构

原图将壁垒拆解为**六类**，并将"无形资产"再细分为四个子项，形成"**类型 → 要素 → 强弱**"三列表：

| 壁垒类型 | 要素（一堂自评示例） | 强弱 | 含义 |
|---|---|---|---|
| **无形资产** | 品牌：学创业来一堂 | 强 | 用户心智占位，可跨单元模型复用 |
| | 专利 | × | 无专利保护 |
| | 法定许可 | × | 无牌照/资质门槛 |
| | Know-how：教研方法 | 弱（暂时） | 方法论沉淀中，尚未形成高复制门槛 |
| **转化成本** | 方法论+作业 | 弱 | 用户学习投入形成一定沉没成本，但切换仍低 |
| **技术壁垒** | 无 | × | 平台/算法/专利未构成独占 |
| **网络效应** | 无 | × | 用户之间互动未形成正向循环 |
| **规模效应** | 课程研发、直播课运营 | 弱 | 部分内容可复制摊薄，但边际成本下降有限 |
| **成本优势** | 无 | × | 无独特资源或流程成本领先 |

[conf=0.80, source=原图/VLM描述]

六维并非等权，实际评估时应结合**单元模型**判断：哪一类壁垒能直接改善单元经济模型的收入、成本或持续性。

## 4. 边界与反例

- **不适用于需求未验证阶段**：没有真实收入/用户前谈"网络效应""规模效应"通常是伪命题。[conf=0.70, source=一堂原创]
- **不能替代专业尽调**：专利、法定许可需要法律/财务确权，表格只是快速自评。[conf=0.70, source=一堂原创]
- **强弱标记是相对概念**："强"只说明在六维中相对占优，不保证能抵御头部玩家跨界攻击。[conf=0.70, source=一堂原创]
- **反例**：某课程平台品牌声量"强"，但内容同质、转化成本低，被低价竞品快速抢走用户——品牌未与转化成本或规模效应绑定，护城河虚胖。[conf=0.70, source=一堂原创]

## 5. 失败模式（≥3 条）

1. **把"有品牌口号"当品牌壁垒**：没有复购、口碑或搜索心智支撑，口号只是营销文案。[conf=0.70, source=一堂原创]
2. **忽视无形资产中的 Know-how**：只盯专利/牌照，忽略流程、教研、行业 know-how 的渐进式积累。[conf=0.70, source=一堂原创]
3. **误判网络效应土壤**：社交/交易平台才具备网络效应，单点内容付费强行设计"社区"常是成本黑洞。[conf=0.70, source=一堂原创]
4. **在规模不经济业务上追求规模效应**：To B 重定制、重交付时，规模扩大反而人效下降，应优先转化成本或无形资产。[conf=0.70, source=一堂原创]
5. **壁垒与单元模型脱节**：壁垒建在总部职能，而最小经济单元本身不赚钱，护城河只是空中楼阁。[conf=0.70, source=一堂原创]

## 6. 与已有框架的关系

- 是一堂五步法"壁垒分析"的前置/自评工具，输出结果可进入 [[yt-barrier-analysis-cheat-sheet]] 的"6 大壁垒类型"做深化。[conf=0.70, source=一堂原创]
- 与 [[yt-unit-model-overview]] 形成"先算单元、再判壁垒"的闭环：单元模型回答"能不能赚钱"，壁垒预判回答"能不能守得住"。[conf=0.70, source=一堂原创]
- 在 To B 场景中，需结合 [[yt-tob-barriers]] 的三类壁垒选择（转化成本、规模效应、无形资产）与规模不经济对抗策略。[conf=0.70, source=一堂原创]
- 与 [[yt-barrier-identification-skill]] 的"真假壁垒四问"衔接：预判打分后，再用四问验证"强"项是否是真壁垒。[conf=0.70, source=一堂原创]

## 7. 可迁移场景

- 创业项目路演前的护城河自检。[conf=0.70, source=一堂原创]
- 产品战略规划会：识别当前阶段应重点投资哪一类壁垒。[conf=0.70, source=一堂原创]
- 投资/并购标的初步尽调：快速标注目标公司护城河结构。[conf=0.70, source=一堂原创]
- 进入新市场/新业务线前，评估自身可复用的壁垒与需新建的壁垒。[conf=0.70, source=一堂原创]

## 8. 行动 checklist

- [ ] 明确最小经济单元：先完成 [[yt-unit-model-overview]] 选择，再填壁垒预判表。[conf=0.70, source=一堂原创]
- [ ] 逐项标注"要素"：把抽象优势写成可被观察、被验证的具体对象。[conf=0.70, source=一堂原创]
- [ ] 用"× / 弱 / 强"三档自评，避免中间模糊；"弱"需注明是暂时还是结构性。[conf=0.70, source=一堂原创]
- [ ] 对"强"项执行 [[yt-barrier-identification-skill]] 真假壁垒四问验证。[conf=0.70, source=一堂原创]
- [ ] 对"×"项判断：是不需要、未建成，还是无法建成，并写入 90 天壁垒建设计划。[conf=0.70, source=一堂原创]
- [ ] 将壁垒强度映射到单元模型：看其是否提升收入、降低边际成本或提高用户留存。[conf=0.70, source=一堂原创]
- [ ] 每季度复评一次，跟踪"弱（暂时）"项是否向"强"转化。[conf=0.70, source=一堂原创]

## 9. Critique

- **Michael Porter** 的产业结构视角会认为，六维工具忽视了"行业吸引力"与"五力"的情境：同一壁垒在不同产业结构中的价值差异巨大，脱离行业集中度和进入壁垒谈"强/弱"容易误判。[conf=0.70, source=学者视角]
- **Bruce Greenwald** 在《竞争优势》中强调，真正可持续的壁垒通常只有三类：供给端的成本优势、需求端的客户锁定（转化成本/习惯）、规模经济效应。六维工具中的"技术壁垒""网络效应"若不能转化为上述三类，可能只是暂时领先而非真正护城河。[conf=0.70, source=学者视角]
- **Hamilton Helmer** 的《7 Powers》会追问：每项壁垒是否对应"规模经济、网络效应、反定位、切换成本、品牌效应、垄断资源、流程效能"中的某种 Power，否则只是形容词。[conf=0.70, source=学者视角]
- 实践者视角：**任正非**在华为内部强调"领先半步是先进，领先三步是先烈"——技术/专利壁垒若与市场节奏脱节，评估表上的"强"可能变为现金流陷阱。[conf=0.70, source=实践者视角]
