# 框架三板斧：短剧英雄之旅结构工具

> **Burn line**: 英雄不是一上来就无敌，而是被深渊逼出光芒。

框架三板斧是冰火写本罗盘中"框架大纲"维度的核心工具，将短剧结构简化为英雄之旅的三个阶段：**深渊入局闯难关、迷雾博弈克万难、决战收官展不凡**。它解决的是"一部短剧的整体骨架如何搭建"的问题，对应传统三幕剧：入局（第一幕）、对抗（第二幕）、结局（第三幕），但针对短剧的快节奏和高密度钩子做了压缩和本土化。

## Claims

- **C1 [conf=0.9]**: 框架三板斧是短剧版"英雄之旅"，三阶段分别对应：触发困境、递进对抗、终极对决。
- **C2 [conf=0.85]**: "深渊入局"必须在开局 1-3 集内完成，主角被抛出日常，进入高风险情境。
- **C3 [conf=0.85]**: "迷雾博弈"是剧集主体（约 60%-70% 集数），需要设计 3-5 个递进障碍，每个障碍都比前一个更难。
- **C4 [conf=0.8]**: "决战收官"不是简单的胜利，而是主角在决战中的选择体现了全剧主题，并完成情绪升华。
- **C5 [conf=0.8]**: 该框架可转化为 AI prompt 模板，用于生成短剧分集大纲或检查已有大纲的结构完整性。
- **C6 [conf=0.75]**: 三斧与"剧本策划三板斧"中的"内容走向"直接对应：入局=起、迷雾=承转、决战=合。

## Purpose

帮助短剧创作者在动笔前搭建整体结构骨架，确保剧本有清晰的**入局触发、中段递进和终极对决**。适用于已有剧本基地（题材、主角、欲望、阻碍）但不知道如何组织全剧结构的场景。

---

## Protocol

### 步骤 1：深渊入局 — 设计触发困境

1. 写出主角的"日常状态"和"欲望缺口"。
2. 设计一个在第 1-3 集内发生的"深渊事件"，让主角不得不离开日常：
   - 被羞辱、被陷害、被退婚、被解雇
   - 获得神秘身份/能力，但伴随代价
   - 亲人/爱人陷入危机，主角必须行动
3. 确认主角有"不能退"的理由：情感羁绊、复仇动机、身份责任。

### 步骤 2：迷雾博弈 — 设计递进障碍

1. 将全剧中间部分（约第 4 集到倒数第 5 集）划分为 3-5 个障碍层级。
2. 每个层级满足：
   - 比上一层更难
   - 揭示反派/困境的新信息
   - 迫使主角做出选择或牺牲
3. 在每层障碍之间插入"小胜利"或"假解脱"，维持观众期待。

### 步骤 3：决战收官 — 设计终极对决与情绪落点

1. 确定最终 BOSS 或最终考验（不一定是人，也可能是心魔、社会偏见、时间）。
2. 写出决战中的关键选择：主角为了胜利必须放弃什么？
3. 设计结局情绪落点：大快人心、意难平、豁然开朗、余韵悠长。
4. 倒推检查：决战是否回应了开局欲望和中段障碍？

### AI 使用方式

将三斧转化为 prompt：

```
请基于"框架三板斧"为以下短剧生成 24 集大纲：
1. 深渊入局（1-3 集）：写出主角进入困境的触发事件
2. 迷雾博弈（4-19 集）：设计 4 个递进障碍，每个障碍标注难度升级点
3. 决战收官（20-24 集）：写出终极 BOSS、关键选择和情绪落点
输出：分集标题 + 一句话剧情 + 每集钩子
```

## When NOT to Use

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **单元剧/系列小品** | 每集独立，不需要统一英雄之旅。 | 使用"单集钩子模板"或"情境喜剧结构"。 |
| **群像短剧** | 多主角并行，单一英雄之旅无法覆盖。 | 使用"多线并进结构图"，为每个主角设计 mini 三斧。 |
| **实验性/反类型短剧** | 故意打破三幕结构，使用框架会削弱实验性。 | 使用作者电影分析框架或后现代叙事理论。 |
| **只有 6 集以内的超短剧** | 集数太少，无法铺陈迷雾博弈的递进。 | 使用"单集闭环结构"或"起-转-合"压缩版。 |

## Constraints & Boundaries

| 边界 | 说明 |
|------|------|
| **适用题材** | 逆袭、复仇、悬疑、甜宠、重生等强主线型题材效果最好。 |
| **入局速度** | 短剧节奏要求深渊事件必须在 3 集内发生，传统长剧可以拖延。 |
| **障碍递进** | 每个新障碍必须比前一个更难，否则观众会感到重复。 |
| **决战非打斗** | "决战"可以是商业谈判、身份揭露、情感抉择，不一定是动作戏。 |
| **AI 边界** | AI 擅长生成套路化三斧，但"选择背后的主题深度"需要人把控。 |

## [Critique]

### 内部局限性

- 框架三板斧对"日常状态"的铺垫要求较高，短剧开头时间有限，可能来不及让观众共情主角的日常就进入深渊。
- "迷雾博弈"强调递进障碍，但对障碍之间的"情绪曲线"设计不足，容易变成机械升级。
- 三斧假设主角是单一英雄，对双主角、群像剧、反英雄主角的覆盖不足。

### 外部攻击：Joseph Campbell — "单一神话"的同质化风险

**Joseph Campbell**（《千面英雄》作者，常被译为约瑟夫·坎贝尔）会认为：英雄之旅是人类故事的深层结构，但当所有短剧都按"深渊-迷雾-决战"三斧生产时，市场会迅速陷入"单一神话"的同质化。观众对套路产生免疫后，再标准的结构也会失效。

### 外部攻击：Vladimir Propp — "功能项"比"阶段"更精确

**Vladimir Propp**（《故事形态学》作者，常被译为弗拉基米尔·普罗普）会认为：真正的结构分析应该拆到"功能项"（如缺席、禁令、欺骗、争斗）层面，而不是停留在"三阶段"这种粗粒度划分。三斧对实际创作的指导颗粒度不够。

### 反事实测试

- 如果去掉"深渊入局"，主角直接进入迷雾博弈，会怎样？观众缺少情感锚点，对后续障碍的投入感会下降。
- 如果决战只是主角大获全胜，没有任何代价或选择，会怎样？爽完即忘，无法形成口碑或二创传播。
