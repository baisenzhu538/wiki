# 技能：AI质价比评估方法

## 原始表述

AI质价比评估方法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 评估任务：AI做 vs 自己做
2. 计算AI修改细节的耗时（如20-30分钟）
3. 对比自己手动操作耗时（如10分钟）
4. 选择成本小于无法替代的方案

## 适用场景

- 选择设计工具和工作流时
- 评估是否使用AI agent时
- 优化个人/团队效率时

## 不适用场景

- AI明显更优时无需评估
- 手动操作明显更快时

## 工具/环境

- 计时工具
- 各AI平台

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

避免盲目追求AI而忽视实际效率，很多AIGC设计agent在细节修改上复杂度过高，不如传统方式
