# 技能：内容创作中的观察训练法

## 原始表述

内容创作中的观察训练法是李诞在创作分享中提出的实操方法。

## 操作步骤

1. 在看任何内容（影视剧、短视频等）时，不只被动'看'，要主动'观察'
2. 观察镜头调度、剧情节奏、预算分配等技术层面
3. 将观察到的一切转化为创作素材，'像疯狗一样去占有'
4. 把世界据为己有的方法：把一切变成自己的创作
