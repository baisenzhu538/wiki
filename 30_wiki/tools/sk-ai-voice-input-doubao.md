# 技能：口喷式语音输入法

## 用一句话讲清楚

用手机语音输入法（如豆包输入法）把灵光一现的想法立刻口述成文字，再转给笔记或 AI 工具整理，避免“等有空再记”导致的遗忘。

> **Burn line**：想法不等人，口喷先捕获，文本再打磨。

## 核心要点

| 维度 | 说明 |
|---|---|
| **核心目标** | 在想法出现的当下完成捕捉，降低遗忘损耗 |
| **关键输入** | 灵光一闪的问题、灵感、待办、复杂提示词 |
| **关键输出** | 可编辑的文本草稿，供后续整理或交给 AI |
| **核心原则** | 先说再修，不要等“组织好语言” |
| **工具选择** | 手机端语音输入法（豆包输入法为例），支持普通话/部分方言识别 |
| **人的角色** | 开口说、做快速校对、决定后续整理方式 |
| **AI 的角色** | 接收文本后做结构化、扩展、执行 |

## Protocol/Procedure

### Step 1：安装与配置

1. 在手机应用商店下载安装豆包输入法（iOS / Android）。
2. 系统设置中授予麦克风与语音输入权限。
3. 设置顺手触发方式（建议：长按空格键；也可按个人习惯设置）。

### Step 2：日常口喷捕获

1. 有想法时立即触发语音输入。
2. 直接说，不要等待“组织好语言”——先说再修。
3. 说完后检查识别结果，快速修正错字和歧义。
4. 复制文本到目标应用（备忘录 / 微信 / 飞书 / AI 对话框）。

### Step 3：与 AI 工具联动

1. 在 AI 对话框中切换为豆包输入法。
2. 用语音输入复杂提示词或长描述（比手机键盘输入更快）。
3. 检查 AI 接收后的文本，确认意图未被语音识别改变。
4. 若识别错误率高，改用键盘输入关键词段落。

## 边界

| 边界 | 说明 |
|---|---|
| **适用场景** | 灵感捕捉、待办记录、复杂提示词初稿、不便打字的移动场景 |
| **不适用场景** | 需要高精度术语 / 代码 / 多语言混合的输入 → 键盘输入更可靠 |
| **不适用场景** | 敏感 / 保密信息 → 注意语音输入法的隐私与云端识别风险 |
| **来源约束** | 当前操作细节主要来自个人经验演绎，非官方 SOP |
| **不替代校对** | 语音识别必有错误，必须人工快速校对 |
| **最小启动** | 只要手机 + 豆包输入法即可开始 |

## 失败模式

| 失败模式 | 典型症状 | 原因 | 修复/预防 |
|---|---|---|---|
| 等“组织好语言”再说 | 想法消失或记录不完整 | 过度追求完美即时性 | 先口喷再编辑，接受初稿 |
| 跳过校对直接发送 | 别人看到错字、AI 理解偏差 | 语音识别错误未修正 | 养成“说完必看”习惯，快速校对 |
| 环境嘈杂 / 口音重 | 识别率暴跌，反复重说 | 输入条件差 | 换安静环境、戴耳机，或改用键盘输入关键词 |
| 对敏感信息口喷 | 隐私泄露风险 | 语音经过云端识别 | 敏感内容改用键盘输入或本地工具 |
| 把口喷当最终交付 | 文本结构混乱、逻辑跳跃 | 缺少二次整理 | 口喷产物必须再编辑 / 结构化后再输出 |
| 工具设置未就绪 | 想用时找不到触发入口 | 未提前配置 | 提前设置好快捷键并演练一次 |
