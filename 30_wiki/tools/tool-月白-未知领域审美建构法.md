# 技能：未知领域审美建构法

## 原始表述

未知领域审美建构法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 区分狭义审美（图好不好看）与广义审美（商业适配性、场景合理性、用户感知等）
2. 进入新领域时，先大量收集该领域最佳实践案例（Best Practice）
3. 用'十层解读'框架逐层拆解案例（如：战略层→用户层→场景层→视觉层等）
4. 建立该领域的审美坐标系，再动手设计
