# 智能药柜/智慧药房招商骗局识别清单

> **核心定位**：智能药柜/智慧药房招商领域存在典型骗局模式。本卡以"修正未来智慧药房"等案例为镜鉴，提供招商合作前的风险识别 checklist。

---

## Summary

智能药柜/智慧药房招商骗局的典型特征：

- **高收益承诺**：宣称"躺赚""月入过万""半年回本"，但无真实运营数据支撑。
- **品牌背书滥用**：借用知名药企/互联网平台名义招商，实际运营主体与品牌方关系不清。
- **合同陷阱**：加盟费/设备费一次性收取，后续无实质服务；合同条款模糊，退款无门。
- **虚假点位**：承诺医院、社区等优质点位，实际投放位置偏远或无人流。
- **无实际运营**：收取费用后不提供设备、不补货、不维护，投资者收益"每月仅几元"。

> **核心原则**：任何承诺"低风险高回报"的药柜加盟/投资项目，都应先按本卡逐项排查。

## Claims

### 1. 典型骗局：修正未来智慧药房案例

| 维度 | 事实 |
|---|---|
| 招商主体 | 海南清修智能药柜科技有限公司（修正集团授权为"未来药房项目唯一经营主体"） |
| 宣传话术 | 宣称"修正集团背书""24 小时无人药房""高收益回报""投资 7 万元/台，预估年收益分润 6 万余元，1 年多回本" |
| 受害者规模 | 黑猫投诉平台截至 2024-06-14 投诉量达 **155 条** |
| 典型投诉 | 虚假宣传、不履行合同、拖欠违约金、收益仅几元 |
| 实际收益 | 投资者反映月收益"几元、十几元、几毛钱"；有投资者 2 年多总收益仅 **776.25 元**；汉中 31 台机器 2022.4–2023.11 月均区域销售 **151 元/台** |
| 司法状态 | 海南清修已被列为**被执行人**；法定代表人徐国梁被**限制高消费**；2024 年上半年 4 起执行案件，总金额约 43.9 万元；与上海家营物业房屋租赁合同纠纷**终本**（法院认定"暂无财产可供执行"） |
| 公司回应 | 黑猫投诉商家回复承认"前期内外部因素运营不力导致公司无力推进地推活动收益甚微，目前公司资金匮乏，实在无法解决委托人诉求" |
| 核心教训 | 品牌背书不等于项目可靠；招商合同与实际运营能力需分开审查 |

### 2. 招商骗局 8 大识别信号

| 信号 | 具体问题 | 排查动作 |
|---|---|---|
| **1. 高收益承诺** | "月入过万""半年回本""躺赚" | 要求提供已运营点位的真实销售额、回本周期、分成记录 |
| **2. 模糊点位资源** | 仅承诺"医院/社区/高校"，无具体地址 | 要求提供拟投放点位的清单、租赁合同/合作协议 |
| **3. 一次性高额加盟费** | 加盟费、设备费、保证金一次性收取 | 核实费用明细，对比市场设备价格；避免一次性大额预付 |
| **4. 品牌背书滥用** | 借用知名药企、互联网平台名义 | 核实授权文件真实性，查询品牌方官网/工商登记 |
| **5. 合同条款不对等** | 退款难、违约责任轻、服务承诺模糊 | 请律师审核合同，重点看退款条件、违约责任、服务清单 |
| **6. 无实际运营能力** | 无设备交付、无补货、无维护 | 实地考察已运营点位，访谈其他加盟商 |
| **7. 资质不全** | 无药品经营许可证、无 GSP 体系 | 查询《药品经营许可证》、企业信用报告、司法风险 |
| **8. 涉嫌违规销售** | 宣称可售处方药/甲类 OTC | 对照国家 48 号公告，仅乙类 OTC 可售 |

### 3. 合作前必查清单

#### 企业资质
- [ ] 营业执照、药品经营许可证（或依托药店的许可证）。
- [ ] 企业信用报告（企查查/天眼查）：注册资本、实缴资本、股东结构、历史变更。
- [ ] 司法风险：是否被列为被执行人、限制高消费、股权冻结、诉讼记录。
- [ ] 行政处罚：是否有药监局、市场监管局处罚记录。

#### 项目真实性
- [ ] 已运营点位清单及地址。
- [ ] 至少实地走访 2–3 个已运营点位。
- [ ] 访谈 2–3 位现有加盟商/投资者，了解真实收益和运营支持。
- [ ] 设备实际交付情况、补货频率、故障处理响应时间。

#### 合同与财务
- [ ] 费用明细表：加盟费、设备费、系统费、维护费、分成比例。
- [ ] 退款条款：什么条件下可退、退款周期、违约金计算。
- [ ] 收入结算方式：日结/月结、对账方式、提现门槛。
- [ ] 违约责任：双方违约情形及赔偿标准。

#### 合规性
- [ ] 可销售药品种类是否符合当地政策（通常仅乙类 OTC）。
- [ ] 是否具备执业药师远程审方/药学服务。
- [ ] 是否具备药品追溯码、温湿度监控等合规功能。

### 4. 推销方四类话术模式识别（来自诊所访谈交叉验证）

| 话术模式 | 典型案例 | 识别方法 |
|---|---|---|
| **政策包装** | 将国家统一的诊所备案要求说成“广东要求” | 核对政策发布层级：国家统一要求、省级试点还是地方执行？ |
| **场景混淆** | 将“医疗机构内智能取药机可售处方药”与“零售药店自助售药机”混为一谈 | 明确药柜设置主体：药店 vs 诊所/医院，适用法规完全不同 |
| **利润夸大** | 强调原研药高毛利、药柜引流、会员预充值锁定现金流 | 要求提供真实运营数据、转化率、合规成本，区分“逻辑可行”与“已验证” |
| **合规风险淡化** | 将“大医院处方照方开药”“院内药柜利润反哺医院”包装为成熟模式 | 对照《处方管理办法》《反不正当竞争法》《医疗机构管理条例》等红线 |

### 5. 新增风险信号（来自诊所访谈及第八轮深挖）

| 信号 | 具体问题 | 排查动作 |
|---|---|---|
| **宣称系统内测很短即可上线** | “系统内测已有两周，基本功能没问题” | 要求提供测试报告、客户案例、医保/药监对接证明 |
| **引用无法核实的品牌/产品** | 如“修正点检”公开渠道查无此产品 | 核实产品名称、备案信息、品牌授权关系 |
| **医疗短视频 MCN 代运营** | 平台已禁止医疗账号交由 MCN 机构运营 | 要求说明合规审核流程，确认不违反视频号/抖音医疗内容规则 |
| **预充值/会员制锁定现金流** | 医疗预付卡受单用途预付卡及地方卫健委监管 | 确认是否备案、资金存管、退费机制 |
| **宣称掌握平台流量密码/AI 批量生成文案** | AI 生成医疗科普须显著标识；批量同质化 AI 文案已被四部门点名清理；视频号禁止流量包投放 | 要求提供内容合规审核流程、广告审查证明、AI 标识机制 |
| **用普通自动售货机数据套用药柜** | 饮料/零食自动售货机高频低价，不能套用于乙类 OTC 药柜 | 要求提供药柜专用运营数据，而非普通智能货柜数据 |
| **宣称巨头也在做/即将进入** | 阿里、京东、美团、饿了么、叮当、平安均未公开布局诊所+药柜 | 核实具体是哪家巨头、什么场景、是否有公开公告 |

### 6. 一旦受骗的应对路径

1. **保留证据**：合同、付款记录、聊天记录、宣传资料、设备交付记录。
2. **协商退款**：书面致函要求解除合同并退款。
3. **投诉举报**：
   - 黑猫投诉、12315 消费者投诉平台；
   - 当地市场监督管理局（虚假宣传、合同欺诈）；
   - 当地药品监督管理局（无资质经营药品）。
4. **司法途径**：
   - 民事诉讼：要求解除合同、返还费用、赔偿损失；
   - 刑事报案：若涉嫌合同诈骗，向公安机关报案。
5. **集体维权**：联合其他受害者，降低单人体力成本，提高关注度。

## Critique

### 局限性

1. **案例代表性**：修正未来药房是当前公开信息最完整的案例，但不能代表全部招商项目；也有正规药柜运营商存在。
2. **证据时效性**：司法状态会变化，合作前应重新查询最新司法风险信息。
3. **不能替代法律尽调**：本卡为风险识别清单，重大投资前应聘请律师/会计师做正式尽职调查。

### 与已有知识的联系

- **认知偏差视角**：招商骗局识别本质是对确认偏误（"知名品牌背书"）、故事偏误（"躺赚故事"）、锚定效应（"高收益承诺"）的防御。参考 `master-cognitive-bias-checklist`。
- **决策卫生视角**：本清单要求在投资前逐项排查企业资质、项目真实性、合同财务、合规性，是"先证据后结论"的决策卫生实践。参考 `master-decision-hygiene`。
- **反脆弱视角**：避免一次性大额加盟费、要求实地走访已运营点位，是为了让投资决策在信息不对称环境下更具韧性。参考 `master-antifragile-checklist`。
- **失败模式视角**：修正未来药房案例可与 `kc-p1-04-failure-patterns` 联动，作为"品牌背书滥用 + 虚假点位 + 合同陷阱"的典型失败模式。

### 使用建议

- 在考虑任何药柜加盟/投资前，先完成本清单 8 大信号排查。
- 特别警惕"知名品牌背书+高收益承诺+一次性大额收费"的组合。
- 宁可错过一个项目，也不要踩进一个骗局。
