# 技能：新媒体热点物料快速迭代法

## 原始表述

新媒体热点物料快速迭代法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 明确核心目标：快速出图、快速迭代、快速试错，而非追求好看
2. 聚焦本质需求：获得点击、获得阅读完成率
3. 降低设计感和美感的优先级
4. 建立标准化模板，替换核心情绪点即可批量产出

## 适用场景

- 追热点运营物料
- 超级个体无专职设计/运营
- 需要为微信公众号、小红书、抖音快速产出内容
- 测试验证阶段

## 不适用场景

- 品牌重大发布
- 需要精致品牌调性表达
- 时间充裕可精细打磨

## 工具/环境

- AI图像生成工具
- 模板库

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

热点时效性要求速度优先，快速试错才能找到高传播性内容；运营物料的本质是获得点击而非艺术表达
