# 技能：+1视角升级思考法

## 原始表述
> 如果+1视角思考，这个事情该怎么评估？

## 操作步骤
1. 明确自己当前视角层级（如执行层/管理层）
2. 向上提升一个层级重新定义问题边界
3. 用更高层级的KPI和约束条件重新评估
4. 对比原视角与+1视角的结论差异

## 质疑

- **具体假设**：该工具假设"向上一个视角总能获得更好的决策质量"，但在某些场景中，更高视角可能脱离一线执行细节，导致决策虽然"战略正确"但"执行不可行"——视角升级的**边界**在于信息完整度。
- **反例**：基层工程师被要求"+1 视角"思考时，可能因为缺乏高层信息（公司战略、财务约束）而做出更差的判断，而非更好的判断。

**Daniel Kahneman**（普林斯顿大学心理学家，诺贝尔经济学奖得主）会质疑："+1 视角"假设视角切换是低成本操作，但他的研究表明，人类在不同思维框架间切换时存在严重的"锚定效应"——你当前的视角会系统性地扭曲你对更高视角问题的理解，纯粹的"向上想一层"很难做到。
