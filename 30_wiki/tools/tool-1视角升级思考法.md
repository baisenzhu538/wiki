# 技能：+1视角升级思考法

## 原始表述
> 如果+1视角思考，这个事情该怎么评估？

## 操作步骤
1. 明确自己当前视角层级（如执行层/管理层）
2. 向上提升一个层级重新定义问题边界
3. 用更高层级的KPI和约束条件重新评估
4. 对比原视角与+1视角的结论差异
