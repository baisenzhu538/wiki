# 蓝海战略画布（价值曲线工具）

> 通过可视化价值曲线，把客户重视的多个竞争要素同时展示出来，从而发现"同时追求差异化与低成本"的蓝海空间。

---

## 一、工具结构

```
顾客得到的利益（高 → 低）
    │
120 ┤
100 ┤
 80 ┤        ●──●  未来定位
 60 ┤   ═══════  对客户重要性
 40 ┤─────── 竞品A
 20 ┤  ┈┈┈┈┈  竞品B
  0 ┼────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────→ 行业内竞争价值要素
       健康  口味  包装  场景  方便  易选购  人员  环境  活动  会员  价格
             解决方案  快捷  服务   服务   体验   惊喜   专享   优惠
```

---

## 二、四步动作框架

| 动作 | 问题 | 效果 |
|--|--|--|
| **剔除** | 哪些被行业认为是理所当然、实则客户不再重视的要素？ | 降低成本结构 |
| **减少** | 哪些要素投入过度，远超客户感知价值？ | 释放资源 |
| **增加** | 哪些要素客户重视但行业普遍做得不够？ | 强化差异化 |
| **创造** | 哪些行业从未提供的要素可以创造新需求？ | 开辟新市场 |

---

## 三、PPT _112 示例：零食/零售价值曲线

**竞争价值要素（X 轴）**：

| 类别 | 要素 |
|--|--|
| 产品 | 健康、口味好、包装好、场景解决方案 |
| 服务 | 方便快捷、容易选购、专业友好的人员服务、购物环境体验好、活动带给顾客惊喜/新奇、会员专享服务、特别优待 |
| 价格 | 价格优惠 |

**曲线类型**：

- 对客户重要性（红色虚线）
- 竞品 A（绿色实线）
- 竞品 B（蓝色实线）
- 竞品 C（紫色实线）
- 未来定位（绿色虚线）

**未来发力点**（红色箭头标注）：场景解决方案、方便快捷、购物环境体验好。

---

## 四、使用步骤

1. **列出竞争要素**：从客户视角归纳 8-12 个购买决策要素。
2. **评分**：邀请客户/内部专家对各要素的重要性（1-10）和各竞品表现（1-10）打分。
3. **绘制价值曲线**：同一坐标系内画出客户重要性与各竞品曲线。
4. **识别差距**：客户重视但竞品得分低的要素 = 差异化机会。
5. **四步动作重构**：决定剔除/减少/增加/创造哪些要素。
6. **设定未来定位**：画出目标价值曲线，明确发力点。

---

## 五、分析模板

```markdown
| 竞争要素 | 客户重要性 | 竞品A | 竞品B | 当前我们 | 未来定位 | 动作 |
|--|--|--|--|--|--|
| 要素1 | | | | | | 增加/减少/剔除/创造 |
```

---

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 要素来自内部视角 | 曲线好看但客户不买单 | 用访谈/问卷验证要素权重 |
| 只画不行动 | 曲线停留在PPT | 每个发力点对应具体产品/运营举措 |
| 追求全面差异化 | 成本飙升 | 配合"剔除/减少"同步降低成本 |
| 忽视动态变化 | 蓝海很快变红海 | 定期重画价值曲线，监控竞品模仿 |

## 七、Agent 执行指令

```python
def blue_ocean_canvas(industry: str, competitors: list[str]):
    """绘制蓝海战略画布"""
    prompts = {
        "竞争要素": f"列出{industry}客户做购买决策时最重视的8-12个要素。",
        "评分": f"对每个要素，给出{competitors}及本公司的1-10分表现。",
        "价值曲线": "用文本表格形式输出价值曲线数据。",
        "机会识别": "找出客户重视但竞品表现差、本公司可发力的要素。",
        "四步动作": "给出剔除、减少、增加、创造的具体建议。",
        "未来定位": "描述目标价值曲线和关键举措。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```
