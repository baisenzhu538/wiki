# 实地调研/蹲店：蹲店·谈话·数人头三板斧

> **一句话**：实地调研朴实无华——蹲店、谈话、数人头。只要把这三板斧做好了，就能砍掉90%的认知盲区。瑞幸做空报告动用了92个全职+1400个兼职，靠的就是这三件事。

---

## 核心认知

"真正赚过大钱、赔过大钱的那些老兵，特别愿意花很多很多的时间去市场上拿信息。小招小花招层出不穷——蹲店啦、数人头啦、假装合作方啦、找求职者啦——他们总能拿到一些很意外的核心情报。"

实地调研的本质：**用体力换信息质量**。它不聪明、不高科技，但它是所有调研手段中最难被造假的信息获取方式。

## 三板斧详解

### 第一板斧：蹲店（观察法）

> 啥话不说，先跑到竞品店里待两周。还不知道怎么做没关系，先待在你想做的那个竞品店里。

| 层级 | 做法 | 时间投入 | 产出 |
|:---|:---|:---:|:---|
| **浅蹲** | 以顾客身份进店，观察店面布局、产品陈列、客流高峰低谷 | 半天 | 店面的"体感地图"，知道客人在看什么、问什么 |
| **中蹲** | 在店外/商场公共区域驻点，从开门到关门完整记录客流变化 | 1-3天 | 真实的客流曲线、高峰时段、每单消费人数 |
| **深蹲** | 系统覆盖多个门店（至少选3类：旗舰店/普通店/偏远店），在同一时段交叉对比 | 1-2周 | 标准化vs非标准化运营的区别、不同区位门店的真实表现差异 |

### 第二板斧：谈话（访谈法）

> 关店调研比开店调研重要得多。访谈赔了钱的店=深层调研，访谈赚了钱的店=中层调研。

| 谈话对象 | 能问出的信息 | 可信度 | 怎么找 |
|:---|:---|:---:|:---|
| 店员/服务员 | 真实客单价、高峰时段、总部管理严格度 | ⭐⭐⭐ | 多去几次、混脸熟后闲聊 |
| 店长/加盟商 | 加盟真实成本、总部支持力度、回本周期 | ⭐⭐⭐⭐ | 以"也想开店"的身份请教 |
| 已关店/亏损加盟商 | 总部的坑、隐藏成本、选址失败原因、为什么不做了 | ⭐⭐⭐⭐⭐ | 企查查找已注销的加盟商主体，或通过中介找转让信息 |
| 竞品员工 | 内部管理问题、产品真实缺陷、公司战略方向 | ⭐⭐⭐⭐ | 招聘网站/Boss直聘约聊 |

### 第三板斧：数人头（量化法）

> 拿着计数器一单一单地数。瑞幸做空报告就是这么干的——92个全职、1400多名兼职，覆盖38个城市、981个门店，收集了25000多张小票。

| 统计维度 | 具体做法 | 关键指标 |
|:---|:---|:---|
| **进店人数** | 在店门口/商场公共区域统计进入门店的人数 | 日均客流、高峰低谷比、周末vs工作日比 |
| **购买转化** | 统计进店后实际购买/下单的人数 | 转化率 = 购买人数/进店人数 |
| **客单价** | 观察结账金额（有条件的可以收集小票） | 平均客单价、客单价分布 |
| **消费结构** | 统计点了什么产品、多少人、什么组合 | 爆品率、搭配率、单人vs多人消费比 |

## 案例：瑞幸做空——实地调研的教科书

2020年浑水/雪湖发布瑞幸做空报告，89页报告的核心证据来自实地调研：

| 维度 | 数据 | 启示 |
|:---|:---|:---|
| **人力投入** | 92个全职 + 1400多名兼职 | 实地调研是劳动密集型，但信息质量无法伪造 |
| **覆盖范围** | 38个城市、981个门店 | 样本量足够大才能排除偶然性 |
| **数据采集** | 从1万多顾客中收集25000多张小票 | 小票=不可篡改的交易记录，比财报数据可信 |
| **调研周期** | 覆盖门店从开门到关门全时段 | 完整周期=消除时段偏差 |
| **前期准备** | 先访谈行业专家确认看空策略，再加大投入 | 先做专家预判确定方向，再投入资源执行 |

**核心教训**：实地调研不需要"聪明"，需要"狠"——愿意投入足够的时间和人力。

## 行动决策树

```
你要调研一个线下业务
│
├─ 自己有门店/打算开店
│  ├─ 先蹲自己的店（摸清自己）
│  └─ 再蹲竞品的店（对标竞品）
│
├─ 考虑加盟
│  ├─ 第一优先级：访谈关店/亏损的加盟商 ← 最值钱的信息
│  ├─ 第二优先级：蹲非样板店（3家以上不同区位）
│  └─ 第三优先级：数人头（至少3天完整数据）
│
├─ 投资/做空标的
│  ├─ 先做专家预判（值不值得投入资源）
│  └─ 确定方向后，用规模化的实地调研验证假设
│
└─ 纯研究/学习
   └─ 选1-2家典型门店做深度蹲点即可
```

## Constraints & Boundaries

### 适用边界

1. **有实体门店/线下场景的业务**：餐饮、零售、加盟、本地服务
2. **需要验证公开数据真实性**：财报/招商材料的数据和实际经营数据是否一致
3. **投入足够时间和人力**：至少1-3天的基础蹲点，深度的需要1-2周
4. **有明确的调研假设**：知道要验证什么（客流量？客单价？转化率？），不是乱看

### 不适用场景

1. **纯线上业务**：SaaS、电商、App等无实体门店的
2. **高端B2B**：客户不通过门店获取，门店调研无法触及决策链
3. **极其分散的行业**：门店间隔太远，覆盖成本过高
4. **只需定性不需定量的调研**：只是想"感受一下"就可以，不需要数据统计

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 只看样板店 | 品牌方安排的店客流好得出奇 | 自己随机选3-5家，包括评分中等的和偏远的 | "我们帮您安排几个店看看" |
| 蹲店时间太短 | 只看了一个中午就下结论 | 完整覆盖工作日+周末+早中晚 | "我看了一中午，挺好的" |
| 没做量化记录 | 凭感觉判断"人挺多的" | 带上计数器/手机，一单一单地数 | 汇报时只有形容词没有数字 |
| 只访谈成功者 | 听到的全是正面信息 | 主动找亏损/关店的加盟商，问"你最后悔的是什么" | 访谈对象都说"还不错" |
| 没做前期的专家预判 | 直接投入大量资源做实地但方向可能错了 | 先用1-2天做专家访谈，确认调研方向和假设 | "我们先蹲一个月看看"（没有假设的蹲=盲目） |
| 被店员识破 | 蹲了几天后被店员赶走或刻意回避 | 定期换人、换装、换时段；必要时用多个观察者 | 店员主动过来问"你是做什么的" |
| 数据样本不足 | 只在一个门店+一个时段做了统计 | 至少3个门店×3个时段×3天=27个数据点 | "我统计了XX店周日下午的人流" |
| 忽略季节性波动 | 暑假统计的数据用来判断全年 | 如果无法覆盖全年，参考同商圈同品类的季节性系数 | "这个月客流不错"（但不知道是不是旺季） |

## 行动触发器

1. **决定考察一个线下业务**：先花1天做基础蹲点——逛店、观察、感受
2. **基础蹲点发现"有点意思"**：投入3天以上做量化统计——数人头、记客单、算转化
3. **量化数据和公开/招商数据矛盾**：启动谈话——找店长、找亏损加盟商
4. **需要超大规模验证（如做空/投资）**：参考瑞幸模式，组织专职团队做系统性实地调研
5. **关键红线**：蹲了1天发现没什么客流且没有增长趋势、访谈3个亏损加盟商都指向同一个致命问题、量化数据和招商材料的差距>30%
