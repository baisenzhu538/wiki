# 技能：需求创造验证法

## 原始表述

需求创造验证法是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 不直接询问用户想要什么
2. 基于洞察创造新需求方案
3. 向用户验证'这是否是你的需求'
4. 让用户确认而非自发提出
