# 技能：立即实践转化法

## 原始表述
> L6.立即实践 √立刻动手：立即转化为行动改变 √刻意练习：长期大量高水平练习

## 操作步骤
1. 学习后立即动手转化为具体行动
2. 设计刻意练习任务
3. 长期保持大量高水平练习

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 技能类学习，需要形成肌肉记忆 |
| ✅ 适合 | 改变习惯或行为模式，需要即时行动 |
| ✅ 适合 | 需要真正掌握而非知道，验证理解深度 |
| ✅ 适合 | 学习后48小时内，动量窗口未关闭 |
| ❌ 不适合 | 纯知识了解无行动需求 → 强行实践无意义 |
| ❌ 不适合 | 48小时窗口已关闭 → 学习动量消失，需重新输入 |
| ❌ 不适合 | 没有反馈渠道 → 无法知道实践效果 |
| ❌ 不适合 | 风险过高的场景 → 实践成本超过收益 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **实践拖延** | 等我学完这门课再开始做——学完的时间点永远在两周后 | 立即实践的'立即'是今天，不是明天。48小时窗口关闭后，学习动量消失 |
| **实践过小** | 每次都拿最安全、最熟悉的场景实践 | 实践必须挑战舒适区，100%确定能做到的场景说明不够挑战，本质是在重复已知 |
| **实践无记录** | 做了但没有记录结果和反思 | 没有记录的实践等于没有发生。必须写'做了什么、结果如何、下次怎么调整' |
| **实践一次就停** | 做了一个项目就觉得我学会了 | 刻意练习要求长期大量高水平练习，不是一次。单次实践只能验证理解，不能形成技能 |
| **脑内实践** | 只是在脑子里想了想怎么应用，没有具体输出物 | 实践必须产出可展示的结果（文档/产品/代码片段），脑内实践是自我欺骗 |
| **舒适区循环** | 长期在同一难度水平重复，没有渐进提升 | 每次实践必须比上次增加10%难度，刻意练习的核心是'舒适区边缘' |
| **反馈缺失** | 做了但不知道做得好不好，没有改进方向 | 实践前必须设计反馈机制：导师点评、数据指标、同行评审 |
| **目标错配** | 实践的方向和长期目标不一致，忙碌但无进展 | 实践前用三层目标对齐法确认方向，避免'为了实践而实践' |

## 判断标准

**什么算一次有效的立即实践**：

| 标准 | 好的实践 | 坏的实践 |
|:---|:---|:---|
| 48 小时内行动 | 学完 48 小时内就找到了一个可以尝试的场景 | "等我准备好了再试"——准备好那天永远不会来 |
| 有具体输出物 | 实践后产出了一个可展示的结果（文档/产品/代码片段） | 只是在脑子里"想了想怎么应用" |
| 挑战舒适区 | 实践的场景是"以前不会做"或"做不好"的 | 用自己最熟悉的场景"实践"，本质上是在重复已知 |
| 有记录有反思 | 做了之后写了"做了什么、结果如何、下次怎么调整" | 做完了就完了，没有留下任何可供复盘的材料 |

**自检问题**：
1. 离我上次学习已经过去多少小时？如果超过 48 小时，立即实践的窗口已经关闭了。
2. 这个实践场景是我 100% 确定能做到的吗？如果是，说明不够挑战。
3. 如果我今天不做，下一周会做吗？如果答案是"可能也不会"，说明动力窗口正在关闭。
