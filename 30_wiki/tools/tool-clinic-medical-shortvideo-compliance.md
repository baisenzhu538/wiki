## 操作步骤


Step 1: 明确诊所医疗短视频/个人 IP 合规边界 c要解决的核心问题
Step 2: 收集至少3个数据点或案例
Step 3: 按诊所医疗短视频/个人 IP 合规边界 c框架结构化分析
Step 4: 识别关键风险和依赖
Step 5: 制定执行计划和时间节点

## Purpose

本工具解决以下问题：

1. 为智能药柜/医药项目相关方提供结构化的检查框架。
2. 在决策前识别关键风险点，避免被单方面宣传误导。
3. 作为团队内部复核清单，确保关键证据已经交叉验证。
4. 为后续尽职调查、合同谈判或政策申报提供起点。

---

## Protocol/Procedure

使用本工具的步骤：

1. **明确使用场景**：确定你要评估的是项目、合作方、点位还是内容。
2. **逐条核对**：按本卡中的检查项逐项打分或标注证据状态（已验证/待验证/矛盾）。
3. **交叉验证**：对关键断言，要求对方提供书面材料或第三方数据源。
4. **记录偏差**：把矛盾点、待验证点汇总成风险清单，写入决策记录。
5. **定期复核**：医药政策与商业环境变化快，建议每季度复核一次关键条款。

## When NOT to Use

- **需要制定具体诉讼策略、行政处罚应对方案或个案危机公关时**：本工具只提供合规边界识别框架，不能替代律师、医疗合规顾问或公关专家的具体方案。
- **账号实际由 MCN 机构代运营或需要付费流量投放决策时**：视频号等平台已明确禁止 MCN 代运营医疗账号和医疗内容付费推广，本工具不能帮你绕过平台规则。
- **跨境医疗、境外平台或境外药械推广时**：本工具基于中国大陆法律法规和主要国内平台规则，境外场景需另行评估当地法律。
- **仅做非医疗类个人 IP、与诊疗/药品/器械完全无关时**：本工具聚焦医疗短视频合规，普通健康生活方式内容适用一般内容合规框架即可。
- **需要对具体文案做逐字审核把关时**：本工具给出的是边界清单，不能替代发布前的法务/合规逐条审查。

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **把健康科普当医疗广告做** | 视频讲疾病知识时顺带展示药品、诊所联系方式或"专治"话术 | 科普与广告之间加防火墙：不点名药品品牌、不承诺疗效、不引导到店购药 |
| **由 MCN 代运营医疗账号** | 视频号/抖音医生账号实际由 MCN 策划、拍摄、发布 | 平台已明令禁止，医生本人应掌握账号实际控制权，MCN 只能提供培训或素材支持 |
| **AI 批量生成同质化医疗文案未标识** | 一天发布数十条"科普"，内容高度雷同且未标注 AI 生成 | 显著标识 AI 生成内容，控制发布频率，避免被四部门清理行动命中 |
| **在视频/评论中引导到店购药** | 私信、评论区、口播中出现"来店购买""加微信拿药"等导流 | 切断医疗内容与药品销售的直接引导链路，销售行为在合规渠道独立完成 |
| **医生个人账号与诊所商业推广混同** | 医生以科普名义出镜，实际为诊所引流并产生销售转化 | 明确账号性质是医生个人科普还是机构宣传，分别适用不同合规要求 |
| **用"成功案例"代替真实转化率数据** | 决策依据来自 MCN 机构宣传的"爆款案例"，无独立验证 | 要求 MCN 提供可审计的后台数据，否则不将短视频作为核心增长假设 |
| **忽视平台规则更新** | 按半年前经验发布内容， suddenly 被限流、封号 | 每季度复核视频号/抖音/小红书/快手医疗内容规则，建立规则变更预警 |
| **把单一平台规则套用到所有平台** | 抖音允许的医生账号规则直接搬到视频号 | 分别阅读并标注各平台最新《医疗健康行业公约》或医疗内容管理规范 |

# 诊所医疗短视频/个人 IP 合规边界

> **核心定位**：为诊所/医生提供医疗短视频（抖音、视频号、小红书、快手）内容创作的合规边界 checklist，识别推销方"流量部代运营"话术中的风险。

---

## Summary

医疗短视频/个人 IP 在诊所场景下具有引流潜力，但**合规边界比推销方描述的窄得多**。核心约束来自三个层面：

1. **法律法规**：《广告法》《医疗广告管理办法》《互联网广告管理办法》《医师法》。
2. **平台规则**：抖音、视频号、小红书、快手对医疗内容、医疗账号、本地生活医疗投放有严格限制。
3. **AI 内容监管**：AI 生成医疗内容须显著标识，批量同质化 AI 医疗文案已被四部门点名清理。

> **核心原则**：医疗短视频可以做健康科普，但不能做药品/器械广告，不能引导到店购药，不能由 MCN 机构代运营医疗账号。

## Claims

### 1. 各平台医疗内容政策要点

#### 1.1 视频号（2026 年 4 月《医疗健康行业公约》）

| 维度 | 规则要点 |
|---|---|
| 账号认证 | 仅支持三甲医院、执业医师、健康科普机构等资质认证 |
| MCN 代运营 | **明确禁止将医疗健康账号交由 MCN 机构代运营** |
| 流量投放 | **禁止通过流量包/付费推广等方式获取流量** |
| 商业变现 | 医疗账号不得参与直播带货、商品分享、广告分成 |
| 内容禁区 | 不得在非广告场景提及商品名、品牌名、医疗机构联系方式；不得夸大疗效、保证治愈 |
| 违规处罚 | 限流、禁言、封号、取消认证 |

#### 1.2 抖音

| 维度 | 规则要点 |
|---|---|
| 账号认证 | 医生账号需提交执业医师资格证、执业证、在职证明 |
| 私信/粉丝群 | **已关闭医生账号私信、粉丝群功能** |
| 带货/小黄车 | **医疗账号禁止带货** |
| 本地生活 | 医疗机构入驻抖音本地生活受严格限制，部分城市仅开放体检、口腔等少数类目 |
| 内容禁区 | 不得发布诊疗行为、不得推销药品/器械、不得制造健康焦虑 |

#### 1.3 小红书

| 维度 | 规则要点 |
|---|---|
| 医疗内容 | 对医疗科普实行严格审核，非认证医生账号发布医疗内容易被限流或下架 |
| 禁推品类 | **明确禁止推广药品、医疗器械、保健品"三品一械"** |
| 导流风险 | 私信引流、评论区留联系方式可能被封号 |

#### 1.4 快手

| 维度 | 规则要点 |
|---|---|
| 医疗账号 | 需提交医疗机构/医师资质认证 |
| 直播 | 医疗账号直播受限，不得进行诊疗、卖药 |
| 内容禁区 | 不得夸大疗效、不得宣传未经批准的疗法 |

### 2. 推销方常见话术与合规现实

| 推销方话术 | 合规现实 | 风险等级 |
|---|---|---|
| "我们有流量部，帮你做短视频/直播" | 视频号已禁止 MCN 代运营医疗账号 | 🔴 高 |
| "可以精准投放到诊所周边 3–5 公里" | 技术上支持地理投放，但医疗内容/医疗账号投放受限或禁止 | 🔴 高 |
| "AI 批量生成科普文案，一天发几十条" | AI 生成医疗内容须显著标识；批量同质化 AI 文案已被四部门清理 | 🔴 高 |
| "视频里不能出现药盒、不能说'专治'" | 只是底线之一，平台还有 MCN 代运营、流量包投放等更多限制 | 🟡 中 |
| "医生出镜讲科普，顺便宣传诊所" | 科普与广告界限模糊，易被认定为变相医疗广告 | 🟡 中 |
