# A/B测试：增长实验的统计基础

> 一堂五步法：A/B测试不是简单的对比，而是统计实验。样本量、显著性、置信区间，缺一不可。

## 关键洞察

### 1. 样本量计算

| 参数 | 说明 | 常用值 |
|:---|:---|:---:|
| **基准转化率** | 版本A的转化率 | 历史数据 |
| **预期提升** | 版本B相对A的提升 | 10-20% |
| **显著性水平α** | 假阳性概率 | 0.05 |
| **统计功效1-β** | 真阳性概率 | 0.8 |
| **样本量** | 每组需要的用户数 | 计算得出 |

样本量公式（简化）：
```
n = 16 × p × (1-p) / (p1 - p2)²

其中：p = 基准转化率，p1-p2 = 预期提升
```

### 2. A/B测试的陷阱

| 陷阱 | 说明 | 避免 |
|:---|:---|:---|
| ** peeking问题** | 测试过程中偷看结果 | 预设测试时长 |
| **多重比较** | 同时测试多个指标 | 预设主要指标 |
| **选择偏差** | 分组不随机 | 严格随机 |
| ** novelty效应** | 新版本的短期效应 | 延长测试时间 |
| **外部效度** | 测试结果不适用于其他场景 | 多场景验证 |

### 3. A/B测试的类型

| 类型 | 说明 | 适用 |
|:---|:---|:---|
| **标准A/B** | 两个版本对比 | 简单优化 |
| **A/B/n** | 多个版本对比 | 多方案选择 |
| **多变量测试** | 多个变量同时测试 | 复杂优化 |
| **Bandit** | 动态分配流量 | 快速优化 |
| **分层测试** | 不同层独立测试 | 大规模优化 |

### 4. A/B测试的流程

| 步骤 | 行动 | 注意 |
|:---|:---|:---|
| **提出假设** | 明确预期提升 | 可量化 |
| **计算样本量** | 确定测试时长 | 足够大 |
| **随机分组** | 用户随机分配 | 严格随机 |
| **运行测试** | 不偷看结果 | 预设时长 |
| **分析结果** | 统计显著性 | p值、置信区间 |
| **做出决策** | 上线或放弃 | 考虑长期影响 |
| **记录学习** | 记录实验结果 | 知识积累 |

### 5. A/B测试的评估

| 指标 | 说明 | 健康标准 |
|:---|:---|:---|
| **测试数量** | 每月测试数 | > 10 |
| **成功率** | 显著结果比例 | 20-30% |
| **上线率** | 显著结果上线比例 | > 50% |
| **学习率** | 从失败中学习 | 100% |
| **迭代速度** | 从假设到上线 | < 2周 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **样本量不足** | 结果不显著 | 提前计算 |
| **测试时间太短** | novelty效应 | 延长测试 |
| **分组不随机** | 选择偏差 | 严格随机 |
| **指标过多** | 多重比较 | 预设主要指标 |
| **忽视长期影响** | 短期好，长期差 | 长期跟踪 |
| **测试后不记录** | 知识流失 | 实验记录 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 产品优化 | 战略决策 |
| 页面优化 | 品牌定位 |
| 功能测试 | 创意判断 |
| 定价测试 | 伦理问题 |
