# 项目定方案一页纸画布

> **一句话**：把三段论（背景/目标/关键路径）压缩到一页纸，可直接打印、截图、发飞书。

## 二、填写指南

### 进入标准
- 项目至少为B级（A级不需要画布）
- 三段论至少有一句话
- 负责人已明确

### 退出标准
- 签字画押至少1人确认
- 评估三角三个格子都有答案（哪怕是"不需要"）
- 关键路径至少1个里程碑

### 最小可行版本
时间紧时：**背景只填核心需求1行 + 目标一句话 + 关键路径1个里程碑**。其余待补充。

---

## 三、Before/After：虚需求→数据论证

来自定方案口述稿 L604-L642。

**Before（虚需求版）**：背景：用户想落地

**After（数据版）**：背景：至少一千个团队有共同学习需求 [确认]；上传速度从2分半→最快10秒，差距20倍 [确认]；>50%城市发起人反馈缺营销物料 [确认]

---

## 四、失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 格子全"待定" | 背景和目标都空 | 核心需求+目标必须填，其他可待定 |
| 数据全空白 | 画布没有数字 | 每个主张配数字或标[空白] |
| 评估三角跳过 | 没算ROI就开干 | 强制过三角——哪怕粗估 |
| 签字画押空 | 做完了老板说不知道 | 启动前至少一人确认 |
