# 技能：建立策略-要素映射表设计对抗策略

## 原始表述
> 建立「策略-要素映射表」：针对每种典型不利要素（如专家依赖/非标沟通/管理复杂度），给出3-5个已验证的对抗策略案例，降低设计门槛

## 操作步骤
1. 识别自身业务的不利要素类型
2. 查阅映射表找到对应不利要素
3. 选择3-5个已验证的对抗策略案例
4. 根据自身资源禀赋适配调整
5. 实施并追踪效果
