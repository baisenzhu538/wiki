# 护城河评估工具

> 一堂五步法：护城河需要定期评估。评估工具 = 护城河清单 × 强度评分 × 趋势分析。

## 核心框架

护城河评估的5个维度：

```
护城河识别 → 强度评估 → 持续时间评估 → 可量化评估 → 趋势分析
```

## 关键洞察

### 1. 护城河清单

| 护城河类型 | 说明 | 评估问题 |
|:---|:---|:---|
| **网络效应** | 用户越多，价值越大 | 用户迁移成本多高？ |
| **转换成本** | 用户离开的成本 | 用户离开会损失什么？ |
| **品牌** | 品牌认知和信任 | 用户是否愿意付溢价？ |
| **规模经济** | 规模越大，成本越低 | 单位成本是否持续下降？ |
| **技术专利** | 专利保护 | 专利是否难以绕过？ |
| **数据资产** | 数据积累 | 数据是否用于产品优化？ |
| **生态锁定** | 生态丰富 | 生态参与者是否依赖平台？ |
| **供应链** | 资源独占 | 供应链是否难以复制？ |
| **人才密度** | 人才质量 | 核心人才是否难以流失？ |
| **文化** | 组织文化 | 文化是否独特且深入？ |
| **监管** | 牌照合规 | 牌照是否难以获取？ |

### 2. 强度评分

| 评分 | 说明 | 标准 |
|:---|:---|:---|
| **5分** | 极强 | 几乎无法突破 |
| **4分** | 强 | 很难突破 |
| **3分** | 中 | 可以突破，但成本高 |
| **2分** | 弱 | 容易突破 |
| **1分** | 极弱 | 几乎没有 |

### 3. 持续时间评估

| 持续时间 | 说明 | 管理 |
|:---|:---|:---|
| **长期（>10年）** | 可持续很长时间 | 维护 |
| **中期（5-10年）** | 可持续一段时间 | 强化 |
| **短期（<5年）** | 很快会消失 | 替代 |

### 4. 可量化评估

| 可量化 | 说明 | 指标 |
|:---|:---|:---|
| **是** | 可以量化 | 用户留存率、市场份额 |
| **否** | 难以量化 | 品牌认知、文化 |

### 5. 趋势分析

| 趋势 | 说明 | 行动 |
|:---|:---|:---|
| **增强** | 护城河在增强 | 继续 |
| **稳定** | 护城河稳定 | 维护 |
| **减弱** | 护城河在减弱 | 修复 |
| **消失** | 护城河即将消失 | 替代 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **忽视评估** | 不评估护城河 | 定期评估 |
| **评估主观** | 评估过于主观 | 数据支撑 |
| **忽视趋势** | 不关注护城河变化 | 趋势分析 |
| **评估后不行动** | 评估后不修复 | 行动 |
| **过度自信** | 高估护城河 | 客观评估 |
| **忽视新护城河** | 不建立新护城河 | 持续建设 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 战略评估 | 技术架构 |
| 投资评估 | 日常运营 |
| 竞争分析 | 内部管理 |
| 长期规划 | 短期决策 |

## 行动触发器

- 当评估公司时 → 评估护城河
- 当护城河被突破时 → 修复或替代
- 当投资时 → 评估目标护城河
- 当规划时 → 建设护城河
