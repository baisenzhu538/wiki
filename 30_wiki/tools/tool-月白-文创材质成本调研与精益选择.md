# 技能：文创材质成本调研与精益选择

## 原始表述

文创材质成本调研与精益选择是月白在文创案例中提出的实操方法。

## 操作步骤

1. 海量调研市面现有做法和材质
2. 与AI深度讨论各材质优劣
3. 用AI计算每种材质/做法的基础费用
4. 根据产品内核（足够可爱有内容的载体）选择成本最低且满足需求的方案
