# 技能：精准提示词撰写法

## 原始表述

精准提示词撰写法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 删除冗余形容词和情绪词（如绝美、震撼）
2. 保留客观、具体、无歧义的要素描述
3. 用可量化和可识别的特征替代主观感受
4. 测试提示词是否不同的人能理解出同一画面
5. 持续迭代直到输出稳定可控
