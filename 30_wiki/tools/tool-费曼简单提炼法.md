# 技能：费曼简单提炼法

## 原始表述
> L1.简单提炼 √划重点：把重点内容做标记 √提炼三句话：提炼触动和价值点

## 操作步骤
1. 阅读/学习时先划重点标记
2. 学完后用三句话提炼核心内容
3. 聚焦提炼'触动点'和'价值点'

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 每次学习后立即检验理解，暴露盲区 |
| ✅ 适合 | 信息过载需要简化，聚焦核心 |
| ✅ 适合 | 准备分享或教学前，需要结构化表达 |
| ✅ 适合 | 复习时快速激活记忆，不用重读原文 |
| ❌ 不适合 | 需要完整保留原始信息的场景 → 提炼会丢失细节 |
| ❌ 不适合 | 高度技术性的精确知识 → 三句话无法承载精度 |
| ❌ 不适合 | 没有听众/分享对象 → 费曼法的检验环节缺失 |
| ❌ 不适合 | 情绪/体验类内容 → 难以用三句话概括 |

#| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **提炼变摘要** | 把原文缩写成三句话，不是用自己的语言重新表达 | 费曼的核心是'翻译成自己的话'不是'浓缩原文'。用自己的话讲给不懂的人听 |
| **三句话不检验** | 写完三句话就觉得理解了，没有拿去讲给别人听 | 费曼的完整版是'提炼→讲述→发现盲区→回去重学→再讲'，跳过讲述等于没完成 |
| **跳过划重点** | 直接写三句话，没有先做标记 | 划重点帮你找到'最值得提炼的内容'，跳过这步提炼质量下降，先标记再提炼 |
| **提炼对象过宽** | 读完一本书提炼三句话，信息量太大 | 一本书只能覆盖一章。提炼单元应该是'一个核心观点'，不是整本书 |
| **盲区未暴露** | 写完后非常满意，没有暴露盲区 | 提炼的价值是发现你不懂什么。写完后发现'这句话对吗？好像不太确定'才是好提炼 |
| **术语依赖** | 用了原文术语，换个人名换个场景就说不出来了 | 必须用外行能懂的语言，术语是理解的遮羞布。讲不通说明没真懂 |
| **价值缺失** | 三句话只描述'是什么'，没有'对我有什么用' | 必须包含触动点和价值点，没有价值判断的提炼是信息搬运 |
| **完美主义** | 追求三句话的文学性，反复打磨不输出 | 先完成再完美，三句话的检验价值在'讲'不在'写' |

## 判断标准

**什么算一次好的费曼提炼**：

| 标准 | 好的提炼 | 坏的提炼 |
|:---|:---|:---|
| 用自己的话 | 讲给不懂这个领域的人能听懂 | 用了原文术语，换个人名换个场景就说不出来了 |
| 一句话说内核 | "这次我学到的核心观点是：当 X 发生时，应该先做 Y，因为 Z" | "这本书讲了三点，第一点……"——不是提炼，是笔记 |
| 暴露盲区 | 写完后发现"这句话对吗？好像不太确定"——提炼的价值是发现你不懂什么 | 写完后非常满意——说明你可能只是在重复已知 |
| 可验证 | 提炼的内容可以拿去问别人"你觉得这个对吗" | 提炼的内容太个人化，无法和他人讨论验证 |

**自检问题**：
1. 这三句话里，有哪一句是我自己从来没想过、从原文里学到的新东西？
2. 我能用这三句话说服一个质疑者吗？
3. 如果只能留一句话，会是哪一句？——如果选不出来，说明三句话其实是一句话的三种说法。
