# 技能：叙事性场景海报构建

## 原始表述

叙事性场景海报构建是月白在文创案例中提出的实操方法。

## 操作步骤

1. 在场景图基础上增加微型故事
2. 设定角色互动关系（如Leo小人看着你写作业）
3. 添加文案强化叙事（如'创业好辛苦，看里程碑不给钱，我在一旁等你'）
4. 组合多个元素：主体产品+场景+辅助道具+文案
5. 使用图生图将各元素合成完整画面
