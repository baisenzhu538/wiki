# 技能：封面情绪转化法

## 原始表述

封面情绪转化法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 提取文章核心情绪关键词（非事实关键词）
2. 将情绪转化为视觉化、有冲击力的图像表达
3. 避免仅有信息密度而缺乏情绪引导
4. 对比测试：将封面放入真实手机信息流截图，验证是否能在众多内容中跳出

## 为什么有效
