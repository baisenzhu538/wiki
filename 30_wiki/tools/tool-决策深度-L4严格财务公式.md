# 决策深度L4：严格财务公式

## 一句话定义

L4是最高决策深度——**用完整的财务公式做决策**，包含收入、成本、费用、折旧、税、资金成本，每个参数有来源和审计痕迹 [conf=0.80, source=一堂方法论]。

## L3→L4 升级

L3说"利润=收入-成本"，L4说"净利润=收入-COGS-销售费用-管理费用-研发费用-折旧摊销-利息-税-少数股东权益"。
升级的本质不是公式更复杂，是**每个参数都经过验证**。

## 操作步骤

1. 建完整财务模型（三张表联动）
2. 每条假设标注：(a)数据来源 (b)验证方式 (c)历史对标
3. 三条基准线校准：行业平均/竞品/历史最优
4. 压力测试：最坏情况下的现金流断点在哪？

## 边界

L4耗时最长，只用于**不可逆的重大决策**（融资、收购、关停业务线）。日常决策到L3就够了。

## 失败模式

- L4做完了但不敢信——参数都填了但来源是"我觉得" → L4≠真L4
- 过度追求L4——对可逆的小决策用L4是浪费时间
