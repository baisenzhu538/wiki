# 教练反馈卡（6原则 + BE FASTER）

> 定位：属于 `framework-coaching-leadership-core` 的教练沟通武器库第 3 组（反馈组），承接倾听卡（听）→ 提问卡（问）→ 反馈卡（馈），服务于五阶梯 L4 成长层（1v1 反馈）。核心增量：BE FASTER 对比反馈法（口述 01 L2910 增量，暗知识 W2）。

## 一句话定义

反馈是通过"基于事实的客观表达"（而非观点评判）让对方看见自己的行为与影响，从而强化优势、修正行为、促进成长的沟通动作。6 原则覆盖反馈的完整性，BE FASTER 提供"事上反馈"的具体方法。

## 为什么重要

1. **L4 成长层集大成动作**：真正在 L4 级别集大成的动作是给关键人高水平反馈（口述 01 L2900-2902）
2. **事实 vs 观点是基础**：基于事实的客观反馈才有效；从观点出发的反馈易碰撞偏离主题（口述 02 L1074-1076）
3. **反馈频率影响状态**：每月 1-2 次高水平反馈对方状态好；连三个月不给状态差（口述 01 L2974-2976）
4. **反馈是高频加减币动作**：好的反馈加币，指责式反馈减币

## 核心机制：反馈 6 原则

### 原则 1：及时回应（馈1）

**核心**：及时回应是反馈的基础，让对方感受到被关注。

- 表达时有人频频点头、适时简短回应 → 听众觉得被关注，激发表达欲
- 反馈要及时，动作发生马上给（对应 BASIC 的 Agile）

### 原则 2：复述回应（馈2）

**核心**：沟通中的信息通过复述，确保理解完整准确。

| 层级 | 操作 |
|:--|:--|
| 基础 | 简单复述："你的意思是……吗？"请确认 |
| 进阶 | 明确要点："对方所表达的观点中，你最在意的是……"请确认 |
| 重新框架 | 复述细节后用自己的话做总结确认 |

### 原则 3：积极回应（馈3）

**核心**：捕捉关键信息和结论，利于更深的觉察。

| 方式 | 操作 |
|:--|:--|
| 具体事实 | 确认对方观点，认可"这个想法很对" |
| 好奇提问 | "你说的这个是什么意思，能详细说说吗？" |
| 具象未来 | 让对方想象"如果……你会怎么做？" |

### 原则 4：二次确认（馈4）

**核心**：把抽象理解以对方确认，是对对方的关键动作。

- 同一段话"你的理解"不一定等于"他的表达"
- 双向确认，才能尽可能保证理解一致

### 原则 5：BASIC 原则 ✅（VLM 已校对）

**核心**：有效反馈基于 BASIC 原则——也是反馈的自查清单。

| 字母 | 含义 | 要点 |
|:--|:--|:--|
| **B** | Behavior | 基于可观察到的行为反馈 |
| **A** | Agile | 反馈要及时，动作发生马上给 |
| **S** | Specific | 针对具体动作反馈 |
| **I** | Influence | 从行为造成的影响给反馈 |
| **C** | Consistent | 每次反馈方式呈现一致性 |

### 原则 6：刻意练习反馈（馈6）

**核心**：反馈要先为对方构建刻意练习的容器。

- 创建长期/短期发展目标
- "努力"有方法：A 优点 / B 努力点 / C 次缺点 / D 次缺点 + B 次优点（反馈循环图）
- 关联 `concept-一堂-基本功-刻意练习四要素`

## 核心增量：BE FASTER 对比反馈法（口述 01 L2904-2924）

**定义**：BE FASTER = 对比反馈——你改了对方的方案后，让对方**拿着原方案和你的方案逐条对比**，说出"我改哪了、为什么改"（L2910-2916）。

**操作步骤**：
1. 你改了他的方案（同步或异步改完还给他）
2. 要求他对比原方案和你的版本
3. 逐条说明：为什么把目标砍掉一个？为什么调顺序？为什么删这段？为什么加这个字？
4. 全部对比出来，告诉他为什么

**为什么有效**：你改的部分大概率就是这件事的套路，只是对方之前不理解。随着对比次数足够多，他就学会了（L2920-2922）。来自"莹莹那次反馈"的实战验证（L2926-2928）。

**反馈三层级**（L2904-2948）：
| 层级 | 对象 | 方法 | 周期 |
|:--|:--|:--|:--|
| 事上反馈 | 具体的事/方案 | BE FASTER 对比反馈 | 即时 |
| 能力反馈 | 能力参数 | 刻意反馈（评估缺哪个要素） | 中期 |
| 路径反馈 | 人生红点 | 路径反馈（如"你今年主要练建模"） | 以年为单位 |

## 关键技巧：三种反馈结构（口述 02 L1104-1164）

### 正面反馈（强化优势）
- 结构：**情境 + 行为 + 积极影响**
- 要点：避免浮夸泛滥，锁定可复制的行为细节
- 示例："我看到你昨晚加班离开时把水果盘放冰箱，避免了坏掉还维持整洁，难怪大家都说你安排得井井有条"（L1114-1120）

### 改进反馈（修正行为）
- 结构：**情境 + 行为 + 负面影响 + 建议**
- 要点：把指责性"你"换成"我们"拉近距离，降低防御
- 示例："昨天开会你晚进 15 分钟，我们少了 15 分钟讨论时间，不是怪你。下次会晚的话提前打个招呼或派代表，你觉得方便吗？"（L1132-1138）

### 负面反馈（严重后果）
- 结构：**情境 + 行为 + 严重后果 + 询问补充建议**
- 要点：冷静语气 + 客观事实数据；**把猴子放回对方身上**（"我直接回去了"）
- 示例：会场布置缺手册——"我们准备先用上次的，你这边有没有什么补充建议给到我？"（L1154-1160）

**反馈是双向互动**：观察对方反应（往后退还是抬头？）判断反馈是否有效，调整策略（L1166-1174）。

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 情绪激动时 | 情绪>理性时反馈无效 | 先处理情绪（静默卡场景2） |
| 公开场合负面反馈 | 羞辱感引发防御 | 一对一私下给 |
| 对方无成长意愿 | 反馈无人接收 | 先处理意愿/信任问题 |
| 只给观点不给事实 | 观点碰撞偏离主题 | 事实/观点区分，只说事实 |
| 反馈变指责 | "你"字句引发防御 | 换"我们"，给建议不给审判 |

> **冰山延伸（P1 合并判断 2026-08-09）**：任务单建议的"反馈冰山理论（显性/隐性）"经核查——口述 02 与 VLM 反馈区均无"冰山/显性/隐性"直接表述，其内核（表面行为 vs 深层需求）已由三种反馈结构（情境+行为+影响）+ 3F 倾听（事实/情绪/意图）覆盖。按任务单"二选一"条款**合并入本卡**，不单独立 dk 卡（避免无源推断）。深层需求挖掘走 `tool-leadership-listening-cards` 的 3F 意图层。

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 浮夸正反馈 | "你真棒"说不出具体行为 | 情境+行为+影响结构 |
| 指责式反馈 | "你在搞什么鬼" | 换"我们"结构 |
| 无事实反馈 | 基于观点评判 | 只说可验证的事实 |
| 反馈后无跟进 | 说完就完，对方没懂 | 二次确认 + BE FASTER 对比 |
| 反馈不透明 | 改了方案不说为什么 | BE FASTER 让对方自己对比 |

## 行动 Checklist

- [ ] 反馈前：确认基于事实（可验证行为）
- [ ] 选结构：正反馈/改进反馈/负面反馈（情境+行为+影响）
- [ ] 用 BASIC 自查：Behavior？Agile？Specific？Influence？Consistent？
- [ ] 反馈后：二次确认对方理解
- [ ] 改了方案：用 BE FASTER 让对方对比
- [ ] 观察反应：对方往后退还是抬头？调整策略

## Critique

### 攻击者 1：绩效管理视角——"BE FASTER 只适用于'你改对方方案'场景，覆盖面窄"

**攻击论点**：BE FASTER 的前提是"上级改了下级的方案"，但领导力反馈大量场景是行为反馈、态度反馈、结果反馈——没有"方案可对比"时 BE FASTER 失效。

**回应**：BE FASTER 是"事上反馈"的专用方法，口述明确反馈分三层级（事/能力/路径）——能力反馈用刻意反馈（缺要素评估），路径反馈用人生红点。BE FASTER 不覆盖全部，但覆盖最高频的"改方案"场景。承认：卡内应补三层级分工说明（已补）。

### 攻击者 2：教育心理学——"对比反馈可能让下属产生'被全盘否定'感"

**攻击论点**：让下属逐条对比"我改了什么"，本质是放大差距——如果改动过多，下属可能感受到全盘否定，反而损伤自信和成长意愿。

**回应**：BE FASTER 的机制是"你改的部分大概率是套路"——目的是让对方理解套路而非羞辱。正确操作：逐条解释"为什么"而非只展示差异；配合正面反馈结构（情境+行为+积极影响）平衡。承认：改动过多时应先给整体肯定，再进入逐条对比。

### 攻击者 3：ICF 教练伦理——"负面反馈'把猴子放回对方身上'可能变成甩锅"

**攻击论点**：负面反馈结构中"把资料叫回去给到对方"（L1152-1160），如果操作不当，管理者可能用话术把责任全部推给下属，变成"我给建议了，剩下的你自己想办法"——这恰恰是减币行为（甩锅）。

**回应**：口述的意图是"不把猴子背在自己身上"（领导力核心：不是自己背多少猴子，而是教下属养好猴子 L392-394），与甩锅的区别在于：甩锅是"你的问题我不管"，正确做法是"问题我们一起面对，但解决的责任和行动在你"。承认：卡内应补"把猴子放回去 ≠ 甩锅——必须提供必要的支持/资源/框架"。

## Synthesis

- **不要用的场景**：情绪激动时；公开负面反馈；只给观点不给事实；反馈变指责；把"放回猴子"当甩锅

  - `[[tool-leadership-questioning-cards]]`：事实/观点区分共同基础
  - `[[concept-一堂-基本功-刻意练习四要素]]`：馈6 容器构建
  - `[[framework-leadership-coin-model]]`：反馈是加减币动作
  - `[[framework-leadership-five-ladders]]`：L4 成长层核心工具
- `[[framework-yitang-y-model-cross-domain-fusion]]`：Y 模型共识——反馈是讲道理的落地动作（跨域）
- **Action Triggers**：
  - 对方做了可复制的好行为 → 正面反馈（锁定行为细节）
  - 对方行为需修正 → 改进反馈（"我们"结构）
  - 出现严重后果 → 负面反馈（冷静+事实+放回猴子）
  - 改了对方方案 → BE FASTER 对比反馈
  - 每月至少给关键人 1-2 次高水平反馈

## 可迁移场景

1. **带团队**：每月 1-2 次关键人反馈（频率标准）
2. **方案评审**：BE FASTER 对比反馈（评审后让作者逐条说明改动）
3. **代码/文档 review**：BE FASTER 应用到 Agent 产出 review（改了什么+为什么）
4. **亲子/家庭**：正面反馈锁定行为细节（"我看到你……"）
5. **KDO 工厂（Agent 管理）**：欧阳锋 review 老顽童产出 = BE FASTER 场景——退回时给出对比和"为什么"
