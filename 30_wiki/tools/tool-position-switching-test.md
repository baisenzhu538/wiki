> **定位**：属于 [[concept-collaboration-philosophy-foundation]] 的工具卡。理论锚点——金句9"人所不欲，勿施于人"（8.2）+ 金句4"公平是正义的一部分"（7.6）。公平只保证执行一致，不保证规则本身公正。地位互换是检验规则本身的工具。

### 推导链

```
【底层】坏世界假设 → 他者悖论（他者既限制我又是我利益来源）
  → 需要公正规则（金句6：公正才是权力维持的条件）
  → 公正需要地位互换检验（金句9：用他的尺子量）
      ↓ 压缩为操作
【中层】三问自检 = 利益问（尺子不同定理）+ 动机问（博弈条件改善）+ 退出问（权力对称性）
      ↓ 解压为场景
【上层】一人公司三场景（外包/渠道/写手）+ 红牌信号
```

**自洽检验**：能否从底层原则直接推出每一步操作？利益问 ← 尺子不同定理（口述 L552-578）、动机问 ← 激励让好行为占优（5.3）、退出问 ← 他者悖论（不能消灭只能改造关系，退出是最后通牒）。

## 操作步骤

### 第一步：写下规则（30秒）

用一句话写下你正在设计/评估的规则。只写客观事实，不写你的理由。

> 例："外包开发——5万总价/工期2月/验收后一次性付款"

### 第二步：换椅子（10秒）

物理上或心理上坐到对方的位置。你现在是规则的接受方，不再是制定方。

### 第三步：三问自检（30秒）

| 问 | 问题 | 设计意图 |
|:--|:--|:--|
| **利益问** | 按这条规则，我（对方）能拿到我想要的东西吗？ | 金句9：人所不欲勿施于人——用他的尺子量，不是用你的。对应暗知识「尺子不同定理」 |
| **动机问** | 按这条规则，我会（对方会）主动想把事情做好吗？还是只想应付过关？ | 金句3：改善博弈条件——规则应该让好行为成为优势策略 |
| **退出问** | 如果我不接受这条规则，我有什么替代选择？退出会失去什么？ | 如果对方退出成本极高而你无所谓→规则在结构上偏向你，不是中立 |

### 第四步：红牌信号

以下任一情况出现 → 规则需要重新设计：

| 红牌 | 表现 | 示例 |
|:--|:--|:--|
| 🔴 风险全在对方 | 利益问→对方承担所有风险 | 验收后付款=乙方全风险 |
| 🔴 对方动机扭曲 | 动机问→对方只想应付 | 按篇计费→凑数量不凑质量 |
| 🔴 退出不对称 | 退出问→对方退出成本远高于你 | 小渠道根本达不到返点门槛→白干 |
| 🟡 只算了钱 | 对方最在乎的可能不是钱 | 给外包加钱≠他最想要的（可能是稳定订单/技术挑战/尊重） |

## 一人公司场景示例

### 场景1：找外包开发

| 阶段 | 内容 |
|:--|:--|
| **原规则** | 5万总价/工期2月/验收后一次性付款 |
| **换椅子发现** | 利益问→乙方全风险：2个月0收入、验收标准由我定、付款时间由我控制 |
| **修正** | 30%定金+里程碑付款（原型/测试/上线各30%+10%尾款） |

### 场景2：找渠道分销

| 阶段 | 内容 |
|:--|:--|
| **原规则** | 累计销售额达到10万才返点 |
| **换椅子发现** | 退出问→小渠道根本达不到→等于白干→不会认真推 |
| **修正** | 阶梯返点：3万以下5%、3-10万8%、10万以上10% |

### 场景3：找内容写手

| 阶段 | 内容 |
|:--|:--|
| **原规则** | 按篇计费/修改到满意为止 |
| **换椅子发现** | 动机问→"修改到满意"=无限修改=成本无底洞→写手只会应付首稿等修改 |
| **修正** | 2轮免费修改+超出按小时计费 |

## 常见盲区

| 盲区 | 为什么容易忽略 | 解法 |
|:--|:--|:--|
| 创始人高估idea价值 | 你为idea投入的时间/情感→自动认为对方也该认可 | 问：如果今天你是对方第一次听说这个idea，你愿意出多少？ |
| "市场价"不包括隐性成本 | 对方的隐性成本（学习业务、沟通对齐、等待反馈）被忽略 | 在报价基础上加20-30%隐性成本缓冲 |
| 只算钱没算尊严/自主权 | 「政治人」不只算钱——权力/荣誉/归属感同样是利益 | 利益问不只问"他赚多少"，也问"他有话语权吗？他感到被尊重吗？" |

## 失败模式

| 失败模式 | 信号 | 修复 |
|:--|:--|:--|
| **换椅子但不换尺子** | 嘴上说"如果我是他"，但用的还是自己的评估标准 | 强制列出对方至少3条利益维度（不限于钱），逐条打分 |
| **只测一次** | 规则通过测试后不再复查——但对方情况会变 | 每季度或每次续约前重新跑一次 |
| **忽略权力的系统性不对称** | 小乙方对大甲方——换椅子也救不了结构性不对等 | 承认不对等→规则中加入保护弱势方的条款（如最低保障、退出补偿） |
| **只用在别人身上** | 只检查给别人的规则，不检查给自己的规则 | 对自己的约束也跑一遍互换测试——如果你是被管理的人，你会接受这条规则吗？ |

## When NOT to Use

| 场景 | 原因 | 替代 |
|:--|:--|:--|
| 纯技术/质量检查（如代码review标准） | 不涉及利益分配或权利关系 | 用客观标准 |
| 规则有法律强制力（如劳动合同法定条款） | 互换无法改变法律要求 | 法律合规为底线，互换用于法律之上的协商部分 |
| 单方决策（紧急/独裁场景） | 没时间换椅子——先决策 | 事后复盘时补跑 |

## Critique

### 内部局限

1. **心理换位不完美**——你不可能真正变成对方。你可能低估了对方的真实偏好，高估了自己对对方处境的了解。
2. **系统性不对等无法通过互换消除**——如小乙方对大甲方，即使换椅子意识到不公正，也无法凭一方之力改变。
3. **来自赵汀阳二手解读**——「地位互换」源于罗尔斯「无知之幕」的批评——莫非的解读简化了赵汀阳的论证。原文中对称+互换是作为「古典正义」的两个结构条件，不是单独的工具。

### 外部攻击者

**John Rawls（正义论）**：赵汀阳批评罗尔斯的「无知之幕」剥夺了博弈者的真实信息——人们不知道自己的社会地位和他们要保护什么。但 Rawls 可以回应：正是因为你知道了自己的地位，你的「换椅子」会不自觉地偏向自己的利益——你不会真的公正，你只是在计算。

## Action Triggers

| 触发条件 | 动作 |
|:--|:--|
| 设计任何涉及利益分配的规则 | 跑一遍本工具 |
| 合作伙伴/员工表达不满 | 换椅子：从对方视角重新看规则 |
| 签订长期合同前 | 逐条过三问 |
