# 技能：四层联系建立法

## 原始表述
> L2.建立联系 √模型到现象：举一反三 √现象到现象：底层关联 √现象到模型：N层洞察 √模型到模型：十层解读

## 操作步骤
1. 模型到现象：用理论解释具体案例，举一反三
2. 现象到现象：发现不同案例间的底层关联
3. 现象到模型：从具体案例中提炼N层洞察
4. 模型到模型：进行跨理论的十层深度解读

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 深度学习、建立体系理解时，需要跨概念连接 |
| ✅ 适合 | 需要创新突破时，跨域迁移产生新洞察 |
| ✅ 适合 | 已有一定知识储备，需要整合为网络 |
| ✅ 适合 | 教学或分享前，需要建立知识间的逻辑桥梁 |
| ❌ 不适合 | 初学阶段信息不足时 → 缺乏建立联系的素材 |
| ❌ 不适合 | 时间紧迫的紧急任务 → 联系建立需要深度思考 |
| ❌ 不适合 | 纯执行性工作 → 不需要概念层面的联系 |
| ❌ 不适合 | 知识体系尚未成型 → 强行联系产生错误关联 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **联系过浅** | 这个和那个都提到用户——表面相似性连线 | 联系必须有深层逻辑：'A的认知机制是B的变体'，有因果、有转化关系，不是表面相似 |
| **联系过泛** | 把所有概念都和第一性原理连起来 | 当所有路径都通向罗马时，路径没有信息量。联系必须有具体的信息增益 |
| **只连不验证** | 建立联系后不去验证是否成立 | 联系可以设计实验检验：'如果A的解释成立，那么在B的场景下应该观察到X' |
| **联系冗余** | 联系图谱越来越密但没有去重，噪音淹没了信号 | 定期清理联系图谱，删除'有趣但不重要'的噪声联系，保留有预测力的联系 |
| **联系不可输出** | 联系只在自己脑子里，说不出来具体关联是什么 | 联系必须能写成一段话讲给不懂的人听，说不出来等于没真正理解 |
| **联系僵化** | 一旦建立联系就拒绝修正，即使新证据显示联系不成立 | 联系是假设不是真理，新证据出现时必须重新评估联系的有效性 |
| **跨域过度** | 把生物学概念硬套到商业决策，缺乏领域适配 | 跨域联系必须说明'在什么条件下'适用，不能无条件迁移 |
| **联系替代理解** | 忙于建立联系但每个概念本身理解不深 | 先确保单个概念理解到位，再建立联系。联系是理解的深化不是理解的替代 |

## 判断标准

**什么算一条有效的联系**：

| 标准 | 好的联系 | 坏的联系 |
|:---|:---|:---|
| 有深层逻辑 | "A 的认知机制是 B 的变体"（有因果、有转化关系） | "A 和 B 都提到了用户"（表面相似性，接触即分） |
| 可验证 | 联系可以设计一个实验来检验："如果 A 的解释成立，那么在 B 的场景下应该观察到 X" | 联系是主观感受，无法被第三方验证 |
| 有信息增益 | 建立联系后对 A 或 B 的理解加深了 | "X→Y"只是换了个说法，没有新增认知 |
| 可输出 | 联系能写成一段话，讲给不懂的人听 | 只在自己脑子里"我知道它们有关联"，说不出来具体关联是什么 |

**自检问题**：
1. 我能在 30 秒内讲清楚这两个概念是怎么联系的吗？——如果能，是真的懂了；如果支支吾吾，可能只是隐约觉得有关。
2. 这条联系过去一个月，我还在用它吗？——如果不用了，它可能是"有趣但不重要"的噪声联系。
3. 这条联系能不能用来预测？——比如"因为 A 和 B 是这种关系，所以当 A 变化时，B 会..."
