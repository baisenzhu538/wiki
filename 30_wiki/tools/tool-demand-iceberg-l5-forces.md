# L5隐藏洞察

> L4告诉你在哪切入，L5告诉你用户会不会真的切换过来。人改变习惯不是因为"更好的功能"，是因为推力+拉力 > 焦虑+习惯。

## 三种任务（不只是功能）

| 任务类型 | 问题 | 示例 |
|:---|:---|:---|
| **功能任务** | 用户要完成什么？ | "在30分钟内做出3人份的晚餐" |
| **情感任务** | 用户想感觉到什么？ | "我不是一个糟糕的妈妈" |
| **社交任务** | 用户想让别人看到什么？ | "同事觉得我生活有品质" |

## 四种力量

| 力量 | 方向 | 示例 |
|:---|:---|:---|
| **推力** | 旧方案有多让人崩溃？→ 推动离开 | "每次都要手动对账，错一次扣500" |
| **拉力** | 新方案有多诱人？→ 拉动尝试 | "自动对账+错误预警，省2小时/天" |
| **焦虑** | 新方案有什么风险？→ 阻止尝试 | "数据会不会泄露？迁移要多久？" |
| **习惯** | 旧习惯有多顽固？→ 阻止离开 | "用了3年了，肌肉记忆" |

**核心公式**：(推力+拉力) > (焦虑+习惯) → 用户才会切换

## Agent执行指令

```python
# 引自 AI场景推演教练 Step 4

2. 情感任务：他想感觉什么？
3. 社交任务：他想让别人看到什么？
4. 四种力量分析：
   - src_unknown
   - src_unknown
   - src_unknown
   - src_unknown
5. 判断：(推力+拉力)是否 > (焦虑+习惯)？
"""
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 只分析功能 | 忽略了情感和社交维度 | 强制问两个问题 |
| 四种力量失衡 | 只说推力和拉力，不提焦虑和习惯 | 每个力量至少列2条 |

## 适用边界

- src_unknown
- src_unknown
