# L5隐藏洞察

> L4告诉你在哪切入，L5告诉你用户会不会真的切换过来。人改变习惯不是因为"更好的功能"，是因为推力+拉力 > 焦虑+习惯。

## 三种任务（不只是功能）

| 任务类型 | 问题 | 示例 |
|:---|:---|:---|
| **功能任务** | 用户要完成什么？ | "在30分钟内做出3人份的晚餐" |
| **情感任务** | 用户想感觉到什么？ | "我不是一个糟糕的妈妈" |
| **社交任务** | 用户想让别人看到什么？ | "同事觉得我生活有品质" |

## 四种力量

| 力量 | 方向 | 示例 |
|:---|:---|:---|
| **推力** | 旧方案有多让人崩溃？→ 推动离开 | "每次都要手动对账，错一次扣500" |
| **拉力** | 新方案有多诱人？→ 拉动尝试 | "自动对账+错误预警，省2小时/天" |
| **焦虑** | 新方案有什么风险？→ 阻止尝试 | "数据会不会泄露？迁移要多久？" |
| **习惯** | 旧习惯有多顽固？→ 阻止离开 | "用了3年了，肌肉记忆" |

**核心公式**：(推力+拉力) > (焦虑+习惯) → 用户才会切换

## Agent执行指令

```python
# 引自 AI场景推演教练 Step 4

2. 情感任务：他想感觉什么？
3. 社交任务：他想让别人看到什么？
4. 四种力量分析：
   - src_unknown
   - src_unknown
   - src_unknown
   - src_unknown
5. 判断：(推力+拉力)是否 > (焦虑+习惯)？
"""
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 只分析功能 | 忽略了情感和社交维度 | 强制问两个问题 |
| 四种力量失衡 | 只说推力和拉力，不提焦虑和习惯 | 每个力量至少列2条 |

## 适用边界

- **适用**：任务地图完成后，需要理解"用户为什么不改变"的深层阻力
- **不适用**：用户已明确表达不满但客观条件限制（如预算硬约束）

## 质疑

- **具体假设**：该工具假设"微观体感推演能揭示用户的真实感受"，但"微观体感"本质上是研究者的共情投射——研究者把自己代入用户角色后的感受，不等于用户的真实感受。共情的准确性高度依赖研究者与用户的相似度。
- **边界**：在跨文化需求分析中，微观体感推演几乎完全失效——一个中国研究者在推演美国农村用户的心理状态时，体感数据几乎为零。
- **前提**：该工具的前提是"用户能感知并表达自己的体感"，但许多体感是前意识的——用户在做出决策的 0.3 秒前，大脑已经完成了情感评估，而用户事后报告的"理由"只是对已做决策的合理化。

**Daniel Pink**（行为科学作家，《Drive》作者）会质疑：微观体感推演把"理解用户"等同于"感受用户的痛苦"，但共情和行动是两回事。一个产品经理可能在推演中"深刻感受到"用户的焦虑，但这不会改变产品决策——因为产品决策受组织资源、技术约束、时间压力的影响远大于"理解用户"的影响。微观体感推演可能变成"感动自己"的仪式，而非"改变产品"的杠杆。
