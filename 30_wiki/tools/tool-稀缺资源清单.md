# 稀缺资源清单

## 一句话定义

列出你的业务中**真正稀缺、不可替代、决定生死**的资源——不是"什么都重要"，是"只有这几样卡住了就会死" [conf=0.78, source=一堂方法论]。

## 稀缺资源判断标准

一个资源是「稀缺」的，当且仅当：
1. **不可替代**：没有Plan B，找不到替代品
2. **决定产出上限**：这个资源有多少，业务最多做多大
3. **获取周期长**：不是加钱就能立刻拿到的

## 常见稀缺资源类型

| 类型 | 例子 | 对决策的影响 |
|:---|:---|:---|
| 一号位时间 | CEO每周只能深度参与3个决策 | 决定能同时推进几条业务线 |
| 核心人才 | 能独立操盘0-1的PM | 决定能同时开几个新项目 |
| 关键供应商 | 独占芯片/原料供应 | 决定产能上限 |
| 渠道/牌照 | 唯一的线下入口/经营许可 | 决定市场准入节奏 |
| 资金窗口 | 融资到账前的runway | 决定试错次数上限 |

## 操作步骤

1. 列出你业务中所有"感觉稀缺"的资源
2. 用三条标准逐条过滤——不符合的全划掉
3. 对剩下的真正的稀缺资源，标注「当前存量」和「消耗速度」
4. 基于消耗速度，倒推「决策截止日期」

## 失败模式

- 把"贵"当"稀缺"——钱能解决的不是稀缺
- 清单太长——超过5条的"稀缺"= 什么都没真稀缺
