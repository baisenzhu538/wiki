# 行业报告可信度评估：多信数据，少信观点

> **一句话**：Doris来自顶级咨询公司的经验——多信数据，少信解读，警惕观点。数据的可信度 > 解读的可信度 ≫ 观点的可信度。

---

## 三层信息可信度金字塔

```
        ▲ 观点（最低可信度）
       / \  "我们认为XX赛道前景广阔"
      /   \
     / 解  \  解读（中等可信度）
    /  读   \  "营收增长20%，主要原因是..."
   /________\
  /          \
 /   数  据    \  数据（最高可信度）
/______________\  "2019年市场规模4777亿元，年复合增长9.9%"
```

| 层级 | 是什么 | 可信度 | 处理方式 |
|:---:|:---|:---:|:---|
| **数据** | 原始数字、统计结果 | ⭐⭐⭐⭐⭐ | 可以直接引用，但注意统计口径 |
| **解读** | 对数据含义的分析 | ⭐⭐⭐ | 参考但不盲信，用自己的判断重新解读 |
| **观点** | 主观判断和建议 | ⭐ | 警惕！可能包含严重偏见 |

## 实战四步判断法

```
1. 先看数据，忽略解读和观点
2. 溯源数据的原始出处（不要相信"据XX研究"而没有链接的引用）
3. 检查统计口径（同样的数字，口径不同含义完全不同）
4. 用另一个独立来源交叉验证
```

## 质疑

- **具体假设**：该工具假设"多信数据、少信观点"能有效评估报告可信度，但"数据"和"观点"的边界在实际报告中经常模糊——报告选择展示哪些数据、隐藏哪些数据，本身就是一种"观点"。所谓"纯数据"也是"被选择的证据"。
- **边界**：在高度政治化的行业（如新能源、半导体），即使是"数据"也可能被操纵——政府统计口径的变化、行业协会的口径差异，都会让"多信数据"变成"多信不同版本的偏见"。
- **反例**：一份"数据详实、方法论透明"的行业报告预测"VR 市场将在 2025 年达到 1000 亿美元"——数据可信、方法可信、结论完全错误。可信度不等于准确性。

**Carl Sagan**（康奈尔大学天文学教授，《魔鬼出没的世界》作者）会质疑："多信数据少信观点"听起来像科学思维，但真正的科学思维不是"区分数据和观点"，而是"追问证据的强度"。他的"探测气球"原则是：非同寻常的主张需要非同寻常的证据。行业报告中的"市场将增长 10 倍"是非同寻常的主张——它需要的不是"多信数据"，而是"可验证的因果机制"。没有因果机制的数据，再多也只是"相关性的堆砌"。
