# 决策深度L1：优先级定性

## 一句话定义

L1是最浅的决策深度——**只用定性判断排出优先级**，不涉及数字计算。适用于"筛选项太多，先砍掉明显不行的"阶段 [conf=0.80, source=一堂方法论]。

## 适用场景

- 10+候选方案，需要快速缩小到3个
- 决策时间 < 1小时
- 数据不完整，但需要方向判断

## 操作步骤

1. 列出所有候选方案
2. 对每个方案，只回答三个问题：
   - 这个方案「大概率能成」还是「大概率不行」？（直觉判断）
   - 如果成了，影响是「改变命运」「有意义」「微不足道」？
   - 如果砸了，代价是「致命」「可承受」「无所谓」？
3. 三个都偏正面的 → 进入L2
4. 任一偏负面 → 暂时搁置

## 边界

L1不能用来做最终决策。L1只负责「筛」——筛掉明显不行的，筛选留下的都需要L2+验证。

## 失败模式

- 用L1做最终决策：觉得"大概率能成"就直接干了 → 跳到L3/L4才知道不成立
- L1被锚定效应绑架：第一个方案给了好印象，后面全被带偏 → 随机打乱顺序
