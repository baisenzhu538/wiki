# IPO工具箱导航：I/P/O三段工具索引

> **一句话**：知道IPO还不够，知道每步用什么工具才算会用。Input→Process→Output三段，每段有L1-L6递进工具。

---

## I（Input）工具箱

| 段位 | 工具 | 用途 |
|:---:|:---|:---|
| L1 | 选书方法 | 判断"这本值不值得读" |
| L2 | 速读法 | 30分钟提取一本书的核心 |
| L3 | 主题阅读 | 围绕一个主题同时读5-10本 |
| L4 | 跨域阅读 | 把A领域的书用到B领域 |

## P（Process）工具箱

| 段位 | 工具 | 用途 |
|:---:|:---|:---|
| L1 | 笔记法 | 读完能记住 |
| L2 | 费曼学习法 | 讲给一个完全不懂的人听 |
| L3 | 刻意练习 | 针对薄弱环节反复练 |
| L4 | 案例拆解 | 用模型分析真实案例 |

## O（Output）工具箱

| 段位 | 工具 | 用途 |
|:---:|:---|:---|
| L1 | 200字摘要 | 学完写一段话总结 |
| L2 | 分享/讲授 | 给别人讲一遍 |
| L3 | 写文章/做课 | 系统的知识输出 |
| L4 | 带人/教练 | 教别人跑IPO |

> 每段选择工具的规则：先自评当前L段位，选高一级的工具尝试——L1用L2工具，L3用L4工具。
