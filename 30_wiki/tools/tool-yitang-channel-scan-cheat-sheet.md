# 渠道扫描小抄：线上/线下/转化/推荐获客清单

## Burn line

在决定「投哪个渠道」之前，先用一张清单把你能想到、同行在用、行业常识里的获客方式全部摊开，避免把局部经验当成全部选项。`[conf=0.92, source=00_inbox/一堂五步法之增长/一堂-渠道探索方法论-小抄-01_vlm_desc.md]`

## 一句话

渠道扫描小抄是把「线上获客、线下获客、获客转化、推荐获客」四大类共 40+ 种具体打法结构化摊开的检索工具，用于在渠道探索的「扫描」阶段消除认知盲区，而不是直接决定最终投放渠道。

## 1. 为什么需要这张小抄

多数团队做渠道决策时，会陷入两个极端：要么只知道自己做过的两三个渠道，反复在舒适区里试错；要么什么火就跟风做什么，没有系统性的选项池。`[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §1-120, 诊断报告 diag_20260627_wangyuyan-channel-growth-nine-layer.md L4]`

这张小抄的价值在于：

- **打开视野**：把分散在微信、抖音、地推、展会、分销、裂变等场景中的打法，按统一维度归类。
- **建立共同语言**：团队讨论渠道时，先对齐「我们到底在讨论哪一类打法」，避免概念混淆。
- **支撑扫描阶段**：与 `framework-yitang-channel-exploration-4step` 中的「扫描 → 预判 → 测试 → 建模」配合使用，作为扫描阶段的起点输入。

四类渠道不是相互独立的，而是构成一条完整的获客链路：线上/线下负责把流量拉进来，转化负责把流量变成成交，推荐负责让老用户带来新用户。`[conf=0.92, source=00_inbox/一堂五步法之增长/一堂-渠道探索方法论-小抄-01_vlm_desc.md]`

## 3. 线上获客（A 类）：用互联网媒介触达目标客户

线上获客小抄把打法分为 6 大方向、20 余种具体方法。`[conf=0.96, source=00_inbox/一堂五步法之增长/一堂-渠道探索方法论-小抄-02_vlm_desc.md]`

### A1. 内容营销：用内容换信任与流量

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 内容类型 | 长视频、短视频、直播、音频、图片、长篇文字、短篇文字 | 需要建立专业认知、创始人 IP、行业影响力的业务 |
| 媒体平台 | 微信、微博、抖音、快手、B 站、知乎、小红书、视频号 | 有内容生产能力，但不确定哪个平台用户更匹配 |
| 不同侧重 | 商品信息、创始人 IP、热点事件、动态热点信息、权威排名榜单 | 需要快速借势或建立信任背书 |
| 关键材料 | 白皮书、产品介绍、行业解决方案、出书、技术推广目录、免费知识库 | B2B、高客单价、决策链复杂的业务 |
| AI 内容 | 数字人、文生图、文生视频、AI 写歌 | 需要低成本、规模化生产内容的团队 |

### A2. 采买流量：直接花钱买曝光与线索

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 投信息流 | 抖音、微博、QQ、朋友圈、公众号、视频号 | 产品价值已验证，需要快速放量 |
| 搜索引擎 | SEM 搜索引擎营销，重点打长尾流量 | 用户有主动搜索需求，如工具、SaaS、本地服务 |
| 投自媒体 | 小红书、微博、抖音、知乎、大 V/KOL/KOC | 需要借助达人信任背书做种草 |
| 广告联盟 | Google 联盟、百度联盟、网易联盟、金山联盟 | 有预算做规模化流量分发 |
| 商机线索 | 企查查、天眼查、启信宝、探迹、运营商线索 | B2B 销售，需要精准企业联系人 |
| 线上广告 | 视频广告、植入广告、电视广告、冠名、明星代言 | 品牌成熟期，预算充足 |
| 小众渠道 | WiFi 页面、问卷、快递、App 预装 | 特定场景触达，如线下零售、本地生活 |

### A3. 线上活动：借节点与互动拉新

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 举办活动 | 会员日、周年活动、节日折扣、吸粉小游戏、视频试看 | 已有用户池，需要激活与裂变 |
| 参加活动 | 618、国庆节、光棍节、双十二 | 电商、零售、消费品借势大促 |

### A4. 入驻平台：到用户已经聚集的地方开店

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 电商平台 | 阿里、京东、拼多多、抖音、小米有品、亚马逊、速卖通、Temu、社区团购 | 标准化消费品、有供应链能力 |
| 服务平台 | 美团、58 同城、饿了么、京东到家、阿里高德、抖音同城 | 本地服务、O2O、餐饮、家政 |
| 内容平台 | 知乎、喜马拉雅、得到、荔枝微课 | 知识付费、教育、专业内容 |
| 采购平台 | 政府采购平台、招标平台、知了标讯、京东慧采、百度爱采购 | B2B、政企客户、招投标业务 |

### A5. 技术算法：用技术手段抓取或截流

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 爬虫抓取 | 抓取销售线索、百度地图、58 同城、采招网站公告 | B2B 销售线索采集，需注意合规边界 |
| 竞争调研 | 设法获得竞对的客户、竞对截流 | 竞争激烈的成熟市场 |

### A6. 搜索优化：让用户搜到你

| 具体分类 | 典型打法 | 适用场景 |
|:---|:---|:---|
| 官方网址 | SEO 优化（官网、留资渠道、独立站） | 用户有主动搜索习惯，需要长期自然流量 |
| 应用商店 | ASO 优化（华为、小米、苹果应用商店） | App 类产品，需要提升自然下载 |

## 7. 操作步骤：如何使用这张小抄

### Step 1：建立选项池

把本小抄中的 40+ 种打法全部过一遍，先不判断好坏，只判断「是否适用本公司」。用下面这张表做第一轮筛选。

**渠道扫描初筛表**

| 渠道编号 | 渠道名称 | 是否已知 | 是否尝试过 | 初步判断（高/中/低匹配） | 不尝试的原因 |
|:---:|:---|:---:|:---:|:---:|:---|
| A11 | 长视频内容 | ☐ | ☐ | ☐ | |
| A21 | 信息流投放 | ☐ | ☐ | ☐ | |
| B11 | 举办线下活动 | ☐ | ☐ | ☐ | |
| C12 | 私域运营 | ☐ | ☐ | ☐ | |
| D11 | 老带新机制 | ☐ | ☐ | ☐ | |

### Step 2：标注业务属性

对每一类渠道，从三个维度快速标注：

1. **目标客户是否在此出没**：这个渠道上的用户是不是你的目标客户？
2. **产品形态是否匹配**：这个渠道适合卖什么价位、什么决策复杂度的产品？
3. **团队能力是否可及**：内容、销售、技术、供应链，哪一项是瓶颈？

### Step 3：与渠道特性五维度交叉

结合 `tool-yitang-channel-scoring-matrix` 中的五维度（大小、集中度、成本、快慢、持续性），对初筛后的渠道打分排序。

### Step 4：选出 5-10 个候选渠道

不要只选 1-2 个，也不要超过 10 个。太少会遗漏机会，太多会分散测试资源。

### Step 5：进入低成本测试

对每个候选渠道，设计一个最小可行测试（MVT），用尽可能低的成本拿到「这个渠道能不能带来目标客户」的真实数据。具体可参考 `framework-lean-abcd-model` 中的假设验证逻辑。

## 8. 典型场景

### 场景 1：初创团队第一次系统做获客

团队之前只靠创始人发朋友圈和地推，增长遇到瓶颈。使用本小抄后，发现内容营销、入驻垂直平台、老带新机制三个方向此前完全没有尝试过，于是分别安排小预算测试。

### 场景 2：成熟业务开拓第二增长曲线

已有渠道增长放缓，需要寻找新增量。使用本小抄做全员脑暴，要求每个部门从四个大类中各提出 2 个未尝试渠道，再用评分矩阵排序。

### 场景 3：To B 业务从直销扩展到多元获客

销售团队习惯陌拜和面销，对其他渠道不熟悉。使用本小抄识别出商机线索平台、行业峰会、内容白皮书、KOL 推荐等候选渠道，进入测试队列。

### 场景 4：跨部门对齐渠道语言

市场部和销售部对「渠道」理解不一致。市场部说渠道是抖音和小红书，销售部说渠道是代理商和展会。用本小抄把四类渠道摊开，统一分类后再讨论分工。

## 9. When NOT to Use

### 9.1 不适合直接使用本小抄的场景

- **产品价值尚未验证**：如果产品本身没有解决真实需求，渠道再多也只是加速失败。应先用 `framework-lean-product-kernel` 验证价值假设。
- **没有基础转化能力**：流量来了接不住，先用本小抄的「获客转化」部分补齐 CRM、私域或销售团队。
- **团队没有测试资源**：扫描出 20 个渠道但没有人力和预算测试，不如先聚焦 2-3 个最匹配的渠道。
- **把清单当战略**：本小抄是输入工具，不是决策工具。最终投哪个渠道，必须经过预判和测试。

### 9.2 使用边界

- 小抄中的渠道是「常见打法」而非「穷尽列表」。行业特殊性打法（如医疗、金融、政务）需要补充专业渠道。
- 线上渠道的合规边界（爬虫、隐私、广告法）需要单独评估，本小抄只列选项，不替代法律判断。

## 10. 常见失败模式

### 失败模式 1：把小抄当答案，直接抄同行

**症状**：看到竞品做抖音，自己也做抖音；看到行业展会效果好，立刻报名参展。

**修复**：先用小抄建立选项池，再用产品匹配度和渠道特性评分筛选，最后用测试验证。

### 失败模式 2：只扫描自己熟悉的渠道

**症状**：团队背景是互联网，就只列线上渠道；团队背景是传统销售，就只列线下渠道。

**修复**：强制要求每个大类至少选出 2 个候选渠道，再由非本部门同事挑战。

### 失败模式 3：扫描完不做预判和测试

**症状**：会议室贴满渠道清单，但没有下一步动作，三个月后清单过时。

**修复**：扫描阶段结束后 48 小时内，必须输出「5-10 个候选渠道 + 测试计划 + 负责人」。

### 失败模式 4：把转化和获客混为一谈

**症状**：讨论获客时只谈拉新，不考虑 CRM、私域、销售团队能否接住流量。

**修复**：使用本小抄时，必须同时看「获客转化」大类，评估承接能力。

### 失败模式 5：忽视推荐获客

**症状**：把所有预算都投向新客获取，不设计老带新、分销、异业联盟。

**修复**：在产品体验达标的业务中，推荐获客往往是成本最低、持续性最好的渠道之一。

## 11. 渠道扫描检查清单

- [ ] 已把线上获客、线下获客、获客转化、推荐获客四大类全部过一遍
- [ ] 每个大类至少识别出 2 个此前未尝试或忽视的渠道
- [ ] 已用「目标客户是否在此出没 / 产品形态是否匹配 / 团队能力是否可及」三问初筛
- [ ] 已结合渠道特性五维度（大小、集中度、成本、快慢、持续性）打分
- [ ] 已收敛到 5-10 个候选渠道，并明确测试优先级
- [ ] 每个候选渠道都有负责人、预算上限、测试周期、判断标准
- [ ] 已评估获客转化承接能力，避免流量来了接不住
- [ ] 已标注合规与数据隐私风险点
- [ ] 测试结果已回写到渠道清单，更新匹配度评分
- [ ] 每季度复盘一次渠道清单，补充新渠道、淘汰失效渠道

## 12. 与一堂五步法的关系

渠道扫描小抄是 `framework-yitang-channel-exploration-4step` 中「扫描」阶段的实操工具。它回答「有哪些选项」，但不回答「哪个最好」。后一个问题需要结合：

- `tool-yitang-channel-scoring-matrix` 做渠道预判评分；
- `framework-lean-abcd-model` 设计渠道测试实验；
- `tool-区分获客渠道计算单元roi` 或 `yt-unit-model-overview` 核算单渠道经济账；
- `framework-yitang-channel-industrialization` 把验证后的渠道工业化放大。
