# 股票/上市公司数据

> 同花顺/东方财富/雪球——上市公司的股价、估值、财务数据和投资者讨论。

**用法**：
- 看财报里的营收/毛利/用户增长趋势——比 PR 稿诚实，因为造假有法律后果
- 看招股说明书的风险因素章节——竞对自己承认的最大风险=你最该关注的攻击方向
- 看投资者电话会议纪要——管理层对分析师提问的回答往往透露战略意图
- 看雪球/东方财富的投资者讨论——散户情绪是消费端需求的滞后指标

**价值**：资本市场对行业的定价=机构用真金白银投票的结果。比任何报告都诚实。

**坑**：股价受宏观经济和流动性影响，不完全反映公司基本面。

## 目的

解决"竞对公开信息全是 PR 稿"的问题——从上市公司强制披露的财报、招股书、电话会议中提取真实经营数据。适用于竞对或行业内有上市公司的场景，是获取可信竞对数据性价比最高的途径。

## 操作步骤

1. **定位上市公司**：在同花顺/东方财富中搜索竞对公司或行业概念股，确认是否有上市主体；若有，下载最近 2-3 年财报和招股说明书。
2. **提取关键数据**：从财报中提取营收、毛利率、用户数、获客成本、研发投入占比等核心指标；从招股书"风险因素"和"业务模式"章节提取竞对自己承认的弱点和战略方向。
3. **对比行业基准**：将提取的指标与行业平均水平对比（可用同行业其他上市公司数据），判断竞对在行业中的真实位置——是行业领跑还是落后者。

## 不要用的场景

- **竞对未上市**：没有公开披露义务，此工具完全不适用。
- **上市公司业务多元化**：如果竞对上市主体包含多个业务线，单看合并报表无法拆分出目标业务的真实数据。
- **VIE 架构公司**：海外上市的中国公司通过 VIE 架构披露的数据可能与境内实体有差异。
- **短期投机视角**：本工具用于获取经营数据，不是用于股票投资决策。

## 质疑

### 内在局限

上市公司财报是"合规真实"但不是"完整真实"——财报中可以通过会计政策选择、关联交易、收入确认时点等合法手段美化数据。瑞幸在暴雷前的财报也是"审计过"的。

### 外部反对者

**Howard Schilit**（财务欺诈研究）：
> 「财报是经过法律和会计过滤后的叙事，不是企业运营的原貌。最关键的劣势往往藏在附注和会计政策变更里，而 90% 的分析师只看利润表前几行。用财报数据做竞对分析，你看到的是对方想让你看到的版本。」

**Aswath Damodaran**（估值理论）：
> 「市场定价不等于真实价值。股价反映的是市场预期，而市场预期经常系统性偏离基本面——尤其是在泡沫期。把'机构用真金白银投票的结果'等同于'比报告更诚实'，混淆了价格与价值的根本区别。」

进一步审视该方法的四类关键术语：
- **具体假设**：上市公司强制披露的财报、招股书等数据比 PR 稿更真实可信。
- **边界**：适用于竞对或行业内有上市公司、业务相对单一的场景；不适用于未上市、业务多元化、VIE 架构或用于短期投资决策的场景。
- **反例**：财报可通过会计政策合法美化，瑞幸暴雷前财报也经审计；市场定价受预期和流动性影响，会系统性偏离基本面。
- **前提**：前提是深入阅读附注、会计政策变更和"风险因素"，并将财务数据与行业基准、非财务指标交叉验证。
