# 产品内核十大典型指标：从假设到验证的数据体系

> 一堂五步法：产品内核必须有指标验证，不是"感觉好"，而是"数据好"。

## 核心框架

十大典型指标按从业者已验证的**获客→服务（转化）→复购**漏斗重新分类：

| 漏斗环节 | 核心指标 | 说明 | 验证什么 | 代理指标（proxy） |
|:---|:---|:---|:---|:---|
| **🔵 获客** | 1. 目标用户精准度 | 用户画像与实际用户的匹配度 | 用户定义是否准确 | 渠道来源分布、自然搜索关键词匹配度 |
| | 2. 用户获取成本(CAC) | 获取一个目标用户的成本 | 获客效率 | 渠道ROI、点击率(CTR)、CPM/CPC |
| | 3. 试训/试用量 | 愿意"来一次"的人数（足球俱乐部案例） | 获客吸引力 | 落地页访问量、表单提交量、预约量 |
| **🟢 服务（转化）** | 4. 关键转化率 | 从"来一次"到"选择购买/留存"的比例 | 内核竞争力 | 首次体验完成率、停留时长、关键动作完成率 |
| | 5. 用户激活率 | 完成核心功能的用户比例 | 内核吸引力 | 首次核心功能使用率、7日活跃度 |
| | 6. 付费转化率 | 从试用到付费（或从免费到付费）的比例 | 价值认可度 | ARPU、客单价、免费→付费漏斗各层转化 |
| | 7. 核心功能使用率 | 内核功能的使用比例 | 功能设计是否命中 | 功能点击热力图、功能渗透率 |
| **🟠 复购** | 8. 复购/续费率 | 再次付费的比例 | 持续价值 | 用户生命周期价值(LTV)、消费频次 |
| | 9. 用户满意度(NPS) | 用户推荐意愿 | 综合体验 | CSAT评分、主动推荐次数、社交媒体提及 |
| | 10. 用户流失率 | 停止使用产品的比例 | 内核是否持续满足需求 | 沉默用户占比、7/30日留存率、退订率 |

> **设计原则**：代理指标（proxy）用于当核心指标难以直接测量时的替代观测。选用 proxy 需满足两个条件——与核心指标高度相关，且比核心指标更易获取。当 proxy 与核心指标出现背离时，以核心指标为准。

### 漏斗三环节的决策逻辑

| 环节 | 核心问题 | 典型诊断 |
|:---|:---|:---|
| **获客** | 用户为什么来？试训量够不够？ | 试训量不足 → 渠道或用户定义出问题；试训量大但转化低 → 内核吸引力不足 |
| **服务（转化）** | 来了之后为什么选你？关键转化率卡在哪？ | 体验完不转化 → 决定性要素缺失或"看起来好但体验差"；转化高但付费低 → 价值感知或定价问题 |
| **复购** | 为什么继续来？为什么不再来？ | 复购率低 → 习惯未养成或社交纽带不够（足球俱乐部案例）；流失高 → 内核价值不持续 |

> **口述来源**：Truman 在足球俱乐部案例中，将业务拆为「试训量 × 转化率 × 复购率」三个参数，分别对应获客、转化、复购漏斗三环节。（来源：`一堂-产品内核实操课-Truman-口述.txt` L998-L1070）

## 关键洞察

### 1. 指标与内核按漏斗对应

每个指标必须对应内核假设，并按漏斗环节归位：

| 漏斗环节 | 内核假设 | 验证指标 | 指标下降说明 | proxy 辅助判断 |
|:---|:---|:---|:---|:---|
| 获客 | 用户定义准确 | 目标用户精准度 + 试训量 | 用户画像与实际不符，或获客渠道不对 | 渠道来源是否集中在目标人群 |
| 获客 | 获客效率合理 | CAC | 获客成本过高，不可持续 | 渠道ROI是否高于阈值 |
| 转化 | 内核有吸引力 | 关键转化率 + 激活率 | 内核竞争力不足或体验不符预期 | 首次体验完成率、停留时长 |
| 转化 | 价值被认可 | 付费转化率 | 价值感知不足或定价问题 | 免费→付费各层转化 |
| 转化 | 功能设计命中 | 核心功能使用率 | 功能未命中用户痛点 | 功能渗透率、热力图 |
| 复购 | 价值持续 | 复购/续费率 | 内核价值不持续 | LTV、消费频次 |
| 复购 | 用户满意 | NPS | 体验差或竞品替代 | CSAT、推荐行为 |
| 复购 | 内核持续满足需求 | 流失率 | 内核过时或被替代 | 沉默用户占比、留存曲线 |

### 2. 关键指标 vs 虚荣指标

| 虚荣指标 | 关键指标 | 为什么 |
|:---|:---|:---|
| 总用户数 | 目标用户精准度 | 用户多但不精准，无价值 |
| 总下载量 | 激活率 | 下载了但不用，无价值 |
| 总营收 | 付费转化率 | 营收高但转化率低，不可持续 |
| 功能数量 | 核心功能使用率 | 功能多但不用，是负担 |
| 媒体曝光 | 关键转化率 | 曝光多但转化少，效率低 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **指标缺失** | 产品上线，但没有指标监测 | 定义3-5个关键指标，建立监测机制 |
| **虚荣指标** | 关注总用户数、下载量 | 替换为关键指标 |
| **指标与内核脱节** | 指标变化无法说明内核问题 | 重新设计指标，确保对应内核假设 |
| **指标过多** | 看20个指标，无法聚焦 | 聚焦3-5个关键指标 |
| **无基准无目标** | 有指标，但不知道好坏 | 设定基准值和目标值 |
| **指标不行动** | 指标差，但不采取措施 | 建立指标-行动闭环 |

## 质疑

- **具体假设**：该工具假设结构化方法论能提升效果，但方法论的有效性取决于执行者的判断力和场景适配——没有判断力的执行只是'走流程'，不等于'做好事'。
- **边界**：在全新领域或快速变化的环境中，已有数据和经验可能完全失效——工具的有效性高度依赖场景的稳定性。
- **前提**：该工具的前提是使用者能正确理解和执行工具的规则，但执行者的认知偏差和经验限制会影响工具的实际效果。

**Peter Drucker**（管理学大师）会质疑：工具的价值不在于"有没有"，而在于"用得好不好"。任何工具都是"能力放大器"——如果使用者的判断力不足，工具只会放大错误。真正的风险不是"缺少工具"，而是"有了工具后产生的虚假安全感"——让你以为自己已经覆盖了所有可能性，实际上只是走完了流程。
