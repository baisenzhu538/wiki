# 产品内核十大典型指标：从假设到验证的数据体系

> 一堂五步法：产品内核必须有指标验证，不是"感觉好"，而是"数据好"。

## 核心框架

十大典型指标按业务链条分为**获客→服务→复购**三个环节（来源：「一堂产品内核・十大典型指标」图，`src_20260510_5ef61f8f` / OCR 件 `src_20260611_94673a56`，两者一致）：

| 环节 | 指标 | 一句话说明（源原文） |
|:---|:---|:---|
| **获客环节** | 1. 销转率 | 看潜在客户转化为实际购买客户的比例 |
| | 2. 动销率 | 看有销售的商品品种数与所有商品总品种数的比例 |
| | 3. 捕获率 | 看进店消费人数占总经过人流量的比例 |
| **服务环节** | 4. 留存率 | 看使用产品的用户，N天/周/月后还在持续使用的比例 |
| | 5. 完课率 | 看用户是不是能完成履约和最后学习 |
| | 6. 退款率 | 看服务履约中，用户退款的比例 |
| | 7. 满意率 | 看用户接受完服务，满意度的比例和打分 |
| **复购环节** | 8. 复购率 | 看消费购买后，会继续购买的比例 |
| | 9. 续费率 | 看续费用户数占现有用户数的比例 |
| | 10. 推荐率 | 看用户是否愿意主动推荐的比率 |

### 漏斗三环节的决策逻辑

| 环节 | 核心问题 | 典型诊断 |
|:---|:---|:---|
| **获客** | 用户为什么来？试训量够不够？ | 试训量不足 → 渠道或用户定义出问题；试训量大但转化低 → 内核吸引力不足 |
| **服务（转化）** | 来了之后为什么选你？关键转化率卡在哪？ | 体验完不转化 → 决定性要素缺失或"看起来好但体验差"；转化高但付费低 → 价值感知或定价问题 |
| **复购** | 为什么继续来？为什么不再来？ | 复购率低 → 习惯未养成或社交纽带不够（足球俱乐部案例）；流失高 → 内核价值不持续 |

> **口述来源**：Truman 在足球俱乐部案例中，将业务拆为「试训量 × 转化率 × 复购率」三个参数，分别对应获客、转化、复购漏斗三环节。（来源：`一堂-产品内核实操课-Truman-口述.txt` L998-L1070）

## 关键洞察

### 1. 指标与内核假设按环节对应

十大指标不是孤立的数字——每个指标回答一个内核假设是否成立：

| 环节 | 指标 | 验证的内核假设 | 指标异常说明 |
|:---|:---|:---|:---|
| 获客 | 销转率 | 潜在客户认可你的价值主张 | 来了不买——卖点或定价与目标用户错位 |
| 获客 | 动销率 | 产品线组合有效 | 大量品种无人买——SKU 堆砌而非内核驱动 |
| 获客 | 捕获率 | 触点/门店对目标人流有吸引力 | 人流经过但不进店——触达或定位出问题 |
| 服务 | 留存率 | 产品持续被使用 | 用一两次就流失——内核吸引力不持续 |
| 服务 | 完课率 | 履约设计用户跟得下来 | 学不完——交付超出用户基础能力（声音变现案例同款病灶） |
| 服务 | 退款率 | 承诺与交付一致 | 退款上升——过度承诺或内核不成立 |
| 服务 | 满意率 | 交付体验达标 | 分数低——服务环节有决定性要素缺失 |
| 复购 | 复购率 | 价值持续、习惯养成 | 不复购——习惯未养成或社交纽带不够（足球俱乐部案例） |
| 复购 | 续费率 | 存量用户认可长期价值 | 不续费——长期价值感知不足 |
| 复购 | 推荐率 | 用户愿意背书 | 不推荐——体验未超预期或有隐性不满 |

### 2. 关键指标 vs 虚荣指标

| 虚荣指标 | 关键指标（源清单内） | 为什么 |
|:---|:---|:---|
| 总触达/总人流 | 捕获率 | 人流大但不进店，无价值 |
| 咨询量/线索数 | 销转率 | 线索多但不成交，获客白费 |
| 报名/开课人数 | 完课率 | 报了名学不完，履约失败 |
| 流水/GMV | 退款率 | 流水高但退款同步走高，是虚假繁荣 |
| 老用户总数 | 续费率/复购率 | 盘子大但不续费，内核价值不持续 |

### 3. 指标的基准和目标

源文件只给指标定义，未给基准值——基准要靠自己建立：

- 每个选定的指标先记录**当前实测值**作为基准，不设基准的指标等于没设
- 目标值从单元模型反推：要让业务公式成立，这个指标至少要多少
- 设预警线：指标跌破基准的某个幅度（如退款率突然上升）触发复盘，而不是等季度总结
- 基准随阶段更新：早期用定性判断+小样本实测，数据积累后再定量化（与 [[yt-product-kernel-validation]] 的「先定性后定量」一致）

### 4. 指标的聚焦原则

不是看所有指标，而是聚焦关键指标：

- Truman 在足球俱乐部案例中把业务拆成「试训量 × 转化率 × 复购率」三个参数——**"最重要的是这三个参数"**（`一堂-产品内核实操课-Truman-口述.txt` L998-L1002）
- 十大指标是备选池，不是全看清单：按你的业务公式选出决定成败的 3 个左右重点盯
- 聚焦标准：这个指标的变化能否直接说明内核假设是否成立？不能说明的先放一边

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **指标缺失** | 产品上线，但没有指标监测 | 定义3-5个关键指标，建立监测机制 |
| **虚荣指标** | 关注总用户数、下载量 | 替换为关键指标 |
| **指标与内核脱节** | 指标变化无法说明内核问题 | 重新设计指标，确保对应内核假设 |
| **指标过多** | 看20个指标，无法聚焦 | 聚焦3-5个关键指标 |
| **无基准无目标** | 有指标，但不知道好坏 | 设定基准值和目标值 |
| **指标不行动** | 指标差，但不采取措施 | 建立指标-行动闭环 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 产品内核验证 | 技术性能评估 |
| 产品迭代决策 | 品牌传播效果 |
| 投资尽调 | 运营活动评估 |
| 团队绩效评估 | 财务预测 |

## 行动触发器

| 触发场景 | 第一个动作 | 成功指标 |
|:---|:---|:---|
| 内核假设定义完毕 | 从十大指标中选出与假设对应的 3 个左右指标 | 每个指标能回答"假设是否成立" |
| 产品已上线无监测 | 先补获客环节指标（销转率/动销率/捕获率按业务形态选） | 每周能看到真实数值 |
| 某环节指标异常 | 对照「指标与内核假设对应表」定位失守假设 | 明确是哪个环节的内核要素出问题 |
| 指标全面平稳但业务不涨 | 检查是否在看虚荣指标 | 替换为源清单内的关键环节指标 |

## 目的

> 解决"产品内核有没有被数据验证"的问题：把内核假设翻译成获客/服务/复购三环节的可测量指标，用数据替代"感觉好"。适用于产品内核定义完成后的验证与迭代阶段。

## 操作步骤

1. **选指标**：从十大指标清单中，按你的业务形态（获客/服务/复购三环节）选出与当前内核假设对应的 3 个左右关键指标
2. **建基准**：记录每个指标的当前实测值作为基准，并从单元模型反推目标值
3. **盯异动**：定期复盘指标；某个环节指标异常时，回到内核假设定位失守要素，触发迭代（参考足球俱乐部案例：试训量×转化率×复购率三参数定位法）

## 不要用的场景

> 技术性能评估、品牌传播效果评估、财务预测——这些场景的指标体系不在本卡覆盖范围；另外，业务尚未有任何真实用户行为数据时（纯概念阶段），应先用「聊、问、查」定性验证（见 [[yt-product-kernel-validation]] 六策略），而不是硬套指标。

## 质疑

- **具体假设**：该工具假设结构化方法论能提升效果，但方法论的有效性取决于执行者的判断力和场景适配——没有判断力的执行只是'走流程'，不等于'做好事'。
- **边界**：在全新领域或快速变化的环境中，已有数据和经验可能完全失效——工具的有效性高度依赖场景的稳定性。
- **前提**：该工具的前提是使用者能正确理解和执行工具的规则，但执行者的认知偏差和经验限制会影响工具的实际效果。

**Peter Drucker**（管理学大师）会质疑：工具的价值不在于"有没有"，而在于"用得好不好"。任何工具都是"能力放大器"——如果使用者的判断力不足，工具只会放大错误。真正的风险不是"缺少工具"，而是"有了工具后产生的虚假安全感"——让你以为自己已经覆盖了所有可能性，实际上只是走完了流程。
