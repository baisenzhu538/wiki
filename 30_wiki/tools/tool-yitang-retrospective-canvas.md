# 项目复盘关键成果画布

> **一句话**：项目复盘"挖到的金矿"一页纸拉走。按十六字原则（成败认定→场景还原→得失分析→总结提炼）走完复盘会后，把核心共识、行动计划和过程资产填入本画布——可打印、可截图、可发飞书。

> **画布全称**：一堂深度复盘·关键成果画布（Yitang Retrospective Canvas）

### 一、整体评价

> **操作**：先不做细节分析，团队每个人独立给出一个整体判断，暴露认知差。

|:---|:---|:---|:---|
| **整体大目标** | | | □ 大大超出预期 □ 超出预期 □ 符合预期 □ 基本符合预期 □ 低于预期 |
| **分支-时间** | | | |
| **分支-质量** | | | |
| **分支-成本** | | | |
| **分支-范围** | | | |

**判断规则**：
- 大目标完成 → 整体判定为"达成"（即使分支目标有瑕疵）
- 大目标未完成 → 整体判定为"未达成"（即使分支目标都做到了）
- 如果觉得"目标本身有问题"→ 本次复盘应包含决策类复盘议题

## 二、填写指南

### 进入标准
- 已完成十六字原则前两步（成败认定 + 场景还原），得失分析至少走到了第2层追问
- 核心参与人全部在场（或异步确认过信息）
- 提前收集的材料已汇总

### 退出标准
- **整体评价区**：至少包含整体大目标 + 1个分支目标的判定
- **亮点共识区**：至少2条亮点 + 对应成功因素
- **问题共识区**：至少2条问题 + 对应根因分析
- **坚持做/放弃做/新任务区**：至少各1条，且每条都有负责人+截止时间
- **过程资产区**：至少沉淀1项（哪怕只是一个checklist）

### 最小可行版本
时间紧时：**整体评价3分钟（只达大目标共识）+ 亮点/问题各1条（5分钟）+ 行动三件事（2分钟）+ 1项过程资产（填表留坑，会后补充）。**10分钟产出最小画布，其余待异步补充。

### 画布在复盘会中的使用节奏

```
成败认定 → 填"整体评价"区
场景还原 → 不填画布，只在白板/文档中罗列事实
得失分析 → 填"亮点共识"和"问题共识"区（深挖到假设层）
总结提炼 → 填"坚持做/放弃做/新任务" + "过程资产" → 签字
```

## 三、Before/After：没画布 vs 有画布

来自口述课 L2650-L2672。

**Before（没画布时复盘的产出）**：
> 工作总结式的几句话——"本次项目整体完成得不错，大家辛苦了。有些细节下次注意。"

**After（用画布后的产出）**：
> 一页纸清晰呈现——
> - 整体判断：符合预期（大目标完成，但时间延迟2天）
> - 亮点：会员领取率93%，归因→老会员召回+限时促销+直播推流
> - 问题：排版审核缺失→建立三审流程+审核checklist
> - 坚持做：提前预留审校时间；继续买A品牌物料
> - 放弃做：印刷前不审核就发稿
> - 新任务：建立品控清单；梳理客户画像
> - 过程资产：手册排版规范v1.0、供应商联系清单、印刷流程SOP

> 当别的团队在随随便便写两句的时候，你的团队用画布把认知结构化地沉淀下来——差距就是这样一天一天拉开的。

## 四、失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 画布空着开复盘会 | 复盘会开完才想起来"要填画布"，结果信息全忘了 | 画布投屏——复盘会上边讨论边填，它是你的"战场地图" |
| 格子填"待定" | 整体评价、亮点、问题全是空 | 成败认定必须当场完成，至少填1条亮点+1条问题，其余可会后补 |
| 得失分析停在第一层 | 亮点写"我们做得好因为团队努力"，问题写"下次细心点" | 用十大追问清单至少追到第三层——"努力"不是根因，"细心"不是方案 |
| 行动计划无负责人 | 坚持做/放弃做/新任务全填了但没人认领 | 每行必须指定1个负责人+截止时间，当场确认 |
| 过程资产无人管 | "回头整理个SOP"→ 再也没整理 | 当场指定资产整理人+24小时内发出→存入知识库 |
| 签了字再也没看过 | 画布填完存到文件夹吃灰 | 打印贴工位/发飞书群→下周周会第一项review行动计划 |
| 画布写得完美但行动为零 | 画布是画布，执行是执行——认知和行动两层皮 | 行动计划进周会checklist、过程资产进新项目启动模板 |
