# 复盘浪费九宗罪自检清单：3×3完整诊断

> 一句话：90%的复盘失败不是因为"没做"，是因为"做了但犯了这些罪"——意识层不动、姿势层不对、深度层不够。

---

## 3×3 完整清单

### 第一层：意识（根本不想/不会/不要）

| 罪 | 症状 | 典型场景 | 修复 |
|:---|:---|:---|:---|
| **不做** | 根本不复盘——做完事直接冲下一个 | "太忙了没时间" | 三分钟复盘——极低门槛启动 |
| **不信** | 做了复盘但内心不信有用——应付 | "领导要求的" | 先用一个小成功建立正反馈——复盘一次让你少踩一个坑 |
| **不求** | 复盘了但没有面向未来的产出——有回顾无行动 | "我们总结了很多但下次还是老样子" | 强制：每次复盘最后5分钟写"下一次具体做什么不同" |

### 第二层：姿势（做了但方向/方法错了）

| 罪 | 症状 | 典型场景 | 修复 |
|:---|:---|:---|:---|
| **不真** | 复盘变成甩锅/背锅——不是在找原因，是在找责任人 | "这次主要是XX部门的责任" | 规则：复盘会前5分钟宣布"今天的目标是找到系统原因，不是找到谁该骂" |
| **不实** | 只有主观感受，没有事实和数据 | "我觉得这次做挺好的" | 强制：每个观点必须有对应的事实证据——"你说的'好'，具体是哪个数据好？" |
| **不懂** | 停在表面分析——"这次失败了因为不够努力" | "下次加油" | 追问"为什么"至少3层——"为什么不够努力？因为什么？那个原因的原因是什么？" |

### 第三层：深度（做了但不够深）

| 罪 | 症状 | 典型场景 | 修复 |
|:---|:---|:---|:---|
| **不透** | 找到了表面原因就停了——没有追问到底层 | "这次失败因为流量不够"→但为什么不投流量？ | 用冰山五层（`[[yt-model-deep-review-iceberg]]`）逐层下探直到能力/模型层 |
| **不全** | 只复盘了失败，没复盘成功——或者相反 | "这次失败了我们复盘一下"（成功了就不复盘） | 成功也要复盘——KSF分析（右上象限）和流程固化（右下象限）同样有价值 |
| **不改** | 有了认知但没有落地——复盘了等于没复盘 | "我们总结了很多洞察"→但下一次还是老样子 | 每次复盘产出至少1个具体改进行动 + 指定负责人 + 截止日期 |

## 自检触发词

当你复盘时听到以下关键词，立刻查对应条目：

| 触发词 | 对应宗罪 |
|:---|:---|
| "太忙" / "没时间" | 不做 |
| "领导要求的" | 不信 |
| "下次注意"（但没说具体做什么） | 不求 |
| "主要是XX的问题" | 不真 |
| "我觉得"（无数据支撑） | 不实 |
| "不够努力" / "能力不行"（归因太浅） | 不懂 |
| "流量不够"（停在表面归因） | 不透 |
| "这次失败了复盘一下"（成功不复盘） | 不全 |
| "总结了很多洞察"（但没有行动计划） | 不改 |

## 使用方式

**复盘前**：快速扫一遍——这次复盘最容易犯哪1-2宗罪？提前预防
**复盘后**：逐条对照——这次复盘犯了哪几宗罪？下次怎么避免

## 适用边界

| 场景 | 适用？ | 说明 |
|:---|:---|:---|
| 个人日常复盘 | ✅ | 快速自检——1分钟扫完 |
| 团队复盘会 | ✅ | 会前/会后对照——特别关注"不真"（甩锅）和"不实"（无数据） |
| 纯执行问题复盘 | ⚠️ | "不透"这宗罪可能不适用——执行问题有时不需要追到冰山第5层 |
| 首次复盘的团队 | ⚠️ | 不要上来就扔九宗罪——先建立复盘习惯，再用清单精进 |

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 把九宗罪当甩锅工具 | "你看，你这次犯了'不做'——你根本不重视复盘" | 九宗罪是自检清单，不是攻击清单——先自检，再帮别人 |
| 每次都能找出9条 | 说明清单太泛——失去了聚焦价值 | 每次只找最匹配的1-2条——找到最致命的那个 |
| 复盘前不看，复完盘才看 | 预防效果丢失——"早知道会犯这宗罪" | 复盘前花1分钟扫一遍——提前预防
