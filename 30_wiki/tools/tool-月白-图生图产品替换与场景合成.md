# 技能：图生图产品替换与场景合成

## 原始表述

图生图产品替换与场景合成是月白在文创案例中提出的实操方法。

## 操作步骤

1. 准备素材1：场景底图（如办公桌场景）
2. 准备素材2：产品白底图（如Leo小人）
3. 准备素材3：辅助元素白底图（如里程碑、手持喇叭）
4. 编写替换提示词：'将图片二中的XX放进图片一的XX位置，将图片三的XX放进XX位置，添加XX文案'
5. 使用图生图方式生成
6. 注意：此阶段不适合文生图，因已有明确元素需替换
