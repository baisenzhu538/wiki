# 四种力量建模

> 用户不换产品不是因为你的产品不够好，是因为(推力+拉力)还没超过(焦虑+习惯)。四种力量是JTBD中判断"用户会不会切换"的核心框架。

## 四力公式

```
切换动力 = (推力 + 拉力) - (焦虑 + 习惯)
  > 0 → 用户可能切换
  ≤ 0 → 用户不会切换，不管你的产品多好
```

| 力量 | 方向 | 核心问题 |
|:---|:---:|:---|
| **推力** | → 推出旧方案 | "旧方案有多让人崩溃？" |
| **拉力** | → 拉入新方案 | "新方案解决了什么旧方案解决不了的问题？" |
| **焦虑** | ← 阻止尝试新方案 | "用户担心什么？数据安全？学习成本？" |
| **习惯** | ← 阻止离开旧方案 | "旧习惯有多顽固？用到什么程度了？" |

## Agent执行指令

```python
prompt = """对「{PRODUCT_IDEA}」做四种力量建模：

推力（Push——旧方案的痛苦）：
- src_unknown

拉力（Pull——新方案的吸引力）：
- src_unknown

焦虑（Anxiety——对新方案的担忧）：
- src_unknown

习惯（Habit——旧习惯的惯性）：
- src_unknown

判断公式：（推力+拉力）是否 >（焦虑+习惯）？
如果答案为否：需要增强什么？哪边的力量最容易改变？
"""
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 只列推力拉力 | 焦虑和习惯空着 | 强制每项至少3条 |
| 力量太弱 | "用户可能觉得有点不方便" | 找"崩溃级"的痛苦——用户为此骂过人的 |

## 质疑

- **具体假设**：该工具假设"切换动力 = (推力+拉力) - (焦虑+习惯)"的线性加法模型能预测用户行为，但人类决策不是力的简单加减——焦虑和习惯之间存在"非对称放大"效应：一个小的焦虑（如"数据可能不安全"）可以完全抵消一个大的拉力（如"省 50% 成本"）。加法模型无法捕捉这种非对称性。
- **边界**：在冲动消费场景中，"切换动力"的公式完全不适用——冲动消费不是"推力+拉力>焦虑+习惯"的理性计算，而是情绪触发的即时行为。
- **反例**：用户明知道旧方案很痛苦（推力高）、新方案更好（拉力高）、焦虑可控、习惯可改——但就是不换。四种力量模型无法解释"知道该换但不换"的"意向-行为鸿沟"。

**Byron Sharp**（南澳大利亚大学营销科学教授，《How Brands Grow》作者）会质疑：四种力量模型隐含"用户是理性权衡者"的假设，但他的研究表明，大多数购买行为不是"权衡后选择"，而是"习惯性重复"。用户不换产品不是因为"焦虑+习惯>推力+拉力"，而是因为"根本没想过要换"——竞争产品的"心理可得性"（mental availability）太低。真正的增长不来自"降低焦虑和习惯"，而来自"提高品牌在用户心智中的可得性"。
