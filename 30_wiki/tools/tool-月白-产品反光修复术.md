# 技能：产品反光修复术

## 原始表述

产品反光修复术是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 生成基础场景图后检查材质反光
2. 发现不锈钢/玻璃反光不正确时
3. 使用指令：'给产品中的[材质]添加符合场景反光'
4. 重新生成验证反光一致性
