> **定位**：属于 [[concept-collaboration-philosophy-foundation]] 的工具卡。理论锚点——金句3"政治的根本出路在于改善博弈条件"（7.7）+ 金句5"可信即可行"（5.4）+ 金句6"马基雅维利策略经不起普遍模仿"（6.3）。别试图改变人，改变他们面对的收益结构。

### 推导链

```
【底层】坏世界假设 → 制度悖论（人会学习利用侵蚀制度）
  → 需要博弈条件改善（金句3：别改人，改收益结构）
  → 需要可信性（金句5：可信即可行）+ 普遍模仿检验（金句6：坏策略经不起模仿）
      ↓ 压缩为操作
【中层】五问 = 行为导向（金句3·激励）+ 坏人测试（金句6·普遍模仿）
            + 信任趋势（金句5·可信性）+ 自我修正（制度悖论）+ 可移植（法律面向未来）
      ↓ 解压为场景+反例
【上层】一人公司双场景（写手/技术）+ 反例库 + 红牌信号
```

**自洽检验**：五问的每一步能否从底层原则直接推导？行为导向问 ← 激励让好行为占优（5.3）、坏人测试 ← 普遍模仿（金句6）、信任趋势问 ← 可信即可行（金句5）、自我修正问 ← 制度悖论（人会学习漏洞）、可移植问 ← 法律面向未来（口述 L206-214）。

## 操作步骤

### 第一步：写下规则（30秒）

写下一项你正在设计/评估的制度或规则。只写客观内容。

> 例："合伙利润平分——不论各自投入多少，年底净利润五五分成"

### 第二步：五问自检

| # | 问 | 判断标准 | 设计意图 |
|:--|:--|:--|:--|
| **行为导向问** | 这条规则在奖励什么行为？ | 对比"你想要的行为"和"规则实际奖励的行为"是否一致 | 金句3：激励不是奖励好人，是让好行为成为优势策略（逐字稿 5.3） |
| **坏人测试** | 如果所有人都是"理性自利"的人（不算计别人但也不吃亏），这条规则还成立吗？ | 如果规则被钻了空子而你只能说"不应该这样"→规则有漏洞 | 金句6：马基雅维利策略经不起普遍模仿——制度应假设所有人都会学坏策略 |
| **信任趋势问** | 按这条规则运行6个月后，合作双方的信任会增加还是减少？ | 如果规则依赖于双方始终善意→信任趋势向下；如果规则本身迫使双方合作→信任趋势向上 | 金句5：可信即可行——制度自己产生信任，不依赖人的善意 |
| **自我修正问** | 如果规则出了问题，有没有内建的修正机制？还是只能等人发现？ | 好的制度自己有反馈信号（如定期复盘/指标自动报警/退出触发重新谈判） | 制度悖论——人会学习利用制度，制度需要自我更新能力 |
| **可移植问** | 如果换一个人（换一个合作方），这条规则还适用吗？ | 规则不应依赖特定人的性格/关系——换人就失效=规则本身有问题 | 口述 L206-214：法律面向未来——制度不是为当前这些人，是塑造未来所有人的行为 |

### 第三步：红牌信号

≥2 问负面 → 规则需要重新设计。

| 问 | 🔴 负面信号 |
|:--|:--|
| 行为导向 | 规则奖励短视/搭便车/偷懒/信息垄断 |
| 坏人测试 | 存在明显漏洞且只能靠道德约束填补 |
| 信任趋势 | 规则使人倾向不透明/不主动/留一手 |
| 自我修正 | 出问题时除了"人发现"没有自动信号 |
| 可移植 | 换个合作方就完全跑不通 |

## 反例库

| 反例规则 | 看似合理 | 实际效果 | 根因 |
|:--|:--|:--|:--|
| 按项目总价计费 | 简单、可预算 | 外包砍需求减质量——交付的是最低成本版本 | 行为导向：奖励偷工减料 |
| 利润平分 | 公平、简单 | 不干活的人搭便车——干多干少一样 | 坏人测试：假设所有人都不会偷懒 |
| 验收合格后付款 | 保护自己权益 | 双方互相不信任——你不付钱我不交付→死锁 | 信任趋势：规则制造了不信任的囚徒困境 |

## 一人公司场景示例

### 场景1：内容写手

| 阶段 | 内容 |
|:--|:--|
| **原规则** | 按篇计费/每篇固定价格 |
| **五问诊断** | 行为导向→奖励凑数量不凑质量；坏人测试→写手会用AI批量生成 |
| **修正** | 基础月费（保底）+ 爆款奖金（阅读量/转化率挂钩） |

### 场景2：兼职技术

| 阶段 | 内容 |
|:--|:--|
| **原规则** | 纯分利润/无基础薪资 |
| **五问诊断** | 信任趋势→赚不到钱就不急了→进度越来越慢；可移植→换个更急的项目就跑了 |
| **修正** | 基础时薪（保障）+ 里程碑股权（长期绑定） |

## 失败模式

| 失败模式 | 信号 | 修复 |
|:--|:--|:--|
| **只测好人场景** | 规则在理想情况下完美，一遇到"坏人"就崩溃 | 强制跑坏人测试——如果所有人都学最坏策略，规则还能成立吗？ |
| **忽略补偿原则** | 因为某人"好说话"就一直让他吃亏→规则实际在惩罚合作者 | 每季度统计一次：谁承担了最多隐性成本？规则是否在奖励"不计较"的人？ |
| **把制度当一次性设计** | 规则制定后不再修订→人学会了漏洞→规则逐渐失效 | 制度必须有内置的定期复审机制（季度/每轮合作结束） |
| **模仿大公司制度** | 照搬大公司管理制度→人数/资源/复杂度不匹配→制度反而增加成本 | 大公司制度解决的是大公司的问题——你的问题是"一人公司的协作"，不是"百人公司的管控" |

## When NOT to Use

| 场景 | 原因 | 替代 |
|:--|:--|:--|
| 单次交易/一次性项目 | 不需要考虑长期博弈效果 | 用地位互换测试即可 |
| 规则没有执行可行性（只是愿望/口号） | 本卡假设规则真实执行——空口号不需要博弈分析 | 先确认规则能否被执行 |
| 制度本身被法律强制（如税法） | 你无法单方面改变博弈条件 | 法律合规为底线，博弈分析用于合规范围内的设计空间 |

## Critique

### 内部局限

1. **五问不能穷尽所有博弈维度**——信息不对称、多轮博弈的声誉效应、第三方外部性等未覆盖。
2. **坏人测试假设「理性自利」——但真实世界的人有非理性行为（情绪、面子、报复即使对自己不利）**。纯理性模型可能低估了非理性破坏。
3. **可移植问与特定知识矛盾**——某些规则依赖特定行业的know-how，换个行业就失效是正常的，不一定是规则的问题。

### 外部攻击者

**Robert Axelrod（合作的进化）**：Axelrod 的囚徒困境锦标赛证明，最简单的「以牙还牙」（Tit-for-Tat）策略在长期博弈中最成功——不需要复杂的制度设计。Axelrod 式攻击：你的五问检查清单是在设计「好规则」，但最好的规则可能根本不需要设计——就是「你怎么对我，我就怎么对你」+ 长期未来。

## Action Triggers

| 触发条件 | 动作 |
|:--|:--|
| 新规则上线前 | 过五问——≥2问负面→重新设计 |
| 规则执行3个月后 | 复盘：当初的五问判断是否成立？有没有新的博弈行为出现？ |
| 合作方换人/规则扩展适用 | 可移植问：规则还能成立吗？ |
