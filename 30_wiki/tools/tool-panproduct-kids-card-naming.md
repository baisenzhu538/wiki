# 九张技能卡的K12命名体系：成人术语→儿童名翻译表

> 一句话：崔磊给每张成人方法论卡片起了一个孩子能记住的名字——换位读心不是噱头，是「用户视角」的儿童翻译。9张卡的命名遵循一个规律：动作意象 + 物品隐喻 = 孩子一听就能在脑子里看到画面的名字。

---

## 完整命名对照表

| # | 儿童名 | 一句话描述（给孩子） | 方法论实质 | 对应KDO成人卡 |
|:--|:---|:---|:---|:---|
| ① | **换位读心** | 一秒变成使用者，站在TA的角度想问题 | 用户视角 | `yt-panproduct-demand-user-perspective` |
| ② | **魔法沙盘** | 在脑子里演一遍：谁在什么情况下遇到了什么问题 | 场景推演 | `yt-panproduct-demand-scenario-walkthrough` |
| ③ | **寻宝之镐** | 挖出我们班最独特的东西 | 用户特点/群体特质提取 | `yt-panproduct-demand-user-segmentation` |
| ④ | **万象罗盘** | 先把所有人的想法收进来，再挑出全班都点头的那几个 | 先加法后减法 | `yt-product-kernel-add-subtract` |
| ⑤ | **收集秘籍** | 去收藏100个你觉得最棒的设计 | 最佳实践池建设 | `yt-panproduct-aesthetic-collection` |
| ⑥ | **鉴宝之眼** | 不只说"好看"，还能说清"好在哪" | 最佳实践建模/评分 | `yt-panproduct-aesthetic-modeling` |
| ⑦ | **最美设想** | 在脑子里先看到最完美的样子 | 美好作品想象 | `yt-panproduct-aesthetic-imagination` |
| ⑧ | **神兵宝库** | 多试几个AI工具，同一句话画出来不一样 | 多AI工具选择 | `tool-月白-AI模型选择策略` |
| ⑨ | **初心结界** | 每加一样就问"还是我们班吗"，不是就砍 | 内核与边界 | `concept-一堂-product-kernel` |

### 对照表使用方式

**给孩子用**：用左栏名字直接沟通——"今天我们学第一张技能卡：换位读心"。
**给家长/老师备课用**：对照右栏成人卡找原始方法论。
**给KDO搜索用**：成人卡的aliases应加上对应的儿童名。

## 命名规律

9张卡的名字不是随意起的，都遵循以下规律：

### 公式：动作意象（2-4字）+ 物品隐喻 = 可记忆的动作名

| 卡片 | 动作意象 | 物品隐喻 | 拆解 |
|:---|:---|:---|:---|
| 换位读心 | 换位 | 心 | 「换位置」+「读心里在想什么」 |
| 魔法沙盘 | 魔法 | 沙盘 | 「魔法」（想象）+「沙盘」（在脑子里推演） |
| 寻宝之镐 | 寻宝 | 镐 | 「找宝贝」+「镐头」（挖掘工具） |
| 万象罗盘 | 万象 | 罗盘 | 「一万种可能」+「指南针」（筛选方向） |
| 收集秘籍 | 收集 | 秘籍 | 「攒东西」+「武功秘籍」（高手的秘密） |
| 鉴宝之眼 | 鉴宝 | 眼 | 「鉴定宝贝」+「眼睛」（辨别力） |
| 最美设想 | 最美 | 设想 | 「最好的样子」+「在脑子里想」 |
| 神兵宝库 | 神兵 | 宝库 | 「厉害的兵器」+「武器库」（AI工具） |
| 初心结界 | 初心 | 结界 | 「最初的心」+「保护罩」（守住边界） |

**规律总结**：
- **动作意象**让名字「可执行」——孩子听到名字就知道要做什么
- **物品隐喻**让名字「可记忆」——具象物品比抽象概念好记100倍
- **4字结构**比长句好记——"换位读心"四字="用户视角"的心理学术语
- **避免直接音译/缩写**——"用户视角"→不是"用户卡"，而是"换位读心"

### 自检公式

如果你要给K12设计一张新技能卡的名字，用这个公式自检：
> 「[动作] [物品]」——孩子听到这个名字，能立刻在脑子里看到自己正在做这个动作吗？
> 如果不能 → 名字无效，回去重想。

## 命名方法论价值

**不是给成人卡贴个标签那么简单。**

这9个名字是一套**可复用的K12方法论命名体系**——以后任何一堂方法论（关键假设、科学决策、单元模型）要做K12降维时，都可以参考同一套命名规律：
- 找到方法论卡片的核心动作 → 用2-4字的动作意象表达
- 找到这个动作的隐喻物品 → 用孩子熟悉的物品命名
- 检查：孩子听到名字能想象自己正在做这个动作吗？

**与 `[[bridge-panproduct-kids-translation]]` 的关系**：桥接卡定义"翻译机制"，本卡是翻译机制的**命名层执行资产**。

## When to Use

| 场景 | 用哪部分 |
|:---|:---|
| 给孩子讲泛产品设计 | 用左栏儿童名 + 一句话描述 |
| 备课/设计K12课程 | 用完整对照表（左中右三栏） |
| 给KDO已有卡打标签 | 把儿童名加入对应成人卡的aliases |
| 设计新的K12学习方法论卡片 | 用命名规律公式 + 自检公式 |
| 帮助家长理解孩子在学什么 | 先给儿童名，再解释=成人XX方法论 |

---

## When NOT to Use

| 不当使用 | 后果 | 正确做法 |
|:---|:---|:---|
| 直接用儿童名替换成人卡title | 成人用户搜索不到/认知混乱 | 儿童名放aliases，成人title不变 |
| 给孩子同时展示两个名字 | 孩子困惑——"到底叫哪个" | 给孩子只用儿童名；给大人可以做对照 |
| 以为名字=全部方法论 | 只记名字忘掉方法 | 每个名字背后是一套完整方法论，见对应成人卡 |
| 把命名当成唯一降维手段 | 只改名字不改教法，孩子还是学不会 | 配合桥接卡的四件套（RPG比喻/金句/行动化/技能卡命名） |

---

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 命名太过文艺 | 孩子听到名字不知所云（如"星辰大海之钥"） | 回归公式：动作+物品。文艺感可以保留但不能压过功能性 |
| 命名和成人术语毫无关联 | 对照表无法建立映射，家长和老师不知道怎么解释 | 确保每一对"儿童名↔实质↔成人卡"有逻辑关系 |
| 所有卡片都套同一个公式 | 九张卡听起来差不多，孩子分不清 | 让动作意象足够差异化——"换位"和"寻宝"和"鉴宝"是三个不同动作 |
| 忘记更新成人卡的aliases | 儿童名在KDO搜索中找不到对应卡 | 每次新建/更新儿童名后同步补成人卡aliases |

---

## 操作步骤

1. **确认目标方法论卡片**——你要给哪张成人卡做K12翻译？
2. **提取核心动作**——这张卡的方法论里最大的一个动作是什么？
3. **找物品隐喻**——这个动作的隐喻物品是什么？（「寻宝→镐」「换位→心」）
4. **用自检公式验证**——孩子能想象自己正在做这个动作吗？
5. **写对照表**——儿童名 | 一句话描述 | 方法论实质 | 成人卡ID
6. **反写aliases**——把儿童名加入对应成人卡的aliases字段
