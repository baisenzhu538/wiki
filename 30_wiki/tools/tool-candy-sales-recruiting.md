# 销售招聘的客观验证方法：能力模型 + 定量定性结合

> 本卡属于「销售组织管理」体系：招聘销售不能用「你能吃苦吗」这类无法验证的问题，核心是**能力模型 + 客观验证方法**——面试官结论必须一致，用可观测行为验证候选人的宣称。
> ⚠️ **传播限制标注：本卡内容来自内部课程分享，仅限内部知识库使用，禁止外传。**

## 1. 核心洞察

绝大多数销售面试问的是「你行动快吗？你能吃苦吗？能出差吗？」（L940-944）——候选人讲个故事说自己能吃苦，毫无意义（L950）。「能吃苦」这类宣称无法验证：有人一年出差 360 天觉得正常，有人出差 30 天就觉得很多（L954-958）。**核心是要有一套客观的验证方法，把「是不是勤劳」验证出来（L960）。**

方法来自 Candy 文档（「百倍成交」招聘篇）：这套思想和理念花了十几万美金、折合人民币三百多万买回（L918-920），市场验证过的销售超过 30 万（L922）。

## 2. 操作步骤

### 2.1 建立能力模型（第一是核心，L926）

先列出能力模型（几项核心能力），再根据能力模型客观验证候选人是否满足（L962-964）：

1. 确定销售岗位的关键能力维度（如：目标感、抗压、沟通、学习力）
2. 每个能力维度定义**可观测的验证标准**（不是口头宣称）
3. 定量和定性尽量结合（L938）——定量考核 + 定性观察

### 2.2 星巴克式面试：面试官结论必须一致（L974-998）

- 三个面试官面同一个候选人
- 候选人走后，三个面试官各自写面试结果，**结论必须一致**（L978-980）
- 产生分歧 → 讨论**面试官自己的问题**，不讨论被面试者的问题（L992-998）：「是咱们的面试方法出问题了，还是咱们的衡量标准出问题了？」
- 对比中国式面试：你行我不行他行，三人坐下来讨论候选人（L982-984）——讨论的是候选人，不是面试方法

### 2.3 Cosmos 式客观验证：用行为验证宣称（L1000-1022）

- 候选人面试材料写「坚持运动/热爱健身」
- 面试官（四五十岁）带候选人从一楼跑 28 层楼
- 面试官跑到了，候选人没在视野范围内 → 第一层就不用来了（L1018-1020）
- 逻辑：「我才不管你平时讲什么坚持锻炼不坚持锻炼，你都是扯淡，都是骗人的」（L1020-1022）

用可观测的行为直接验证宣称，不给口头故事留空间。

## 3. 使用场景

- 销售岗位招聘面试（能力模型 + 客观验证）
- 团队扩编时批量筛选销售候选人
- 面试官团队培训（结论一致性机制）
- 任何「口头宣称无法验证」的招聘场景（如「抗压能力强」「学习能力强」）

## 4. When NOT to Use

1. **创意/研发岗位**——能力无法用行为跑楼式验证，需要作品集/技术评估等不同方法。
2. **高管岗位**——结论一致性机制适合执行层批量筛选，高管需价值观与战略判断。
3. **候选人数量极少时**——一套完整能力模型+多面试官机制的投入产出比不划算。
4. **法律合规敏感场景**——28 层跑楼式体力验证需评估合规风险，用等价的业务模拟（如模拟销售 call）替代。

## 5. 失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 口头宣称陷阱 | 面试问「你能吃苦吗」 | 换可观测行为验证（业务模拟/现场任务） |
| 面试官分歧 | 三人结论不一致但没人质疑方法 | 按星巴克规则：讨论面试官自己的问题 |
| 无能力模型 | 凭感觉打分、没有维度 | 先列能力模型再面试 |
| 结论不落盘 | 面试官口头交流不写结果 | 每人独立书面结论，再对一致性 |
| 只定性不定量 | 全是印象没有打分 | 定量考核+定性结合 |
| 外传泄密 | 内部方法流出 | 遵守传播限制标注，仅内部使用 |

## 6. Action Triggers

- 启动销售招聘 → 先建能力模型，再设计客观验证环节
- 面试官意见分歧 → 转向讨论面试方法/衡量标准，不讨论候选人
- 候选人宣称难以验证的特质 → 设计行为验证（如模拟销售场景）
- 批量扩编销售团队 → 用结论一致性机制保证标准统一
