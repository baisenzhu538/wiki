# 教练提问卡（8类）

> 定位：属于 `framework-coaching-leadership-core` 的教练沟通武器库第 2 组（提问组），承接倾听卡（听→问），服务于五阶梯 L2 共识层。与 `tool-一堂-kernel-three-questions`（内核三问验证法）的关系：不重叠——内核三问是产品/决策验证方法，本卡是对话中的提问策略。

## 一句话定义

提问是教练式沟通的核心手段：通过 8 类提问（关心/支持/思考/出口/ABCD/视角/重定义/乔哈里窗），在"不直接给答案"的前提下引导对方自己思考、看清问题、找到出口——最终激发对方的潜力去解决眼前的难题。

## 为什么重要

1. **提问是教练最熟悉的场景**（口述 02 L968）："授人以鱼不如授人以渔"（口述 01 L2496）
2. **激发潜力是核心目标**：领导力的本质是引导别人心甘情愿解决难题；提问指向解决问题，不跑偏（L1022-1032）
3. **避免被投喂状态**：一旦主观评判，下属就等指示不思考了（L1092-1098）
4. **提问三层理解**：解放思想（抓主要矛盾）→ 保持好奇（全然无知视角）→ 激发潜力（指向解决）（L984-1030）

## 核心机制：提问 8 类

### 第 1 类：关心式提问 ✅（VLM 已校对）

**核心**：建立信任是深度沟通的基础，避免单刀直入。

- 围绕"建立信任"展开，关心对方最近情绪或身体状态，是很好的开场
- "真诚的关心是建立信任的必杀器，有时候简单一句'你还好吗'可能让他记你一辈子的好"（口述 02 L1680-1688 关键性提问）

### 第 2 类：支持式提问

**核心**：最好的建立信任方式，是给予最直接的支持。

| 方式 | 话术示例 |
|:--|:--|
| 主动询问 | "你觉得要保证这个项目的推进，我可以给你提供哪些支持？" |
| 联结情感 | "没关系，这个事情确实不容易。你会如何度过这个坎？" |
| 给予支持 | "你尽管放手去做，我是你们的后盾。" |

### 第 3 类：引发思考

**核心**：提问最主要的目的之一是激发对方主动思考。

- 循序渐进：问事实之后，问背后的原因，问数据的本质，问结论的边界
- 口头禅式提问（口述 01 L2560-2570）："这事儿的逻辑是啥？""最重要的三个点是什么？""这事儿的难点和卡点是什么？""如果转化率想再提升一倍还能做啥？"
- **第一层理解·解放思想**：抓主要矛盾（唯物辩证法）——"如果明天所有投诉突然都消失了，你觉得同学真正满意的关键会是什么？"（L992-998）

### 第 4 类：明确出口

**核心**：挖掘对方分歧点背后真正的渴望，推动共识。

- 对方不同意你时，往往有非常在意的理由
- 抛出可行且简略的前提假设，可能快速对齐共识
- 关联出口式咨询（见 P1 增量卡 tool-leadership-exit-consulting）：找出口 → 换视角 → 探究解法

### 第 5 类：ABCD 提问

**核心**：用结构性提问框架系统性梳理业务。

| | |
|:---|:---|
| **A. 商业现实**：事实：发生了什么？ | **B. 关键决策**：影响：用户/团队/关键方怎么看？ |
| **C. 业务提升**：策略：业务构成如何变化？ | **D. 关键转化**：行动：下一步做什么？ |

### 第 6 类：切换视角

**核心**：借助对方从不同视角看待问题，跳出局限。

| 方法 | 话术示例 |
|:--|:--|
| 询问挑战者 | "在真实情况中，有没有什么人最可能挑战你这个方案？" |
| 检验他人视角 | "如果换作你的同事/上级/客户，他们会有什么看法？" |
| 检查反思 | 更具体："这其中什么让你感到意外？"；更整体："是什么结果影响到了这个场景？" |

### 第 7 类：重新定义

**核心**：有时候分歧和问题很难被解决，只能被重新定义。

| 方法 | 话术示例 |
|:--|:--|
| 从本质思考 | "在完成这件事的任务中，根本目的在于什么？" |
| 关联信息 | "假设不是在常规情况下，换一个方向，这会怎么样？" |
| 关联业务 | "如果让对手来做，Top3 的问题会是什么？" |

### 第 8 类：乔哈里窗

**核心**：找到信息盲区，发现隐藏问题，拓宽沟通深度与协作空间。

- 很多时候不能达成共识不是方法问题，而是认知问题
- 探索对方认知边界是达成共识的关键步骤

## 关键技巧：三层理解 + 事实/观点区分

### 提问三层理解（口述 02 L984-1030）

1. **解放思想，理解本质**：一切问题有一个主要矛盾，抓主要矛盾（L988-992）
2. **有好奇心是基础要求**：忘记自己是领导，带入全然无知的局外人视角；避免主观引导；通过追问给予表达空间（L1010-1018）
3. **激发潜力是核心目标**：提问指向眼前的难题和解决方案，不聊八卦（L1022-1032）

### 事实 vs 观点（L1050-1076）

- **事实**：客观存在可验证的现象/事件（如"城市人口超 80 亿"）
- **观点**：个人对事实的主观看法/感受/价值判断（如"有人不吃香菜"）
- 基于事实的客观反馈才有效；从观点出发的反馈易碰撞偏离主题

### 不做评判不给建议（L1090-1098）

- 对方讲完后尽量不做评判——一旦主观评判，下属进入被投喂状态，不动脑子等指示
- "眼看下属的思路已经到半空了，结果领导一开口，啪一片沉默又没了"

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 对方卡住问"还有吗"无效 | 穷举式追问在卡点时无用 | 理清节点、扫除障碍（L1040-1044） |
| 紧急决策 | 提问时间成本高 | 快速收集事实 + 拍板 |
| 纯执行任务 | 无需激发思考 | 直接指令 |
| 对方无基本公理共识 | 提问无地基 | 先对齐前提 |
| 对方已明确要答案 | 教练式引导 ≠ 拒绝给信息 | 透明切换：给答案 + 讲逻辑 |

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 跑偏 | 聊生活聊兴趣，忘了难题 | 用核心目标拉回："回到眼前的难题" |
| 急于给建议 | 对方一说就接话 | 克制表达欲（倾听卡），"先听三分钟" |
| 穷举式追问 | "还有吗"连问 5 次 | 换卡点处理：理清节点、扫除障碍 |
| 主观评判 | 一开口就评判 | 区分事实/观点，只说事实 |
| 无好奇心 | 带着预设提问 | 带入全然无知的局外人视角 |

## 行动 Checklist

- [ ] 提问前：明确核心目标（激发潜力解决眼前难题）
- [ ] 开场：关心式提问（"你还好吗"）
- [ ] 过程中：区分事实/观点，只问事实
- [ ] 对方说完：停顿 2-3 秒，不做评判
- [ ] 讨论僵持：切换视角或重新定义
- [ ] 对话结束：确认是否有出口（下一步行动）

## Critique

### 攻击者 1：认知心理学——"8 类提问清单可能造成认知负荷"

**攻击论点**：8 类提问 + 每类多种话术，学习者在真实对话中无法快速选型，认知负荷过高导致"一个都用不上"。

**回应**：清单是武器库——不需要全用，每类都是独立可用的卡。口述也强调"先听后问"的衔接（倾听卡）。承认：卡内应补"最少可用组合"：新手先掌握 关心→思考→出口 三类即可。

### 攻击者 2：实用主义管理——"全程提问不做评判，效率太低"

**攻击论点**：教练式提问在快节奏团队中显得迂回，下属可能觉得领导"绕圈子不解决问题"。

**回应**：口述 01 已给边界——"在希望不给答案的前提下"（L484-486）+ 紧急时刻拍板（L1636）。提问不是唯一手段，是武器库之一。承认：卡内应补"何时教练、何时指令"的透明切换原则。

### 攻击者 3：ICF 视角——"提问与倾听/反馈的衔接未明确"

**攻击论点**：ICF 八项核心能力中提问（能力 7）与倾听（能力 6）、直接沟通（能力 8）是连续体，本卡孤立讲提问，可能造成"只会问不会收"。

**回应**：武器库三组卡（倾听/提问/反馈）本就是连续体——口述 02 L1182-1186 明言"先做了倾听，然后来做提问，提问之后的反馈"。承认：卡内应补衔接说明（听→问→馈的微笑沟通曲线）。

## Synthesis

- **不要用的场景**：卡点时穷举追问；紧急决策；对方要答案时绕圈子；无共识前提
- **关联表**：
  - `[[tool-leadership-listening-cards]]`：听→问衔接（3F 意图层追问）
  - `[[tool-leadership-feedback-cards]]`：问→馈衔接（事实/观点区分）
  - `[[framework-yitang-y-model-cross-domain-fusion]]`：提问是 Y 模型共识的手段
  - `[[tool-一堂-kernel-three-questions]]`：内核三问（决策验证）
  - `[[framework-how-to-know-a-person]]`：认识他人的提问工具
- **Action Triggers**：
  - 对方求助但思路不清 → 引发思考（抓主要矛盾）
  - 讨论僵持 → 切换视角/重新定义
  - 对方有分歧 → 明确出口（找背后的渴望）
  - 需要系统性梳理 → ABCD 提问
  - 发现认知盲区 → 乔哈里窗

## 可迁移场景

1. **一对一辅导**：关心→思考→出口 最小组合
2. **业务复盘**：ABCD 提问系统性梳理
3. **产品讨论**：切换视角（挑战者/他人视角）发现盲点
4. **客户需求挖掘**：乔哈里窗探索认知边界
5. **Agent 需求理解**：用提问澄清用户真实意图，避免误解需求
