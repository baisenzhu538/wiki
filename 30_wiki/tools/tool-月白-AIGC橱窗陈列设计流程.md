# 技能：AIGC橱窗陈列设计流程

## 原始表述

AIGC橱窗陈列设计流程是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 确定橱窗主题与目标（吸引路过客流/突出卖点/引导动线）
2. 用AIGC 3分钟生成10套同主题不同风格方案
3. 让门店店长/策划方/甲方从方案中选风格
4. 风格确定后再精细调整陈列细节、模特穿搭、价格标签
5. 输出最终效果图指导执行
