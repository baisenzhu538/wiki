# 技能：判断标准快速产出法

## 原始表述

判断标准快速产出法是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 明确需要判断的维度（如品牌调性、AI可行性等）
2. 将判断标准书面化（自己写约10分钟，或用Cubox辅助3-5分钟）
3. 将标准交给AI工具执行（如品牌手册生成、图片生成等）
4. 验证标准有效性：按标准执行后检查结果是否符合预期
5. 迭代优化标准直至结果绝对可控
