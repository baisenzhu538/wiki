# 百度指数

> 百度指数——最老牌的需求趋势工具。搜索量=用户对这个东西的"主动兴趣"。

百度指数以关键词搜索量为核心，帮助研究者判断公众对某话题、产品或品牌的主动关注程度。它的价值在于把"用户主动搜索"这一行为转化为可量化、可比较的时间序列数据，常用于趋势判断、竞品对比、需求验证和市场进入时机评估。

## Purpose

- 识别某个关键词在特定时间段内的搜索热度变化。
- 对比多个关键词或品牌的相对关注度，判断竞争格局。
- 验证产品概念或市场假设：如果目标用户连搜索都不愿意，需求真实性存疑。
- 发现季节性、事件驱动型或周期性的需求波动。

## Protocol

1. **明确研究问题**：把业务问题转化为可搜索的关键词，例如"儿童护眼台灯"而非抽象的"护眼市场"。
2. **选择关键词组合**：包含核心词、竞品词、场景词和上下游词，避免单一词的幸存者偏差。
3. **设定时间与地域**：选择与研究目标匹配的时间窗口（如近90天、近一年）和省份/城市维度。
4. **交叉对比**：将百度指数与微信指数、小红书搜索趋势、抖音热点并置，检查结论是否一致。
5. **导出与归档**：保存趋势图、人群画像和来源词数据，记录分析假设和限制条件。

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|---|---|---|
| 评估短视频/直播驱动的冲动消费品类 | 百度搜索主要反映主动搜索，难以捕捉算法推荐触发的兴趣 | 抖音热点、小红书搜索、巨量算数 |
| 分析Z世代或00后的兴趣变化 | 移动搜索份额下降，年轻用户更多使用垂直App内搜索 | 微信指数、B站指数、小红书趋势 |
| 判断绝对市场规模 | 搜索量是相对热度，不等于实际购买量或用户基数 | 行业报告、企业财报、问卷调研 |
| 需要精确因果推断 | 搜索上升可能是结果而非原因，存在反向因果和混淆变量 | A/B测试、田野实验、专家深访 |

## 质疑

百度指数的真正前提是什么？它的核心假设是"搜索热度=真实需求"，但这个等式存在明显边界：第一，具体假设上，它默认用户会用百度进行搜索，而微信、小红书、抖音的内置搜索正在分流；第二，边界上，百度指数只覆盖公开可搜索的关键词，长尾词、口语化表达和敏感词会被过滤或低估；第三，反例上，某些高搜索量来自媒体事件、负面舆情或竞品广告投放，并不反映正向需求；第四，前提上，百度指数的人群画像基于样本推断，可能与实际购买者存在系统性偏差。因此，把它当作唯一证据链是危险的。

**外部反对者**：**Michael Porter** 可能会指出，百度指数只能描述"现有竞争可见度"，却难以揭示产业结构、进入壁垒和议价能力，真正的战略分析需要五力模型与一手调研的结合，而非搜索曲线的简单外推。
