# 行业报告搜索七技：三级搜索能力+渠道清单

> **一句话**：Doris的方法——7天内通过行业报告建立完整行业认知。关键是三级搜索能力：关键词搜索→增加限制词→按图索骥。

---

## 三级搜索能力

### Level 1：关键词搜索（广撒网）

```
行业名 + 关键词组合
```

| 行业词（可替换） | + | 报告词（可替换） |
|:---|:---:|:---|
| 出境游 | | 报告 |
| 出境旅游 | | 趋势 |
| 出国旅游 | | 行业分析 |
| 海外旅游 | | 行业解读 |
| ... | | 规模/研究/白皮书 |

**规则**：看前3页，3页没有就换关键词。排列组合全试一遍。

### Level 2：增加限制词（精准定位）

| 限制词类型 | 示例 | 作用 |
|:---|:---|:---|
| `filetype:pdf` | `出境游 报告 filetype:pdf` | 只要PDF（报告通常是PDF） |
| `site:` | `site:mckinsey.com 消费` | 在特定网站内搜索 |
| `after:` | `出境游 after:2024` | 只要最近的 |
| `""` | `"出境游市场规模"` | 精确匹配 |
| `-` | `出境游 -攻略 -游记` | 排除无关结果 |

### Level 3：按图索骥（顺藤摸瓜）

1. 找到一份好的报告 → 看它的引用来源 → 找到更多报告
2. 搜索引擎的"相关推荐" → 点进去看
3. 报告作者/机构的其他报告 → 批量获取

## 六大报告来源渠道

| # | 来源类型 | 代表 | 特点 |
|:---:|:---|:---|:---|
| 1 | **咨询公司** | 麦肯锡/BCG/贝恩/德勤 | 宏观趋势，方法论强 |
| 2 | **券商投行** | 中金/中信/高盛研报 | 有具体公司分析 |
| 3 | **行业媒体** | 36氪/亿欧/猎云网 | 新锐视角，创业向 |
| 4 | **创投媒体** | IT桔子/鲸准/ CVSource | 融资数据，赛道热度 |
| 5 | **头部企业** | 阿里/腾讯/美团的行业报告 | 一手平台数据 |
| 6 | **官方/协会** | 国家统计局/工信部/行业协会 | 最权威的宏观数据 |
