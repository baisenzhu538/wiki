# 技能：光影灰度控制能力构建

## 原始表述

光影灰度控制能力构建是月白在文创案例中提出的实操方法。

## 操作步骤

1. 学习素描基础：结构、光影、明暗关系
2. 练习造型能力与灰度层次控制
3. 理解光源方向、体积感、空间层次
4. 将素描能力迁移到AI提示词的光影描述
5. 用专业术语精准控制画面（如侧逆光、伦勃朗光等）
6. 持续回归基本功训练
