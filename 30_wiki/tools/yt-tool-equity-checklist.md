# 股权设计检查清单

> 从 [[yt-management-business-formula]] 和 [[yt-entrepreneur-lean-validation]] 萃取的公司治理工具。不是“分股比例怎么切”的财务计算，而是一套在“绑定”前检查关系健康度的“婚前协议”——**80% 的创业团队分裂不是因为业务失败，而是因为股权没说清楚**。

## Summary

股权设计检查清单是一套面向联合创始人和核心团队的股权治理工具。核心主张：**股权设计的核心不是“分得公平”，而是“分得清晰”——清晰到即使团队分裂，侟创也能按顺序离婚**。本工具卡交付：5 大检查维度（分配原则、vesting 机制、决策权、退出机制、增次设计）→ 每维度的检查项 → “汞门”判断——如果这一项说不清楚，先不要签字。

---

## 进入标准（When to Use）

| 场景 | 信号 |
|------|------|
| 准备联合创业，需要确定初始股权比例 | 至少 2 个人准备全职投入，且各自有贡献 |
| 团队第一次融资前 | 投资人要求看股权结构，但发现没有书面协议 |
| 核心员工加入（给股权激励） | CTO/COO 级别人员入职，需要确定股权体量和条件 |
| 创始人团队出现矛盾 | “谁做得多/谁更重要”的争论开始出现 |
| 公司将进入新阶段（从创业到规模化） | 过去的“口头约定”不再适用 |

**不满足进入标准**：单人创业未进行融资（无需复杂股权结构）、“考虑联合创业”但仅限于“想法阶段”（还没有共同工作超过 3 个月）、“为了拿到投资”而临时拉人头上（先做事，再谈股权）。

---

## 操作步骤（Step-by-Step）

### Step 0：检查前准备（1-2 天）

**目的**：确保所有关键方在同一个情绪基准上进行对话——不是“谈判”，而是“设计”。

- [ ] 避免在“有压力的时刻”讨论股权（如融资前一周、有人提出离职时）
- [ ] 每个参与者先独立填写“我的贡献清单”（不是自我感觉，是具体事件和数据）
- [ ] 明确此次讨论的决策权：全体一致通过？2/3 多数决？还是“如果无法一致，谁有最终决定权？”

### Step 1：分配原则检查（2 小时）

**核心问题**：我们到底在分什么？

**检查项**：

1. **贡献清单是否具体**：不是“我负责产品”，而是“我从 0 到 1 搭建了 XX 系统，支撑了 X 万用户”
2. **分配时间窗口是否明确**：初始股权是基于“创业前的贡献”还是“未来 4 年的预期贡献”？（建议：初始股权只反映已发生的，未来的用 vesting 解决）
3. **“全职 vs 兼职”是否区分**：如果有兼职创始人，股权是否与时间投入挂钩
4. **“钱 vs 人”是否区分**：投资人（钱）和创始人（人）的权益是否用不同机制保护（如投资人常见的“清算优先级” vs 创始人的“控制权”）
5. **是否预留“第三人空间”**：未来核心人员的股权池是否预留（建议 10-15%），还是“分完了才发现没剩多少”

**“汞门”判断**：如果谁的“贡献”说不清楚——“我主要负责——”停顿超过 3 秒——这个人的股权应该与 vesting 完全挂钩（即“证明了再给”）。

### Step 2：Vesting 机制检查（2 小时）

**核心问题**：如果有人离开，股权怎么办？

**检查项**：

1. **Vesting 周期是否合理**：创业公司建议 4 年 vesting + 1 年 cliff（即第一年离职零股权）。不是“对人不信任”，是“对未来不确定”的保护。
2. **加速 vesting 条件是否明确**：如果超额完成 KPI，能否提前解锁？条件是什么？（防止“你说我说”）
3. **离职后的股权处理是否清晰**：
   - “好聚好散”情况：已解锁部分保留，未解锁部分公司回购，回购价格怎么定
   - “不欢而散”情况：是否有“股权冷冻”机制（如触发竞业禁止条款、便宣日有限责任条款）
4. **死亡/失能情况是否有预案**：创始人意外时，股权如何处置？不是迷信——这是保护公司继续运营的结构性安排。

**“汞门”判断**：如果离职后的股权处理没有书面约定——先不要签字。“我们都是兄弟，不会那么糟糕”是最危险的假设。

### Step 3：决策权检查（1 小时）

**核心问题**：谁有最终决策权？什么事需要一致通过？

**检查项**：

1. **日常运营决策**：CEO 是否有最终决策权？还是所有大事都要会议决定？（建议：CEO 有日常运营决策权，重大事项需要核心团队协商）
2. **重大事项清单**：哪些事需要“一致通过”（如融资、收购、上市、解散公司）？哪些事 CEO 可以独立决定？
3. **“一票否决权”是否存在**：是否有某个创始人可以单方面否决某类决策？这是“保护”还是“缸席”？
4. **“死锁解决机制”是否存在**：如果核心团队对某个重大决策不能一致，有没有“破局”机制？（如第三方仲裁、时间限制后 CEO 决断）

**“汞门”判断**：如果"谁能解雇 CEO”这件事没说清楚——先不要签字。

### Step 4：增次设计检查（1 小时）

**核心问题**：如果有新人加入或融资，股权怎么动？

**检查项**：

1. **新轮融资的股权稀释方案**：是“同比例稀释”（所有人同比例减少）还是“某些人先稀释”？（建议：标准的投资条款下所有人同比例稀释，但创始人可以用“反稀释”条款保护）
2. **新核心员工的股权来源**：是从“预留池”出，还是“原有股东让出来”？如果是后者，让出方是否自愿？有没有补偿机制？
3. **股权激励的“再洁议”机制**：如果某人的贡献远超预期，是否有“加授”机制？条件是什么？
4. **“触发点”是否明确**：融资、新人加入、年度评估，哪些是“自动触发股权调整”的节点？

**“汞门”判断**：如果"下一轮融资后我的股权会变成多少”这个问题回答不出来——先不要签字。

### Step 5：书面化与存档（1 小时）

**目的**：把“口头共识”变成“法律文件”。

- [ ] 所有关键条款写入股东协议（Shareholders Agreement）
- [ ] 每个人签字前有 48 小时独立审阅期（提供给每个人的律师）
- [ ] 将“当前版本”存档到公司共享盘，标注日期和版本号
- [ ] 设定“每年审查一次”的日历提醒

## 退出标准（When to Stop）

| 信号 | 行动 |
|------|------|
| 公司已经有现成的股东协议，且律师审过 | 不需要重新设计，只需要“增次时是否符合原则”检查 |
| 团队已经分裂，正在谈离职 | 从“设计模式”切换到“卸载模式”——重点变为“怎么分”而非“怎么设计” |
| 团队 <3 人，且所有人完全信任 | 用“简化版清单”（只保留 vesting + 离职回购）即可 |
| 已有专业律师/财务顾问全程参与 | 工具卡作为“自检清单”，不是“法律文件”——最终以律师意见为准 |
| 投资人已经强制要求某些条款 | 不要硬挫——投资人的条款有时是行业标准，先理解原因再谈 |

## Constraints & Boundaries

1. **不是法律建议**：本工具卡是“检查清单”，不是“法律文件”。所有关键条款必须经过合规律师审核，尤其是涉及外资结构的股权设计。
2. **不能解决“信任问题”**：如果团队之间已经没有基本信任，股权协议只是在“用法律条款修补破损的关系”。先修复关系，再修复股权。
3. **对“家族企业”适配性极低**：如果创始人之间有夫妻、亲属关系，股权设计的复杂度呈指数级增长——需要专门的家族企业治理顾问。
4. **“汞门”判断不是“拒绝签字”**：如果某项说不清楚，应该“先谈清楚再签”，而非“因为有问题所以不签”。反复犹豫也是一种信号——关系可能不够成熟。
5. **不能解决“股权与业务表现脱钩”**：股权是“初始分配”，不是“持续奖励”。如果某个股东后续贡献显著下降，股权本身不会自动调整——需要其他治理机制（如董事会换届、解雇机制）。

## Critique

### Coase：交易成本——股权不一定是最优解

Ronald Coase 在《企业的性质》中提出了一个反直觉的问题：**企业为什么存在？**答案是：因为使用市场机制（买卖、合约）有交易成本——搜寻、谈判、签约、监督都要花钱。当内部组织的成本低于市场交易的成本时，企业就是有效率的。

**攻击点**：80股权设计检查清单假设“设计好股权结构，企业就能顺利运作”。但 Coase 会问：**为什么一定要用股权这种治理结构？**在某些情况下，市场协作可能更便宜：比如某个股东的贡献可以用“项目制合同+分成”来实现，而非“给股权”。股权是一种“长期绑定”，它的代价是“退出成本极高”——如果关系变坏，准备“离婚”的成本远高于“分手”的成本。更危险的是，股权设计可能让“本来可以市场化的协作”变成“必须内部化的纠缠”。例如，为了保持“创始人团队完整”而给不适合的人股权，反而增加了企业的内部治理成本。

**紧迫感**：如果你正在“给股权”来绑定合伙人，Coase 会问你——你是因为“这是最好的治理结构”还是因为“这是创业圈的默认做法”？如果是后者，你可能在用一种“退出成本很高的长期契约”来解决“本可以用短期市场协作解决”的问题。而且，当关系变坏时，你发现退出比留下更贵。

### Williamson：资产专用性——股权是治理结构选择，不是默认答案

Oliver Williamson （Coase 之后的交易成本经济学集大成者）提出：不同的治理结构适合不同的交易特征。其中一个关键变量是**资产专用性**（asset specificity）——如果某个合作伙伴的投入是“专用于这个关系的”（如知识产权、专有技术、特殊客户关系），那么“股权”比“合同”更安全；如果投入是“通用的”，合同可能更灵活。

**攻击点**：股权设计检查清单假设“股权是创业团队的标准治理结构”。但 Williamson 会说：股权的选择应该取决于**各方贡献的资产专用性程度**。如果某个创始人的核心贡献是“可移植的行业经验”（可以带到下一家公司），那么给他股权可能不如给“高佣金+短期合约”；如果某个人的贡献是“专有的知识产权”（离开就无价值），股权才是合适的绑定方式。更可怕的是，创业团队往往**给每个人都给股权**，而不是根据“交易特征”选择合适的治理结构。结果是：一些本该用合同解决的关系被股权“锁死”，退出成本极高；一些本该用股权保护的专用性投入，反而用低佣金合同处理，导致核心人才被挖走。

**紧迫感**：如果你正在“均分股权”，Williamson 会问你——你给每个人的是同一种“治理结构”，但每个人对企业的投入是不同“交易类型”。你可能在用一把锤子砸所有钉子——有些钉子需要锯子，有些需要螺丝刀，有些根本不需要被钉住。

## Action Triggers

| 触发条件 | 立即行动 | 预期产出 |
|---------|---------|---------|
| 确定联合创业，劳动合同即将签署 | 在签约前 1 周完成全清单检查 | 初始股权方案草稿 |
| 第一次融资前（投资人尽调前） | 检查现有股权结构是否经得起投资人审查 | 法律审查后的股东协议 |
| 新核心员工入职（CTO/COO 级） | 确定股权池来源和 vesting 条款 | 股权激励方案 |
| 创始团队出现“谁做得多”争议 | 用“贡献清单”客观化讨论，而非情绪化争执 | 更新的股权分配方案 |
| 有股东提出离职 | 启动“退出模式”，按协议执行回购/冷冻 | 离职股权处置方案 |
| 每年年度评估时 | 检查“当前股权结构 vs 实际贡献”是否匹配 | 增次/调整建议 |
| 投资人要求“清算优先级”时 | 检查这个条款对创始人控制权的影响 | 法律评估报告 |

---

> **自检**：如果你读完这张卡，第一反应是“这个清单很全面，我跟合伙人一起填一下”——先停一下。Coase 会问：你们的关系真的需要用股权来绑定吗？Williamson 会问：你给每个人的是同一种治理结构，但他们的交易类型一样吗？如果答案不确定，你可能在用一份“退出成本极高的长期契约”来解决“本可以用短期市场协作解决”的问题。股权是治理工具，不是信任替代品。
