# 决策深度L3：定量公式

## 一句话定义

L3是把关键假设**写成公式**——收入 = 客单价 × 转化率 × 流量，成本 = 固定成本 + 可变成本 × 数量。每个参数标注来源和置信度 [conf=0.80, source=一堂方法论]。

## L2→L3 升级

L2说"大概赚50万"，L3说"客单价200×客户数2500×毛利率60%−固定成本30万−可变成本20万=50万"。
公式化的价值：**暴露假设链中的薄弱环节**——哪个参数最不确定，一目了然。

## 操作步骤

1. 写出收入公式（拆到最细的参数）
2. 写出成本公式（固定+可变）
3. 对每个参数：标注来源、置信度、波动范围
4. 跑敏感性分析：改动最大不确定参数±20%，结论变不变？

## 边界

L3的公式比L2精确，但参数本身可能不准。如果关键参数置信度 < 0.7，L3≈精心包装的L2。
