# 决策深度L3：定量公式

## 一句话定义

L3用**明确的公式和具体数字**计算收益/成本，但数字来源可以是估算或行业均值——不需要严格溯源 [conf=0.82, source=原图]。

## 公式模板

```
决策ROI = (Σ收益项 × 置信度) - (Σ成本项 × 置信度)
```
