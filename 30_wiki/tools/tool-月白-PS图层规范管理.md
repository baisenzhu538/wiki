# 技能：PS图层规范管理

## 原始表述

PS图层规范管理是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 每个修改元素独立图层
2. 图层命名清晰（如'Leo小人-面部-眼睛'）
3. 按修改部位分组管理
4. 保留原始图层备份
