# 技能：基于需求拆解找设计参考

## 原始表述

基于需求拆解找设计参考是月白在文创案例中提出的实操方法。

## 操作步骤

1. 明确项目的需求与解决方案（拆推评算）
2. 确定目标人群、使用场景、刚需频率、普及频次
3. 找到频次最高、最刚性、最普及的人群
4. 分析该人群的审美类型
5. 据此确定参考图的风格方向
6. 避免B端/C端需求错位导致参考方向错误
