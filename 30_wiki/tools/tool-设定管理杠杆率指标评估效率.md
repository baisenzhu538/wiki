# 技能：设定管理杠杆率指标评估效率

## 原始表述
> 设定「管理杠杆率」指标：每个管理者的「直接管理人数/间接影响产出」，定期评估管理效率

## 操作步骤
1. 计算每个管理者的直接管理人数
2. 评估其间接影响产出
3. 计算管理杠杆率（直接管理人数/间接影响产出）
4. 定期评估并识别效率损耗点
5. 针对性优化管理层级
