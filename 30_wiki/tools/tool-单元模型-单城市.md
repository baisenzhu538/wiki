## 1. 一句话定义

**单城市模型**是把「一个城市」当作独立物理空间，把城市层面的全部收入与城市层面的全部成本（含本地运营中心、仓储、分公司/代理公司等固定投入，以及可归属的总部摊销）核算成一个可复制、可扩张的单元模型 [conf=0.70, source=一堂原创]。

换言之：在考虑「要不要去下一个城市」时，先算清楚「这一个城市」作为独立生意到底赚不赚钱、多久回本、能不能复制。

## 2. 为什么重要

1. **城市复制是很多业务从 1 到 N 的生死门**。租车、房地产、旅游、物流、连锁服务等业务，扩张的最小规模化单位往往不是单店、单订单，而是一个城市模型 [conf=0.80, source=原图/VLM描述]。
2. **它能拆穿总账幻觉**。全国总账盈利时，可能少数城市在补贴多数城市；只有单城市模型才能识别出哪些城市是真利润中心，哪些是失血黑洞。
3. **它决定扩张节奏**。在单城市模型未算透前盲目开新城，容易把成熟城市的盈利连同新城市的亏损一起烧掉。

## 3. 核心机制 / 结构

| 模块 | 说明 |
|:-----|:-----|
| **空间边界** | 以城市为独立 P&L 单元，收入 = 城市产生的全部收入；成本 = 城市直接成本 + 可归属的总部/中台/供应链摊销 |
| **常见变种** | 单子公司模型、单省模型、单区域模型（华东、华南等）、单国家模型（国际业务） [conf=0.80, source=原图/VLM描述] |
| **典型类型** | 租车业务、房地产开发、旅游业务 [conf=0.80, source=原图/VLM描述] |
| **触发条件** | 1) 打算复制城市；2) 城市开分公司、代理公司；3) 城市同时配置运营中心、仓储 [conf=0.80, source=原图/VLM描述] |
| **关键指标** | 城市级毛利率、城市现金流回正周期、单城市产能利用率、城市间边际成本曲线、城市复制周期 |

### 计算口径建议

- **财务口径**：城市收入 − 城市直接成本 − 可归属总部摊销 = 城市经营利润。
- **现金流口径**：城市累计投入（押金、装修、车辆/设备、首批库存、前期运营亏损） ÷ 月均经营现金流入 = 现金回正周期。
- **复制口径**：把上一个城市的单位经济参数按新城市系数调整后，预测新城市何时达到盈亏平衡。

## 4. 边界与反例

### 适用边界

- 业务在不同城市之间存在可复制的收入/成本结构。
- 城市内有可辨识的本地固定投入（分公司、仓库、运营中心、车辆等）。
- 城市数据可独立核算，或可通过合理的分摊规则拆分。

### 不适用场景 / 反例

- **纯线上、无城市级固定投入的业务**：用户在全国均匀分布，城市边界对成本结构没有实质影响。
- **平台早期**：网络效应跨城市，单城市模型会割裂双边/多边价值，低估跨城供给与需求联动。
- **项目制房地产开发**：单个项目差异远大于城市差异，用城市模型会掩盖项目级风险。
- **行政区与经济腹地错位**：长三角、珠三角城市间高度协同，按行政城市划分可能把「一个市场」切成多个失真单元。

## 5. 失败模式

| 失败模式 | 典型症状 | 修复方向 |
|:-----|:-----|:-----|
| **总部费用分摊错误** | 每个城市模型都盈利，但公司总账亏损；或亏损城市被摊销过少，看起来还能继续输血 | 建立「双口径」：经营利润口径与完全成本口径，强制把可归属总部成本摊入城市 |
| **用成熟城市模板硬套新城市** | 把北京/上海模型直接搬到三四线，忽略租金、人工、消费密度、竞争差异 | 做城市分级系数表，每个新城市先跑 3-6 个月真实数据再建模 |
| **把城市规模经济当成必然** | 认为「城市越大成本越低」，超过最优密度后履约、管理、协调成本反而上升 | 画出城市边际成本曲线，识别规模不经济拐点 |
| **只看利润不看现金流** | 城市经营利润为正，但前期车辆/仓库/押金投入巨大，现金流断裂 | 同步考核城市现金流回正周期与资金占用效率 |
| **核心城市未验证就复制** | 第一个城市还没跑通模型，就开始「百城大战」 | 用 [[yt-tool-unit-model-selection]] 的「加法减法」原则，先算透再扩张 |

## 6. 与已有框架的关系

- **[[yt-unit-model-overview]]**：单城市模型是十大单元模型中「按空间」维度的最高层，与单商圈、单门店是聚合关系 [conf=0.70, source=一堂原创]。
- **[[yt-tool-unit-model-selection]]**：当业务进入城市复制阶段，单城市模型常成为「最需盯紧的单元」。
- **[[yt-decision-y-model]]**：Y 模型的成本、收益、时间、空间四个维度，需要落到单城市模型才能精确衡量——城市模型是 Y 模型在空间扩张中的落地工具。
- **[[master-decision-hygiene]]**：决策卫生要求「先算小账再算大账」，单城市模型是全国总账的最小可核算小账单元。
- **[[yitang-domain-digest]]**：单城市模型属于一堂「单元模型」知识域，是五步法商业模式验证的核心工具之一。

## 7. 可迁移场景

- **租车/网约车**：以城市为单位配置车辆、司机运营中心、维保点，核算城市模型后决定开城节奏。
- **房地产开发**：城市公司作为独立 P&L，决定拿地、项目布局与资源倾斜。
- **旅游/目的地业务**：按城市配置供应链、销售团队、本地履约，评估单城市 ROI。
- **即时零售 / 城市仓配**：一个城市的前置仓+配送网络是否符合单元经济。
- **SaaS / 企业服务区域分公司**：以城市/大区为单位的销售+交付团队是否养活得了自己。
- **连锁服务出海**：把「单国家模型」作为单城市模型的国际版，验证首国是否成立。

## 8. 行动 Checklist

- [ ] 明确城市级收入/成本边界：哪些收入算城市收入，哪些总部费用要摊销进来。
- [ ] 对核心城市做至少 6-12 个月的真实 P&L 和现金流复盘。
- [ ] 建立城市分级系数表：租金、人工、获客成本、履约成本在不同城市的差异。
- [ ] 定义城市健康度标准：红灯（关停/改造）、黄灯（限期整改）、绿灯（复制）。
- [ ] 每进入一个新城市前，先做「单城市模型压力测试」：悲观、基准、乐观三种假设。
- [ ] 每季度校准城市级模型参数，关停长期无法回正的城市或调整业务模式。
- [ ] 扩张前确认：不是「总账有钱」，而是「已验证城市的模型在新城市仍成立」。

## 9. Critique

### **Michael Porter** — 城市边界不等于竞争优势边界

Porter 在《The Competitive Advantage of Nations》(1990) 中强调，真正的竞争优势往往来自**地理产业集群**，而非行政城市边界。长三角、珠三角的城市之间在供应链、人才、客户流动上高度耦合，强行把每个城市切成独立单元模型，会忽视跨城协同与外部性，甚至把「一个市场」误判为「多个城市」。单城市模型更适合城市间相对独立、本地固定投入显著的业务；在高度一体化的城市群中，需要叠加「城市群/产业集群」视角。

### **Richard Rumelt** — 平均化城市模型会制造「坏战略」

Rumelt 在《Good Strategy Bad Strategy》(2011) 中指出，坏战略的常见症状是「把资源平均分配给多个目标，缺乏战略焦点」。单城市模型如果变成「每个城市都要盈利」的平均主义考核，会迫使团队把有限资源撒胡椒面，而不是在最有战略价值的城市建立压倒性优势。单城市模型是分析工具，不能替代「在哪里打赢」的战略选择——有时需要主动放弃一些城市，集中兵力打透关键城市。

### **Chris Zook** — 城市扩张若偏离核心，会稀释而非放大价值

Zook 在《Profit from the Core》(2001) 中证明，多数失败扩张源于企业偏离核心能力圈。城市复制成功的前提是：新城市能够复用已有核心能力（品牌、供应链、运营体系）。如果只是为了规模而进新城，单城市模型即使算得再细，也可能复制一个「放大的亏损单元」。
