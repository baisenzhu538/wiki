# 技能：风格探索试错法

## 原始表述

风格探索试错法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 大量生成不同风格方案
2. 对比筛选最适合IP特质的风格
3. 参考官方最佳实践（如GPT-2提示词）
4. 评估标准：符合人物身份+整体质感+性格表达
