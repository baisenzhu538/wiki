# 技能：新媒体平台流量逻辑-问平台亲儿子AI法

## 原始表述

新媒体平台流量逻辑-问平台亲儿子AI法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 识别平台所属公司的AI工具：微信/视频号→腾讯元宝，抖音→豆包，小红书→点点（或豆包/千问）
2. 构造提示词模板：'我是做[行业]的，有[具体场景]，[平台]的[物料]要怎么做最符合平台流量推荐？该平台风格是什么？'
3. 根据AI返回的平台风格、算法偏好、关键假设制定设计方案
4. 如需数据诊断：将后台数据导出表格，让对应平台AI按平台规则分析
