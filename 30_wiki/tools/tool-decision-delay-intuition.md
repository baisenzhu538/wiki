# 技能：延迟直觉法

> **来源**：基于 master-decision-hygiene 框架提炼（Kahneman《噪声》）
> **核心**：不要在做完分析后立即拍板——让判断"多飞一会儿"。直觉太快、太自信、太容易被最近的信息污染。

## 原始表述
> "你的第一反应不是你的最佳反应，只是你最快的反应。"
> —— 基于Kahneman研究提炼

---

## 操作步骤

### Step 1：完成分析（不拍板）

走完所有分析步骤（偏差自检、外部视角、独立评估等）后，**强制不拍板**。

在分析结论上标注：
```
分析完成时间：_____年_____月_____日 _____:_____
建议拍板时间：_____年_____月_____日 _____:_____（至少24小时后）

当前判断：________________________
暂不拍板的原因：等待延迟直觉验证
```

### Step 2：设置强制等待期

根据决策重要度设置等待时间：

| 决策重要度 | 等待时间 | 设置方式 |
|:----------|:--------|:--------|
| 日常决策 | 不需要 | 不适用 |
| 中等重要 | 24小时 | 日历提醒 |
| 高重要度 | 3-7天 | 日历提醒+他人监督 |
| 战略级 | 1-2周 | 团队评审会 |

**关键规则**：等待期间不要主动想这个决策。让大脑"孵化"。

### Step 3：重新审视（强制对比）

等待期结束后，强制回答：

```
重新审视表：

24小时前的判断：________________________
现在的判断：________________________

是否有变化？是 / 否

如果变化了：
- src_unknown
- src_unknown

如果没有变化：
- src_unknown
- src_unknown

最终拍板：________________________
拍板时间：________________________
```

### Step 4：记录延迟效果（可选）

长期追踪延迟直觉的准确率：

```
延迟直觉记录：

决策#1：延迟后改变了判断 → 结果：正确/错误
决策#2：延迟后未改变判断 → 结果：正确/错误
...

统计：延迟后改变判断的准确率 = _____%
       延迟后未改变判断的准确率 = _____%
```

## 为什么有效

直觉（System 1）太快、太自信、太容易被最近的信息污染。延迟让System 2有机会检查System 1的结论。

**金句**：你的第一反应不是你的最佳反应，只是你最快的反应。

| 失败现象 | 原因 | 解决方案 |
|---------|------|---------|
| 等待期间偷偷决定了 | 忍不住提前拍板 | 告诉他人你的拍板时间，让他监督 |
| 等待后没有重新审视 | 忘记执行 | 设置强制提醒，写入日程 |
| 重新审视只是形式 | 心理上已经决定了 | 强制回答"如果今天是第一次看到这个问题，还会做同样选择吗？" |
| 等待时间太长 | 等待1周，机会消失 | 根据重要度调整等待时间，不是越长越好 |
| 团队等不及 | 组织有上线压力 | 用"最小可行延迟"——至少等1晚 |

## 质疑

- **具体假设**：该工具假设"延迟 = 更好的决策"，但在许多真实场景中，延迟本身就是一种决策——"不做决定"的代价可能比"做了不完美的决定"更高。延迟直觉法可能被用来回避决策（拖延症的合理化），而非改善决策。
- **边界**：在时间窗口极短的竞争性场景中（如投标、竞价、突发事件响应），24 小时延迟可能导致机会永久丧失。
- **反例**：消防指挥官在火灾现场不能"延迟 24 小时"——他们的研究表明，最佳决策往往是在几秒内基于模式识别做出的（Gary Klein 的 RPD 模型）。

**Gary Klein**（认知心理学家，《Sources of Power》作者）会质疑：延迟直觉法基于 Kahneman 的"System 1 有偏差"的前提，但他的研究发现，专家的直觉（经过多年经验训练的模式识别）在高压环境下的准确率远高于延迟后的"理性分析"。强制延迟可能打断专家的"识别-决策"链条，让一个本可以在 3 秒内做出的正确决定变成 24 小时的纠结。真正的风险不是"直觉太快"，而是"把直觉用于不擅长的领域"。
