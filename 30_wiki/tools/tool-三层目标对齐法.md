# 技能：三层目标对齐法

## 原始表述
> √高度：眼下难题<年度挑战<长期追求<人生红点

## 操作步骤
1. 识别眼前的具体难题
2. 对齐到年度挑战层面
3. 再对齐到长期追求
4. 最终对齐到人生红点（终极方向）

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 迷茫或动力不足时，需要意义感驱动 |
| ✅ 适合 | 做重要选择时，需要长期视角校准 |
| ✅ 适合 | 需要持续学习动力时，避免短期焦虑 |
| ✅ 适合 | 季度/年度规划，统一行动方向 |
| ❌ 不适合 | 紧急执行、无需反思时 → 对齐消耗时间 |
| ❌ 不适合 | 目标体系尚未建立 → 强行对齐无意义 |
| ❌ 不适合 | 团队目标与个人目标冲突 → 对齐后更焦虑 |
| ❌ 不适合 | 人生红点频繁变动 → 对齐失去稳定性 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **目标太虚** | "成为更好的学习者"——空洞不可衡量 | 目标必须具体到"下季度能独立完成竞品调研报告"，有明确的完成标准和验收条件 |
| **三层断层** | 年度挑战是提升战略思维，每天在学Python教程 | 每一层必须是上一层的自然延伸，层间断层说明目标体系没有形成逻辑链条 |
| **只定高度不定宽度** | 确定了年度挑战目标，但没有指定哪些专题/领域要覆盖 | 除了高度（目标层级）外，必须指定宽度（哪些专题/领域要覆盖），否则学习内容散乱 |
| **红点执念** | 把人生红点理解成终身使命，因为太遥远而无法行动 | 红点是方向不是KPI，提供意义感但不规定具体路径。当下行动只需要对齐到年度挑战即可 |
| **目标过时** | 一年前定的三层目标，现在还在用 | 每月/每季度检查一次对齐情况，超过3个月没更新可能已经完全不匹配了 |
| **宽度失控** | 年度挑战覆盖10个领域，每个都浅尝辄止 | 宽度必须有限，建议年度聚焦3-5个专题，深度优先于广度 |
| **对齐仪式化** | 每季度做一次对齐但行动毫无变化 | 对齐必须产出具体的行动调整，不是心理安慰。对齐后必须有至少一个行动改变 |
| **红点他人化** | 人生红点是父母/社会期望，不是内心真实渴望 | 红点必须通过"如果钱不是问题，我会做什么"测试，确保是内在驱动而非外部压力 |

## 判断标准

**什么算一份有效的三层目标对齐**：

| 标准 | 好的对齐 | 坏的对齐 |
|:---|:---|:---|
| 四层可清晰写出 | 能用具体文字写出"当前难题 → 年度挑战 → 长期追求 → 人生红点" | "成为更好的学习者"——空洞不可衡量 |
| 四层有逻辑连贯 | 每一层是上一层的自然延伸（学习 Python → 提升技术能力 → 做独立开发者） | 层间断层——年度目标是"提升战略思维"，每天在学"Python 教程" |
| 宽度已指定 | 除了高度（目标层级）外，也指定了宽度（哪些专题/领域要覆盖） | 确定了高度但没指定宽度，学习内容散乱 |
| 有定期检查 | 每月/每季度检查一次对齐情况，调整偏差 | 一年前定的三层目标，现在还在用——可能已经完全不匹配了 |

**自检问题**：
1. 今天做的事情，和三层目标中的哪一层有关？如果哪一层都连不上，说明正在做无关的事。
2. 我的人生红点能驱动我度过最难的那一周吗？——如果不行，红点可能还不够真实。
3. 上一次更新三层目标是什么时候？超过 3 个月没更新？可能已经过时了。
