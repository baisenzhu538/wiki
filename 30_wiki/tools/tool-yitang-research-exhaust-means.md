# 穷尽手段：底线之上，努力拉满

> **一句话**：穷尽手段不是"不择手段"，而是"在合法合规的底线之上，穷尽所有可用手段，拿到最高质量情报"。

---

## 核心原则：合法合规 + 穷尽手段

```
合法合规（底线）
   ↓
穷尽手段（努力拉满）
```

---

## 手段层次

### 第一层：公开信息（难度低）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **官网** | 公司官网信息 | 产品、价格、团队 |
| **财报** | 上市公司财务报告 | 收入、利润、成本 |
| **新闻** | 媒体报道 | 动态、事件、观点 |
| **报告** | 行业研究报告 | 数据、趋势、分析 |
| **专利** | 专利数据库 | 技术、创新 |
| **招聘** | 招聘信息 | 团队规模、方向 |

### 第二层：半公开信息（难度中）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **招投标** | 政府/企业招投标 | 客户、订单、价格 |
| **工商信息** | 工商注册信息 | 股权、关联公司 |
| **法院公告** | 法律诉讼信息 | 法律风险 |
| **融资信息** | 融资披露信息 | 估值、投资方 |
| **社交媒体** | 员工/高管社交动态 | 组织变化、战略方向 |
| **用户评价** | 应用商店、电商评价 | 用户满意度 |

### 第三层：专家访谈（难度中）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **行业专家** | 访谈行业专家 | 趋势、判断、建议 |
| **从业者** | 访谈竞品员工 | 内部信息、经验 |
| **前员工** | 访谈离职员工 | 内部问题、真实数据 |
| **供应商** | 访谈供应商 | 成本、产能、合作 |
| **客户** | 访谈竞品客户 | 满意度、切换意愿 |

### 第四层：逆向工程（难度高）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **产品拆解** | 拆解竞品产品 | 技术、成本、供应链 |
| **数据分析** | 分析公开数据 | 用户量、活跃度、趋势 |
| **ID自增** | 分析ID规律 | 用户增长、订单量 |
| **爬虫抓取** | 抓取网站数据 | 价格、库存、评价 |
| **API分析** | 分析接口数据 | 功能、用户行为 |

### 第五层：社会工程（难度极高，合规风险高）

| 手段 | 说明 | 合规风险 | 示例 |
|:---|:---|:---:|:---|
| **假装客户** | 以客户身份获取信息 | 中 | 询价、体验服务 |
| **假装加盟商** | 以加盟商身份获取信息 | 高 | 了解加盟政策 |
| **假装求职者** | 以求职者身份获取信息 | 中 | 了解团队、薪酬 |
| **潜入社群** | 加入竞品用户群 | 低 | 了解用户反馈 |
| **信息交换** | 用信息换取信息 | 低 | 行业交流 |

---

## 穷尽手段检查清单

- [ ] 是否穷尽了所有公开信息来源？
- [ ] 是否穷尽了所有半公开信息来源？
- [ ] 是否访谈了足够的专家/从业者？
- [ ] 是否进行了逆向工程分析？
- [ ] 是否考虑了社会工程手段？
- [ ] 所有手段是否在合法合规范围内？
- [ ] 是否记录了所有信息来源和可信度？
- [ ] 是否对关键信息进行了交叉验证？

## 手段选择矩阵

| 决策重要性 | 建议手段层次 | 时间投入 | 成本投入 |
|:---|:---|:---:|:---:|
| 低（<10万） | 第一层 | 1-2天 | 低 |
| 中（10-100万） | 第一+第二层 | 3-5天 | 中 |
| 高（100-1000万） | 第一至第四层 | 1-2周 | 高 |
| 极高（>1000万） | 所有层次 | 2-4周 | 极高 |

---

## Constraints & Boundaries

### 适用边界

1. **关键决策**：需要高质量信息
2. **信息稀缺**：公开信息不足
3. **竞争情报**：需要深度了解竞品
4. **投资尽调**：需要全面信息
5. **风险识别**：需要识别隐性风险

### 不适用场景

1. **简单查询**：公开信息足够
2. **紧急决策**：没有时间穷尽
3. **成本过高**：穷尽成本超过价值
4. **法律风险**：手段可能违法
5. **道德风险**：手段不道德

---

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 手段单一 | 只用公开信息 | 强制使用多层次手段 | "看了几篇报告" |
| 合规风险 | 使用非法手段 | 明确法律边界 | "这个手段有点灰色" |
| 成本失控 | 穷尽成本过高 | 评估投入产出比 | "调研花了10万" |
| 信息过载 | 信息太多无法消化 | 聚焦关键问题 | "看了100页，还是不知道" |
| 验证不足 | 单一来源就下结论 | 强制交叉验证 | "根据XX报道..." |
| 记录缺失 | 信息来源没记录 | 强制记录 | "这个信息哪来的？" |
| 团队能力不足 | 某些手段不会用 | 培训或外包 | "这个我们没做过" |
| 忽视时效 | 只调研一次 | 建立持续跟踪 | "调研后不再更新" |

---

## 行动触发器

1. **关键决策前**：穷尽手段获取信息
2. **信息不足时**：升级手段层次
3. **团队培训**：培训穷尽手段能力
4. **定期复盘**：检查手段是否穷尽
5. **竞争情报**：建立穷尽手段体系
