# 穷尽手段：底线之上，努力拉满

> **一句话**：穷尽手段不是"不择手段"，而是"在合法合规的底线之上，穷尽所有可用手段，拿到最高质量情报"。

---

## 核心原则：合法合规 + 穷尽手段

```
合法合规（底线）
   ↓
穷尽手段（努力拉满）
```

---

## 手段层次

### 第一层：公开信息（难度低）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **官网** | 公司官网信息 | 产品、价格、团队 |
| **财报** | 上市公司财务报告 | 收入、利润、成本 |
| **新闻** | 媒体报道 | 动态、事件、观点 |
| **报告** | 行业研究报告 | 数据、趋势、分析 |
| **专利** | 专利数据库 | 技术、创新 |
| **招聘** | 招聘信息 | 团队规模、方向 |

### 第二层：半公开信息（难度中）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **招投标** | 政府/企业招投标 | 客户、订单、价格 |
| **工商信息** | 工商注册信息 | 股权、关联公司 |
| **法院公告** | 法律诉讼信息 | 法律风险 |
| **融资信息** | 融资披露信息 | 估值、投资方 |
| **社交媒体** | 员工/高管社交动态 | 组织变化、战略方向 |
| **用户评价** | 应用商店、电商评价 | 用户满意度 |

### 第三层：专家访谈（难度中）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **行业专家** | 访谈行业专家 | 趋势、判断、建议 |
| **从业者** | 访谈竞品员工 | 内部信息、经验 |
| **前员工** | 访谈离职员工 | 内部问题、真实数据 |
| **供应商** | 访谈供应商 | 成本、产能、合作 |
| **客户** | 访谈竞品客户 | 满意度、切换意愿 |

### 第四层：逆向工程（难度高）

| 手段 | 说明 | 示例 |
|:---|:---|:---|
| **产品拆解** | 拆解竞品产品 | 技术、成本、供应链 |
| **数据分析** | 分析公开数据 | 用户量、活跃度、趋势 |
| **ID自增** | 分析ID规律 | 用户增长、订单量 |
| **爬虫抓取** | 抓取网站数据 | 价格、库存、评价 |
| **API分析** | 分析接口数据 | 功能、用户行为 |

### 第五层：社会工程（难度极高，合规风险高）

| 手段 | 说明 | 合规风险 | 示例 |
|:---|:---|:---:|:---|
| **假装客户** | 以客户身份获取信息 | 中 | 询价、体验服务 |
| **假装加盟商** | 以加盟商身份获取信息 | 高 | 了解加盟政策 |
| **假装求职者** | 以求职者身份获取信息 | 中 | 了解团队、薪酬 |
| **潜入社群** | 加入竞品用户群 | 低 | 了解用户反馈 |
| **信息交换** | 用信息换取信息 | 低 | 行业交流 |

## 手段选择矩阵

| 决策重要性 | 建议手段层次 | 时间投入 | 成本投入 |
|:---|:---|:---:|:---:|
| 低（<10万） | 第一层 | 1-2天 | 低 |
| 中（10-100万） | 第一+第二层 | 3-5天 | 中 |
| 高（100-1000万） | 第一至第四层 | 1-2周 | 高 |
| 极高（>1000万） | 所有层次 | 2-4周 | 极高 |

---

## Constraints & Boundaries

### 适用边界

1. **关键决策**：需要高质量信息
2. **信息稀缺**：公开信息不足
3. **竞争情报**：需要深度了解竞品
4. **投资尽调**：需要全面信息
5. **风险识别**：需要识别隐性风险

### 不适用场景

1. **简单查询**：公开信息足够
2. **紧急决策**：没有时间穷尽
3. **成本过高**：穷尽成本超过价值
4. **法律风险**：手段可能违法
5. **道德风险**：手段不道德

---

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 手段单一 | 只用公开信息 | 强制使用多层次手段 | "看了几篇报告" |
| 合规风险 | 使用非法手段 | 明确法律边界 | "这个手段有点灰色" |
| 成本失控 | 穷尽成本过高 | 评估投入产出比 | "调研花了10万" |
| 信息过载 | 信息太多无法消化 | 聚焦关键问题 | "看了100页，还是不知道" |
| 验证不足 | 单一来源就下结论 | 强制交叉验证 | "根据XX报道..." |
| 记录缺失 | 信息来源没记录 | 强制记录 | "这个信息哪来的？" |
| 团队能力不足 | 某些手段不会用 | 培训或外包 | "这个我们没做过" |
| 忽视时效 | 只调研一次 | 建立持续跟踪 | "调研后不再更新" |

## 目的

解决"信息不足导致决策失误"的问题。当你面临关键决策（如进入新市场、投资并购、战略转型），需要最高质量情报，但公开信息不足以支撑决策时，穷尽手段强迫你在合法合规的底线之上，用所有可用手段获取信息。不是"不择手段"，而是"底线之上，努力拉满"。适用于：投资决策尽调、竞品深度研究、市场进入评估、重大合作前的背景调查。

## 操作步骤

1. **评估决策重要性**：根据决策金额和时间窗口选择手段层次——低重要性（<10 万）用第一层（公开信息），中重要性（10-100 万）用第一+第二层，高重要性（100-1000 万）用第一至第四层，极高重要性（>1000 万）用所有层次
2. **逐层升级手段**：从低难度（公开信息）开始，如果信息仍不足，升级到半公开信息（招投标、工商、法院）→ 专家访谈（行业专家、从业者、前员工）→ 逆向工程（产品拆解、数据分析、爬虫）→ 社会工程（假装客户、加盟商、求职者）
3. **交叉验证和记录**：每个手段获取的信息用至少 2 个独立来源验证，全程记录信息来源和获取方式，确保可追溯和可验证

## 不要用的场景

- 简单查询（公开信息足够），不需要穷尽手段，浪费资源
- 紧急决策（没有时间穷尽），只能用最快的手段，标注信息风险
- 成本过高（穷尽成本超过决策价值），需评估投入产出比，设定成本上限
- 法律风险（手段可能违法），立即停止，只使用合法合规手段
- 道德风险（手段不道德），即使合法也不使用，维护长期声誉

## 质疑

- **具体假设**：该工具假设结构化方法论本身能产生正确结论，但方法论只是框架——结论质量取决于输入数据的质量和执行者的判断力。
- **边界**：在数据稀缺或快速变化的新兴领域，已有经验框架可能完全失效——工具的有效性高度依赖场景的稳定性。
- **反例**：一个团队完整执行了所有步骤，产出了漂亮的文档，但核心假设从一开始就是错的——流程的完整性掩盖了判断的缺陷。
- **前提**：使用者已具备该领域的基础认知，能正确理解和执行工具规则，且数据来源具有代表性。

**Rachel Huang**："穷尽手段"这个词本身就让人警觉。你是在做商业调研，还是在培养间谍？假装求职者去竞品公司面试、假装客户套取信息、潜入用户群——这些手段即使在法律上打擦边球，在商业道德上也有很大问题。一旦被发现，对你的声誉和合作关系造成的损害，远远超过你获取的那点信息价值。

**James Wu**：这个方法最大的问题是"手段升级"的判定标准很模糊。什么时候"公开信息不足"？你看了 3 份报告就说不足，还是看了 30 份？没有客观标准，导致要么过早升级到高风险手段，要么迟迟不升级导致信息不足。更实际的问题是：你的团队有能力执行第四、第五层手段吗？大多数团队连专家访谈都做不好，谈何"社会工程"？

**Sophie Chen**：穷尽手段假设"更多信息=更好决策"，但信息过多会导致"分析瘫痪"。你穷尽了 5 个层次，获取了海量信息，然后呢？如果你没有足够的信息处理和分析能力，更多信息只会让你更困惑。更重要的是，有些信息知道了反而有害——比如你知道竞品即将融资，但无法阻止，这只会增加你的焦虑，不影响决策。
