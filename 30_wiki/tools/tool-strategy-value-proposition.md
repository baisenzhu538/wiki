# 价值主张设计工具：三问 + 六维排序法

> 业务设计六要素第 2 要素。核心问题：**我们提供什么独特价值，让客户选择我们而不是对手？**

---

## 一、价值主张三问

| 问题 | 关键意图 | 诊断标准 |
|--|--|--|
| **1. 客户需求导向** | 主要细分客户群体的主要愿望和需求是什么？ | 是否基于真实客户场景，而非自嗨 |
| **2. 影响力** | 我们能否帮助客户实现增值和利益？哪些优势最能满足目标客群的主要需求？ | 是否量化或具体描述客户收益 |
| **3. 独特性** | 哪项优势和利益最能实现我们与竞争对手的差异化？ | 是否明确“非我不可”的理由 |

---

## 二、价值主张六维评估

将候选价值要素放在六个维度上打分（1-5 分），并排序。

| 维度 | 含义 | 高分表现 |
|--|--|--|
| **价格敏感度** | 客户为满意交付愿意支付的价格，兼顾实际价格与感知价值 | 让客户感知“物超所值” |
| **功效重视性** | 产品/服务的功能和特性是否满足期望 | 必备功能齐全，且有超预期性能 |
| **品牌影响力** | 品牌带来的感知、体验、身份认同 | 品牌能代表客户的某种观念或身份 |
| **渠道便利性** | 购买的容易程度和有效性 | 客户能以自己喜欢的方式快速获得 |
| **服务要求度** | 售前、售中、售后全环节体验 | 服务过程让人感到被重视、被解决 |
| **设计吸引力** | 视觉、包装、外观、集成性 | 在第一眼和长期使用中都有吸引力 |

### 六维排序模板

```markdown
| 维度 | 当前得分 (1-5) | 目标得分 (1-5) | 与竞品对比 | 优先级 |
|--|--|--|--|--|
| 价格敏感度 | | | | |
| 功效重视性 | | | | |
| 品牌影响力 | | | | |
| 渠道便利性 | | | | |
| 服务要求度 | | | | |
| 设计吸引力 | | | | |
```

## 三、价值曲线（竞品对比版）

参考 PPT `_112` 的价值曲线，横轴为行业竞争价值要素，纵轴为客户得到的利益。

**步骤：**
1. 列出行业内 8-12 个关键竞争价值要素（产品、服务、价格相关）。
2. 为每个要素给出现有主要竞品、自身现状、未来定位三个得分。
3. 连接成线，识别：
   - **未来发力点**：我们要大幅提升的要素
   - **可削减点**：行业过度投入但客户感知弱的要素
   - **差异化空白**：竞品忽视但客户重视的要素

```markdown
| 价值要素 | 竞品A | 竞品B | 我们现状 | 未来定位 |
|--|--|--|--|--|
| 健康 | | | | |
| 口味好 | | | | |
| 包装好 | | | | |
| 场景解决方案 | | | | |
| 方便快捷 | | | | |
| 容易选购 | | | | |
| 专业友好的人员服务 | | | | |
| 购物环境体验 | | | | |
| 会员专享服务 | | | | |
| 价格 | | | | |
```

## 四、一句话价值主张公式

将排序最高的 2-3 个维度整合成一句话：

> **我们为 [目标客户]，提供 [核心差异化价值]，让他们在 [关键场景] 中获得 [具体收益]， Unlike [竞品]，我们 [独特之处]。**

**示例（PPT _110）：**
> 亲切温暖的专业美容管家，为您提供时尚优选美妆商品和快捷智能服务体验。
> - 时尚优选的美妆商品
> - 快捷智能的专业服务
> - 亲切温暖的美容管家

## 五、Agent 执行指令

```python
def design_value_proposition(customer_segment: str, competitor_list: list[str]):
    """为客户群设计差异化价值主张"""
    prompts = {
        "三问": f"""基于客户群「{customer_segment}」，回答价值主张三问：
1. 他们的主要愿望和需求是什么？
2. 我们能帮他们实现什么增值/利益？
3. 与{competitor_list}相比，我们独有的优势是什么？""",
        "六维打分": "为上述价值要素在六维上打分（1-5），并排序。",
        "价值曲线": f"""列出{competitor_list}与我们共同竞争的8-12个价值要素，
分别打分，找出未来发力点和差异化空白。""",
        "一句话主张": "用公式整合出30字以内的一句话价值主张，并附3个支撑点。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 自嗨式价值 | “我们产品质量好、服务周到” | 必须绑定具体客户场景和可感知收益 |
| 维度过多 | 六维都想做第一 | 排序，明确 Top 2-3 发力点，其余保持不落后即可 |
| 与竞品同质化 | 价值曲线高度重叠 | 寻找蓝海空白或刻意做减法（剔除/减少行业默认要素） |
| 口号化 | 一句话价值主张没有支撑点 | 每个主价值必须配 2-3 个可验证的次级价值 |
