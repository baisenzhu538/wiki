# PC/Web端数据

> SimilarWeb/Alexa/百度统计——网站流量、来源、用户行为。

**用法**：看竞对网站的月访问量、流量来源（搜索/社媒/直接访问）、用户地理分布、跳出率。

**价值**：PC/Web端虽然流量占比下降，但对B2B/SaaS/工具类产品仍然是核心渠道。

**坑**：SimilarWeb的数据是估算值（浏览器插件采样），小网站的数据偏差可能很大。
