# 短视频 6 维度拆解工具

> **Burn line**: 爆款不是玄学，是结构。6 维度拆解把"这条视频为什么火"从感觉变成可复制的清单。

## 目的

当你看到一条爆款短视频时，用 6 维度拆解工具系统分析它，提炼可复用的结构、钩子、情绪设计和转化路径。适用于：

- 内容团队学习对标账号
- 新手快速理解爆款逻辑
- 为案主/客户定制脚本前先做拆解

## 操作步骤

### Step 0：准备拆解对象

选择一条数据表现突出的视频（点赞、评论、转发、收藏任一指标显著高于账号平均水平）。

### Step 1：定位与受众

回答：
- 这条视频的 IP 定位是什么？一句话怎么说清？
- 目标受众是谁？他们的核心痛点是什么？
- 受众处于哪个阶段？（潜在用户 / 沉默用户 / 付费用户）

**验收信号**：能用一句话描述"这个账号为谁解决什么问题"。

### Step 2：选题与钩子

回答：
- 选题类型：工具型 / 痛点型 / 情绪型 / 热点型？
- 前 3 秒钩子用了什么公式？
  - 痛点直击："你是不是…"
  - 结果承诺："1 分钟就能…"
  - 方法具体："找到全网同行"
- 这条选题为什么切中刚需？

**验收信号**：能复写出这条视频的前 3 秒钩子。

### Step 3：文案结构

回答：
- 整体结构是否符合：反常识开场 → 痛点共鸣 → 方法论输出 → 案例证明 → 总结 + 转化钩子？
- 信息密度如何？每秒几个关键信息点？
- 金句/记忆点分布：每段是否有至少 1 个可收藏的点？

**验收信号**：能画出这条视频的结构骨架图。

### Step 4：表现力与情绪

回答：
- 情绪类型：亢奋型 / 行动派 / 温和教学 / 故事叙事？
- 演示方式：屏幕录制 / 手机录屏 / 真人出镜 / 字幕高亮？
- 场景设计：办公室 / 书房 / 户外？背景如何建立专业感或信任感？
- 节奏：短句多还是长句多？停顿和转折如何设计？

**验收信号**：能说出这条视频的情绪曲线。

### Step 5：转化设计

回答：
- 变现路径是否清晰：公域 → 关注/私信 → 领取资料/进粉丝群 → 付费？
- 信任建立机制：方法背书 / 步骤清晰 / 可操作性强 / 学员案例 / "说真话"人设？
- 转化钩子是否自然？是否全程不提价格但处处暗示"我有方法、有学员、有结果"？

**验收信号**：能写出这条视频的转化路径图。

### Step 6：数据特征与可复制性

回答：
- 互动设计：有没有低门槛评论引导？（如"试完回来告诉我"）
- 争议点设计：有没有故意制造讨论的切入点？（如"抄作业"vs"借鉴"）
- 播放量估算：点赞数 ÷ 平均点赞率（干货类 3-5%）= 估算播放量
- 这条视频的哪些元素可以直接迁移到自己的内容中？
- 内化检验：拆完后，你心里是否对这个视频的逻辑更清晰？（参见大馨战队升华的验收口诀）
- 审美肌肉记忆：哪些判断（节奏、情绪、镜头感）不是靠模板能教会的，需要反复拆才能形成手感？（参见 [[dk-content-muscle-memory-vs-knowledge]]）

**验收信号**：能提炼出 3 个可复用元素，并能回答“拆完后我对这条视频的逻辑是否更清晰”。

## 暗知识：拆解就是刻意练习审美的过程

> *「拆解就是刻意练习审美的过程。」* —— 魏千洛，大馨战队

**盲区说明**：6 维度拆解工具把爆款视频结构化了，但没有解释“为什么拆多了就会变强”。这条暗知识说明：拆解的本质不是填表，而是通过反复对比、分析、判断来训练审美肌肉记忆。模板可以帮你看到结构，但节奏、情绪张力、镜头感等判断必须靠大量拆解积累。参见 [[dk-content-muscle-memory-vs-knowledge]]。

## 6 维度检查清单

```markdown
- [ ] 定位与受众：一句话说清 IP 定位和受众痛点
- [ ] 选题与钩子：前 3 秒包含痛点/结果/方法
- [ ] 文案结构：反常识 → 痛点 → 方法 → 案例 → 转化
- [ ] 表现力与情绪：情绪、演示、场景、节奏可描述
- [ ] 转化设计：公域→私信→资料→付费路径清晰
- [ ] 数据特征：互动设计、争议点、可复制性已提炼
```

## 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|---|---|---|
| 拆解娱乐/情绪类无商业目的视频 | 6 维度聚焦商业内容结构，娱乐视频不适用 | 用更简单的情绪曲线分析 |
| 没有数据支撑就判断"爆款" | 凭感觉选的"爆款"可能不是真爆款 | 先确认点赞/评论/转发数据显著高于平均水平 |
| 只拆解不模仿 | 拆解的目的是提炼可复用结构，不是写评论 | 拆解后立即写一条自己的脚本 |
| 拆解后全盘照搬 | 照搬会丢失自己的人设和受众差异 | 提取结构，替换案例和语言风格 |

## 质疑

#### **Creative Director**

**攻击**：过度拆解会扼杀原创。如果每个视频都按固定框架分析，创作者会变成机械套用模板的"内容工人"。

**回应**：拆解不是复制，是理解结构。就像学音乐先学和弦进行，理解结构后才能写出自己的旋律。6 维度是训练工具，不是创作枷锁。

#### **Growth Hacker**

**攻击**：爆款视频很多是偶然，无法复制。算法推荐、时机、热点都具有随机性，拆结构是事后诸葛亮。

**回应**：单条爆款确实可能有偶然因素，但持续爆款的账号一定有可复制的结构。6 维度拆解帮助识别"可复制"的部分，降低偶然依赖。

#### **Startup Founder**

**攻击**：6 维度太复杂，小团队用不上。每次拆解要填 6 张表格，成本太高。

**回应**：小团队可以从"钩子 + 结构 + 转化"三个最小维度开始，逐步扩展。6 维度是完整版，不是强制版。具体使用边界：团队 ≥2 人且每周生产 ≥3 条视频时，完整 6 维度才有 ROI。
