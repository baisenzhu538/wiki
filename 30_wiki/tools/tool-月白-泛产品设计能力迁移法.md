# 技能：泛产品设计能力迁移法

## 原始表述

泛产品设计能力迁移法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 识别自己现有领域的核心能力（如营销、传播、服装打版等）
2. 分析设计任务的本质需求（如：营销人做设计=视觉化表达卖点）
3. 将原有能力重新封装，迁移到设计场景中
4. 用AI工具补足专业技术缺口，而非从零学完整设计课
