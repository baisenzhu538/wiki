# 技能：电商白底图生成与高清处理

## 原始表述

电商白底图生成与高清处理是月白在文创案例中提出的实操方法。

## 操作步骤

1. 先生成产品的正面白底图
2. 对图片使用'高清重绘'提示词提升清晰度
3. 向AI要求生成正面、侧面、背面、45度角四个视角
4. 确保图片干净利落，材质细节清晰可见
