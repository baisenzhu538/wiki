# 项目沟通计划表模板

> **一句话**：一张表说清楚：什么时候、用什么方式、和谁沟通。填完发群，全员对齐。

---

## 一、沟通计划表（直接填）

| 形式 | 时间 | 参与人 | 备注 |
|:---|:---|:---|:---|
| 固定例会 | 每周__ 下午__:__-__:__ | | 会议室/线上链接：___ |
| 日站会 | 每天__:__ | | 15分钟以内，只说三件事 |
| 周报 | 每周__ 前提交 | 负责人：___ | 模板链接：___ |
| 里程碑评审 | 每个里程碑节点 | | 至少提前3天通知 |
| 紧急沟通 | 随时 | | 紧急联系渠道：___ |
| 不定期沟通 | 按需 | | |  

---

## 二、操作步骤

```
Step 1: 确定必选项 → 固定例会+周报（每个项目至少这两项）
Step 2: 确定可选项 → 日站会/里程碑评审/紧急渠道（按项目复杂度和敏感度决定）
Step 3: 填表 → 具体到时间、人、地点
Step 4: 同步 → 截屏发项目群+钉在群公告
Step 5: 执行 → 第一次例会就按表执行，建立节奏
```

---

## 三、Constraints

- 例会时间一旦定了就不要随便改——节奏乱了沟通就乱了
- 参与人必须明确到名，不能用"相关人""大家"
- 如果项目<2周或<3人，只保留周报即可，不必设例会

---

## 四、失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 填了表不执行 | 第一周就没开会 | 设定日历邀请+会前15分钟提醒 |
| 参与人写"大家" | 没人觉得自己该来 | 明确到具体姓名 |
| 例会没议程 | 每周开会闲聊30分钟 | 提前发议程：3个议题以内 |
| 周报没人看 | 写了但群消息刷过去了 | 收件人明确+要求已读确认 |

---

## 五、Action Triggers

- 项目启动会最后一个环节：填这张表
- 团队超过5人或项目超过1个月：必须设固定例会
- 沟通出现混乱信号（信息不对称、有人不知情）：回来检查这张表
