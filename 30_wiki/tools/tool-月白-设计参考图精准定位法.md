# 技能：设计参考图精准定位法

## 原始表述

设计参考图精准定位法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 明确项目需求与解决方案
2. 拆解目标人群：谁、在什么场景下、看到图片会心动购买
3. 用拆推评算判断刚需频率与普及度，确定核心人群
4. 基于核心人群审美偏好寻找对应风格参考
5. 验证参考：该场景是否最能引起目标消费者购买欲
