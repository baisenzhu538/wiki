# 技能：商业预判15字诀

## Summary

商业预判15字诀是Truman提出的创业前决策框架，核心逻辑：**先主动定义目标区间（定中局），再尽可能多地拆解选项（做加法），最后用专业标准排除致命缺陷（做减法）**。Truman的原话："预判的本质是把一个1%的成功率提升到30%，再通过多轮试错拉到80%。" 这个方法论将创业从"赌博"转化为"可计算的概率游戏"。

## 操作步骤

1. **主动定中局：明确目标区间** — 回答"3-5年后我想做成什么规模"。用"保A争B"框架：保A是最低可接受结果（如单店盈利），争B是理想目标（如开5家店）。差距不超过2个阶段。同时用光谱模型定位当前阶段（1-7）
2. **充分做加法：拆解选项池** — 从三个维度拆解：①横向拆行业（同一行业内不同细分赛道）；②纵向拆产业链（上游、中游、下游、周边服务）；③按要素拆模式（人群、需求、渠道、定价、合作方式等）。目标：每个维度至少产出10个选项，总计30-100个
3. **专业做减法：识别三大类硬伤** — 对前10个高分选项逐一检查：①行业硬伤：天花板是否足够高？是否规模经济？②商业硬伤：需求是否刚需？单元模型能否跑通？③团队硬伤：核心能力是否匹配？资源是否足够？任何一类硬伤出现，该选项降级或排除
4. **保留3-5个高概率选项** — 通过减法后，保留没有硬伤且与团队能力匹配的3-5个选项。为每个选项制定最小验证计划，确定优先级排序
5. **制定Plan B和退出标准** — 为主选项设定"验证失败即切换"的明确标准（如"3个月内无法验证单店盈利则切换到选项2"）。Plan B不是后备，是计划的一部分

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 准备创业或启动新项目前的系统性预判 |
| ✅ 适合 | 现有业务遇到瓶颈，需要评估是否继续投入 |
| ✅ 适合 | 投资决策前对创业项目做结构化评估 |
| ✅ 适合 | 职业转型或副业选择时的方向筛选 |
| ❌ 不适合 | 时间窗口极窄的紧急机会 → 来不及走完完整流程 |
| ❌ 不适合 | 高度依赖个人品牌的创意型项目 → 如独立艺术家、作家 |
| ❌ 不适合 | 已有强约束条件的项目 → 如家族业务传承、政策指定方向 |
| ❌ 不适合 | 颠覆性创新探索 → 15字诀的减法逻辑可能系统性地排除反直觉机会 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **目标模糊** | 想做点生意但没有定义中局，最终选项池混乱 | 必须先写保A争B，否则不做加法。没有中局定义，加减法都会失去坐标 |
| **加法不足** | 只拆了3-5个选项就开始排除，错过更优路径 | 强制要求每个维度至少10个选项。加法的目标不是找正确答案，是确保没有遗漏高概率选项 |
| **困难硬伤混淆** | 将可克服的挑战误判为致命缺陷，过早排除潜力方向 | 硬伤的标准是即使投入最优资源也无法解决。困难可以克服，硬伤不能 |
| **团队硬伤忽视** | 选了正确的行业和商业模式，但团队核心能力不匹配 | 团队硬伤必须诚实面对，不能靠学习能力掩盖。核心能力不匹配是致命缺陷 |
| **Plan B缺失** | 主选项失败后没有替代方案，被迫继续投入 | Plan B必须在开始前就确定，不能临时想。Plan B不是后备，是计划的一部分 |
| **规划谬误** | 定中局时系统性地低估困难、高估能力，产生虚假安全感 | 定中局后做压力测试：如果最优资源减半，保A还能实现吗？ |
| **选择过载** | 选项池扩大到30-100个，决策者陷入分析瘫痪 | 分阶段筛选：先粗筛到20个，再细筛到10个，最后减法到3-5个。不要一次性面对100个选项 |
| **静态分析** | 硬伤判定基于当前环境，忽视技术和市场的动态变化 | 定期Review硬伤清单（每季度），技术突破可能让原来的硬伤不再是硬伤 |

## 为什么有效

15字诀的有效性建立在"概率思维"和"选项理论"基础上：通过扩大选项池（做加法）提高找到高概率路径的可能性，通过排除硬伤（做减法）降低单次试错的失败成本，通过多轮试错将整体成功率从1%提升到80%。它不是让你一次选对，而是让你"在有限资源内最大化成功概率"。

### 外部攻击

#### Daniel Kahneman 的"规划谬误"与过度自信

**Daniel Kahneman** (*思考，快与慢*作者) 从行为经济学角度攻击15字诀：

- src_unknown

> **Kahneman 的嘲讽**："你的15字诀第一步是'定中局'，但我的研究表明，人类在'定中局'时的准确率比随机猜测好不了多少。你花了两周做预判，最后选中的方向可能和你闭着眼睛随便选一个的成功率差不多——但你花了两周，所以你会更执着地坚持错误选择。"

**Michael Porter** (竞争战略之父，哈佛商学院教授) 从战略管理角度攻击：

> **Porter 的质问**："你的减法清单排除了'需求不刚需'的市场。但Uber刚出现时，打车是刚需吗？Airbnb刚出现时，住陌生人家是刚需吗？你所谓的'硬伤'，可能只是'现有解决方案不够好'。你的15字诀会系统性地过滤掉颠覆性创新。"
