# 四环修炼闭环自检清单

> **一句话**：逐环打分1-4，找最低的一环——就是当前学习能力的瓶颈。

---

## 自检表

| 环 | L1不会 | L2会一点 | L3熟练 | L4精通 | 你的分数 |
|:---|:---|:---|:---|:---|:--:|
| IPO | 没听过 | 知道概念 | 独立跑过几次 | 能带人跑 | |
| 科学提问 | 不会问 | 能问基础问题 | 能精炼到核心问题 | 提问驱动学习方向 | |
| 思维模型 | 凭经验判断 | 知道几个模型 | 能主动匹配模型 | 能自建模型 | |
| 知识萃取 | 学完就忘 | 能写笔记 | 能提炼SOP | 产出可教学的方法论 | |

---

## 卡点定位

| 最低环 | 原因 | 下一步 |
|:---|:---|:---|
| IPO | 没有系统学习方法 | 从IPO口述课开始，先建立框架 |
| 科学提问 | 带着模糊问题学习 | 练提问三段式：模糊→精炼→可验证 |
| 思维模型 | 凭直觉处理信息 | 找3个最常用的现成模型先熟练 |
| 知识萃取 | 学完没有输出 | 强制每次学习后写200字"我学到了什么" |

## 使用节奏

- 每月自检一次
- 最低环连续两个月不变→需要刻意练习
- 四环全L3以上→可以带人修炼
