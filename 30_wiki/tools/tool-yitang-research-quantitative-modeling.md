# 定量建模：用数字说话的分析框架

> **一句话**：定量建模不是"做数学题"，而是"用数字把模糊的判断变得清晰可验证"。没有数字支撑的调研结论，都是观点。

---

## 核心工具：定量建模四步法

```
定义问题 → 收集数据 → 建立模型 → 验证输出
```

---

## 第一步：定义问题

### 问题类型

| 类型 | 说明 | 示例 |
|:---|:---|:---|
| **估算问题** | 估算某个数值 | "市场规模多大？" |
| **比较问题** | 比较两个选项 | "A和B哪个更好？" |
| **预测问题** | 预测未来趋势 | "明年增长多少？" |
| **优化问题** | 找到最优解 | "最优定价是多少？" |
| **验证问题** | 验证某个假设 | "用户是否愿意付费？" |

### 问题定义模板

```markdown
## 定量建模问题

### 问题描述
[具体要回答的问题]

### 问题类型
[估算/比较/预测/优化/验证]

### 关键变量
1. [变量1]
2. [变量2]

### 输出要求
[需要什么形式的输出]
```

---

## 第二步：收集数据

### 数据收集方法

| 方法 | 说明 | 适用场景 |
|:---|:---|:---|
| **行业报告** | 引用行业数据 | 市场规模、趋势 |
| **公司财报** | 分析财务数据 | 收入、成本、利润 |
| **用户调研** | 收集用户数据 | 需求、偏好、意愿 |
| **行为数据** | 分析用户行为 | 使用频率、转化率 |
| **实验数据** | A/B测试 | 功能效果、定价 |
| **专家估计** | 专家判断 | 难以量化的因素 |

### 数据质量检查

| 检查项 | 问题 | 标准 |
|:---|:---|:---|
| **来源** | 数据从哪来的？ | 可追溯 |
| **时效** | 什么时候的数据？ | 在有效期内 |
| **样本** | 样本够大吗？ | 统计显著 |
| **方法** | 怎么收集的？ | 方法科学 |
| **偏差** | 有选择性偏差吗？ | 随机抽样 |

---

## 第三步：建立模型

### 常用模型类型

| 模型 | 说明 | 示例 |
|:---|:---|:---|
| **市场规模模型** | TAM/SAM/SOM | TAM=总人口×渗透率×客单价 |
| **财务模型** | 收入-成本-利润 | 利润=收入-固定成本-变动成本 |
| **用户模型** | 获客-留存-变现 | LTV=CAC×(留存率/流失率) |
| **竞争模型** | 市场份额 | 份额=我的收入/市场总收入 |
| **敏感性模型** | 关键变量影响 | 如果价格变化10%，利润变化多少？ |

## 第四步：验证输出

### 验证方法

| 方法 | 说明 | 示例 |
|:---|:---|:---|
| **历史验证** | 用历史数据验证 | "模型预测去年增长30%，实际是28%" |
| **交叉验证** | 用不同方法验证 | "用两种方法估算市场规模，结果接近" |
| **专家验证** | 请专家评估 | "请行业专家评估模型合理性" |
| **敏感性分析** | 测试关键变量 | "如果用户增长慢20%，结果如何？" |
| **边界测试** | 测试极端情况 | "如果市场崩溃，结果如何？" |

## Constraints & Boundaries

### 适用边界

1. **需要量化**：问题需要数字回答
2. **数据可得**：有数据支撑
3. **决策重要**：决策需要量化依据
4. **说服他人**：用数字增强说服力
5. **验证假设**：用数据验证假设

### 不适用场景

1. **纯主观问题**：如审美、偏好
2. **数据不可得**：无法获取数据
3. **快速决策**：没有时间建模
4. **复杂系统**：模型过于复杂
5. **高度不确定**：变量无法估计

---

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 数据质量差 | 用不准确的数据 | 数据质量检查 | "这个数据大概..." |
| 模型过度复杂 | 模型太复杂 | 简单优先 | "模型有100个变量" |
| 忽视验证 | 模型不验证 | 强制验证 | "模型应该对" |
| 输入错误 | 变量数值错误 | 交叉验证 | "这个数字好像不对" |
| 忽视不确定性 | 把预测当事实 | 标注置信度 | "预计明年增长30%" |
| 模型僵化 | 不更新模型 | 定期更新 | "模型建了就没动" |
| 行动缺失 | 建模后不行动 | 制定行动计划 | "模型做完了，然后呢？" |
