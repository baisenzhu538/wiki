# 招投标分析

> 政府采购网/招投标平台是B2G/B2B情报的金矿——中标公告里写着竞对的客户、订单金额、技术方案。通过反推竞对中标记录，可快速还原其客户结构、定价策略与技术优势方向。

## Purpose

在竞品调研或市场进入分析中，通过政府采购与招投标公开数据，反推竞争对手的真实客户名单、订单金额区间、技术参数偏好及商务能力边界，从而辅助渠道设计、产品定价与销售策略。

## Protocol

1. **锁定目标与平台**：明确竞对名称、关联子公司及别名，选定中国政府采购网、地方公共资源交易中心、第三方招投标聚合平台（如剑鱼、比比招标）等数据源。
2. **采集中标公告**：以企业名称为关键词检索近1-3年历史中标/成交公告，导出项目名称、采购单位、中标金额、中标（成交）供应商、公告日期。
3. **结构化清洗与分类**：按行业、区域、金额区间、采购单位类型（政府/国企/学校/医院）归类，剔除明显分包、联合体中标等噪声样本。
4. **分析金额趋势与客户集中度**：绘制中标金额时间序列，识别重点客户与重复采购关系，估算竞对客户生命周期价值。
5. **解读技术参数与评分细则**：提取招标文件中的技术参数、资质门槛、评分权重变化，判断竞对产品优势方向与政策风向。
6. **交叉验证与落地应用**：结合专利分析、财报数据与实地走访，验证招投标结论的可信度，并输出可执行的策略建议。

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|------|------|----------|
| 目标行业以民营/消费级市场为主 | 政府采购与招投标覆盖率极低，样本偏差大 | [[tool-yitang-app-store-data]]、[[tool-yitang-social-media-monitoring]] |
| 金额无法拆分硬件/软件/服务 | 公告通常只披露总价，难以还原真实毛利率 | [[tool-yitang-competitor-financial-analysis]]、供应商访谈 |
| 竞对通过关联公司或分包隐藏身份 | 中标主体与最终实施方不一致，容易误判 | [[tool-yitang-business-registration-check]]、股权穿透分析 |
| 需预测未来订单具体时点 | 招投标具有随机性与政策周期性，不适合精确预测 | 结合行业报告与客户访谈进行综合研判 |

## 质疑

本工具的内在局限需要被显式列出：

- **具体假设**：默认中标公告真实、完整且及时；若存在围标、拆分合同或未公开的小额采购，结论会系统性偏误。
- **边界**：仅覆盖必须公开招标的政府/国企/事业单位采购，对民营市场、海外项目与军口项目几乎无效。
- **反例**：某SaaS厂商80%收入来自中小微企业订阅，但其招投标记录集中在几个政府大单，易让人高估其G端依赖度。
- **前提**：研究者需具备识别关联公司、清洗异常金额、理解招标文件技术参数的能力，否则容易被表象误导。

**外部反对者**：**Michael Porter** 可能会指出，单纯依赖公开招投标数据容易陷入“可观测样本”陷阱，真正的竞争优势来自供应商议价能力、买方转换成本与行业进入壁垒，这些无法通过中标公告直接读取。
