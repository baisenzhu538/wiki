# 招投标分析

> 政府采购网/招投标平台是B2G/B2B情报的金矿——中标公告里写着竞对的客户、订单金额、技术方案。

**做法**：在政府采购网/招标平台搜索竞对名称→看历史中标记录→分析中标金额趋势、客户行业分布、技术参数倾向性。

**价值**：参数倾向性暴露竞对的技术优势方向；评分细则变化=政策风向。

**坑**：不是所有行业都有公开招投标；金额可能包含硬件+服务无法拆分。
