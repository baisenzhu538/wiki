# 产业链机会与行动计划分析工具

> 从上游到下游逐环节扫描产业链，识别每个环节的商业机会、可执行行动计划与责任部门，支撑企业在价值链上的角色选择。

---

## 一、工具结构

| 维度 | 说明 |
|--|--|
| **产业链环节** | 原料/种植/养殖 → 原料采购 → 配方工艺 → 生产加工 → 物流配送 → 批发 → 零售 |
| **机会** | 该环节存在的商业机会或竞争优势来源 |
| **行动计划** | 为抓住机会需采取的具体措施 |
| **负责部门** | 采购、研发、供应链、物流、市场部等 |

---

## 二、PPT _66 零食产业链示例

| 产业链环节 | 机会 | 行动计划 | 负责部门 |
|--|--|--|--|
| 原料/种植/养殖 | 坚果炒货果干原料上游资源控制 | 投资/收购/包销等方式控制上游有限优势资源 | 采购 |
| 原料采购 | 坚果/炒货/果干/肉/海产优势资源源头采购 | 上游原料独立或联合采购；加强预付款支持，激励供应商抢夺优势资源 | 采购 |
| 配方工艺 | 自主研发，实现产品差异化 | 新口味/新配方研发；坚果统一配料标准；建立研发中心，引入专业人才和第三方机构 | 研发 |
| 生产加工 | 鲜食糕点生鲜自有生产加工，满足产品创新和快速供应 | 自建或联合建立鲜食工厂，实现研发生产供应联动 | 供应链 |
| 物流配送 | 冷链运输、多温层仓储、本地配送能力 | 建立全国冷链运输（第三方）；租赁多温层仓储；提升配送效率，一天多配；建立本地配送网络 | 物流 |
| 批发 | 进口产品或自主研发产品批发 | 进口品批发或分销 | 采购 |
| 零售 | 产品推广和营销能力；娱乐化互动化产品设计；节令性产品规划；周边产品；进口产品丰富度 | 打造明星产品营销流程；社交定制化产品规划；节令性产品推广；周边产品规划；进口产品快上快下经营模式 | 市场部/供应链 |

---

## 三、使用步骤

1. **拆解产业链**：按上游 → 中游 → 下游列出关键环节。
2. **评估每个环节**：从壁垒、毛利率、企业数、竞争状况、发展趋势五维度分析。
3. **识别机会点**：找到高毛利、低竞争、可建立壁垒的环节。
4. **制定行动计划**：为每个机会点匹配具体措施和责任部门。
5. **决策活动范围**：决定企业应在哪些环节自营、哪些外包、哪些放弃。

---

## 四、分析模板

```markdown
| 产业链环节 | 机会 | 行动计划 | 负责部门 | 自营/外包/放弃 |
|--|--|--|--|--|
| | | | | |
```

---

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 环节划分过粗 | 行动计划无法落地 | 拆到可分配责任部门的最小单元 |
| 只看毛利率 | 忽视壁垒和竞争 | 综合五维度评估 |
| 机会与行动脱节 | 机会列得很大，行动很虚 | 每个机会必须对应具体措施、责任人和时间节点 |
| 未对齐战略控制点 | 抢了低价值环节，放弃核心环节 | 结合企业战略控制点决定活动范围 |

## 六、Agent 执行指令

```python
def industry_chain_analysis(industry: str):
    """对指定行业进行产业链机会与行动计划分析"""
    prompts = {
        "拆解产业链": f"列出{industry}从上游到下游的关键产业环节。",
        "五维度评估": "对每个环节评估进入壁垒、毛利率、企业数、竞争状况、发展趋势。",
        "识别机会": "找出高毛利、可建立壁垒或可改善效率的机会点。",
        "行动计划": "为每个机会点制定具体措施、责任部门和时间节点。",
        "活动范围决策": "建议哪些环节自营、外包或放弃，并说明理由。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```
