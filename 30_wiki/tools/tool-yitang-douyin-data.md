# 抖音数据

> 蝉妈妈/飞瓜/抖音指数——追踪抖音生态的达人、商品和内容趋势。

**核心工具**：蝉妈妈（直播带货数据）、飞瓜（快手+B站数据）、抖音指数（搜索热度）。

**用法**：看竞对的抖音号数据（粉丝增长、视频播放、直播GMV）、看品类趋势（什么品类在抖音上快速增长）、看达人合作效果（竞对投了哪些达人）。

**坑**：直播GMV含大量退货，第三方数据平台的GMV通常虚高。参考趋势不参考绝对值。
