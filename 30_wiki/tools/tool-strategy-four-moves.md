# 战略四招法

> **Burn line**: 在高度不确定的市场环境中，企业制胜往往不在于资源多少，而在于选择哪种打法。四招法把复杂战略问题浓缩为四种可识别的行动原型：抢先机、逆共识、打缝隙、换赛道。

## Purpose

帮助战略制定者在业务定位、竞争节奏和资源约束下，快速判断当前最适合的出击方式，避免“什么都想做、什么都做不深”的战略散焦。

## Protocol

### Step 1：判断市场阶段与情绪

| 诊断维度 | 关键问题 | 信号示例 |
|---|---|---|
| 市场阶段 | 行业处于进化周期的哪一阶段？ | 物种爆发期 / 适者生存期 / 成熟期 |
| 市场情绪 | 主流资本和同行是乐观还是悲观？ | 媒体情绪、估值水平、并购活跃度 |
| 竞争空隙 | 领先者是否留下未被防守的细分市场？ | 人群、场景、价格带、渠道空白 |
| 技术底层 | 现有核心技术能否迁移到新需求？ | 技术平台化程度、专利复用性 |

### Step 2：匹配战略招式

| 招式 | 核心逻辑 | 适用条件 | 典型案例 |
|---|---|---|---|
| **小李飞刀**（先发优势） | 在行业进化周期的早期窗口快速占位 | 新物种爆发、规则未定、速度重于完美 | 进入新兴品类或新区域市场的先行者 |
| **分筋错骨手**（逆向投资） | 与市场共识反向而行，在悲观中低价布局 | 市场恐慌、资产错配、长期价值被低估 | 李嘉诚下行周期并购；小熊电器定位年轻单身男性 |
| **葵花点穴手**（细分垄断） | 选对手不防守的点集中突破，形成局部垄断 | 大市场被巨头把持、存在被忽视的细分场景 | 凉白开高考生切入两年 30 亿；一米八八奶粉 0→20 亿 |
| **乾坤大挪移**（底层技术迁移） | 把已验证的核心能力迁移到新赛道存活 | 原赛道衰退、技术/能力可复用、新赛道有需求 | 乐凯胶卷→光学薄膜→新赛道 |

### Step 3：设计执行动作与止损线

1. 为选定招式设定 3-6 个月的关键验证指标（用户增长、市场份额、现金流回正）。
2. 明确“如果验证失败则切换招式”的触发条件，避免路径依赖。
3. 定期复盘招式是否仍然匹配市场阶段，必要时在四招之间切换。

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|---|---|---|
| 企业资源极度有限且没有明确能力标签 | 四招法需要一定的资源或能力基础，空有招式难以落地 | 先用 [[tool-strategy-12-word-test]] 澄清战略定位 |
| 行业处于强监管或政策高度不确定期 | 招式选择容易被政策变化瞬间推翻 | 优先使用 [[tool-strategy-risk-management]] 评估政策风险 |
| 组织内部缺乏快速决策机制 | 四招法强调时机窗口，慢决策会错失先手 | 先优化决策流程和授权机制 |
| 仅用于短期促销或战术动作 | 四招法是战略级选择，不适用于单次营销campaign | 使用促销或增长黑客工具 |

## 质疑

### Internal Limits

1. **具体假设：企业已经具备至少一种可被识别的核心能力或资源禀赋**
   如果企业没有清晰的能力边界，招式选择会变成纸上谈兵。**边界**：本工具更适合成长期或转型期企业，而非初创零起点企业。

2. **边界：四种招式并非互斥，但组合使用容易稀释焦点**
   同时追求“先发”和“逆向”可能导致资源分散。反例：某消费品牌在 2021 年既想抢占新渠道红利（小李飞刀），又想抄底线下资产（分筋错骨手），结果两端都未形成绝对优势。

3. **反例：招式标签化可能掩盖行业特异性**
   同样是“细分垄断”，高考生瓶装水与儿童奶粉的渠道逻辑、监管环境、品牌信任机制完全不同，不能直接照搬。

4. **前提：对市场阶段和情绪的判断必须及时更新**
   四招法的有效性高度依赖诊断输入；如果对市场阶段误判（把衰退期当成逆向布局期），分筋错骨手会变成接飞刀。

### External Attacker

#### **Michael Porter**

**攻击**：战略的核心是选择一个独特的竞争定位并建立可持续的竞争优势，而不是在不同招式之间切换。四招法更像机会主义清单，缺乏对产业结构、进入壁垒和长期定位的系统分析。

**回应**：四招法并非替代定位理论，而是帮助企业在动态环境中快速识别机会窗口。在窗口识别之后，仍需回到产业分析和定位设计，才能形成可持续优势。

### Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|---|---|---|
| 不知道当前该进攻还是防守 | 用四招法扫描市场阶段、情绪、空隙、技术 | 明确匹配到 1 个主招式 |
| 新业务拓展遇到瓶颈 | 检查是否错配了招式（如用先发打成熟市场） | 找到更优招式并设计验证实验 |
| 行业出现重大下行 | 评估是否具备分筋错骨手的逆向条件 | 列出潜在低估资产清单 |
