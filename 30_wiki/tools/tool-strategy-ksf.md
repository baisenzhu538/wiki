# 关键成功因素（KSF）分析工具

> 关键成功因素（Key Success Factors, KSF）是行业内决定企业输赢的 3-5 个核心要素。识别 KSF 后，才能判断自身优势和劣势，制定针对性策略。

---

## 一、KSF 定义

> KSF 是那些对行业成员在市场竞争中成功影响最大的因素——包括战略要素、产品属性、竞争能力、资源或业务成果。

**识别 KSF 的三个问题：**
1. 客户在选择竞争品牌时最看重什么？
2. 企业需要具备哪些资源和能力才能成功竞争？
3. 什么因素能带来可持续竞争优势？

---

## 二、KSF 分析步骤

1. **行业与客户分析**：理解客户选择标准、行业利润池、竞争格局。
2. **头脑风暴候选因素**：列出 10-20 个可能影响成功的因素。
3. **筛选关键少数**：用“结果测试”和“差异测试”筛选至 3-5 个。
4. **对标主要竞争者**：评估自身与竞品的 KSF 表现。
5. **制定策略**：强化优势、弥补劣势、规避不可竞争领域。

## 六、Agent 执行指令

```python
def ksf_analysis(industry: str, competitors: list[str]):
    """分析行业关键成功因素"""
    prompts = {
        "识别": f"分析{industry}中客户选择标准和竞争驱动因素，列出候选 KSF。",
        "筛选": "用结果测试和差异测试筛选出3-5个关键成功因素。",
        "对标": f"将我司与{competitors}在每个 KSF 上评分（1-5）。",
        "策略": "基于差距制定优势强化、劣势弥补、差异化策略。",
        "衔接SWOT": "将 KSF 分析结果转化为 SWOT 的输入。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 七、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| KSF 过多 | 列出十几个“都很重要” | 强制筛选至 3-5 个 |
| 脱离客户 | KSF 是企业内部视角 | 先回答“客户凭什么选你” |
| 评分主观 | 没有数据支撑 | 为每个评分配证据 |
| 策略泛泛 | “加强品牌建设” | 明确具体动作、资源、负责人 |

## 质疑

> 待补充：这个工具的内在局限是什么？外部反对者会怎么批评？

**Richard Rumelt** 可能会质疑：这个工具依赖的 **KSF 时效性、行业差异、因果关系、动态竞争** 是否已经被充分验证？

- 关键成功因素会随行业阶段变化，昨天的 KSF 不一定是明天的 KSF。
- KSF 若只来自成功案例总结，可能忽视幸存者偏差。

- 使用前应明确本工具的 **具体假设**、适用 **边界**、潜在 **反例** 和隐含 **前提**，避免把模板输出直接当成战略结论。
