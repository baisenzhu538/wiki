# 垂直小模型 MVP 五步法

> 本卡属于 `framework-token-economy-three-layer` 的落地子卡——高价值小模型路线（口述者认定普通人可入局的路线）的操作层。

## 一句话

选开源模型 → 选算力 → 一键部署 → **找应用场景（最关键）** → 挂 Hugging Face 收费验证——做不好，再做下一个。

## MVP 五步法（书引+口述者认可）

1. **选开源模型**：千问 / Llama / Kimi 等（含权重开源的拉下来能跑即可）
2. **选算力平台**：云服务（AWS/阿里云等）或下方四途径
3. **一键部署**：vLLM / Hugging Face TGI / Ollama——「部署问题不大，重点是你知不知道有这些东西、去哪找」
4. **找应用场景**：⚠️ MVP 最关键的一步——场景不对，前面全白搭
5. **种子用户验证**：最简路径=模型挂 Hugging Face 标个百万 token 价格，看有没有人付费；有行业合作则直接针对小工厂做

## 低成本拿算力四途径（书引）

1. 云服务（AWS/Azure/谷歌云/阿里云/腾讯/字节）
2. **二手 GPU 市场**（矿场/倒闭 AI 公司收购——很多起手者从此入手）
3. 算力租赁平台（CoreWeave 类——但其 2025 净亏 11.7 亿美元，租赁价≠健康商业，见 framework 卡核验记录）
4. 边缘计算/闲置算力出租

**算力成本优化三关键**：拉高 GPU 使用率 / 降本选型 / **规模化**（硬件拉到 90%+ 24 小时运转摊薄折旧）

## 模型优化五法（知道即可，下场再深学）

模型量化（如 4bit）/ 知识蒸馏（大训小，大厂主流）/ 推理优化（TensorRT-LLM 等）/ MoE 组合架构 / 微调（LoRA）

**边缘部署**（口述者个人看好）：设备放用户附近——成本极低（每百万 token 甚至约 1 元，书引待核）、低延迟、隐私好、可离线。

## 五大变现模式（书引，金额均原书数据待核）

| # | 模式 | 逻辑 | 书引案例（待核） |
|:--|:--|:--|:--|
| 1 | 词元引擎优化 | 帮企业降 token 消耗，省 20-30% 成本 | 电商/内容平台客户 |
| 2 | **垂直词元订阅**（口述者推荐） | 医疗/法律/工业/金融按月按年订阅 | 医疗月 10 万×100 家 |
| 3 | 企业私有化部署 | 一次部署+年度维护 | 一次性 500 万级 |
| 4 | **词元出海**（口述者推荐） | 美元/欧元按量结算，面向全球开发者 | 每百万 token $0.5 起 |
| 5 | 算力打包出租 | 算力+词元打包租生产线 | 月 10 万×百家 |

**垂直定价参考**（⚠️ 原书数据待核，未找到独立来源）：医疗 100 倍于通用（$30/百万）/法律 67 倍（$20）/工业 50 倍（$15）/金融另计——定价权排序：医疗 > 金融 > 法律 > 工业。教育行业书中未列，留作调研作业。

## 操作步骤（组合使用）

1. 按 MVP 五步法跑出最小闭环（Hugging Face 收费验证）
2. 验证成立→选变现模式（优先垂直订阅/出海）
3. 成本侧按四途径+三关键持续压
4. 全程数据合规（见下）

## 判断标准

- Hugging Face 上架有人真金白银付费=场景成立；无人问=换场景不是换模型
- 定价能不能到通用模型 10 倍以上？不能=你的垂直深度不够

## 失败模式

- **先技术后场景**：模型调优三个月没找用户——MVP 第四步才是灵魂。修复：场景+种子用户前置
- **数据版权踩坑**：公开可见≠可训练≠可商用——GitHub 数据看协议：MIT/Apache 宽松可商用（遵守声明义务），**GPL 强制开源，闭源商业项目千万别碰**（口述者补充，L208-224）
- **低成本幻觉**：学 MiniMax 打价格战——极致低成本是大公司游戏（口述者批判层）
- **只看书中定价表下注**：垂直定价均为原书转述未独立核实——下场前自己做一轮目标行业定价调研

## When NOT to Use

- 无垂直行业数据/场景积累的纯技术团队——先做概念验证别碰重资产
- 期望「搭好生产线躺赚」——模型要迭代、运维要投入（口述者批判：还是要拼时间）
