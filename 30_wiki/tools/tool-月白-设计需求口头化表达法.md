# 技能：设计需求口头化表达法

## 原始表述

设计需求口头化表达法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 在动手做图前，先用口语完整描述设计需求（'口喷'）
2. 确保脑中所想与口头表达同步，检验需求清晰度
3. 将口语表达转化为AI可执行的精准文字提示词
4. 通过'说出来'的过程，完成从'向AI许愿'到'指挥AI执行'的思维转变
