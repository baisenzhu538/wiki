# 决策深度L2：部分定量

## 一句话定义

L2是对**关键参数做粗略估算**——不追求精确，但要把"感觉"变成"大概数" [conf=0.80, source=一堂方法论]。

## 与L1的区别

| | L1 定性 | L2 部分定量 |
|:---|:---|:---|
| 收益 | "这个能赚钱" | "大概赚 50-100 万/年" |
| 成本 | "成本不高" | "一次性投入~30万，月运营~5万" |
| 概率 | "大概率能成" | "我觉得成功概率大约 60%" |

## 操作步骤

1. 对L1筛出的方案，列出**最关键的3个数字**（通常是：最大投入、最乐观收益、最可能收益）
2. 每个数字标注：数字来源（拍脑袋/问过行家/看过数据）+ 置信度
3. 用乐观值做「证伪」——如果连乐观假设下都跑不通 → 放弃

## 边界

L2的数字精度不够做最终决策。但它可以帮你砍掉乐观假设下都不成立的项目。
