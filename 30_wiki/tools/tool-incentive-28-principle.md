# 奖励设计28原则

> 20%总部定战略方向+80%团队自主设计。不是"给钱就行"——是"给对的钱"。

## 操作步骤

1. 总部定20%：战略方向（如"今年重点是拉新"）+ 奖励池上限
2. 团队定80%：在业务范围内自主设计奖励规则
3. 每月review：只看结果（拉新数/留存率），不审规则
4. 季度调整：根据数据调整20%的战略方向

## 适用边界

- 有多个独立业务单元的组织（代理体系/区域团队/门店网络）
- 结果可量化、可对比
- 不适用：单一团队、结果难以量化

## 失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 总部管太细 | 80%形同虚设，团队等总部批 | 总部只定方向不定规则 |
| 只奖不罚 | 激励变成大锅饭 | 28原则隐含"达不成目标=0奖励" |

## When NOT to Use

- 团队只有1-2个人，不需要复杂的激励分层
- 结果无法量化，奖励设计失去客观基础
