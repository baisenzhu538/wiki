# 阿里铁军聆听三七法则执行卡

## 一句话

销售沟通不是「说得越多越好」，而是让客户充分表达；阿里铁军的聆听纪律主张销售说 30%、客户说 70%，并把销售说话时间不超过 50% 作为硬上限，用结构化聆听挖掘真实需求 `[conf=0.85, source=00_inbox/销售专题/_processed/销售有工具-阿里铁军的三七法则_vlm.md:L5-L27]`。

## 目的

把「多听少说」从抽象建议变成可自检、可训练、可复盘的执行标准，帮助销售在需求挖掘阶段减少打断、降低预设立场，通过客户语言发现真实痛点和购买动机 `[conf=0.85, source=00_inbox/销售专题/李蕊-销售系统之五-销售工具箱-口述.txt:L1488-L1524]`。

## When to Use

- 顾问式销售、复杂产品方案销售，需要深度理解客户需求。
- 销售团队普遍存在「急着推销、打断客户、自说自话」的问题。
- 新人销售不知道如何通过提问和沉默让客户开口。
- 希望通过录音/对话分析提升销售沟通质量。
- 需求挖掘阶段客户说得少、销售说得多，导致方案不匹配。

## When NOT to Use （不要用的场景）

- **产品演示/技术说明会**：销售需要在短时间内高密度输出信息，强行套用 70/30 会拖累信息传递效率。
- **客户明确要求「直接告诉我答案」的低接触购买**：过度聆听可能被客户视为不专业或拖延。
- **文化/场景不适于长时间沉默**：某些商务文化偏好直接、简洁，机械 silence 会造成尴尬。
- **销售还处于产品知识严重不足阶段**：听不懂客户所说，再多听也难以转化为有效需求。
- **把「客户说得少」简单归因于销售话多**：可能是客户没需求、时间紧、或信任未建立。

## 操作步骤

### Step 1：理解目标比例与硬上限

根据李蕊课堂对阿里铁军培训资料的转述 `[conf=0.85, source=00_inbox/销售专题/_processed/销售有工具-阿里铁军的三七法则_vlm.md:L5-L27]`：

- **目标比例**：客户说 70%，销售说 30%。
- **硬上限**：销售说话时间不得超过 50%。超过 50% 视为违反聆听纪律。

> 上述比例是**课程经验值**，用于训练目标和自检参考，不是绝对科学定律。

### Step 2：掌握六大聆听技巧

源自阿里铁军培训资料的课程经验，六项技巧如下 `[conf=0.85, source=00_inbox/销售专题/_processed/销售有工具-阿里铁军的三七法则_vlm.md:L5-L27]`：

| 技巧 | 操作要点 | 反面行为 |
|:---|:---|:---|
| **目光接触** | 注视客户眉心区域，营造专注氛围 | 低头看手机、眼神游离 |
| **全神贯注** | 放下手机、关闭通知，把注意力放在客户身上 | 中途接电话、回消息 |
| **做笔记** | 记录关键信息、承诺和待确认点 | 凭记忆，事后遗忘或失真 |
| **控制时间比例** | 销售说话 ≤50%，引导客户多说 | 销售独白、客户插不上话 |
| **不轻易打断** | 让客户把意思表达完整后再回应 | 抢话、预判断、急着给方案 |
| **不预设立场** | 从客户角度理解问题，而不是急着证明自己正确 | 有成见、听一半就反驳 |

### Step 3：区分阶段差异化比例

课程经验值：不同销售阶段对「听/说」比例的要求不同 `[conf=0.85, source=00_inbox/销售专题/_processed/销售有工具-阿里铁军的三七法则_vlm.md:L5-L27]`：

| 阶段 | 建议销售说话占比 | 核心任务 | 原因 |
|:---|:---|:---|:---|
| **需求挖掘/初步接触** | ≤30% | 提问、澄清、确认 | 充分了解客户背景、痛点、决策链 |
| **方案呈现/产品演示** | 40%–50%（硬上限内） | 结构化输出价值、回应疑问 | 既要传递信息，也要留出确认和反馈空间 |
| **谈判/关单** | 30%–40% | 确认条件、处理异议、推动下一步 | 避免说多错多，让客户表达顾虑 |
| **售后/履约回访** | 20%–30% | 倾听使用反馈、识别增购/复购信号 | 客户说得越多，越能发现新机会 |

> 课程主张：**50% 是销售说话比例的硬上限**，任何阶段都不应突破；复杂方案呈现阶段可在上限内灵活调整。

### Step 4：使用录音自检表

每次重要通话/会议后可对照以下自检表复盘：

| 检查项 | 是/否 | 改进动作 |
|:---|:---|:---|
| 销售说话时间是否 ≤50%？ | | 若超时，标记哪些话可删减或转成提问 |
| 是否出现过 3 次以上打断客户？ | | 练习在客户停顿 3 秒后再回应 |
| 是否记录了客户原话中的 3 个关键痛点？ | | 把痛点写入客户画像 |
| 是否因为预设立场而反驳或跳过客户观点？ | | 写下客户观点，事后验证 |
| 是否在适当时机用开放式问题引导客户深入？ | | 准备 3 个本场景下的开放问题 |
| 是否确认了客户的决策人和购买紧迫度？ | | 在下次沟通中补充确认 |

（录音分析涉及隐私，需获得客户或内部合规授权。）

## 示例

**场景**：To B SaaS 需求访谈。

> **销售**：「张总，您刚才提到销售团队扩到 40 人后业绩波动很大，能具体说说波动主要来自新人流失还是老客复购吗？」（开放问题，让客户说）
>
> **客户**：「主要是新人三个月内流失，老员工又不愿意带。」
>
> **销售**：「新人三个月流失，对您的 Pipeline 影响有多大？有没有算过招一个新人到独立成单的成本？」（继续引导，不急于给方案）

**复盘**：本次访谈销售说话约 25%，客户说话约 75%，记录了 3 个关键痛点，没有打断。符合聆听三七法则。

## Critique

### 外部反对者

1. **复杂方案销售/售前派**：B2B 复杂产品需要销售做大量解释和演示，硬卡 50% 会让方案讲不透，反而降低专业感。
   - **回应**：50% 是硬上限而非目标；方案呈现阶段可在 30%–50% 之间灵活调整，关键是留出反馈空间，避免独角戏。

2. **行为经济学派**：说话时间比例不等于聆听质量。销售可能在「沉默」时想着下一步怎么推销，表面在听，实际没在听。
   - **回应**：时间比例是可量化的纪律起点，不是终点；需配合全神贯注、做笔记、不预设立场等行为指标共同评估。

3. **高语境沟通/跨文化销售派**：在某些文化或客户群体中，过多让客户说会被视为缺乏主见；客户更期待销售直接给结论。
   - **回应**：比例是训练参考，不是行为准则；销售应根据客户风格、沟通阶段和文化背景动态调整，同时保持「先理解再表达」的原则。

4. **AI 语音分析厂商**：现代工具可以实时监测说话占比，销售会被监控压力驱动，导致机械追求比例而忽视沟通效果。
   - **回应**：工具应作为复盘反馈而非实时评分；把比例与成单结果、客户满意度关联，避免为指标而指标。

### 内部局限

1. **难以精确测量自然对话中的占比**：真实销售对话常有重叠、笑声、简短确认词，简单计时可能失真。
2. **对高知识密度产品适应性有限**：技术参数、合规条款、实施方案等内容必须销售主导输出，强行让客户多说会浪费时间。
3. **销售个人风格差异**：有些销售天然话少，再压比例可能导致冷场；需要结合性格和场景训练。
4. **不解决「听不懂」问题**：如果销售缺乏行业知识或提问能力，客户说得再多也无法转化为有效需求。

## Synthesis

- 本卡是 [[framework-yitang-scientific-sales-five-step]] 中「拆解过程」与「推进业绩」的微观执行纪律，帮助把「接触/购买决策」中的客户需求显化。
- 与 [[tool-yitang-sales-process-decomposition]] 的关系：需求挖掘阶段的高质量输入，直接决定后续里程碑和动作设计的准确性。
- 与 [[tool-opc-sales-dialogue-assistant]] 的关系：对话助手可在分析客户对话时，用本卡的 50% 硬上限做自检，提示销售是否说得过多。
- 与 [[opc-ai-sales-agent-architecture]] 的关系：聆听纪律可嵌入「客户意图识别智能体」和「销售复盘智能体」，作为对话质量评估维度。
- 与 [[dk-yitang-sales-common-pitfalls]] 的关系：对抗「过程黑盒」「卖点五花八门」背后的「不听客户说」问题。
- 与 [[tool-yitang-sales-toolkit-radar]] 的关系：聆听能力属于「销售有能力」维度的 75 分进阶训练内容。
