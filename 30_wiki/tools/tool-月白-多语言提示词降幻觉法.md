# 技能：多语言提示词降幻觉法

## 原始表述

多语言提示词降幻觉法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 撰写基础中文提示词
2. 识别关键概念和核心名词
3. 在关键词后附加英文
4. 如涉及特定文化元素，附加意大利语等第三语言
5. 保持提示词结构清晰，多语言部分用括号标注
6. 生成后检查关键元素是否准确
