# 合作方案数据

> 以合作名义拿到竞对的渠道政策、分成比例、促销方案——这些是公开渠道永远不会出现的数字。

**做法**：以"我们也在考虑和你们合作"的身份，向竞对的合作方（经销商/供应商/服务商）索要合作方案和报价。

**价值**：合作方案里包含利润分配、返点政策、促销支持力度——这些数据直接暴露竞对的渠道策略和利润空间。

**坑**：合作方可能给的是"最高版本"（对外的报价而非真实成交价）。需要找2-3家交叉验证。
