# 裁判文书检索

> 裁判文书网——被严重低估的商业情报源。法律纠纷中暴露的信息远超新闻稿。

**检索维度**：
- 知识产权纠纷→竞对侵犯了谁的专利/技术被谁抄袭
- 合同纠纷→竞对跟谁有矛盾、欠谁的钱
- 劳动仲裁→竞对的员工关系和离职率信号
- 产品质量诉讼→竞对产品的真实缺陷

**价值**：法院文书里的事实陈述比PR稿诚实100倍。

**坑**：不是所有纠纷都会走到诉讼；文书可能经过脱敏处理。
