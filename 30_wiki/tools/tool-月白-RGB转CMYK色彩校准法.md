# 技能：RGB转CMYK色彩校准法

## 原始表述

RGB转CMYK色彩校准法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 确认输出需求为印刷实物时，将文件导入设计软件（PS/AI等）
2. 转换色彩模式为CMYK
3. 观察转换后的变灰效果
4. 手动调整曲线和饱和度曲线，尽量还原预期色彩
5. 必要时使用潘通色卡（预算充足时）

## 为什么有效

RGB为发光色（屏幕光点），CMYK为油墨反射色，原理差异导致巨大色差；提前转换并手动校准是避免印刷翻车的唯一途径
