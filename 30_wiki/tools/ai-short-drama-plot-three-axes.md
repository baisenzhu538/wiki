# 剧情三板斧：短剧剧本的情节张力设计工具

> **Burn line**: 有锋芒、聚目光、升高度——三斧子砍出爆款味。

## 用一句话讲清楚

剧情三板斧是短剧策划阶段的情节张力自检工具：先让主角与对手形成不可调和的**极致对立**，再用强冲突/悬念/情绪完成**高能吸睛**开场，最后让结局落在一个观众能共鸣的**价值立意**上。

剧情三板斧是冰火写本罗盘中"剧情元素"维度的核心工具，用于在剧本策划阶段快速检查剧情张力。三斧分别是：**极致对立（有锋芒）、高能吸睛（聚目光）、立意升华（升高度）**。它解决的是"剧情有没有爆款感"的问题，而非"剧情是否完整"的问题。

## 核心要点

- **三斧是检查维度，不是写作公式**：它们帮你判断剧情是否具备冲突锋芒、开场吸引力和结局价值感，但不能替代人物弧光与细节打磨。
- **顺序不能颠倒**：先立对立，再设计吸睛场面，最后收束到立意；没有对立支撑的钩子会变成碎片爽点，没有立意的爽剧容易"爽完就忘"。
- **每斧都要能回答一个关键问题**：对立——是否有不可调和的根本冲突？吸睛——前3秒/前10秒是否有强钩子？升华——结局价值是否从主角选择中自然生长？
- **AI 可执行检查，但立意需人判断**：AI 能按模板输出三斧清单，"共鸣"是否真实必须靠创作者和测试观众验证。

## Claims

- **C1 [conf=0.9]**: 剧情三板斧是短剧剧本的"爆款感"自检工具，三斧分别对应：冲突张力、开场吸引力、结局价值感。
- **C2 [conf=0.9]**: 极致对立要求设计"有锋芒"的核心矛盾——身份、立场、价值观至少有一处根本对立。
- **C3 [conf=0.85]**: 高能吸睛聚焦前 3 秒/前 10 秒，必须用强冲突、强悬念或强情绪抓住观众。
- **C4 [conf=0.85]**: 立意升华不是道德说教，而是让观众在爽完之后获得情绪价值或社会共鸣。
- **C5 [conf=0.8]**: 三斧有先后顺序：先立对立，再设计吸睛场面，最后收束到立意，不能颠倒。
- **C6 [conf=0.75]**: 该工具可转化为 AI prompt 模板，用于检查或生成剧情大纲。

## Purpose

帮助短剧创作者在策划阶段快速诊断剧情张力，确保剧本同时具备：**冲突锋芒、开场吸引力和结局价值感**。适用于已有初步创意但不确定是否够"爆款"的场景。

---

## Protocol

### 步骤 1：极致对立 — 检查冲突锋芒

1. 列出主角、核心对手、第三方的身份、立场、价值观。
2. 标出至少一处"不可调和"的根本对立。
3. 确认该对立贯穿全剧，而非只出现在某几集。

### 步骤 2：高能吸睛 — 检查开场吸引力

1. 打开第一集剧本，只看前 10 秒。
2. 判断前 3 秒是否出现以下至少一种元素：危机、悬念、强情绪、强冲突。
3. 如果没有，重写开场，直到"让人不想划走"。

### 步骤 3：立意升华 — 检查结局价值感

1. 写出结局的一句话价值主张。
2. 追问：这个价值是否从主角的选择中自然生长出来？
3. 去掉口号式结尾，确保观众爽完后还能产生共鸣。

### AI 使用方式

将以上三步转化为 prompt：

```
请基于"剧情三板斧"检查以下短剧大纲：
1. 找出主角与对手的根本对立点
2. 评估第一集前10秒是否高能
3. 提炼结局的价值主张
输出：问题清单 + 优化建议
```

## When NOT to Use

| 场景 | 为什么失效 | 替代方案 |
|------|-----------|---------|
| **温情治愈类短剧** | 强对立和强吸睛会破坏温情氛围。 | 使用"情绪曲线"和"关系递进"工具替代。 |
| **品牌定制短剧** | 品牌需要传递正面形象，过度锋芒可能损害品牌调性。 | 使用"品牌价值映射表"，弱化对立、强化共鸣。 |
| **儿童/教育类短剧** | 高能冲突和复仇式立意不适合未成年人。 | 使用"成长型冲突"框架，强调学习、友谊、勇气。 |
| **台词打磨阶段** | 三斧是策划层工具，不解决具体台词问题。 | 使用"台词张力检查清单"或"视听语言优化表"。 |

## 边界

| 边界 | 说明 |
|------|------|
| **适用题材** | 强冲突型题材（逆袭、甜宠、复仇、悬疑）效果最好，治愈、日常、文艺类可能不适用。 |
| **使用阶段** | 主要用于大纲和分集策划阶段，而非台词打磨阶段。 |
| **三斧缺一不可** | 仅有极致对立会变成纯爽文，仅有高能吸睛会变成短视频合集，仅有立意升华会变成说教片。 |
| **不是万能公式** | 三斧提供检查维度，但不能保证爆款，还需平台适配、制作质量、投放时机配合。 |
| **AI 使用边界** | AI 可以按模板生成三斧，但"立意升华"的真实共鸣需要人判断。 |

## 失败模式

| 失败模式 | 典型症状 | 根因 | 修复动作 |
|---------|---------|------|---------|
| **假对立** | 主角与对手只是误会，和解后剧情坍塌 | 把"可调和矛盾"当成"不可调和对立" | 把身份、立场、价值观中的至少一处升级为根本冲突 |
| **钩子悬空** | 前3秒很炸，第2集后热度骤降 | 高能开场与核心对立没有绑定 | 让开场危机成为主线的"引线"，在中点、反转、结局持续回收 |
| **口号式升华** | 结局旁白强行点题，观众无感 | 价值主张不是从主角付出代价后的选择中长出 | 把价值点嵌入主角的"最后选择"，用动作和代价代替说教 |
| **三斧失衡** | 剧本爽点密集但口碑差 | 过度追求高能，忽视人物成长与价值落点 | 每新增一个爽点前追问：它是否服务于对立升级或立意表达？ |
| **题材错配** | 治愈/品牌短剧显得"戾气重" | 在不适合强冲突的题材强行套用三斧 | 改用情绪曲线、品牌价值映射或成长型冲突工具 |

## [Critique]

### 内部局限性

- "高能吸睛"过度强调前 3 秒，可能导致后续剧情为了维持刺激而牺牲人物成长逻辑。
- "立意升华"容易被执行成口号式结尾，而非真正从人物选择中自然生长出的价值。
- 三个维度偏男性向/爽文向，对细腻情感类短剧的覆盖不足。

### 外部攻击：Georges Polti — "36 种情境已穷尽冲突"

**Georges Polti**（《三十六种戏剧模式》作者，常被译为乔治·普罗蒂）会认为：人类戏剧冲突早已被归纳为 36 种基本情境。"极致对立"一斧如果仅停留在"身份/立场/价值观"三个标签上，容易让 AI 生成的是模式化的冲突外壳，而非真正新鲜的戏剧关系。

### 外部攻击：Robert McKee — "虚假冲突"风险

**Robert McKee**（《故事》作者，常被译为罗伯特·麦基）会批评：过度追求"高能吸睛"会导致"虚假冲突"（false conflict）——为了吸睛而制造不必要的戏剧化，破坏故事的真实性和人物可信度。

### 反事实测试

- 如果去掉"立意升华"，只用前两斧，剧本能否过稿？能，但大概率是低单价、低口碑的纯爽剧。
- 如果只有"立意升华"没有前二斧，会怎样？观众根本看不到第三集，立意无从传递。
