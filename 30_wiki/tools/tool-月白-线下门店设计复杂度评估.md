# 技能：线下门店设计复杂度评估

## 原始表述

线下门店设计复杂度评估是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 测量门店面积（30平/300平等）
2. 评估门店类型：单点小店/连锁多店/旗舰店
3. 确定设计触点数量：橱窗、吊旗、货架贴、促销挂牌等
4. 面积越小越简化，可能仅需海报；面积越大越复杂，需完整橱窗+动线设计
5. 按复杂度分配设计资源
