# 技能：辩证讨论法

## 原始表述
> L5.辩证讨论 √讨论案例：拆解和讨论案例使用 √讨论理论：讨论理论的内核和边界

## 操作步骤
1. 组织案例拆解和讨论
2. 讨论理论的内核适用边界
3. 在讨论中检验和修正理解

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 学习理论后检验适用性，避免教条主义 |
| ✅ 适合 | 需要提升批判性思维，暴露假设盲区 |
| ✅ 适合 | 团队决策前，需要多视角碰撞 |
| ✅ 适合 | 案例复盘时，需要区分内核与边界 |
| ❌ 不适合 | 基础事实学习阶段 → 无假设可检验 |
| ❌ 不适合 | 时间紧迫的紧急决策 → 讨论成本过高 |
| ❌ 不适合 | 团队缺乏心理安全感 → 讨论变成附和 |
| ❌ 不适合 | 只有附和没有反对 → 认知同温层无效 |

#| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **讨论变辩论** | 目标是证明我对，不是看看我们对不对 | 辩证讨论的核心是检验假设，不是赢得争论。先明确'我要检验的假设是什么' |
| **认知同温层** | 只和自己水平相当的人讨论，大家拥有相同的信息和偏见 | 必须引入异见者，讨论的价值在分歧不在附和。没有反对意见的讨论是互相确认 |
| **讨论完不记录** | 两小时深度对话后，靠记忆存档 | 讨论的产出必须是一页纸：我们达成了什么+分歧在哪+下一步验证什么 |
| **边界回避** | 只讨论案例适用性，不讨论理论在什么条件下失效 | 理论边界讨论比案例讨论更有价值。必须问'这个理论在什么条件下失效' |
| **无产出讨论** | 讨论得很热闹但结束后发现什么都没记录下来 | 讨论必须有结论、分歧记录、下一步动作。没有产出的讨论只是社交 |
| **立场固化** | 讨论前已有固定立场，讨论只为寻找支持证据 | 讨论前必须写下'如果我的假设错了，我会看到什么证据'，预设证伪条件 |
| **情绪污染** | 讨论中人身攻击，观点之争变成立场之争 | 设定规则：攻击观点不攻击人，讨论的是'什么对'不是'谁对' |
| **深度不足** | 讨论停留在表面，没有触及底层假设 | 用'五个为什么'追问，直到找到不可再分的底层假设 |

## 判断标准

**什么算一次有效的辩证讨论**：

| 标准 | 好的讨论 | 坏的讨论 |
|:---|:---|:---|
| 有假设可检验 | 讨论前已知"我要通过讨论检验哪个具体假设" | 随便找个话题就开始——讨论完没有结论，也没有修正任何认知 |
| 分歧被记录 | 讨论结束后知道"我们达成了什么 + 分歧在哪" | 讨论得很热闹但结束后发现"什么都没记录下来" |
| 有下一步动作 | 讨论产出了"下一轮验证什么"的行动计划 | 讨论完就结束，没有验证，没有迭代 |
| 异见安全 | 团队中有人敢说"这个我不认同"，而且讨论的是观点不是立场 | 只有附和没有反对，讨论变成了互相确认 |

**自检问题**：
1. 这次讨论前，我能用一句话说清楚"我想检验的假设是什么"吗？
2. 讨论结束后，我有什么判断被修正了？（如果完全没有，这次讨论可能只是社交）
3. 如果换一个反对这个观点的人加入讨论，他会觉得公平吗？
4. 讨论的产出能写成一页纸吗？（结论 + 分歧 + 下一步验证）

**Amy Edmondson**（哈佛商学院教授）会质疑：工具的价值不在于"有没有"，而在于"用得好不好"。任何工具都是"能力放大器"——如果使用者的判断力不足，工具只会放大错误。真正的风险不是"缺少工具"，而是"有了工具后产生的虚假安全感"——让你以为自己已经覆盖了所有可能性，实际上只是走完了流程。
