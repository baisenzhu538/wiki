# 技能：产品白底图标准化制作

## 原始表述

产品白底图标准化制作是月白在文创案例中提出的实操方法。

## 操作步骤

1. 拍摄产品清晰照片
2. 使用AI工具生成纯白背景图
3. 确保输出六面视图：正面、背面、左面、右面、上面、下面
4. 建立白底图素材库供团队复用
