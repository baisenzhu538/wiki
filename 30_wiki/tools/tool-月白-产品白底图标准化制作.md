# 技能：产品白底图标准化制作

## 原始表述

产品白底图标准化制作是月白在文创案例中提出的实操方法。

## 操作步骤

1. 拍摄产品清晰照片
2. 使用AI工具生成纯白背景图
3. 确保输出六面视图：正面、背面、左面、右面、上面、下面
4. 建立白底图素材库供团队复用

## 适用场景

- 电商公司有产品需要设计时
- 建立设计素材体系时
- 团队协作需要统一素材标准时

## 不适用场景

- 人像类设计项目
- 纯抽象概念设计
- 已有完整3D模型可直接渲染时

## 工具/环境

- AI抠图/背景移除工具
- 产品摄影设备
- 图像处理软件

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

白底图不完整导致每次做图都需重新拍摄后期，前置素材标准化可让后续设计效率提升70%基础分
