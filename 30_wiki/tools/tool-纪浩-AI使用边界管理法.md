---# 技能：AI使用边界管理法

- **纪浩体系**：[[concept-ji-hao-ai-collaboration-methodology]] — 纪浩 AI 协作方法论总纲

## 原始表述

AI使用边界管理法是纪浩在AI协作方法论分享中提出的具体方法，用于AI使用边界管理法。

## 操作步骤

1. 每天限定AI使用时长（如3-4小时）
2. 把AI当worker时只用于降本增效
3. 把AI当教练时让它设计A+1梯度问题
4. 保留自己动脑、动手、有体感的环节
5. 定期反思哪些事AI搞不定时自己能搞定

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 感觉过度依赖AI，需要建立使用边界 |
| ✅ 适合 | 学习记忆不深、决策印象模糊，需要保留手动环节 |
| ✅ 适合 | 希望保持手感和判断力，防止能力退化 |
| ✅ 适合 | 需要平衡效率与深度学习，AI辅助但不替代 |
| ❌ 不适合 | 任务完全机械重复无需学习 → 全力用AI降本增效 |
| ❌ 不适合 | 紧急任务需要全力赶工 → 优先效率，事后复盘 |
| ❌ 不适合 | 纯创意发散阶段 → 不需要边界，尽情探索 |
| ❌ 不适合 | AI作为教练设计学习路径时 → 边界会限制学习效果 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **过度依赖** | 每天使用AI超过8小时，几乎所有工作都交给AI | 每天限定AI使用时长（如3-4小时）。把AI当worker时只用于降本增效，保留自己动脑动手的环节 |
| **认知外包** | 学习后记忆不深，决策印象模糊，无法独立判断 | 把AI当教练时让它设计A+1梯度问题。保留自己动脑、动手、有体感的环节 |
| **能力萎缩** | AI搞不定的事情自己也搞不定，能力退化 | 定期反思哪些事AI搞不定时自己能搞定。专门留出AI不能碰的区域，不是因为AI做不好，而是因为做了你会退化 |
| **应急依赖** | 紧急任务全力用AI赶工，之后不复盘 | 紧急任务可以用AI，但事后必须复盘：哪些环节本可以自己完成？下次如何减少应急依赖？ |
| **手感丧失** | 用AI代替所有练习，从不手写代码或手动操作 | 学习的本质是摩擦和必要难度。必须保留手动操作环节，AI辅助但不能替代 |
| **边界僵化** | 机械执行时长限制，忽视任务实际需求 | 边界是指导原则不是 rigid 规则。高价值任务可以突破边界，但必须有意识决策 |
| **反思缺失** | 设定了边界但从不检查执行效果 | 每周Review AI使用日志，评估边界是否合理。边界需要动态调整 |
| **全有全无** | 要么完全依赖AI，要么完全不用AI | 区分worker模式（降本增效）和coach模式（学习提升）。不同模式不同边界 |

## 为什么有效

学习的本质是摩擦和必要难度，人让AI变强不会自动让人变强，必须自己参与挑战才能形成深层记忆和判断力。
