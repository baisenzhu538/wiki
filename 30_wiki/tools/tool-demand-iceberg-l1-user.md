# L1粗拆用户标签

> 不能只看"职场人"这种大标签。要深入到身心状态、特别时刻和空间环境。三维拆解缩小切口。

## 三维拆解

| 维度 | 问题 | 示例 |
|:---|:---|:---|
| **人群** | 谁在经历这个问题？ | 不是"宝妈"——是"产后6个月内+重返职场+一线城市的宝妈" |
| **时刻** | 在什么特别时刻？ | 不是"想点外卖"——是"加班到23点+饿了但不想吃油腻的" |
| **空间** | 在什么环境里？ | 不是"在家办公"——是"合租房+室友睡觉了+不能出声" |

## Agent执行指令

```python
# 引自 AI场景推演教练 Step 1
prompt = """基于以下创业想法，主动提供3个最可能的"目标用户群+场景+痛点"组合选项。

[IDEA]

要求：
- 每个组合配一个真实用户画像（姓名+年龄+职业+一句话痛点）
- 标注每个组合的"最可能替代方案"（他们现在怎么解决）
- 从3个组合中选出"最值得深挖的1个"并说明原因
- 如果3个组合都不满意，要求AI再生成3个不同维度的
"""
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 标签太宽 | "目标用户是年轻人"——几亿人 | 加限定条件直到<100万人 |
| 只拆一维 | 只说了人群没说场景 | 补全"时刻"和"空间"维度 |

## 适用边界

- **适用**：创业项目0-1阶段，需要快速锁定第一批目标用户
- **不适用**：成熟产品已有清晰的用户画像和分群数据

## 质疑

- **具体假设**：该工具假设"三维拆解（人群+时刻+空间）能精确定位目标用户"，但三维拆解可能导致"过度细分"——当用户群被切分到"产后 6 个月+重返职场+一线城市的宝妈"时，市场规模可能已经小到无法支撑一个商业模式。
- **边界**：在 B2B 场景中，"人群+时刻+空间"的三维框架不够用——B2B 需要增加"决策角色"和"预算周期"两个维度才能有效拆解。
- **前提**：该工具的前提是"标签越细 = 洞察越深"，但精细标签可能只是"描述性精确"而非"预测性精确"——知道用户是"产后 6 个月的宝妈"不能预测她是否会购买你的产品。

**Tony Ulwick**（Strategyn 创始人，JTBD 理论先驱，《What Customers Want》作者）会质疑：用户标签的本质是"把人分类"，但 JTBD 理论的核心洞察是"用户不是在购买产品，而是在'雇佣'产品来完成某个任务"。按"人群属性"拆分用户是错的——应该按"待办任务"拆分。两个完全不同的人群（退休老人和大学生）可能有完全相同的待办任务（如"快速记笔记"），而把他们分到不同的用户群只会让产品策略更加碎片化。
