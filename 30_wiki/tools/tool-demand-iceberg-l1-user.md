# L1粗拆用户标签

> 不能只看"职场人"这种大标签。要深入到身心状态、特别时刻和空间环境。三维拆解缩小切口。

## 三维拆解

| 维度 | 问题 | 示例 |
|:---|:---|:---|
| **人群** | 谁在经历这个问题？ | 不是"宝妈"——是"产后6个月内+重返职场+一线城市的宝妈" |
| **时刻** | 在什么特别时刻？ | 不是"想点外卖"——是"加班到23点+饿了但不想吃油腻的" |
| **空间** | 在什么环境里？ | 不是"在家办公"——是"合租房+室友睡觉了+不能出声" |

## Agent执行指令

```python
# 引自 AI场景推演教练 Step 1
prompt = """基于以下创业想法，主动提供3个最可能的"目标用户群+场景+痛点"组合选项。

[IDEA]

要求：
- 不能只用大标签（如"职场人""宝妈"）
- 必须深入到身心状态、特别时刻和空间环境
- 每个选项包含：谁/什么时候/在哪/什么问题
- 让我选择其一或微调
"""
```

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 标签太宽 | "目标用户是年轻人"——几亿人 | 加限定条件直到<100万人 |
| 只拆一维 | 只说了人群没说场景 | 补全"时刻"和"空间"维度 |

## 适用边界

- **适用**：需求分析第一步——在你还不确定"谁是我的用户"时
- **不适用**：已有明确用户画像和数据的产品优化
