# 技能：电商场景图三类构建法

## 原始表述

电商场景图三类构建法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 判断产品适合的场景类型：使用场景/氛围场景/故事场景
2. 使用场景：展示产品正在被使用的瞬间（如手持杯子喝水）
3. 氛围场景：将产品置于美好状态传递生活方式（如杯子放在绿野上）
4. 故事场景：构建微型故事剧融入产品（如情人节递水场景）
5. 通过主体+周围小玩意搭配+氛围营造激发情感共鸣
