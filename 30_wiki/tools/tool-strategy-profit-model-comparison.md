# 盈利模式对比框架

> 冉鹏 PPT _117——四种盈利模式的全维度对比。业务设计六要素第 3 要素"价值获取"的操作工具。

## 四种模式

| 模式 | 经营权 | 管控权 | 代表品牌 | 适合 |
|:--|:--|:--|:--|:--|
| **直营** | 公司全资 | 强管控 | 屈臣氏/麦当劳 | 品牌一致性要求高 |
| **强类直营** | 加盟商出资+公司强管控 | 强管控 | 海澜之家 | 轻资产+品控 |
| **弱类直营** | 加盟商出资+弱管控 | 弱管控 | 大东/唐三彩 | 快速铺量 |
| **代理加盟** | 代理商独立运营 | 最弱 | 娇兰佳人/植物医生 | 低成本扩张 |

## 全维度对比（PPT _117 原表结构）

| 维度 | 子维度 | 直营 | 强类直营 | 弱类直营 | 代理加盟 |
|:--|:--|:--|:--|:--|:--|
| **场** | 店铺归属 | 公司 | 加盟商 | 加盟商 | 代理商 |
| | 招聘 | 公司 | 公司/加盟商 | 加盟商 | 代理商 |
| **货** | 培训 | 公司统一 | 公司强管控 | 基础培训 | 代理商自行 |
| | 绩效管理 | 公司统一 | 公司制定标准 | 加盟商自主 | 代理商自主 |
| | 品类规划 | 公司统一 | 公司主导 | 加盟商参与 | 代理商主导 |
| | 定价 | 公司统一定价 | 公司指导价 | 加盟商定价 | 代理商定价 |
| | 货品所有权 | 公司 | 加盟商 | 加盟商 | 代理商 |
| | 现金流 | 公司 | 加盟商 | 加盟商 | 代理商 |
| **管理控制** | 督导 | 分公司强督导 | 分公司督导 | 弱督导 | 无 |
| | 成本 | 高 | 中 | 低 | 最低 |
| | 收益 | 全收 | 分成 | 分成 | 固定费用 |
| | 风险 | 全担 | 共担 | 加盟商担 | 代理商担 |
| **优势** | 品控/体验一致 | 品控好/资产轻 | 扩张快/成本低 | 最轻/最快 |

## 决策矩阵

| 你的需求 | 推荐模式 | 原因 |
|:--|:--|:--|
| 品牌一致性 > 扩张速度 | 直营 | 管控最强，体验一致 |
| 想轻资产但保持品控 | 强类直营 | 加盟商出资+你管控标准 |
| 快速铺量抢占市场 | 弱类直营 | 低门槛吸引加盟商 |
| 最低成本试水新市场 | 代理加盟 | 最低投入，最快铺开 |

## Agent 执行指令

```python
def profit_model_selector(requirements: dict):
    """基于冉鹏四模式对比框架推荐盈利模式"""
    factors = {
        "品牌控制需求": requirements.get("brand_control", 5),
        "资金充裕度": requirements.get("capital", 5),
        "扩张速度需求": requirements.get("speed", 5),
        "管理能力": requirements.get("management", 5),
    }
    # 直营: 高品牌控制 + 高资金 + 强管理
    if factors["品牌控制需求"] >= 4 and factors["资金充裕度"] >= 4:
        return "直营", "屈臣氏/麦当劳模式——品控最好，体验最一致"
    # 强类直营: 高品牌控制 + 低资金
    elif factors["品牌控制需求"] >= 4 and factors["资金充裕度"] <= 3:
        return "强类直营", "海澜之家模式——加盟商出资，你管控标准"
    # 代理加盟: 低资金 + 高速度 + 低管理
    elif factors["资金充裕度"] <= 3 and factors["扩张速度需求"] >= 4:
        return "代理加盟", "娇兰佳人模式——最低成本试水"
    else:
        return "弱类直营", "大东/唐三彩模式——平衡扩张和品控"
```

## 失败模式

| 失败 | 症状 | 案例 |
|:--|:--|:--|
| 模式与品牌定位不匹配 | 选了代理加盟但品牌定位高端→代理商乱价 | 奢侈品用代理加盟=品牌自杀 |
| 管控跟不上扩张 | 选了弱类直营但总部没有督导能力→品控崩塌 | 加盟商各自为政 |
| 资金错配 | 选了直营但资金只够开 3 家店→规模上不去 | 直营烧钱但回本慢 |
