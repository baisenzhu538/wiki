# 技能：视频转化关键要素标注校验

## 原始表述

视频转化关键要素标注校验是马易在AI落地场景识别中提出的实操方法。

## 操作步骤

1. 提出影响播放量/转化率的关键要素假设（如颜色、时长、开头3秒）
2. 设计对照实验通过投流分发不同版本
3. 收集数据对比各要素对结果的影响
4. 迭代验证找到关键驱动因子
5. 将验证后的要素固化为生产标准
