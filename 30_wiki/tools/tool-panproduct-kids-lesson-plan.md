# K12泛产品设计完整教案：四步法+技能卡+四级作业+提示词模板

> 一句话：家长或老师拿到这份教案，不用备课、不用改——直接带孩子走完「从设计班徽到迁移到海报/盲盒/课本剧」的完整泛产品设计学习旅程。

---

## 适用场景

- 课堂教学：小学4-6年级或初中1-2年级，1-2课时
- 亲子共学：家长带孩子一起做，约90分钟
- 夏令营/社团活动：作为AI×设计主题工作坊

---

## 课前准备

| 准备项 | 内容 | 说明 |
|:---|:---|:---|
| AI工具 | 豆包/即梦AI/LibTV/GPT image/Midjourney（任意1个即可） | 提前注册好账号，确保孩子可以直接用 |
| 材料 | 纸+笔（前三步不用电脑）、投影设备（展示参考设计用） | 前三步不碰AI |
| 热身故事 | LEO班徽翻车故事（见`[[case-cui-lei-kids-ai-design-class]]`） | 开场5分钟讲，孩子立刻理解「为什么不能第一步就用AI」 |
| 技能卡打印 | 9张技能卡名称+一句话描述 | 可选但推荐——孩子们当「装备卡」握在手里 |

---

## 四步法教学流程

### 第一步：明确任务（约20分钟）——不碰AI

**目标**：回答「我们班是谁」和「班徽给谁看、在哪用」。

**核心原则**：这一步一定不碰AI，先碰人。不要打开任何AI工具。

**使用技能卡**：①换位读心 ②魔法沙盘 ③寻宝之镐 ④万象罗盘

**操作步骤**：

1. **换位读心**（3分钟）——让孩子闭上眼，想象自己不是自己，是站在校门口第一次看到这个班徽的隔壁班同学。「你觉得这个班徽代表一个什么样的班级？」

2. **魔法沙盘**（5分钟）——用金句模板填空：
   > （谁）在（什么情况下）遇到了（什么样问题）？
   > 
   > 例如：全班同学和老师在运动会上，运动员入场时引导员举的班徽、同学们在看台上加油用的手持班徽、同学们衣服上佩戴的徽章——需要醒目、好看、代表班级的特点。

3. **寻宝之镐**（7分钟）——从四个维度挖出班级特质：
   - 性格：热闹、勇敢、幽默……
   - 能力：运动强、画画强、表达强……
   - 氛围：团结、互助、敢挑战……
   - 愿望：更自律、更像一个团队……
   
   填空句式：「我们班最重要的特点是___，___」

4. **万象罗盘**（5分钟）——先加法（把所有人的想法都收进来，不否定任何人），再减法（从中挑出「全班都点头」的1-2个核心特点）

> **第一步结束后的产出物**：一张纸上写着——班级核心特质（1-2个）+ 使用场景 + 目标受众。

---

### 第二步：看齐高手（约15分钟）——还是不碰AI

**目标**：建立「好班徽」的审美标准。

**核心原则**：没有标准就打开AI = AI画出什么你只能凭感觉判断。

**使用技能卡**：⑤收集秘籍 ⑥鉴宝之眼 ⑦最美设想

**操作步骤**：

1. **收集秘籍**（10分钟）——用投影或iPad给孩子展示优秀徽章设计（校徽/纪念章/社团徽章等），至少看5-10个。关键操作：
   - 不要只是浏览——让孩子说出「这个好在哪」
   - 按风格分类：简约/复杂/卡通/传统

2. **鉴宝之眼**（3分钟）——教孩子用四个维度给每个作品打分：
   - 辨识度（一眼认出是哪个班）
   - 代表性（代表了群体特质）
   - 简洁度（缩小到头像还清楚）
   - 美感（颜色搭配和构图）

3. **最美设想**（2分钟）——让孩子闭上眼想象：「最完美的班徽做出来之后，贴在校服上多神气，运动会上举着牌子进场多有气势。」把这画面在脑子里演一遍。

> **第二步结束后的产出物**：孩子能说出「好的班徽长什么样」——至少有2-3条评判标准。

---

### 第三步：多出几招（约20分钟）——AI首次登场

**目标**：用AI出3版草稿，投票选方向。

**核心原则**：AI不是第一步是最后一步——前三步的答案全部装进提示词。

**使用技能卡**：⑧神兵宝库

**操作步骤**：

1. **写提示词**（5分钟）——用以下模板：
   > 给[班级]设计一个班徽，使用场景是[场景A]和[场景B]。班级关键词是「[特点1]，[特点2]」，所以要体现[元素]方面的元素。需要三个风格的班徽。

   示例：
   > 给五一班设计一个班徽，使用场景是运动会入场仪式手举牌子和校服胸前佩戴的徽章。班级关键词是「脑洞大，爱创新」，所以要体现活力和灵感方面的元素。需要三个风格的班徽。

2. **AI生成**（5分钟）——把提示词输入AI工具，等3版草稿出来。

3. **投票选方向**（10分钟）——至少找3位同学或家人投票。明确规则：不是投「最好看」的那个，而是投「最能代表我们班」的那个。
   - 投票时可以让孩子解释「为什么投这个」
   - 引导孩子注意：投票结果是对「方向」的选择，不是最终稿

> **第三步结束后的产出物**：3版AI草稿 + 投票结果标记（选出1个方向继续打磨）。

---

### 第四步：打磨通关（约20分钟）——AI辅助迭代

**目标**：一轮一轮改到全班都认。

**核心原则**：打磨不是改一版就完事——是加法-减法-验证的循环。每加一个元素就问一句「还是我们班吗」。

**使用技能卡**：⑨初心结界

**操作步骤**：

1. **加法**——在选定的草稿基础上，根据反馈添加元素（如颜色太暗加亮度、缺少文字加上字）。

2. **减法**——每加一个元素就问：「还是我们班吗？」不是就砍。初心结界——锁住班徽的「魂儿」（第一步挖出的核心特质）。

3. **验证**——两个硬性测试：
   - 缩小测试：缩到微信头像大小看——还清楚吗？
   - 实物测试：贴在真实校服上看、缩小到手举牌看——别只在电脑上看大图自我陶醉。

4. **重复**——加-减-验证循环，直到全班（或至少3人投票）都说「我要的就是这个」。

> **第四步结束后的产出物**：最终版班徽。

## 四级作业体系

### 必做（基础）——当天完成

用四步法给自己的班级/小组做一枚班徽，填完《AI班徽产品设计卡》：
1. 班徽给谁看？
2. 出现在哪里？
3. 3个班级关键词
4. 一句设计假设（「如果班徽包含___元素，大家会觉得这代表我们班」）
5. AI生成/手绘 2-3个草图方向
6. 找至少3位同学或家人投票
7. 根据反馈改一版

### 选做（迁移）——一周内

把班徽方法迁移成一张「班级活动海报」。
关键问题：「谁看完这张海报，要去做什么？」

### 挑战（迁移）——两周内

采访一位家人/朋友「你喜欢什么」，用调研思维为TA做一份小设计（礼物/卡片/封面）。

关键问题：把「班级特质」替换成「个人特质」——四步法完全通用。

### 作品集（高阶）——持续

准备在社区跳蚤市场上卖的吧唧（徽章/小周边），走完整四步法：
1. 用户调研（谁会在跳蚤市场买吧唧？他们喜欢什么风格？）
2. 设计创意（确定主题和元素）
3. AI草图1/2/3（出3版供选择）
4. 投票和反馈（找同学或家人投）
5. 修改前后对比（记录从草图到成品的迭代过程）
6. 确定方案（最终成品）

## 迁移表

同一套四步法+9张技能卡可以迁移到以下K12场景：

| 产品类型 | 关键问题 | 适用技能卡 |
|:---|:---|:---|
| 活动海报 | 谁看完这张海报，要去做什么？ | 换位读心/魔法沙盘/最美设想 |
| 跳蚤市场盲盒 | 花小钱买惊喜，拆开不亏 | 寻宝之镐/万象罗盘/初心结界 |
| 课本剧 | 把课文演活，观众看得懂又觉得有意思 | 换位读心/魔法沙盘/鉴宝之眼 |
| 校园角落改造提案 | 给学校负责人看，要可行/安全/有教育意义 | 魔法沙盘/寻宝之镐/初心结界 |
| 礼物设计 | 收礼物的人喜欢什么？TA收到什么反应？ | 换位读心/最美设想/初心结界 |
| PPT/小组展示 | 观众不知道背景，怎么让他们5分钟看懂？ | 魔法沙盘/鉴宝之眼/神兵宝库 |

**万能第一问**：「这东西，是给谁、希望TA怎么反应？」——这一句话就是泛产品设计的全部。

## 提示词模板

### 班徽设计（通用）
```
给[班级]设计一个班徽，使用场景是[场景A]和[场景B]。班级关键词是「[特点1]，[特点2]」，所以要体现[元素]方面的元素。需要三个风格的班徽。
```

### 活动海报
```
给[活动]设计一张海报，张贴在[地点]，目标是让[受众]看到后[行动]。风格参考[灵感来源]。需要两个版本。
```

### 小周边（吧唧/钥匙扣等）
```
设计一组[物品]的图案，目标受众是[受众]，他们的偏好是[偏好]。风格：[描述]。需要3个不同方向的方案。
```

## When NOT to Use

| 不当使用 | 后果 | 正确做法 |
|:---|:---|:---|
| 1-3年级低龄儿童 | 四步法需要抽象思维和文字表达，可能过难 | 简化两步（明确任务→多出几招），减少文字增加画画和贴纸 |
| 没有AI工具访问权限 | 第三步无法执行 | 把AI生成替换为手绘草图——四步法框架不变，工具适配 |
| 时间不充裕（<45分钟） | 赶流程导致每步都走马观花 | 分两次课：第一次走第一步和第二步，第二次走第三第四步 |
| 用本教案替代方法论理解 | 家长/老师只照做但不知道为什么这样做 | 先读 `[[bridge-panproduct-kids-translation]]` 理解翻译机制再执行 |

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 第一步没做完就跳到AI | 孩子还没说清「我们班是谁」，AI已经出图了——结果和LEO一样翻车 | 前三步步骤强制分阶段——第一步做完检查产出物（纸上有班级特质+场景），没做完不碰AI |
| 投票时只让孩子投「最好看」 | 票投给了最炫但不是最能代表的那个 | 把投票问题从「你最喜欢哪个」改成「哪个最能代表我们班」 |
| 验证只在大屏幕上看 | 自认为好看但实际应用时看不清 | 强制实物测试——缩到头像大小、贴在真实校服上看 |
| 做完班徽就结束 | 方法学到手但只会在班徽上用 | 引导孩子至少做一个选做/挑战作业（海报/礼物/课本剧），体验迁移 |
| 忘记记录迭代过程 | 最后只有成品没有过程，学不到方法论 | 要求孩子拍/保存至少2版草稿+1版最终稿，对比着写一句「改了什么、为什么」 |
