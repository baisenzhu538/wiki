# 一堂七大转化场景自检：流量 / 一对多 / 一对一 / 门店 / LTV / 运营节点 / 组织提升

> **一句话**：转化率工作不只发生在成交环节，把公司遇到的各种转化率问题"合并同类项"后，常见的转化场景主要有七个——流量转化、一对多销售、一对一说服、门店销售、用户生命周期/LTV、产品/运营节点、组织内部提升。（`入门篇-口述:954-970`, `组合篇-口述:1172-1176`）

---

## Purpose

解决"团队只盯着销售环节做转化"的狭隘视角问题。提供一张自检清单，帮助团队盘点业务中所有存在转化潜力的环节，找到优化切入点。

适用场景：
- 年度/季度增长规划
- 新业务上线前梳理转化地图
- 团队对齐：让非销售部门也看见自己的转化责任

---

## Protocol

### 七大场景清单

| 序号 | 场景 | 入门篇表述 | 组合篇表述 | 典型转化问题 |
|---|---|---|---|---|
| 1 | **流量转化** | 流量转化场景 | 流量相关的转化 | 访客→线索、点击→注册、曝光→互动 |
| 2 | **一对多销售** | 一对多的集体销售 | 一对多的集体销售 | 直播、会销、群发售、公开课 |
| 3 | **一对一说服** | 一对一的重点说服工作 | 一对一的关键说服 | 销售跟进、大客户谈判、私域 1v1 |
| 4 | **门店销售** | 门店销售场景 | 门店场景的 | 到店转化、陈列、导购话术 |
| 5 | **用户生命周期 / LTV** | LTV 的运营 | 用户生命周期场景的 | 复购、续费、升单、流失挽回 |
| 6 | **产品 / 运营节点** | 产品运营的节点 | 运营场景的 | 注册、激活、留存、关键功能使用 |
| 7 | **组织内部提升** | 组织各种提升 | 组织内部管理场景的 | 内部会议效率、跨部门协作、员工动员 |

> "基于内部细节梳理就是你们一共有七大主要的场景，都是有各种各样的转化。分别有……流量相关的转化，一对多的集体销售，一对一的关键说服，门店场景的，用户生命周期场景的，运营场景的，组织内部管理场景的。这些其实背后都是有大量的转化工作。"（`入门篇-口述:954`, `组合篇-口述:1174-1176`）

### 自检步骤

1. **列出公司所有"希望用户从 A 状态到 B 状态"的环节**：不限于成交。
2. **把环节归入七大场景**：每个环节只归一类，若跨场景拆成子环节。
3. **评估每个场景的转化效率**：当前转化率、环比变化、与行业/目标差距。
4. **选择 1-3 个优先级最高的场景**：考虑频率、增量空间、资源投入。
5. **用 D 域工具拆解**：
   - 动力侧：`[[tool-一堂-FAB说服法]]`、`[[tool-一堂-名利权情动力法]]`、`[[tool-一堂-影响力六原则]]`
   - 阻力侧：`[[tool-一堂-阻力挖掘方式]]`、`[[tool-一堂-阻力消除12策小抄]]`、`[[tool-一堂-阻力三句话心法]]`

### 输出格式

```
场景：__________
当前环节：__________ → __________
当前转化率：__________
主要动力：__________
主要阻力：__________
优先消除手段：动嘴 / 动手 / 动钱
负责人：__________
预期效果：__________
```

## Anti-patterns

| 反模式 | 症状 | 修复 |
|---|---|---|
| **只盯着销售场景** | 把所有转化工作都压给销售团队 | 用七大场景盘点全公司转化工作 |
| **把"转化"狭隘理解为成交** | 忽略流量、LTV、组织内部等场景 | 重新定义"转化 = 用户状态的改变" |
| **七大场景平均用力** | 每个场景都设 KPI，资源分散 | 按频率和增量空间选 1-3 个优先级 |
| **场景归属错误** | 把门店销售当成一对一说服 | 按触达形式和用户规模归类 |

---

## When NOT to Use

- 公司只有单一转化场景时：七大场景自检会显得过度复杂。
- 团队尚未建立基础转化率意识时：先用动力阻力分析打透一个场景，再扩展。
- 把'场景'当政绩清单而非优化抓手时：清单会变成表格功夫。

## Critique


**Clayton Christensen**（哈佛商学院教授）会质疑：现有方法论框架的有效性依赖于环境稳定性——当环境发生颠覆性变化时，旧框架不仅无效，还可能误导。
- 容易平均用力：七大场景都想优化，反而资源分散，没有单点突破。
- 场景边界不易切分：很多业务环节同时属于多个场景，归类争议会消耗团队精力。
- 清单不等于行动：列出场景后若缺乏后续优先级排序，会停留在'我们都知道'的阶段。

## 案例区：七大场景自检

本卡为清单式工具，无具体口述案例。使用时可结合公司实际业务，把每个场景下的具体环节填入输出格式，形成本公司的"转化地图"。

### 示例：一堂自身

| 场景 | 一堂典型环节 |
|---|---|
| 流量转化 | 公众号/短视频→体验课注册 |
| 一对多销售 | 直播公开课→正价课转化 |
| 一对一说服 | 学习顾问 1v1 跟进 |
| 门店销售 | 线下活动/开放日 |
| LTV | 续费、升单、老带新 |
| 运营节点 | 体验课完课→正价课转化 |
| 组织内部 | 内部培训、团队动员 |
