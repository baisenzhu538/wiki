# 武器库策略6：前员工人脉网络

> 通过人脉链找到曾在目标公司工作过的人——朋友的朋友、前同事的前同事。

## 六个找法

| # | 方法 |
|:---:|:---|
| 1 | 通过朋友介绍认识目标公司的前员工 |
| 2 | 在脉脉/LinkedIn搜索"曾在XX公司"的人 |
| 3 | 利用人脉库/微信人脉查找 |
| 4 | 找曾在目标公司工作的同行 |
| 5 | 主动联系——说明来意，请教行业问题 |
| 6 | 整理完整的信息分析图——标记每个人的角色和信息可信度 |
