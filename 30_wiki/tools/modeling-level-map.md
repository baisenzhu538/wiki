# 建模能力段位图：从 L1 到 L6 的十年爬山地图

> **Burn line**: 建模能力不是天赋，是可以按段位逐步修炼的十年爬山路。

建模能力段位图是楚门在一堂建模培训中提出的**自我诊断与修炼路径工具**。它将建模能力划分为 L1 到 L6 六个段位，横轴为「入门—进阶—高阶」三大阶段，纵轴为每个段位的核心特征、能力表现和提升路径。该工具解决的是「我不知道自己建模能力在什么水平，也不知道下一步练什么」的问题。

---

## Visual Analysis

原图为一张矩阵式信息图，标题为「一堂建模高手·十年爬山地图 / How to Become a Modeling Master within 10 Years」。

- **横向三列**：入门、进阶、高阶
- **纵向六行（L1-L6）**：
  - L1 缺少意识 → 只靠经验 → 不太在乎
  - L2 追求建模 → 追求复利 → 缺少见识
  - L3 流程建模 → 清单/SOP → 及时复盘 → 知行合一
  - L4 抽象建模 → 武器库强 → 场景广泛 → 稳定使用
  - L5 本质提炼 → 提炼本质 → 精准匹配 → 分层自洽
  - L6 持续创新 → 跨界建模 → 无限迭代 → 形成品牌
- **底部提升路径**：
  - 开始见识提升（天单位）
  - 开始实操提升（月单位）
  - 开始迁移创新（年单位）

视觉结构强调：**段位越高，所需时间越长，越依赖复利积累**。

## Purpose

帮助个人或团队快速判断当前建模能力段位，明确下一阶段的核心修炼方向，避免在低段位盲目追求高阶模型。

---

## Protocol

### 步骤 1：逐条自评

对照下表，为每个段位特征打分（0-10 分）：

| 段位 | 核心特征 | 自评问题 |
|---|---|---|
| L1 | 缺少意识 | 我是否主动总结过规律？ |
| L2 | 追求建模 | 我是否渴望把经验变成方法？ |
| L3 | 流程建模 | 我能否为高频任务写出可执行的 SOP？ |
| L4 | 抽象建模 | 我是否有 3-5 个可跨场景调用的模型？ |
| L5 | 本质提炼 | 我能否用 1-4 个关键词概括一个领域？ |
| L6 | 持续创新 | 我能否跨领域建模并形成自己的方法论品牌？ |

### 步骤 2：确定当前段位

- 找到**第一个得分低于 6 分**的段位，即为当前瓶颈。
- 该段位的前一段即为「已稳定段位」。

### 步骤 3：制定提升计划

- 若卡在 L1-L2：每天阅读/见识一个模型，建立建模意识。
- 若卡在 L3：选择一个高频任务，输出 SOP 并稳定执行 1 个月。
- 若卡在 L4：收集 10+ 同类案例，提炼一个抽象模型。
- 若卡在 L5：选择一个战略课题，用本质公式推导 3 个策略。
- 若卡在 L6：选择 2 个跨界领域，尝试建立连接模型。

## When NOT to Use

| 场景 | 为什么失效 | 替代方案 |
|---|---|---|
| **完全无建模意愿的人** | 段位图是修炼地图，不是说服工具。 | 先用具体案例展示建模价值，激发意愿。 |
| **评估他人作为绩效考核** | 段位主观性强，容易引发争议。 | 改为评估具体产出物（SOP、模型、本质公式）。 |
| **急于求成（期望几周登顶）** | 段位提升以月/年为单位。 | 设定 6-12 个月的具体里程碑。 |

---

## Constraints & Boundaries

| 边界 | 说明 |
|------|------|
| **自评主观性** | 段位图用于自我诊断，不建议作为绝对标准。 |
| **领域差异** | 不同领域的建模深度不同，跨领域比较需谨慎。 |
| **时间标签** | 「十年爬山」是比喻，实际周期因人而异。 |
| **AI 辅助** | AI 可加速 L3-L4，但 L5-L6 仍需人类深度思考。 |

## [Critique]

### 内部局限性

- 段位标签（L1-L6）是教学化的简化，实际能力成长是非线性的。
- 每个段位的自评标准较模糊，不同人理解可能差异很大。
- 段位图强调「高阶更好」，但未讨论「够用即可」的场景。

### 外部攻击：Benjamin Bloom — "认知目标分类不等于能力成长路径"

**Benjamin Bloom**（教育心理学家，Bloom 分类法提出者）会认为：把能力拆成 L1-L6 段位有助于教学，但真实能力发展是螺旋上升的，而非线性爬阶。段位图如果变成「打怪升级」的心态，可能让人忽视深度思考和反思。

### 反事实测试

- 如果一个人 L3 很强但 L4 很弱，会怎样？执行能力优秀，但难以迁移和创新，容易成为「高级执行者」。
- 如果一个人直接跳到 L5 本质提炼但 L3 不稳，会怎样？容易提出空洞的「本质」，无法落地。
