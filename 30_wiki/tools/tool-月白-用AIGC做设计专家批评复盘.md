# 技能：用AIGC做设计专家批评复盘

## 原始表述

用AIGC做设计专家批评复盘是月白在文创案例中提出的实操方法。

## 操作步骤

1. 将自己的设计稿和设计要求一起输入AIGC
2. 使用提示词：'以一个严厉的有多年经验的设计专家，严苛评价这个海报哪里有问题'
3. 要求AI指出具体问题点
4. 进一步要求AI给出调整方案
5. 基于自身专业能力判断调整方案是否合适

## 适用场景

- 自己看不出设计问题
- 找不到人帮忙审稿
- 需要突破个人审美/能力上限
- 运营海报、社群海报、直播预告等设计场景

## 不适用场景

- 完全没有设计基础无法判断AI方案质量
- 需要高精度品牌级设计输出
- 涉及复杂印刷工艺需人工把控

## 工具/环境

- AIGC工具（豆包/GPT/Claude等）

## 常见失败模式

- 步骤跳过或省略 → 结果不完整 → **严格按步骤执行**
- 未确认场景是否匹配 → 方法失效 → **先对照"适用场景"确认**

## 为什么有效

AI不受个人能力上限限制，可以模拟专家视角做严苛点评；本质是用AI替代'找专家访谈'的环节，实现低成本复盘
