# 技能：用AIGC做设计专家批评复盘

## 原始表述

用AIGC做设计专家批评复盘是月白在文创案例中提出的实操方法。

## 操作步骤

1. 将自己的设计稿和设计要求一起输入AIGC
2. 使用提示词：'以一个严厉的有多年经验的设计专家，严苛评价这个海报哪里有问题'
3. 要求AI指出具体问题点
4. 进一步要求AI给出调整方案
5. 基于自身专业能力判断调整方案是否合适
