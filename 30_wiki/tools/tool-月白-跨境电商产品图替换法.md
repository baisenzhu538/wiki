# 技能：跨境电商产品图替换法

## 原始表述

跨境电商产品图替换法是月白在AI设计师实操中提出的实操方法。

## 操作步骤

1. 准备两张图：场景图（图一）和产品白底图（图二）
2. 明确描述图一中要被替换的物体：位置+外观特征
3. 明确描述图二中要替换成的物体：位置+外观特征
4. 指令格式：'将图一中【女人手中的逗猫棒】改成【图二中的红色精品绿色棍子产品】'
5. 检查是否有同类物体歧义，必要时加限定词区分
