# 战略控制点设计工具：价值定位模型

> 业务设计六要素第 5 要素。核心问题：**我们如何建立并守住持续竞争优势？护城河在哪里？**

---

## 一、价值定位三角

PPT `_124` 提出三种基本战略定位，企业必须选择并拥有一席之地：

```
              客户亲密
             /    \
            /      \
           /        \
    成本领先 ———— 产品卓越
```

| 定位 | 核心逻辑 | 适合场景 |
|--|--|--|
| **客户亲密** | 比对手更懂客户，建立深度关系与信任 | 服务差异化、高转换成本、B2B 长期合作 |
| **成本领先** | 以更低的成本提供可接受的价值 | 标准化产品、规模经济、价格敏感市场 |
| **产品卓越** | 在产品性能、创新、设计上领先 | 技术驱动、快速迭代、品牌溢价 |

---

## 二、战略控制点清单

### 2.1 按价值定位匹配控制点

| 价值定位 | 典型战略控制点 | 具体抓手 |
|--|--|--|
| **产品卓越** | 标准/专利拥有权 | 专利池、行业标准、技术壁垒 |
| | 产品开发 | 研发pipeline、快速迭代能力 |
| | 协同创新平台 | 开放生态、开发者社区、产学研联盟 |
| **成本领先** | 供应商战略合作关系 | 长期协议、股权绑定、联合采购 |
| | 整合供应链 | 垂直整合、物流网络、数字化供应链 |
| | 成本控制 | 规模经济、流程优化、自动化 |
| **客户亲密** | 客户关系 | 会员体系、私域流量、客户成功团队 |
| | 企业形象 | 品牌认知、ESG、社会责任 |
| | 政府关系 | 牌照、政策支持、公共事务 |

### 2.2 通用控制点类型

| 类型 | 说明 | 示例 |
|--|--|--|
| 网络效应 | 用户越多，价值越大 | 社交平台、交易平台 |
| 转换成本 | 客户离开代价高 | SaaS、企业软件 |
| 规模经济 | 成本随规模下降 | 制造、物流、云计算 |
| 品牌溢价 | 情感认同与信任 | 奢侈品、消费品 |
| 数据资产 | 独有数据形成反馈闭环 | 推荐系统、风控模型 |
| 牌照/标准 | 政策或行业准入壁垒 | 金融、医疗、通信 |

---

## 三、控制点评估矩阵

```markdown
| 潜在控制点 | 价值定位匹配 | 建设难度 | 可防御性 | 可持续性 | 优先级 |
|--|--|--|--|--|--|
| 例：会员数据闭环 | 客户亲密 | 中 | 高 | 高 | P0 |
| 例：专利组合 | 产品卓越 | 高 | 高 | 中 | P1 |
| 例：供应链整合 | 成本领先 | 高 | 中 | 高 | P1 |
```

## 四、Agent 执行指令

```python
def design_control_points(value_proposition: str, chosen_position: str):
    """设计战略控制点"""
    assert chosen_position in ["客户亲密", "成本领先", "产品卓越"]
    prompts = {
        "定位确认": f"""确认我们的价值定位是「{chosen_position}」：
价值主张「{value_proposition}」是否支撑这一定位？""",
        "控制点清单": f"""针对「{chosen_position}」，从标准清单中选出3-5个潜在战略控制点，
并说明每个控制点如何支撑价值主张。""",
        "评估矩阵": "用‘建设难度、可防御性、可持续性’三维度评估，排出优先级。",
        "建设计划": "为Top 3控制点制定12个月内的关键举措和里程碑。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 定位模糊 | 同时想“客户亲密+成本领先+产品卓越” | 三选一为主，其余两个做到不落后即可 |
| 控制点与价值脱节 | 护城河不能保护核心利润 | 控制点必须直接保护价值主张和收入来源 |
| 过度依赖单一控制点 | 只有品牌，没有数据/供应链 | 构建2-3个相互加强的控制点组合 |
| 静态护城河 | 过去有效，现在失效 | 每年评估控制点的可防御性和可持续性 |
