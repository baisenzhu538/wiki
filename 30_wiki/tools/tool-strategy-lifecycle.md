# 企业生命周期战略：从 0 到 1、从 N 到 ∞、从 N 到 0

> 企业不同阶段的核心任务、陷阱、战略重点和决策方式完全不同。用生命周期视角做战略，才能避免“用成熟企业的方法做初创”或“用初创的方法做转型”。

---

## 一、五阶段生命周期

| 阶段 | 状态 | 核心任务 | 战略奥义 | 核心产出 | 谁拍板 |
|--|--|--|--|--|--|
| **谋生：0~1 验证期** | 验证“宝贝”是否真有人要并愿意掏钱 | 拼命试错，快速学习 | 前两步（五步法） | 被初步验证的 MVP 和第一批忠实用户 | 结构化共创 + 创始人果断拍板 |
| **吃饱：1~N 扩张期** | 放大赚钱小模型，让收入稳定增长 | 优化模型，跑通飞轮 | 增长路径和商业模式 | 可复制的、效率持续提升的“增长飞轮” | 先民主，后集中；创始人最终拍板 |
| **吃好：N~∞ 壁垒期** | 扩大领先，修护城河，找第二曲线 | 构建优势，布局生态 | 竞争壁垒和新增长点 | 清晰品牌定位、差异化策略、第二曲线种子 | 由战略流程决定；对抗创始人路径依赖 |
| **吃撑：N→N' 转型期** | 业务转型、商业模式蜕变 | 敢于自我否定：边赛车边换引擎 | 重走五步法 | 转型作战计划 | 创始人/CEO 亲自领导 |
| **吃吐：N→0 存亡期** | 生存判断 > 现金流 > 核心保全 > 退出/重启 | 快速决断，体面收场 | 无可对应内容 | 企业重组方案、退市计划、资产处置表 | 绝对权威独裁（创始人或 turnaround 专家） |

---

## 二、各阶段陷阱

| 阶段 | 典型陷阱 |
|--|--|
| 0~1 | 闭门造车做功能、自嗨、什么都想做 |
| 1~N | 产品没打磨好就猛砸钱扩张、管理跟不上增长、忽略成本控制 |
| N~∞ | 躺在功劳簿上、对市场变化反应迟钝、组织僵化 |
| N→N' | 只换人/改组织不动业务；盲目多元化；押注一个超级大项目一把梭；用加班和 KPI 硬顶旧增长；舍不得砍历史包袱 |
| N→0 | 把退出当失败，忽视退出窗口期，最终失控崩盘；退出方式极端导致信誉受损 |

---

## 三、阶段战略内容模板

| 阶段 | 一页纸战略内容 |
|--|--|
| 0~1 | 我们假设 XX 人群有 XX 痛点，准备用 XX 方案试试，关键看他们是否愿意付 XX 钱。 |
| 1~N | 已验证 A 市场，计划通过 X 渠道、Y 策略，将核心指标从 A 提升到 B，需投入 Z 资源。 |
| N~∞ | 未来 3~5 年在 XX 领域构建以（品牌/技术/网络效应）为核心的壁垒，同时探索 A/B 方向新机会。 |
| N→N' | 原增长引擎在？时间内见顶：①？个月止血；②？个月重构；③？个月换引擎。 |
| N→0 | ①核心业务能否在现金流耗尽前重回正轨；②变革/降本/裁撤；③债权人/供应商谈判；④团队稳定。 |

---

## 四、使用步骤

1. **判断当前阶段**：根据收入、增长、组织复杂度、竞争态势判断。
2. **识别阶段陷阱**：对照各阶段典型陷阱做自检。
3. **明确核心任务**：本阶段最重要的 1-3 件事是什么？
4. **选择战略方法**：不同阶段用不同工具（0~1 用 MVP，1~N 用增长飞轮，N~∞ 用业务设计+控制点，N→N' 重走五步法）。
5. **确定决策方式**：不同阶段需要不同的决策机制和拍板人。

## 五、Agent 执行指令

```python
def lifecycle_strategy(company_stage: str, context: str):
    """基于生命周期阶段制定战略"""
    assert company_stage in ["0~1", "1~N", "N~∞", "N→N'", "N→0"]
    prompts = {
        "诊断": f"基于「{context}」，确认企业处于{company_stage}阶段。",
        "陷阱": "列出本阶段最可能陷入的陷阱。",
        "核心任务": "明确本阶段最重要的1-3个核心任务。",
        "战略内容": "用一页纸模板输出战略内容。",
        "决策机制": "明确本阶段合适的决策方式和拍板人。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 阶段误判 | 初创企业学大厂做长期规划 | 按阶段选择工具和节奏 |
| 方法错配 | 用增长期方法做转型 | 转型期必须重走五步法 |
| 忽视决策机制 | N→0 还追求共识 | 不同阶段匹配不同决策方式 |
| 阶段跃迁无序 | 没验证就扩张 | 必须跑通上一阶段再进入下一阶段 |

> 待补充：这个工具的内在局限是什么？外部反对者会怎么批评？

**Richard Rumelt** 可能会质疑：这个工具依赖的 **生命周期阶段判断、S 曲线、技术 disrupt、阶段边界模糊** 是否已经被充分验证？

- 生命周期阶段边界模糊，误判阶段会导致战略错位。
- 新技术可能让成熟产品重新进入增长，生命周期曲线并非单行道。

- 使用前应明确本工具的 **具体假设**、适用 **边界**、潜在 **反例** 和隐含 **前提**，避免把模板输出直接当成战略结论。
