# 招募用户访谈

> 公开招募目标用户参与访谈——用激励换取深度信息。

**做法**：在目标用户聚集的渠道（微信群/小红书/知乎）发布招募帖，说明访谈目的、时长、报酬。筛选符合画像的用户，预约一对一深访。

**激励设计**：现金红包（最直接）、产品试用、行业报告分享、优先体验权。

**坑**：来的人可能不是你的目标用户——设置筛选问卷过滤。给钱太多招来"职业受访者"。
