# AI草写报告：用AI生成调研初稿

> 用AI生成调研报告的初稿框架——人定结构，AI填内容，人做最终判断。

---

## Purpose

AI草写报告解决的是"从0到1写调研报告太慢"的问题。它的目标不是替代人写报告，而是把最耗时的初稿搭建、资料整理、文字填充环节交给AI，让人把精力集中在结构判断、数据核证和洞察提炼上。适用于行业综述、竞品扫描、市场初探、政策梳理等需要快速产出可读稿的场景。

---

## Protocol

1. **人定骨架**：先由人明确报告目标、读者、核心问题、章节结构和每节必须回答的要点，必要时给出模板或示例段落。
2. **AI填肉**：把骨架、背景资料、关键数据、参考链接喂给AI，让它按章节逐段生成初稿；对每一章都要求它标注信息来源。
3. **逐条核验**：人对AI生成的数据、引用、结论做溯源；凡找不到出处或来源可疑的内容，必须删除或重写。
4. **修正偏差**：识别AI的过度解读、因果混淆、样本偏差，把"AI推测"改写成"人判断"或明确标注不确定性。
5. **人定终稿**：整合多轮输出，补充人工洞察，统一语言风格，输出最终报告。

---

## When NOT to Use

| 场景 | 原因 | 替代方案 |
|:---|:---|:---|
| 需要直接对外发布的正式研报 | AI可能产生幻觉、措辞不严谨，未经核实的输出会损害专业信誉 | 人工撰写或使用AI仅生成素材清单 |
| 数据精度要求高的投资决策 | AI会编造看似权威的数据和来源，错误数据可能导致错误决策 | 使用`tool-yitang-stock-data`、`tool-yitang-financial-report-intelligence`等专门工具做一手数据采集 |
| 涉及机密或敏感商业信息 | 上传机密内容到第三方AI服务存在泄露风险 | 本地模型或人工处理 |
| 研究者对领域几乎不了解 | 人无法判断AI输出质量，AI会放大盲区 | 先用人脑做一轮信息扫描和假设梳理 |
| 需要强烈观点立场或创新洞察的报告 | AI倾向于平庸、折中的表达，缺乏真正的批判性 | 人工主导写作，AI只做语法润色 |

## 质疑

- **具体假设**：本工具假设"人能够识别AI生成内容中的错误"。如果使用者对行业、数据源或研究方法不熟悉，这个假设就不成立。
- **边界**：它只适用于结构化信息整理和中等复杂度的报告初稿，不适合需要实地体感、深度访谈、机密情报或高度创造性论证的场景。
- **反例**：曾有团队用AI生成竞品分析，AI把两家公司的融资额和收入数据张冠李戴，因为训练数据混杂了不同年份的新闻；由于人未逐条核验，报告被直接用于投委会，造成决策偏差。
- **前提**：有效使用的前提是研究者先想清楚"要回答什么问题"、"好答案长什么样"、"哪些数据必须有来源"。没有这些前提，AI只是更快地生产垃圾。

**外部反对者**：**Daniel Kahneman** 会警告说，人对AI输出的"流畅性"会产生认知放松，误以为文字通顺就等于内容可信；必须引入系统性的反幻觉检查清单，而不是依赖直觉判断。

## Synthesis

本工具应作为人机协作流程中的一个环节，而非独立终点：

- 与 [[tool-yitang-ai-research-workflow]] 配合使用，把"草写报告"嵌入七工具四层深度的AI调研流程。
- 与 [[concept-yitang-ai-research-human-loop]] 对齐，确保在"定方向、判质量、识幻觉、做归因、定决策"五个人类节点上有人介入。
- 与 [[tool-yitang-research-cross-validation]] 组合，对AI给出的关键数据和结论做交叉核验。
- 与 [[framework-yitang-research-quality-gate]] 对接，让报告在输出前通过质量闸口检查。
