# 段位升级三部曲自检

> **一句话**：会用≠会用得好≠出神入化。三段自检——从"给别人讲得清"到"能带着团队跑"到"能根据业务定制"。

---

## L1：会用（能给别人讲清楚）

| # | 自检项 | 是/否 |
|:--|:---|:---|
| 1 | 能在一分钟说清五步法是哪五步 | |
| 2 | 能说出两次跃迁的区别（价值假设 vs 增长假设） | |
| 3 | 至少自己独立跑过一次完整五步法 | |
| 4 | 能用五步法画布给别人展示一个项目 | |

## L2：用好（能带团队跑通）

| # | 自检项 | 是/否 |
|:--|:---|:---|
| 1 | 至少带团队跑过2次五步法 | |
| 2 | 能在换档时准确判断"能不能过" | |
| 3 | 至少经历过一次"发现假设错了→回退→重来" | |
| 4 | 团队其他成员能独立执行五步法中的至少3步 | |

## L3：出神入化（能根据业务定制）

| # | 自检项 | 是/否 |
|:--|:---|:---|
| 1 | 能根据行业特性调整五步法的重点步 | |
| 2 | 能识别"哪些项目不需要走完五步" | |
| 3 | 单元模型从"精算"升级到"驱动决策" | |
| 4 | 能教别人做五步法——不是讲概念，是带人跑通 | |

---

## 升级路径

```
L1→L2：独立跑通2次→带1个人跑→带3个人跑→团队能独立复现
L2→L3：发现方法论局限性→根据业务定制→形成自己的版本→教别人
```

## 常见假升级

| "我L3了" | 为什么不是 |
|:---|:---|
| "我听过五步法课" | 这是L0——连L1都不是 |
| "我给人讲过五步法" | 可能是L1——讲和带人跑是两回事 |
| "我项目用了五步法" | 可能是L2——用一次和"能带团队反复用"不同 |
