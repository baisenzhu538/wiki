# 价值获取设计工具：8 问盈利模型

> 业务设计六要素第 3 要素。核心问题：**我们如何从提供的价值中获利？盈利模式是什么？**

---

## 一、价值获取 8 问

按 PPT `_115` 的结构，依次回答 8 个问题：

| # | 问题 | 关注焦点 |
|--|--|--|
| A | 提供什么产品/服务（解决方案）？ | 卖什么 |
| B | 为哪些目标用户提供什么价值主张（定位战略）？ | 卖给谁、为什么买 |
| C | 以什么样的渠道形式提供？ | 怎么触达 |
| D | 需要在什么市场上开展创新？ | 在哪竞争 |
| E | **如何向用户交付价值（工作系统）？** | 交付流程与运营体系 |
| F | **如何捕获价值（财务模型）？** | 收入来源与定价 |
| G | **如何实现持续的价值增值（经营壁垒）？** | 护城河与复利机制 |
| H | **有其它的盈利模式吗？** | 备选/组合盈利方式 |

> E、F、G、H 为加粗重点，是盈利设计的核心。

---

## 二、业务模式 vs 运营模式双轮

### 2.1 业务模式创新（收入逻辑）

| 层面 | 问题 | 典型选项 |
|--|--|--|
| 收入模式 | 钱从哪里来？ | 一次性销售 / 订阅 / 会员 / 抽成 / 广告 / 授权 / 增值服务 |
| 行业模式 | 在行业价值链中扮演什么角色？ | 品牌商 / 平台 / 渠道商 / 生产商 / 服务商 |
| 企业模式 | 资本与组织形态？ | 直营 / 加盟 / 代理 / 合资 / 生态联盟 |

### 2.2 运营模式创新（成本与效率）

| 层面 | 问题 | 典型选项 |
|--|--|--|
| 成本结构 | 主要成本是什么？固定/变动比例？ | 原材料 / 获客 / 研发 / 履约 / 人工 |
| 管理模式 | 如何组织资源？ | 中央集权 / 区域自治 / 项目制 / 平台化 |
| 职能再造 | 哪些职能自营、外包或自动化？ | 生产外包 / 营销中台 / 客服 AI 化 |

## 四、常见盈利模式参考（PPT _117 示例）

PPT `_117` 以 M 品牌为例，展示了代理加盟的连锁加盟模式：

- **收入端**：加盟费 + 货品差价 + 管理费
- **运营端**：总部负责品牌、设计、供应链；加盟商负责本地门店运营
- **壁垒端**：品牌标准化、供应链规模、区域排他

其他可组合模式：

| 模式 | 适用场景 | 关键成功要素 |
|--|--|--|
| 产品直销 | 高毛利、强品牌 | 渠道控制、复购率 |
| 订阅会员 | 高频使用、持续服务 | 留存率、LTV/CAC |
| 平台抽成 | 双边/多边市场 | 网络效应、供给密度 |
| 授权加盟 | 快速扩张、轻资产 | 标准化、加盟商赋能 |
| 广告变现 | 流量型产品 | 用户规模、精准度 |
| 增值服务 | 基础免费、高级付费 | 转化漏斗、价值阶梯 |

## 五、Agent 执行指令

```python
def design_value_capture(value_proposition: str, target_customers: str):
    """为价值主张设计盈利模式"""
    prompts = {
        "8问": f"""基于价值主张「{value_proposition}」和目标客户「{target_customers}」，
回答价值获取8问（A-H），重点展开E、F、G、H。""",
        "双轮创新": """分别设计：
1. 业务模式创新（收入模式/行业模式/企业模式）
2. 运营模式创新（成本结构/管理模式/职能再造）""",
        "盈利组合": "用盈利组合画布呈现现状、期望、执行挑战。",
        "备选方案": "至少提出2种备选盈利模式，并比较风险与回报。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只有收入没有壁垒 | 谁都能抄的盈利模式 | 设计至少一个战略控制点（数据、品牌、专利、网络效应） |
| 价值与定价脱节 | 成本高、客户不愿付 | 回到价值主张三问，确认客户真正愿意付费的价值 |
| 单一收入来源 | 过度依赖一种收入 | 用 H 问探索组合收入（如订阅+增值+授权） |
| 忽略运营成本 | 收入增长但利润薄 | 运营模式同步设计，明确成本结构和职能边界 |
