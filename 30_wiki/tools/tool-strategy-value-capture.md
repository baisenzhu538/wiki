# 价值获取设计工具：8 问盈利模型

> 业务设计六要素第 3 要素。核心问题：**我们如何从提供的价值中获利？盈利模式是什么？**

---

## 一、价值获取 8 问

按 PPT `_115` 的结构，依次回答 8 个问题：

| # | 问题 | 关注焦点 |
|--|--|--|
| A | 提供什么产品/服务（解决方案）？ | 卖什么 |
| B | 为哪些目标用户提供什么价值主张（定位战略）？ | 卖给谁、为什么买 |
| C | 以什么样的渠道形式提供？ | 怎么触达 |
| D | 需要在什么市场上开展创新？ | 在哪竞争 |
| E | **如何向用户交付价值（工作系统）？** | 交付流程与运营体系 |
| F | **如何捕获价值（财务模型）？** | 收入来源与定价 |
| G | **如何实现持续的价值增值（经营壁垒）？** | 护城河与复利机制 |
| H | **有其它的盈利模式吗？** | 备选/组合盈利方式 |

> E、F、G、H 为加粗重点，是盈利设计的核心。

## 二、业务模式 vs 运营模式双轮

### 2.1 业务模式创新（收入逻辑）

| 层面 | 问题 | 典型选项 |
|--|--|--|
| 收入模式 | 钱从哪里来？ | 一次性销售 / 订阅 / 会员 / 抽成 / 广告 / 授权 / 增值服务 |
| 行业模式 | 在行业价值链中扮演什么角色？ | 品牌商 / 平台 / 渠道商 / 生产商 / 服务商 |
| 企业模式 | 资本与组织形态？ | 直营 / 加盟 / 代理 / 合资 / 生态联盟 |

### 2.2 运营模式创新（成本与效率）

| 层面 | 问题 | 典型选项 |
|--|--|--|
| 成本结构 | 主要成本是什么？固定/变动比例？ | 原材料 / 获客 / 研发 / 履约 / 人工 |
| 管理模式 | 如何组织资源？ | 中央集权 / 区域自治 / 项目制 / 平台化 |
| 职能再造 | 哪些职能自营、外包或自动化？ | 生产外包 / 营销中台 / 客服 AI 化 |

## 四、常见盈利模式参考（PPT _117 示例）

PPT `_117` 以 M 品牌为例，展示了代理加盟的连锁加盟模式：

- 向加盟商一次性收取品牌加盟费与年度品牌授权费，形成初始现金流
- 总部统一采购原材料与供应链配送，赚取供货差价或返点
- 按区域/门店流水比例收取管理服务费，实现持续收入

其他可组合模式：

| 模式 | 适用场景 | 关键成功要素 |
|--|--|--|
| 产品直销 | 高毛利、强品牌 | 渠道控制、复购率 |
| 订阅会员 | 高频使用、持续服务 | 留存率、LTV/CAC |
| 平台抽成 | 双边/多边市场 | 网络效应、供给密度 |
| 授权加盟 | 快速扩张、轻资产 | 标准化、加盟商赋能 |
| 广告变现 | 流量型产品 | 用户规模、精准度 |
| 增值服务 | 基础免费、高级付费 | 转化漏斗、价值阶梯 |

## 五、Agent 执行指令

```python
def design_value_capture(value_proposition: str, target_customers: str):
    """为价值主张设计盈利模式"""
    prompts = {
        "8问": f"""基于价值主张「{value_proposition}」和目标客户「{target_customers}」，
回答价值获取8问（A-H），重点展开E、F、G、H。""",
        "双轮创新": """分别设计：
1. 业务模式创新（收入模式/行业模式/企业模式）
2. 运营模式创新（成本结构/管理模式/职能再造）""",
        "盈利组合": "用盈利组合画布呈现现状、期望、执行挑战。",
        "备选方案": "至少提出2种备选盈利模式，并比较风险与回报。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只有收入没有壁垒 | 谁都能抄的盈利模式 | 设计至少一个战略控制点（数据、品牌、专利、网络效应） |
| 价值与定价脱节 | 成本高、客户不愿付 | 回到价值主张三问，确认客户真正愿意付费的价值 |
| 单一收入来源 | 过度依赖一种收入 | 用 H 问探索组合收入（如订阅+增值+授权） |
| 忽略运营成本 | 收入增长但利润薄 | 运营模式同步设计，明确成本结构和成本边界 |

## Purpose

本工具解决的核心问题：**价值主张设计完后，如何从这套价值中可持续地获利？**

不是回答"定什么价"，而是设计一套完整的价值捕获系统：谁来付钱、以什么形式付、付多少、付多久、靠什么壁垒让这套系统不被轻易复制。

## Protocol

1. **锚定价值主张**：先明确 B 问——为哪类客户创造什么价值。价值获取不能脱离价值主张单独设计。
2. **回答 8 问**：用 A-H  checklist 扫描一遍，先写现状，再写期望。
3. **聚焦 E/F/G/H**：把"如何交付""如何捕获""如何增值""还有什么模式"四个问题展开成具体方案。
4. **双轮校验**：业务模式（收入/行业/企业模式）和运营模式（成本/管理/职能再造）必须同时有答案，不能一边重一边空。
5. **画布呈现**：用盈利组合画布把现状、期望、执行挑战对齐到一张表。
6. **设计备选**：至少提出 2 种备选盈利模式，比较风险、回报和所需能力。
7. **定义撤销条件**：在什么数据信号下，这个盈利模式需要调整或放弃？

## 核心洞察

> **价值获取不是定价问题，而是"价值-成本-壁垒"三位一体的系统设计。**

大多数人把"价值获取"理解为"怎么收钱"，所以一谈盈利模式就想到订阅、抽成、广告。但冉鹏 8 问的真正价值在于：它强迫你把价值捕获拆解成一套相互咬合的系统。

**三个关键洞察**：

1. **E/F/G/H 才是杠杆点**。A-D 问的是"做什么、卖给谁、通过什么渠道、在哪创新"——这些更接近价值主张和市场选择。真正决定你能不能赚钱的，是 E（交付系统）、F（财务模型）、G（经营壁垒）、H（备选模式）。一家公司可以有好产品、好客户、好渠道，但如果交付成本失控、收入结构单一、没有壁垒、没有备选方案，仍然赚不到钱。

2. **业务模式和运营模式必须同时设计**。业务模式回答"钱从哪里来"，运营模式回答"成本怎么控"。很多人只设计前者：加盟费、会员费、广告位。但如果没有配套的运营模式——谁来履约、成本结构是什么、哪些职能外包——收入越高可能亏得越多。M 品牌从直营转向代理加盟，变的不是"怎么收钱"，而是整个运营体系：总部管品牌+供应链，加盟商管本地门店。

3. **备选盈利模式是风险对冲，不是锦上添花**。H 问"有其它的盈利模式吗"最容易被跳过，因为大家默认"先把主业做好"。但市场变化、政策变化、技术变化会让单一盈利模式瞬间失效。真正有韧性的公司，主业盈利模式之外至少还储备 1-2 个可切换模式。不是同时做所有事，而是知道"如果 A 不行了，B 怎么接上"。

## When NOT to Use

- **价值主张尚未被客户验证时**：如果连目标客户愿为什么价值、付多少钱都没跑通，直接用 8 问设计盈利模型会基于假设堆叠假设。应先用价值主张工具或最小化验证闭环确认付费意愿，再进入价值捕获设计。
- **只有定价诉求，没有交付/成本/壁垒设计诉求时**：本工具的核心杠杆是 E/F/G/H（交付系统、财务模型、经营壁垒、备选模式），如果只是回答“这个产品定 199 还是 299”，用本工具会造成过度设计。
- **运营模式无法配合业务模式切换时**：例如设计了加盟/授权盈利模式，但总部没有标准化 SOP、供应链和督导体系，加盟商无法复制。此时应先用运营模式工具补齐能力，再谈盈利组合。
- **监管或合同严格锁定单一收入形态时**：如某些医药、金融、公用事业领域，盈利模式受牌照、集采、费率管制约束，8 问中的“备选盈利模式”和“收入模式创新”空间有限，强行套用会产出不可执行方案。


## 质疑

**Michael Porter** 可能会质疑：这个工具依赖的 **价值分配、议价能力、盈利模式、可持续性** 是否已经被充分验证？

- 价值捕获能力强不代表价值创造能力强，过度攫取可能损害生态。
- 捕获机制若缺乏壁垒，竞争者会迅速模仿并压缩利润空间。

- 使用前应明确本工具的 **具体假设**、适用 **边界**、潜在 **反例** 和隐含 **前提**，避免把模板输出直接当成战略结论。
