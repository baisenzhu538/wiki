# 二维定位：找到差异化竞争的坐标

> **一句话**：二维定位不是"选择一个位置"，而是"创造一个新位置"。找到两个差异化维度，在竞品未覆盖的坐标上建立优势。

---

## 核心工具：二维定位三步法

```
识别差异化维度 → 验证坐标可行性 → 建立定位优势
```

---

## 第一步：识别差异化维度

### 差异化维度来源

| 来源 | 方法 | 示例 |
|:---|:---|:---|
| **用户需求** | 用户调研 | "用户既想要快，又想要好" |
| **竞品弱点** | 竞品分析 | "竞品都贵，但质量一般" |
| **技术能力** | 技术评估 | "我们能做到又快又便宜" |
| **资源禀赋** | 自身优势 | "我们有独家供应链" |
| **市场空白** | 市场扫描 | "这个区域没人做" |

### 常用差异化维度

| 维度 | 说明 | 示例 |
|:---|:---|:---|
| **价格** | 高/中/低 | 高端 vs 性价比 |
| **质量** | 高/中/低 | 精品 vs 快消 |
| **速度** | 快/中/慢 | 即时 vs 预约 |
| **个性化** | 高/中/低 | 定制 vs 标准化 |
| **服务** | 高/中/低 | 管家式 vs 自助 |
| **技术** | 高/中/低 | 领先 vs 跟随 |

---

## 第二步：验证坐标可行性

### 可行性验证方法

| 验证项 | 问题 | 方法 |
|:---|:---|:---|
| **需求验证** | 用户需要这个定位吗？ | 用户访谈、问卷 |
| **能力验证** | 我们能做到这个定位吗？ | 能力评估、原型测试 |
| **竞争验证** | 这个定位有竞争优势吗？ | 竞品分析、差异化评估 |
| **盈利验证** | 这个定位能盈利吗？ | 单元模型、财务预测 |

### 可行性评估矩阵

| 维度 | 需求 | 能力 | 竞争 | 盈利 | 综合 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 坐标1 | ✓ | ✓ | ✓ | ✓ | 可行 |
| 坐标2 | ✓ | ✗ | ✓ | ✓ | 不可行 |
| 坐标3 | ✓ | ✓ | ✗ | ✓ | 需调整 |

---

## 第三步：建立定位优势

### 定位建立方法

| 方法 | 说明 | 示例 |
|:---|:---|:---|
| **产品差异化** | 产品功能、体验独特 | "唯一支持AI的功能" |
| **服务差异化** | 服务流程、质量独特 | "24小时响应" |
| **品牌差异化** | 品牌形象、认知独特 | "高端定制专家" |
| **渠道差异化** | 渠道方式独特 | "只在线上销售" |
| **价格差异化** | 定价策略独特 | "按效果付费" |

## Constraints & Boundaries

### 适用边界

1. **产品定位**：找到差异化产品定位
2. **品牌定位**：建立独特品牌形象
3. **市场进入**：找到空白定位进入
4. **战略调整**：重新定位
5. **竞争策略**：差异化竞争

### 不适用场景

1. **无差异化可能**：产品同质化严重
2. **资源不足**：无法支撑差异化
3. **市场成熟**：定位已固化
4. **快速变化**：定位频繁失效
5. **成本领先**：不需要差异化

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 维度选择不当 | 维度与用户无关 | 选择用户关心的维度 | "我们技术最强" |
| 定位不可行 | 无法做到定位 | 可行性验证 | "理论上可以" |
| 定位不独特 | 与竞品雷同 | 差异化评估 | "我们和竞品差不多" |
| 定位不持续 | 定位无法长期保持 | 建立壁垒 | "竞品很快模仿" |
| 传播不足 | 用户不知道定位 | 强化传播 | "用户不知道我们定位" |
| 定位僵化 | 定位后不再调整 | 定期评估 | "我们一直这样定位" |
| 忽视变化 | 市场变化，定位失效 | 监控变化 | "市场变了，我们还这样" |
