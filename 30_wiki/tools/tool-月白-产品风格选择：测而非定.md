# 技能：产品风格选择：测而非定

## 原始表述

产品风格选择：测而非定是月白在文创案例中提出的实操方法。

## 操作步骤

1. 准备多种风格方向的场景图（如4种不同办公桌风格）
2. 明确产品目标人群（如职场新人、离职创业者）
3. 生成不同风格的场景方案
4. 通过测试验证哪类人群对产品最感兴趣
5. 最终风格取决于'最有兴趣人群+解决方案+他们的审美'，而非设计师个人审美
6. 综合考虑产品价格定位
