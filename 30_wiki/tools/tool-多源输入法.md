# 技能：多源输入法

## 原始表述
> √阅读：读书/论文/文章 √听课：学习高质量课程 √搜索：使用搜索引擎 √用AI：使用人工智能工具

## 操作步骤
1. 阅读书籍、论文、文章
2. 学习高质量课程
3. 使用搜索引擎主动检索
4. 使用AI工具辅助学习

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:-----|
| ✅ 适合 | 系统学习需要多元视角，避免单一信息源偏见 |
| ✅ 适合 | 验证信息准确性，需要交叉验证 |
| ✅ 适合 | 获取最新信息，单一来源可能过时 |
| ✅ 适合 | 非时间敏感型决策，允许深度调研 |
| ❌ 不适合 | 已有明确单一权威来源时 → 无需多源，直接深挖 |
| ❌ 不适合 | 时间敏感型决策 → 多源搜索消耗时间，可能延误决策 |
| ❌ 不适合 | 信息质量差距大 → 低质量来源会拉低整体认知水准 |
| ❌ 不适合 | 追求深度而非广度 → 单源深挖可能比多源浮光掠影更有效 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:-----|:-----|
| **多源同质** | 读了五篇文章，全是同一个观点的不同写法 | 检查来源异质性：书（体系）+论文（证据）+课程（实战）+AI（快速连接），至少覆盖2种不同媒介 |
| **被动输入** | 信息流完全由推荐算法驱动，看不到舒适区外内容 | 主动设计搜索策略和检索词，目标明确，主动搜索比被动推荐重要十倍 |
| **输入输出脱节** | 大量输入但没有输出，产生"我很懂"的假象 | 维持输入输出正相关：每输入1小时至少产出1个输出物（笔记/复盘/行动） |
| **信息矛盾** | 多源信息冲突时无法判断哪个更可靠 | 建立信息质量标准：官方来源>研究机构>专业媒体，自媒体和AIGC内容需验证 |
| **时间成本失控** | 多源搜索消耗大量时间，决策延迟 | 时间敏感型决策采用"精准单源+快速验证"，非关键决策才用多源深度交叉 |
| **渠道偏见** | 只看公众号不看论文，或只看英文不看中文 | 每个渠道都有系统性信息偏差，强制要求自己至少接触2种不同语言/媒介 |
| **确认偏误** | 只收集支持自己喜欢的结论的信息 | 找到支持性观点后，专门找反对观点来验证，逆向验证是多源的核心价值 |
| **消费幻觉** | 多源输入给人一种"我在学习"的幻觉，实际在浅水区打转 | 设定输出比例红线：输入不产出=消费，不是学习 |

## 判断标准

**什么算一次好的多源输入**：

| 标准 | 好的输入 | 坏的输入 |
|:---|:---|:---|
| 来源异质 | 书（体系）+ 论文（证据）+ 课程（实战）+ AI（快速连接），至少覆盖 2 种不同媒介 | 五篇公众号文章，全是同一个观点的不同写法——同质多源 = 单源 |
| 有主动搜索 | 自己设计了搜索策略和检索词，目标明确 | 完全由推荐算法驱动，永远看不到舒适区之外的内容 |
| 有逆向验证 | 找到支持性观点后，专门找了反对观点来验证 | 只收集支持自己喜欢的结论的信息——确认偏误 |
| 有输出比例 | 每输入 1 小时，至少产出了 1 个输出物（笔记/复盘/行动） | 大量输入没有输出——知识在脑子里腐烂，产生"我很懂"的假象 |

**自检问题**：
1. 最近一周的输入中，有多少来源是我主动搜索找到的？如果低于 50%，说明输入结构已经僵化了。
2. 如果我现在只能留一种输入渠道，我会留哪个？——答案揭示了我的深层学习偏好。
3. 最近一次因为输入而改变判断是什么时候？如果很久没有，可能不是我懂太多，而是我读太少。

## Critique

### 外部攻击

**攻击者1：深度工作法提倡者（Cal Newport）——“多源是泥泜，深度才是玉石”**

> 你只要找到一个真正顶尖的来源，就应该全力深挖。多源输入给人一种“我在学习”的幻觉，实际上是在各个浅水区打转。真正的认知践跃来自对一个高质量来源的深度吞噬，而不是对十个中等来源的浮光掠影。

**攻击者2：信息管理学家（Tiago Forte）——“输入过载导致行动力丧失”**

> 多源输入的本质是“消费”而非“生产”。每多一个来源，决策疲劳就增加一分。最佳学习策略不是“多源”，而是“精准单源+快速验证”——先深入一个来源，用实践结果验证，然后再决定是否需要补充。
