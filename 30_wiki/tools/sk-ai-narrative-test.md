# 技能：你的方案有叙事力吗？快速测试

## 用一句话讲清楚

用「角色—冲突—转折—氛围—行动」五个要素快速诊断一个方案是否具备让人产生行动冲动的叙事力。

---

## 核心要点

1. **叙事驱动行动，逻辑仅驱动认同**。人脑对故事的反应强于对论证的反应，逻辑正确的方案若无叙事力，往往无法促成行动。
2. **五要素缺一不可**。角色给代入感，冲突给紧迫感，转折给惊喜，氛围给真实感，行动给下一步。
3. **这是一个诊断工具，不是写作模板**。目标是快速发现方案中的叙事缺口，而非套公式写故事。
4. **每个缺口都有对应修复动作**。缺角色就找人设，缺冲突就找代价，缺转折就找反常识，缺氛围就加场景，缺行动就加下一步。
5. **AI 可辅助检查，但判断在人**。可以让 AI 用五要素打分并给改写建议，最终是否打动目标受众仍需人做审美判断。

### 五要素检查表

| 要素 | 问题 | 参考标准 | 如果答案是"无" |
|------|------|----------|---------------|
| **角色** | 方案里有没有一个明确的"主人公"？ | 用户/客户/受益者有具体的人设 | 只是"系统优化"没有人 |
| **冲突** | 有没有一个待解决的问题或挑战？ | 读者能感受到"这个问题不解决不行" | 只是"就这样做吧"没有紧迫感 |
| **转折** | 有没有一个意想不到的发现或解决方案？ | 用户觉得"原来还可以这么做" | 完全在预期内，没有惊喜 |
| **氛围** | 有没有能让人感同身受的细节？ | 有具体的场景/数据/故事 | 只有结论和数据，没有场景 |
| **行动** | 读完后是否能说出"我现在该做什么"？ | 有明确的下一步动作指引 | 感觉"挺好的"但不知道该做什么 |

### 缺口快速修复

- **缺角色** → 找一个具体的用户/客户故事，用他的视角写。
- **缺冲突** → 强调"不做的后果"——量化机会成本或风险。
- **缺转折** → 加一个"反常识的发现"或"别人没做过的方法"。
- **缺氛围** → 加一个具体的数字、场景描述或真实案例。
- **缺行动** → 结尾加一句"接下来的第一步是……"

---

## 边界

| 边界 | 说明 |
|------|------|
| **不替代完整策略设计** | 叙事力测试只解决"能不能打动人"，不解决"方案本身是否正确"。 |
| **不保证转化** | 有叙事力只是提升行动概率，最终取决于产品、渠道、时机等。 |
| **受众差异** | 同一叙事对不同人群效果不同，需针对具体决策者/用户调整。 |
| **不能用于误导** | 叙事力是把双刃剑，不应用来包装逻辑不成立或有害的方案。 |
| **非创意写作课** | 目标不是写出小说，而是让商业/产品方案更易被理解和接受。 |

## 失败模式

| 失败模式 | 真实症状 | 可执行修复 |
|----------|----------|------------|
| **跳过某个要素** | 只检查冲突和角色，忽略行动，导致听众感动但不知道下一步做什么。 | 强制按「角色→冲突→转折→氛围→行动」顺序逐条打分，缺一项不通过。 |
| **把叙事当包装** | 逻辑本身有问题，却想用故事掩盖，导致短期打动、长期失信。 | 先让方案通过逻辑/证据检查，再用叙事力测试优化表达。 |
| **角色太抽象** | "我们的用户"没有具体人设，无法让人代入。 | 找一个真实用户/客户名字和具体场景，用他的视角重写。 |
| **冲突不痛** | 问题描述不痛不痒，听众没有"必须解决"的紧迫感。 | 量化不做决定的代价：钱、时间、机会、风险。 |
| **转折可预测** | 解决方案在预期内，没有"原来还能这样"的惊喜。 | 加入一个反常识发现或别人没试过的方法。 |
| **氛围靠形容词** | "非常重要""极具价值"等空话，没有具体细节。 | 用 1 个数字、1 个场景、1 个真实故事替换形容词。 |
| **行动太模糊** | 结尾说"我们一起推进吧"，没有明确的第一步。 | 结尾必须有一句："接下来 24 小时内的第一步是……" |

---

## 行动 Checklist

- [ ] 明确方案的目标受众（具体一个人或一类人）。
- [ ] 用五要素逐项检查：角色、冲突、转折、氛围、行动。
- [ ] 为每个要素打分（0-10），低于 6 分的标记为缺口。
- [ ] 针对每个缺口，按修复指引重写对应段落。
- [ ] 让至少 1 个目标受众试读，确认其能复述"主人公、问题、解决方案、下一步"。
- [ ] 输出最终版：1 句话版本 + 1 分钟版本 + 完整版本。
