# 技能：AI一句话改图尺寸

## 原始表述

AI一句话改图尺寸是月白在文创案例中提出的实操方法。

## 操作步骤

1. 直接向AI输入指令：'帮我把图片改成横版16:9'
2. 或指定具体比例如'改成3:4''改成16:9'
3. 获取AI直接输出的改后图片
4. 避免手动拆图层、重新排版
