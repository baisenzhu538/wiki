# 人脉库检索

> 利用脉脉/LinkedIn/微信人脉库，系统化搜索目标公司的人——在职的、离职的、认识目标公司的人的。

**做法**：
1. 脉脉：搜索公司名→看员工列表→筛选目标部门的人
2. LinkedIn：同样逻辑，适合外企和海外公司
3. 微信：搜索"曾在XX公司"→通过群聊/朋友圈找到线索
4. 整理成"人脉地图"——标记每个人的角色、可信度和可触达性

**价值**：不需要认识目标公司的人——只需要找到认识他们的人。

**坑**：冷联系回复率低。通过共同认识的人引荐（二度人脉）效果远好于直接联系。
