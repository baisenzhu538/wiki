# 用户访谈五步执行法：画像·场景·信任·提问·判断

> **一句话**：80%的创业失败源于对用户需求理解不足。用户访谈五步法——先想清楚找谁聊（画像）、在哪聊（场景）、凭什么跟你聊（信任）、怎么问出真话（提问）、怎么判断真伪（判断）。

---

## 核心认知

"用户调研是CEO的工作。除非你们现在已经做到了B轮，否则这是CEO的工作，不能委派。"

**三个最常见的错误**：
1. **聊错人**：找了身边朋友或非目标用户
2. **问错问题**："你愿意付多少钱？""你会用我的产品吗？"——这种问题得到的答案毫无意义
3. **依赖二手信息**：只看报告，不直接接触用户

---

## 五步法详解

### 第一步：用户画像——"选择，不是许愿"

> "用户画像是选择，不是许愿。明确谁不是你的用户，比确定谁是用户更重要。"

| 画像维度 | 要确定的内容 | 为什么重要 |
|:---|:---|:---|
| **人类基本属性** | 年龄、性别、学历、婚否、职业 | 最基础的筛选条件 |
| **客观标签** | 城市级别、收入水平、消费水平、是否有房/车 | 决定购买力和使用场景 |
| **用户认知** | 轻度/重度用户、小白/专家、高频/低频 | 决定访谈时问什么问题 |
| **实际限制** | 居住环境、使用条件、消费习惯、时间约束 | 决定产品是否真的能用 |

**核心动作**：列出至少3类用户画像，明确"我的核心用户是XX，我的非用户是XX"。

### 第二步：确定场景——"魔鬼在现场"

> "魔鬼在现场。十个微信不如一个电话，十个电话不如一个见面。"

| 场景优先级 | 方式 | 适用情况 | 信息质量 |
|:---:|:---|:---|:---:|
| 🥇 | **线下现场调研** | 去用户的使用场景，边看边聊 | ⭐⭐⭐⭐⭐ |
| 🥈 | **线上视频/电话深访** | 无法线下但需要深度交流 | ⭐⭐⭐⭐ |
| 🥉 | **微信/文字交流** | 快速验证简单问题 | ⭐⭐⭐ |
| 4 | **问卷** | 大规模定量验证（定性之后） | ⭐⭐ |

**核心原则**：早期定性优先于定量。先聊10个人理解需求，再做问卷验证规模。

### 第三步：建立信任——"他凭什么跟你聊？"

> "创业不易，全靠演技。"

| 建立信任的方式 | 适用场景 | 示例 |
|:---|:---|:---|
| **真诚求助** | 对方是潜在用户且容易接触 | "我们正在做一个改善XX的产品，想请教你的真实体验" |
| **小礼物/红包** | 对方时间宝贵 | "占用你10分钟，给你发个红包表示感谢" |
| **虚拟身份** | 需要对方坦诚评价竞品 | 以调研员/同行身份切入（见社会工程学卡） |
| **社群渗透** | 需要了解群体行为 | 加入目标用户群，长期观察后再私聊 |
| **利他交换** | 你有对方需要的资源 | "我可以帮你XX，作为交换想了解YY" |

### 第四步：提问技巧——"多问过去，少问未来"

> 最怕的问题是"如果有一个产品能帮你XX，你会用吗？"——这是产品经理的大忌。

| 应该问（过去事实） | 不应该问（未来观点） |
|:---|:---|
| "你上一次遇到XX问题时，是怎么解决的？" | "你会用能解决XX问题的产品吗？" |
| "你最近一次购买XX花了多少钱？" | "你愿意为XX付多少钱？" |
| "你用过哪些类似的产品？哪个好用？为什么？" | "你觉得我们的产品怎么样？" |
| "能给我看看你是怎么用的吗？" | "你觉得这个功能有用吗？" |
| "当时是什么让你决定买XX的？" | "如果我们的产品和XX一样你会买吗？" |

**四大提问原则**：
1. **多问过去的事实，少问未来的观点**——历史行为不会说谎
2. **多问场景，少问解决方案**——用户知道自己的痛，但不知道解决方案
3. **多问对比，少问孤例**——"A和B你选哪个？为什么？"
4. **多看行为，少听表态**——"能演示给我看吗？"比"你觉得好吗？"有用100倍

### 第五步：完成判断——"相信事实，怀疑观点"

| 信息类型 | 处理方式 |
|:---|:---|
| **一手信息**（自己访谈到的） | 最可信，但样本小 |
| **二手信息**（别人访谈的/报告里的） | 需要溯源和交叉验证 |
| **事实性信息**（"我上周买了三次"） | 可以相信 |
| **观点性信息**（"我觉得这个产品不错"） | 保持怀疑，追问"为什么"和"跟什么比" |

**判断四步法**：拆（拆开用户说了什么）→ 推（推断背后的动机）→ 评（评估信息可信度）→ 算（算这个需求有多普遍）
