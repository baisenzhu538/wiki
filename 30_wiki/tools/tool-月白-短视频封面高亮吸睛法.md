# 技能：短视频封面高亮吸睛法

## 原始表述

短视频封面高亮吸睛法是月白在文创案例中提出的实操方法。

## 操作步骤

1. 提高画面亮度，确保在手机上足够醒目
2. 拉高饱和度，避免画面发灰
3. 确保高亮足够，使画面在手机屏幕上能'跳出来'
4. 对比检查：将画面缩放到手机屏幕大小，验证是否足够醒目

## 为什么有效

手机屏幕显示环境下，亮度更高、饱和度更高的画面更容易抢占视觉注意力，类似音乐'响度战争'原理——谁更醒目谁获得观看
