# 知识小抄 S/A/B 三级收录清单

> 本卡属于「AI×知识管理」体系（楚门探索营第二次飞跃·团队集体阶段，015204 图）：知识收录的优先级分级清单——按**复用频率**（大量/偶尔/不再）把文档分成 S/A/B 三级，S 一定收录、A 最好收录、B 可以不录。解决"什么该收进知识库"的判断成本。

## 1. 工具定义

知识小抄 = 知识库收录的优先级分级标准（015204 图，一堂知识库·重点知识小抄）：

| 级别 | 复用频率 | 分类 | 示例文档 |
|:--|:--|:--|:--|
| **S 一定收录** | 大量复用 | 培养类 | 《新人入职一页纸》《公司文化价值观》《公司制度和规则》 |
| | | 知识类 | 《XXX关键难题思考》《XXX方法论模型》《XXX工具箱》《XXX模板》《XXXSOP》 |
| **A 最好收录** | 偶尔复用 | 分享类 | 最佳实践/内部分享（如何起好标题）/复盘总结 |
| | | 备忘类 | 关键项目备忘/关键沟通备忘（评审沟通） |
| **B 可以不录** | 不再复用 | 日常类 | 例会文档（周报日报会议纪要）/工作总结（年度总结晋升汇报） |
| | | 项目类 | 项目设计文档/项目协作文档（进展记录沟通记录） |

## 2. 使用步骤

1. **判断复用频率**：这篇文档未来还会大量用/偶尔用/不再用？
2. **对表分级**：S（一定收录，进知识库）/A（最好收录，有空就收）/B（可以不录，不占知识库）
3. **S 级优先沉淀**：新人入职/文化价值观/制度规则/方法论模型——这些是知识库的骨架
4. **A 级按需沉淀**：最佳实践/复盘总结/关键备忘——偶尔复用，收进来找得到就行
5. **B 级不强制**：例会文档/工作总结——用即时工具即可，不占知识库

## 3. 为什么分级

- **降低收录门槛**：不是所有东西都值得进知识库——分级让"要不要收"有标准答案
- **知识库质量**：S/A 级是"资产"，B 级是"流水"——混在一起知识库会失控（火箭六要素的可掌控底线）
- **新人友好**：S 级=新人必知必会（扫描两篇文档两天入门，顶层文档制度配套）

## 4. When NOT to Use

1. **纯个人速记**——个人临时笔记不需要分级（个人知识库用个人标准）。
2. **极少量文档**——文档 <50 篇时分级成本高于收益。
3. **AI 自动分类已成熟**——自动分类脚本（B8）可替代人工分级（规则驱动）。

## 5. 失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 什么都收 S | 知识库膨胀失控 | 按复用频率严格分级（B 级不录） |
| B 级混入 | 周报日报占知识库 | 例会文档用即时工具，不收录 |
| S 级缺失 | 新人入职没人带 | S 级培养类文档优先补（入职一页纸） |
| 分级不统一 | 每个人标准不同 | 小抄挂在知识库入口，收录前先查表 |

## 6. Action Triggers

- 建团队知识库 → 先定 S/A/B 分级标准（小抄挂入口）
- 犹豫"要不要收录" → 查小抄对表（复用频率=唯一判据）
- 知识库失控 → 用 S/A/B 重新分级，B 级移出
