# 技能：一抽流长提示词写作法

## 原始表述

一抽流长提示词写作法是月白在AI设计基础中提出的实操方法。

## 操作步骤

1. 一次性撰写2000字级别的完整约束提示词
2. 涵盖：主体、构图、光影、色彩、材质、相机参数、氛围等全维度
3. 直接提交，避免反复与AI拉扯调整
4. 生成后只做微调或直接使用
