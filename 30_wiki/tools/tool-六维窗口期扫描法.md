# 技能：六维窗口期扫描法

## 原始表述
> 外部竞争有窗口期吗？关键资源有窗口期吗？营销时间有窗口期吗？流量红利有窗口期吗？政策支持有窗口期吗？

## 操作步骤
1. 扫描外部竞争窗口（竞品动态、市场格局变化）
2. 扫描关键资源窗口（人才、供应链、资本可得性）
3. 扫描营销时间窗口（节日、事件、用户注意力周期）
4. 扫描流量红利窗口（平台政策、新渠道、算法变化）
5. 扫描政策支持窗口（补贴、监管、产业导向）
6. 综合判断时间敏感性并调整决策优先级
