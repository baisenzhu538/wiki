**转型**：原油价值链突变 → 预测未来市场规模萎缩 → 提前从生产转向服务。

**核心洞察**：不是"等到不行了再转"——壳牌在原油还在赚钱时就启动了转型。吃撑期转型的第一原则：在旧引擎还能跑的时候就开始找新引擎。

## 背景

壳牌石油长期依赖上游原油生产和炼化业务。20 世纪中后期，行业普遍认为石油需求会以每年 10%–20% 的速度持续增长，但壳牌战略部通过情景分析发现：一方面地缘政治（如海湾战争）会带来短期冲击；更重要的是，按当时的开采增速，市场将在几年内达到饱和，传统以生产为核心的价值链将面临天花板。壳牌因此在行业仍处高位时主动调整战略。

## 关键决策

1. **市场规模预测**：放弃简单线性外推，对石油需求、开采量、饱和度、价值链变化进行情景推演。
2. **战略转向**：从"以生产为中心"转向"以服务为中心、生产为辅"，提前布局润滑油等消费类产品。
3. **能力迁移**：把在石油产业链中积累的品牌、渠道、化工技术能力复制到高附加值服务与消费品。
4. **持续迭代**：进入 21 世纪后，壳牌继续推进能源转型，设定 2050 年净零排放目标，加大对 LNG、电力、充电网络、生物燃料、氢能的投入。

## 可迁移场景

- 传统能源企业转型：煤炭、油气、电力企业面对碳中和与可再生能源趋势。
- 价值链迁移与市场规模预测：用情景规划替代线性外推。
- 吃撑期提前寻找新引擎：在主业仍盈利时布局第二曲线。
- 政策驱动型行业转型：把政策压力转化为提前布局的窗口期。
- 制造业向服务业延伸：从产品收入转向服务收入、订阅收入。
- 成熟行业企业应对技术替代：如胶片、功能机、传统媒体等。

## 教训

- 在旧引擎还能跑的时候就开始找新引擎。
- 转型需要基于市场规模预测与情景规划，而非等到危机出现。
- 从生产向服务转型可以平滑周期波动，但需要品牌、渠道、技术能力的迁移。
- 长期趋势比短期价格波动更重要，战略部要敢于用长期视角挑战业务部门的乐观预测。
- 吃撑期转型的最大风险不是转错了，而是转晚了。

## 失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| **等到主营业务不行了才转型** | 现金流枯竭时无力投入新业务 | 在行业高点储备现金并布局新赛道，设定转型触发指标 |
| **忽视市场长期趋势** | 只盯短期油价/股价波动，否认替代能源威胁 | 建立长期市场预测和情景规划机制，每季度复盘关键假设 |
| **新旧业务冲突** | 传统部门抵制新业务，资源争夺内耗 | 设立独立业务单元，给予独立预算、考核与激励机制 |
| **把转型当口号** | 喊净零排放但资本开支仍集中在上游 | 将低碳投资占比、服务收入占比纳入高管考核 |
| **能力迁移失败** | 用做上游开采的团队和 KPI 做消费服务 | 为新业务配备适配的人才、渠道、品牌与运营模式 |

## 执行检查清单

- [ ] 是否用情景规划替代简单的线性外推？
- [ ] 是否识别了价值链的重大变化信号？
- [ ] 主业仍盈利时是否已开始布局新引擎？
- [ ] 新业务是否与现有核心能力有可迁移性？
- [ ] 是否为新业务设立独立预算与考核？
- [ ] 长期趋势指标是否纳入高管考核？
- [ ] 新旧业务冲突是否有隔离机制？
- [ ] 转型触发指标是否明确，而不是凭感觉？

## 适用边界

- 适用于传统能源、制造业、传媒等面临技术替代或政策转向的行业。
- 适用于吃撑期企业寻找第二曲线。
- 不适用于初创期或验证期业务。

## 常见误区

| 误区 | 正确理解 |
|---|---|
| 等主业不行了再转 | 那时已无资源转型 |
| 长期趋势不可预测 | 情景规划可以提高预判与应变能力 |
| 新业务靠老团队老 KPI | 新业务需要独立组织与激励 |
| 转型就是放弃主业 | 主业是现金引擎，用来哺育新业务 |
| 一次转型定终身 | 战略需要根据环境持续迭代 |

## 一句话总结

壳牌石油的转型成功在于：在原油业务仍赚钱时，就基于市场规模预测主动从生产转向服务，提前布局新引擎。
