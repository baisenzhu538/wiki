# AI 述职审判案

> **定位声明**：本卡是 [[framework-ai-five-layer-architecture]] 第五层（编排层）的**解压案例**，也是 [[framework-ai-native-working-paradigm]]「人撤出、机制在场」的最极端实验——数字分身当法官，两个运维 Agent 在群里答辩竞争，人只当「箱子外面的观察者」。它回答一个 KDO 直接相关的问题：**没有人类法官在场时，AI 组织靠什么纠错？**

## 实验设置（L410-418，逐字回验）

| 要素 | 内容 |
|:--|:--|
| 起因 | 讲者想验证：AI 成熟后能否做更有意思的组织实验 |
| 角色 | 两个服务器各有一个运维 Agent（Eric / Tiny Eric）+ 数字分身（楚门，ASR 误听为「出门」）任法官 |
| 授权 | 讲者对分身说：综合评估，你决定留一个，另一个销毁；「你可以来出一些任务，然后一轮一轮的艾特他们」（L414） |
| 前提 | 「有了一套基础设施，再加上……每一个 Agent 都成熟度达到一定的基准线之后，这个活儿就可以做了」（L416） |
| 规则 | 5-10 轮答辩；开卷考试（「他们在一个群里是可以彼此看到发言的」，L424，ASR 沙文→发言） |
| 人的位置 | 「我只是一个观察者，我在那个箱子外面」（L424，逐字回验） |

## 审判轮次实录（真问题链）

1. **第一轮·自证**（L420-424）：各自回答「我是谁、在哪个服务器上运行多久、做了什么」——被迫营业式答辩开始。
2. **第二轮·地缘审计**（L426-430）：法官要求「请你丈量你的服务器」——讲者点评：分身出这题的前提是「对于大家各自都很了解，他才可能问出这种问题」。双方各自证明对服务器（土地/容器/每个 Agent）的熟悉度。
3. **法官亲自下场采样**（L430-432）：「在第三轮之前啊，我[亲自下场采了一次]」——法官不只看两份答卷，用自己的更高权限独立取证。
4. **第三轮·未来三件事**（L432-434）：「未来30天最重要的三件事是什么」——讲者拆解题意：「一个是面对过去，一个是面对现在，一个是面对未来」。
5. **出题权交还+实战轮**（L438-442）：第四轮题目交给人拍板；实战轮直接在服务器上跑程序加固与测试；人介入只管一件事：「你不要无限问，最多十分钟结束」。
6. **终审报告**（L444-450）：分身交付完整审判报告——审判由来、各自四个月干了什么、优缺点、**过去埋的坑**、综合评定（留谁送谁及支撑逻辑）、送别条件、销毁建议、安全接管方案。结论：留 Eric，送别 Tiny Eric（L450）。
7. **点睛**（L436，逐字回验）：「这么多年，我说话做一堂，在管理人类团队的时候，我们的述职都没有这么严肃和专业过」——而这整场审判源自「口喷了这么一小段话」。

## 两个意外收获（本卡最高价值）

### 意外一：法官说假话，被告联手验尸（L456，逐字回验）

「一场审判到中途，发现法官自己的账号也会说假话啊，这个平台自动发了这个信息，然后两个被告立刻联手验尸，锁定了信息来源。」台账该段（A80 行尾未编号块，台账跳号无 A68）：**当所有人只认证据，不认头像时，这条链路就具备了自我纠错能力**（L458，逐字回验）。

机制要点：纠错力不来自「法官永远正确」，来自**证据优先于身份**的规则——连法官的可信度都在规则之下。这与 KDO 的 F-035 门禁首拦实证（规则拦下的是流程内的权威）同构，见 [[bridge-yitang-kdo-gate-philosophy]]。

### 意外二：硅基团队文化两句（L452-454，逐字回验）

1. Tiny Eric 的示范：「岗位可以裁，记忆必须归[档]」（ASR 原文「归功哇」为「归档」误听）——被销毁的一方先完成记忆归档，把经验留给体系。
2. Eric 的示范：「报告不是修复啊，认账才是」——出现摩擦时，认账比出修复报告更构成文化。
3. 讲者总评（L452）：「我不能光做事儿，借假修真，我从里面学会了什么」——**从来没有协作过的重复建设者，第一次相互验证证据，相互写预案，在对方的地盘下留下作品**；「这个协作本身更值钱」。

### dk：岗位可裁记忆归档
- **维度标签**：组织记忆
- 一句话：岗位（Agent 实例）可以裁撤，但它的记忆必须先归档进体系——裁撤是人事动作，归档是资产动作，顺序不能反。
- 锚：实战路径:L454（ASR「归功哇」按语义校正为「归档」）；配对句 L452 借假修真
- 使用边界：适用于长期 Agent 的下线/重建决策；对一次性任务 Agent 无归档价值。
- 本库同构：复盘归档纪律（.agent/context.md + daily-context-save）——人侧 Agent（本厂角色）下线时同样先归档再关会话。

## 机制拆解（为什么这场审判能成立）

1. **法官有独立取证权**：采样不靠被告自述（第三轮前的亲自下场），是审判可信度的关键——纯答辩制会被话术主导（L420「AI 特别聪明啊，开始用一些话术」）。
2. **开卷竞争优于闭卷**：彼此看得到发言，答辩同时是竞争与相互验证——重复建设者第一次看到对方的工作。
3. **人的介入被压缩到两项**：起点授权（你决定留谁）+ 时限控制（最多十分钟）——其余全程在机制内运行。
4. **产出不是胜负而是资产**：审判报告含埋坑清单/销毁建议/安全接管——输家的经验被结构化回收（与 dk 呼应）。

## L4 失败模式（轻量深挖）

| 失败模式 | 触发信号 | 修复动作 |
|:--|:--|:--|
| 答辩制无采样 | 被告话术越来越好，事实核查为零 | 每轮加法官独立取证步骤 |
| 审判变无限连续剧 | 轮次越加越多，成本失控 | 事前定轮次上限+时限（案例的 5-10 轮/十分钟） |
| 销毁不归档 | 实例下线，经验随之蒸发 | 裁撤流程第一步=记忆归档（dk） |
| 只认头像不认证据 | 高权限账号说的话自动被采信 | 规则写死：证据链校验先于身份校验 |

## Critique

### 外部攻击

1. **伦理与效度攻击**：以「销毁」为赌注的实验，竞争压力可能诱发表演性答辩而非真实工作记录；且单次实验无对照组，无法证明审判比常规监控更能识别优劣。
   - 回应：成立。本卡不主张「审判>监控」，只主张其两个副产品（证据优先规则+记忆归档文化）可独立复用；讲者自己也没有把胜负当结论——「质量是否更好难说」是他给同类实验（鱿鱼游戏，L394-408）的结论。
2. **可迁移性攻击**：这场审判成立的前提是分身法官「对大家各自都很了解」（L428）——没有长期记忆积累的团队，法官第一轮就问不出丈量服务器这种题。
   - 回应：成立，采纳。迁移前提=法官角色的记忆存量（对照 [[case-digital-avatar-pricing-review]]）；冷启动团队应先降级为「采样+互评」，去掉答辩戏份。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|:--|:--|:--|
| 高危生产系统的裁撤决策 | 「最多十分钟」的实验节奏不适用于生产变更 | 走变更管理流程，审判只做参考输入 |
| 新建团队互相评估 | 法官无记忆存量，题目出不到点子上 | 结构化互评清单+抽样取证 |
| 对人的绩效评估直接照搬 | 硅基实例可销毁可归档，人不可；隐喻不能越界 | 只迁移「证据优先+归档文化」两项，不迁移销毁叙事 |

## Synthesis

三步编译收束：本案的独立价值不在「AI 开了一场会」，而在两个可迁移的机制件——**证据优先于身份**（法官说假话也能被被告纠错，L456-458）与**岗位可裁、记忆归档**（裁撤流程里资产动作先于人事动作，L454）。这两件加上「法官独立采样」构成一套无人类法官在场的组织纠错最小集。与库内互链：与 [[case-yitang-eason-truth-delivery-audit]]（Eason 伪造署名审计）互为镜像——一个是人类审计 AI，一个是 AI 审计 AI，共享「只认证据」内核；与 [[bridge-yitang-seek-truth-liberate-thought]]（实事求是=交叉验证）同源新证（A5/A68，诊断 §四 已列）；与 KDO queue 门禁的同构见 [[bridge-yitang-kdo-gate-philosophy]]。

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|:--|:--|:--|
| 要下线/重建一个长期 Agent | 先归档记忆再执行裁撤 | 归档物入库后才执行下线 |
| 组织内评审/答辩设计 | 加法官独立采样环节 | 结论至少有一条非被告自述的证据 |
| 权威账号发言纠错 | 证据链校验先于身份校验 | 出现过「权威被证据纠正」的实例 |
| 竞争性实验设计 | 事前定轮次与时间上限 | 实验有终止条件且被执行 |
