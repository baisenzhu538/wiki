# 农机撮合平台：从「续费率10%」到「新客一月5次撮合率」的因果验证

> 一堂业务公式参数探索篇案例：一个 ToB 农业双边撮合平台，续费率只有 10%，远低于一堂的 50%+。讲师没有直接给建议，而是引导团队找到一个动作指标——新客一个月 5 次撮合率——作为续费的领先指标，通过追这个动作指标来预测并提升续费。用来说明「因果验证」和「自定义组合参数」。数字均为「课程案例口径」，未独立核实。

---

## 案例背景

| 维度 | 信息（课程案例口径） |
|---|---|
| 行业 | ToB 农业双边撮合平台 |
| 当前续费率 | 约 10% |
| 对比 | 一堂续费率 50%+ |
| 问题 | 不知道续费率低的原因，也不知道该追什么指标 |
| 关键动作 | 定义「新客一个月 5 次撮合率」作为续费领先指标 |
| 验证方式 | 追这个指标，观察第二年续费是否提升；若不提升则证伪 |

---

## 错误拆解

常见的错误思路：

```
续费率低 → 加强客户成功 → 多打电话 → 续费率提升
```

这是典型的「相关动作当因果动作」。打电话多可能只说明客户在续费期被触达了，不是续费的原因。

---

## 核心矛盾

续费率是结果指标，不能直接优化。需要找到一个**动作指标**作为续费的直接因。

### 探索过程

1. 先问：续费的用户有什么共同特征？
2. 发现：用户在平台上被撮合的次数达到某个阈值后，续费率显著更高。
3. 估算：大概需要撮合 **5 次**。
4. 再问：运营团队大概多久能把新客推到 5 次撮合？
5. 回答：快的话 **一个月**。
6. 定义新指标：**新客一个月 5 次撮合率**。

### 因果链

```
运营推动 → 新客一个月内完成 5 次撮合 → 体验到平台价值 → 第二年续费
```

---

## 正确拆解路径

### 第一步：把结果指标拆成过程指标

```
续费率 = f(使用深度, 价值感知, 切换成本)
```

### 第二步：找到使用深度的拐点

通过数据观察，发现「撮合 5 次」是一个拐点：达到 5 次的用户续费率显著高于未达到的。

### 第三步：定义可干预的动作指标

```
新客一个月 5 次撮合率 = 一个月内撮合 ≥5 次的新客数 / 总新客数
```

### 第四步：运营追指标并验证因果

- 如果今年把这个指标追上去，明年续费率高 → 因果成立
- 如果指标上去了，续费率没高 → 因果不成立，需要重新定义指标

---

## 关键动作

1. **不直接给建议，先引导团队找因果**：每个行业的关键动作不同，不能照搬一堂的续费打法。
2. **用数据找拐点指标**：观察续费用户和未续费用户的行为差异，找到阈值。
3. **把拐点指标变成运营目标**：让运营团队围绕「一个月 5 次撮合」设计动作。

---

## 教训

- **续费率的直接因是「用起来」，不是「催费」**：客户真正体验到价值，才会续费。
- **因果关系要靠数据验证，不能凭经验**："撮合 5 次"是不是关键，要跑一年数据验证。
- **L6 魔法参数往往是组合参数**：不是单一动作，而是「时间窗口 + 动作次数 + 结果阈值」的组合。

---

## 关键证据

| Before | After |
|---|---|
| 指标：续费率 10% | 指标：新客一个月 5 次撮合率 |
| 动作：加强客户成功、多打电话 | 动作：运营推动新客尽快完成 5 次撮合 |
| 假设：触达多→续费高 | 假设：使用深度达拐点→续费高（待验证） |

真实锚点：参数探索篇 L3246-L3278。

---

## 可迁移场景

1. **SaaS 续费**：找到「7 天激活核心功能」「30 天关键动作 N 次」等续费领先指标。
2. **平台双边撮合**：定义「新客首月完成交易 N 次」作为留存预测指标。
3. **会员制业务**：找到会员体验到价值的临界点，围绕该点设计 onboarding。

---

## 失败模式

| 踩坑方式 | 表现 | 避免方法 |
|---|---|---|
| 直接复制别人的续费打法 | 一堂打电话催费，我也打电话 | 先找到自己业务的续费因果链 |
| 把相关当因果 | 续费期触达多 = 续费原因 | 观察续费用户的早期行为特征 |
| 只追结果指标 | 直接追续费率 | 把续费率拆成可干预的过程指标 |
