**对比**：方特（范围经济——IP复用，熊出没IP用到多个场景）vs 迪士尼（规模经济——单一IP多次变现）
**结论**：方特有IP也打不过迪士尼——因为迪士尼的竞争力不在IP本身，在IP的"规模变现能力"。方特的IP复用是"省钱"，迪士尼的IP规模变现是"印钱"

## 关键证据

| 证据点 | 来源 | 可检验性 |
|:---|:---|:---|
| 两家公司营收结构对比 | 公开财报 | 可拆分门票、衍生品、影视收入占比 |
| 单客消费差距 | 行业研究 | 可查人均消费、复购率等数据 |
| IP 生命周期与变现深度 | 内容发行数据 | 可对比 IP 的电影、乐园、商品、授权收入 |

## 可迁移场景

- IP 运营策略选择：范围经济 vs 规模经济
- 主题乐园的差异化竞争
- 内容公司评估 IP 变现能力

## 教训

- IP 价值不在拥有，而在变现能力。有 IP 也打不过变现体系更强的对手
- 范围经济能省钱，规模经济能印钱，战略选择取决于 IP 等级和能力禀赋
- 不要只关注 IP 数量，要关注 IP 能否跨场景、跨周期、跨区域变现

## 失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| **有 IP 但缺乏变现体系** | IP 只停留在乐园场景，未延伸到衍生品和授权 | 构建 IP 全生命周期变现矩阵 |
| **把省钱当战略** | 范围经济降低了成本，但没有创造品牌溢价 | 评估是否应投入提升 IP 等级而非仅复用 |
| **盲目对标迪士尼** | 用方特的资源和迪士尼比规模和体验 | 找到自身差异化定位，避免正面硬拼 |
