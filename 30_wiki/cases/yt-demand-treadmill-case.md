# 跑步机案例：需求分析全流程实战

> 一堂五步法需求分析经典案例：跑步机——从"所有人想健身"到"特定人群的特定场景"。

## 案例背景

**产品**：家用跑步机
**初始假设**："很多人想健身，但去健身房麻烦，家用跑步机会有市场"
**问题**：需求分析太泛，导致产品定位模糊

### 第二步：推——用户现在怎么解决的？

| 替代方案 | 成本 | 痛点 |
|:---|:---|:---|
| 健身房 | 年费3000+时间成本 | 远、人多、时间固定 |
| 户外跑步 | 免费 | 天气、空气质量、安全 |
| 其他家用器械 | 500-2000元 | 功能单一、占地方 |
| 不运动 | 健康成本 |  guilt、身体变差 |

关键发现：用户不是"不健身"，而是"在寻找更便捷的健身方式"。

### 第三步：评——跑步机比现有方案好多少？

| 维度 | 跑步机 | 健身房 | 户外 | 其他器械 |
|:---|:---|:---|:---|:---|
| 时间成本 | 低（随时可用） | 高（往返+准备） | 中 | 低 |
| 空间成本 | 高（占地方） | 无 | 无 | 中 |
| 专业指导 | 无 | 有 | 无 | 无 |
| 社交氛围 | 无 | 有 | 无 | 无 |
| 天气影响 | 无 | 无 | 有 | 无 |

关键发现：跑步机在"时间成本"和"天气影响"上有优势，但在"专业指导"和"社交氛围"上有劣势。

### 第四步：算——市场规模估算

| 方法 | 估算 | 逻辑 |
|:---|:---|:---|
| 自上而下 | 健身市场1000亿 × 家用占比10% × 跑步机占比30% = 30亿 | 基于行业报告 |
| 自下而上 | 目标用户1000万 × 渗透率5% × 均价3000 = 15亿 | 基于用户估算 |
| 替代方案 | 健身房用户3000万 × 替代率10% × 均价3000 = 9亿 | 基于替代成本 |

交叉验证：三种方法差异较大，说明假设需要调整。最保守估计：9-15亿。

## 关键洞察

### 1. 需求分析的段位差异

| 段位 | 分析 | 结果 |
|:---|:---|:---|
| L1 | "用户想健身，市场很大" | 产品定位模糊，竞争不过健身房 |
| L2 | "用户想在家健身，节省时间" | 找到差异化，但忽视社交需求 |
| L3 | "特定人群：时间碎片化的上班族，需要便捷但不愿牺牲专业指导" | 产品可差异化：跑步机+在线课程 |
| L4 | "用户不仅想健身，还想坚持。需要反馈、社群、成就感" | 产品可重新定义：智能健身生态 |

## 失败模式（如果需求分析做错了）

| 错误 | 结果 |
|:---|:---|
| 需求太泛："所有人想健身" | 产品定位模糊，竞争不过健身房和户外 |
| 忽视替代方案："用户现在不健身" | 产品功能不匹配实际使用场景 |
| 只比价格："比健身房便宜" | 忽视社交和专业指导价值，用户还是去健身房 |
| 过早定量："市场100亿" | 未搞清楚用户是谁，盲目投入 |
| 忽视空间成本："在家就能跑" | 用户住公寓，跑步机占地方，成为阻碍 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 硬件产品需求分析 | 纯软件产品（无物理限制） |
| 有明确替代方案的市场 | 全新市场（无替代方案） |
| 需要差异化定位的产品 | 标准化 commodity |
