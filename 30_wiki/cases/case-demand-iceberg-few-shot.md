# 需求冰山Few-Shot案例库

> **一句话**：四个经典案例的完整冰山拆解，用作Agent推演和新手学习的Few-Shot参考。

---

## 案例1：奶昔（JTBD经典）

| 冰山层 | 内容 |
|:---|:---|
| L1 用户 | 通勤上班族 |
| L2 场景 | 每天早上开车上班，路上无聊，需要一只手能拿的东西 |
| L3 核心任务 | 在无聊的早高峰路上，有一个有趣的东西拿着慢慢消耗 |
| L4 任务地图 | 买→拿→开车→喝→扔——关键崩溃点：喝太快=无聊还没结束;太稀=弄脏衣服 |
| L5 力量 | 推力：无聊 → 惯性：吃别的东西也行 → 拉力：奶昔比香蕉有趣 → 焦虑：会不会长胖 |
| L6 假设 | 奶昔的竞品不是别的奶昔，是香蕉/面包圈/开车时什么都不吃 |

## 案例2：银发育儿

| 冰山层 | 内容 |
|:---|:---|
| L1 用户 | 退休后+有闲钱+子女不在身边的活力银发族（不是笼统的"老年人"） |
| L2 场景 | 想帮忙带孙辈但和子女育儿观念冲突——想证明"我的方法也有道理" |
| L3 核心任务 | 用科学的方式参与孙辈的成长，同时不引起家庭矛盾 |
| L4 任务地图 | 发现育儿差异→想沟通→怕冲突→找证据→偷偷尝试→被子女发现→解释 |
| L5 力量 | 推力：想帮忙 → 惯性：不管也行 → 拉力："科学育儿"给了合法性 → 焦虑：被子女嫌弃 |
| L6 假设 | 银发育儿的需求不是"怎么带孩子"，是"怎么在不被嫌弃的情况下参与" |

> 方法论口述稿 L80-L122

## 案例3：挂脖空调

| 冰山层 | 内容 |
|:---|:---|
| L1 用户 | 户外工作者+通勤族+怕热但不想手持风扇的人 |
| L2 场景 | 夏天通勤/户外工作时，热但双手需要自由 |
| L3 核心任务 | 在需要双手自由的热环境中，保持身体凉爽 |
| L4 任务地图 | 出门→感到热→找降温方式→手持风扇占手→放弃→忍→干脆不出门 |
| L5 力量 | 推力：热得受不了 → 惯性：手持风扇凑合 → 拉力：挂脖解放双手 → 焦虑：看着奇怪/别人怎么看我 |
| L6 假设 | 挂脖空调的用户不是"想降温的人"，是"想降温但双手必须自由的人" |

## 案例4：马术课

| 冰山层 | 内容 |
|:---|:---|
| L1 用户 | 中产家庭父母+有6-12岁孩子的家长 |
| L2 场景 | 想给孩子报个"不一样"的课外班——钢琴/画画太卷了 |
| L3 核心任务 | 给孩子一个能锻炼勇气+责任感+身体素质的综合成长体验（而不是"学骑马"） |
| L4 任务地图 | 发现→对比课程→犹豫（贵+远+会不会受伤）→试课→孩子喜欢→报名→持续 |
| L5 力量 | 推力：想给孩子"不一样"的成长 → 惯性：继续上钢琴课也行 → 拉力：马术=勇气+责任感 → 焦虑：安全+成本+"会不会被说炫富" |
| L6 假设 | 马术课卖的从来不是"学骑马"，是"我的孩子和别人的孩子不一样" |
