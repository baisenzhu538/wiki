---# 扑克牌案例：同样的任务，两个同学评估结果截然相反

> Truman 在 ROI 决策高度课上分享了一个真实内部案例：同样是评估"是否做一套扑克牌知识产品"，两个同学给出了截然相反的结论。这不是能力差距的问题，而是**决策高度**的问题。
> 
> "我们发现绝大部分的决策都是这么做的——让你评估这事的 ROI，可能就坐在那聊一聊，说这事可能有什么价值，可能有什么成本，这儿拿点那儿拿点，心一凑，哦感觉还行对吧？"——Truman

---

## Background

2020 年底，一堂决定做一个年度活动，需要一套学习周边物料作为赠品。有人建议做一套扑克牌：每一张牌印一个思维模型，共 54 张。Truman 把评估任务派给了两个同学，要求评估投入产出比，并回答：如果不做扑克牌，有没有更好的方向？

这个决策看似很小（单份成本只有十块钱级别），但它占用的是教研人日——一堂当时最核心的稀缺资源。

---

## What Happened

### 同学 1：快速评估（两小时完成）

| 维度 | 评估内容 |
|:---|:---|
| 价值主张 | 提升品牌信任和粘性 |
| 成本估算 | 100 小时设计，单份成本约十块钱，总成本三四万元 |
| 支持论据 | 同行都做过知识卡片，内部业务负责人都支持 |
| 结论 | 能做，你点头我立刻就去搞 |

**问题所在**：同学 1 的评估只覆盖了"直接成本 + 短期营销价值"，没有进入 Y 模型的宽度、深度、高度三层。

### 同学 2：深度评估（花了一个周末）

| 维度 | 评估内容 |
|:---|:---|
| 项目管理 | 需要 30 人日的教研参与（包括重绘内容） |
| 实用性 | 以营销为主，实用性较差，用户玩两下就扔了 |
| 长期复用性 | 一堂每年出新课，扑克牌只有 54 张，每次出新课都要废掉旧牌重做新牌 |
| 版本管理 | 不同批次的扑克牌大小、版本不一致，反而混淆品牌信任 |
| 机会成本 | 30 人日的教研投入，足够做 2-4 节课 |
| 替代方案 | 工具训练手册：不需教研、实用性高、长期可迭代、品牌价值复利 |
| 结论 | **ROI 不太值得做**，建议做工具训练手册 |

**关键差异**：同学 2 把同样的任务从"要不要做扑克牌"拔高到"哪种学习周边能长期服务品牌与教学"，并引入了机会成本、长期复用性、版本管理等高度分析变量。

### 最终决策

Truman 采纳了同学 2 的结论，没有制作扑克牌，而是选择制作**工具训练手册**。后续这个手册成为一堂可以逐年迭代的长期品牌资产。

---

## 结果

- **决策结果**：放弃扑克牌，改做工具训练手册。
- **直接收益**：节省了 30 人日教研投入，相当于保住了 2-4 节课的产出。
- **长期收益**：工具训练手册可随课程迭代持续更新，避免了扑克牌"每出新课就废掉旧牌"的版本混乱问题。
- **品牌收益**：手册具备"一本越做越厚的教材"属性，强化了品牌的长期主义叙事，比一次性营销赠品更能积累信任。
- **组织启示**：同一任务交给不同的人，决策质量可以差一个量级——差距不在执行力，而在是否能把决策放到正确的高度、宽度和深度上分析。

## 可迁移场景与使用边界

| 可迁移场景 | 使用边界 |
|:---|:---|
| **学习周边 / 品牌物料选型** | 适合有持续内容产出、需要长期复用的教育/知识类产品团队 |
| **内部工具 / 模板投资决策** | 适合需要评估"做 vs 买 vs 借"的内部效率工具 |
| **营销活动礼物选择** | 适合预算有限、但需要兼顾品牌感与实用性的场景 |
| **产品迭代中的版本管理决策** | 适合每次迭代都会引发旧物料作废的实体/半实体产品 |
| **机会成本估算** | 适合资源紧张、核心人日有明确替代产出的团队 |

### 不适合的场景

- 一次性、纯品牌曝光的物料（不需要长期复用，ROI 逻辑不同）。
- 决策者的核心诉求是"快速讨好某个利益相关方"而非真实投入产出。
- 团队完全没有替代方案可做比较（没有选项池的 ROI 分析会失真）。

## 失败模式

| 失败模式 | 真实症状 | 可执行修复 |
|:---|:---|:---|
| **只算直接成本，不算人日机会成本** | 单份物料才十块钱，总预算三四万，看起来便宜；实际占用 30 人日教研，足够做 2-4 节课 | 强制把所有参与角色的人日折算进去，列出"如果不做这个项目，这些人日能产出的替代价值" |
| **用"同行都做了"代替独立判断** | 调研结论变成"别人有知识卡片/扑克牌，我们也该有"，没有评估自己的课程更新节奏和用户真实使用场景 | 回到自身业务约束：我们的内容更新频率是多少？用户拿到这个物料后会在什么场景下使用？使用几次？ |
| **把低单价等同于低代价** | 决策者说"反正才几万块钱"，快速拍板，忽视了稀缺资源（教研人日）被占用后对其他项目的挤出效应 | 用"单位稀缺资源的机会成本"替代"总金额的绝对大小"作为决策门槛 |
| **忽视版本混乱对品牌的长期损伤** | 只考虑单期效果，没考虑每次出新课都要废掉旧牌、重做新牌，导致不同批次规格不一致，反而稀释品牌信任 | 在项目启动前评估"可迭代性"：未来 3 年这个物料需要重做多少次？每次重做的成本和对品牌的负面影响是什么？ |

## 实操模板：学习周边 ROI 快速估算表

当你要评估一个"轻物料/周边/内部工具"项目时，可以用下面这张表替代直觉判断。

### 第一步：列出收益项（每项 1-5 分）

| 收益维度 | 评分（1-5） | 说明 |
|:---|:---:|:---|
| 品牌信任与粘性 |  | 是否能强化用户对品牌的长期认同？ |
| 实用性 |  | 用户拿到后是否会高频、反复使用？ |
| 教学/服务支撑 |  | 是否能直接支持课程交付或用户实践？ |
| 长期复用性 |  | 未来 3 年是否可持续迭代，不需要推倒重来？ |
| 可传播性 |  | 是否适合作为礼物被分享，带来自然获客？ |

### 第二步：列出成本项（折算为稀缺资源人日）

| 成本维度 | 人日估算 | 直接费用 | 备注 |
|:---|:---:|:---:|:---|
| 内容/教研投入 |  |  | 是否需要重绘、重写、重调研？ |
| 设计投入 |  |  | 是否需要外部设计或大量设计时间？ |
| 运营/项目管理 |  |  | 协调、印刷、发货、客服等 |
| 机会成本 |  |  | 同样的人日如果不投入这里，能产出什么？ |

### 第三步：计算"机会成本 adjusted ROI"

```
机会成本 adjusted ROI = （总收益评分 × 长期系数） / （人日投入 + 机会成本人日）

其中：
- 长期系数 = 预计可迭代年数（例如 3 年 = 3，一次性 = 1）
- 分母统一用人日，便于比较不同项目对稀缺资源的占用
```

### 第四步：替代方案对比

| 候选方案 | 总收益评分 | 长期系数 | 人日投入 | 机会成本人日 | adjusted ROI | 结论 |
|:---|:---:|:---:|:---:|:---:|:---:|:---|
| 扑克牌 | 12 | 1 | 30 | 30 | 0.20 | 不建议 |
| 工具训练手册 | 18 | 3 | 10 | 5 | 3.60 | 建议 |

> **使用提示**：这张表的核心不是算出一个精确数字，而是强制团队把"隐性成本"和"长期复用性"放到同一个桌面上比较。
