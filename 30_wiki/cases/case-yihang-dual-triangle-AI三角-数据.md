## 一、思维修养

✔ **数据敏感**：对于业务数据有敏感性
✔ **资产思维**：形成长期的Domain-Knowledge
✔ **复利思维**：用10年的心态去设计和建设数据

✔ **正面案例**：可参考的正面案例

## 一、这张图讲什么

### 核心概念
这张图阐述了一个核心命题：**"高水平的结果需要高水平的数据"**——在AI时代，数据不是副产品，而是驱动模型表现的**第一性燃料**。整个框架回答的是"如何主动设计和积累高质量数据"这一战略问题。

### 视觉结构表达
- **纵向层级结构**：四个阶段从"思维"到"系统"，呈现明显的**金字塔升级**逻辑
- **递进色块暗示**：标题"探索AI'数据'"中"数据"加引号，提示这是一种**重新定义的数据观**（不仅是数字，更是资产）
- **✔勾选符号**：每一条都是可执行的行动项，强调"知行合一"
- **底部装饰**：隐约可见的数据图表纹理，呼应"数据"主题

## 二、结构拆解：四阶进化模型

整个图分为**四个递进模块**，体现从"认知"到"系统"的完整路径：

### 模块一：思维修养（认知层 — Why）
| 要素 | 核心要义 |
|------|---------|
| 数据敏感 | 对业务数据有"嗅觉"，识别数据价值 |
| 资产思维 | 数据是长期积累的Domain-Knowledge |
| 复利思维 | 用10年心态建设，而非短期功利 |

**关系**：递进式认知升级——从被动感知→主动定义→长期主义

### 模块二：FewShot 基础案例（战术层 — What）
- **正面案例**：作为"标准答案"引导AI输出
- **负面案例**：作为"警戒线"避免AI犯错

**关系**：**正反对照**，构成FewShot Prompting的完整性

### 模块三：Data pack 数据包（产品层 — How）
- **维度**：覆盖结构化与非结构化数据
- **预判**：识别高价值数据资产

**关系**：从"有什么"到"什么值钱"的**价值筛选**

### 模块四：System 数据体系（生态层 — Loop）
四个闭环要素：
```
采集收集 → 数据处理 → 数据使用 → 数据飞轮
   ↑                                    ↓
   └────────────── 持续循环 ─────────────┘
```

**关系**：完整的**飞轮效应**，数据越用越多、越用越准

### 整体逻辑链条
```
思维修养 (认知)
    ↓
基础案例 (战术) 
    ↓
数据包 (产品)
    ↓
数据体系 (飞轮)
```

这是一个**从心智模式到工程系统的完整闭环**。

## 三、在双三角体系中的位置

### 双三角模型定位

| 维度 | 人类三角 | AI三角 |
|------|---------|--------|
| 三角1 | 认知/能力 | 数据 ← **本图所在** |
| 三角2 | 意图/判断 | 算法 |
| 三角3 | 协作/流程 | 算力 |

**本图位于"AI三角"的第一支柱——数据**，是AI能力的**底层基座**。

### 与其他维度的关联

```
        人类三角                AI三角
    ┌─────────────┐        ┌─────────────┐
    │ 认知能力     │  →映射→ │ 数据 (本图)  │
    │ 意图判断     │  →映射→ │ 算法         │
    │ 协作流程     │  →映射→ │ 算力         │
    └─────────────┘        └─────────────┘
            ↑                       ↑
            └─────── 双三角耦合 ─────┘
```

- **与"算法"的关系**：数据是预训练/微调的食材，决定模型上限
- **与"算力"的关系**：高质量数据可降低算力需求（Data > Compute）
- **与人类三角的耦合**：人类的"数据敏感"思维，直接决定了AI数据质量

## 四、深层含义与认知洞察

### 1. 反常识点：数据的"主动性"
传统认知中，数据是"业务运行中产生的副产品"。本图颠覆为：**数据是被主动设计、主动采集的战略资产**。

> "主动搜集和积累"——五个字点破了数据观的根本转变。

### 2. 容易被忽略的"复利思维"
> "用10年的心态去设计和建设数据"

这一条最容易被忽视，却最深刻：
- 大多数人追求"速胜"，用完即弃的数据无法形成复利
- 真正有价值的数据是**时间的朋友**——标注一次，使用无数次
- Domain-Knowledge的积累需要"慢功夫"

### 3. 负面案例的隐性价值
多数人只收集正面案例，但**负面案例是AI的"安全护栏"**。它教会模型的不是"做什么"，而是"不要做什么"——这在医疗、法律、金融等高风险场景至关重要。

### 4. 数据飞轮的飞轮效应
> "主动构建一个数据飞轮"

这是最高阶的洞察：**数据不是静态资产，而是动态系统**。
- 用得越多 → 数据越丰富 → 模型越好 → 用得更多
- 飞轮一旦转起来，竞争对手难以追赶（**数据护城河**）

### 5. "数据"的引号玄机
标题中"数据"加引号，暗示**这不是技术意义上的数据，而是一种新的生产要素**——和土地、劳动力、资本并列的"第四要素"。

## 五、实践落地指南

### 适用场景
| 场景 | 应用方式 |
|------|---------|
| **个人知识管理** | Obsidian + RAG，构建个人AI知识库 |
| **企业AI落地** | 从FewShot起步，逐步搭建数据包 |
| **专业领域（法律/医疗）** | 重点建设负面案例库，规避风险 |
| **创业团队** | 用"10年心态"设计数据架构，避免返工 |
| **AI产品经理** | 用"数据预判"思维设计产品数据闭环 |

### 具体行动清单（由低到高）

**第1步：建立数据敏感（1周）**
- 每天记录3条"今天接触到的有价值数据"
- 标记敏感性、用途、潜在价值

**第2步：积累FewShot案例（1个月）**
- 整理10个正面案例 + 5个负面案例
- 形成结构化文档（Markdown）

**第3步：构建数据包（3个月）**
- 分类：结构化（表格）vs 非结构化（文档/音频/图片）
- 评估数据资产价值（按ROI排序）
- 向量化处理，为RAG做准备

**第4步：搭建数据飞轮（6个月+）**
```
采集 → 标注 → 入库 → 使用 → 反馈 → 优化采集策略
```
- 使用Obsidian做个人知识库
- 接入RAG构建问答系统
- 构建数据图谱（Graph RAG）
- 让每一次使用都反哺数据体系

### 关键工具栈
- **采集**：Notion / 飞书 / 录音转写工具
- **处理**：AI辅助标注 + Markdown化 + Embedding
- **存储**：向量数据库（Chroma / Milvus）
- **使用**：Obsidian + RAG + GraphRAG
- **飞轮**：自动化工作流（n8n / Coze）
