# f4faadff37c0b43b

> 视频号逐字稿知识化 · 楚门三层次框架

## 事实（客观信息）

**事实**

- 视频介绍两种方法：方法1接入DPCC，方法2接入GPT等其他模型。
- 方法1步骤：打开DPC官网进入APA开放平台，新手充值10块钱够用，按用量扣费。
- 创建API后必须立刻复制保存，关掉页面就找不回来。
- 回到WokeBody设置，添加模型，选择深度求所DPCC，粘贴Key，模型名称选DPCC Vispro或Vis flash。
- 两个新手坑：密钥只在创建那一刻完整显示一次；API等于模型账户钥匙，不能截图发群、贴进代码仓库或发给陌生人，泄露后要第一时间作废。

**规律**

- 接入第三方模型通用的三步：获取API Key → 在工具设置中填入接口地址/Key/模型名称 → 发消息测试。
- 使用自定义模型可按用量扣费，绕过平台积分费用，适合高频轻量使用。
- 密钥安全三原则：创建后立即保存、不对外泄露、疑似泄露立即作废止损。

**洞察**

- 本质是“前端工具 + 外部API”的替换：平台只是交互壳，真正收费的是底层模型，所以自定义接入能省下平台差价。
- 密钥就是资源的“钥匙”，掌握密钥管理能力，才能安全地使用API资源，这是AI工具链中的基础素养。
- 对知识库而言，这套“接入+测试+安全”流程可以沉淀为标准化操作指南，帮助用户从“买积分”转向“按量付费”，降低长期使用成本。
