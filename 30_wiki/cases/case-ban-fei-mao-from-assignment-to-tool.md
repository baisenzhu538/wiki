# 案例：半肥猫把一堂课程作业变成可复用调研工具

> 半肥猫将一堂《AIGC调研方法》课程作业用自己的真实业务重做，通过给AI提供结构化上下文、连续四轮纠偏把AI从"推理"逼到"证据"，最终把单次作业沉淀为一套可复用的"从模糊问题到证据决策型报告"调研工具。

## 一句话摘要

半肥猫用真实业务替代假业务完成一堂调研作业，并用"干净上下文 + 连续纠偏"把AI输出从流畅推理升级为可验证证据，最终让作业变成可复用的调研工具。

## 背景

半肥猫参加了一堂张磊老师的《AIGC调研方法》课程，作业要求用课程方法做一次用户调研。在动手前，他面临三个典型困境：

| 困境 | 具体表现 |
|:---|:---|
| **用假业务练习动力不足** | "拿别人的业务来做的时候你是一个打工的，做自己的真实业务的时候你会变成一个老板——打工的心态和老板的心态是不一样的。" |
| **单次作业无法复用** | 花两三个月做用户画像和产品定位，如果每次都重头来，效率极低。 |
| **AI第一轮回答"太顺"** | 老板买解脱、职场人买底气、博主买效率——听起来很有道理，但"靠推理不是证据"。 |

## 关键事件/决策点

### 决策一：用真实业务做练习

不用假设的业务，直接用自己的真实产品——帮老板用AIGC提升内容生产效率和获客效率。有真实用户（4000+付费），有真实场景，动力完全不同。

### 决策二：给AI提供干净、结构化的上下文

不是直接把原始资料扔给AI。先把张磊老师的课程笔记和自己的产品资料整理成Markdown格式，清理噪音，用明确的标记（第一类/第二类）让AI快速识别重点。

> "垃圾进垃圾出，AI不可能把垃圾变成黄金。"

### 决策三：连续纠偏，把AI从"会说"逼到"给证据"

| 纠偏轮次 | 发现的问题 | 纠偏动作 |
|:---|:---|:---|
| 第一轮 | AI回答太顺——"老板买解脱、职场人买底气、博主买效率" | 质问：你都是依靠推理，有没有证据？能不能引用真实数据？ |
| 第二轮 | AI引用的是微软、海外大企业数据 | 设边界：你引用的是大企业数据，没有中国地区微小企业/个体户的实际情况 |
| 第三轮 | AI默认使用过时训练数据 | 告知时间："现在是2025年5月，你不要用过时的训练数据"。要求补充中国地区数据 |
| 第四轮 | 数据来源杂乱 | 强制要求：标注信源和出处，不要编造，不要扩写，只要事实 |

### 决策四：把调研流程沉淀为可复用工具

最终产出的不是一份调研报告，而是一套"从模糊问题到证据决策型报告"的结构化流程：

- 调研问题澄清
- 假设地图生成
- 证据链补强
- 决策报告输出

并且用AI讨论产品化方案——目标用户是谁、什么场景、第一期做哪些功能、怎么迭代——最终沉淀为PRD文档。

## 结果

| 维度 | Before | After |
|:---|:---|:---|
| 练习动机 | 用假业务/别人业务，"打工心态"，动力不足 | 用真实业务，"老板心态"，问题真实 |
| 上下文质量 | 原始资料直接扔给AI，噪音多 | 结构化Markdown，重点明确 |
| AI输出 | 流畅推理，缺乏证据 | 有信源、有边界、有事实 |
| 交付物 | 单次作业报告 | 可复用调研工具 + PRD |

本质变化：作业从"交差"变成了"资产"——以后每次做定位、用户画像、课程定价、销售策略都可以反过来调用。

## 复盘与洞察

1. **最难的不是让AI给答案，而是自己有没有真实的问题、有没有判别的标准、有没有持续纠偏的能力。** 真实业务提供了问题，结构化上下文提供了标准，四轮纠偏提供了习惯。
2. **AI的"丝滑回答"是危险的。** 顺口的结论往往是合理推理，不是证据。必须逼AI回答"证据在哪里"。
3. **工具化的前提是目标收窄。** 不是做"万能调研助手"，而是做"从模糊问题到证据决策型报告"的固定流程。
4. **证据必须带边界。** 时间、地域、客群、信源，任何一条缺失都会让结论失真。

## 可迁移模式

### 可复用条件

1. 你正在学一门方法论课程，有完整的作业要求。
2. 你有一个真实的、正在进行中的业务问题。
3. 你愿意花时间给AI提供干净、结构化的上下文。
4. 你有足够的判断力来识别AI回答中的推理和证据。

### 不可复制的场景

- 你只是想"快速完成作业"而不是解决真实问题（动力不足）。
- 你没有真实业务，只能用假设场景练习。
- 你不愿意检查AI的证据，习惯性相信"丝滑的回答"。

### 关键转折点

> 最难的不是让AI给答案，而是自己有没有真实的问题、有没有判别的标准、有没有持续纠偏的能力。

## 失败模式/教训

| 失败模式 | 真实症状 | 可执行修复 |
|:---|:---|:---|
| **把作业当终点** | 调研报告写完就丢，下次从零开始 | 在动手前定义"这次作业要沉淀成什么工具/模板/检查清单" |
| **把原始资料直接扔给AI** | AI输出泛泛而谈，抓不住课程重点 | 先整理成结构化Markdown，清理噪音，标注"第一类/第二类"重点 |
| **相信AI的顺回答** | 结论听起来很有道理，但无法验证 | 强制要求AI列出证据、信源、时间、地域，没有证据就打回 |
| **不给AI设边界** | AI引用大企业、海外、过时数据 | 明确告知"中国地区微小企业/个体户""2025年5月"等边界条件 |
| **目标定成万能调研** | 工具什么都说，什么都不准 | 收窄为固定流程：问题澄清→假设地图→证据补强→决策报告 |
