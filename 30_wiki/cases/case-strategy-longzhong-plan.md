**战略内容**：成就霸业→三足鼎立→四击北伐。六大举措+执行团队（诸葛亮/关羽/马超/李辉）。

**失败四因**：
1. 资源禀赋不对等（2州 vs 9州）。
2. 生态联盟脆弱（荆州不可兼容）。
3. 执行环节出错（关羽失荆州/夷陵之战）。
4. 宏观环境误判（武都大地震→陈仓古道断绝）。

**核心洞察**：最完美的战略规划也可能被四个因素摧毁——BRM的"执行"环节从来不是自动完成的。

## 背景

东汉末年，刘备屡遭挫败后屯兵新野，求贤若渴。建安十二年（207 年），刘备三顾茅庐，请诸葛亮出山。诸葛亮在《隆中对》中为刘备描绘了"兴复汉室、成就霸业"的总体蓝图：先取荆州为家，再取益州建基业，东联孙权、北抗曹操，待天下有变则两路北伐。这一规划后来成为蜀汉政权的基本战略框架，也被视为中国古代最完整的战略规划之一。

## 关键决策

1. **战略目标**：成就霸业、兴复汉室。
2. **战略主题**：先形成三足鼎立，再伺机北伐。
3. **六大举措**：
   - 东联孙权，结成抗曹联盟；
   - 北抗曹操，避免正面决战；
   - 跨有荆、益，建立两州根据地；
   - 西和诸戎、南抚夷越，稳定后方；
   - 内修政理，积蓄国力；
   - 天下有变时，荆州出宛洛、益州出秦川，两路北伐。
4. **执行分工**：外交与整体筹划由诸葛亮负责；荆州方向倚重关羽；川西、羌地联络倚重马超；南中安抚倚重李恢。

## 可迁移场景

- 制定公司级长期战略时，把"资源禀赋—联盟生态—执行路径—宏观环境"四张清单同时摊开核对。
- 在资源明显劣势时，避免把战略成败押在单一理想化假设上。
- 与互补伙伴建立联盟时，提前约定利益分配与冲突解决机制。
- 关键岗位的人事安排必须与战略举措一一对应，避免执行断层。
- 战略制定阶段就要研究宏观环境（政策、地理、技术、周期）的长期变化，不能只看当下机会窗口。

## 教训

- 最完美的战略规划也可能被执行和外部因素摧毁，战略不是一次性交付物。
- 战略必须与资源禀赋匹配，两州对九州的差距难以仅靠谋略弥补。
- 联盟关系需要持续经营，利益冲突会瓦解最佳战略设计。
- 对宏观环境（尤其是不可逆的长期变量）的误判，会让后续所有战术努力付诸东流。

## 失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| **战略与资源禀赋不匹配** | 以弱胜强的规划依赖"天下有变"等理想条件，一旦条件不出现便无以为继 | 制定战略时做敏感性分析，列出关键假设并准备 B 计划 |
| **联盟生态设计缺陷** | 荆州对孙刘双方都是必争之地，联盟因领土冲突从合作转向敌对 | 在联盟设计阶段明确不可兼容的利益红线，必要时用条约或第三方机制隔离冲突 |
| **关键执行节点失控** | 关羽失荆州、刘备夷陵战败，战略双翼被折断 | 建立关键节点的监控、授权与应急预案，避免单一将领的决策毁掉全局 |
| **宏观环境误判** | 隆中对假定可出秦川、暗度陈仓，但武都大地震已使古道断绝，后勤崩溃 | 将宏观环境研究纳入战略前置环节，对地理、政策、技术等长期变量做情景规划 |

## 战略拆解表

| 维度 | 隆中对的做法 | 现代映射 |
|---|---|---|
| 战略目标 | 成就霸业、兴复汉室 | 企业愿景与终局目标 |
| 战略主题 | 三足鼎立 → 四击北伐 | 阶段目标与关键战役 |
| 关键举措 | 东联孙权、北抗曹操、跨有荆益、内修政理 | 核心业务动作 |
| 执行团队 | 诸葛亮/关羽/马超/李恢 | 关键岗位与责任人 |
| 外部变量 | 武都大地震、联盟破裂 | 宏观环境、生态伙伴 |
| 失败根因 | 资源、联盟、执行、环境四重错配 | 战略假设失效 |

## 执行检查清单

- [ ] 战略目标是否被分解为可验收的阶段主题？
- [ ] 每个关键举措是否对应到具体责任人与资源？
- [ ] 是否列出 3–5 个关键假设并准备 B 计划？
- [ ] 联盟/合作伙伴的利益冲突是否被识别并设计隔离机制？
- [ ] 宏观环境（政策、地理、技术、周期）是否做过情景规划？
- [ ] 执行节点是否有监控、预警与应急预案？
- [ ] 资源禀赋差距是否被量化，而非仅靠信心弥补？
- [ ] 战略复盘是否同时看结果与假设，而不是只看胜负？

## 适用边界

- 适用于需要制定 3–5 年公司级战略或业务单元战略的场景。
- 适用于资源弱势方制定差异化或联盟型战略。
- 不适用于高度确定、无需外部协作的单一市场作战。

## 常见误区

| 误区 | 正确理解 |
|---|---|
| 战略好就一定能赢 | 战略只是起点，执行、资源、环境都会改变结果 |
| 失败都是执行不力 | 有时失败根因是战略假设本身错误 |
| 盟友永远可靠 | 联盟需要利益结构维护，否则随时破裂 |
| 宏观环境不可预测就不研究 | 情景规划可以提高应变能力 |
| 人定胜天 | 承认外部约束，才能制定可落地的战略 |

## 延伸问题

- 如果诸葛亮提前知道武都大地震，隆中对是否会有不同的北伐路线？
- 企业在制定 3–5 年战略时，如何防止把理想化假设当作确定性事实？
- 可参考 `[[strategy-domain-digest]]` 中的战略落地框架，把本案例的教训映射到自身业务。

## 一句话总结

隆中对是中国古代最完整的战略规划之一，它的失败提醒我们：战略再完美，也必须在资源、联盟、执行、环境四个维度上同时成立。
