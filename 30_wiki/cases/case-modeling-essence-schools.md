---# 本质建模案例：知识付费派、经验萃取派与学科建模派的三派分野

> 来源：Truman-高阶建模-本质建模-案例-02 | 一堂建模能力培训（Truman）

## Background

一堂在建模能力培训中，发现课程设计者、方法论负责人和外部顾问经常对"什么是好模型/好课程"争吵不休。表面看是审美分歧，实质是大家对知识生产的流派定位不同：有人按知识付费的启发性标准验收，有人按内部萃取的可复制性标准验收，有人按学科建模的普适性标准验收。Truman 用一张三派对比图（萃取范围 / 目标 / 手段 / 角色）把隐性分歧显性化，让团队先选流派、再定标准。

## What Happened

培训现场，Truman 展示了"知识付费派 / 经验萃取派 / 学科建模派"的三列对比图：

| 维度 | A. 知识付费派 | B. 经验萃取派 | C. 学科建模派 |
|:-----|:------|:------|:------|
| **萃取范围** | 单个案例 / 单个人 | 组织内经验 | 大量案例 / 跨领域经验 |
| **目标** | 知识商品，启发性 | 提升团队做事能力 | 普适有用 + 提升各行业做事能力 |
| **手段** | 找切口、讲故事 | 复盘、建模 | 案例研究、建模、抽象方法论 |
| **角色** | 知识 IP / 知识付费公司 | 公司内部 | 行业专家 / 教育 / 培训公司 |

随后他用一堂自身做课过程说明：一堂核心方法论（五步法、单元模型、决策框架）属于学科建模派，必须经得起"大量案例 + 跨领域 + 反例撞击"的验收；而内部新人培训 SOP、某讲师个人故事课，则可以分别按经验萃取派或知识付费派的标准来要求。

## 结果

- 团队停止用"启发性"标准去争论学科级模型的科学性，也停止用"普适性"标准去苛责内部 SOP。
- 课程评审会引入"先定流派，再定标准"的前置问题，评审冲突减少。
- 一堂将学科建模派定位为核心方法论建设路径，并明确成为 TCP-R 高级专家需要走学科建模路线。

## 可迁移场景 / 使用边界

| 场景 | 说明 |
|:-----|:------|
| **验收一门课程或方法论** | 先判断它属于哪一派，再用对应维度打分，而不是混用标准。 |
| **企业内部知识管理** | 区分"内部分享型"（经验萃取派）与"学科级方法论"（学科建模派），分配不同资源。 |
| **个人职业定位** | 想走知识 IP、内部教练还是行业专家路线，对应三派角色选择。 |
| **引入外部顾问/培训** | 根据企业需求选择流派：要传播选知识付费派，要落地选经验萃取派，要建体系选学科建模派。 |
| **对外发布模型/框架前** | 如果宣称是学科级方法论，必须准备好大量跨领域案例和反例验证，否则应降级定位。 |

## 诊断信号

| Signal | Lens | Follow-up |
|:-----|:-----|:------|
| 团队验收课程/方法论时，不同成员的质量标准互相冲突 | 三派混用 | 先统一目标：我们想做知识付费、组织萃取还是学科建模？ |
| 一个模型同时被批评"案例太少不科学"和"太抽象不落地" | 用错了流派的验收标准 | 用三派四维度（萃取范围、目标、手段、角色）重新定位它 |
| 个人想靠几个爆款案例就成为行业专家 | 混淆了知识付费派与学科建模派的角色 | 评估自己是否具备跨领域案例库和反例验证能力 |
| 内部 SOP 被外部顾问评价"过度抽象、无法使用" | 学科建模标准侵入经验萃取场景 | 把抽象层级降到组织内可执行，补充上下文和触发条件 |

## 失败模式 / 常见陷阱

| 模式 | 真实症状 | 可执行修复 |
|:-----|:-----|:------|
| **用知识付费思维做学科级产品** | 案例少、边界大、经不起反例；用户听完有启发，但无法复用 | 回到源头重新界定边界与证据标准；启动撞击实验，以推翻模型为目标找反例 |
| **用学科建模标准做内部 SOP** | 过度抽象，落地成本过高；一线员工看不懂、用不上 | 把模型降维到组织内具体场景，补充触发条件、输入输出和示例 |
| **三派混用导致团队质量标准混乱** | 验收时互相不服；同一模型有人打高分有人打低分 | 在评审表最上方增加"流派定位"字段，先选流派再打分 |
| **个人 IP 强行做学科建模** | 资源不足、案例不够，产出变成"包装过的个人经验" | 先走经验萃取派沉淀组织案例，再逐步扩展跨领域样本 |
| **把流派选择当道德判断** | 认为学科建模派"高级"，其他两派"低级" | 明确三派是角色/目标差异，不是高低差异；按需求选择 |

## 落地模板：三派定位 Checklist

在评审任何一个课程 / 方法论 / 模型前，先回答以下 6 个问题：

1. **萃取范围**：案例来自单个人、单一组织，还是大量跨领域样本？
2. **目标**：我们要的是启发性、组织内可复制，还是跨行业普适？
3. **手段**：主要靠讲故事、复盘建模，还是案例研究 + 抽象方法论？
4. **角色**：负责人是知识 IP、内部教练，还是行业专家 / 教育公司？
5. **反例验证**：如果声称是学科建模派，是否已经组织过撞击实验？
6. **资源匹配**：现有案例量、时间、团队是否支撑所选流派的证据标准？

如果 1/2/3 的答案不一致，说明流派定位模糊，需先统一再进入评审。
