### 五步法预判A（轻量版）

| 维度 | 关键要点 |
|:---|:---|
| **需求** | 快（便利性）+ 好（咖啡因） |
| **解决方案** | 专注咖啡 + 普通环境 + 办公店 |
| **商业模式** | 中低价 + 小店20平 + 普通店员 |
| **增长** | 直营连锁 + 本地区连锁 |

### 充分做加法3.0选项池

**关键逻辑：充分拆解每个维度的所有可能选项，然后逐一打勾或打叉**

#### 需求选项池

| 分类 | 选项 |
|:---|:---|
| 城市选择 | 一线城市 / 二线城市 / 三四线城市 |
| 品类需求 | 只喝咖啡 / 咖啡带餐 |
| 便利性 | 便利 / 非便利 |
| 品质 | 咖啡因 / 特调咖啡 |
| 价格 | 低价省钱 |
| 其他 | 拍照晒点 / 社交空间 / 咖啡师交流 |

#### 解决方案选项池

| 分类 | 选项 |
|:---|:---|
| 价格带 | 高价 / 中价 / 低价 |
| 产品 | 专注咖啡 / 咖啡奶茶 / 带餐咖啡 |
| 选址 | 街边店 / 社区店 / 学校店 / 商场店 / 便利店 / 办公店 |

#### 商业模式选项池

| 分类 | 选项 |

## Lessons

1. **充分做加法3.0的价值在于"选项可视化"**：创业者很容易陷入"我只想开一家咖啡店"的单一思维，选项池工具帮助看到所有可能性。
2. **打勾 ≠ 确定，打叉 ≠ 否决**：充分做加法的目的是"全面考虑"，而非"全部选择"。最终只选择1-2个组合深入验证。
3. **五步法预判A是轻量版，适合初级预判**：如果案主想做更深度分析，可以升级到五步法预判B（充分做加法3.0全量选项 + 竞争对手分析）。
