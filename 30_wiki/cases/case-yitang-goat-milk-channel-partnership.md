# 羊奶粉「卖地图」区域代理模式案例

## 一句话

羊奶粉行业普遍采用「卖地图」式区域代理——厂商给底价，把区域经营权「卖」给代理商，代理商自负盈亏当小老板。这不是某个品牌的偶然选择，而是品类特征（小众、高教育成本、单区域量小）逼出来的行业公约 `[conf=0.85, source=战略培训课堂口述 + itingnao 3979746 转写]`。

## 关键证据

### 证据 1：战略培训课堂口述

> "羊奶粉的激励方式全都是合伙，全都是你把这个生意托付给我，我就变成你的阿里巴巴。"
>
> — 冉鹏战略培训案例，`10_raw/sources/src_20260614_22f103f0-战略培训-实战案例分析.md`

**解读**：「托付生意」四个字是关键——不是「你帮我卖货我给你提成」，而是「这个区域的生意是你的，赚多赚少看你自己」。底薪提成制下，销售卖不动可以怪产品/怪价格/怪市场；代理制下，代理商卖不动亏的是自己的钱。

### 证据 2：itingnao 3979746 会议转写

> "羊奶粉完全不同，羊奶粉如果你拿薪底薪提成，人家根本不给你干。"
>
> — itingnao 3979746 转写，`10_raw/itingnao/details/3979746.json`

> "羊奶粉的激励方式全都是合伙，全都是你把这个生意托付给我，我就变成你的阿里巴巴。"
>
> — 同上

**解读**：两句连起来揭示了完整的逻辑链——（1）底薪提成制对羊奶无效，因为销售不会为提成去做消费者教育；（2）必须用「托付生意」式的合伙——代理商觉得「这是我的生意」，才会花 20 分钟给消费者讲清楚羊奶和牛奶的区别。冉鹏本人曾任蒙牛雅士利 CSO，接手时公司连亏十年、行业排名十名开外，第一年扭亏盈利 1.8 亿——他对羊奶粉渠道模式的判断来自实操，不是理论推演 `[conf=0.88, source=itingnao 3979746 转写 + 战略培训案例源文件]`。

## 案例背景：羊奶 vs 牛奶，渠道模式为何截然不同

| 维度 | 普通婴儿奶粉（牛奶粉） | 羊奶粉 |
|:---|:---|:---|
| **市场规模** | 大（千亿级） | 小（百亿级，且增速放缓） |
| **消费者认知** | 成熟（"奶粉=牛奶粉"是默认选项） | 需要教育（"为什么喝羊奶不喝牛奶？"） |
| **品牌格局** | 飞鹤/伊利/君乐宝等大品牌强控渠道 | 品牌分散，头部品牌（佳贝艾特）市占率也有限 |
| **渠道模式** | 品牌商直营 + KA/电商分销 + 底薪销售团队 | 「卖地图」区域代理 / 阿米巴包干 |
| **销售团队** | 底薪 + 提成，公司强管控 | 代理商自负盈亏，厂商只管底价和窜货 |
| **终端动销** | 品牌广告拉动，门店自然动销 | 代理商需要教育门店老板 + 消费者，自己做动销 |

**核心差异**：牛奶粉的消费者「知道要买奶粉，选哪个品牌」→ 品牌广告 + 门店陈列能解决。羊奶粉的消费者「不知道为什么要买羊奶粉」→ 需要有人花 20 分钟讲清楚「羊奶和牛奶有什么区别」，底薪销售没有动力做这件事 `[conf=0.80, source=课堂口述逻辑推演]`。

## 模式结构

### 底价供货 + 区域包干 + 自负盈亏

```text
┌─────────────────────────────────────────────────────────┐
│                      厂商（品牌方）                       │
│  职责：生产 + 品牌建设 + 产品培训 + 供货保障              │
│  收入：出厂价（底价）× 出货量                             │
│  风险：品牌风险自留，库存风险转移给代理商                  │
│  管控：仅控窜货底线 + 品牌使用规范 + 区域收回权           │
└────────────────────────┬────────────────────────────────┘
                         │ 底价供货
                         ▼
┌─────────────────────────────────────────────────────────┐
│                   代理商（区域"小老板"）                   │
│  权利：区域经营权、自主定价、自主促销、本地团队管理       │
│  责任：进货库存、地推、客情维护、消费者教育               │
│  收入：终端零售收入 − 进货成本 − 本地运营成本              │
│  风险：库存/资金/本地市场不确定                           │
└─────────────────────────────────────────────────────────┘
```

## 关键决策点：为什么不能用底薪提成？

这个案例的核心洞察不在「代理模式是什么」，而在 **「为什么不能选别的」**：

### 决策逻辑链

```
羊奶需要消费者教育（20 分钟讲清楚"羊奶 vs 牛奶"）
    ↓
底薪销售只做成交不做教育（因为教育的投入产出不在 KPI 里）
    ↓
必须找一个「做教育能赚钱」的人
    ↓
代理商——因为他赚的不是提成，是「经营利润」
    ↓
消费者被教育 → 长期复购 → 代理商赚长期利润
    ↓
因此代理商有动力花 20 分钟教育一个消费者
```

**反事实推理**：如果厂商用底薪+提成模式——

- 销售底薪 5000，提成 5%；
- 教育一个消费者要 20 分钟，成功转化率 30%；
- 销售的最优策略是：不教育，只做高意向客户（节省时间 → 多触达 → 多成交）；
- 没被教育的消费者 → 不买/买了也不复购 → 品类做不大。

### 为什么必须是「托付生意」而不仅仅是「高提成」？

即使把提成从 5% 提高到 20%，仍然不够：

- 提成制下，销售只关心「本月提成」，不关心「消费者一年后的复购」；
- 代理制下，代理商关心「消费者的一年价值」，因为续购利润全归他；
- 底薪销售的「心理账户」= 工资+提成（短期）；代理商的「心理账户」= 经营利润（长期）`[conf=0.75, source=课堂口述 + Williamson资产专用性框架逻辑推演]`。

## 结果/影响

| 利益方 | 得 | 失 |
|:---|:---|:---|
| **厂商** | 轻资产、低风险、快速铺市、库存风险转移 | 失去终端定价权、品牌控制力弱、代理商老化风险 |
| **代理商** | 当小老板、利润上限高、经营自主权 | 承担库存/资金/本地竞争风险、品牌方政策变化风险 |
| **消费者** | 本地化服务、有人花时间教育 | 价格不统一、不同区域体验不一致、窜货风险 |
| **竞品（牛奶粉）** | — | 如果羊奶模式跑通并扩容，牛奶巨头可能用直营+低价打穿代理体系 |

## 教训

本案例的核心教训是：**小众高教育成本品类不能用底薪提成制做市场，必须用「托付生意」式的代理模式；但代理模式的收益（轻资产、本地深度）必须以失控（窜货、品牌一致性弱、代理商老化）为代价提前设计防控机制。**

具体可提炼为三点：

1. **激励机制决定行为**：底薪销售只做成交不做教育；只有让代理商把区域生意当成自己的经营利润，他才愿意花 20 分钟教育消费者。
2. **底价设计要从终端倒推**：底价不能只算厂商成本，必须覆盖代理商本地运营成本 + 合理利润，否则招商失败或厂商失血。
3. **代理合同要预设退出和收回机制**：没有「不增长就收回」条款，代理商老化后厂商会失去对区域的掌控。

## 失败模式

### 失败 1：窜货是代理模式的癌症

**场景**：A 市代理商销量压力大，以低于合同最低价把货批发到 B 市，B 市价格体系被打穿，B 市代理商向厂商抗议。

**根因**：厂商窜货管控缺失。代理商压货压力 × 无有效追踪机制 = 窜货必然发生。

**应对**：区域编码 + 消费者扫码溯源 + 三级窜货罚则（警告→罚款→取消代理权）。

### 教训 2：底价定错，全盘皆输

**场景**：厂商把底价定在「自己的成本 + 30%」，觉得合理。招商时发现没人愿意接——代理商一算账，加上本地运营成本后净利润不如打工。最后被迫降价，但已经浪费了招商窗口期。

**根因**：底价设计从厂商端出发，没从「终端零售价倒推」。

**应对**：终端零售价 → 减代理商合理利润 → 减代理商运营成本 = 厂商底价上限。如果这个数字 ≤ 厂商生产成本，说明品类不适合代理模式。

### 教训 3：品牌控制力弱是一种隐性成本

**场景**：代理商为了冲量，在门店用「买一送三」的促销，消费者觉得「这品牌天天打折，是不是快过期了」。品牌形象受损，但厂商管不了代理商的促销方式。

**根因**：「卖地图」的本意是下放经营权，但品牌体验的一致性需要强管控——两者天然冲突。

**应对**：合同约定促销方式和折扣底线，设神秘顾客抽查。但需认识到品牌体验不一致是代理模式的结构性短板——如果这是致命问题，考虑升级到强类直营。

### 教训 4：代理商老化 = 厂商慢性死亡

**场景**：某个区域的代理商做了 8 年，赚够了，不再拓展新客、不更新团队、不投入地推。厂商在该区域的销量连跌 3 年，但因为该代理商「没有违反合同」，厂商无法收回代理权。

**根因**：代理合同只有「违规收回」条款，没有「不增长收回」条款。代理商的最优策略是守住现有盘子（低投入），厂商需要的是增长（高投入）——激励不兼容。

**应对**：合同预设「最低年度进货任务 + 增长率目标」，连续不达标则厂商有权收回区域或引入第二代理商。

## 可迁移场景

### 场景 1：地方小众白酒

- **共同点**：区域性强、需要本地关系、消费者教育成本中高。
- **差异**：白酒的消费者教育是「品尝 + 社交货币」，不像羊奶那样需要理性说服。
- **可迁移度**：⭐⭐⭐⭐（高），五要素结构可直接迁移，需调整底价模型中的终端零售价形成机制。

### 场景 2：功能性食品/保健品

- **共同点**：小众、需要消费者教育、毛利空间中高。
- **差异**：保健品合规风险更高，代理商乱宣传可能触发监管风险。
- **可迁移度**：⭐⭐⭐（中高），需增加合规管控机制（如宣传物料强制审核）。

### 场景 3：县域教育培训加盟

- **共同点**：本地化运营、品牌方轻资产、加盟商自负盈亏。
- **差异**：教育是服务而非实体产品，库存风险替换为师资/场地固定成本风险。
- **可迁移度**：⭐⭐⭐⭐（高），五要素中的「定价权」需改为「课程定价权」+「课时费分成」。

### 反例：标品快消不适合

可口可乐如果用「卖地图」模式：产品高度标准化、消费者无需教育、品牌体验必须一致 → 代理商只会比价、不会教育、体验参差。可口可乐的深度分销（直营/强管控）才是正解。
