# ToC 内容付费平台：把“流量↑转化率↓”当因果导致的投放崩盘

> 一堂业务公式拆解培训中的“相关≠因果”错误示范：一个月 GMV 800 万、付费用户 3 万的内容付费平台，团队把“流量和转化率正相关”当成因果，加大投放后 ROI 崩盘。来源：一堂 2026-06-13 业务公式拆解培训（孔阳）。



## 案例背景

| 维度 | 信息 |
|---|---|
| 行业 | ToC 内容付费平台 |
| 月 GMV | 800 万 |
| 付费用户 | 3 万人 |
| 目标 | GMV 翻倍至 1600 万/月 |
| 团队直觉 | 流量和转化率正相关，加大投放即可 |

---

## 错误的公式拆解

团队当时的拆解停在 L1-L2：

```
GMV = 流量 × 转化率 × 客单价 × 复购率
```

如果直接把“相关”当成“因果”，就会做出错误决策：拼命加大投放，结果转化率越来越低，ROI 崩盘。

---

## 正确拆解：先切分用户，再拆转化

正确的做法是**先切分（+），再拆转化（×）**：

```
GMV = 新用户 GMV + 复购用户 GMV + 转介绍 GMV
```

再分别拆解：

```
新用户 GMV = 曝光量 × 点击率 × 落地页完成率 × 支付转化率 × 首单客单价

复购用户 GMV = 复购用户数 × 复购率 × 复购客单价

转介绍 GMV = 转介绍人数 × 转化率 × 客单价
```

拆完后，三类用户的增长逻辑完全不同：

| 用户类型 | 核心矛盾 | 优化动作 |
|---|---|---|
| 新用户 | 流量够不够？转化漏斗哪一环掉了？ | 优化投放渠道、优化落地页、优化首单体验 |
| 复购用户 | 用户用得爽不爽？有没有触发复购的动力？ | 提升产品体验、设计复购机制、建立会员体系 |
| 转介绍用户 | 用户愿不愿意分享？分享有没有激励？ | 优化分享体验、设计激励机制、降低分享门槛 |

## 可迁移的校验方法

当你看到两个指标同向变化时，先问三个问题：

1. **有没有可能 A 和 B 都是第三个变量 C 的结果？**
2. **如果控制其他变量，A 变化时 B 是否一定变化？**
3. **能不能用一个小实验验证这个关系？**

如果答不上来，就把它当成“监控指标”，而不是“决策抓手”。
