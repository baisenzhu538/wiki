# 从巨米成本定价失败到 OPC 利润前置：同一个创始人用利润优先框架重做一次

> **定位**：[[framework-利润-利润优先经营框架]] 的一手对照案例——同一创始人先经历「成本定价 + 资本驱动扩张」的失败，再以「利润前置 + 轻资产」重做，是利润优先框架最完整的真实验证。

> 一句话：巨米死于「利润是事后剩余」，OPC 活于「利润是前置设计」——同一个创始人、同一个技术底盘，区别只在是否把利润放进单元模型的第一行。

---

## 案例过程

### 阶段一：巨米（2011-2022）——从成本定价到资本驱动扩张

| 阶段 | 决策 | 后果 |
|:---|:---|:---|
| 早期（2011） | 采用成本加成定价 | 利润不是前置设计，而是事后剩余——价格 = 成本 + margin，成本一失控就没有利润 |
| 2018 | 资本方入局，附带建厂条件 | 失去决策权，被迫战略扩张——工厂、产能、人员都被资本节奏推着走 |
| 扩张期 | 为拿订单和融资数据选择「先亏后赚」 | 负向单位经济模型下，规模越大亏损越大 |
| 后期 | 国企股东入场，业绩对赌 + 面子工程 | 投入大量研发和人员，成本彻底算不过来 |
| 疫情后 | 只能靠银行融资续命 | 现金流极度紧张，最终面临清算 |

> 脱敏来源：30_wiki/personal-os/zhu-lessons-learned.md#L39-L71（公司名已脱敏为「某智能设备公司」）

### 阶段二：OPC（2022 后）——利润前置的轻资产重做

| 设计项 | 决策 | 对应利润框架 |
|:---|:---|:---|
| 不做重资产 | 设备制造交给供应商，自己只做控制系统 | 单元模型：固定成本降到最低，单件利润结构更清晰 |
| 团队 ≤ 5 人 | 用 AI 与智能体放大个人产出 | 隐性成本控制：不养重团队 |
| 现金流硬约束 | 现结 + 年预付，不接受分期赊账 | 「现金流是空气」：从第一天就锁死现金流风险 |
| 利润前置 | 每单明确毛利目标，不是先规模后利润 | **定价定利润**：价格在接单那一刻就锁死利润结构 |
| 知识资产化 | 10 年经验先沉淀为知识库再提供服务 | 价值定价：卖的是经验与系统，不是工时 |

## 关键数字（证据表）

| 指标 | 巨米（失败模式） | OPC（利润前置设计） |
|:---|:---|:---|
| 定价方式 | 成本加成（利润 = 事后剩余） | 目标毛利前置（每单 ≥ 50%） |
| 资产结构 | 重资产建厂（被资本绑架） | 轻资产（制造外包） |
| 现金流 | 应收账款 + 银行续命 | 现结 + 年预付（无应收账款） |
| 单位经济模型 | 负向 → 规模放大亏损 | 单点为正 → 规模是放大器 |
| 决策权 | 资本方/国企股东主导 | 创始人独立 |

> 数字为比例与区间（脱敏规则：隐去绝对金额），源于 personal-os 已确认结论（#L39-L103），非公开财务数据。

## 根本原因：为什么巨米会失败

1. **成本定价是陷阱**：价格不是按客户价值和利润目标设计，而是按成本加 margin——成本一旦失控，利润直接消失（对照 `concept-定价-价格杠杆` 的三种定价方式）。
2. **资本可以成为枷锁**：附带建厂、对赌、业绩条件的资本会绑架经营逻辑——利润逻辑被股东要求压垮（对照 `dk-利润-资本游戏与真实商业分界线`：巨米玩的是「真实商业」，却用了「资本游戏」的扩张姿势）。
3. **规模不解决利润问题**：在负向单位经济模型下，扩张只是放大亏损——这正是 `framework-利润-利润优先经营框架` 的 F5 规模幻觉。
4. **失去决策权 = 失去利润控制权**：当股东要求做 ROI 明显不好的事，利润结构无法守住——定价权与决策权是利润的地基。

## 一堂方法论诊断

用利润优先框架的五步行动框架复盘巨米→OPC：

| 框架步骤 | 巨米（反面） | OPC（正面） |
|:---|:---|:---|
| 1. 核算真正利润 | 成本加成，从未算单件真正利润 | 每单毛利目标 ≥ 50%，先算后接 |
| 2. 诊断利润结构 | 扩张期利润结构恶化而不自知 | 轻资产结构，利润来源单一清晰 |
| 3. 定价锁利润 | 价格跟着成本走 | 价格跟着利润目标走（`bridge-利润-单元模型-定价闭环`） |
| 4. 客户筛选 | 为订单什么都接 | 只接能守住毛利目标的单 |
| 5. 防线建设 | 靠银行融资续命 | 现结 + 年预付，现金流零风险 |

## 教训（可迁移）

1. **利润必须前置设计**：先定单件利润目标，再谈价格、客户、扩张——顺序错了，后面全错。
2. **融资有价格**：资本的钱有隐藏成本——决策权、扩张节奏、对赌条件。拿钱前先算这笔「资本成本」。
3. **轻资产不一定是退缩，可能是利润结构的最优解**：把重资产外包，把利润留在自己手里。
4. **同一个创始人、同一个技术底盘，可以做出完全相反的利润结果**——变量不在能力，在利润是否被前置设计。

## Critique

- **内部局限**：这是**单一创始人、单一行业（智能设备/控制系统）**的对照，外部效度有限；OPC 的利润前置设计尚在验证期（待验证假设：加工厂付费意愿、采购规模、海外代理），「成功」结论为时过早。
- **外部攻击（幸存者偏差）**：巨米失败与 OPC 设计对照存在事后归因风险——失败可以归因于成本定价，但同期行业环境（疫情、政策、资本寒冬）同样可能是主因；不能仅凭「利润前置」就断定成败差异。
- **外部攻击（资源禀赋）**：OPC 的轻资产模式依赖创始人 10 年技术积累与 AI 放大——这套打法对没有技术壁垒的创始人不可复制；「利润前置」是必要条件，不是充分条件，仍需要单元模型成立（单件利润 > 0 且需求真实）。
