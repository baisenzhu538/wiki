# 转化率私董会实录：古法护肤祛斑项目的动力/阻力/触点三轮共创与幕僚收敛

> ⚠️ **传播限制标注：本卡素材来自私董会现场实录，原始文档含全员保密承诺条款（源文档 L27-L33「本人对在私董会小组、会议、群聊、作业、飞书文档……接触到的非公开信息，承担保密义务」）。本卡已脱敏（案主与幕僚保留姓氏去全名），仅限内部知识库使用，禁止外传。**（比照 #322 Candy 卡先例：保密义务素材，内部库可用）

> **定位**：[[tool-一堂-名利权情动力法]] 与 [[tool-private-board-facilitation-sop]] 的**活体应用样本**——一堂转化率私董会的完整实录：案主古法护肤项目，动力/阻力/触点三轮共创 + 幕僚收敛建议全记录。方法论卡讲「怎么做」，本卡展示「真实项目上做出来长什么样」。

## 一句话

一个熟人生意起步、50+ 女性客群的古法护肤（祛斑主打）项目，在一堂转化率私董会上经三轮共创（动力→阻力→触点）+ 一轮金字塔原理收敛建议，被幕僚团队诊断为「动力天然存在、重点做阻力消除」——核心洞察是**熟人与陌生人的首单阻力结构完全不同，定价与信任策略必须分级**。

## 背景：案主画像与问题（L39-L146）

| 维度 | 信息（实录口径） |
|---|---|
| 业务 | 古法护肤（中药材料+流程工艺，0 添加），祛斑系列主打 |
| 客群 | 约 100 来人，亲朋好友+推荐熟人，祛斑提亮比重最大，年龄 50+ 居多（L133） |
| 渠道 | 双线：熟人私域（成本价）+ 高收费案例（3000+6000）+ 旅游人员/一堂同学；期待拓展私域渠道（L131） |
| 团队/规模 | 2 名+兼职；去年销售 8000（未正式），现每月 2 万以上，仍在试错期，有复购（L129） |
| 提出的问题 | 转化率提升（目标本身未量化，源文档写作「从xxx，提升到xxxx」，L49） |
| 特殊卡点 | **消字号资质**：直播和视频号不能直接说功效，「是卡点；目前尽量多认识人；以 IP 的方式来讲故事」（L142） |

**案主自报的阻力与动力**（第一轮问答，L133/L142）：
- 陌生人首单阻力 = **贵**；认识的人几乎没有首单阻力（目前是熟人生意）
- 复购阻力 = 贵拉长购买时间；可能的解法 = 打折
- 渠道端信任问题 = 用体验装解决；渠道如何解决终端用户信任 = 美容院
- 动力 = 共性案例较多；见效周期 case by case，3-6 个月光泽度明显改善

## 打法：三轮共创实录（L152-L197）

### 第一轮：目标确认——用 2 分钟限时问挖掘信息（L122-L146）

规则：每位幕僚仅限 2 分钟、专注某个模块具体转化率、不讨论五步法战略优化（L124）。产出密度最高的两个问答：

- **成幕僚问「优先人群/阻力/动力/单品销售额」**（L133）→ 逼出案主画像全貌：主推祛斑、100 来人熟客、50+ 居多、阻力=价格、动力=共性案例多。
- **罗幕僚问「首单和复购的主要阻力是什么」**（L142）→ 逼出本案例最关键的分层事实：**陌生人首单阻力=贵，熟人首单阻力≈0**，复购阻力=贵。

这轮验证了 [[yt-model-questioning-practice-canvas]] 的「一句话问题→先说结论的 3-5 句回应」问答结构在真实会上的运转。

### 第二轮：动力/阻力/触点分段共创（各 20 分钟：5 分钟各自闪现 + 轮流分享归类）

**动力共创**（L152-L164）——幕僚假设按名利权情归类（[[tool-一堂-名利权情动力法]] 直接命中）：

| 类别 | 幕僚假设举例（实录原话提炼） |
|---|---|
| 名 | 生物学领域 38 年专家亲身经历；博主亲测有效；配方取值「本草纲目」老祖宗智慧；协和 30 年医生研制；比同龄人年轻 5 岁自然美（L160-L163） |
| 利 | 1 瓶顶 7 瓶（L157）；3 天见效 15 天有效果；1 万人亲测好评；免费体质诊断（L160） |
| 权 | 权威媒体报道；冠军/专家背书（L160）；稀缺原料提取物证明高价格和价值（L162） |
| 情 | 朋友介绍+好友推荐截屏（L157）；「我用了特别好，纯中药，推荐给家人们」；前 10 名买一送一（L158-L160） |

**阻力共创**（L166-L178）——幕僚假设与消减方法**配对**给出（这是本轮的范式价值：阻力不单列，必须配消减法）：

| 阻力 | 消减方法（幕僚假设） |
|---|---|
| 贵 | 锚定物对比、成本摊到每一天（跑医院 10 个药的成本）；不满意退货（L172/L176） |
| 信任（没听过/不靠谱） | 专家背书+检测报告+成分报告；案例+三方证言；before/after 连续剧（L171-L173） |
| 功效疑虑（怕又一次无效） | 保密配方+体验装；先用再付+退款机制；百日祛斑挑战赛与竞品打擂台（L173/L177-L178） |
| 原料疑虑 | 古典书籍+原材料溯源（L173） |
| 不着急（拖延） | 名额锁定（L177） |
| 副作用担忧 | 有保险（L171） |
| 消字号合规 | 平衡配方披露和消字号的保密性（L175） |

**触点共创**（L180-L197）——幕僚假设按「触点+价值」成对给出：

| 触点 | 价值 | 出处 |
|---|---|---|
| before/after 打卡展示（自己和他人） | 真实性+身边效果 | L187/L192 |
| 评论区 | 关注反馈+信任 | L193 |
| 诊断报告页挂购买链接 | **信任度最高，方便购买** | L193 |
| 抽奖/粉丝现身说法 | 制造稀缺+真实 | L187 |
| 邀请制/测评/短视频抽好友皮肤诊断 | 低门槛进入 | L188 |
| 二维码/引导私信/标题党/B·A 图片/水军留言 | 添加+吸引+信任 | L189 |
| 广告重复触达/占领关键字 | 熟悉感→信任感 | L190 |
| 节日生日打折送小样/代言官试用官 | 占便宜心理+口碑 | L192 |

### 第三轮：幕僚收敛建议——金字塔原理总-分-总（L203-L218）

表述要求（L205/L209）：麦肯锡金字塔原理，先说选项再解释为什么；句式模板「如果我是你，我会重点做动力 xx、阻力 xxx 和触点 xxx，是因为____」。选 3 条典型：

1. **老朱（本案参与者）**：「动力天然存在，如果我是你，重点应该在做阻力消除方面，加强背书和触达」（L216）——全场唯一把「动力/阻力不对称」点破的收敛判断：熟客复购已验证动力，瓶颈在陌生人首单的阻力侧。
2. **罗幕僚**：「我重点做动力专家背书、保密配方、before/after；阻力第一次信任感、功效原料；触点线下拜访、展会招商或招募博主，是因为**市场不缺生发和祛斑产品，缺乏真实对自己有效的产品**」（L212）——总-分-总范式样本：选项+理由一句话闭环。
3. **刘幕僚**：「先不找博主，先自己在小红书发图文尝试（我的产品、我的经历故事、我的专家背景），摸/踩坑完之后再和博主聊；同样的话题坚持重复发，通过留言/互动挖动力/阻力；去竞品直播间/留言区刷用户问题找竞品盲区」（L214）——最小成本验证路径：先自营再放大。

其他收敛判断（备查）：协和专家+保密配方+权威检测三背书（王幕僚，L210）；差异化古代秘方+「每天 2 元钱美丽陪伴」价格锚点+短视频 IP（徐幕僚，L211）；自己专家身份背书消除信任阻力+亲测有效是触点（林幕僚，L213）；皮肤诊断+试用无效退款（张幕僚，L217）。

## 结果

- 会后闭环动作（L238）：案主指定一名幕僚做鼓励/监督成长人；Top3 优秀幕僚投票；AI 笔记官发作业链接。
- 复盘互评（L233-L236）：「专业的事情给专业的人做 ROI 最高」；老朱建议案主与成幕僚/罗幕僚两位（渠道打法）合作（L235）。
- **注意**：本卡是过程实录，**不含会后执行结果**——转化率是否提升、哪些假设被验证，素材未记录，不编造。

## 可迁移原则

1. **熟人生意 vs 陌生人生意是两套转化率问题**：熟人首单阻力≈0（信任前置），陌生人首单阻力=价格+信任双阻力 → **信任分级定价启示**：对熟人做复购深度（拉长购买周期的会员/套餐），对陌生人做信任基建（背书+体验装+退款机制）再谈价格。与 [[dk-sponsor-three-tier-pricing]] 的分层对接思想同构。
2. **阻力必须配消减方法成对产出**：单列阻力清单没有行动价值，「贵→锚定物对比/成本摊到每一天」「怕无效→先用再付+退款」的配对格式才能直接变成动作（L171-L178）。
3. **动力天然存在时不要硬加码**：已有复购和共性案例的项目（本案），边际收益在阻力消除与触点加密，不在新动力假设——老朱收敛判断的适用边界是「有复购的熟人生意」。
4. **合规限制可以转化为内容策略**：消字号不能直接说功效 → 诊断报告页挂购买链接（信任度最高）、before/after 打卡、IP 讲故事，都是把「不能说的」变成「可以展示的」。
5. **限时 2 分钟问答+先说结论的回应结构**是私董会信息挖掘效率的关键（第一轮实录验证）。

## 教训

- **目标未量化则共创无靶心**：案主问题写作「从 xxx 提升到 xxxx」（L49），全程没有具体数字靶子——三轮共创只能做假设池，无法排序优先级。下次私董会应把「量化目标」作为准入门槛（画布 L113-L116 的流程触点栏也因此留白）。
- **共创密度≠收敛质量**：三轮共产生成 30+ 条假设，但收敛轮只有 15 分钟、9 人各一条——真正的收敛质量取决于「理由」质量（罗幕僚「市场不缺产品缺真实有效」一句话胜过十条罗列）。
- **熟人生意数据会掩盖转化率问题**：100 来人熟客、月 2 万的销售数据无法回答「陌生人转化率是多少」——因为样本里几乎没有陌生人。分层诊断要先问「这个数字是哪层人群产出的」。

## Critique

### 外部攻击者 1：转化率方法论本身——「案例多」不等于「转化率可提升」

本案动力侧最强的证据是「共性案例较多」（L133），但祛斑产品效果 case by case（3-6 个月），**个体差异大恰恰是转化率的天然阻力**——别人的 before/after 对潜在客户的说服力受「我们肤质不一样」心理折损。幕僚们提出的 before/after 连续剧、挑战赛等触点假设都没有处理这个折损机制。案例展示策略需要补充「同类肤质/同龄分桶」才闭环。

### 外部攻击者 2：熟人生意样本的选择偏差——结论可能不可迁移到陌生人市场

全场最亮洞察「陌生人首单阻力=贵」建立在一个未被追问的前提上：案主还没真正做过陌生人生意（渠道端只有想法）。**「贵」可能是陌生人对不知名产品的合理风险定价，而非价格本身问题**——如果是信任问题伪装成价格问题，那么「打折/成本摊到每一天」这类价格类消减法会全部失效，钱白烧。罗幕僚的体验装方案（L142）碰巧是对的，但理由（渠道信任）和本案需要的理由（陌生人信任）不同。

### 内部局限：单场过程实录，无执行数据

本卡证据止于会议本身：假设池和收敛建议的质量可评，但无一被验证；毛利率「还没计算」（L142）；投屏文档内飞书图片外链不可达，共创画布截图内容未纳入（文字层一等证据已足）。

## 失败模式

| 踩坑方式 | 表现 | 避免方法 |
|---|---|---|
| 把熟人生意结论直接套陌生人市场 | 按「熟人≈0 阻力」线性外推，对陌生人做加法营销烧钱 | 先小样本测陌生人首单，区分「贵」是价格问题还是信任问题 |
| 阻力清单不配消减方法 | 共创产出漂亮清单，会后无法行动 | 强制配对格式：每条阻力必须带「消减方法」才算产出 |
| 动力堆砌症 | 已有复购的项目继续加动力假设 | 先判断动力/阻力哪侧是瓶颈（老朱判断），再分配共创火力 |
| 合规卡点当死结 | 消字号「不能说功效」导致内容停摆 | 转「可展示」策略：诊断报告页/before-after/IP 故事 |
| 共创目标不量化 | 「从 xxx 到 xxxx」无靶心，假设无法排序 | 私董会准入门槛：案主必须带基线数字+目标数字 |

## When NOT to Use

1. **需要已验证结论时**——本卡是假设池+收敛建议的过程实录，没有任何被验证的转化率结论；找已验证案例去 [[case-一堂-阻力篇案例库]]。
2. **纯线上陌生人流量生意**——本案的熟人双线结构、50+ 客群、消字号约束都是特定上下文，直接套用触点假设会错配。
3. **替代方法论学习**——先读 [[tool-一堂-名利权情动力法]] 和 [[tool-private-board-facilitation-sop]] 再看本卡，顺序反了会把实录当教程。
4. **非私董会场景的三轮共创**——限时 2 分钟+金字塔收敛的节奏依赖主持人和 AI 笔记官的现场配置，松散团队照搬会散架。

**跨卡模式**：与 [[dk-sponsor-three-tier-pricing]]（王非私董会案）对照，两场私董会的收敛建议都指向「**分层对接**」——本案是熟人/陌生人分层定价，赞助案是 Logo/精准/内容资产分层报价。私董会作为方法，其产出往往不是单一答案而是**结构化的分层策略**。

**最终判断**：本卡价值不在结论（无执行数据），而在**过程范本**——三轮共创的组织格式、阻力配消减法的产出纪律、金字塔收敛的表述纪律，都是可直接复用的会议工程。转化率提升本身，等案主会后执行数据回来再评。
