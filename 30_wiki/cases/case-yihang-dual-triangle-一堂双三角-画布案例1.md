| A. 场景 | H. 审美 | H. 体系 |
|---|---|---|
| 【细分场景】：学生写完论文初稿 → AI预审 → 输出结构化问题清单 → 学生自行修改基本问题（格式、投稿规范、参考文献、数据基础检查等）→ 带着剩余问题（创新贡献度、方法严谨性等深层次问题）与导师讨论<br><br>【内核】：帮学生筛掉基本问题（格式、投稿规范、参考文献真实性、数据基础检查、AI味儿等）——这些问题你自己就能改<br><br>【边界】：它主动不做什么？砍掉哪些非场景？<br>❌ 不做「该不该接受」的判断——不是审稿人，不替导师做录用决策<br>❌ 不做高级造假检测——不判定造假，只标记可疑信号，最终判断由导师人工做<br>❌ 不做论文润色/改写——只指出问题，不替学生改句子<br>❌ 不做跨领域评审——只覆盖电信/电子工程<br>❌ 不做实验补做方案设计——只指出实验缺失，不给具体实验方案<br>❌ 不做论文写作教学——不教怎么写论文，只评审已有稿件<br>❌ 不做创新点判断——只检查「论文自己说的话前后对不对得上」，不替学生判断创新性够不够——这是新增的边界，对应你说的「深层次问题留给导师讨论」 | 1) 对标已录用论文的最佳实践；<br>2) 最佳论文奖论文的结构和表达风格；<br>3) 出口式诊断语气（以XX期刊标准，差在这几个地方）；<br>4) 讲香策略三化：场景化+数字化+升华化；<br>5) 导师视角而非审稿人视角：目标是「帮学生改好」不是「给论文打分」<br>6) 五维评分体系：实验完整性 / 创新贡献度 / 方法严谨性 / 结构与表达 / 数据可信度 | 1) 三步评审流程：阻断检查 → 期刊边界匹配 → 技术深度评审<br>2) 三色灯阻断机制：🔴 终止 / 🟡 警告 / 🟢 继续<br>3) 期刊等级基线模型（Tier 0-8）：创新基线 + 实验期望基线 + 可复现性基线 + 方法严谨性基线<br>4) 三驱动创新分类：理论驱动型 / 方法驱动型 / 工程驱动型<br>5) 场景-约束-方法勾连检查模型：场景声明 → 约束推导 → 方法回应 → 断裂标注<br>6) 数据可信度四维检测框架：图表异常 + 统计异常 + 来源异常 + 数值矛盾<br>7) 参考文献抽样策略：最近3年优先、小众期刊优先、高引文献优先 + 随机抽样<br>8) AI味儿量化检测清单：引号强调、破折号频率、空洞套话、段落均匀度等10项指标<br>9) 修改路线图模型：第一步→第二步→等级跃迁建议 |

|---|---|---|
| 1) journal-tier-baseline.yaml：期刊等级定义 + 创新基线 + 实验基线 + 可复现性基线 + 方法严谨性基线<br>2) IEEE-journal-mapping.yaml：电信8个子领域 → 期刊映射 + 各子领域特殊指标（如多光谱的SAM/SID/ERGAS）<br>3) early-warning-journals.yaml：预警期刊清单 + 掠夺性特征库<br>4) 目标期刊已发表论文样本：最近3年录用论文的结构/表达/实验深度标杆<br>5) 目标期刊最佳论文/高引论文：作为审美标杆的顶级样本<br>6) 各期刊模板规范：字数范围、图表要求、章节结构要求<br>7) 各任务类型必报指标清单：分类 → Accuracy+Precision+Recall+F1；检测 → mAP+Recall@IoU+FLOPS等<br>8) AI味儿特征库：引号强调、破折号、「值得注意的是」「综上所述」等高频套话模式<br>9) 常见虚假文献模式：AI幻觉高发特征（小众期刊+跨领域+最近3年+看似合理的DOI格式）<br>10) 测试集论文样本：5-10篇真实论文（含已知问题和已知合格的），用于验证阻断率和误报率 | 1) PDF解析：提取文本、图表、表格、参考文献列表<br>2) 图表提取与排列：将论文所有图表提取出来、并列排列，检查复用/拼接<br>3) Web搜索：验证DOI是否解析到真实论文页面、查预警期刊状态、验证数据集链接<br>4) 统计检验：卡方检验（尾数分布）、Benford检验（首位数字分布）、变异系数计算<br>5) 曲线分析：多条实验曲线的导数相关性分析、形状相似度判断<br>6) 自然语言理解：提取场景关键词→映射场景类型→加载硬约束→检查方法回应<br>7) 数值交叉比对：正文 vs 表格 vs 图表 vs 摘要中的同指标数值自动提取和比对<br>8) 结构化报告生成：Markdown格式、评分表格、问题清单、修改路线图<br>9) 置信度分级逻辑：多信号叠加升级机制（低→中→高→阻断）<br>10) 期刊等级匹配引擎：目标期刊名称→查baseline→加载对应等级的全部评审基线 | 1) 「只看前后对不对得上」：判断技术使用场景，看看理论场景和应用场景是否一致<br>2) AI味儿量化检测：把「像AI写的」从主观感受变成可统计的指标<br>3) 数据可疑信号检测：用统计方法（尾数偏好、误差棒异常）代替直觉判断 |
