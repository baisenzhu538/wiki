# 案例：VPN场景

> Candy在Problem OS逐字稿中使用的核心案例——展示一个低质量提问如何一步步消耗双方。

## 场景还原

同事问："咱们线下数据库要同步线上主库，我在家怎么访问？"

回答："用VPN就行。"

## 问题链分析

| 层次 | 暴露的问题 |
|:---|:---|
| 表面 | 提问者不知道VPN是什么 |
| 中层 | 提问者有顾虑（安全/数据风险）但没表达 |
| 深层 | 提问者没定义清楚自己真正的问题是什么 |
| 最深层 | 一次低质量提问消耗了三样东西：回答者的时间、提问者的信任、问题本身的解决效率 |

## 映射到方法论

Problem OS的核心痛感：

1. **提问者没定义清楚问题**——把"我怎么安全地完成数据同步"表达成了"怎么访问"
2. **回答者预判了顾虑但对方不信任**——说了VPN但对方不信"这样就行了"
3. **一次低质量提问消耗双方关系**——如果提问者事先用Problem OS的框架梳理清楚："我的真实需求是什么？我的顾虑是什么？我真正需要对方确认的是什么？"——整个对话效率会完全不同
