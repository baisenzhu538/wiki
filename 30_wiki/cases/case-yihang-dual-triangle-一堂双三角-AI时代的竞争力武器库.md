## 中间双三角图示

**创造力** ← | → **场景**

**人类三角 × AI三角**

- 人变强了，调教更强AI
- 持续让自己变强

- 有了强AI，辅助人变得更强

**审美** ← **体系** | **基本功** → **数据**

---

## 左上：人要练"创造力"
*敢于提出新解法、新设想、善于高水平创新*

♥ 自我修养
- ✓ 解放思想：大胆提出创造性假设
- ✓ 分层自洽：上下分层可推理，左右自洽可辩证
- ✓ 敢于想象：有自己的独特想象力和设想

基础：敢于跳出旧道路，提出新解法
- ✓ 大胆设想：敢于提出大胆的新解法
- ✓ 灵感闪现：能源源不断提出灵感和Idea

进阶：善于理性分析底层的合理性
- ✓ 一性原理：遵循本质和底层做事
- ✓ 分层自洽：追求下层规律和上层规则统一
- ✓ 辩证思维：找到规律的矛盾性，寻找更优的更好的规律

高阶：构建一套创新工作系统
- ✓ 大胆设想：不设限，大胆解放思想，找到足够多/大的想法
- ✓ 底层自洽：理性评估，找到规律的底层合理性
- ✓ 假设试错：构建实验试错体系，现实中不断验证
- ✓ 模型重构：变成新的模型和范式，稳定复现创新

同义词：创新  提假设  大胆设想

---

## 左下：人要练"审美"
*对于结果的质量有高水平判断力*

♥ 自我修养
- ✓ 重视审美：主动积累专家级别的Top判断
- ✓ 训练审美：设法培养最佳实践细节判断力
- ✓ 无底追求：对于最佳实践的追求永无设限

基础：有基本的判断
- ✓ 有感觉：对于好坏优劣有基本的分辨
- ✓ 有案例：最佳实践清单和复盘
- ✓ 粗打分：20分很差，40分不够，60分可用，80分优秀，99分无懈可击

进阶：能讲出维度和评价方法
- ✓ 有定量：综合加权打分机制
- ✓ 有精度：建立雷达图评估角度
- ✓ 正负表：有to-do list和not-to-do list
- ✓ 校准法：能通过样稿校准、版本对比、真实反馈，让AI逐步接近标准

高阶：能持续push到最佳实践
- ✓ 有超越：基于最佳实践再次突破
- ✓ 有引领：引领更多人的Top审美
- ✓ 有迁移：跨大领域进行审美借鉴
- ✓ 和高水平迁移

同义词：品味  见识  判断力

---

## 中下：人要练"体系"
*对于过程的稳定、有拆解和模型*

♥ 自我修养
- ✓ 明确的定义：对于复杂概念有基本统一的定义
- ✓ 完备MECE：追求逻辑完备，不重不漏
- ✓ 科学工作流：稳定高效的工作流程和里程碑

基础：基础的执行工作流/SOP
- ✓ 工作流：解决某类问题的固定流程/方法
- ✓ 清单：解决某一类问题的清单/禁止清单

进阶：复杂决策有稳定拆解模型
- ✓ 矩阵图：按空间/二维拆解复杂逻辑
- ✓ N步法：按实践拆解成逻辑完善的里程碑结构
- ✓ 武器库：熟练掌握建立各种类型的模型

高阶：自己抽象有竞争力的体系
- ✓ 稀缺工作流：自己建立KnowHow级别工作流
- ✓ 稀缺方法论：构建一整套"本质-方法-技巧-案例"行业稀缺的方法体系。

同义词：框架  工作流  思维模型

---

## 中右下：探索AI"基本功"
*练习使用各种AI工具、善于使用AI工具和特性解决问题*

♥ 自我修养
- ✓ 既不迷信：任何工具都有局限性
- ✓ 也不排斥：任何工具都值得尝试
- ✓ 刻意练习：专家是刻意练出来的

基础：高频使用LLM提示词
- ✓ 提示词工程：撰写复杂专业的结构化框架Prompt
- ✓ 口喷提示词：刻意练习语音输入高水平提示词

进阶：使用更多更丰富工具
- ✓ 封装提示词：系统提示词，YAI-partner
- ✓ 封装自动化：工作流、智能体、Skill、OpenClaw
- ✓ 多工具创造：多模态、VibeCoding

高阶：模型微调/训练，多Agent编排
- ✓ 有算法：看底层算法/模型论文
- ✓ 有协同：AI和人类组织分工和协同
- ✓ 自进化：构建自动化进体系/循环

武器库：打造自己的AI分层武器库
- ✓ 有匹配：不同场景使用什么工具
- ✓ 有理解：最小核心特性（Feature）

同义词：AI工具  AI技术  AI实操能力

---

## 右上：探索AI"场景"
*发掘高匹配的高价值场景，本身就是AI能力进步的重要维度*

♥ 自我修养
- ✓ 强敏感性：持续保持场景敏感性
- ✓ 大胆假设：积极提出场景假设
- ✓ 细分场景：找到高价值的细分场景

基础：大胆提出场景假设
- ✓ 需求捕捉：寻找痛点的/叹气的/不得不做的关键场景
- ✓ 大胆假设：AI在这个场景下发挥足够大的价值
- ✓ STAR模型：个人和组织，下限和上限

进阶：专业分析场景可行性和ROI
- ✓ AI匹配：AI优劣势特性和场景特性匹配
- ✓ 评估ROI：考虑3-5个维度，多场景对比
- ✓ 定义边界：善于剥离场景的内核和边界

高阶：场景创新和持续发现
- ✓ 创新场景：找到未被同行发现的高价值AI场景
- ✓ 持续发现：有源源不断的场景积累和发现能力

同义词：AI机会探索  AI价值预判  AI落地边界

---

## 右下：探索AI"数据"
*高水平的结果需要高水平的数据，主动搜集和积累高质量数据*

♥ 自我修养
- ✓ 数据敏感：对于业务数据有敏感性
- ✓ 资产思维：形成长期的Domain-Knowledge
- ✓ 复利思维：用10年的心态去设计和建设数据

基础：有意识攒高质量案例/数据
- ✓ 正面案例：可参考的正面案例
- ✓ 负面案例：提醒AI警锡的负面案例

进阶：有意识收集多样性数据
- ✓ 形式：非结构化数据，结构化数据
- ✓ 维度：结果数据，过程数据，错误数据

高阶：构建10年尺度数据飞轮（Adapted）
- ✓ 预判：以终为始，思考数据长期的场景和价值
- ✓ 识别：识别哪些数据值得关注和优先级
- ✓ 收集：及时采集，主动获取数据，确保可追溯
- ✓ 处理：清洗萃取，转化成AI可用的高质量数据
- ✓ 使用：回到场景，使用数据真正实现商业价值
- ✓ 反馈：结果评估，信息回流，回到起点迭代形成反馈飞轮

同义词：AI数据资产  AI数据建设

## 底部
**AI竞争力的系统构建，不是学习某一两个高阶技术**
**而是一个刻意练习x螺旋上升的过程**

时间线（从左到右）：
- 培养意识 → 基础 → 进阶 → 高阶
- 追求自我修养 → 开始补盲区 → 提升专业/复杂度 → 体系/创新领先
