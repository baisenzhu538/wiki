# 案例：泡泡玛特 MOLLY 诞生——代理权受制到自有 IP 的「掀桌子」转型

> **定位**：本卡属于 [[framework-popmart-long-termism-operating-philosophy]] 卡组的**转型动因层**案例卡——回答「长期主义经营观是被什么逼出来的」：卡组四卡讲经营哲学/判断法/消费理解/品牌交付（怎么做），本卡讲 2015-2016 年那次决定公司物种的转型（为什么必须变）。

> **一句话**：Sonny Angel 占单店销售额 1/3 但代理权捏在日本版权方手里——扩代理被拒、做特别款被拒、参展也被拒；2016 年王宁微博调研「除了 Sonny Angel 还喜欢收集什么」，50% 留言说 MOLLY，半年后第一个 MOLLY 系列问世，公司从渠道商掀桌子变成 IP 公司——「跟《鞋狗》的故事一模一样」。

## 二、深挖（L1-L5）

- **L1 业务公式**：代理商价值 = 渠道效率 × 品牌方让渡的剩余索取权。当单品占比到 1/3，渠道效率再高，剩余索取权=0——增长越快，命门越外露。**1/3 是「甜点位」也是「绑架点」**：占比太小引不起版权方警惕，大到 1/3 时你的命运已经不在自己手里。
- **L2 假设审计**：代理模式的隐含假设是「版权方与渠道利益长期一致」。三连拒证明假设在规模阈值后失效——版权方担心单一渠道绑架定价权，天然会压制大代理。因此「把代理做得更大」不能解除风险，只会加深风险；唯一解是换物种（自有 IP）。
- **L3 政策/边界**：掀桌子的前提是你已验证「我选品的眼光=市场需求」——微博调研 50% 命中 MOLLY 是转型前最后一次低成本验证。若渠道本身没有需求感知能力（纯铺货型代理），掀桌子=自杀：自有 IP 的第一步不是签 IP，是确认自己有「测出下一个 MOLLY」的能力。
- **L4 失败模式**：详见 §九——核心是「把代理权风险误判为商务谈判问题」（去求更好的代理条款）与「转型后重复依赖单一 IP」（MOLLY 一家独大风险，公司后来以 IP 矩阵对冲）。
- **L5 隐性成本**：掀桌子的隐性成本是**主动放弃当期最大现金流的确定性**——Sonny Angel 是 1/3 销售额的现金牛，转向自有 IP 意味着短期业绩承压+库存风险自担+艺术家关系从零建。素材 L63「不行马上调」的不被沉没成本束缚，正是为这种转型付学费的组织心态。

## 四、可迁移场景

- **老朱业务线（健康小屋/药柜/SPD）的供应商依赖审计**：任何单一供应商/授权方占收入或关键 SKU 超 1/4 → 触发「Sonny Angel 测试」：扩权会被拒吗？定制会被拒吗？答案有一个「会」就启动自有能力备份。
- **渠道型公司的物种判断**：毛利率高≠安全（case-popmart-prospectus-pricing 的 60-70% 毛利是自有 IP 之后的事）——先问「剩余索取权在谁手里」，再看毛利。
- **用存量用户做转型前验证**：微博调研成本≈0，命中率 50% 才动手——转型决策前的最后一次验证应该便宜、直接、可量化，而不是咨询报告。
- **被卡脖子清单即转型路线图**：三连拒（扩代理/特别款/参展）逐条列出「别人不让我做的事」，这份清单反过来就是自有化后要自建的能力清单。

## 五、教训（何时学/何时不学）

- **正面（学）**：命门外露时换物种而不是修条款；转型前用存量用户做零成本需求验证；把「被拒清单」当能力建设清单。
- **反面（别学错）**：掀桌子需要已有需求感知能力和供应链承接能力——泡泡玛特敢掀，是因为门店网络+选品数据已在手；纯贸易型代理盲目自有化=把「受制于人」换成「库存自杀」。时机上，王宁等到占比 1/3 才掀——太早掀没有验证资本，太晚掀没有转身余地。

## 六、Critique

- **叙事幸存者偏差**：提炼件 L37 把转型讲成「微博一问、半年问世」的顺滑叙事，隐去了试错成本与同期其他 IP 尝试的失败率。公开报道补充了「2016 年 1 月版权方终止代理」这一催化剂——转型不完全是主动掀桌子，也含被断供后的被动加速；两个版本并存，按「主动布局+被动催化叠加」理解更接近史实。
- **外部对标①（资源依赖理论，RDT）**：Pfeffer & Salancik《The External Control of Organizations》（1978）——组织对关键资源供应方的依赖度决定其自主权丧失度；Sonny Angel 占 1/3 销售额=关键资源依赖成型，自有 IP=垂直内化以重获自主权。本案例是 RDT 在消费零售 IP 场景的标准教科书式演绎。
- **外部对标②（交易成本经济学，TCE）**：Coase/Williamson 纵向一体化逻辑——当市场交易成本（三连拒的谈判成本+被断供风险）超过内部组织成本，一体化（自有 IP）成为更优治理结构。「掀桌子」不是情绪决策，是治理结构切换。
- **鞋狗类比的边界**：耐克与泡泡玛特同构在「代理→被断→自有」，但耐克自有品牌靠产品性能立足（技术资产），泡泡玛特靠 IP 审美立足（情感资产）——后者的护城河更依赖持续签约艺术家的能力，可复制性更低、衰减更快（L43 上市后「潮玩 IP 能红多久」的质疑即此）。
- **检索标注**：本卡为 #596 遗留②补验执行卡——§三表格中 ✅ 项已于 2026-09-02 在线核实（多源互证），增量细节（占比逐年攀升/终止代理催化剂）为单一来源链标注待复核；RDT/TCE 为公认学术框架。

## 七、Synthesis

本卡补上了卡组缺失的**动因环**：framework 卡讲「尊重时间尊重经营」是果，本卡讲这个经营观是被「命运被别人掌握的焦虑」（L35）逼出来的因。链条闭合：**代理权受制（本卡）→ 掀桌子做自有 IP（本卡）→ 减宽加深聚焦（tool 卡）→ 满足感×存在感选品（concept 卡）→ 感官包裹感交付（case 卡）→ 60-70% 毛利兑现（case-popmart-prospectus-pricing）**。没有本卡，卡组四卡回答不了「为什么是 2016 年、为什么是 MOLLY」。「跟《鞋狗》一模一样」的可迁移内核不是热血叙事，而是一个可操作的转型公式：**命门占比超阈值 → 被拒清单写成能力清单 → 存量用户零成本验证 → 半年内出第一拳**。

## 八、Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|:--|:--|:--|
| 单一供应商/授权方占收入超 1/4 | 跑「Sonny Angel 测试」三问：扩权会被拒吗？定制会被拒吗？同台会被拒吗 | 三问答案落纸面，任一「会」→ 立项自有能力备份 |
| 考虑从代理/渠道转自有品牌 | 先做存量用户零成本调研（社群/评论/客服记录），不动供应链 | 验证命中率有量化数字（对标 50% 量级）再签约 |
| 被卡脖子后情绪上头想立刻掀桌子 | 把「被拒清单」逐条改写成「自建能力清单」并排序 | 清单 ≥3 条且每条有承接方案，否则不掀 |
| 自有化后单一自有 IP 占比又超阈值 | 启动 IP/产品矩阵化对冲（防「第二次 Sonny Angel 依赖」） | 头部 IP 占比设上限并纳入季度审视 |

## 九、失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 把代理权风险误判为商务谈判问题 | 团队讨论焦点是「争取更好代理条款/独家政策」而非能力建设 | 改用 RDT 框架重述问题：依赖度不下降，条款再好也是缓刑；设依赖度指标（单一外部 IP/供应商收入占比）季度监控 |
| 无需求感知能力就掀桌子 | 自有化决策依据是「老板觉得能成」，无用户验证数据 | 掀桌子前强制过一次「微博调研式」零成本验证，命中率无量化结果则冻结转型投入 |
| 转型后重复单一 IP 依赖 | 自有 IP 单品占收入比再次逼近 1/3 | 头部 IP 占比设上限；孵化管线常备 ≥2 个候选 IP 在测（泡泡玛特后来以 MOLLY+Dimoo+LABUBU 等矩阵对冲） |
| 把顺滑叙事当操作手册 | 团队引用「微博一问半年问世」论证转型很快很容易 | 复盘时强制补全被隐去的成本项（试错 IP 数/库存风险/组织调整），按「主动布局+被动催化」双因素重述 |
