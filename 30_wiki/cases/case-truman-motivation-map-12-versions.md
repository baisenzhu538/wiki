# 动机地图12版迭代：先观察再设计

> Truman在设计一堂的"学习动机地图"时，没有先画设计稿，而是**先观察了大量用户的学习行为，然后才开始设计**。这张地图经历12个版本的迭代（第一阶段），并在48小时内继续迭代到约23个版本，最终成为一堂课程体系的核心视觉交付物。

---

## 背景

一堂需要一张视觉化的"学习动机地图"，帮助学员理解自己为什么要学习、学习的目标是什么。这个交付物未来会出现在课程介绍、学员导航、营销材料、课堂教材等多个高频场景，因此它的可读性、记忆度和逻辑性都会直接影响用户对一堂课程体系的认知。

Truman承担了这个设计任务。起点不是"怎么画一张好看的图"，而是"用户到底是怎么被驱动的"。

---

## What Happened

### 起点：10个关键词太碎，需要被"产品化"

课程中想传递的核心方法叫"影响力法则46"， Truman 最初提炼出 10 个关键词。但"划重点、背下来"的方式太零碎，既难记忆，也难使用。团队需要把它改造成一个**可以独立交付的小产品**。

### 早期失败：从口诀到"看起来不错"的结构图

| 版本 | 尝试 | 为什么失败 |
|:--|:--|:--|
| 口诀版 | 把 10 个词编成押韵口诀 | 绕口、难记、low，高段位用户反感背诵 |
| 火箭轨道图 | 国外留学背景的同事曼达做的结构图，中间是 IMPROVE，一路 R 下来 | 形状惊艳，但除了"好看"没有用户价值；英文单词不常用，回忆不起来 |

关键判断：**不能模模糊糊站在设计者角度说"好像挺好看"，要问"用户获得了什么"**。

## 结果

1. **交付物成为核心视觉资产**：动机地图被广泛应用于课程介绍、学员导航、营销材料、课堂教材等场景。
2. **从"好看"升级为"好用"**：用户不需要背诵，一眼就能理解"驱动力-影响力"的双路径逻辑。
3. **确立了"小抄式"设计原则**：一堂后续多张工具图都沿用"拿来就用、不背"的设计标准。
4. **沉淀了迭代纪律**：每个切片版本都被记录，成为教研团队复盘和练基本功的素材。

## 可迁移场景 / 使用边界

| 场景 | 说明 |
|:-----|:------|
| **高频复用的核心交付物** | 课程地图、品牌主视觉、产品导航图、SOP封面等会被反复看到的东西，值得迭代到审美上限。 |
| **把复杂方法论变成"一眼可用"的小抄** | 当用户需要快速调用而非深度理解时，用"小抄"形式降低记忆负担。 |
| **有真实用户观察/行为数据作为输入** | 先观察用户为什么学、什么时候放弃、什么时候坚持，再抽象维度，避免闭门造车。 |
| **团队有审美判断力和迭代预算** | 需要有人能像 Truman 一样判断"还能不能再改一版"，并且愿意为关键交付物投入时间。 |
| **不适合一次性、低频的临时物料** | 内部后台页面、一次性的活动海报不需要这种级别的迭代，"足够好"即可。 |

## 失败模式 / 常见陷阱

| 失败模式 | 真实症状 | 可执行修复 |
|:-----|:------|:------|
| **把"好看"当终点** | 评审时只能说"这张图挺惊艳"，但说不出用户获得了什么、能不能直接用起来。 | 强制回答三个问题：用户看完能做什么？不背能不能用？删掉装饰后逻辑还成立吗？ |
| **让用户硬背口诀/缩写/英文** | 设计稿里出现 RAIL、I1/I2、轨道等需要记忆的元素，用户回忆不起来。 | 改为"小抄"逻辑：默认用户不背，信息结构要让第一眼就能定位到自己需要的内容。 |
| **一次成型，不再迭代** | 画完一版觉得"差不多了"就定稿，后续没有版本记录和复盘。 | 对核心交付物建立"还能不能再改一版"的追问机制；每次迭代留档，标注这一版解决了什么问题。 |
| **没有用户观察直接设计** | 团队开会讨论"我们觉得用户需要什么"，然后直接出设计稿。 | 先 dump 用户行为观察，再抽象关键维度，最后才进入设计；设计后找真实用户做"不解释测试"。 |
| **过度追求对称而牺牲信息优先级** | 为了左右对称，把次要信息放大，核心信息反而被弱化。 | 眯着眼睛看图，视觉重心应该落在最重要的内容上；如果次要元素抢注意力，继续调比例和字号。 |

## 诊断信号

> 以下信号来自本卡 frontmatter，正文不再重复。

1. **Signal**：设计评审时，团队只能说"这张图挺好看"，但说不出用户获得了什么。  
   **Lens**：用户价值优先于视觉表现。  
   **Follow-up**：如果删掉所有颜色、图标和装饰，用户还能理解这张图的核心逻辑吗？

2. **Signal**：交付物里出现英文缩写、口诀、轨道等需要用户先背诵才能用的元素。  
   **Lens**：小抄式设计原则——拿来就用，不是背完再用。  
   **Follow-up**：用户不背这个，他第一眼能否直接找到自己要用的信息？

3. **Signal**：某个核心交付物未来会高频复用（课程主视觉、品牌图、导航图、SOP封面）。  
   **Lens**：迭代到审美上限。  
   **Follow-up**：这张图是否已经达到了团队审美的极限？还能再改一版吗？

4. **Signal**：多轮迭代后仍然"能解释但不好看"或"好看但没逻辑"。  
   **Lens**：对称性服务于逻辑性。  
   **Follow-up**：问题是视觉重心不对，还是信息结构本身有歧义？两者要分版本解决。

## 落地模板：动机地图设计自检清单

在定稿任何一张"会被高频复用的核心图"之前，逐条检查：

| 检查项 | 通过标准 | 本案例对应 |
|:------|:--------|:----------|
| 用户价值 | 能不依赖装饰解释清楚"用户获得什么" | 从"好看"转向"理解逻辑、当小抄用" |
| 记忆负担 | 不背诵也能用 | 放弃英文缩写和口诀，改为中文大字 |
| 逻辑结构 | 删掉颜色/图标后依然成立 | 双曲线 → 驱动力/影响力对称结构 |
| 视觉重心 | 眯眼测试，核心信息最突出 | 去掉编号、放大中文、调颜色避免抢注意力 |
| 独立交付 | 脱离讲解也能自解释 | 把 FAB 从课上内容补到图上 |
| 审美上限 | 团队一致认为"改不动了" | 48小时23版，直到"一点毛病都挑不出" |
| 版本留档 | 每版记录了改动了什么 | 教研团队保留每个切片版本 |
