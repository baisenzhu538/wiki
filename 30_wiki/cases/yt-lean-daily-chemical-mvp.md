# 日化沐浴露MVP：不生产产品验证行业机会

> "你不是在验证这个产品本身，而是在验证它背后的核心假设——验证它背后的用户群体，验证它背后的核心卖点，甚至是核心卖点的某一项选项。" —— 张磊，AMA Q4（来源：src_20260616_b1e25c49）

## 案例背景

| 维度 | 内容 |
|------|------|
| 项目 | 日化品细分领域：沐浴露/内衣洗衣液 |
| 提问者状态 | 已有内衣洗衣液项目的实战经验，计划用同样逻辑做沐浴露 |
| 核心问题 | 如何在不生产产品的情况下，用精益测试验证产品内核或生意可行性 |
| 关键方法 | 时光机理论、对标头部（小林制药）、3D打印包装、场景化卖点 |

> 来源：张磊 AMA 口述/笔记，外部可验证性有限。

## 核心问题：到底在验证什么？

提问者的直觉是"做一款沐浴露"，但张磊把问题拉回了一层：在真正开模、投产之前，要验证的不是"产品能不能做出来"，而是**产品背后的关键假设**。

这些假设至少包括：

1. **行业机会假设**：沐浴露这个细分是否还有进入空间？
2. **用户群体假设**：哪类用户会被新产品打动？
3. **核心卖点假设**：去血渍、留香、按压泵小瓶装……哪个卖点真实有效？
4. **包装识别假设**：在洗护区货架上，新包装能否被一眼识别？

张磊的核心判断是：**这些假设大部分可以通过调研、对标、3D打印包装等低成本方式前置验证，而不是等产品生产出来再测。**

### 产品内核验证：不做产品，先测"卖点组合"

| 验证对象 | 低成本做法 | 验证目的 |
|----------|------------|----------|
| 外包装 | 用3D打印快速制作多款包装原型，在货架场景下做对比测试 | 判断哪款包装能在洗护区被一眼识别 |
| 使用体感 | 小瓶装 + 按压泵设计，匹配"洗完澡顺手洗内衣"的场景 | 验证场景下的使用便利性和手感差异化 |
| 核心卖点 | 对标小林制药，聚焦去血渍、微胶囊留香 | 验证这些卖点是否比"杀菌抑菌"更能打动目标用户 |

### 关键结论

> "我们真的生产了吗？没有，我们用3D打印。我们真的设计了吗？没有，我们仔细研究那个场景下的使用习惯，直接找对标。对标完之后，仍然要进一步验证这东西是否有效。"

这个案例的精髓在于：**把"验证行业机会"和"产品研发"拆成两个阶段**。前者用3D打印、对标、调研就能快速排除高风险假设；后者才需要真正投入资金做配方和供应链。

## 对沐浴露项目的迁移建议

基于同样的逻辑，张磊给沐浴露项目的建议可以归纳为三步：

1. **明确要验证的假设**：是行业机会、用户群体、核心卖点，还是包装的识别度？一次测试只回答一个最关键的问题。

## 一堂方法论的映射

| 五步法步骤 | 本案例的对应验证 |
|------------|------------------|
| 需求 | 用户是否真的有这个细分场景下的洗护痛点？ |
| 产品内核 | 哪个核心卖点（去血渍/留香/小瓶装/按压泵）最能打动用户？ |
| 商业模式 | 成本结构和定价能否在日化红海中跑通？（本案例未深入验证） |
| 增长 | 洗护区货架识别度、电商主图点击率等增长要素（本案例未深入验证） |
| 壁垒 | 包装设计、配方、供应链哪一项能形成长期壁垒？（本案例未深入验证） |

## Constraints & Boundaries

| 边界类型 | 说明 |
|----------|------|
| 适用场景 | 日化、快消、包装型消费品等"产品形态可快速原型化"的品类；已存在可对标竞品或先行市场 |
| 不适用场景 | 强技术驱动型产品（如AI算法、硬件）、无对标品的全新品类、需要长周期临床验证的产品 |
| 验证上限 | 3D打印和对标只能验证"卖点方向"和"外观吸引力"，无法替代配方、供应链、成本结构的真实验证 |
| 信息来源限制 | 本案例基于张磊口述经验，外部可公开验证的细节有限 |

## Common Failure Modes

| 模式 | 症状 | 修复 |
|------|------|------|
| 把"做产品"当成"做验证" | 团队一上来就投钱开模、打样、做配方，几个月后发现用户根本不认这个卖点 | 先列出关键假设，用3D打印、对标、访谈等低成本手段验证卖点方向 |
| 卖点贪多，没有内核 | 包装和文案同时强调去血渍、留香、杀菌、天然、便携等10个卖点，用户记不住 | 用产品内核四要素做减法，一次测试只打一个最尖的卖点 |
| 忽视货架场景 | 包装设计在电脑屏幕上很好看，但放在超市洗护区被淹没，辨识度为零 | 做真实的货架模拟测试，让目标用户在3秒内找到你的产品 |
| 时光机理论误用 | 看到日本有就简单认为中国也会火，忽略渠道、价格带、消费习惯的差异 | 时光机是判断"消费利差"的启发工具，仍需本地用户访谈和竞品调研验证 |
| 验证完卖点就以为万事大吉 | 3D打印包装测试效果很好，但投产后发现配方成本过高、供应链不稳定 | 明确阶段边界：卖点验证通过后，再进入配方、成本、供应链的二次验证 |

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|----------|------------|----------|
| 想进入一个新的日化细分 | 先做一线货架调研 + 对标先行市场（如日本） | 能清晰说出3个竞争机会点和2个致命风险 |
| 纠结产品外观设计 | 用3D打印做3-5版包装，做货架模拟 + 用户5秒测试 | 目标用户在3秒内识别出产品，并能说出1个核心卖点 |
| 不确定核心卖点 | 找10-15个目标用户做深度访谈，对比不同卖点的反应 | 有一个卖点明显获得"这就是我要的"式反馈 |
| 准备启动产品研发 | 先确认哪些假设已经验证，哪些还需要二次验证 | 形成一份"已验证 / 待验证 / 不可验证"假设清单 |
