# 案例：固体红牛如何通过渠道探索找到司机群体

## 一句话

固体红牛是一个把"渠道探索四步法"跑得最鲜活的早期消费品案例：它用扫描找到司机群体，用预判把卡车司机收敛到网约车司机，用加油站单点测试跑通最小盈利模型，再把转化率优化的认知迁移到网吧、台球厅，最终形成可复制的线下渠道网络 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §382-800, 笔记.txt §39]`。

## 1. 背景

### 1.1 产品是什么

固体红牛是一款固态提神含片，卖点非常清晰：不用喝、含在嘴里即可提神、避免喝红牛后频繁上厕所、价格便宜、口味好吃 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §386-390]`。它的目标人群是那些"需要提神但上厕所不方便"的场景——长时间驾驶、网吧开黑、夜班工作等。

### 1.2 创业初期的核心难题

这是一个典型的"新品类 + 新品牌"开局。摆在团队面前的问题是：

- **直销还是渠道？** 团队创始人有大厂市场营销背景，判断标准化产品更适合走代理/渠道模式，以提升资金周转率 `[conf=0.75, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §400-406]`。
- **渠道选择极多，资源极少。** 开车的人、医疗工作者、学生、白领、驴友、电竞玩家、UP 主……人群 × 场景 × 触点的组合可能超过 100 种 `[数字来自 Truman 口述/估算，待独立核实]`。
- **不能凭感觉选。** 早期资金紧张，试错成本过高，一旦连续踩错几个渠道，业务可能就续不下去了。

### 1.3 为什么这个案例值得研究

Truman 在课堂上反复强调，这个案例是在"一堂眼皮底下"跑出来的：团队反复试错、调整、迭代，最终把一个看似简单的提神含片从 0 推到覆盖多个连锁渠道 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §678-684]`。它不是靠一笔大钱砸出来的，而是靠"扫描 → 预判 → 测试 → 建模"的系统方法，一步一步抠出来的。

## 3. 关键决策

### 3.1 决策一：不抄成熟品类的全渠道，回到新品类的原点人群

团队最初研究了红牛和咖啡的渠道，发现这两个成熟品类已经全渠道铺开：商超、便利店、电商、无人货柜几乎都有 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §440-444]`。但如果固体红牛直接跟进这些渠道，作为一个没有知名度的新品牌，根本拼不过。

关键洞察来自 Truman 的提醒：**渠道探索不要看成熟品类的现在，要看它最早的状态。** 团队继续深挖，发现红牛早期 66% 的用户是司机 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §456]`。这成为固体红牛的原点人群假设。

### 3.2 决策二：把"司机"再细分，收敛到"网约车司机"

找到"司机"还远远不够。团队进一步把司机市场拆分：

- **长时间驾驶 vs 短时间驾驶**：大部分人每天开车 30 分钟到 1 小时，提神需求很弱；真正强需求的是长时间驾驶人群。
- **网约车司机 vs 卡车司机**：长时间驾驶人群又分为网约车司机和卡车司机。卡车司机虽然需求强，但触达极难——他们全国跑、不固定、电商无法收货、需要极高密度才能养成购买习惯 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §468-485]`。

最终团队选择**网约车司机**作为早期种子用户：需求强、聚集度高、触达相对可控。

### 3.3 决策三：建立"低成本、可复制、规模化"三个预判标准

锁定了网约车司机后，团队面临第二波选择：饭店、居民区、检修厂、车主社群、商场、加油站…… dozens of 触点。他们没有凭感觉拍脑袋，而是给自己搭了一个预判模型，三个黄金标准是 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §520-532]`：

1. **低成本**：团队 hold 得住，几万甚至更少就能启动，不需要几十万、上百万的渠道入场费。
2. **可复制**：渠道未来可以标准化、足够简单，避免"参加一次会卖一波，第二个月没了"的一次性渠道。
3. **规模化**：覆盖的人数要足够多，天花板不能太低。

用这个模型一筛，很多看上去很美的渠道被直接排除：

- **电商**：专家判断早期需要 5-10 万投放 + 3-4 人团队，确定性还很低，被排除 `[数字来自 Truman 口述/估算，待独立核实]`。
- **汽车检修厂**：全是司机，但不是消费场景，配促销员又太重 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §560-576]`。
- **便利店**：新品类 + 新品牌动销率极低，信心不足 `[conf=0.75, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §580-592]`。
- **加油站**：符合三个标准，进入测试名单。

### 3.4 决策四：加油站亏损时不放弃，而是做转化率优化

加油站第一次测试请了 1 位促销员，1 个月营收约 1 万元。团队一开始很高兴，但一算账发现：促销员工资 + 进口关税等固定成本约 6000 元，加上货款和其他成本，实际是"出多少亏多少" `[数字来自 Truman 口述/估算，待独立核实]`。

这时有两个常见选择：
- A. 放弃加油站，换下一个渠道；
- B. 继续亏着做，至少能跟投资人讲故事。

团队选了第三条路：**把促销员的价值拆解为动力、触点、阻力三个要素，用产品设计和销售机制替代人力。**

具体动作 `[conf=0.82, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §632-674]`：

1. **触点优化**：团队去加油站走用户动线，把货架调到人脸高度、动线必经的高频位置，用大红色视觉抢占注意力。
2. **信息传递**：货架上放大广告语"喝一片不如含一片，方便携带不用找厕所，长途驾驶神器"，把 To B 卖点直接展示给用户。
3. **店员动力**：给店员足够高的销售分成，让他们在卖红牛/咖啡时多说一句"这是新品，不用去厕所"。
4. **降低用户阻力**：用户已经想买提神产品，只需要一个额外的购买理由，转化成本很低。

一轮迭代后，转化率翻了一番，甚至不再需要促销员，模型跑通 `[数字来自 Truman 口述/估算，待独立核实]`。

### 3.5 决策五：网吧渠道从"铺货失败"中找真实消费信号

加油站跑通后，团队开始寻找下一个"去厕所不方便"的场景，选中网吧。但网吧初次铺货大半个月只卖了 2 盒，老板要求撤货 `[数字来自 Truman 口述/估算，待独立核实]`。

团队在清点库存时发现少了 16 盒。追查后发现，网吧老板和网管们觉得好吃，自己吃掉了，日均吃掉 1 盒 `[数字来自 Truman 口述/估算，待独立核实]`。这个信号说明：**不是产品不行，而是用户没有认知、没有动力尝试。**

于是团队调整策略 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §742-754]`：

1. **免费试吃**：给网吧足够多的样品，让用户零成本体验。
2. **场景化陈列**：把产品放在槟榔旁边——去槟榔货架的用户本身就是提神需求人群，功能一致、决策路径最短。

调整后网吧销量上升到大几千元，渠道跑通 `[数字来自 Truman 口述/估算，待独立核实]`。

### 3.6 决策六：把加油站 + 网吧的认知迁移到台球厅

第三个渠道是台球厅。因为有了加油站和网吧的转化率优化经验，团队迁移认知的速度明显加快：知道怎么选触点、怎么设计话术、怎么给渠道方动力、怎么降低用户尝试门槛。台球厅渠道"没有费太多力气"就跑通了 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §768-770]`。

## 4. 结果

- **加油站模型跑通**：从 1 个促销员亏损测试，到优化后去促销员、转化率翻倍、模型盈利；随后覆盖北京、广东几十个加油站，并具备向全国几千上万家加油站复制的潜力 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §682-684]`。
- **网吧渠道跑通**：从半月卖 2 盒到卖大几千，进入全国头部连锁网吧 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §752-754]`。
- **台球厅渠道跑通**：认知迁移后快速复制 `[conf=0.78, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §768-770]`。
- **方法论沉淀**：团队形成了一套"找场景 → 测单点 → 优化转化率 → 复制连锁"的渠道建模能力。

## 5. 业务公式 / 要素映射

### 5.1 加油站单点盈利模型

```
单加油站月利润 = 日客流量 × 转化率 × 客单价 × 30 − 渠道固定成本
```

| 阶段 | 关键变化 | 结果 |
|:---|:---|:---|
| 第一阶段 | 促销员推荐 + 普通货架 | 营收 ~1 万/月，但促销员 + 关税等成本 ~6000+，亏损 `[数字来自 Truman 口述/估算，待独立核实]` |
| 第二阶段 | 高频动线货架 + 大标语 + 店员分成 + 一句话话术 | 转化率翻倍，去掉促销员，模型盈利 `[数字来自 Truman 口述/估算，待独立核实]` |

这个公式说明：线下渠道的利润不只取决于"有没有人买"，更取决于**触点位置、信息传递、渠道方动力、用户决策阻力**这四个要素的系统优化。

### 5.2 网吧渠道从 0 到 1 的要素映射

| 要素 | 第一次失败 | 优化后成功 |
|:---|:---|:---|
| 用户认知 | 没听说过固体含片，品类陌生 | 免费试吃降低尝试门槛 |
| 触点 | 随便摆放在货架角落 | 放在槟榔旁边，精准拦截提神需求人群 |
| 动力 | 用户没有购买理由 | 功能一致 + 口感好 + 不用去厕所 |
| 阻力 | 不知道好不好吃、怕踩雷 | 免费试吃 + 旁边人都在吃 |

### 5.3 与渠道探索四步法的映射

```
扫描 → 预判 → 测试 → 建模
 │      │      │      │
 │      │      │      └─ 加油站/网吧/台球厅的连锁复制 + 转化率工业化
 │      │      └─ 加油站、网吧单点测试
 │      └─ 低成本、可复制、规模化三标准筛选
 └─ 红牛早期用户、司机群体、加油站渠道
```

## 6. 成功原因

### 6.1 人群细分做到了第三层

不是"司机"，而是"长时间驾驶的网约车司机"。越细分，渠道越精准，测试成本越低。

### 6.2 预判模型让团队避免"凭感觉"

"低成本、可复制、规模化"三个标准，把几十个候选渠道快速收敛到可测试范围，避免资源散弹枪。

### 6.3 把"亏损测试"当作学习信号，而不是失败信号

加油站第一次亏损，团队没有换渠道，而是拆解成本结构：促销员的价值能否被产品 + 机制替代？这种思维方式是渠道建模的核心。

### 6.4 转化率优化不是拍脑袋，而是走用户动线

团队亲自去加油站走用户路线，摸查动线触点，找到"没看到、没认知、店员没动力"三个真正的问题。

### 6.5 善于从异常数据中发现真实需求

网吧库存少了 16 盒，表面是"货丢了"，实际是"网管爱吃"。团队把这个异常信号转化为"免费试吃 + 槟榔旁陈列"的关键策略。

### 6.6 从一个渠道跑通后，再迁移认知

加油站 → 网吧 → 台球厅，每一步都复用前一步的转化率优化经验，而不是每个渠道都从零摸索。这是渠道建模阶段的核心能力。

## 教训

### 7.1 如果直接进便利店/电商

新品类 + 新品牌在便利店很难有动销；电商早期需要较大投放和团队。如果团队一开始就把资源砸在这两个渠道上，很可能在验证产品-渠道匹配之前就把钱花光。

### 7.2 如果只停留在"司机"这个层面

卡车司机需求也很强，但触达成本极高。如果没有进一步细分到网约车司机，团队可能在错误的用户群体上浪费大量资源。

### 7.3 如果加油站第一次亏损就放弃

亏损测试是常态。关键不是"亏不亏"，而是"为什么亏、能不能通过优化模型扭亏"。

## 可迁移场景

### 8.1 对消费品创业者

- 不要一上来就盯着成熟品类的全渠道，回到原点人群和原点场景。
- 线下渠道的胜负往往不在产品本身，而在触点、陈列、话术、渠道方利益分配。
- 每个渠道都要算清一笔账：流量 × 转化率 × 客单价 − 固定成本。

### 8.2 对 To B / SaaS 创业者

虽然固体红牛是消费品，但其底层逻辑与 To B 渠道探索相通：

- 扫描行业标杆的早期路径，而不是现在的全渠道布局；
- 用"低成本、可复制、规模化"三标准筛选候选渠道；
- 第一个渠道跑通前，不要分散资源；
- 把渠道方的动力、触点、阻力拆解到可执行动作。

### 8.3 对知识付费 / 内容创业者

- 找"用户聚集且决策成本低"的原点渠道；
- 先单点跑通一个转化闭环，再考虑多渠道复制；
- 转化率优化是永恒的杠杆：同样的流量，转化率翻倍等于获客成本减半。

## 失败模式

### 9.1 把"有需求"等同于"有渠道"

卡车司机需求强，但触达难。很多创业者看到一个强需求人群就冲进去，结果发现触达成本比产品价值还高。

### 9.2 把"第一次测试结果"当作最终结论

加油站第一次亏损、网吧第一次只卖 2 盒，如果团队就此放弃，就不会找到后面的盈利模型。

### 9.3 忽视渠道方的利益

便利店、加油站、网吧都不是你的员工。如果不设计渠道方的分成、动力、陈列支持，产品再好也卖不动。

## 10. 与一堂五步法的关系

固体红牛案例是「渠道探索四步法」在消费品领域的典型落地：

- **扫描**：红牛早期用户数据、加油站渠道历史；
- **预判**：低成本 / 可复制 / 规模化三标准；
- **测试**：加油站、网吧单点最小化验证；
- **建模**：转化率优化 + 连锁复制。

它也说明，渠道增长不是孤立的获客动作，而是与「用户内核」（谁是最刚需的原点人群）、「商业模式」（渠道成本结构）紧密耦合的。
