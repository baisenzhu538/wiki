# 教练式沟通对话案例集（三版本对比）

> 定位：属于 `framework-coaching-leadership-core` 的案例层——四套真实对话的 Before/After 对比，展示教练式沟通（先认同→再提问→帮梳理→找方案，L2278）与权威式/给答案式的差异。**与 `case-leadership-communication-failures`（#280 卡9）的关系**：那张卡详述小红书运营案例（含三版本），本卡补充另外三套（小李项目/销售业绩/AI海报）+ 交叉引用小红书，形成完整案例库。

## 一句话定义

四套同场景不同对话版本证明：**教练式沟通的关键不是话术，而是"先认同再提问帮梳理找方案"的结构 + 让下属自己得出结论**——给答案式看似高效实则培养依赖，权威式直接伤害信任。

## 案例一：小李项目压力（两版本，L1454-1560）

**背景**：软件项目经理小李负责项目交付，客户要求提前一周，加班状态差，总监想沟通缓解压力（L1454-1460）。

### Before（给答案式，L1470-1502）

总监：认可辛苦 → 说"我们主要任务还是全力推进，哪怕加班也得坚持" → 小李说"担心加班也做不完" → 总监："你之前几个子项目不是蛮好吗？说明你能力很强" → 小李："时间太紧了" → 总监："压力是成长的必经之路" → 小李："实在太累了，担心撑不下来" → 总监："我跟同事讲让他们多帮帮你"。

**结果**：小李强打精神"我会好好努力"，总监送走他——"不及时的赞美关怀和支持鼓励，没有给具体的支持和解决方向，最终只给了一个哭笑不得的脸"（L1506）。

### After（教练式，L1514-1560）

总监从会议室出来看到小李还在加班 → 关心："你最近脸色有点白，又熬到这么晚" → 小李说出真实困境（客户提前一周，硬着头皮答应） → 总监**搬椅子坐在旁边**（肢体语言）→ 看关键路径："有什么我能帮忙的" → 小李打开项目文件整理思路 → 总监肯定："排期已经很合理了，你们这一批项目经理我一直最看好你" → 发现小李语气犹豫 → **"不要什么事情都自己一个人扛，出意外及时跟我讲，我来帮你协调资源，给你兜底，隔壁组可以再要两个开发过来"**（L1540-1548）。

**结果**：小李"总监有你这句话我就更有信心了"——放下顾虑（L1552-1560）。

## 案例二：销售业绩下滑（两版本，L2100-2282）

**背景**：行业不景气，销售团队业绩波动，VP 想通过沟通提升下半年业绩（L2100-2102）。

### Before（半教练式但推拉，L2110-2148）

VP：认可努力 → 问"业绩提升对团队意味着什么"（教练味）→ 小李分析 → VP 提 20% 目标 → 小李面露难色"20% 压力很大" → VP 施压："你在这个位置要承担得起责任" → 小李讨价还价"定个 10%" → VP 不满意："我相信你有这个能力" → 小李"尽量争取"。

**结果**：等于不情愿（L2152）——"所有的提问都是教练式提问"的反思（L2158）：提问但不用下属的答案 = 假教练。

### After（真教练式，L2162-2266）

VP 先倾听小李状态（加班/士气低/项目被取消）→ "除了大环境，你觉得还有什么核心原因？"（引导归因）→ 小李说出两方面（士气/精力分散）→ VP 肯定："你提到客户都想抓这点很重要" → "如果聚焦客户，有什么具体方法分类？"（引导方案）→ 小李提出按需求类型分类 → VP 深化："如果只讨论一个维度，哪种更重要？" → 小李定"按需求类型" → 小李主动提出产品组合建议（S 产品/DD 产品）→ VP 惊喜："原来这些产品建议都是你提的" → 引导思考风险："对现有客户和团队有什么影响？" → 小李分析阻力（销售习惯/部门协同）→ VP 收尾："你现在感觉怎么样？对下半年业绩有多少信心？"（探真实状态）→ 小李："刚进来还挺担心，现在至少有七八十分信心"（L2258）。

**结果**："老板放心，我现在马上就回去做方案"（L2266）——主动行动 + 高信心。

## 案例三：AI 海报（两版本，L2650-2790）

**背景**：新人用 AI 做海报不理想，部门经理想帮他提升（L2650）。

### Before（看似没问题但没找到根因，L2656-2678）

主管：问卡点 → 下属："重点不突出效果一般" → 主管："是不知道什么是不好的海报，还是不会用 AI？" → 下属："两个都有" → 主管："你感觉有什么好办法？" → 下属："回去把国外教程再练一练"。

**结果**："听着没毛病，但感觉哪里不太对"（L2682-2684）——提问了但没深入根因，下属回到自我摸索。

### After（教练式+指导式结合，L2692-2782）

主管问进展 → 下属说卡点（信息层级混乱/风格不统一）→ 主管内心判断"抓得蛮准" → 肯定："信息层级和视觉统一性是海报最基础的部分" → "有什么办法更精准控制 AI 生成？" → 下属："指令没描述清楚" → 主管提炼："AI 是工具，主要怎么用？一是先知道想要什么，二是怎么通过提示词画出来" → 下属抓到感觉："我就是卡在提示词写不好" → 主管："你平常怎么练？" → 下属："用 Midjourney，画几十张出一张" → 主管看记录："练习量蛮大的，但有点在舒适区" → "怎么摆脱？" → 下属想不出 → 主管给方法：最佳实践池子 + **before/after 版本对比**（记录每次提示词，分析前后区别，L2768-2772）。

**结果**：下属顿开："之前怎么没想到这么简单的方法，这个也是我主要的绝招和核心能力了"（L2776）——**主管给方法但让下属自己领悟**。

## 失败/成功原因拆解

**共同失败模式（Before 版）**：
1. 认可但没解决——"辛苦了+要加油"不解决具体困难
2. 提问但不用答案——假教练式（销售业绩 Before）
3. 给答案替代引导——小李项目 Before 直接"让同事帮你"

**共同成功要素（After 版）**：
1. **先倾听真实状态**（加班/士气/脸色）——专注+3F
2. **先认同再提问**——"你抓得蛮准""排期很合理"
3. **引导归因和方案**——"除了大环境还有什么原因""有什么具体方法"
4. **给支持兜底**——"我帮你协调资源""给你兜底"
5. **探真实状态收尾**——"你现在感觉怎么样"
6. **给方法让领悟**——AI 海报 before/after 对比

## Critique

### 攻击者 1：案例方法论——"四套案例均为事后构造的对比，缺乏真实过程数据"

**攻击论点**：三版本对比是教学构造，真实对话不会"重录"——案例无法证明 After 版在真实场景中必然产生更好结果（小李可能只是口头配合）。

**回应**：案例的价值在**结构对比**（同一场景不同底层假设的结果差异），且 After 版的结果信号可观察（主动做方案/七八十分信心/顿开）。承认：作为教学案例，应标注"结果信号为对话内观察，长期效果待验证"。

### 攻击者 2：管理效率——"After 版在业绩硬指标场景（20% 目标）过度温和"

**攻击论点**：销售业绩案例中 VP 的目标是硬性的 20%，After 版让小李自己"七八十分信心"——如果小李只定 10% 怎么办？教练式沟通可能弱化业绩要求的刚性。

**回应**：After 版并非放弃目标——VP 通过提问让小李自己认识到"按需求类型分类可提升转化"，目标共识建立在下属自己的方案上（比强压 20% 更可能达成）。承认：卡内应补"教练式沟通不豁免业绩目标——目标刚性 + 路径弹性"。

### 攻击者 3：认知科学——"Before/After 对比可能强化'对话万能论'"

**攻击论点**：案例暗示只要用对沟通方式就能解决管理问题，但认知科学证明大量问题根因在系统（考核/资源/市场），对话技巧无法替代结构性改革。

**回应**：四套案例的 After 版都含**资源支持**（协调开发/兜底/给方法），说明沟通与资源配套才有效。承认：卡内应补"教练式沟通是必要条件非充分条件——需要资源/机制/授权配套"。
