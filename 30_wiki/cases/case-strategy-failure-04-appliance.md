**表面问题**：空调之外的新品类全部失败。

**战略根因**：路径错误——靠渠道优势推新品，但缺乏核心研发能力。渠道能卖空调，不代表能卖其他家电。

**问题类型**：九问题 #4 路径错误。

**教训**：复制成功路径之前先问：这个路径依赖的能力是可迁移的吗？

## 背景

家电公司 G 靠空调起家，在空调市场拥有强大的品牌认知和渠道网络。随着空调市场趋于饱和、产品结构被质疑"不健康"，公司决心大力发展非空调家电（冰箱、洗衣机、热水器等）。公司甚至发现空调业务已被竞争对手超越，于是强势 CEO 决定以个人名字命名新店，把所有家电品类集中进店，并对非空调产品给予更高营销补贴，希望复制空调时代的渠道打法。然而结果是非空调增长率很差，新店 Logo 最终全线改回。

## 关键决策

1. **战略意图**：通过品类扩张摆脱对空调的过度依赖，提升整体营收规模。
2. **打法选择**：把公司最擅长的"渠道 + 补贴"路径复制到非空调品类，包括开新店、集中陈列、加大非空调营销补贴。
3. **资源倾斜**：把高管精力和资金投向渠道端，而非产品定义、研发与品类突破。
4. **结果验证**：市场反馈证明该路径失效，非空调产品卖不动，渠道改造被迫回退。

## 可迁移场景

- 渠道型企业在品类扩张前的能力评估。
- 多元化战略中判断核心能力可迁移性。
- 消费品企业从单一品类向相关品类延伸。
- 强势 CEO 用个人成功路径推动新业务的场景。
- 补贴与渠道激励设计：当补贴方向与品类成功要素错配时如何纠偏。
- 复盘品类失败时区分"执行不力"与"路径错误"。

## 教训

- 复制成功路径之前先问：这个路径依赖的能力是可迁移的吗？
- 渠道是放大器，不是万能钥匙，不能替代产品本身的核心竞争力。
- 品类扩张应优先选择与核心技术栈、用户洞察、供应链能力相近的领域。
- 当新业务的失败 repeatedly 出现时，要怀疑战略路径是否正确，而不是继续加大渠道投入。
- 领导者的惯性（自己擅长什么就做什么）是路径错误的重要诱因。

## 失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| **把渠道能力当万能钥匙** | 用卖空调的方式卖其他家电，忽视品类差异 | 评估每个新品类所需的独特能力（研发、设计、供应链、用户洞察），补足后再进入 |
| **忽视品类核心能力差异** | 认为品牌光环可以覆盖研发和设计短板 | 建立品类进入 checklist：技术、设计、供应链、用户认知、售后体系逐项达标 |
| **用补贴掩盖产品短板** | 对非空调品类给更高营销补贴，但产品定义不到位 | 把补贴与产品力、差异化价值挂钩，而不是与出货量挂钩 |
| **领导惯性驱动路径** | CEO 渠道出身，遇到瓶颈就加大渠道投入 | 引入跨职能评审机制，让产品、研发、用户研究在决策中拥有否决权 |
| **短期销量掩盖长期亏损** | 渠道压货造成虚假增长，库存积压 | 追踪终端动销率而非渠道出货量，用真实市场反馈替代渠道反馈 |

## 战略拆解表

| 维度 | 家电公司 G 的做法 | 现代映射 |
|---|---|---|
| 战略意图 | 摆脱对空调的依赖，发展全品类家电 | 多元化/第二曲线 |
| 核心能力 | 渠道、销售、品牌 | 可迁移能力评估 |
| 选择路径 | 开新店、集中陈列、加大非空调补贴 | 路径依赖 |
| 忽视能力 | 研发、产品定义、品类用户洞察 | 新品类核心能力 |
| 结果 | 非空调增长差，门店 Logo 改回 | 路径错误 |
| 根因 | 把渠道能力当成万能钥匙 | 能力-路径错配 |

## 执行检查清单

- [ ] 新品类是否做过核心能力差距分析？
- [ ] 成功路径依赖的能力是否可以迁移？
- [ ] 是否同时投入研发、产品、用户洞察，而非只投渠道？
- [ ] 补贴/激励是否与产品力挂钩？
- [ ] 高管团队是否有新品类经验或外部专家？
- [ ] 试点结果是否真实反映终端动销？
- [ ] 失败信号出现时是否敢于停止而非加钱？
- [ ] 是否建立了跨职能评审，避免领导个人惯性？

## 适用边界

- 适用于渠道强势企业进入新品类前的能力评估。
- 适用于领导者个人成功路径可能形成组织惯性的场景。
- 不适用于技术路线成熟、仅靠渠道即可放量的品类。

## 常见误区

| 误区 | 正确理解 |
|---|---|
| 渠道强就能卖一切 | 渠道是放大器，不能替代产品力 |
| 加大补贴就能推新品 | 补贴只能解决渠道意愿，不能解决用户价值 |
| 品牌认知可以覆盖品类短板 | 用户对不同品类的信任门槛不同 |
| 失败是因为执行不够狠 | 可能是战略路径本身错误 |
| 领导者擅长什么就做什么 | 要按品类成功要素配置资源 |

## 延伸问题

- 如果你是 G 公司 CEO，会如何把空调时代的渠道能力迁移到冰箱、洗衣机？
- 你的企业中，哪些成功路径已经变成了不可迁移的惯性？

## 一句话总结

家电公司 G 的失败说明：渠道能力再强，也不能替代新品类所需的研发、产品与用户洞察能力。
