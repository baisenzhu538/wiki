# 案例：一堂课程里程碑模型——方法论级建模的六步生产流程

> **Burn line**: 如果八年前 Truman 能穿越到现在，他会把这套课程建模的六句话带走。

这是 Truman 分享的一堂做课流程案例。基于千人广场模型，一堂打磨出了一套从边界到包装的完整方法论生产流程。

---

## Background

- **场景**：一堂需要持续产出高质量方法论课程
- **问题**：早期先讲后改，理论出错后团队很难受
- **目标**：建立科学的课程/方法论建模流程
- **来源**：`src_20260614_8269ccdb#2170-2248`

---

## What Happened

### 六步流程

1. **敲定边界**
   - 先定问题边界，超过边界不研究
   - 防止无边无际的信息和观点涌入

2. **饱和收集事实**
   - 收集正面案例、反面案例、最佳实践、搞砸案例
   - 收集自己的经验、体感、全国调研、复盘
   - **事实 > 观点 > 理论**

3. **整合萃取**
   - 对事实分类建模
   - 找 before/after 的共性、卡点、爬坑路径、最佳实践、原则、本质

4. **产出 1.0 模型**
   - 画一个框子：冰山图、双三角、雷达图等
   - 先有模型，再迭代

5. **辩证讨论 / 撞击实验**
   - 内部交叉评审 + 专家评审
   - **以推翻模型为目标**
   - 检查：硬伤？反例？边界模糊？定义不清？
   - 撞到无可撞、专家无坚决反对时，才勉强成熟

6. **封装与包装打磨**
   - 先封装成可交付形式
   - 再做十层解读对外宣传

### 关键原则

- **两种十层解读**：一种是为了推翻，一种是为了宣传；先推翻，再宣传。
- **不许提前讲**：理论没推翻前，谁都不许对外讲，否则团队会舍不得改。

### 结果

这套流程成为一堂做课的底层方法，支撑了个人地图、创业地图、管理地图等核心产品。

## 可迁移场景

| 场景 | 如何套用 |
|---|---|
| 做课程/培训 | 边界 → 事实 → 萃取 → 1.0 → 撞击 → 封装 |
| 做方法论产品 | 同样六步，只是把"课程"换成"方法论" |
| 写书/白皮书 | 先饱和事实，再建模，再推翻验证 |
| 团队知识萃取 | 用撞击实验保证质量 |

---

## 教训

- **边界是第一件事**：没有边界，研究会失控。
- **事实优先于理论**：不要先信市场上的理论，先收集事实。
- **推翻比宣传重要**：成熟的标志是撞无可撞。
- **不要提前讲**：讲了就不愿意改了。

---

## 失败模式

| 失败模式 | 表现 | 避免方法 |
|---|---|---|
| **边界不定** | 研究范围无限扩大 | 先写一句话边界 |
| **理论先行** | 只看书不看事实 | 先收集真实案例 |
| **1.0 就宣传** | 讲完发现理论有错 | 先完成撞击实验 |
| **没有推翻机制** | 团队自嗨 | 找外部专家评审 |
