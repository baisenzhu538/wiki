# 案例库索引

> 案例库是 KDO 知识工厂的"参考样本层"——agent 产出前先查类似案例，产出质量下限由案例标杆决定。

## 如何使用案例库

**Agent 产出前**：
```
kdo case list              → 看全部案例
kdo case list --query "Agent" → 按关键词搜索
```

**手动检索**：
```
打开 index.md → 按领域找到对应案例 → 阅读完整案例卡
```
