# 人要练"创造力"
敢于提出新解法、新设想，善于高水平创新

● 自我修炼

✓ 解放思想：大胆提出创造性假设
✓ 分层自洽：上下分层可推理，左右自洽可辨证
✓ 敢于想象：有自己的独特想象力和设想

● 勇于探索：敢于跳出旧道路，提出新解法

✓ 批判性思维：不要迷信，主动思考合理性
✓ 学会提问：多追求WHY，提出新的好问题

● 善于使用工程思维探索解法

✓ 关键假设思维：用确定性的前提假设，去解决高难度的业务问题
✓ 假设验证Ω循环：目标/加法/减法/验证/调整

● 高级心法：高手从分析和试验，探索新规律

✓ 第一性原理：遵循本质和底层原理做事
✓ 分层自洽：追求下层规律和上层规则统一
✓ 辨证思维：找到规律的矛盾性，寻找更统一的更好规律
