# 洗发水案例：产品内核实战——从"去屑"到"专业形象"

> 一堂五步法：产品内核案例——高端洗发水，内核不是"去屑功能"，而是"有效去屑+专业形象"。

## 案例背景

**产品**：高端去屑洗发水
**初始假设**："用户需要去屑，我们的去屑效果好"
**问题**：把功能（去屑）当内核，忽视了用户选择的真正原因

### 第二步：内核 vs 功能

| 维度 | 内核 | 功能 |
|:---|:---|:---|
| 层面 | 价值层面 | 手段层面 |
| 内容 | "有效去屑+专业形象" | 特定成分、包装设计、品牌传播 |
| 变化 | 相对稳定 | 随技术迭代 |
| 用户感知 | "这个专业品牌能解决我的去屑问题" | "这个成分好" |

关键发现：用户买的不是"去屑成分"，而是"专业品牌的去屑承诺"。

### 第三步：内核验证

| 验证维度 | 方法 | 结果 |
|:---|:---|:---|
| 愿意用 | 试用测试 | 用户愿意试用，因为品牌信任 |
| 愿意付 | 定价测试 | 用户愿意为"专业形象"付溢价 |
| 愿意推荐 | NPS调查 | 用户推荐因为"有效+专业" |

关键发现：如果只有"去屑"没有"专业形象"，用户不愿意付溢价。

### 第四步：内核迭代

| 阶段 | 内核 | 迭代原因 |
|:---|:---|:---|
| V1 | "去屑功能" | 初始假设 |
| V2 | "有效去屑" | 验证发现"有效"比"功能"更重要 |
| V3 | "有效去屑+专业形象" | 验证发现"专业形象"是溢价来源 |
| V4 | "头皮健康管理专家" | 市场变化，从"去屑"扩展到"头皮健康" |

## 关键洞察

### 1. 内核的层次

| 层次 | 内核 | 说明 |
|:---|:---|:---|
| 功能层 | "去屑" | 基础功能，所有竞品都有 |
| 效果层 | "有效去屑" | 差异化，效果比竞品好 |
| 形象层 | "专业形象" | 品牌溢价，用户愿意付更多 |
| 专家层 | "头皮健康管理专家" | 品类扩展，从去屑到头皮健康 |

结论：内核是"有效去屑+专业形象"的组合，不是单一功能。

### 3. 内核与定价

| 内核 | 定价 | 用户接受度 |
|:---|:---|:---|
| "去屑功能" | 低（和竞品一样） | 低（无差异化） |
| "有效去屑" | 中（比竞品略高） | 中（效果差异化） |
| "有效去屑+专业形象" | 高（显著溢价） | 高（价值感知高） |

### 4. 内核的跨品类迁移

洗发水案例的内核逻辑可以迁移：

| 品类 | 内核 | 功能 |
|:---|:---|:---|
| 洗发水 | "有效去屑+专业形象" | 成分、包装 |
| 护肤品 | "有效抗老+专业形象" | 成分、包装 |
| 保健品 | "有效补充+专业形象" | 成分、认证 |
| SaaS | "高效解决+专业品牌" | 功能、UI |

## 失败模式（如果内核分析做错了）

| 错误 | 结果 |
|:---|:---|
| 功能即内核 | "去屑功能"无法支撑溢价，和竞品打价格战 |
| 忽视形象层 | 效果再好，用户不愿意付溢价 |
| 内核太宽 | "所有洗头的人"无法聚焦，资源分散 |
| 内核未验证 | 假设"专业形象"重要，未验证 |
| 内核静态 | 市场从"去屑"扩展到"头皮健康"，内核未迭代 |
