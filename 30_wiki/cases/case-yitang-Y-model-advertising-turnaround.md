# 一堂抖音 AD 投放扭亏：Y模型科学投放实战

> **一句话**：一堂 2023 年尝试抖音 AD 投放，经历外包失败、内部团队临摹也失败后，创始人亲自用 Y模型搭建「四大模型 + A本/B本 + 每周 AB 测试」的科学投放体系，最终把付费流量变成核心增长引擎。

## Background

- 2023 年，一堂决定进入抖音 AD 投放（信息流买量），将其作为规模化获客渠道。
- 当时团队对短视频投放认知较浅，采取「短平快」启动策略，希望快速验证渠道价值。
- 案例素材来自李善友在一堂「底层逻辑之一：Y模型」课程中的口述复盘，属于一堂内部真实项目经验。

## Problem

- **外包阶段（约三个月）**：委托外部短视频服务商代写内容、代做投放。结果广告内容与一堂品牌调性严重偏离，甚至出现「创业不要先注册公司」「先接大订单再开公司」等从未在一堂课程中教过的内容，有学员私下质疑「一堂是不是变了」。
- **内部临摹阶段**：抽调「网感最强」的两人成立虚拟小组，拆同行爆款、临摹脚本，但内容张力明显差一截，ROI 长期在 0.3–0.6 之间，持续净亏。
- **组织困境**：创始人当时主要精力在教研和产品创新上，希望投放问题能由外部或个别员工自行解决，结果陷入「模模糊糊的认知 → 模模糊糊的动作 → 模模糊糊的随机结果」。
- **财务压力**：口述中提到「每周亏一辆小米汽车」等说法，属于该项目特定阶段的经验描述，不应视为普遍规律或对外承诺。

## Decision

- 创始人与合伙人亲自牵头，把短视频投放定义为**公司级核心难题**，不再依赖外包或单点英雄。
- 用 [[yt-decision-y-model]] 的五步法重构投放体系：明确核心问题 → 拆解变量/业务公式 → 理论端 → 事实端 → 知行迭代。
- 核心判断：高难度、长周期的增长问题，必须由最高决策层下场建模，才能把核心认知沉淀在组织内部。

## Process

### 1. 明确目标：顾客规模 + ROI

- 一堂在相当长的时间内追求「风险可控的规模最大化」，而非单纯利润最大化。
- 选定两个核心评估参数：
  - **顾客规模**：体验课用户数量，代表增长天花板。
  - **ROI**：投放回报，代表单位经济健康度。
- 目标明确后，团队才进入变量拆解，避免被平台算法或短期爆款牵着走。

### 2. 拆解四大模型

团队梳理出决定顾客规模与 ROI 的四大模型：

| 模型 | 解决什么问题 | 在 Y模型中的位置 |
|:---|:---|:---|
| **单视频审美模型** | 单个短视频的制作标准、审美判断、信息密度 | 理论端·提炼建模 + 事实端·定性定量 |
| **工业化生产模型** | 一个脚本成功后，如何持续、批量、稳定地产出 | 理论端·科学类比 + 知行迭代 |
| **测试机制模型** | 单次投放成本高，如何多轮、安全、可控地验证 | 事实端·假设驱动 |
| **投放策略模型** | 出价、供应商配置、运营配套等具体策略 | 事实端·定性定量 + 知行迭代 |

### 3. 理论端：A本 / B本 模型

- **A本**：把已验证可跑出的内容模板沉淀为「老本」，持续生产。
- A本 生命周期：多次投放后会失败（投不出去）→ 若能投出，会稳定一段时间 → 随后下滑。
- **B本**：在 A本 衰退前启动新模板研发，作为下一代内容引擎。
- 工作盘：有一个模型持续做 A本、有一个模型持续监控数据、有一个模型持续优化 B本。
- 这一机制让内容生产从「随机抄爆款」变成「可预期的迭代管线」。

### 4. 事实端：选题池 + AB 测试 + 每周复盘

- **选题池**：收集大量投放选题 idea，用筛选模型挑出可能优质的选题进入测试池。
- **AB 测试**：选题池中的候选内容跑 AB 测试，持续筛选优化。
- **数据拆解**：围绕四大模型做基本数据拆解，把结果归因到可控变量。
- **每周复盘**：即使再忙再累，也坚持每周一轮测试、一轮拆解、一轮复盘，把认知和数据整合进四大模型。
- 关键节点方法论：如何拆解对标账号、如何解决前三秒留存、实验循环周期多长等，逐步被模型化。

### 5. 知行迭代：关键假设驱动

- 持续提出并验证关键假设，例如：
  - 送地图（赠送「一堂创业地图」作为钩子）
  - 混剪素材
  - 数字人口播
  - 供应商配置
  - 自然流口播
  - 切换目标人群
  - 不同人拍同一脚本 / 不同账号测试 / 渠道联动
- 用「绿色保留 / 红色证伪」标记假设结果，失败的假设快速退出，有效的假设进入模型沉淀。

## Result

- 约一个多季度后，投放效果明显改善，能够稳定产出 ROI 0.8–1.2 以上的内容（该数字为项目经验值，不作为对外承诺）。
- 付费流量占整体流量约一半，成为核心增长来源。
- 收入相比投放前增长约四倍（口述中的经验描述，不视为普适结论）。
- 跑通抖音后，陆续复制到视频号、小红书，并继续测试百度等新渠道。
- 每月体验课用户达到大几千量级。

## Lessons

1. **核心难题必须创始人牵头建模**：高难度、长周期的公司核心问题，不能寄希望于外包或个别员工自行解决。
2. **每周咬碎牙复盘**：把数据好坏持续沉淀到模型里，是跨越亏损期的关键动作。
3. **小模型叠加成大模型**：单视频审美、工业化生产、测试机制、投放策略四大模型下再拆小模型，逐步形成可复用的科学投放框架。
4. **目标先于手段**：先明确顾客规模 + ROI，再拆解决定结果的变量，避免被平台算法或爆款牵着走。
5. **理论端与事实端要闭环**：A本/B本 提供理论模板，AB 测试和每周复盘提供事实校正，两者缺一不可。

## Failure Modes

| 失败模式 | 症状 | 反打 |
|:---|:---|:---|
| **依赖外包** | 广告内容与品牌脱节，服务商不懂业务 | 创始人亲自牵头，把核心认知握在组织内部 |
| **抄爆款** | 内容张力差，ROI 长期低于 1 | 建立 A本/B本 模型，形成自有内容工作盘 |
| **不建模** | 模模糊糊地投，结果随机性大 | 拆解四大模型，把结果归因到可控变量 |
| **不复盘** | 同样错误反复犯，亏损持续 | 每周固定复盘，把数据整合进模型 |
| **只看 ROI 不看规模** | 过度保守，错过增长窗口 | 明确「风险可控的规模最大化」作为双目标 |
| **模型僵化** | A本 失效后仍持续复制 | 建立 B本 研发机制，提前准备下一代内容模板 |

## Critique

### 外部反对者

1. **广告平台算法黑箱论者**：抖音、视频号等平台的推荐逻辑不完全透明，科学建模可能只是在拟合平台阶段性规则；规则一旦调整，模型可能快速失效。
2. **品牌原生派（长期品牌主义）**：过度依赖效果广告与 ROI 优化，可能损害品牌长期资产，把品牌简化为可量化的转化漏斗，忽视情感、意义与信任积累。
3. **创业方法论怀疑者（如 Nassim Taleb 的反脆弱视角）**：把成功归因于「科学模型」容易犯叙述谬误，真实世界的高维不确定性无法被五步法与 AB 测试穷尽。
4. **组织行为学者**：创始人亲自牵头虽能破局，但也可能导致能力过度集中、团队产生英雄式依赖，后续难以规模化复制和授权。

### 内部局限

1. **数据噪音与平台周期**：短视频平台的内容衰减周期短，历史数据对未来预测的有效期有限，模型可能过度拟合短期信号。
2. **创意生产的不可完全结构化**：单视频审美涉及品味、情绪、文化语境，无法全部量化为可复现模型。
3. **成本与节奏**：每周复盘、AB 测试需要持续投入人力与预算，对现金流紧张的小团队可能是沉重负担。
4. **幸存者偏差**：案例来自一堂自身成功经历，失败教训的传播强度通常弱于成功经验，外部学习者容易低估执行难度。

## Synthesis

本案例是 [[yt-decision-y-model]] 在付费流量领域的具体落地：以客观因果规律为根，把「顾客规模 + ROI」作为目标，拆解出四大模型，通过 A本/B本 机制连接理论端与事实端，再以每周复盘和关键假设驱动知行迭代。它与 [[tool-yitang-Y-model-application]] 的操作清单、[[dk-yitang-Y-model-pitfalls]] 中的「愿望思维」「经验主义」等陷阱形成互证，也与 [[case-yitang-Y-model-seven-applications]] 共同说明 Y模型在不同领域的可迁移性。

在跨域层面，案例中的「创始人牵头建模 + 假设驱动 + 每周复盘」可映射到 [[master-decision-hygiene]] 与 [[concept-X型Y型决策习惯]] 所强调的高质量决策习惯；其「目标 → 变量 → 模型 → 实验」的结构也可与 [[yt-business-formula-six-level-logic]] 和 [[yt-five-step-method]] 形成上下贯通的方法论网络。

> 本案例中的数字（ROI 0.3–0.6、ROI 0.8–1.2、收入翻四倍、每月大几千体验课用户等）均来自口述稿中的项目经验，仅用于说明一堂自身的实践过程，不构成对其他业务或行业的普适承诺。
