# 线下连锁健身：把“到店频率"变成“到店习惯"才是续卡率抓手

> 一堂业务公式拆解培训案例：20 家门店、月 GMV 600 万、会员续卡率 35% 的连锁健身房，目标续卡率提升到 50%。团队把“到店频率”“私教购买率”等与续卡率的相关关系当成因果，拼命提升满意度，却忽略了真正该做的是把“到店频率”变成“到店习惯”。来源：一堂 2026-06-13 业务公式拆解培训（孔阳）。

---

## 案例背景

| 维度 | 信息 |
|---|---|
| 行业 | 线下连锁健身 |
| 门店数 | 20 家 |
| 月 GMV | 600 万 |
| 会员续卡率 | 35% |
| 目标 | 续卡率提升至 50% |
| 团队直觉 | 让会员多来、多卖私教课 |

---

## 错误拆解

```
续卡收入 = 会员数 × 续卡率 × 客单价
```

拆到 L1-L2 后，团队发现：
- 续卡率与"满意度"正相关，于是拼命提升环境、教练、前台服务
- 续卡率与"会员等级"正相关，于是推会员升级

这些都是**相关关系**，不是**因果关系**。按相关关系做决策，会浪费资源在不能直接推动续卡的动作上。

---

## 核心矛盾

真正影响续卡率的路径是：

```
满意度 → 到店频率 → 到店习惯 → 续卡率
```

**满意度是“因的因”，不是续卡率的直接原因**。如果直接把满意度当成续卡率的直接原因，会拼命提升环境、教练、服务，但到一定程度后满意度提升的边际收益会递减。真正该做的，是把“到店频率”变成“到店习惯”。

---

## 正确拆解路径

### 第一步：先切分（+）

```
续卡收入 = 普通续卡收入 + 私教续卡收入 + 团课续卡收入
```

### 第二步：再拆转化（×）

```
续卡率 = 满意度 × 到店习惯 × 价格接受度

满意度 = 环境满意度 + 教练满意度 + 前台服务满意度
```

注意：满意度内部是**加法关系**（+），不是乘法。只要有一个维度做得特别好，满意度大概率就够了；如果写成 ×，会要求每个维度都完美，导致平均用力。

### 第三步：找到真正的因果链

```
满意度（因） → 到店频率（中间） → 到店习惯（直接因） → 续卡率（果）
```

因此，到店习惯才是续卡率的直接抓手。把“偶尔来”变成“固定时间来”“不来就不舒服”，续卡率才会稳定提升。

---

## 关键动作

1. **把满意度从"全面提升"改为"有一个亮点即可"**：环境、教练、前台中至少有一项让用户印象深刻，避免平均用力。
2. **设计到店习惯养成机制**：
   - 固定时段预约：用户选固定时段（如每周二/四/六晚 7 点），到点 AI/教练提醒，缺勤主动跟进
   - 21 天打卡挑战：连续到店 21 天送私教课/周边，把"偶尔来"变成"固定来"
   - 社群比拼：会员群公布每周到店次数排行，社交压力转化为到店动力
3. **围绕到店习惯埋数据节点**：
   - 单会员周到店次数（目标 ≥2 次/周）
   - 固定时段到店占比（目标 ≥60%，越固定习惯越牢）
   - 缺勤后 7 天内复访率（衡量召回机制有效性）
   - 续卡前 90 天到店频次（预测续卡率的前置指标）

---

## 教训

- **把相关当因果会浪费资源**：满意度与续卡率相关但非直接因果，拼命提升满意度的边际收益递减；到店习惯才是直接因，资源应投在习惯养成而非满意度全面提升。
- **加法关系误用乘法会平均用力**：满意度内部是加法（环境+教练+前台），写成乘法会要求每项都完美，导致资源分散；正确做法是"有一个亮点即可"。
- **L1-L2 拆解掩盖真实瓶颈**：续卡率拆到 L1-L2 只能看到"会员数×续卡率×客单价"，看不到"到店习惯"这个 L4-L5 抓手；必须拆到行为层才能找到可干预点。

---

## 关键证据

| Before | After |
|---|---|
| 续卡率 35%，目标 50% | 围绕到店习惯设计养成机制 |
| 动作：让会员多来、多卖私教 | 动作：固定时段预约 + 打卡 streak + 社群搭子 |
| 核心假设：到店频率高 = 续卡率高 | 核心假设：到店习惯才是续卡率的直接原因 |

真实锚点：20 家门店、月 GMV 600 万、续卡率 35%，来自培训中的真实教学案例。

---

## 可迁移场景

1. **订阅制会员业务**：把“使用频次”变成“使用习惯”。
2. **在线教育/训练营**：把“上课次数”变成“固定学习习惯”。
3. **健康管理/慢病管理**：把“偶尔测量”变成“每日记录习惯”。

---

## 失败模式

| 踩坑方式 | 表现 | 避免方法 |
|---|---|---|
| **把相关当因果** | 拼命提升满意度，续卡率不动 | 找到满意度 → 到店习惯 → 续卡率的完整因果链 |
| **把加法写成乘法** | 要求环境、教练、前台都完美 | 识别满意度是叠加关系，有一个亮点即可 |
| **忽视习惯养成** | 会员来了几次就不来了 | 用固定时段、 streak、社群把频率变成习惯 |
