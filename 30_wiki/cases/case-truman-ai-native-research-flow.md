# 楚门 AI 原生调研流：口喷一段→Agent 科学调研→Obsidian 资产

## 事迹

> 「我当时就想说，有没有可能我以后有任何调研的想法……然后我就随便喷口拍一段，他就用非常专业的一堂科学体系的方法，交叉验证的、全面搜集的这种调研方法帮我去。」（口述 L984-990）
> 「然后我看过市场很多这种调研的一些能力和所谓的工具，说实话都不够好啊，就是他们太通用了，导致在商业表演上有点弱，而且很随机。」（L990）
> 「最佳实践指南文档是一个参考文档，就类似于我刚才的报告，那就是一个最佳实践的最佳文档是个资产包。」（L1550-1554）
> 「我想象中的场景是：我随时想到一个 idea，比如'调研国内一人公司 APP 最佳实践清单'，他跟我聊几句目标和边界，然后就启动安排任务去调研，最后给我写一篇完整的调研报告，放到我的知识库（Obsidian）里。」（逐字稿 L343）

楚门把"调研"从人工流程变成 Agent 原生流程：**口喷一段话（调研想法）→ Agent 用一堂科学体系方法（交叉验证/全面搜集）执行 → 产出最佳实践文档（资产包）→ 落 Obsidian 知识库**。核心差异化是他认为市场通用调研工具"太通用、商业表现弱、很随机"（L990）——而一套有方法论内核（一堂科学体系）的调研 Agent 是壁垒。

## 背景

- 楚门在 AI 知识管理探索营口述（2026-08），素材=口述 3510 行 + 逐字稿
- 调研想法随时产生（"调研国内一人公司 APP 最佳实践清单""调研 OpenClaw 真正高价值应用场景清单"——逐字稿 L343 例）
- 传统调研工具的痛点：通用化导致商业表现弱、随机（L990）
- 产出物定位：最佳实践指南文档=资产包（L1550-1554）——可复用、可积累

## 可迁移场景

- **任何"想了解一个主题"的时刻**：口喷一段想法（目标+边界），交给调研 Agent 执行
- **新项目启动前**：调研最佳实践（对标楚门 16 项目调研图 L1192——产品调研/工程调研/客户案例）
- **知识资产积累**：最佳实践文档作为资产包沉淀（L1550-1554）
- **与"口喷→Agent 做图"同构**：口喷一句话+上下文自动学（L1206）——调研流是同一模式在"调研"领域的实例
- 局限：依赖 Agent 的科学调研能力（一堂体系内核）——无此内核的通用工具表现弱（L990 楚门原话）
