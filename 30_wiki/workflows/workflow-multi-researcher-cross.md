# 多研究员交叉研究工作流

> **定位**：把一个研究课题拆成 N 个立场/背景不同的研究员视角，并行调研后合并交叉，产出单一研究员给不出的多视角总报告。本卡是 `40_outputs/capabilities/skills/shared/multi-researcher-cross/SKILL.md` 的总纲——skill 是可执行件（画像池/任务书模板/裁决规则），本卡讲流程与判断。
> **来源**：AI大航海 2026-09-05 金矿 A60-A61，Truman 实录案例（哈佛案例教学法研究，6 Agent 并行）。**场景复现一**——老朱 09-06 拍板第一优先（`60_feedback/tasks/task_20260906_laowantong-multi-researcher-cross.md`）。

## 核心主张

**单角色研究的天花板是视角，不是算力。** Truman 的原始发现（A60）："这个之前我试过我在研究一些课题的时候，只配一个这个角色的时候，我发现他的研究总是有自己的偏好和狭窄性，而且 AI 本来就是概率很随机。"（`AI实战路径-五个层级全解析-口述.txt:368`）他的解法不是换更强的模型，而是换**更多的立场**：把课程地图拆成 10 个背景/信息/目标/思维方式/立场都不同的研究员，每次挑 3-5 个分头研究再合并交叉。

这个判断和业界实证是同向的：多视角集合的价值来自**去相关的错误**——不同视角犯不同的错，合并时错误互相抵消；相同视角犯相同的错，合并只是放大（LLM Ensemble 综述，MDPI Information 2025）。

## 使用场景

**用**：
- 课题是判断题/开放题："X 值不值得做""这个方向的机会在哪""我们该不该投入"
- 结论要支撑资源投入决策，错一次成本高
- 你已经让一个 Agent 答过一次，但怀疑答案太窄或有偏好

**不用**：
- 事实检索（一个 `kdo query` 能答的）——多视角是奢侈品，检索题用它是浪费 token
- 攻击**已有**知识卡找漏洞 → `[[framework-kdo-self-attack]]`（对抗验证，产出后）
- 两个 Agent 对**同一事实**口径打架 → `[[workflow-cross-agent-fact-dispute]]`（事后裁决协议）
- 只是想让答案更稳定（同一视角采样方差）→ Self-Consistency（并行采样+多数投票）更便宜

## 操作步骤

```
①触发判型 → ②分视角（挑画像）→ ③任务书翻译 → ④并行调研 → ⑤合并裁决 → ⑥报告分层
     │              │                │               │             │            │
   判断题吗？   写出预期分歧点    A62 信息完整性门   3-5 实例同跑   禁止平均     三层结构
```

### 第 1 步：触发判型

问一句：**这道题的不同答案会来自不同的"看什么"和"不信什么"吗？**
会 → 继续。不会（答案只有一个，只是需要查资料）→ 停，单角色检索即可。
这是全流程最便宜也最关键的一步——判错在这里，后面 3-5 倍的 token 成本全浪费。

### 第 2 步：分视角（从画像池挑 3-5 张）

从 skill 的 10 张画像池（P1 商业模式建筑师 / P2 需求分析师 / P3 决策心理师 / P4 增长操盘手 / P5 壁垒审计师 / P6 财务裁判 / P7 交付运营工程师 / P8 反方案例审计师 / P9 一线用户声音 / P10 组织与人事）中挑 3-5 张。

**挑选硬标准：写下"他们会在哪道子问题上分歧"。** 写不出分歧点 = 这几张画像实际是同一个视角换了名字，换掉。
A60 的原始表述：挑的标准是"大家的背景不一样，信息不一样，目标不一样啊，思维方式不一样，甚至立场不一样啊"（口述稿 L370）。

> 画像按**课题域相关性**策展，不是凑数量。业界实证（arXiv:2311.17371）：任意堆画像与无条件唱反调会**降低**准确率。

### 第 3 步：任务书翻译（把你的问题翻译成研究员的任务书）

Truman 实录："它写了一个完整的任务说明书，把我的问题翻译成了一个给各个研究员的任务书。我又补了一个信息：**不要省 Token，保证完整，不要丢三落四，一定要把信息传清楚**。"（口述稿 L380，即 A62）

这是本工作流**最高杠杆的一步**——课题方的一句话，必须被翻译成每个研究员都能独立执行的完整任务书。任务书模板六节：画像逐字抄入 / 子问题全量 / 边界条件（含"不研究什么"与"不得重新论证"）/ 信息源与检索指令 / 交付格式 / A62 自检清单。

**A62 不是客气话，是硬门**：省 Token = 研究员自行揣测你要什么 = 每个人揣测的方向还不一样 = 合并时发现根本答的不是同一道题。

### 第 4 步：并行调研

3-5 个实例**同时**下发（同通道多实例即可，画像用提示词实现，不需要多供应商）。Truman 实测单研究员 10-20 分钟，并行跑墙钟时间不变。
研究员之间**互不可见**——可见就会趋同，交叉就失效了。

### 第 5 步：合并裁决

合并 ≠ 摘要拼接。六条裁决规则（R1 同类项对齐 / R2 三级标注贯穿 / R3 三种关系三种处理 / R4 反方门控 / R5 单源隔离 / R6 报告分层），完整定义在 skill §4。

三条最容易被违反的：
- **R3 禁止平均**：结论相反时不许写"综合来看各有利弊"。回到锚点裁决；锚点裁决不了 → 明确写"两说并存，裁决需 <具体决策者>"，交还给人。
- **R4 反方门控**：反方/审计型研究员只在 ≥2 人已独立形成共识后才介入，且反例须附存在性核查锚点。业界实证显示无条件唱反调拉低准确率。
- **R5 单源隔离**：只有一人提出、无人印证的结论进"待验证"区，不进正文主张。

### 第 6 步：报告分层

对齐 Truman 案例的真实产出结构——他得到的"不是一个研究报告，而是一系列的研究报告"（口述稿 L390）：

```
1. 原始课题输入（可追溯）
2. 各研究员任务书 + 各自报告全文（不删减）
3. 事实分析（第 5 步对齐与裁决结果）
4. 规律与洞察（事实之上的抽象）
5. 应用设想 / 决策建议（每条标注支撑视角）
```

没有第 5 层的报告是研究吗啡——读完很爽，不知道干嘛。每条建议必须能指回是哪个视角支撑的，指不回来的删掉。

## 试金石实录（2026-09-06，#664）

> **目的**：验证本工作流能否真跑通（不是纸面推演）。**课题**：「一个人/小团队持续引入新 AI 工具，却总是换一批丢一批、沉淀不下资产。根因是什么？该设哪几条止损线？」**研究员**：P3 决策心理师 / P7 交付运营工程师 / P5 壁垒审计师（3 张，同通道多实例并行）。**全文存档**：`60_feedback/diagnosis/working/pilot-multi-researcher-cross-20260906.md`。

### 过程实测【实证】

| 项 | 值 |
|:--|:--|
| 并行墙钟 | ≈417s（P3/P7/P5 = 417/391/406s，取最大值）；串行等效 ≈1214s → **并行加速比 ≈2.9×** |
| 报告间结论重叠 | ≈0（见下） |
| 锚点回验发现缺陷 | 1 处行号错 |

### 交叉增量【实证】——三层分工，零重叠

这是本次试金石最重要的产出。三份报告对"根因"给出了**三种不同的切法**，不是同一结论的三次复述：

| 层 | 谁覆盖 | 回答的问题 |
|:--|:--|:--|
| 动机层（为什么停不下来） | P3 决策心理师 | 换工具是焦虑调节伪装成能力建设（Y模型三问：表面"找最好用的工具"→深层"缓解落伍焦虑"→本质"用我在行动替代我在积累"） |
| 流程层（在哪断的） | P7 交付运营工程师 | 资产四环节（定义/产出/归档/复用）各断一处，"资产不是被换死的，是从未被真正定义过" |
| 资产性质层（什么值得存） | P5 壁垒审计师 | 复利四测（排他性/私有性/抽象度/显性度），并自我修正"复利 ≠ 壁垒" |

任何单层都给不出完整止损线：P3 的"反馈重定时"没有 P5 的"什么算资产"就没有对象；P5 的四测没有 P7 的四环节就没有执行位置。

### 裁决规则被真实触发的三处【实证】

1. **R3 同源偏置检查拦住了一次假共识**：P7 与 P5 独立命中「存量封装决定新工具起点」，但引的是**同一条锚**（`宣讲会:388-390` WalkerBot/DeepSeek Harness 一刹那巅峰）→ 按 R3 判同源，**不升格为独立验证**，标注单源口述入正文。若没有这条规则，两票一致会被误读为双源验证。
2. **R3 冲突裁决处理了 1 处真冲突**：P7/P5 均主张"资产建在 Feature 层，工具无关"；P3 反例引 `ai-methodology-tools.md:185` 明文条件——"'Feature 思维优于工具层训练'——条件：AI 工具栈相对稳定，工具频繁迭代时不适用"。回锚裁决：`feature-periodic-table-v1.0.json:1614`（主张）vs `ai-methodology-tools.md:185`（边界条件）→ **非同级矛盾，是主张与适用边界的关系**，两级都保留，未取中间。这条边界只有跑 P3 才会出现——单跑 P7 或 P5 都会得到无条件的 Feature 层主张。
3. **R2 锚点回验抓到一处行号错**：P5 称某引语出自 `feature-periodic-table-v1.0.json:1522`，回验发现 `:1522` 是 `case_ref` 字段，引语实际在 `:1614`/`:288`。引语真、主张立，但行号错——不回验就会把错行号固化进知识库。→ 已回写 skill §5 第 6 步。

### 哪里和预想不一样【实证】

- **反方不需要专职画像**：本跑未启用 P8，但任务书要求每名研究员自带 ≥1 条反例，结果 3 人共产出 10 条反例，**零条推翻共识，全部在给共识划边界**。与外部基准（无条件唱反调降低准确率）方向一致。→ 已回写 skill §4 R4（推荐"反例内嵌交付格式"而非专职反方）。
- **研究员会主动执行纪律**：P3 拒绝引用"73.2% 认知投降"数字，理由是库内已标注"统计口径不明"——三级标注纪律在无监督子实例里被自发执行，说明任务书里写明纪律是有效的。
- **报告自带反例的部分质量最高**：P5 的反例1（复利≠壁垒）修正了它自己前面的框架，这种自我修正不会发生在单角色报告里。

### 局限（不夸大本次证据）

本次试金石验证的是**流程能跑通 + 视角确实分歧 + 裁决规则可执行**，**没有**验证"合并报告优于单角色报告"——那需要同一课题双跑对照（单角色跑一遍 vs 三研究员交叉），属后续工作。本卡 Critique 第一条的证据缺口仍然开放。

## 适用边界

| 维度 | 适用 | 不适用 |
|:--|:--|:--|
| 问题类型 | 判断题、开放题、投入决策前的摸底 | 事实检索、定义查询 |
| 视角可得性 | 课题域内存在真实分歧的立场 | 全员共识的领域（分歧是表演性的） |
| 成本预算 | 决策价值 > 3-5 倍单角色 token 成本 | 日常小问题 |
| 研究员来源 | 同通道多实例 + 提示词画像即可 | 不需要多供应商（A60 的 10 人池用的就是同一套 Hermes） |

**"10 选 3-5"的 10 不是普适常数**【推断】：10 是 Truman 课程地图的产物，本厂的 10 张画像池对应 AI for Business 能力地图。关键不是 10，是"池中画像两两之间存在真实分歧点"。换一个厂，这个数字会变。

## 为什么值钱

1. **它把"换个角度想想"从一句劝告变成一条可执行流水线。** 以前这句话靠人自觉，现在它有画像池、任务书模板、裁决规则——换个人也能跑出同样结构的结果。
2. **最高杠杆的一步是翻译，不是调研。** Truman 案例里真正决定质量的动作，是把他的口头好奇翻译成六节完整的任务书。这一步的成本几乎为零，收益却是全局的——这是普通人带 AI 和高手带 AI 的分界线（A61："我自己带 AI 不一定做得出来，Eason 带更多 AI 能"）。
3. **它给"冲突"一个出口而不是一个平均值。** R3 禁止平均 + 锚点裁决 + 升级给人，这是把实事求是从口号落成规则——多数多 Agent 方案败在把冲突糊弄过去。
4. **与技能中心同构（B93）**：这套东西沉淀成 skill 后，别人"扫到装上就会"——这正是 B93 描述的组织形态，KDO 已经在实现它。

## Critique

- **Truman 的证据是单案例自述，不是对照实验**【推断】：他说"总的研究报告显著更好"，但没有给出与单角色基线的可比对照。本卡的试金石同样只验证"流程能跑通、视角确实分歧"，**不验证"合并报告优于单角色报告"**——那需要同一课题双跑对比，属后续工作。这是本卡最大的证据缺口。
- **成本是真实的**：3-5 倍 token、编排者的翻译时间、合并裁决的回读时间。对检索题用这套是纯浪费。判型（第 1 步）必须先行。
- **画像可能造成表演性立场**：Agent 可能"扮演"投资人却没有投资人的判断力。skill 的缓解是画像只改变**信息源与怀疑点**（看什么/不信什么），不要求画像具备其不具备的专业能力。此缓解是否足够，试金石的交叉质量是第一个数据点。
- **业界对多智能体辩论（MAD）的批评部分适用**：arXiv:2311.17371 发现 MAD 未必优于 Self-Consistency。本工作流的辩护是目标不同——MAD 解决推理不稳定，本工作流解决单一视角的结构性盲区。但若你的问题里盲区不成立，用更便宜的方法。
