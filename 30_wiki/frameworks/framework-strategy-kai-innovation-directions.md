# 凯纳创新方向分类框架

> 企业创新不是一句口号，而是发生在三个不同层面的系统性工程。凯纳咨询将该框架用于帮助企业识别创新切入点：产品/服务与市场创新、业务模式创新、运营创新。

---

## 一、三层创新方向

```
┌─────────────────────────────────────────────────────────┐
│  第一层：产品、服务和市场创新                            │
│  → 聚焦客户与进入市场                                    │
│  · 发展和发行创新产品和服务                              │
│  · 进入新市场，寻找新客户                                │
│  · 推行新的渠道和交付路径                                │
├─────────────────────────────────────────────────────────┤
│  第二层：业务模式创新                                    │
│  → 用于重建和企业扩展                                    │
│  · 发展业务运营的新方式                                  │
│  · 建立伙伴关系快速响应市场                              │
│  · 提升业务灵活性                                        │
├─────────────────────────────────────────────────────────┤
│  第三层：运营创新                                        │
│  → 改善核心职能领域的效能和效率                          │
│  · 发展的最佳成本结构                                    │
│  · 优化流程以改进生产力                                  │
│  · 核心职能再造（改组）以提高效率                        │
└─────────────────────────────────────────────────────────┘
```

---

## 二、分层定义

| 层级 | 关注对象 | 战略意图 | 典型问题 |
|--|--|--|--|
| **产品、服务和市场创新** | 外部客户与市场 | 增长与获客 | 为谁创造什么新价值？通过什么新渠道触达？ |
| **业务模式创新** | 企业价值创造与捕获逻辑 | 重构与扩张 | 如何重新设计交易结构、伙伴关系和盈利方式？ |
| **运营创新** | 内部核心职能 | 效率与成本 | 哪些流程和职能可以降本增效？ |

---

## 三、与成长/运作的映射

| 关注点 | 覆盖层级 | 说明 |
|--|--|--|
| **关注成长** | 第一层 + 第二层 | 直接带来收入增量和市场扩张 |
| **关注成长/运作** | 第三层 | 通过效率提升释放利润和支撑成长 |

---

## 四、使用步骤

1. **诊断创新缺口**：当前企业短板主要在哪一层？
2. **匹配资源投入**：研发预算偏产品、数字化预算偏运营、并购/合作预算偏业务模式。
3. **避免错位**：不要只盯着产品创新，忽视运营效率；也不要只做运营优化，错过模式重构窗口。
4. **组合设计**：三层创新往往组合发生，例如新模式（订阅制）+ 新产品 + 新运营系统。

---

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只在第三层做微创新 | 修修补补，增长停滞 | 同时审视第一层和第二层的重构机会 |
| 产品创新无运营支撑 | 新品上线后交付混乱、成本失控 | 新品与流程再造同步推进 |
| 模式创新脱离客户价值 | 换了盈利模式，客户不买账 | 从第一层客户需求出发反向设计模式 |

---

## 六、Agent 执行指令

```python
def kai_innovation_audit(current_initiatives: list[str]):
    """用凯纳三层框架审计企业创新布局"""
    prompts = {
        "产品服务市场创新": "列出当前面向客户/市场的新产品、新服务、新渠道举措。",
        "业务模式创新": "列出当前在交易结构、伙伴关系、盈利模式上的重构举措。",
        "运营创新": "列出当前在成本结构、流程优化、职能再造上的举措。",
        "缺口识别": "哪一层投入明显不足？哪一层过度拥挤？",
        "组合建议": "给出三层协同的创新组合建议。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```
