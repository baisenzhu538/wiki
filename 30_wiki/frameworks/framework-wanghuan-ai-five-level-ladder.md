# 王欢AI能力五层跃迁模型

> **Burn line**: 从“会问 AI 问题”到“能搭建系统级 AI 操作台”，有五层台阶。多数人卡在第二层。
>
> **来源**：王欢 AI 实战分享（2026-06-18）

---

## 一、用一句话讲清楚

AI 能力可以分成五层：问答层、工作流层、作品层、产品/应用层、系统层。**每一层解决不同问题，上一层比下一层价值高一个数量级**。

---

## 二、五层模型

```
第五层 系统层        ← 工程化的 AI 操作台
第四层 产品/应用层   ← 被人持续依赖
第三层 作品层        ← 产出真实作品
第二层 工作流层      ← 可复用上下文
第一层 问答层        ← 解决答案
```

### 2.1 第一层：问答层

| 项目 | 内容 |
|:---|:---|
| **核心跃迁** | 从“问 AI”到“验证 AI” |
| **解决什么问题** | 信息差 |
| **典型场景** | 聊天机器人、知识问答 |
| **晋级标准** | 能识别幻觉，知道何时交叉验证 |
| **风险** | 把 AI 答案当成事实，不做判断 |

### 2.2 第二层：工作流层

| 项目 | 内容 |
|:---|:---|
| **核心跃迁** | 从一次性对话到可复用上下文 |
| **解决什么问题** | 效率 |
| **典型场景** | 模板调用、知识库整合、项目化知识库 |
| **晋级标准** | 口述输入、会议重构、项目化知识库已常态化 |
| **效率提升** | 30%–50% |

### 2.3 第三层：作品层

| 项目 | 内容 |
|:---|:---|
| **核心跃迁** | 从辅助工作到产出真实作品 |
| **解决什么问题** | 作品 |
| **典型场景** | 网页生成、技能封装（Skills）、内容/代码/智能资产 |
| **晋级标准** | 能产出内容、代码、智能资产三类作品并被验证 |
| **价值** | 超越 90% 用户，形成个人竞争力 |

### 2.4 第四层：产品/应用层

| 项目 | 内容 |
|:---|:---|
| **核心跃迁** | 从单点作品到被人持续依赖 |
| **解决什么问题** | 交付 |
| **典型场景** | 产品化工具、智能体应用 |
| **晋级标准** | 有真实用户、有数据、有维护、有版本演进 |
| **关键差异** | 不是“我做出了一个东西”，而是“别人持续在用” |

### 2.5 第五层：系统层

| 项目 | 内容 |
|:---|:---|
| **核心跃迁** | 从单点产品到工程化的 AI 操作台 |
| **解决什么问题** | 工程化 |
| **典型场景** | 操作系统级平台、技能库、多工具编排 |
| **晋级标准** | 有编排底座、技能库、自动触发、反馈闭环 |
| **价值** | 行业级解决方案，构建护城河 |

---

## 三、一句话主轴

> **第一层解决答案，第二层解决效率，第三层解决作品，第四层解决交付，第五层解决工程化。**

---

## 四、如何判断自己在哪一层

| 层级 | 自检问题 |
|:---|:---|
| 问答层 | 你是否能判断 AI 给出的答案是否可靠？ |
| 工作流层 | 你是否有可复用的 prompt 模板和知识库？ |
| 作品层 | 你是否能产出别人愿意用的内容/代码/工具？ |
| 产品/应用层 | 你的作品是否有真实用户和持续迭代？ |
| 系统层 | 你是否能搭建一个自动运行的 AI 操作台？ |

---

## 五、如何向上一层跃迁

| 当前层级 | 下一步跃迁动作 |
|:---|:---|
| 问答层 → 工作流层 | 把常用 prompt 固化成模板，建立个人知识库 |
| 工作流层 → 作品层 | 用 AI 产出第一个可复用作品（网页、脚本、技能） |
| 作品层 → 产品/应用层 | 让作品被真实用户使用，收集反馈并迭代 |
| 产品/应用层 → 系统层 | 把多个产品编排成自动触发、反馈闭环的系统 |

---

## 六、与演员/导演模型的关系

- **问答层、工作流层**：主要是**演员模式**——人用 AI 工具做事。
- **作品层、产品/应用层、系统层**：主要是**导演模式**——人设计系统，AI 执行。

> 想要突破第二层，必须完成从演员到导演的切换。

---

## 七、应用场景

### 7.1 个人成长

用这个模型给自己定位，找到最短板的层级，集中突破。

### 7.2 团队评估

评估团队成员的 AI 能力分布，决定培训方向。

### 7.3 产品规划

判断一个 AI 产品当前处于哪一层，规划向上一层演进的路径。

### 7.4 KDO 知识工厂映射

| KDO 现状 | 对应层级 |
|:---|:---|
| 用 AI 回答问题、查资料 | 问答层 |
| 有 prompt 模板、批量处理卡片 | 工作流层 |
| 产出 skill/dk/concept 卡片 | 作品层 |
| 卡片被用户持续使用、迭代 | 产品/应用层 |
| 知识工厂自动分发、自动质检、自动迭代 | 系统层 |

---

## 八、Action Triggers

| 触发场景 | 第一个动作 |
|:---|:---|
| 你每天都在问 AI 同样的问题 | 把工作流模板化 |
| 你做出了一个好东西但只用一次 | 把它变成可复用作品 |
| 你的作品没人用 | 找一个真实用户，收集反馈 |
| 你有多个独立作品 | 设计一个把它们串起来的系统 |
