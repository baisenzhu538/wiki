# 一堂六维销售激励模型

> **一句话**：激励不是事后奖励，而是事前设计的发动机。

## 一、四大常见问题

| 问题 | 典型表现 | 后果 |
|------|----------|------|
| **忽略激励** | 创业早期创始人不擅长精神鼓励，又因资金有限干脆不做激励 | 销售积极性受挫，团队缺乏基本动力 |
| **无效激励** | 目标拍脑袋，只定高目标不给方法、不给资源 | 销售反复完不成，最终躺平 |
| **只靠金钱** | 激励手段单一，只有提成，缺少辅助手段 | 不愿挑战新市场，只挖老客户，做点事都要看钱 |
| **标准不科学** | 激励规则不公开、计算不透明、不敢承诺 | 团队感觉不公平，内耗严重，信任崩塌 |

## 二、六维激励模型

一堂把销售激励拆成六个相互补位的维度，形成从「物质驱动」到「意义驱动」的完整光谱。

| 维度 | 核心问题 | 分值定位 | 关键抓手 |
|------|----------|----------|----------|
| **目标有渴望** | 销售是否愿意持续挑战更难目标？ | 60 分基础 | 里程碑、小胜仗、及时反馈 |
| **业绩有奖金** | 金钱激励是否让销售持续战斗？ | 75 分进阶 | 底薪、提成、绩效、过程奖励、及时发放 |
| **同事有竞争** | 团队能否形成正向竞争氛围？ | 85 分进阶 | 销冠荣誉、张榜公示、仪式感 |
| **打仗有感情** | 销售是否对团队有归属感？ | 85 分进阶 | 团建、生活保障、善待家人 |
| **成长有奔头** | 销售是否看到成长空间？ | 85 分进阶 | 老板扛事、培训辅导、职级晋升 |
| **岗位有使命** | 销售是否感受到工作意义？ | 85 分高阶 | 外部认可、企业文化、内部地位 |

> **经验判断**：目标有渴望是销售团队的 60 分底线；业绩有奖金做到位可到 75 分；再想上到 85 分，必须同时抓竞争、感情、成长、使命四个维度。

## 三、50 策略速查表

以下为课程中总结的约 50 条可执行策略，按六维分类。实际使用时不必一次性全做，建议每个阶段重点补齐 2–3 个最短板。

### 3.1 目标有渴望（8 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **挑战难题** | 1. 定里程碑 | 把公司大目标与销售个人目标关联，拆成跳一跳够得着的阶段节点 |
| | 2. 多赢小仗 | 帮销售一步步打赢小仗，积累完成大目标的信心 |
| | 3. 讲清逻辑 | 讲清楚目标背后的因果和收益，让销售心甘情愿领任务 |
| | 4. 生活改善 | 把目标与销售关心的生活改善（买房、养家、还债）挂钩 |
| | 5. 非你莫属 | 用激将法或示弱法，让销售觉得这件事只有他能干 |
| | 6. 反向激励 | 适度刺激销售的自尊心，激发不服输的斗志 |
| **反馈及时** | 7. 黑板公示 | 用群名、白板、数据看板让目标进度可视化 |
| | 8. 进展夸奖 | 对每一个小进展即时给予正反馈 |

### 3.2 业绩有奖金（9 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **钱给到位** | 9. 设置底薪 | 设计合理的底薪结构，避免零底薪高提成导致团队极不稳定 |
| | 10. 发好提成 | 提成规则清晰、阶梯合理，让业绩突出者能拿得多 |
| | 11. 绩效奖金 | 对定性目标（大客户维护、预测能力）设置固定额度奖励 |
| | 12. 大奖金包 | 设置季度/年度大奖，用于冲刺关键战役 |
| | 13. 日常奖励 | 小额高频奖励，让销售每天都有正反馈 |
| | 14. 补贴到位 | 出差、市场费用、客户小礼品等补贴及时报销 |
| **奖励过程** | 15. 奖励过程 | 对关键里程碑动作（首次拜访、带看、新客户开发）给予奖励 |
| **奖励及时** | 16. 及时算好 | 用人工同步、Excel 测算表或系统让销售实时看到预计收入 |
| | 17. 按时发放 | 承诺的发放时间尽量兑现，延迟时提前沟通 |

### 3.3 同事有竞争（6 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **销冠荣誉** | 18. 授予头衔 | 给销冠命名化头衔、勋章或专属标识 |
| | 19. 设置奖励 | 设置最佳新人、最快进步、最具潜力等单项奖 |
| | 20. 独特权益 | 销冠享有专属福利（优先选客户、培训机会、家属晚宴等） |
| **张榜公示** | 21. 仪式感足 | 用敲锣、奖状、模拟支票等方式公开表彰 |
| | 22. 开表彰会 | 固定周期举办表彰会，老板亲自颁奖 |
| **分组 PK** | 23. 分组 PK | 按团队、区域、产品线分组竞赛，张榜但不打击末位 |

### 3.4 打仗有感情（9 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **团队建设** | 24. 迎新仪式 | 新人入职有固定欢迎流程，明确导师和求助对象 |
| | 25. 日常团建 | 给小额预算让销售自己组织饭局/活动 |
| | 26. 团队搭配 | 按 hunter/farmer、性格、客户类型互补组队 |
| **生活保障** | 27. 了解生活 | 关注销售生活困难，及时聆听和帮助 |
| | 28. 住宿保障 | 异地销售提供住宿或住宿补贴 |
| | 29. 配套装备 | 给大销售配好电脑、车辆等见客户的装备 |
| **善待家人** | 30. 钱给父母 | 部分奖金寄给父母，帮助销售储蓄和表达孝心 |
| | 31. 子女教育 | 关怀员工子女教育、入学等问题 |
| | 32. 生病关怀 | 本人或直系亲属生病时及时慰问、提供补贴 |

### 3.5 成长有奔头（10 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **老板扛事** | 33. 冲在前面 | 管理者比销售更勤奋，亲自参与大客户攻坚 |
| | 34. 抗住问题 | 出问题时不甩锅，与销售共同承担责任 |
| | 35. 能要资源 | 为销售向后端争取产品、研发、政策支持 |
| **做好培训** | 36. 企业内训 | 搭建分层培训课程，提升综合能力 |
| | 37. 老人带新 | 建立师徒制，让老销售传帮带 |
| | 38. 表率分享 | 销冠和骨干定期分享成功案例 |
| **辅导支持** | 39. 日常复盘 | 周/日复盘制度化，持续改进 |
| | 40. 及时鼓励 | 在关键节点给予具体表扬 |
| | 41. 助力成单 | 管理者在临门一脚时介入支援 |
| **晋升双轨** | 42. 晋升双轨 | 设计管理线 + 专家线，按业绩和能力双轨晋升 |

### 3.6 岗位有使命（8 策略）

| 武器 | 策略 | 落地动作 |
|------|------|----------|
| **外部认可** | 43. 公司更强 | 让销售对外能讲清楚公司实力和品牌背书 |
| | 44. 产品更好 | 让销售相信产品优势，有底气报价 |
| | 45. 老板更牛 | 借助创始人/老板 IP 为销售赋能 |
| | 46. 销售铁军 | 打造有战斗力的团队形象，让成员自豪 |
| **企业文化** | 47. 宣传使命 | 让销售理解公司存在的意义 |
| | 48. 宣传愿景 | 让销售看到公司未来蓝图 |
| **内部地位** | 49. 养活公司 | 让销售感知到自己对公司生存的贡献 |
| | 50. 核心团队 | 让销售进入核心圈层，参与重要决策 |

## 四、不同阶段的激励重点

| 阶段 | 业务特点 | 激励重点 | 核心策略举例 |
|------|----------|----------|--------------|
| **业务探索期** | 资源匮乏，模型未验证 | 以软性激励为主：目标渴望、打仗感情、岗位使命 | 定里程碑、迎新仪式、讲清使命 |
| **复制期** | 模型跑通，现金仍紧张 | 使命 + 感情 + 初步提成 + 引入竞争 | 老人带新、分组 PK、设置底薪提成 |
| **快速增长期** | 收入稳定，现金流好 | 金钱激励大胆，上不封顶，培养忠诚梯队 | 发好提成、大奖金包、晋升双轨 |
| **业务成熟期** | 增长放缓但稳定 | 规则细致，考核过程，奖励多元化 | 绩效奖金、奖励过程、规则透明化 |

> **经验提示**：探索期不要照搬增长期的重金钱激励，否则现金流压力会压垮团队；成熟期不要只讲感情不讲规则，否则老销售容易躺平。

## 五、发钱三大设计重点

发钱是销售激励中最敏感也最容易踩坑的环节。设计时需同时考虑三个点：

| 重点 | 核心问题 | 落地原则 |
|------|----------|----------|
| **杠杆点** | 钱要花在最能激发动力的地方 | 识别当前阶段的关键瓶颈（是新客户开发？大客户攻坚？还是回款？），把钱砸到关键动作上 |
| **公平点** | 规则是否公开透明 | 提成公式、发放时间、考核标准提前公示，尽量用公式而不是口头承诺 |
| **感知点** | 销售是否能清晰感知收入变化 | 通过日算、周结、系统实时显示，让销售随时看到「我做了多少、能拿多少」 |

> **法律与合规声明**：提成、绩效、奖金等涉及劳动法和税收规定，课程只提供管理设计思路，具体方案需结合当地法规、公司制度和财务/法务专业意见制定。

## 提成比例参考区间

课程在讨论提成设计时给出了一个按客单价区分的参考区间，用于管理者在缺乏内部数据时快速锚定 `[conf=0.82, source=00_inbox/销售专题/李蕊-销售体系之四-激励体系搭建-口述.txt L1648-L1654]`。

| 客单价区间 | 参考提成比例 | 课程案例 | 换算逻辑 |
|:---|:---|:---|:---|
| 低客单（约 3000–5000 元） | 约 8%–10% | 培训课销售 | 客单价低，需要较高比例才能形成有效激励 |
| 高客单（约 65000 元） | 约 5% | 高端学院课程 | 绝对值已足够大，比例可低于低客单 |

> 数字说明：以上比例来自课程经验分享，属于特定企业案例，**不应作为 universal 标准**。实际设计需结合毛利率、销售成本、回款周期、行业惯例和当地劳动/税务法规，并建议财务/法务复核。

**使用原则**：
1. **先看绝对值能否留住销售**：高客单即使比例低，单笔提成绝对额也要对销售有足够吸引力；
2. **再看过渡与长期影响**：提成比例不是越低越好，长期过低会导致优秀销售流失；
3. **激励哪些环节**：要区分「结果提成」和「过程奖励」，避免市场部拉新但门店不接待的激励错位。

## 零底薪高提成适用边界与切换信号

课程中提到一种极端薪酬结构：零底薪 + 高提成（提成比例可达约 30%–40%），并以定制旅游行业为例说明其适用场景 `[conf=0.82, source=00_inbox/销售专题/李蕊-销售体系之四-激励体系搭建-口述.txt L398-L402]`。

### 适用边界

| 维度 | 可尝试的情况 | 不建议的情况 |
|:---|:---|:---|
| **现金流** | 公司现金流紧张，无法承担固定底薪 | 现金流已稳定，有能力支付底薪 |
| **销售特质** | 销售愿意接受挑战、对高提成有强渴望 | 团队需要稳定收入预期、家庭负担重 |
| **业务阶段** | 探索期/复制期，模型尚未完全验证 | 成熟期，需要规则透明和团队稳定 |
| **行业惯例** | 行业内存在零底薪高提成先例 | 行业普遍有底薪，零底薪会导致招聘困难 |

### 切换信号

零底薪高提成应被视为**过渡结构**，而非长期方案。当出现以下信号时，应考虑恢复底薪或降低提成比例：
- 连续 2–3 个月现金流转正，具备支付底薪能力；
- 销售流失率明显上升，招聘难度加大；
- 团队短期行为严重，只追容易成交的单、不愿拓新；
- 公司从「活下来」转向「规模化复制」，需要稳定组织。

> 风险提示：零底薪结构可能涉及劳动法、社保缴纳等合规风险，具体方案需财务/法务复核，不能照搬课程案例。

## 情感仪式与狼性文化风险

六维激励模型中，「同事有竞争」「打仗有感情」「岗位有使命」三个维度都涉及非物质激励。课程指出，当团队从 60 分往 80 分、85 分走时，精神层面、情怀类激励会越来越多 `[conf=0.83, source=00_inbox/销售专题/李蕊-销售体系之四-激励体系搭建-口述.txt L1126-L1128]`。

### 情感仪式的正向作用

| 场景 | 仪式示例 | 管理意图 |
|:---|:---|:---|
| 阶段性胜利 | 敲锣、奖状、模拟支票表彰 | 强化「小胜仗」的即时反馈 |
| 团队凝聚 | 迎新仪式、团建、家属晚宴 | 让销售对团队产生归属感 |
| 使命传递 | 宣传公司愿景、让销售参与重要决策 | 把工作意义从「卖东西」升级为「创造价值」 |

### 狼性文化风险

情感仪式如果过度使用或方向跑偏，可能带来以下风险：
1. **形式大于内容**：只搞喊口号、打鸡血，没有真实业绩支撑，销售会觉得被洗脑；
2. **过度竞争伤害协作**：分组 PK、末位打击如果设计不当，会造成内部抢客户、不分享经验；
3. **忽视个体差异**：不是所有人都对「狼性」买账，对使命、成长、生活保障敏感的销售可能被排斥；
4. **合规与舆论风险**：极端狼性文化可能触碰劳动权益边界，甚至引发外部负面舆论。

### 使用建议

- 情感仪式必须与**真实业绩反馈**和**公平规则**配套；
- 竞争设计要「张榜但不打击末位」，给落后者改进路径；
- 定期用匿名反馈或离职访谈检查团队对仪式文化的真实感受；
- 涉及薪酬、工时、劳动权益的激励设计，需财务/法务复核。

> 延伸框架：当销售目标之间发生冲突（GMV vs 利润 vs 立标杆）时，激励设计需要与目标权衡框架配合，参见 [[framework-yitang-sales-target-tradeoffs]]。

## 六、OPC 智能体适配

六维激励模型原版为「带团队的管理者」设计，直接移植到一人公司（OPC）会水土不服。OPC 没有「团队」，因此需要将「激励团队」替换为「创始人自我驱动 + AI 反馈循环」。

### 6.1 不适用 OPC 的模块

- 同事有竞争、打仗有感情、岗位有使命：缺乏真实团队场景，难以直接生效。
- 金钱激励结构：OPC 的收入即公司利润，不需要设计「提成」。

### 6.2 OPC 替代方案：目标-行动-反馈循环

| 原模块 | OPC 替代 | 智能体角色 |
|--------|----------|------------|
| 目标有渴望 | 创始人对季度/月度目标的自我承诺 | 智能体记录目标、拆解里程碑、每日提醒 |
| 业绩有奖金 | 利润分配再投资/个人生活保障目标 | 智能体实时计算收入、成本、可分配利润 |
| 成长有奔头 | 个人技能升级、客户能力积累 | 智能体推荐学习、复盘动作、跟踪进步 |
| 岗位有使命 | 业务对客户/行业的价值感 | 智能体每周生成「价值小结」，强化使命感 |

### 6.3 可落地的智能体规格

```text
角色：OPC 销售自我激励助手
输入：创始人本周目标、已完成动作、收入/成本数据、客户反馈
输出：
  1. 里程碑进度条（目标完成率、关键动作完成率）
  2. 收入可视化（本周预计收入、本月累计、可分配利润）
  3. 下一步最小行动建议
  4. 每周一句「价值确认」：本周为客户创造了什么价值
边界：
  - 不替代真实人际反馈和创业同伴支持
  - 不自动做重大财务/法律决策
  - 数据需本地/合规处理
```

## 七、Checklist

- [ ] 已诊断团队当前最缺哪个激励维度（六维雷达图自检）
- [ ] 激励目标与公司当前业务阶段匹配（探索期/复制期/增长期/成熟期）
- [ ] 提成/奖金规则已书面化，能向销售讲清楚计算公式
- [ ] 目标已拆到可执行的里程碑，销售能看到阶段性胜利
- [ ] 至少有 1 种非物质激励在运行（荣誉/团建/成长/使命）
- [ ] 奖励发放时间已约定，并有延迟时的沟通预案
- [ ] 过程奖励与结果奖励比例合理，避免只奖励结果导致动作变形
- [ ] 激励方案已跑完一个完整周期再决定是否调整
- [ ] 涉及薪酬/劳动合规的条款已咨询专业法务或财务
- [ ] OPC/一人公司使用者已将「团队激励」改编为「自我驱动循环」

## 八、Anti-patterns

| 反模式 | 表现 | 后果 |
|--------|------|------|
| **只发钱** | 所有激励手段只剩提成和奖金 | 销售只挖老客户，不愿拓新，动力边际递减 |
| **目标拍脑袋** | 年度目标年年涨，但没有拆解方法和资源支持 | 销售躺平，团队不信任目标 |
| **规则不透明** | 提成公式不敢公开，发钱时讲不清楚 | 内耗、猜忌、优秀销售流失 |
| **激励与目标割裂** | 激励方向与公司战略重点不一致 | 销售做对公司无益但对自己有利的事 |
| **频繁改规则** | 方案跑不到一个周期就调整 | 销售觉得被算计，短期行为严重 |
| **忽略探索期软性激励** | 早期资金紧张就干脆不做激励 | 团队缺乏基本动力，连 60 分都保不住 |

## 九、Critique

### 外部反对者

**A. 行为经济学家：非物质激励效果有限，金钱才是最直接信号**
- 反对点：对大多数销售而言，收入才是硬道理，荣誉、使命感是锦上添花。
- 回应：金钱确实是基础保健因素，但单一金钱激励会导致行为扭曲（挖老客、拒新客）。六维模型的价值在于用非物质激励补充金钱无法覆盖的长期动力。关键是组合，而非二选一。

**B. 精益创业派：早期公司不该花精力建激励体系，而应all in产品和市场验证**
- 反对点：探索期资源极少，建激励体系是过度管理。
- 回应：本框架明确探索期以「软性激励」为主，不主张重金钱投入。目标渴望、打仗感情、岗位使命几乎不需要额外资金，但能防止早期销售团队散架。

**C. 人力资源合规专家：许多激励设计触碰劳动法、社保和税收红线**
- 反对点：零底薪高提成、现金奖励、补贴不透明等做法可能违法或引发税务风险。
- 回应：本框架仅提供管理思路，落地时必须由专业机构审核薪酬结构、社保缴纳、个税代扣等合规细节，不能照搬课程案例。

**D. 组织行为学研究者：激励效果高度依赖文化和个体差异，难以标准化**
- 反对点：不同行业、地区、代际的销售对荣誉、竞争、使命的敏感度差异巨大。
- 回应：六维模型是「体检清单」和「策略池」，不是固定配方。管理者需要根据团队反馈动态调整权重，并通过 A/B 测试验证效果。

### 内部局限

1. **数据来源为课堂经验，缺少大规模实证**：课程中的案例（如美团、3M、支付公司）多为经验叙事，未经过严格的对照实验或跨行业验证，应用时应作为启发而非真理。

2. **对成熟大企业的组织复杂度估计不足**：模型主要面向创业和成长期团队，对大型企业中复杂的矩阵管理、跨部门博弈、薪酬带宽限制等场景覆盖有限。

3. **激励与惩罚的边界未充分展开**：框架强调「激励」，但对「负激励」、末位淘汰、文化冲突等敏感话题讨论较少，落地时容易走向只奖不罚的极端。

4. **OPC 改编尚处于概念层**：目标-行动-反馈循环的颗粒度较粗，具体智能体实现、数据安全、创始人心理机制等仍需后续迭代。
