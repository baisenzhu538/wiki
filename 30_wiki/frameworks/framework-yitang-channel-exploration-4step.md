# 渠道探索四步法：科学找到可持续获客渠道

## 一句话

渠道探索四步法是通过 **扫描 → 预判 → 测试 → 建模** 四个环节，系统性地找到并持续化一条或多条获客渠道的方法论；它的核心目标不是追求一次性爆款，而是让业务获得可持续的收入循环 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §14-49, 268-318]`。

## 核心结构图

```
┌─────────────────────────────────────────────────────────────┐
│                    渠道探索四步法                             │
├───────────┬───────────┬───────────┬─────────────────────────┤
│  1. 扫描   │  2. 预判   │  3. 测试   │       4. 建模            │
│  （做加法） │  （做减法） │  （拿认知） │     （持续化）           │
├───────────┼───────────┼───────────┼─────────────────────────┤
│ 打开视野   │ 渠道特性   │ 关键指标   │ 业务公式拆解              │
│ 消除盲区   │ 产品匹配   │ 低成本验证 │ 持续提转化率              │
│ 20-50 选项 │ 确定性评分 │ 动态调整   │ 工业化生产                │
└─────┬─────┴─────┬─────┴─────┬─────┴───────────┬─────────────┘
      │           │           │                 │
      └───────────┴───────────┴─────────────────┘
                          │
                          ▼
              可持续获客渠道组合
```

**工作流公式（启发式）**：

> 可持续获客 = Σ(验证通过的渠道_i × 单渠道单元模型_i × 渠道生命周期_i)

这个公式强调：最终业绩不是依赖单一渠道，而是多条有效渠道在各自生命周期内的叠加 `[conf=0.84, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-笔记.txt §39-49]`。

## 1. 四步详细拆解

### Step 1：扫描——做加法，打开视野，消除盲区

扫描的中心任务是：把尽可能多的潜在渠道拉出来，让自己有机会做选择题。Truman 强调，很多团队失败不是因为测试能力差，而是选项池里根本没有正确答案 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §268-279, 2982-3005]`。

**目标数量**：通常建议列出 **20–50 个** 备选渠道，关键业务甚至要做到 50–100 个 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3638-3646]`。

**三个扫描策略**：

| 策略 | 核心动作 | 适用场景 |
|:---|:---|:---|
| **借鉴同行** | 研究竞争对手、行业标杆已经在用的渠道 | 有明确对标对象时 |
| **使用小抄** | 用线上/线下/转化/推荐四类获客清单自查盲区 | 认知边界不清晰时 |
| **大胆推演** | 基于用户、场景、触点、动力、阻力五要素做创新组合 | 需要差异化渠道时 |

**解放思想五要素**：

真正创新的渠道假设，往往来自对五个底层要素的重新组合 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3346-3436]`：

1. **用户**：能不能换一个人群切片？
2. **场景**：能不能换一个出现场景？
3. **触点**：能不能换一个触达点或动线？
4. **动力**：能不能给渠道方/用户更强的推荐动力？
5. **阻力**：能不能消除信任、骚扰、操作等阻力？

> 例：驾校推荐渠道的创新——在科目二通过的峰值体验时送六杯奶茶，让学员带回宿舍推荐，本质上是换了一个「触点」和一个「动力」设计 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3294-3324]`。

### Step 2：预判——做减法，科学排序，避免散弹枪

预判不是拍脑袋，而是用一套结构化的评分逻辑，把 20–50 个渠道收敛到 Top 5–10 再进入测试。Truman 提醒：减法要靠专业度，三只手同时抓——渠道特性、产品匹配、确定性/能力 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3706-4317]`。

#### 2.1 渠道特性五维度

评估渠道本身时，至少看五个维度 `[conf=0.92, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-渠道特性-五个维度_vlm_desc.md]`：

| 维度 | 问题 | 偏好场景 |
|:---|:---|:---|
| **大小** | 渠道能覆盖多少目标用户？ | 成长期追天花板 |
| **集中度** | 目标人群密度高不高？ | 精准触达优先 |
| **成本** | 获客/进入成本是否可承受？ | 早期低成本优先 |
| **快慢** | 多久能看到结果？ | 早期优先起盘快的 |
| **持续性** | 渠道生命周期有多长？ | 成熟期优先稳定渠道 |

#### 2.2 产品匹配维度

- **标准化程度**：越标准化、信息越透明的产品，越适合电商、搜索、短视频等自助式渠道；越非标、越需要说服的产品，越需要社群、直播、面销等高信息密度渠道 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3940-4079]`。
- **客单价/毛利**：客单价决定你能承受的销售成本。一堂内部经验：低客单价用图文/短视频；1000 元左右可尝试社群/促销/陌拜，3500 元以上才更适合电销；万元级产品通常用面销/顾问式销售 `[数字来自 Truman 口述/估算，会随平台政策与行业差异漂移，待独立核实]`。

#### 2.3 确定性与能力维度

即使渠道和产品匹配，也要问自己三个问题：

1. **同行是否跑通？** 有成功案例说明「事可行」。
2. **团队能力是否拉满？** 资金、技能、资源是否到位。
3. **与合格线差距多大？** 差距小可救，差距大要果断放弃。

**早期原则**：优先选择 **确定性高、起盘快** 的渠道，哪怕天花板小。活下来比赌大渠道更重要 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3875-3926]`。

### Step 3：测试——低成本拿认知，数据说话

测试阶段要把「脑子里的预判」变成「真实世界的数据」。关键是：**不要线性推进，而要建立关键假设池，动态建立信心** `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4489-4606]`。

#### 3.1 找到关键指标（尺子）

每个渠道都需要一把稳定的尺子，避免测完不知道好坏。最基本的两个刻度：

- **ROI / CAC**：获客质量；
- **规模/增速**：获客上限。

再叠加三个维度：天花板、增速、持续性。Truman 强调：算不清楚时，归因到单元模型 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4436-4455]`。

#### 3.2 低成本验证三层方法

| 方法 | 成本 | 速度 | 作用 |
|:---|:---|:---|:---|
| **专家访谈** | 几十到几百元 | 几小时 | 用常识快速排除明显不靠谱的渠道 |
| **情报调研** | 几百到几千元 | 几天 | 看同行 benchmark、市场规模、进入门槛 |
| **小范围实验** | 几千到几万元 | 几天到几周 | 拿到真实转化数据 |

> 例：一堂测试孵化器陌拜渠道时，现场拆业务公式，打电话给专家确认两个关键参数，2 小时内判定 ROI 极低，省掉可能三个月、小十万元的测试 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4613-4638]`。

#### 3.3 动态调整：判断「事不行」还是「人不行」

测试不顺时，用三维判断法 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4695-4743]`：

1. **看同行成功率**：同行跑通则可能是人的问题；
2. **看能力是否拉满**：是否做到了团队逻辑上的最好水平；
3. **看与合格线差距**：差距小（如 30% 以内）可救，差距大（如 50% 以上）应止损。

### Step 4：建模——持续化、工业化，延长渠道生命周期

这里的「建模」不是做一个静态文档，而是把验证通过的渠道拆解为可迭代、可规模化的业务公式与生产机制；「持续化」和「工业化生产」是建模输出的两种形态 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4757-4896]`。

渠道天然会衰减：好投放的号会被投完、用户会疲劳、平台政策会变。建模的目标不是让渠道永远不死，而是尽量延缓下滑、提高稳定性和规模经济性。

最终，多个验证通过的渠道应落到 `[[framework-yitang-channel-unit-economics]]` 的渠道投资组合决策中，平衡快回收、可扩展与实验型渠道，避免单一渠道风险。

**建模三任务**：

| 任务 | 核心动作 | 示例 |
|:---|:---|:---|
| **拆业务公式** | 把渠道拆解成 3–5 个甚至 30–50 个参数，定位问题 | 复盘营的到场率、作业率、留存率、推荐率 |
| **持续提转化率** | 围绕关键参数不断提假设、做实验 | 一堂抖音从 0.3–0.6 ROI 调到稳定产出 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §2728-2730, 2866]` |
| **工业化生产** | 用流程替代个人手感，保证大规模持续交付 | 公众号投放的首投/二投模型、短视频 ABCD 模型 |

## 2. 核心洞察：可持续获客是项目生存标志

Truman 反复强调：可持续获客是项目生存的关键标志之一，但产品价值与商业模式仍是前提。在它们基本成立之后，能否建立可持续的获客渠道、完成第一个收入循环，往往决定项目能不能真正活下来 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §14-21, 1314-1321]`。

这意味着：

- 产品好但卖不动，项目依然会死；
- 商业模式成立但流量不可持续，公司也会慢慢耗光现金流；
- 渠道探索能力是一家公司从 0 到 1 的核心基本功。

一堂自身从 2021 年以来新用户增长规模涨了近十倍 `[数字来自 Truman 口述/估算，待独立核实]`，核心经验是：几乎以每周为单位提假设、做实验、复盘认知 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §40-42, 1340-1343]`。

## 4. When NOT to Use

### 4.1 不适合的场景

- **产品价值尚未验证**：如果产品本身没人要，再好的渠道也只会加速死亡。应先用精益创业验证价值假设。
- **没有基本资源**：扫描和预判几乎不需要钱，但测试需要最低限度的资金和人力。如果连小范围实验都无力启动，应先解决生存能力。
- **团队没有测试能力**：渠道测试需要数据分析、实验设计、快速迭代能力。如果团队只会执行不会复盘，四步法会沦为形式。
- **一次性项目**：四步法解决的是持续获客问题，单次 campaign 用漏斗或项目制管理更合适。

### 4.2 特殊边界

- **早期不要盲目追大渠道**：量大、成本高、持续性好的渠道往往是大公司的战场，早期硬上广点通、巨量引擎等渠道风险极高 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3927-3934]`。
- **不要追求「一击即中」**：好的渠道通常是调出来的，不是一次测出来的。关键是建立快速止损和快速学习的机制。

### 4.3 特殊风险边界

以下风险并非四步法本身能消除，需在执行中额外评估：

- **用户骚扰与品牌反噬**：老带新、地推、电销、私域裂变若过度打扰用户，会损害品牌信任。设计渠道时需把「不骚扰」作为约束条件，而非仅追求转化率 `[conf=0.80, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §3516]`。
- **合规与平台政策风险**：数据隐私、广告法、电销许可、裂变奖励机制可能触碰监管红线；抖音、视频号、公众号、知乎等平台的投放/内容政策也可能突变。上线前需法务/合规 review，并准备政策突变时的备选渠道。
- **渠道冲突**：直销团队与代理商、不同区域/层级渠道之间可能存在利益冲突；大渠道被竞对买断或签订排他协议也会封锁通路。需提前在合同与激励机制中明确边界。

## 5. 常见失败模式

### 失败模式 1：依赖手感碰运气

**症状**：什么火做什么，渠道换来换去，始终没有系统的方法论。

**修复**：强制做扫描清单，至少列出 20 个备选渠道，给自己做选择题的权利。参考 `truman-渠道探索方法论-反案例-渠道扫描错误案例_vlm_desc.md` 中的饮料代理、烤鱼连锁店等 #盲目跟风、#认知盲区 案例。

### 失败模式 2：跳过扫描和预判，直接测试

**症状**：脑子里出现一个答案就扎进去，花光预算才发现还有其他 99 条路。

**修复**：先花 30% 的资源做加法和减法，再用 70% 的资源做验证。参考 `truman-渠道探索方法论-反案例-渠道预判踩坑_vlm_desc.md` 中研学、袋泡茶、O2O、AI 自习室等 #盲信经验、#没有重心 案例。

### 失败模式 3：单渠道依赖

**症状**：所有收入压在一个渠道上，一旦平台政策或竞争格局变化，业务立刻崩塌。

**修复**：成熟期布局 3–5 个不同类型渠道，避免单一渠道失控。参考 `truman-渠道探索方法论-反案例-渠道扫描错误案例_vlm_desc.md` 中化妆培训、服装、水处理等 #渠道单一 案例。

### 失败模式 4：混淆「事不行」和「人不行」

**症状**：渠道数据不好时，要么过早放弃有潜力的渠道，要么在明显不可行的渠道上死磕。

**修复**：用「同行成功率 + 能力拉满度 + 与合格线差距」三维判断。

### 失败模式 5：测试方法线性推进

**症状**：一个渠道失败再换下一个，每次重新组建团队、重新投入，学习和资金效率极低。

**修复**：建立关键假设池，专家访谈、情报调研、小实验并行推进，动态建立信心。

### 失败模式 6：忽视渠道生命周期

**症状**：渠道跑通后不做建模，ROI 自然下滑，三个月后从盈利变亏损。

**修复**：从跑通第一天就拆业务公式，持续提转化率，建立工业化生产机制。参考 `truman-渠道探索方法论-反案例-渠道建模踩坑_vlm_desc.md` 中动漫周边、教育公司等 #不可持续、#没有模型 案例。

### 失败模式 7：把建模当成 SOP 照搬

**症状**：以为建个流程文档就是工业化，忽视加减法和筛选机制。

**修复**：工业化生产=加法池 + 减法模型 + 筛选测试流程，三者缺一不可 `[conf=0.85, source=00_inbox/一堂五步法之增长/truman-渠道探索方法论-口述.txt §4890-4896]`。参考 `truman-渠道探索方法论-反案例-渠道建模踩坑_vlm_desc.md` 中污水处理设备、数字化新基建等 #没有模型 案例。

### 失败模式 8：忽视渠道冲突与平台政策风险

**症状**：渠道跑通后未考虑第三方平台规则变化、竞对封锁、直销与代理冲突，一旦平台政策或合作条款突变，收入立即断崖。

**修复**：在预判阶段就把渠道冲突、平台政策、竞对动作列为风险维度；成熟期至少保留 1–2 条不依赖同一平台/场地的备用渠道。

## 6. Critique：三派质疑与回应

### 6.1 增长黑客派

**质疑**：四步法太慢，增长黑客强调快速试错、数据驱动。

**回应**：四步法并不排斥快速试错，而是让试错更有结构。扫描和预判的目的正是减少低质量试错，测试和建模阶段完全可以一周一个实验。

### 6.2 资源约束论者

**质疑**：小公司没有资源同时扫描 50 个渠道、维护假设池。

**回应**：扫描主要靠脑力而非资金；预判靠专家访谈和情报调研，成本从几十到几千元；真正烧钱的是测试。四步法帮助小公司把有限的弹药花在最有希望的渠道上。

### 6.3 精益创业视角

**提醒**：渠道探索四步法的前三步（扫描、预判、测试）本质上是对「获客假设」的低成本验证，与精益创业的假设-实验-学习循环高度一致。但四步法更强调渠道的系统性筛选和持续性建模，而不是单次验证。具体可参考 `[[concept-yitang-channel-lean-validation-bridge]]`。

### 6.4 来源与时效性边界

- **来源层级**：本框架的核心主张（可持续获客的重要性、四步法、渠道特性五维度、案例数字）主要源自一堂内部案例与 Truman 口述，未与外部独立数据源做交叉验证。因此 `trust_level` 已降至 `medium`，关键数字均标注 `[conf=..., source=...]` 或「待独立核实」。
- **时效性边界**：案例与经验值来自约 2024 年的口述与素材。2025–2026 年，AI 搜索/内容生产、小红书电商闭环、视频号投流政策、隐私合规（苹果 ATT、安卓隐私沙盒）等变量可能显著改变渠道成本与五维度评估结果。读者需按当前行业、平台与合规要求重新测算，不建议直接套用历史数字。

## 7. 与一堂五步法的关系

渠道探索位于一堂五步法的「增长」环节，但它不是孤立存在的：

- **用户内核**：渠道选择必须回到目标用户是谁、他们在哪里扎堆。
- **产品内核**：标准化程度、客单价、毛利空间决定渠道匹配。
- **商业模式/单元模型**：渠道测试的尺子最终要归到 CAC、LTV、ROI、回收周期。
- **增长飞轮**：当多个渠道协同增强时，可以进一步升级为增长飞轮。
- **工业化生产**：渠道建模的高级形态就是把不稳定的手工活变成可持续的工业化流程。
