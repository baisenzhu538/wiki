# 创始人 IP 三定位模型

> **Burn line**: 网红追求流量，创始人 IP 追求信任。三定位不是三件事，而是一个递进问题：先回答怎么赚钱，再回答拍什么，最后回答用户为什么信你。

## Summary

创始人 IP 三定位模型把 IP 建设拆成三个必须按顺序回答的问题：

1. **商业定位**：你怎么赚钱？卖什么？客单价多少？成交路径是什么？
2. **内容定位**：拍什么能让目标用户种草？
3. **人设定位**：用户为什么信你，而不是信别人？

这三个定位缺一不可：
- 没有商业定位 → 内容火了但不变现
- 没有内容定位 → 有产品但没流量
- 没有人设定位 → 有流量但无信任，转化不了

## Claims

### Claim 1：商业定位必须排在第一位

很多创始人做 IP 的第一个错误是：先想"拍什么能火"。但如果没有明确的商业闭环，流量越大，成本越高。

> 大馨战队案例：「网红追求流量，创始人 IP 追求信任」——魏千洛

商业定位要回答：
- 卖什么？（课程 / 服务 / 产品 / 咨询）
- 客单价多少？
- 卖给谁？
- 成交路径是什么？（公域 → 私信 → 资料 → 付费）

### Claim 2：内容定位不是"我想讲什么"，而是"用户需要什么"

创始人 IP 的内容，是解决问题。用户有什么问题，就拍什么。不是把创始人想表达的观点强行塞给用户。

判断标准：如果删除你的个人经历，这条内容对别人还有用吗？
- 如果没用 → 这是自嗨内容
- 如果有用 → 这是内容定位正确的信号

### Claim 3：人设定位是信任度的核心

用户付费高客单产品，往往不是因为产品本身，而是因为信任"你这个人"。人设定位要提炼：
- **专业标签**：你解决了什么具体问题
- **经历标签**：为什么是你（ Credentials ）
- **性格标签**：用户能否 3 秒钟记住你

## 操作步骤

### Step 1：回答商业定位三问

```text
1. 我的产品/服务是什么？客单价多少？
2. 目标用户是谁？他当前最痛的点是什么？
3. 从公域流量到付费的成交路径是什么？
```

**验收信号**：能用一句话说清"我帮谁，通过什么，解决什么问题，收多少钱"。

### Step 2：推导内容定位

基于商业定位，列出目标用户的 10 个高频问题。然后筛选：
- 哪些问题能体现你的专业判断？
- 哪些问题用户会主动搜索？
- 哪些问题能自然导向你的产品？

**验收信号**：有 30 天内容选题库，每个选题都对应一个用户痛点。

### Step 3：提炼人设定位

填写人设定位表：

| 维度 | 我的标签 | 证据/故事 |
|---|---|---|
| 专业标签 | 我解决什么具体问题 | 案例、数据、客户证言 |
| 经历标签 | 为什么是我 | 创业故事、行业年限、独特背景 |
| 性格标签 | 用户怎么记住我 | 口头禅、视觉风格、价值观 |

**验收信号**：用户能用一句话描述你是谁、你为什么可信。

### Step 4：三定位一致性检查

检查内容定位是否服务于商业定位，人设定位是否支撑内容定位。

```text
商业定位（卖什么）→ 内容定位（拍什么）→ 人设定位（为什么信你）
```

如果三定位互相矛盾（例如商业定位是高客单咨询，内容定位是泛娱乐短视频），需要重新调整。

## 质疑

### 内部局限

1. **具体假设：创始人已有明确产品或服务**
   三定位模型的**前提**是创始人能回答「卖什么、卖给谁、怎么卖」。对于早期探索型创始人，商业定位本身就在变化，强行套用会导致内容方向频繁调整。**边界**：三定位更适合已进入验证期、需要放大信任的业务，而不是从 0 探索产品-市场匹配的阶段。

2. **人设定位容易被模仿**
   专业标签和经历标签相对难以复制，但性格标签（口头禅、视觉风格）容易被模仿。真正的人设壁垒来自持续输出和真实案例。**反例**：某些账号模仿成功 IP 的说话风格，但缺乏真实案例支撑，最终因内容空洞而停更。

3. **行业差异大**
   ToC 消费品和 ToB 专业服务的 IP 打法不同。三定位的权重需要按行业调整。例如，ToC 可能更重视内容定位（种草效率），ToB 高客单服务更重视人设定位（信任建立）。

### 外部攻击

#### 质疑者视角 A：流量优先论

在互联网早期，很多创始人 IP 是"先做大流量，再想办法变现"。三定位把商业定位放在第一步，可能限制了内容的传播广度。

**回应**：流量优先适合广告变现和平台分成模式。对于高客单专业服务，没有信任基础的流量是成本而非资产。三定位不是反对流量，而是反对"只有流量没有转化"。

#### 质疑者视角 B：人设是表演，不真实

过度强调人设定位可能导致创始人变成"演员"，失去真实性，最终被用户识破。

**回应**：好的人设定位不是扮演一个角色，而是放大真实的专业标签和价值观。用户反感的不是人设，而是"假人设"。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|---|---|---|
| 创始人还没有产品或明确服务 | 商业定位无法回答 | 先做产品验证，再建 IP |
| 追求短期爆款而非长期信任 | 三定位是长期资产建设，短期 ROI 不明显 | 明确这是品牌建设投入，不是短期投放 |
| 创始人不愿意公开个人经历 | 人设定位缺少经历标签支撑 | 用专业标签和案例替代个人故事 |

### Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |

| 准备做创始人 IP | 先写商业定位一句话 | 能清楚说出产品、客单价、成交路径 |
| 内容数据差 | 检查内容定位是否偏离商业定位 | 每条内容都能回答"这条视频想让谁做什么" |
