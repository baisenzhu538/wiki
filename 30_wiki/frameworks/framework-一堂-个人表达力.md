# 一堂个人表达力总框架：火箭模型×十指讲香×逐字稿

> **一句话**：表达力是个人修炼的"输出层"——上游（产品内核/动力阻力/卖点）找准之后，靠它把卖点"讲得让人听得进去"。四块拼图：火箭模型（纲）+十指讲香（术）+逐字稿（控制）+刻意练习/灵感闪念（训练）。

---

## 一、四块拼图

```
┌──────────────────────────────────────────┐
│          表达力总框架                      │
│                                          │
│  火箭模型（纲）──→ 十指讲香（术）          │
│  四要素递进        十指组合匹配            │
│       │                  │                │
│       └──────┬───────────┘                │
│              ▼                            │
│        逐字稿（控制）                       │
│        写下来→讲出来→改出来                 │
│              │                            │
│              ▼                            │
│    刻意练习+灵感闪念（训练）                 │
│    练→反馈→再练                            │
└──────────────────────────────────────────┘
```

| 块 | 做什么 | 核心卡 |
|:---|:---|:---|
| **火箭模型** | 表达力的四要素递进——有卖点→有专业度→打动人→逐字稿 | `framework-一堂-表达力火箭模型` |
| **十指讲香** | 十个技巧把"价值点"变成"价值感" | `yt-model-personal-pitch-toolkit` |
| **逐字稿** | 写下来→抠字眼→练出来 | `yt-personal-verbatim-script` |
| **刻意练习** | 练→反馈→再练→固化 | `yt-personal-scientific-expression` |

---

## 二、上游承接

表达力不是孤立技能——它承接上游的"卖点输入"：

```
产品内核 → 动力阻力 → 卖点 → 表达力（本域）
  ↑                          ↓
找准卖点                    讲好卖点
```

如果卖点没找准（上游问题），十指讲香再厉害也没用。表达力教练必须先判断"卖点找准了没有"。

---

## 三、十指讲香：术与道

讲香十指口述版（阿蕊，3504行）有两层：

| 层 | 内容 | 现有卡状态 |
|:---|:---|:---|
| **术**（十指技巧） | 金句/口语化/冲突/情绪化/具象化/场景化/升华——10个具体技巧 | ✅ yt-pitch-* 10张已覆盖 |
| **道**（为什么需要十指） | 卖点找准却"直男式直给"→数据差；十指把"价值点"双向拉伸成"价值感" | 🔴 口述版有但wiki缺失——本任务补why卡 |

---

## 四、When NOT to Use

- 卖点没找准——先回上游（产品内核/动力阻力）
- 不需要公开表达的场景
- 已经有成熟表达风格的人

## 失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 跳过纲直接学术 | 没搞清楚"我有什么卖点"就开始练技巧 | 先过火箭模型四要素 |
| 十指堆砌 | 十指全用上——内容花哨但没重点 | 选2-3指组合，不是十指全上 |
| 只练不写 | 讲了很多遍但不写逐字稿 | 强制写逐字稿——写下来的才是真功夫 |
