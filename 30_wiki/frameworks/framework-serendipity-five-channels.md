# 偶遇自动采集五通道：让偶遇成为资产

> 本卡属于「AI×知识管理」体系（楚门探索营第五次飞跃·体系自动化之一，L2520-2870 + 015814 图）：日常偶遇的碎片（文章/视频/灵感/产品/项目）通过五条自动化通道进入知识库，两三分钟变成可调用的 Markdown 资产——"别点收藏了，收藏夹不会变成你的资产"（L2590）。配套：单点学习一年 100+ 个 + 饱和话术 + 120 万字笔记零人工撰写。

## 1. 核心洞察

体系自动化的第一层（L2572-2578）：把"日常偶遇变成自动采集"——碎片进知识库，而不是收藏夹吃灰。五通道：

| 通道 | 触发 | 自动处理 | 产出 |
|:--|:--|:--|:--|
| ① 文章 | 公众号/知乎点收藏 | Cubox 自动转 Markdown（两三分钟） | Obsidian 知识库笔记 |
| ② 视频 | 视频号/短视频 | 自动转逐字稿+可视化编排+分类 | Cubox 月份文件夹 |
| ③ 创作者 | 喜欢一个作者 | 抖音学习产品清单+代表作 5-10 条 | NAS 存储+逐字稿+研究文档 |
| ④ 选题 | 一分钟随手看到新品 | 深度调研 Skill 全网饱和研究 | 1-3 天研究报告 |
| ⑤ 开源项目 | 偶遇开源项目 | 交叉验证真实性→是否合作→部署 ROI | 评估报告 |

## 2. 关键机制

- **AI 超级入口**（L2648-2652）：任何视频扔给超级入口，两分钟出现在 Cubox 月份文件夹+逐字稿
- **单点学习**（L2682-2686）：一年至少 100 个——看到课题/理念/项目随手扔给对应 Agent 研究
- **饱和话术**（L2734-2742）："不要给我省任何投入，至少调研 30-50 篇文章，写不出来不许提交"（C1 与爆炸式 W3-1 互链）
- **事实核查**（L2756-2778）：投资稿案例——Claude 研究后指出五个关键错误（名字错/没有员工是错的），"好多都是博主瞎编的"
- **120 万字机制**（015814 + L50）：龙虾项目累计约 120 万字笔记零人工撰写——收集→转写→核查→分类→打分→聚合全自动化

## 3. 使用步骤

1. **打通通道①**：公众号/知乎收藏 → Cubox → Obsidian（两三分钟）
2. **打通通道②**：视频号 → 自动转逐字稿+分类
3. **建 AI 超级入口**：任何偶遇扔一个入口自动采集
4. **配深度调研 Skill**：选题研究 1-3 天出报告
5. **单点学习派活**：随手扔给对应 Agent（一年 100+）

## 4. When NOT to Use

1. **采集量少**——偶遇不多时通道成本高于收益。
2. **无 AI 基础设施**——自动转写/调研需要 AI Skill 支撑。
3. **收藏夹够用**——不追求资产化时点收藏即可（但收藏夹不会变成资产）。

## 5. 失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 采集不分类 | 全堆 inbox 不归类 | 自动分类脚本（B8）+目录规则 |
| 采集不消化 | 转成 Markdown 没人读 | 单点学习派活（扔给 Agent 研究） |
| 省 token | 调研浅 | 饱和话术（30-50 篇不许省投入） |
| 通道断 | 视频转不了逐字稿 | 备用方案（腾讯官方/元器，不稳定但能用） |

## 6. Action Triggers

- 常点收藏但不回看 → 建自动采集通道（收藏夹→资产）
- 偶遇灵感无处安放 → 扔 AI 超级入口
- 看到产品/作者/项目 → 单点学习派活（对应 Agent 研究）
