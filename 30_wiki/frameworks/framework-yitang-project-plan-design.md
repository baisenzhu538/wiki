# 项目定方案：背景-目标-关键路径三段论

> **一句话**：定方案80%的失败是因为跳过"背景"——没论证是不是真问题，就开始写解决方案。三段论强制先问"为什么做"，再问"做什么"，最后才问"怎么做"。

---

## 一、三段论

```
背景：为什么做？（真问题 vs 假问题）
  ↓
目标：做成什么样算成功？（SMART + 评估三角）
  ↓
关键路径：怎么做到？（里程碑 + 资源 + 风险）
```

---

## 二、Step 1：背景——论证真问题

### 背景分析8个维度

| 维度 | 检查问题 |
|:---|:---|
| 用户/客户需求 | 谁需要？需求多强？ |
| 业务目标对齐 | 跟公司今年目标什么关系？ |
| 竞品/市场对标 | 竞品怎么做？我们差异化在哪？ |
| 现状落差 | 现在和理想的差距？用数据说 |
| 紧迫性 | 为什么现在做？不做会怎样？ |
| 可行性 | 我们有什么资源？缺什么？ |
| 风险预判 | 最可能失败的原因？ |
| 历史经验 | 以前做过类似项目吗？结果？ |

### 虚需求→数据论证（定方案口述稿 L604-L642）

Truman演示了三个假问题案例：

| 原始说法 | 问题 | 改造 |
|:---|:---|:---|
| "用户想落地" | 太模糊 | 至少一千个团队有共同学习需求 [确认] |
| "学习效率低" | 没对比 | 上传速度从2分半→最快10秒，差20多倍 [确认] |
| "缺少营销工具" | 没数据 | >50%城市发起人提过物料需求 [确认]，转化率提升50%-2-3倍 [确认] |

---

## 三、Step 2：目标——SMART+评估三角

### 目标三要素
1. **一句话目标**：项目做完，"成功"是什么？
2. **可衡量指标**：用什么数字判断？
3. **签字画押**：谁确认这个目标？

### 方案评估三角形

| 维度 | 关键问题 |
|:---|:---|
| ROI | 投入多少？产出多少？多久回本？ |
| 机会成本/窗口期 | 不做做别的会不会更好？现在是最佳时机吗？ |
| 资源/风险 | 人够不够？钱够不够？最大坑在哪？ |

### ROI快速判断演示（L840-L866）

| 场景 | 投入 | 产出 | 判断 |
|:---|:---|:---|:---|
| 教研换外包 | 40人日 [假设] | 释放教研时间 | 值得 |
| 5小时换好评 | 5小时 [假设] | 口碑 | 值得 |
| 四周换500万 | 4周 | 500万现金流 | 值得 |

> 原则："够评估就好"——不需要精算，能判断做不做就行。

---

## 四、Step 3：关键路径

1. **里程碑**：从终点倒推，找到必经之路。不是"要做的事情列表"，而是"如果这个节点没达成，项目就失败了"的关键检查点。判断标准：①必经之路 ②有可检查的交付物 ③时间可估算 ④前后有依赖关系
2. **资源匹配**：谁来做？人的时间够不够？需要什么外部支持？RASCI（R负责人/A批准/S支持/C咨询/I知情）明确到人
3. **风险预判**：最可能出问题的3个地方是什么？每个风险配一个Plan B。不是"可能会延期"这种废话——要具体到"如果设计师第三周还没交初稿，备选方案是找外包XX，成本增加Y"
4. **签字画押**：方案写完必须有人签字确认——不是走过场，是"我确认这个目标、这个路径，出了问题我负责"

---

## 五、失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 跳过背景 | 方案漂亮但不解决真问题 | 强制先写背景分析8维度 |
| 目标太虚 | "提升品牌形象"——没法衡量 | SMART化：X指标从A到B |
| 无评估三角 | 做着做着发现ROI负数 | 方案评审强制过三角 |
| 虚需求 | "效率低"——没数字没对比 | 每条主张配数字+来源 |
| 签字缺失 | 做完老板说不知道 | 启动前书面确认 |

## 六、Action Triggers

| 触发 | 动作 | 指标 |
|:---|:---|:---|
| 启动B级以上项目 | 用三段论写方案 | 三段论写满一页 |
| 方案评审被问"为什么做" | 回退到背景分析 | 8维度填满5+ |
| 发现ROI可能为负 | 重算评估三角 | 判断：继续/降级/取消 |
