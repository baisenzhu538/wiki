# 鑫港湾医药零售商业模式计算框架与业务公式

> **用途**：为「小程序医药商城 + 实体药店 + 智慧药柜 + 互联网医院/HIS + 诊所场地合作」模式提供一套可复用的商业计算框架与业务公式。
>
> **使用方式**：
> 1. 用本文档理解模型结构、公式定义和变量含义。
> 2. 用配套 CSV/Excel 模板填入实际数据，自动计算关键指标。
> 3. 调研后由用户修正假设数据，迭代模型。
>
> **数据来源**：基于知识库中药柜政策、互联网医院调研、O2O 成本结构，以及外部公开信息（医药零售上市公司财报、行业报告、智慧药房设备商资料）。

---

## 用一句话讲清楚
这是一套从“单柜单元经济 → 单店综合模型 → 区域复制 → 平台/B 端生态”四层递进的财务测算与业务公式框架，用于判断鑫港湾医药零售模式在不同规模下的盈利性、回本周期与规模化可行性。

## 核心要点
1. **四层架构**：L1 单柜经济、L2 单店+药柜+小程序、L3 区域复制、L4 平台/B 端生态。
2. **关键公式**：收入、毛利、盈亏平衡、回本周期、LTV/CAC、现金流、库存周转。
3. **核心假设**：客单价 100-300 元、综合毛利率 20%-40%、日均订单 1-10 单、目标回本 18 个月。
4. **健康基准**：单柜日均 ≥2 单、月净利润 ≥833 元、LTV/CAC ≥3、单柜回本 ≤18 个月。
5. **医保影响**：门诊统筹报销显著降低患者自付，需根据机构类别起付线与报销比例调整转化模型。

## 失败模式

| 失败模式 | 触发条件 | 后果 | 预防/对冲 |
|:---|:---|:---|:---|
| 单柜订单不足 | 日均订单 < 盈亏平衡日订单（约 1.5-2 单） | 无法覆盖固定成本，回本周期拉长或亏损 | 提升诊所转化率、增加高毛利 SKU、优化摆放位置 |
| 毛利率塌陷 | 处方药占比过高或价格战导致综合毛利率 < 20% | 毛利额不足以覆盖变动+固定成本 | 调整品类结构，增加 OTC/保健品/器械占比 |
| 合规/审方成本失控 | 远程审方费、平台费上涨或政策收紧 | 变动成本率上升，净利润下降 | 与多家审方平台议价、预留合规成本缓冲 |
| 医保支付接入失败 | 无法接入门诊统筹或医保报销比例低 | 患者自付高，转化率与复购率下降 | 提前对接医保局与 HIS/互联网医院系统 |
| 区域复制边际成本未递减 | 学习曲线系数低、总部成本摊销不足 | 规模化后仍亏损 | 标准化 SOP、集中采购、区域共享仓储 |
| 小程序私域运营失效 | 会员活跃度低、ARPU 下降 | 高毛利渠道贡献不足 | 建立慢病管理会员体系、定期随访与用药提醒 |

## 二、通用财务公式

### 2.1 收入类公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **销售收入** | $S = Q \times P$ | Q = 销售数量/订单量；P = 客单价 |
| **综合销售收入** | $S_{total} = \sum_{i}(Q_i \times P_i)$ | 按品类 i 汇总 |
| **月销售收入** | $S_m = D \times 30 \times \bar{P}$ | D = 日均订单；$\bar{P}$ = 平均客单价 |
| **GMV** | $GMV = \sum_{订单}(商品金额 + 服务费 - 退款)$ | 平台总交易额 |
| **净销售额** | $S_{net} = GMV \times (1 - 退货率)$ | 扣除退货 |

### 2.2 成本与毛利公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **单品毛利** | $G = P - C$ | C = 单品采购成本 |
| **品类毛利率** | $g_i = \frac{P_i - C_i}{P_i} \times 100\%$ | 按品类计算 |
| **综合毛利率** | $\bar{g} = \frac{\sum_i (S_i \times g_i)}{S_{total}} \times 100\%$ | 销售额加权平均 |
| **毛利额** | $G_{total} = S_{total} \times \bar{g}$ | |
| **变动成本率** | $v = \frac{变动成本}{销售收入} \times 100\%$ | 含平台抽成、配送费、支付手续费、审方费等 |
| **边际贡献** | $MC = S - 变动成本$ | 用于覆盖固定成本 |

### 2.3 盈利与回本公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **月净利润** | $\pi_m = G_{total} - FC_m - VC_m$ | FC = 月固定成本；VC = 月变动成本 |
| **盈亏平衡销售额** | $S_{BE} = \frac{FC_m}{\bar{g} - v}$ | 月固定成本 / (毛利率 - 变动成本率) |
| **盈亏平衡订单量** | $Q_{BE} = \frac{S_{BE}}{\bar{P}}$ | |
| **回本周期（月）** | $PB_m = \frac{I}{\pi_m}$ | I = 初始投资；$\pi_m$ = 月净利润 |
| **年化投资回报率** | $ROI = \frac{\pi_m \times 12}{I} \times 100\%$ | |
| **坪效** | $E_s = \frac{S_m}{A}$ | A = 经营面积（㎡） |
| **人效** | $E_h = \frac{S_m}{N}$ | N = 员工数 |

### 2.4 现金流公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **月经营现金流** | $CF_m = \pi_m + D_m - \Delta W$ | $D_m$ = 折旧摊销；$\Delta W$ = 营运资金变动 |
| **现金回本周期** | $PB_{cf} = \frac{I}{CF_m}$ | 考虑非现金支出后的回本速度 |
| **库存周转天数** | $DIO = \frac{平均库存}{月销售成本} \times 30$ | |
| **应付账款周转天数** | $DPO = \frac{平均应付账款}{月采购成本} \times 30$ | |
| **现金循环周期** | $CCC = DIO + DSO - DPO$ | DSO = 应收账款周转天数 |

## 三、L1：单柜单元经济模型

### 3.1 变量定义

| 变量 | 符号 | 单位 | 参考范围 | 说明 |
|:---|:---:|:---:|:---|:---|
| 硬件投资 | $I_c$ | 元 | 10,000-25,000 | 智慧药柜设备、安装、调试 |
| 设计回本周期 | $T_c$ | 月 | 12-24 | 用户目标：18 个月 |
| 月硬件摊销 | $D_c$ | 元/月 | $I_c / T_c$ | |
| 月场地租金 | $R_c$ | 元/月 | 300-1,500 | 诊所场地费 |
| 月平台费 | $F_p$ | 元/月 | 100-500 | 互联网医院/审方平台年费摊销 |
| 单张审方费 | $f_r$ | 元/张 | 1-5 | 远程执业药师审方 |
| 月电费网费 | $F_u$ | 元/月 | 100-300 | |
| 月维护人工 | $F_m$ | 元/月 | 300-1,000 | 补货、巡检、清洁 |
| 损耗率 | $l$ | % | 1%-3% | 过期、破损、盗损 |
| 支付手续费率 | $f_p$ | % | 0.6%-1.0% | 微信支付/支付宝/医保支付 |
| 平均客单价 | $\bar{P}_c$ | 元 | 100-300 | 慢病月度用药 |
| 日均订单 | $D_c$ | 单/天 | 1-10 | |
| 综合毛利率 | $\bar{g}_c$ | % | 20%-40% | 处方药低，OTC/保健品高 |
| 复购周期 | $T_r$ | 天 | 25-35 | 慢性病患者购药间隔 |
| 活跃客户数 | $N_a$ | 人 | 30-100 | 月内至少购买 1 次 |

### 3.2 核心公式

**月固定成本**：
$$FC_c = D_c + R_c + F_p + F_u + F_m$$

**月变动成本**：
$$VC_c = S_c \times (l + f_p) + Q_c \times f_r$$
其中 $S_c$ = 月销售收入，$Q_c$ = 月订单量。

**月销售收入**：
$$S_c = D_c \times 30 \times \bar{P}_c = N_a \times \bar{P}_c$$
（假设活跃客户每月购买 1 次）

**月毛利额**：
$$G_c = S_c \times \bar{g}_c$$

**月净利润**：
$$\pi_c = G_c - FC_c - VC_c$$

**回本周期**：
$$PB_c = \frac{I_c}{\pi_c}$$

**盈亏平衡日订单**：
$$D_{BE} = \frac{FC_c}{30 \times (\bar{P}_c \times \bar{g}_c - \bar{P}_c \times (l + f_p) - f_r)}$$

### 3.3 单柜业务公式

**活跃客户数与日新增客户**：
$$N_a = D_c \times 30$$
$$\Delta N_{daily} = \frac{N_a}{转化率 \times 30}$$
（若从诊所客流转化，需知道日均到店患者数和转化率）

**复购驱动的客户终身价值（药柜场景）**：
$$LTV_c = \bar{P}_c \times \bar{g}_c \times \frac{生命周期月数}{复购周期月数}$$
例如：客单价 180，毛利率 28%，生命周期 24 个月，复购周期 1 个月：
$$LTV_c = 180 \times 0.28 \times 24 = 1,209.6 \text{ 元}$$

**获客成本上限**：
$$CAC_{max} = LTV_c \times \frac{1}{LTV/CAC\text{ 目标比}}$$
通常 LTV/CAC ≥ 3，故 $CAC_{max} = LTV_c / 3$

### 3.4 单柜敏感性矩阵

| 综合毛利率 | 客单价 150 元 | 客单价 200 元 | 客单价 250 元 |
|:---:|---:|---:|---:|
| **20%** | 日订单 3.59 | 日订单 2.69 | 日订单 2.16 |
| **25%** | 日订单 2.87 | 日订单 2.16 | 日订单 1.72 |
| **30%** | 日订单 2.40 | 日订单 1.80 | 日订单 1.44 |
| **35%** | 日订单 2.05 | 日订单 1.54 | 日订单 1.23 |
| **40%** | 日订单 1.80 | 日订单 1.35 | 日订单 1.08 |

> 以上基于：硬件 1.5 万、18 个月回本、月运营成本 2,400 元。

## 四、L2：单店 + 药柜 + 小程序模型

### 4.1 收入结构

| 渠道 | 收入占比参考 | 毛利率参考 | 说明 |
|:---|---:|---:|:---|
| 门店自然客流 | 30%-50% | 25%-35% | 传统药店业务 |
| 诊所导流药柜 | 20%-40% | 20%-30% | 慢病处方药为主 |
| 小程序私域 | 15%-30% | 35%-50% | 会员复购、高毛利品类 |
| O2O 平台 | 10%-25% | 15%-25% | 美团/饿了么/京东秒送 |
| 企业/B 端订单 | 5%-15% | 30%-50% | 公共卫生项目、企业健康 |

**单店月销售收入**：
$$S_s = S_{store} + S_{cabinet} + S_{miniapp} + S_{o2o} + S_{b2b}$$

**单店综合毛利率**：
$$\bar{g}_s = \frac{S_{store}g_{store} + S_{cabinet}g_{cabinet} + S_{miniapp}g_{miniapp} + S_{o2o}g_{o2o} + S_{b2b}g_{b2b}}{S_s}$$

### 4.2 成本结构

**固定成本**：
$$FC_s = R_{store} + S_{staff} + D_{assets} + F_{system} + F_{license}$$

| 项目 | 参考金额/占比 | 说明 |
|:---|:---|:---|
| 门店租金 $R_{store}$ | 5,000-20,000 元/月 | 视城市/地段 |
| 人员工资 $S_{staff}$ | 8,000-25,000 元/月 | 店长、药师、店员 |
| 资产折旧 $D_{assets}$ | 1,000-3,000 元/月 | 药柜、装修、设备 |
| 系统费用 $F_{system}$ | 500-2,000 元/月 | ERP、小程序、审方平台 |
| 合规/证照 $F_{license}$ | 摊销后 500-1,500 元/月 | 医保、GSP、追溯码等 |

**变动成本**：
$$VC_s = S_s \times v_s$$

| 项目 | 参考费率 | 说明 |
|:---|---:|:---|
| 药品采购成本 | 65%-85% | 已计入毛利公式 |
| O2O 平台抽成 | 5%-10% | 美团/饿了么佣金 |
| 配送费 | 3-6 元/单 | 或按 GMV 2%-4% |
| 支付手续费 | 0.6%-1.0% | |
| 营销/优惠券 | 2%-5% | 私域拉新、复购激励 |
| 损耗 | 1%-3% | |

### 4.3 单店盈利公式

**月毛利额**：
$$G_s = S_s \times \bar{g}_s$$

**月净利润**：
$$\pi_s = G_s - FC_s - VC_s$$

**单店回本周期**：
$$PB_s = \frac{I_{store}}{\pi_s}$$
其中 $I_{store}$ = 单店初始投资（装修 + 首批货 + 药柜 + 系统 + 押金）。

### 4.4 关键业务公式

**小程序私域贡献**：
$$S_{miniapp} = N_{members} \times ARPU_m$$
其中 $N_{members}$ = 活跃会员数，$ARPU_m$ = 会员月均消费。

**O2O 渠道贡献**：
$$S_{o2o} = D_{o2o} \times 30 \times \bar{P}_{o2o}$$
其中 $D_{o2o}$ = O2O 日均订单，$\bar{P}_{o2o}$ = O2O 客单价（通常 40-80 元）。

**药柜对门店的引流效率**：
$$\eta = \frac{S_{cabinet}}{S_{store} + S_{cabinet}} \times 100\%$$

**人效**：
$$E_h = \frac{S_s}{N_{staff}}$$

**坪效**：
$$E_s = \frac{S_s}{A_{store}}$$

## 五、L3：区域复制模型

### 5.1 变量定义

| 变量 | 符号 | 说明 |
|:---|:---:|:---|
| 城市数量 | $N_{city}$ | |
| 每城药店数 | $N_{store/city}$ | |
| 每店药柜数 | $N_{cabinet/store}$ | |
| 单柜月净利润 | $\pi_c$ | |
| 单店月净利润 | $\pi_s$ | |
| 区域总部月成本 | $FC_{region}$ | 区域运营、BD、培训、仓储 |
| 总部月成本 | $FC_{hq}$ | 产品研发、品牌、管理 |

### 5.2 核心公式

**区域总药柜数**：
$$N_c = N_{city} \times N_{store/city} \times N_{cabinet/store}$$

**区域总门店数**：
$$N_s = N_{city} \times N_{store/city}$$

**区域月净利润**：
$$\pi_{region} = N_c \times \pi_c + N_s \times (\pi_s - N_{cabinet/store} \times \pi_c) - FC_{region}$$
（避免重复计算药柜利润）

**公司整体月净利润**：
$$\pi_{total} = \sum_{region} \pi_{region} - FC_{hq}$$

### 5.3 规模化经济公式

**边际成本递减**：
$$MC_n = MC_1 \times n^{-\alpha}$$
其中 $\alpha$ = 学习曲线系数（通常 0.05-0.15），n = 累计铺设数量。

**总部成本分摊**：
$$FC_{hq/unit} = \frac{FC_{hq}}{N_c + N_s}$$

**区域盈亏平衡柜数**：
$$N_{BE} = \frac{FC_{region}}{\pi_c \times N_{cabinet/store} + (\pi_s - \pi_c \times N_{cabinet/store})}$$

## 六、L4：平台/B 端商业模式

### 6.1 B 端收入类型

| 类型 | 收入公式 | 说明 |
|:---|:---|:---|
| **政府公共卫生项目** | $S_{gov} = N_{patients} \times F_{service}$ | $F_{service}$ = 人均慢病管理服务年费 |
| **企业健康管理** | $S_{corp} = N_{employees} \times F_{plan}$ | $F_{plan}$ = 人均年度健康计划费 |
| **商保/惠民保** | $S_{ins} = N_{claims} \times \bar{V}_{claim}$ | 按理赔单数或药品金额分成 |
| **数据服务/RWE** | $S_{data} = N_{projects} \times F_{project}$ | 真实世界研究数据服务 |
| **平台技术服务费** | $S_{tech} = N_{pharmacies} \times F_{saas}$ | 向加盟药店收取 SaaS 年费 |

### 6.2 平台经济公式

**总 GMV**：
$$GMV_{total} = \sum_{all}(S_{c2c} + S_{b2b} + S_{b2c})$$

**平台收入**：
$$S_{platform} = GMV_{total} \times t + S_{subscription} + S_{service}$$
其中 t = 平台佣金率。

**平台毛利率**：
$$g_{platform} = \frac{S_{platform} - C_{platform}}{S_{platform}}$$
平台成本主要是技术、运营、客服，毛利率通常 60%-80%。

## 七、客户与经济公式

### 7.1 客户漏斗公式

| 阶段 | 公式 |
|:---|:---|
| 曝光量 | $E$ |
| 到店/访问 | $V = E \times CTR$ |
| 注册/建档 | $R = V \times CVR_{reg}$ |
| 首单转化 | $F = R \times CVR_{first}$ |
| 复购活跃 | $A = F \times Retention$ |
| 月活客户 | $MAU = A \times 购买频次$ |

### 7.2 客户终身价值（LTV）

**基础 LTV 公式**：
$$LTV = \bar{P} \times \bar{g} \times \frac{1}{1 - r} - CAC$$
其中 $r$ = 月留存率，$\frac{1}{1-r}$ = 客户生命周期月数。

**更精确的 LTV**：
$$LTV = \sum_{t=1}^{T} \frac{\bar{P} \times \bar{g} \times r^{t-1}}{(1 + d)^t} - CAC$$
其中 $d$ = 月折现率，$T$ = 最大生命周期。

### 7.3 获客成本（CAC）

**CAC 公式**：
$$CAC = \frac{总营销获客投入}{新增首单客户数}$$

**按渠道拆分**：
$$CAC_{channel} = \frac{ChannelSpend_i}{NewCustomers_i}$$

**CAC 回收周期**：
$$PB_{CAC} = \frac{CAC}{\bar{P} \times \bar{g}}$$

## 九、库存与供应链公式

### 9.1 库存周转

**库存周转率**：
$$ITR = \frac{月销售成本}{平均库存}$$

**库存周转天数**：
$$DIO = \frac{30}{ITR}$$

**安全库存**：
$$SS = Z \times \sigma_d \times \sqrt{LT}$$
其中 $Z$ = 服务水平系数，$\sigma_d$ = 日需求标准差，$LT$ = 补货提前期。

### 9.2 采购与应付

**采购成本**：
$$C_p = S \times (1 - \bar{g})$$

**应付账款周转天数**：
$$DPO = \frac{平均应付账款}{月采购成本} \times 30$$

**现金循环周期**：
$$CCC = DIO + DSO - DPO$$

## 十一、使用示例：单柜 18 个月回本测算

### 输入假设

| 变量 | 值 |
|:---|---:|
| 硬件投资 $I_c$ | 15,000 元 |
| 目标回本周期 $T_c$ | 18 月 |
| 月场地租金 $R_c$ | 800 元 |
| 月平台费 $F_p$ | 200 元 |
| 月电费网费 $F_u$ | 150 元 |
| 月维护人工 $F_m$ | 600 元 |
| 单张审方费 $f_r$ | 3 元 |
| 损耗率 $l$ | 2% |
| 支付手续费率 $f_p$ | 0.6% |
| 平均客单价 $\bar{P}_c$ | 180 元 |
| 综合毛利率 $\bar{g}_c$ | 28% |

### 计算过程

**月固定成本**：
$$FC_c = 833 + 800 + 200 + 150 + 600 = 2,583 \text{ 元}$$

**月变动成本率**：
$$v = 2\% + 0.6\% = 2.6\%$$

**盈亏平衡月销售额**：
$$S_{BE} = \frac{2,583}{28\% - 2.6\%} = 10,169 \text{ 元}$$

**盈亏平衡月订单**：
$$Q_{BE} = \frac{10,169}{180} = 56.5 \text{ 单}$$

**盈亏平衡日订单**：
$$D_{BE} = \frac{56.5}{30} = 1.88 \text{ 单/天}$$

**盈亏平衡活跃客户数**（按复购周期 30 天）：
$$N_{BE} = 56.5 \approx 57 \text{ 人}$$

**结论**：要实现 18 个月回本，单柜需日均约 1.9 单、月约 57 位活跃慢病客户。
