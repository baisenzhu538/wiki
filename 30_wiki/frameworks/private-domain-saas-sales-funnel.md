# 私域 SaaS 销售四步法

> 从七件事集团招商录音中提取的标准销售流程，可复用于分析同类私域/SaaS 公司的销售漏斗设计：先顶层设计，再模式设计，然后系统搭建，最后招商落地。

## 四步流程

```
顶层设计（股权架构 + 风险隔离 + 税务合规）
        ↓
模式设计（分销层级 + 佣金比例 + 裂变机制）
        ↓
系统搭建（定制 / SaaS / 源码交付）
        ↓
招商落地（会务邀约 → 现场成交 → 5% 佣金）
```

## 各阶段要点

### Step 1：顶层设计

- 股权架构设计
- 风险隔离安排
- 税务合规方案

**目的**：在签约前把客户的顶层结构与合规框架梳理清楚，为后续模式设计奠定制度基础。

### Step 2：模式设计

- 分销层级设定
- 佣金比例与结算规则
- 裂变机制与奖励设计

**目的**：把客户的商业意图转化为可执行的分销规则，是 SaaS 系统需求的主要来源。

### Step 3：系统搭建

- 定制开发
- SaaS 标准化交付
- 源码交付

**目的**：根据客户预算、控制欲与定制深度，选择合适的技术交付形态。

### Step 4：招商落地

- 会务邀约
- 现场成交
- 按成交额 5% 抽成

**目的**：帮助有资源但缺招商能力的客户完成首批渠道或终端拓展，实现从"系统"到"业务结果"的闭环。

## 使用场景

| 场景 | 用法 |
|:---|:---|
| 分析 SaaS 公司销售链路 | 用四步法拆解其售前、售中、售后环节 |
| 设计私域电商销售流程 | 以四步法为骨架，填充自身产品与行业内容 |
| 评估供应商交付完整性 | 检查供应商是否在每个阶段都有可验证的交付物 |

## Constraints & Boundaries

| 边界 | 适用 | 不适用 |
|---|---|---|
| 业务类型 | 私域电商/SaaS 销售流程设计 | 标准化消费品零售 |
| 客户阶段 | 有产品/服务需构建销售漏斗 | 产品尚未验证 PMF |
| 销售模式 | 高客单价、需会议成交的 B2B/B2B2C | 纯自助线上转化 |
| 合规环境 | 中国大陆分销合规框架 | 海外多级分销/传销合法地区 |

### Common Failure Modes

1. **顶层设计流于形式** → 症状：股权/税务方案与销售话术脱节；原因：未结合客户真实业务结构；修复：要求出具经客户确认的顶层结构文档
2. **模式设计超出合规边界** → 症状：分销层级与佣金结构触碰法律红线；原因：为成单过度承诺；修复：引入法务/合规审查节点
3. **系统交付与模式不匹配** → 症状：系统无法支撑承诺的分销规则；原因：售前与技术团队未对齐；修复：模式设计阶段技术负责人必须参与
4. **招商落地效果不可追责** → 症状：会务成交后无持续运营；原因：招商服务按成交额抽成但无后续指标；修复：约定招商后的 30/60/90 天转化率对赌
