# 降龙十八掌：18张调研策略卡全景图

> **一句话**：降龙十八掌不是18个独立招式，而是18个策略节点，覆盖从假设验证到深度归因的完整调研链条。每一掌都有明确的触发条件、执行标准和验收标准。

---

## 核心框架：18掌分布图

```
第一层：假设与验证（3掌）
   1. 调研先行验证假设
   2. 最佳实践
   3. 竞对跟踪

第二层：扫描与拆解（3掌）
   4. 行业扫描
   5. 公司拆解
   6. 单元模型

第三层：定位与追踪（4掌）
   7. 单点狙击
   8. 竞争象限
   9. 二维定位
   10. 按图索骥

第四层：情报与手段（2掌）
   11. 地图在手
   12. 穷尽手段

第五层：归因与验证（4掌）
   13. 事实优先
   14. 定量建模
   15. 交叉验证
   16. 深度归因

第六层：总结与输出（2掌）
   17. 归一总结
   18. 持续跟踪
```

## Constraints & Boundaries

### 适用边界

1. **商业调研**：市场、竞品、用户、行业等
2. **投资决策**：尽职调查、标的分析
3. **产品决策**：定位、功能、体验
4. **战略规划**：市场进入、并购、转型
5. **定期复盘**：每季度审视调研能力

### 不适用场景

1. **学术研究**：需要严格方法论
2. **纯执行型任务**：不需要调研
3. **紧急响应**：几小时内决策
4. **高度主观判断**：如审美、品牌调性

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 掌法单一 | 只用1-2掌 | 根据重要性选择掌数 | 所有调研用同一方法 |
| 掌法僵化 | 按顺序用，不调整 | 根据场景灵活组合 | 所有项目用同一顺序 |
| 验证不足 | 用1掌就下结论 | 强制交叉验证 | 单一来源结论 |
| 归因不深 | 找到表面原因就停 | 强制5Why | "因为A所以B" |
| 跟踪缺失 | 调研后不再更新 | 建立跟踪机制 | 调研后不再关注 |
| 手段穷尽不足 | 只用公开信息 | 强制穷尽手段清单 | "看了几篇报告" |
| 定量不足 | 只有定性分析 | 强制定量建模 | "感觉不错" |
| 总结不清 | 调研后无明确结论 | 强制归一总结 | 调研后不知道结论 |

---

## 行动触发器

1. **新项目启动**：选择对应掌法组合
2. **调研计划审查**：检查掌法是否完整
3. **信息质量不足**：回到武器库，选择更深入的手段
4. **团队培训**：用18掌培训团队调研能力
5. **定期复盘**：每季度检查18掌使用情况
