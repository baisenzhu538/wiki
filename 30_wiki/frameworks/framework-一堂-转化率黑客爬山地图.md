# 一堂转化率黑客爬山地图：六段 L1-L6 与三次跨越

> **一句话**：D 域自带段位体系——爬山地图把转化率能力切成 L1-L6 六段（图原字为权威，口述未口播逐段名称），口述主讲**三次跨越**（混乱→稳定→专业→迁移），两者是同一座山的两种坐标：六段回答「你在哪」，三次跨越回答「下一步往哪走」。

---

## 一、六段 L1-L6（图《转化率黑客的爬山地图》原字）

| 段位 | 能力定位 | 常见问题（图原字） |
|---|---|---|
| **L1 不想提升** | 陷入低水平重复 | 缺少欲望 / 与我无关 / 低效重复 / 浅尝辄止 |
| **L2 有追求** | 持续追求更好 | 缺三段论 / 只盯结果 / 碎片随机 / 缺少体系 |
| **L3 全局分析** | 稳定使用三段论 | 缺专业分析 / 缺少动力构建 / 缺少阻力消除 / 缺少场景挖掘 |
| **L4 手段专业** | 善于提升动力阻力触点 | 缺快速迭代 / 假设太少 / 速度太慢 / 迭代不够 |
| **L5 迭代领先** | 能持续迭代到领先 | 缺大量迁移 / 练习数量少 / 不能跨领域 / 认知难迁移 |
| **L6 广泛迁移** | 善于迁移 + 第一次就专业 | ——（终极目标：**转化率黑客**） |

**阶段分类**（图原字）：入门 = L1-L3；进阶 = L4；高阶 = L5-L6。

**课程学习路径三阶段**（图原字）：①认识到「动力阻力触点」并刻意分析 → ②持续追求「最佳转化率」实操 → ③大量跨领域练习。

> 段位自评用法：对照「常见问题」列逐格打钩——哪一格的四个问题你全中，你就在那一段。常见问题列本身就是该段的修炼清单。

---

## 二、三次跨越：混乱 → 稳定 → 专业 → 迁移（口述主讲框架）

「大家先不要迷路，一共有三次大的跨越」（`入门篇-口述:2774`）：

1. **第一次跨越：混乱 → 稳定**（`入门篇-口述:2776`）——「从这种碎片化的、混合混乱的、不稳定的状态，变成动力阻力触点」。即 L1→L3：认识三段论并稳定使用。
2. **第二次跨越：稳定 → 专业**（`入门篇-口述:2782-2786`）——「从一种相对只会动不动就动力阻力触点的、很业余的，练到很专业。你手里掌握了一套非常专业的、长期可以修炼的动力阻力触点工具集」。即 L3→L4：手段专业化。
3. **第三次跨越：专业 → 迁移**（`入门篇-口述:2788-2800`）——「你已经相对专业了。但是你能快速迭代吗？你能驱动业务向前不断迭代，甚至形成行业的最佳实践吗？甚至形成最佳实践之后，你的能力还能迁移吗？」即 L4→L6：「从少量的、缓慢的状态，过渡到大量的、广泛的迁移」（`入门篇-口述:4782-4784`）。

课后总结的同框架复述（`入门篇-口述:4752-4756`）：「第一阶段，从混乱到习惯用动力阻力触点；第二阶段，从习惯使用到能够稳定使用，基本上就到专业了；第三个问题是你有了工具够专业，但是你能提出大量的关键假设，能够快速地去验证和推进，拿到业务结果。」

> 「一堂的同学绝大部分人是卡在第一关」（`入门篇-口述:2804`）——六段图与三次跨越的对应：第一关≈L1→L3，第二关≈L3→L4，第三关≈L4→L6。

## 三、第一关的三种典型卡死状态（L2840-2862）

| 状态 | 原话 | 病根 |
|---|---|---|
| 闷头干 | 「闷头执行，习惯了做事不喜欢往上想，没有太多追求，一直在一个水平线上长期执行」（`入门篇-口述:2842`）——且随时间、换人「持续还得往下滑」 | L1：缺少欲望 |
| 心气高但缺能力 | 「心气很高，想提升，但是缺少能力，就一直盯着结果……到处都想框架，非常碎片」（`入门篇-口述:2848-2852`） | L2：缺三段论 |
| 没有稳定框架 | 「虽然负责某一个最佳转化率，但没有稳定的框架。今天老板说 123，明天说 456……没有稳定的思考结构，前后左右乱成一团」（`入门篇-口述:2854-2862`） | L2-L3：缺体系 |

反面教材的量化对照（`入门篇-口述:2812`）：到场率从 40% 提升到 70%——有框架的人做的是这种量级的事。

**第三关前的三个问题**（`入门篇-口述:4772-4778`）：①推动力不够，一号位不能驱动提出大量假设；②高质量假设太少，灵感不够；③认知迁移很少——「做了 A 做了 B 做了 C 反正都是独立的，很难持续性提升核心能力」。

---

## 四、与 C 域段位同构互训

D 域爬山地图与 C 域业务公式的段位体系同构：都是「认识框架 → 稳定使用 → 专业工具集 → 快速迭代 → 广泛迁移」的同一条修炼路径，只是一个管宏观效率（找战场）、一个管微观效率（打节点）。两域段位对照与互训见 [[framework-一堂-业务公式拆解-总纲]] 第五节（C 域爬山地图/段位自评）。

**修炼入口**：第一次跨越靠 [[framework-一堂-转化基本功七个自我修养]] 的修养 ①②（固定拿结果、固定拆同行）；第二次跨越靠修养 ③④⑤（提动力、降阻力、珍惜触点）+ 五篇专业课的工具集；第三次跨越靠修养 ⑥⑦（驱动迭代到最佳、大量的迁移）+ [[framework-一堂-转化率提升六步法]] 的全流程实操。
