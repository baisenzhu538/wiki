# 一堂·机会预判：CEO 的预判操作系统（总框架）

> **一句话**：预判是每个 CEO/业务负责人**最重要的工作之一**——从第一天到最后一天都要持续做。本卡把"预判段位差 → 15字诀 → 终局光谱七段 → 保A争B → 加法/减法 → 五步法预判"串成一条项链，并声明：**机会预判是五步法（[[framework-一堂五步法]]）的前置滤镜 / 第 0 步**——它回答"这件事值不值得做、最多做多大"，然后才进入需求分析。
>
> 来源主线：口述 L38-L66（预判篇第一节、CEO 工作、三失败、段位差、本轮 Truman 牵头）；预热题 L68-L90（西安咖啡馆，周末两天做可行性分析）。

## 一、元命题：为什么预判是"完全不一样的操作系统"

| 命题 | 依据 | 推论 |
|:---|:---|:---|
| 预判是 CEO 最重要的工作之一 | 口述 L44-L46：从第一天到最后一天都要持续预判 | 不是立项前做一次，而是贯穿全程 |
| 不预判有三种典型失败 | 口述 L50-L56：跟风 Copy / 不看同行就开干 / 八字硬压资源 | 三种失败都源于"预判能力弱、花时间少、不成体系" |
| 人和人之间有**预判段位差** | 口述 L58-L66：银行近 1000 个项目，有人一眼看硬伤，有人硬烧钱 | 段位差可训练——本课就是练这套段位 |
| 本轮目标 | 口述 L62-L66：时隔三年重启教研，Truman 牵头做一套机会预判必修课 | 本卡是这套必修课的承重层 |

> 关键口径：本课 = "预判篇第一节"，定位在**五步法之前**。它不止给框架，更给"用更高视角重新审视五步法"的操作系统（口述 L38-L42）。

## 二、预判段位阶梯（L1-L6）

> 来源：图03 + business-spectrum 已萃取的 L1-L6 爬山段位。每一段能排除一类硬伤，并配一种练法。

| 段位 | 能识别/排除的硬伤 | 练法（一句话） | 越级风险 |
|:---:|:---|:---|:---|
| L1 热情段 | "我喜不喜欢" | 区分热情与需求 | 用热情硬扛商业硬伤 |
| L2 概率段 | "这件事成不成得了" | 算基础成功率 | 把低概率当高概率 |
| L3 商业段 | "单元模型是否成立" | 算 LTV/CAC、毛利 | 能赚钱但天花板低 |
| L4 团队段 | "团队配不配做这件事" | 能力-机会匹配 | 小团队扛大体系 |
| L5 行业段 | "行业稳态/变化/天花板" | 行业分析六要素 | 不会行业预判=重大硬伤 |
| L6 超越段 | "超越头部的新格局" | A→B 稳态切换预判 | 错判动荡期窗口 |

> 详见 [[yt-foresight-business-spectrum]]（段位与练法）；行业段需接 [[yt-foresight-ab-steady-state]]（A→B 稳态模型）。

## 三、15 字诀（核心操作）

> 来源：笔记 L21-L23。完整表述见 [[yt-foresight-15-char-mantra]]。

- **主动定中局**：先明确目标区间（在终局光谱上选保A争B），再谈路径。
- **充分做加法**：把一个 idea 拆成 ≥10-100 个选项（三轴：横拆行业 / 纵拆产业链 / 按要素拆商业模式），见 [[yt-foresight-addition-subtraction]]。
- **专业做减法**：用三类硬伤（商业 / 团队 / 行业）逐层排除，"知道死在哪，就永远不去那个地方"（笔记 L35-L37）。

> 成功率口径（**课程经验值**，未经外部验证）：笔记 L21-L23 记"把 1% 提升到 30%，再多轮试错拉到 80%"；笔记速览另记"10%→30%"。两口径并存，正文统一标"课程经验值"。

## 四、终局光谱：七段 + 质变点 + 保A争B

> 来源：图01（七段框架）+ 解读02 L1-L5（五条读法）+ 示例01 L1-L14（风险/收益量化）。

机会预判的终局光谱把机会分成 7 段：**副业 → 个体 → 单体 → 小规模 → 体系增长 → 细分头部 → 做大上市**，相邻段之间有 6 个质变点（全职 / 招人 / 复制 / 持续增长标准化 / 融资 / 上市）。

- **框架数据**（七段营收数、质变点、6 项预判工作）→ 见 [[yt-foresight-business-spectrum]]。
- **读法**（五条解读 + 七段风险/收益量化表）→ 见 [[concept-一堂-终局光谱图解读]]。
- **核心动作**：不是选一个点，而是选一个**区间"保A争B"**（解读02 L3）。例：陪诊保2争4、咖啡保3争5、AI 时间保4争6（案例预判01/02/03）。

> **显式区分（防重复造卡）**：机会预判域有两张光谱卡——`yt-foresight-business-spectrum`（框架+数据）与 `concept-一堂-终局光谱图解读`（读法）；需求域另有一张更早的光谱 [[framework-demand-opportunity-spectrum]]（reviewed，配评估三角形"值不值得做"+光谱"做多大"，来源五步法之需求分析）。三者各管一段：本卡（机会预判总框架）只管"预判篇"视角；需求域光谱用于五步法 Step 2 之后的天花板判断。

## 五、必要预判工作流（图02）

> 来源：图02（诊断盘点链条）。这是"预判到底要做哪几件事"的最小闭环。

```
学习对标 → 对标同行主流模式 → 预判（段位/区间）
        → 商业模式（单元模型）→ 长期经营（增长/壁垒）
        → 概率高低 → 短期利润 / 长期规模 → 预判行业（A→B）
```

实操落点：每个环节都对应一张卡——对标（加法三轴）/ 区间（终局光谱）/ 商业模式（五步法 Step 4）/ 长期经营（五步法 Step 5）/ 概率（[[yt-foresight-probability-engineering]]）/ 行业（[[yt-foresight-ab-steady-state]]）。

## 六、五步法预判结构（出口到 #141）

> 来源：咖啡店五步法预判（快/好/办公店 × 五步）。预判不是终点，是五步法的输入。

预判阶段产出三件事，交给五步法：
1. **目标区间**：保A争B（来自终局光谱）。
2. **候选 Plan A/B/C**：加法发散 + 减法收敛后的 1 个 Plan A + 2 个 Plan B（[[yt-foresight-addition-subtraction]] 菱形钻石）。
3. **Top 硬伤清单**：被排除选项的"死因"（[[yt-foresight-ten-fatal-flaws]]）。

→ 详见 [[tool-一堂-机会预判-五步法预判]]；出口接 [[framework-一堂五步法]] Step 1（机会预判）。

## 七、机会预判 = 五步法的前置滤镜（第 0 步）

| 关系 | 说明 |
|:---|:---|
| 顺序 | 先预判（值不值得做、做多大），再进五步法 Step 2 需求分析 |
| 分工 | 预判回答"做不做/做多大"；五步法回答"怎么做、怎么验证、怎么放大" |
| 互链 | 五步法 Step 1 标"机会预判"，回本卡；本卡出口接五步法 Step 2 |

> 旁证：[[concept-一堂-business-prediction]]（15字诀+光谱+P/L型+保A争B）= 商业预判概念详解；本卡 = 把该概念嵌入五步法之前的承重项链；两者互补不重复。

## 八、When NOT to Use（不要用）

- **把预判当验证**：预判只输出"值得调研"，不输出"值得投入"。验证须接五步法（#141）/ 关键假设（#140）/ 实测。
- **用光谱评价现在**：光谱是"预判 5-10 年终局"，不是给当前状态打分（解读02 L5）。
- **保1争7 幻觉**：副业资源却锚定上市目标——区间错配，绝大多数案例不会保1争7（案例预判02/03）。
- **越级烧钱**：L1-L2 段位硬扛 L5-L6 才该识别的行业/团队硬伤。
- **替代商业/投资决策**：本卡是滤镜与导航，最终 Go/No-Go 必须创始人自己做。

## 九、Failure Modes（失败模式）

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 跟风 Copy | 看别人赚钱眼红，没看过同行就开干 | 先列≥5个同行主流模式再谈差异 |
| 单点下注 | 八字硬把全部资源压一个选项 | 强制加法≥10选项 + 减法三层 |
| 评价现在而非预判终局 | 用光谱给当前打分 | 改问"5-10年这件事最多做到哪一段" |
| 区间错配 | 保1争7 / 好高骛远 / 过于短视 | 用保A争B选区间，落到资源匹配的段 |
| 把信号当结论 | AI趋势12/三维交叉≥2信号就立项 | 信号是必要条件非充分，必须过五步法 |
| 跳过滤镜直接做产品 | 没预判就进需求/内核 | 先回本卡做区间+硬伤，再进五步法 |
