# IBM BLM 业务领导力模型 + 华为五看三定

> IBM BLM（Business Leadership Model）是连接战略制定与执行的系统框架。华为在此基础上演化为“五看三定”。

---

## 一、IBM BLM 全景图

```
                    领导力
                      ↓
    ┌─────────────────────────────────┐
    │           战  略                 │
    │  市场洞察 → 战略意图             │
    │      ↓         ↓                │
    │   业务设计 ← 创新焦点           │
    ├─────────────────────────────────┤
    │           执  行                 │
    │  关键任务 → 正式组织             │
    │      ↓         ↓                │
    │   人才 ← 氛围与文化             │
    └─────────────────────────────────┘
                      ↓
                  市场结果
              （业绩差距 + 机会差距）
                      ↑
                    价值观
```

### 1.1 战略侧四要素

| 要素 | 核心问题 | 关键工具 |
|--|--|--|
| **市场洞察** | 外部机会和挑战是什么？ | PEST、五力、价值链、SWOT |
| **战略意图** | 我们要去哪里？ | 愿景、使命、目标 |
| **业务设计** | 我们如何赢？ | 六要素×三步骤 |
| **创新焦点** | 在哪里创新？ | 产品/服务/商业模式创新 |

### 1.2 执行侧四要素

| 要素 | 核心问题 | 关键任务 |
|--|--|--|
| **关键任务** | 必须完成哪些关键事项？ | 年度/季度关键举措 |
| **正式组织** | 组织结构和流程如何支撑？ | 架构、权责、绩效 |
| **人才** | 需要什么样的人才？ | 选育用留 |
| **氛围与文化** | 需要什么样的文化？ | 沟通模式、价值观行为化 |

## 二、BLM 成功六要素

1. **领导人的责任**：业务领导负责和引领战略制定与执行。
2. **聚焦差距**：聚焦差距和关键问题，注重结果。
3. **从外望内看**：洞察市场机会与挑战，了解客户和竞争对手。
4. **战略与执行的协同**：贯穿战略→策略→举措的逻辑思考。
5. **关键任务共识与协同推进**：相关部门充分研讨、协同、共识和承诺。
6. **组织能力和资源保障**：确保组织能力、支撑体系和资源匹配关键任务。

## 三、华为五看三定

华为将 BLM 的战略洞察和战略制定部分演化为“五看三定”。

### 3.1 五看（战略洞察）

| 五看 | 关注焦点 | 典型工具 |
|--|--|--|
| **看行业** | 行业趋势、政策、技术变革 | PEST、产业生命周期 |
| **看市场** | 市场规模、增速、细分需求 | 市场细分、客户细分 |
| **看竞争** | 竞争对手战略、能力、动向 | 五力分析、竞争对标 |
| **看自己** | 自身能力、差距、优势 | SWOT、价值链、核心能力 |
| **看机会** | 可抓住的市场机会 | SPAN 矩阵、机会评估 |

### 3.2 三定（战略制定）

| 三定 | 核心动作 |
|--|--|
| **定控制点** | 确定战略控制点和护城河 |
| **定目标** | 明确战略目标（财务/市场/能力） |
| **定策略** | 制定业务策略和关键举措 |

## 四、Agent 执行指令

```python
def blm_workshop(company_context: str):
    """运行 IBM BLM 战略工作坊"""
    prompts = {
        "差距分析": f"基于「{company_context}」，识别业绩差距和机会差距。",
        "五看洞察": "从行业、市场、竞争、自己、机会五个维度输出洞察。",
        "三定": "确定控制点、目标、策略。",
        "业务设计": "用六要素×三步骤设计业务设计。",
        "执行设计": "设计关键任务、正式组织、人才、文化氛围。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 重战略轻执行 | 有很好的业务设计但落不了地 | 同步设计执行四要素，缺一不可 |
| 从内部出发 | 只看自己有什么，不看市场要什么 | 强制做“五看”后再进入三定 |
| 战略被授权 | 高层不参与，交给战略部 | 明确业务领导是战略第一责任人 |
| 差距不清 | 目标模糊，不知道从哪改 | 先量化业绩差距和机会差距 |
