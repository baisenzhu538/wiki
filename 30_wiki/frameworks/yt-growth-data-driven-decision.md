# 数据驱动增长决策

> 一堂五步法：数据不是答案，而是假设的验证工具。数据驱动 = 假设 → 实验 → 数据 → 决策。

## 核心框架

数据驱动决策的4步循环：

```
提出问题 → 形成假设 → 设计实验 → 分析数据 → 做出决策 → 迭代
```

| 步骤 | 关键 | 错误 |
|:---|:---|:---|
| **提出问题** | 问题具体、可衡量 | 问题模糊 |
| **形成假设** | 假设可验证、可证伪 | 假设不可验证 |
| **设计实验** | 控制变量、对照组 | 变量不控制 |
| **分析数据** | 统计显著、因果推断 | 相关当因果 |
| **做出决策** | 数据+业务判断 | 唯数据论 |
| **迭代** | 持续优化 | 一次决策 |

## 关键洞察

### 1. 增长指标体系

| 层级 | 指标 | 说明 |
|:---|:---|:---|
| **北极星指标** | 核心目标 | 长期价值 |
| **一级指标** | 增长飞轮 | AARRR |
| **二级指标** | 驱动因素 | 转化率、留存率 |
| **三级指标** | 操作指标 | 页面停留、点击 |

### 2. 数据分析的4种类型

| 类型 | 说明 | 方法 | 示例 |
|:---|:---|:---|:---|
| **描述性** | 发生了什么 | 报表、仪表盘 | 留存率报表 |
| **诊断性** | 为什么发生 | 漏斗、路径分析 | 流失原因分析 |
| **预测性** | 将会发生什么 | 模型、趋势 | 流失预测 |
| **处方性** | 应该怎么做 | 实验、优化 | A/B测试 |

### 3. 实验设计原则

| 原则 | 说明 | 注意 |
|:---|:---|:---|
| **随机分组** | 实验组和对照组随机 | 避免偏差 |
| **样本量** | 样本量足够大 | 统计显著 |
| **单一变量** | 只改变一个变量 | 避免混淆 |
| **持续时间** | 实验持续足够长 | 避免短期波动 |
| **提前定义** | 提前定义指标和成功标准 | 避免事后解释 |

### 4. 数据陷阱

| 陷阱 | 说明 | 避免 |
|:---|:---|:---|
| **幸存者偏差** | 只看成功用户 | 看全部用户 |
| **相关≠因果** | 相关关系不等于因果 | 实验验证 |
| **平均数陷阱** | 平均数掩盖分布 | 看分布 |
| **确认偏误** | 只看支持自己的数据 | 主动找反面 |
| **数据滞后** | 数据反映过去，不是未来 | 结合判断 |

### 5. 数据驱动文化

| 要素 | 说明 | 建设 |
|:---|:---|:---|
| **数据素养** | 全员理解数据 | 培训 |
| **数据工具** | 易用的数据工具 | 投资 |
| **数据透明** | 数据公开共享 | 文化 |
| **数据决策** | 用数据说话 | 机制 |
| **数据迭代** | 持续实验优化 | 流程 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **数据孤岛** | 数据分散，不打通 | 数据整合 |
| **唯数据论** | 只看数据，忽视业务判断 | 数据+判断 |
| **数据滞后** | 决策时数据已过时 | 实时数据 |
| **指标过多** | 指标太多，不知关注哪个 | 聚焦北极星 |
| **实验不严谨** | 实验设计不科学 | 严格设计 |
| **分析不行动** | 分析很多，不行动 | 分析→决策→行动 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 增长优化 | 创意判断 |
| 产品决策 | 战略方向 |
| 运营优化 | 人文关怀 |
| 规模化决策 | 一次性决策 |

## 行动触发器

- 当做决策时 → 先问数据支撑
- 当数据矛盾时 → 深入分析原因
- 当实验失败时 → 分析学习
- 当数据滞后时 → 结合判断
