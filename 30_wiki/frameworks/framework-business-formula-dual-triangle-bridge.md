# 业务公式×双三角桥接：C域在六顶点中的定位与映射

> **一句话**：业务公式（C域）是双三角六顶点中**"场景"和"数据"两个AI侧顶点的核心燃料源**，同时也是**"体系"顶点的量化骨架**——参数挖掘提供场景颗粒度，逻辑关系建模提供数据结构，十大范式提供可复用的场景模板。不接C域，AI三角的"场景"和"数据"两个顶点就是空转。

---

## 一、C域在双三角六顶点中的定位

```
人类三角                     AI三角
┌──────────┐              ┌──────────┐
│ 审美      │              │ 场景      │ ← 十大范式 = 场景模板库
│          │              │          │   参数冰山 = 场景颗粒度
│   🔗─────┼──────────────┼──🔗      │
│          │              │          │
│ 体系      │              │ 数据      │ ← 逻辑关系六层 = 数据结构
│          │              │          │   参数挖掘武器库 = 数据采集菜单
│   🔗─────┼──────────────┼──🔗      │
│          │              │          │
│ 创造力    │              │ 基本功    │ ← 假设驱动18招 = AI-基本功训练项
└──────────┘              └──────────┘
     ↑                        ↑
     │    业务公式 C域         │
     └────────🗲──────────────┘
           (宏观效率)
```

| 双三角顶点 | C域贡献 | 具体输入 | 缺失C域时的症状 |
|:-----------|:--------|:---------|:---------------|
| **场景**（AI侧） | 十大范式 = 场景拆解母版 | 任一业务能落回至少1个范式 | AI只能做通用建议，无法做业务级诊断 |
| **数据**（AI侧） | 参数冰山L1-L6 + 逻辑关系六层 | 参数清单 + 因果关系网 | 有数据但不知道哪个数据重要（缺参数优先级） |
| **体系**（人侧） | 业务公式=体系化的业务认知骨架 | 目标×参数×逻辑关系的螺旋模型 | 体系停在抽象层，无法落到具体指标 |
| **审美**（人侧） | 魔法参数(L6)=商业判断的量化载体 | 拐点指标判断力（哪个参数是杠杆点） | 审美是玄学，无法被检验和传递 |
| **基本功**（AI侧） | 假设驱动18招=AI可练的业务诊断动作 | 参数挖掘/逻辑验证/假设筛选 → AI基本功训练项 | AI没有"业务拆解"的训练路径 |
| **创造力**（人侧） | 创新参数(L5)=创造力的结构化出口 | 自定义参数/新组合/新动作定义 | 创造力无结构化载体，等于没有 |

## 二、关键映射：C域四层 → 双三角三回路

### 2.1 参数挖掘 → 场景+数据回路

参数冰山（L1→L6）本质上是一条**场景感知深度**的刻度尺：

| 参数层级 | 场景颗粒度 | 数据需求 | AI可替代程度 |
|:---------|:-----------|:---------|:-----------|
| L1 基础参数 | 粗粒度（"流量不够"） | 宏观数字 | 低——人定方向 |
| L2 财务参数 | 商业模式级（"单元模型不健康"） | 财务数据 | 中——AI可算但需人定假设 |
| L3 分层参数 | 切片级（"女性25-35岁转化率低"） | 分层切片数据 | 高——AI擅长切片分析 |
| L4 转化参数 | 动作级（"试衣率从30%→50%"） | 漏斗节点数据 | 高——AI可逐节点监测 |
| L5 创新参数 | 自定义级（"投屏连接率"） | 自定义埋点 | 低——需要人的业务洞察 |
| L6 魔法参数 | 本质级（"30天3单=留存拐点"） | 拐点检测 | 中——AI可辅助发现，人做判断 |

### 2.2 逻辑关系 → 体系回路

逻辑关系六层（L1→L6）是人侧"体系"顶点的量化表达：

| 逻辑层级 | 体系成熟度 | 对应双三角飞轮状态 |
|:---------|:-----------|:------------------|
| L1 模糊 | 无体系 | 飞轮未启动 |
| L2 相关 | 有监控无抓手 | 飞轮能感知但无法做功 |
| L3 因果 | 有方向 | 飞轮单回路运转 |
| L4 公式完备 | 有结构 | 飞轮双回路联动 |
| L5 定量 | 有精度 | 飞轮三回路精确调控 |
| L6 动态 | 自我进化 | 飞轮自动调参 |

### 2.3 十大范式 → 场景模板库

十个范式是六顶点中"场景"顶点的**预置模板库**，可以直接对接 `[[tool-yihang-dual-triangle-canvas]]` 的画布：

- **收入提升4范式** → 场景拆解的标准入口
- **竞争提升2范式** → 壁垒构建的场景锚点
- **运营提升4范式** → 精细化运营的场景坐标

## 三、飞轮对接：参数变化率 = 飞轮转速的量化代理

双三角飞轮三回路（`[[method-dual-triangle-flywheel-engine]]`）最缺的是一个**可量化的转速指标**。C域提供了天然候选：

> **核心对接公式**：飞轮转速 ≈ 关键参数的假设验证速度（假设/月）× 验证成功率

- **回路一（人-AI协作回路）**：人提假设 → AI辅助参数挖掘 → 人做减法评估 → 飞轮转一圈
- **回路二（能力积累回路）**：每个验证过的假设沉淀为参数认知 → 参数冰山往下挖一层 → 飞轮加速
- **回路三（场景拓展回路）**：一个业务的参数模型迁移到新业务 → 十大范式复用 → 飞轮复制

## 四、补缺：C域进入后双三角的升级点

| C域能力 | 双三角当前缺口 | 升级后 |
|:---------|:--------------|:-------|
| 参数挖掘武器库 | "场景"顶点有定义无工具 | 六层参数 = 场景感知的工具链 |
| 逻辑关系六层 | "数据"顶点有数据无结构 | 因果→定量→动态 = 数据结构化路径 |
| 假设管理五大策略 | "基本功"顶点缺AI-基本功训练项 | 18招 = AI业务诊断的标准训练动作 |
| 魔法参数(L6) | "审美"顶点难量化 | 拐点指标 = 商业审美的可检验表达 |
