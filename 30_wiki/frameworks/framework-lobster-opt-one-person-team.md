# OPT One Person Team——一人 AI 团队的五角色最小决策系统

> **定位声明**：本卡是 strategy/ai-collaboration 域框架卡，萃取自一堂 OPT 产品设想稿（设想性质，非已上线产品）。与 [[concept-agent-university]]（Agent 大学设想）同批同源，均为"AI 时代组织形态"设想线素材。KDO 视角的对标分析是本卡增量。

## 一句话定义

OPT（One Person Team）是对 OPC（One Person Company）的升维：一个人的背后不是一个工具，是一个分工有序的 AI 团队——**"未来的标准配置不是一个人+工具，而是一个人+一个 AI 团队"**。

## 核心论点链

1. **CEO 孤独论**（问题起点）：高质量决策只能一个人孤独完成——外人信息不够、内部段位不够、合伙人利益交织不客观、顾问不能 24 小时在线。关键错误的学费巨大：选错赛道损失 2 年、招错核心高管损失 100 万、错误定价损失市场窗口（设想稿表述，量级待独立核实）
2. **AI 改变可能性**：可训练的 AI 团队=24h 在线+无利益冲突+信息能力+持续进化+成本低于一个初级员工月薪
3. **OPC→OPT 升维**：OPC 是创业概念，OPT 是每个人的决策加速器——创业者/老板/职场人/实习生都可以有 OPT
4. **金句**："不是一个人战斗，是一个人+一个团队"

## 硅基组织行为学：反对"通用虾"

设想稿最有分析价值的部分——为什么"一个全能 Agent"是错误路线：

| 通用虾的问题 | 机理 |
|:--|:--|
| 上下文爆炸 | 一个 Agent 覆盖所有场景→对话历史膨胀→关键信息淹没 |
| 角色混淆 | 一会儿调研、一会儿决策、一会儿诊断——思维模式互相干扰 |
| 工作思维混乱 | 不同工作需要完全不同的认知框架，"一个大脑装不下" |

**核心策略——最小工作循环**：一类长期稳定的工作目标=一个最小工作循环；每个 Agent 只负责一类核心工作，拥有稳定目标+独立认知框架+专属知识体系。多个专业 Agent 分工协作，覆盖完整决策链路。

> 这不是"5 个通用虾"，而是一个真正的团队——每个成员有自己的专业领域、思维方式、配合关系。

## 五角色架构（上下左右中）

| 方位 | 角色 | 一句话定位 | 核心技能示例 |
|:--|:--|:--|:--|
| 上 | 情报调研 | 看宏观、看趋势、看格局 | 深度调研/趋势洞察/竞品雷达 |
| 下 | 核心决策 | 微观数据驱动的理性决策伙伴 | RICE 评估/风险诊断/方案对比 |
| 左 | 商业洞察 | 理解用户、洞察需求、抓产品 | JTBD 分析/产品内核定义/价值链拆解 |
| 右 | 团队诊断 | 评估 AI 团队自身配置与健康（CHO 角色） | 配置评估/技能盘点/组织健康度 |
| 中 | 学习助理 | 记录、整理、规划、提醒 | 知识采集/想法结构化/智能提醒 |

选位逻辑：这五个是 CEO 的**高频通用需求**=最小决策系统；股权、融资、战略分析等低频需求后置扩展。"右·团队诊断"是架构里最独特的一格——**让 AI 团队自带组织 Mirror**，评估"你的 AI 团队够不够强"。

## 六大训练信息源（Agent 团队的"养成配方"）

灵魂赋能流程（批量灌文档建角色认知）/高阶技能封装/已有龙虾精华/知识库注入（方法论 Datapack）/美好作品想象（描述岗位"最好的样子"反向定义能力）/角色人格设计（职业定位+性格色彩+配合关系）。

**分析注**：第 5 条"美好作品想象"与第 6 条"人格设计"是超出工程常规的两条——用理想状态反向定义能力上限、用人格制造团队化学反应，这是教育者做 Agent 的签名式思路（与 [[concept-agent-university]] 的"身份/价值观优先"同源）。

## 与 KDO 五绝架构的对标（本卡分析增量）

| 维度 | OPT 设想 | KDO 五绝（实际运行） | 互证 |
|:--|:--|:--|:--|
| 分工哲学 | 反通用虾：一类目标=一个循环 | 老顽童/欧阳锋/王语嫣/黄药师/洪七公/段王爷——角色+固定路径+禁越界 | 一致：专业分工优于全能 |
| 团队自诊断 | 右·团队诊断 Agent | 欧阳锋审查+王语嫣看板维护+风清扬观察 | 一致：需要独立的组织 Mirror |
| 知识注入 | 知识库注入+Datapack | 30_wiki+source_refs 溯源 | 一致：Agent 质量上限=知识底座质量 |
| 训练机制 | 灵魂赋能+技能封装 | spec 卡+行为牌组+skill 体系 | 一致 |
| 人格设计 | 性格色彩+化学反应 | 角色人格（金庸人物）即人格化设计 | **五绝先行验证了 OPT 的假设** |

**关键互证**：KDO 五绝就是 OPT 假设的一个已运行样本——"专业分工的 Agent 团队优于单全能 Agent"在 KDO 有实证（写审分离、角色路径、禁越界均源于血泪教训）。OPT 设想的增量在"最小决策系统"的**角色选型方法论**（高频通用需求优先）与 C 端产品化路径。

## 失败模式

| 失败 | 症状 | 修复 |
|:--|:--|:--|
| 五角色全上 | 初期建 5 个 Agent，每个都半成品，维护不动 | 从最高频的一个角色起步（多为"下·核心决策"或"中·学习助理"），跑通再加 |
| 分工形同虚设 | 名义五角色，实际每个都被问所有问题 | 每角色写 spec+路径约束（KDO 经验：不设边界必越界） |
| 通用虾回潮 | 为省事把知识库全量共享给所有 Agent | 专属知识体系+上下文隔离，接受"建多个"的成本 |
| 团队无 Mirror | 只建业务角色，没有诊断角色 | "右"角色或人工 review 例会不可省——团队会静默腐化 |

## Critique

### 攻击者 1：产品经济学（成本结构质疑）

**立场**："成本不到一个初级员工月薪"隐藏了真实 TCO。
**攻击论点**：五角色团队的隐性成本被系统性低估——高质量知识库的建设与维护（最大头，恰是 KDO 实证里最贵的部分）、每个角色的调训时间、跨 Agent 上下文同步的摩擦、以及"AI 团队产出仍需人审"的审读成本。对小微企业，5 个半成品 Agent 的组合体验可能不如 1 个打磨好的通用助手；设想稿把"分工"的组织学收益直接平移到个人场景，忽略了个人的管理带宽远小于公司。
**回应**：有效——失败模式表"五角色全上"即此攻击的落地；正确的用法是把五角色当**扩展路线图**而非初始配置，且接受 KDO 实证：知识库质量是整个框架的前提投资，没有 Datapack 的 OPT 只是五个空壳。

### 攻击者 2：人机交互（信任与责任链）

**立场**："AI 团队无利益冲突、绝对客观"是危险的拟人化承诺。
**攻击论点**：AI 没有利益冲突≠没有系统性偏向——训练语料的偏向、对用户已有观点的迎合（sycophancy）是 Agent 的实证问题，设想稿把"客观"当默认属性是过度承诺。更尖锐的：关键决策的责任链无法外包给"绝对客观"的团队——CEO 用 OPT 决策出错时，"AI 建议过"既不能免责也不能追责，责任真空比利益冲突更危险。
**回应**：成立——本卡定位为"决策加速器"而非"决策替代"，AI 团队的产出应作为**假设与证据的供给**（见 [[method-key-assumption-abcd]] 的验证流），最终判断与责任留在人；"绝对客观"表述在引用时应替换为"无内部利益冲突，但存在语料与迎合偏向"。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|:--|:--|:--|
| 无知识库底座的冷启动 | 五角色的输入是 Datapack，没有知识注入=空壳团队 | 先建知识底座（KDO 先例：先有 30_wiki 后有五绝） |
| 高合规决策（法律/医疗/财务签字） | 责任链不能外包，AI 团队只能做前置情报 | AI 情报+专业人士签字的双层结构 |

## Constraints & Boundaries

- 适用：个人/小微决策系统的角色规划、Agent 团队产品设想评审、AI 组织形态研究
- 不适用：作为已验证产品引用（设想稿性质）；无知识库底座的直接套用；高合规决策的责任转移
- 溯源纪律：本卡内容为产品设想稿萃取，全部能力描述为设计意图，**未经产品实测验证**（"成本不到初级员工月薪"等为设想表述）；KDO 对标节为本卡分析增量

**跨域观察**：OPT 的"最小工作循环"与 KDO 的"一次只领一件"是同一条纪律的两个人机版本——认知框架不可复用是跨物种约束（人对多任务、AI 对多角色同样成立）。框架卡最有传播力的判断是**反直觉的"反通用虾"**：在所有人堆"全能助手"的赛道里，"分工的团队"是差异化叙事，且有 KDO 实证背书。

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|:--|:--|:--|
| 想搭自己的 AI 团队 | 先答"最高频的决策需求是哪个" | 第一个角色 2 周内日活，再谈第二个 |
| Agent 越用越乱 | 检查是否通用虾化（一 Agent 多角色） | 每个 Agent 有 spec、路径、专属知识库三件套 |
