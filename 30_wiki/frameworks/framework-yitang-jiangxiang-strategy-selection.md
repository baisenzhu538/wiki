# 讲香策略选择框架：两规律+三对组合+决策树

## 两个底层规律（暗知识A，口述L796-862）

李頔总结了讲香的两条底层规律：

**规律一：具象=回到已发生事实，抽象=调用主动创造**
- 向下具象（场景化/口语化/数字化/故事化/素材化）都是回到"已经发生或可以被感知的事实"——发生的事情、可见的画面、可验证的数字
- 向上拉价值（比喻化/情绪化/金句话/冲突化/升华化）都是调用"你需要主动创造的表达"——创造连接、制造张力、赋予意义

**规律二：策略之间不是平行的——有自然组合**
- 基础组合（场景化+比喻化）：解决"听懂"问题——任何讲香都可以先从这对开始
- 进阶组合（口语化+情绪化）：解决"相关"问题——用户听完觉得"跟我有关系"
- 高阶组合（数字化+金句话）：解决"信任"问题——用户听完觉得"这个人靠谱"
- 四策略扩展（故事化/素材化/冲突化/升华化）：当基础三组合不够时调用

## 三对组合+高阶四策略完整表（含莫非云盘+D案例）

| 组合层级 | 解决什么 | 十指配对 | 核心机制 | 典型案例 |
|:--|:--|:--|:--|:--|
| **基础** | 听懂 | 场景化+比喻化 | 场景建立相关性 → 比喻快速理解 | CLI第三版：场景"每次复制粘贴上下文"→ 比喻"万能插座" |
| **进阶** | 相关 | 口语化+情绪化 | 口语化降低距离 → 情绪化建立共鸣 | 天幕B版：对话式语气 + "你花了钱买风景不该隔着一层失真玻璃" |
| **高阶** | 信任 | 数字化+金句话 | 数字建立客观感 → 金句压缩记忆点 | 莫非云盘：恐惧+数字组合——"丢一个文档2000万没了"vs"每年每人几十块" |
| **扩展1** | 生动 | 故事化 | 起承转合让人沉浸 | 复盘营200期：第1期→第196期演进的叙事线 |
| **扩展2** | 说服 | 素材化 | 实物/视频/实验让人无可辩驳 | 天幕B版：红土实验+沙袋撞击+跳绳+引体向上全套 |
| **扩展3** | 震撼 | 冲突化 | 反差制造记忆烙印 | 王毅43秒：20万年薪vs500万年薪销售副总监开会对比→几万转发 |
| **扩展4** | 深远 | 升华化 | 小事情连接大意义 | 楚曼招人：卖洗发水→改变世界（个人→事业→社会三级跳） |

## 策略选择决策树

```
你要讲什么？
│
├── 内容偏抽象（概念/技术/方法论）
│   → 优先向下具象：基础组合（场景化+比喻化）
│   → 如果用户听完觉得"跟我无关"：加进阶组合（口语化+情绪化）
│   → 如果用户听完不信任：加高阶组合（数字化+金句话）
│   → 如果还不够：故事化（让概念有叙事）/素材化（让概念可见）
│
├── 内容偏平淡（产品功能/配置/参数）
│   → 优先向上拉价值：进阶组合（口语化+情绪化）
│   → 如果需要"不得不信"：素材化（实验/对比/现场演示）
│   → 如果需要记忆点：高阶组合（数字化+金句话）+冲突化（反差）
│   → 如果需要深远共鸣：升华化（小功能→大意义）
│
└── 内容有争议/需要说服
    → 优先证据层：高阶组合（数字化+金句话）+素材化（实验/数据）
    → 冲突化建立对立→情绪化建立共鸣
    → 升华化收尾——把争议拉到更高层面
```

## 操作示例

**莫非云盘（恐惧+数字组合，暗知识D）**：建筑设计院被客户砍价时——"丢一个文档2000万没了"（恐惧情绪）+ "每年每人几十块"（数字化对比）。这个组合的力量在于：恐惧让用户感到"严重后果"，数字让恐惧变得具体可量化。

**王毅43秒冲突化视频**：20万年薪vs500万年薪的销售副总监开会对比——这不是两个数字的对比，是两个世界的人的做事方式的对比。竞争反差做到极致就是传播力。

## 失败模式

| # | 失败模式 | 早期信号 | 修复动作 |
|:--|:--|:--|:--|
| **FM1** | 所有内容都用同一对组合 | 每个产品都用场景化+比喻化——千篇一律 | 先用决策树判断内容偏向再选组合 |
| **FM2** | 跳过基础直接上高阶 | 还没让用户听懂就开始升华——"我听不懂他在说什么但好像很厉害" | 基础组合（听懂）没做到位之前不要升级 |
