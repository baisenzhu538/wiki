# 留存指标：从流失到忠诚

> 一堂五步法：留存是增长的基础。获客不留存，是漏斗漏水。留存率每提升5%，利润提升25-95%。

## 核心框架

留存的核心指标：

| 指标 | 说明 | 计算 |
|:---|:---|:---|
| **次日留存** | 注册后第2天回来 | D2留存用户数/D0注册用户数 |
| **7日留存** | 注册后第7天回来 | D7留存用户数/D0注册用户数 |
| **30日留存** | 注册后第30天回来 | D30留存用户数/D0注册用户数 |
| **月留存** | 本月活跃/上月活跃 | MAU/上月MAU |
| **年留存** | 本年活跃/上年活跃 | 年活跃用户/上年活跃用户 |

## 关键洞察

### 1. 留存曲线的解读

| 曲线形状 | 说明 | 行动 |
|:---|:---|:---|
| **快速下降后平稳** | 产品有价值，但初期体验不好 | 优化 onboarding |
| **持续下降** | 产品没有形成习惯 | 设计习惯形成机制 |
| **先降后升** | 产品有长期价值，但短期不明显 | 加速价值感知 |
| **平稳高留存** | 产品形成强习惯 | 保持，探索增长 |

### 2. 留存的3个层次

| 层次 | 说明 | 指标 | 提升方法 |
|:---|:---|:---|:---|
| **新用户留存** | 注册后短期留存 | 次日、7日留存 | 优化 onboarding |
| **活跃用户留存** | 持续活跃用户留存 | 月留存 | 产品价值强化 |
| **忠诚用户留存** | 核心用户留存 | 年留存、NPS | 社区、会员体系 |

### 3. 流失预警模型

| 信号 | 说明 | 干预 |
|:---|:---|:---|
| **使用频率下降** | 从每天到每周 | 推送提醒、优惠活动 |
| **功能使用减少** | 从多用少 | 功能推荐、使用引导 |
| **反馈减少** | 从积极到沉默 | 主动触达、调研 |
| **竞品使用** | 同时使用竞品 | 差异化价值强化 |
| **付费停止** | 从付费到免费 | 挽留优惠、价值沟通 |

### 4. 留存与产品价值

| 留存类型 | 驱动因素 | 可持续性 |
|:---|:---|:---:|
| **价值留存** | 产品本身有价值 | 高 |
| **习惯留存** | 用户形成习惯 | 高 |
| **数据留存** | 用户数据在平台 | 高 |
| **社交留存** | 社交关系在平台 | 高 |
| **补贴留存** | 补贴激励 | 低 |
| **锁定留存** | 用户被锁定 | 中 |

### 5. 留存优化策略

| 策略 | 说明 | 适用场景 |
|:---|:---|:---|
| **onboarding优化** | 让用户快速体验到价值 | 新用户留存低 |
| **习惯形成** | 设计用户习惯 | 活跃用户留存低 |
| **价值强化** | 持续提供价值 | 忠诚用户留存低 |
| **社区建设** | 建立用户社区 | 社交产品 |
| **会员体系** | 设计会员权益 | 高价值用户 |
| **流失挽回** | 主动挽回流失用户 | 流失率高 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **忽视留存** | 只关注获客 | 留存优先 |
| **留存数据造假** | 把沉默用户算留存 | 区分活跃留存和沉默留存 |
| **补贴依赖** | 停止补贴就流失 | 产品价值留存 |
| **忽视流失预警** | 用户流失后才反应 | 建立流失预警模型 |
| **留存优化不精准** | 对所有用户统一优化 | 分层优化 |
| **忽视长期留存** | 只关注短期留存 | 关注长期留存曲线 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 留存优化 | 技术架构设计 |
| 用户运营 | 品牌传播策略 |
| 产品改进 | 运营活动评估 |
| 增长策略 | 纯公益项目 |
