# 复盘本质与三要素：基于过去真实经验、面向未来的学习

> 一句话：复盘的本质是**从自己做过的事情中学习**——三要素缺一不可：基于过去真实经验 + 面向未来 + 学习手段。缺一个都不是复盘。

---

## 三要素判定法

Truman（L262-328）给出的最简朴素的复盘本质定义：

| 要素 | 是什么 | 不是什么 |
|:---|:---|:---|
| **基于过去真实经验** | 你自己做过的事——开了会、做错了事、做成了事、犯了错误 | 书本、听课、别人讲——那是学习，不是复盘 |
| **面向未来** | 为下一次同样或类似的事做准备——总结认知/模型/教训 | 只反思过去——那是总结会，不是复盘 |
| **学习手段** | 让自己变强——战斗力变强、认知变强 | 甩锅/夸夸/吐槽/应付/团建——那是背锅会/夸夸会 |

> "只要有这三要素，就是复盘，哪怕它长得再不像复盘。反过来说，没这三要素，哪怕再像复盘，它也不是复盘。"（L284-286）

**三要素判定是排他性的**——不是"大概符合就行"，是"缺一个就不是"。这个朴素定义的价值在于：它消除了对"复盘"这个词的迷信——复盘不是某种高级的、需要专门流程的仪式，它是一个朴素的认知动作。

---

## ROI 五规律：什么该复盘？

Truman（L956-982）给出了"什么时候该多花时间复盘"的判断标准：

| 规律 | 为什么 | 什么时候可以少复盘 |
|:---|:---|:---|
| **新事** | 拿不准，容易失败 | 变老事、有稳定方法论后 |
| **新人** | 经常搞错，需要成长 | 经验积累后 |
| **重复的事** | 复盘价值长期可复用，有复利 | 流程已固化无变化 |
| **困难的事** | 容易失败，不复盘怎么提升成功率 | 难度降低后 |
| **核心基本功** | 公司最核心的能力，需要不断修炼 | — |

**反向判断**：如果一件事不新、执行人很熟、只做一次、很简单、非核心——花大量时间复盘的ROI可能为负。复盘深度应该和事情的重要性成正比。

## 三原则：小事及时、大事阶段、事后全面

Truman（L1084-1182）的联想系口诀：

| 原则 | 时机 | 方法 | 例子 |
|:---|:---|:---|:---|
| **小事及时** | 事情发生后尽快（当天/当周） | 快速碰头会/打个电话/抽根烟聊完 | 离职率上升、数据下滑、要不要送客户礼物 |
| **大事阶段** | 项目中设固定复盘节点 | 中场停一下——目标对不对、策略要不要调 | 季度销售战略执行一个月后效果不好 |
| **事后全面** | 项目完整结束后 | 全流程系统性复盘——成败/亮点/教训/资产 | 大型活动/年度项目 |

**小事及时的底层逻辑**：小事太多——不复盘就会累积成系统性问题。且小事往往是重复发生的——"这次复盘了，下次就不用再想了"。

**大事阶段的底层逻辑**：长周期项目不能等结束再复盘——"一旦你过了半年再去复盘整个项目，很多认知已经拿不到了"（L1150-1152）。

## 五类复盘产出（金矿五类）

项目管理视角的复盘价值递增链（L994-1016）：

```
成败共识 → 项目亮点 → 问题教训 → 过程资产 → 执行计划
（初级）                                              （高级）
```

| 产出层级 | 内容 | 价值 |
|:---|:---|:---|
| 成败共识 | 这次到底成了还是败了？团队对齐 | 复杂协作的基础 |
| 项目亮点 | 成功要素是什么？ | 可复制 |
| 问题教训 | 失败在哪？避免再犯 | 止损 |
| 过程资产 | 总结出什么模型/框架？ | 组织能力 |
| 执行计划 | 下一次具体怎么做？To-do直接产出 | 最直接 |

> "真正高质量的复盘，应该直接锁定到下一次怎么做——把下一阶段的计划做出来"（L1016-1018）

## Critique

### 内部局限

- **三要素是必要条件，不是充分条件**——满足三要素只能保证"这是复盘"，不能保证"这是好的复盘"。深度（冰山五层）、姿势（四象限）、质量（九宗罪）是另外的问题
- **"面向未来"的衡量标准模糊**：很多复盘声称"面向未来"但实际产出是一堆无法执行的抽象原则

### 外部攻击者

**攻击者1：AAR原教旨主义者**——「AAR强调'趁记忆新鲜立即复盘'，你的'大事阶段'和'事后全面'违背了及时性。」

**回应**：AAR最初是军队战术复盘，商业项目中很多决策效果需要时间才能显现。三原则是对AAR的场景化扩展而非否定。

**攻击者2：行动派**——「与其花时间复盘，不如多做几件事。」

**回应**：不复盘的代价是"每次都从头做"——同样错误反复犯。"打扫战场"比喻：打完仗不捡武器就冲向下一个山头=浪费。

## When NOT to Use

| 误用 | 后果 | 正确做法 |
|:---|:---|:---|
| 对所有事都深度复盘 | 复盘时间成本超过收益——ROI为负 | 用五规律判断：不新/不重复/不困难/非核心的事，三分钟快速复盘即可 |
| 情绪未平复时强行复盘 | 复盘变成情绪宣泄——不是学习 | 先平复情绪，24小时后再复盘 |
| 只有成功没有失败的事反复复盘 | 自嗨——没有认知增量 | 成功了也要找"还可以更好的地方" |
| 不考虑执行——复盘完就完了 | 有认知无行动——等于没复盘 | 每次复盘最后5分钟必须产出"下一次具体做什么不同" |

## 常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 复盘变成背锅会 | 大家忙着找责任人而非找原因 | 开场声明：今天的目标是找到系统原因，不是找到谁该骂（L518-542） |
| 只有主观感受无事实 | "我觉得这次做挺好的"——没有数据支撑 | 强制：每个观点必须有对应事实证据（L566-616） |
| 归因停留在表面 | "这次失败因为不够努力"→下次"加油" | 追问"为什么"至少3层 |
| 复盘产出的行动计划太模糊 | "下次注意"——无法执行 | 每次复盘至少1个具体行动+负责人+截止日期 |
| 小事拖成大事才复盘 | 离职率已经很高了才开始想原因 | 小事及时复盘——当天/当周解决 |

## Action Triggers

- **听到"太忙了没时间"** → 启动三分钟复盘（`[[framework-一堂-团队复盘四阶段12策略]]`）
- **复盘完不知道深度够不够** → 用冰山五层自检（`[[yt-model-deep-review-iceberg]]`）
- **复盘产出无法执行** → 检查是否缺了"面向未来"——重新聚焦"下一次具体做什么不同"
- **团队不做复盘** → 先检查自己是否做到了"以身作则"（四阶段第一阶段）
