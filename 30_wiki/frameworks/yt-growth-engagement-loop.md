# 参与循环：让用户持续回来

> 一堂五步法：参与循环是留存的核心。用户回来的理由 = 触发 + 行动 + 奖励 + 投入。

## 核心框架

参与循环的4个要素（Hook模型）：

```
触发（Trigger）→ 行动（Action）→ 奖励（Reward）→ 投入（Investment）→ （循环）
```

| 要素 | 说明 | 设计要点 |
|:---|:---|:---|
| **触发** | 什么让用户回来 | 外部触发（推送、邮件）+ 内部触发（习惯、情绪） |
| **行动** | 用户做什么 | 简单、低 friction |
| **奖励** | 用户得到什么 | 可变奖励，惊喜 |
| **投入** | 用户投入什么 | 时间、数据、社交关系 |

## 关键洞察

### 1. 触发的设计

| 触发类型 | 说明 | 示例 | 注意 |
|:---|:---|:---|:---|
| **外部触发** | 产品主动触达 | 推送、邮件 | 有价值，不打扰 |
| **内部触发** | 用户主动回来 | 习惯、情绪 | 形成习惯 |
| **情境触发** | 特定场景触发 | 位置、时间 | 精准 |
| **社交触发** | 社交关系触发 | 好友消息 | 自然 |

### 2. 行动的设计

| 设计原则 | 说明 | 示例 |
|:---|:---|:---|
| **简单** | 行动门槛低 | 一键操作 |
| **快速** | 行动时间短 | 3秒内完成 |
| **明确** | 用户知道做什么 | 清晰按钮 |
| **即时反馈** | 行动后有反馈 | 动画、提示 |

### 3. 奖励的设计

| 奖励类型 | 说明 | 示例 | 效果 |
|:---|:---|:---|:---:|
| **社交奖励** | 来自社交的认可 | 点赞、评论 | 高 |
| **狩猎奖励** | 获取信息/资源 | 新内容、优惠 | 高 |
| **自我奖励** | 自我成就感 | 完成任务、升级 | 中 |
| **可变奖励** | 不确定的奖励 | 抽奖、惊喜 | 极高 |

### 4. 投入的设计

| 投入类型 | 说明 | 示例 | 效果 |
|:---|:---|:---|:---:|
| **时间投入** | 用户花的时间 | 使用时长 | 中 |
| **数据投入** | 用户的数据 | 个人资料、历史 | 高 |
| **社交投入** | 社交关系 | 好友、关注 | 极高 |
| **金钱投入** | 付费 | 会员、购买 | 高 |

### 5. 参与循环的评估

| 指标 | 说明 | 健康标准 |
|:---|:---|:---|
| **DAU/MAU** | 日活/月活 | > 20% |
| **使用频率** | 用户回来频率 | 每周> 3次 |
| **使用时长** | 每次使用时长 | 增长 |
| **功能深度** | 使用功能数量 | 增长 |
| **用户投入** | 用户投入的时间/数据 | 增长 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **触发过度** | 推送太多，用户反感 | 减少触发，提升质量 |
| **行动门槛高** | 用户不愿行动 | 降低 friction |
| **奖励单一** | 用户疲劳 | 可变奖励 |
| **忽视投入** | 用户没有投入感 | 设计投入机制 |
| **循环断裂** | 用户不再回来 | 诊断断裂点 |
| **忽视习惯** | 用户没有形成习惯 | 设计习惯机制 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 留存提升 | 技术架构 |
| 用户参与 | 品牌传播 |
| 习惯形成 | 一次性决策 |
| 产品体验 | 纯工具产品 |
