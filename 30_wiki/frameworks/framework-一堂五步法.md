# 一堂五步法：从机会预判到规模化的五步闭环

> **一句话**：五步法是方法论中枢——不是线性的"做完一步到下一步"，而是两次关键跃迁（价值假设→增长假设→规模化）驱动的迭代闭环。每一步有明确的输出物和换档条件。

---

## 一、五步全景

```
机会预判 → 需求分析 → 产品内核 → 单元模型 → 规模化增长
   │          │          │          │          │
   │   价值假设验证区     │    增长假设验证区    │
   │   (0→1)            │    (1→N)           │
   └────────────────────┴──────────────────────┘
                    两次跃迁
```

| 步 | 名称 | 核心问题 | 输出物 | 子域Agent |
|:---:|:---|:---|:---|:---|
| 1 | 机会预判 | "这件事值不值得做？" | 机会假设+初步天花板 | `#138 产品内核Agent` |
| 2 | 需求分析 | "用户到底要什么？" | L1-L6冰山推演+RAT清单 | `#140 需求冰山教练` |
| 3 | 产品内核 | "最小解决方案是什么？" | 内核画布+九大原则 | `#138 产品内核Agent` |
| 4 | 单元模型 | "能不能赚钱？" | 十大单元模型+斧子/尺子/梯子 | `#141单元模型框架` |
| 5 | 规模化增长 | "怎么放大？" | 增长周期+壁垒判断 | `#141增长/壁垒框架` |

---

## 二、两次跃迁

### 跃迁1：价值假设 → 产品内核（Step 2→3）

**换档条件**（满足≥3条才能换档）：
- [ ] 用户需求已确认（L3核心任务清晰）
- [ ] 需求强度经过评估三角形打分（≥2项高）
- [ ] RAT Top 3已开始验证
- [ ] "用户愿意为这个付钱"有≥1个证据

### 跃迁2：产品内核 → 规模化（Step 3→5）

**换档条件**：
- [ ] 产品内核经过九大原则验证（≥6条满足）
- [ ] 单元模型成立（LTV > 3×CAC [确认]或[假设]）
- [ ] 已有≥10个付费用户 [确认]
- [ ] 增长路径清晰（获客驱动/系统驱动/对抗驱动 三选一）

## 三、两种形态

| 维度 | 商业分析版 | 泛产品设计版 |
|:---|:---|:---|
| 适用场景 | 创业/投资决策 | 产品/功能设计 |
| 核心问题 | "这门生意值不值得做？" | "这个产品/功能怎么做？" |
| 重点步 | 机会预判+单元模型 | 需求分析+产品内核 |
| 输出 | 投资决策/商业计划 | 产品方案/PRD |
| 详见 | `[[yt-five-step-method]]` | `[[framework-一堂五步法-泛产品设计]]` |

## 六、失败模式

| 模式 | 症状 | 修复 |
|:---|:---|:---|
| 跳步 | 还没验证需求就开始做产品 | 强制过换档检查清单 |
| 价值/增长混淆 | 需求都还没确认就在算LTV | 区分两次跃迁——没到Step 4不碰单元模型 |
| 假换档 | 换档清单全打勾但都是"我觉得" | 每个勾必须有验证证据，不能是"我认为" |
| 单向不回退 | 发现假设错了但硬着头皮往下走 | 假设验证失败→回退到上一步，不丢人 |
| 两种形态混淆 | 用商业分析版的方法做产品设计 | 判断场景——创业决策用商业版，产品设计用泛产品版 |

## 七、Critique

**线性幻觉**：五步法看起来是1→2→3→4→5的流水线，但现实中创始人经常在几步之间反复跳。Truman自己说（增长口述 L866-L980）："五步法不是让你一次走完的，是让你知道自己在哪一步、下一步是什么。"

**过度框架化风险**：把五步法当成"创业的唯一正确路径"——有些生意不需要前两步（需求已经验证过了），有些生意在第4步就死了（单元模型永远不成立）。五步法是地图不是导航——告诉你有这些路，但不替你选。
