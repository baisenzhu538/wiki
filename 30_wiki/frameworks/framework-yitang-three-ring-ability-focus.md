# 三环能力聚焦法：从 30 个能力中锁定 3 个重点

## 一句话

面对二三十个"应该练"的能力，画三个同心圆，逼自己只选 3 个核心能力；每个能力再拆 3-5 个子能力，最终形成不超过 15 个当下练习点——把有限精力押注在影响"前三年、后五年"的关键能力上。

## 核心结构图

```
        ┌─────────────────────────────────────┐
        │           外圈：基础能力              │
        │   维持下限、保障运转，不被拉开差距      │
        │   （管理、沟通、基础工具、通用素养）    │
        │   ┌─────────────────────────────┐   │
        │   │        中圈：专业能力          │   │
        │   │  职场立身之本，决定收入与职位    │   │
        │   │  （产品、运营、销售、设计等）    │   │
        │   │   ┌─────────────────────┐   │   │
        │   │   │    内圈：人生红点能力   │   │   │
        │   │   │ 突破天花板、成为人生支点 │   │   │
        │   │   │  （不可替代的顶级专长）  │   │   │
        │   │   └─────────────────────┘   │   │
        │   └─────────────────────────────┘   │
        └─────────────────────────────────────┘
```

**核心约束**：
- 内圈最多 3 个核心能力
- 每个核心能力最多 3-5 个子能力
- 当下重点练习点 ≤ 15 个

> 这些数量约束来自 Truman 基于个人教学与职业规划的实践经验，属于经验法则，用于限制练习焦点的扩散，并非严格实验结论。

三环不是能力分类表，而是**投资决策模型**：把练习时间当作资本，只投向回报率最高的标的。

## 三圈的定义与分工

### 内圈：人生红点能力——用来"摸天花板"

这是对你未来 3-5 年影响最大、最值得追求专业甚至"无限进步"的能力。它通常与人生红点绑定，是你想成为的那个人最不可替代的技能组合。

**判定标准**：
- 不练它，未来三年会显著限制你的可能性
- 练成了，能成为你职业甚至人生的支点
- 你愿意为它主动进入非舒适区、承受失败

**Truman 2024 年内圈示例**：
1. **产品设计**（含最佳实践想象、顶层设计、内核边界、攻坚会、Roy 等子能力）
2. **商业操盘**（含行业预判 map、假设实验、规模经济对抗等子能力）
3. **建模**（含 MECE、灵感闪现等子能力）

### 中圈：专业能力——用来"立身"

这是你当前岗位或领域要求的核心技能，决定了你能不能拿到门票、拿到什么级别的门票。专业能力必须达标，但未必每一个都要追求顶尖。

**判定标准**：
- 岗位 JD 上明确要求的硬技能
- 行业内评价你水平的默认标尺
- 不精通会被淘汰，但精通也不一定带来非线性回报

**Truman 2015 年中圈示例**：
- 产品能力（需求分析、产品设计）
- 运营能力（写文案、设计页面、用户运营）
- 管理能力（风险管理、团队协作）

### 外圈：基础能力——用来"保下限"

这些能力是组织运转和日常工作的通用基础设施。它们的作用是避免短板拖累整体表现，而不是无限精进。

**判定标准**：
- 通用性强，几乎人人需要
- 达到"够用"水平后，边际收益递减明显
- 出问题会拖后腿，但卓越不一定直接带来成功

Truman 明确表示：管理在一堂体系里属于"保下限"的基础能力，补短板即可，不需要追求市场上做得最好。这与很多人的直觉相反——管理不是不重要，而是不应无限占用"刻意练习"的稀缺预算。

## 操作步骤

### 步骤 1：列出所有你认为"该练"的能力

先做一次无筛选的头脑风暴。不要限制数量，把脑子里"我可能应该练"的东西全写下来。常见清单会有 20-30 项，甚至更多。这是正常现象，也是焦虑的来源。

### 步骤 2：按"前三年后五年"影响力排序

对每一项能力问两个问题：
- 未来 3 年，这项能力缺了会对我造成多大损失？
- 未来 5 年，这项能力练到顶级会给我带来多大收益？

把"高损失 + 高收益"的能力排到前面。这里要诚实，不要用"大家都觉得重要"代替"对我真的重要"。

#### 步骤 2.5：用评分表把排序显性化

如果你更喜欢量化，可以给每项能力打一个简单的优先级分：

| 能力 | 3 年损失 (1-5) | 5 年收益 (1-5) | 优先级分 (=损失+收益) | 初步圈层 |
|:---|:---:|:---:|:---:|:---:|
| 示例：数据分析 | 4 | 3 | 7 | 中圈 |
| 示例：公开演讲 | 2 | 5 | 7 | 中圈/内圈候选 |

**打分说明**：

- **3 年损失 1-5**：1=完全不练也没影响；5=不练会显著限制未来三年的机会或收入。
- **5 年收益 1-5**：1=练到顶级对我也没什么额外回报；5=练到顶级会成为职业/人生的关键支点。
- **优先级分**只是决策线索，不是机械排序；最终还要结合人生红点、组织需求和个人意愿。
- 如果两项分数相同，优先选「损失更高」的那项——短板往往比长板更先决定你能不能拿到门票。

### 步骤 3：画三个同心圆，把能力放进圈层

- **内圈**：只放 3 个核心能力——这是硬性约束，逼自己做取舍。
- **中圈**：放专业能力，是你当前阶段吃饭的本事。
- **外圈**：放基础能力，达到合格线即可，不需要重点投入。

如果某项能力放不进内圈，它就不是当下重点。接受这个结论，是三环法的第一个心理门槛。

### 步骤 4：为每个内圈能力拆 3-5 个子能力

不要停留在"我要练产品设计"这种口号。继续拆：
- 产品设计 → 需求分析、顶层设计、内核边界、攻坚会、最佳实践想象

最终形成 9-15 个具体练习点。这就是你未来一年甚至更长时间的能力作战地图。

### 步骤 5：勾出当前重点，贴墙可视化

从 9-15 个练习点中，再选出眼下优先级最高的几项，用红笔勾出来。然后把这张三环图贴在每天必经之地——墙上、桌面、屏保。

Truman 的做法是把它"拍到墙上"，每天路过都能看到。可视化不是仪式感，而是持续把长期追求拉回注意力的锚点。

### 步骤 6：动态调整，以年为单位更新

能力优先级会随着职业阶段变化。Truman 2015 年的重点是产品 / 运营 / 管理，2024 年变成了产品设计 / 商业操盘 / 建模。建议每年复盘一次三环图，确认内圈能力是否仍值得重点投入。

## Truman 两个版本对比

| 维度 | 2015 版 | 2024 版 |
|:---|:---|:---|
| 职业阶段 | 产品经理成长期 | 创业者/战略决策者 |
| 内圈能力 | 产品能力、运营能力、管理能力 | 产品设计、商业操盘、建模 |
| 能力重心 | 执行层技能组合 | 高阶判断与框架能力 |
| 管理位置 | 中圈/内圈附近 | 外圈（保下限即可） |
| 子能力示例 | 需求分析、产品设计、写文案、风险管理 | 顶层设计、行业预判 map、MECE、灵感闪现 |

这个对比说明：三环模型不是静态标签，而是随职业阶段演化的投资决策。

## When NOT to Use

1. **职业初期能力单一**：如果当前岗位只需要把 1-2 项硬技能练扎实，不需要强行画三圈。先解决"会不会"，再解决"选哪个"。
2. **组织强制能力要求**：当公司明确要求你必须在短期内补齐某项能力（如新系统、新流程）时，优先级不由三环决定，而由组织需求决定。
3. **面临生存危机**：如果当前某项能力不足会直接影响工作绩效或收入，它自动进入内圈，不需要用模型筛选。
4. **完全不知道自己想做什么**：三环需要"长期追求"作为前提。如果连人生红点都还没想清楚，先用其他方法探索方向，再回来聚焦。
5. **职业转型期**：旧能力价值骤降、新能力地图尚未建立时，三环法的"严格三圈约束"应暂缓。此时应允许 1-2 个探索性能力先进入中圈，通过 20 小时法快速试错，等方向验证后再收紧到 3 个核心能力。

## 失败模式

| 失败模式 | 真实信号 | 今晚就能执行的修复动作 |
|:---|:---|:---|
| 圈画得太多，舍不得删 | 内圈放了 5-7 个能力，每个都想练 | 把后几名移到中圈，只留前 3；对每项写一句"不练它的代价"，看哪条最不痛 |
| 把"外圈保下限"当"内圈无限精进" | 每天花大量时间练通用管理、沟通，但核心专长没有突破 | 给外圈能力设定"够用标准"，达标后不再增加练习预算 |
| 只画圈不拆子能力 | 三环图挂在墙上半年，但不知道这周具体练什么 | 今晚为每个内圈能力写出 3-5 个可执行子能力，并标注本周练哪个 |
| 凭"市场热门"选能力 | 内圈里有"AI 提示词""数据分析"等跟风项，但与个人目标关联弱 | 把每个候选能力与"三年后想成为的自己"做关联测试，写不出强关联就移出 |
| 画完就不再更新 | 2024 年了还挂着 2019 年的三环图 | 设一个年度日历提醒，每年 12 月复盘一次三环图；职业重大变化时立即更新 |
| 只盯着内圈，外圈塌掉 | 专业能力很强，但基础管理或沟通短板导致项目失败 | 给外圈能力做一次快速诊断，找出当前最短的板，先补到及格线 |
| 把三环当免责借口 | "这个我不练，因为它不在内圈"，但其实是逃避困难 | 区分"战略放弃"和"畏难放弃"：前者能说出明确的替代计划，后者只是不想面对 |

## Critique

1. **过度聚焦可能错过跨界机会**：只练 3 个能力可能让你对相邻领域的信号不敏感。修复方式不是扩大内圈，而是保持中圈和外圈的"扫描"——知道发生了什么，但不深入练。
2. **"人生红点"不是人人都能想清**：三环法假设你对自己的长期目标有一定认知。对于职业方向尚不清晰的人，强行画三圈可能变成"把焦虑具象化"，而不是"把行动聚焦化"。
3. **组织环境可能打乱个人优先级**：公司的晋升体系、绩效考核可能与你的三环图不一致。个人成长模型需要与组织现实协商，不能完全自说自话。
4. **三环法不回答"怎么练"**：它只是目标筛选工具，具体练习质量仍取决于 1+4 模型（长期追求、固定套路、非舒适区、及时反馈、大量重复）。
5. **"人生红点能力"与职业资本的对应**：Cal Newport 在《So Good They Can't Ignore You》中提出，稀缺且有价值的技能会积累「职业资本」（career capital），这与三环法中「把有限时间押注在回报率最高的能力上」的投资逻辑一致；但 Newport 更强调技能的稀缺性和市场价值，而三环法还加入了个人意义与长期目标。

## 与其他知识的关联

- 与 `[[framework-yitang-deliberate-practice-1plus4]]` 的关系：三环法是 1+4 模型在"目标选择层"的配套工具。1+4 解决"怎么练"，三环解决"练什么"。
- 与 `[[tool-yitang-practice-20hour-starter]]` 的关系：20 小时入门法适合快速验证中圈或外圈中的某项能力是否值得继续投入；内圈能力通常需要更长期、更系统的刻意练习。
- 与 `[[concept-yitang-comfort-stretch-panic-zones]]` 的关系：内圈能力应主要安排在拉伸区和困难区练习；外圈能力只需维持舒适区熟练度即可。
- 与 `[[dk-yitang-deliberate-practice-common-traps]]` 的关系：三环法直接对抗"能力太多练不过来"和"动机不足"两个常见陷阱。
- 与 `[[framework-ai-deliberate-practice-loop]]` 的关系：AI 可以辅助三环法中各圈能力的快速试错和反馈，但无法替代你对"哪个能力该进内圈"的战略判断。

## Action Triggers

- 当你感觉"要学的东西太多，不知道从哪里开始"时 → 立即画三环图，把清单从 30 项压到 3 个核心能力。
- 当你发现"练了一年，但没有一项真正突破"时 → 检查内圈能力是否超过 3 个，是否拆到了可执行的子能力。
- 当你进入新职业阶段或新岗位时 → 以年为单位更新三环图，确认内圈能力是否仍然匹配。
- 当你把大量时间花在"大家都觉得重要"的能力上时 → 用"前三年后五年"测试，把它放回该在的圈层。
