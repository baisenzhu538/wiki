# 从商业模式到增长：承上启下

> 一堂五步法：商业模式是增长的基础，增长是商业模式的放大。两者需要协同，不是割裂。

## 核心框架

```
商业模式（第三步）
    ↓
"单元模型成立，可规模化"
    ↓
增长策略（第四步）
    ↓
"获客、留存、变现的优化"
    ↓
增长飞轮
    ↓
"增长强化商业模式，商业模式支撑增长"
```

## 关键洞察

### 1. 商业模式与增长的关系

| 关系 | 说明 | 错误 | 正确 |
|:---|:---|:---|:---|
| **商业模式支撑增长** | 健康的单元模型支撑增长 | 单元模型不成立就增长 | 先验证单元模型 |
| **增长强化商业模式** | 规模效应降低成本 | 增长不考虑商业模式 | 增长优化单元模型 |
| **增长验证商业模式** | 增长数据验证假设 | 增长数据不分析 | 分析增长数据 |
| **商业模式限制增长** | 商业模式决定增长上限 | 忽视商业模式限制 | 评估增长上限 |

### 2. 从商业模式到增长的路径

| 步骤 | 行动 | 验证 |
|:---|:---|:---|
| **单元模型验证** | LTV > CAC | 数据验证 |
| **可规模化评估** | 5个维度评估 | 评分 |
| **增长策略设计** | 获客、留存、变现 | 策略文档 |
| **小规模测试** | 小规模测试增长策略 | A/B测试 |
| **规模化增长** | 扩大成功策略 | 数据监控 |
| **持续优化** | 优化单元模型 | 定期评估 |

### 3. 增长策略与商业模式的匹配

| 商业模式 | 增长策略 | 不匹配的风险 |
|:---|:---|:---|
| **订阅制** | 留存优先，降低流失 | 只获客，不留存 |
| **平台** | 双边启动，网络效应 | 单边增长，无法启动 |
| **免费增值** | 优化付费转化 | 只增长免费用户 |
| **B2B** | 销售驱动，客户成功 | 忽视客户成功 |
| **电商** | 复购驱动，LTV优化 | 只关注首单 |

### 4. 增长飞轮

```
    获客
     ↓
  变现优化
     ↓
  收入增加
     ↓
  投入增加
     ↓
  获客能力增强
     ↓
  （循环）
```

### 5. 增长的边界

| 边界 | 说明 | 管理 |
|:---|:---|:---|
| **单元模型边界** | LTV/CAC决定增长上限 | 优化单元模型 |
| **市场边界** | 市场规模决定增长上限 | 扩展市场 |
| **资源边界** | 资金、团队限制增长 | 融资、招聘 |
| **能力边界** | 组织能力限制增长 | 建设组织 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **商业模式不成立就增长** | 增长越快，亏损越大 | 先验证单元模型 |
| **增长与商业模式脱节** | 增长不考虑商业模式 | 增长服务商业模式 |
| **忽视留存** | 只获客，不留存 | 留存优先 |
| **增长不优化单元模型** | 增长但LTV/CAC不变 | 增长同时优化单元模型 |
| **忽视增长边界** | 增长超出能力边界 | 评估边界，控制增长 |
| **增长后不验证** | 增长后不分析数据 | 分析增长数据 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 增长策略设计 | 技术架构设计 |
| 商业模式与增长协同 | 品牌传播策略 |
| 增长优化 | 运营活动评估 |
| 规模化增长 | 纯公益项目 |
