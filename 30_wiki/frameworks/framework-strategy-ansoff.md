# 安索夫矩阵：产品-市场增长战略

> 安索夫矩阵（Ansoff Matrix）由伊戈尔·安索夫（Igor Ansoff）于 1957 年提出，帮助企业系统思考增长路径。

---

## 一、矩阵结构

```
              产 品
         现有        新
       ┌───────┬───────┐
  现有 │ 市场渗透 │ 产品开发 │
市     │       │       │
场     ├───────┼───────┤
  新   │ 市场开发 │ 多样化  │
       └───────┴───────┘
```

| 象限 | 定义 | 风险 | 典型动作 |
|--|--|--|--|
| **市场渗透** | 现有产品 + 现有市场 | 最低 | 提升客户忠诚度、提高定价能力、获取更大钱包份额、获取新客户、更新产品/服务、增加区域覆盖深度 |
| **市场开发** | 现有产品 + 新市场 | 中 | 进入新客户细分、新区域/海外市场、新渠道 |
| **产品开发** | 新产品 + 现有市场 | 中 | 进入新产品品类、围绕产品提供新服务 |
| **多样化** | 新产品 + 新市场 | 最高 | 既开展产品创新又进入新市场 |

---

## 二、PPT _91 中的战略问题清单

在确定增长方向前，先回答：

1. 继续进行市场渗透和客户渗透？
2. 新品类扩展？
3. 区域拓展？
4. 新客户开发？
5. 新渠道拓展？
6. 新业务模式？

---

## 三、使用步骤

1. **盘点现有产品/服务**：哪些已经验证、哪些在衰退。
2. **盘点现有市场**：哪些已饱和、哪些有增长空间。
3. **生成四个象限的候选策略**：每个象限至少 2-3 个选项。
4. **评估风险与回报**：结合资源、能力、时间窗口。
5. **制定组合策略**：通常企业会同时推进多个象限，而非只选一个。

---

## 四、安索夫矩阵画布

```markdown
| 象限 | 候选策略 | 目标客户/产品 | 所需资源 | 风险 | 优先级 |
|--|--|--|--|--|
| 市场渗透 | | | | | |
| 市场开发 | | | | | |
| 产品开发 | | | | | |
| 多样化 | | | | | |
```

## 五、Agent 执行指令

```python
def ansoff_growth_strategy(current_products: list[str], current_markets: list[str]):
    """生成安索夫矩阵增长策略"""
    prompts = {
        "市场渗透": f"基于现有产品{current_products}和现有市场{current_markets}，
提出市场渗透策略。",
        "市场开发": f"为现有产品{current_products}寻找新市场机会。",
        "产品开发": f"为现有市场{current_markets}开发新产品。",
        "多样化": "探索新产品+新市场的机会。",
        "组合决策": "评估四个象限的风险与回报，给出组合建议。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只选低风险 | 只做市场渗透，错失增长机会 | 用三地平线思维平衡短中长期 |
| 盲目多样化 | 资源分散，新市场新产品都失败 | 评估核心能力是否能迁移 |
| 忽略能力匹配 | 战略方向对，但组织跟不上 | 每个策略配能力建设计划 |
| 静态使用 | 一次定完不再更新 | 每年根据市场变化重新评估矩阵 |
