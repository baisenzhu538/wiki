# 企业战略金字塔：公司、业务与职能协同

> 战略管理的四层结构：公司战略 → 业务战略 → 职能战略 → 运营计划。同一战略目标，不同战略主题，会导向完全不同的行动、能力和 KPI。

---

## 一、四层战略结构

```
        ┌─────────────────┐
        │   公司战略        │  我们的业务应该是什么？
        │  （公司和集团层面）  │  哪些业务保持/进入/退出？
        ├─────────────────┤
        │   业务战略        │  选择哪些目标细分市场？
        │ （业务单元/事业部）  │  如何在竞争中取胜？
        ├─────────────────┤
        │   职能战略        │  价值链各环节如何部署？
        │（研发/供应链/营销等）│
        ├─────────────────┤
        │  运营计划/预算/执行 │  战略如何转化为具体行动任务？
        │    监控/绩效管理    │  配套什么资源和 KPI？
        └─────────────────┘
```

| 层级 | 组织层面 | 核心问题 | 输出物 |
|--|--|--|--|
| 公司战略 | 公司和集团层面 | 我们的业务应该是什么？哪些业务要保持、进入或退出？各业务的定位是怎样的？ | 业务组合、增长路径、资本配置 |
| 业务战略 | 业务单元/事业部/产品线 | 每个业务应该选择哪些目标细分市场？如何在目标市场竞争中取胜？ | 竞争战略、差异化定位、业务设计 |
| 职能战略 | 研发/供应链/营销/服务/财务/HR/IT 等 | 为了保证公司和业务战略的落地，在价值链各环节如何部署和筹划？ | 职能举措、能力建设计划 |
| 运营计划 | 部门层面 | 如何把战略转化为具体行动任务，配套资源和绩效管理措施？ | 年度经营计划、预算、KPI、执行监控 |

## 二、W&C 战略金字塔对比案例（PPT _21）

同样的目标（零售竞争力），不同的战略主题，带来完全不同的行动、能力要求、核心岗位和 KPI。

| 战略主题 | 业务战略 | 职能战略（战略举措） | 核心职能 | 部门执行差异 | 衡量指标 |
|--|--|--|--|--|
| **性价第一** | W集团：天天平价 | 1. 规模化采购，降低采购成本 | 采购 | 聚焦上游：供应商整合、资源配置向采购倾斜、全球供应链协同 | 采购成本降低？% |
| | | 2. 精益管理，减少价值链浪费 | 采购 | | 供应链中间损耗降低？% |
| | | 3. 供应商赋能，减少其管理成本 | 采购 | | A类供应商占比提升？% |
| **高低价** | C集团：高低价 | 1. 强化产品季节性管理 | 营运 | 偏向下游：门店促销、本地化运营、销售转化率考核 | 季节销售增长 X% |
| | | 2. 创新促销机制 | 市场 | | 促销 ROI 提升 Y% |
| | | 3. 供应商促销管理 | 营运 | | |
| | | 4. 优化财务控制体系 | 财务 | | 劳动力成本降低 Z% |

**关键洞察：** 战略主题决定资源配置方向。W 集团把资源投向上游供应链，C 集团把资源投向下游门店营运。

## 三、使用步骤

1. **明确公司战略**：业务组合、增长方向、资本配置。
2. **拆解业务战略**：每个业务单元的市场选择和竞争方式。
3. **制定职能战略**：各职能部门的关键举措和能力建设。
4. **落地运营计划**：年度任务、预算、KPI、责任人。
5. **对齐检查**：上一层目标是否被下一层举措充分支撑？

## 四、Agent 执行指令

```python
def strategy_pyramid_alignment(company_strategy: str):
    """将公司战略逐层拆解为业务和职能行动"""
    prompts = {
        "公司战略": f"确认公司战略：{company_strategy}",
        "业务战略": "列出各业务单元，并明确各自的目标细分市场和竞争方式。",
        "职能战略": "针对每个业务战略，列出研发/供应链/营销/服务/财务/HR/IT的关键举措。",
        "运营计划": "将职能举措转化为年度任务、预算、KPI和责任人。",
        "对齐检查": "用金字塔对齐表检查：上一层目标是否有下一层支撑？"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 层级错位 | 公司层面讨论业务战术 | 明确每个议题属于哪个层级 |
| 目标与行动脱节 | 公司目标宏大，部门计划照旧 | 强制做“战略解码”，每个 KPI 追溯至公司目标 |
| 职能各自为政 | 各职能部门计划不互相关联 | 绘制跨职能举措依赖图 |
| 没有闭环 | 年初定完就忘 | 建立季度战略review和预算调整机制 |
