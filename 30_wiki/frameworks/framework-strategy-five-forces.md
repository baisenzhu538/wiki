# 波特五力分析框架

> 迈克尔·波特（Michael E. Porter）提出的行业竞争分析框架，用于评估行业吸引力和盈利潜力。

---

## 一、五力模型

```
              ┌─────────────┐
              │  潜在进入者威胁  │
              └──────┬──────┘
                     ↓
    ┌──────────┐   ┌──────────┐   ┌──────────┐
    │ 供应商   │ → │ 行业内竞争 │ ← │ 购买者   │
    │ 议价能力 │   │  激烈程度  │   │ 议价能力 │
    └──────────┘   └────┬─────┘   └──────────┘
                        ↓
              ┌─────────────┐
              │  替代品威胁    │
              └─────────────┘
```

| 力量 | 核心问题 | 压力高时的表现 |
|--|--|--|
| **行业内竞争** | 现有竞争者之间的竞争有多激烈？ | 价格战、广告战、产品同质化、增长缓慢 |
| **潜在进入者威胁** | 新进入者进入有多容易？ | 壁垒低、利润高、新玩家不断涌入 |
| **替代品威胁** | 客户有多少替代选择？ | 替代品性价比高、转换成本低 |
| **供应商议价能力** | 供应商对我们的控制力多强？ | 供应商集中、转换成本高、前向一体化威胁 |
| **购买者议价能力** | 客户对我们的控制力多强？ | 客户集中、标准化产品、价格敏感 |

---

## 二、分析维度（PPT _74）

### 2.1 竞争者威胁分析维度

| 维度 | 说明 | 子维度示例 |
|--|--|--|
| 行业集中度 | 企业势均力敌则竞争激烈 | 渠道品牌、产品品牌 |
| 差异化程度 | 差异化越小竞争越激烈 | 产品差异、品牌差异、地区差异、渠道差异 |
| 市场容量和增速 | 容量有限、增长停滞则竞争加剧 | — |
| 竞争对手经营水平 | 对手越成熟威胁越大 | — |
| 退出壁垒高低 | 退出壁垒高则竞争激烈 | 专用设备、过剩产能转移困难 |

### 2.2 压力评估

| 力量 | 压力大小 | 证据 |
|--|--|--|
| 行业内竞争 | 大/中/小 | 集中度、差异化、增速、退出壁垒 |
| 潜在进入者 | 大/中/小 | 进入壁垒、规模经济、政策限制 |
| 替代品 | 大/中/小 | 替代品性价比、转换成本 |
| 供应商 | 大/中/小 | 供应商集中度、转换成本 |
| 购买者 | 大/中/小 | 客户集中度、价格敏感度 |

## 四、Agent 执行指令

```python
def five_forces_analysis(industry: str, company: str):
    """对指定行业进行波特五力分析"""
    prompts = {
        "行业内竞争": f"分析{industry}中现有竞争者的竞争程度，包括集中度、差异化、增速、退出壁垒。",
        "潜在进入者": f"分析新进入者进入{industry}的壁垒和威胁。",
        "替代品": f"分析{industry}面临的替代品威胁及转换成本。",
        "供应商": f"分析{industry}中供应商的议价能力。",
        "购买者": f"分析{industry}中购买者的议价能力。",
        "战略影响": f"基于以上五力，对{company}提出战略建议。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 五、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只分析不行动 | 列出五力但无战略结论 | 每个力量必须对应一条战略影响 |
| 静态分析 | 只拍当前快照 | 结合行业趋势预测五力变化 |
| 平均用力 | 每个力量都讲得很细 | 聚焦对本公司影响最大的 1-2 个力量 |
| 脱离细分市场 | 在行业层面泛泛而谈 | 针对本公司所在细分市场分析 |
