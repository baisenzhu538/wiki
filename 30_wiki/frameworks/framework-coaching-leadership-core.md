# 教练式领导力核心框架

> 定位：教练式领导力卡组的总纲框架卡。下属卡：`framework-leadership-five-ladders`（层级路径）、`framework-leadership-coin-model`（信任机制）、tool 武器库×6（沟通术）。与五阶管理地图（management-domain-digest）的关系：管理保下限，领导力追上限。

## 一句话定义

**领导力 = 带领他人心甘情愿解决难题的能力。** 领导力对标的不是鞭子、KPI、周会、老板身份或强压，靠的是"心甘情愿"——大家执行过程中一定有痛苦、很难、很苦甚至委屈，但整体上是愿意的、内生的、渴望的、饱含热情的（口述 01 L646-672）。

## 为什么重要

1. **区分管理**：管理是做事的方法工具，领导力唤醒内在动机。管理保下限，领导力追上限（L1592-1594）
2. **解决开放难题的唯一杠杆**：开放的、难的、长周期的、大家容易退缩的问题，靠的是领导力；确定执行的、无难度的问题领导力不发挥价值（L686-688）
3. **可提升的工作状态**：领导力被具象成一种高水平工作状态，可以逐步提升，衡量的是"能不能带一群人心甘情愿地解决问题"（L694）
4. **不只针对下属**：向上、跨部门、对合作伙伴同样适用（L700）

## 核心机制：三驱动可代偿三角

| 驱动 | 本质 | 典型手段 | 局限 |
|:--|:--|:--|:--|
| **权力** | 影响外在行为 | 授权、调资源、职级稀缺资源、决策能力 | 志愿者团队无权力可用；跨部门无统一协调机制时失效（L1618-1626） |
| **管理** | 做事方法工具 | 架构工具、执行框架、流程机制 | 管理越强，领导力依赖越弱（L1638） |
| **领导力** | 唤醒内在动机 | 讲道理、愿景、以身作则、攒信任硬币 | 需要敏感性，否则意识不到加减币 |

**核心洞察——三者可代偿**：A 强 B 可以弱一点，反之亦然。志愿者团队没权力 → 早期靠领导力代偿，再靠管理工具优化（L1618-1622）；大公司权力文化强 → 用权力推动就好使（L1632）；初创公司无成熟管理体系 → 创始人主要靠领导力凝聚团队（L1634）。三者都是为了解决问题，互为补充（L1600-1616）。

**决策含义**：接任务时先判断"这个场景哪种驱动可用"——不要默认领导力，也不要默认权力。

## 领导力敏感性（起点能力）

领导力 = 每年成百上千次一对一互动中形成的，每一次信任积累都重要（L1072）。**敏感性 = 对每次互动是加币还是减币的觉察能力**（L1074）。

- 黑盒评价模型：先建立"什么行为增加/减少领导力"的判断标准，再观察团队——有了模型之后能看到之前两年都没观察到的规律（L776）
- 觉察案例：Truman 有了敏感性后，每年有几十上百次"到这儿要对他好一点/到这儿要秀一下肌肉/到这儿要让他觉得我挺厉害"的微观判断（L1148-1154）
- 进步路径：主动构建领导力意识后约两年，敏感性显著增强，生活里每年几十上百次（L1148）

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 确定执行、重复成功的任务 | 领导力不发挥价值（L686） | 流程/管理即可 |
| 纯运营 SOP 岗位 | 不需要领导力 | 管理工具 + 明确指令 |
| 紧急拍板时刻 | 等共识会误事 | 权力快断（L1636：着急时拍板，其余时间用领导力） |
| 对方不认公理前提（如"需求是事实"） | 没有共识地基，聊不下去（L2656-2666） | 先对齐前提，不对齐不进入教练对话 |
| 把"教练式领导力"误用为"做教练" | 重心在领导力不在教练技巧（L1456） | 领导角色 + 教练式沟通手段，不是转行做教练 |

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 用权威代替道理 | "我是领导就听我的"，口服心不服 | 讲决策逻辑，解释不清拉人一起聊（L940） |
| 情绪失控 | 重要场合发脾气，情绪大于理性和事实 | 识别触发点，建立冷静期；情绪失控一次抵消数月硬币积累 |
| 黑盒决策 | 能做对但讲不清，无法形成共识 | 练习白盒决策：事实→推理→结论讲给团队 |
| 忽视敏感性 | 意识不到每次互动的加减币 | 建立个人加减币清单，每周复盘一次关键互动 |
| 把领导力当万能 | 纯运营场景也用讲道理，效率低下 | 按三驱动代偿三角选型 |

## 行动 Checklist

- [ ] 用一句话向团队复述"领导力 = 心甘情愿解决难题"，确认理解
- [ ] 盘点当前最重要的 3 个任务各用哪种驱动（权力/管理/领导力）推动
- [ ] 建立个人加减币清单（参照硬币模型卡），标注最近一周 3 次关键互动的加减
- [ ] 选一个最近的黑盒决策，练习拆成白盒讲给团队
- [ ] 识别 1 个"开放的/难的/长周期的"问题，专门用领导力而非管理去推

## Critique

### 攻击者 1：情境领导力学派（Blanchard）——"定义缺下属发展阶段维度"

**攻击论点**：定义"心甘情愿解决难题"只描述了领导者的意图，没有区分下属的能力×意愿状态。S1 指令型下属不需要"心甘情愿"，S4 授权型下属不需要"带领"。同一套定义无法指导不同成熟度下属的领导行为。

**回应**：定义是"道"层面的总纲，下属差异化在工具层处理——`tool-leadership-three-stubborn-subordinates` 卡的三类棘手下属（小白兔/老黄牛/老油条）即能力×意愿矩阵的本土化，与 Blanchard 同构。承认：总纲卡本身确实不含发展阶段维度，这是有意分层，P2 可考虑补"匹配下属发展阶段"扩展。

### 攻击者 2：组织行为学批评——"可代偿三角可能变成滥用权力的借口"

**攻击论点**：三驱动可代偿听起来中性，但实践中管理者容易把"权力代偿"正当化——"大公司文化就这样，用权力推就好使"。这与讲道理文化（道理大于天）直接冲突，可能成为放弃领导力修炼的借口。

**回应**：口述本身已给边界——代偿是"一些情况下"的选择（L1600），且明确"道理大于天"是理想文化（L950）。代偿是现实主义的过渡手段，不是终点。承认风险存在：卡内应强调代偿≠放弃领导力修炼，代偿是为了腾出时间建立真正的领导力。

### 攻击者 3：纯教练姿态误解——"领导力=永远不给答案，让下属自己发现"

**攻击论点**：教练式领导力可能被误读为"永远提问、从不建议"，导致管理者逃避决策责任，把"让下属自己想"当成不担责的挡箭牌。

**回应**：口述 01 L940 明确"要讲背后的决策逻辑和合理性"——讲道理 ≠ 不给答案，而是给答案时讲清逻辑。L484-486 也给了边界："在希望不给答案的前提下"才用教练式引导。领导者在关键时刻必须拍板（L1636）。承认：误读风险真实存在，使用时需透明切换"何时教练、何时指令"。

## Synthesis

- **不要用的场景**：紧急决策（时间成本 > 共识收益）；对方不接受基本公理（需求是事实/商业可预判）；纯执行岗位；一次性小任务
- **关联表**：
  - `[[framework-leadership-five-ladders]]`：五阶梯是"怎么从 L0 爬到 L5"的路径卡
  - `[[framework-leadership-coin-model]]`：硬币模型是"敏感性具体看什么"的清单卡
  - `[[tool-leadership-listening-cards]]`：倾听卡是"建立信任"的第一组工具（对应 L2 共识层）
  - `[[framework-yitang-y-model-cross-domain-fusion]]`：讲道理的实现工具
  - `[[management-domain-digest]]`：管理域全景，本卡补"上限"维度
- **Action Triggers**：
  - 发现团队"口服心不服" → 启动讲道理流程（白盒拆解）
  - 接任务先问"这个场景哪种驱动可用" → 三驱动选型
  - 情绪失控后 24 小时内 → 主动复盘 + 向受影响成员说明
  - 团队遇到开放难题想退缩 → 识别为领导力场景而非管理场景

## 可迁移场景

1. **带跨部门项目**：无统一指挥权（权力缺位）→ 用领导力代偿：讲清项目价值 + 个人成长收益
2. **带新人/实习生**：前三个月帮 TA 找一个周围人不擅长的稀缺小点（L2352-2358），形成协作价值
3. **Agent 协作（KDO 工厂自身）**：老顽童/黄药师/欧阳锋都是"心甘情愿解决难题"的成员——派活时讲清为什么（讲道理），而非只发指令
4. **家庭/社群志愿者组织**：无职权场景，全部靠领导力代偿，可代偿三角直接适用
