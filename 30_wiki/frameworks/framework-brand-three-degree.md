# 品牌三度

> **Burn line**: 网红追求流量，创始人 IP 追求信任。流量只解决"知不知道"，品牌三度解决"信不信、买不买"。

## Summary

品牌三度把"用户对一个 IP 的认知深度"拆成三层：

- **知名度**：用户知不知道你是谁（曝光）
- **美誉度**：用户喜不喜欢你、信不信任你（情感 + 专业认可）
- **信任度**：用户愿不愿意为你付费（转化）

做短视频内容时，三种度对应三种内容类型：
- 人设视频 → 建**美誉度**（让用户喜欢你、信任你）
- 营销视频 → 建**信任度**（让用户愿意付费）
- 爆款/泛流量视频 → 建**知名度**（让更多人知道你）

## Claims

### Claim 1：只做知名度不做美誉度会"塌"

曝光大但口碑差，流量反而会放大负面。用户知道你，但不喜欢你，最后宁愿买竞品。

> 大馨战队案例：某个人设视频可能报了百万播放，但咨询并不多——它在建信任，不是直接转化。

### Claim 2：三度的转化漏斗是"知道 → 喜欢 → 付费"，不能跳级

让用户直接付费前，必须先让他相信"你这个人靠谱"。很多销售型内容失败，是因为只在讲"我的产品多好"，没有先建"我这个人可信"。

### Claim 3：创始人 IP 的内容定位，要同时服务三度

- 知名度内容：讲行业大话题、争议观点，吸引新用户
- 美誉度内容：讲价值观、创业故事、专业判断，让老用户更信你
- 信任度内容：讲案例、方法论、服务边界，让有需求的用户付费

| 来源 | 关键数据/观察 | 对应三度 |

| 大馨战队拆解 | 人设视频百万播放但咨询少，夏令营视频非大爆款但上千条咨询 | 美誉度 vs 信任度的功能分离 |
| 魏千洛分享 | "网红追求流量，创始人 IP 追求信任" | 创始人 IP 的核心是信任度 |

## 质疑

### 内部局限

1. **具体假设：三度之间不是严格的线性漏斗**
   有些用户可能是先买了低价产品，使用过程中才产生美誉度和信任度。三度更像是"循环强化"而不是"必须按顺序"。**边界**：三度模型更适合作为内容策略框架，而不是用户心理阶段的精确测量工具。

2. **不同行业对三度的权重不同**
   快消品可能知名度更重要；高客单专业服务（咨询、教育、医疗）信任度权重更高。用同一个标准衡量会失真。**前提**：使用三度前需先明确行业特性和客单价区间。

3. **"美誉度"难以量化**
   知名度和信任度可以用播放量、转化率、客单价衡量；美誉度更多依赖评论情感、复购、口碑传播，指标不够稳定。**反例**：某账号播放量高、评论正面，但用户仍因价格或竞品而不转化，说明美誉度≠购买意愿。

### 外部攻击

#### 质疑者视角 A：品牌资产理论更复杂，三度过于简化

Aaker 的品牌资产十要素模型包含品牌忠诚、品牌认知、感知质量、品牌联想、其他专利资产等。把品牌资产简化为"三度"可能丢失关键维度（如品牌个性、品牌文化）。

**回应**：三度不是替代完整品牌理论，而是给创始人 IP 短视频内容一个**可操作的内容分层框架**。它的价值在于指导"今天拍什么"，而不是替代品牌战略。

#### 质疑者视角 B：短视频算法不区分三度，只区分完播和互动

平台算法不会因为你"在建美誉度"就给你推流。完播率、点赞、评论、转发才是流量分配的核心信号。

**回应**：算法指标是流量杠杆，三度是商业杠杆。同一条视频可以既满足算法（前 3 秒钩子、信息密度），又服务三度（内容主题选择）。两者不是二选一。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|---|---|---|
| 用三度评估一条单条娱乐短视频 | 单条爆款可能只服务知名度，无法体现美誉度和信任度 | 用三度评估一个账号的内容组合，而不是单条视频 |
| 用三度评估纯产品功能介绍 | 功能介绍主要服务信任度，美誉度部分较弱 | 配合创始人出镜、案例、用户证言，补足美誉度 |
| 用三度做短期投放效果归因 | 三度是长期信任资产，短期 ROI 无法完全反映 | 结合 30/60/90 天复购率、线索质量等长周期指标 |

## 操作步骤

### Step 1：诊断当前三度分布

对账号近 30 天内容按「知名度 / 美誉度 / 信任度」分类，统计数量、播放量、互动率、转化率。

| 维度 | 主要指标 | 诊断问题 |
|---|---|---|
| 知名度 | 播放量、曝光人数、搜索量 | 是否没人知道你？ |
| 美誉度 | 正面评论率、关注率、完播率 | 用户知道你了，喜不喜欢你？ |
| 信任度 | 私信/咨询数、转化率、客单价 | 喜欢你的人，愿不愿付费？ |

### Step 2：确定阶段主提升度

根据业务阶段选择一个主目标，避免三度同时发力导致资源分散。

| 业务阶段 | 主目标 | 典型信号 |
|---|---|---|
| 0-1 起号期 | 知名度 | 账号粉丝 < 1000，搜索量极低 |
| 1-10 成长期 | 美誉度 | 有流量但转化差，评论负面多 |
| 10-100 变现期 | 信任度 | 有粉丝但成交少，销售成本高 |

### Step 3：匹配内容类型与主题

| 主目标 | 内容类型 | 选题方向 |
|---|---|---|
| 知名度 | 爆款/泛流量视频 | 行业大话题、争议观点、热点借势 |
| 美誉度 | 人设视频 | 创业故事、价值观、专业判断、幕后花絮 |
| 信任度 | 营销视频 | 案例拆解、方法论、服务边界、用户证言 |

### Step 4：按比例排期

默认参考比例：**美誉度 2 : 信任度 1 : 知名度 1**。

- 成熟期创始人 IP 可提高信任度比例。
- 新账号起号期可先提升知名度比例，但不超过 50%。

### Step 5：发布与数据归因

每条视频发布前明确标注「主服务哪一度」，数据复盘时分别看对应指标，避免用播放量评价信任度内容。

### Step 6：迭代优化

每两周做一次三度复盘，找出最弱的维度，下一周期补 2-3 条针对性内容。
