# 调研超级武器库：三层八模块十四节点

> **一句话**：调研不是"有没有做"，而是"有没有穷尽手段"。三层八模块十四节点，从公开到内部，从线上到线下，从人工到AI，构建完整的调研武器谱系。

---

## 核心框架：三层结构

```
第一层：三端调研（用户·产品·合作方）
    ↓
第二层：内线调研（员工·前员工·内部信息）
    ↓
第三层：外线调研（专家·AI·媒体/数据库）
```

---

|:---|:---:|:---:|:---|

## Constraints & Boundaries

### 适用边界

1. **商业调研**：适用于市场、竞品、用户、行业等商业调研
2. **投资决策**：适用于投资前的尽职调查
3. **产品决策**：适用于产品战略、定位、功能设计
4. **战略规划**：适用于公司战略、市场进入、并购
5. **风险识别**：适用于合规、法律、政策风险评估

### 不适用场景

1. **学术研究**：需要严格方法论和伦理审查
2. **国家安全**：涉及国家安全的调研需要专业资质
3. **个人隐私**：涉及个人隐私的调研需要明确授权
4. **非法活动**：任何违法手段均不适用
5. **纯执行型任务**：不需要调研，按SOP执行即可

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 手段单一 | 只用公开信息，不深入 | 强制使用至少3个模块 | 所有信息来自同一渠道 |
| 合规风险 | 使用非法手段 | 明确法律边界，咨询法务 | "这个手段有点灰色" |
| 信息过载 | 用了太多手段，无法整合 | 用OSC框架缩小范围 | 调研报告超过50页 |
| 质量不均 | 某些手段执行质量差 | 建立质量标准，自检 | 某些模块信息明显薄弱 |
| 忽视验证 | 单一来源就下结论 | 强制交叉验证 | "根据XX报道..." |
| 成本失控 | 调研成本超过决策价值 | 评估投入产出比 | 调研花了10万，决策只值1万 |
| 团队能力不足 | 某些手段团队不会用 | 培训或外包 | "这个我们没做过" |
| 忽视动态 | 只调研一次，不跟踪 | 建立自动监控机制 | 调研后不再更新 |

## 行动触发器

1. **新项目启动**：根据重要性选择节点组合
2. **调研计划审查**：检查是否穷尽了足够手段
3. **信息质量不足**：回到武器库，选择更深入的手段
4. **团队培训**：用武器库培训团队调研能力
5. **定期复盘**：每季度检查武器库使用情况
