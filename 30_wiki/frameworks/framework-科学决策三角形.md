# 科学决策三角形

## 一句话定义

**科学决策三角形**是一堂方法论中的三维决策框架：**宽度**（关键收益项+关键成本项）、**高度**（长期视角+公司视角+机会成本+时间窗口）、**深度**（L1优先级定性→L2部分定量→L3定量公式→L4严格财务公式）[conf=0.82, source=原图/VLM描述]。

## 三维拆解

```
              高度
              /\
             /  \  长期视角·公司视角
            /    \ 机会成本·时间窗口
           /      \
          /  决策  \
         /   三角形  \
        /            \
       /______________\
    宽度                深度
  关键收益项           L1→L2→L3→L4
  关键成本项           从定性到
                      严格财务公式
```

| 维度 | 核心问题 | 子项 |
|:---|:---|:---|
| **宽度** | 这个决策涉及哪些收益和成本？ | 关键收益项、关键成本项 |
| **高度** | 从多高维度看这个决策？ | 长期视角、公司视角、机会成本、时间窗口 |
| **深度** | 算到什么程度？ | L1优先级定性 → L2部分定量 → L3定量公式 → L4严格财务公式 |

## 为什么重要

1. **防止「宽度够但深度不够」**：列出所有因素（宽度）但全凭直觉判断（深度L1）= 伪科学决策 [conf=0.70, source=一堂原创]。
2. **防止「算得很深但方向错了」**：L4级精确计算但漏了长期视角（高度不够）= 把错误算得更精确 [conf=0.70, source=一堂原创]。
3. **三维互相制约**：宽度不够会漏关键因素，高度不够会短视，深度不够会被"感觉"左右 [conf=0.75, source=一堂原创]。

## 使用方式

1. 对任何重大决策，先问：宽度的关键收益和成本列全了吗？高度的四个视角都考虑了吗？深度至少做到 L2 了吗？
2. 如果三维中某一维明显短板——先补那一维，再推进决策。
3. 应急决策可以降低深度（L1足够），但宽度和高度不能省。

## 失败模式

| 失败 | 症状 | 修复 |
|:---|:---|:---|
| 只用一维 | "我算过ROI了"但没考虑时间窗口 | 三维自查：宽度、高度、深度各打分1-5 |
| 深度幻觉 | 觉得"想得挺深"实际只到L1 | 对照L1-L4定义，诚实打分 |
| 宽度只列显性 | 漏了机会成本、品牌影响 | 用「还有吗」追问三轮 |

## 与已有框架的关系

- **[[yt-decision-y-model]]**：Y模型提供成本/收益/时间/空间四个维度的分析框架，决策三角形是Y模型的「执行层」——告诉你具体怎么算。
- **[[tool-ROI决策评估画布]]**：画布是决策三角形的填空工具——宽度填收益/成本，高度填长期/公司/机会/时间，深度决定每项填多精确。

## Critique

> **一堂内部批判**：决策三角形把「深度」定义为L1-L4的线性升级，但现实中很多决策的深度是跳跃的——某个关键假设需要L4级验证，其他项L1足够。三维框架应该支持「混合深度」而非强制统一深度 [conf=0.70, source=方法论自我反思]。
