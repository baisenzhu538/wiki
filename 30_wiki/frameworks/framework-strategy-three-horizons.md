# 三个地平线：短中长期业务组合管理

> 三个地平线（Three Horizons）框架帮助企业同时管理当下现金流、中期增长和长期创新。

---

## 一、三地平线结构

```
时间 / 不确定性
    ↑
    │    H3  孵化潜在业务
    │
    │    H2  培育新兴业务
    │
    │    H1  扩展与防卫核心业务
    └──────────────────→
```

| 地平线 | 核心任务 | 目标 | 管理重点 |
|--|--|--|
| **H1：核心业务** | 扩展与防卫 | 维护行业地位；延伸、捍卫、增加生产力和利润贡献 | 增收减费；持续改进价值链运营 |
| **H2：新兴业务** | 培育 | 迅速扩张；形成和凸显竞争优势 | 提升销售收入和增长率；发起挑战，扩大市场份额；培养核心能力 |
| **H3：潜在业务** | 孵化 | 跑通单元模型；低成本测试、快速迭代 | 新方案筛选；达成关键里程碑；完善核心技术或使用模式 |

---

## 二、三地平线管理对比

| 维度 | H1 核心业务 | H2 新兴业务 | H3 潜在业务 |
|--|--|--|--|
| **管控方式** | 经营计划实施与控制；财务预算控制 | 战略及业务计划引导；核心能力差距分析 | 项目规划；商业化准备度分析 |
| **绩效重点** | 近期利润表现与现金流；利润；经济增加值/资产回报率；生产效率 | 收入增长和投资回报；收入增长；净推荐值/新客户/关键客户获取；市场份额增长 | 投资回报多少和成功可能性；项目进展关键里程碑；机会点数量和回报评估；从创意到商用成功概率 |
| **时间跨度** | 0-1 年 | 1-3 年 | 3-5 年或更长 |
| **不确定性** | 低 | 中 | 高 |
| **资源需求** | 大规模、高效率 | 选择性投入、快速扩张 | 小规模、可试错 |

---

## 三、使用步骤

1. **盘点全部业务/产品**：按成熟度和增长潜力分类。
2. **填入三地平线**：明确每个业务属于 H1/H2/H3。
3. **设定差异化目标和管理方式**：H1 看利润和现金流，H2 看增长，H3 看里程碑。
4. **分配资源**：H1 保现金流，H2 投增长，H3 小规模孵化。
5. **建立动态迁移机制**：H3 跑通后进入 H2，H2 成熟后进入 H1。


## 五、Agent 执行指令

```python
def three_horizons_portfolio(business_list: list[str]):
    """将业务组合分类到三个地平线"""
    prompts = {
        "盘点": f"对业务{business_list}，评估成熟度、增长潜力、不确定性。",
        "分类": "将每个业务归入 H1/H2/H3，并说明理由。",
        "目标": "为每个业务设定目标地平线。",
        "资源配置": "按 H1/H2/H3 分配资源投入比例。",
        "迁移计划": "设计从 H3→H2→H1 的迁移标准和里程碑。"
    }
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 六、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只关注 H1 | 现金流好但增长乏力 | 强制分配一定比例资源给 H2/H3 |
| H3 过早规模化 | 还没验证就大规模投入 | 明确 H3 必须先跑通单元模型 |
| 用同一 KPI 管理三类业务 | H3 也被要求短期盈利 | 差异化考核：H1 利润、H2 增长、H3 里程碑 |
| 没有迁移机制 | H3 永远在试点 | 设定清晰的 H3→H2→H1 晋升标准 |
