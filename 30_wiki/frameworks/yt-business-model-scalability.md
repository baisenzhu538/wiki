# 商业模式可规模化评估：从1到100万

> 一堂五步法：单元模型成立只是开始，商业模式还需要可规模化。评估规模化潜力，避免"做不大"的陷阱。

## 核心框架

可规模化评估的5个维度：

```
可规模化 = f(获客可规模化, 交付可规模化, 团队可规模化, 资金可规模化, 技术可规模化)

每个维度评分：1-5分
总分 > 20分：可规模化
总分 15-20分：有条件可规模化
总分 < 15分：不可规模化
```

## 关键洞察

### 1. 获客可规模化

| 评估项 | 问题 | 评分标准 |
|:---|:---|:---:|
| **渠道数量** | 有几个获客渠道？ | 单一渠道1分，3+渠道5分 |
| **渠道上限** | 每个渠道能获客多少？ | 上限低1分，上限高5分 |
| **获客成本稳定性** | 规模化后CAC是否稳定？ | 上升快1分，稳定5分 |
| **自然获客占比** | 自然获客占比多少？ | 低1分，高5分 |
| **口碑效应** | 是否有口碑传播？ | 无1分，强5分 |

### 2. 交付可规模化

| 评估项 | 问题 | 评分标准 |
|:---|:---|:---:|
| **交付成本** | 交付成本是否随规模下降？ | 上升1分，下降5分 |
| **交付质量** | 规模化后质量是否稳定？ | 下降1分，稳定5分 |
| **自动化程度** | 交付过程自动化程度？ | 低1分，高5分 |
| **供应链** | 供应链是否支撑规模化？ | 脆弱1分，强5分 |
| **服务边界** | 服务是否有边界？ | 无边界1分，清晰5分 |

### 3. 团队可规模化

| 评估项 | 问题 | 评分标准 |
|:---|:---|:---:|
| **关键人依赖** | 是否依赖个别关键人？ | 高依赖1分，低依赖5分 |
| **招聘难度** | 规模化需要的人才好招吗？ | 难1分，易5分 |
| **培训体系** | 有培训体系快速复制能力吗？ | 无1分，完善5分 |
| **管理复杂度** | 团队规模扩大，管理复杂度？ | 指数增长1分，线性增长5分 |
| **文化一致性** | 规模化后文化是否一致？ | 易稀释1分，强5分 |

### 4. 资金可规模化

| 评估项 | 问题 | 评分标准 |
|:---|:---|:---:|
| **现金流** | 规模化需要多少资金？ | 大量1分，少5分 |
| **融资能力** | 需要融资吗？融资难度？ | 难1分，易5分 |
| **回本周期** | 规模化后的回本周期？ | 长1分，短5分 |
| **资金效率** | 资金使用效率？ | 低1分，高5分 |
| **盈利路径** | 规模化后盈利路径清晰吗？ | 模糊1分，清晰5分 |

### 5. 技术可规模化

| 评估项 | 问题 | 评分标准 |
|:---|:---|:---:|
| **架构扩展性** | 技术架构是否支撑规模化？ | 脆弱1分，强5分 |
| **性能瓶颈** | 规模化后性能是否稳定？ | 瓶颈多1分，无瓶颈5分 |
| **技术债务** | 技术债务是否影响规模化？ | 严重1分，少5分 |
| **运维复杂度** | 规模化后运维复杂度？ | 指数增长1分，可控5分 |
| **安全合规** | 规模化后的安全合规要求？ | 复杂1分，简单5分 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **忽视规模化评估** | 单元模型成立就盲目增长 | 先做规模化评估 |
| **单一渠道依赖** | 只有一个获客渠道 | 多元化渠道 |
| **交付瓶颈** | 规模化后交付跟不上 | 优化交付流程，提升自动化 |
| **关键人依赖** | 依赖个别关键人 | 建立体系，降低依赖 |
| **资金断裂** | 规模化需要大量资金 | 优化现金流，控制增长节奏 |
| **技术崩溃** | 规模化后技术架构崩溃 | 提前做技术架构评估 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 商业模式评估 | 技术架构设计 |
| 增长策略 | 品牌传播策略 |
| 融资准备 | 运营活动评估 |
| 产品商业化 | 纯公益项目 |

## 行动触发器

- 当单元模型成立时 → 评估可规模化
- 当规划增长时 → 检查5个维度
- 当融资时 → 展示规模化评估
- 当增长停滞时 → 定位规模化瓶颈
