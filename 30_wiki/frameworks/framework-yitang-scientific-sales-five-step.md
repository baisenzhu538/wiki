# 一堂科学销售五步法

## 一句话

科学销售 = 用数据驱动和系统方法，让销售能力从依赖个人天赋与手感，变成**可预测、可复制、可规模化**的组织能力 `[conf=0.88, source=00_inbox/销售专题/_processed/销售专题_整合笔记.md]`。

它不是教某个销售如何把单谈成，而是教团队如何持续地把单谈成。

## 五步法总图

```
┌──────────────────────────────────────────────────────────────┐
│                    一堂科学销售五步法                          │
├─────────────┬─────────────┬─────────────┬──────────┬─────────┤
│  A. 提炼卖点  │  B. 拆解过程  │  C. 推进业绩  │ D. 激励团队 │ E. 打造工具 │
│  用户分层+卖点 │  拆路径→划阶段 │  拆目标→定策略 │ 六维激励模型 │ 销售武器库 │
│   提炼      │   →配动作   │   →追过程   │          │ 六维雷达图 │
└─────────────┴─────────────┴─────────────┴──────────┴─────────┘
```

| 步骤 | 核心任务 | 解决的关键问题 | 典型产出 |
|:---|:---|:---|:---|
| **A. 提炼卖点** | 用户分层 + 卖点提炼 | 客户凭什么选我们？ | SABC 客户分级、Top3 卖点、落地话术 |
| **B. 拆解过程** | 拆解用户付费关键决策路径，设计销售动作 | 客户如何从接触到成交？ | 成交地图、里程碑、标准动作清单 |
| **C. 推进业绩** | 带领团队拆目标、抓过程、拿结果 | 如何稳定达成业绩？ | 业绩管理画布、Pipeline/Gap 分析、周会机制 |
| **D. 激励团队** | 带一个嗷嗷叫、能打仗的销售团队 | 如何让团队持续有战斗力？ | 六维激励方案、发钱设计、阶段重点 |
| **E. 打造工具** | 提炼销售工具箱，大量复制优秀销售 | 如何规模化复制 Top Sales？ | 60/75/85 分工具、话术、案例集、CRM |

五步法在销售管理中的执行顺序通常是 **A → B → C**，但 D 与 E 是贯穿始终的使能器：没有激励和工具，前三步的打法很难被复制 `[conf=0.86, source=00_inbox/销售专题/_processed/销售专题_整合笔记.md]`。

## 粗放销售六大通病

李蕊在课程中把大多数创业公司的销售状态概括为「粗放销售」，其典型症状如下 `[conf=0.88, source=00_inbox/销售专题/_processed/销售专题_整合笔记.md]`：

| 通病 | 表现 | 后果 |
|:---|:---|:---|
| **不懂科学销售** | 认为销售靠人、靠感觉、靠天赋，管理缺位 | 无法规模化，业绩随人员流动大幅波动 |
| **缺用户卖点** | 不做用户分层，卖点只写不用，销售各说各话 | 资源分散，方向错误，打动不了客户 |
| **不拆销售过程** | 只盯结果，不拆决策节点 | 过程黑盒，丢单原因不清楚，经验无法复制 |
| **不抓销售过程** | 没有目标拆解和日常跟进 | 业绩过山车，现金流不可预测 |
| **不懂激励团队** | 只会金钱激励或干脆不激励 | 团队动力不足，只挖老客户不愿拓新 |
| **没有工具箱** | 销售赤膊上阵，工具单一不迭代 | 新人成长慢，专业度不足，资产无法沉淀 |

> 判断口诀：如果你发现「招不到牛人就做不起来」「所有销售拿同样线索」「客户卡两个月不知道原因」，说明已经掉进粗放销售的陷阱。

## 与一堂五步法的关系

科学销售五步法不是一门独立发明的方法论，而是**一堂五步法在销售管理场景下的专项实例化** `[conf=0.88, source=60_feedback/diagnosis/diag_20260702_yitang-scientific-sales-methodology.md]`。

| 一堂五步法（通用） | 科学销售五步法（销售管理实例化） | 对应 KDO 卡 |
|:---|:---|:---|
| 需求分析 | 用户分层 + 卖点提炼 | [[tool-yitang-customer-segmentation-4step]] / [[tool-yitang-value-proposition-4step]] |
| 产品内核 | 把价值语言统一为可销售的卖点 | [[tool-yitang-value-proposition-4step]] |
| 商业模式 / 单元模型 | 销售过程拆解、业绩管理画布 | [[tool-yitang-sales-process-decomposition]] / [[tool-yitang-sales-performance-management]] |
| 增长策略 | 目标拆解、Pipeline 管理、周会追过程 | [[tool-yitang-sales-performance-management]] |
| 壁垒建设 | 激励体系 + 销售工具箱（组织能力沉淀） | [[framework-yitang-sales-incentive-6d]] / [[tool-yitang-sales-toolkit-radar]] |

这种实例化的意义在于：当创业者问「我的销售团队怎么管」时，可以直接调用科学销售五步法，而不必从通用五步法中重新推导销售动作。

## OPC 智能体适配

原版科学销售五步法为「带团队的管理者」设计；对一人公司（OPC）创始人，必须做以下改编 `[conf=0.85, source=60_feedback/diagnosis/diag_20260702_yitang-scientific-sales-methodology.md]`：

| 原版（团队版） | OPC 版（创始人 + AI 智能体军团） |
|:---|:---|
| 用户分层四步法 | 用户分层智能体：判断「这个客户值不值得我亲自跟」 |
| 卖点提炼四步法 | 卖点提炼智能体：针对不同客户生成差异化卖点 |
| 销售过程拆解 | 销售过程追踪智能体：追踪里程碑、卡点预警 |
| 业绩管理三步法 | 业绩预测 + 跟进编排智能体：周计划 + Gap 提醒 |
| 六维激励团队 | 替换为创始人「目标-行动-反馈」自我驱动循环 |
| 销售武器库 | 智能体提示词库 + 提案模板库 + 案例库 |
| 周会三要点 | 个人复盘 + AI 定时提醒，不再召开团队周会 |
| 拆目标到个人/团队 | 拆目标到「创始人时间块」与「AI 调用成本」 |

**OPC 落地的 MVP 建议**：先从 [[tool-opc-sales-dialogue-assistant]] 开始——一个「读对话 → 想策略 → 给话术」的对话助手，解决创始人同时聊多个客户时跟丢、跟乱、跟错节奏的问题。智能体只处理信息、生成初稿、发出提醒，**关键人际信任的建立仍必须由人完成** `[conf=0.85, source=60_feedback/diagnosis/diag_20260702_yitang-scientific-sales-methodology.md]`。

## Critique：外部质疑与内部局限

### 外部质疑

#### 质疑 1：顶级关系型销售派认为「销售本质上是信任，无法体系化」

**质疑**：家族办公室、艺术品经纪、顶级 B2B 顾问式销售中，成交高度依赖个人信誉、长期关系与现场判断，任何流程化方法都会让销售变僵硬。

**回应**：科学销售五步法的目标是**把普通人稳定提升到 60–80 分**，而不是把所有人都变成顶级销售。它承认顶级关系型销售中有不可复制的部分，但可以把可复制的部分（分层、过程、工具）沉淀下来，降低对个别天才的依赖。

#### 质疑 2：增长黑客派认为「五步法太慢，会错过窗口期」

**质疑**：销售机会稍纵即逝，强调扫描、拆解、画布的流程会拖慢执行，不如快速试错、数据驱动。

**回应**：五步法并不排斥快速试错，而是让试错更有结构。前端的用户分层和过程拆解可以减少低质量试错；后端的过程跟进和周会机制可以加速学习循环。对极小团队，可以先只做「用户分层 + 过程拆解」两个最小模块。

#### 质疑 3：行为经济学 / 销售心理学派认为「五步法忽视情绪、影响力与人际动态」

**质疑**：销售成交中，情绪共鸣、稀缺感、社会认同、谈判心理往往起决定性作用，五步法过于理性与结构化。

**回应**：五步法中的「关键动作设计」和「话术工具」预留了人际技巧的落地空间。它要求「标准化关键动作，保留灵活发挥空间」`[conf=0.85, source=00_inbox/销售专题/_processed/销售专题_整合笔记.md]`，而不是把销售变成机械执行。

### 内部局限

1. **依赖产品价值已验证**。如果产品本身没有解决真实问题，再科学的销售体系也只是加速死亡。应先用 [[framework-lean-abcd-model]] 等工具验证价值假设。
2. **建设成本不低**。用户分层、卖点提炼、过程拆解通常需要 2–4 周集中梳理，并需要持续的数据维护与工具迭代 `[conf=0.83, source=60_feedback/diagnosis/diag_20260702_yitang-scientific-sales-methodology.md]`。极小团队或现金流极紧张时，可能等不起。
3. **对冲动消费 / 极短周期销售颗粒度不足**。课程案例多集中在 To B 面销、门店零售、工业分销等中长周期场景；对直播秒杀、快消品冲动购买等决策路径极短的场景，五步法需要进一步裁剪。
4. **原版为带团队设计，直接移植 OPC 会水土不服**。激励团队、周会三要点、拆目标到个人等模块需按 OPC 版重新设计，否则会造成误导。

> **法律与合规提示**：课程中涉及的商标、合同、提成等案例仅提供公共知识扫盲，不构成法律或财务建议；最终法律结论需专业机构复核。OPC 智能体处理客户通话、聊天记录时，需符合数据隐私与合规要求。

## Synthesis

科学销售五步法在 KDO 知识库中的定位是一座「桥」：它把一堂通用方法论实例化到销售管理场景，同时反向补全了 OPC 智能体军团的落地接口。

- 与 [[yt-five-step-method-complete]]：科学销售五步法是一堂五步法在「增长 + 组织能力」环节的细化，对应需求分析、商业模式、增长策略与壁垒建设。
- 与 [[yitang-methodology-system]]：它是「一堂方法论体系」中「科学做事 + 模型 + 工具 + 刻意练习」三件套在销售域的落地。
- 与 [[framework-一堂五步法-泛产品设计]]：销售过程拆解与泛产品设计中的用户决策路径、加减法、迭代思维同构，都是在降低关键决策成本。
- 与 [[framework-yitang-channel-exploration-4step]]：渠道探索解决「线索从哪里来」，科学销售五步法解决「线索来了之后如何分层、转化、管理、复制」。
- 与 [[yt-unit-model-overview]]：业绩管理、目标拆解、Pipeline/Gap 分析最终都要落到单元模型（单销售、单客户、单订单）上，才能判断模型是否成立。
- 与 [[opc-ai-sales-agent-architecture]]：五步法的 A/B/C/D/E 五个模块可直接映射为 OPC 智能体军团，其中 [[tool-opc-sales-dialogue-assistant]] 是首个 MVP 规格卡。

> 跨域定位：本框架是 Y模型 在销售管理域的实例化，可与 [[framework-yitang-y-model-cross-domain-fusion]]、[[agent-spec-yitang-Y-model-cross-domain-coach]] 联动做跨域迁移与实事求是审查。

## 电话 / 线上 / 面谈三类触点差异

科学销售五步法中的「卖点」和「过程」需要落到具体触点才能执行。同一产品在不同触点下，客户决策成本、信息密度和信任-building 顺序并不相同 `[conf=0.84, source=00_inbox/销售专题/李蕊-科学销售方法论-口述.txt L228-L230,L266,L372]`。

| 触点 | 信息特点 | 关键决策成本 | 销售动作重心 | 典型误区 |
|:---|:---|:---|:---|:---|
| **电话** | 仅声音，无视觉辅助 | 客户在前三秒判断「你是谁、是否安全」 | 快速建立身份、降低挂断率、拿到下一步许可 | 把面谈长话术直接搬到电话 |
| **线上（微信 / 在线客服）** | 文字/图片异步，可附带资料 | 响应及时性、专业感、后续跟进便利性 | 及时回复、用资料降低理解成本、明确下一步 | 回复慢、一次性丢大量资料 |
| **面谈 / 探店** | 多感官、可演示、可观察 | 时间成本高，客户要判断「值得我来一趟吗」 | 关键决策人必须到场、用场景化体验建立信任 | 只约到非决策人、没准备演示 |

课程中的两个关键判断：

1. **复杂或需要演示的产品，必须见面**：如果产品价值无法通过电话/线上完整传递，找到关键决策人后一定要争取约见或邀请探店，不能停留在电话沟通 `[conf=0.84, source=00_inbox/销售专题/李蕊-科学销售方法论-口述.txt L228-L230]`。
2. **话术要按触点拆分，并在日会/周会中迭代**：老店/新店、线上/线下场景需要不同话术；销售在日会/周会中分享的新说法，要及时回写到话术清单 `[conf=0.83, source=00_inbox/销售专题/李蕊-科学销售方法论-口述.txt L266]`。

> 经验提示：线上咨询的「响应及时性」常被低估——课程案例中把「线上咨询服务是否及时」列为用户决策的关键节点，因为不及时回复会中断信任建立 `[conf=0.84, source=00_inbox/销售专题/李蕊-科学销售方法论-口述.txt L372]`。

## 前三秒作为电话触点独立决策点

在「拿到线索 → 打电话」这一里程碑下，课程把「前三秒」拆为一个**独立决策点**：用户会在接通后的前三秒决定是否挂断 `[conf=0.86, source=00_inbox/销售专题/李蕊-科学销售方法论-口述.txt L800-L814]`。

**为什么需要单独管理**：
- 挂断率高会让销售受挫、转化率大幅降低；
- 前三秒不解决「你是谁、干嘛、是否安全」的顾虑，后续话术再漂亮也没有机会；
- 这是一个可量化、可训练的子动作，不是笼统的「开场白技巧」。

**管理动作**：
1. **把「降低前三秒挂断率」写入过程拆解**：让销售意识到这不是天赋，而是可以通过练习优化的能力。
2. **准备 3-5 版不被拒绝话术**：针对不同客户类型、不同线索来源设计开场白，并在团队内共享。
3. **日会/周会复盘**：分享「今天哪版开场白挂断率低」「客户前三秒的顾虑是什么」，把经验回写进话术清单。

> 延伸工具：如需具体话术模板和 A/B 测试方法，参见 [[tool-yitang-three-second-opening-scripts]]。
