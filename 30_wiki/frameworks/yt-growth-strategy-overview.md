# 增长策略总纲：从商业模式到增长飞轮

> 一堂五步法：增长不是单一动作，而是系统优化。增长飞轮 = 获客 × 激活 × 留存 × 变现 × 推荐。

## 核心框架

增长飞轮的5个环节：

```
    获客（Acquisition）
        ↓
    激活（Activation）
        ↓
    留存（Retention）
        ↓
    变现（Revenue）
        ↓
    推荐（Referral）
        ↓
    （循环）
```

## 关键洞察

### 1. 增长飞轮的每个环节

| 环节 | 核心问题 | 关键指标 |
|:---|:---|:---|
| **获客** | 用户从哪里来？ | CAC、渠道ROI |
| **激活** | 用户第一次体验到价值了吗？ | 激活率、Time to Value |
| **留存** | 用户会回来吗？ | DAU/MAU、流失率 |
| **变现** | 用户愿意付费吗？ | ARPU、LTV |
| **推荐** | 用户会推荐给别人吗？ | NPS、推荐率 |

### 2. 增长策略的3种驱动模式

| 模式 | 说明 | 适用场景 | 核心能力 |
|:---|:---|:---|:---|
| **产品驱动增长（PLG）** | 产品本身驱动增长 | SaaS、工具 | 产品体验 |
| **销售驱动增长（SLG）** | 销售团队驱动增长 | B2B、高客单价 | 销售能力 |
| **市场驱动增长（MLG）** | 市场营销驱动增长 | 品牌、平台 | 营销能力 |

### 3. 增长实验的PDCA循环

```
Plan（假设）→ Do（实验）→ Check（数据）→ Act（迭代）
```

| 步骤 | 行动 | 注意 |
|:---|:---|:---|
| **Plan** | 提出增长假设 | 假设可验证 |
| **Do** | 小规模实验 | 控制变量 |
| **Check** | 分析实验数据 | 统计显著性 |
| **Act** | 迭代或放弃 | 快速决策 |

### 4. 增长瓶颈诊断

| 瓶颈环节 | 症状 | 诊断方法 |
|:---|:---|:---|
| **获客瓶颈** | 流量少，CAC高 | 渠道分析 |
| **激活瓶颈** | 注册用户多，活跃用户少 | 激活漏斗 |
| **留存瓶颈** | 用户用完即走 | 留存曲线 |
| **变现瓶颈** | 用户不付费 | 付费漏斗 |
| **推荐瓶颈** | 用户不分享 | NPS调查 |

### 5. 增长与商业模式的协同

| 协同点 | 说明 | 错误 | 正确 |
|:---|:---|:---|:---|
| **单元模型支撑** | 增长需要健康的单元模型 | 单元模型不成立就增长 | 先验证单元模型 |
| **增长优化单元模型** | 规模效应降低成本 | 增长不考虑成本 | 增长优化LTV/CAC |
| **增长验证假设** | 增长数据验证商业模式 | 增长数据不分析 | 分析增长数据 |
| **商业模式限制增长** | 商业模式决定增长上限 | 忽视增长上限 | 评估增长边界 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **增长与商业模式脱节** | 增长快，但亏损大 | 增长服务商业模式 |
| **忽视留存** | 只获客，不留存 | 留存优先 |
| **增长不优化单元模型** | 增长但LTV/CAC不变 | 增长同时优化单元模型 |
| **忽视增长边界** | 增长超出能力边界 | 评估边界，控制增长 |
| **增长后不验证** | 增长后不分析数据 | 分析增长数据 |
| **单一增长策略** | 依赖单一渠道 | 多元化增长策略 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 增长策略设计 | 技术架构设计 |
| 商业模式与增长协同 | 品牌传播策略 |
| 增长优化 | 运营活动评估 |
| 规模化增长 | 纯公益项目 |

## 行动触发器

- 当商业模式成立时 → 设计增长策略
- 当增长时 → 优化增长飞轮每个环节
- 当增长停滞时 → 诊断瓶颈环节
- 当增长过快时 → 检查能力边界
