# 逻辑洁癖五段位：从散点堆到逻辑链的建模审美标准

> **Burn line**: 建模不是把东西堆在一起，而是让内容从散点 → 清单 → 优先级 → MECE → 逻辑链逐段升级。

Truman 在课上提出，他建模能力强的核心原因之一是"逻辑洁癖"——对低水平逻辑极度不爽。他把自己的逻辑审美分成五个段位，这也是一堂内部判断一个模型是否值得交付的标尺。

---

## 五段位模型

```
L1 散点/大坨  →  L2 清单  →  L3 优先级  →  L4 MECE  →  L5 逻辑链
（几乎不可用）   （解耦）    （有顺序）     （不重不漏）  （有推理关系）
```

### L1：散点 / 一大坨

- 所有内容揉在一起，无结构
- 几乎不可用，Truman 已经基本不看这个段位的东西

### L2：清单

- 把内容拉开展平，逐条列出
- 比 L1 好：至少解耦了
- 但长清单仍然难读、难记、难用

### L3：有优先级

- 在清单基础上分出顺序：SABC、高中低、主要矛盾
- 知道什么是重点、什么是减法
- **Truman 的合格线**：重要内容至少要做到 L3

### L4：MECE

- 不重不漏，彼此独立，完全穷尽
- 能明显感觉没丢东西，概念之间能解耦
- 一堂认为：一个相对好的体系至少要达到 MECE

### L5：逻辑链

- 不只是拆成几块，而是有内在推理关系
- 谁是头、谁是尾、谁推导出谁
- 有理想顺序和内在规律
- 一堂五步法就是典型：打乱顺序后，头不能当头，尾不能当尾

---

## 一堂内部交付标准

| 内容类型 | 最低要求 | 追求目标 |
|---|---|---|
| 核心方法 | L4 | L5 |
| 重要模型 | L4 | L5 |
| 辅助清单 | L3 | L4 |
| 一般备忘 | L2 | L3 |

Truman 说：一堂课应该 **80% 做到 L5，剩下 20% 做到 L4**。一堂几乎不交付 L3 以前的东西。

---

## 实操 checklist

1. **先检查是不是 L1**：有没有把很多东西堆成一大坨？
2. **拆成 L2 清单**：一行一个信息点，换行就有分解
3. **升级到 L3**：超过 6–7 条就分层，标出优先级
4. **推到 L4 MECE**：检查是否遗漏、是否重叠
5. **追求 L5 逻辑链**：给模块之间加上推理关系
6. **问问自己**：还能不能往右走一步？

---

## 为什么值钱

- **模型的完备性由 L4 保证**：没有 MECE，模型一定千疮百孔。
- **模型的内在规律由 L5 呈现**：没有逻辑链，就只是分类。
- **逻辑洁癖是建模之本**：如果对低水平逻辑没有不爽，就不可能做出厉害模型。
- 市场上大量书和课停留在 L1/L2（如"优秀组织的十二大原则"），没有优先级、没有逻辑、也无法判断是否遗漏。

---

## 失败模式

| 段位 | 典型错误 | 后果 |
|---|---|---|
| L1 | 一堆想法直接堆砌 | 自己看不懂，别人更看不懂 |
| L2 | 列了 20 条不分层 | 大脑处理不了，执行时丢三落四 |
| L3 | 有优先级但彼此重叠 | 判断混乱，资源错配 |
| L4 | MECE 但无顺序 | 能用，但无法指导步骤 |
| L5 | 强行构造逻辑链 | 为了复杂而复杂，反而难懂 |
