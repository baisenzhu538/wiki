# 逻辑洁癖五段位：从散点堆到逻辑链的建模审美标准

> **Burn line**: 建模不是把东西堆在一起，而是让内容从散点 → 清单 → 优先级 → MECE → 逻辑链逐段升级。

---

## 用一句话讲清楚

**逻辑洁癖**是对低水平逻辑结构极度不爽的审美习惯；**五段位模型**是把这种审美落地为建模交付标准：越重要的模型，越应该往 L4（MECE）和 L5（逻辑链）走。

---

## 核心要点

1. **逻辑洁癖是建模之本**：如果对 L1/L2 不难受、对 L3 不想继续往右推，就建不出 robust 的模型。——`src_20260614_8269ccdb#806-912`
2. **五段位是一个升级漏斗，不是五种风格**：每一级都在解决上一级未解决的结构问题。
3. **Truman 的合格线是 L3，一堂核心方法几乎不交付 L3 以前**：重要内容至少 L3，核心方法/模型至少 L4，理想状态 80% L5。——`src_20260614_8269ccdb#884-886`
4. **L4 保证完备性，L5 保证内在规律**：没有 MECE 会千疮百孔，没有逻辑链就只是分类。——`src_20260614_8269ccdb#912`
5. **市场上大量内容停在 L1/L2**：例如“优秀组织的十二大原则”，无顺序、无逻辑、无法判断是否遗漏。——`src_20260614_8269ccdb#890-894`

---

## 五段位模型

```
L1 散点/大坨  →  L2 清单  →  L3 优先级  →  L4 MECE  →  L5 逻辑链
（几乎不可用）   （解耦）    （有顺序）     （不重不漏）  （有推理关系）
```

### L1：散点 / 一大坨

- 所有内容揉在一起，无结构
- 几乎不可用，Truman 已经基本不看这个段位的东西——`src_20260614_8269ccdb#840-844`

### L2：清单

- 把内容拉开展平，逐条列出
- 比 L1 好：至少解耦了
- 但长清单仍然难读、难记、难用——`src_20260614_8269ccdb#846-848`

### L3：有优先级

- 在清单基础上分出顺序：SABC、高中低、主要矛盾
- 知道什么是重点、什么是减法
- **Truman 的合格线**：重要内容至少要做到 L3——`src_20260614_8269ccdb#848-852`

### L4：MECE

- 不重不漏，彼此独立，完全穷尽
- 能明显感觉没丢东西，概念之间能解耦
- 一堂认为：一个相对好的体系至少要达到 MECE——`src_20260614_8269ccdb#854-862`

### L5：逻辑链

- 不只是拆成几块，而是有内在推理关系
- 谁是头、谁是尾、谁推导出谁
- 有理想顺序和内在规律
- 一堂五步法就是典型：打乱顺序后，头不能当头，尾不能当尾——`src_20260614_8269ccdb#864-875`

---

## 一堂内部交付标准

| 内容类型 | 最低要求 | 追求目标 |
|---|---|---|
| 核心方法 | L4 | L5 |
| 重要模型 | L4 | L5 |
| 辅助清单 | L3 | L4 |
| 一般备忘 | L2 | L3 |

Truman 说：一堂课应该 **80% 做到 L5，剩下 20% 做到 L4**。一堂几乎不交付 L3 以前的东西。——`src_20260614_8269ccdb#884-886`

---

## 边界

| 边界 | 说明 |
|---|---|
| **并非所有内容都要 L5** | 简单备忘、日常清单做到 L2/L3 即可；方法论/核心模型才需要 L4/L5 |
| **段位之间可逐级推进** | 不要跳过 L3 直接追求 L5；先解耦、再排序、再 MECE、最后找推理关系 |
| **逻辑链 ≠ 复杂** | L5 强调内在推理关系，不是把简单事情故意做复杂 |
| **适用对象** | 主要用于判断“结构化内容”的质量；不适用于纯创意发散、头脑风暴早期阶段 |

---

## 失败模式

| 段位 | 典型错误 | 后果 |
|---|---|---|
| L1 | 一堆想法直接堆砌 | 自己看不懂，别人更看不懂 |
| L2 | 列了 20 条不分层 | 大脑处理不了，执行时丢三落四 |
| L3 | 有优先级但彼此重叠 | 判断混乱，资源错配 |
| L4 | MECE 但无顺序 | 能用，但无法指导步骤 |
| L5 | 强行构造逻辑链 | 为了复杂而复杂，反而难懂 |

---

## 行动 Checklist

1. **先检查是不是 L1**：有没有把很多东西堆成一大坨？
2. **拆成 L2 清单**：一行一个信息点，换行就有分解
3. **升级到 L3**：超过 6–7 条就分层，标出优先级
4. **推到 L4 MECE**：检查是否遗漏、是否重叠
5. **追求 L5 逻辑链**：给模块之间加上推理关系
6. **问问自己**：还能不能往右走一步？
