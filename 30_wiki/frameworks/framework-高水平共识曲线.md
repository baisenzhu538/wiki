# 高水平共识曲线

## 一句话定义

团队决策不是「越快达成共识越好」——高质量的共识需要经历**分歧→碰撞→对齐**的过程，跳过分歧直接共识 = 集体盲点 [conf=0.78, source=原图/VLM]。

## 核心机制

```
共识质量
  ↑
  │        ★ 高水平共识
  │       ╱
  │      ╱ （碰撞对齐）
  │     ╱
  │    ╱
  │   ★ 低水平共识（跳过分歧的假共识）
  │  ╱
  │ ╱
  └──────────────────→ 时间
```

**低水平共识**：团队表面同意，但各怀想法 → 执行时暴露 → 返工
**高水平共识**：充分表达分歧 → 碰撞 → 真正对齐 → 执行有力

## 操作要点

1. 决策前强制「反对者发言」——指定一个人必须提出反对观点
2. 区分「我同意这个决策」vs「我同意试试看」——后者不是真共识
3. 共识不等于全员满意——高水平共识是「我理解为什么这么定，我虽然不完全同意但我会全力执行」

## 与 X型/Y型 的关系

- X型决策习惯：独断、快速、靠直觉 → 容易达成低水平共识（因为没人敢反对）
- Y型决策习惯：数据驱动、多视角、慢决策 → 更可能达成高水平共识
