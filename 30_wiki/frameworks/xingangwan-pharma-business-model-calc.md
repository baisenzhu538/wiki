# 鑫港湾医药零售商业模型计算框架

> **用途**：为「小程序医药商城 + 实体药店 + 智慧药柜 + 诊所场地合作 + 互联网医院/HIS」模式提供一套可复用的**财务计算框架**。
>
> **与业务公式的分工**：
> - 业务公式文档 `[[xingangwan-pharma-business-formulas]]` 回答：客户怎么一步一步变成利润（转化漏斗、杠杆变量）。
> - 本文档回答：利润到底有多少、多久回本、需要多少订单/客户才能盈亏平衡。
>
> **商业模式假设**：
> - 医保药 = 流量入口（低毛利、高频、政策驱动）
> - 自费原研药/高毛利药 = 利润引擎（高毛利、患者自主选择）
>
> **使用方式**：
> 1. 用本文档理解财务模型结构、公式定义和变量含义。
> 2. 用配套 CSV/Excel 模板填入实际数据，自动计算关键指标。
> 3. 调研后由用户修正假设数据，迭代模型。

## 用一句话讲清楚

为「小程序医药商城 + 实体药店 + 智慧药柜 + 诊所场地合作 + 互联网医院/HIS」模式，提供一套从单柜单元经济到公司级平台 GMV 的可复用财务计算框架；核心判断是「医保药引流、原研药盈利、四层模型逐级汇总」。

## 核心要点

1. **双轮驱动**：医保药作为低毛利流量入口建立信任，自费原研药/高毛利药作为利润引擎；综合毛利率与原研药销售占比直接决定盈亏平衡日订单。
2. **四层模型**：L1 单柜单元经济 → L2 单店+药柜+小程序 → L3 区域复制 → L4 平台/B 端；每一层都有明确的收入、成本、毛利、回本公式。
3. **关键约束**：医保药毛利率 10%–20%、原研药毛利率 40%–60%；单柜 18 个月回本要求月净利润 ≥833 元，对应盈亏平衡日订单 1.5–3.5 单。
4. **双口径验证**：利润口径（月净利润）与现金流口径（经营现金流/现金回本周期）需同时监控，避免账面盈利但现金断裂。
5. **动态重算**：收入结构、政策报销比例、租金/审方费、规模化方式发生变化时，必须重新测算单元模型。

## 边界

| 边界 | 说明 |
|---|---|
| 财务计算框架，不是运营转化手册 | 客户如何转化、复购漏斗、杠杆变量见 `[[xingangwan-pharma-business-formulas]]`。 |
| 参考区间来自行业公开数据与桌面推演 | 具体数字需用山西实地调研、供应商报价、诊所运营数据校准。 |
| 主要适用于智慧药柜+实体药店+小程序的医药零售场景 | 纯线上电商、纯医院院内药房、DTP 药房等模式需调整模型。 |
| 未计入政策合规的全部潜在成本 | GSP、追溯码、医保飞检、处方合规等成本仅在部分科目中粗略估算。 |
| 未覆盖资本成本与税务优化 | 本框架聚焦经营层面，融资利息、税务筹划、资产证券化等未纳入。 |

## 失败模式

| 模式 | 症状 | 修复 |
|---|---|---|
| 参数照搬参考区间，未做实地校准 | 算出来盈利，落地后订单量、客单价、租金与假设差距大，导致亏损。 | 用最小可行单元（1 柜/1 店）跑 4–8 周真实数据，再回填模型。 |
| 只看利润口径，忽视现金流 | 账面月净利润为正，但库存占用、应付账款周期、医保回款账期导致现金断裂。 | 同时测算现金循环周期 CCC、DIO、DPO，设定现金流安全线。 |
| 原研药占比假设过于乐观 | 实际患者更倾向医保集采药，自费原研药订单低，综合毛利率低于 25%。 | 按保守/中性/乐观三档测算，先按保守档决策是否扩张。 |
| 政策变动未建敏感性分析 | 医保报销比例下调、集采扩围、审方费上涨，直接吃掉毛利。 | 将政策变量设为敏感性分析项，设定触发重算阈值。 |
| 区域复制前未分摊总部成本 | 单柜/单店盈利，但叠加区域总部、产品研发、品牌管理成本后整体亏损。 | L3 区域复制模型必须把总部与区域成本按柜/店分摊后再评估。 |
| 药柜与门店利润重复计算 | 区域汇总时把单柜利润和单店利润简单相加，导致虚高。 | 使用 L3 公式，先扣除单柜已在单店中计算的部分，再加回区域总部成本。 |

## 二、商业模式：医保药引流 + 原研药盈利

| 业务层 | 功能定位 | 毛利率 | 频次 | 客户价值 |

| **医保药** | 流量入口、建立信任、满足基础用药 | 10%–20% | 高（1–1.5 次/月） | 解决“可及性”和“ affordability ” |

## 三、通用财务公式

### 3.1 收入类公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **销售收入** | $S = Q \times P$ | Q = 销售数量/订单量；P = 客单价 |
| **综合销售收入** | $S_{total} = S_m + S_o + S_{other}$ | 按医保药 m、原研药 o、其他品类汇总 |
| **月销售收入** | $S_m = D \times 30 \times \bar{P}$ | D = 日均订单；$\bar{P}$ = 平均客单价 |
| **GMV** | $GMV = \sum_{订单}(商品金额 + 服务费 - 退款)$ | 平台总交易额 |
| **净销售额** | $S_{net} = GMV \times (1 - 退货率)$ | 扣除退货 |

### 3.2 成本与毛利公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **单品毛利** | $G = P - C$ | C = 单品采购成本 |
| **品类毛利率** | $g_i = \frac{P_i - C_i}{P_i} \times 100\%$ | 按品类计算 |
| **综合毛利率** | $\bar{g} = \frac{\sum_i (S_i \times g_i)}{S_{total}} \times 100\%$ | 销售额加权平均 |
| **毛利额** | $G_{total} = S_{total} \times \bar{g}$ | |
| **变动成本率** | $v = \frac{变动成本}{销售收入} \times 100\%$ | 含平台抽成、配送费、支付手续费、审方费等 |
| **边际贡献** | $MC = S - 变动成本$ | 用于覆盖固定成本 |

### 3.3 盈利与回本公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **月净利润** | $\pi_m = G_{total} - FC_m - VC_m$ | FC = 月固定成本；VC = 月变动成本 |
| **盈亏平衡销售额** | $S_{BE} = \frac{FC_m}{\bar{g} - v}$ | 月固定成本 / (毛利率 - 变动成本率) |
| **盈亏平衡订单量** | $Q_{BE} = \frac{S_{BE}}{\bar{P}}$ | |
| **回本周期（月）** | $PB_m = \frac{I}{\pi_m}$ | I = 初始投资；$\pi_m$ = 月净利润 |
| **年化投资回报率** | $ROI = \frac{\pi_m \times 12}{I} \times 100\%$ | |
| **坪效** | $E_s = \frac{S_m}{A}$ | A = 经营面积（㎡） |
| **人效** | $E_h = \frac{S_m}{N}$ | N = 员工数 |

### 3.4 现金流公式

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| **月经营现金流** | $CF_m = \pi_m + D_m - \Delta W$ | $D_m$ = 折旧摊销；$\Delta W$ = 营运资金变动 |
| **现金回本周期** | $PB_{cf} = \frac{I}{CF_m}$ | 考虑非现金支出后的回本速度 |
| **库存周转天数** | $DIO = \frac{平均库存}{月销售成本} \times 30$ | |
| **应付账款周转天数** | $DPO = \frac{平均应付账款}{月采购成本} \times 30$ | |
| **现金循环周期** | $CCC = DIO + DSO - DPO$ | DSO = 应收账款周转天数 |

## 四、L1：单柜单元经济模型

### 4.1 变量定义

#### 4.1.1 投入与固定成本

| 变量 | 符号 | 单位 | 参考范围 | 说明 |
|:---|:---:|:---:|:---|:---|
| 硬件投资 | $I_c$ | 元 | 10,000–25,000 | 智慧药柜设备、安装、调试 |
| 设计回本周期 | $T_c$ | 月 | 12–24 | 用户目标：18 个月 |
| 月硬件摊销 | $D_c$ | 元/月 | $I_c / T_c$ | |
| 月场地租金 | $R_c$ | 元/月 | 300–1,500 | 诊所场地费 |
| 月平台费 | $F_p$ | 元/月 | 100–500 | 互联网医院/审方平台年费摊销 |
| 月电费网费 | $F_u$ | 元/月 | 100–300 | |
| 月维护人工 | $F_m$ | 元/月 | 300–1,000 | 补货、巡检、清洁 |
| 单张审方费 | $f_r$ | 元/张 | 1–5 | 远程执业药师审方 |
| 损耗率 | $l$ | % | 1%–3% | 过期、破损、盗损 |
| 支付手续费率 | $f_p$ | % | 0.6%–1.0% | 微信支付/支付宝/医保支付 |

#### 4.1.2 医保药收入参数

| 变量 | 符号 | 单位 | 参考范围 | 说明 |
|:---|:---:|:---:|:---|:---|
| 医保药日均订单 | $D_m$ | 单/天 | 1–5 | |
| 医保药客单价 | $\bar{P}_m$ | 元 | 80–150 | 集采/医保定价 |
| 医保药毛利率 | $g_m$ | % | 10%–20% | 受集采和医保限价影响 |
| 医保药复购频次 | $N_m$ | 次/月 | 1.0–1.5 | 慢病月度用药 |

#### 4.1.3 原研药收入参数

| 变量 | 符号 | 单位 | 参考范围 | 说明 |
|:---|:---:|:---:|:---|:---|
| 原研药日均订单 | $D_o$ | 单/天 | 0.3–1.5 | |
| 原研药客单价 | $\bar{P}_o$ | 元 | 200–500 | 自费高毛利药 |
| 原研药毛利率 | $g_o$ | % | 40%–60% | 取决于采购渠道和谈判 |
| 原研药复购频次 | $N_o$ | 次/月 | 0.5–1.0 | |

### 4.2 核心公式

**月固定成本**：
$$FC_c = D_c + R_c + F_p + F_u + F_m$$

**月销售收入**：
$$S_c = (D_m \times 30 \times \bar{P}_m \times N_m) + (D_o \times 30 \times \bar{P}_o \times N_o)$$

**月销售毛利额**：
$$G_c = (D_m \times 30 \times \bar{P}_m \times N_m \times g_m) + (D_o \times 30 \times \bar{P}_o \times N_o \times g_o)$$

**综合毛利率**：
$$\bar{g}_c = \frac{G_c}{S_c}$$

**月变动成本**：
$$VC_c = S_c \times (l + f_p) + Q_c \times f_r$$
其中 $Q_c$ = 月总订单量 = $D_m \times 30 + D_o \times 30$。

**月净利润**：
$$\pi_c = G_c - FC_c - VC_c$$

**回本周期**：
$$PB_c = \frac{I_c}{\pi_c}$$

**盈亏平衡日订单**：
$$D_{BE} = \frac{FC_c}{30 \times (\bar{P}_{avg} \times \bar{g}_c - \bar{P}_{avg} \times (l + f_p) - f_r)}$$
其中 $\bar{P}_{avg}$ 为加权平均客单价。

### 4.3 单柜业务公式

**活跃客户数**：
$$N_a = D_m \times 30 + D_o \times 30$$
（假设活跃客户每月至少购买 1 次）

**复购驱动的客户终身价值（药柜场景）**：
$$LTV_c = \bar{P}_{avg} \times \bar{g}_c \times \frac{生命周期月数}{复购周期月数}$$

**获客成本上限**：
$$CAC_{max} = LTV_c \times \frac{1}{LTV/CAC\text{ 目标比}}$$
通常 LTV/CAC ≥ 3，故 $CAC_{max} = LTV_c / 3$

### 4.4 单柜敏感性矩阵

基于：硬件 1.5 万、18 个月回本、月运营成本 2,400 元、医保药毛利率 15%、原研药毛利率 50%、原研药客单价 300 元。

| 综合毛利率 | 医保药客单价 100 元 | 医保药客单价 120 元 | 医保药客单价 150 元 |
|:---:|---:|---:|---:|
| **20%** | 日订单 3.59 | 日订单 3.07 | 日订单 2.55 |
| **25%** | 日订单 2.87 | 日订单 2.46 | 日订单 2.04 |
| **30%** | 日订单 2.40 | 日订单 2.05 | 日订单 1.70 |
| **35%** | 日订单 2.05 | 日订单 1.75 | 日订单 1.46 |
| **40%** | 日订单 1.80 | 日订单 1.54 | 日订单 1.28 |

> 注：原研药销售占比越高，综合毛利率越高，盈亏平衡日订单越低。

## 五、L2：单店 + 药柜 + 小程序模型

### 5.1 收入结构

| 渠道 | 收入占比参考 | 毛利率参考 | 说明 |
|:---|---:|---:|:---|
| 门店自然客流 | 30%–50% | 25%–35% | 传统药店业务 |
| 诊所导流药柜 | 20%–40% | 25%–40% | 医保药 + 原研药组合 |
| 小程序私域 | 15%–30% | 40%–60% | 会员复购、高毛利品类 |
| O2O 平台 | 10%–25% | 15%–25% | 美团/饿了么/京东秒送 |
| 企业/B 端订单 | 5%–15% | 30%–50% | 公共卫生项目、企业健康 |

**单店月销售收入**：
$$S_s = S_{store} + S_{cabinet} + S_{miniapp} + S_{o2o} + S_{b2b}$$

**单店综合毛利率**：
$$\bar{g}_s = \frac{S_{store}g_{store} + S_{cabinet}g_{cabinet} + S_{miniapp}g_{miniapp} + S_{o2o}g_{o2o} + S_{b2b}g_{b2b}}{S_s}$$

### 5.2 成本结构

**固定成本**：
$$FC_s = R_{store} + S_{staff} + D_{assets} + F_{system} + F_{license}$$

| 项目 | 参考金额/占比 | 说明 |
|:---|:---|:---|
| 门店租金 $R_{store}$ | 5,000–20,000 元/月 | 视城市/地段 |
| 人员工资 $S_{staff}$ | 8,000–25,000 元/月 | 店长、药师、店员 |
| 资产折旧 $D_{assets}$ | 1,000–3,000 元/月 | 药柜、装修、设备 |
| 系统费用 $F_{system}$ | 500–2,000 元/月 | ERP、小程序、审方平台 |
| 合规/证照 $F_{license}$ | 摊销后 500–1,500 元/月 | 医保、GSP、追溯码等 |

**变动成本**：
$$VC_s = S_s \times v_s$$

| 项目 | 参考费率 | 说明 |
|:---|---:|:---|
| 药品采购成本 | 已计入毛利公式 | 按品类分别计算 |
| O2O 平台抽成 | 5%–10% | 美团/饿了么佣金 |
| 配送费 | 3–6 元/单 | 或按 GMV 2%–4% |
| 支付手续费 | 0.6%–1.0% | |
| 营销/优惠券 | 2%–5% | 私域拉新、复购激励 |
| 损耗 | 1%–3% | |

### 5.3 单店盈利公式

**月毛利额**：
$$G_s = S_s \times \bar{g}_s$$

**月净利润**：
$$\pi_s = G_s - FC_s - VC_s$$

**单店回本周期**：
$$PB_s = \frac{I_{store}}{\pi_s}$$
其中 $I_{store}$ = 单店初始投资（装修 + 首批货 + 药柜 + 系统 + 押金）。

## 六、L3：区域复制模型

### 6.1 变量定义

| 变量 | 符号 | 说明 |
|:---|:---:|:---|
| 城市数量 | $N_{city}$ | |
| 每城药店数 | $N_{store/city}$ | |
| 每店药柜数 | $N_{cabinet/store}$ | |
| 单柜月净利润 | $\pi_c$ | |
| 单店月净利润 | $\pi_s$ | |
| 区域总部月成本 | $FC_{region}$ | 区域运营、BD、培训、仓储 |
| 总部月成本 | $FC_{hq}$ | 产品研发、品牌、管理 |

### 6.2 核心公式

**区域总药柜数**：
$$N_c = N_{city} \times N_{store/city} \times N_{cabinet/store}$$

**区域总门店数**：
$$N_s = N_{city} \times N_{store/city}$$

**区域月净利润**：
$$\pi_{region} = N_c \times \pi_c + N_s \times (\pi_s - N_{cabinet/store} \times \pi_c) - FC_{region}$$
（避免重复计算药柜利润）

**公司整体月净利润**：
$$\pi_{total} = \sum_{region} \pi_{region} - FC_{hq}$$

### 6.3 规模化经济公式

**边际成本递减**：
$$MC_n = MC_1 \times n^{-\alpha}$$
其中 $\alpha$ = 学习曲线系数（通常 0.05–0.15），n = 累计铺设数量。

**总部成本分摊**：
$$FC_{hq/unit} = \frac{FC_{hq}}{N_c + N_s}$$

**区域盈亏平衡柜数**：
$$N_{BE} = \frac{FC_{region}}{\pi_c \times N_{cabinet/store} + (\pi_s - \pi_c \times N_{cabinet/store})}$$

### 7.2 平台经济公式

**总 GMV**：
$$GMV_{total} = \sum_{all}(S_{c2c} + S_{b2b} + S_{b2c})$$

$$S_{platform} = GMV_{total} \times t + S_{subscription} + S_{service}$$
其中 t = 平台佣金率。

**平台毛利率**：
$$g_{platform} = \frac{S_{platform} - C_{platform}}{S_{platform}}$$
平台成本主要是技术、运营、客服，毛利率通常 60%–80%。

## 八、客户与经济公式

### 8.1 客户终身价值（LTV）

**基础 LTV 公式**：
$$LTV = \bar{P} \times \bar{g} \times \frac{1}{1 - r} - CAC$$
其中 $r$ = 月留存率，$\frac{1}{1-r}$ = 客户生命周期月数。

**更精确的 LTV**：
$$LTV = \sum_{t=1}^{T} \frac{\bar{P} \times \bar{g} \times r^{t-1}}{(1 + d)^t} - CAC$$
其中 $d$ = 月折现率，$T$ = 最大生命周期。

### 8.2 获客成本（CAC）

**CAC 公式**：
$$CAC = \frac{总营销获客投入}{新增首单客户数}$$

**按渠道拆分**：
$$CAC_{channel} = \frac{ChannelSpend_i}{NewCustomers_i}$$

**CAC 回收周期**：
$$PB_{CAC} = \frac{CAC}{\bar{P} \times \bar{g}}$$

### 8.3 LTV/CAC 比

$$\frac{LTV}{CAC} \geq 3 \text{（健康业务基准）}$$

若 LTV/CAC < 3，需：

## 十、库存与供应链公式

### 10.1 库存周转

**库存周转率**：
$$ITR = \frac{月销售成本}{平均库存}$$

**库存周转天数**：
$$DIO = \frac{30}{ITR}$$

**安全库存**：
$$SS = Z \times \sigma_d \times \sqrt{LT}$$
其中 $Z$ = 服务水平系数，$\sigma_d$ = 日需求标准差，$LT$ = 补货提前期。

### 10.2 采购与应付

**采购成本**：
$$C_p = S \times (1 - \bar{g})$$

**应付账款周转天数**：
$$DPO = \frac{平均应付账款}{月采购成本} \times 30$$

**现金循环周期**：
$$CCC = DIO + DSO - DPO$$

## 十二、使用示例：单柜 18 个月回本测算

### 12.1 输入假设

| 变量 | 值 |
|:---|---:|
| 硬件投资 $I_c$ | 15,000 元 |
| 目标回本周期 $T_c$ | 18 月 |
| 月场地租金 $R_c$ | 800 元 |
| 月平台费 $F_p$ | 200 元 |
| 月电费网费 $F_u$ | 150 元 |
| 月维护人工 $F_m$ | 600 元 |
| 单张审方费 $f_r$ | 3 元 |
| 损耗率 $l$ | 2% |
| 支付手续费率 $f_p$ | 0.6% |
| 医保药日均订单 $D_m$ | 1.5 单 |
| 医保药客单价 $\bar{P}_m$ | 120 元 |
| 医保药毛利率 $g_m$ | 15% |
| 医保药复购频次 $N_m$ | 1.0 次 |
| 原研药日均订单 $D_o$ | 0.5 单 |
| 原研药客单价 $\bar{P}_o$ | 300 元 |
| 原研药毛利率 $g_o$ | 50% |
| 原研药复购频次 $N_o$ | 0.8 次 |

### 12.2 计算过程

**月固定成本**：
$$FC_c = 833 + 800 + 200 + 150 + 600 = 2,583 \text{ 元}$$

**月销售收入**：
$$S_c = (1.5 \times 30 \times 120 \times 1.0) + (0.5 \times 30 \times 300 \times 0.8)$$
$$S_c = 5,400 + 3,600 = 9,000 \text{ 元}$$

**月销售毛利额**：
$$G_c = (5,400 \times 15\%) + (3,600 \times 50\%)$$
$$G_c = 810 + 1,800 = 2,610 \text{ 元}$$

**综合毛利率**：
$$\bar{g}_c = \frac{2,610}{9,000} = 29.0\%$$

**月变动成本**：
$$VC_c = 9,000 \times (2\% + 0.6\%) + (1.5 + 0.5) \times 30 \times 3$$
$$VC_c = 234 + 180 = 414 \text{ 元}$$

**月净利润**：
$$\pi_c = 2,610 - 2,583 - 414 = -387 \text{ 元}$$

> **结论**：在当前假设下，单柜尚未盈利。需要将原研药日均订单从 0.5 单提升至约 0.9 单，或提升原研药毛利率/客单价，才能实现 18 个月回本。

### 12.3 盈亏平衡分析

要实现 18 个月回本，月净利润需达到 833 元：

$$\pi_c^{target} = \frac{15,000}{18} = 833 \text{ 元}$$

所需月销售毛利：
$$G_c^{target} = FC_c + VC_c + \pi_c^{target}$$

假设变动成本率不变，反推所需月销售收入：
$$S_c^{target} = \frac{FC_c + \pi_c^{target}}{\bar{g}_c - (l + f_p) - \frac{Q \times f_r}{S}}$$

代入后，目标月销售收入约为 12,000–13,000 元，对应：
- src_unknown
- src_unknown日均订单：约 0.9 单（从 0.5 单提升）

或：
- src_unknown毛利率从 50% 提升至 60%，同时原研药日均订单 0.7 单
