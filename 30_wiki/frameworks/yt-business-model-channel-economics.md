# 渠道经济学：获客成本优化

> 一堂五步法：获客渠道不是越多越好，而是需要优化组合。理解每个渠道的CAC、LTV、可规模化，才能优化获客成本。

## 核心框架

渠道评估矩阵：

```
        高LTV
           │
    优先   │   优化
    扩大   │   效率
           │
低CAC ─────┼───── 高CAC
           │
    测试   │   放弃
    新渠道 │   或优化
           │
        低LTV
```

## 关键洞察

### 1. 常见获客渠道

| 渠道 | CAC | LTV | 可规模化 | 适用阶段 |
|:---|:---|:---|:---:|:---|
| **付费广告** | 高 | 中 | 中 | 增长期 |
| **SEO/内容** | 低 | 高 | 高 | 验证期+ |
| **口碑推荐** | 低 | 高 | 中 | 验证期+ |
| **销售团队** | 高 | 高 | 中 | 增长期 |
| **合作伙伴** | 中 | 中 | 中 | 增长期 |
| **病毒传播** | 低 | 中 | 高 | 验证期 |
| **线下活动** | 高 | 高 | 低 | 企业级 |
| **PR/品牌** | 中 | 中 | 低 | 成熟期 |

### 2. 渠道优化方法

| 方法 | 说明 | 效果 |
|:---|:---|:---|
| **A/B测试** | 测试不同渠道策略 | 找到最优策略 |
| **归因分析** | 分析用户触达渠道 | 优化渠道组合 |
| **漏斗优化** | 优化每个渠道的转化漏斗 | 提升转化率 |
| **渠道组合** | 组合多个渠道 | 降低整体CAC |
| **自然获客提升** | 提升口碑、SEO | 降低付费依赖 |

### 3. 渠道组合策略

| 阶段 | 推荐渠道组合 | 说明 |
|:---|:---|:---|
| **验证期** | SEO+口碑+病毒 | 低成本验证 |
| **增长期** | 付费广告+销售+内容 | 规模化增长 |
| **成熟期** | 品牌+口碑+合作伙伴 | 降低CAC |
| **扩张期** | 全渠道 | 多元化 |

### 4. 渠道之间的协同

| 协同类型 | 说明 | 示例 |
|:---|:---|:---|
| **内容→广告** | 内容提升广告效果 | 内容营销提升广告转化率 |
| **广告→口碑** | 广告带来用户，用户口碑传播 | 广告获客，口碑留存 |
| **销售→内容** | 销售反馈内容需求 | 销售洞察指导内容创作 |
| **口碑→SEO** | 口碑提升品牌搜索 | 品牌词搜索提升 |

### 5. 渠道 cannibalization

| 情况 | 说明 | 处理 |
|:---|:---|:---|
| **付费广告 cannibalize 自然搜索** | 用户本来会自然搜索，被广告拦截 | 减少品牌词广告 |
| **新渠道 cannibalize 老渠道** | 新渠道抢了老渠道用户 | 区分渠道定位 |
| **折扣渠道 cannibalize 正价渠道** | 折扣渠道影响正价销售 | 控制折扣渠道 |

## 失败模式

| 失败模式 | 症状 | 修复方法 |
|:---|:---|:---|
| **单一渠道依赖** | 只有一个渠道 | 多元化渠道 |
| **忽视自然获客** | 付费获客占比过高 | 提升自然获客 |
| **渠道测试不充分** | 新渠道测试失败就放弃 | 充分测试，优化变量 |
| **渠道之间不协调** | 渠道互相竞争 | 协调渠道策略 |
| **忽视渠道LTV差异** | 只看CAC，不看LTV | 综合评估CAC和LTV |
| **渠道不可规模化** | 渠道达到上限 | 寻找新渠道 |

## 适用边界

| 适用场景 | 不适用场景 |
|:---|:---|
| 获客策略 | 技术架构设计 |
| 增长优化 | 品牌传播策略 |
| 渠道选择 | 运营活动评估 |
| 获客成本优化 | 纯公益项目 |
