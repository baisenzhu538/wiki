# 业务公式定性参数行为化指标库

> 业务公式拆到 L3-L4 时，会出现大量定性参数（如信任度、满意度、使用深度）。这些参数如果停留在“我觉得很高”，就只是主观判断。必须把它们拆成**可定量的行为指标**，才能提出可验证的假设。来源：一堂 2026-06-13 业务公式拆解培训（孔阳）。



## 核心原则

1. **每个定性参数必须对应 3-5 个行为指标**
2. **每个行为指标都能直接关联到一个具体动作**
3. **尽量给出健康阈值，便于判断当前水平**
4. **指标要分层：L3 是可行动的抓手，L4 是定性参数的行为佐证**

---

## 指标速查表

### 1. 信任度（ToC 电商 / 私域电商 / 内容付费）

| 行为指标 | 健康阈值参考 | 对应动作 |
|---|---|---|
| 详情页停留时长 | >3 分钟 | 优化详情页结构与内容密度 |
| 详情页下滑完成率 | >80% | 调整图文节奏，关键信息前置 |
| 用户评价区停留时长 | >30 秒 | 补充真实用户证言与使用场景 |
| 试听课完课率 | >70% | 优化试听课内容结构与节奏 |
| 咨询会话发起率 | >15% | 增加咨询入口，降低提问门槛 |
| 真实用户证言曝光率 | — | 晒单、好评截图、案例展示 |
| 专业资质展示触达率 | — | 检测报告、专家背书、售后承诺 |

**来源案例**：[[case-private-domain-ecommerce-formula]]

### 2. 使用深度（ToB SaaS / 企业培训）

| 行为指标 | 健康阈值参考 | 对应动作 |
|---|---|---|
| 月活账号率 | 月活账号数 / 总账号数 | 推动关键角色激活 |
| 核心功能使用率 | >50% | 找到“最小可用功能”，帮客户先用起来 |
| 关键角色参与度 | 管理员 / HR / 员工分层看 | 针对性培训和提醒 |
| 周活跃天数 | >3 天 | 设计使用触发和习惯养成机制 |
| 功能覆盖率 | — | 识别未使用但高价值的功能 |
| 场景渗透率 | — | 把产品嵌入客户日常工作流 |

**来源案例**：[[case-saas-renewal-formula]]

| 培训效果可量化比例 | — | 把学习结果与业务指标挂钩 |

### 10. 课程匹配度（在线教育 / 知识付费）

```
课程匹配度 = 需求识别准确度 × 内容匹配度 × 讲师匹配度

需求识别准确度 = 痛点共鸣 × 方案可行 × 预期收益明确
```

| 行为指标 | 健康阈值参考 | 对应动作 |
|---|---|---|
| 痛点共鸣率 | — | 优化课程介绍中的痛点描述 |
| 方案可行认可度 | — | 展示可落地的步骤和工具 |
| 预期收益明确度 | — | 用前后对比数据呈现学习收益 |
| 试听课到正课转化率 | — | 验证课程匹配度是否足够 |

## 使用步骤

1. **识别定性参数**：在 L3-L4 拆解中找到无法直接测量的参数。
2. **选择对应指标库**：根据业务类型从表中挑选指标。
3. **设定健康阈值**：结合行业基准、历史数据或合理假设。
4. **设计改进动作**：每个指标低，都对应一个可执行的优化动作。
5. **建立数据埋点**：确保指标可被持续追踪，形成反馈闭环。
