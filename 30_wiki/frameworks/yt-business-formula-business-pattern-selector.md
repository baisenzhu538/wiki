# 业务公式商业模式选型框架：单次成交型 vs 持续复购型

> 一堂业务公式拆解培训中的“前置选型器”：不要一上来就拆 `GMV = 流量 × 转化 × 客单价 × 复购`，而应先判断业务是**单次成交型**还是**持续复购型**，再选择对应的公式范式。来源：一堂 2026-06-13 业务公式拆解培训（孔阳）。

---

## 核心判断

业务公式失效的常见原因不是变量拆得不够细，而是**选错了公式范式**。同一个变量在不同商业模式里的因果关系完全不同。

| 维度 | 单次成交型 | 持续复购型 |
|---|---|---|
| **决策特征** | 客户单次决策即完成闭环 | 单次成交只是长期关系的起点 |
| **价值来源** | 把每个潜在客户高效转化为成交 | 把客户生命周期价值做深做长 |
| **核心矛盾** | 触达 → 成交的转化链路 | 留存、复购、切换成本 |
| **典型行业** | 房产、汽车、装修、口腔初诊、B2B 大单 | SaaS 订阅、私域电商、会员服务、企业咨询、线下餐饮、健身 |
| **常见错误** | 忽视转化漏斗，上来就放量 | 用销售思维推续费，客户根本没用起来 |

---

## 与十大业务公式范式的对应关系

### 单次成交型优先使用的范式

| 范式 | 适用场景 | 关键问题 |
|---|---|---|
| **流量变现型** | 电商、内容付费 | 哪个环节是短板？ |
| **线索转化型** | B2B 销售、房产、汽车、企服 | 漏斗哪一层流失最严重？ |
| **门店收入型** | 零售、餐饮、诊所、药店 | 选址/门头/转化哪个是瓶颈？ |
| **连续动作型** | 需要多步转化的成交链路 | 动作链是否连续？中断点在哪？ |
| **动作节点型** | 线下培训、训练营、强运营型成交 | 哪个节点流失最多？ |

### 持续复购型优先使用的范式

| 范式 | 适用场景 | 关键问题 |
|---|---|---|
| **脱离成本型** | 防止客户流失到竞品 | 壁垒由哪些因素叠加？ |
| **类脱离成本型** | 构建信任、满意度 | 多维度信任背书是否补齐？ |
| **连续留存型** | APP、SaaS、订阅服务 | 留存曲线在哪断崖？ |
| **留存节点型** | 在线教育、训练营、知识付费 | 关键行为里程碑是什么？ |
| **用户周期型** | 订阅制、会员制、社群 | 生命周期哪个阶段是杠杆？ |

---

## 三步选型法

1. **看客户关系深度**：客户是一次性买单，还是持续反复买单？
2. **看增长杠杆来源**：增长主要靠新客户成交，还是老客户复购/续费？
3. **看当前核心瓶颈**：是“卖不出去”（转化问题），还是“留不住”（留存问题）？

选型结果决定你先从哪类公式范式开始拆：

```
单次成交型  →  先拆收入提升类 + 连续动作/动作节点型
持续复购型  →  先拆竞争提升类 + 连续留存/留存节点型
```

## 案例对照

| 案例 | 业务类型 | 错误做法 | 正确做法 |
|---|---|---|---|
| ToC 消费品电商 | 单次成交型为主 | 追加投放，忽视转化率低于行业基准 | 先拆转化漏斗，优化落地页与复购体验 |
| 私域电商 10W 人社群 | 持续复购型 | 拉新+发广告，认为人不够多 | 补信任背书 + 设计用户升级路径 |
| ToB 企业培训 SaaS | 持续复购型 | 续费期打电话送课程 | 提升使用深度、价值感知、切换成本 |
| 连锁口腔诊所 | 单次成交 & 长周期复购 | 投广告+打折 | 构建危机感知体系，推动长期健康管理 |

## Constraints & Boundaries

### 适用边界

| 边界 | 说明 |
|:-----|:------|
| ✅ 业务已有可区分的首单与复购数据 | 能判断收入结构，否则无法识别真实瓶颈 |
| ✅ 商业模式基本确定，非方向探索期 | 创新型业务无现成范式，需先用假设推断再验证 |
| ✅ 同一业务可按“单次成交段”与“持续复购段”切分 | 混合业务必须分别建模，不能混在一起 |
| ✅ 团队接受“不同业务类型用不同公式范式” | 如果团队坚持用一组 GMV 公式解释所有业务，本框架无法落地 |
| ❌ 业务处于 PMF 之前 | 核心变量未定，强行选型会制造虚假确定性 |
| ❌ 数据无法区分首购与复购贡献 | 分不开两段收入，就无法判断是转化问题还是留存问题 |

### 常见失败模式

| 模式 | 症状 | 修复 |
|:-----|:------|:-----|
| **把持续复购型当单次成交型做** | 续费率/复购率低，团队靠电话催费、打折促销、送功能续命 | 转向客户成功导向：先拆 `活跃客户续费率 = 使用深度 × 价值感知 × 切换成本`，建立 7天激活/30天关键功能使用/季度价值报告等数据节点 |
| **把单次成交型当持续复购型做** | 一次性决策业务过度运营用户生命周期，拉新 ROI 被复购运营成本稀释 | 聚焦转化链路：用连续动作型/动作节点型公式把访问→成交的断点找出来，停止无效的生命周期运营 |
| **混合业务只建一个总公式** | 总 GMV 拆完后找不到抓手，不同团队互相甩锅 | 按首单收入/复购收入分层，分别建立公式；口腔、健身等业务需把初诊/首购与长期健康管理/续卡拆开 |
| **上来就拆总 GMV，不先做类型判断** | 公式完整但落地时不知道优化哪个变量 | 先用“三步选型法”判断业务类型，再选择对应公式范式；禁止未分类直接拆 `GMV = 流量×转化×客单价×复购` |
| **停在 L1-L2，忽视 L3-L4 行为参数** | 团队讨论“流量不够/转化率低”但无具体动作 | 把每个变量拆到 3-5 个行为化指标，对应具体触点（如“危机感知度”=影像读片完成率×对比展示执行率×紧迫感确认率） |

## 落地模板：选型错配诊断表

遇到业务公式拆解失效时，先用下表做一轮“选型体检”，再决定拆哪类公式。

| 检查项 | 单次成交型特征 | 持续复购型特征 | 当前业务证据 |
|:-----|:------|:------|:------|
| 客户关系深度 | 一次决策即闭环 | 成交只是关系起点 | |
| 增长杠杆来源 | 主要靠新客成交 | 主要靠老客复购/续费 | |
| 当前核心瓶颈 | “卖不出去”——转化链路断点 | “留不住”——使用/留存/切换成本 | |
| 常用错误动作 | 追加投放、打折促销 | 电话催费、送功能、群发广告 | |
| 优先公式范式 | 收入提升类 + 连续动作/动作节点型 | 竞争提升类 + 连续留存/留存节点型 | |

### 计算示例：ToB 企业培训 SaaS 的续费率修复

假设一家企业培训 SaaS 年 GMV 2000 万，续费率 50%，竞品 80%。

**错误做法（单次成交思维）**：
- 续费期加大电话触达、多送课程
- 预期提升：续费率从 50% → 55%（效果有限，因为客户根本没用起来）

**正确做法（持续复购思维）**：
1. 拆分收入结构：`续费收入 = 活跃客户续费(70%) + 沉睡客户唤醒(20%) + 流失客户挽回(10%)`
2. 锁定核心矛盾：客户使用深度不够——30 天关键功能使用率仅 40%
3. 建立行为指标：7 天激活率、30 天关键功能使用率、季度培训报告送达率
4. 估算提升空间：若 30 天关键功能使用率从 40% 提升到 70%，按 `活跃客户续费率 = 使用深度 × 价值感知 × 切换成本` 估算，续费率可从 50% 提升至 75% 左右
