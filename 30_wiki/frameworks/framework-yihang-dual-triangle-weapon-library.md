# 一行双三角六要素武器库

> **一句话定义**：把「一行双三角」的六个要素各拆成「自我修养 → 基础 → 进阶 → 高阶」四级，形成一张 6×4 的竞争力段位矩阵。它回答了「我现在在哪一级、下一级该练什么」。

---

## 一、矩阵总览

| 要素 | 自我修养 | 基础 | 进阶 | 高阶 |
|:---|:---|:---|:---|:---|
| **审美** | 重视审美、训练审美、无底追求 | 有感觉、有案例、粗打分 | 有定量、有精度、正负表、校准法 | 有超越、有引领、有迁移 |
| **体系** | 准确定义、完备 MECE、科学工作流 | 工作流/清单 | 矩阵图/N 步法/武器库 | 稀缺工作流/稀缺方法论 |
| **创造力** | 解放思想、分层自洽、敢于想象 | 大胆设想、灵感闪现 | 第一性原理、分层自洽、辩证思维 | 大胆设想+底层自洽+假设试错+模型重构 |
| **场景** | 强敏感性、大胆假设、细分场景 | 需求捕捉、大胆假设、STAR 模型 | AI 匹配、ROI 评估、定义边界 | 创新场景、持续发现 |
| **基本功** | 不迷信、不排斥、刻意练习 | 提示词工程、口喷提示词 | 封装提示词/自动化/多工具创造 | 模型微调/训练、多 Agent 编排、自进化 |
| **数据** | 数据敏感、资产思维、复利思维 | 正面/负面案例 | 多样性数据（结构化/非结构化，结果/过程/错误数据） | 10 年尺度数据飞轮 |

## 二、人类三角详细展开

### 2.1 审美（Judgment / Taste）

> 对结果质量的高水平判断力。**不是品味，而是可以打分、可以有维度、可以有正反清单的判断系统。**

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 重视审美、训练审美、无底追求 | 主动收藏 Top 案例，愿意为好标准花时间 |
| **基础** | 有感觉、有案例、粗打分 | 能用 20/40/60/80/99 给结果快速定档 |
| **进阶** | 有定量、有精度、正负表、校准法 | 能建雷达图、加权打分；能用样稿校准 AI |
| **高阶** | 有超越、有引领、有迁移 | 能基于最佳实践再突破；能跨领域借鉴审美 |

**关键动作**：
- 每周收集 3-5 个本领域的 Top 案例
- 把「感觉好」翻译成 3-5 个可评估维度
- 用 AI 生成多个版本，做 A/B 对比校准
- 把每次反馈从「好/不好」升级成「维度打分」

**暗知识**：很多团队协作卡在 L2 审美（有感觉、有粗判），迟迟到不了 L3（有维度、有校准法）。这不是因为没品味，而是因为**没有把审美判断结构化、可复用化**。

### 2.2 体系（System / Framework）

> 解决一类问题的成熟、稳定的思考与执行框架。

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 准确定义、完备 MECE、科学工作流 | 开会前先把概念定义对齐 |
| **基础** | 工作流/清单 | 把重复做的事写成 SOP 和检查清单 |
| **进阶** | 矩阵图/N 步法/武器库 | 能用二维矩阵、漏斗、金字塔等模型拆解复杂问题 |
| **高阶** | 稀缺工作流/稀缺方法论 | 能构建「本质-方法-技巧-案例」的完整行业稀缺方法论 |

**关键动作**：
- 把做过 3 次以上的事写成 SOP
- 每次做年度规划/战略汇报前先做 MECE 拆解
- 把自己的成功方法论显性化：背景→原则→步骤→适用边界

### 2.3 创造力（Creativity / Hypothesis）

> 敢于跳出原有经验和惯例，提出新解法、新设想。

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 解放思想、分层自洽、敢于想象 | 不急着否定看似荒诞的想法 |
| **基础** | 大胆设想、灵感闪现 | 能针对一个问题提出 3 个以上不同方向 |
| **进阶** | 第一性原理、分层自洽、辩证思维 | 能追问本质，找到规律的矛盾和更优解 |
| **高阶** | 大胆设想+底层自洽+假设试错+模型重构 | 能构建实验体系，把创新变成稳定可复现的范式 |

**关键动作**：
- 每周刻意练习「提 3 个假设」
- 遇到卡点时先问「这件事的本质是什么？」
- 把验证过的创新封装成可复用的方法论

## 三、AI 三角详细展开

### 3.1 场景（Scenario / Opportunity）

> 发掘高匹配、高价值细分场景的能力。

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 强敏感性、大胆假设、细分场景 | 工作中遇到「叹气」「不得不做」的事会立刻想「AI 能帮忙吗？」 |
| **基础** | 需求捕捉、大胆假设、STAR 模型 | 能用 STAR 模型评估场景：个人/组织 × 下限/上限 |
| **进阶** | AI 匹配、ROI 评估、定义边界 | 能对比多个场景的 ROI，明确场景内核和边界 |
| **高阶** | 创新场景、持续发现 | 能找到同行还没发现的高价值场景，并持续积累场景库 |

**关键动作**：
- 每天记录 3 个让你「叹气」的瞬间
- 把大任务拆到「AI 单次可完成」的最小单元
- 用 3-5 个维度（时间/质量/情绪/学习/可复用性）给场景打分

### 3.2 基本功（Fundamentals / Tools）

> 熟练使用各种 AI 工具、技术和特性解决问题。AI 时代的新基本功不限于提示词——扩展定义见 `[[concept-一堂-AI时代基本功变与不变]]`。

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 不迷信、不排斥、刻意练习 | 不追风口，也不排斥新工具；愿意刻意练习 |
| **基础** | 提示词工程、口喷提示词、全网调研 | 能用结构化提示词和语音输入清晰表达需求；能主动搜索全球最佳实践为决策提供依据 |
| **进阶** | 封装提示词/自动化/多工具创造、上下文工程 | 能搭建工作流、智能体、Skill、VibeCoding；能为 AI 构建结构化的上下文（提示词模板/知识库/RAG 管线） |
| **高阶** | 模型微调/训练、多 Agent 编排、智能体协作、自进化 | 能读论文、做微调、设计多 Agent 协同和自进化机制；能设计嵌入模式/副驾模式/智能体模式的人机协作范式 |

> **AI 时代新基本功说明**（四项，展开内容见 `[[concept-一堂-AI时代基本功变与不变]]`）：
> - **提示词工程**：已有（基础层）。结构化 prompt、FewShot、链式思考。
> - **全网调研**：新增（基础层）。主动用 AI 搜索全球最佳实践，建立领域对标基准。
> - **上下文工程**：新增（进阶层）。从 Prompt Engineering → Context Engineering → Harness Engineering 的范式漂移。为 AI 构建结构化的知识底座。
> - **智能体协作**：新增（高阶层的细化）。不仅是"多 Agent 编排"，更是设计人机协作的三种范式——嵌入模式（AI 嵌入现有工作流）/ 副驾模式（AI 与人对等协作）/ 智能体模式（AI 自主执行，人审结果）。

**关键动作**：
- 建立个人提示词库
- 每月尝试 1 个新工具，评估其最小核心 Feature
- 把高频重复任务封装成工作流或 Agent
- 为每个高频 Agent 建立上下文工程档案（知识库/RAG/模板）

### 3.3 数据（Data / Assets）

> 主动搜集和积累高质量 AI 可用数据资产。

| 层级 | 关键词 | 可观察行为 |
|:---|:---|:---|
| **自我修养** | 数据敏感、资产思维、复利思维 | 看到业务数据会想「这能用来训练 AI 吗？」 |
| **基础** | 正面/负面案例 | 能整理 10 个正面 + 5 个负面案例作为 FewShot |
| **进阶** | 多样性数据 | 能区分结构化/非结构化、结果/过程/错误数据 |
| **高阶** | 10 年尺度数据飞轮 | 能设计采集→处理→使用→反馈的闭环，让数据越用越多 |

**关键动作**：
- 每天记录 3 条有价值的数据
- 用 Markdown 化 + Embedding + 标签化整理案例
- 用 Obsidian/RAG/GraphRAG 构建个人或团队知识库

## 段位双轨：岗位 SABC + 单项 L1-L6

> 本矩阵的四级（自我修养→基础→进阶→高阶）可同时从两个维度使用。段位体系详见 `[[concept-一堂-基本功-段位体系]]`。

### 轨道 1：岗位段位 SABC（团队配置用）

用于团队能力拼图——每个角色在六要素上的期望段位：

| 段位 | 含义 | 六要素期望 | 典型角色 |
|:---|:---|:---|:---|
| **S 级**（架构） | 负责复杂系统设计与创新 | 审美高阶 + 体系高阶 + 创造力高阶 | 架构师、一号位 |
| **A 级**（专家） | 独立闭环复杂项目 | 审美进阶 + 体系进阶 + 创造力进阶 | 域负责人、Oraner |
| **B 级**（专项） | 解决局部难题 | 审美基础 + 体系基础 + 某项可到进阶 | 执行层 TL |
| **C 级**（基础） | 执行标准化动作 | 审美自我修养 + 体系自我修养 + 基本功基础 | 新人、实习生 |

**使用场景**：组建 AI 项目团队时，用 SABC 判断"这个角色需要哪个段位的人"。

> ⚠️ 本 SABC = 个人能力段位，与 `yt-tob-customer-sabc`（销售客户分层）不同义，不可混用。

### 轨道 2：单项段位 L1-L6（个人精进用）

每个要素可以从 L1 到 L6 逐级精进，不同于岗位段位（岗位是综合的，单项是聚焦的）：

| L1 | L2 | L3 | L4 | L5 | L6 |
|:---|:---|:---|:---|:---|:---|
| 入门：完成基础动作 | 熟练：稳定输出 | 优化：改进流程 | 进阶：多维定量 | 高阶：跨域迁移 | 大师：创造新范式 |

**使用场景**：个人针对某个薄弱要素做刻意练习时，用 L1-L6 判断"我这项能力现在在哪一级、下一级该练什么"。

### 双轨对应关系

| 岗位 SABC | 单项 L1-L6 的大致对应 |
|:---|:---|
| C 级 | L1-L2 |
| B 级 | L2-L4 |
| A 级 | L4-L5 |
| S 级 | L5-L6 |

> 对应关系是近似值——一个人可以岗位 C 级但某项单项到 L4（如新人提示词工程很强但其他要素弱），这正是矩阵要暴露的"长板"和"致命短板"。

### 与 management-map L1-L5 的关系

management-map 的 L1-L5 是**管理范围**的进阶（管自己→管任务→管团队→管部门→管组织），本段位体系是**个人能力熟练度**的进阶。二者正交互补——一个管理范围 L5 的人可能在双三角某项基本功上只有 L2。

## 四、如何使用这张矩阵

### 用法 1：自我段位评估

对六要素分别定位，找到自己的「长板」和「致命短板」。

### 用法 2：团队配置拼图

组建 AI 项目团队时，不要按岗位招聘，而是按六要素凑齐：
- 谁负责审美判断？
- 谁负责把流程拆成体系？
- 谁负责找场景和 ROI？
- 谁负责攒数据？
- 谁负责工具/工程化？

### 用法 3：项目启动检查

每个新项目启动前，对照矩阵问：
- 这六要素中，哪些已经达标？哪些还是空白？
- 空白项中，哪一个是当前最大瓶颈？
- 先补哪个能在最短时间内提升整体交付质量？

## 五、Critique

### 内部局限

1. **矩阵是理想型**：真实人的能力分布不会这么整齐，多数人某些要素在 L2、某些在 L4。
2. **组织级能力不等于个人级能力**：一个人可以是六边形战士，但组织级落地需要分工。
3. **等级边界模糊**：L2 到 L3 的跃迁不是线性的，而是质变。

### 外部攻击

**Kirkpatrick 培训评估模型**：四级修炼路径容易变成「课程学习 = 能力提升」的幻觉。真正改变行为的是实践和反馈，不是读完这张表。

**Dreyfus 技能获取模型**：从新手到专家需要大量情境化练习，不是简单的一级一级爬。双三角武器库应被视为脚手架，而非能力发展的唯一路径。

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|:---|:---|:---|
| 不知道下一步该练什么 | 用这张矩阵给自己打分，找出最低的一项 | 明确接下来 2-4 周刻意练习的目标 |
| 组建 AI 项目团队 | 按六要素画团队能力拼图 | 每个要素都有人负责 |
| AI 项目失败复盘 | 对照矩阵看哪个要素是短板 | 不是泛泛说「数据不够」，而是指出「数据缺少负面案例」 |
| 设计培训课程 | 把课程目标映射到矩阵的某一级 | 学员能说出自己从 L2 升到 L3 的具体行为变化 |


## VLM 深度分析：5 个关键洞察

### 1. 自我修养前置——能力建设的起跑线不是"学技术"而是"校心态"

六个模块全部把"自我修养"放在"基础"之前。这不是排版——是世界观。技术会变，人对自己能力建设的心态是最稀缺的元能力。

### 2. 审美是最被低估的 AI 核心能力

传统认知：审美=艺术。武器库定义：审美=对 AI 输出质量的高水平判断力。未来最稀缺的不是会用 AI 的人，是能判断 AI 输出好坏的人。

### 3. 数据是唯一有明确时间尺度的维度

六个维度中只有数据明确提出"10 年心态"和"数据飞轮"。AI 能力的差距本质是数据资产的差距，数据资产的差距本质是时间复利的差距。这是最慢的变量，也是最难追的护城河。

### 4. 创造力×场景 = 孪生顶点

两个顶点不是巧合：没有创造力找不到新场景（只能跟随），没有场景敏感创造力无处落地（变成空想）。真正的 AI 创新者 = 创造力 × 场景敏感。

### 5. 体系是被低估的杠杆

大多数人在"基本功"层卷，真正稀缺的是把基本功封装成可复用体系的人。这是个人 IP 化、知识产品化的底层逻辑。

## 五个实践场景

| 场景 | 怎么用武器库 |
|:---|:---|
| **个人能力诊断** | 用 6×4 矩阵给自己打分，找出最低的一项作为下阶段刻意练习目标 |
| **AI 项目立项评估** | 立项前对照矩阵检查：六个要素各到什么段位？最低的要素是项目最大风险 |
| **团队能力地图** | 把团队成员的六要素段位画成热力图，识别团队级短板 |
| **内容创作与知识生产** | 把武器库矩阵作为内容框架——每个格子一篇方法论文章/一个案例 |
| **竞争优势护城河识别** | 数据段位（L3-L5）= 时间复利壁垒；其他五个要素可以速成，数据不能 |
