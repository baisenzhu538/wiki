# 小众品类渠道合伙人/区域包干决策框架（「卖地图」模式）

## 一句话

当品类小众、产品非标、消费者需要被教育时，「把区域经营权卖给代理商」比直营或底薪提成团队更经济——不是因为直营不好，而是因为单区域销量撑不起直营团队的固定成本。「卖地图」的本质是用利润换资产轻、用控制权换本地深度。

## 1. 什么品类该「卖地图」——品类诊断四问

在选渠道模式之前，先回答四个问题。每个「是」往代理加盟方向推一步：

| 诊断问题 | 判断标准 | 指向 |
|:---|:---|:---|
| **市场够不够小？** | 单城市/单区域潜在年销量 < 支撑一个直营团队（含督导+销售+管理）的盈亏平衡点 | 是 → 代理加盟 |
| **教育成本够不够高？** | 消费者购买前需要 ≥2 次触达/讲解才能理解产品价值，底薪销售只做成交不做教育 | 是 → 代理加盟 |
| **毛利空间够不够分？** | 出厂价到终端零售价之间的毛利空间，能否同时覆盖代理商本地运营成本 + 代理商预期利润 | 是 → 代理加盟 |
| **地域差异够不够大？** | 不同城市的消费习惯、渠道关系、关键影响者（医生/营养师/母婴店）差异大到总部无法统一管理 | 是 → 代理加盟 |

> 四个全「是」→ 强烈建议代理加盟模式（如羊奶粉）。四个全「否」→ 直营或强类直营（如可口可乐、苹果）。中间状态 → 弱类直营。

## 2. 品类特征 × 渠道模式决策矩阵

基于冉鹏四模式框架（`tool-strategy-profit-model-comparison`）延伸，加入品类特征维度：

| 品类特征 | 直营 | 强类直营 | 弱类直营 | 代理加盟（卖地图） |
|:---|:---|:---|:---|:---|
| **市场规模** | 大（单城可撑团队） | 中-大 | 中 | **小**（单城不够养团队） |
| **标准化程度** | 高（消费者无需教育） | 中-高 | 中 | **低**（需本地化教育） |
| **毛利空间** | 高（覆盖直营成本） | 中-高 | 中 | **中-高**（够分给代理商） |
| **品牌控制需求** | 极高 | 高 | 中 | **低-中**（能接受弱管控） |
| **扩张速度需求** | 稳 | 中 | 快 | **最快** |
| **现金流充裕度** | 充裕 | 中 | 中-低 | **低** |
| **管理能力** | 强总部 | 强督导体系 | 弱督导 | **仅底线管控** |

**使用方式**：将你的品类在每一行打分（1-5），加权后看落在哪个模式最匹配。权重建议：市场规模 25% + 教育成本/标准化 25% + 毛利空间 20% + 品牌控制 15% + 现金流 15%。

## 3. 「卖地图」模式的五个结构要素

羊奶行业的「卖地图」不是模糊的"把区域交给代理商"，而是五个要素组成的可设计结构：

| 要素 | 厂商侧（品牌方） | 代理商侧 | 关键设计参数 |
|:---|:---|:---|:---|
| **所有权** | 保留品牌 + 供货权 + 区域收回权 | 拥有区域经营权 + 本地客户资产 | 区域经营权的排他性、续约条件、收回触发条件 |
| **定价权** | 给底价/出厂价 + 建议零售价上限 | 自主终端定价、自主促销 | 底价公式（出厂成本 + 厂商利润）、窜货最低价 |
| **投入** | 生产 + 品牌 + 产品培训 + 供货 | 资金（进货 + 本地团队 + 地推）+ 客情维护 | 首单进货门槛、年度进货任务 |
| **风险** | 库存风险转移给代理商，品牌风险自留 | 库存/资金/本地市场不确定性 | 退换货政策、滞销处理机制 |
| **控制** | 仅控窜货底线 + 品牌使用规范 | 区域内运营主导权 | 窜货处罚标准、品牌违规罚则 |

### 3.1 定价权分配：底价模型

```
厂商出厂价（底价）= 生产成本 + 厂商目标利润率 × 生产成本

代理商终端毛利 = 终端零售价 − 厂商出厂价 − 代理商本地运营成本

代理商净利润 = 代理商终端毛利 − 代理商资金成本
```

**底线约束**：代理商净利润必须 ≥ 代理商投入资金 × 资金机会成本（否则代理商不如把钱存银行）。

### 3.2 控制权分配：厂商留哪三张牌

即使「卖地图」，厂商也必须保留三张牌：

1. **窜货底线**：跨区域销售 = 违约，有明确罚则（如没收保证金、取消代理权）。
2. **品牌使用规范**：门头/宣传物料/线上内容必须过厂商审核。
3. **区域收回权**：连续 N 个季度未完成进货任务的，厂商有权收回区域另招代理。

其余运营权（定价、促销、团队、本地渠道）全部交代理商。

## 4. 与已有框架的接口

### 4.1 与冉鹏四模式框架的关系

本框架是 `tool-strategy-profit-model-comparison` 中「代理加盟」象限的**纵深展开**：

- 冉鹏框架给了四模式的场/货/管/优对比 → 本框架给了「什么品类该选代理加盟」的**决策前置条件**。
- 冉鹏框架给了代理加盟的通用特征 → 本框架给了代理加盟的**五要素结构设计和定价权分配**。
- 冉鹏框架适用于全品类 → 本框架专门针对**小众/非标/高教育成本**品类。

### 4.2 与渠道预判评分矩阵的关系

`tool-yitang-channel-scoring-matrix` 三模块十一维度中，产品匹配度（标准化程度 + 客单价/毛利 + 决策复杂度）天然解释了「为什么小众品类指向代理模式」：

- **标准化程度低** → 产品需要本地化解释和教育 → 代理商比总部销售更懂本地。
- **客单价/毛利中高** → 毛利空间够分给代理商 → 经济上可行。
- **决策复杂度高** → 需要深度信任和长期关系 → 代理商在当地有人脉有信任。

### 4.3 与渠道单元经济模型的关系

`framework-yitang-channel-unit-economics` 提供了按渠道拆分单元经济的工具。在本框架下：

- **厂商单元经济** = 出厂毛利 × 出货量 − 品牌/培训/管理成本。
- **代理商单元经济** = 终端收入 − 进货成本 − 本地运营成本 − 资金成本。
- **模式可行性判据**：厂商和代理商两边的单元经济必须同时为正。如果厂商的出厂价只能让代理商微利或亏损，模式不可持续。

### 4.4 与合伙股权的关系

`yt-management-partnership-equity` 讲的合伙人股权分配逻辑可类比代理关系设计：

- 股权 vesting → 代理权续约条件（连续完成任务的才给续约）。
- 退出机制 → 代理商退出时的库存回购/客户移交条款。
- 控制权设计 → 厂商保留的关键否决权（窜货、品牌、区域收回）。

代理商本质是「外部合伙人」：厂商让渡部分利润和控制权，换取代理商的资金、时间和本地能力。

## 5. 六种失败模式

### 失败模式 1：品牌力不足，代理商不接盘

**症状**：底价定了、区域画了，但招商招不到人——代理商算了账发现赚不到钱。

**根因**：厂商高估了自己的品牌溢价。代理商的实际问题是「这个品牌在本地有没有认知度？没认知度我要花多少钱去教育？」如果厂商在消费者端品牌投入为零，代理商等于自己出钱替厂商做品牌。

**修复**：招商前先在至少 1 个样板市场跑通代理商单元经济，用真实数据而非 PPT 说服代理商。样板市场的代理商净利润必须 ≥ 代理商投入资金年化 15%-20%（这是代理商的隐性机会成本 `[conf=0.70, source=羊奶行业口述经验，待独立核实]`）。

### 失败模式 2：底价设计失误，一边被吸干

**症状**：厂商底价过高→代理商没利润→流失或消极经营；底价过低→厂商失血→无法持续。

**根因**：底价设计时只算了厂商端的成本，没算代理商的本地运营成本和合理利润。

**修复**：底价设计必须从「终端零售价」倒推——市场能接受的零售价 → 减去代理商合理利润 → 减去代理商本地运营成本 → 等于厂商最高可设底价。如果这个底价低于厂商生产成本，说明这个品类不适合代理模式（毛利空间不够分 `[conf=0.80, source=冉鹏四模式框架 + 王语嫣九层深挖]`）。

### 失败模式 3：窜货失控，价格体系崩塌

**症状**：A 区代理商把货卖到 B 区，B 区价格被打穿，B 区代理商亏损、消极经营、甚至退货。

**根因**：厂商窜货管控缺位——没有区域编码追踪、没有窜货罚则、没有价格底线。

**修复**：
- 每批货打区域编码 + 消费者扫码查区域；
- 窜货罚则：首次警告 + 罚款，二次没收保证金，三次取消代理权；
- 设终端最低零售价，低于此价视为窜货/低价倾销。

### 失败模式 4：市场放量期代理商成为增长瓶颈

**症状**：品类从小众走向大众，市场需求爆发，但代理商不敢扩产/扩团队，厂商直营又和代理商冲突。

**根因**：代理商的投资决策是「自己能赚多少钱」而不是「厂商需要多少增长」。当市场爆发时，代理商的最优策略可能是「守住现有盘子，不冒险扩产」——这恰好与厂商的增长需求冲突。

**修复**：在代理合同中预设「放量期触发条款」——当区域销量连续 N 个季度增长超过 Y%，厂商有权：
- 拆分区域（大区拆小区，引入新代理商）；
- 或转为强管控（厂商派驻督导，代理商保留经营权但运营标准由厂商定 `[conf=0.65, source=行业观察推理，待独立案例验证]`）。

### 失败模式 5：代理商服务不一致，伤害品牌

**症状**：不同区域的门头、话术、服务标准差异巨大，消费者在 A 城和 B 城的体验完全不是同一个品牌。

**根因**：「卖地图」的本质是把运营权交出去——但品牌体验的一致性是需要强管控才能实现的。你把运营权交给 30 个代理商，就等于有 30 种品牌体验。

**修复**：
- 厂商保留「品牌使用规范」审核权，门头/核心话术/服务流程由厂商统一输出；
- 设神秘顾客抽查机制，不合格者限期整改，多次不合格者取消代理权；
- 品牌体验一致性是代理模式的天生短板——如果这对你来说是致命问题，考虑升级到「强类直营」。

### 失败模式 6：品类始终小众，代理商老化流失

**症状**：品类在区域内增长见顶，代理商赚了几年钱后不再投入，甚至转做其他品牌。厂商增长停滞，又找不到新代理商接盘。

**根因**：「卖地图」让厂商轻资产扩张，但也让厂商失去了对终端客户的直接触达和关系。代理商老化时，厂商既没有直营团队可接手，也不了解本地客户。

**修复**：
- 厂商必须保留终端客户数据（至少是脱敏的消费行为数据），不能完全依赖代理商；
- 提前布局「代理商接班人」机制——老代理商培养副手/子女接手，或厂商有优先收购代理权的条款；
- 品类进入成熟期后，评估是否从「代理加盟」升级到「强类直营」——厂商收编核心代理商，转为强管控 `[conf=0.65, source=羊奶行业口述 + 冉鹏四模式框架逻辑推演]`。

## 6. 适用边界

### ✅ 适用的品类特征

- 单城市/区域潜在销量不足以支撑直营团队盈亏平衡；
- 消费者购买决策需要 ≥2 次教育触达，底薪销售无法有效完成；
- 出厂价到终端零售价之间的毛利空间 ≥ 代理商本地运营成本 + 代理商合理利润；
- 不同区域的市场环境差异大到总部无法用统一 SOP 管理；
- 厂商现金流紧张，无法承担铺货 + 库存 + 回款周期的资金压力。

### ❌ 不适用的品类特征

- 品牌感极强、体验一致性是核心竞争力的（如苹果、星巴克）；
- 产品高度同质化、代理商只会比价没有本地壁垒的（如普通白牌快消）；
- 市场正在快速放量、需要厂商强控渠道节奏的（如风口期的瑞幸）；
- 政策/合规风险高、需要总部强合规管控的（如处方药、金融产品）；
- 消费者已经高度数字化、线上直营效率远超线下代理的（如纯 SaaS 产品）。

## 7. 跨域双向价值

### 对渠道增长域的价值

补充了「什么情况下不选直营/分销，而选区域包干」的**品类前置诊断**。渠道预判评分矩阵帮你选「哪个渠道」，本框架帮你判断「这个品类能不能用代理渠道」。

### 对商业模式/战略域的价值

把冉鹏四模式中的「代理加盟」做厚：从通用描述升级为包含决策前置条件、五要素结构、定价权分配、失败模式的具体操作框架。让四模式框架从「知道有四种模式」升级为「能判断自己的品类该不该用代理加盟」。

### 对管理/合伙域的桥接

揭示了代理关系与合伙股权在结构上的同构性：都是「让渡利益换投入」，都需要设计进入/退出/控制权/激励机制。代理商的「外部合伙人」视角可以反哺合伙股权课程的案例丰富度。

## 8. Critique

### 外部反对者一：代理模式是一种「低端锁定」

**质疑**：选择代理加盟意味着你承认你的品类不够大、品牌不够强。这会成为自我实现的预言——因为选了代理模式，所以不会投入品牌建设，所以品类永远小众。

**回应**：代理模式是阶段性的，不是永久性的。羊奶行业已有品牌（如佳贝艾特）在品类扩容后逐步强化直营/电商/商超占比。框架的价值在于帮你识别「当前阶段最适合什么」，而不是「永远应该是什么」。但确实存在路径依赖风险——一旦代理商网络建成，转型直营会面临巨大的渠道冲突 `[conf=0.70, source=冉鹏四模式框架逻辑 + 王语嫣九层深挖 L8 预判]`。

### 外部反对者二：你忽略了平台革命

**质疑**：在抖音/快手/拼多多时代，为什么还需要区域代理商？平台可以帮你直接触达全国消费者，绕过所有中间环节。

**回应**：平台解决的是「触达」，不是「教育」和「信任」。羊奶粉的购买决策涉及母婴店老板推荐、医生/营养师背书、宝妈社群口碑——这些信任节点是平台流量无法替代的。但确实，线上内容种草 + 线下代理商承接的组合模式可能是更优解，值得在工具卡中进一步展开 `[conf=0.75, source=Truman渠道方法论 + 羊奶行业观察推理]`。

### 内部局限

- 本框架核心案例来自羊奶粉一个品类（via 王语嫣九层深挖），迁移到其他小众品类（小众酒、功能性食品、教育加盟）需按品类特征重新验证。
- 代理商的单元经济数据（合理利润率、资金机会成本、本地运营成本）在诊断素材中未给出具体数字，均标注为估算或待独立核实。
- "卖地图"模式在快消/耐用/服务三种品类中的适用差异尚未系统比较。

## 9. 速查卡

```text
品类诊断四问：
1. 单区域销量能撑直营吗？→ 不能 → 代理
2. 消费者需要被教育吗？→ 需要 → 代理
3. 毛利够分给代理商吗？→ 够 → 代理
4. 不同城市差异大到无法统一管理吗？→ 是 → 代理

「卖地图」五要素：
所有权（区域经营权+收回权）、定价权（底价+终端价）、
投入（厂商品牌+代理商本地）、风险（库存转移+品牌自留）、
控制（仅窜货+品牌+收回三张牌）

六种死法：
品牌力不足没人接 → 底价失误单边失血 → 窜货价格崩盘 →
放量期代理成瓶颈 → 服务不一致伤品牌 → 品类小众代理老化流失

厂商必须留的三张牌：窜货底线、品牌使用规范、区域收回权
```
