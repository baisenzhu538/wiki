# 基本功九层金字塔：从底层信念到基本功化的完整地图

> **一句话**：一堂把整套基本功方法论压进一张「武器库全景图」，并用逐层解读的方式读出九层结构——**底层信念**（人不是组织能力的最小单位，基本功才是）托着九层：理念 → 对象 → 目标 → 路径 → 各字目标 → 策略集合 → 演化路径 → 关键工具 → 内化。读透这张图，等于拿到基本功从认知到落地的完整地图；落地时从底层信念开始逐层往下走，缺一层上面全是空的。
>
> **口径说明**：整合笔记整理为「底层信念 + 九层」结构（L286-300）；课程口述逐层解读实际讲了十层——前九层与笔记一一对应，口述的「隐藏第十层」是把第八层的 40 张工具卡每格再往下拆 1-2 层。本卡按任务单命名为「九层金字塔」，把口述第十层（40 卡深拆）并入第八层「关键工具」展开，特此注明，两层口径不矛盾。

---

## 何时用

- 第一次接触一堂基本功体系，需要一张全局地图知道"这套东西到底有几层、我在哪层"时
- 团队基本功推进卡住，需要定位"卡在第几层"再对症下药时（见 diagnostic_signals）
- 要给团队讲清楚"为什么是苦练、练什么、怎么练、用什么练"的完整逻辑链时（启动会备课）
- 评估一套基本功方案是否完整：从信念到工具是否逐层有据，还是空中楼阁

## 需要什么

- 一张武器库全景图（素材：`基本功武器库_vlm.md` / `基本功武器库.png`）——九层就是从这张图上逐层读出来的
- 对底层信念的真实认同（或至少愿意验证）：不相信"基本功是组织能力的最小单位"，上面九层全是装饰品
- 按层消费的耐心：口述原话是"通过一轮解读、两轮解读……解读到第十层的时候，这张图就是由我准备的了"（L2516-2520）——图要一轮一轮读厚，不是一次看完

## 金字塔全图（底层信念 + 九层）

```
底层信念：人不是组织能力的最小单位，基本功才是
  第一层 理念：苦练基本功（苦/练/基/功四字皆有深意）
  第二层 对象：五类高频重复工作（创造 / 专业 / 领先 / 标准 / SOP）
  第三层 目标：专业化 → 领先化 → 标准化 → SOP化（把工作往右推）
  第四层 路径：落地四字诀 拆 → 建 → 推 → 练
  第五层 各字目标：独立动作 / 固定套路 / 形成共识 / 刻意练习（大量反馈）
  第六层 策略集合：把开放题变成选择题——答案已写在图上，照菜单选
  第七层 演化路径：先加法后减法再稳定；抽象 → 具体；一个人 → 全员；氛围由轻到重
  第八层 关键工具：4 个色块 = 40 张工具卡（口述隐藏第十层：每卡再深拆 1-2 层）
  第九层 内化：深入用工具，融入工作场景，完成"基本功化"
```

## 逐层解读

### 底层信念：人不是组织能力的最小单位，基本功才是

整套方法论的承重墙。组织能力的落差，不在人跟人之间，在基本功跟基本功之间——所以管理动作要下沉到"练基本功"这一格，而不是只在"换人/激励人"那一格使劲。不认同这一层，下面九层都会退化成口号。

### 第一层 理念：苦练基本功（四个字都不浪费）

口述逐字拆读（L2526-2554）：
- **苦**：练基本功是苦的，团队得有"愿意重复做重复事"的共识——都喜欢花招、喜欢"一招新"的团队，练不了基本功；
- **练**：好东西都是练出来的，不可能一学就会、一蹴而就，"别瞎想"；
- **基**：它是一个基本框架、基本模型——学习没那么难，记住"要给它建模"；
- **功**：功要落到一个点上——扎马步是一个功，选址是一个功，每个功都是具体可练的动作。

整合笔记另给一组提炼（苦=枯燥、练=实践、基本=高频重复、功=复利），两组解读并列参照，口述口径为准。

### 第二层 对象：五类高频重复工作

基本功面对的是五类工作，各有各的练法（L2560-2646）：

| 工作类型 | 特征 | 进化方向 |
|:--|:--|:--|
| 创造类 | 开放、依赖灵感（内容、创意、选址、选品） | 专业化：不依赖灵感 |
| 专业类 | 有专业门槛但执行弱（面试、开会、投放、写作） | 领先化：练出水准、练成行业最佳实践 |
| 领先类 | 行业稀缺能力（获客、IP、电商、投放）但依赖单个人 | 标准化：建模型、持续复盘，不依赖某一个人，可复制 |
| 标准类 | 天然有标准、需大规模复制（品控、门店制作） | 精细化建模 + 健康持续复制 |
| SOP类 | 相对标准、要求严丝合缝 | 100% 执行 + 监督执行（甚至双层监督：派人监督监督的人） |

口述金句：做管理就是"在业务不断发展的过程中，努力把 ABCDE 往右推"，推得比同行明显领先 1-2 步，结果大概也领先 1-2 步（课程经验值）。第二层与第三层的对应关系，操作化展开见 [[framework-一堂-基本功-四类工作四化]]。

### 第三层 目标：专业化 → 领先化 → 标准化 → SOP化

四化是第二层各类工作的进化目标，也是全公司基本功的总追求——把创造类工作推到专业化、专业类推到领先、领先类建成体系（标准化）、标准类推到 SOP 化。很多工作推不到终点（"1 太绝对了"），但脑子里要有这根弦：能推几步推几步。

### 第四层 路径：落地四字诀 拆 → 建 → 推 → 练

理念落到地上的唯一通道。口述用三个反问点出四层缺一不可（L2690-2696）：推不动？是因为没有共识（缺「推」）；效率差？是因为没有建模型（缺「建」）；大家不想练？是因为连拆都没拆出来（缺「拆」）。四字诀的全流程展开见 [[framework-一堂-基本功-四字诀拆建推练]]。

### 第五层 各字目标：独立动作 / 固定套路 / 形成共识 / 刻意练习

每个字都有一个可验收的靶心（L2698-2730）：
- **拆 → 独立动作**：找到关键的独立动作，"越小越好"——动作越小越可练，练习和复制都会变好，不追求大而全；
- **建 → 固定套路**：动作要固定下来——每个人写法不一样就没法沉淀（"如果不固定的话，怎么备案呢"）；
- **推 → 形成共识**：团队必须对练什么、怎么练形成共识，循序渐进，共识不到位就推不下去；
- **练 → 刻意练习（获取大量反馈）**：练习要配上大量反馈（口述原话"可以获取大量反馈"，整理稿表述为刻意练习），没有反馈的重复只是低效劳动。

### 第六层 策略集合：把开放题变成选择题

金字塔中段以下是"策略合集"（L2732-2750）：图上每个小格子都是一道已答好的选择题——拆法无外乎那几格、六维做减法那几格，绝大部分情况"打勾就行"。口述估计：把图做完，90%-95% 的问题就已解决（课程经验值）；全用透了还不够，再自己创造新解。这层的作用是降低决策成本：把开放无边界的决策，变成"选菜单"。

### 第七层 演化路径：四条渐进的顺序线

这一层读的是"顺序"（L2752-2774），四条线同时成立：
1. **数量线**：早期先做加法（多拆候选），再做减法（六维筛），最后稳定；
2. **颗粒线**：先抽象后具体——对逐字稿的理解从"模模糊糊的发言稿"，到 N 个要素，再到越来越具体；
3. **范围线**：先一两个人以身作则，再到全员——"我先练，我练不会我不要求你们，我练会了你们再跟着我练"；
4. **力度线**：氛围提醒从最轻（氛围、挂在嘴边）到最重（工具、制度），逐步加码。

### 第八层 关键工具：4 个色块 = 40 张工具卡（含口述"隐藏第十层"）

每一个关键工具和策略背后都是一个小的单元模型（L2776-2790）。例：「20%迭代」——重点项目每次结束后要求每个人提改进点，"下次比上一次好 20%，一直好一直好下去"，靠这个原则把团队不断往前推。

按任务单铁律口径，40 卡 = 拆 6 + 建 7 + 推 7 + 练 20。其中建 7 见 [[tool-一堂-基本功-建模七法]]、推 7 见 [[tool-一堂-基本功-推动七式]]、练 20 见 [[tool-一堂-基本功-练习二十法]]，拆 6 见 [[framework-一堂-基本功-四字诀拆建推练]] 的拆段导航。

**口述"隐藏第十层"（本卡并入本层）**：武器库口述 L2860-2882 把第八层再往下挖一层——给每一个实操格配了一张卡片，共 40 张，按 拆/建/推/练 分色；而且每个格子再往下拆 1-2 层：什么叫"按框架拆"、有哪些框架；雷达图怎么画；表扬先进怎么表扬；市场上十大主流培训是什么……以后想培训，从那十个里选就行。口述的自评是：实操往下多挖 1-2 层，"立竿见影地提升工具的实用性，瞬间这个工具就很值钱"。以后改善业务的方式就是"找到关键场景，不断出卡出牌"。

### 第九层 内化：完成"基本功化"

最后一层是把工具用进工作场景、变成组织的肌肉（L2792-2818）。借课程现场郭总的词——**基本功化**：基本功不是非黑即白的"有/没有"，而是随着一点点往前推、逐步成长分化的过程（"开始的时候可能就三个技能，慢慢变得好……从上往下逐步分化"）。小格子用得越多，团队的"四格漫画"做得越好——工具循环（项目循环、业务汇报循环、管理人的循环）跑顺了，基本功就长进了日常。

## When NOT to Use

| 场景 | 为什么失效 | 替代 |
|:--|:--|:--|
| 拿金字塔当"九层打卡清单"，要求团队逐层交作业 | 金字塔是认知地图不是考核表，强行打卡会把理解型结构压成形式主义 | 只用于诊断定位（卡在第几层）和讲课串线，落地走第四层四字诀 |
| 底层信念还没共识，就先铺工具层 | 没有信念托底，工具会被用成应付检查的表格 | 先回第一层把"苦/练/基/功"的共识谈透，再往下走 |
| 想用一张图解决具体业务问题 | 金字塔是地图不是药方，具体问题要落到第八层的具体卡片 | 按第五/六层定位问题类型，去对应工具卡取操作步骤 |
| 团队连"练什么"都没拆出来，就讲九层结构 | 跨层灌输，听得热血、回去无从下手 | 先走拆解四法立项，金字塔留到启动会讲全图时用 |

## Failure Modes（症状 → 根因 → 修复）

| # | 症状 | 根因 | 修复 |
|:--|:--|:--|:--|
| 1 | 课上得热血沸腾，回去两周一切照旧 | 只读到第一/四层，第五层以下的工具层没进手 | 复盘时用本卡逐层自查：共识（一）→对象（二）→目标（三）→路径（四）→靶心（五）→选菜单（六）→顺序（七）→工具（八）→内化（九），缺哪层补哪层 |
| 2 | 拆出来的"基本功"是"提升沟通能力"这种大词，没法练 | 第五层「独立动作」靶心没达成——拆得不够小 | 继续拆到"一次破冰电话的开场 1 分钟"这种粒度，越小越可练 |
| 3 | 每个人都有自己的一套"做法"，复盘没法沉淀 | 第五层「固定」没达成 | 上建模七法，把动作固定成模板/清单/SOP，不固定不许练 |
| 4 | 一号位要求全员练，自己不动 | 第七层范围线被跳过 | 先走"一个人 → 小团队 → 全员"，一号位练会之前不要求团队 |
| 5 | 一上来就上考核制度，团队反弹 | 第七层力度线被跳过——氛围还没起就直接加重 | 退回最轻档（挂在嘴边/文字化），按 氛围→原则→工具→流程→制度 逐层加码 |
| 6 | 图看了一遍就归档，再没翻过 | 把全景图当一次性教材 | 照口述方法"一轮一轮解读"，每次推进基本功前重读一次图，读到"图是自己准备的"为止 |
| 7 | 40 卡摆在桌上不知道先出哪张 | 没按第六层"选菜单"逻辑走 | 先定位当前场景属于 拆/建/推/练 哪一色块，再在该色块里按卡点选卡 |

## Critique（外部攻击与回应）

**1. 层级模型的"伪精确"批判（Mintzberg 对管理框架化的警惕）**：把复杂的管理实践压成九层，容易让人误以为组织成长是线性爬楼梯，忽视了真实组织的混乱与涌现。**本域回应**：金字塔自始自终声明自己是"解读同一张图的十个角度"之一（L2512-2520），是认知脚手架而非组织发育时间表；第七层四条顺序线恰恰承认了非线性（先加法后减法、由轻到重可按需降层），层与层之间允许回退，不是单向阶梯。

**2. 还原论批判（Ackoff 的系统论视角）**：把组织能力还原成"基本功"这一最小单位，可能丢掉系统层面的交互效应——基本功都练好了，组织未必好。**本域回应**：底层信念说的是"最小单位"而非"全部"——基本功是必要条件层的抓手，不声称替代战略与系统设计；第九层"基本功化"要求的正是工具融入真实业务循环（项目循环、汇报循环），在系统里长出来，而不是在训练室里堆出来。

**3. 工具拜物教批判（呼应《清单革命》的边界讨论）**：第八层 40 卡容易诱发"集卡式学习"——卡集齐了，动作没变化。**本域回应**：Failure Modes 第 7 条已内置防御——卡片必须按"当前场景 → 色块 → 卡点"出牌，且口述原话把价值锚在"每格往下拆 1-2 层的实操性"上；卡不是收藏品，是打牌的手牌，出不了手的卡等于没有。
