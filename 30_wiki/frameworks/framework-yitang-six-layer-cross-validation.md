# 六层交叉验证：从单源到多源的信息可信度提升

> **一句话**：单一来源的信息不可信，即使是专家也可能错。六层交叉验证强迫你从六个独立维度验证关键信息，确保结论的可靠性。

---

## 核心框架：六层验证模型

```
第一层：来源验证（谁说的？）
   ↓
第二层：时间验证（什么时候？）
   ↓
第三层：逻辑验证（说得通吗？）
   ↓
第四层：数据验证（有数字支撑吗？）
   ↓
第五层：反例验证（有反面证据吗？）
   ↓
第六层：行动验证（能指导行动吗？）
```

## 第三层：逻辑验证

### 核心问题：说得通吗？有没有逻辑漏洞？

### 常见逻辑陷阱

| 陷阱 | 症状 | 检查方法 |
|:---|:---|:---|
| **因果混淆** | 把相关当因果 | "A和B同时发生，但A不一定是B的原因" |
| **以偏概全** | 用个别案例推一般结论 | "这个案例能代表整体吗？" |
| **幸存者偏差** | 只看成功案例 | "失败案例是什么？" |
| **选择性失明** | 只看支持自己观点的信息 | "反面证据是什么？" |
| **滑坡谬误** | 夸大连锁反应 | "每一步都必然发生吗？" |
| **虚假两难** | 非黑即白 | "只有这两个选项吗？" |

## 第四层：数据验证

### 核心问题：有数字支撑吗？数字可靠吗？

### 数据质量检查

| 检查项 | 问题 | 标准 |
|:---|:---|:---|
| **数据来源** | 数字从哪来的？ | 可追溯到原始出处 |
| **样本量** | 样本够大吗？ | 统计显著性 |

| **时间范围** | 什么时候的数据？ | 在有效期内 |

## 六层验证完整流程

```
关键信息
   ↓
第一层：来源验证 → 可信？
   ↓ 否 → 丢弃
   ↓ 是
第二层：时间验证 → 有效？
   ↓ 否 → 标记过时
   ↓ 是
第三层：逻辑验证 → 合理？
   ↓ 否 → 标记存疑
   ↓ 是
第四层：数据验证 → 有数据？
   ↓ 否 → 标记待验证
   ↓ 是
第五层：反例验证 → 有反例？
   ↓ 有 → 调整结论
   ↓ 无
第六层：行动验证 → 可执行？
   ↓ 否 → 标记需细化
   ↓ 是
结论可信，可指导行动
```

## Constraints & Boundaries

### 适用边界

1. **关键信息**：影响重大决策的信息
2. **争议信息**：不同来源说法不一致
3. **专家观点**：需要独立验证
4. **AI生成信息**：必须验证
5. **长期项目**：需要持续验证

### 不适用场景

1. **常识性信息**：如"地球是圆的"
2. **紧急决策**：没有时间充分验证
3. **纯主观判断**：如审美、偏好
4. **信息不可得**：无法获取验证来源
5. **验证成本过高**：验证成本超过信息价值

## Common Failure Modes

| 失败模式 | 症状 | 修复方法 | 预警信号 |
|:---|:---|:---|:---|
| 来源单一 | 只用一个来源 | 强制多源交叉 | "根据XX报道..." |
| 时间忽视 | 用过时信息 | 强制检查时间 | "据XX年报告显示" |
| 逻辑跳跃 | 论证不完整 | 强制逻辑检查 | "显而易见..." |
| 数据迷信 | 有数字就信 | 强制追溯来源 | "数据显示..." |
| 忽视反例 | 只看支持信息 | 强制寻找反例 | "所有信息都支持我" |
| 行动脱节 | 结论无法执行 | 强制行动验证 | "理论上可行..." |
| 验证过度 | 过度验证，拖延决策 | 设定验证时限 | "还在验证，没结论" |
| 验证不足 | 关键信息未验证 | 建立验证清单 | "这个应该没问题" |
