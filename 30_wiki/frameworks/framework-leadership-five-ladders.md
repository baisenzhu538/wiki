# 领导力五阶梯（L0→L5）

> 定位：属于 `framework-coaching-leadership-core` 的领导力成长路径卡。与 John Maxwell 五层领导力（Position/Permission/Production/People Development/Pinnacle）**高度同构**——同为"基于追随者为什么跟随"的层级模型；差异 = KDO 实践化：每层补充 Feature（关键能力）、追随者画像、提升建议。五阶管理地图（management-domain-digest）是管理者职责路径（下限），本卡是影响力层级（上限）。

## 一句话定义

领导力从 L0 认同到 L5 希望共六个层级，每上一层，追随者"为什么跟随"的理由就深一层：认同（我信你）→ 结果（你能带我赢）→ 共识（你讲道理）→ 成长（你能让我变强）→ 希望（你让我看到未来）。

## 为什么重要

1. **定位当前状态**：知道自己在哪层，才知道下一步练什么
2. **解释"不服"**：团队"口服心不服"往往是领导力停留在低层级（L2458-2460）
3. **区分能力边界**：L3 与 L4 的本质区别是"会提问" vs "能带人刻意练习"（L2882-2886）
4. **与 Maxwell 互证**：业界同构模型验证了层级逻辑的普适性，但 KDO 版更可操作（每层有 Feature/画像/建议）

## 核心机制：五阶梯结构

| 层级 | 核心 | 追随者画像（为什么跟随） | Feature（关键能力） | 提升建议 |
|:--|:--|:--|:--|:--|
| **L0 认同** | 我愿意陪着你们，带头干（L2186） | 觉得你靠谱、氛围好、愿意跟你干（L2188） | 以身作则 / 安全氛围 / 鼓励 | ①以身作则（最难过的一关，L2194）②给安全空间 ③鼓励团队 |
| **L1 结果** | 打胜仗：扛事 + 稀缺优势 + 实事求是（L2316） | 想要"带我赢的领导"，不是贴心队友（L2310-2312） | 主动扛事 / 稀缺优势 / 实事求是 | 新人前三个月找一个周围人不擅长的小点（L2352） |
| **L2 共识** | 讲道理：白盒决策（L2402-2408） | 愿意跟我讲道理、不把我当工具（L2410） | 讲道理（Y模型）/ 善于提问 / 出口式咨询 | 决策拆成白盒；口头禅"这事儿的逻辑是啥"（L2560） |
| **L3 成长** | 带人成长：基本功（刻意练习团队版）+ 1v1 反馈（L2890-2900） | 跟着你能进步、能成长（L2982） | 基本功训练 / BE FASTER 反馈 / 人生红点 | 每月给关键人 1-2 次高水平反馈（L2974） |
| **L4 希望** | 愿景感召：讲希望（L2988-2994） | 为希望追随：想参与有价值的事（L2994） | 愿景故事 / 公司文化 / 社会价值 / 人生终点 | 建希望表达库，分文化/相信/故事三维度（L3096-3100） |

> 注：任务单命名 L0-L4 对应本表 L0-L4，L5=希望层。诊断报告以 L0-L5 计（含 L0 认同层），本卡沿用 L0-L5 六层计法。

## 关键机制细节

### L0 认同层：以身作则 + 安全 + 鼓励

- **以身作则是最难过的一关**（L2194）：想让大家信服，先让自己全力以赴。"我只要做出来大家就不好意思不做"（L2200-2202）。实例：让团队拍短视频，自己先交三倍的量（L2206）
- **安全氛围**：给下属说话和试错的空间；"你卖一个就算没卖成也正常"——一句话就给对方安全感（L2232-2238）
- **2×5 耐心标准**（L2248-2260）：第一个项目改 5 轮，第二个 4 轮，第三个 3 轮，五个项目内要学会——安全空间有期限
- **鼓励（Truman 自认短板）**：正反馈 vs 练习反馈的度很难把握（L2270-2292）

### L1 结果层：扛事 + 稀缺优势 + 实事求是

- **主动扛事**：每次马拉松后公司分层加剧——主动找事的人信任和协作明显上升（L2324-2332）
- **稀缺优势**：新人前三个月找一个周围人不擅长的小点（PPT/写 prompt/写标题），成为协作价值点（L2350-2358）
- **实事求是**：不懂就说不懂，错了就认；情绪失控/甩锅/拒绝认错是三大伤（L2366-2380）

### L2 共识层：白盒决策 + 提问 + 出口式咨询

- **白盒决策**：能做对但解释不清 = 黑盒，无法形成共识（L2398-2404）
- **讲道理 = Y 模型**："Y 模型是达成团队共识最好的手段"（L2490）；公司决策效率 = 一个 Y 模型叠加（L2488）
- **善于提问**：授人以渔；三个问题引导对方自己想出答案，全程不给答案（L2528-2548）
- **出口式咨询**：借教练提问 + 咨询解决问题；"站在他的鞋子里用他的眼睛走一遍流程"（L2584-2594）

### L3 成长层：基本功 + 1v1 反馈

- **基本功 = 刻意练习团队版**：一对一用刻意练习四要素，组织版用流程化机制固化（L2892-2896）
- **1v1 反馈分级**：事儿上 BE FASTER（对比反馈）→ 能力上刻意反馈（缺要素评估）→ 人生红点（以年为单位）（L2904-2948）
- **反馈频率**：每月 1-2 次高水平反馈对方状态好；连三个月不给状态差（L2974-2976）

### L4 希望层：愿景感召

- **希望是最高级的领导力**：很多人想要的是"有念头有希望"（L2992）
- **小目标即可**：不用"建立新中国"级别，小点也可以喊愿景——"给市场示范教科书级别的课"（L3010-3016）
- **希望表达库**：分文化类/相信类/故事类三维度建库，不同场景讲不同希望（L3096-3100）

## 边界与反例（When NOT to Use）

| 场景 | 为什么不用 | 正确做法 |
|:--|:--|:--|
| 确定执行的基础工作 | L0 认同层足够（L2306） | 管理 + 明确指令 |
| 紧急拍板 | 等共识会误事 | 权力快断，事后讲逻辑 |
| 对方不接受基本公理 | 没有共识地基 | 先对齐前提（需求是事实/商业可预判） |
| 纯运营 SOP 岗位 | 不需要影响力层级 | 流程管理 |

## 常见失败模式

| 失败模式 | 症状 | 修复动作 |
|:--|:--|:--|
| 只做认同层 | 氛围好但打不了硬仗 | 补 L1：设计"带团队赢一次" |
| 黑盒决策 | 能做成但讲不清 | 白盒拆解练习（事实→推理→结论） |
| 无限安全空间 | 项目改 20 轮还学不会 | 用 2×5 标准给安全空间设期限 |
| 只会提问不带练 | 团队有共识但没成长 | 从 L3 提问升级到带基本功训练 |
| 只讲钱不讲希望 | 高价值成员留不住 | 建希望表达库，讲愿景故事 |
| 越级冒进 | 无认同基础直接喊愿景 | 先补 L0 以身作则和 L1 打胜仗 |

## 行动 Checklist

- [ ] 定位自己当前主要在哪层（认同/结果/共识/成长/希望）
- [ ] L0 练习：选一个重要节点先自己做出来（以身作则）
- [ ] L1 练习：找一个没人做的难题主动扛下来
- [ ] L2 练习：把一个黑盒决策拆成白盒讲给团队
- [ ] L3 练习：本月给关键人 1-2 次 BE FASTER 反馈
- [ ] L4 练习：建 3 条希望表达（文化/相信/故事各一条）

## Critique

### 攻击者 1：情境领导力学派（Blanchard）——"层级模型忽略了情境适配"

**攻击论点**：层级模型暗示领导者应逐层爬升，但情境领导力证明：面对 D1（低能力低意愿）下属，指令式比"讲道理"更有效；面对 D4 下属，授权式比"带成长"更合适。五阶梯没有回答"对谁用哪层"。

**回应**：五阶梯描述的是领导力**影响力深度**的成长路径，不是每个互动的策略选择。下属差异化在 `tool-leadership-three-stubborn-subordinates`（三类棘手下属 = 能力×意愿矩阵）中处理。承认：卡内应补一句"层级是能力成长维度，不是每次互动都要用最高层"。

### 攻击者 2：John Maxwell 体系——"L0-L5 命名与 Position 层有语义冲突"

**攻击论点**：Maxwell 的 Position（职位层）是起点，而 KDO 把"认同"放最底层——但现实中最常见的领导力失败恰恰是"只有职位没有认同"。层级命名是否误导？

**回应**：KDO 五阶梯的 L0 认同层 = Maxwell 的 Permission 层（人们跟随因为"我愿意"），职位本身不算领导力（口述明确"领导力对标的不是老板的身份"L662）。命名差异是刻意的：不把职位当作领导力层级，避免"我有职位所以我有领导力"的错觉。

### 攻击者 3：成长型组织批评——"2×5 耐心标准可能被误用为绩效威胁"

**攻击论点**：2×5（五个项目学不会"再单说"）在压力文化下会被管理者当作辞退/威胁工具，安全空间名存实亡。

**回应**：口述原文语境是"给安全空间同时给压力"（L2262-2264）——2×5 是防"无限安全空间"的另一极端。正确用法：事先说清标准（"安全空间我先跟你说清楚"L2258），让对方有预期。承认风险：卡内应强调 2×5 必须事先沟通，不能事后翻旧账。

- **不要用的场景**：纯执行岗位、紧急决策、无共识前提的对话、把层级当"每次互动策略"

- **Action Triggers**：

  - 重点项目复盘 → 用 2×5 标准评估给下属的耐心空间是否无限
  - 高价值成员想走 → 检查 L5 希望表达是否缺失

## 可迁移场景

1. **带新人**：L0 安全氛围 + L1 稀缺优势建议（前三个月找小点）
2. **跨部门协作**：无职权 → 靠 L2 共识层讲道理推动
3. **KDO 工厂（Agent 团队）**：给 agent 派活讲清"为什么"（L2），带 agent 基本功（L4）——与老顽童带子代理同构
4. **个人成长规划**：用五阶梯定位自己当前层级，选下一步练习
