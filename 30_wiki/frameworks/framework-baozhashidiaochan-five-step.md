# 爆炸式调研五步法：目标→范围→搜索⇄建模→交付

> 本卡属于「调研系列课」体系第三块积木（宽=爆炸式调研）：核心方法是五步法——目标（明确+ROI 预判）→ 范围（收缩边界）→ 搜索⇄建模（循环，最难）→ 交付（做厚：分层/讲香/DataPack）。与挖掘式（深）、系统式 OSCAR（高）、自动式（动态）并列（framework-yitang-four-research-types 第四维"宽"）。

## 1. 核心洞察

爆炸式调研（案例大爆炸）解决的核心问题：调研时收集的信息随机、碎片、像盲人摸象（上 L184-196），同一关键词给 AI 的答案五花八门。解法不是"看更多"，而是**看到规律基本稳定为止**——饱和覆盖式地收集案例，直到模型稳定呈现规律（下 L3012-3022）。

五步范式（下 L2996-3030）：**目标 → 范围 → 搜索⇄建模 → 交付**。注意箭头——搜索和建模不是先后关系，是循环往复：搜索→建模→建不成再搜索→搜索完再建模，直到规律基本稳定体系（12 字终止标准）。

## 2. 五步详解

### 第一步：目标（L3042-3052）
- 目标要明确：调研究竟为了干啥，先努力锁定一个目标
- 与 AI 协作时：尽量告诉 AI 最终意图（所有工作的基础）
- 复杂调研先评估 ROI：花几个小时做"调研的调研"，收益是否足够大
- 目标要清晰和笃定

### 第二步：范围（L3054-3066）
- 收缩一个边界：我到底拿什么写
- 边界不清楚 → 无边无际地搜集资料
- 与 AI 协作时边界尤其重要：给 AI 模糊的任务 = AI 给你错误的结果（看着都行，实际跑分与目标无关）
- 专业做法：预判未来调研的重要渠道

### 第三步：搜索⇄建模（循环，最难）（L3068-3076）
- 搜索：收集信息，从各种渠道拿（搜索引擎/AI/现场/灵感闪现）
- 建模：**单开一个文档**，把信息合并整理、分享排序、寻找规律（呼应 concept-open-a-document）
- 循环：一直转，直到找到一个稳定的体系
- 这是五步中最难的一环，也是 AI 主要的工作（L3032）

### 第四步：终止判断（L3012-3022, L3076-3080）
- 何时终止：**规律基本稳定体系**（12 字）
- 再往里面加信息，发现框架都差不多、很难推翻 → 可以往后走
- 模型形态四种：**SABC 排序 / 一二三级分类 / 二维象限 / N 步法**
- 不要轻易结束：50 个还是 500 个，取决于看完 50 个之后，50-100 个还有没有明显优化你的体系（L3036-3038）

### 第五步：交付（做厚）（L3092-3110）
- 建完模很硬很抽象（过几周自己都看不懂）→ 必须做厚
- 做厚三种方式：
  1. **分层**：从抽象到具体分层（框架层/抽象层/方法层）
  2. **讲香**：包装成文档——给人看=好看的输出文档；给 AI 用=清单/文档/**DataPack 数据包**
  3. 让同事也能用（L3026-3028）

## 3. 借假修真（L3082-3092）

当规律稳定后，那些具体的调研案例、具体策略已经不重要了——**求真的那个框架、那个模型、那个规律本身最重要**。恭喜你找到了一个高价值的调研维度。这是爆炸式调研与普通收集的本质区别：案例是假的（借），模型是真的（修真）。

## 4. When NOT to Use

1. **单一信息点的调研**——只需要深挖一个具体情报时，用挖掘式（破案式），爆炸式过重。
2. **重要决策的推理式调研**——需要逐步推理、里程碑式推进时，用系统式 OSCAR（五步法第一步"调研的调研"评估会告诉你该用哪个）。
3. **时间极短的紧急调研**——一晚上都拿不出的调研任务，饱和覆盖的投入产出比不成立。
4. **线下为主的调研**——需要大量现场体验、体感信息的课题（AI 搜不着的信息），70% AI 模式不适用（下 L3928-3934）。

## 5. 失败模式

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 目标模糊 | AI 结果五花八门、跑分与目标无关 | 回到第一步：明确最终意图，写清楚要做什么决策 |
| 边界无边 | 资料越收越多收不住 | 收缩范围：明确"我到底拿什么写" |
| 只搜不建模 | 收集了一堆案例没有文档 | 单开文档：研究：顶级作品建模，刷一个存一个 |
| 过早终止 | 50 个案例就下结论，规律未稳 | 检查 50-100 个还有没有明显优化，有就继续 |
| 永不停歇 | 4000 个标题还觉得不够 | 用"规律基本稳定"判断：新信息已无法推翻框架 |
| 交付裸奔 | 模型抽象到过几周自己看不懂 | 做厚三件套：分层/讲香/DataPack |
| 案例当真 | 纠结具体案例细节不放 | 借假修真：框架模型规律才是真的 |

## 6. Action Triggers

- 面对"信息五花八门、盲人摸象"的调研任务 → 用五步法，先明确目标再收缩范围
- 收集资料 → 先开一篇文档（研究：顶级作品建模），刷一个存一个
- 模型开始成形 → 检查规律是否基本稳定（SABC/一二三级/二维象限/N 步法）
- 模型太抽象用不了 → 做厚：分层/讲香/DataPack
- 设计 AI 调研工作流 → 搜索⇄建模循环交给 AI，目标/范围/终止判断人把关
