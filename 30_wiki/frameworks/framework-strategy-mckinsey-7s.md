# 麦肯锡 7S 模型：组织诊断与变革管理

> 麦肯锡 7S 模型用于全面扫描组织的软硬要素，判断战略与组织能力的匹配度，尤其适合变革管理、数字化转型、并购整合等场景。

---

## 一、7S 全景图

```
                    ┌─────────┐
                    │  Style  │
                    │  风格   │
                    └────┬────┘
                         │
    ┌─────────┐    ┌────┴────┐    ┌─────────┐
    │Strategy │←→│ Shared  │←→│ Skills  │
    │ 战略    │   │ Values  │   │ 技能    │
    └────┬────┘   │共同价值观│   └────┬────┘
         │        └────┬────┘        │
    ┌────┴────┐        │        ┌────┴────┐
    │Structure│←───────┼──────→│ Staff   │
    │ 结构    │        │        │ 员工    │
    └────┬────┘        │        └─────────┘
         │              │
    ┌────┴────┐         │
    │ Systems │←────────┘
    │ 系统    │
    └─────────┘
```

---

## 二、七要素与诊断问题

| 要素 | 英文 | 核心问题 | 属于 |
|--|--|--|--|
| **战略** | Strategy | 我们的“期望业务设计”清晰、一致吗？ | 硬要素 |
| **结构** | Structure | 新模式需要跨部门协作吗？现组织架构支持吗？ | 硬要素 |
| **系统** | Systems | 需要新 IT 系统/流程吗？现有系统跟得上吗？ | 硬要素 |
| **技能** | Skills | 需要数字化/会员运营技能吗？团队有吗？ | 软要素 |
| **员工** | Staff | 需要新人才吗？招聘难度大吗？ | 软要素 |
| **风格** | Style | 领导风格是否亲抓变革？ | 软要素 |
| **共同价值观** | Shared Values | 文化是否接受“以客户为中心”？ | 软要素（核心） |

---

## 三、硬要素 vs 软要素

| 类型 | 要素 | 特点 | 变革切入点 |
|--|--|--|--|
| **硬要素** | 战略、结构、系统 | 相对容易识别和改变 | 常作为组织变革的切入点 |
| **软要素** | 风格、员工、技能、共同价值观 | 抽象，与文化和人相关 | 是组织内涵与核心，需要长期沉淀 |

> 共同价值观位于模型中心，是企业的 DNA，也是最难改变的部分。

---

## 四、使用步骤

1. **明确变革目标**：新业务设计、数字化转型、并购整合等。
2. **逐要素诊断**：对每个 S 回答核心问题，识别差距。
3. **找出错位点**：哪些要素支持变革，哪些要素阻碍变革？
4. **制定对齐计划**：调整结构、系统、技能、人员等，使其与战略和价值观一致。
5. **持续监控**：7S 相互关联，改变一个会影响其他，需动态调整。

## 六、Agent 执行指令

```python
def mckinsey_7s_diagnosis(change_goal: str):
    """用麦肯锡7S模型诊断组织与战略的匹配度"""
    elements = ["Strategy", "Structure", "Systems", "Skills", "Staff", "Style", "Shared Values"]
    prompts = {
        elem: f"针对变革目标「{change_goal}」，回答麦肯锡7S中 {elem} 要素的诊断问题：现状、期望、差距、行动。"
        for elem in elements
    }
    prompts["对齐检查"] = "检查七个要素是否相互支撑，识别最关键的错位点。"
    return {step: ask(prompt) for step, prompt in prompts.items()}
```

## 七、失败模式

| 失败 | 症状 | 修复 |
|--|--|--|
| 只调结构 | 改组织架构但系统、文化不变 | 7S 必须联动调整 |
| 忽视共同价值观 | 战略对但员工不买账 | 把价值观放在诊断中心 |
| 静态诊断 | 做一次就放下 | 变革过程中持续复评 |
| 只看硬要素 | 忽视领导风格和员工能力 | 软要素往往是变革失败根因 |
