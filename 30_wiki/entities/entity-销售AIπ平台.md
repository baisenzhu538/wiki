# 销售AIπ（salesaipai.com）——销售场景Agent工具平台

> 定位情报：外部竞品/KDO可对标结构——「科学销售方法论 + 零代码Agent封装 + 企业知识管理」三件套的平台化产品。与库内一堂系 agent-spec 工具卡群（方法论同构但未平台化）形成对照。

| 价值主张 | 复杂AI技术封装成开箱即用助手，「成单效率提升10倍+」（宣传口径，未验证） |

## 核心功能四件套

1. **20+ 专业 Agent 工具库**（三类）：
   - 科学销售系列：线索挖掘、客户画像分析、销售转化策略、卖点提炼、销售一页纸策略；
   - 专业工具内容生成系列：小红书IP规划师、图文案专家、会议纪要助手；
   - 日常管理系列：管理者日省五问、团队动力分析、商业模式设计。
2. **零代码 Agent 搭建器**：可视化界面创建专属Agent；自定义人设、提示词逻辑、大模型选择；多Agent流水线串联复杂业务；一键发布团队共享。
3. **企业知识管理**：PDF/Word/Excel/图片上传，AI解析为Agent可调用知识，企业专属知识沉淀。
4. **智能对话交互**：图片/文档附件解析、多轮对话记忆、会话历史回溯。

## 平台自述优势与适用客户

优势（自述）：专业聚焦销售商业领域、开箱即用（3秒上手）、每周迭代、企业级数据加密、多Agent按业务场景自由组合。

适用客户（自述）：要提升销售成单效率的创业公司/企业级客户；要提升销售团队管理效率的事业部。

## 对标价值（KDO视角，独立判断）

1. **工具矩阵即方法论产品化**：其「科学销售系列」五工具（线索挖掘/画像/转化策略/卖点提炼/一页纸）恰是 [[framework-arui-ai-six-fundamentals]] 销售三大基本功的Agent化落地——印证「方法论→系统提示词→封装Agent」路径已在市场验证。库内 `tool-agent-spec-yitang-*` 系列同构，但分散在vault未成平台。
2. **零代码搭建器=给「不会编程的业务者」的封装层**：对应阿蕊体系「六块基本功→封装Agent」的最后一步，把封装门槛降到零代码。
3. **企业知识管理=Agent的域知识底座**：与KDO「30_wiki是Agent的弹药库」同构——文档→Agent可调用知识，即KDO卡片的外部商业化形态。
4. **情报边界**：全部内容来自平台自述介绍文，无第三方评测、无用户量/留存数据，「10倍」为营销话术；作为竞品结构情报入库，不作效果背书。

## Critique（外部攻击者视角）

- 攻击1（信源单一）：仅平台自述文，功能真实性与成熟度未验证。
- 攻击2（同质化风险）：零代码Agent平台赛道拥挤（含库内已收录 [[紫鲸AI]] 等），其差异化仅剩「销售域垂直」一点。
- 攻击3（与公众号体系关系）：平台是方法论的变现载体，评估时应区分「方法论价值」与「平台产品价值」——方法论部分已单独入卡（框架卡）。

## Boundary（适用边界）

- 适用：KDO设计销售域Agent工具矩阵时的结构对标；评估「方法论平台化」路径参考。
- 不适用：作为工具推荐给业务方使用（未实测）；方法论学习（直接读框架卡/方法卡）。
