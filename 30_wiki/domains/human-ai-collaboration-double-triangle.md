# 域摘要：人机协作范式——双三角模型域

> 来源：王欢 AI 实战分享（2026-06-18）  
> 核心命题：AI 时代的人机协作，不是“更好的工具”，而是“身份切换”——从演员到导演，从任务到系统。  
> 本域由多个“双三角”结构构成：演员↔导演、任务↔产品↔系统、说↔想↔做、定义↔执行↔验收。

## 一、一句话讲清楚

本域研究“人如何与 AI 协作才能产生系统级价值”，核心答案是：**人从执行者升级为导演，AI 从工具升级为可编排的执行系统**。

| `framework-wanghuan-ai-five-level-ladder` | framework | 问答层 → 工作流层 → 作品层 → 产品/应用层 → 系统层 |

## 六、域间桥接

- **→ 鑫港湾医药零售域**：PACED 可用于患者沟通，AI 业务档案可用于药师/医生 agent 角色定义，OODA 可用于药柜运营迭代。
- **→ KDO 知识工厂域**：三层架构映射老顽童/王语嫣/欧阳锋分工，对抗式生成可用于卡片质量提升。
- **→ 一堂五步法域**：任务→产品→系统与五步法的“需求→产品内核→商业模式→增长→壁垒”可相互参照。
- **→ 纪浩 AI 技能域**：BITCOE 可与纪浩的 skill 设计方法结合，提升 agent 提示词稳定性。

## 七、双三角模型结构

```
三角 1：身份切换
        演员（执行者）
           ↘
              AI 执行 ←——→ 导演（定义者+验收者）
           ↗
        工具使用者        系统设计者

三角 2：价值跃迁
        任务（一次性）
           ↘
              产品（可复用）
           ↗
        系统（可编排）

三角 3：工具链
        说（输入/豆包）
           ↘
              想（推理/深度思考）
           ↗
        做（执行/TREE/Cursor）

三角 4：工作闭环
        定义（开头）
           ↘
              AI 执行（中间）
           ↗
        验收（结尾）
```

## 八、使用建议

1. **自我定位**：先判断自己当前是“演员”还是“导演”。
2. **选择杠杆**：从五层跃迁中找到当前层级，优先向上一层突破。
3. **建立标准**：用 BITCOE 和 AI 业务档案定义 AI 协作标准。
4. **构建闭环**：用 OODA 让每次人机协作都比上一次更快更好。
