# 域摘要：企业战略

> 冉鹏 · 30年战略咨询经验 · 一堂「引擎点火 · 战略破局」课程
> 战略不是定目标——是站在全局做出影响成败的艰难选择，更是一系列连贯性的选择与行动。

## 核心定位

战略域是 KDO 的**顶层调用者**——它不替代五步法/需求分析/决策/壁垒，而是把它们串成一条完整的决策链：

```
战略调用关系
├── 需求分析 → "这个市场值不值得进？"
├── 五步法   → "进去后怎么打？"
├── 决策     → "一号位怎么拍板？"
├── 壁垒     → "打下来怎么守？"
└── 调研     → "以上每一步的信息从哪来？"
```

### 📖 关键案例

| 案例 | 教训 |
|:--|:--|
| 长尾品类化妆品公司 | 天花板低时继续投营销=浪费——应拓展新品类 |
| 精品超市 O | 高速增长期追求利润而非增长→盈利反而下滑 |
| 清洁用品公司 | 盲目高端定位→丢失低端市场 |
| 家电公司 G | 重渠道轻研发→非空调业务失败 |
| IT 公司 H | 高层共识不足→多方向反复横跳→市值下降 |
| 手机公司 N | 组织形态不适应互联网化→产品迭代缓慢 |
| 良品铺子 | 涨价→暴跌→品牌升级+品类拓展+区域扩张→恢复增长 |
| Gucci | 重新定位客群+供应链调整+渠道掌控→起死回生 |
