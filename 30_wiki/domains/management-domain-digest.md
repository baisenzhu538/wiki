# 域摘要：一堂管理方法论

> 一句话：一堂管理域以「管理地图」五阶路径（管自己→管项目→管团队→管业务→管公司）为骨架，以「苦练基本功」为能力底座——**项目管事（事的最小单元），基本功练能力（能力的最小单元）**。
> 管理域现有核心卡约 49 张（concept 17 + 管项目 framework 5 + 管项目 tool 20 + 管理工具 6 + 地图 1），L4 关联的决策簇、业务公式簇另计。

## 核心定位

```
一堂管理方法论
├── 骨架：管理地图五阶路径（yt-model-management-map）
│   ├── L1 管自己 → 突破个人天花板（接个人修炼地图）
│   ├── L2 管项目 → 拿结果（四步闭环 + ABCD 分级）
│   ├── L3 管团队 → 带队伍（基本功 / 懂招聘 / 会落地 / 会开会 / 做沉淀）
│   ├── L4 管业务 → 驱动增长（管目标 / 提业务 / 做决策 / 提转化）
│   └── L5 管公司 → 治理组织（做战略 / 定文化 / 分股权 / 管财务）
└── 底座：苦练基本功子域（L3 管团队第一项基本功，本批新建）
    ├── 认知：基本功是组织能力的最小单位 + 三环六维判据
    ├── 方法：四字诀「拆 → 建 → 推 → 练」
    └── 工具：40 张工具卡（拆 6 / 建 7 / 推 7 / 练 20）
```

## 关键冲突调和（读卡前必读）

本域与既有卡片存在 4 处相邻/撞名，统一口径如下，生产与引用时以此为准：

| 冲突 | 双方 | 裁定 |
|:--|:--|:--|
| **「最小单位」命题** | `yt-management-project-management`：项目管理是公司**最小管理单元**（事）；本域：**人不是组织能力的最小单位，基本功才是**（能力） | **正交并存，不互斥**：项目=事的最小单元（目标落地的最小闭环）；基本功=能力的最小单元（能力复制/训练的最小颗粒）。管事靠项目，练能力靠基本功；项目恰好是基本功在「事」上的演练场 |
| **四字诀撞名** | 需求域「拆推评算」（`tool-demand-chai-tui-ping-suan-guide`：拆需求/推演/评估/算账）vs 本域「拆建推练」（拆动作/建模型/推共识/练重复） | **两套四字诀内容完全不同**，仅发音相近。本域卡标题一律带「基本功」前缀，related 不互链，避免混用 |
| **SABC 撞名** | 销售 ToB 客户分层 SABC（`yt-tob-customer-sabc`：按客户价值分 S/A/B/C 级配资源）vs 本域岗位能力段位 SABC（S 架构/A 专家/B 专项/C 基础） | **同名不同义**：一个是客户分层工具，一个是人员能力段位。引用时带域说明（销售 SABC / 基本功 SABC） |
| **段位体系并存** | 管理地图 L1-L5（管理**范围**进阶：管自己→管公司）vs 本域单项基本功 L1-L6（**熟练度**进阶）+ 岗位 SABC（**成长阶段**） | **三套刻度各管一维**：L1-L5 量管理范围，L1-L6 量单项熟练度，SABC 量岗位成长阶段；互补不替换 |
