# OPC AI 销售智能体架构

> 来源：2026-07-02 王语嫣 × 老朱 OPC 战略讨论
> 对齐框架：一堂科学销售五步法（A.提炼卖点 → B.拆解过程 → C.推进业绩 → D.激励团队 → E.打造工具）
> 更新规则：每次讨论OPC架构后更新此文件
> 最近更新：2026-07-02 补充 #47 / #49 共 7 张 agent-spec 卡及其调用关系

## 一、架构总图

```
┌─────────────────────────────────────────────────────────────┐
│                    OPC AI 销售中枢                          │
├─────────────────────────────────────────────────────────────┤
│ 输入层：官网/社媒/CRM/邮件/微信/通话/行为数据                  │
├─────────────────────────────────────────────────────────────┤
│ 认知层（识别 + 分层）                   对应五步法            │
│  ① 用户分层智能体       — SABC分级       → A.提炼卖点       │
│  ② 客户意图识别智能体    — 决策阶段/抗拒点  → B.拆解过程      │
│  ③ 竞品动态监控智能体    — 卖点对比更新    → A.提炼卖点       │
├─────────────────────────────────────────────────────────────┤
│ 策略层（分析 + 决策）                                        │
│  ④ 卖点提炼智能体       — 差异化话术/A/B测试 → A.提炼卖点    │
│  ⑤ 销售过程拆解智能体    — 里程碑/卡点预警  → B.拆解过程     │
│  ⑥ 报价与提案生成智能体  — 方案书/价格策略   → C.推进业绩    │
├─────────────────────────────────────────────────────────────┤
│ 执行层（接触 + 推进）                                        │
│  ⑦ 话术准备智能体       — 多场景话术生成    → E.打造工具     │
│  ⑧ 跟进编排智能体       — 时机/渠道协同     → C.推进业绩     │
├─────────────────────────────────────────────────────────────┤
│ 复盘层（学习 + 进化）                                        │
│  ⑨ 业绩预测智能体       — Pipeline预测     → C.推进业绩     │
│  ⑩ 销售复盘智能体       — 成交/丢单分析    → E.打造工具     │
│  ⑪ 知识沉淀智能体       — 案例库/话术库更新 → E.打造工具     │
└─────────────────────────────────────────────────────────────┘
```

## 二、各智能体详细定义

### ① 用户分层智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 自动给线索打 S/A/B/C 标签，判断客户值不值得亲自跟进 |
| 输入 | 客户官网、LinkedIn、聊天记录、行为数据 |
| 输出 | 客户画像卡片 + 推荐跟进策略 + 对应卖点版本 |
| 一堂模型 | 用户分层四步法（确定目标→分层假设→验证→执行） |
| 深挖点 | ①结合阶段性目标动态调整权重 ②识别假意向和真决策人 ③不同层级匹配不同话术版本 |
| 优先级 | **P0 — 第一个做**。分层错了后面全歪 |

### ② 客户意图识别智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 从对话中识别客户决策阶段、关心什么、抗拒什么 |
| 输入 | 聊天记录、通话转写、邮件往来 |
| 输出 | 意图标签 + 情绪分析 + 决策人类型 + 隐藏抗拒点 + 购买紧迫度 |
| 一堂模型 | 四类用户决策（接触/购买/付款/履约） |
| 深挖点 | ①不止识别"想买不想买"，识别决策人类型（技术/价格/关系/风险厌恶）②隐藏抗拒点（预算/信任/时机/替代方案）③与话术智能体联动 |
| 优先级 | **P1** |

### ③ 竞品动态监控智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 持续监控竞品，自动更新卖点对比表 |
| 输入 | 竞品URL、行业报告、客户反馈 |
| 输出 | 差异化卖点建议 + 防御话术 + 反击话术 |
| 一堂模型 | 卖点提炼四步法·第2步（建立卖点审美） |
| 深挖点 | ①竞品新功能→自动生成攻防话术 ②识别竞品弱点和客户抱怨转化为你的卖点 |
| 优先级 | **P2** |

### ④ 卖点提炼智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 针对不同客户生成差异化卖点和A/B测试版本 |
| 输入 | 客户画像、竞品对比、历史成功案例 |
| 输出 | 多版本卖点 + 推荐匹配策略 |
| 一堂模型 | 卖点提炼四步法（初始版本→审美→打磨→落地） |
| 深挖点 | ①话术A/B测试自动追踪转化率 ②多风格切换 ③多模态输出 |
| 优先级 | **P1** |

### ⑤ 销售过程拆解与里程碑预警智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 把每个客户的推进状态映射到标准销售流程，识别卡点 |
| 输入 | CRM数据、聊天记录、通话摘要 |
| 输出 | 客户当前阶段 + 下一步最佳动作 + 风险预警 + "本周最可能成交"清单 |
| 一堂模型 | 拆解过程三步法（拆路径→划阶段→配动作） |
| 深挖点 | ①自动计算各阶段转化率 ②关键节点停滞超阈值自动提醒 ③生成成交概率预测 |
| 优先级 | **P0 — 第二个做**。让OPC知道自己每天该做什么 |

### ⑥ 报价与提案生成智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 自动生成报价单、方案书、合同 |
| 输入 | 客户需求、产品服务清单、历史报价数据 |
| 输出 | 专业提案PDF + 合同草案 + 价格策略建议 |
| 一堂模型 | 业绩管理三步法·定策略 |
| 深挖点 | ①S/A/B/C分级定价 ②自动计算毛利率和最低可接受价 ③砍价时生成替代方案 |
| 优先级 | **P2** |

### ⑦ 话术准备智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 针对不同客户、场景、阶段生成多版本话术 |
| 输入 | 客户画像、当前阶段、客户问题、历史成功案例 |
| 输出 | 开场白、产品介绍、异议处理、逼单话术 |
| 一堂模型 | 卖点提炼四步法·第4步（落地应用场景） |
| 深挖点 | ①话术A/B测试 ②多风格切换 ③多模态输出 |
| 优先级 | **P1 — 第三个做**。依赖①②的输出 |

### ⑧ 跟进编排智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 决定什么时候、通过什么渠道、说什么内容跟进 |
| 输入 | 客户行为数据、历史跟进记录 |
| 输出 | 每日跟进任务清单 + 自动发送文案 + 沉默客户激活策略 |
| 一堂模型 | 业绩管理三步法·追过程 |
| 深挖点 | ①预测最佳跟进时机 ②多渠道协同编排 ③沉默客户自动激活 |
| 优先级 | **P2** |

### ⑨ 业绩预测智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 基于Pipeline数据预测收入 |
| 输入 | 客户阶段分布、历史转化率、销售周期 |
| 输出 | 月度/季度收入预测 + 风险预警 + Gap分析 |
| 一堂模型 | 业绩管理三步法·拆目标（乐观/中性/悲观三版） |
| 优先级 | **P2** |

### ⑩ 销售复盘智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 自动分析成交和丢单案例，提取关键因素 |
| 输入 | 成交/丢单案例、客户反馈、销售对话 |
| 输出 | 成交关键因素 + 丢单根因 + 话术优化建议 |
| 一堂模型 | Y模型·知行合一（假设→验证→复盘→迭代） |
| 优先级 | **P1** |

### ⑪ 知识沉淀智能体

| 维度 | 内容 |
|:---|:---|
| 做什么 | 把每次销售过程转化为可复用的组织知识 |
| 输入 | 成交/丢单案例、客户反馈、销售对话 |
| 输出 | 案例库更新 + FAQ更新 + 话术库更新 + 工具更新清单 |
| 一堂模型 | 打造工具·六维雷达图 |
| 优先级 | **P1** |

## 三、实施优先级

```
第一波（OPC MVP）
  ① 用户分层智能体      — 判断"值不值得我亲自跟"
  ⑤ 销售过程拆解智能体   — 让我知道每天该做什么

第二波（闭环成型）
  ② 客户意图识别智能体    — 知道客户在想什么
  ⑦ 话术准备智能体       — 知道该说什么

第三波（效率放大）
  ④ 卖点提炼智能体
  ⑥ 报价提案智能体
  ⑧ 跟进编排智能体

第四波（自我进化）
  ⑩ 销售复盘智能体
  ⑪ 知识沉淀智能体
  ③ 竞品监控智能体
  ⑨ 业绩预测智能体
```

### 4.2 各卡触发场景

| 对话阶段 | 触发的 agent-spec | 输出价值 |
|:---|:---|:---|
| **首次接触** | `tool-agent-spec-yitang-opening-3min` | 30 秒自我介绍 + 价值钩子 + 第一个开放问题 |
| **建立信任/诊断需求** | `tool-agent-spec-yitang-customer-segmentation` | S/A/B/C 分级 + 跟进策略 |
| **准备方案/话术** | `tool-agent-spec-yitang-value-proposition` | 针对该客户的 Top3 卖点 + 多触点话术 |
| **推进中** | `tool-agent-spec-yitang-sales-process-tracker` | 阶段判断 + 卡点 + 下一步动作 |
| **客户提出异议** | `tool-agent-spec-yitang-objection-handler` | 异议类型 + 真实顾虑 + 应对策略 + 回复选项 |
| **周/月复盘** | `tool-agent-spec-yitang-sales-performance-monitor` | Gap 诊断 + 优先级客户 + 下周策略 |
| **个人倦怠/拖延** | `tool-agent-spec-yitang-self-motivation` | 最小动作清单 + 动机提醒 + 倦怠预警 |

### 4.3 人机边界

- **Agent 做带宽**：信息处理、初稿生成、提醒预警、标准化判断。
- **人做判断**：首次信任建立、关键谈判、复杂异议、价格/合同/法律承诺、最终发送确认。
- **不自动执行**：所有 agent-spec 只输出建议，不直接发送消息、不修改 CRM、不代替创始人做最终决策。

## 五、OPC 特别注意事项

原版销售五步法假设"有销售团队"，OPC 需要改编：

| 原版 | OPC 版 |
|:---|:---|
| 拆目标到销售个人 | 拆目标到你自己的周计划 + AI智能体任务 |
| 周会三要点 | 你自己的周五复盘流程——AI帮你追Gap |
| 六维激励团队 | **不适用**。替换为OPC自我驱动机制 |
| 发钱设计 | 替换为你自己的现金流管理 |
