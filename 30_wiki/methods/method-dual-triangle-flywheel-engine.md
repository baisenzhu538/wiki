# 双三角飞轮引擎与制度化运行

> **一句话定义**：把一行双三角从静态模型变成动态飞轮，通过「审美↔场景」「体系↔数据」「创造力↔基本功」三个结构化反馈回路，让人机协作持续自我增强。

---

## 状态

本卡为第二批卡片占位符。完整内容将在第一批 12 张卡审阅通过后补充，包括：

1. 三个回路的详细设计
2. 每周飞轮日志制度
3. Agent-spec 卡的 `## 迭代日志` 规范
4. 月度飞轮回顾报告模板
5. 与 `kdo report --monthly` 的对接方式

---

## 核心要点（预览）

- **回路 1：审美 ↔ 场景**：审美判断 → 改进 Agent Prompt → 场景表现更好 → 人做更高层判断。
- **回路 2：体系 ↔ 数据**：方法论卡 → Agent 调用 → 执行结果 → 发现方法论 gap → 更新方法论卡。
- **回路 3：创造力 ↔ 基本功**：新 Agent/新域设计 → 工具/编译器降低建 Agent 成本 → 能设计更多 Agent。

---

## 最小可行动作

每次 Agent 协作结束或任务复盘时，在 `70_product/operations/dual-triangle-flywheel-log.md` 追加一行结构化日志。
