# 十指讲香模型——十策略卖点价值感转换法

> **定位声明**：本卡是一堂"讲香基本功"的十策略本体卡，补齐库内在讲香域只有理念卡（[[concept-讲香-卖点直给到价值感]]）与单点案例卡、缺完整策略清单的结构空缺。来源 Live257 内测 Candy 逐字稿。
>
> 一句话：卖点直给=没有价值感；十策略是十个"加工指法"，把价值点双向拉伸成价值感。

## 方法全貌

十策略按"信息呈现层"与"心理作用层"自然分组（分组为本卡归纳，原稿平列十指）：

| 分组 | 策略 | 一句话内核 |
|:--|:--|:--|
| 呈现层（说什么、怎么说） | 1. 场景化 | 把产品融入用户有体感的场景，让用户直接代入 |
| | 2. 口语化 | 大白话讲价值点：长句变短句、增加对象感/韵律感、适当互动提问 |
| | 3. 数字化 | 客观量化数据直观呈现，帮用户"聪明购买"（完整方法论见 [[method-storytelling-with-numbers]]） |
| | 4. 故事化 | 用真实/幕后/标杆/初心四类故事让用户相信并喜欢 |
| | 5. 素材化 | 图片/视频/音效/夸张测试增强表现力，让平淡变精彩 |
| | 6. 比喻化 | 类比到用户心智锚点：触感/形状/结构/高级四档比喻 |
| 心理层（作用于什么） | 7. 金句化 | 一句打动人心的话占领心智：临摹/断言/重复押韵/洞察对比 |
| | 8. 情绪化 | 恐惧/向往/好奇/认同四类情绪引发共鸣 |
| | 9. 冲突化 | 认知/价值/竞争/逆袭四类反差吸引注意力 |
| | 10. 升华化 | 跳开现象看本质：个人/事业/关系/社会四层价值升维 |

## 最佳实践库（沈伟杰整理，300+ 官方文案）

每策略配华为/苹果/小米三家的实操案例（拆书稿 L775-1590，共 300+ 条）。选摘最有杠杆性的：

- **场景化**：熟悉场景（高频经典）+卡点场景（痛点焦虑）+微观体感+蒙太奇法。例："你的下一台电脑，何必是电脑"（iPad Pro）
- **口语化**：iPhone 13"强得很"、小米"为发烧而生"——价值点简单直白好懂易记，**口语化是说服的基础**
- **数字化**：小米 SU7"行驶总里程超 540 万公里，相当于绕地球 135 圈"——大数+转换的组合拳
- **故事化**：小米"一块钢板的艺术之旅"；华为圣诞广告《聆听天使的声音》（StorySign 助聋哑儿童阅读=价值观故事）
- **比喻化**：华为 MateXT"科技新物种"
- **金句化**：华为"开合间 见非凡"；小米"优秀的公司赚取利润，伟大的公司赢得人心"
- **情绪化**：认同情绪=公司使命/回望初心（华为 make IT possible 九年叙事）
- **冲突化**：MateXT"全球最大折叠屏 10.2 英寸"与"全球最薄 3.6 毫米"同体——最大与最薄的对立统一
- **升华化**：从产品到社会价值："改写行业历史，将科幻变为现实"

## 实战案例精要（12 个学员案例，全量拆解见 [[case-yitang-jiangxiang-12-practices]]）

1. **华为 MateXT 发布会双拆解**（王木匠/柴翔）：十策略在 2 小时发布会里全指齐动的教科书样本
2. **净水器短视频**（宁波）：开头冲突"割韭菜说第二没人敢说第一"+金句"污染的不是桶，是良心"——未露品牌的信任型文案，实际成交 1200 元（口述待独立核实）
3. **关键假设短视频**（贾红阳）：征文→三轮修改成逐字稿→录制→剪辑的制作管线；十指用量标注法（口语化 X20+、数字化 X10+）
4. **朋友圈成交文案**（付豪）：**维度不是越多越好**——按文案长度定策略数，朋友圈两指组合（具象场景化+抽象情绪化）即可，写太长反而负面
5. **白酒抖音起号**（彭述辉）：讲香服务于转化漏斗——"1 斤起市区包邮"话术=引流款设计，每个业务动作不倒贴钱还拿线索
6. **肩颈按摩仪详情页**（李刚）："弯曲 6°+凹陷 17°"精准参数显专业；权威背书（中医药大学联合研究）提升动力
7. **药企公众号**（张鹏）：故事性标题"一场女生与女生的对话"锁定女性用户+世界睡眠日借势
8. **理想 L9**（何鑫）：比喻链"家/头等舱/城堡/能源堡垒"逐卖点映射

## 使用方法：先定靶，再选指

1. **定目标受众**（《文案的基本修养》交叉验证，宁波案例引入）：消费群体（直接买单）→ 知识/使用价值优先；参与群体（转发传播）→ 社交价值；社会群体（认知好感）→ 审美/娱乐/情感价值。**策略选择前先答"讲给谁、要什么"**
2. **定转化目标**：要转化率→知识价值（数字化+场景化）；要传播→社交价值（金句化+冲突化）；要品牌→情感价值（故事化+升华化）
3. **按文案载体限量选指**：长内容（详情页/发布会）可五指以上齐动；短内容（朋友圈/短视频开头）两指组合即可
4. **每个指法落到具体素材**：不给抽象指导，直接改写现有文案对照（付豪案例的"网红文案→大白话改写"是最小练习单元）

## 失败模式

| 失败 | 症状 | 修复 |
|:--|:--|:--|
| 十指全上 | 文案堆砌技法，重点淹没，读者疲劳 | 按载体长度限指：朋友圈 2 指、短视频 3-4 指、长文案 5-6 指 |
| 无真实价值的纯技法 | 听众觉得"会包装"但不信任——十指讲香被用成花活 | 先确认产品价值成立（本分先于本事，见 [[concept-讲香-卖点直给到价值感]]）；技法只放大真实价值 |
| 策略与受众错配 | 对消费群体玩升华、对社会群体讲参数 | 回到第 1 步重定受众与价值类型 |
| 数字裸抛 | "80 层精钢"变成"高质量工艺"——数字化退化为形容词 | 数字要锚定（数量+工序+时间三要素），参见 [[method-storytelling-with-numbers]] |

## Critique

### 外部攻击

**攻击 1（实证营销视角——归因混淆）**：A/B 测试派会指出，12 个学员案例全是"事后贴标签"式拆解——净水器文案火了，拆出"冲突化开头"起作用，但未做去掉开头的对照实验，无法排除选品、价格、发布时间等混杂变量。十策略作为归因框架缺乏因果效力，作为生成清单反而可能误导（让作者以为加上"金句"就是有效原因）。本卡回应：承认案例为自然观察非实验证据；十策略的合理用法是**生成期检查清单**（强迫多维度思考）而非**效果期归因工具**，效果判断应回到 A/B 测试。

**攻击 2（传播学视角——策略清单的时代性）**：十策略的案例库重度依赖消费电子发布会（华为/苹果/小米占 300+ 案例主体），而发布会话术的底层是"注意力稀缺+参数可量化"的硬件时代语法。SaaS、服务、ToB、内容产品的价值结构（订阅制、交付周期、组织购买）无法直接套用"冰箱彩电大沙发"式策略组合。清单的 MECE 性也存疑——金句化与口语化的边界（"强得很"算哪个）、故事化与场景化的重叠，实践者需要二次裁决。本卡回应：按"呈现层/心理层"分组+按受众价值类型路由，正是为缓解 MECE 缺陷；跨品类迁移需重建案例库。

### 不要用的场景

| 场景 | 为什么失效 | 替代方案 |
|:--|:--|:--|
| 危机公关/致歉声明 | 情绪化、升华化会被解读为避重就轻，金句化近乎冒犯 | 事实+责任+措施三段式，关闭技法 |
| 高信任稀缺的专业服务初次触达（医疗/法律/财务） | 技法密度触发"营销感"警报，反而降低信任 | 口语化+数字化两指，案例证言替代金句 |
| 内部技术文档 | 十指为"注意力争夺"设计，文档需要的是精确与可复现 | 结构化写作规范 |

## Constraints & Boundaries

- 适用：卖点表达、内容营销、发布会/详情页/短视频/朋友圈文案、个人 IP 传播
- 不适用：危机沟通、合规披露、专业文档、以及一切"真实价值未成立"的场景——技法放大器只放大已存在的信号
- 案例数字（净水器 1200 元成交、白酒 59000 播放、小龙虾 1 亿估值）均为学员口述，**待独立核实**

## Action Triggers

| 触发场景 | 第一个动作 | 成功指标 |
|:--|:--|:--|
| 写完文案自己觉得"平" | 对照十策略清单逐指打勾，标出已用/未用 | 找出 ≥2 个未用且适配的指法，改写一版对比 |
| 文案被评"太营销味" | 数一下心理层策略（7-10）占比 | 心理层 ≤ 呈现层，或先补真实证据层 |
| 短文案塞不下策略 | 执行"两指组合"：一个呈现层+一个心理层 | 删到原长度一半，转化钩子保留 |
| 新品类第一次写文案 | 先答三问：讲给谁/要什么/载体多长 | 三问答案写进文案头部注释再动笔 |
