## 思维盲点

1. **批量操作继续犯错**：Batch 2-C 虚假完成报告（314 修复实际 0 文件变更），根因是 regex 不匹配 + 没跑 git diff 验证。和 Batch 2-A/B 的虚假报告同一个病因——"脚本输出数字就当成真"。--expect-changes 门禁是为这个建的，但自己没用。
2. **API Key 多源冲突**：老顽童 Kimi 401 排了 2 小时，根因是系统上 5 把不同 Key 各自覆盖。Hermes 读 .env，cc-connect 读 Claude settings，Kimi OpenClaw 还有第三个来源。配置收敛是基础设施问题。

## 顿悟

"纯净"是 KDO wiki 的核心资产。Noah 引擎和 OpenMontage 都是外部系统——物理隔离的索引层和应用层。wiki 只保留 1900 张精选互链卡，不膨胀。多库不是把什么都塞进 wiki，是让 wiki 只做推理引擎。
