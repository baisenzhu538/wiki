# 老顽童复盘知识库（Producer）

本目录为 **老顽童**的每日认知复盘知识库，面向未来能力提升，非项目进度报告。
其他角色（欧阳锋、黄药师、洪七公、段王爷）各有自己的复盘目录。

## 触发词
用户说话中包含"复盘"二字时，老顽童自动执行每日复盘流程。

## 目录结构
```
daily_cognitive_review/
├── README.md                ← 本文件
├── 索引.md                  ← 知识库目录、统计
├── 错误模式库.md            ← 系统性错误跟踪
├── 技能进化日志.md          ← Keep/Improve/Add/Stop
├── 能力雷达图.md            ← 多维度自评分趋势
├── 用户反馈档案.md          ← 用户偏好/不满/建议
└── 每日复盘/               ← 按日期的详细复盘
```
