## 做得差的
**最蠢的是问题2——同一个坑掉两次。**

上次 Phase C 文章老朱就说过缺 Audience + Core Thesis，我当时修了，但**没建立强制检查机制**。这次写第三圈文章，结构又走老路：标题 → 直接进叙事。

根因是我写文章时的**默认模板有缺口**。我的 muscle memory 里，开头是"钩子叙事"，不是"Core Thesis → Audience → 钩子"。这是工业化写作的大忌——靠记忆靠不住，要靠 checklist。

**问题1的根因是字段规范没吃透。** contradicts 和 wiki_refs 不同，前者是 frontmatter 里的关系字段，用纯文本 id；后者是正文里的引用，用 `[[wikilink]]`。我批量补充时把两者混为一谈。

---

## 改进措施（下次执行时生效）

**文章写作强制 checklist**（写完后、提交前必须自检）：
```
□ Core Thesis 节存在（一句话论点，非引用块）
□ Audience 节存在（三级：主要/次要/不适合）
□ 正文 ≥2000 中文字符
□ wiki_refs ≥5 个，且有 ≥30 字关联说明
□ Kahneman System 1-2 洞察至少一处
```

**frontmatter 字段格式速查**：
- `contradicts:` → 纯文本 id，`- card-name`
- `wiki_refs:` → 纯文本 id（无 `[[ ]]`)
- 正文引用 → `[[wikilink]]`
