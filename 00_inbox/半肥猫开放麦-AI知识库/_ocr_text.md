# 胆囊结石与胆囊炎：饮食与生活方式要点（基于指南）

![清淡烹调与少油示意（占位）](images/guideline-06-meals-water.jpg)

## 概述与适用：

- 以低脂清淡与规律餐次为核心，避免暴饮暴食与重油重辣；术后康复按医嘱推进食物形态。

## 饮食要点：

- 限油少脂：烹调油25-30g/日内；避免油炸与肥肉、动物皮；选择蒸煮炖烩。
- 合理餐次：少量多餐，避免一次大量高脂餐；主食定量、蔬菜加倍。
- 蛋白来源：优选鱼禽蛋瘦肉与大豆制品；浓汤与重酱不推荐。
- 限酒控糖：酒精与含糖饮料不利胆囊与体重管理，建议不饮。

## 就医指征与安全提醒：

- 明显右上腹痛、发热、黄疸、持续呕吐或术后异常，应立即就医。
```

## 批注 2026-08-23 150123.png

**源文件**: `批注 2026-08-23 150123.png`
**处理时间**: 2026-08-23 15:21:01

一般人做标注，可能就是把**食材、克重、操作步骤**写清楚就完事了。这些当然是基础，也很重要。但我在这个基础之上，**还继续深挖了好几层**。

**第一层，专业维度。** 写清楚中医怎么解释这道汤的原理、西医营养学怎么解释、什么人适合喝、什么人不能喝，甚至连热量算法都标上去。

**第二层，平台风控。** 我专门建了一套**敏感词映射表**。比如"便秘"这个词发出去可能直接被限流甚至封号，我就提前标注好，让AI自动替换成消费者能听懂、平台又安全的说法——叫"噗噗"。

**第三层，受众话术。** 光有专业知识还不够，**对不同的人得说不同的话**。我会预置好几套话术——面对中医受众就讲经络温补；碰到有人拿西医知识来质疑，马上切换到有效成分和作用原理。**同一份数据，话术全都提前埋好了。**

**第四层，视觉维度。** 这个产品呈现时该用什么色调、什么风格的图片提示词——我提前就标好了，为后面AI生成配图做准备。

**第五层，经验边界。** 比如会写"当归要后下，出锅前十分钟才能放，早放药性就散了；枸杞也是，起锅前五分钟放，煮久了反而不好"。这种东西，你让AI自己去搜、去猜，它永远猜不到，**只有在这个行业摸爬滚打了多少年，才一点点攒得出来。**

其实很多时候，工具层面的东西，花时间都能学会。真正难的是标注的内容本身。

说白了，**标注的质量取决于你对行业的理解深度。**
