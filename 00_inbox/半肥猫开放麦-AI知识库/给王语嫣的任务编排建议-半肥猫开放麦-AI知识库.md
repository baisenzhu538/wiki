## 二、知识体系核心结构

### 2.1 主模型：五阶段演进（贯穿全程的唯一主线）

```
阶段1 内容生产    阶段2 RAG检索    阶段3 Workflow    阶段4 数字员工    阶段5 多AI协同
把知识带进对话 → 让AI自己查资料 → 让团队能用 → 让能力灵活组合 → 让多工具协同
─────────────────────────────────────────────────────────────────────────────
提示词/专业资料/   原子化拆分       工作流六要素       Skill封装         项目知识库五件套
成功案例           YAML标签        飞书机器人入口    岗位制数字员工     （总控/需求/清单/
Markdown化        分库管理         多维表格回流      QBD2 29字段      收件箱/归档）
                  映射表联动       隐性知识显性化     MCP API化        关键节点人验收
```

### 2.2 四个关键词（课程的"魂"）

| 关键词 | 核心表达 | 对应方法论 |
|-------|---------|-----------|
| **协作桥梁** | AI是发动机，知识库是燃料；发动机可以换，燃料必须自己的 | 知识库=资料/经验/判断的资产底座 |
| **问题驱动** | 先问"卡在哪个动作上"，不追工具 | 每次升级都是被具体问题逼出来的 |
| **范式复利** | 拆分问题→设定标准→小步验证→沉淀可复用结构 | 黑盒变白盒，从Photoshop说明书到AI知识库 |
| **拒绝焦虑** | 找到自己在AI地图中的位置（三类人） | 底层研发/模型之上做产品/直接使用工具 |

### 2.3 核心公式与框架（可直接成卡）

- **知识卡片公式**：YAML标签（给AI看）+ 原子化正文（给人看）= 知识卡片
- **加卡片/加标签原则**：知识不够→加卡片；索引不到→加标签（业务强绑定，半肥猫实测29字段够用）
- **知识库四象限资产**：私有事实 / 经验判断 / 业务边界 / 可复用输出（图1，最核心可复用框架）
- **知识加工六步**：收集→清洗→原子化→加字段→分库→调试
- **Workflow六要素**：知识库 / Prompt规则 / 检索方式 / 明确任务 / 输入输出标准 / 验收方法
- **内容Workflow八步**：定位→用户研究→选题→脚本→素材→发布→私域承接→复盘
- **项目知识库五件套**：总控文档 / 需求说明 / 任务清单 / 收件箱 / 结果归档区
- **标签五层深挖**（批注图）：专业维度 / 平台风控 / 受众话术 / 视觉维度 / 经验边界
- **人类价值四件**：审美 / 远见 / 信念 / 勇气
- **金句**：技术是公器，经验是私产

### 2.4 概念网络

```
AI资产问题/个人经验问题（两个预热思考题）
├── 知识库 ≠ RAG（知识库是底座，RAG是调用方式）
├── 注意力机制 / 上下文窗口（桌子比喻）/ Garbage In Garbage Out
├── 原子化（按语义切分，非按字数）
├── YAML标签（title/type/topic/source/tags/version/audience/kb_id...）
├── 分库管理（专业领域库/流量运营库/人设表达库 + 映射表联动）
├── Workflow（Coze/n8n，六要素）
├── Skill（提示词+查询代码+路由+边界+验收，不只是提示词）
├── Agent（拥有多项技能的员工，按任务调度）
├── 数字员工（丁定位/固画像/赵选题/温脚本...按线下岗位组织）
├── QBD2结构（29字段标签体系，跨岗位共享）
├── MCP（数字员工API化，接入本地工具）
├── 项目知识库（多AI协同的"共同协议"）
└── 知识来源六类（商业实操/数据反馈/行业报告/平台规则/AI复盘/活动方案）
```

## 五、给王语嫣的特别提醒

1. **本课与KDO体系高度同源** 🔥：半肥猫的"Obsidian+Markdown+YAML标签"笨办法，正是楚门（Truman）在一堂团队选型Obsidian搭建AI协作知识库时吸收延续的思路——**建议在卡片中标注这一传承关系**，能让学员理解"一堂的KDO体系为什么长这样"。

2. **最独特的产出定位**：半肥猫不是讲"知识管理理论"，而是讲"一个非程序员如何被问题驱动着从零长出一套可售卖的多AI系统"。建议卡片命名走**"问题→解法"**叙事（如"资料太多AI找不到→原子化拆分"），而不是纯概念名。

3. **标签颗粒度是深水区**：半肥猫明确说"真正难的不是打标签动作，而是知道标什么颗粒度"（批注图五层深挖法）。建议在B档手册中把这一点作为核心教学点，配膳食指南/胆囊结石两个真实卡片范本。

4. **风险提示**：课程中提到"AI删了我的测试文档还不承认"、"AI只打补丁不找根因"——这是很好的反面教材，建议在C档案例中保留原汁原味，不美化成"全自动成功"。

5. **最高ROI产出**：**A档卡片1（五阶段演进）** 和 **B档手册1（长文到卡片）**——学员"拿到就能用"，是复利最高的两件产出。
