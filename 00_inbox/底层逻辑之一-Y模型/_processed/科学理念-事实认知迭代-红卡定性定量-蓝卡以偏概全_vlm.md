【核心内容】

- **红卡主张**：面对高复杂度事实时，必须从定性走向定量，追求全面准确的描述——而非止步于模糊感受。
- **定性定量的四层递进**：单一样本 → 简单定性 → 区间定量 → 精准定量，每上一层对客观事实的理解就更逼近真相。
- **蓝卡警示**：以偏概全就是把单一案例升格为普遍规律，其典型表现包括单一维度、单一视角、单一点决策、不验证、幸存者偏差。
- **正反对位关系**：红卡的"全面准确"与蓝卡的"信息不足就下判断"形成因果对应——后者正是前者的反例。
- **红蓝闭环**：蓝卡"如何调整"一栏直接指回红卡，说明本套体系不是单向说教，而是"识别错误模式→调用正确方法"的自洽回路。

【结构化解析】

**① 定性定量层级表（从低到高）**

| 层级 | 形态 | 信息密度 | 典型风险 |
|------|------|----------|----------|
| L1 单一样本 | 拿一个例子代表整体 | 极低 | 极易以偏概全 |
| L2 简单定性 | 判断好坏、高低、强弱 | 低 | 判断粗糙但可大致归类 |
| L3 区间定量 | 给出大致数值范围 | 中 | 有方向感但精度有限 |
| L4 精准定量 | 有准确统计数字 | 高 | 最接近真相 |

**② 以偏概全的"症状词云"（六种典型表现）**

| 症状 | 含义 |
|------|------|
| 单一维度 | 只用一个指标衡量（如只看销量不看利润） |
| 单一视角 | 只从一个立场观察（如只听用户不看数据） |
| 单一样本 | 用一个个案推导普遍规律 |
| 单点决策 | 在信息未充分时拍板 |
| 不会验证 | 假设不检验、不复盘 |
| 幸存者偏差 | 只看到成功者而忽视沉默的失败者 |

- 本卡位于"一葙科学方法论·理念卡牌"的**第10对**，属于"**认识论/方法论**"模块而非具体技能卡。

【落地应用建议】

**1. 决策前的"四阶升级问诊"**
任何判断先用上面四个层级自检：现在我处于哪一级？如果停留在"单一样本"或"简单定性"，立刻补足数据；能上到"区间定量"再做决定；"精准定量"留给需要复盘的高价值决策。

**2. 当识别到自己"以偏概全"时的红队清单**
立刻在脑内勾选六个症状：维度是否单一？视角是否多元？样本量是否≥3个？信息是否充分？结论是否验证过？是否只看到了幸存者？任何一项打勾，先暂停决策，调用红卡的"层级升级"流程补救。

**3. 把判断写成"区间句式"而非"点句式"**
训练表达习惯：从"这件事很赚钱"（单一点）→ 改为"这件事毛利率大约在 X%–Y% 区间，受 A、B 两个变量影响"（区间+维度）。这是把蓝卡陷阱直接编码进语言系统的最小可执行改造。
