# 善于练习

善于营造专项练习的机会来练基本功

> 刻意设计一些围绕"关键动作"的专项练习，快速提升基本功水平。

- ○ **背诵练习**：直接把关键话术/方法/案例进行背诵和复述
- ○ **教学练习**：要求能给别人讲清楚，通过输出倒逼输入
- ○ **复刻练习**：找到最佳实践，自己动手临摹二次实现
- ○ **模拟练习**：创造仿真环境，进行内部模拟任务练习
- ○ **桌下练习**：不以实际交付为目标，自己主动偷偷练习

**一堂案例**：教研为了练习文案基本功，无论是否采用，每节课都写招生文案
**同学案例**：丹同学为了练习剪辑基本功，找到一个爆款视频的原片复刻剪辑
**同学案例**：蒋同学为了练习用户破冰基本功，每天背诵内部沉淀的有效话术

## 核心主题

这张图出自"苦练基本功练习卡"，主题是**如何通过专项练习来高效提升基本功**。核心观点是：基本功的提升不是靠零散学习，而是要**刻意设计围绕关键动作的专项练习**，将练习机会融入日常工作流中。

## 结构化内容

### 善于练习：五种专项练习方法

| 练习方式 | 操作方式 |
|---------|---------|
| **背诵练习** | 直接把关键话术/方法/案例进行背诵和复述 |
| **教学练习** | 要求能给别人讲清楚，通过输出倒逼输入 |
| **复刻练习** | 找到最佳实践，自己动手临摹二次实现 |
| **模拟练习** | 创造仿真环境，进行内部模拟任务练习 |
| **桌下练习** | 不以实际交付为目标，自己主动偷偷练习 |

### 实战案例

- **一堂内部案例**：教研团队 → 每节课写招生文案（练文案基本功）
- **学员案例 1**：丹同学 → 复刻爆款视频原片（练剪辑基本功）
- **学员案例 2**：蒋同学 → 每天背诵有效话术（练用户破冰基本功）

## 一句话总结

基本功不是练出来的，而是"设计"出来的——围绕关键动作设计背诵、教学、复刻、模拟、桌下五种专项练习，让练习嵌入日常业务流程，才能快速提升个人与组织的能力底线。
