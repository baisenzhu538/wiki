## 核心主题

这张图介绍了一种叫"六维分析"的方法，用于从众多动作中识别出最关键的基本功。核心思想是：组织能力的最小单位不是人，而是基本功——因此需要用"足够务实（具体性+场景性）、足够可练（独立性+检验性+重复性）、足够价值（复利性）"三个维度来筛选真正关键的基本功。

## 结构化内容

### 六维分析框架

```
            ┌─────────────────────────────┐
            │       足够务实（蓝色）       │
            │     具体性 ← → 场景性       │
            └──────────────┬──────────────┘
                           │
    ┌──────────────────────┼──────────────────────┐
    │  足够可练（粉色）     │      足够价值（黄色）   │
    │  独立性              │      复利性            │
    │  检验性  ──→ 重复性  │                       │
    └──────────────────────┴──────────────────────┘
                           │
                    关键基本功（三者交集）
```

### 三个筛选维度

| 维度 | 包含要素 | 作用 |
|------|---------|------|
| **足够务实** | 具体性、场景性 | 避免"太虚了" |
| **足够可练** | 独立性、检验性、重复性 | 避免"价值低" |
| **足够价值** | 复利性 | 长期累积效应 |

### 应用案例

| 来源 | 对象 | 通过六维分析发现 |
|------|------|-----------------|
| 一堂案例 | 教研 | 算单元模型/夸讲师 **不是** 关键基本功 |
| 张同学案例 | 销售 | 同理心 **不是** 关键基本功 |
| 古同学案例 | 店长 | 销售能力 **不是** 关键基本功 |

## 关键概念

- **六维分析**：识别关键基本功的筛选方法
- **关键基本功**：组织能力的最小单元
- **足够务实**：具体性 + 场景性
- **足够可练**：独立性 + 检验性 + 重复性
- **足够价值**：复利性
- **拆解卡**：用于分析基本功的工具
- **组织能力**：由基本功而非个人构成

## 一句话总结

通过"足够务实、足够可练、足够价值"三个维度的六维分析，可以从众多动作中精准筛选出真正关键的基本功——而识别人才的关键，不在于人本身，而在于其掌握的关键基本功。
