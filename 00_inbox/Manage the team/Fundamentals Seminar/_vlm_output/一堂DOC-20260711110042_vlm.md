## 核心主题

这张图出自「一堂」Yitang 必修课，提出了一套将模糊管理逐步升级为制度化执行的"关键基本功"成长路径。其核心思想是：管理者应根据业务不同阶段（稳定重复、必经之路、认知成熟、分层矛盾、组织扩大）主动升级工具，分别通过拆关键、起名字、模型化、阶梯化、制度化六个步骤实现工作的可拆解、可复制、可传承。

## 关键概念

- **关键基本功**：管理者从经验走向体系化的核心能力
- **拆关键（加法/减法）**：依靠框架、专家、同行、复盘做加法；聚焦业务当前目标、三环六维做减法
- **起名字**：通过差异化、动词化让概念可传播
- **模型化**：本质/方法论 → 清单/画布 → SOP/配套检查
- **阶梯化（L6 / SABC）**：阶段拆解 + 岗位拆解
- **制度化**：文化 + 知识库 + 培训 + 绩效/职级/晋升
- **主动升级**：根据组织规模与发展阶段持续更换管理工具

## 一句话总结

Yitang「一堂」必修课将管理者的成长路径压缩为六步——**模糊管理 → 拆关键 → 起名字 → 模型化 → 阶梯化 → 制度化**，并提出"扫码辛苦学3天，不扫弯路走3年"的强行动呼吁。
