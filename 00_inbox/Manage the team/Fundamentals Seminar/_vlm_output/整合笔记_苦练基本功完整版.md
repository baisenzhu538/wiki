## 二、课程结构

### 第一节：基本功方法论入门（认知篇）

**核心命题**：基本功是团队能力的最小单位。

| 概念 | 内容 |
|------|------|
| 定义 | 针对具体场景的独立可检验动作，通过重复练习形成长期复利 |
| 痛点 | 工作名称不一致、能力描述模糊、新人畏惧复杂任务 |
| 价值 | 管理颗粒度精细化、能力可复制可检验可迭代、形成成长飞轮 |
| 四字诀 | 拆（识别动作）、建（建立模型）、推（推动团队）、练（反复重复） |
| 三环模型 | 足够务实（具体+场景）、足够可练（独立+可检验）、足够价值（重复+复利） |
| 四类工作 | 创造类→专业化、专业类→领先化、领先类→标准化、标准类→SOP化 |
| 段位 | SABC 划分，明确各阶段学习目标 |

**典型案例**：
- 创造类：熊猫现烤汉堡（建池子 + 多轮减法）
- 专业类：李志宏团队（拆解 5 个销售能力 + 3 级闯关）
- 领先类：张扬团队（文案标准化 + 主播演员化）
- 标准类：北辰青年（严格 SOP + 有人味儿的 SOP）

### 第二节：基本功拆解与落地（拆解篇）

**核心命题**：把复杂能力拆成最小可执行动作。

#### 四大卡点
1. 缺乏意识
2. 不会建模
3. 难以落地
4. 重复不足

#### 关键基本功的三大特性
- 足够有价值：高频重复 + 长期复利
- 足够务实：具体场景化，避免"产品 sense"这种模糊概念
- 足够可练：独立动作组合，可检验效果

#### 四种拆解方法
| 方法 | 说明 | 适用 |
|------|------|------|
| 靠框架拆 | 自上而下按工作流/岗位/用户体验拆 | 中期团队 |
| 靠专家拆 | 从高手/销冠的重复动作中提炼 | 有标杆时 |
| 靠外部拆 | 参考行业标杆（如美团通用基本功） | 向外看时 |
| 靠复盘拆 | 从意外结果中挖掘关键动作 | 项目结束后 |

#### 命名原则
- 宽而不泛（如"QR"而非"信息搜集"）
- 简单上口（动名词结构）
- 差异化（避免日常用语）

#### 建模方法
- 思考框架：解决不确定性（Y 模型、STC 模型）
- 执行框架：解决稳定性（清单、SOP）
- 知识萃取工具：复盘提炼模型

#### 段位体系
- STC 模型：S 级（架构）/ A 级（专家）/ B 级（专项）/ C 级（基础）
- 单一基本功：入门 → 进阶 → 高阶（L1-L6）

### 第三节：基本功方法论武器库（武器库篇）

**核心命题**：把方法论变成 40 张可直接用的工具卡。

#### 科学练习四要素
- 套路（固定方法）
- 非舒适区（挑战边界）
- 大量重复（形成肌肉记忆）
- 及时反馈（复盘、交叉评审）

#### 苦练基本功全景地图

```
四字诀：拆 → 建 → 推 → 练

拆：找到关键独立动作
  ├─ 做加法：框架拆/专家拆/外部拆/复盘拆
  ├─ 做减法：三环模型筛选
  └─ 稳定命名：朗朗上口

建：构建固定套路
  ├─ 本质要素：1-5 个核心原则
  ├─ 方法论：关键步骤与因果关系
  └─ 清单/模板/SOP：从检查到标准化流程

推：形成团队共识
  ├─ 循序渐进：先 1-3 个，从标杆开始
  ├─ 分层段位：新老员工不同成长阶段
  └─ 启动会：明确理念、点燃动力、提出规则

练：大量重复与反馈
  ├─ 氛围提醒：挂在嘴边、文字化、文化墙
  ├─ 工具训练：专项练习、复盘、会议融入
  ├─ 流程管控：计划、记录、考核
  └─ 制度保障：绩效、职级、晋升挂钩
```

### 第四节：基本功落地案例篇（春萍）

**核心命题**：AI 时代下，基本功更重要，而不是更不重要。

#### 三个真实案例

| 案例 | 背景 | 落地动作 | 成果 |
|------|------|---------|------|
| 刘伟 | To B 大客户销售标准化 | 拆解销售动作到极致（见客户第一句话、穿衣服），形成"18 般武艺" | 年销售额 +130%，利润 +20% |
| 温校长 | 校园代理招生标准化 | 拆解招生链路（加微信、促转化），建立 SABC 段位 | 代理收入 +2-3 倍，年营收 800 万 |
| 花总 | AI 时代研发能力升级 | 拆解研发能力 → 培养实习生 → AI 替代基础工作 → AI+基本功 | 算法评估从 1 周缩短至 1 天 |

#### 基本功的四层解读
1. **实质**：组织能力的最小单位，支撑业务的重复核心动作
2. **关键基本功识别**：三环模型判断（务实/可练/价值）
3. **落地四大要素**：拆、建、推、练
4. **体系演化路径**：模糊 → 拆解 → 命名 → 建模 → 阶梯化 → 制度化

#### AI 时代的变与不变

| 维度 | 不变 | 变化 |
|------|------|------|
| 拆 | 从业务拆解开始 | AI 提示词工程也要拆任务边界 |
| 建 | 建模逻辑一致 | 需为 AI 建模（提示词模板、上下文工程） |
| 侧重点 | —— | 人类重"推"和"练"；AI 重"测试"和"工程化" |
| 新基本功 | —— | AI 全网调研、提示词工程、智能体协作 |
| 协作范式 | —— | 嵌入模式 / 副驾模式 / 智能体模式 |

**核心结论**：基本功仍是必经之路。AI 是工具（外骨骼），核心能力（肌肉）需通过苦练获得。AI 倒逼人类专注判断、创造和审美。

```

        │

第二层 对象：五类高频重复工作（创造/专业/领先/标准/SOP）

```

## 六、与双三角/OPC 的关联

### 与双三角模型的呼应

| 双三角 | 基本功体系对应 |
|--------|--------------|
| 人的审美 | 雷达图建模、段位标准（什么算 60/80/99 分） |
| 人的体系 | 四字诀、全景地图、SOP |
| 人的创造力 | 美好作品想象、跨领域迁移 |
| AI 场景 | AI 全网调研、提示词工程等新基本功 |
| AI 基本功 | 为 AI 建模（提示词模板、上下文工程） |
| AI 数据 | 知识库沉淀、案例库、复盘数据 |

### 对 OPC 建设的启示

1. **OPC 的本质就是把个人能力拆成基本功**：每个人/Agent 都有可识别、可练习、可评估的基本功
2. **40 工具卡可以直接改造为 OPC 智能体的 Skill 体系**：
   - 拆 → 任务拆解 Skill
   - 建 → 模型构建 Skill
   - 推 → 协作推动 Skill
   - 练 → 迭代练习 Skill
3. **AI 时代基本功**：提示词工程、上下文工程、智能体协作、全网调研
4. **段位体系**：可以套用到 Agent 能力评估（L1-L6）
