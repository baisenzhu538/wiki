# 项目敏感度模型

| 敏感点 | 内容 |
| --- | --- |
| 1.预算敏感 | 是不是对于费用很敏感，不希望超出预算？ |
| 2.时间敏感 | 是不是对于DeadLine很敏感，不太接受延期？ |
| 3.人力敏感 | 是不是人力投入敏感，中途加人很不容易？ |
| 4.协作敏感 | 是不是协作方信任敏感，得让大家觉得你靠谱、可靠？ |
| 5.风险敏感 | 是不是项目有一定风险，得好好管理，避免整体失败？ |
| 6.老板敏感 | 是不是老板特别关注，你希望老板放心，甚至开心？ |
