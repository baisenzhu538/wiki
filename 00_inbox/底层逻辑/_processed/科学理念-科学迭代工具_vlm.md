# 科学理念-科学迭代工具

【OCR原文】

我们按照偏理论和偏事实分类，再尝试合并一下同类项，同时关联其他部分，严谨化一些，于是**我们就有了四大科学迭代工具**：

1. **定性定量**：调研和实验分析，全面准确地理解客观事实。
2. **科学类比**：用辩证的、交叉类比的方法使用规律，理解内核边界。
3. **假设驱动**：勇敢提出一些前置假设，用假设驱动推进工作。
4. **提炼建模**：不要怂，练习自己建模、抽象一些客观的规律。

【核心内容】

- **分类逻辑起点**：按"偏理论 vs 偏事实"两条轴划分，并合并同类项，形成迭代工具集合。
- **四大工具并列**：定性定量、科学类比、假设驱动、提炼建模，构成一个完整的"从认识→理解→推进→抽象"的方法闭环。
- **每条工具都指向不同认知动作**：理解事实 / 利用规律 / 推进未知 / 抽象规律，互补无重叠。
- **隐含递进关系**：认识事实 → 迁移规律 → 提出假设 → 自主建模，形成"使用者→创造者"的能力跃迁。
- **贯穿姿态**："勇敢""不要怂"等措辞强调——科学方法不仅是认知工具，更是敢于下注的实践态度。

【落地应用建议】

1. **接到新问题，先过四问再选工具**：
   - 是事实不清？→ 用 **定性定量**
   - 是别处有现成规律？→ 用 **科学类比**
   - 是没人知道答案？→ 用 **假设驱动**
   - 是需要造新框架？→ 用 **提炼建模**

2. **刻意练习跃迁**：给自己设一条规则——本月只用 L1/L2 工具，下月强制用 L3/L2，半年后就能自如在四层间切换，避免长期停留在"调研员"层级。

3. **团队分工映射**：将四人/四组分别压在不同工具上（事实组、类比组、假设组、建模组），定期汇总碰撞——本质是用"四象限"防止群体思维单极化，比单纯头脑风暴产出更锐利。
