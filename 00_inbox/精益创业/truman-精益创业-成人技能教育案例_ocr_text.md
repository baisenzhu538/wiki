# 成人技能教育案例

提供在线学习视频剪辑的课程,面向三四线已经购买过初级课程的用户,判断能否完成二次销售。

| | Before | After |
|---|---|---|
| 做法 | 开始做一系列准备工作:<br><br>1. 做课,招5个课程研发+3个设计师,花4个月交付28天的训练营。<br>2. 招聘运营团队,设计SOP和服务体系,至少需要1个月。<br>3. 招主播讲师 + 培训主播讲师,至少2个月。<br>4. 准备大量企微账号,甚至需要注册新公司,需要3个月到半年<br>来养号。 | 核心验证:用户到底是对提升技能、还是在TikTok变现、还是在视频号抖音变现有需求?<br><br>三轮验证:<br>1. 第一轮,假设用户对提升剪辑技术有需求,开始卖海报。<br>2. 第二轮,假设用户对TikTok变现有需求,开始卖海报。<br>3. 第三轮,假设用户对视频号和抖音变现有需求,开始卖海报。 |
| 结果 | 至少花费百万费用,顺利的话需要4个月才能开始第一轮测试。 | 三个Top级别班主任+业务负责人带头协作,3个月跑通,最后业务贡献了500万月营收。 |
