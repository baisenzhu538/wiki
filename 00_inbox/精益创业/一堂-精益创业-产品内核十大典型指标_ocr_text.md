# 一堂产品内核·十大典型指标

| 环节 | 指标 | 一句话说明 |
|------|------|------------|
| 获客环节 | 销转率 | 看潜在客户转化为实际购买客户的比例 |
| 获客环节 | 动销率 | 看有销售的商品品种数与所有商品总品种数的比例 |
| 获客环节 | 捕获率 | 看进店消费人数占总经过人流量的比例 |
| 服务环节 | 留存率 | 看使用产品的用户，N天/周/月后还在持续使用的比例 |
| 服务环节 | 完课率 | 看用户是不是能完成履约和最后学习 |
| 服务环节 | 退款率 | 看服务履约中，用户退款的比例 |
| 服务环节 | 满意率 | 看用户接受完服务，满意度的比例和打分 |
| 复购环节 | 复购率 | 看消费购买后，会继续购买的比例 |
| 复购环节 | 续费率 | 看续费用户数占有用户数的比例 |
| 复购环节 | 推荐率 | 看用户是否愿意主动推荐的比率 |
