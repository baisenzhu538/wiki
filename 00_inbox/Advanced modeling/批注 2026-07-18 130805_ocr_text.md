# 建模通用的步骤有四步

从固定范围，到探索关系，再压缩成模型，最后解压成可实践的工具。

**建模前的自我追求**
- 学员课前
- ROI物品
- 江湖地位
- 人生红点

**01 固定范围**
找到建模的边界和范围
- 反应 / 范围 / 场景 / 外部类型
- 统一标准 / 统一行为 / 行动原则 / 思维习惯
先决定研究哪一块

**02 探索关系**
找出高价值的内在关系和因果规律
- 关系 / 报表 / 梳理 / 信息流 / 矩阵图
- 卡片图 / 双向分析 / 连环分析 / 解构分析
从大量事实里找规律

**03 压缩建模**
把关系抽象成核心模型
- 核心模型
- 流程图 / 漏图模型 / 抽象 / 过滤 / 筛选
- 结构图 / 重点小结 / 心智模型 / 思维框架
海量 → 抽象，找出关键规律

**04 解压展开**
把抽象加工，变成易实践的模型
- 解决方案 / 实操指导 / 决策框架
- 分解 / 博弈思维 / 平衡视角 / 数学模型 / 分析
抽象 → 具象，让人能理解和使用

**最终目标：**
- 指导实践
- 解决实际问题
- 更轻、更简、更高水平

具象世界 → 关系规律 → 抽象模型 → 具象工具

1. 圈定范围：找到建模的边界和范围，建模必先有边界。
2. 探索关系：探索出更多高价值的内在关系和因果规律。
3. 压缩建模：抽象成核心的模型，承载高价值关系/规律
4. 解压展开：把抽象加工，变成是易用容易实践的模型。
