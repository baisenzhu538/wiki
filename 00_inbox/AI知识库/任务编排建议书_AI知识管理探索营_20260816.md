## 二、课程内容骨架

知识管理定义（面向未来/碎片认知/资产复利）→ **知识复利火箭模型六要素**（超长周期/数量/质量/自动化/协作化/可掌控）→ **五次飞跃**（2013 印象笔记个人复利 → 2021 飞书团队集体 → 2025 底 Obsidian×AI 个人 → 2026.2-5 团队多 Agent → 2026.5-8 体系自动化）→ 三大进步（盯文档不盯窗口 / Session<<记忆<<文档 / AI Style 文档资源化）→ 多 Agent 协作链六环节（读写关系管理）→ 团队组织（三个 10 人 Agent 团队+负责人制）→ 在测系统（分类脚本/PatrolKit 雷达）→ 未来假设（WriteLess / Context is Everywhere）。

关键数据：120 万字笔记零人工撰写；3000 收藏/3 万扫读/10% 收录率；顶层文档每年 100+；VibeCoding 训战营 2-3 月→4-6 周→1 周（900 页 PPT/100+图/5 套代码）；30 个 Agent 角色配置。

### P2（暗知识 dk 候选，6 条）

1. 调研饱和话术："不要给我省任何投入，至少调研 30-50 篇，写不出来不许提交"
2. 先萃取再二次合并萃取（显著优于基于原始案例直接建模）
3. 四棒接力"每次交接只说一句话"（无文档交接、无提示词传递）
4. "你不用 Obsidian 我没法跟你协作"——工具落地靠硬推不靠倡议
5. 模型祛魅：上下文完备度 >> 模型差距（"上下文够强，模型差距几乎感觉不到"）
6. 15 秒做图三上下文公式（知道我是谁+检索项目文档+读取设计宪法）
