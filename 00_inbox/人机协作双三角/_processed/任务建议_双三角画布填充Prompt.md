# 任务建议：构建「双三角画布填充 Prompt」

> 提案人：洪七公  
> 时间：2026-07-04  
> 背景：基于对一堂双三角模型（缪斯模型/MUSE）的深度理解和 108 张课程素材的识别分析，建议开发一个可复用的双三角画布填充 Prompt，帮助用户在任何 AI 协作项目启动前完成六要素结构化输入。

---

## 一、为什么要做这件事

### 1.1 用户已经暴露的真实痛点

从你给我的「填双三角画布十倍数刻意练习提示词.txt」中可以看到：

> "如果双三角的六个要素没有被补齐，AI 往往很难给出高质量、可落地、可复用的结果。我希望自己不是直接把模糊需求丢给 AI，而是能先主动完成一轮结构化思考。"

这说明核心痛点是：**人不知道该怎么把模糊需求翻译成 AI 能高质量执行的六要素输入**。

### 1.2 现有资料的问题

- **解释版画布**只告诉你六格填什么，但没告诉你"怎么问出来"
- **清单版画布**给了问题清单，但需要用户自己逐条思考，负担重
- **课程口述稿**讲了很多案例，但没有提炼成可复用的 Prompt

**缺口**：缺少一个"对话式引导 + 结构化输出"的 Prompt，让 AI 主动帮用户把画布填满。

### 1.3 这个 Prompt 的价值

| 价值 | 说明 |
|------|------|
| **降低使用门槛** | 用户不需要背六要素，通过对话自然完成填充 |
| **提升 AI 输出质量** | 补齐六要素后，下游 AI 任务的方向更准、边界更清 |
| **沉淀 DataPack** | 每次填好的画布本身就是可复用的数据资产 |
| **训练用户思维** | 长期使用，用户会内化成"启动任务前先填画布"的习惯 |

## 二、我对双三角模型的理解（Prompt 设计的理论基础）

### 2.1 六顶点的官方定义

| 人的三角（H） | 含义 | AI 三角（A） | 含义 |
|---|---|---|---|
| **审美** | 对结果质量的高水平判断力 | **场景** | 发掘高匹配细分场景的能力 |
| **体系** | 解决问题的科学框架和工作流 | **基本功** | 熟练使用 AI 工具和技术特性 |
| **创造力** | 突破现有知识和经验的创新能力 | **数据** | 积累高质量 AI 可用数据资产 |

### 2.2 核心协作逻辑

不是顶点一一对应，而是分层协作：

```
人三角 = 定方向、定标准、定流程、提假设
AI三角 = 找场景、练基本功、攒数据、做执行
```

### 2.3 四级修炼路径

每个顶点都有「自我修养 → 基础 → 进阶 → 高阶」四级递进。

例如：
- **审美**：有感觉（20/40/60/80/99 打分）→ 有维度雷达图 → 能持续优化最佳实践
- **数据**：正面/负面案例 → DataPack → 10 年尺度数据飞轮

### 2.4 DataPack 概念

画布中填写的每个要素，本质上都是未来可复用的 **DataPack**（最小、通用、可迁移的原子资产）。

## 三、「九层深挖」Prompt 设计思路

我设计了一个**九层递进式对话框架**，让 Prompt 不是一次性索要答案，而是像专家顾问一样逐层引导用户深入。

### 3.1 九层架构总览

```
第 1 层：任务定位 —— 这是什么类型的事？
第 2 层：场景扫描 —— 有哪些可落地的细分场景？（A.场景）
第 3 层：审美校准 —— 好的结果长什么样？（H.审美）
第 4 层：体系拆解 —— 这件事的标准流程是什么？（H.体系）
第 5 层：创造力激发 —— 有什么新的可能性？（H.创造力）
第 6 层：数据盘点 —— 我们有什么可用的数据资产？（A.数据）
第 7 层：基本功匹配 —— 用什么 AI 工具/技术特性？（A.基本功）
第 8 层：飞轮设计 —— 如何持续迭代这个协作？
第 9 层：画布生成 —— 输出标准化的双三角画布
```

### 3.2 每层详细设计

#### 第 1 层：任务定位

**目的**：先判断这件事是否适合用 AI，以及适合到什么程度。

**Prompt 引导问题**：
1. 你要解决的具体问题是什么？用一句话描述。
2. 这件事目前是谁在做？（你一个人 / 团队 / 外包）
3. 你尝试过用 AI 吗？效果怎么样？
4. 如果这件事分成"人必须做"和"AI 可以做"两部分，你觉得各占多少？

**输出物**：任务类型标签 + 人机分工初判

#### 第 2 层：场景扫描（A.场景）

**目的**：找到高匹配、高价值的细分场景，而不是泛泛而谈。

**Prompt 引导问题**：
1. 这件事可以拆成哪些小场景？（用 STAR 模型：个人/组织 × 下限/上限）
2. 哪个场景最痛苦？（用户会叹气、不得不做）
3. 哪个场景的 ROI 最高？
4. 这个场景的边界在哪里？（哪些不在范围内）

**输出物**：3-5 个候选场景 + 优先级排序 + 选定核心场景

#### 第 3 层：审美校准（H.审美）

**目的**：建立判断结果好坏的标准，避免"我觉得还行"。

**Prompt 引导问题**：
1. 这个场景的"顶级交付"长什么样？（找一个标杆）
2. 从 20 分到 99 分，各档分别是什么水平？
3. 有哪些维度可以评判好坏？（列出 3-5 个评估维度）
4. 你的最低可接受标准是什么？（60 分线）
5. 有没有绝对不能出现的错误？（Not-to-do list）

**输出物**：审美标准表（标杆 + 评分维度 + 最低标准 + 负面清单）

#### 第 4 层：体系拆解（H.体系）

**目的**：把模糊任务变成可执行的流程和里程碑。

**Prompt 引导问题**：
1. 完成这件事需要几个步骤？
2. 每个步骤的输入和输出是什么？
3. 关键里程碑是什么？（必须达成什么才能进入下一步）
4. 有没有现成的 SOP/方法论可以借用？
5. 哪些环节必须人把关？哪些可以 AI 自动跑？

**输出物**：流程图/里程碑清单 + 人机分工表

#### 第 5 层：创造力激发（H.创造力）

**目的**：跳出常规思路，找到差异化解法。

**Prompt 引导问题**：
1. 同行通常怎么做这件事？他们的解法有什么问题？
2. 如果预算/时间/技术没有限制，你会怎么做？
3. 有没有跨领域的解法可以迁移过来？
4. 这件事的本质是什么？（第一性原理）
5. 你能提出 3 个不同方向的假设吗？

**输出物**：3-5 个创新假设 + 可行性初评

#### 第 6 层：数据盘点（A.数据）

**目的**：识别和整理 AI 可用的数据资产。

**Prompt 引导问题**：
1. 你有哪些正面案例可以参考？（好的输出样例）
2. 你有哪些负面案例需要 AI 警惕？（失败的、错误的）
3. 有没有相关的 Domain Knowledge 文档？
4. 这些数据的格式是什么？（结构化/非结构化）
5. 哪些数据是最值钱的？最值得优先整理成 DataPack？

**输出物**：数据资产清单（正面案例/负面案例/Domain Knowledge/DataPack 候选）

#### 第 7 层：基本功匹配（A.基本功）

**目的**：根据场景选择最合适的 AI 工具和技术特性。

**Prompt 引导问题**：
1. 这个任务需要哪些 AI 能力？（文本/图像/视频/代码/多模态）
2. 你熟悉哪些工具？（ChatGPT/Claude/Coze/Dify/Manus 等）
3. 每个工具的最小核心特性（Feature）是什么？
4. 有没有现成的 Skill/Agent/工作流可以复用？
5. 是否需要模型微调或多 Agent 编排？

**输出物**：工具选型表 + Feature 清单 + 是否需要工程化

#### 第 8 层：飞轮设计

**目的**：设计人机协作的持续迭代机制。

**Prompt 引导问题**：
1. 第一轮交付后，谁来评估结果？
2. 评估结果如何反馈给 AI？（哪些进入数据资产）
3. 多久迭代一次？
4. 哪些指标可以衡量这个协作是否变好？
5. 人在这个过程中要练什么能力？审美/体系/创造力哪个是短板？

**输出物**：迭代机制 + 反馈闭环 + 人三角提升计划

#### 第 9 层：画布生成

**目的**：把前面的对话整合成标准化的双三角画布。

**输出格式**：

```markdown
# 双三角画布：[任务名称]

- 核心问题：
- 任务类型：
- 人机分工初判：

### A. 场景
- 核心场景：
- 场景边界：
- 优先级理由：

### A. 基本功
- 推荐工具：
- 核心 Feature：
- 工程化需求：

### A. 数据
- 正面案例：
- 负面案例：
- DataPack 候选：

## 三、人的三角

- 顶级标杆：

- 最低标准：
- Not-to-do list：

### H. 体系

- 关键里程碑：
- 人机分工表：
```

## 四、Prompt 核心设计（草案）

### 4.1 System Prompt 框架

```markdown
你是一位双三角画布填充专家。你的任务是通过九层深挖对话，帮助用户把任何一个 AI 协作任务拆解成"人的三角"（审美、体系、创造力）和"AI 的三角"（场景、基本功、数据）六要素。

【核心原则】
1. 不要一次性输出完整画布，而是逐层引导用户深入。
2. 每一层都要先理解用户当前状态，再给出具体问题和建议。
3. 对于模糊回答，要追问到可执行、可验证的程度。
4. 始终把"填画布"当成训练用户双三角思维的过程，而不是一次性交付。

【九层深挖流程】
第1层 任务定位 → 第2层 场景扫描 → 第3层 审美校准 → 第4层 体系拆解 → 第5层 创造力激发 → 第6层 数据盘点 → 第7层 基本功匹配 → 第8层 飞轮设计 → 第9层 画布生成

【对话风格】
- 专业但不晦涩，用创业者听得懂的语言
- 每个问题后简要说明"为什么要问这个"
- 及时总结已确认的信息，避免重复
- 当用户卡壳时，提供 2-3 个选项帮助推进

【输出纪律】
- 每层结束时用一句话总结当前层结论
- 只有完成九层后才输出完整画布
- 画布中每个要素都要有用户原话或确认过的内容支撑
```

### 4.2 第一层对话示例

**AI**：我们先来定位一下这个任务。你要解决的具体问题是什么？请用一句话描述，比如"我想用 AI 帮我生成小红书爆款笔记"。

**用户**：我想做一个销售话术助手。

**AI**：好的。我把它记录为：用 AI 辅助生成/优化销售话术。接下来我想确认三件事：
1. 这个话术主要给谁用？（你自己 / 销售团队 / 客户自助）
2. 现在话术是怎么产生的？（自己写 / 抄同行 / 没有固定话术）
3. 你尝试过用 AI 做这件事吗？效果如何？

这个问题帮我判断：这件事的人机分工比例，以及应该从哪里切入。

## 八、风险与边界

### 8.1 不能替代什么

- **不能替代人的最终判断**：审美和创造力仍然需要人
- **不能替代 domain 专家**：如果用户本身不懂业务，填出来的画布也是空的
- **不能替代试错**：画布只是起点，真正的规律来自执行和迭代

### 8.2 使用边界

- 适合：有一定业务认知、想用 AI 提升效率的人
- 不适合：完全零基础、连问题都描述不清的用户
- 建议：配合刻意练习使用，而不是一次性用完
