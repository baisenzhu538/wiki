# 一堂·科学开会思考画布
## YITANG SCIENTIFIC MEETING THINKING CANVAS

---

### Step1. 目标
大家愿意花时间开会，希望达成的具体目标和价值

- 点燃热情
- 分配角色
- 明确落实
- 展示价值

**如果不开会有哪些问题：**
1. 协作方无法被点燃
2. 对项目价值不明确
3. 有人不清楚自己的任务
4. 有人不清楚自己的角色

---

### Step2. 原则
为了达成目标，大家要遵循的原则 / 保持的
开会氛围和做事姿势

- 点燃原则
- 落实原则
- 责任原则

---

### Step3. 关键流程
为了提升效率，具体开会的执行过程，第一第二第三步

1. 参会人：项目相关人员都要参加
2. 提前准备：邮件同步 + 文档准备
3. 渲染价值：公司价值 + 项目价值 + 成长价值
4. 项目阐述：项目概述，阐述关键节点
5. 反向确认：向关键人确认项目关键点
6. 会后同步：同步会议纪要，以及会议共识

**提升会议效率的手段：**
1. 成长价值：这个项目很难，对于成长很有价值。
2. 行业价值：讲项目/目标的背后意义。
3. 公司价值：讲一讲这个项目对于公司的重要性。
4. 打仗氛围：营造要打仗的氛围。
5. 关键人签字：关键人需要回复邮件，或者方案上签字。
6. 最佳实践：我们一起做一个牛逼的东西/树标杆。
