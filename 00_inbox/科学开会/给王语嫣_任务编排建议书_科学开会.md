## 二、课程核心框架（从OCR+口述+笔记中提取）

### 2.1 核心认知：科学开会 = 提升会议 ROI

> **会议的本质是ROI问题**：用集体时间换共识和结果。

**核心口号**：非必要不开会，深度讨论开会，浅度讨论化简。

| 会议痛点 | 表现 |
|:---|:---|
| 目标模糊 | 话题发散、时间无限长 |
| 效率低下 | 发言重复跑题、参会人无关、会前无准备 |
| 缺少沉淀 | 无纪要、无落实计划、决策无法追溯 |

### 2.2 冰山模型（会议认知框架）

```
        ┌─────────────┐
流程层  │ 具体操作步骤  │  ← 最外层（看得见）
        ├─────────────┤
原则层  │ 开会姿势氛围  │  ← 中层
        ├─────────────┤
目标层  │ 解决什么问题  │  ← 最内核
        └─────────────┘
```

> **新手执行流程，高手把控原则。** 原则比流程更重要。

### 2.3 会议优化三板斧

1. **明确目标**：用"不开会有什么问题"反向推导具体目标
2. **确定原则**：根据会议类型匹配原则（复盘会要务实、启动会要点燃）
3. **设计流程**：会前准备→会中执行→会后落实

### 2.4 十大原则武器库（核心！花瓣图 + 10张小抄）

**结构统一**：每张原则小抄 = 三大反面现象 + 提升维度（会前/会中/会后）+ 方法/技巧/工具

| 分组 | 原则 | 痛点（反面） | 关键策略 |
|:---|:---|:---|:---|
| **基础** | 务实 | 讨论模糊/空对空/讨论很浅 | 准备数据、设置结束条件、追问定量、指定蓝军 |
| | 良性 | 气氛沉闷/缺少信任/冲突攻击 | 提前铺垫、Check-in、申明参与标准、冷静降温、会后私聊 |
| **执行** | 高效 | 准备不足/参会过多/发散跑题/时间冗长 | 会议申请制度、边角料时间、筛选名单、开头一分钟、会议地图/停车场、SOP |
| | 激发 | 不爱发言/激发太少/质量太低 | 提前准备想法、预埋活跃分子、设定Flag、可视化、持续追问+鼓励 |
| | 点燃 | 没有热情/没有动力/没有信心 | 先点燃自己、起好名字、打仗氛围、上升意义、心理激励为主 |
| | 投入 | 都不抬头/都不思考/都不参与 | 规则前置、订餐零食、"正在参会"模板、预热思考、高频互动、可视化记录 |
| | 责任 | 没有分工/责任不明/执行不好 | 角色赋予+意义、规则郑重声明、监督执行、友善提醒、红黄牌制度 |
| | 民主 | 领导强势/会议冷场/过度民主 | 老板最后发言、提前约稿、主持人中立、发言顺序设计、民主集中策略 |
| **结果** | 落实 | 信息丢失/没有todo/缺少闭环 | 二次确认共识+to do、纪要分级（录音/备忘/完整版）、R/S计划、跟踪迭代 |
| | 学习 | 学习意识弱/热情差/效率低 | 刻意练习任务、录音沉淀、经验萃取（SOP/思考模型）、定期汇报、以会养会 |

### 2.5 四类常见会议类型

| A.团队例会 | B.项目管理 | C.团队建设 | D.主题专项 |
|:---|:---|:---|:---|
| 日会/周会/月会/季度会/选题会 | 启动会/评审会/推进会/验收会/宣讲会/复盘会/客户分析 | 培训会/分享会/裸心会/生日会/述职会 | 头脑风暴/战略会/碰头会/casestudy/磨课会/攻坚会 |

### 2.6 三类典型会议30分版本 → 优化方向

| 会议 | 30分版本问题 | 优化方向 |
|:---|:---|:---|
| 周例会 | 报喜不报忧、缺乏深度、跑题 | 会前发材料并要求回复、明确目标边界角色时间 |
| 启动会 | 信息对齐不足、职责不清 | 明确目标+分工+激发热情+风险落地（A同学案例Before/After） |
| 复盘会 | 变成表扬会、务虚、无行动计划 | 发掘问题、务实求真、沉淀经验（批注三原则） |
