# 常见五种会议类型目标小抄Cheatsheet

## 周例会
1. **关键信息同步**
   同步新信息、关键的洞察
2. **解决卡点风险**
   处理卡点、异常
3. **对齐工作步调**
   对齐下一周的工作目标优先级
4. **推动资源协作**
   调节资源分配
5. **让老板能安心**
   向上汇报，给老板关键信息

## 启动会
1. **明确目标**
   明确项目的核心目标
2. **明确分工**
   明确关键角色和协作关系
3. **明确协作关系**
   各个模块的负责人
4. **明确里程碑**
   明确关键节点的交付物
5. **明确跟进机制**
   开会/文档和汇报机制
6. **激发热情**
   打打气，提升团队战斗力

## 复盘会
1. **结果评估**
   客观评估结果和贡献
2. **过程资产**
   沉淀关键认知和SOP
3. **发掘问题**
   分析问题和深层原因
4. **稳定执行**
   持续执行不变形
5. **持续迭代**
   拿到下次迭代Todo

## 分享会
1. **复制优秀经验**
   分享业务中可复用的优秀经验
2. **分享实用知识**
   分享工作相关的实用知识
3. **激发团队创新**
   激发创造力，产生新idea

## 攻坚会
1. **明确问题**
   明确遇到的核心问题是什么
2. **找到关键要素**
   找到影响成功的关键要素是什么
3. **暴露关键风险**
   找到影响成功的关键风险是什么
4. **探讨解决方案**
   尝试找到解决方案
5. **确定解决方案**
   找到最终能解决问题的方案
