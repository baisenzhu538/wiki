## 一段位体系（L1 → L6）

从左到右，从"起始状态"逐步进阶到"高难阶段"。

| 段位 | 名称 | 笔记类型 | 核心特征 |
|:---|:---|:---|:---|
| **L1** | 不记 | 记脑子里 | — |
| **L2** | 备忘 | 备忘笔记 | 学习笔记 | 习惯笔记、快速记录、不丢信息 |
| **L3** | 协作 | 协作笔记 | 可视化笔记 | 逻辑清晰、美观舒适、方便扫读 |
| **L4** | 内化 | 清单笔记 | 专题笔记 | 重新整理、有故事线、有强逻辑 |
| **L5** | 思考 | 长期思考笔记 | 灵感闪现笔记 | 有好问题、激发洞察、思考涌现 |
| **L6** | 萃取 | 建模笔记 | 访谈笔记 | 现场激发、快速建模、提亮升华 |

## 二六大提升维度

每个维度对应一个段位的核心练习目标：

| 维度 | 目标描述 |
|:---|:---|
| **提升笔记数↑** | 养成记笔记习惯，大幅提升思考水平和长期记忆力 |
| **提升完整度↑** | 不断提升笔记的完整度，保证关键信息未来可追溯 |
| **提升舒适度↑** | 不断提升笔记的阅读舒适度，方便他人阅读/使用 |
| **提升内化率↑** | 不断提升笔记的内化率，通过整理提高自己的 IPO 效率 |
| **提升思考量↑** | 不断提升笔记的思考占比率，激发自己的深度思考和洞察 |
| **提升完成度↑** | 不断提升笔记的完成度，能现场完成高质量的萃取和输出 |

## 四刻意练习加速

### 策略一：及时反馈

>如何不断"收集反馈"来修正姿势：

| 方法 | 说明 |
|:---|:---|
| 自我反馈 | 不断反思，笔记是不是最好水平 |
| 事实反馈 | 分析反思笔记被阅读/使用/点赞情况 |
| 他人反馈 | 找同伴/师傅/笔记高手给反馈 |
| 版本对比 | 对笔记的多个版本进行对比和反思 |
| 最佳实践池子 | 建一个优秀笔记池对照分析差距 |

### 策略二：大量重复

>如何把笔记练习次数提升2-10倍：

| 方法 | 说明 |
|:---|:---|
| 日常练习 | 做计划保证次数，比如固定日期/场景 |
| 专项练习 | 设计专项小练习，比如练视觉美化 |
| 主动练习 | 各种机会主动记笔记，比如开会/访谈 |
| 叠加练习 | 用暗时间进行练习，比如听课记笔记 |
| 迁移练习 | 抽象底层模型反复练习，比如练 MECE |
