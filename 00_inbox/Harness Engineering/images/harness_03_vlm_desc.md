### 描述

这是一张垂直分层结构的流程图，展示了一个五阶段的AI代码安全验证流水线。整体采用深蓝色科技感背景，搭配金色/琥珀色的几何装饰元素（左侧的立方体网络节点、两侧的对称电路/树叶状装饰图案），营造出类似区块链或高端科技产品的视觉氛围。流程自上而下依次为：Layer 1（Happy Path Verification，正常路径验证）→ Layer 2（Active Attack Probing / Hostile Inputs，主动攻击探测）→ Layer 3（Cross-Model Code Review / AI Family A，跨模型代码审查）→ Layer 4（Cross-Model Architecture Review / AI Family B，跨模型架构审查）→ 最终输出 Certified Code Output（已认证代码输出）。每个层级之间用粗体金黄色向下箭头连接，暗示层层递进、逐步深入的验证逻辑。

### 关键元素

- Layer 1: Happy Path Verification（正常路径验证）
- Layer 2: Active Attack Probing (Hostile Inputs)（主动攻击探测，含恶意输入）
- Layer 3: Cross-Model Code Review (AI Family A)（AI家族A跨模型代码审查）
- Layer 4: Cross-Model Architecture Review (AI Family B)（AI家族B跨模型架构审查）
- Certified Code Output（已认证代码输出）
- 金色向下箭头连接线
- 深蓝色多层八角形/圆角矩形容器
- 两侧对称的金色电路/树叶状装饰
- 背景中的金色六边形立方体网络节点
