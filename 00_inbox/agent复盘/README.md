# Agent 复盘域

> 创建于 2026-07-06，Phase 1 启动。
> 积累 Agent 复盘资产——面向未来，提升 Agent 能力，解决复杂问题。

## 目标

复盘成果反馈到 Agent 能力提升。监督执行，让复盘不只是"写了"，而是"用了"。

## 来源

- 桌面 `agent复盘/<agent-id>/daily-context/YYYY-MM-DD.md`（Agent 每日产出）
- `60_feedback/session-archives/`（自动双写存档）
- 黄药师审计日报

## 子目录规划

| 目录 | 用途 | 创建时间 |
|:--|:--|:--|
| `patterns/` | 跨会话聚类分析：相同盲点、重复失败模式 | Phase 3 |
| `reports/` | 周报/月报：覆盖率趋势、质量分布 | Phase 2 |
| `templates/` | 复盘模板迭代历史（v1→v2→...） | Phase 2 |
| `actions/` | 复盘触发的改进任务追踪 | Phase 3 |
