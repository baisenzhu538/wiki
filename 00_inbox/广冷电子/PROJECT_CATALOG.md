## 一、项目背景

这是一个**自动售货机红外光栅检测系统**（HX-SMJ 系列），包含多块电路板通过 CAN 总线通信。系统由离职工程师开发，现有资料存在多版本混乱问题。

---

## 二、系统架构

```
                     ┌─────────────────┐
 电源 24V ─────────→ │ HX-SMJ-01B      │ ← STM32F103ZE (MCU)
                     │ 主控板           │ ← CAN 总线主节点
                     │                  │ ← 运行固件 BootLoad_v1.2.3
                     └────────┬────────┘
                              │ CAN Bus
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
  ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
  │ HX-SMJ-03B-A │ = │ HX-SMJ-03B-B │   │ HX-SMJ-01    │
  │ 红外板-A(主控) │   │ 红外板-B(外设) │   │ 继电器板      │
  │ 16路红外对射   │   │ 16路红外对射   │   │              │
  │ 自带DC-DC电源 │   │ 从A取电      │   │              │
  └──────────────┘   └──────────────┘   └──────────────┘
                                           │
                                           ▼
                                    ┌──────────────┐
                                    │ HX-SMJ-04B   │
                                    │ 货道电机板    │
                                    └──────────────┘
```

## 三、各电路板详情

### 3.1 HX-SMJ-03B-A 红外板-A（主控红外板）

| 属性 | 内容 |
|:----|:------|
| **实板标记** | HX-SMJ-03B-A, VER:2.2, 2024.08.12 |
| **照片确认** | ✅ 已通过 PaddleOCR 确认丝印 |
| **功能** | 16 路红外发射 + 16 路接收，主控板（自带电源） |

#### 核心芯片方案

| 功能 | 芯片 | 数量 | 封装 |
|:----|:-----|:---:|:----|
| 电源 24V→5V | TPS54360DDAR (TI) | 1 | SOIC-8 EP |
| 运放信号放大 | LMV358IDR (TI) | 1 | SOIC-8 |
| 模拟多路器 8选1 | CD4051BPWR (TI) | 2 | TSSOP-16 |
| 串转并移位寄存器 | SN74LV595APWR (TI) | 2 | TSSOP-16 |
| 总线收发器 | SN74LV245APWR (TI) | 1 | TSSOP-20 |
| 开漏缓冲器 | SN74LVC2G07DBVR (TI) | 6 | SOT-23-6 |
| 红外发射管 940nm | IR333C-A (EVERLIGHT) | 16 | 5mm直插 |
| 红外接收管 940nm | PT334-6B (EVERLIGHT) | 16 | 5mm直插 |
| LED驱动 MOSFET | AP2302B (N-CH) | 16 | SOT-23 |
| MOSFET | NCE3400 (N-CH) | 1 | SOT-23 |
| TVS保护 | P6SMB33CA (33V 双向) | 1 | SMB |
| 肖特基二极管 | SS36 (60V/3A) | 2 | SMB |
| 晶振 8MHz | SG-8018CE | 1 | 3225 |
| 电感 15uH | FXL0624-150-M | 1 | 7.0×6.6mm |

### 3.2 HX-SMJ-03B-B 红外板-B（外设红外板）

与 A 板结构基本相同，但：
- ❌ **无** TPS54360 DC-DC（从 A 板取电）
- ❌ **无** 8MHz 晶振
- ❌ **无** TVS/肖特基保护
- ❌ **无** NCE3400 MOSFET
- ❌ **无** 10uF 钽电容
- 通过 PHB-2×5AW 线缆与 A 板连接

### 3.3 HX-SMJ-01B 主控板

- MCU: **STM32F103ZE**（LQFP-144）
- CAN 总线接口
- 运行 BootLoad_v1.2.3 固件（ARM Cortex-M3）
- 固件源码存在多处副本

## 五、已发现的版本矛盾

| # | 器件 | V2.1 BOM (12月) | V2.2 BOM (9月) | 设计PDF | 优先级 |
|:-:|:----|:-------------:|:-------------:|:-------:|:-----:|
| 1 | DC-DC (24V→5V) | TPS54360DDAR | TPS54360DDAR | **JW5026** | 🔴 |
| 2 | 保护二极管 | SS36(60V/3A) | SS36(60V/3A) | **SS24(40V/2A)** | 🟡 |
| 3 | TVS | P6SMB33CA(33V) | P6SMB33CA(33V) | **P6SMB30CA(30V)** | 🟡 |

**🔴 矛盾1 最关键**：PDF 设计分析中 DC-DC 写的是 JW5026（国产，最高输入 28V），但实际打板的 BOM 用的是 TPS54360DDAR（TI，最高 60V）。这涉及整个电源方案的根本差异。

## 七、分析方法：故障树（FTA）+ 版本回溯

> 不急于回答"什么故障"，先建立分析框架。

### 分析框架

```
Step 1: 建立可信基准
   ├── 以实物板为锚点（照片已确认）
   ├── 以 V2.2 BOM (9月) 为主参考
   └── 以 V2.1 BOM (12月) 为修改对照

Step 2: 三角交叉验证
   对每个关键信号/器件，三向比对：
   ├── BOM（焊接了什么元件）
   ├── PCB JSON/Gerber（布局连接是否正确）
   └── PDF 设计分析（设计意图）

Step 3: 故障树构建
   根据实际故障现象，从顶事件向下逐层分解：
   ├── 电源层（24V输入 → 5V → 各芯片供电）
   ├── 信号层（发射驱动 → 红外链路 → 接收放大 → MCU采集）
   └── 通信层（板间CAN → 主控→上位机）

Step 4: 版本影响评估
   每个故障分支标注"此部分受版本混乱影响吗？"
   └── 受影响 → 先确认哪版正确
   └── 不受影响 → 直接走故障树
```

### 故障树顶层架构

```
红外光栅不工作 / 工作异常
├── 电源问题
│   ├── 24V输入异常（保护电路/P6SMB/SS36）
│   ├── 5V电源异常（TPS54360/反馈电阻）
│   └── 各芯片供电异常
├── 发射链路问题
│   ├── MCU不发送控制信号
│   ├── SN74LV595 不工作
│   ├── AP2302B MOSFET 不导通
│   └── IR333C-A 不发光 / 光弱
├── 接收链路问题
│   ├── PT334-6B 收不到光 / 信号弱
│   ├── LMV358 放大异常
│   ├── CD4051 通道切换异常
│   └── MCU IO 采不到信号
├── 通信问题
│   ├── 板间 CAN 总线
│   └── 与上位机通信
└── 固件问题
    ├── 固件版本不匹配
    └── 配置参数错误
```
