## 一、执行摘要

本报告系统梳理了中国各省在药品零售渠道创新领域的政策演进，重点对比分析了**药品销售专柜**、**自助售药机（自动售药机）**与**智慧药房（柜）**三种业态在设施类型、允许销售药品范围、审批要求、监管标准等方面的差异。核心发现如下：

- **国家层面**：2024年4月国家药监局第48号公告明确"自助售药机不得销售甲类非处方药和处方药"，将自助售药机限定为乙类OTC销售终端。[^1]
- **山西突破**：山西省2026年新规（晋药监规〔2026〕7号）将三类设施严格区分，明确"智慧药房（柜）可销售处方药及非处方药"，前提是具备互联网诊疗、远程药学服务设备和能力，经执业药师审方。[^15]
- **地方分化**：全国呈现"三档分化"格局——（1）严格保守型（仅乙类OTC）：北京、陕西、广西、甘肃、江西等；（2）适度放开型（可售甲类OTC）：重庆、西藏；（3）积极探索型（可售处方药）：山西（智慧药房柜）、山东烟台、湖南永州、湖北（远程药柜）、江苏连云港、上海、河北（自助药房/双通道）等。
- **争议焦点**：山西"智慧药房（柜）"售处方药是否与国家48号公告冲突，取决于监管部门对"智慧药房（柜）"与"自助售药机"的概念界定。

## 二、国家层面政策定调：2024年第48号公告与2026年合规指南

### 2.1 国家药监局2024年第48号公告

2024年4月22日，国家药监局发布《关于进一步做好药品经营监督管理有关工作的公告》（2024年第48号），对自助售药机做出明确的全国统一规定：

> "药品零售企业可按照药品储存要求设置自助售药机销售乙类非处方药，自助售药机放置地址在许可证'经营地址'项下注明。**自助售药机不得销售甲类非处方药和处方药。** 企业质量管理体系应当覆盖自助售药机，自助售药机的药品销售、更换、检查及药品有效期管理应当纳入企业计算机系统。"[^1]

该公告是《药品经营和使用质量监督管理办法》（国家市场总局84号令）实施后的进一步细化，几乎在药监层面叫停了此前部分地区探索的"自助售药机售处方药"项目。此后，陕西、甘肃、广西、重庆、江西等地纷纷调整本地政策，收紧至仅售乙类OTC。[^1]

### 2.2 2026年《处方药网络零售合规指南》

2026年5月25日，国家药监局发布《处方药网络零售合规指南》，提出"凭处方、严审核、可追溯、控风险"的核心要求：

- 网售处方药必须凭真实处方、实名制销售；
- 严禁AI替代审方、重复使用处方；
- 审方数量控制在合理范围；
- 处方审核工作由执业药师开展，不得由其他岗位人员或人工智能代为实施。[^16]

该指南为"互联网+药品零售"业态（包括智慧药房）销售处方药提供了合规框架，强调线上线下处方药销售监管一致性。[^16]

## 三、山西省2026年新规解析：三类设施的差异化定位

### 3.1 政策文件与核心条款

山西省药品监督管理局、山西省行政审批服务管理局于2026年2月12日联合印发《药品零售经营监督管理办法（试行）》（晋药监规〔2026〕7号），自2026年5月1日起施行，有效期至2028年4月30日。[^15]

**核心条款（第二十三条）：**

> "药品零售企业在符合《药品经营质量管理规范》及保证药品质量安全的前提下，可在**机场、车站、景点、院校、商场、超市、街道社区、住宅小区**等人口聚集场所内设置**药品销售专柜、自助售药机、智慧药房（柜）**销售药品。
>
> **药品销售专柜和自助售药机仅限销售乙类非处方药。**
>
> **智慧药房（柜）可销售处方药及非处方药**，销售处方药的，应具备**互联网诊疗、远程药学服务设备和能力**，应确保处方来源真实、可靠，**经执业药师审方后方可调配、出售**。
>
> 自助售药机和智慧药房（柜）应具备温湿度自动监测、调控功能；药品零售企业质量管理体系应当覆盖药品销售专柜、自助售药机、智慧药房（柜），药品储存、销售管理应当纳入企业计算机系统统一管理。"[^15]

### 3.2 山西省对"智慧药房（柜）"的定义

该办法在附则中明确：

> "智慧药房（柜）是应用**大数据、云计算、物联网**等先进的信息技术，对接'互联网+'医院、电子处方流转平台和电子医保系统、远程审方平台，提供线下自动售药、取药以及线上问药、售药、配送服务的零售药店。对药品的请领、储存、调配、核对、发放、使用等流程进行可追溯和精细化管理，为患者提供**处方审核、药品核对、用药交待、用药提醒**等药学服务。"[^15]

该定义强调智慧药房（柜）并非简单的自助售药设备，而是具备完整互联网诊疗和远程药学服务能力的数字化零售终端。

### 3.3 其他配套要求

- **设置管理**：药品销售专柜、自助售药机、智慧药房（柜）应当符合所在地市级药品监督管理部门的要求，经行政审批部门核准，放置地址在《药品经营许可证》"经营地址"项下注明。[^15]
- **智慧药房管理**：智慧药房（柜）应当在显著位置标示依托的药品经营企业名称、《药品经营许可证》信息、24小时服务电话、投诉举报电话等，由专人按照GSP要求进行管理，重点加强药品储存条件、实名在线诊疗、远程药事服务、智能拣选打包、电子支付和售后服务等管理。[^15]
- **效力条款**：第六十二条明确"原有关药品零售经营监督管理要求与本办法规定不一致的，按本办法执行。**国家有新规定的，依国家规定。**"[^15]

## 五、智慧药房技术标准、运营案例与监管实践

### 5.1 技术标准与地方规范

目前中国尚未出台全国统一的"智慧药房"国家标准，但已形成多个地方标准和团体标准：

1. **安徽省**：《智慧药房建设指南》（DB34/T 3790-2021）和《智慧药房验收规范》（DB34/T 3791-2021），由安徽省市场监督管理局2021年2月发布，适用于医疗机构智慧药房建设。明确智慧药房定义：应用大数据、云计算、物联网等信息技术，对药品申领、调拨、储存、调配、核对、发放、使用等流程进行可追溯和精细化管理。[^14]

2. **长三角区域**：2022年5月，沪苏浙皖市场监管局联合发布长三角区域地方标准《智慧药房评价体系》，由中国科大附一院牵头起草，2022年7月25日实施。提出2个一级指标、6个二级指标和46个三级指标，涵盖药房管理、处方审核、药品冷链管理、互联网医院电子处方和药品配送等。[^22]

3. **浙江省/湖州市**：2022年6月，湖州发布全国首个《零售智慧药房建设与管理规范》市级地方标准（DB3305/T 228-2022），2025年8月升级为浙江省地方标准（DB33/T 1445-2025），2025年9月29日实施。规定了智慧药房的术语和定义、建设要求、服务流程及要求、管理要求、评价与改进等。[^13]

4. **智慧药房定义（浙江标准）**："应用大数据、云计算、物联网等信息技术，对接'互联网+'医院、电子处方流转平台和电子医保系统，提供线下自助售药、取药，以及线上问药、售药、配送服务的零售药店。"[^13]

### 5.2 运营案例与行业实践

- **上海浦东**：2023年5月，华氏大药房与美团买药合作打造上海首家"24小时智慧药房"，近10平方米封闭空间，自动分拣设备在多层货架前取货，通过传送带运输至打包机自动打印小票和塑封，再放入自助交接柜。每笔订单经过四层安全校验（库存匹配、传感器分拣校验、视觉核验数量与内容）。外卖骑手输入取货码即可取走打包好的药品。该智慧药房打通互联网诊疗和药师远程审方，支持24小时购买处方药。[^11]

- **北京**：截至2024年底，北京市开办24小时便民服务药店共1244家，覆盖全市16区及经开区。2025年2月，北京市药监局发布《北京市药品零售企业许可管理规定》，鼓励提供24小时药学服务，推进"15分钟便民服务圈"建设。[^24]

- **深圳**：2022年12月，深圳市上线处方药销售管理及监管系统，顾客通过"深i您"健康码扫码录入身份，药店上传处方单，药师扫码登入系统、刷脸确认身份后完成审核。实现购药登记便捷化、处方审核智能化、监管治理智慧化。[^23]

- **河北**：双通道药店可在定点医疗机构内部设置"自助药房"销售国谈药，须接入国家统一医保信息平台处方流转中心。已具备与地方医保支付系统对接的能力。[^12]

- **重庆垫江**：探索药品智慧监管模式，推动三方问诊平台与进销存软件深度对接，在流程上对处方药凭处方销售实施强制管控，药店可通过进销存软件输入处方号或在线发起问诊获取处方信息。[^3]

### 5.3 技术安全要求共性

综合各地政策，智慧药房/自助售药机的技术安全要求包括：

| 维度 | 具体要求 |
|------|----------|
| **温湿度控制** | 配备自动监测、调控设备，温度按药品包装标示或药典要求，相对湿度35%~75%；数据实时上传至企业计算机系统 [^4][^15] |
| **处方审核** | 电子处方来源真实可靠；互联网医院出具；远程审方平台执业药师审核；保存咨询录音和视频记录 [^8][^9][^15] |
| **系统对接** | 纳入企业统一计算机系统；进销存实时联网；与互联网医院/电子处方流转平台/医保系统对接 [^15][^12] |
| **监控追溯** | 安全监控设施和报警装置；出售药品全程监控；出药拍照和留存取证；建立真实完整可追溯的销售记录 [^4][^15] |
| **标识公示** | 显著位置标示企业名称、许可证编号、联系电话、投诉举报电话（12315/12345）、警示语 [^15] |
| **药学服务** | 提供实时在线药学服务；视频连线执业药师指导合理用药；24小时服务电话 [^2][^4] |

## 六、争议分析：山西"智慧药房（柜）售处方药"是否与国家规定冲突？

### 6.1 争议核心

国家药监局2024年第48号公告明确："自助售药机不得销售甲类非处方药和处方药。"[^1] 而山西省2026年新规明确"智慧药房（柜）可销售处方药及非处方药"。[^15] 这一差异引发业内对政策合规性的讨论。

### 6.2 山西政策的合规性依据

**（1）概念区分：智慧药房（柜）≠自助售药机**

山西省对三类设施做了严格区分：
- **药品销售专柜**：物理陈列柜，人工/半自助，仅乙类OTC；
- **自助售药机**：自动化设备，消费者自助购买，仅乙类OTC；
- **智慧药房（柜）**：数字化终端，对接互联网医院、电子处方流转平台、远程审方平台，提供完整的互联网诊疗+药学服务，可售处方药。[^15]

从功能定义看，山西的"智慧药房（柜）"更接近"互联网医院+远程审方+自动调配"的数字化药房形态，而非传统意义上仅做药品物理输出的"自助售药机"。其技术要求包括：互联网诊疗设备、远程药学服务、执业药师在线审方、实名诊疗、智能拣选打包、与医保系统对接等。[^15]

**（2）上位法衔接：遵循"国家有新规定，依国家规定"原则**

山西新规第六十二条设置保留条款："原有关药品零售经营监督管理要求与本办法规定不一致的，按本办法执行。**国家有新规定的，依国家规定。**"[^15] 这意味着若国家药监局后续明确将"智慧药房（柜）"纳入"自助售药机"统一管理并禁止售处方药，山西政策将自动调整。

**（3）符合2026年《处方药网络零售合规指南》精神**

2026年5月发布的《处方药网络零售合规指南》强调处方药销售的核心是"凭处方、严审核、可追溯、控风险"，并未禁止通过数字化终端调配处方药，只要确保处方审核由执业药师开展、全程留痕、实名制。[^16] 山西智慧药房（柜）的要求与此一致。

**（4）地方先行先试的立法空间**

《药品管理法》及《药品经营和使用质量监督管理办法》授予省级药监部门在一定范围内制定实施细则的权限。在鼓励"互联网+医疗健康"和药品零售新业态的政策背景下，山西对具备完整远程审方能力的智慧药房（柜）允许销售处方药，可视为在国家政策框架内的创新探索。

### 6.3 潜在风险与不确定性

- **概念边界模糊**：若国家药监局认为"智慧药房（柜）"本质上属于"自助售药机"的一种高级形式，则山西政策可能面临调整压力。
- **审方质量风险**：远程审方能否达到与现场执业药师同等的审核质量，在用药指导、患者交互方面存在争议。2025年8月，某地市场监督管理局发布征求意见稿拟允许"自助取药机领取处方药"，引发实体药店强烈担忧，认为"无执业药师现场核对，存在用药安全隐患"。[^25]
- **成本竞争冲击**：单台自助设备年运营成本仅数千元，而传统药店单店月均人力成本近2万元。若智慧药房（柜）大规模铺设处方药，可能对实体药店形成不对称竞争。[^25]
- **医保衔接风险**：智慧药房（柜）的处方药销售能否纳入门诊统筹和医保报销，取决于各地医保部门的接口开放程度。

## 七、售药渠道创新对行业竞争格局的影响

### 7.1 零售药店现状与痛点

- 截至2023年底，全国持证药店数量超过66.7万家，其中24小时药店占比不足10%。[^24]
- 传统药店面临夜间运营成本高、订单量不稳定、人员安全等困境，"24小时售药"在很多地区近似虚设。
- 行业进入结构性转型深水区：2025年第一季度全国新开药店7118家，闭店10284家，净减少约3000家，门店数回落至70万家以下，零售药店进入有序出清阶段。[^25]

### 7.2 渠道创新的影响路径

| 影响维度 | 具体表现 |
|----------|----------|
| **成本结构重塑** | 智慧药房（柜）占地仅1-2平方米，无需常驻药师，租金和人力成本大幅降低。一台自动售药机售价约3万元，若每月订单额达5000元，3年内可盈利。[^10] |
| **连锁化优势强化** | 北京要求连锁门店≥15家方可跨店设机；上海要求拥有10家以上门店的连锁药店才有资格投放离店智慧药柜。政策向大型连锁倾斜，加速行业集中度提升。[^2][^19] |
| **处方药外流承接** | 门诊统筹、双通道政策推动处方外流，智慧药房（柜）+电子处方流转成为承接院内处方的新终端。河北已允许双通道药店在院内设自助药房销售国谈药。[^12] |
| **线上线下融合** | "网订店取""网订店送"模式普及。京东健康、美团买药、阿里健康等平台与线下药店合作，通过智慧药房实现自动化分拣和24小时履约。[^11] |
| **监管能力升级** | 数字化售药全流程留痕（处方来源、审方记录、视频咨询、温湿度数据、销售凭证），理论上比传统药店更易监管。深圳、重庆垫江等地已实现数据互联互通和强制处方管控。[^23][^3] |
| **区域分化加剧** | 一线城市（北京、上海）政策相对谨慎，侧重便民服务；部分二三线城市（烟台、永州、连云港）探索更积极，试图通过渠道创新吸引产业投资和消费升级。 |

### 7.3 未来趋势研判

- **"虚实融合"成为主流**：全国政协委员、一心堂董事长阮鸿献指出，"电商是渠道，实体是场景，长期一定是虚实融合。"未来市场将形成全国头部引领、区域龙头深耕、实体服务为王、线上线下融合的新格局。[^25]
- **AI赋能而非替代**：AI可用于智能审方、慢病管理、精准运营，但执业药师的专业把关不可替代。国家明确严禁AI替代审方。[^16]
- **标准统一迫在眉睫**：当前各地政策差异大，"政策各地不同、标准尚未建立、运营模式分化"是行业三大难题。推行备案制取代许可制、建立国家统一的技术标准和监管规范，将成为下一阶段政策重点。[^11]

## 九、关键发现与结论

### 9.1 核心发现

1. **国家"天花板"与地方"地板"之间存在创新空间**：国家药监局48号公告为自助售药机设定了"仅乙类OTC"的上限，但并未明确禁止具备完整互联网诊疗和远程审方能力的"智慧药房（柜）"销售处方药。山西、烟台、永州、湖北等地的探索，实质上是将"智慧药房"视为**互联网医院的线下延伸终端**，而非单纯的自助售药机。

2. **"三类设施"的差异化定位是政策精细化的体现**：山西省2026年新规将药品销售专柜（人工/半自助）、自助售药机（全自动自助）、智慧药房（柜）（数字化诊疗+调配）做了清晰区分，对应不同的技术能力要求和药品销售范围，代表了监管思路从"一刀切"向"分类分级"的演进。

3. **远程审方与处方流转是处方药自动销售的生命线**：所有允许智慧药房/自动售药机销售处方药的地区，无一例外地要求：（1）处方来源真实（互联网医院或实体医院电子处方）；（2）执业药师远程审方；（3）系统全程留痕可追溯。这与2026年国家《处方药网络零售合规指南》的核心逻辑完全一致。

4. **医保结算是决定商业模式成败的关键变量**：单纯销售乙类OTC的自助售药机盈利空间有限（以低毛利率感冒药、肠胃药为主），月销可能仅数百元。而一旦接入门诊统筹和双通道医保结算，承接院内流出的慢病处方和国谈药处方，智慧药房（柜）的客单价和客流量将大幅提升。河北、重庆在此方面走在前列。[^3][^12]

5. **连锁药店马太效应加剧**：多地政策对设置离店自助售药机/智慧药柜设置连锁门店数量门槛（北京≥15家、上海≥10家），叠加远程审方平台建设投入、医保系统对接成本，使得头部连锁和互联网平台型企业（美团买药、京东健康、阿里健康）在智慧药房赛道具有天然优势。

### 9.2 对山西政策的合规性判断

综合现有信息，**山西省"智慧药房（柜）可售处方药"在现行法律框架下具有合规性依据，但存在被上级规范调整的不确定性**：

- **合规性**：山西将"智慧药房（柜）"与"自助售药机"做概念区分，并设置了严格的互联网诊疗、远程审方、执业药师审核等前置条件，符合《药品管理法》《药品网络销售监督管理办法》及2026年《处方药网络零售合规指南》的立法精神。其第六十二条"国家有新规定的，依国家规定"也设置了安全阀。[^15][^16]
- **风险点**：若国家药监局后续将"智慧药房（柜）"纳入"自助售药机"范畴统一禁止售处方药，或出台更严格的线下处方药自动调配禁令，则山西政策需相应调整。当前国家层面尚未明确回应此类探索。

### 9.3 建议关注的后续政策节点

1. 国家药监局是否会针对"智慧药房（柜）"出台专门的技术标准或管理规范；
2. 国家医保局是否将智慧药房（柜）纳入门诊统筹和双通道医保结算的全国统一接口标准；
3. 山西省智慧药房（柜）的实际运营数据和监管案例，是否出现处方审核违规或用药安全事件；
4. 其他省份（尤其是与山西相邻的陕西、河北、河南）是否会跟进类似政策，形成区域协同或竞争。
