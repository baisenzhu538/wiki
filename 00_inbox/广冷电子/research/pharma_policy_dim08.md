# 智慧药房（智慧药柜）技术标准、监管实践与行业应用调研报告

## 一、核心定义与政策背景

### 1.1 智慧药房定义

根据山西省2026年新规，**智慧药房（柜）**被明确定义为：

> "应用大数据、云计算、物联网等先进信息技术，对接'互联网+'医院、电子处方流转平台和电子医保系统、远程审方平台，提供线下自动售药、取药以及线上问药、售药、配送服务的零售药店。对药品的请领、储存、调配、核对、发放、使用等流程进行可追溯和精细化管理，为患者提供处方审核、药品核对、用药交待、用药提醒等药学服务。"[^1]

浙江省地方标准进一步将智慧药房定义为：

> "应用大数据、云计算、物联网等信息技术，对接'互联网+'医院、电子处方流转平台和电子医保系统，提供线下自助售药、取药，以及线上问药、售药、配送服务的零售药店。"[^2]

医疗机构内智慧药房（不含中药房）的定义为：

> "应用大数据、云计算、物联网等信息技术，利用各类数据资源辅助科学决策，结合智能控制系统，对药品的申领、储存、调配、核对、发放、使用等流程进行可追溯和精细化管理，为患者提供处方审核、药品调剂、药物重整、用药交待、用药提醒、用药随访等药学服务，实现工作任务、场所环境等智能化管理的药房。"[^3]

[^1]: 山西省药品监督管理局智慧药房相关定义及政策文件，2026年
[^2]: 浙江省地方标准《智慧药房建设与管理规范》，dbba.sacinfo.org.cn

### 2.2 硬件技术要求

#### 2.2.1 自动发药与分拣系统

根据上海美团买药与华氏大药房合作的24小时智慧药房实践，硬件系统核心包括：

- **自动分拣设备**：在5米货架柜前快速取货，通过传送带运输至打包机[^7]
- **智能机械手**：替代传统螺旋式和重力式药柜，直接抓取药品，避免包装破损和货道限制[^8]
- **自助交接柜**：骑手输入取货码即可取走自动打包好的药品[^7]
- **全封闭式设计**：保证药品储存条件符合GSP规定，可储存158-1500种药品[^9]

#### 2.2.2 环境监控与温湿度管理

- **智能温湿度调控**：药柜温湿度可实现远程预警、实时监控和远程操作，满足药品GSP管理要求[^8]
- **温控传感设施**：后台实时监测，遇温湿度超标立即预警[^9]
- **恒湿恒温**：智慧药房终端设备具备恒湿恒温功能，确保药品储存合规[^10]

#### 2.2.3 身份识别与支付系统

- **人脸识别**：用于用户身份验证、执业药师考勤打卡、医保电子凭证支付[^11]
- **多种支付方式**：支持微信、支付宝、医保电子凭证、医保卡等多种结算方式[^8]
- **智能门禁**：文成首家无人智慧药房配备智能人脸识别测温门禁系统，实现防疫码核验、未戴口罩检测[^12]

| 智慧药房服务器 | 智慧药房数据同步、药监监管对接 |
| 远程审方系统 | 处方扫描/拍照、高清视频语音、指纹/人脸识别 |
| 追溯管理系统 | 药品追溯码全流程采集、入库校验、出库扫码 |

### 2.4 GSP质量管理要求

#### 2.4.1 药品追溯体系

根据《药品管理法》及GSP要求，智慧药房必须：

- **建立药品追溯管理制度**：按GSP规范建立覆盖采购、储存、销售全流程的追溯体系[^15]
- **追溯码全流程闭环**：基于药品追溯码构建全流程闭环管理体系，入库自动采集追溯码信息，与医保追溯码数据库实时比对[^16]
- **全程可追溯**：患者、药品、医师、药师信息关联，实现"来源可查、去向可追、责任可究"[^17]
- **二次扫码预警**：从源头到终端防范回流药，保障医保基金安全[^16]

[^15]: 全国医药政策月度汇编，2025-05
[^16]: 基于药品追溯码的智慧药房全流程闭环管理创新与实践，chinjmap.com，2025
[^17]: 智慧中药房中药饮片追溯管理体系，cn-healthcare.com

#### 2.4.2 处方药销售管理

- **先审核后销售**：远程审方系统必须做到先审核后销售，未经执业药师确认的系统应及时提示门店禁止该处方药销售[^18]
- **处方信息传输**：处方信息须经过拍摄或由第三方电子处方流转平台传输至远程审方室，由远程审方室的执业药师审核并确认后发回门店，经门店药师复核后方可销售[^18]
- **自动识别预警**：计算机系统应具备对处方药进行自动识别、提示和预警的功能[^18]
- **显著位置挂牌**：实施远程审方的药店应在显著位置挂牌明示，告知患者"本店为执业药师在线远程审方药店"[^18]

[^18]: 全国医药政策月度汇编中远程审方相关规定

#### 2.4.3 人员管理要求

- **执业药师配备**：应配备注册在本智慧药房的执业药师1名，如有中药材、中药饮片经营范围的，应至少配备1名执业中药师[^13]
- **远程审方考勤**：自建远程审方系统的企业，远程审方执业药师应采取排班工作制，与门店营业时间同步，在电脑或手机端通过指纹或人脸识别技术完成执业药师登录、日常考勤[^19]
- **专业技术人员**：应配备满足智慧药房建设、运营和维护所需的数字化、信息化等领域专业技术人员和管理人员[^2]

[^19]: 江西省药品监督管理局关于药品零售连锁企业开展执业药师远程审方服务工作指导意见，2024-10-28

## 四、智慧药房与自动售药机的本质区别

### 4.1 功能能力对比

| 对比维度 | 智慧药房（柜） | 传统自动售药机 |
|---------|-------------|--------------|
| **销售范围** | 处方药+非处方药（禁网药品和高风险药品除外） | 一般仅非处方药；部分高标准设备可售处方药 |
| **处方审核** | 必须具备远程审方能力，执业药师在线审核 | 通常无审方能力；高标准设备可对接远程审方 |
| **互联网诊疗** | 对接互联网医院，可在线问诊开方 | 无此功能 |
| **电子处方流转** | 对接电子处方流转平台，接收医院外流处方 | 无此功能 |
| **药学服务** | 提供处方审核、用药交待、用药提醒、用药咨询等 | 一般无专业药学服务 |
| **医保结算** | 可对接医保系统，支持医保电子凭证支付 | 部分已支持医保电子凭证 |
| **GSP管理** | 专人按GSP要求管理，温湿度自动监测调控 | 需符合GSP要求，但管理深度不同 |
| **数据对接** | 自动生成销售记录并与企业药品信息管理系统实时连接 | 需与企业计算机管理系统实时联网 |
| **24小时服务** | 支持 | 支持 |
| **配送服务** | 线上问药、售药、配送服务一体化 | 一般无配送服务 |

### 4.2 监管定位差异

根据河北省药监局文件明确区分：

- **自动售药机**：以销售非处方药品为主，禁止销售处方药（河北省规定）[^30]
- **24小时无人智慧药店**：作为实体药店的有益补充，可以使用具备人机交互功能、能够实现顾客自测用药指导及其他专业药学服务的机器人，提供专业药学服务[^30]
- **远程药柜**：具备"网上药店"资质的社会药房，可根据药学服务能力设置远程药柜，提供自动售药服务[^31]

[^30]: 河北省药品监督管理局关于支持药品零售连锁企业发展的意见，yjj.hebei.gov.cn
[^31]: 2023年中国自动化药房行业概览，dfcfw.com，2024-01

### 4.3 技术架构差异

智慧药房的核心技术架构包括：
- 大数据、云计算、物联网等信息技术底层[^2]
- 对接"互联网+"医院、电子处方流转平台、电子医保系统三大外部系统[^2]
- 远程审方平台作为药学服务支撑[^18]
- 药品信息管理系统实时连接[^1]

而传统自动售药机主要技术聚焦于：
- 货道控制与出货机制
- 支付接口
- 基础温湿度监测

## 五、智慧药房与医保结算的对接情况

### 5.1 医保对接模式

#### 模式一：医保电子凭证刷码购药

- **叮当智慧药房**：北京17家门店于2023年3月开通医保电子凭证刷码购药服务，参保群众通过实名实人认证完成医保电子凭证申领和激活，即可使用个人账户资金"码"上购药[^32]
- **覆盖城市**：北京、上海、深圳、佛山、成都、杭州、广州等[^33]
- **亲情账户**：无智能手机的老年参保人员可由家属办理"医保亲情账户"[^32]
- **异地结算**：异地参保人可在"国家医保服务平台"APP办理异地备案，凭医保电子凭证刷码支付[^32]

[^32]: 北京17家叮当智慧药房开通医保电子凭证刷码购药服务，bjd.com.cn，2023-03-21
[^33]: 叮当健康加速医保线上布局，qianlong.com，2025-11-17

- **叮当智慧药房杭州落地**：2024年6月，杭州多家叮当智慧药房开通在线医保支付功能，覆盖华中路、凤山桥直街、华星路等核心区域[^33]

- **山西省**：2023年2月完成全省统一医保电子处方平台建设，实现医保电子处方定点医疗机构上传、定点零售药店下载并进行实时结算的全流程功能对接[^34]

- **大连模式**：智慧药房建设实现与医疗卫生机构、药店ERP、医保结算系统的对接，做到医生处方有序外延至药店，实现购药、医保结算和药品进销存的同步一体化监管与服务[^28]

### 5.2 医保对接技术要求

- **医保电子凭证**：作为医保身份识别的电子介质，支持刷脸、扫码等多种方式[^11]
- **电子处方流转**：医保电子处方由定点医疗机构上传至医保电子处方中心，定点零售药店下载后进行实时结算[^34]
- **区块链存证**：部分平台构建电子处方区块链存证系统，确保处方全程可信、可验真伪、过程可追溯[^14]
- **人脸识别核验**：药房执业药师借助参保人电子医保凭证调取处方信息，人脸识别确认身份后在线实名签字核方[^14]

- **医院、药店、医保**三方共同参与，实现处方外流、医保同步、闭环管理

## 七、人脸识别与远程审方技术应用

### 7.1 人脸识别技术应用

#### 7.1.1 执业药师身份核验与考勤

- **江西、福建、湖北**等地要求：远程审方执业药师在电脑或手机端通过**指纹或人脸识别技术**完成登录、日常考勤，确保门店营业时间内有执业药师在岗[^19][^41]
- **福建技术规范**：远程审方室配备高清视频和语音系统设备、指纹确认和人脸识别等相关设备，确保与门店实时联网[^41]
- **湖北洪湖AI监管**：采用"人脸识别+活体检测"技术，执业药师每日通过药店终端打卡，系统实时抓取面部微表情、眼球运动等生物特征，防止照片、视频造假；与社保、个税系统数据联动，发现社保缴纳单位与执业注册地址不符自动触发预警[^42]

[^41]: 福建省执业药师远程审方设置技术规范（试行），yjj.scjgj.fujian.gov.cn，2019-09
[^42]: 执业药师"挂证"新监管，赛柏蓝药店，2025-07-30

#### 7.1.2 患者身份识别与医保支付

- **DTP药房**：患者购药时通过人脸识别系统等智能化途径核实患者身份，同时验证待遇证加以校对[^43]
- **智慧药房**：人脸识别与医保电子凭证无缝对接，毫秒级完成用户身份验证，实现无感支付[^11]
- **浙江衢州"药店360°"**：执业药师通过"阳光监管"APP人脸识别进行处方审核后方可交易成功，实现处方审核实时化[^44]

[^43]: 医保药品"双通道"落地，DTP药房身份识别要求，mp.weixin.qq.com
[^44]: 衢州柯城创新建设"药店360°"集成监管系统，jjdf.chinadevelopment.com.cn，2021-09-22

### 7.2 远程审方技术流程

根据各省技术规范，远程审方标准流程如下：

```
门店扫描处方 -> 网络传输至远程审方室 -> 执业药师核对处方
    <- 指纹/人脸确认后发送 <- 视频对话问询答疑 <-
门店药师复核发药
```

**具体要求**：
- 处方信息须经过拍摄或由第三方电子处方流转平台传输[^18]
- 审核后的处方经审方执业药师**指纹或人脸等识别方式确认**后发送至门店[^45]
- 门店实时接收经审核且有指纹/人脸确认的处方，对通过审核的处方进行调配[^41]
- 系统因故障无法正常实施远程审方时，无驻店执业药师的门店应暂停销售处方药[^41]

[^45]: 湖北省互联网医院药学服务管理办法，mpa.hubei.gov.cn，2021-07

## 十、结论与建议

### 10.1 核心结论

1. **技术标准逐步完善**：长三角区域已建立统一的《智慧药房评价体系》，安徽、浙江等省出台了建设指南和验收规范，但针对零售药店智慧药房（柜）的全国性标准尚待制定。

2. **处方流转是核心能力**：智慧药房与自动售药机的本质区别在于是否具备**远程审方能力**和**电子处方流转对接能力**。山西、大连、浙江等地已将此作为硬性要求。

3. **医保对接是发展关键**：医保电子凭证、在线医保支付、电子处方中心流转三种模式并行发展，已在北京、上海、深圳、杭州、大连、山西等地落地。医保对接能力直接影响智慧药房的市场竞争力。

4. **24小时无人化是趋势**：上海、浙江、湖南等地已成功运营24小时智慧药房，技术成熟度较高，但需配套远程审方和AI监管能力。

5. **监管趋向智能化**：人脸识别、AI视频监控、区块链存证、电子处方追溯等技术正在被纳入监管体系，浙江衢州"药店360°"、湖北洪湖AI监管模式具有示范意义。

### 10.2 政策建议

1. **加快制定全国性智慧药房（柜）技术标准**，明确硬件、软件、GSP、数据接口的最低要求。

2. **推动电子处方流转平台与医保结算系统全面打通**，统一数据标准和接口规范。

3. **建立远程审方服务质量评价体系**，确保执业药师真正在岗履职，防止"代签""挂证"等问题。

4. **推广智慧药房药品追溯码全流程应用**，从源头防范回流药，保障医保基金安全。

5. **鼓励"平台+药店"合作模式**，降低中小药店数字化转型成本，同时保障药品质量和药学服务不降级。
