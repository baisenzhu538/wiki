## 一、主控板概述

HX-SMJ-01B 主控板是自动售货机系统的核心控制板，主要功能包括：

| 功能模块 | 说明 |
|---------|------|
| 主控 MCU | STM32F103ZET7 (LQFP-144, 256KB Flash) |
| 电源系统 | 双路 TPS54360DDAR DC-DC + AMS1117-3.3 LDO |
| 电机驱动 | 13路货道电机（ULN2003AIDR + MOSFET）+ 1路步进电机（TB6642FG） |
| 温度控制 | 3区制冷/制热，压缩机+风扇+四通阀控制 |
| 通信接口 | RS232×2、CAN总线、UART×3（4G/WiFi/蓝牙） |
| 显示接口 | DGUS 串口屏 + Android 上位机 |
| 传感器 | 门开关、人体红外、2路掉货检测红外、编码器 |
| 电子锁 | 1路电子锁控制 |
| 网络模块 | 支持 EC20(4G)/ESP32(WiFi)/Air720 多种模块 |
| OTA升级 | HTTP 固件在线升级 V2.3.0 |

### 2.2 关键差异（V1.0 vs V2.0）

**MCU 型号变更（重大）：**
- V1.0: STM32F103VET7 (LQFP-100)
- V2.0: STM32F103ZET7 (LQFP-144)

**其他重要变更：**
- U8: 74HC237D → 74HC138D（3-8译码器型号变更）
- U14: 新增 74HC137D
- U21: 新增 TB6642FG（步进电机驱动）
- Q10-Q13: NCE6005AS 数量 2→4
- 新增 Q21: IRFR5410TRPBF
- 删除 Y2: 8MHz 晶振（可能使用内部时钟或改由其他晶振提供）

### 8.2 固件确认事项

1. 确认实际使用的 MCU 是 VET7 还是 ZET7

## 九、两种主板变体说明

根据用户提示和固件分析，主控板存在两种变体：

| 变体 | 特征 | 固件差异 |
|------|------|---------|
| **标准版** | 不带安卓板/上位机软件 | 无 AndroidApp 相关代码 |
| **安卓版** | 带安卓板和上位机软件 | 包含 `AndroidApp_Set_Miscs()` 等接口 |

固件源码中同时存在两种支持，通过编译选项或运行时配置切换。
