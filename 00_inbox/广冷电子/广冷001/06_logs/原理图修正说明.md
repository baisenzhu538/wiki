## 二、核心结论：BOM和PCB正确，原理图是未修改完的过程产品

### 2.1 证据链

```
原理图（PNG）          BOM（CSV）            PCB坐标（CSV）
    │                      │                       │
    │  U11-U13: 1G07      │  U11-U13: 2G07        │  U11-U13: SOT-23-6
    │  （5脚，单路）        │  （6脚，双路）          │  （6脚焊盘）
    │       ❌              │        ✅              │         ✅
    │                      │                       │
    │  C35: 无标注          │  C35: 10uF/25V钽电容   │  C35: 钽电容焊盘
    │       ❌              │        ✅              │         ✅
    │                      │                       │
    │  R1-R16: 2kΩ          │  R1-R16: 2kΩ          │  R0603焊盘
    │       ✅              │        ✅              │         ✅
    │                      │                       │
    │  U6: TPS54360         │  U6: TPS54360DDAR      │  SOIC-8焊盘
    │       ✅              │        ✅              │         ✅
```

### 2.2 判断依据

| 判断维度 | 分析 |
|:---------|:-----|
| **PCB是最终物理实现** | PCB焊盘是6脚，只能焊6脚器件，不可能焊5脚器件。PCB不会错 |
| **BOM是采购依据** | BOM采购的是2G07（6脚），与PCB焊盘匹配。如果BOM错了，采购的器件焊不上去 |
| **原理图是设计文档** | 原理图上的1G07标注可能是旧版符号未更新，或库符号混用 |
| **C35遗漏** | PCB上有焊盘、BOM有采购、坐标有位置，唯独原理图没画。这是典型的"改版后原理图未同步" |

### 2.3 结论

> **BOM清单和PCB板图是正确的。原理图是过程产品，在改版过程中有2处未修改完：**
> 1. U11-U13的型号未从1G07更新为2G07
> 2. C35未在原理图上补画

## 三、修正说明（输出给工程师）

### 3.1 修正1：U11-U13 型号修正

**当前状态（错误）**：
- 原理图标注：SN74LVC**1**G07DBVR（单路开漏缓冲器，SOT-23-5，5脚）
- 实际PCB焊盘：SOT-23-6（6脚）
- 实际BOM采购：SN74LVC**2**G07DBVR（双路开漏缓冲器，SOT-23-6，6脚）

**需要修正**：
```
U11: SN74LVC1G07DBVR → SN74LVC2G07DBVR
U12: SN74LVC1G07DBVR → SN74LVC2G07DBVR
U13: SN74LVC1G07DBVR → SN74LVC2G07DBVR
```

**引脚对应关系**（2G07有2路，原理图只画了1路，需确认第2路是否悬空或接其他信号）：

SN74LVC2G07DBVR 引脚定义：
```
Pin 1 (1A)  → 第1路输入
Pin 2 (GND) → 地
Pin 3 (2A)  → 第2路输入
Pin 4 (2Y)  → 第2路输出（开漏）
Pin 5 (VCC) → 电源
Pin 6 (1Y)  → 第1路输出（开漏）
```

原理图上U12画了2路输入（SRCLK + RCLK）但只有1路输出标注，需要确认：
- 是否2路输出合并？（不合理，开漏不能合并）
- 还是只使用了1路，另一路悬空？
- 或者原理图连线有误，实际只接了1路信号？

**建议**：请原工程师确认U12/U13的实际连线意图。从PCB坐标看，U11-U13都在同步信号区域（Y坐标-14.1mm），可能确实需要双路缓冲。

### 3.2 修正2：C35 补画

**当前状态（遗漏）**：
- 原理图U7（AMS1117-3.3）附近只有C34和C36
- PCB上有C35焊盘，在U7输出端附近
- BOM有C35=10uF/25V钽电容

**需要补画**：
```
在AMS1117-3.3（U7）的输出端（VOUT引脚）附近增加：
  C35 = 10uF/25V 钽电容 (TAJB106K025RNJ)
  封装 = CAP-SMD_L3.5-W2.8-R-RD
```

**电路连接**：
- C35正极 → U7的VOUT（3.3V输出）
- C35负极 → DGND
- 与C36（100nF）并联，共同作为输出滤波

### 3.3 修正3：版本号更新

**当前状态**：
- 标题框显示 REV: 1.0, Date: 2021-10-19 / 2021-12-11
- 但器件参数已是2025年BOM的升级版本

**建议更新**：
```
REV: 2.2 或 V2.2-M1
Date: 2025-12-03（与BOM日期同步）
修改记录：
  1. R1-R16: 8.2kΩ → 2kΩ
  2. R17/R20: 100kΩ → 9.1kΩ
  3. C31: 1210贴片10uF → 220uF/16V电解电容
  4. D34/D35: SS24 → SS36
  5. U6: JW5026 → TPS54360
  6. U11-U13: 1G07 → 2G07
  7. 新增C35: 10uF/25V钽电容
```
