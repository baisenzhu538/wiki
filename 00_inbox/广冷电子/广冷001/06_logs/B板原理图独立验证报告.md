## 二、B板电路架构分析

### 2.1 B板功能定位

B板是**纯外设板**，无独立MCU和电源，通过同步线与A板配对工作：

```
A板（主控） ←──同步线──→ B板（外设）
   │                          │
   ├─ 16路发射 ─────────────→ ├─ 16路接收
   ├─ 16路接收 ←───────────── ├─ 16路发射
   ├─ 电源(5V) ────────────→ ├─ 取电工作
   └─ 控制信号 ────────────→ └─ 595/4051驱动
```

### 2.2 B板电路组成

| 模块 | 原理图页面 | 核心器件 | 功能 |
|:-----|:-----------|:---------|:-----|
| 接收前端 | B-01 | D17-D32 + R1-R16 + 运放调理 | 16路红外光接收 |
| 接收模块 | B-02 | U2/U3=CD4051 + U1=LMV358 | 16选2模拟开关 + 信号放大 |
| 发射驱动 | B-03/B-04 | Q1-Q16=AP2302B + U4/U5=595 | 16路红外LED驱动 |
| 同步接口 | B-05 | U6=SN74LV245 + J1 | 与A板信号同步/电平隔离 |

## 四、B板特有电路分析

### 4.1 C30-C37：8个11pF电容（B板特有）

**位置**：B-05图05，SN74LV245（U6）的8路输入线旁边（A_EX, B_EX, C_EX, QD3_EX, SRCLK_EX, RCLK_EX, X_IN3_EX, X_IN4_EX）。

**作用分析**：
- 11pF电容并联在信号线和地之间
- 在高速数字信号线（如SRCLK、RCLK）旁边放置小电容，作用是：
  1. **阻抗匹配**：消除信号线阻抗不连续引起的反射
  2. **EMI抑制**：吸收高频噪声，减少对外的电磁辐射
  3. **边沿减缓**：略微减缓信号边沿，降低串扰

**设计合理性**：✅ **合理**
- 同步线从A板到B板通过连接器J1传输，线缆长度可能>10cm
- 高速时钟信号（SRCLK/RCLK）在长线上容易产生反射和振铃
- 11pF小电容可以做高频端接，不影响低频信号
- 每路信号独立一个电容，避免信号间耦合

**与A板对比**：
- A板没有C30-C37，因为A板的信号在PCB内部走线，线短，反射风险低
- B板通过外部线缆连接，需要额外的信号完整性措施

### 4.2 C26=220uF/16V电解电容（B板电源滤波）

**位置**：B-05图05右下角，靠近J1的VDD_5V引脚。

**作用分析**：
- B板无独立电源，5V从A板通过J1引入
- 220uF电解电容在电源入口处做储能滤波
- 当16路LED同时开启时，瞬态电流需求大，220uF提供本地储能
- 避免长距离供电导致的电压跌落

**设计合理性**：✅ **合理**
- B板16路发射管全开时电流：16 × 75mA ≈ 1.2A
- 线缆电感会导致瞬态电压跌落，本地大电容补偿
- 与A板C31=220uF/16V对应，A板在DC-DC输出端也有同等容量

### 4.3 SN74LV245（U6）双向缓冲

**作用分析**：
- A板通过J2输出控制信号，B板通过J1接收
- SN74LV245是8路双向总线收发器，带方向控制
- 作用1：**电平隔离** — A板和B板的地可能不完全等电位，缓冲器隔离
- 作用2：**驱动增强** — 长距离线缆驱动能力不足，245增强驱动
- 作用3：**方向控制** — 通过DIR引脚控制数据流向（A→B或B→A）

**设计合理性**：✅ **合理**
- 自动售货机内部环境有电机、继电器等干扰源
- 长距离同步线（A板在上，B板在下，距离可能>30cm）需要缓冲
- 245的DIR由A板控制，确保时序正确

## 五、⚠️ 疑问项：D17-D32 符号与型号

### 5.1 问题描述

| 项目 | A板 | B板 |
|:-----|:----|:----|
| 接收管位号 | D1-D16 | **D17-D32** |
| 接收管型号 | PT334-6B | **PT334-6B** ✅ |
| 发射管位号 | D17-D32 | **D1-D16** |
| 发射管型号 | IR333C-A | **IR333C-A** ✅ |
| 原理图符号 | D1-D16=光电二极管(接收) | **D17-D32=LED(发射)** ❓ |

**发现**：
- B板BOM中D17-D32 = PT334-6B（红外接收管，光电二极管）
- B板原理图B-01上D17-D32画的是**LED符号**（箭头向外，发射管符号）
- 但B-01右侧有XA_COM/XB_COM运放调理电路，这是**接收前端**的典型电路

**矛盾**：接收前端应该接光电二极管（接收管），但符号画成了LED（发射管）。

### 5.2 可能原因分析

| 可能性 | 解释 | 概率 |
|:-------|:-----|:----:|
| **A** | 原理图符号库混用，实际器件正确 | **高** |
| **B** | 位号标注错误，D17-D32应为D1-D16 | 中 |
| **C** | BOM位号与原理图不对应，但器件正确 | 中 |

**最可能的情况（A）**：
- 立创EDA的符号库中，PT334-6B和IR333C-A可能使用了相同的封装符号
- 或者工程师在画图时复制了A板的发射管符号到B板的接收前端，忘记修改符号类型
- 实际PCB上焊的是正确的PT334-6B（接收管），只是原理图符号画错了

**验证方法**：
1. 检查PCB上D17-D32焊盘的极性方向（接收管光电二极管通常无极性或有特定极性）
2. 检查B板实物上的D17-D32丝印，确认焊的是PT334-6B还是IR333C-A
3. 如果实物是PT334-6B → 只是原理图符号错误，不影响功能

### 5.3 对功能的影响

| 场景 | 影响 |
|:-----|:-----|
| 如果实物是PT334-6B（接收管） | ✅ 无影响，只是原理图符号画错了 |
| 如果实物是IR333C-A（发射管） | ❌ 严重错误，B板无法接收A板发射的信号 |

**建议**：首件确认B板实物上D17-D32的器件型号。

## 六、B板与A板差异对比

| 对比项 | A板（主控） | B板（外设） | 差异说明 |
|:-------|:-----------|:-----------|:---------|
| MCU | STM32F103RCT7 | 无 | B板由A板控制 |
| 电源 | TPS54360 + AMS1117-3.3 | 无 | B板从A板取电 |
| 复位电路 | TPS3808G33DBVR | 无 | 不需要 |
| 晶振 | 8MHz | 无 | 不需要 |
| 烧录口 | XH-5AW (SWD) | 无 | 通过A板烧录 |
| LED指示灯 | LED1(电源) + LED2(检测) | 无 | 不需要 |
| 信号缓冲 | U11-U16=2G07 (6个) | U6=SN74LV245 (1个) | B板用245做总线缓冲 |
| 信号匹配 | 无 | C30-C37=11pF×8 | B板有长线缆匹配 |
| 电源滤波 | C31=220uF/16V | C26=220uF/16V | 对应位置不同 |
| 连接器 | J1=M2016R-03P (电源) + J2=PHB-2*5AW (同步) | J1=PHB-2*5AW (同步+电源) | B板只有1个连接器 |

**设计合理性**：✅ **完全合理**
- B板作为纯外设，去掉MCU/电源/复位等是正确的设计简化
- 增加245缓冲和11pF匹配电容是应对长距离同步的必要措施
- 与A板形成主从架构，降低成本和复杂度

## 七、设计合理性独立评估

### 7.1 接收链路

```
红外光 → D17-D32(PT334-6B) → R1-R16(2kΩ上拉) → XA/XB_COM → 
R74/R75(0Ω) → R18/R21(1kΩ) + R17/R20(9.1kΩ) + C22/C24(11pF) → 
INA-/INB- → U1(LMV358)放大 → X_IN1/X_IN2 → U2/U3(CD4051)选择 → 
A_5V/B_5V/C_5V → U6(SN74LV245)缓冲 → 同步线 → A板MCU
```

**评估**：✅ 链路完整，每级功能明确，与A板接收链路完全一致。

### 7.2 发射链路

```
A板MCU → 同步线 → U6(SN74LV245) → U4/U5(595移位寄存器) → 
Q1-Q16(AP2302B) → D1-D16(IR333C-A发射管) → 红外光 → A板接收
```

**评估**：✅ 链路完整，595串行转并行驱动16路MOSFET，设计合理。

### 7.3 电源链路

```
A板5V输出 → J1(Pin9=VDD_5V) → C26(220uF)滤波 → 
VDD_5V母线 → 各模块供电
```

**评估**：✅ 简单可靠，本地大电容补偿长线缆压降。
