## 六、基线文件使用指南

### 6.1 生产流程

```
1. 采购：按 BOM V2.1-修改_2025-12-03 采购器件
2. 制板：按 Gerber V2.2_2025-12-03 制板
3. 贴片：按 坐标 V2.2_2025-12-03 + BOM 贴片
4. 烧录：编译 现场调试成功版 ir.c → 烧录hex
5. 测试：16路全扫描 + 四路冗余判断验证
```

### 6.2 维修流程

```
1. 查原理图：使用修正后的原理图（U11-U13为2G07，含C35）
2. 查BOM：确认器件型号和封装
3. 查坐标：确认器件在PCB上的物理位置
4. 查固件：确认烧录的是现场调试成功版
```

### 6.3 版本升级流程

```
1. 修改原理图（立创EDA）
2. 同步更新BOM（导出新的CSV）
3. 同步更新Gerber（重新生成）
4. 同步更新坐标（重新导出）
5. 更新版本号（REV + Date）
6. 放入 02_pcb/[板型]/ 目录
7. 更新本清单
```
