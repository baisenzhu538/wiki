## 二、修正1：U11-U13 型号更新（优先级：🔴 最高）

### 2.1 问题描述

| 位号 | 当前原理图 | 正确型号 | 正确封装 | 影响 |
|:-----|:-----------|:---------|:---------|:-----|
| U11 | SN74LVC**1**G07DBVR | SN74LVC**2**G07DBVR | SOT-23-6 | 5脚器件无法焊到6脚焊盘 |
| U12 | SN74LVC**1**G07DBVR | SN74LVC**2**G07DBVR | SOT-23-6 | 同上 |
| U13 | SN74LVC**1**G07DBVR | SN74LVC**2**G07DBVR | SOT-23-6 | 同上 |

### 2.2 立创EDA操作步骤

**步骤1：定位器件**
```
1. 打开立创EDA工程
2. 切换到"同步接口"页面（或包含U11-U13的页面）
3. 在画布上找到 U11、U12、U13 三个器件
4. 单击选中 U11
```

**步骤2：修改型号**
```
5. 右侧属性面板 → 型号 → 当前显示 "SN74LVC1G07DBVR"
6. 删除旧型号，输入新型号：SN74LVC2G07DBVR
7. 按回车确认
8. 系统可能提示"是否更换封装" → 选择"是"或手动更新封装
```

**步骤3：更新封装**
```
9. 如果封装未自动更新：
   属性面板 → 封装 → 点击"选择封装"
   搜索：SOT-23-6 或 SN74LVC2G07DBVR
   选择：SOT-23-6_L2.9-W1.6-P0.95-LS2.8-BR
   确认
10. 检查引脚编号是否正确：
    1A(1) → 第1路输入
    GND(2) → 地
    2A(3) → 第2路输入
    2Y(4) → 第2路输出（开漏）
    VCC(5) → 电源
    1Y(6) → 第1路输出（开漏）
```

**步骤4：检查连线**
```
11. 对U12（双路缓冲SRCLK+RCLK）：
    - 确认Pin1(1A)连接SRCLK信号
    - 确认Pin6(1Y)连接SRCLK_5V输出
    - Pin3(2A)和Pin4(2Y)的处理：
      * 方案A：如果实际只使用1路 → 将Pin3接GND，Pin4悬空
      * 方案B：如果实际使用2路 → 确认Pin3接RCLK，Pin4接RCLK_5V
    - 请根据实际PCB走线确认

12. 对U13（双路缓冲A+QD3）：
    - 确认Pin1(1A)连接A信号
    - 确认Pin6(1Y)连接A_5V输出
    - Pin3(2A)和Pin4(2Y)的处理：
      * 方案A：如果实际只使用1路 → 将Pin3接GND，Pin4悬空
      * 方案B：如果实际使用2路 → 确认Pin3接QD3，Pin4接QD3_5V
    - 请根据实际PCB走线确认

13. 对U11（单路缓冲C信号）：
    - 使用Pin1(1A)和Pin6(1Y)
    - Pin3接GND，Pin4悬空（或根据实际走线）
```

**步骤5：重复修改U12、U13**
```
14. 对U12、U13重复步骤2-4
15. 确认三个器件全部更新为SN74LVC2G07DBVR + SOT-23-6封装
```

**步骤6：验证**
```
16. 设计规则检查(DRC) → 运行电气规则检查
17. 确认无"封装不匹配"或"引脚未连接"错误
18. 保存工程
```

## 三、修正2：C35 补画（优先级：🔴 高）

### 3.1 问题描述

| 项目 | 状态 |
|:-----|:-----|
| BOM | 有C35 = 10uF/25V钽电容 (TAJB106K025RNJ) |
| PCB坐标 | 有C35焊盘，位于U7(AMS1117-3.3)输出端附近 |
| 原理图 | **遗漏，未画出** |

### 3.2 立创EDA操作步骤

**步骤1：定位U7**
```
1. 切换到"电源模块"页面（图05对应的页面）
2. 找到 U7 (AMS1117-3.3)
3. 确认U7周围已有：
   - C34 = 100nF/50V (C0603) → 输入端
   - C36 = 100nF/50V (C0603) → 输出端
```

**步骤2：放置新电容**
```
4. 工具栏 → 放置 → 器件 或 快捷键 P
5. 搜索器件：TAJB106K025RNJ 或 10uF/25V 钽电容
6. 选择封装：CAP-SMD_L3.5-W2.8-R-RD
7. 将器件放置在U7输出端附近（参考PCB坐标：U7在30.86,-27.56，C35在37.08,-26.21）
8. 双击器件，修改位号为 C35
```

**步骤3：连线**
```
9. 连线工具(W)或快捷键 W：
   - C35正极 → 连接到 U7的VOUT引脚（与C36并联）
   - C35负极 → 连接到 DGND（与C36共地）
10. 确认连接方式：
    VOUT(3.3V) ─┬─ C36(100nF) ─┬─ DGND
                └─ C35(10uF) ──┘
```

**步骤4：添加参数**
```
11. 选中C35
12. 属性面板 → 值 → 输入：10uF/25V
13. 属性面板 → 型号 → 输入：TAJB106K025RNJ
14. 属性面板 → 封装 → 确认：CAP-SMD_L3.5-W2.8-R-RD
```

**步骤5：验证**
```
15. 运行DRC检查
16. 确认C35无"未连接"或"短路"错误
17. 保存工程
```

## 五、修正4：U16 引脚利用检查（优先级：🟢 低，可选）

### 5.1 问题描述

U16标注为SN74LVC2G07DBVR（双路），但原理图只画了1路（QD1→QD1_5V）。

### 5.2 操作步骤

```
1. 找到U16
2. 检查Pin3(2A)和Pin4(2Y)的连接状态
3. 如果悬空：
   - 方案A：保持现状（2G07只使用1路，另一路悬空是允许的）
   - 方案B：将Pin3接GND，Pin4悬空（更规范）
4. 如果PCB上实际有走线：
   - 补画原理图上的缺失连线
```

**建议**：如果PCB上U16的第2路确实悬空，可以不改。这不是错误，只是器件利用率不高。

## 八、常见问题排查

### Q1：立创EDA库中搜不到SN74LVC2G07DBVR？

**A**：
```
1. 尝试搜索：2G07 或 LVC2G07
2. 如果仍无结果：
   - 使用通用SOT-23-6封装手动创建符号
   - 或从TI官网下载SPICE模型导入
3. 临时方案：使用SN74LVC1G07DBVR符号，但手动修改引脚数为6脚
```

### Q2：修改封装后引脚编号错乱？

**A**：
```
1. 双击器件 → 引脚映射
2. 确认引脚对应关系：
   Pin1 → 1A (输入)
   Pin2 → GND
   Pin3 → 2A (输入)
   Pin4 → 2Y (输出)
   Pin5 → VCC
   Pin6 → 1Y (输出)
3. 如果引脚映射错误，手动调整
```

### Q3：C35的钽电容极性怎么画？

**A**：
```
1. 立创EDA中钽电容符号通常有极性标记（+号）
2. 正极接VOUT(3.3V)，负极接DGND
3. 确认封装上的极性标记与原理图一致
4. 钽电容反接会爆炸，务必确认极性
```
