## 一、项目全貌与系统架构

### 1.1 项目背景

广冷电子 HX-SMJ 项目是一款自动售货机控制系统，包含以下核心模块：

| 模块 | 板卡型号 | 功能定位 | 复杂度 |
|:-----|:---------|:---------|:-------|
| **主控板** | HX-SMJ-01B | 整机控制核心：MCU、电源、通信、电机驱动、温度控制 | 高 |
| **红外主控板(A)** | HX-SMJ-03B-A | 红外光栅发射/接收主控，管理货道检测 | 中 |
| **红外从控板(B)** | HX-SMJ-03B-B | 红外光栅从控，配合A板完成货物检测 | 中 |
| **继电器板** | HX-SMJ-01-1 | 6路继电器扩展，控制货道电磁锁/电机 | 低 |
| **安卓板** | 外购 | 上位机显示与交互（另行项目分析） | - |

### 1.2 系统连接关系

```
                    +-------------+
                    |   安卓板    |  (外购上位机)
                    |  (上位机)   |
                    +------+------+
                           | UART/RS232
                    +------v------+
        +-----------+   主控板    +-----------+
        |           | HX-SMJ-01B  |           |
        |           |  STM32ZET7  |           |
        |           +------+------+           |
        |                  |                   |
   CAN总线            6路GPIO            13路电机驱动
        |                  |                   |
   +----+----+      +------v------+      +-----+-----+
   |红外A板  |      |  继电器板   |      |  货道电机  |
   |03B-A    |      | HX-SMJ-01-1 |      |  (13通道)  |
   +----+----+      +-------------+      +-----------+
        | 红外对射
   +----v----+
   |红外B板  |
   |03B-B    |
   +---------+
```

| 型号 | HX-SMJ-01B (又称 HX-SMJ01B-12306) |
| MCU | STM32F103ZET7 (LQFP-144, 512KB Flash, 64KB RAM) |

| 通信接口 | RS232 x2, CAN, MQTT/4G |

**结论**: V2.0 (2025-11-25) 为最新可信基线。

|:---------|:-----|:-----|

### 2.4 原理图 vs BOM 验证（⚠️ 严重问题）

| 验证项 | 原理图(PDF V1.0) | BOM(V2.0) | 一致性 |
|:-------|:-----------------|:----------|:-------|
| MCU型号 | STM32F103**VET7** (LQFP-100) | STM32F103**ZET7** (LQFP-144) | ❌ **不匹配** |
| U14 | 未标注 | 74HC137D | ❌ 缺失 |

**核心问题**: 原理图PDF (2021-10-19, REV 1.0) 是**过时版本**，未反映V2.0硬件变更。

### 2.5 固件验证

| 固件版本 | 大小 | 服务器地址 | 兼容性 |
|:---------|:-----|:-----------|:-------|

| 验证方向 | 结果 |
|:---------|:-----|
| BOM -> 坐标 | 全部匹配 |
| BOM -> Gerber | 层文件齐全 |
| **综合** | **100%通过** |

### 3.4 原理图验证发现的问题

| 问题 | 位号 | 原理图 | BOM/PCB | 影响 |
|:-----|:-----|:-------|:--------|:-----|
| 1. 缓冲器型号错误 | U11-U13 | SN74LVC**1**G07DBVR (单路) | SN74LVC**2**G07DBVR (双路) | 中：功能可实现，但封装不匹配 |
| 2. 电容缺失 | C35 | 未标注 | 10uF/25V钽电容 | 低：AMS1117输出滤波，影响电源稳定性 |

**问题1说明**: 1G07是SOT-23-5单路缓冲器，2G07是SOT-23-6双路缓冲器。PCB焊盘为6脚，若贴1G07会空一脚，功能上单路缓冲器也能工作，但非最佳设计。

**问题2说明**: C35为AMS1117-3.3输出端滤波电容，缺失会导致LDO输出纹波增大，影响红外MCU电源质量。

## 九、待资深电子工程师核对事项

### 9.1 高优先级（必须核对）

1. **主控板原理图MCU型号确认**
   - 请确认实际PCB上焊接的是 STM32F103VET7 还是 ZET7
   - 若实际为ZET7，则原理图必须更新
   - 核对引脚数量：VET7为100脚，ZET7为144脚

2. **主控板缺失器件确认**
   - 请确认PCB上是否存在 U14(74HC137D) 和 U21(TB6642FG)
   - 若存在，则原理图必须补充
   - 核对这两个器件的实际连接关系

3. **红外A板缓冲器型号确认**
   - 请确认实际焊接的是 SN74LVC1G07 还是 2G07
   - 核对PCB焊盘是5脚还是6脚
   - 确认功能是否正常（单路vs双路缓冲）

### 9.2 中优先级（建议核对）

4. **红外A板C35电容确认**
   - 请确认AMS1117-3.3输出端是否有10uF钽电容
   - 测量LDO输出纹波，确认电源质量

5. **红外B板LED/接收管确认**
   - 请确认D17-D32实际器件是LED发射管还是PT334-6B接收管
   - 核对BOM采购记录

6. **主控板位号体系统一**
   - 建议统一原理图与BOM的位号命名规则
   - 例如：IC统一用U开头，Q开头用于晶体管，D开头用于二极管

### 9.3 低优先级（可选优化）

7. **Keil工程修复评估**
   - 评估是否需要修复工程目录结构以支持二次开发
   - 确认目标器件是否应从VC改为ZET7

8. **域名可配置机制评估**
   - 评估在固件中增加域名Flash配置的可行性
   - 评估双域名冗余机制的必要性
