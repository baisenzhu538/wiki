## 3. 知识要点提炼（供后续编排参考）

- **立身之本**：内容逻辑 → 空间结构的映射；全景图只看布局能读出几大块 = 合格，均匀路径线 = 失败
- **三硬指标**：单文件自包含（base64 内联断网可播）/ 空间叙事 / 零臆造（事实清单带 source）
- **三步流水线**：策划（plan.json）→ 媒体（media_manifest.json）→ 构建+QA（演示.html），闸门 rc≠0 不放行，scene_id 串闭环
- **聚簇四原则**：先拆聚簇 / 簇内紧凑不遮挡 / 簇间分离承载关系 / 结构靠镜头涌现禁止剧透
- **真嵌套**：父子 scale 比 ≥3、子坐标落父包围盒内、有钻入+退回序列；纯 y 平铺+远景 hub ≠ 嵌套
- **防晕规则**：相邻旋转 ≤90°、缩放比 ≤10 倍、运动类型交替、间距大于包围盒
- **Roam 双向线**：`prezi2roam.py` 导出大纲 / `roam2prezi.py` 确定性重建；本地快迭代=机械三闸，正式交付须重截图+独立终审
- **信任红线**：构建者禁止手写/修改 review.json；final 闸用 html_sha256 绑定防「改产物拿旧 review 闯关」
- **实战规模**：60 镜头 / 7 聚簇 / 每章 3 嵌套子讲点 / 约七成场景配图 / 单文件 ~42MB
