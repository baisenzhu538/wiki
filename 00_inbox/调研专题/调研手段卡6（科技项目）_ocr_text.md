# 调研手段卡6：科技型项目评估

如果我想做一个科技型项目，如何拿到信息，评估技术可行性、市场可行性

| 类型介绍 | 常见类型 | 1. 想要推新技术，基于新技术研发新产品<br>2. 想要保持领先，把新型技术应用到自身产品上<br>3. 想要跟进同行，把竞品的优点赋能到自身产品 |
|---|---|---|
| | 调研重点 | 调研侧重点在于水下的技术信息比较难拿，早期的市场反馈太少 |
| 调研手段 Top10 | 浅层手段 | 1. 裁判文书网（搜集对手的法律纠纷）<br>2. 天眼查查（看中标信息，查背后专利，倒推技术方案）<br>3. 查阅学术论文（跟踪产业化进度、技术参数）<br>4. 官网搜索资料（了解研发思路和解决方案）<br>5. 公司抖音（关注竞对的抖音号，获取设备和生产信息） |
| | 中层手段 | 1. 逆向工程（分析技术原理，购买竞品拆解拆机报告）<br>2. 参加展会（伪装成客户和销售沟通）<br>3. 同行圈子（交流话题，了解最新情报） |
| | 深层手段 | 1. 访谈顶级科学家（交流技术可行性）<br>2. 供应商调研（获得各项参数和流程） |
