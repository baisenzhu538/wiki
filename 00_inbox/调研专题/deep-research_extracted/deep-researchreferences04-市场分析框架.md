# 市场分析框架

## 概述

市场分析是深度调研的核心输出之一。本框架提供PEST、波特五力和市场地图三种工具，系统化分析市场机会和竞争格局。

---

## PEST 分析框架

PEST 用于分析宏观环境对行业的影响。

### 四维度分析

| 维度 | 关键问题 | 分析要点 |
|------|----------|----------|
| **P 政治/政策** | 政策是鼓励还是限制？ | 监管政策、政府补贴、行业准入口、贸易政策 |
| **E 经济** | 经济环境如何影响消费？ | 人均收入、消费趋势、支付能力、成本结构 |
| **S 社会** | 社会变化如何影响需求？ | 人口结构、消费习惯、文化趋势、生活方式 |
| **T 技术** | 技术变革带来什么机会？ | 技术成熟度、创新速度、专利壁垒、替代威胁 |

### PEST 示例（智能电动车）

```
P 政治/政策
├── 政策支持：新能源补贴、免购置税、送牌照
├── 监管加强：安全标准、续航虚标监管
└── 行业准入：造车资质收紧

E 经济
├── 人均收入提升：消费升级趋势
├── 油价上涨：燃油车使用成本上升
└── 电池成本下降：价格下探空间

S 社会
├── 环保意识：年轻人更接受电动车
├── 智能化偏好：科技感成为购车重要因素
└── 共享经济：从拥有到使用的观念转变

T 技术
├── 电池技术：续航500km以上成为主流
├── 自动驾驶：L2+普及，L3试点
└── 充电基础设施：快充站加速铺设
```

## 波特五力模型

波特五力用于分析行业竞争强度和盈利能力。

### 五力详解

| 五力 | 关键问题 | 分析要点 |
|------|----------|----------|
| **行业内现有竞争** | 竞争有多激烈？ | 主要玩家数量、集中度、差异化程度 |
| **潜在进入者** | 新进入者威胁多大？ | 壁垒高低、资本要求、渠道获取 |
| **替代品威胁** | 替代品威胁多大？ | 替代品性能、用户转换成本 |
| **供应商议价能力** | 供应商有多强势？ | 供应商集中度、替代供应商难度 |
| **买家议价能力** | 买家有多强势？ | 用户集中度、信息透明度、价格敏感度 |

### 波特五力示例（智能电动车）

```
1. 行业内现有竞争
├── 特斯拉、比亚迪、蔚来、小鹏、理想...
├── 竞争激烈，价格战开打
└── 集中度：CR5约60%

2. 潜在进入者
├── 壁垒：高资本要求、造车资质
├── 小米、华为等科技公司进入
└── 威胁：中高

3. 替代品威胁
├── 燃油车：市场份额被侵蚀
├── 公共交通：影响有限
└── 威胁：中高（燃油车替代）

4. 供应商议价能力
├── 电池（宁德时代、比亚迪）：议价能力强
├── 芯片（英伟达、高通）：议价能力强
└── 整体：供应商较强势

5. 买家议价能力
├── 个人消费者：分散，议价能力弱
├── B端客户：议价能力强
└── 整体：买家议价能力中

结论：行业盈利能力承压，竞争激烈
```

## 市场地图

市场地图提供市场的全景视图。

### 产业链结构

```
[产业链位置]

上游：零部件
├── 电池（宁德时代、比亚迪电池、国轩高科）
├── 电机（方正电机、卧龙电驱）
├── 电控（汇川技术、宁德时代）
└── 芯片（英伟达、高通、地平线）

中游：整车制造
├── 传统车企转型（比亚迪、吉利、广汽）
├── 新势力（蔚来、小鹏、理想、零跑）
└── 科技公司（小米、华为问界）

下游：销售与服务
├── 4S店/直营店
├── 充电网络（特来电、星星充电）
└── 二手车/储能
```

### 核心玩家分布

```
[核心玩家]

第一梯队（年销50万+）
├── 比亚迪：全价格带覆盖
├── 特斯拉：高端+中端
└── 五菱：微型车下沉

第二梯队（年销10-50万）
├── 蔚来：高端换电
├── 小鹏：智能驾驶
├── 理想：家庭SUV
└── 广汽埃安：网约车+家用

第三梯队（年销1-10万）
├── 零跑：性价比
├── 哪吒：下沉市场
└── 问界：华为赋能
```

### 市场规模估算

```
[市场规模]

总体市场（TAM）
├── 全球：万亿级
└── 中国：8000亿+

可服务市场（SAM）
├── 中国新能源市场：5000亿+
└── 智能电动车：3000亿+

可获得市场（SOM）
├── 目标细分市场：500亿+
└── 3年后目标：100亿
```

### 市场规模估算方法

| 方法 | 公式 | 适用场景 |
|------|------|----------|
| **自上而下** | 总量×份额 | 有权威数据时 |
| **自下而上** | 用户数×客单价 | 需要调研验证 |
| **类比法** | 参考成熟市场 | 新兴市场 |
| **推演法** | 渗透率×总人口 | 长期预测 |
