# 10维度竞品深度分析

## 概述

通用AI的竞品分析往往停留在表面（功能对比），真正有价值的竞品分析需要从10个维度深入挖掘。

## 10维度详解

### 维度1：公司背景

| 信息点 | 获取方式 |
|--------|----------|
| 成立时间 | 官网/天眼查/企查查 |
| 融资阶段 | IT桔子/鲸准/Crunchbase |
| 团队规模 | 官网/LinkedIn/猎聘 |
| 创始人背景 | 媒体报道/LinkedIn |
| 总部位置 | 官网 |

**重点看**：
- 融资阶段反映资本认可度
- 创始人背景决定基因和资源
- 团队规模反映执行力

---

### 维度2：产品定位

| 信息点 | 获取方式 |
|--------|----------|
| 核心功能 | 官网/App Store描述 |
| 目标用户 | 官网/产品文案 |
| 价值主张 | 官网/广告语 |
| 差异化标签 | 官网/媒体报道 |

**重点看**：
- 产品解决了什么核心问题？
- 与竞品的定位差异是什么？
- 目标用户是否与我们的重叠？

---

### 维度3：商业模式

| 信息点 | 获取方式 |
|--------|----------|
| 收费模式 | 官网定价页 |
| 价格体系 | 官网/App Store |
| 收入结构 | 年报/招股书（如果披露） |
| 盈利情况 | 年报/媒体报道 |

**重点看**：
- 是订阅制还是买断制？
- 定价策略是什么？（高端/中端/低价引流）
- 是否有增值服务？

---

### 维度4：市场规模

| 信息点 | 获取方式 |
|--------|----------|
| 营收规模 | 年报/招股书/媒体报道 |
| 用户规模 | 官网/App Store/媒体报道 |
| 市场份额 | 行业报告 |
| GMV（如果是电商） | 媒体报道/年报 |

**重点看**：
- 绝对值vs增速
- 市场份额变化趋势
- 与行业平均的对比

---

### 维度5：增长策略

| 信息点 | 获取方式 |
|--------|----------|
| 获客渠道 | 官网/广告/ASO |
| 留存策略 | 产品体验/媒体报道 |
| 扩品路径 | 官网/媒体报道 |
| 国际化 | 官网/App Store多地区 |

**重点看**：
- 主要获客方式是什么？
- 用户留存策略有哪些？
- 产品线如何扩展？

---

### 维度6：技术实力

| 信息点 | 获取方式 |
|--------|----------|
| 核心技术 | 官网/专利查询 |
| 专利布局 | 专利局/鲸准 |
| 研发投入 | 年报（如果披露） |
| 技术团队 | LinkedIn/招聘网站 |

**重点看**：
- 是否有独特技术壁垒？
- 研发投入占比？
- 核心技术人员背景？

---

### 维度7：运营数据

| 信息点 | 获取方式 |
|--------|----------|
| DAU/MAU | 财报/App Annie/QuestMobile |
| 留存率 | 财报/行业报告 |
| 转化率 | 财报/行业报告 |
| NPS | 行业报告/用户调研 |

**重点看**：
- 用户粘性如何？
- 付费转化率？
- 用户满意度？

---

### 维度8：用户评价

| 信息点 | 获取方式 |
|--------|----------|
| App Store评分 | App Store |
| 用户评分分布 | App Annie/七麦 |
| 好评关键词 | App Store |
| 差评关键词 | App Store/知乎 |

**重点看**：
- 评分趋势（上升/下降）？
- 用户最满意的点是什么？
- 用户最抱怨的点是什么？

---

### 维度9：融资历史

| 信息点 | 获取方式 |
|--------|----------|
| 融资轮次 | IT桔子/鲸准 |
| 融资金额 | IT桔子/媒体报道 |
| 投资方 | IT桔子/鲸准 |
| 最新估值 | 媒体报道 |

**重点看**：
- 融资节奏（快/慢）？
- 背后投资方资源？
- 估值是否合理？

---

### 维度10：未来规划

| 信息点 | 获取方式 |
|--------|----------|
| 近期动态 | 官网/公众号 |
| 产品路线图 | 官网/媒体报道 |
| 战略方向 | 采访/演讲 |
| 组织架构 | 官网/LinkedIn |

**重点看**：
- 产品下一步方向？
- 是否有新业务布局？
- 组织扩张还是收缩？

## 常见错误

| 错误 | 后果 |
|------|------|
| 只看功能对比 | 不了解商业逻辑 |
| 只看公开信息 | 忽略水面下的动作 |
| 没有用户视角 | 脱离实际需求 |
| 没有时间维度 | 看不到趋势变化 |
