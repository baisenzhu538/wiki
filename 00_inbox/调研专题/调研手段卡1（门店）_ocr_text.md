# 调研手段卡1：门店加盟评估

如果我考虑加盟一个门店，拿到了一个招商材料，如何评估加盟靠谱程度和成功率

| | | |
|---|---|---|
| 类型介绍 | 常见类型 | 1. 加盟一个餐饮品牌，比如火锅店/奶茶店/日料店等<br>2. 加盟一个零售品牌，比如零食店/花店/熟食/水果店等<br>3. 加盟一个本地生活品牌，比如自助台球厅/桌游店/麻将馆等 |
| | 调研重点 | 调研侧重在于加盟品牌靠不靠谱，以及在这个城市实际的成本投入和加盟成功率，预测我的投资回报率和风险 |
| 调研手段 Top10 | 浅层手段 | 1. 企查查（重点看法务纠纷和是否老赖）<br>2. 新闻搜索（看市场评价和口碑）<br>3. 美团统计（围绕同城美团，统计销量和增速）<br>4. 调研相同客户群的服务（了解人群重合度） |
| | 中层手段 | 1. 参加加盟商大会（拿到最新的招商材料）<br>2. 蹲店数人头（非样板店，统计一个完整的周期）<br>3. 体验产品服务（体验本品牌和竞品的产品和服务） |
| | 深层手段 | 1. 关店调研（访谈开店失败的加盟商）<br>2. 访谈中介（获取房租信息和四季客流变化）<br>3. 选址软件（使用软件查看查看客流） |
