# 调研手段卡4：咨询类调研

如果我想做咨询，或扩大扩大咨询业务，如何判断关键决策，赛道/服务/客户/报价/转化/履约。

| 类型介绍 | 常见类型 | 1. 资深行业专家转型，想做咨询师<br>2. 咨询师想扩展团队，做规模化的业务 |
| --- | --- | --- |
| | 调研重点 | 调研侧重点在服务范围、定价、转化策略、判断适不适合做。 |
| 调研手段 Top10 | 浅层手段 | 1. 市场定位调研（爬取知乎/知识星球锁定未被满足的问题）<br>2. 潜伏行业峰会（搜集名片/分析目标客户）<br>3. 裁判网的书（挖掘法务盲区）<br>4. 行业报告（预判细分咨询市场的天花板大小） |
| | 中层手段 | 1. 伪装客户（向竞对询价/体验转化流程/套取服务体系和报价单）<br>2. 用好在行（向资深顾问请教）<br>3. 主动吸引调研（自己展示公开信息，吸引目标客流来交流）<br>4. 专家社群（加入顾问社群，找相同业务的顾问进行交流） |
| | 深层手段 | 1. 面试/入职竞对公司（系统学习流程和标准化）<br>2. 调研目标公司的 HR（了解咨询的服务） |
