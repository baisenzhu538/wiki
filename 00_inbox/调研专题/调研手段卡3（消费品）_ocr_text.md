# 调研手段卡3：消费品调研

如果我想设计一款消费品，如何拿到信息，用来评估消费品的商业可行性

| 类型介绍 | 常见类型 | 1. 创业做消费品，判断消费品的创业机会<br>2. 拓展新品类，设计一款新的消费品类型<br>3. 迭代新产品，找消费品的新迭代点 |
| --- | --- | --- |
| | 调研重点 | 调研侧重点在用户需求、核心卖点、毛利空间、渠道推广。 |
| 调研手段 Top10 | 浅层手段 | 1. 完整体验（体验完整的购买决策/开箱/使用情况）<br>2. 收集差评（中差评，小红书"踩雷"笔记）<br>3. 收集卖点（线上销售页面，直播销售话术） |
| | 中层手段 | 1. 产品逆向拆解（调研供应链的成本结构，调研认证资质）<br>2. 大量试用（分析竞品材料成分和参数）<br>3. 线下用户调研（扮演促销员/调研员）<br>4. 访谈竞品员工（访谈相关促销人员/相关客服） |
| | 深层手段 | 1. 竞对的供应链端（毛利/技术）<br>2. 出货渠道政策（促销力度，合作方式、分销体系）<br>3. 实时统计订单（网络爬虫监控销售订单） |
