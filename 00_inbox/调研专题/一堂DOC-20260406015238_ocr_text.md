# 公司公开信息（10）

公司有很多公开的信息，想办法搜集到，就够做很多判断了

来源1：公司官网
·公司官方对外介绍

来源2：公司融资信息
·了解融资轮次/金额/投资方/数据等

来源3：公司PR新闻
·了解公司重大事项/里程碑/发布会等

来源4：高管公开发言
·CEO/联创对外的公开演讲/采访/文章等

来源5：商业计划书
·鲸准(早期公司/需投资人账号)

来源6：公司招股书和财报
·公司招股书和财报(二级市场上市公司)

来源7：公司招聘启事
·公司对外招聘的岗位/薪酬/岗位要求

来源8：员工公开发言
·员工在知乎/脉脉匿名区等的发言

来源9：裁员信息
·通过公司裁员信息可倒推业务重点

来源10：股吧讨论
·东方财富网/雪球/同花顺/新浪财经等
