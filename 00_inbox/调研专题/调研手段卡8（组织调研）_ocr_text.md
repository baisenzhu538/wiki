# 调研手段卡8：组织调研卡

如果我搭建公司组织架构，想调研同行的组织结构、关键岗位的薪资和激励方式。

| 类型介绍 | 常见类型 | 1. 想借鉴同行组织结构，了解组织结构/部门结构<br>2. 想借鉴同行具体岗位，了解该岗位的人数、薪资结构<br>3. 想加入一家公司，调研公司的发展趋势 |
| --- | --- | --- |
| | 调研重点 | 调研侧重点在可靠信息源，不同来源人的信息准确性差别很大 |
| 调研手段Top10 | 浅层手段 | 1. 公开数据收集（官网/新闻报道查看组织结构）<br>2. 企查查/天眼查看（社保人数波动/实缴资本/竞业限制输送）<br>3. 调研创始团队的背景（了解过往项目的社会正负反馈）<br>4. 分析公司财报（查看公司的营收利润/员工人数）<br>5. 脉脉/领英（搜索正面负面的员工反馈/是否大规模离职） |
| | 中层手段 | 1. BOSS 直聘（找离职的前员工）<br>2. 直接面试（包装身份，参加同行的面试）<br>3. 同行跳槽人员（了解组织设置公司业务发展） |
| | 深层手段 | 1. 在行找行家付费（目标公司的离职员工）<br>2. 直接向猎头打听（是否有大规模离职/具体岗位要求） |
