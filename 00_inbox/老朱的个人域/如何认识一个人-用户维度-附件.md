# 把"人"请回商业的中心 —— 读《如何认识一个人》，从"用户维度"重看我的生意

我以前做生意、带团队，从没觉得"认识一个人"是门需要专门学的本事。直到读了戴维·布鲁克斯的《如何认识一个人》，又顺着知识库里"人域"的拆书卡把视角切到"用户维度"，我才猛然发现：过去在药店数字化、在带团队、在做销售上踩的坑，根子几乎都在同一处——我把人当成了角色、数字、采购清单，却没真正"看见"那个人。

布鲁克斯把"看见一个人"拆成三支柱：看见存在（关注如同氧气，让人感到被看见）、看见挣扎（共情而非急着解决）、看见力量（看见他的品格与叙事）。知识库把这套翻译成了商业语言——看见存在就是用户洞察，看见挣扎就是缝隙需求，看见力量就是情绪价值溢价。我越读越觉得，这不是鸡汤，是我每天做的生意里最缺的那块。下面从三个维度，说说这本书给我的新启发。

## 一、用户维度：药店数字化，我搞错了"谁才是用户"

我们做药店数字化改造，一直以来的默认假设是：客户就是药店老板。帮老板提高流量、增加收入，生意就成了。但书里"看见存在"那句——关注如同氧气——点醒了我：我只盯着老板这个"角色"，却没看见老板背后那团真正的氧气：买药的 C 端用户。

这不是 B2B，这是 B2B2C。逻辑链条其实是反的：如果我们没法帮药店真正提升曝光率、拓宽获客的途径和手段，就触达不了 C 端；触达不了 C 端，药店老板 B 端的流量根本起不来。我们过去把劲儿全使在"说服老板"上，等于在没接上氧气的情况下想让人喘气。

成都那个客户就是活生生的反面教材。我们一门心思想着怎么把系统卖给药店老板，全程围着老板的决策和预算转，偏偏忽略了 C 端用户到底怎么被触达、怎么被服务。结果可想而知——老板那头没起来，C 端更没影。书里讲，叙事型用户洞察的第一条是"用户不是数字"。我当时看见的"用户"是老板的采购意向，没看见的是一个个等着拿药的人。这单做砸，不是执行问题，是认知问题：我把 B 当成了全部，忘了 C 才是源头。好生意往往藏在缝隙里，而 C 端，正是我们一直没蹲下去看的那个缝隙。

## 二、员工即用户：领导力最大的盲区，是看不见"打工者"

第二个启发落在带人上。以前我是老板，心态很直接：我是老板，我要怎么样，员工就得怎么样。书里"看见挣扎"那支柱——共情而不是急着解决——把我这层傲慢照得清清楚楚。员工也是人，有想法、有喜怒哀乐，会偷懒、会钻空子，这都正常。我以前站在老板视角，只看见"他不配合"，没看见他背后的挣扎。

最戳我的是报销这件事。以前差旅报销，我们习惯往后拖一拖、压一压，觉得这没什么大不了，不就是晚几天到账嘛。但站在员工角度，完全是另一回事：车费迟迟不报销，他本来可以打车省时间、把效率提上去，现在只能去坐公交。公交是能坐，可来回要浪费两三个小时，效率损耗非常大。我"看见"了报销流程，却没"看见"他——没看见那两三个小时对他意味着什么，没看见他作为一个打工者，在保护自己的时间和利益时有多无奈。

现在大家都在新港湾，物理距离拉近了，我也才开始真正去了解他们的想法、心态和诉求。这正应了那句"人同此心，心同此理"。我得正视员工"打工者"的角色：在实际情况里，他首先保护自己的利益，这再正常不过，不该一味埋怨他"不站在老板角度想问题"。把员工也当"用户"来看，管理措施就得跟着实际情况变——该报的及时报，该认的诉求认真认。在这里，"被及时看见、被尊重"本身就是一种情绪价值，有时候比那点报销款本身更值钱。教练式领导力说到底，不是教，是先看见。

## 三、销售需求洞察：客户的"动力与阻力"，我过去只看见自己

第三个维度是做销售。我们推进药店数字化业务特别慢，惯用的打法是"成本价 + 利润"定个价，然后强推。书里"看见力量"提醒我：客户不是一张采购清单，他是一个有故事、有算盘、有顾虑的人。我们这种定价和强推，本质是"不管客户怎么想，反正我要怎么样"——典型的没站到对方角度。

站到客户那边想想就明白了：你让我买一台机器，可两年内都收不回成本，我也看不清它最终能给我带来什么，后面还得投入精力把运营做得更专业。这种情况下，我凭什么有信心快速做决策？我们的定价逻辑站在"做生意"的角度没错，但站在客户角度，这里横着一道巨大的阻力。这正好对应商业里"动力与阻力"的触点关系：你只讲了你的动力（我能帮你增收），却没拆解他的阻力（回本慢、看不清、还要自己投入）。需求洞察的第一步，是先把对方的阻力看见、说破，再谈成交。叙事型用户洞察讲"从你熟悉的一个人开始"——我该先看见那个具体的客户，而不是先看见我的业绩目标。

## 收尾：把人从角色里请回来

写到这里，这本书给我最大的启发其实就一句话：在商业里，"认识一个人"不是软技能，是底层能力。无论是药店数字化的 C 端、是被我当成下属的员工、还是被我强推机器的客户，问题都出在同一个地方——我把人简化成了角色、数字、清单，却忘了先去看见那个具体的人。

从"我是老板我说了算"，到"我先看见你"，这是这本书在我个人域里撬动的一点变化。往后做业务、带团队，我想试着把布鲁克斯那三支柱当成习惯：先给存在以关注，再对挣扎有共情，最后看见每个人的力量。生意的源头，终究是一个人看见了另一个人。
