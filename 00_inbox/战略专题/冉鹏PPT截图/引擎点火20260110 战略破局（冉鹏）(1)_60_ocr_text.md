战略目标

定义"我们要成为什么样的公司？"
战略目标是"阶段性成绩单"，通常用SMART原则（Specific、Measurable、Achievable、Relevant、Time-bound）。常见目标误区：只看GMV（成交额），忽略利润、现金流、风险。

分层目标体系（3-5年分阶段）：
•财务目标：
    • 年销售额：从当前X百万 → 3年内达到Y亿。
    • 净利润率：从当前10-15% → 提升到25%以上（通过精品化减少低利润SKU）。
    • ROI（广告回报）：维持4-6倍以上。
•运营目标：
    • 精品SKU占比：从当前10% → 3年内提升到50%以上（即一半销售额来自精选精品）。
    • 海外仓覆盖率：至少50%销售额来自海外仓发货（提升物流时效，降低差评）。
    • 多平台布局：从1-2个平台 → 覆盖3-5个主流平台（Shopee + TikTok + Amazon + 独立站）。
•组织/能力目标：
    • 团队规模：从当前小团队 → 建立选品、供应链、品牌、数据分析四大部门。
    • 供应链能力：从纯一件代发 → 建立稳定供应商体系 + 小批量自采 + 海外仓备货。
    • 品牌建设：推出1-3个自有品牌，独立站流量占比达到20%。
