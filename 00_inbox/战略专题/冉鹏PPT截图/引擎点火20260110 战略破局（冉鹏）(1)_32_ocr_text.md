TRUE NORTH

01
战略定势
Core Foundation
本质上是建立一个可重复的框架或心智模型（如BLM, 它帮助领导者系统地评估业务领先地位），以确保战略不是随意决策，而是基于规则和最佳实践。

02
战略洞察
Critical Insight
包括速度 * 角度。速度是通过【(模型+图表)*(假设+验证+迭代)】快速决策、快速试错、快速迭代；角度是广角镜+聚焦镜+反转镜，从不同的角度审视市场环境，以制定有效的战略

03
战略布局
Configuration Layout
如何围绕企业目标，布局企业的三个地平线或者说现金流业务增长型业务和种子型业务；如何在无法坚持时体面地撤退，如何打破常规，利用规模经济、范围经济、网络经济、生态经济突破增长天际

04
价值创造体系
Creation System
理解战略不是局部的优化，而是需要构建一个完整的体系，甚至是一个全新的生态系统

05
变革管理
Change Mastery
战略执行的最大挑战是战略绝不可能按照你的意愿行事，我们要应对各种意外、各类反馈，然后尝试预测变革，最终引领变革

底层通用能力
系统思维、决策力、数据分析能力等，作为支撑基础，确保框架落地。
