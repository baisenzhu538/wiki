业务设计大定势：六要素*三步骤

讨论目标： ·基于市场洞察和需要解决的关键差距,讨论并就业务设计初步达成共识
           ·可能需要针对不同子业务或细分客户群分别设计(可先分别做业务设计,然后再看是否可以合并)

关键问题： ·步骤1、现有业务设计的六要素是什么？
           ·步骤2、基于市场洞察和战略意图，为了缩小或者关闭差距，当前业务设计的哪几项要素需要改变？
           ·步骤3、新的业务设计可能的主要执行挑战有哪些（可能的组织、能力、资源障碍是什么）？

| 六要素 | 内涵 | 步骤1、诊断现有业务设计 | 步骤2、设计期望业务设计 | 步骤3、识别执行挑战 |
| 客户选择 | 我们到底为谁创造价值？谁是核心客户？ | | | |
| 价值主张 | 我们提供什么独特价值，让客户选择我们而不是对手？（差异化竞争优势） | | | |
| 价值获取 | 我们怎么盈利？（盈利模式、收入来源） | | | |
| 活动范围 | 我们在价值链上做哪些事、不做哪些事？（经营边界和角色） | | | |
| 战略控制 | 我们如何建立并守住持续竞争优势？（控制点，如品牌、技术、渠道、成本等） | | | |
| 风险管理 | 有哪些潜在风险？如何防控？ | | | |
