## 0. 摘要（先看这个）

**课题**：把微信视频号内容自动变成逐字稿，再进知识库（楚门：存 Cubox 文件夹）。

**一句话答案**：这条路 2026 年 8 月已经完全走通，**不用等任何 token、不用交一分钱给商业服务**——开源工具链 + 本地 Whisper/FunASR 引擎 + Agent Skill 生态三件套，一套流水线从收藏到逐字稿到知识库全自动。

**三个关键规律**：
1. **下载环节收敛于两条路线**：MITM 代理+证书（4 个工具同源）vs API 解析+Referer（扫码登录态路线，免证书）
2. **转写引擎三选一**：faster-whisper（重精度）/ FunASR SenseVoice-Small（轻量 234M）/ 商业 API（省事）
3. **完整链路有现成样板**：`dlv2008/weixin-favor-kb` 与楚门场景 100% 重合（下载→Whisper→LLM 分类→知识库），唯一差异是目标库（Obsidian vs Cubox）

**给你的行动建议**：管线接入优先「API 解析路线（元宝扫码登录态）」做主力通道、「scribe-transcribe（网页版 MITM）」做备用——C 零证书零 GUI，A 纯本地不依赖第三方。

## 8. 讲香节（为什么这么分组）

**价值**：
1. **一张矩阵看懂全局**：四环节×路线矩阵把"黑科技"拆成了可选的工程组合——楚门不需要知道 MITM 原理，只需要在两条下载路线里选一条
2. **完整链路有现成样板**：weixin-favor-kb 证明"收藏吃灰→知识入库"不是概念是代码（261 篇笔记、955 标签、13 分类的真实案例）
3. **Agent Skill 生态是新红利**：2026 年这批工具已经从"命令行工具"进化到"给 AI Agent 用的 Skill"——这意味着楚门/欧阳锋可以把整个链路交给 Agent 编排，而不是自己写脚本
4. **反爬情报避免踩坑**：公共 Worker 失效、Referer 必带、证书坑——这些是 README 里散落、本文集中的"过路费"知识

**边界**：
- 不做线下/现场调研；工具可用性以 2026-08 为准（≤6 个月时效）
- BibiGPT 视频号支持、秒转工具箱小程序能力、sph_caiji_wenan（404）未实证，标记"待验证"
- 商业服务侧（通义听悟/飞书妙记/腾讯云 ASR/剪映）未深挖——不在楚门"零成本"诉求的主线上

**为什么这么分组**：
- **第一维技术能力分层**：按"人需要付出多少技术劳动"切——零/轻/重/Agent/完整链路，从"点两下"到"全自动"，用户按自己的技术水位选层
- **第二维管线四环节**：按"数据流动"切——下载→转写→知识化→编排，每个环节独立可选型，组合成完整管线
- 两维交叉 = 决策矩阵：先定层（我要多自动），再定环节选型（每环节选哪条路线）
