## 一、培训核心理念讲解

### 1.1 核心管理理念

* 讲师表述：**领导力的本质是引导别人心甘情愿解决难题的能力**，重点在于“心甘情愿”的过程和“解决难题”的结果。
* 讲师表述：**教练式领导力是基于价值和意义引导别人心甘情愿解决难题的能力**，以激发对方内在动力为核心，认为每个人都有实现自我价值的渴望。
* 讲师表述：教练式领导力是一种高阶领导力形态，**以信任为基础**，需打破传统层级隔阂，建立平等开放的沟通关系。
* 讲师表述：教练式沟通是教练式领导力发挥作用的核心场景，适用于日常绩效提升、一对一辅导、目标设定、卡点突破、方案设计、决策共识等场景。

### 1.2 理念适用边界

* 讲师表述：教练式沟通**不是万能的**，以下三种情况不适用：时间紧急时需直接解决问题；缺乏信任基础时难以有效开展；当直接给答案的ROI更高时，无需使用教练式沟通。

## 二、管理方法模型拆解

### 2.1 教练式沟通三要素

| 要素       | 核心动作              | 关键要点                                                  |
| -------- | ----------------- | ----------------------------------------------------- |
| **深度倾听** | 营造安全氛围、保持专注、全方位关注 | 克制表达欲，通过肢体语言（如微笑、点头、记笔记）传递尊重，接纳沉默作为沟通工具               |
| **有效提问** | 解放思想、保持好奇心、激发潜力   | 聚焦当前难题，避免主观引导，通过追问理解对方思路和卡点，可使用“你觉得…？”“如果…会怎样？”等开放式问题 |
| **有效反馈** | 基于事实、不做评判、双向互动    | 区分事实与观点，正面反馈需具体到行为细节，改进反馈需描述影响并共同探讨解决方案               |

### 2.2 教练式领导力成长四阶梯

| 阶段       | 核心目标            | 关键动作                                                    |
| -------- | --------------- | ------------------------------------------------------- |
| **建立信任** | 搭建沟通桥梁，让下属感到安全  | 倾听（保持专注、识别情绪意图、静默留白）、提问（关怀性提问、支持性提问）、反馈（及时回应、复述确认、积极肯定） |
| **达成共识** | 统一目标与路径，激发主动性   | 倾听（识别分歧点）、提问（引发思考、挖掘渴望、业务公式拆解、切换视角）、反馈（二次确认）            |
| **带来成长** | 突破能力瓶颈，提升认知水平   | 倾听（识别成长卡点）、提问（强化认知边界）、反馈（BASIC原则：行为、及时、具体、影响、一致；刻意练习反馈） |
| **激发希望** | 点燃对未来的渴望，实现使命认同 | 自我暴露、笃定长期目标、关注个体动机，通过初心卡连接团队使命与个人价值                     |

### 2.3 GREAT教练模型

| 阶段                  | 核心动作      | 对应工具          |
| ------------------- | --------- | ------------- |
| **G（Goal）目标**       | 明确挑战目标    | 倾听、提问（引发思考）   |
| **R（Reality）现状**    | 了解当前情况与卡点 | 深度倾听（识别情绪、意图） |
| **E（Engagement）参与** | 激发主动承担意愿  | 提问（挖掘渴望、切换视角） |
| **A（Action）行动**     | 制定具体行动计划  | 反馈（二次确认）      |
| **T（Think over）反思** | 复盘提炼经验    | 反馈（刻意练习反馈）    |

## 三、案例讨论实录

### 3.1 案例一：管理者与下属的一对一沟通（小红书运营场景）

#### 案例背景

* 新部门主管与负责小红书运营的下属沟通，下属粉丝数连续三个月超KPI30%，但转化率未达标，且刚查出怀孕三个月。

#### 不同沟通版本对比

* **版本一（指令式）**：主管直接质疑目标合理性，打断下属解释，拍桌子要求提升转化率50%，未关注下属怀孕情况，导致下属委屈。
* **版本二（部分改进）**：主管肯定成绩，指出转化率问题，直接给出调整方向和资源支持，但未引导下属自主思考，仍主动背责任（“我来定方向，你执行”）。
* **版本三（教练式）**：主管微笑引导，倾听下属困惑，通过提问（“你觉得影响转化率的核心原因是什么？”“有什么突破想法？”）引导下属分析用户匹配问题，共同探讨解决方案，关注下属怀孕情况并协调资源支持，激发下属信心。

### 3.2 案例二：软件项目经理压力沟通

#### 案例背景

* 项目经理因客户要求提前一周交付项目，压力大、状态差，总监与其沟通。

#### 不同沟通版本对比

* **版本一（说教式）**：总监肯定努力，强调项目重要性，鼓励加班坚持，承诺协调资源但未具体解决问题，项目经理仍感疲惫。
* **版本二（教练式）**：总监观察到项目经理状态，主动关心，倾听其困难，通过提问（“关键路径有什么我能帮忙的？”）引导梳理项目排期，肯定其能力，明确表示“我来兜底”，提供具体资源支持（协调开发人员），缓解其顾虑。

### 3.3 案例三：销售团队业绩波动沟通

#### 案例背景

* 行业不景气，销售团队业绩下滑，VP与销售经理沟通下半年业绩目标。

#### 教练式沟通示例

* VP先关心销售经理状态，倾听其面临的困难（客户预算收紧、新客户开拓难），通过提问（“除了大环境，还有什么核心原因？”“如果聚焦客户分类，有什么具体方法？”）引导其分析团队士气和精力分散问题，共同探讨客户分类策略（按需求类型分）和产品组合调整建议，最终销售经理自主提出业绩提升信心。

## 五、参训反思要点

### 5.1 参训者反馈（讲师提及）

* 参训者反馈：日常管理中存在“好心办坏事”的情况，有帮助下属的意愿，但缺乏教练式沟通技巧。
* 参训者反馈：在团队出现分歧时，习惯直接给答案或强制决策，未充分引导下属参与共识。
* 参训者反馈：对“信任建立”和“激发希望”阶段的具体操作感到困惑，希望获得更多可直接应用的工具。

### 5.2 讲师总结反思

* 讲师反思：教练式领导力不是单一技巧，而是**基于“相信每个人都能找到答案”的信念**，需要长期刻意练习。
* 讲师反思：领导者需**放下“给答案的焦虑”**，从“决策者”转变为“引导者”，通过倾听、提问和反馈帮助下属成长。
* 讲师反思：信任建立是基础，需通过持续互动积累“信任硬币”，避免因不当言行消耗信任账户。
