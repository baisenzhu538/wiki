## 二、核心知识框架

### 2.1 领导力定义

> **领导力 = 带领他人心甘情愿解决难题的能力**

| 要素 | 含义 |
|:---|:---|
| 心甘情愿 | 内在动机，非强迫 |
| 解决难题 | 高价值挑战，非简单执行 |

### 2.2 驱动三角

```
权力驱动（职位/薪酬）→ 保底执行
管理驱动（流程/SOP）→ 提升效率 → "管理保下限"
领导力驱动（内在动机）→ 迎难而上 → "领导力追上限"
```

> 越是高难度、高目标、少资源、长周期，越依赖领导力。

### 2.3 领导力五阶梯

| 层级 | 名称 | 核心 | 关键动作 |
|:---:|:---|:---|:---|
| L1 | 认同层 | 建立信任 | 以身作则、营造安全氛围、鼓励团队 |
| L2 | 结果层 | 打胜仗 | 主动扛事、发挥稀缺优势、实事求是 |
| L3 | 共识层 | 讲道理 | RY分析、提问技巧、初始咨询 |
| L4 | 成长层 | 促成长 | 科学练习、基本功训练、一对一反馈 |
| L5 | 希望层 | 绘愿景 | 描绘愿景、传递社会价值、连接人生红点 |

### 2.4 硬币模型

| 加硬币（存信任） | 减硬币（耗信任） |
|:---|:---|
| 关键决策讲道理 | 过度依赖KPI |
| 传递振奋愿景 | 言行不一 |
| 以身作则 | 甩锅下属 |
| 取得胜利 | 拒绝承认错误 |
| 失败后公开反思 | 滥用职权压制异见 |
| | **情绪失控（高危：一次可抵消数月积累）** |

### 2.5 莫非老师：教练沟通卡牌矩阵

- 三类棘手下属：小白兔（低能力高意愿）/ 老黄牛（执行强无创新）/ 老油条（高能力低意愿）
- 两大死局：成为团队瓶颈 + 成为救火队长
- 20+教练沟通技巧卡片，按场景分组

### 2.6 实践案例（一堂自身）

- 吸引20+会员降职加入，核心负责人留存率高
- CEO亲自示范、建立讲道理文化、允许试错
- 团队特点："因事儿不难而沮丧，很少因事儿太难而后退"
