## 二、课程核心框架（从OCR+口述中提取）

### 2.1 领导力本质定义

> **领导力 = 带领他人心甘情愿解决难题的能力**

| 要素 | 含义 |
|:---|:---|
| 心甘情愿 | 内在动机（自主/胜任/关联） |
| 解决难题 | 高价值挑战 |

**管理保下限，领导力追上限**。目标越高、资源越少、周期越长、人数越多 → 越依赖领导力。

### 2.2 驱动三角

```
权力驱动 → 职级身份/稀缺资源/决定奖惩/强制执行（保底）
管理驱动 → 确定执行/机制架构/工具流程/执行框架（效率）
领导力驱动 → 心甘情愿/高水平影响力/挑战现状（上限）
```

### 2.3 领导力五阶梯（核心图：一堂DOC-20260808224437 12段全景）

| 层级 | 核心 | 追随者 | 关键Feature |
|:---:|:---|:---|:---|
| L1 认同 | 良好氛围与信任 | 愿意和你一起做事的人 | 以身作则、安全氛围、关心鼓励 |
| L2 结果 | 打胜仗 | 渴望做事的人 | 主动扛事、稀缺优势、实事求是 |
| L3 共识 | 讲道理/凝聚共识 | 渴望思考的人 | ROI讲道理、善于提问、出口式咨询 |
| L4 成长 | 带成长/无限进步 | 高潜力的人 | 刻意练习、基本功、1v1成长反馈 |
| L5 希望 | 美好愿景 | 优秀的人 | 组织文化、社会价值、人生红点 |

### 2.4 硬币模型（攒信任）

**加硬币（+1）**：
- 关键决策讲道理
- 以身作则带团队练基本功
- 一次次带领团队取得胜利
- 巨大压力下情绪稳定
- 提出好问题引发团队思考
- 失败中公开反思
- 用使命愿景唤醒个体人生红点
- 培养下属成为更优秀领导者
- 赞扬团队贡献

**减硬币（-1）**：
- 做不符合价值观的事
- 过度依赖短期KPI
- 甩锅下属
- 面对困境退缩不敢扛事
- 拒绝承认错误
- 滥用职权压制异议
- 自己没有成长而push团队
- 突发状况大发脾气（高危！）
- 对愿景产生动摇

### 2.5 教练沟通策略武器库（莫非老师·匠心卡）

**倾听卡6步**：
1. 保持专注（注意力爆值曲线）
2. 3F倾听（Fact事实/Feeling情感/Focus意图）
3. 大智若愚（不fast-jump打断）
4. 善用静默（空间回应）
5. 识别分歧（理解意见背后的分歧点）
6. 识别卡点（对方不知道自己不知道）

**提问卡8类**：
1. 关心式提问（建立信任）
2. 支持式提问（给具体支持）
3. 引发思考（激发主动思考）
4. 明确出口（让对方说出渴望）
5. ABCD提问（封闭+开放结合）
6. 切换视角（3种方法：询问挑战者/检验他人视角/检查反思）
7. 重新定义（3种方法：从本质/关联信息/关联业务）
8. 乔哈里窗（找信息盲区）

**反馈卡6原则**：
1. 及时回应
2. 复述回应（脚手架复述/显性复述/隐性复述）
3. 积极回应（具体事实/好奇提问/具象）
4. 二次确认
5. BASIC原则（Behavior/Agile/Specific/Influence）
6. 刻意练习反馈（冰山理论：显性/隐性）

**专家自我修养Top10**：能背下来/明确出口/尊重公理/切换视角/有敬畏心/克制答案/主动提问/引导思考/避免对抗/友好探讨

### 2.6 三类棘手下属（莫非老师）

| 类型 | 特征 | 困境 |
|:---|:---|:---|
| 小白兔 | 高意愿低能力 | 什么都来问，不敢决定 |
| 老黄牛 | 执行稳无创新 | 只能复制不能发展 |
| 老油条 | 高能力低意愿 | 永远有理由规避 |

两大死局：成为团队瓶颈 + 成为救火队长

### 2.7 共识目标三次跨越（从说服到自主设定）

- **60分**：领导者主导，ROI拆解说服 → 下属被动服从（"猴子在谁身上？"）
- **80分**：开放沟通，邀请参与 → 下属有归属感
- **更高**：目标自主设定 + 团队战略平衡
- ⚠️ 共识不是一切，高质量的目标才是

### 2.8 沟通失败案例（教学素材）

- 经理×小红书运营：KPI高压 → 转化率追问 → 怀孕员工被呵斥（反面教材）
- 反馈三明治结构：正面反馈（情境+行为+影响+优势）/ 改进反馈（我们式）/ 负面反馈（责任共担）
