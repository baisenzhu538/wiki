# 供应商管理办法 · 轻量版 v1.1

> 版本：v1.1（2026-08-07）| 适用：4 人团队 × 小型供应商
> 使用说明：**只要能识字，拿过去就能直接操作。** 每个阶段照着做，做完勾掉。
> 编制依据：千惠合作复盘逐字稿 + v1.0 完整版 + 行业实践。每条条款都能在文末案例库里找到出处。

---

# 总纲

## 两个原则（任何阶段不可违背）

1. **研发与生产分开**——带研发性质的项目：研发归我们、生产归工厂。合同分开签（委托开发 + 采购两本），图纸/技术/IP 永远在我们手里。
2. **信任不能替代尽调，关系不能替代制度**——再熟的人、再急的时间，下面四个阶段的条款不能省。

## 一页纸速查

```
合同前：查征信 → 对话工程师 → 3案例+1现场 → 打样验证 → 对比2-3家 → 内部共识会
合同中：研发生产分开签 → 技术附件 → 付款挂钩 → 禁转包 → 违约金 → 质保金 → IP归我们
合同后：每日日志(供应商填+照片) → 周例会(风险五问) → 里程碑验收 → 月度现场 → 变更书面 → B计划
移交：逐项验收 → 交付物清单 → 供应商清单 → 质保期 → 评价表 → 档案归档
```

## 时间预算（4 人团队一周投入）

| 动作 | 谁 | 每周耗时 |
|:--|:--|:--|
| 每日工作日志（收集+归档） | 对接人 | 每天 10 分钟 |
| 周例会（进度+风险五问） | 全员或对接人+负责人 | 30 分钟 |
| 月度现场查看 | 负责人 | 每月半天 |
| 其他（按项目阶段） | 全员 | 按需 |

# 阶段一：合同前（7 条）

> 目的：选对人。选对了，后面 80% 的管理成本都不用花。**千惠的全部学费里，这一阶段占 70% 责任。**

- [ ] **1.1 查征信**（30 分钟）：企查查/天眼查查司法案件、被执行、社保人数。**红线：涉诉>5 条 / 失信被执行人 / 社保人数与声称规模矛盾 → 停下开会讨论**
- [ ] **1.2 直接对话对方工程师**（1 小时）：找对方的结构/电子工程师本人聊技术，老板在场可以，但技术问题必须工程师回答。**红线：老板代答 / 答非所问 / 回避细节 → "大包大揽"型，高危**
- [ ] **1.3 三个案例 + 一次现场**（半天）：让对方列 3 个做过的产品，挑 1 个去现场看（或看实物）。现场看：设备在不在转、工人是不是他的、车间是不是"展厅"。**红线：拿不出案例 / 现场看不到东西 → 表演型供应商**
- [ ] **1.4 关键方案打样验证**：对方声称能做的关键技术点，先打样/测试再谈后续。**红线：只有方案没有实物 → 方案只是 PPT**
- [ ] **1.5 对比至少 2-3 家**：不对比不签约。"没资源""时间急"不是理由。对比的维度：技术/交付/成本/质量/征信
- [ ] **1.6 内部共识会**（1 小时）：4 人过一遍：我们要什么样的供应商？（能力清单）我们的底线是什么？（红线清单）谁负责哪块？（分工）
- [ ] **1.7 填供应商画像档案**（沉淀）：一页纸记录：查了什么、看到什么、红线有没有触发、结论（选/不选/有条件）。**这页纸就是决策依据，也是下次的参照**

---

# 阶段二：合同中（7 条）

> 目的：把话说死。合同是最后的法律武器，签约时一次写清，后面零成本生效。

- [ ] **2.1 研发与生产分开签**：新产品 = 《委托开发协议》+《采购合同》两本；绝不用"订单合同"替代正式协议
- [ ] **2.2 技术需求明细（附件）**：每个功能、参数、性能指标写进附件，作为验收唯一依据。变更必须双方书面确认
- [ ] **2.3 付款与里程碑挂钩**：预付款 ≤30%，后续每笔付款跟验收走（样机验收→进度款，终验→验收款）
- [ ] **2.4 禁止转包条款**：主体工序严禁转包；外协提前书面报备；甲方有权直接接触分包方；发现未报备转包扣减 20% 订单额
- [ ] **2.5 违约金**：节点违约金（5‰/天）+ 总交货违约金（超期甲方有权取消订单）
- [ ] **2.6 质保金 + 售后**：质保金 ≥10%，质保期满（≥1 年）后支付；质保期内 48 小时响应
- [ ] **2.7 知识产权与保密**：图纸/技术/工艺文件 IP 归甲方；乙方不得为第三方做同类产品；终止后归还技术文件

# 阶段三：合同后 · 过程跟进（7 条）

> 目的：天天盯着。**管理成本最低、效果最好的跟进方式就是每日日志+周例会。**

- [ ] **3.1 每日工作日志（必做！）**：供应商每天在群里报三条：今日进度 / 明日计划 / 现场照片（照片必须拍，防口头应付）。对接人每天 10 分钟归档。**没有落到纸面上的跟进等于没有跟进**
- [ ] **3.2 每周例会**（30 分钟）：进度对表 + 风险五问（①老板回避技术问题？②交付延期？③发现未报备转包？④换关键人员？⑤拒绝我们去现场？）——任一"是"→口头预警+启动 B 计划
- [ ] **3.3 里程碑验收**：关键节点（样机、终验）正式验收——按技术附件逐项检验，通过才付下一笔款
- [ ] **3.4 月度现场查看**：每月至少去一次现场（不提前太久通知），看设备/看进度/看人
- [ ] **3.5 变更管理**：协议变更/换人/换供应商——任何重大变更必须书面确认，记录变更原因（千惠三次变更没一次经我们审批）
- [ ] **3.6 风险信号清单**（贴墙上）：六信号——回避技术/多次延期/发现转包/换关键人/到处找融资/拒绝看现场。出现即评估替代方案，不抱幻想
- [ ] **3.7 B 计划**：选型时预评估 1-2 家备选（哪怕只有名字+联系方式），写在供应商档案里。风险信号触发即启动

---

# 阶段四：移交与收尾（6 条）

> 目的：把账算清、把经验留下。

- [ ] **4.1 逐项验收**（半天）：按合同技术附件逐项检验（功能/性能/外观/可靠性），不通过出问题清单→整改→复验
- [ ] **4.2 交付物清单**：图纸、BOM、工艺文件、检验报告、操作/维护手册、备件清单——一样不能少
- [ ] **4.3 供应商清单移交**：对方把它的供应商清单给我们（售后追溯用）
- [ ] **4.4 质保期管理**：48 小时响应；质保期满前 30 天评估→释放质保金
- [ ] **4.5 合作评价表**（30 分钟）：交期/质量/配合度/转包情况打分 → A/B/C/D 分级（决定下次是否合作）
- [ ] **4.6 档案归档（沉淀）**：供应商档案 + 踩坑案例 → 入库。**每次合作都是一堂课，把课上完再走**

# 案例库：千惠踩坑实录（条款出处）

> 每条条款都能在这里找到血的教训。**写条款的人没踩过的坑，案例库帮你踩过了。**

## 合同前踩的坑

| # | 踩了什么 | 后果 | 对应条款 |
|:--|:--|:--|:--|
| C1 | 没查征信就签约 | 廖总 20+ 条司法案件，项目快崩了才知道；社保 30 人 vs 实际 4 人 | 1.1 |
| C2 | 只接触一家就签约（云印不做、印象有纠纷，就再没找过） | 没有对比就没有议价空间和风险底线 | 1.5 |
| C3 | 码盘方案只听没验证 | "水平仪被包装成高科技"（骆工原话），方案从未打样测试 | 1.4 |
| C4 | 第一次去现场只看场地规模 | 场地大、各种整机在造——结果都不是他的（接单道场） | 1.3 |
| C5 | 王健第一次见面就感觉"夸大、回避"，但被"不要这么快下定义"压掉 | 早期信号丢失 4 个月；信息流通失败 | 1.6 共识会 + 3.1 日志（让信号有记录通道） |

## 合同中踩的坑

| # | 踩了什么 | 后果 | 对应条款 |
|:--|:--|:--|:--|
| C6 | 用订单合同替代正式协议 | "拿着订单合同你告诉他都没得告"（老朱原话） | 2.1 |
| C7 | 没有技术需求明细 | 验收无标准、变更无控制 | 2.2 |
| C8 | 4/17 打款，无里程碑挂钩 | 钱付完就失去谈判筹码 | 2.3 |
| C9 | 没写禁止转包 | 层层转包（电子给尚合/钣金给石楼镇）无法律武器 | 2.4 |

## 合同后踩的坑

| # | 踩了什么 | 后果 | 对应条款 |
|:--|:--|:--|:--|
| C10 | 没有工作日志 | 复盘时时间线混乱，"读起来有点费劲"（老朱原话） | 3.1 |
| C11 | 通讯协议三次变更+7/20 整体推翻，无变更管理 | 我们开发工作反复推翻重来 | 3.5 |
| C12 | 六个风险信号全亮（回避技术/延期/转包/换人/找融资/拒绝看现场）没预警 | "抱有幻想"到 7/28 才讨论退路 | 3.6 |
| C13 | 拒绝我们去钣金厂"十几次以上" | 被隔断的信息管道（尚合"我以为你们不做了"） | 3.4 + 2.4 |
| C14 | 样机阶段当量产管（6/1 上线思维） | 升降平台到 7 月没定（EVT 没走完），我们却在谈 10 台订单 | 1.4 + 3.3 |

|:--|:--|:--|:--|

# 沉淀工具（做完什么，留下什么）

> 原则：**每做一件事，必须留下一样东西。** 不沉淀=白干。

| 工具 | 什么时候用 | 留下什么 | 放哪里 |
|:--|:--|:--|:--|
| **每日工作日志** | 每天 | 供应商进度+照片+问题（微信记录归档） | 项目文件夹/月归档 |
| **供应商画像档案** | 合同前 | 一页纸：查了什么/红线触发/结论 | 供应商档案库 |
| **阶段验收单** | 里程碑 | 验收结果+问题清单 | 项目文件夹 |
| **合作评价表** | 项目结束 | A/B/C/D 分级+理由 | 供应商档案库 |
| **踩坑案例** | 每次踩坑后 | 踩了什么/后果/对应条款（补进案例库） | 本文件案例库 |
| **供应商档案总库** | 持续 | 每家供应商：画像+合作史+评价 | 单独文件夹 |
