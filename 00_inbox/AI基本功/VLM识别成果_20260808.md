## 提取的核心知识框架

### 一、Feature思维定义

> **Feature = 提升AI解题水平的最小实践单位**

| 四要素 | 含义 |
|:---|:---|
| AI范围 | 必须是AI项目 |
| 解题水平 | 能提升解决问题的水平 |
| 实践单位 | 可执行的动作 |
| 最小颗粒度 | 越细越好 |

**对立面**：工具思维(T型) → Feature思维(F型)，"借工具之假，修能力之真"

---

### 二、AI学习五大流派

```
原理派 ← 工程派 ← Feature派 → 工具派 → 教程派/模板派
(最稳定/难)                          (最实用/易)
              ↑ Feature派：平衡稳定+实用
```

---

### 三、Feature分层体系（L0-L5 + 宏观）

```
宏观 组织层    → 分工逻辑 / 服务隔离 / 本地+云端 / 人机边界
L5   组织架构层 → 角色分工 / 共享资源 / 权限分层 / 协作 / 自主控制
L4   Opencl层   → 角色设定 / 记忆 / 知识 / 边界
L3   Agent层    → Role / ReAct / 状态记忆 / 多轮交互 / 网关 / 心跳
L3   技能层     → Skill封装（命名规则，无法发起任务）
L2   提示词层   → 7个子类别（2A-2G）
L1   提示词层   → 5-10个Feature → YAI+Partner封装
L0   LLM层      → 模型选择/组合/调优
```

#### L2 提示词层详细（7个子类）

| 编号 | 类别 | 内容 |
|:---|:---|:---|
| 2A | 高阶角色 | 反向提示、反向教我、反向采访、反向记录、自我批评 |

| 2E | 强化能力 | 语言风格、优化词语、指定能力 |
| 2F | 节奏控制 | 新开窗分支测试、Prompt版本管理 |
| 2G | 审核/自动化 | 人工审核、AI自动搭、插件调 |
