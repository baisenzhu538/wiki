## 一、产品概览

### 1.1 一句话定位

**「Zero Friction from Desire to Action——从愿望到行动之间，零摩擦。」**

Jovida 不是又一个任务清单或效率工具，而是一个**主动式 AI 生活教练**，核心使命是帮助用户把"想做但一直没做的事"变成真正的行动。它覆盖健康减脂、技能学习、旅行规划、社交提升、祷告提醒等个人生活场景，每天为用户生成 3 个微行动任务，并通过智能推送在合适时机"轻推"用户完成。

## 二、创始人背景与团队基因

### 2.1 张心皓的核心经历

张心皓是典型的"大厂产品老兵 + AI 创业者"路线：

- **字节跳动（2014-2023，约 10 年）**
  - 以应届生身份加入今日头条，经历了从几百万 DAU 到近一亿的全过程
  - 从 0 到 1 做了皮皮虾，峰值约 10 亿营收、团队上百人
  - 后转教育线做 ToB 产品，最后在字节人力负责组织改革与创新
  - 深度参与字节几乎所有产品与组织从 0.5→1→100 的过程

- **阶跃星辰（2023-2025，约 2 年）**
  - 首次创业做招聘 Agent，3 个月后公司被阶跃星辰并购
  - 在阶跃做 ToC 产品合伙人，先探索冒泡鸭（AI 陪伴/互动故事），后转跃问
  - 冒泡鸭日活时长近 2 小时，验证了陪伴价值

- **Jovida（2025.6-至今）**
  - 出来第三次创业，聚焦"工作之外 16 小时"的消费级 AI Agent

### 2.2 创始人核心认知提炼

从 Founder Park 深度访谈中，张心皓展现了几个非常有洞察力的判断：

1. **Agent Loop vs Human Loop 二分法**
   - Agent Loop（Claude Code 为代表）：纯自动化，赢家通吃，年底人类参与度趋近 0%
   - Human Loop（Jovida 的路线）：以人为本，Agent 帮助人完成自己想做的事
   - 创业公司应避开 Agent Loop 红海，走 Human Loop 蓝海

2. **上下文飞轮是唯一壁垒**
   - 大模型没壁垒，Agent 编排没壁垒
   - 唯一壁垒：创造场景 → 用户有动机分享上下文 → Agent 越懂用户 → 体验越好 → 更多上下文

3. **不要定义人，要定义场景**
   - 传统 PMF 思路（先画用户画像）在 Agent 时代可能过时
   - 应该围绕"用户有没有想做但没做的事"来定义场景

4. **AI 创业最大风险：过早以为自己找到了 PMF**
   - Agent 能力在指数级提升，过早锁定 PMF = 局部最优
   - 策略：每个阶段达到"还不错"的匹配，同时为下一代能力做准备

## 三、产品功能深度拆解

### 3.1 核心功能架构

```
Jovida 功能架构
├── 🎯 目标输入（多种方式）
│   ├── 文字描述目标
│   ├── 分享链接/视频/截图
│   └── Agent Market 一键复用
│
├── 📋 智能行动规划
│   ├── 自动拆解为每日 3 个微行动
│   ├── 根据可用时间调整任务量
│   └── 随进度动态调整计划
│
├── 🔔 智能推送（Smart Nudges）
│   ├── 交互式任务卡片
│   ├── 基于日历的时机推送
│   ├── 基于位置的情境感知
│   └── WhatsApp 消息触达
│
├── 🧠 长期记忆系统
│   ├── 进度追踪与学习
│   ├── 挣扎模式识别
│   ├── 偏好动态调整
│   └── 多目标关联涌现
│
├── 🏪 Agent Market（目标市场）
│   ├── 官方预设 Agent
│   ├── 用户创建并分享的 Agent
│   ├── 真实目标与结果展示
│   └── 一键复用他人成功路径
│
└── 📱 多端感知（端云一体架构）
    ├── 手机端（iOS 主力）
    ├── 日历/健康/运动数据打通
    ├── 未来：电脑端/手表/邮件/电话
    └── 云端大脑统一决策
```

### 3.2 关键功能详解

#### Smart Nudges（智能轻推）

区别于传统定时提醒，Jovida 的推送基于**福格行为模型（B=MAP）**：
- **Motivation（动机）**：个性化 IP 角色、连胜激励、情绪支持
- **Ability（能力）**：拆成极小行动，降低门槛（如直接通过外卖 API 点健康餐）
- **Prompt（触点）**：基于日历空隙 + 地理位置 + 用户状态的智能时机推送

例：检测到用户晚上 8 点在涮羊肉店，推送"今天涮肉可以把麻酱换成海鲜汁，多吃蛋白质和蔬菜"。

#### Agent Market（目标市场）

类似"目标商店"：用户可以浏览其他人创建的 Agent 和完成的目标，一键复用。这既降低了冷启动门槛，又形成了社区驱动的目标生态。

#### 多目标涌现效应

这是 Jovida 最具差异化的价值点。当用户有多个目标时（如看演唱会 + 学英语），Agent 会自动创造跨目标关联：
- 把明星歌词转成英语测试题
- 旅游目标关联服装品牌英语词汇
- 五一东南亚游 → 提前两周准备旅游英语

**单个目标做到好是工具，多个目标之间产生涌现才是 Agent。**

### 3.3 技术架构特色

| 维度 | Jovida 方案 |
|------|------------|
| 架构模式 | **端云一体**（非纯云/纯端） |
| 参考范式 | 类似鸿蒙分布式操作系统 |
| 端节点 | 手机/电脑/手表各自感知数据和 Context |
| 云端大脑 | 统一执行和决策 |
| 记忆管理 | 短期+长期+持久化目标记录，围绕动机/能力/触点搭建 |
| 模型策略 | 模型与编排解耦，多模型适配，Benchmark 驱动 |
| 不用沙盒 | 给每个用户建独立长期状态（终身陪伴） |

区别于 Claude Code（纯本地，关机即停）和 Manus（纯云端虚拟机），Jovida 追求 7×24 小时跨端感知。

## 四、商业模式与定价

### 4.1 定价体系（Credits 积分制）

| 方案 | 月付 | 年付 | 月积分 |
|------|------|------|--------|
| Standard | $19.99/月 | $191.90/年（省 20%） | 8,000 |
| Pro | $49.99/月 | $479.90/年（省 20%） | 22,000 |
| Max | $99.90/月 | $959.90/年（省 20%） | 46,000 |

- 免费版可下载试用，高级功能需订阅
- 积分制 = 用多少付多少，重度用户自然付更多
- 创始人定位：不是"订阅软件"，而是"给生活秘书付工资"

### 4.2 商业化哲学

- **ARR 是结果，不是目标**
- 先让用户离不开 → 稳定日常节奏 → 商业化自然发生
- AI Agent 成本结构特殊（API 调用成本高），节奏需更激进
- 核心指标：用户愿不愿意持续贡献 Context + 愿不愿意每天打开

## 五、竞争格局分析

### 5.1 直接竞品

| 竞品 | 定位 | 差异 |
|------|------|------|
| 多邻国 Duolingo | 语言学习 | 单品类、工程化、IP 固定、触点死板 |
| 各种习惯打卡 APP | 单点习惯追踪 | 无 AI 智能规划、无跨目标涌现 |
| 通用 AI 助手（ChatGPT 等） | 全能对话 | 被动响应、无主动推送、无长期行为管理 |
| AI 健康教练（如 Fitbod） | 运动健身 | 品类单一、缺乏生活场景覆盖 |

### 5.2 Jovida 的差异化壁垒

1. **主动式（Proactive）vs 被动式**：不是等你打开 App，而是它主动找你
2. **多目标涌现**：跨目标关联产生惊喜，单点工具做不到
3. **上下文飞轮**：越用越懂你，体验持续提升，迁移成本高
4. **端云一体 7×24**：比纯云/纯端更贴近"生活秘书"定位

### 5.3 潜在威胁

- **平台级玩家**（微信/苹果）：天然有更多 Context，但激励函数不同（苹果不会帮你减少订阅支出）
- **通用 Agent 进化**：如果 ChatGPT/Google 做类似功能，场景深度可能不如 Jovida
- **用户隐私顾虑**：需要日历、位置、健康数据、社交内容等高敏感权限

## 七、核心评价与启示

### 7.1 亮点

1. **创始人对方向的判断力极强**
   - Agent Loop vs Human Loop 的二分法是非常清晰的战略框架
   - "不定义人，定义场景"的思路在 Agent 时代很有启发性
   - 上下文飞轮作为壁垒的理论，逻辑自洽

2. **产品哲学底层扎实**
   - 福格行为模型不是噱头，是真的贯穿产品每一个环节
   - "改变人是反人性的，我们做的是让用户本来就想做的事更容易发生"——这是对的方向

3. **多目标涌现是真正的差异化**
   - 单点做好语言学习或减肥并不难，难的是多个生活目标之间产生化学反应
   - 这个能力一旦建立，迁移成本极高

4. **团队基因匹配**
   - 字节 10 年 + 阶跃 2 年 = 内容/社区/AI 产品的综合能力
   - 经历了冒泡鸭到 Jovida 的产品认知进化

### 7.2 风险与挑战

1. **用户教育成本高**
   - "AI 生活教练"是个新品类，用户心智需要从零建立
   - 需要让用户愿意分享高敏感度的个人数据（日历、位置、健康、社交内容）

2. **定价偏高**
   - Standard $19.99/月起步，对标多邻国 Super $6.99/月
   - 消费级产品 + 高定价 = 需要极强价值证明

3. **平台限制**
   - 仅 iOS 生态，Android 用户完全无法触达
   - 中国市场 iPhone 占比约 25%，意味着放弃了 75% 的潜在用户

4. **过早定位泛化 vs 过窄 PMF 的平衡**
   - 创始人说"不急于定义 PMF"，但 Pre-Seed 阶段需要找到至少一个高留存场景
   - 减肥？学英语？旅行？哪个是"钉子"还需要验证

5. **平台竞争风险**
   - 微信如果做一个类似的"生活助手"小程序，用户触达和数据获取都有天然优势
   - 虽然激励函数不同，但用户习惯迁移成本低

### 7.3 对一堂的启示

| 维度 | Jovida 带来的启发 |
|------|-------------------|
| **产品定位** | "消除愿望到行动的摩擦"这个命题，在教育场景同样成立——学员从"想学"到"真正练"之间有大量摩擦 |
| **行为设计** | 福格行为模型（动机+能力+触点）可以直接应用于课程学习行为设计 |
| **Agent 路线** | Human Loop 路线比 Agent Loop 更适合教育场景——帮学员完成想学但没学的事 |
| **上下文飞轮** | 如果 AI 教练了解学员的学习目标、日程、进度、偏好，就能产生类似的涌现效应 |
| **定价参考** | 积分制 + "付工资给 AI 教练"的模式，值得参考 |
