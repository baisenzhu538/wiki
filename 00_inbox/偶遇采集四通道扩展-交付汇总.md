## 二、本次修改清单

### 1. 新增头条图文文章解析（`wechat_link_monitor.py`）
- 链接识别正则扩展：`video|group|article|is` 四种形态
- 新增 `fetch_toutiao_article()`：短链跟随 302 → 提取 gid → `m.toutiao.com/i<gid>/info/` → `data.content`(HTML) → 清洗纯文本
- 主流程分支：`/video/` → 视频管线；其他 → 文章管线

### 2. 修复 bug A：转正正则匹配不了前缀（`wechat_promote.py`）
- 原正则 `src_wechat_([A-Za-z0-9]{8,20})` 匹配不了 `src_wechat_tt_...`、`src_wechat_article_...`
- 后果：头条视频/文章、公众号文章永远无法转正入仓（10_raw/sources 缺失）
- 修复：`src_wechat_(?:[A-Za-z]+_)*([A-Za-z0-9]{8,20})`，任意小写前缀均可

### 3. 修复 bug B：公众号链接 &amp; 未转义（`wechat_link_monitor.py`）
- XML 卡片提取的公众号链接带 `&amp;` → 抓取 404 → 被标记 seen 不再重试
- 后果：seen_links 里有 3 条公众号链接但一直无产物
- 修复：提取时统一 `&amp;` → `&`

### 4. 数据修复
- 头条视频逐字稿补转正：`10_raw/sources/src_2026-08-19_wechat_7666646931699367986.md`
- case 修复：title `"tt 7666646931699367986"` → `"AI写的代码要不要逐行看：自动化关卡代替人眼审查"`；domain `wechat-video` → `toutiao-video`

### 5. 顺手优化（`wechat_knowledge.py`）
- 标题提取：文章取 `# 标题`，视频取首句口播（不再用丑陋的 hash）
- domain 按来源区分：wechat-video / toutiao-video / wechat-article / toutiao-article
