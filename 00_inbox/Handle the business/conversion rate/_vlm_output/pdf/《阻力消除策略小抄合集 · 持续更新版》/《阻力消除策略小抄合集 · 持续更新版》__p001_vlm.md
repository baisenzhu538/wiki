**《阻力消除策略小抄合集·持续更新版》**——「一堂转化率黑客」课程的策略工具表，针对12种常见客户阻力提供"动嘴/动手/动钱"三层次的消除策略。

## 关键概念

- **12种阻力**：觉得贵 / 没能力 / 没时间 / 门槛高 / 距离远 / 不靠谱 / 有风险 / 折面子 / 不专业 / 体验差 / 怕冲动 / 还不急
- **三层次策略**：
  - **动嘴**：用话术转换、痛点提醒、价值塑造等方式进行语言层面的说服
  - **动手**：降低门槛、提供试用、简化流程、UGC铺垫等行为层面支持
  - **动钱**：免费升级、退款保障、补贴试用、成本削减等金钱层面兜底
- **策略深度**：每种策略细分 A（动嘴）、B（动手）、C（动钱）三个深度层，每层下设多个具体策略
- **品牌**：「一堂」转化率黑客课程出品
