# 阻力消除策略之8：折面子

| 策略深度 | 具体策略 | 解读 |
|---------|---------|------|
| **A. 动嘴** | A1. 重塑需求 | 换角度重塑需求，eg."换系统不是驳了老板面子，而是为了帮老板把事情做得更好" |
| | A2. 社会认可 | 展示产品收到广泛认可和支持，，eg."现在很多医生都推荐应该用xxx" |
| | A3. 强调普及 | 强调产品的普及性和接受度，eg."我们有xx客户在使用，您不是唯一尝试新事物的人" |
| | A4. 用户证言* | 高端/知名用户证言，eg."xx企业也是我们的客户，有成功案例" |
| **B. 动手** | B1. 转换角度 | 转换文案，eg. 不是拉新扫码，而是分享学习体会 |
| | B2. 隐私保障 | 确保用户在使用产品时的隐私得到保护，减少他们的担忧 |
| | B3. 匿名体验 | 提供匿名体验或试用选项，让用户在不暴露身份的情况下尝试产品 |
| | B4. 增加高价 | 直接设置高单价产品，提高高级感知度 |
| | B5. 帮助成功 | 帮助用户树立正面形象，降低折面子阻力 |
| **C. 动钱** | C1. 激励机制 | 只要推荐，无论成功与否都有小礼物/提高激励返利的返点 |
| | C2. 朋友免费 | 对朋友免费服务，或先服务再收款，eg. 我请客 |
| | C3. 品牌塑造 | 增加品牌投入，提升品牌知名度 |

注：标\*的为多重策略，会出现在多个消除策略中

## 核心主题
这张图片是「一堂转化率黑客」课程中讲解"折面子"这一阻力类型的消除策略框架。该策略从"动嘴、动手、动钱"三个维度展开，共计12个具体策略（如重塑需求、社会认可、隐私保障、激励机制等），帮助产品在用户因"丢面子"而抗拒时有效降低转化阻力。

## 关键概念
- **折面子**：用户因害怕丢面子而产生的转化阻力
- **动嘴**：通过语言话术降低阻力（如重塑需求、社会认可）
- **动手**：通过产品设计/操作流程降低阻力（如隐私保障、匿名体验）
- **动钱**：通过利益激励降低阻力（如激励机制、朋友免费）
- **重塑需求**：换角度重新定义用户需求
- **社会认可**：借助他人/权威的认可来降低抗拒
- **用户证言**：高端或知名用户的成功案例背书
- **匿名体验**：让用户在不暴露身份的情况下试用产品

## 一句话总结
"折面子"阻力可通过「动嘴（重塑需求/社会认可/用户证言）、动手（隐私保障/匿名体验/帮助成功）、动钱（激励机制/朋友免费/品牌塑造）」三大维度共12个策略系统化消除。
