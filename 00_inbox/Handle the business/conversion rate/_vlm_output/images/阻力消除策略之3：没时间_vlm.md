# 阻力消除策略之3：没时间

| 策略深度 | 具体策略 | 解读 |
|---------|---------|------|
| **A.动嘴** | A1.既有时间 | 强调并不是额外的时间<br>eg."这个本来就是小朋友锻炼身体应该付出的时间啊" |
| | A2.效率优势 | 突出节省时间的优势<br>eg."看起来一周花1小时，但省了很多自己摸索的时间" |
| | A3.长期视角 | 算时间的投入产出比<br>eg."短期看起来花了时间，但是长期看有很强的回报" |
| | A4.估算时间 | 给相对明确的时间/进度条，建目标感<br>eg."其实算下来每个月只需要花xx小时" |
| **B.动手** | B1.切换时段 | 切换到更好的、更适合用户安排的时段 |
| | B2.灵活安排 | 提供按需服务，让用户根据自己的时间灵活选择服务 |
| | B3.远程服务* | 提供线上远程服务，让客户花费的时间更短 |
| **C.动钱** | C1.上门服务 | 提供上门服务，节省用户时间 |
| | C2.延长时间 | 提供凌晨2h服务/24h服务/技师加班服务 |
| | C3.增加人手 | 增加老师/技师/服务人员，增加可选时间段 |

注：标*的为多重策略，会出现在多个消除策略中

## 核心主题

这张图片系统阐述了当用户因"没时间"而产生购买或行动阻力时，可以从**动嘴（沟通说服）、动手（灵活安排）、动钱（资源投入）**三个维度实施的阻力消除策略矩阵。

## 结构化内容

- **策略主题**：阻力消除策略之3：没时间
- **策略三维度**：
  - **A. 动嘴（沟通说服层面）**
    - A1. 既有时间 —— 强调并非额外时间
    - A2. 效率优势 —— 突出节省时间
    - A3. 长期视角 —— 算投入产出比
    - A4. 估算时间 —— 明确时间/进度条
  - **B. 动手（服务设计层面）**
    - B1. 切换时段
    - B2. 灵活安排（按需服务）
    - B3. 远程服务*（多重策略）
  - **C. 动钱（资源投入层面）**
    - C1. 上门服务
    - C2. 延长时间（凌晨2h / 24h / 加班）
    - C3. 增加人手（可选时间段增加）
- **备注**：标 * 的为多重策略，会出现在多个消除策略中

## 关键概念

- 阻力消除策略
- 没时间（用户阻力）
- 动嘴（沟通说服策略）
- 动手（灵活安排策略）
- 动钱（资源投入策略）
- 既有时间 / 效率优势 / 长期视角 / 估算时间
- 远程服务（多重策略）

## 一句话总结

针对"没时间"这一用户阻力，应从"动嘴说服（重塑时间认知）、动手设计（灵活时段与远程服务）、动钱投入（上门与延长时间）"三个层次组合出击，全方位降低用户的时间成本感知。
