# 阻力消除策略之12：还不急

| 策略深度 | 具体策略 | 解读 |
|---------|---------|------|
| **A.动嘴** | A1.美好想象* | 给客户关于未来的美好想象，eg."如果现在购买了，会带来xxx" |
| | A2.早用早好 | 强调早购买的好处，eg."早购买就是多享受xx天，费用摊薄更划算" |
| | A3.激发懊悔 | 现在不买会后悔，eg."当初XXX不用，他犹豫了，现在就产生了XXX的问题" |
| | A4.从众成交 | 同行/头部都在用，给对方带来竞争压迫感，eg."xxx竞品都在用，您也应该尽快" |
| | A5.损失厌恶 | 限数量/时间，马上涨价，eg."现在这个价格非常优惠，月底我们就会全面涨价" |
| **B.动手** | B1.自选激活 | 可以现在购买，然后自行选择激活/生效的时间 |
| | B2.给时间窗 | 给对方一个稀缺的时间窗口的机会，eg."我们阶段正在对重点客户做投资" |
| | B3.名额锁定 | 付款后可以锁定xx个限量优惠名额，有额外权益 |
| **C.动钱** | C1.先用再付* | 购买后不需要立即付款，降低决策成本 |
| | C2.早鸟优惠 | 现在支付比临近活动日期/到期日期支付有更多优惠 |
| | C3.增加激励 | 增加立刻购买的激励，eg."现在购买一年直接按14个月给你" |

*注：标*的为多重策略，会出现在多个消除策略中*

## 核心主题
本图片是「一堂转化率黑客」课程中"阻力消除策略"的第12个策略——「还不急」，针对客户"觉得不着急购买"的拖延心理，从"动嘴（语言层面）""动手（行动层面）""动钱（金钱层面）"三个深度，系统梳理了11种具体消除阻力的策略。

## 结构化内容

```
阻力消除策略之12：还不急
│
├── A. 动嘴（语言说服层面）
│   ├── A1. 美好想象* → 给客户描绘购买后的美好未来
│   ├── A2. 早用早好 → 强调早买享受更多/费用摊薄
│   ├── A3. 激发懊悔 → 用案例警示不买的遗憾
│   ├── A4. 从众成交 → 借助同行/头部用户制造压迫感

│
├── B. 动手（行动操作层面）
│   ├── B1. 自选激活 → 现在买，自行决定激活时间
│   ├── B2. 给时间窗 → 稀缺窗口期权益
│   └── B3. 名额锁定 → 付款锁名额享额外权益
│
└── C. 动钱（资金支付层面）
    ├── C1. 先用再付* → 延后付款降低决策成本
    ├── C2. 早鸟优惠 → 早付享更多优惠

```

**说明**：标 * 号的策略（A1 美好想象、C1 先用再付）为多重策略，可复用于其他阻力消除场景。

## 关键概念
- **阻力消除策略**：针对客户购买决策障碍的系统性干预方法
- **动嘴（A层）**：通过语言沟通影响客户认知与情绪
- **动手（B层）**：通过行动机制降低客户的执行难度
- **动钱（C层）**：通过资金安排降低客户的支付压力
- **损失厌恶**：利用人对失去的痛感大于得到的快感的心理
- **从众成交**：借助群体行为对个体施加决策压力
- **早鸟优惠 / 早用早好**：通过时间差利益驱动客户提前决策
- **多重策略**（标*项）：可复用于多个阻力场景的通用策略

## 一句话总结
针对客户"还不急"的拖延心理，从"动嘴、动手、动钱"三个维度提供11种具体策略，系统性地消除客户的不着急心态，推动其尽快完成购买决策。
