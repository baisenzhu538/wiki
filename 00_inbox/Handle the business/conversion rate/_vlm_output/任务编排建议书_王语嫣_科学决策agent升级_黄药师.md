# 任务编排建议书：科学决策 Agent 对话引擎升级

> 发起人：黄药师 | 承接人：王语嫣 | 2026-07-13
> 触发：YAI 科学决策 agent 对话记录反向蒸馏 + 科学决策域资产盘点

---

## 一、核心发现

YAI 的科学决策 agent 不是"分析工具"——它是**决策三角形的对话引擎实现**。

它的对话流程正好是决策三角形三维在对话中的逐维展开：

```
YAI Agent 流程              决策三角形维度
─────────────────────────    ─────────────
里程碑A: 成本收益吐干净    → 宽度（收益+成本）
里程碑A: 补充遗漏项        → 宽度（关键不确定项）
高度四维扫描               → 高度（长期/公司/机会成本/时间窗口）
Level 1-4 深度选择         → 深度（L1定性→L4财务公式）
里程碑8: 决策备忘录        → 三维收束+下一步行动
```

**KDO 不缺方法论卡——缺的是把卡片编织成这个对话流程的引擎。** #153（科学决策教练 spec）定义了角色和工具清单，但没有定义"什么时候该做什么动作"。

---

## 二、差距分析：YAI Agent vs KDO #153

| 能力 | YAI Agent | KDO #153 | 差距 |
|:---|:---|:---|:---|
| 确认理解 | ✅ 复述+追问澄清，选项合并（"A和B是一回事→二选一"） | ❌ 无 | 缺入口动作 |
| 宽度展开 | ✅ 逐选项吐成本收益，不追求完整，想到什么说什么 | ⚠️ 有宽度方法卡，无对话引导 | 有工具无流程 |
| 盲区补充 | ✅ 对照"盲区库"逐条检查遗漏项 | ⚠️ 有 `dk-yitang-Y-model-pitfalls` 等暗知识卡，未聚合为 agent checklist | 盲区分散 |
| 高度扫描 | ✅ 时间窗口/机会成本/长期视角/整体资源配置 四维追问 | ⚠️ 有 `yt-decision-height-toolkit`，但 agent 没有把它变成标准化追问模板 | 有卡无对话 |
| 深度分级 | ✅ 让用户选 L1-L4，默认从 L1 开始 | ⚠️ 有 `yt-decision-depth-ladder`，但 agent 不会主动提供分级选择 | 同上 |
| 收束 | ✅ 决策备忘录（成本侧/收益侧/高度层摘要/关键不确定项/下一步行动） | ⚠️ Y模型有输出格式，但没有"备忘录"这种轻量收束格式 | 输出太重 |
| 硬约束识别 | ✅ "负债压力下一年的爬坡期撑不住→'走'短期不可行" | ❌ 实事求是框架有约束优先理念，但 agent 没实现 | 缺硬过滤 |
| 底牌资产盘点 | ✅ "两个选项共用的资产"独立列出 | ❌ 无 | 缺新动作 |

## 三、建议方案：升级 #153 spec，不是新建 agent

### 3.1 为什么是升级不是新建

- 科学决策域已完整——38+ 张卡，三角形/Y模型/深度阶梯/高度工具箱/盲区库全部就位
- #153 spec 已定义角色和能力边界，有 TCPR 身份声明和 Y模型 OS 底座
- 新建 agent 会造成"两个决策 agent"的混乱——升级让 #153 从工具清单变成对话引擎

### 3.2 建议升级内容

**对话流程章（新增）**：定义里程碑式推进序列

```
入口：确认理解（复述+追问+选项合并）
  → 里程碑A：宽度展开（逐选项吐成本收益，不追求完整）
  → 里程碑B：盲区补充（对照盲区库逐条检查 + 用户确认成立/不成立）
  → 里程碑C：高度扫描（四维追问：时间窗口/机会成本/长期视角/整体资源配置）
  → 里程碑D：深度分级（让用户选 L1-L4，默认从 L1 开始）
  → 硬约束过滤（识别"当前不可行"的选项，明确宣告）
  → 里程碑8：决策备忘录（成本侧/收益侧/高度层摘要/关键不确定项/下一步行动）
```

**三个注入的 YAI pattern**：

1. **选项合并**——用户说"A和B是一样的"→ agent 合并为更少选项，不硬拆
2. **底牌资产盘点**——独立列出"两个选项共用的资产"（14年经验/AI能力/团队/知识产权），这些不随选项变化，是跨选项的筹码
3. **硬约束识别**——"负债压力下一年的爬坡期撑不住→'走'短期不可行"，不等到深度分析才排除，在宽度阶段就标明

**盲区库聚合（工具层新增）**：从分散的暗知识卡聚合成 agent 可调用的 checklist

| 盲区类型 | 来源卡 | 对话题 |
|:---|:---|:---|
| 知识产权/协议盲区 | — | "道理说得通，纸上是空的——有没有没写进协议的关键条款？" |
| 合作方动机盲区 | `dk-yitang-Y-model-pitfalls` | "对方真正要的是你的人还是你的底牌？" |
| 精力分散盲区 | — | "三条赛道每条分到多少注意力？一年分散 vs 一年聚焦？" |
| 家庭/健康盲区 | — | "50岁，身份落差和创业焦虑对身体和家庭的影响纳入考量了吗？" |

### 3.3 不做的

- ❌ 不新建 agent spec——升级 #153 现有文件
- ❌ 不改科学决策域的方法论卡——卡片本身不需要动
- ❌ 不复制 YAI 的全部功能——YAI 的财务公式深度（L4）KDO 已经有 `tool-yitang-business-formula-quant-space-3d` 等工具卡覆盖
