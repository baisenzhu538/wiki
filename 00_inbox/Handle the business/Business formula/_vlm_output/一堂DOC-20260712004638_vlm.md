## 核心主题

这张图展示了从「模糊认知」到「动态决策」的六层业务认知升级路径。它通过不同阶段对应的「工具比喻」（从安慰剂、体温计到导航仪），说明业务公式的认知深度决定了决策的精准度——从仅有模糊答案，到拥有完备的、可定量的、动态优化的决策能力。

---

## 结构化内容

### 一、六层认知阶梯（核心框架）

```
L1 模糊（安慰剂）──→ L2 相关（体温计）──→ L3 因果（方向盘）──→ L4 公式（X光片）──→ L5 定量（刻度尺）──→ L6 动态（导航仪）
```

### 二、每层三个维度

#### L1. 模糊
- **典型范式**：散点分布，无规律
- **公式表达**：N/A
- **获得价值**：安慰剂——有了一个模糊答案，内心踏实很多

#### L2. 相关
- **典型范式**：散点呈线性相关
- **公式表达**：R ~ r
- **获得价值**：体温计——有了一个确定性规律可以预测和监控（辅助参考决策）

#### L3. 因果
- **典型范式**：树状因果结构
- **公式表达**：R = f(A, B, C)
- **获得价值**：方向盘——有了因果规律判断，可找到业务抓手/做功点（大方向上的决策）

#### L4. 公式
- **典型范式**：多变量结构公式
- **公式表达**：R = (A + B) × C × D
- **获得价值**：X光片——有了完备的公式，可以抓主要矛盾路径（单点击穿决策）

#### L5. 定量
- **典型范式**：定量参数化的公式
- **公式表达**：R = (A + B) × C × D，参数：400 / 850 / 25% / 5%
- **获得价值**：刻度尺——有了定量和判断空间，可以预判增长空间（精准的ROI决策）

#### L6. 动态
- **典型范式**：动态曲线（抛物线型）
- **公式表达**：自己建立模型
- **获得价值**：导航仪——有了动态业务理解，可以探索最佳参数（追求最佳决策）

### 三、升级路径

| 当前层级 | 提升方向 |
|---------|---------|
| L1 → L2 | 找相关性 |
| L2 → L3 | 找因果性 |
| L3 → L4 | 参数尽量完备 |
| L4 → L5 | 找基准值/空间 |
| L5 → L6 | 动态理解公式 |
