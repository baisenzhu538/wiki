## 核心主题

这张图是一堂"业务公式"课程的落地策略集，系统化地呈现了**"凝聚共识→配套角色→加法激发→管理假设→减法评估"**这五大核心环节在入门、进阶、高阶三个不同挑战阶段下的具体动作和执行标准。核心观点是：业务公式的落地不是单点突破，而是需要团队在假设驱动的前提下，通过角色配置、机会激发、机制管理和优先级评估形成完整闭环。

---

## 结构化内容

### 一、整体框架

**5大环节 × 3个阶段 = 15格行动矩阵**

- **5大环节**（列）：凝聚共识 / 配套角色 / 加法激发 / 管理假设 / 减法评估
- **3个阶段**（行）：入门起码 / 进阶专业 / 高阶挑战

### 二、各阶段特征

| 阶段 | 特征 | 核心要求 |
|---|---|---|
| 入门起码 | 经验少、探索多、解法多 | 允许试错、建立基本假设管理意识 |
| 进阶专业 | 协作多、投入高、周期长 | 明确目标公式、专业角色分工 |
| 高阶挑战 | 时间紧、风险大、困难高 | 充足假设池、完整团队、严格评估 |

### 三、PEAHD五角色模型（高阶）

1. 倡导者 - promoter
2. 执行者 - executor
3. 管理者 - admin
4. 轰炸者 - hero
5. 讨论者 - discusser

### 四、业务公式统一管理三角模型

- **顶点**：假设池
- **左下角**：关键会议
- **右下角**：仪表盘
- **三条边**：迭代事 / 协作人 / 进展现
- **中心**：业务公式

### 五、ROI评估三维度

1. ROI：价值和成本（至少定性高中低，最好定量预期数值）
2. 确定性
3. 风险和负收益

### 六、验证策略三大难题

- 难题1：单独验证 vs 直接正式投入
- 难题2：独立测试 vs 合并测试
- 难题3：数据量不足时是否坚持实验验证
- **本质策略**：综合考虑确定性和边际ROI

## 关键概念

- **业务公式落地五环节**：凝聚共识、配套角色、加法激发、管理假设、减法评估
- **假设驱动**：用高质量假设+验证实现高难目标
- **Discusser / Admin 角色**：分别负责提假设、管假设
- **PEAHD 五角色模型**：promoter / executor / admin / hero / discusser
- **业务公式统一管理三角**：假设池 + 关键会议 + 仪表盘 围绕业务公式运转
- **ROI 评估三维度**：价值成本、确定性、风险和负收益
- **项目攻坚会**：现场多轮提假设、民众集中制激发业务假设
- **本质策略**：综合考虑确定性和边际ROI，对低确定性高边际成本假设谨慎对待

## 一句话总结

这张图将"业务公式"的落地拆解为「凝聚共识—配套角色—加法激发—管理假设—减法评估」五大环节在不同挑战阶段下的15格行动矩阵，核心传达的是：**业务公式的落地本质上是一套"假设驱动的闭环管理体系"——既要大胆提假设（加法），也要严格筛假设（减法），用统一自洽的机制让业务公式真正跑起来。**
