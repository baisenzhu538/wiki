## 核心主题

这张图片以"冰山模型"为隐喻，将业务参数划分为初阶、进阶、高阶三个层级共六类（基础、财务、分层、转化、创新、魔法参数），强调优秀管理者应持续深入研究参数，从表面直觉走向本质洞察。

## 结构化内容

### 一、冰山模型——参数三层六阶

```
            ┌─────────────────────┐
            │   L1 基础参数（直觉） │ ← 初阶·靠经验
   ┌────────┤   L2 财务参数（算）   │
   │        └─────────────────────┘
   │        ┌─────────────────────┐
   │ 冰山   │   L3 分层参数（切）   │ ← 进阶·靠分析
   │        │   L4 转化参数（拆）   │
   │        └─────────────────────┘
   │        ┌─────────────────────┐
   │        │   L5 创新参数（探）   │ ← 高阶·靠创新
   └────────┤   L6 魔法参数（本质） │
            └─────────────────────┘
```

### 二、L1–L6 核心参数清单

- **L1 基础参数**：粗流量、粗线索、粗订单、粗收入
- **L2 财务参数**：算单元模型、算关键指标、算财务模型
- **L3 分层参数**：切用户、切渠道、切行为、切场景、切SKU
- **L4 转化参数**：拆首单、拆LTV、拆动作、拆筛选
- **L5 创新参数**：探索动作、探索数值、探索组合
- **L6 魔法参数**：销售本质、留存本质、复购本质

### 三、两种参数研究路径

- **从上往下拆解**（演绎）：流程梳理、已有经验、逻辑推理、最佳实践
- **从下往上涌现**（归纳）：异常分析、变化归因、范式迁移、大胆假设

## 关键概念

- 参数冰山模型
- 基础参数（粗流量/线索/订单/收入）
- 财务参数（单元模型/关键指标/财务模型）
- 分层参数（用户/渠道/行为/场景/SKU）
- 转化参数（首单/LTV/动作/筛选）
- 创新参数（动作/数值/组合）
- 魔法参数（销售/留存/复购本质）
- 自上而下拆解 vs 自下而上涌现

## 一句话总结

业务能力藏在"参数冰山"之下——从初阶的粗放经验到高阶的本质洞察，需沿 L1→L6 六阶逐级深入，并结合"自上而下拆解"与"自下而上涌现"两条路径，方能成为高段位管理者。
