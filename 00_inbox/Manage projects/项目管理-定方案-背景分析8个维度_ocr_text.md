# 项目背景问题思考的8个维度清单

| 层级 | 思考维度 | 落差 | 解释 |
|------|---------|------|------|
| 宏观 | 战略上 | 战略目标和现状的落差 | 活下来/增长/盈利上岸/做到第一名/壁垒？ |
| 中观 | 商业上 | 收入增长和停滞的落差 | 这个给公司创造的商业价值是什么？ |
| 中观 | 目标上 | 团队目标和进展的落差 | 各个团队最想要追求是什么？okr？KPI？ |
| 微观 | 市场上 | 我们和对手基准的落差 | 我们和竞争对手/市场benchmark差距多大？ |
| 微观 | 用户上 | 用户价值和缺失的落差 | 用户到底遭遇了什么问题？比例和数量？ |
| 微观 | 效率上 | 内部高效和低效的落差 | 内部系统遇到了什么低效的问题？ |
| 微观 | 成长上 | 团队成长和低效的落差 | 团队需要提升什么能力、文化和战斗力？ |
| 微观 | 老板上 | 老板想法和拒绝的落差 | 老板有哪些任务安排和喜欢偏好？ |
