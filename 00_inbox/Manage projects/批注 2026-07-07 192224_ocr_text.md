# 项目复盘深度 选择5维模型

| 考虑维度 | 重点问问自己 |
|---------|-------------|
| 1. 是否会重复 | 这类工作未来会不会重复，还是一次性的 |
| 2. 是否很重要 | 是不是对公司、对团队很重要的项目，高投入的项目 |
| 3. 是否需讨论 | 与计划不符，显著成功/未达预期，需要讨论背后的原因 |
| 4. 是否可挖掘 | 是不是有很多过程资产，方法论/SOP可以总结 |
| 5. 是不确定 | 是不是风险很高，或者探索型的项目，很容易失败 |
