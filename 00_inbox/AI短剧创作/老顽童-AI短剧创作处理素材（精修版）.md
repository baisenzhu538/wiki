## 一、核心方法论总览

代俊隆的 AI 短剧创作体系可归纳为 **"罗盘 + 三板斧"** 结构：

| 层级 | 名称 | 作用 |
|---|---|---|
| 总纲 | 冰火写本罗盘 | 剧本策划全流程体系与创作底层方法论 |
| 拆解 | 冰火拆本罗盘 | 剧本创作底层逻辑与核心要素全息解构 |
| 剧情 | 剧情三板斧 | 极致对立 → 高能吸睛 → 立意升华 |
| 策划 | 剧本策划三板斧 | 剧本基地 → 内容走向 → 剧情终局 |
| 结构 | 框架三板斧 | 深渊入局 → 迷雾博弈 → 决战收官 |
| 冲突 | 矛盾冲突三板斧 | 外在阵营 → 内在人际 → 自我宿命 |
| 落地 | 主流平台政策对比 | 抖音/红果、快手、腾讯、爱奇艺、优酷、芒果 |

## 二、剧情三板斧

### 第一板斧：极致对立
- **关键词**：有锋芒
- **作用**：制造强烈冲突，让故事有张力
- **老顽童可转**：
  - Prompt 模板："设计一个极致对立的设定：A 是____，B 是____，两人因____被迫绑定。"
  - Checklist：是否有身份/立场/价值观的根本对立？

### 第二板斧：高能吸睛
- **关键词**：聚目光
- **作用**：前三秒/前十秒抓住观众注意力
- **老顽童可转**：
  - Prompt 模板："为以下剧本写 3 个高能开场：____"
  - Checklist：开场是否有强冲突、强悬念、强情绪？

### 第三板斧：立意升华
- **关键词**：升高度
- **作用**：让短剧不止爽，还有情绪价值或社会共鸣
- **老顽童可转**：
  - Prompt 模板："在故事结尾加入一个立意升华点，让观众感到____"
  - Checklist：结局是否传递了明确价值观或情感共鸣？

## 三、剧本策划三板斧

### 第一板斧：剧本基地 夯根基
- **英文标注**：Essential Information of Situation
- **作用**：奠定剧本核心框架与基础设定
- **老顽童可转**：
  - Prompt："请为一部____题材短剧建立剧本基地：世界观、主角身份、核心冲突、目标动机。"
  - 输出格式：
    - 题材：
    - 主角：
    - 核心欲望：
    - 核心阻碍：
    - 故事发生场景：

### 第二板斧：内容走向 明轨迹
- **英文标注**：Step Information Iteration
- **作用**：梳理剧情发展脉络与关键节点
- **老顽童可转**：
  - Prompt："基于以下剧本基地，列出 10-15 个关键剧情节点（每节点 1 句话）。"
  - 输出格式：起 → 承 → 转 → 合，标注每集的卡点/钩子

### 第三板斧：剧情终局 落华章
- **英文标注**：Station Conclusion Elevation
- **作用**：收束故事线，完成情节闭环
- **老顽童可转**：
  - Prompt："为以下剧情走向设计 3 种结局方案：HE / BE / 开放式，并说明各自情绪落点。"

## 四、框架三板斧（英雄之旅短剧版）

### 第一板斧：深渊入局闯难关
- **意象**：英雄踏入深渊，面对黑暗与困境
- **老顽童可转**：
  - Prompt："设计主角的'深渊入局'时刻：他/她因什么被迫进入困境？初始劣势是什么？"

### 第二板斧：迷雾博弈克万难
- **意象**：迷雾中前行，突破重重障碍
- **老顽童可转**：
  - Prompt："列出主角在'迷雾博弈'阶段需要克服的 3 个主要障碍，每个障碍对应一次成长。"

### 第三板斧：决战收官展不凡
- **意象**：故事光芒中战胜最终 BOSS，成就非凡
- **老顽童可转**：
  - Prompt："设计最终决战：对手是谁？主角用什么新能力/认知获胜？胜利后人物关系如何变化？"

---

## 五、矛盾冲突三板斧

### 第一板斧：外在阵营 立分明
- **要点**：阵营划分，明确立场
- **老顽童可转**：
  - Prompt："明确本剧的外在阵营：正方、反方、摇摆方，各方的核心利益和代表人物。"

### 第二板斧：内在人际 见真情
- **要点**：人际连接，情感共鸣
- **老顽童可转**：
  - Prompt："设计 3 组核心人物关系，每组包含：关系类型、情感纽带、潜在裂痕。"

### 第三板斧：自我宿命 寻答案
- **要点**：自我探索，寻找意义
- **老顽童可转**：
  - Prompt："主角的内在矛盾是什么？他/她最终如何与自己和解？"

## 六、主流短剧平台政策对比

| 平台 | 投稿方式 | 分成模式 | 题材偏好 | 新人友好度 |
|---|---|---|---|---|
| 抖音/红果 | 巨量创意平台投稿 | 广告分成 + 保底 | 女频甜宠、都市逆袭 | 高 |
| 快手 | 快手短剧后台 | 分账 + 广告 | 男频爽文、逆袭 | 高 |
| 腾讯视频 | 腾讯视频创作者平台 | 会员分账 | 悬疑、古装 | 中 |
| 爱奇艺 | 爱奇艺分账合作 | 会员分账 + 广告 | 全品类 | 中 |
| 优酷 | 优酷开放平台 | 阶梯奖金 | 女频甜宠 | 中 |
| 芒果 TV | 芒果 TV 创作平台 | 分账 + 定制 | 青春、悬疑 | 中 |

### 老顽童可转
- Prompt："为____平台定制一版短剧策划，突出其题材偏好和分成逻辑。"
- Checklist：
  - [ ] 目标平台是否符合题材偏好？
  - [ ] 开头是否符合该平台用户的观看习惯？
  - [ ] 是否预留了广告分账所需的钩子密度？

## 七、老顽童可直接使用的 Prompt 模板

### 模板 1：短剧策划总览
```
请基于"剧情三板斧 + 剧本策划三板斧 + 框架三板斧 + 矛盾冲突三板斧"，
为一部[题材]短剧生成完整策划：
1. 极致对立设定
2. 高能开场（3 个）
3. 立意升华点
4. 剧本基地（世界观、主角、核心冲突）
5. 15 个内容走向节点
6. 3 种结局方案
7. 深渊入局、迷雾博弈、决战收官三幕设计
8. 外在阵营、内在人际、自我宿命三层冲突
9. 适合[平台]的投稿优化建议
```

### 模板 2：单集剧本生成
```
基于以下剧本基地：
[粘贴剧本基地]

请生成第[集数]集剧本：
- 本集目标：
- 开场钩子：
- 核心冲突：
- 结尾卡点：
- 台词风格：
- 预计时长：1-2 分钟
```

### 模板 3：平台适配改写
```
以下是一份短剧策划：
[粘贴策划]

请针对[抖音/红果/快手/腾讯视频/爱奇艺/优酷/芒果TV]进行改写：
1. 调整题材侧重点
2. 优化开头钩子以匹配平台用户
3. 调整集数/时长/节奏
4. 给出投稿路径和分成策略建议
```
