【核心内容】

- 这是一张**销售目标拆解与执行画布**，用于将"业绩目标"逐层分解为可落地的管理动作。
- 画布采用**"目标→维度→策略→跟进"四段式结构**，符合 PDCA 风格的闭环管理逻辑。
- 第 3 部分特别区分了**"核心策略"与"备选策略"**，体现了 Plan A + Plan B 的风险管理思维。
- 整体设计为**空白填写式模板**，强调"一图一议、一堂一用"，适用于销售管理者进行周会、月度复盘或战术讨论。
- 标题"一、堂"暗示这是系列画布的第一张，强调的是**单次/单议题业绩管理的标准化思考路径**。

---

【结构化解析】

**画布四层结构表：**

| 层级 | 模块名称 | 关键问题 | 输出物 |
|------|----------|----------|--------|
| L1 | 核心目标 | 这一堂要达成什么？ | 1 个清晰的数字目标 |
| L2 | 拆解维度 | 从哪些角度拆解目标？ | 2~4 个维度（如客户/产品/团队/时间） |
| L3 | 策略设计（核心+备选） | 用什么打法达成目标？ | 主推策略 + 后备策略 |
| L4 | 过程跟进 | 如何确保执行不跑偏？ | 关键节点 + 检查机制 |

**策略设计子结构：**

```
3、策略设计
   ├── 3.1 核心策略（首选打法、最重要资源投放方向）
   └── 3.2 备选策略（Plan B，应对核心策略失效时的兜底方案）
```

---

【与科学销售五步法的关联】

科学销售五步法典型流程为：**定目标 → 找路径 → 配资源 → 强执行 → 拿结果**（或"目标设定 → 策略制定 → 过程管理 → 结果复盘"）。

本画布与五步法的对应关系：

| 画布模块 | 对应五步法环节 | 管理价值 |
|----------|----------------|----------|
| 1、核心目标 | **第一步·目标设定** | 强制把"模糊业绩"翻译成"具体可衡量数字" |
| 2、拆解维度 | **第二步·路径规划** | 将总目标分解到客户/产品/区域/时间等可操作维度 |
| 3、策略设计 | **第三步·策略制定**（含资源配置） | 输出主备两套打法，降低单一路径失败风险 |
| 4、过程跟进 | **第四步·过程管理** | 设置检查点，把"事后追责"变为"事中纠偏" |

**核心管理价值：**
- 把"业绩目标"从**结果导向**升级为**过程导向**，解决"目标喊了但不知道怎么追"的痛点。
- 通过"核心策略 + 备选策略"强制管理者做**风险预案**，避免单点失败导致业绩崩盘。
- 标准化画布可作为团队**共创工具**，统一管理语言与思考颗粒度。

---

【落地应用建议】

**建议 1：销售周会必用画布（30 分钟战情分析）**
- 每周一用本画布复盘上周业绩：先填第 1、2 栏锁定目标与缺口，再讨论第 3 栏策略调整，最后第 4 栏明确本周跟进节点。
- 建议把画布打印或投影，让销售管理者**边讲边填**，比 Excel 数字汇报更能暴露问题。

**建议 2：为"备选策略"设定触发条件**
- 不要等核心策略失效才想 Plan B。**给每个核心策略设置一条"撤退红线"**（例如：连续 2 周新客到店<5 单/周，或成交率<15%）。
- 当红线触发，立刻切换到 3.2 备选策略，并将切换动作录入第 4 栏过程跟进。

**建议 3：把画布升级为"系列作战地图"**
- 标题中的"一、堂"暗示这是系列模板。建议配套开发：
  - **二堂：客户分层画布**（聚焦目标客户群体）
  - **三堂：团队分工画布**（聚焦人员责任）
  - **四堂：风险预警画布**（聚焦问题诊断与对策）
- 形成一个完整的"**业绩管理作战工具箱**"，覆盖五步法全流程。
