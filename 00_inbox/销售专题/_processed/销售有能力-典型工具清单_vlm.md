## 【核心内容】

- 🎯 **主题定位**：一份"销售能力建设"的工具清单（Checklist），用于销售人员的自我检视与能力盘点。
- 🧩 **两大模块**：分为"专项技能"（8 项，偏行为/方法）与"专业知识"（3 项，偏认知/储备），合计 11 个能力项。
- 🔧 **技能导向**：专项技能聚焦客户接触、关系推进、调研方法、案例学习等可训练动作。
- 📚 **知识导向**：专业知识侧重行业认知、产品方案及销售角色认知等基础素养。
- ✅ **使用方式**：以"Checklist"形式呈现，暗示用于销售入门检核、培训对照、能力评估。

## 【与科学销售五步法的关联】

> 五步法：① 客户定位 → ② 关系建立 → ③ 需求挖掘 → ④ 方案呈现 → ⑤ 推进成交

| 五步法阶段 | 对应清单项 | 关联说明 |
|------------|------------|----------|
| **① 客户定位** | 6.行业调研 / 1.专业知识 | 锁定行业与目标客户画像 |
| **② 关系建立** | 2.拉近客户关系 / 7.新拜访示范 | 首访破冰与信任锚定 |
| **③ 需求挖掘** | 1.客户聆听 / 5.用户调研 / 3.找到决策人 | 锁定痛点与权力地图 |
| **④ 方案呈现** | 2.专业知识（产品方案） | 个性化价值传递 |
| **⑤ 推进成交 + 长期经营** | 4.老客户推荐 / 8.失败案例 / 3.怎么当好销售 | 客户裂变与持续复盘 |

**管理价值**：
- 📌 这是一份覆盖"售前—售中—售后"全链路的能力自检表。
- 📌 既可用于**新销售入职培训地图**，也可用于**老销售能力盘点（Gap Analysis）**。
- 📌 11 项之间形成"行为+认知"互补，避免单点训练导致的"会做不会想"或"会想不会做"。

## 【落地应用建议】

### ✅ 建议一：转化为《销售能力诊断问卷》
将 11 项做成 5 级评分表（如 1=完全不会，5=完全掌握），让每位销售每季度自评 + 主管评分，自动生成个人能力雷达图，识别短板。

### ✅ 建议二：按清单设计"训战结合"培训计划
- **专项技能 8 项** → 设计 8 节实操工作坊（角色扮演、案例研讨）；
- **专业知识 3 项** → 设计知识库 + 每周行业/产品分享会；
- 每项配套 **Checklist 评估标准**（如"客户聆听"需完成：开放式提问 ≥3 次、复述确认 ≥2 次）。

### ✅ 建议三：与销售漏斗（Pipeline）联动管理
将清单 11 项与销售阶段绑定，例如：
- 漏斗"商机发现"阶段必检 → 行业调研、用户调研是否完成；
- 漏斗"方案确认"阶段必检 → 产品方案是否熟练呈现；
- 漏斗"成交转介绍"阶段必检 → 老客户推荐机制是否启动。

形成"**能力清单 × 销售漏斗**"双维度管理矩阵，确保能力建设真正服务于业绩结果。
