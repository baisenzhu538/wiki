## 【核心内容】

- 🎯 **客户全旅程行为地图**：从"线上看到商家→浏览→购单→预约→到店→体验→二次复购/储值→复约→复到店消耗"完整拆解，覆盖新客到忠诚客户的10+个关键触点
- 🚦 **7个关键决策点（红色标注）**：进店详情页 / 购买团单 / 预约 / 如期到店 / 继续体验 / 二次复购 / 储值办卡 / 是否复约 / 复到店消耗
- ⚙️ **每个决策都有对应的影响因子**：客户判断依据 = 客观因素（价格、距离、评论）+ 主观感受（专业度、服务态度、体验感）+ 外部因素（天气、交通）
- 🔄 **双次到店闭环设计**：首次到店体验 → 复约到店消耗，是医美/美容/服务类行业的标准成交架构
- 📊 **决策点 = 流失点 / 转化点**：图中红色加粗环节均为管理者重点关注的转化瓶颈

## 【结构化解析】

### 一、客户旅程阶段分层

| 阶段 | 关键动作 | 对应决策点（红字） | 漏斗性质 |
|------|---------|------------------|---------|
| **阶段1：线上发现** | 美团列表→详情页→看到团单 | ①是否点进详情页<br>②是否购买团单 | 流量入口 |
| **阶段2：预约确认** | 购单→预约→电话回访→加微信 | ③是否预约时间<br>④是否如期到店 | 意向确认 |
| **阶段3：首次到店** | 到店→环境观察→皮肤检测→开始体验→对比效果 | ⑤是否继续体验<br>⑥做完就走还是深入了解 | 体验交付 |
| **阶段4：转化决策** | 了解长期护理→考虑长期护理→购卡储值→付款 | ⑦是否购卡/储值<br>⑧定金vs全款/分期 | 二级变现 |
| **阶段5：锁客复购** | 离店→提前预约下次→复到店消耗 | ⑨是否继续来店<br>⑩复到店是否如期 | 长期价值 |

### 二、各决策点核心影响因子归类

| 决策点 | 关键影响因子 | 可优化维度 |
|--------|------------|----------|
| 进店详情页 | 店铺星级、团单匹配、价格、金银铜牌、距离 | **视觉+精准度**（封面图+人群标签） |
| 购买团单 | 销量、评价内容、回复及时性 | **口碑运营** |
| 预约时间 | 入口可见性、时间段可选性 | **SOP标准化** |
| 如期到店 | T-1天/T-1小时提醒、天气应对 | **客户提醒机制** |
| 继续体验 | 咨询师专业度、皮肤话术 | **销售技能培训** |
| 二次了解 | 项目体感、效果对比、长期价值塑造 | **效果可视化** |
| 购卡储值 | 价格、优惠、跑路风险、专业度 | **信任建设+促销设计** |
| 提前复约 | 是否主动帮预约、话术引导 | **客户经理制** |
| 下次复约到店 | 售后服务（护理提醒、关怀） | **私域运营** |

## 【与科学销售五步法的关联】

> 科学销售五步法：①客户定位 → ②客户开发 → ③建立信任 → ④需求挖掘/方案呈现 → ⑤成交与转介绍

| 对应步骤 | 图中对应阶段 | 管理价值 |
|---------|------------|---------|
| **①客户定位** | 阶段1线上发现（美团列表） | 美团人群标签、金银铜牌权重决定流量精准度 |
| **②客户开发** | 阶段2预约确认 | 线上咨询回复及时性、回访话术是开发转化关键 |
| **③建立信任** | 阶段3首次到店+皮肤检测 | 店面环境、咨询师专业度、检测话术 = 信任地基 |
| **④需求挖掘/方案** | 阶段3二次了解+考虑长期护理 | 效果对比、长期价值塑造是促成深度需求的关键 |
| **⑤成交转介绍** | 阶段4购卡储值 + 阶段5复购 | 储值锁客+售后关怀+复约提醒 = 转介绍来源 |

**核心管理价值**：
- 这张图是"客户决策漏斗"的具象化，管理者可以用它**对每个节点设定转化率KPI**
- 红色决策点 = **销售辅导的关键SOP节点**，可用于团队话术训练、流程优化
- 帮助管理者从"凭感觉抓管理"升级为"按触点做运营"

## 【落地应用建议】

### ✅ 建议一：搭建"触点KPI看板"，按图索骥做漏斗管理
将图中10个红色决策点逐一拆解为**团队KPI指标**，例如：
- 美团详情页点击率 ≥ 35%
- 团单购买转化率 ≥ 8%
- T-1小时预约确认执行率 = 100%
- 首次到店→皮肤检测完成率 ≥ 95%
- 体验后→购卡储值转化率 ≥ 20%
- 老客户复约到店率 ≥ 60%

每月复盘每个节点的流失原因，**用数据驱动优化**而非凭经验管理。

### ✅ 建议二：沉淀"决策点话术库"用于团队复制
每个红色决策点都对应一套标准话术包，例如：
- **是否继续体验** → 咨询师3步法：问题确认+专业解读+预期管理
- **是否购卡储值** → 顾问5要素话术：效果+专业+安全+优惠+长期价值
- **是否复约到店** → 客户经理3件套：提前预约+护理提醒+关怀触达

**核心原则：让销冠的经验变成团队的可复制SOP**。

### ✅ 建议三：建立"客户全旅程地图评审会"机制
每月选1条客户全路径做深度复盘：
1. 随机抽3-5个新客户走查每个触点的实际体验
2. 找流失最高的3个红色决策点做根因分析
3. 输出1-2项流程/话术/工具的改善方案，下月验证

**一句话总结**：这张图不仅是一张行为路径表，更是一张"**销售管理作战地图**"——管理者看的是转化漏斗，客户经理看的是销售节奏，培训师看的是话术拆解点。
