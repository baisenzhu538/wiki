【图片类型】
**清单表**（结构化清单/Checklist分类表），按业务场景分为5大模块共15+子项。

---

【核心内容】

- **交付物模板**：覆盖研究报告、标书、设计方案、项目时间表4类，是面向客户的核心产出文档。
- **客户模板**：聚焦客户档案与客户关系图谱，用于客户信息沉淀与关系梳理。
- **成单模板**：包含销售合同、代理协议、订货单，是交易闭环的法律与商务凭证。
- **财务模板**：付款通知、请款函、追款律师函、收据，构成应收账款全流程文档。
- **跟进模板**：Pipeline清单、过程记录表（面谈/电销/新拜访）、计划表（年度/月度），是日常销售过程管理的核心工具。

【与科学销售五步法的关联】

这张清单属于**五步法的全过程支撑工具集**，并非单一步骤，而是横跨全流程：

| 五步法步骤 | 对应模板 |
|------------|----------|
| **第一步：客户分析与约访** | 客户档案模板、客户关系图谱、年度/月度拜访计划表 |
| **第二步：建立信任与价值呈现** | 研究报告模板、设计模板、新拜访记录表 |
| **第三步：需求挖掘与方案呈现** | 标书模板、项目执行时间表模板、过程记录表 |
| **第四步：商务谈判与成交** | 销售合同、代理协议、订货单、Pipeline清单 |
| **第五步：交付与回款** | 付款通知书、请款函、追款律师函、收据模板 |

**管理价值**：
1. **标准化**：将个人经验固化为组织资产，降低人员流动带来的能力损耗。
2. **专业化**：让销售动作有"模板"可依，提升对客输出的专业感。
3. **流程化**：从售前→签约→回款形成完整文档链，避免"口头承诺""流程断点"。
4. **可复制**：新人可借模板快速上手，缩短培养周期。

【落地应用建议】

**建议1：建立"模板库三件套"分级管理**
- **L1通用模板**（客户档案、面谈记录表、收据）：全员强制使用
- **L2业务模板**（标书、合同、Pipeline）：按角色调用
- **L3精英模板**（客户关系图谱、追款律师函）：管理者审批后使用
- 落地动作：搭建云端共享盘（如钉钉/企微知识库），每月更新版本号

**建议2：将"模板使用率"纳入销售管理仪表盘**
- 每月统计每位销售调用模板的次数、填写完整度
- 与成单率、回款周期做相关性分析
- 用数据证明：模板使用率高的销售，业绩表现是否更优
- 落地动作：CRM系统记录模板调用日志，季度复盘

**建议3：每季度做"模板瘦身+迭代"**
- 删除3个月未使用的僵尸模板
- 收集Top Sales的"实战改良版"反哺模板库
- 重点迭代：**过程记录表**（最易流于形式）→ 增加"客户原话摘录""下一步承诺"两个必填字段
- 落地动作：每季度末召开"模板评议会"，销售+管理者共创更新
