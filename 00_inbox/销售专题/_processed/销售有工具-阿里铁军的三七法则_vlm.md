# 销售有工具-阿里铁军的三七法则

【OCR原文】

聆听三七法则：70%时间让客户说。这样做的好处：

第一，深入了解客户。

第二，挖掘客户需求。

第三，可以把客户长期发展为伙伴，甚至是朋友。

通过聆听，我们就有机会了解到客户个人生活中的一些情况，包括子女、家庭、经历，还有在职业、生活上对未来的规划，其实这是非常重要的。

聆听技巧。

第一，要做到目光接触。和客户沟通的过程当中，双眼一定要始终盯着客户。人们发现在人与人沟通时用双眼盯着对方的眉心，营造的氛围和给对方的体验是最好的。

第二，一定要全神贯注。有的销售员非常不专注。例如，两个人聊着聊着，他的手机响了，就会低头看手机，在商务环境中，这其实是非常不礼貌的；

第三，可以做笔记。做笔记可以帮助我们履行确定的承诺，还可以记一些其他对销售有帮助的信息。

第四，注意聆听在整个销售过程当中的时间比例。"销售员说30%，聆听70%"的规则来分配时间比例。销售员说话的时间比例不应该超过50%。

第五，千万不要轻易打断客户。

第六，千万不要预设立场。不要抱有成见，我们要学会和客户从同一角度去看事情，只有这样才能真正地去了解、引导对方。

【核心内容】

- **聆听三七法则**：销售员说30%，聆听70%，销售员讲话时间不应超过50%。
- **聆听三大价值**：深入了解客户、挖掘客户需求、把客户发展为长期伙伴。
- **聆听六大技巧**：目光接触、全神贯注、做笔记、控制时间比例、不打断客户、不预设立场。
- **聆听深层目标**：通过了解客户生活（子女、家庭、经历、职业规划）建立深层连接。
- **聆听的反例警示**：看手机、心不在焉、轻易打断、预设立场均为典型错误行为。

---

【结构化解析】

### 一、聆听价值（三层递进）

| 层级 | 价值点 | 客户关系深度 |
|------|--------|------------|
| L1 信息层 | 深入了解客户 | 信息收集 |
| L2 需求层 | 挖掘客户需求 | 痛点识别 |
| L3 关系层 | 发展为伙伴/朋友 | 长期信任 |

### 二、聆听技巧清单（六大执行动作）

| 序号 | 技巧 | 关键动作 | 常见错误 |
|------|------|----------|----------|
| 1 | 目光接触 | 双眼盯客户眉心 | 眼神游移 |
| 2 | 全神贯注 | 专注当下对话 | 看手机/分心 |
| 3 | 做笔记 | 记录承诺与信息 | 仅凭记忆 |
| 4 | 时间比例 | 30/70分配，讲话≤50% | 滔滔不绝 |
| 5 | 不打断 | 让客户充分表达 | 抢话/插话 |
| 6 | 不预设立场 | 与客户同角度思考 | 抱有成见 |

### 三、聆听时间分配规则

```
销售员说话：30%（硬上限50%）
客户说话：70%（目标值）
```

【与科学销售五步法的关联】

科学销售五步法：① 准备 → ② 调查分析 → ③ 呈现价值 → ④ 异议处理 → ⑤ 达成承诺

**本图关联步骤：第②步"调查分析"（核心）、贯穿第③④⑤步**

| 关联步骤 | 关联说明 |
|----------|----------|
| 第②步 调查分析 | **核心对应**——聆听是采集客户信息、识别需求的核心手段 |
| 第③步 呈现价值 | 只有充分聆听，价值呈现才能精准匹配客户需求 |
| 第④步 异议处理 | "不打断"是非暴力沟通的基石，直接影响异议化解 |
| 第⑤步 达成承诺 | "做笔记"是履行承诺、推进落地的基础 |

**管理价值**：将销售员的客户沟通行为标准化，从"会说话"转向"会听话"，是销售团队从产品推销型向顾问咨询型转型的关键能力。

【落地应用建议】

### 建议一：30秒聆听取证检查表（每日应用）

每次客户拜访后，销售员立即填写：
- ☑ 本次沟通我说话时长占比 ____%
- ☑ 是否出现看手机/分心行为
- ☑ 笔记记录了几条客户关键信息
- ☑ 是否出现打断客户的瞬间
- ☑ 客户是否透露了个人生活信息

**管理动作**：销售经理每周抽查3位销售员的取证表，与录音复盘交叉验证。

### 建议二：团队"聆听30讲"训练计划

| 周次 | 训练主题 | 训练方式 |
|------|----------|----------|
| W1 | 目光接触训练 | 角色扮演+视频回放 |
| W2 | 不打断训练 | 红蓝对抗演练 |
| W3 | 30/70时间管理 | 录音切片分析 |
| W4 | 做笔记SOP | 笔记模板统一化 |

### 建议三：将"70%聆听"嵌入销售流程KPI

- **过程指标**：客户拜访录音中，客户发言时长占比≥60%
- **质量指标**：每次拜访产出≥3条客户关键信息（含个人生活维度）
- **红线指标**：单次拜访打断客户次数≤2次

将以上三项纳入销售员的月度考核，与绩效奖金直接挂钩。
