## 【核心内容】

- 这是一张**目标拆解工作模板**，销售人员/管理者可用于将模糊的"公司目标"转化为可量化的子目标体系。
- **核心拆解逻辑**：目标 = 多个"维度X"之和，每个"维度X" = 多个"维度Y"之和，形成**两级漏斗式拆解结构**。
- 公式给出了样例（一级3维度，二级3维度），并引导学员**写下自己的目标公式**，强调学以致用。
- 下方4×3矩阵提供了**结构化填写框架**：行=一级维度（预留4个），列=二级维度（预留3个），共计12个填空位，便于穷举拆解。
- 顶部"公司目标 vs 拆解目标"双栏，引导学员做**目标翻译**——从公司语言转化到个人/团队可执行的细化目标。

### 一、模板结构层级

```
┌─────────────────────────────────────────────┐
│  第一层：目标对齐（公司目标 ⇔ 拆解目标）       │
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  第二层：拆解公式（一级维度X分解）              │
│  公式：目标 = X₁ + X₂ + X₃                   │
│       X₁ = Y₁ + Y₂ + Y₃                      │
│       （引导学员自创公式）                      │
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  第三层：矩阵填空（二级维度Y穷举）              │
│  X₁ ──┬── Y₁                                 │
│  X₂ ──┼── Y₂                                 │
│  X₃ ──┼── Y₃                                 │
│  X₄ ──┘ （预留扩展位）                        │
└─────────────────────────────────────────────┘
```

## 【与科学销售五步法的关联】

> 科学销售五步法通常指：①目标设定 → ②客户分析 → ③价值塑造 → ④推进成交 → ⑤复盘复购

| 关联步骤 | 关联说明 |
|---------|---------|
| **第①步 目标设定** | ✅ **核心对应**——本模板就是五步法第1步的"工具化输出"，用于将模糊目标转化为可量化结构。 |
| **第⑤步 复盘复购** | ⚪ **二次关联**——矩阵化拆解便于复盘时回溯"目标差距在哪个维度X、哪个维度Y"。 |
| **管理价值** | 1. **对齐价值**：让一线清楚公司目标如何映射到个人指标；2. **诊断价值**：业绩波动时可定位到具体维度Y；3. **激励价值**：明确子目标，增强成就感与执行力。 |

## 【落地应用建议】

### 建议1：季度初用模板做"目标拆解工作坊"（30分钟）

**操作步骤：**
1. 销售经理填写顶部"公司目标"（如：Q4 营收 1000 万）。
2. 全员共创"拆解公式"——用头脑风暴定义一级维度X（如：新客/老客/产品线）。
3. 每人领取一张矩阵表，**独立完成12格填写**，15分钟后交叉点评对齐。
4. 输出每位销售的"个人目标公式"上墙，**周会跟进维度完成率**。

### 建议2：建立"维度Y颗粒度标准"，避免拆解过粗或过细

- 每个维度Y必须是**可独立追踪、可独立归因**的指标（如：可到具体客户/产品/渠道）。
- 颗粒度过粗 → 失去拆解意义；颗粒度过细 → 失去管理意义。
- 推荐标准：**每个维度Y的工作量占销售人员总工时的5%-25%**为宜。

### 建议3：周复盘时用矩阵做"差距归因表"

- 若"目标=维度X₁+X₂+X₃"未达成，在周会上直接定位：
  - 是 X₁ 未达成？还是 X₂、X₃？
  - 进一步：是 X₁ 的 Y₁ 未达成？还是 Y₂、Y₃？
- **通过两级穿透，让"业绩差距"转化为"具体行动项"**，避免模糊归因（如"努力不够""市场不好"等无效结论）。
