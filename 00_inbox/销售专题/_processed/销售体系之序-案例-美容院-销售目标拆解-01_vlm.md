## 【结构化解析】

### 一、目标拆解的两维模型

| 拆解维度 | 子项 | 管理意图 |
|---------|------|---------|
| **按顾客来源**（流量端） | 老客续卡 | 维系存量客户复购，降低获客成本 |
| | 新客成交 | 拉新贡献，对应引流到店效果 |
| | 　— 新客1314以上 | 高客单新客，标注重点突破对象 |
| | 追尾款 | 历史欠款回收，保现金流 |
| **按卡种性质**（产品端） | 储值 | 锁定客户长期消费，预收现金流 |
| | 非储值 | 即时消费，验证产品吸引力 |

### 二、目标管理流程（隐藏逻辑）

```
店面总目标（25万）
   │
   ├── 横向拆：顾客来源 ──→ 老客/新客/高客单新客/尾款
   │
   └── 纵向拆：卡种结构 ──→ 储值/非储值
                │
                └──> 合计校验 → 过程追踪 → 完成比复盘 → 滚动至1月目标
```

## 【与科学销售五步法的关联】

| 五步法步骤 | 本图对应环节 | 管理价值 |
|----------|-----------|--------|
| **第一步 定目标** | ✅ 核心对应 | 将模糊的"25万营收"分解为可落地的客户/产品颗粒度 |
| **第二步 找客户** | 部分对应（顾客拆解） | 明确新客/老客各自承担的目标量，指导获客动作 |
| **第三步 建信任** | 弱对应 | 通过新客1314以上、储值卡等指标，倒逼服务体验升级 |
| **第四步 促成交** | 强对应（卡种拆分） | 储值与非储值对应不同成交话术与逼单策略 |
| **第五步 促转介绍** | 弱对应 | 老客续卡目标的达成度，是转介绍漏斗的源头 |

**核心管理价值**：本表是"目标分解+过程管控"的最小作战单元，贯穿五步法的**第1步（定目标）**，并牵引**第2、4步**的执行节奏。

## 【落地应用建议】

### 建议1：建立"双向校验"填写机制
每月1日由店长填写目标，**每周三**由销售复盘完成比；要求"按顾客拆解合计 = 按卡种拆分合计 = 店面总目标"，避免数据脱节。

### 建议2：针对"新客1314以上"设置专项激励
高客单新客是利润引擎，建议单独设立**阶梯奖金**（如达成10单奖励500，15单奖励1500），让目标拆解直接驱动动作。

### 建议3：增加"健康度诊断列"
在原表基础上新增两列：
- **目标置信度**（绿/黄/红）——根据月初前5天日均推算月末达成概率
- **重点动作**——对应未达预期的子项，明确下周1-2个纠偏动作

让此表从"目标记录表"升级为"目标作战指挥表"。
