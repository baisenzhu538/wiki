## 【图片类型】
**清单表（Checklist）**——以两列表格形式呈现目标拆解的7个标准维度及对应举例，属于销售管理中"目标分解"的工具型清单。

---

## 【核心内容】
- 🎯 **这是一套目标拆解的标准维度工具**，帮助管理者将模糊的大目标分解为可衡量、可执行、可追溯的细分指标
- 📊 **涵盖7大拆解维度**：时间、人头、地区、产品、渠道、新增存量、完成单元，构成"5W1H+存量管理"的完整分解框架
- 🔄 **核心逻辑**：任何一个销售目标都可以从这7个维度中的至少2-3个进行交叉拆解，避免目标停留在口号层面
- 💡 **场景适配性强**：从快消品（手机膜）到培训服务（班主任）、从线上（抖音）到线下（门店）均可适用
- ⚠️ **管理价值**：清单化、标准化，让团队对"目标"的理解形成统一语境，减少沟通偏差

---

## 【结构化解析】

### 一、7大维度分类拆解

| 拆解维度 | 拆解本质 | 适用场景 | 举例说明 |
|---------|---------|---------|---------|
| **时间** | When——明确交付节点 | 任何目标都需要时间锚点 | 按年/按月/按日拆解 |
| **人头** | Who——明确责任主体 | 适合需要人盯人的业务 | 销售、班主任、KOL |
| **地区** | Where——明确地理范围 | 适合有区域差异的业务 | 华东、北京、朝阳区 |
| **产品** | What——明确品类范围 | 适合多品类经营 | 充电器、手机膜 |
| **渠道** | Which Channel——明确投放/获客路径 | 适合多渠道获客 | 抖音、京东、天猫 |
| **新增存量** | Customer Type——明确客户类型 | 适合需做客户分层运营 | 新增、存量、复购 |
| **完成单元** | KPI Unit——明确最小核算单位 | 适合需精细化核算的场景 | 门店、直播间、购买链接 |

### 二、组合拆解的典型范式（举例）

| 业务目标 | 组合维度 | 拆解示例 |
|---------|---------|---------|
| Q3手机膜销售目标 | 时间×地区×产品×渠道 | 朝阳区8月通过抖音销售手机膜XX片 |
| 直播间GMV | 时间×人头×完成单元 | 8月主播A在直播间完成XX万元 |
| 客户增长目标 | 时间×地区×新增存量 | 华东区Q3新增客户XX人，复购XX人 |

## 【与科学销售五步法的关联】

### 🔗 对应五步法中的位置：**第二步"客户分析"与第三步"目标制定"之间，以及贯穿第四步"计划制定"全程**

| 五步法阶段 | 本清单的应用价值 |
|-----------|----------------|
| **第1步 客户分析** | "新增存量"维度直接对应客户分层（新增/存量/复购），是客户分析的标准输出 |
| **第2步 价值传递** | "产品""渠道"维度帮助明确价值传递的具体场景与触点 |
| **第3步 目标制定** | ⭐ **本清单的核心应用场景**——任何目标都必须经过这7个维度的拆解才可落地 |
| **第4步 计划制定** | "时间×人头×完成单元"的组合直接生成可执行的行动计划表 |
| **第5步 复盘改进** | 复盘时按这7个维度诊断目标完成差距，快速定位问题所在 |

### 💼 管理价值
- **统一语境**：让管理者与执行者对"目标"的理解同频
- **防漏检**：清单化思维避免遗漏关键拆解维度
- **可量化**：每一条拆解都对应具体的衡量标准
- **可追踪**：每个分解单元都可以独立核算进度

---

## 【落地应用建议】

### ✅ 建议1：在销售目标制定会上强制使用清单做"维度打勾"
每月/每季度目标设定时，要求每个目标必须至少回答以下7个问题中的3个以上，未回答清楚的目标不予立项。例如："华东区8月抖音渠道手机膜销售目标XX万元"——明确回答了时间、地区、渠道、产品4个维度。

### ✅ 建议2：制作团队专属的"目标拆解标准化模板"
将本清单固化为Excel/飞书模板，预设下拉选项（时间、地区、渠道等），要求销售/运营填报目标时按模板填写。模板示例：
```
目标 = [时间] + [地区] + [渠道] + [产品] + [人头] + [完成单元] + [新增/存量]
数值 = XX万元 / XX人 / XX件
```

### ✅ 建议3：在周复盘会上按本清单进行"差距诊断"
当目标未完成时，按7个维度逐一排查：是不是时间节点出了问题？是不是某地区掉队？是不是某渠道没跑通？是不是某产品滞销？帮助团队从"凭感觉找原因"升级为"按维度找根因"。
