## 【核心内容】

- **完整呈现客户从初次接触到最终使用产品的18步决策路径**，每个动作都是客户内心决策的外在表现。
- **红色高亮8个关键里程碑节点**：首次接触（1）→ 第一次接待（4）→ 第二次接待（6）→ 第三次接待（8）→ 第四次接待（10）→ 合同签署（12）→ 系统上线（16）→ 稳定监控（18），构成完整的销售作战地图。
- **典型"拒绝—再激活"的客户旅程**：步骤2名片被丢弃、步骤3拒接电话，体现了销售在前期遭遇的普遍阻力，需要多次触达才能破冰。
- **决策涉及多方角色**：老板（决策者）、财务（建议者）、内部团队（使用者），是典型的B2B多人决策场景。
- **销售周期长且环节复杂**：从首次接触到打款上线，至少需要4次接待拜访 + 内部审批 + 合同签订 + 技术对接，整个过程可能持续数周甚至数月。

## 【结构化解析】

### 一、客户决策阶段划分（按销售漏斗层级）

| 阶段 | 对应步骤 | 客户心理状态 | 销售任务 |
|------|---------|------------|---------|
| **认知阶段** | 1-3 | 抵触、抗拒、觉得没必要 | 想尽办法突破防线，争取面谈机会 |
| **兴趣阶段** | 4-6 | 了解一下、随便听听 | 用定制化方案激发兴趣 |
| **评估阶段** | 7-9 | 内部讨论、对比价格 | 推动内部审批，加速决策 |
| **决策阶段** | 10-14 | 条件谈判、合同签订 | 锁定条款，签单打款 |
| **落地阶段** | 15-18 | 系统对接、稳定使用 | 确保交付，提升续约率 |

### 二、关键触点解读（红色高亮8节点）

| 节点 | 触点类型 | 销售动作要点 |
|------|---------|-------------|
| **第1次** | 初次接触 | 留下良好第一印象，争取二次见面机会 |
| **第4次接触（第一次接待）** | 标准产品讲解 | 介绍公司+产品，建立信任 |
| **第6次接触（第二次接待）** | 定制化方案 | 针对客户痛点提出差异化方案 |
| **第8次接触（第三次接待）** | 价格谈判 | 探讨价格政策，确定意向 |
| **第10次接触（第四次接待）** | 条件确认 | 锁定合作条件细节 |
| **第12次 合同签订** | 法律承诺 | 远程签署法律文件 |
| **第16次 系统上线** | 技术交付 | 安排系统正式上线 |
| **第18次 稳定监控** | 服务闭环 | 监控稳定性，为续约/转介绍铺垫 |

## 【与科学销售五步法的关联】

> 科学销售五步法：**第一步 找对人 → 第二步 找痛点 → 第三步 给方案 → 第四步 推成交 → 第五步 做服务**

| 五步法 | 对应图中节点 | 管理价值 |
|--------|------------|---------|
| **第一步 找对人** | 步骤1-3（识别KPIC） | 揭示"名片被扔、拒接电话"的真实场景，提醒销售必须进行**关键人识别**，找到真正的决策影响者 |
| **第二步 找痛点** | 步骤4-5（第一次接待） | 第一次接待的核心任务不是讲产品，而是**深度挖掘客户痛点**，为定制化方案做准备 |
| **第三步 给方案** | 步骤6-7（第二次接待） | 用定制化方案激发客户兴趣，是**价值呈现**的关键时刻，直接决定客户是否进入评估阶段 |
| **第四步 推成交** | 步骤8-14（谈判到打款） | 涵盖价格谈判、内部审批、合同签订、打款，是**推动决策**的核心战场，需识别多方决策角色 |
| **第五步 做服务** | 步骤15-18（上线到稳定监控） | 技术交付和稳定性监控是**售后服务**的开始，关乎续约率与转介绍率，体现"LTV客户终身价值" |

**全流程贯穿价值：** 该图不仅是一个客户的成交案例，更是一个**标准成交漏斗（SOP）模板**，可以复用到所有B2B复杂销售场景中。

## 【落地应用建议】

### 🛠️ 建议一：绘制本行业的"客户决策路径图"
组织销售团队按本图模板，绘制各自负责客户类型的决策路径图，标注出3-5个**关键触点**和对应的销售动作，形成团队的**标准化作战手册（SOP）**。

### 🛠️ 建议二：建立"红色节点"预警机制
在CRM系统中为图中8个关键里程碑设置**阶段提醒和责任到人**，每到达一个红色节点，要求销售填写：
- 客户此阶段的核心顾虑是什么？
- 下一步推进的关键动作是什么？
- 需要哪些资源支持？

### 🛠️ 建议三：针对多方决策角色制定"角色作战卡"
根据路径图中财务、老板、技术团队的不同角色，制作**差异化沟通话术卡**：
- 对老板：讲ROI、商业价值
- 对财务：讲账期、风险、合规
- 对技术：讲对接成本、稳定性

让销售在每个角色面前都能提供**精准价值主张**，加速决策闭环。
