# 销售武器库-六维雷达图-详解

【OCR原文】

这6个不同的维度分别是什么，我快速地介绍一下。

1. 公司有实力：让销售在介绍公司介绍产品的时候，能凸显公司产品的实力。
2. 话术说人话：让销售在跟用户打交道的各个环节，有说人话的沟通语言。
3. 服务很专业：让销售在展示提供交付材料的时候，能充分展示公司专业性。
4. 销售有能力：让销售想提高专业性和销售技能时，可以自我学习和成长。
5. 团队有效率：让销售得到工具或者内部人力支持，提高团队整体销售效率。
6. 攻坚有策略：让销售面对不同阶段不同类型客户，都有应对的策略和方法。

【核心内容】
- 本图介绍销售赋能/销售团队建设的 **6个核心维度**，每个维度对应一个具体的销售场景痛点。
- 6个维度依次覆盖：**公司实力呈现、沟通话术、交付材料专业性、销售个人能力、团队支持、不同类型客户的攻坚策略**。
- 采用"**让销售……**"的句式结构，强调每个维度的赋能对象和价值结果。
- 关键词以红色突出（**实力、说人话、专业、能力、有效率、策略**），其余文字以深灰色弱化，形成视觉层次。
- 6个维度从"**外部形象→内部能力→外部客户应对**"形成一个完整的销售赋能闭环。

【与科学销售五步法的关联】

科学销售五步法通常指：**客户开发 → 需求探询 → 方案呈现 → 异议处理 → 促成签约**（不同流派略有差异）。

这张图整体属于 **销售赋能体系**（Sales Enablement）模块，是五步法落地的底层支撑系统，具体关联如下：

| 五步法环节 | 对应的赋能维度 | 关联说明 |
|-----------|--------------|---------|
| 客户开发（开发信/陌拜/转介绍） | 维度2（话术）、维度6（策略） | 开发客户需要"说人话的开口话术"和"对不同类型客户的接触策略" |
| 需求探询（SPIN/提问） | 维度2（话术）、维度4（能力） | 探询需要专业提问技巧，属于销售能力训练范畴 |
| 方案呈现/产品介绍 | 维度1（实力）、维度3（专业） | 介绍公司和产品需要"凸显实力"的素材，展示方案需要"专业交付材料" |
| 异议处理 | 维度2（话术）、维度6（策略） | 异议应对依赖沟通话术库与差异化策略 |
| 促成签约 | 维度5（团队）、维度6（策略） | 临门一脚需要团队资源支撑和针对性攻坚策略 |

**管理价值：**
1. **系统化诊断工具**：6个维度可作为"销售团队成熟度评估模型"，对团队各维度打分定位短板。
2. **赋能体系完整性**：覆盖了"形象-话术-交付-能力-团队-战术"全链路，避免单点培训。
3. **与五步法互为表里**：五步法是"做事的流程"，6维度是"做事的能力底座"。

【落地应用建议】

**建议一：用6维度做销售团队诊断（1-2天内可完成）**

- 制作一份《销售能力6维度自评问卷》，每个维度下设3-5个具体问题（例：维度2话术——"开场白是否有标准化话术？"、"异议处理是否有FAQ？"）。
- 组织每位销售、每位主管进行**自评 + 他评**，形成6维度雷达图。
- 对得分最低的2个维度作为Q季度的重点赋能对象。

**建议二：按6维度搭建销售赋能知识库（1-2周）**

- 在企业内网/飞书/钉钉中建立6个文件夹：①公司实力素材库（奖项、案例、数据）；②话术库（按场景：开场/跟进/异议/逼单）；③专业交付包（方案模板、产品手册）；④学习地图（书籍、课程、认证）；⑤团队资源目录（设计、售前、SDR支持清单）；⑥攻坚策略库（按行业/客户规模/角色）。
- 每个维度指定1名**内容官**负责每周更新，避免变成"僵尸库"。

**建议三：将6维度嵌入销售管理晨会/复盘SOP（当日即可执行）**

- 晨会5分钟：主管每日随机选1个维度提问（如"今天用到了哪个维度的话术？"）。
- 周复盘30分钟：用6维度检视本周客户推进卡点，定位"哪一维度的能力缺失导致了丢单"。
- 形成闭环：**诊断 → 补短板 → 案例沉淀 → 回到知识库**。
