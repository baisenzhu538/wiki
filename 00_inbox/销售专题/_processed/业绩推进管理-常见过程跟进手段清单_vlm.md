【核心内容】
- 销售过程跟进手段分为两大维度：**文件类（6项）** 和 **制度类（5项）**，合计11种常见手段
- 文件类聚焦于"书面化、数据化"的跟踪，覆盖日报/周报/重点客户/个性化数据/目标分析/Pipeline六大场景
- 制度类聚焦于"会议化、互动化"的跟进，覆盖日会/周会/脑暴/培训/分享五种会议形态
- 文件解决"看得清"，制度解决"动起来"，二者配合形成完整的销售过程管理体系

【与科学销售五步法的关联】

本图主要服务于**第二步：诊断现状** 与 **第三步：制定方案** 之间的"过程管理"环节，具体关联如下：

| 五步法阶段 | 对应关联 |
|------------|----------|
| L1 探寻需求 | 文件2/3、 制度4 培训会 → 提升客户洞察能力 |
| L2 诊断问题 | 文件5 目标完成情况分析模板 → 差距诊断 |
| L3 方案呈现 | 制度3 脑暴会 → 集中共创方案 |
| L4 谈判成交 | 文件1/4/6 + 制度1/2 → 过程跟进、临门一脚 |
| L5 持续经营 | 制度5 分享会 → 经验沉淀与客户长期经营 |

**管理价值**：
- 提供一套"文件 + 制度"双轮驱动的过程跟进工具箱，避免管理者"拍脑袋"式管理
- 帮助销售管理者从"只看结果"转向"过程管控"，让业绩达成可拆解、可追踪、可干预
- 解决团队执行力参差不齐的问题：通过统一模板和会议节奏，标准化优秀销售的行为

---

【落地应用建议】

1. **【文件落地三件套】** 立即配置日报、Pipeline跟进模板、目标分析模板三项基础工具：
   - 日报：明确"今日拜访客户/跟进事项/明日计划/需支持"四要素
   - Pipeline模板：包含客户名、阶段、金额、概率、下一步动作、责任人
   - 目标分析模板：用"目标-现状-差距-原因-措施-责任人-时间"七要素诊断

2. **【会议制度化】** 建立"日清日结、周清周结"节奏：
   - 日会控制在15分钟内，每人3句话说清进展和卡点
   - 周会60分钟，复盘Pipeline变化 + 重点客户集体会诊
   - 每月至少1次脑暴会，集中攻关TOP3大单

3. **【分层使用，避免形式主义】**
   - 初级销售多用日报 + 周会，养成过程习惯
   - 资深/大客户销售用个性化数据跟踪表 + 脑暴会，聚焦关键商机
   - 管理者重点使用目标分析模板，定期诊断团队健康度，防止"表格满天飞但问题没解决"
