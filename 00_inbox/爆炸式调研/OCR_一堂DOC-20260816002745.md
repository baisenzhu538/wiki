```markdown
## 2. 二级分类展开

在每个一级分类下，统一按入门必会 → 进阶实操 → 内行心法三个台阶再切。这样切的理由：同一类法则的**学习难度**和**使用频率**差异极大——比如同样是视觉法则，"对齐"新人三天就能用对，而"版面牵控"需要看过大量作品才能有手感。不切的话，新人会把高阶法则当入门法则硬学，或者把入门法则当高阶法则轻视，两头都错。

### A. 视觉法则（好看）

- 分类逻辑：本类内部按"从单个元素 → 元素组合 → 整页气质"的颗粒度递进，而不是按"配色/排版/字体"这种素材维度切——因为新手最容易在素材维度里迷失，而按操作颗粒度学，每一级都能立刻上手
```

## 段2 ✅

上手。

- 为什么还要再切：若只停在一级，新人会把"对比"（单个元素的事）和"版面率"（整页气质的事）当成同一难度。再切之后，A1 练的是"单个元素摆对"，A2 练的是"元素之间的主次"，A3 练的是"整页的阅读动线与气质"，三层各自独立可练。

## A1. 入门必会

- 从哪来：从 CRAP 四大基本功（对比/重复/对齐/亲密性）和留白基础中抽出，是任何界面"看起来专业"的最低门槛。
- 它管什么：只回答"单个或一组元素怎么摆才不丑"；不管整页气质（那是 A3 的事）。

## 段3 ✅

```markdown
- 为何必须独立：若并入 A2，新人会跳过最基础的"对齐和亲密"，直接去学配色主次，地基不牢，后面全歪。

## A2. 进阶实操

- 从哪来：从视觉层级研究、WCAG 对比度标准、字体排版规则中抽出。
- 它管什么：回答"元素之间的主次关系怎么建立"——大小、颜色、字体、比例怎么协同。
- 为何必须独立：若并入 A1，会丢失"对比达标"这种有客观数字的硬标准——它是独立做产品时躲不掉的验收项。
```

## 段4 ✅

```markdown
**A3. 内行心法**

- **从哪来**：从浏览行为研究（F 型/Z 型）和版面设计理论中抽出。
- **它管什么**：回答"整页的视线路径和气质"——用户眼睛怎么走、页面给人什么感觉。
- **为何必须独立**：若并入 A2，会把"单个元素主次"和"整页动线"混为一谈——动线需要大量作品积累才有手感，必须单独练。

### B. 认知法则（好懂）

- **分类逻辑**：本类内部按"理解成本从直觉到科学"递进：B1 是用户天生就会的直觉（格式塔基础），B2 是需要刻意观察才能发现的机制，B3 是隐藏在长流程中的心理学效应。
```

## 段5 ✅

- 为什么要再切：若不切，新人会把"峰终法则"和"接近成组"当成同一难度，导致在入门阶段就去研究长流程心理效应，得不偿失。

## B1. 入门必会

- 从哪来：从格式塔原理的核心条目和功能可见性研究中抽出。
- 它管什么：回答"用户第一眼怎么把信息自动分组、认领"。
- 为何必须独立：这是人类视觉的本能，每条都能立刻在任意 App 上验证，是建立"设计直觉"最快的入口。
