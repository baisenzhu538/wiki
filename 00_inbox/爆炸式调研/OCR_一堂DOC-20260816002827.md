# 🏠 A 组·视觉法则｜管"好看"（外墙装修）

◆ **价值**（它为什么重要）：用户看到产品的第一眼，0.5 秒内就在心里打了分。**视觉不过关，后面内容再好，用户也没耐心看到。视觉是入场券。**

◆ **边界**（它管什么、不管什么）：只回答"怎么排、怎么配色、怎么留白才美"；**不管**"用户懂不懂这个按钮是干嘛的"（那是 B 组）、**不管**"点了有没有反应"（那是 C 组）。**A 组的失职是"丑"，不是"难用"。**

◆ **为什么这么分组**（内部按操作颗粒度切三档）：

- 入门必会（A1）：单个元素怎么摆不丑——对齐、对比、亲密、留白。**新人第一天就能用**，改完立竿

## 段2 ✅

见影。

- **进阶实操（A2）：** 元素之间的主次怎么建立——大小、色彩、字体、对比度。需要一点审美积累。
- **内行心法（A3）：** 整页的视线路径和气质——F型/Z型、版面率。没有大量看图经验，手感出不来，所以放最后。

◆ **关键原则（重点提 3 条）：**

- **对齐秩序：** 所有元素沿同一条隐形线排，整齐=专业感的最快来源（场景化：一页里三个模块各对各的，用户视线像跳格子）。
- **强烈对比：** 重点元素要"跳"出来，弱对比不是对比是冲突。
