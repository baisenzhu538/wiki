## 二、知识体系核心结构

### 2.1 主模型：复盘冰山图（五层深度）

```
冰山上（相对容易）
  ├── 第1层 主观感受 → 从不复盘到复盘的飞跃。可以主观，但必须面向未来。
  ├── 第2层 客观事实 → 从观点到事实的飞跃。真实发生、有细节、有数据。
冰山下（越来越难）
  ├── 第3层 背后原因 → 从现象到原因的飞跃。剥洋葱式追问为什么。
  ├── 第4层 底层模型 → 从具体到迁移的飞跃。总结KSF/SOP/N步法/雷达图。
  └── 第5层 能力建设 → 从事到人的飞跃。团队基本功、组织能力。
```

> 五层递进口诀：不复盘→主观感受→客观事实→背后原因→底层模型→能力建设

### 2.2 场景选择：四象限复盘法

| | **决策类（把事做对）** | **执行类（把事做稳）** |
|---|---|---|
| **失败/负向** | 归因 + 提出新假设 | Case Study + 安全机制 |
| **成功/正向** | KSF 关键成功要素提炼 | 固化流程 + SOP |

> 核心原则：不要跑偏——决策类的事别只复盘执行细节，执行类的事别硬套策略框架。

### 2.3 概念网络

```
复盘本质 = 基于过去真实经验的面向未来的学习手段
  ├── 三要素：真实经验 + 面向未来 + 学习提升
  ├── 场景原则：小事及时复盘、大事阶段性复盘、事后全面复盘
  ├── 常见误区（9宗罪）
  │   ├── 意识不够：不做、不信、不求
  │   ├── 姿势不对：不真、不实、不懂
  │   └── 深度不够：不透、不全、不改
  ├── 团队培养四阶段
  │   ├── 以身作则：反向汇报、及时复盘、充分重视
  │   ├── 挂在嘴边：引导分析、沉淀资产、引导行动
  │   ├── 提出要求：强制flag、Before-After复盘、3分钟复盘
  │   └── 做出流程：固定例会复盘、关键项目复盘、模板复盘
  ├── 产出物类型
  │   ├── KSF 关键成功要素
  │   ├── 雷达图（评估维度的全面性）
  │   ├── N步法（做事的步骤框架）
  │   ├── 执行清单
  │   └── 完整SOP
  └── 关联工具
      ├── 一堂五步法（商业策略复盘）
      ├── 动力阻力模型（转化率归因）
      ├── 单元模型（经营效率归因）
      ├── 项目管理链条（执行类复盘）
      └── Before-After对比法（个人刻意练习）
```

## 五、给王语嫣的特别提醒

### 1. 概念命名统一（最重要！）
笔记中使用了一套术语体系，口述稿中有所出入。建议以笔记为准统一：
- "冰山图" = 复盘五层深度模型
- "四象限" = 决策×执行×成功×失败矩阵
- "9宗罪" = 复盘常见误区
- "12策略" = 团队培养四阶段下的具体方法论

### 2. 难度梯度建议
- **入门**：冰山图前3层 + 四象限基本用法 → A1+A2
- **进阶级**：第4层模型层 + Before-After + 12策略 → A4+A5+B档
- **高阶**：第5层能力建设 + 深度案例 → C档

### 3. 最高ROI产出标记
- **A1 冰山图**：学员拿到就能用的自检工具——"我的复盘到第几层了？"
- **A4 团队培养四阶段**：管理者可以直接对照执行
- **C1 一堂创业复盘**：叙事性强，适合做公众号/视频内容引流

### 4. 独特价值定位
这节课在一堂体系中的定位是**管自己**体系的基石——它是个人成长的"元能力"（复盘能力决定所有其他能力的学习效率）。建议在知识卡片开头标注与刻意练习、知识管理、项目管理等课程的关系链接。
