## 执行方式

1. 欧阳锋审签本清单（确认"改/摘/例外"判定）
2. 黄药师按清单批量执行：

3. 执行后 `kdo_lint --baseline` 更新基线
4. 预期：ocr-* BROKEN LINK 从 770 → 0

## 风险提示

- "摘"操作只是从 related 列表移除死链，**不删除源卡正文中可能存在的内联 wikilink**。正文 wikilink 需另行 grep 处理（如正文中有 `[[ocr-*]]` 则同样会触发 BROKEN LINK）。
- 建议执行为 `backlink_fixer` 式 dry-run → diff 确认 → apply 流程。
