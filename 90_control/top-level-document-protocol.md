# KDO 顶层文档规范 v1.0

> 把 Truman「顶层文档」暗知识制度化为 KDO 可执行规范。素材锚点：战略笃定口述（L618-620「我先打开了最顶层文档」、L1620「反复跟你们说要建顶层文档」）+ 楚门口述（L648-710，`tool-top-level-document` 卡引用）。
> 生效链：欧阳锋终审 ✅ → 老朱拍板 ✅ → v1.0 已生效（2026-08-30）。v1.0 已生效（老朱 2026-08-30 拍板）。

## 1. 目的与定位

老朱直指 KDO「有 charter（角色规则），但无『每项目唯一入口 + 必知必会 + 索引一切』」。顶层文档 = 每个独立项目/域/复杂课题的**唯一入口文档**——解决什么问题、背景目标、参与方、关键文档、思考讨论，从顶层文档能索引出所有东西。金句：「知识不在于某一个人的脑子里，也不靠大家的口头交接；重要的事儿都有入口，关键的材料都有位置」。

**KDO 现状**：域级已有雏形（`90_control/domain-mapping.md` 域挂接、`30_wiki/domains/design-moc.md` 域索引、`90_control/infrastructure-inventory.md` 基建总表），但无「每项目有且只有一个顶层文档」的成文制度——新项目开不开入口、开成什么样，全靠自觉。本规范把雏形升级为制度。

## 2. 适用范围

| 适用（必须开顶层文档） | 豁免（不需要） |
|:--|:--|
| 知识域 / 产品线 / 业务线 | 一次性小任务（当天做完） |
| 复杂项目（多阶段/多依赖） | 个人速记 / 随手笔记 |
| 专项工程（基建专题、调研专题） | 纯事务、无推导的任务 |

## 3. 规范条款（立项即开）

1. **有且只有一个**：一个项目/域一个顶层文档，禁止多入口（楚门口述 L664）。
2. **立项即开**：先写顶层文档再开工（楚门口述 L710「我们所有的训练营、公开课、产品设计、大活动，要想做先做这份文档」），不是做完再补。
3. **必知必会放最前**：解决什么问题、为什么做，放文档最前面（楚门口述 L686「最大的必知必会放在前」）。
4. **五段结构**：背景目标 / 参与方 / 关键文档 / 思考讨论 / 索引——五段缺一不可（模板见 §5）。
5. **索引一切**：项目进展中所有关键材料都从顶层文档可达；项目动 → 顶层文档跟着动。
6. **没有就问责**：项目缺顶层文档，问责负责人（楚门口述 L694「没有就骂那个负责人」）。
7. **命名规范**：四字开头「顶层文档-XXX」或 KDO 约定命名（见 §4 映射）；命名/版本/时间戳走《文件流转规范》。

## 4. KDO 命名映射（顶层文档在各层的落点）

| 层 | 顶层文档形态 | 现有实例 |
|:--|:--|:--|
| 知识域 | 域 digest / 域索引卡（`30_wiki/domains/` 或 concepts） | `design-moc` |
| 域挂接 | `domain-mapping.md`（域↔卡挂接总表） | `90_control/domain-mapping.md` |
| 基建 | `infrastructure-inventory.md`（基建总表） | `90_control/infrastructure-inventory.md` |
| 项目/专题 | 顶层文档（立项即开，用 §5 模板） | 本规范落地后新项目启用 |

## 5. 模板（复制即用）

```markdown
# 顶层文档-<项目名>

> 解决什么问题（必知必会，放最前）

## 背景与目标
- 为什么做 / 要达成什么 / 不做什么

## 参与方
- 负责人 / 协作角色 / 对接人

## 关键文档
- 指向项目内所有关键材料（链接/路径）

## 思考与讨论
- 过程中的关键决策 / 分歧 / 待定

## 索引
- 从本文件能索引出的所有东西
```

## 6. 与其它规范/知识的关系

- `tool-top-level-document`：本规范的方法论来源卡（顶层文档 5 步 + 制度强化）。
- 《KDO 文件流转规范》：顶层文档是「资产文件」，命名/版本/时间戳走该规范。
- 《KDO 编号依赖规范》：顶层文档统揽编号体系（顶层文档=入口，编号=地图，见 `dk-doc-numbering-business-logic`）。
- `concept-session-vs-memory-vs-document`：顶层文档=文档层级入口，不依赖口头交接。

## 7. 生效规则

- 欧阳锋终审 + 老朱拍板后 v1.0 生效。
- **向前生效**：存量域已有多入口的不回头改；新项目/新域一律立项即开顶层文档。
