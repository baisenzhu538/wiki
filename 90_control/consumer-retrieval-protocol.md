# 消费端检索协议 v1（任何 agent 进库必守）

> 王语嫣裁定 2026-08-25（盲测报告+小昭消费端实况双证据链）。适用对象：一切消费本库知识的 agent——工厂角色、外部协作 agent（小昭类）、未来新接入的任何工具实例（#525 工具接入契约引用本文件）。
> 入口承诺：新 agent 进库，读本文件+`AGENTS.md` 即知道「用什么工具、按什么纪律检索」。

## 四条纪律

1. **语义检索优先**：域知识问题先走 `kdo_search`（GraphRAG+BM25+MOC 语义层），grep/glob 是补充不是首选。实证：同一问法 grep 漏掉周期表框架卡、kdo_search 命中——字面检索天然漏「语义相关但字面不中」的卡。
2. **名词实体核查**：回答域知识问题前，把答案里的专有名词/大词逐个当实体查一遍（「这个词是不是库里一张卡？」）。防「类比遮蔽检索」——比喻带来「已理解」错觉，跳过实体验证（dk-analogy-blinds-search）。
3. **结果看 status**：`status: draft`/`pending_review` 的卡带 ⚠️ 不得当定论引用（#524 已机器标注）；引用前确认 reviewed 或注明「草稿待审」。
4. **verified 一任务一回填**：实际用了未验证条目，随手补 verified+evidence（实测/引用/推演三级），不专项回填（盲测报告建议 5）。
5. **负向断言双核查**（v1.1，2026-08-26 小昭 ADUCIT 事件+王语嫣半截核查双教训）：说「库里没有 X」之前，必须做完两步——①内容级全库搜（含 00_inbox，主题词/别称/ASR 变体都试，不能只搜文件名和 src id）；②`check-source-refs.py` 查死引（原稿可能在 inbox 未归档，src id 可能是虚空）。两步都做完还找不到，才允许断言「缺失」或向老朱索要。「我没看到」≠「不存在」（#433）。
