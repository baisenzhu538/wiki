# tags 词表设计 v0.3 正式稿（#426 词表设计节）

> 老朱 2026-08-23 确认方向：**五维标注框架 + 双原则 + 颗粒度业务强绑定**——词表不是固定清单，是维度框架+增长原则。v0.1「≤5 个短词」原则正式废止（v0.2 修正预告兑现）。

## 一、三条总纲（老朱确认的方向）

1. **五维标注框架**：每域按业务定义维度轴（半肥猫五层：专业/风控/话术/视觉/经验为参照系），同一对象多轴打标——「细」=维度细，不是词多
2. **双原则**（增长引擎，替代固定词表上限）：**知识不够→加卡片；索引不到→加标签**——词表是活的，随业务长
3. **颗粒度业务强绑定**：没有通用标准（半肥猫 29 字段=营销增长实测）——每域自测出自己的维度轴与颗粒度

## 二、KDO 适配（维度框架思想的落地，不照搬半肥猫五维）

| 半肥猫五维 | KDO 既有承载 | KDO 适配口径 |
|:--|:--|:--|
| 专业维度 | domain + difficulty + 正文 | tags 补对象词+性质词（域受控词表） |
| 平台风控 | Critique 节 + discoverable_by | tags 补边界警示词（如 认知偏差） |
| 受众话术 | tags: audience:* | 按 audience 轴细分（manager/executor/beginner…） |
| 视觉维度 | （KDO 文字库少用） | 可选轴，图文卡启用 |
| 经验边界 | dk/case 卡 + discoverable_by | 经验词入 tags（如 避坑/实操/踩坑实录） |

**不变纪律**（v0.1 保留有效的两条）：判断/质量类信息走字段（quality_labels/status/confidence，不进 tags）；来源名/课程名禁入 tags（source_refs 唯一归宿）——半肥猫「理论上越多越好但也不是太多」+「卡片=YAML 给 AI+正文给人」同构印证。


### 词量口径分卡型（2026-08-24 王语嫣裁定 #498）

- **普通卡**（concept/framework/case/tool 等）：每卡 5-8 个跨轴词
- **dk 暗知识卡**：豁免 5-8 词标准，改 **1-3 词**但**核心维度必须覆盖**（认知警示轴/方法轴/场景轴——Agent 检索场景词的命中面）
- 词仍须在轴内 + 匹配正文（豁免是"覆盖核心维度后的实际量"，不是降标）

## 三、分域实施规则

- **【轴文件先行 · 硬纪律 #485】**：任何域未出轴文件前，该域**不得进入 #426 治理队列**（gate 化）。轴文件是治理批次的前置必写件，不是随用随补——治理域缺轴=放量堵点（content 域 12 张空缺卡数小时实证），生产者「无词表不动手」的对称面是编排侧「无轴不排域」。治理前先查 `90_control/tags-vocab/<domain>.yaml` 是否存在，不存在先建轴（王语嫣起草→老朱/欧阳锋拍板），再排治理批次。黄药师工具支撑：pre-submit / full-library-rescan 侧加「域空缺治理前置检查」（该域轴文件存在才允许批次提审）
- 每域一张**维度轴定义文件**：`90_control/tags-vocab/<domain>.yaml`（轴名/每轴受控词/同义词归并映射/颗粒度说明）——王语嫣按域起草、老顽童试点反馈、欧阳锋批次验收、老朱终稿
- 现有 tags 治理迁移：课程名/长短语按映射表清洗（v0.1 迁移规则保留）
- 索引不到的标签需求（使用中发现）→ 加词进域词表（双原则的日常动作，域 digest 评审）

## 四、试点批（首批=决策域）

决策域维度轴（判断类卡五维 KDO 版）：
1. **决策模型轴**（专业）：科学决策/五步法/单元模型/决策画布…
2. **认知警示轴**（风控）：认知偏差/幸存者偏差/沉没成本…
3. **使用者轴**（受众）：决策者/执行者/教练…
4. **场景轴**（对象）：定价/取舍/止损/进入退出…
5. **经验轴**（隐性）：避坑/踩坑实录/实操口径/边界案例…

首批 50 张（决策域 ~100 张池的前半）：老顽童按轴治理→欧阳锋批次验收（抽维度覆盖+迁移映射正确）→PASS 后放量其余域。

## 五、验收与收官

- 试点 PASS → 按域放量（每域轴文件先行）
- 收官：全库 tags 判断类复扫归零（full-library-rescan.py 输出，#399 纪律）+ 各域维度轴文件落 90_control/tags-vocab/
- 长效：双原则入域 digest（增长维护口径）
