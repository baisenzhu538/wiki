## 思维盲点

1. **初版族清单靠"kdo query+印象"凑，没用 source_refs 全量枚举**——为什么漏掉：把"MOC 先行"理解成"检索到主干卡就行"，没理解成"分母必须穷举"。追问到底：W8 牌只要求"找 MOC 再回答"，但族清单是分母型断言，分母型断言的核查方法必须是枚举法不是抽样法。
2. **负向判词台账只核了判词本身，没核判词的分母**——"族内 0 命中"的"族内"是 16 卡的族，不是 25 卡的族。为什么漏掉：宪法第二条只教我"负向判词附锚"，没教我"先验证锚的分母"。本次终审把这条补进了我的操作规程。

## 顿悟

**存在性核查是两层结构：判词层 + 分母层。** "X 在族内 0 命中"= 判词；"族=这 16 张卡"= 分母。初版我只给判词附了锚（grep 记录），分母是抽样凑的——欧阳锋一层 grep 就把分母证伪，判词连锁塌了 2 条。以后凡"族内/域内/库内 0 命中"型判词，先跑全量枚举确定分母，再下判词；枚举命令本身写进检索记录节。
