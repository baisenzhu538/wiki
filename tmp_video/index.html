CLI 设计哲学

本地优先 + 命令行驱动 = 极速工作流

kdo init

一键初始化工作目录

创建 10_inbox · 20_processing · 30_concepts · 40_outputs

kdo compile

编译原材料为中间件

笔记 → 概念卡 · 截图 → 方法卡

kdo produce

中间件组装为成品

概念卡 + 方法卡 → 文章 / 视频脚本

kdo deliver

验证 + 输出 + 分发

QA检查 → 多格式输出 → 飞书/公众号/YouTube
