# 教练式领导力·微笑沟通段位清单
## Coaching Leadership: Smile Communication Tiered Checklist

| 重点能力 | 段位提升 | 练习目标 | 技巧Tips | 使用例句 |
|---------|---------|---------|---------|---------|
| 🎧 **倾听**<br>Listening | **初阶：**<br>做到"**听见**" | 克服"听自己说话"的冲动，把注意力放在对方身上 | • 眼神注视，身体前倾<br>• 不打断、不急于回应<br>• 复述对方关键内容 | • "你刚刚说到 xxx，可以再多讲一点吗？"<br>• "我听到你说……，这对你来说很重要，对吗？"<br>• "我理解你刚才提到的重点是……我理解对吗？"<br>• "你刚才提到压力'，是指工作量还是期望不清？"<br>• "我想确认一下，我的理解是……" |
| | **中阶：**<br>听出"**情绪**"与"**模式**" | 从言语背后捕捉情绪信号，帮助对方更好觉察 | • 关注语气、表情、停顿<br>• 用简短回应共情<br>• 重复关键词，引导深入 | • "听起来你对这个决定有点犹豫，是吗？"<br>• "当你说又是我的时候，似乎带着点委屈？"<br>• "这已经不是第一次你提到这个问题了。"<br>• "我注意到你讲到这件事时，语气特别平静，这是刻意的吗？"<br>• "这件事让你最不舒服的地方是什么？" |
| | **高阶：**<br>听出"**核心议题**" | 把对话从问题带向更深的觉察或动机 | • 不急于解决，先深入问题底层<br>• 揭示重复模式或对话盲点<br>• 提出"听见没说出口"的内容做镜像 | • "我听到你在描述很多外在的挑战，但你真正担心的是什么？"<br>• "你说'没办法'，这三个字里有点无力感，我说得准吗？"<br>• "你总说自己跟不上节奏，这是不是一种自我定义？"<br>• "这背后，是不是还有一层你没说出[?]的期待？"<br>• "如果你放下这件事，你会担心发生什么呢？" |
| ❓ **提问**<br>Questioning | **初阶：**<br>**开放问题**替代**封闭问题** | 让对话更多围绕对方的思考，而不是你想听的答案 | • 避免"是不是""有没有"<br>• 用"什么""怎么"开头<br>• 一次只问一个问题 | • "你现在最希望解决的问题是什么？"<br>• "你已经试过哪些方法？"<br>• "你还有哪些可能的选择？"<br>• "你最担心的结果是什么？"<br>• "你觉得这个问题出[?]在什么地方？" |
| | **中阶：**<br>帮助**聚焦**和**澄清** | 帮助对方厘清问题结构、定义清楚优先级 | • 追问概念模糊处（例如"很多"、"感觉"）<br>• 对齐目标/标准/时间线<br>• 引导从情绪转向行动 | • "你说'大家都[?]有点情绪'，你指的是谁？具体是怎样的情绪？"<br>• "你现在最需要我们专注在哪一件事上？"<br>• "在你心中，成功的标准是？"<br>• "这件事重要是因为？"<br>• "如果我们今天就要决定，你希望怎么做？" |
| | **高阶：**<br>激发**内在动机**与**觉察** | 让对方找到"为什么这事对我重要"，从而启动改变 | • 探索价值观与身份认同<br>• 引导自我评价/审视盲点<br>• 设置"情景反转"做思维挑战 | • "你之所以在意这件事，是因为它和你什么样的期待有关？"<br>• "这件事如果换作你是老板，你会怎么思考？"<br>• "你过去有没有类似经历？你怎么克服的？"<br>• "这个决定符合你未来3年想成为的人吗？"<br>• "你对现在的状态打几分？差距在哪里？" |
| 📢 **反馈**<br>Feedback | **初阶：**<br>**表达观察**+**正向评价** | 让对方明确知道自己哪做得好 | • 明确行为而非人格<br>• 使用"我观察到…"、"我欣赏…"<br>• 及时给出反馈、不堆积 | • "我看到你今天提前准备了客户资料，这点让我印象深刻。"<br>• "你的表达非常清晰，我特别喜欢你总结时的结构感。"<br>• "这次你主动承担的态度很棒！"<br>• "你在会议中没有打断别人，这是一个非常好的倾听示范。"<br>• "我觉得你正在往'团队合作者'的角色更进一步。" |
| | **中阶：**<br>提出**具体建议** | 帮助对方看到成长空间，同时保有尊重 | • 反馈+建议结构：行为+影响+期望<br>• 鼓励改进，不做裁判<br>• 不要一上来就"你哪里错了" | • "你在表达观点时跳得有点快，我担心听众跟不上，你可以试试用例子。"<br>• "我注意到你在会议上几乎没有发言，你怎么看自己参与感？"<br>• "你的文案很完整，下一步可以加强视觉上的引导感。"<br>• "这个项目最后两天进度有点赶，也许我们可以提前复盘风险？"<br>• "你讲方案讲得很好，如果加上开头的用户痛点，会更有说服力。" |
| | **高阶：**<br>激发**自我反馈**与**反思** | 培养"自己觉察、自己改进"的能力 | • 多问"你觉得呢？"、"你自己怎么评估？"<br>• 给出可能的角度，但不代替判断<br>• 鼓励自我总结下一步 | • "你对自己的表现打几分？你觉得还能提升哪些地方？"<br>• "你回头看这件事，有什么你会想做得不一样？"<br>• "听完反馈，你打算怎么处理这些建议？"<br>• "你对这次的状态满意吗？为什么？"<br>• "你觉得下一次，要怎么做才会更好？" |
