# A同学：启动会的对比

## Before：之前的理解

1. **多拉人**：确认参加人员。
2. **讲目标**：介绍项目目标。
3. **拆项目**：同步项目里程碑。
4. **拆角色**：划分角色与职责。
5. **读需求**：阅读需求管理计划。

## After：具体的流程

**设计关键流程：**

1. **准备文档**：提前准备文档，并把分工、风险提前写明白。
2. **快速破冰**：项目组快速破冰，让大家彼此熟悉，重点角色当面夸一夸。
3. **现场确认**：现场不止宣讲，还要跟大家当面认真确认一遍。
4. **会议沉淀**：把会议的关键结论、关键共识和任务，都记录下来。

**提升效率要点：**

1. **会前阅读**：会前24小时，提前发出文档，请各方确认，并群里回复"已阅读"。
2. **会后邮件**：把结论和Todo邮件发出来备忘，并且抄送各方老板周知。
3. **减少人数**：除了需要重点参与的同学，其他同学不邀请，会后邮件周知就好了。
