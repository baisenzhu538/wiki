# 徐剑 ToB 五步法 vs Truman 一堂五步法：异同、联系与底层逻辑

## 一、两套方法论的骨架对照

### 1.1 Truman 一堂五步法（通用创业框架）

| 步骤 | 核心问题 | 关键产出 |
|------|----------|----------|
| 需求 | 目标用户是谁？解决什么问题？ | 价值假设 |
| 产品内核（解决方案） | 用户选择你的核心要素是什么？ | 产品内核假设 |
| 商业模式 | 关键成本/收入项分别有哪些？ | 单元模型 / 商业模式假设 |
| 增长 | 你可规模化的获客渠道是什么？ | 增长假设 |
| 壁垒 | 哪些是你业务真正的护城河？ | 壁垒假设 |

**核心抓手**：
- 两个贯穿假设：**价值假设**（需求+产品内核+商业模式）与 **增长假设**（增长+壁垒）。
- 产品内核定义：**用户愿意选择你的最小解决方案**。
- 壁垒判断：**六个月测试** + **抄不了测试**。
- 增长原则：**增长方式从产品内核中长出来**；开始增长的前提是 LTV/CAC ≥ 3 且连续 3 个月稳定或上升。

### 1.2 徐剑 ToB 五步法（ToB 场景专用深化版）

| 步骤 | 徐剑 ToB 版的核心展开 | 对应通用五步法 |
|------|----------------------|----------------|
| 需求 | 客户分层（头/腰/腿）→ SABC 自定义切分 → 需求场景四象限 → 成本占有率 + 业务天花板 → 收入=客户成本 | 需求 |
| 产品内核 | 面向决策者研究付费、面向使用者夯实价值；分阶段多角色卖点；价值可传导 | 产品内核 |
| 解决方案 | 交付形式（标品/定制）× 履约周期（一次性/持续）× 采购方式（入围/一次性/周期性） | 解决方案 |
| 商业模式 | 五种单元模型（单订单、单 SKU、单客户、单销售、单履约）；双口径验证（财务确认口径 + 现金流口径） | 商业模式 |
| 增长 | 直销 vs 渠道；按目标、单元模型、规模化能力、动态毛利做取舍 | 增长 |
| 壁垒 | 三类壁垒（转化成本、规模效应、无形资产）+ 强弱三维度 + 对抗规模不经济 | 壁垒 |
| 现金流 | 自由现金流比账面利润更重要；长账期风险管理 | 贯穿商业模式/增长 |

## 二、异同分析

### 2.1 相同点：同源同构

1. **五步结构同源**
   两者都是一堂体系下的创业分析框架，结构高度一致：需求 → 产品/解决方案 → 商业模式 → 增长 → 壁垒。这不是巧合，而是一堂方法论的共同基因。

2. **都强调"假设验证"而非"商业计划书想象"**
   Truman 明确提炼出价值假设和增长假设；徐剑则用"成本占有率""业务天花板""单元模型跑通"等工具，把假设变成可量化、可验证的指标。

3. **都重视产品内核的"最小性"**
   Truman："产品内核 = 用户愿意选择你的最小解决方案"。徐剑在 ToB 场景下把它翻译为：面向决策者设计"最小可付费解决方案"，同时面向使用者夯实价值。

4. **都把壁垒放在最后，但要求早期识别**
   两者都警告不要等到规模大了再想壁垒。Truman 用"六个月测试/抄不了测试"，徐剑用"三类壁垒 + 强弱三维度 + 规模不经济对抗"。

5. **都反对盲目增长**
   Truman 强调 LTV/CAC ≥ 3 才能开始增长；徐剑强调单元模型未跑通前不要规模化，直销/渠道选择要看"业务单元总毛利覆盖所有成本"。

### 2.2 不同点：通用 vs 专用、战略 vs 战术

| 维度 | Truman 一堂五步法 | 徐剑 ToB 五步法 |
|------|-------------------|-----------------|
| **适用范围** | 通用创业框架，ToC/ToB/平台型均可使用 | 专门针对 ToB/企业服务/项目型业务 |
| **核心第一性** | 价值假设 + 增长假设 | **ToB 收入 = 客户成本** |
| **产品内核关注点** | 用户选择你的最小解决方案 | 决策者 vs 使用者分离；价值可传导 |
| **需求分析工具** | 相对抽象，强调用户痛点和价值假设 | 客户分层、SABC、四象限、成本占有率、业务天花板 |
| **商业模式工具** | 单元模型、LTV/CAC | 五种单元模型 + 双口径验证 + 现金流管理 |
| **增长工具** | 增长周期模型、增长黑客、渠道匹配 | 直销 vs 渠道、按区域/客户分层做销售组织取舍 |
| **壁垒工具** | 六个月测试、抄不了测试 | 转化成本/规模效应/无形资产分类 + 强弱三维度 + 规模不经济对抗 |
| **风格** | 偏战略框架、思维模型 | 偏战术落地、可操作的判断清单 |

**关键差异一句话概括**：
> Truman 的五步法是"地图"，告诉你商业世界有哪些关键地形；徐剑的 ToB 五步法是"导航"，告诉你在 ToB 这片地形上每一步具体怎么踩、踩错了会怎样。

## 三、深层次联系：徐剑版是 Truman 版的 ToB 场景化展开

### 3.1 不是两套体系，是一套体系的两次封装

如果把 Truman 一堂五步法比作操作系统，徐剑 ToB 五步法就是为 ToB 这个应用场景开发的专用 App。它们共用同一套底层逻辑，但徐剑在每一层都做了 ToB 化的"补丁"：

- **需求层**：ToB 的"用户"不是单一自然人，而是组织中的多角色决策者。所以徐剑加入了客户分层、SABC、四象限、决策链分析。
- **产品内核层**：ToB 存在决策者与使用者天然分离，所以徐剑强调"面向决策者研究付费、面向使用者夯实价值"。
- **商业模式层**：ToB 成交/交付/回款周期长，现金流和财务确认口径可能打架。所以徐剑加入双口径验证和自由现金流管理。
- **增长层**：ToB 获客依赖销售组织而非流量投放，所以徐剑重点讲直销 vs 渠道、单销售模型。
- **壁垒层**：ToB 常见壁垒不是品牌，而是转化成本、规模效应、无形资产和关系/数据/流程的组合。所以徐剑细化了壁垒类型和对抗规模不经济。

### 3.2 两条暗线贯穿两套方法论

**暗线一：从"价值验证"到"规模化防御"**

两条方法论都隐含同一个节奏：
1. 先验证价值假设（有没有人真正需要你、愿不愿意付费）；
2. 再验证商业模式假设（能不能赚到钱）；
3. 最后验证增长假设（能不能规模化、能不能挡住对手）。

前五步是"从 0 到 1"，后五步是"从 1 到 N"的防御。

**暗线二：用"单元"思维替代"整体"思维**

Truman 讲"最小解决方案"，徐剑讲"单元模型"。本质上都是把复杂的商业系统拆成最小可分析、可验证、可复制的单元，降低试错成本。这是精益创业"Build-Measure-Learn"在一堂体系中的本土化表达。

## 四、底层逻辑究竟是什么？

### 4.1 一句话底层逻辑

> **商业成功不是一次性想出来的，而是一组关键假设被逐步验证、逐步加固的过程。**

### 4.2 三个更底层的共识

1. **商业世界是可建模的**
   无论是 Truman 的五步画布，还是徐剑的单元模型、成本占有率、客户分层，本质都是把模糊的商业直觉转化为可讨论、可验证的结构。

2. **创业风险主要来自"不知道自己不知道"**
   两套方法论都把重心放在"识别关键假设"和"快速证伪"上。Truman 的"价值假设/增长假设"、徐剑的"成本占有率/业务天花板"都是为了减少盲区。

3. **规模化的前提是单元经济健康 + 护城河可建**
   不是"先做大再赚钱"，而是"先验证单元模型能跑通，再判断能不能规模化，同时建立壁垒"。这是两套方法论共同反对的"烧钱换规模"逻辑。

### 4.3 与精益创业、Buffett 护城河、Blitzscaling 的关系

| 外部框架 | 与一堂五步法的关系 |
|----------|-------------------|
| **Eric Ries 精益创业** | 同源。都强调 Build-Measure-Learn 和假设验证。一堂五步法是把精益创业的循环嵌入了五步商业分析结构。 |
| **Warren Buffett 护城河** | 互补。Buffett 关注"别人不想抄"（威慑力），一堂关注"别人抄不了"（防御力）。两者结合更完整。 |
| **Blitzscaling** | 对立场景。Blitzscaling 主张在关键窗口期先亏钱占市场；一堂五步法主张先跑通单元模型再规模化。两者适用于不同的市场窗口和资金环境。 |

## 五、关于"十八招"是否单独成卡的建议

### 5.1 当前卡片覆盖度评估

当前徐剑 ToB 域已有 **13 张有效卡片**（12 张框架/概念/工具 + 1 张销售单元模型概念），基本覆盖了五步法的"主干"。但课程内容中确实还散落着大量可深挖的"招数"。

### 5.2 建议策略：先补主干，再拆高价值招式

不建议直接把"十八招"机械拆成 18 张卡片。建议按以下优先级处理：

#### 优先级 P0：补充主干缺口（3-5 张）

当前主干中仍有必要补强的：
1. **yt-tob-sales-unit-model** 已存在，但可加强"时间闭环 + 空间闭环"的实操工具。
2. **yt-tob-decision-chain-map**（决策链地图）：徐剑反复强调"面向决策者研究付费"，但目前没有一张专门讲"怎么画决策链"的工具卡。
3. **yt-tob-value-transmission**（价值传导）："价值不可传导就等于不成立"是核心论断，值得单独成卡。
4. **yt-tob-cash-conversion-cycle**（现金转换周期）：现金流管理已有概念卡，但"成交/交付/回款/财务确认"四个周期的实操分析可独立。

#### 优先级 P1：从优秀作业合集提取 case 卡（3-5 张）

学员作业中的真实案例是徐剑方法论的最佳落地材料。建议优先提取：
- 有完整业务背景、有数据、有决策困境的案例；
- 能同时映射到 2-3 个框架卡片的案例；
- 有明显失败教训或转折点的案例（比成功案例更有学习价值）。

#### 优先级 P2：精选"招式"单独成卡（6-10 张）

在满足 P0/P1 后，再从课程内容中挑选最有复用价值的"招式"独立成卡。判断标准是：
- **高频触发**：在实际业务讨论中会被反复问到；
- **独立诊断价值**：单拿出来能帮人解决一个具体问题；
- **与主干卡片有 bridge**：不能是孤立的知识点，要能连回五步法结构；
- **有案例或工具化表达**：不能只是概念复述。

### 5.3 暂不建议单独成卡的类型

| 类型 | 原因 |
|------|------|
| 纯讲师经验观察（如"ToB 每年两三倍就是极好"） | 缺少通用性，放入主干卡的"讲师观察"边界说明即可 |
| 单个课堂举例数字 | 未经独立核实，不宜独立成卡 |
| 与已有卡片高度重叠的概念 | 应合并到现有卡片，避免卡片膨胀和重复 |
| 仅在特定行业有效的技巧 | 更适合作为 case 卡或边界说明，而非通用框架卡 |

### 5.4 推荐下阶段卡片建设顺序

```
Step 1: 完成当前 P0 任务（图片补充已有卡 + 新增壁垒卡 + case 卡 3-5 张 + source 注册）
Step 2: 新增 3-4 张主干工具卡（决策链地图、价值传导、现金转换周期、单销售模型实操）
Step 3: 从口述稿和作业合集中挑选 6-10 个高价值"招式"，逐一独立成卡
Step 4: 欧阳锋抽检审查，根据复用率和召回质量再决定是否继续拆分
```

## 六、结论

1. **徐剑 ToB 五步法和 Truman 一堂五步法不是两套体系，是一套体系在不同抽象层级和场景下的表达**。Truman 提供通用框架，徐剑提供 ToB 落地版。
2. **底层逻辑一致**：商业成功 = 关键假设逐步验证 + 单元经济跑通 + 规模化时建立壁垒。
3. **徐剑版的核心增量在于**：把 ToB 场景的特殊性（角色分离、周期长、现金流错配、销售组织、规模不经济）工具化、可操作化。
4. **十八招建议分阶段拆**：先补主干、再出 case、最后精选高复用招式独立成卡，避免卡片数量膨胀但网络价值下降。
