## 🟡 巡检过敏 — 保留不处理

泛产品设计的"落地卡片"和"用户卡片"簇（约60组），巡检器因结构模板相同而误判为重复。实际每张卡片主题不同：

- 落地卡片：业务建模 / 设计原则 / 善用佳软 / 假设拆解 / 灵感闪现 / 解放思想 / 努力仿真 / 复盘迭代 / 风险管理 / 攻坚会 等
- 用户卡片：行业分析 / 用户分层 / 动力阻力 / 需求挖掘 / 峰终定律 / 场景推演 / 惊喜公式 / 用户视角 等

**这类不处理**。是巡检器的文本相似度算法对"结构相似 + 主题不同"的内容过度敏感。
