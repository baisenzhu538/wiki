## 思维盲点（≥1 条：什么被漏掉了？每条追问"为什么漏掉"）

1. **停车场候选编号与队列实际编号撞车**——为什么漏：我把候选号（F-030~F-033/F-038/F-040）当成确定编号在对话和文档里引用，没意识到队列实际分配的任务号会占用同段数字。教训：**候选编号=排队提示不是承诺；任何跨文档引用一律以队列任务单 frontmatter 为准；立项时若撞号，以实际号为准并回改引用处**
2. **pre-submit 全 0 error 却 FAIL 的截断假象**——为什么漏：老顽童 spec 提交时 pre-submit 显示全 0 error 却 FAIL，差点误判交付不合规；实为隐藏项 index_freshness 未过，先跑 `python -m kdo index` 再重跑即过。教训：门禁输出读全量不读头部，FAIL 但零 error 时先怀疑索引新鲜度（与欧阳锋「截断假象第 5 次」同族——读数据先完整读）
3. **#441 任务单 frontmatter assignee 被脚本写成 hermes（实例名）**——为什么漏：流转脚本写的是执行实例不是角色名，我读 frontmatter 时差点当口径错误。教训：frontmatter assignee=实例、正文 assignee=角色，两层口径都要认
