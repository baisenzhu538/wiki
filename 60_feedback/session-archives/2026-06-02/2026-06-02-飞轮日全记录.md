## 三、今天发现的核心模式

### 飞轮规律

```
建造（建一个工具/框架/门禁）
  ↓
使用（建造者自己用）
  ↓
反思（在使用中发现摩擦→问为什么→挖深一层）
  ↓
实验（推理碰壁时跑数据）
  ↓
回到建造（用新发现驱动下一轮）
```

关键跃迁发生在第 3 轮——当分析对象从"外部问题"变成"自己"的时候。

### 递归深挖法

每一轮解剖三步：
1. **触发**一个话题/问题
2. **三个反馈**从不同角度解剖
3. **深挖**每条反馈直到收敛

收敛条件：下一轮新信息 < 10%，或修复路径已具体到可执行级别。

### 五套反馈框架

| # | 框架 | 适用场景 |
|:-:|:-----|:---------|
| A | 三层解剖（证据→根因→修复） | 技术问题诊断 |
| B | 四死刑法（框架照自身） | 系统性复盘 |
| C | Judge 三问（自我应用/边界判断/转换叙事） | 深度文章产出 |
| D | ADUCIT 逐环诊断 | 流程分析 |
| E | 辩证对偶（肯定→否定→综合） | 争议分析 |

## 五、未来的种子

### AI 快速精通领域知识

今天结束时生成的预提案：用 KDO 管线 + 自动搜索 + 递归深挖，让 AI 在几小时内精通一个陌生领域。已在桌面上。

### 自洽性搜索引擎

飞轮 + Judge + 递归深挖 + 自动搜索嫁接在一起时，RAG 就不再是"检索→生成"的单向管道。它变成了一台每回答一个问题就自我重组一次的知识机器——不叫 RAG，叫"递归收敛引擎"。

### 迁移可能性

飞轮模式可以迁移到产品设计（Design → Dogfood → Friction → Refine）、代码审查（Rule → Self-lint → False Positive → Fix）、学习方法论（Learn → Apply to Self → Find Edge Case → Deepen）、商业策略（Hypothesis → Bet → Surprise → Update Model）。
