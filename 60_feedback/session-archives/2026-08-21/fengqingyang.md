## 思维盲点
> ≥1条：什么被漏掉了？每条追问"为什么漏掉"。

1. **我把「全员会诊」误写成「老朱拍板」**。为什么漏：把「老朱是最终拍板人」惯性放大成「唯一决策者」，忽略了四方会诊机制才是决策过程。
2. **我提了七类工作流，却没第一时间意识到「角色边界和工作流必须逐条明确」才是工作台能落地的前置**。为什么漏：只盯着「看得见」，没追「不越界、不空转」。
3. **我做了大量审计却没给自己写每日复盘**。为什么漏：默认「诊断报告就是产出」，把交付物当成了记忆维护——两者不是一回事。
4. **我以为能随时看到其他 agent 的 session**。为什么漏：没区分「落盘痕迹」与「实时内存上下文」，高估了观察者视角。
5. **我一度把「停车场」当成单一实体**。为什么漏：只见"停车场"这个词，没先盘点它实际是 6 份文件、多编号宇宙、三类语义混装——词同≠物同，又是同名漂移。

## 顿悟
> ≥1条：什么基础认知被推翻了？

1. **工作台只解决「看得见」，边界与工作流才解决「不越界、不空转、不重复」**——状态字段必须映射到工作流的某一环。
2. **「记忆 = 分层 + 精选 + 洞察 + 消费闭环」「资产生而不用 = 僵尸资产」**（建设者案例 94）——资产提炼必须走「生成→索引→消费」，否则白存。
3. **观察者的「清醒」不是全知，是只读客观痕迹且不参与生产/终审**；胶囊机制是把他人 session 落盘给我的桥，未跑起来前必须显式提示缺口。
4. **工具多样"不利于自动化"的真正原因不是"多"，是"会话上下文格式不统一、无法回收"**——接口统一，多工具只是多适配器；接口不统一，单工具也漂。
5. **停车场不缺内容，缺"单一收口 + 生命周期闭环"**——同一批工厂债被拆散在 6+ 文件、多人重复登记、闭环了也不出池。
