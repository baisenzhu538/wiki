## 思维盲点

1. **claim 参数用序号**:"claim 399"报"不在队列"——queue_transition 的 task_id 是完整文件名。CLI 用法与直觉不符,白跑一轮诊断才定位。
2. **报告数字凭记忆归并**:#401 报告簇计数第一版凭印象写(规则数/friction 合计),与 JSON 原始数据对不上——当场用关键词重跑校准。08-20"报告是快照"教训当天复发当天修,但复发本身说明要工具化(簇归类入脚本或强制附 JSON)。
3. **JSON 不可见字符**:规则文本含特殊字符 → json.dumps 输出非法 JSON 两次炸(ensure_ascii 兜底)。08-20 U+FFFD 教训同族——不可见字符场景一律转义+读回验证。
4. **bash cd 漂移**:cd 到 KDO 仓后提审命令相对路径找不到脚本,报错 2 次才意识到 cwd 变了。低智错误,靠纪律(pwd 确认)防。
