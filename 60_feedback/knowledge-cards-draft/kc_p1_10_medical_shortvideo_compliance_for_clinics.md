# 诊所医疗短视频/个人 IP 合规边界

> **核心定位**：为诊所/医生提供医疗短视频（抖音、视频号、小红书、快手）内容创作的合规边界 checklist，识别推销方"流量部代运营"话术中的风险。

---

## Summary

医疗短视频/个人 IP 在诊所场景下具有引流潜力，但**合规边界比推销方描述的窄得多**。核心约束来自三个层面：

1. **法律法规**：《广告法》《医疗广告管理办法》《互联网广告管理办法》《医师法》。
2. **平台规则**：抖音、视频号、小红书、快手对医疗内容、医疗账号、本地生活医疗投放有严格限制。
3. **AI 内容监管**：AI 生成医疗内容须显著标识，批量同质化 AI 医疗文案已被四部门点名清理。

> **核心原则**：医疗短视频可以做健康科普，但不能做药品/器械广告，不能引导到店购药，不能由 MCN 机构代运营医疗账号。

---

## Claims

### 1. 各平台医疗内容政策要点

#### 1.1 视频号（2026 年 4 月《医疗健康行业公约》）

| 维度 | 规则要点 |
|---|---|
| 账号认证 | 仅支持三甲医院、执业医师、健康科普机构等资质认证 |
| MCN 代运营 | **明确禁止将医疗健康账号交由 MCN 机构代运营** |
| 流量投放 | **禁止通过流量包/付费推广等方式获取流量** |
| 商业变现 | 医疗账号不得参与直播带货、商品分享、广告分成 |
| 内容禁区 | 不得在非广告场景提及商品名、品牌名、医疗机构联系方式；不得夸大疗效、保证治愈 |
| 违规处罚 | 限流、禁言、封号、取消认证 |

#### 1.2 抖音

| 维度 | 规则要点 |
|---|---|
| 账号认证 | 医生账号需提交执业医师资格证、执业证、在职证明 |
| 私信/粉丝群 | **已关闭医生账号私信、粉丝群功能** |
| 带货/小黄车 | **医疗账号禁止带货** |
| 本地生活 | 医疗机构入驻抖音本地生活受严格限制，部分城市仅开放体检、口腔等少数类目 |
| 内容禁区 | 不得发布诊疗行为、不得推销药品/器械、不得制造健康焦虑 |

#### 1.3 小红书

| 维度 | 规则要点 |
|---|---|
| 医疗内容 | 对医疗科普实行严格审核，非认证医生账号发布医疗内容易被限流或下架 |
| 禁推品类 | **明确禁止推广药品、医疗器械、保健品"三品一械"** |
| 导流风险 | 私信引流、评论区留联系方式可能被封号 |

#### 1.4 快手

| 维度 | 规则要点 |
|---|---|
| 医疗账号 | 需提交医疗机构/医师资质认证 |
| 直播 | 医疗账号直播受限，不得进行诊疗、卖药 |
| 内容禁区 | 不得夸大疗效、不得宣传未经批准的疗法 |

### 2. 推销方常见话术与合规现实

| 推销方话术 | 合规现实 | 风险等级 |
|---|---|---|
| "我们有流量部，帮你做短视频/直播" | 视频号已禁止 MCN 代运营医疗账号 | 🔴 高 |
| "可以精准投放到诊所周边 3–5 公里" | 技术上支持地理投放，但医疗内容/医疗账号投放受限或禁止 | 🔴 高 |
| "AI 批量生成科普文案，一天发几十条" | AI 生成医疗内容须显著标识；批量同质化 AI 文案已被四部门清理 | 🔴 高 |
| "视频里不能出现药盒、不能说'专治'" | 只是底线之一，平台还有 MCN 代运营、流量包投放等更多限制 | 🟡 中 |
| "医生出镜讲科普，顺便宣传诊所" | 科普与广告界限模糊，易被认定为变相医疗广告 | 🟡 中 |

### 3. 医疗短视频合规边界清单

#### 内容层面
- [ ] 不得出现具体药品名称、品牌、包装（除非为经审批的医疗广告）。
- [ ] 不得出现"根治""治愈""无副作用""最有效"等绝对化用语。
- [ ] 不得针对具体患者病情给出诊断或用药建议。
- [ ] 不得制造健康焦虑、夸大疾病危害。
- [ ] 不得引导用户私信咨询、加微信、到店购药。

#### 运营层面
- [ ] 医疗账号须由本人或本机构运营，不得委托 MCN 机构代运营（视频号明确禁止）。
- [ ] 不得购买流量包、DOU+、薯条等推广医疗内容（视频号禁止；抖音/小红书医疗内容投放受限）。
- [ ] AI 生成内容须显著标识"本内容由 AI 生成"。
- [ ] 直播不得涉及诊疗行为、药品/器械推销。

#### 资质层面
- [ ] 医生账号须完成平台资质认证。
- [ ] 诊所作为机构账号入驻须提供医疗机构执业许可证/诊所备案凭证。
- [ ] 发布医疗科普的人员应具备相应专业资质。

### 4. 真实转化数据的稀缺性

公开渠道几乎找不到诊所医疗短视频的真实转化率数据。常见的"成功案例"多来自 MCN 机构宣传，存在以下问题：
- 只展示粉丝量/播放量，不展示到店率、转化率、ROI；
- 混淆健康科普账号与医疗机构账号；
- 不说明账号是否曾因违规被限流或封号。

> **结论**：在缺乏独立验证的转化率数据前，不能将"医疗短视频引流"作为诊所+药柜模式的核心增长假设。

## Critique

### 局限性

1. **平台政策变化快**：抖音、视频号、小红书、快手的医疗内容规则 2024–2026 年多次调整，本卡需定期更新。
2. **地方执法差异**：部分地区市监局对医疗广告的执法尺度不同。
3. **转化数据缺失**：公开渠道难以找到诊所场景的真实转化数据。

### 与已有知识的联系

- **认知偏差视角**：推销方常利用"平台有 3–5 公里投放能力"暗示医疗内容可自由投放，这是混淆了技术能力与合规许可。参考 `master-cognitive-bias-checklist`。
- **决策卫生视角**：本卡要求对流量运营方案进行合规审查，而非仅凭播放数据判断。参考 `master-decision-hygiene`。
- **招商骗局识别**："流量部 MCN 代运营"是 `kc-p0-04-fraud-detection` 中新增的风险信号之一。参考 `kc-p0-04-fraud-detection`。
- **诊所+药柜风险观察**：医疗短视频合规风险是 `kc-p0-06-clinic-cabinet-risk-observation` 中"流量运营"风险的展开。参考 `kc-p0-06-clinic-cabinet-risk-observation`。

### 使用建议

- 诊所若计划做短视频，先完成本卡"合规边界清单"自测。
- 若与第三方"流量部"合作，必须先索取：平台合作协议、医疗内容审核流程、已运营账号案例及后台数据、AI 内容标识机制。
- 将短视频定位为"品牌曝光/科普教育"，而非"直接引流/转化"，以降低合规风险。
