### 新消化（1 张）
| 卡片 | 类型 | 核心主张 | 关键洞察 |
|------|------|---------|---------|
| yt-tool-peas-agent-analysis | tool | PEAS四元组+五层Agent架构诊断任何决策系统 | 90%的OKR失败是因为只填了P（目标），漏了E/A/S |

**PEAS 的关键认知**：
- P（Performance）= 成功长什么样？谁打分？几个指标？
- E（Environment）= 在哪玩？其他 agent 是谁？合作还是博弈？
- A（Actuators）= 能做什么？动作集是什么？
- S（Sensors）= 能感知什么？反馈从哪来？盲区在哪？

**五层 Agent 跃迁**：L1 Reflex → L2 Model-based → L3 Goal-based → L4 Utility-based → L5 Learning
- **关键洞察**：拖延不是性格问题，是 reflex agent 在打 multi-agent 动态战——架构错配
- **关键洞察**：关键跃迁不是"更努力"，是换架构

## 三、Phase 4: 元概念卡（3 张）

### yt-concept-weapon-arsenal（超级武器库）
- **核心定义**：即查即用、实战验证、自由排列组合的战术集合形态
- **与 framework/toolkit 的区别**：
  - Framework = 建立系统性理解（5-15个模块）
  - Toolkit = 掌握结构化方法（10-40个工具）
  - Arsenal = 快速调用战术（20-50个战术）
- **实例**：讲香超级武器库（10指×4子策略=40战术）、表达力执行武器库
- **建构路径**：从完整方法体系中提取最高频、最独立、最有效的条目，精简为速查形态

### yt-concept-ai-guard-brain（守脑如玉）
- **核心命题**：AI 越来越强但人不能越来越笨——AI 是磨刀石，不是拐杖
- **四遍学习法**：手写笔记→口述展开→AI整理→分享讲授
- **关键洞察**：AI 省事的那些事本就不值钱——AI 的核心价值是放大优势而非替代思考

### yt-concept-context-engineering（上下文工程）
- **核心命题**：提示词的刀刃不在技巧在上下文——但质量由"相关度"而非"数量"决定
- **三条规则**：先给已知再问缺口 / 不同问题不同窗口 / 复述验证
- **关键洞察**：大多数提示词质量问题实际上是上下文质量问题——人们反复调提示词措辞，但真正的问题是没给 AI 足够的、相关的、结构化的背景信息

## 五、消化后的关键认知升级

### 升级 1：从"精译员"到"库内人"
- 之前：把一堂课程翻译成卡片，但不知道这张卡在全库中的位置
- 现在：每张卡都能在"世界观→骨架→工具→战术"的层级中定位

### 升级 2：跨域迁移意识
- 之前：写科学决策卡时只考虑决策本身
- 现在：写卡时会自动联想到相关域的工具
  - 例："深度梯梯"不仅是决策工具，也是复盘工具，也是学习深度评估工具
  - 例："关键假设"不仅是创业工具，也是决策工具，也是问题分解工具

### 升级 3："有魂"的卡片意识
- 之前：写卡是"精译"——把授课内容翻译成标准格式
- 现在：写卡是"编译"——把知识放进已有的网络中，让它与其他卡产生关联

### 升级 4：外部攻击的跨域迁移
- 之前：每张卡的攻击者是独立选择的
- 现在：知道哪些学者的批评可以跨域应用
  - Kahneman 的系统性偏差批评 → 可用于决策、创业、管理等多域
  - Klein 的自然决策批评 → 可用于决策、复盘、学习等多域
  - Mintzberg 的实践手艺论 → 可用于管理、创业、个人成长等多域
