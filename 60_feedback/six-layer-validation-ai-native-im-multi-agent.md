## 四、去伪存真后的 AI 原生协作工具框架

### 核心判断

当前 Agent 工具面临的真实瓶颈不是「模型不够聪明」，而是「协作基础设施不匹配」。把 Agent 嵌入人类设计的 IM/协作工具，会产生上下文管理、状态可视化、角色协作等一系列摩擦。

### AI 原生协作工具的关键要素

1. **Agent 作为一等公民**：工具设计围绕 Agent 的工作方式，而非把 Agent 作为插件。
2. **团队仿真**：支持创建不同角色/职能的 Agent，模拟真实团队结构。
3. **上下文管理**：重置、归档、压缩等多级上下文控制，降低 token 消耗。
4. **状态可视化**：实时显示 Agent 的工作状态（思考中、读文件、调用工具等）。
5. **会话隔离**：不同 Agent/任务之间上下文隔离，避免信息串扰。
6. **@触发与委派**：Agent 之间可通过@机制相互触发任务。
7. **与人类工作流深度集成**：不是替代现有工具，而是与飞书/钉钉/Slack 等打通。

### 两条路径

- **平台原生路径**：飞书 aily、Slack AI 等在现有平台上增加 Agent 能力。
- **独立原生路径**：从头设计 Agent 优先的协作工具（如演讲者演示的工具）。

当前平台原生路径更成熟，独立原生路径仍处于早期探索。
