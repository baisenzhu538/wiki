## 会诊纪律

1. **讨论轴 = `checklist.md`**：逐条编号，每方只对编号条目表态，不另起炉灶
2. **单一写者**：每角色只写 `positions/<自己>.md`，不碰别人文件
3. **表态格式**：每条「同意 / 修改 / 反对 + 理由」，**沉默不默认通过**
4. **按利益相关度必读**：老顽童必读 B2-3/B4-3（draft 分仓/回链线），其余可按需；不强求全员读全 28 条
5. **一批一结**：拍板落盘到 `decisions.md` 后再进下一批
6. **队列只承接已拍板项**：讨论中的条目不入 production-queue
