# OSCAR-R：拿到信息正确判断

OSCAR最后一步，也是最不可外包的一步——AI可以帮前四步，但判断必须人来做。

## 四层递进

| 层次 | 操作 | 反模式 |
|:----:|:-----|:-------|
| 1. 事实优先 | 先区分"数据"和"解读"。同一数据可以有多种解读 | 拿到一篇券商报告直接采信其结论 |
| 2. 定量建模 | 把关键信息代入数字模型，看算不算得过账 | 凭"感觉挺大"判断市场空间 |
| 3. 交叉验证 | 同一个结论必须≥2个独立来源确认 | 一个专家说"这个行业很好"就信了 |
| 4. 深度归因 | 不合预期的信息比合预期的更值钱——追问"为什么？" | 看到不利信息就忽略或解释掉 |

## 核心原则

**让你不舒服的信息，往往是真信息。让你舒服的信息，更值得再验证一遍。**

### [Critique]

- **Boundary**：R步骤对判断力要求最高，而判断力无法仅通过方法论传授——需要大量案例训练和失败复盘。这是调研能力最后的护城河。
