# 行业报告调研四步法

Doris 在一堂调研系列中提出的行业报告调研方法论。聚焦"案头工作"——如何用公开行业报告快速建立行业认知。

## 四步流程

### 1. 明确调研目标

围绕**行业预判六要素**设定目标：
- 产业链结构（上下游是谁？）
- 变化原因（为什么这个行业在变化？）
- 稳态B（终局可能是怎样的？）
- 行业周期（处于哪个阶段？）
- 天花板（市场有多大？）
- 集中度（头部玩家占多少份额？）

### 2. 了解报告来源

六类报告来源：
1. 行业媒体
2. 创投媒体
3. 券商投行
4. 咨询公司
5. 头部企业（年报/招股书）
6. 官方渠道（政府/行业协会）

### 3. 高效搜索

三级搜索能力：
- L1 关键词搜索
- L2 增加限制词（filetype:pdf, site:）
- L3 按图索骥（从一篇好报告的引用链向上追溯）

> 90%的行业报告可通过搜索引擎找到，不需要特殊数据库。

### 4. 判断可信度

**多信数据，少信解读，警惕观点。**

- 数据 > 解读 >> 观点
- 注意统计口径（同一"市场规模"不同报告定义可能不同）
- 注意立场（券商报告天然偏乐观，咨询报告天然偏"需要咨询服务"）

## 价值主张

Doris 声称通过行业报告可在**7天内从外行达到可与专家平等对话的水平**。这一声称有个人案例支撑（音乐流媒体行业预判成功获得融资）但不可普遍化——7天效果取决于行业复杂度和个人学习能力。

### [Critique]

- **Assumption**：Doris的方法论假设行业有足够多的高质量公开报告。对于新兴行业或信息高度不透明的行业（如部分B2B制造业），报告严重不足——此时需转向一手调研（专家访谈/用户调研）。
- **Boundary**：适用于"可通过公开信息建立认知"的行业。高壁垒行业（如军工、尖端制药）核心信息不在公开报告中。
- **Reliability**：Medium——双源验证（口述+笔记），Doris个人案例支撑，但方法论本身未经独立第三方验证。
