# 洞察卡：智能药柜/无人药房失败模式案例库

## 一句话洞察

智能药柜/无人药房的失败不是个案，而是**招商骗局、点位质量差、政策合规失败、运营能力不足、商业模式结构性失败**五类问题的集中体现。任何新项目都必须先排除这五类模式。

## 失败模式分类

| 失败模式 | 典型案例 | 核心问题 | 识别信号 |
|---------|---------|---------|---------|
| **招商加盟骗局** | 修正未来智慧药房 | 高收益承诺 + 虚假点位 + 运营缺位 | "包点位、包运营、保证回本"；无法提供真实加盟商流水 |
| **点位质量失败** | 广西五年仅 92 台 | 人流不足、需求虚假、O2O 替代强 | 日均销售额低于保本线；周边药店/O2O 覆盖密集 |
| **政策合规失败** | 各地违规销售处方药被处罚 | 超范围经营、药师挂证、医保违规 | "数字人药师""名义有人实际无人""先拿证再分租" |
| **运营能力不足** | 设备故障、不补货、无维护 | 设备不稳定、SKU 受限、售后缺失 | 故障率高、缺货率高、消费者投诉多 |
| **商业模式结构性失败** | 叮当健康关闭多城业务 | 低频低价乙类 OTC 无法覆盖固定成本 | 单点长期亏损、规模化后亏损扩大 |

## 典型案例

### 案例一：修正未来智慧药房（招商加盟骗局典型）

| 维度 | 详情 |
|------|------|
| 时间 | 约 2022–2024 年 |
| 主体 | 海南清修智能药柜科技有限公司（修正集团授权） |
| 模式 | 招商加盟，投资者购买设备，公司承诺点位、运营、分润 |
| 承诺 | "投资 7 万元/台，预估年收益分润 6 万余元，1 年多回本" |
| 现实 | 投资者月收益仅几元、十几元；汉中 31 台机器 2022.4–2023.11 月均销售 **151 元/台** |
| 投诉 | 黑猫投诉 155+ 条：虚假宣传、不履行合同、拖欠违约金 |
| 司法 | 海南清修被列为被执行人；法定代表人被限制高消费 |
| 失败模式 | 招商骗局 + 虚假点位 + 运营缺位 |
| 教训 | 品牌背书不等于项目可靠；必须实地考察点位、访谈真实加盟商 |

### 案例二：广西自动售药机五年仅 92 台（政策与需求双重制约）

| 维度 | 详情 |
|------|------|
| 时间 | 2019–2024 年 |
| 主体 | 广西全区自动售药机试点 |
| 数据 | 五年累计仅 92 台自动售药机 |
| 失败模式 | 政策限制（仅乙类 OTC）+ 需求不足 + 运营成本未被充分认识 |
| 教训 | 政策只允许乙类 OTC 严重限制 SKU；消费者对自助购药的信任度和使用习惯尚未养成 |

### 案例三：叮当健康关闭多城业务（商业模式承压）

| 维度 | 详情 |
|------|------|
| 时间 | 2024 年 |
| 主体 | 叮当健康（09886.HK） |
| 事件 | 暂停重庆、南京、济南、福州业务，聚焦北上广深 |
| 财务 | 2024 年智慧药房及医疗服务收入下滑 |
| 失败模式 | 前置仓模式重资产、高履约成本，低线城市订单密度不足 |
| 教训 | 即使是上市公司，低线城市的即时医药零售也难以盈利；药柜模式更难 |

### 案例四：院内智慧药房上市公司收入下滑（成熟市场也承压）

| 维度 | 详情 |
|------|------|
| 时间 | 2024 年 |
| 主体 | 艾隆科技（-14.42%）、健麾信息（-56.84%）智慧药房收入 |
| 失败模式 | 医院端采购周期波动、竞争加剧、集采压缩利润空间 |
| 教训 | 院内智慧药房是成熟市场但增长承压；院外药柜市场更不成熟 |

### 案例五：各地政策收紧导致早期试点失效

| 地区 | 早期政策 | 后续变化 | 失败模式 |
|------|---------|---------|---------|
| 成都 | 2020 年允许甲类 OTC | 文件 2025-12-31 到期，省级文件限缩为乙类 OTC | 政策窗口关闭 |
| 重庆 | 2020 年允许甲类 OTC | 2024-11 新细则收紧为仅乙类 OTC | 政策收紧 |
| 陕西 | 2024 年征求意见稿 | 未找到正式印发版本 | 政策未落地 |

## 国际对照

| 国家/地区 | 代表企业 | 模式 | 失败/困境原因 |
|-----------|---------|------|--------------|
| 美国 | MedAvail、Asteres | 自动取药机 | 需求低频、医保壁垒、点位质量差、运营成本高 |
| 欧洲 | 多国试点 | 自动售药机 | SKU 受限、监管严格、消费者习惯尚未形成 |
| 日本 | 部分药妆店 | 自动售药机 | 仅限部分非处方药，规模有限 |

**共性**：国际主流是"自动取药机"而非"自动售药机"，失败原因与中国高度同构（SKU 受限、需求低频、医保壁垒、合规成本、点位质量差）。

## 失败模式自检清单

在评估任何药柜项目前，逐一检查：

1. **是否存在招商加盟骗局信号？**
   - [ ] 承诺"保证回本""包点位""包运营"
   - [ ] 无法提供真实加盟商流水
   - [ ] 设备价格显著高于市场价但承诺高回报

2. **点位是否经过真实验证？**
   - [ ] 日均人流量、夜间需求、周边竞争是否测算过？
   - [ ] 是否有 3–6 个月试销数据？
   - [ ] O2O 覆盖是否已饱和？

3. **合规路径是否清晰？**
   - [ ] 当地政策允许售什么药？
   - [ ] 执业药师如何配置？
   - [ ] 医保如何接入？
   - [ ] 处方来源是否合法？

4. **运营能力是否匹配？**
   - [ ] 设备故障率、补货频次、运维响应速度
   - [ ] SKU 是否能满足目标场景需求
   - [ ] 冷链、效期、追溯管理是否到位

5. **商业模式是否成立？**
   - [ ] 单点财务模型是否测算？
   - [ ] 悲观情景下是否仍能回本？
   - [ ] 规模化后固定成本和边际成本如何变化？

## 深度核验说明

### 已验证
- 修正未来智慧药房案例有黑猫投诉、法院执行信息、公开报道支持。
- 叮当健康关闭多城业务有上市公司公告支持。
- 艾隆科技、健麾信息收入数据来自 2024 年年报。
- 广西五年 92 台数据来自行业公开信息。

### 待验证/降级
- 部分国际案例为二手概括，具体财务数据需进一步查证。
- "汉中 31 台月均销售 151 元/台"来自投诉材料，未独立审计。

## 局限

- 本卡案例主要来自公开渠道，可能存在幸存者偏差（失败的更容易被报道）。
- 成功案例（如部分医院内智慧药房）未在本卡重点覆盖。
- 案例时间跨度大，部分早期案例的政策环境已变化。

## 使用场景

- 投资/加盟药柜项目前的尽职调查。
- 评估项目方商业计划书的反面教材。
- 向团队/客户解释药柜项目的结构性风险。

## 相关概念

- **招商加盟骗局**：以高收益承诺吸引投资，实际无运营能力的商业模式。
- **前置仓模式**：在靠近消费者处设小型仓储，缩短配送时效，但重资产、高履约成本。
- **SKU 受限**：可销售品类有限，难以满足多样化需求。
