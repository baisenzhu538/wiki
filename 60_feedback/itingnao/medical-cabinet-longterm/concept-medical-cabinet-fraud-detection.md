# 概念卡：智能药柜/智慧药房招商骗局识别

## 一句话定义

智能药柜/智慧药房招商领域存在典型骗局模式：以高收益承诺吸引投资者购买设备，但实际无优质点位、无运营能力、无合规资质，最终投资者血本无归。

## 典型案例：修正未来智慧药房

| 维度 | 详情 |
|------|------|
| 招商主体 | 海南清修智能药柜科技有限公司（修正集团授权为"未来药房项目唯一经营主体"） |
| 宣传话术 | "修正集团背书""24 小时无人药房""投资 7 万元/台，预估年收益分润 6 万余元，1 年多回本" |
| 受害者规模 | 黑猫投诉平台投诉量达 **155 条**（截至 2024-06-14） |
| 典型投诉 | 虚假宣传、不履行合同、拖欠违约金、收益仅几元 |
| 实际收益 | 投资者月收益"几元、十几元"；汉中 31 台机器 2022.4–2023.11 月均销售 **151 元/台** |
| 司法状态 | 海南清修被列为**被执行人**；法定代表人被**限制高消费**；2024 年上半年 4 起执行案件，总金额约 43.9 万元 |
| 公司回应 | 承认"前期内外部因素运营不力导致公司无力推进地推活动收益甚微，目前公司资金匮乏" |
| 核心教训 | 品牌背书不等于项目可靠；招商合同与实际运营能力需分开审查 |

## 招商骗局 8 大识别信号

| 信号 | 具体问题 | 排查动作 |
|------|---------|---------|
| **1. 高收益承诺** | "月入过万""半年回本""躺赚" | 要求提供已运营点位的真实销售额、回本周期、分成记录 |
| **2. 模糊点位资源** | 仅承诺"医院/社区/高校"，无具体地址 | 要求提供拟投放点位的清单、租赁合同/合作协议 |
| **3. 一次性高额加盟费** | 加盟费、设备费、保证金一次性收取 | 核实费用明细，对比市场设备价格；避免一次性大额预付 |
| **4. 品牌背书滥用** | 借用知名药企、互联网平台名义 | 核实授权文件真实性，查询品牌方官网/工商登记 |
| **5. 合同条款不对等** | 退款难、违约责任轻、服务承诺模糊 | 请律师审核合同，重点看退款条件、违约责任、服务清单 |
| **6. 无实际运营能力** | 无设备交付、无补货、无维护 | 实地考察已运营点位，访谈其他加盟商 |
| **7. 资质不全** | 无药品经营许可证、无 GSP 体系 | 查询《药品经营许可证》、企业信用报告、司法风险 |
| **8. 涉嫌违规销售** | 宣称可售处方药/甲类 OTC | 对照国家 48 号公告，仅乙类 OTC 可售 |

## 合作前必查清单

### 企业资质
- [ ] 营业执照、药品经营许可证（或依托药店的许可证）。
- [ ] 企业信用报告：注册资本、实缴资本、股东结构、历史变更。
- [ ] 司法风险：是否被列为被执行人、限制高消费、股权冻结、诉讼记录。
- [ ] 行政处罚：是否有药监局、市场监管局处罚记录。

### 项目真实性
- [ ] 已运营点位清单及地址。
- [ ] 至少实地走访 2–3 个已运营点位。
- [ ] 访谈 2–3 位现有加盟商/投资者，了解真实收益和运营支持。
- [ ] 设备实际交付情况、补货频率、故障处理响应时间。

### 合同与财务
- [ ] 费用明细表：加盟费、设备费、系统费、维护费、分成比例。
- [ ] 退款条款：什么条件下可退、退款周期、违约金计算。
- [ ] 收入结算方式：日结/月结、对账方式、提现门槛。
- [ ] 违约责任：双方违约情形及赔偿标准。

### 合规性
- [ ] 可销售药品种类是否符合当地政策（通常仅乙类 OTC）。
- [ ] 是否具备执业药师远程审方/药学服务。
- [ ] 医保接入是否经官方审批。

## 深度核验说明

### 已验证
- 修正未来智慧药房案例有黑猫投诉、法院执行信息、公开报道支持。
- 国家药监局 48 号公告明确自助售药机仅售乙类 OTC。

### 待验证/降级
- "汉中 31 台月均销售 151 元/台"来自投诉材料，未独立审计。
- 其他招商骗局模式为行业经验归纳，非统计结论。

## 局限

- 本卡以修正未来药房为主要案例，可能存在幸存者偏差（失败的更容易被报道）。
- "8 大识别信号"为经验框架，不能保证 100% 识别所有骗局。
- 本卡不构成法律或投资建议。

## 使用场景

- 投资/加盟药柜项目前的尽职调查。
- 向团队/客户解释药柜招商风险。
- 作为合同审核和实地考察的 checklist。

## 相关概念

- **品牌背书滥用**：借用知名品牌名义招商，实际运营主体与品牌方关系不清。
- **虚假点位**：承诺优质点位，实际投放偏远或无人流地点。
- **运营缺位**：收取费用后不提供设备、补货、维护等实质服务。
