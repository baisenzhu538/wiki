# 方法卡：公转私风险控制清单

## 一句话定义

公转私是指公司账户资金转到个人账户的行为，必须基于真实业务、合规纳税、留痕完整，否则可能触发税务稽查、挪用资金或法人人格否认风险。

## 适用场景

- 创业者需要把公司利润合法提取。
- 股东与公司之间有资金往来。
- 公司给员工、合作方支付报酬。
- 融资前规范财务结构。

## 合规公转私的 9 种情形

| 情形 | 必备条件 | 税务处理 |
|------|---------|---------|
| 发放工资 | 劳动合同、代扣个税、缴纳社保 | 工资薪金个税 |
| 支付劳务报酬 | 服务合同、发票或代扣代缴 | 劳务报酬个税 |
| 股东分红 | 股东会决议、税后利润 | 20% 分红个税 |
| 员工差旅费报销 | 真实票据、出差证明材料、审批流程 | 不缴个税 |
| 个人独资企业利润分配 | 缴完经营所得个税后的利润 | 已按经营所得纳税 |
| 偿还个人借款 | 借款合同、利息合规 | 利息收入个税 |
| 向个人采购 | 取得税务局代开发票、留存合同协议 | 按业务性质缴税 |
| 支付赔偿金/违约金 | 合同依据、司法/仲裁文书、证明材料 | 视情况而定 |
| 向个人房东支付房租 | 租赁合同、房东身份信息 | 房东缴纳相关税费 |

## 法律依据

| 法律 | 关键条款 | 含义 |
|------|---------|------|
| 《公司法》第 63 条 | 一人公司股东需证明财产独立，否则承担连带责任 | 公私混同可刺破公司面纱 |
| 《公司法》第 148 条 | 董事/高管不得将公司资金以个人名义存储 | 禁止公款私存 |
| 《公司法》第 171 条 | 公司除法定账簿外不得另立会计账簿 | 禁止账外账 |
| 《商业银行法》第 48 条 | 任何单位和个人不得将单位资金以个人名义开立账户存储 | 禁止私户存公款 |
| 《税收征收管理法》 | 纳税人应如实申报纳税 | 私户收款可能构成偷税 |

## 风险控制清单

### 事前

- [ ] 是否有真实业务背景？
- [ ] 是否有合同/协议/决议支持？
- [ ] 是否已经正确计算应纳税额？
- [ ] 收款方身份是否清晰（员工/股东/供应商/个人）？

### 事中

- [ ] 转账备注是否明确用途？
- [ ] 金额是否与合同/发票一致？
- [ ] 是否通过公司账户转账，避免现金或第三方账户？
- [ ] 是否同步更新账簿？

### 事后

- [ ] 是否取得合规发票或收据？
- [ ] 是否在账簿中正确分类？
- [ ] 是否按期申报相关税费？
- [ ] 借款是否在约定时间内归还或计息？

## 高风险行为

| 行为 | 风险 |
|------|------|
| 长期挂账"其他应收款-股东" | 可能被视同分红补税 |
| 用个人卡收公司货款 | 偷税漏税、账外经营、三流不一致 |
| 虚构交易套取资金 | 虚开发票、刑事责任 |
| 频繁大额公转私无依据 | 银行风控、税务稽查、反洗钱监测 |
| 公户私户频繁交易 | 最高法：可构成财产混同，承担连带责任 |
| 个人账户短期内累计 100 万以上现金收付 | 可能被列为可疑交易监控 |

## 真实处罚案例

| 案例 | 行为 | 处罚 |
|------|------|------|
| 厦门 J 公司 | 10 年间通过员工私人账户收取销售款，隐瞒收入 5290.07 万元 | 补缴税费 1198.27 万元、滞纳金和罚款 905.32 万元 |
| 某企业 | 个人账户收款未报税 | 补税 500 多万、罚款近 300 万 |

## 优化策略

1. **提前设计股权和薪酬结构**：工资+分红+报销组合，合法降低税负。
2. **使用家族公司/持股平台**：在合规前提下优化分红税负（需专业设计）。
3. **建立费用报销制度**：让合理的个人垫付有合规出口。
4. **定期清理往来款**：避免长期挂账引发风险。
5. **确保三流一致**：资金流、货物流、发票流一致。
6. **公私分离**：所有业务收入最终归集至对公账户。

## 与相关方法的关系

- **财务合规体系**：公转私是其中的关键控制点。
- **税务筹划**：合法节税，而非偷税漏税。
- **公司治理**：清晰的股东与公司边界。

## 重要提醒

- 金税四期背景下，税务对公转私的监控能力显著增强。
- 本卡为通用清单，具体方案需结合企业实际情况咨询专业人士。
