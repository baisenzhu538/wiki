# 方法卡：公转私风险控制清单

## 一句话定义

公转私是指公司账户资金转到个人账户的行为，必须基于真实业务、合规纳税、留痕完整，否则可能触发税务稽查、挪用资金或法人人格否认风险。

## 适用场景

- 创业者需要把公司利润合法提取。
- 股东与公司之间有资金往来。
- 公司给员工、合作方支付报酬。
- 融资前规范财务结构。

## 合规公转私的 6 种情形

| 情形 | 必备条件 | 税务处理 |
|------|---------|---------|
| 发放工资 | 劳动合同、代扣个税、缴纳社保 | 工资薪金个税 |
| 支付劳务报酬 | 服务合同、发票或代扣代缴 | 劳务报酬个税 |
| 股东分红 | 股东会决议、税后利润 | 20% 分红个税 |
| 差旅/报销 | 真实票据、审批流程 | 不缴个税 |
| 偿还股东借款 | 借款合同、利息合规 | 利息收入个税 |
| 支付赔偿金/违约金 | 合同依据、司法/仲裁文书 | 视情况而定 |

## 风险控制清单

### 事前

- [ ] 是否有真实业务背景？
- [ ] 是否有合同/协议/决议支持？
- [ ] 是否已经正确计算应纳税额？
- [ ] 收款方身份是否清晰（员工/股东/供应商/个人）？

### 事中

- [ ] 转账备注是否明确用途？
- [ ] 金额是否与合同/发票一致？
- [ ] 是否通过公司账户转账，避免现金或第三方账户？
- [ ] 是否同步更新账簿？

### 事后

- [ ] 是否取得合规发票或收据？
- [ ] 是否在账簿中正确分类？
- [ ] 是否按期申报相关税费？
- [ ] 借款是否在约定时间内归还或计息？

## 高风险行为

| 行为 | 风险 |
|------|------|
| 长期挂账"其他应收款-股东" | 可能被视同分红补税 |
| 用个人卡收公司货款 | 偷税漏税、账外经营 |
| 虚构交易套取资金 | 虚开发票、刑事责任 |
| 频繁大额公转私无依据 | 银行风控、税务稽查 |

## 优化策略

1. **提前设计股权和薪酬结构**：工资+分红+报销组合，合法降低税负。
2. **使用家族公司/持股平台**：在合规前提下优化分红税负（需专业设计）。
3. **建立费用报销制度**：让合理的个人垫付有合规出口。
4. **定期清理往来款**：避免长期挂账引发风险。

## 与相关方法的关系

- **财务合规体系**：公转私是其中的关键控制点。
- **税务筹划**：合法节税，而非偷税漏税。
- **公司治理**：清晰的股东与公司边界。

## 重要提醒

- 金税四期背景下，税务对公转私的监控能力显著增强。
- 本卡为通用清单，具体方案需结合企业实际情况咨询专业人士。
