# 方法卡：FD 直供合作谈判清单

## 一句话定义

FD 直供合作谈判是厂家与大型终端/平台就价格、账期、物流、库存、数据共享等核心条款进行协商的过程，需要提前明确底线和可交换条件。

## 适用场景

- 厂家与连锁超市、便利店、电商平台洽谈直供。
- 品牌方与大型餐饮连锁洽谈 B2B 直供。
- 评估是否接受平台提出的直供条件。

## 谈判前的准备

### 1. 明确自身成本结构

- 生产成本
- 物流成本
- 仓储成本
- 资金成本
- 最低可接受毛利率

### 2. 了解对方需求

- 对方的采购量和增长预期
- 对方对价格、账期、配送的要求
- 对方是否有替代供应商
- 对方的核心 KPI（如毛利、周转、用户体验）

### 3. 确定谈判底线

| 条款 | 理想值 | 可接受值 | 底线 |
|------|--------|---------|------|
| 供货价 | | | |
| 账期 | | | |
| 退货率 | | | |
| 最小订货量 | | | |
| 数据共享范围 | | | |

## 核心谈判条款

### 1. 价格与毛利

- 供货价如何确定？是否随原料波动调整？
- 终端零售价由谁定？是否有价格保护？
- 促销费用如何分摊？

### 2. 账期与资金流

- 账期多长？是否可接受？
- 是否有预付款或保证金？
- 逾期付款如何处理？

### 3. 物流与库存

- 配送频率和时效要求？
- 库存由谁承担？滞销品如何处理？
- 退换货政策是什么？

### 4. 数据与市场

- 销售数据是否共享？共享到什么程度？
- 是否允许厂家做终端营销？
- 新品上架和推广的权益如何分配？

### 5. 合作期限与退出

- 合同期限多长？
- 提前终止条件是什么？
- 是否有排他性条款？

## 谈判策略

1. **用数据说话**：准备好成本、销量、市场份额等数据。
2. **寻找双赢点**：比如用独家新品换取更好的陈列位置。
3. **分阶段让步**：不要一次性亮出底线。
4. **设定替代方案**：如果谈不拢，Plan B 是什么？
5. **法务和财务参与**：确保合同条款可执行、风险可控。

## 常见陷阱

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 只关注价格 | 忽视账期、退货、物流成本 | 用总成本模型评估 |
| 过度承诺销量 | 为了拿订单乱承诺 | 基于真实产能承诺 |
| 接受超长账期 | 资金链承压 | 账期与价格联动谈判 |
| 数据共享过度 | 泄露核心信息 | 明确数据范围和用途 |

## 与相关方法的关系

- **商务谈判原则**：利益而非立场。
- **成本分析**：准确计算底线。
- **合同管理**：把谈判结果落到可执行条款。
