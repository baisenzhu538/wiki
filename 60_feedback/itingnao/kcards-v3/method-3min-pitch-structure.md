# 方法卡：3 分钟项目路演结构

## 一句话定义

3 分钟路演是一种高度浓缩的项目展示方式，要求在极短时间内抓住听众注意力，讲清楚问题、方案、价值和可信度。

## 适用场景

- 创业比赛 Demo Day。
- 投资人初次会面。
- 公司内部项目提案。
- 社群/线下活动快速介绍。

## 3 分钟结构（180 秒）

```
0:00-0:20  钩子（Hook）
0:20-0:50  问题（Problem）
0:50-1:30  解决方案（Solution）
1:30-2:00  商业模式/ traction（Why now / Why you）
2:00-2:30  壁垒/团队（Moat / Team）
2:30-3:00  结尾/ call to action（CTA）
```

## 各环节要点

### 1. 钩子（0:00-0:20）

- 用一句话或一个场景让听众立即理解你在做什么。
- 避免行业黑话和复杂定义。
- 例："每年有超过 1000 万餐饮创业者，80% 死在第一年，我们帮他们算清每一笔账。"

### 2. 问题（0:20-0:50）

- 明确目标用户和痛点。
- 用数据或故事增强真实感。
- 例："小餐饮老板不会算成本，不知道自己每道菜赚多少，经常卖越多亏越多。"

### 3. 解决方案（0:50-1:30）

- 产品/服务是什么？
- 核心功能如何解决问题？
- 可展示 1 张关键界面或 Demo。

### 4. 商业模式/ traction（1:30-2:00）

- 怎么收费？已有多少用户/收入？
- 增长趋势如何？
- 如果没有收入，讲清楚验证到了哪一步。

### 5. 壁垒/团队（2:00-2:30）

- 为什么你能做？团队背景、数据积累、渠道优势。
- 不要罗列所有人，只讲关键成员。

### 6. 结尾/ CTA（2:30-3:00）

- 明确你想要什么：投资、合作、试用、引荐。
- 留下记忆点：一句话总结。

## 设计原则

1. **一个核心信息**：3 分钟只讲一件事。
2. **用户视角**：听众关心的是"这和我有什么关系"。
3. **故事化**：用具体的人/场景/数字，而不是抽象概念。
4. **视觉辅助**：1-3 张高质量幻灯片，不要文字堆砌。
5. **反复排练**：时间控制精确到秒。

## 常见错误

| 错误 | 表现 | 对策 |
|------|------|------|
| 超时 | 内容太多讲不完 | 删减到只剩核心 |
| 技术堆砌 | 大段讲模型/算法 | 一句带过，聚焦价值 |
| 缺乏 CTA | 讲完不知道要干嘛 | 结尾明确提出请求 |
| 假设听众都懂 | 用大量行业术语 | 用外行人能懂的语言 |
| 没有数字 | "市场很大""用户很喜欢" | 用具体数据说话 |

## 练习方法

1. **录音计时**：每次练习都录音，检查时间。
2. **找外行试听**：如果他们能听懂，说明表达清楚。
3. **准备 1 分钟版本**：万一时间被压缩，能迅速切换。
4. **准备 Q&A**：预判 5-10 个常见问题。

## 与相关方法的关系

- **电梯演讲**：更短（30-60 秒），但结构相似。
- **故事弧线**：开场-冲突-解决-结局。
- **AIDA 模型**：注意-兴趣-欲望-行动。
