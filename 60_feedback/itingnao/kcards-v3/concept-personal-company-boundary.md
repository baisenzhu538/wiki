# 概念卡：个人与公司财产的合规边界

## 一句话定义

公司是独立的法律主体，公司财产和个人财产必须分离；混同可能导致股东承担无限连带责任，并引发税务风险。

## 核心原则

### 1. 公司法人人格独立

- 公司以其全部财产对公司债务承担责任。
- 股东以其出资额为限承担责任。
- 这是有限责任公司的核心保护机制。

### 2. 财产混同的风险

当股东把公司账户当个人钱包使用时，可能触发"法人人格否认"（刺破公司面纱），股东需对公司债务承担连带责任。

### 3. 常见混同行为

| 行为 | 风险 |
|------|------|
| 用个人微信/支付宝收公司款项 | 收入不入账，涉嫌偷税 |
| 直接用公司账户给个人买房/消费 | 可能被认定为分红或抽逃出资 |
| 个人与公司资金随意往来无凭证 | 财务混乱，审计风险 |
| 用公司名义贷款供个人使用 | 可能构成挪用资金 |

## 合规做法

1. **分开账户**：公司收入必须进入公司账户。
2. **规范报销**：个人为公司垫付的费用，按报销流程处理。
3. **合理分红**：股东从公司拿钱，应通过工资、分红、借款（需还）等合法途径。
4. **保留凭证**：每一笔资金往来都有合同、发票、审批记录。
5. **按时纳税**：增值税、企业所得税、个人所得税分开申报。

## 股东合法从公司拿钱的途径

| 方式 | 税务处理 | 注意事项 |
|------|---------|---------|
| 工资薪金 | 代扣个税、社保 | 需实际任职 |
| 分红 | 20% 个人所得税 | 公司先缴企业所得税 |
| 报销 | 凭票报销，不缴税 | 必须真实业务相关 |
| 借款 | 无息借款可能视同分红 | 年底前归还或计息 |
| 劳务报酬 | 按劳务所得缴税 | 需真实提供服务 |

## 对创业者的启示

1. **从第一天就规范**：公司注册后就要分账，不要等做大再补。
2. **不要为了省税走私账**：短期省税，长期埋雷。
3. **找专业财务/法务**：合规成本远低于违规成本。
4. **融资前必须 clean up**：投资人尽调时混同是大问题。

## 局限性

- 具体规则因地区、公司类型、行业而异。
- 本卡为通用原则，不构成法律或税务建议。
- 重大决策应咨询持牌会计师或律师。
