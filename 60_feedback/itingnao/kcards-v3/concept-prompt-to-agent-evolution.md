# 概念卡：从提示词到智能体（Prompt → Agent）

## 一句话定义

从提示词到智能体的演进，是把 AI 从"一次性回答问题"升级为"能自主规划、调用工具、持续迭代完成复杂任务"的系统。

## 演进四阶段

```
提示词（Prompt）
  ↓
提示词模板（Prompt Template）
  ↓
工作流/链（Workflow / Chain）
  ↓
智能体（Agent）
```

### 阶段 1：提示词（Prompt）

- 单轮、静态指令。
- 例："请总结这段文字。"
- 局限：上下文短、无法处理复杂任务。

### 阶段 2：提示词模板（Prompt Template）

- 把提示词参数化，复用结构。
- 例："你是{角色}，请用{风格}总结以下{text}。"
- 价值：提高复用性和一致性。

### 阶段 3：工作流/链（Workflow / Chain）

- 多步骤、固定流程。
- 例：检索 → 摘要 → 生成 → 校验。
- 价值：完成更复杂的确定性任务。
- 局限：流程固定，无法应对意外情况。

### 阶段 4：智能体（Agent）

- 能根据目标自主决策下一步行动。
- 能调用外部工具（搜索、代码、数据库）。
- 能根据环境反馈迭代。
- 例："帮我调研竞争对手最近三个月的动态"，Agent 自动搜索、分析、汇总。

## Agent 的核心能力

| 能力 | 说明 |
|------|------|
| 目标理解 | 把模糊目标拆解为可执行子任务 |
| 工具调用 | 使用搜索、代码、API、数据库等 |
| 记忆/状态 | 维护上下文和中间结果 |
| 规划与反思 | 根据反馈调整计划 |
| 自我校验 | 检查输出质量，必要时重做 |

## 提示词、工作流、Agent 的选择标准

| 场景 | 推荐形态 | 理由 |
|------|---------|------|
| 单轮问答 | 提示词 | 简单直接 |
| 批量重复任务 | 提示词模板 | 标准化 |
| 多步骤确定性任务 | 工作流/链 | 可控、可预期 |
| 开放式、多变量任务 | Agent | 灵活、自适应 |

## 从工程角度看

- **提示词**：输入优化。
- **RAG**：给模型加外部记忆。
- **工作流**：把任务 SOP 化。
- **Agent**：让系统能自主执行 SOP 并动态调整。

## 当前落地现状

- 大多数企业级应用仍停留在"提示词模板 + RAG + 简单工作流"。
- 真正的 Agent 应用还在探索期，稳定性和成本是主要瓶颈。
- "Agent"一词被过度营销，很多产品只是把多个提示词串起来就自称 Agent。

## 实用建议

1. **先把工作流跑稳**：不要一上来就做 Agent。
2. **明确哪些步骤可以交给 AI 自主决策**：边界清晰再放权。
3. **建立监控和回退机制**：Agent 可能陷入循环或产生错误。
4. **从低风险的内部工具开始试点**：如代码审查、数据清洗。
