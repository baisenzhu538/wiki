# 概念卡：FDE 模式（Forward Deployed Engineer / 前沿部署工程师）

## 一句话定义

FDE 模式是指派遣技术工程师驻扎在客户现场，与客户共同工作，填补通用产品能力与特定客户需求之间的鸿沟，并把这些现场实践抽象沉淀为可规模化的平台能力。

## 核心要素

| 要素 | 说明 |
|------|------|
| 驻扎现场 | 工程师深入客户内部，而非远程销售或支持 |
| 交付结果 | 目标是解决客户实际问题并交付可量化成果 |
| 产品探索 | 把现场定制当作发现通用需求的过程 |
| 平台沉淀 | 总部产品团队将共性需求抽象为平台能力 |
| 长期关系 | 通过持续价值交付扩大合作范围 |

## 起源

- FDE 模式最早源于 **Palantir**（2000 年代中期）。
- 当时 Palantir 为美国情报机构开发软件，面临无法从外部了解客户工作流程的困境。
- 创始人 Stephen Cohen 带着产品原型去 CIA 展示，对方说"这和我们做的事一点关系都没有"。
- Cohen 反问"那你们希望它能做什么？"，由此开启现场协作模式。
- Palantir 早期员工 Shyam Sankar 将这一做法正式化为 FDE 战略。

## FDE 与咨询的本质区别

| 维度 | 传统咨询 | FDE 模式 |
|------|---------|---------|
| 目标 | 提供建议/交付项目 | 交付业务结果并沉淀产品 |
| 收费模式 | 按人天/按项目 | 按结果/按价值 |
| 责任 | 通常不对最终结果负责 | 对结果负责 |
| 可复制性 | 每个项目独立 | 经验沉淀到平台，可复制 |
| 客户关系 | 项目结束即结束 | 长期嵌入，持续扩大合作 |
| 利润率曲线 | 线性 | 早期可能为负，后期显著提升 |

## FDE 与 SaaS 的区别

| 维度 | 经典 SaaS | FDE 模式 |
|------|----------|---------|
| 产品形态 | 标准化、低定制 | 高度可定制平台 |
| 销售方式 | 销售主导，产品固定 | FDE 驻扎，共同探索 |
| 定价 | 订阅/按席位 | 结果导向，合同扩大 |
| 客户成功 | 远程支持 | 现场深度合作 |
| 适合场景 | 需求明确、产品成熟 | 需求未定、AI/Agent 等新兴领域 |

## 运作机制：碎石路到高速公路

```
客户现场
   ↓
FDE 发现具体需求
   ↓
用现有平台搭建临时方案（碎石路）
   ↓
验证价值，交付结果
   ↓
总部产品团队抽象共性
   ↓
沉淀为平台标准能力（高速公路）
   ↓
下一个客户只需轻量定制
```

## 为什么 AI 时代 FDE 火了

1. **AI Agent 没有标准形态**：每个客户需求差异巨大。
2. **产品探索成本高**：需要深入客户现场才能理解真实问题。
3. **合同金额大**：解决核心问题后客户愿意支付高价。
4. **数据飞轮**：现场经验持续优化平台能力。

## 关键角色

| 角色 | 名称 | 职责 |
|------|------|------|
| 行业专家 | Echo | 深度沟通客户，发现真实痛点 |
| 技术专家 | Delta | 现场快速实现解决方案 |
| 产品经理 | — | 将现场方案抽象为平台功能 |
| 平台工程师 | — | 把共性能力沉淀到平台 |

## 成功条件

1. **平台思维**：不能只满足单个客户，要能抽象共性。
2. **高层支持**：需要 CEO/高管级别的问题优先级。
3. **T 型人才**：FDE 需要技术深度 + 业务广度。
4. **耐心**：早期可能亏损，需要时间积累平台能力。
5. **组织纪律**：避免滑落成纯咨询服务公司。

## 风险与误区

| 风险 | 说明 |
|------|------|
| 变成咨询公司 | 只做定制，不做平台沉淀 |
| 前期亏损过大 | 没有清晰的路径把成本降下来 |
| 产品臃肿 | 把每个客户需求都塞进产品 |
| 人才稀缺 | 既懂技术又懂业务的 FDE 难招 |
| 客户依赖 | 过度依赖少数大客户 |

## 适用场景

- AI Agent/企业级 AI 落地
- 高度定制化 B2B 软件
- 新兴技术领域，尚无标准产品形态
- 客户问题复杂，无法通过远程销售解决

## 不适用场景

- 标准化程度高的通用 SaaS
- 客单价低、无法支撑重投入的市场
- 公司缺乏平台化能力和耐心

## 纠偏说明

此前本知识库曾将"FDE"误作"Factory Direct / 直供模式"，并已标记为废弃。FDE 的正确含义是 Forward Deployed Engineer（前沿部署工程师），源自 Palantir，当前硅谷 AI 创业公司广泛采用。
