# 概念卡：FD 模式（Factory Direct / 直供模式）

## 一句话定义

FD 模式是指工厂或品牌方绕过传统多级经销商，直接与大型零售终端或渠道平台建立供货合作关系，以缩短链条、提高效率、掌控终端。

## 与传统经销模式的区别

| 维度 | 传统经销模式 | FD 直供模式 |
|------|-------------|------------|
| 渠道层级 | 厂家 → 一批 → 二批 → 终端 | 厂家 → 终端/平台 |
| 价格控制 | 弱，层层加价 | 强，统一定价 |
| 终端掌控 | 弱 | 强 |
| 库存压力 | 分散在经销商 | 厂家承担更多 |
| 资金流 | 经销商垫资 | 平台/终端账期 |
| 数据反馈 | 慢且失真 | 快且直接 |

## FD 模式的典型玩家

| 角色 | 说明 |
|------|------|
| 品牌方/工厂 | 希望掌控终端、提升毛利 |
| 大型连锁/平台 | 希望减少中间环节、降低采购成本 |
| 物流服务商 | 承担仓储配送职能 |
| 信息系统 | 实现订单、库存、销售数据实时共享 |

## 核心优势

1. **毛利提升**：减少中间环节分润。
2. **价格稳定**：避免经销商乱价。
3. **终端洞察**：直接获取销售和用户数据。
4. **响应速度**：根据终端动销快速调整生产和补货。

## 主要风险

1. **资金压力**：厂家需要承担更多库存和账期。
2. **运营复杂度**：直接管理大量终端，组织要求高。
3. **渠道冲突**：原有经销商体系可能反弹。
4. **平台依赖**：过度依赖大平台会丧失议价权。

## 适用条件

- 品牌方有较强的生产和供应链能力。
- 终端规模大、标准化程度高。
- 信息系统能够支撑实时数据共享。
- 厂家愿意承担更多运营和资金压力。

## 与相关概念的关系

- **DTC（Direct to Consumer）**：直接面向消费者，FD 更偏向 B2B 直供。
- **O2O**：线上线下融合，FD 解决的是供应链效率问题。
- **渠道扁平化**：FD 是渠道扁平化的一种实现方式。

## 使用场景

- 评估是否要建立直供体系。
- 与传统经销商模式做对比分析。
- 设计渠道战略时引用。
