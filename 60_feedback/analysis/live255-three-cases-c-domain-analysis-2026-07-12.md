# 案例一：叶文彬·射箭馆 —— 公式完整度全场最高，但 A 目标始终缺席

## 1. 案例速写

汉风上弦射箭连锁，11 年，武汉/宜昌/重庆 17 家店，会员 8 万+。疫情+盲目扩张后剩 5 家老店，用一堂方法论重回 17 家。核心业务公式：**门店收入 = 进店量 × 办卡率 × 会员 ARPU × (1+裂变率)**，配 16 字口诀「一看就进，一进就买，一买再买，带人来买」。办卡率从约 10% 做到约 50%（同行 5-10 倍），回流礼品卡五轮假设迭代（回流率约 1%→10%+）。

## 2. ABC 建模诊断

**A（目标）—— 全场最大缺口。** 他开场给的是「利润 = 收入 - 成本」这个会计恒等式，然后直接跳到收入公式。**始终没回答：这个公式服务于什么目标？** 是单店利润最大化？17 店规模扩张？还是穿越周期的生存能力（他结尾说「核心转化率磨扎实，下限就不会太差」——这其实是生存目标，但从未被锚定为公式服务的对象）？

对照我在鑫港湾重做版的教训：**A 不锚定，公式就是无的放矢。** 叶文彬的四参数公式能跑通，靠的是九年试错的直觉补偿，但如果要做加盟复制（他正在做——要求加盟商先学一堂转化率课），没有锚定目标的公式无法回答「加盟商该优先保哪个参数」。

**B（参数）—— 全场最完整。** 四个核心参数 + 每个下面的子参数 + 几十个细颗粒参数，且有关键的**分层意识**：「新客办卡率和回流办卡率是同一个指标吗？——不是，转化路径完全不同」（L101-113）。这是 L3 分层参数的教科书示范。ARPU 拆成 8 个子转化率（到店率/组数消耗率/任务参与率/任务完成率/升卡率/器材试用率/购买率/课程私教率），参数下钻做到 -2 层。

**C（逻辑）—— 乘法结构正确，但混着一处未验证的假设。** `收入 = 进店量 × 办卡率 × ARPU × (1+裂变率)`：前三项乘法是算术恒等（L4 公式层），但「(1+裂变率)」这个加成项**隐含假设裂变带来的顾客与主渠道顾客同质量**——而他自己裂变公式还是 0.1 版（L1001），裂变客的办卡率/ARPU 是否与自然客相同，无数据。加法项里藏着一个 L2 级的未验证假设。

## 3. 参数冰山分层

| 层 | 命中情况 | 内容 |
|---|---|---|
| L1 基础 | **缺席** | 选址/商圈/楼层（江汉路店爬三楼就是 L1 参数的事故）从未进公式——但恰恰是他亏最惨的地方（盲目扩张 17→5 家）。L1 是选择型参数，选址即选命 |
| L2 财务 | ✅ | 客单价（20 元/组→59 元 3 组→108 元 6 组）、会员卡定价（500→388→300 调研后定） |
| L3 分层 | ✅✅ **全场最佳之一** | 新客 vs 回流办卡率区分；线下/线上/携友/回流四渠道进店拆分 |
| L4 转化 | ✅✅ | 办卡率 10%→50% 全程数据；8 个 ARPU 子转化率 |
| L5 创新 | ✅ **自创指标** | **「回流消费率」**——把「没办卡就走的人」从流失名单变成可追踪参数，五轮假设迭代打穿（1%→10%+）；**「组数消耗率」**——会员卡变余额卡的预警参数；「天选射手」达成率（教练可轻松教到 100 环以上——人为可设计的成就参数） |
| L6 本质 | ✅ **摸到了** | 「顾客买的不是射箭，是更好的生活状态：乐趣、健康、成就、朋友」（L699-703）。500 份调研（100 份深访）支撑，不是拍脑袋。**但他止步于认知，没有把 L6 落成可测量的魔法数字** |

**L6 裁定建议**：如果我是他的拆解教练，会追问——「生活状态」太诗意，落不成数字。射箭馆的 L6 本质参数候选：**会员 90 天到店率**（账号活跃=关系存活的唯一硬证据）。他自己说「徽章提升迁移成本」，迁移成本的观测指标就是 90 天到店率。这个数字同时是办卡率、ARPU、裂变率三个参数的共同父参数——会员不回来，一切归零。

## 4. 逻辑冰山定位

| 他使用的关系 | 层级 | 定级 | 风险 |
|---|---|---|---|
| 收入 = 四参数乘法 | L4 公式层 | 算术恒等 | 无 |
| 办卡率与门店利润强正相关 | L3 因果 | 有跨店数据支撑（22% vs 10% 门店对比） | 低 |
| 「59 元 3 组」→ 办卡率↑ | L3 因果（经自我修正） | 他先归因为沉没成本，后自己意识到真因果是「3 组=完整体验的载体」（L557-561）——**罕见的伪因果自我纠正** | 已化解 |
| 教练情绪价值 → 办卡率↑ | L2 相关 | 与「完整体验」混杂，未分离。夸赞/虚报分数有效，但哪个动作贡献多少，未知 | 中——复制到加盟店时可能动作走样 |
| 裂变公式（信任转移×体验承接×独立转化×反馈闭环） | L1 模糊 | 自述 0.1 版，四个因子均无独立测量 | **高**——这是全案唯一「看着像公式、实为口号」的部分 |

## 5. 段位诊断：L4（参数轴 L4-5 / 逻辑轴 L3-4）

**依据**：参数分层完整（L2-L5 全覆盖）+ 自创指标（回流消费率）+ 摸到本质（生活状态）= 参数轴 L4 偏 L5；逻辑侧有伪因果自我纠正的亮点，但裂变公式 L1、情绪价值 L2 未分离 = 逻辑轴 L3-4。

**上 L5 的路径**：①锚定 A（生存/复制/利润三选一，决定参数优先级排序）；②把 L6「生活状态」落成 90 天到店率这类可测参数；③裂变公式四因子各自找到测量口径，从 0.1 版升到 1.0 版。

## 6. 降龙十八掌对照

他无意中用对了的：拆解细节 3-5 层（✓）、MVP（回流券五轮迭代=假设池实战 ✓）、专家访谈（500 份调研 ✓）。**缺的**：关键路径（减法）——四参数齐头并进讲得很精彩，但「当前阶段哪个参数是生死线」从未排序（对比董原的「新生×新老师」单点聚焦，叶文彬是全面铺开型——这恰恰是 A 缺失的并发症：没有目标就无法排优先级）。

# 案例二：董原·舞蹈学校 —— 逻辑轴全场最高，C-D 循环的活教材

## 1. 案例速写

太原跃小兔少儿舞蹈，2016 年创立，学期制续费（非课时包），4 校区 3200+ 学员。单店续班率约 90%（22 春续秋约 94%），扩张后一路跌到 80% 低谷。先在窗口期把动力阻力触点「大招全开」只止跌未拉回，又把「作业率正相关」当因果狠抓大不及预期，最后退回业务公式，用分层参数定位「新生×新老师」双差结构破局，重回 90%+。这是三个案例里**唯一以 C 域方法论本身为叙事主线**的分享。

## 2. ABC 建模诊断

**A（目标）—— 三个案例里锚定最清晰的。** 「续班率几乎等于利润率，决定 LTV、CAC 上限、单元模型能不能成立」（L1281-1283）——一句话把目标、公式、决策门槛全部钉死：续班率 80% 是扩张停止线，90% 是扩张许可线。**A 锚定的最高境界：目标直接变成决策规则。**

**B（参数）—— L3 分层参数的全场最佳示范。** 续班率的两层拆法：
- 第一层（结构）：`续班 ≈ 平日积累 × 窗口期激活`（乘法两段）——把散点动作（教学/服务/活动）第一次串成链条
- 第二层（人群）：`R = 加权(r新生新师, r新生老师, r老生新师, r老生老师)`（加法加权）——2×2 矩阵定位双差格

「看总数以为整体都变差了，拆开才发现不是所有参数都在掉，而是某几个分层参数在拖垮整体」（L1599-1601）——这就是参数冰山 L3 层价值的教科书表述。

**C（逻辑）—— 全场最高，且自带伪因果抗体。** 她亲身踩了「作业率正相关→当因果狠抓→大不及预期」的坑，然后自己复盘出「相关≠因果，背后可能有中间变量」（L1615-1629）。更狠的是她在结尾把这个问题抛给全场自查：「你现在业务里有没有某个指标，看起来和结果高度相关，于是你已经默认它就是因果关系了？」——**自己掉过的坑，提炼成了可迁移的检验问题。**

## 3. 参数冰山分层

| 层 | 命中情况 | 内容 |
|---|---|---|
| L1 基础 | 缺席 | 选址/城市/商圈未进分析（太原四校区选址差异只字未提——但第四个校区引流转化率低时，她拒绝「区域经济弱」的笼统归因，改拆渠道意向分层，算是用 L3 绕开了 L1） |
| L2 财务 | 薄 | 客单价（2000+/学期）提到但未建模；CAC 上限说了「由续班率决定」但没展开成公式 |
| L3 分层 | ✅✅✅ **全场最佳** | 新生/老生 × 新老师/老老师 2×2 矩阵；高意向 vs 低意向渠道分层（四校区引流案例）；低龄 vs 三四年级后家长需求分层（中考班的依据）——**三层不同的分层维度，每层都导向不同动作** |
| L4 转化 | ✅ | 续班率全程数据（94%→80%→90%+）；引流体验课付费转化率 75%+ |
| L5 创新 | ✅✅ **质量最高的 L5** | **「喜欢老师」参数化**——把一个人人会说、无人能测的虚词，下沉为「可判断、可训练、可复盘」的参数（月度盘新学员）；**「安全依恋」进 SOP 考核**——心理学概念落成课前/课中/课后动作；**固定助教留存率/师训通过率**——「新老师快速合格」的 -1 层里程碑参数 |
| L6 本质 | ✅ 摸到 | 「续班不是销售最后那一下，是一个学期交付之后，家长和孩子投出的信任票」（L1281）+「对非标服务型业务，老师不是后台资源，老师就是产品体验的一部分」（L1685）——后者就是跃小兔的 L6：**非标服务的可复制化能力**，单元模型的真正天花板 |

**L6 裁定**：她的 L6 已经相当接近本质——「老师就是产品」这句话决定了跃小兔的扩张速度上限 = 新老师合格速度，而不是资金或选址。如果继续追问魔法数字：**新老师首班续班率 ≥80% 才能开新校区**——把 L6 落成扩张决策的硬门槛（她事实上已经在这么做：「解决不了就不能再扩张」）。

## 4. 逻辑冰山定位

| 关系 | 层级 | 定级 | 备注 |
|---|---|---|---|
| 续班率 → LTV/CAC 上限/单元模型 | L3 因果 | 学期制商业模式下结构性强 | 低 |
| 续班 ≈ 平日积累 × 窗口期激活 | L3 因果 | 访谈证据支撑（续班好的老师讲的都是平日） | 低 |
| 作业率 ↑→ 续班率 ↑ | ~~L2 相关~~ | **亲身证伪**——硬拉后不及预期，可能增负反噬 | 已化解，并提炼成教学案例 |
| 新老师能力 → 续班率 | L3 因果 | 分层数据直接证据（70% vs 85%） | 低 |
| **扩张 → 参数构成与权重变化 → 单元模型动态变化** | **L5 系统层** | 全场唯一的系统层洞察：「扩张不是 1:1 复制，它改变业务公式里参数的构成与权重」（L1605-1609） | **这是 L5 级认知**——大多数经营者死在把扩张当算术 |

## 5. 段位诊断：L4 上段（参数轴 L4 / 逻辑轴 L4-5）

**依据**：参数轴——L3 三层分层 + L5 三个高质量创新参数 = L4 扎实（没到 L5 是因为收入侧公式没展开：获客成本、满班率、教室利用率这些参数缺席，公式只有续班一条腿）；逻辑轴——伪因果亲身证伪 + 系统层洞察（扩张改变参数权重）+ C-D 循环的方法论自觉 = **摸到 L5**。

**上 L5 的路径**：把收入侧公式补全（续班率只是留存腿，获客腿只有「艾莎公主舞会+75% 转化率」的碎片），让单元模型完整可算；然后把「新老师合格速度」作为扩张节奏的约束条件写进模型——那时跃小兔的公式就从「诊断工具」升级成「扩张仪表盘」。

## 6. 降龙十八掌对照

用对的：专家访谈（破局起点=访谈续班好的老师 ✓）、关键路径（减法做到极致——所有动作让路给「新生×新老师」一格 ✓）、看确定性（窗口期动作确定性低→转向平日积累 ✓）。**缺的**：她自己也说了——「成材组→集中师训→固定助教」的机制不是设计出来的，是「从真实问题里长出来的」（L1715）。这是诚实的复盘，但也暴露：**L1 的致命假设管理缺位**——扩张前如果做过假设分级，「新老师供给速度」本该被识别为致命假设（它错了全盘皆输），而不是跌到 80% 才回头发现。

# 案例三：谢泽丰·服装店 —— L5 创新参数的标准挖法，但因果方向留了一道口子

## 1. 案例速写

广州泽择男装，4 家店，客单价 600-800，红海批发市场商圈。前史：父辈 2018 年未验证就 2 个月开 30 家店，亏约 3000 万止损。泽择靠错位竞争赚两年→竞争抹平→换供应商/签独家/改提成/换店长全无效→25 年重学一堂，花一个月搭数据基建（专人数人头、计数器、写正字），拿到首批真实数据（进店率约 17%/触摸率 93%/试穿率 19%/付款率 60%），送水假设把进店率做到约 100% 但销售额零变化→重建公式定优先级→**挖出「二次试穿」创新参数（试 2 次成交约 89%）**，门店转化率约 11%→18%（↑约 63%），音量 Magic Number 80，进店率约 19%→30%，14 个月综合营收约 +16%。

## 2. ABC 建模诊断

**A（目标）—— 明确但单薄。** 目标是「门店营收」（后期降级为「稳住销售额」），公式三版迭代都围着它转。但**利润视角全程缺席**——客单价 600-800 的服装店，毛利率、库存周转、折扣率一个都没进公式。送水假设他认真算了单杯 ROI（<0.95 元不亏），说明他有成本意识，但没有升级成单元模型视角。父辈亏 3000 万的主因是库存积压（L2026），而库存这个杀死上一代业务的参数，在他的新公式里依然缺席。

**B（参数）—— 迭代三版，终版质量高。**
- 第一版（数学直觉）：`营收 = 总客流 × 进店率 × 触摸率 × 试穿率 × 付款率 × 客单价`——6 参数平铺，无数据无对标，「完全没有抓手」
- 第二版（优先级重建）：`收入 = 进店人数 × 门店转化率 × 客单价`——孔源点拨后回归三参数，先做优先级判断
- 第三版（分层下钻）：`进店率 = 看到率 × 看到进入率`、`客单价 = 购买件数 × 商品单价`——每层都可测可打

**公式从平铺到分层到可测的进化过程本身，就是 C 域教学的活素材。**

**C（逻辑）—— 优先级判断是亮点，因果分离留口子。** 「转化率不稳时扩流量=更大浪费，先把转化率打扎实再扩流量入口」（L2430-2432）——这是 L4 级的逻辑判断（参数间有依赖顺序，不是并列关系）。但二次试穿的因果方向见下文。

## 3. 参数冰山分层

| 层 | 命中情况 | 内容 |
|---|---|---|
| L1 基础 | 半命中 | 商圈人流 800-1000/天（实测！）、批发市场「来人就为买衣服」的场景属性——他意识到了 L1（对标头部失败就是因为场景不同），但没把「选商圈」上升为选择型参数 |
| L2 财务 | 薄 | 客单价 600-800 只作背景；购买件数×商品单价拆出来了但未见动作 |
| L3 分层 | ✅ 后天补上 | 用户画像/性别年龄/流失原因/成交原因——数据维度迭代史（5/29→6/9 四轮扩展）就是 L3 分层从无到有的过程 |
| L4 转化 | ✅✅ | 进店/触摸/试穿/付款四率全实测；转化率 11%→18% |
| L5 创新 | ✅✅✅ **全场最标准的 L5 挖法** | **二次试穿率**——不是拍脑袋想的，是从行为数据里挖出来的（试穿次数分布→发现 2 次拐点 89%→验证 3-5 次无增量→聚焦轰假设）。**「看到率」**——站门口观察发现约 50%，「什么都没干就流失一半」——行为观察挖参数 |
| L6 本质 | ⚠️ 有魔法数字，无本质 | Magic Number 80（音量）是情境化的经验数值，他自己也没声称这是本质。**真正的 L6 候选他没说破：试穿 = 服装零售的体验代理，二次试穿率 = 顾客兴趣深化的可观测信号**。本质是「体验深度决定成交」——这和叶文彬的「3 组起步=完整体验」、董原的「平日积累」是同一个 L6 在不同行业的化身 |

## 4. 逻辑冰山定位：必须指出的一道口子

| 关系 | 层级 | 定级 | 风险 |
|---|---|---|---|
| 收入 = 进店人数 × 转化率 × 客单价 | L4 公式层 | 算术恒等 | 无 |
| 转化率不稳→扩流量=浪费 | L4 公式层（约束关系） | 优先级判断正确 | 无 |
| 送水→进店率 100%→销售额不变 | L5 系统层教训 | 亲身验证：单点优化被系统吸收（非潜在客户涌入+店员接不住） | 已化解，成教学案例 |
| **二次试穿→成交 89%** | **L2-L3 之间** | **⚠️ 因果方向未分离**：是「试第二件导致成交」，还是「高意向客户本来就愿意试第二件」？自我选择偏差未排除 | **中**——他围绕它轰假设后转化率 11%→18%，方向性实战验证成立，但机制可能是「劝试第二件的动作筛选出了高意向客户+给了店员二次服务机会」，而非试穿次数本身的魔力。不影响动作有效性，但影响**参数的可迁移性判断** |
| 对话率→成交 | L1 模糊 | 跟踪数月无效（无控制变量） | 已识别，止损 |

**这道口子的 C 域意义**：谢泽丰挖 L5 的方法（数据挖拐点→假设驱动验证）是标准的，但他少了董原那步「相关 vs 因果」的显式检验。两个案例对照看恰好互补：**谢泽丰示范了 L5 怎么挖，董原示范了挖到之后怎么验。** 理想的 L5 工作流 = 谢的挖法 + 董的验法。

## 5. 段位诊断：L4（参数轴 L4-5 / 逻辑轴 L3-4）

**依据**：参数轴——L5 创新参数×2（二次试穿+看到率）+ 魔法数字 + 数据基建自觉 = L4 偏 L5（不到 L5 是因为 L6 本质未触及、利润参数缺席）；逻辑轴——优先级判断 L4 + 控制变量意识 + 送水教训的系统层反思，但二次试穿因果未分离、对话率无控制变量白跑数月 = L3-4。

**上 L5 的路径**：①补利润腿（毛利率/库存周转/折扣率进公式——父辈的坑不能白踩）；②给二次试穿做一次因果分离实验（随机劝试 vs 自然试穿的对照）；③把「体验深度」从直觉上升为 L6 本质参数。

## 6. 降龙十八掌对照

用对的：MVP（卖别人的货验证需求=轻量 MVP 典范 ✓）、收集数据（一个月数人头=笨办法但真实 ✓）、专家访谈（孔源一句话点醒=外部视角 ✓）。**缺的**：他的管理范式升级（「默认假设不成立，先验证」L2609-2613）已经摸到假设管理门槛，但假设分级还没做——哪些假设错了会致命（如：批发市场的批零结合趋势反转），哪些只是优化，没有分层。

# 综合：三案例的 C 域对位表与教学价值

## 段位矩阵

| C 域维度 | 叶文彬 | 董原 | 谢泽丰 |
|---|---|---|---|
| A 目标锚定 | ❌ 缺席（会计恒等式代替目标） | ✅✅ 目标=决策规则 | ⚠️ 有营收无利润 |
| B 参数完整性 | ✅✅✅ 四参数+几十个细参数 | ✅ 续班单腿深钻 | ✅ 三版迭代终版扎实 |
| L3 分层 | ✅✅ 新客/回流+四渠道 | ✅✅✅ 三层分层维度 | ✅ 后天补上 |
| L5 创新参数 | ✅ 回流消费率（自创） | ✅✅ 喜欢老师参数化 | ✅✅✅ 二次试穿（数据挖） |
| L6 本质 | ✅ 摸到未测量 | ✅ 摸到（老师即产品） | ⚠️ 有魔法数字无本质 |
| 逻辑定级 | L3-4（伪因果自我纠正） | **L4-5（系统层洞察）** | L3-4（因果未分离） |

## 三个案例拼出的 C 域全景

1. **叶文彬 = 「公式怎么建」的样板**：从会计恒等式出发，逐层拆出四参数乘法结构，每参数再下钻子参数——建公式的完整路径。他的盲区（A 缺席、L1 缺席、假设不分级）恰好说明：**公式完整 ≠ 体系完整**。

2. **董原 = 「公式怎么用」的样板**：指标下跌→D 域猛打无效→退回 C 域重拆→分层定位真战场→回 D 域打穿。她的 C-D 循环和「扩张改变参数权重」的系统层认知，是三个案例里逻辑轴最高的。她的盲区（致命假设未前置）说明：**复盘能力强 ≠ 前置管理强**——她是救火型高手，还没进化到防火型。

3. **谢泽丰 = 「参数怎么挖」的样板**：数据基建→实测四率→单点误判→重建公式→数据挖拐点找到 L5。他的「二次试穿」挖法是最标准的 L5 工作流，但缺董原的因果检验。他的盲区（利润腿缺席）说明：**转化率思维强 ≠ 单元模型思维强**。

## 对 C 域体系的三个反哺洞察

1. **三个案例的共同盲区是 L1**：选址/商圈/城市——三个线下生意，没有一个把「选择型参数」放进公式。叶文彬爬三楼、谢泽丰对标错场景、董原四校区经济差异，全是 L1 事故。**C 域教学应强化：L1 不进公式，公式就在假装选址免费。**

2. **L5 创新参数有两种合法来源，案例恰好各示范一种**：谢泽丰的「数据挖拐点」（行为数据→分布异常→假设验证）和董原的「虚词参数化」（喜欢老师→可判断可训练）。两种都成立，但都必须过因果检验——这条可以写进参数冰山卡。

3. **C-D 循环的真实形态是「打不动就退，找到就回」**：董原总结得最清楚（D 打不动→退 C 找参数→回 D 打穿）。三个案例加上鑫港湾，全部印证：**C 域的价值不在公式本身，而在「做错了能退回哪里」——公式是经营的撤销键。**
