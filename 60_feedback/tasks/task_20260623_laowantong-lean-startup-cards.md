### 1.2 9 层深挖标注（域级）

| 层级 | 标注 |
|------|------|
| **L1 表面业务公式** | 精益创业的价值公式：`降低的系统性风险 ÷ 投入的试错成本`。一堂将其操作化为：用最低成本工具（FALSE 模型左侧）验证最高风险假设，从而避免“全量投入后发现方向错误”。 |
| **L2 假设审计** | 关键假设链：需求存在 → 产品内核成立 → 商业模式成立 → 增长渠道可扩展 → 壁垒可建立。前置假设（需求、产品）一旦错误，后续投入全部浪费。一堂的 ABCD 模型和五步法都是这条链路的结构化表达。 |
| **L3 政策/合规边界** | “假页面”“假产品”“假营销”在消费品、医疗、教育、金融、博彩等领域受广告法、医疗器械法规、教培监管、金融监管约束。案例中的“共享彩票机”即涉及合规风险，但课程未充分展开。卡片中需明确：监管敏感领域不能照搬 FALSE 模型左侧手段。 |
| **L4 失败模式库** | 六宗罪已系统归纳：问题找错、方案做错、过早细化、过早扩张、闭门造车、转型过慢。每张 case 卡必须提取共因和预警信号。 |
| **L5 隐性成本与替代方案** | 隐性成本：团队信心、时间窗口、机会成本、品牌损伤、认知负荷。替代方案：传统市调、行业专家咨询、竞品对标（“找老的干小的”）、咨询公司报告。课程过度强调“实验”，对“调研和经验验证”的优先级表述在张磊 AMA 中更完整。 |
| **L6 人与组织执行能力** | 需要一号位亲自下场、团队接受“默认失败”文化、具备假设拆解能力。完美主义、害怕抄袭、恐惧失败是最大执行障碍。 |
| **L7 市场情绪与叙事** | “AI 让验证成本归零”存在过度乐观叙事；“憋大招”受东方面子文化/工程师文化强化。卡片需保持审慎，不助长“工具万能论”。 |
| **L8 边界案例 / 反例** | 强监管行业（医疗、金融）、长周期硬件（导盲机器狗 1800 万教训）、B2B 长决策链（假页面价值低）、品牌敏感型产品（粗糙 MVP 损伤信任）是精益手段的边界。 |
| **L9 可执行决策框架** | 阶段判断 → 假设拆解 → 优先级排序 → 选择验证手段（调研 < 经验 < 实验）→ 设计 MVP → 定义通过/不通过标准 → 螺旋上升。 |

## 4. 每张卡的统一内容要求

### 4.1 Framework 卡

必须包含：
- **一句话定义**：用 1 句话说明框架解决什么问题。
- **核心模型/图示**：表格或结构化描述，还原讲义核心结构。
- **与经典理论的关系**：明确哪些部分来自 Eric Ries/Steve Blank，哪些是一堂归纳/本土化。
- **适用边界**：什么场景适合，什么场景不适合。
- **失败模式**：使用这个框架时常见的 2-3 个错误。
- **案例映射**：至少 1 个正例 + 1 个反例。

### 4.2 Tool 卡

必须包含：
- **一句话定义**：这个工具验证什么假设。
- **操作步骤**：分步骤说明怎么用。
- **成本/周期/样本量**：与产品形态和阶段相关的经验参考。
- **适用边界**：什么产品形态、什么阶段最适合。
- **失败模式**：至少 2 个典型错误。
- **案例映射**：至少 1 个案例。

### 4.3 Case 卡

必须包含：
- **核心洞察**：一句话结论（王语嫣重点检查项）。
- **事迹/背景**：项目是什么、做了什么。
- **关键数字**：投入、损失、周期、转化率等，必须标注来源和可信度。
- **失败原因/成功原因**：按六宗罪或 FALSE 模型拆解。
- **可迁移场景**：读者在什么情况下可以套用。
- **教训与预警信号**：至少 2 条。

