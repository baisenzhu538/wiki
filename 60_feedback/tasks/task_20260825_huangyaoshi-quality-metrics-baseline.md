## 任务

   - FAIL 率（终审 fail/总审）——数据源：gate-blocked.log + 任务单终审记录节

   - 门禁拦截率（gate-blocked 拦截分类统计：F-034/F-035/处置门禁）——数据源：gate-blocked.log
   - 误判率（机器拦截后人判放行比例）——数据源：force-exceptions.log + 处置记录
2. 指标口径定义由风清扬定（本单执行前先对齐口径文档一节，落 90_control/ 或指标脚本头部注释）

4. 挂每日健康检查或独立定时（黄药师定，失败可见不静默）
