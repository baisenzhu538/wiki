# 任务 #68：Y模型 引擎层操作法卡

## 任务目标

产出一张 method 卡（建议 id：`method-yitang-y-model-engine-cycle`），把 Y模型 从「分析框架」重新定位为「迭代发动机」，并给出可执行的操作步骤、自检清单和常见陷阱。

## 核心命题

1. Y模型 不是一次性的分析工具，而是持续运转的认知引擎。
2. 每次循环都更新「基础框架认知」，而不是在固定框架内填空。
3. 循环速度和质量，取决于能否快速做小实验、快速推翻旧认知。
4. 双三角是 Y模型 在 AI 协作领域循环后的产物之一；其他领域也可以用同一发动机。

## 卡片必须包含的内容

### 1. 引擎层循环图

```
目标（要解决的真正问题）
  ↓
基础框架认知（朴素的、可错的、第一版）
  ↓
理论侧：科学类比 + 提炼建模
实践侧：假设驱动 + 定性定量
  ↓
实事求是（校准：哪些是事实？哪些只是假设？）
解放思想（突破：还有哪些隐含假设？）
  ↓
更新后的基础框架认知
  ↓
真正的认知（可指导行动的、经过验证的）
  ↓
知行合一（执行、产生资产、沉淀飞轮）
  ↓
新一轮目标（更高分辨率的问题）
```

### 2. 操作步骤

| 步骤 | 动作 | 产出 |
|:---|:---|:---|
| 1 | 定义一个具体的、可验证的目标 | 目标陈述 |
| 2 | 写下当前对这个领域的朴素框架认知 | 框架认知 V1 |
| 3 | 理论侧：找 2-3 个跨领域类比，提炼一个临时模型 | 类比清单 + 临时模型 |
| 4 | 实践侧：提出 3 个可证伪假设，设计最小验证 | 假设 + 实验设计 |
| 5 | 运行实验，记录事实与反馈 | 实验日志 |
| 6 | 实事求是：区分事实、假设、信念 | 校准表 |
| 7 | 解放思想：列出所有隐含假设，逐一挑战 | 假设清单 |
| 8 | 更新框架认知 V2 | 框架认知 V2 |
| 9 | 知行合一：用新认知解决真实问题 | 解决方案 + 资产 |
| 10 | 记录飞轮，启动下一轮 | 飞轮记录 |

### 3. 自检清单

- [ ] 我是否只是填表，还是在真正更新认知？
- [ ] 我的假设是否可证伪？
- [ ] 我区分了事实、假设和信念吗？
- [ ] 我是否有意识地挑战了隐含假设？
- [ ] 这一轮产出了什么可复用资产？
- [ ] 下一轮的问题是否比上一轮更清晰？

### 4. 常见陷阱

| 陷阱 | 表现 | 解法 |
|:---|:---|:---|
| 静态化 | 把 Y模型 当固定分析模板 | 强调每一轮都要更新框架认知 |
| 过度抽象 | 只画图，不落地 | 每个阶段必须有具体动作和产出 |
| 硬套 | 把业务事实削足适履塞进模型 | 模型服务事实，不是事实服务模型 |
| 单次循环 | 跑完一轮就结束 | 必须明确下一轮目标和飞轮 |
| 人在环教条 | 人什么都管 | 人只管关键节点，其余交给飞轮 |

### 5. 与双三角的关系

- 双三角是 Y模型 在 AI 协作领域跑出来的一个框架产物
- 用 Y模型 引擎去跑新的 AI 协作问题，双三角是起点框架；但跑完后框架本身会被更新
