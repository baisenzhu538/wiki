# 任务 #87：口喷 Skill——双三角内功 + 九字诀外功

## 来源

口述稿 L2330-2610。Truman 完整定义了口喷方法论并现场演示。

## 任务目标

产出 1 个 Skill 文件（`40_outputs/capabilities/skills/dual-triangle-oral-spray/SKILL.md`）+ 1 张 tool 卡。

## 核心内容

### 1. 口喷的核心公式

```
口喷 = 双三角（内功/心法） + 九字诀（外功/动作）
```

- **内功**：脑子里装双三角六要素，目标是一次性喷干净，"喷得不能再喷为止"
- **外功**：九字诀——定目标（要做什么）、控节奏（分几个里程碑）、做纠偏（边界和约束）

### 2. 操作步骤

1. 打开语音输入（口述稿 L2364：口语覆盖 95% 场景，打字只用于长结构化输出）
2. 脑子里过一遍六要素：缺什么？需要补什么数据？边界在哪？
3. 开始喷——不管逻辑完美不完美，"喷满"优先于"喷对"
4. 喷完让 AI 整理成计划文档→确认→执行

### 3. 两个关键好处

- **快**：比打字快 3-5 倍
- **上下文更丰富**：口语会带出打字时会省略的额外信息（L2374）

### 4. Skill 结构

- `## 内功准备`：喷之前双三角六要素的脑内 checklist
- `## 九字诀操作`：定目标/控节奏/做纠偏的每一步
- `## 收尾`：喷完让 AI 整理→确认→分里程碑执行
- `## 刻意练习路径`：口喷次数 × 双三角调用次数 = 学习速度
