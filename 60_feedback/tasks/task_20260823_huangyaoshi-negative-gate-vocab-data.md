## 范围（修正落点）

1. **进强词 STRONG**：`为空`、`空值`。理由：明确负向断言，子串误伤面小。
2. **不进强词，走正则 PATTERN 或 SOFT 观察**：`截断`、`损坏`、`乱码`、`半写`。理由：它们高频出现在正向核查声明里（「无截断」「确认无损坏」），直接子串硬拦会自伤。实现优先配断言句式（如 `(?:字段|值|数据|内容|文件).{0,6}(?:为空|损坏|截断|乱码|半写)`），拿不准先 SOFT 标人工。
3. **不进门禁词表**：「数据视图声明」（完整读取 / 截断视图+截断点）——这是验证方法纪律，归王语嫣审查 SOP/#419 话术线，与欧阳锋「双假设原则」并列。
