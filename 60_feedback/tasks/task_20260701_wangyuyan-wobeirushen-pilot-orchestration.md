### 3.2 卡 2：AI 使用杠铃策略

| 项目 | 内容 |
|:---|:---|
| ID | `tool-ai-use-barbell-strategy` |
| 类型 | tool |
| 标题 | AI 使用杠铃策略：把任务分成「高 AI 区」和「无 AI 区」 |
| 主域 | ai-collaboration |
| 桥接域 | learning-methodology、decision-making、content-production |
| 核心命题 | 中间地带（50% AI）最危险：既想省时间，又说不清楚保留什么能力。杠铃策略要求把任务明确分到「90%+ AI」或「0-10% AI」两端 |
| trust_level | medium |

**必须包含的 section**：
1. **When to Use**：感觉能力在退化、团队对 AI 使用边界模糊、学习效率下降、产出同质化。
2. **Steps**：
   - 列出最近一周高频认知任务；
   - 按「能否由 AI 独立完成且后果可控」打分 0-10；
   - 9-10 分进高 AI 区，0-1 分进无 AI 区，中间分数必须重新拆分或升级/降级；
   - 为无 AI 区设定触发器和保护时段；
   - 每周审计真实分配 vs 计划分配。
3. **Examples**：
   - 写作：初稿生成用 AI，但核心论点和修改意见必须手写；
   - 编程： boilerplate/测试补全用 AI，但架构决策和关键 bug 定位先人工推演；
   - 学习：概念理解先读原典 30 分钟，再用 AI 答疑；
   - 决策：信息整理用 AI，最终判断必须无 AI 会议/纸笔推演。
4. **Checklist**：≥5 项自检问题。
5. **Anti-patterns**：中间地带陷阱、全有全无、把边界当 rigid 规则、只做个人不做团队。
6. **Critique**：
   - 外部反对者 1：Pinker / Kelly「工具不会让人变笨」；
   - 外部反对者 2：Taleb 原教旨杠铃者「AI 是高风险黑箱，应把绝大多数认知任务放在无 AI 区」；
   - 外部反对者 3：AI 激进派「未来 AGI 会接管，保留人类低效能力无意义」；
   - 内部局限：基于二手素材，缺乏原书完整操作步骤；需要用户自行校准个人/团队的 AI 容忍度。
7. **Synthesis**：桥接 `concept-cognitive-offloading-in-ai-era`、`tool-纪浩-AI使用边界管理法`、`master-antifragile-checklist`、`framework-ai-deliberate-practice-loop`。
8. **Related**：≥5 条，含跨域回链。

**与 `master-antifragile-checklist` 的边界**：反脆弱清单的杠铃用于资源/风险分配（投资、项目组合、时间），本工具仅用于 **AI 使用强度分配**，不重复。

### 3.3 卡 3：富足悖论

| 项目 | 内容 |
|:---|:---|
| ID | `concept-abundance-paradox` |
| 类型 | concept（可带 dk 视角） |
| 标题 | 富足悖论：为什么技术越富足，新问题越多 |
| 主域 | decision-making |
| 桥接域 | ai-collaboration、master、entrepreneurship |
| 核心命题 | 技术/资源富足会解决旧稀缺问题，但同时释放新的心理、社会、伦理问题；决策者必须把「富足带来的副作用」纳入因果模型 |
| trust_level | medium |

**必须包含的 section**：
1. **Definition**：富足悖论 =  abundance 解除旧约束后，新约束以另一种形式出现；不是反对技术进步，而是反对把富足当成无代价。
2. **Mechanism**：
   - 旧约束消失 → 行为模式改变；
   - 行为模式改变 → 新的外部性/心理成本；
   - 新成本被低估，因为叙事仍停留在「解决了旧问题」上。
3. **Examples**（每个都需区分「旧问题被解决」和「新问题被释放」）：
   - 内燃机： mobility 富足 → 气候危机 / 城市扩张；
   - 社交媒体： 信息富足 → 注意力稀缺 / 极化；
   - AI 生成： 内容富足 → 审美基准下滑 / 认知卸载退化；
   - GLP-1/长寿： 食物/寿命富足 → 社会伦理、医疗资源分配新问题（只做概念讨论，不给医疗建议）。
4. **Decision Triggers**：在哪些决策场景必须调用此概念——评估新技术采纳、评估社会/政策建议、评估个人效率工具。
5. **When NOT to Use**：
   - 不可用来反对所有技术进步；
   - 不可把「富足悖论」当成宿命论；
   - 不可在缺乏具体副作用证据时滥用。
6. **Critique**：
   - 外部反对者 1：技术乐观主义者「富足本身不是问题，分配和政策才是」；
   - 外部反对者 2：反技术保守主义者「所有富足都是代价」；
   - 外部反对者 3：经济学家「只要市场有效，副作用会被定价」；
   - 内部局限：本书案例多为单向叙事，缺少严格因果识别；部分案例（如 Universe 25）类比人类社会需谨慎。
7. **Synthesis**：桥接 `concept-cognitive-offloading-in-ai-era`、`master-antifragile-checklist`、`framework-decision-hygiene`、`concept-ai-information-quality-ladder`。
8. **Related**：≥5 条，含跨域回链。
