# 任务 #89：知识站场建设 Workflow

## 来源

口述稿 L462-600。Truman 做 PPT 的心态转折——从"试工具→失败→清零"切换到"建知识站场→持续积累→花开了"。

这是 Y模型 引擎层在个人能力建设中的**具体操作化**。

## 任务目标

产出 1 张 method 卡 + 1 个 Workflow 定义。

## 核心内容

### 1. 知识站场的定义

一个主题的知识下层（Home）——把关于这个主题的所有认知、模型、审美、数据、工作流堆到一个系统里。不是项目文件夹，是**能力积累的容器**。

### 2. 建站流程

```
选一个要攻克的高价值场景
  → 建 Home 目录（知识站场）
  → 往里堆：
    □ 审美：最佳实践、标杆案例、打分标准
    □ 体系：工作流、里程碑、方法论
    □ 数据：历史案例、模板、测试集
    □ 基本功：可用工具清单、Feature 组合
  → 持续测试：项目来了就用，失败了就补
  → "结果不好，只是积累未到"
  → 积累足够 → 花开了
```

### 3. 心态切换才是核心

口述稿 L446-500 的关键：
- **旧心态**：试 3-5 天→不行→扔掉→清零→丧
- **新心态**：项目失败但资产增长→补审美/补工作流/补数据/补工具→积累到一定程度自然行
- **核心信念**："结果不好，只是我的积累未到"

### 4. 对 KDO 的应用

- 每个新域上线 = 建一个知识站场
- KDO 的 domain 目录结构本身就可以按知识站场组织
- Agent 协作也可以用这个模式：Agent 的输出→存进站场→下次更强
