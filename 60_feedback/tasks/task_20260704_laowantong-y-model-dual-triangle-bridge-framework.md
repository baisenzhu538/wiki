# 任务 #66：Y模型 × 双三角协同工作法框架卡

## 任务目标

产出一张 framework/method 卡（建议 id：`framework-yitang-y-model-dual-triangle-synergy` 或 `method-yitang-dual-triangle-y-model-cycle`），明确：**双三角不是 Y模型 的静态应用框架，而是 Y模型 作为迭代发动机在 AI 协作领域一轮一轮跑出来的产物。**

## 核心命题

1. 一个人入门某个领域的标志：形成对这件事基础的、朴素的、底层的框架性认识。
2. **Y模型 是迭代发动机，不是分析工具**：从目标出发，每次循环都更新基础框架认知。
3. 双三角六要素，就是 Y模型 在 AI 协作领域多轮循环后沉淀的框架性认识。
4. **人在环是这一轮循环的起点原则**；双三角是这一轮循环成熟后的结构化产物。

## 卡片必须包含的内容

### 1. Y模型 引擎层循环图

必须画出或描述引擎层循环，而不是静态分析流程：

```
目标
  ↓
基础框架认知（朴素的、会错的、第一版六要素草稿）
  ↓
理论侧迭代：科学类比 + 提炼建模
实践侧迭代：假设驱动 + 定性定量
  ↓
实事求是（校准） + 解放思想（突破）
  ↓
更新后的基础框架认知（六要素 V2 / V3 / Vn）
  ↓
真正的认知
  ↓
知行合一 → 解决问题 / 产生资产 / 沉淀飞轮
  ↓
新一轮目标 + 更高分辨率的基础框架认知
```

关键说明：每一轮循环都会**升级基础框架认知**，而不是只在固定框架内填空。双三角六要素本身就是多轮循环后的产物。

### 2. 双三角诞生的引擎层叙事

卡片中必须包含以下历史叙事（由口述素材支撑）：

| 阶段 | 状态 | 关键动作 |
|:---|:---|:---|
| 0. 人在环起点 | 朴素原则：AI 生成、人类判断 | 定义了人机协作的基本伦理和最小闭环 |
| 1. 案例驱动 | 大量具体案例（PPT/贝壳/酒店/硬件/D同学等） | 每个案例都暴露一个盲区 |
| 2. 框架粗胚 | 发现需要「审美、体系、创造力」等人侧要素 +「场景、数据、基本功」等 AI 侧要素 | 三角成型 |
| 3. 飞轮发现 | 人侧三角和 AI 侧三角不是对立而是互相喂养 | 双三角 + 三回路飞轮 |
| 4. 引擎化 | 双三角作为下一轮 AI 协作问题的起点框架 | 进入 Y模型 循环 |

### 3. 六要素作为「基础框架认知」的解释

| 要素 | 它回答的问题 | 作为框架性认识意味着什么 |
|:---|:---|:---|
| 审美 | 什么是好结果？ | 能建立判断标准，而不是凭感觉 |
| 体系 | 怎么拆成可执行流程？ | 能把复杂任务结构化 |
| 创造力 | 怎么提出值得 AI 执行的新假设？ | 能解放思想，但不瞎想 |
| 场景 | 哪个切口最值得做？ | 能识别高 ROI、高匹配的场景 |
| 数据 | 什么数据能让 AI 变强？ | 能设计数据飞轮 |
| 基本功 | 用什么工具、怎么组合？ | 能根据任务选最小工具集 |

### 4. 与「人在环」的关系

卡片中必须有独立小节说明：

- **人在环是伦理和治理原则**：人保持判断权、否决权和最终责任。
- **双三角是能力落地框架**：人在环要落地，必须回答「人到底靠什么能力在环？」
- **六要素就是答案**：审美判断力、体系拆解力、创造力、场景判断力、数据设计力、基本功组合力。
- **人在环不是最终状态**：随着双三角成熟，人从「每个细节把关」升级到「框架、飞轮、关键节点把关」。

### 6. 操作步骤（要可执行）

1. 明确一个 AI 协作目标
2. 用画布或清单列出六要素的**初步、朴素、允许错误**认知
3. 理论侧：找类比、建模型
4. 实践侧：提假设、做验证
5. 用实事求是校准，用解放思想突破
6. **更新六要素框架认知**，而不是只填表
7. 知行合一，落地执行并沉淀资产
8. 记录飞轮，进入下一轮
