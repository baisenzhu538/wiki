## 核心命题

1. 一个人入门某个领域的标志：形成对这件事基础的、朴素的、底层的框架性认识。

3. 双三角六要素，就是 Y模型 在 AI 协作领域多轮循环后沉淀的框架性认识。
4. **人在环是这一轮循环的起点原则**；双三角是这一轮循环成熟后的结构化产物。

## 卡片必须包含的内容

### 1. Y模型 引擎层循环图

必须画出或描述引擎层循环，而不是静态分析流程：

```
目标
  ↓
基础框架认知（朴素的、会错的、第一版六要素草稿）
  ↓
理论侧迭代：科学类比 + 提炼建模
实践侧迭代：假设驱动 + 定性定量
  ↓
实事求是（校准） + 解放思想（突破）
  ↓
更新后的基础框架认知（六要素 V2 / V3 / Vn）
  ↓
真正的认知
  ↓
知行合一 → 解决问题 / 产生资产 / 沉淀飞轮
  ↓
新一轮目标 + 更高分辨率的基础框架认知
```

关键说明：每一轮循环都会**升级基础框架认知**，而不是只在固定框架内填空。双三角六要素本身就是多轮循环后的产物。

**特别说明：Truman 做 PPT 的过程就是这条循环的真实演示**。他不是先成为 PPT 专家再动手，而是在完全不懂的情况下，用 Y模型 循环一步步迭代：目标 → 朴素认知 → 实事求是/解放思想 → 更新认知 → 知行合一 → 下一轮。市场上已有 PPT 软件，也有各种 Agent 方案，但都不好使；他不是在旧范式里继续优化，而是在迭代中重定义问题边界，最终做出自己的工具。

### 2. 双三角诞生的引擎层叙事

卡片中必须包含以下历史叙事（由口述素材支撑）：

| 阶段 | 状态 | 关键动作 |
|:---|:---|:---|
| 0. 人在环起点 | 朴素原则：AI 生成、人类判断 | 定义了人机协作的基本伦理和最小闭环 |
| 1. 案例驱动 | 大量具体案例（PPT/贝壳/酒店/硬件/D同学等） | 每个案例都暴露一个盲区 |
| 2. 框架粗胚 | 发现需要「审美、体系、创造力」等人侧要素 +「场景、数据、基本功」等 AI 侧要素 | 三角成型 |
| 3. 飞轮发现 | 人侧三角和 AI 侧三角不是对立而是互相喂养 | 双三角 + 三回路飞轮 |

### 3. 六要素作为「基础框架认知」和「迭代调参器」

必须引入 **L0-L5 认知深度模型**（来自解放思想课程）作为创造力的层级解释：

| 层级 | 名称 | 在双三角创造力中的含义 |
|:---|:---|:---|
| L0 | 盲目创新 | 天马行空、无约束、无验证 |
| L1 | 事实/经验 | 照搬案例或最佳实践，迁移性弱 |
| L2 | 常识 | 行业共识，往往是隐含假设集中地 |
| L3 | 方法模型 | 可迁移的底层原理和方法论 |
| L4 | 本质 | 一句话可推演出整套方法论；双三角六要素本质上是 Y模型 循环沉淀出的 L4 框架性认识 |
| L5 | 学科经典 | 可推翻商业层常识的最底层规律 |

**关键说明**：双三角中的创造力不是停留在 L0 的灵感，而是从 L3/L4 出发的「找到更底层规律，在上层突破做创新」。卡片中必须明确区分「灵感闪现」与「创造力」：灵感只是触发器，创造力要把灵感接住、结构化、验证、落地。

六要素不仅是框架的六个组成部分，更是 Y模型 循环中的**六个可调参数**。Truman 在 PPT 迭代中不是一次性把它们填对，而是每轮循环都追问：审美够不够？体系是否稳定？数据包有没有积累？基本功是否支撑得住？场景有没有选准？创造力有没有被激发？

| 要素 | 它回答的问题 | 作为框架性认识意味着什么 | 作为迭代参数意味着什么 |
|:---|:---|:---|:---|
| 审美 | 什么是好结果？ | 能建立判断标准，而不是凭感觉 | 每轮迭代都要校准「好」的标准 |
| 体系 | 怎么拆成可执行流程？ | 能把复杂任务结构化 | 每轮迭代都要检查流程是否漏步骤 |
| 创造力 | 怎么提出值得 AI 执行的新假设？ | 能解放思想，但不瞎想 | 每轮迭代都要挑战隐含假设 |
| 场景 | 哪个切口最值得做？ | 能识别高 ROI、高匹配的场景 | 每轮迭代都要验证切口是否还成立 |
| 数据 | 什么数据能让 AI 变强？ | 能设计数据飞轮 | 每轮迭代都要沉淀可复用数据 |
| 基本功 | 用什么工具、怎么组合？ | 能根据任务选最小工具集 | 每轮迭代都要补最小可用工具链 |

### 4. 与「人在环」的关系

卡片中必须有独立小节说明：

- **人在环是伦理和治理原则**：人保持判断权、否决权和最终责任。
- **双三角是能力落地框架**：人在环要落地，必须回答「人到底靠什么能力在环？」
- **六要素就是答案**：审美判断力、体系拆解力、创造力、场景判断力、数据设计力、基本功组合力。
- **人在环不是最终状态**：随着双三角成熟，人从「每个细节把关」升级到「框架、飞轮、关键节点把关」。

### 6. 操作步骤（要可执行）

1. 明确一个 AI 协作目标
2. 用画布或清单列出六要素的**初步、朴素、允许错误**认知
3. 理论侧：找类比、建模型
4. 实践侧：把大胆想法转化为**关键假设**，设计最低成本验证（常识 → 情报 → 实验 → 全量投入）
5. 用实事求是校准，用解放思想突破
6. **更新六要素框架认知**，而不是只填表
7. 知行合一，落地执行并沉淀资产（**允许粗糙，优先让飞轮转起来**）
8. 记录飞轮，进入下一轮

**关键工具**：
- 验证假设的成本阶梯（来自实事求是课程）：常识 → 情报 → 实验 → 全量投入
- 关键假设体系（来自解放思想课程）：用「我假设……」替代「我认为/老板说的/专家说的」，并给出证伪条件
- 红蓝卡机制（来自科学理念课程）：把抽象模型转化为团队日常自检/纠偏/激励行为

**关键原则**：第一步可以尽可能详细，但不必追求完美；在干中学、在学中干，让飞轮循环运转比第一步完美更重要。
