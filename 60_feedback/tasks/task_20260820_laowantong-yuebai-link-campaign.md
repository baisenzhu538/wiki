## 执行范围

1. **先建 MOC**：`tool-月白` 系列索引卡（或 MOC 卡）——按子主题聚类（白底图/改图/生图/电商场景图/小红书策略…），作为全批汇聚点。MOC 本身是内容活：聚类要读卡判断，不是机械列表
2. **逐卡补链（孤儿 60 张优先，再弱链）**：每卡 related 补至真实关联——
   - 必链：月白 MOC + 同子主题相邻卡（≥2）
   - 跨域桥接（≥1，E008 纪律）：往设计/AI 协作域已有卡链——候选锚：`dk-aesthetic-redline-doc`、`dk-three-context-formula`、`case-truman-ai-image-workflow-evolution`、`tool-yitang-research-best-practice`（文创调研类）等，**读了内容确实相关才链，不凑数**（O0）
   - related 总数目标 ≥3；能到 5 更好但禁塞垃圾关联，pre-submit 门禁若要求更高，报告里说明取舍
3. **双向回链**：被链的旧卡（MOC/跨域锚卡）侧 related 追加回链，只增不改（#384 模式——frontmatter 插入 yaml 结构感知，不依赖 review_date 锚点；修复后全量复扫，E017）

## 边界

- 只动 related/frontmatter，正文零改动
- 批量三问（dry-run 预览+范围声明+非空不覆盖）；193 张是大批量，建议分子主题分波落地，每波 pre-submit 0 ERROR
- 关联必须真实（读卡判断）——"链接密度"的质量门是"链得对"，不是"链得多"
- 完成后 commit 入档（E040）
- 欧阳锋终审（重点抽查：关联真实性 + 图谱复测孤儿率）
