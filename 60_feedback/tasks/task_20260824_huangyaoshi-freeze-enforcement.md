## 任务

1. **file-flow-check 加 L10「任务单正文冻结检测」**：queued/claimed/pending_review/reviewed 状态任务单 git diff HEAD，四类豁免，其余正文改动（追加/删节/修改）→ 报警"上板冻结禁止回头改"：

   - 执行报告节（complete 前可填）
   - 终审记录节（欧阳锋写入）

2. **挂 health-check 每日自动**（与 L7 同机制）
3. **L7 窗口口径补记**：建议书"落盘即冻结"——落盘→登记 ≤10min 内改动属登记前（文档注明口径）
