# 任务 #99：Agent 配置——人类画像+规则匹配 tool 卡

## 核心方法论（L2544）

> "整个的配置的底层逻辑是我们要去找到人类世界里最美好的这个画像，通过这个画像完成一次规范化的匹配。"

**人类三角负责画像，AI 三角负责规则匹配。**

## 任务目标

产出 1 张 tool 卡，固化 Truman 的 Agent 配置 7 步法。

## 7 步配置结构（从口述稿提取）

| 步骤 | Truman 的做法 | 双三角映射 |
|:---|:---|:---|
| 1. 角色定义 | "我是Truman，一堂COO，帮我设计一个龙虾配置文件" | 场景（锁定问题边界） |
| 2. 前置调研 | 让 AI 自己去知识库学背景、学最佳实践、全网调研 | 数据（AI 自己收集） |
| 3. 工作内容 | 记录灵感、定期汇报清单、专题研究 | 场景（三个细分场景） |
| 4. 人格画像 | 北大经济学+心理学双修，28岁女生，对人温度高对事理性，自带Y思维 | 审美（人类世界最美好的画像） |
| 5. 里程碑 | 第一步不执行只写计划→第二步搜集→第三步输出→第四步MVP测试 | 体系（分步推进） |
| 6. 数据包 | 一堂五步法、IPO思维、用户沟通习惯 | 数据（注入具体知识） |
| 7. 底层逻辑 | "人类画像+规则匹配"——确认方案→敲定→执行 | 创造力（元方法） |
