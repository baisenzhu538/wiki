## 任务 1：全库标签摸底扫描（一次性，只读零风险）

**扫描范围**：`30_wiki/` 全部卡片 frontmatter tags 字段（~2000+ 张）

**四项体检指标**：

| 指标 | 检测方法 | 输出 |
|:--|:--|:--|
| ① 脏词残留 | 课程名/来源名/长短语模式匹配（复用 #426 决策域迁移映射的正则思路扩展全库） | 脏词清单（卡 ID+脏词+建议映射）按域分组 |
| ② 来源轴缺失 | 有 source_person/source_context 但 tags 无来源词的卡 | 缺失清单（预计 90+ 拆书卡+开放麦/Live 卡） |
| ③ 无轴域地图 | 各域卡片数 vs 已有词池轴（human-insights/decision-making/ai-collaboration） | 19 域全景表：有轴/无轴/卡片量 |
| ④ 空值与格式 | tags 为空/null/格式错误的卡 | 异常清单（决策域实测空值 348 处） |

**脏词/空值扫描必须按风清扬三层分档落点（吸收 `diag_20260823_fengqingyang-negative-gate-vocab-review` 建议书 2 修正口径，不另立项——黄药师未领取 #474 时直接并入）**：

| 档 | 语义 | 落在体检里怎么算 | 例子 |
|:--|:--|:--|:--|
| STRONG 强词 | 明确负向断言，硬命中即记脏 | 子串命中即计入脏词清单 | 为空 / 空值 / 不存在 / 未备份 |
| PATTERN 正则 | 短语断言，匹配句式 | 正则 `(?:字段\|值\|数据\|内容\|文件).{0,6}(?:为空\|损坏\|截断\|乱码\|半写)` 命中计入 | 字段…为空 / 数据…截断 |
| SOFT 宽词 | 模糊词，标需人工不硬杀 | **只观察误报率，不进脏词硬清单**（防自伤：正向核查「无截断/无损坏」会被子串误伤） | 截断 / 损坏 / 乱码 / 半写 |

> **关键修正**：欧阳锋原建议把「截断/损坏/乱码/半写」全进强词，风清扬复核为层级错位——这些词在正向核查声明里高频出现，子串硬拦是自伤。故体检扫描器对 SOFT 档只统计出现频次供误报率观察，不计入脏词率分母（脏词率只算 STRONG+PATTERN）。

**产出**：`90_control/tags-audit-20260823.md`（体检报告：四项指标全量清单+按域统计+治理优先级建议——治理批次排产依据，#426 模式按域放量的输入）

**注意**：只读扫描，不改任何卡——治理是后续批次的事（本单不治理只摸底）
