## 三、生产要求

### 3.1 必须遵循的已有规范

- 沿用第一批 case 卡结构：背景 → 决策与行动（人类三角/AI 三角/关键动作链）→ 结果 → 可迁移洞察 → Critique → Synthesis → Action Triggers
- 每个 case 至少提炼 **3 条带原文依据的暗知识**
- 每张卡必须关联第一批核心模型/方法卡（`concept-yihang-dual-triangle-core`、`method-dual-triangle-flywheel-engine` 等）
- 必须通过 `kdo pre-submit`
- frontmatter 必填：`id`、`title`、`type`、`status: draft`、`author`、`reviewed_by: pending`、`confidence`、`trust_level`、`source_refs`、`related`（≥5 条）

- 4 张占位卡已创建，含核心暗知识预览和状态占位

3. 用九层深挖法和六层交叉验证自检
4. 对第一批 14 张卡做交叉回链（在 related 中引用这 4 张新 case）
