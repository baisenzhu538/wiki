# 任务 #80：报告书型学习者 dk 卡

## 任务目标

产出 1 张 dk 卡 `dk-yihang-report-book-learner`——不听课、直接读报告书也能学会的"极简学习路径"，及其对 KDO 卡片设计的启示。

## 原始素材

口述稿课后闲聊 L4858-4902：

> "有一个神同学，从不听一堂课……他就做一件事，高铁上没事就翻报告书，该记的记下来，实践中明白就能掌握。……清华学霸就是不做习题，直接拿数学公式定理，理解了开始做题。"

Truman 评价："如果你真能到这种程度，你的知行合一和认知度够好，你可以不学任何东西，直接用也行。"

## 卡片内容要求

### 1. 两种学习路径对比

| 路径 | 形态 | 适合谁 | KDO 对应物 |
|:---|:---|:---|:---|
| 教学路径 | 直播课 + 预热 + 案例 + 重复 + 作业 | 需要建立体感、需要教学动作引导的多数人 | Skill / Agent |
| 报告书路径 | 直接读结构化核心知识 + 自己去实践验证 | 有经验基础、自制力强、知行合一能力强的人 | 卡片本身 |

### 2. 两种学习者的画像

从口述稿提取：
- 报告书型：已有领域基础，能自己判断应用时机，不需要教学动作——直接拿公式开始做题
- 教学型：需要体感建立、案例激活、逐步理解——需要"废话"来填平认知差距

### 3. 为什么教学动作不是"废话"

口述稿 L4758-4802 Truman 的核心洞察：
- 同样一段重复和强调，对已会的人是废话，对不会的人是必要的理解桥梁
- "我们只能照顾千人广场，照顾多数人"
- 直播课没法做到千人千面，只能按中位数设计教学动作

### 4. 对 KDO 设计的启示

这是这张 dk 卡最有价值的部分：
- **卡片 = 报告书层**：高段位用户直接读卡、直接调用。卡片写的是"核心公式定理"，不夹杂教学动作。
- **Skill/Agent = 教学层**：低段位用户通过 Agent 引导逐步理解，Agent 负责教学动作（追问/纠偏/案例注入）。
- **两层之间用 `query_triggers` 桥接**：用户在 Agent 中遇到的问题，通过卡片索引直接跳转到"报告书"。
- **不混层**：卡片里不要夹教学动作（预热/划重点/思考题），Agent 里不要只给公式不给解释。

### 5. Critique

- 不是所有人都能走报告书路径——需要极高的自制力和判断力
- 报告书路径存在"误读风险"——没有教学动作纠偏，容易把概念用错场景
- 两层分离可能导致卡片过于"干"——需要在简洁和可理解之间找平衡
