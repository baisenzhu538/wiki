## 王语嫣暗知识补充 (2026-07-04)

> 来源：重读口述稿全文后，从课后闲聊段（L3860+）新提取的高密度暗知识。以下素材在解锁后应纳入对应卡片。

### 补充素材 1：双三角六个场景的涌现时间线

口述稿 L3860-3868 Truman 透露了六个应用场景各自出现的时间（当前 P0 的 `dk-yihang-dual-triangle-strategic-bet` 未覆盖）：

| 场景 | 出现时间 |
|:---|:---|
| 底牌（战略用） | 一直有 |
| 拆解用（X光） | 较早 |
| **口喷** | **最近才出现的** |
| **画布（筹备用）** | **最近才出现的** |
| **拼图（分工用）** | **三四周前，内部解决问题时出现的** |
| **AI 辅助复盘** | **一个月前才出现的** |

**暗知识**：双三角不是一个设计完整的系统，是一个在实践中不断被"推着走"长出新的应用场景的有机体。Truman 原话："我们都不知道它会长成什么样，就是在这条路上就被不断的实践，不断的解决问题，就被这个东西推着走。"

这对 `dk-yihang-dual-triangle-strategic-bet` 很重要——战略底牌不是"设计出来的"，是"长出来的"。

### 补充素材 2：五步法四阶段进化史 → 双三角路线图

口述稿 L3490-3512 Truman 详细讲了五步法四个阶段的进化：

| 阶段 | 时间 | 五步法的形态 |
|:---|:---|:---|
| 故事版 | 第 1 年 | 用来说服别人这个业务有价值 |
| 取舍版 | 第 2-3 年 | 用来做战略加减法 |
| 定量版 | 第 4-5 年 | 关键 benchmark 和定量 |
| 分工版 | 近 2 年 | 团队在画布上协作讨论 |

然后他问："有没有可能双三角也走这条路？"

**暗知识**：这不是修辞。Truman 在给双三角画进化路线图——现在是"故事版"阶段，正在往"取舍版"过渡。五步法的四阶段进化是双三角的**先例和路线图**。应纳入 `dk-yihang-dual-triangle-strategic-bet`。

### 补充素材 3：画布填满 = 风险可控

口述稿 L4595-4604 是最惊人的内部操作细节：

> "我们周二周三的时候内部规定，只要他能把双三角画布画出来，我们就敢对外承诺。过去是从来没有过的，就胆子达到这种程度了。"

**暗知识**：画布不是计划工具——是**风险判断工具**。格子填满了 = 有足够多的牌可以打 = 即使现在没做出来，48 小时内也能硬干出来。应纳入 `dk-yihang-dual-triangle-commitment-confidence`。

### 补充素材 4："一堂最强的是科学共同体"

口述稿 L4358-4386 Truman 两次自我纠正"一堂最强的是什么"：先说"建模"→ 立刻纠正 → "国内最大规模的科学共同体和实践共同体" → "喊一嗓子有人攻坚，喊一嗓子有人捐案例" → "这种教育供应链是免费的" → "取之于民、用之于民、赚之于民"。

**暗知识**：双三角不是封闭研发产物，是社区驱动的。这对 `dk-yihang-scientific-community-moat` 是核心素材。

### 补充素材 5：YAI 架构——知识层与数据层解耦

口述稿 L5025-5078 Truman 解释了 YAI 的一次关键架构创新：

> "我们把知识层和数据层解耦了……系统核心词的那一部分（审美+体系为主）和 data pack（最小数据单位）分开生产……可以拆分成更小单元……用插件的方式在生产上去组合。"

**暗知识**：这不是技术细节——这是双三角在 Agent 架构层的具体落地方式。人类三角（审美+体系）→ 系统核心词层；AI 三角（数据+基本功+场景）→ data pack 层。应纳入 `framework-yihang-knowledge-data-decoupling`。
