### Card 7: `case-yitang-Y-model-advertising-turnaround`

**类型**：case  
**主域**：epistemic-foundations / marketing / yitang  
**confidence**：0.85  
**trust_level**：medium

**必须包含的 section**：
1. Background：2023 年一堂准备做抖音 AD 投放。
2. Problem：早期外包和内部团队都失败，ROI 0.3-0.6，每周亏损严重。
3. Decision：创始人亲自牵头，用 Y模型构建科学投放体系。
4. Process：
   - 明确目标：顾客规模 + ROI，追求风险可控的规模最大化
   - 拆解四大模型：单视频审美 / 工业化生产 / 测试机制 / 投放策略
   - 理论端：借鉴同行经验，建立 A本/B本 模型
   - 事实端：每周一轮 AB 测试、数据复盘、选题池筛选
   - 知行迭代：持续提出关键假设，绿色保留、红色证伪
5. Result：付费流量占一半，收入翻四倍，跑通抖音、视频号、小红书、百度。
6. Lessons：核心难题必须创始人牵头建模；每周咬碎牙复盘；小模型叠加成大模型。
7. Failure Modes：依赖外包、抄爆款、不建模、不复盘。
8. Synthesis + Related。

## 五、关键纠偏与边界

1. **科学理念 = Y模型**：不单独建 `concept-yitang-scientific-idea`。
2. **实事求是 / 解放思想 不是平行于 Y模型**：必须在 framework 卡中明确演化关系。
3. **旧卡处理**：重写升级后原卡标记 deprecated，不删除，避免链接断裂。
4. **案例卡不重复建设**：口述中的时间管理、起名字等例子作为 framework/tool 卡嵌入式证据，不单独建 case。
5. **数字降级**：口述中「每周亏一辆小米汽车」「翻四倍」等描述为项目经验，不当作普适真理。
6. **OPC 改编**：每张 framework/tool 卡必须包含「OPC 智能体适配」小节。
7. **哲学引用**：引用《实践论》《矛盾论》、王阳明心学时要明确「用于说明内在联系，不构成学术结论」。
