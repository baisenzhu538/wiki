## 任务（4 张 dk 卡）

1. **多线程打地鼠法**：一个项目拆 6 子任务（总控/调研/设计/测试/生产/运维）→ 6 窗口分头跑 → 拉满还有余力再开第 5 线程 → 舒适区拉大再提假设。操作步骤 + 从 2-3 线程到 15-20 线程的进阶路径。
2. **项目→Skill/DataPack→Agent 自进化闭环**：项目带来结果 → 封装成 Skill/数据包 → 甩给对应 Agent 学习 → Agent 自调度进化 → 把人压到极低。操作步骤（Truman 例：文生图项目→封装数据包→甩给设计师虾）。
3. **ROI 三步决策（成本视角）**：①降噪（追专家要真实案例，要不到=不成熟）②算账（把"追不追"重框成"换不换"机会成本）③对冲（派 5% 兵力侦察，不全押不全退）。操作步骤。
4. **借假修真在 AI 时代重立**：借假修真="做事奔着攒能力和资产去"；但 AI 工具过时使"攒的能力"失效，直到找到 Feature（最小原子）才重立——攒 Feature 而非攒工具。操作步骤。
