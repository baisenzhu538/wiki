### P1 — `tool-position-switching-test`

**标题**：地位互换测试：规则公正性一分钟自检

**理论锚点（v3新增）**：
> 金句14："公平是正义的一部分，但也仅仅是一部分。"（7.6）→ 公平只保证执行一致，不保证规则本身公正。地位互换是检验规则本身的工具。
> 金句27："人所不欲，勿施于人。"（8.2）→ 核心操作逻辑：用对方的尺子量，不是用你的。

**操作步骤**：1.写下规则 → 2.换椅子 → 3.三问自检（利益问/动机问/退出问）→ 4.红牌信号

**一人公司场景示例**（v2保留）：
- 找外包开发：5万/工期2月/验收后付款 → 交换椅子发现乙方全风险 → 修正：30%定金+里程碑付款
- 找渠道分销：10万才返点 → 小渠道根本达不到 → 修正：阶梯返点
- 找内容写手：修改到满意为止 → 无限修改=成本无底洞 → 修正：2轮免费+超出计费

**常见盲区**（v2保留）：
- 创始人高估idea价值，低估对方执行成本
- "市场价"不包括对方的隐性成本（学习业务、沟通时间）
- 只算钱没算尊严/自主权/归属感

**Agent可发现性**：`aliases: ["椅子测试","分钱公平吗","合作协议自检","公正性测试"]` `discoverable_by: ["分钱方案设计","合作协议审查","合伙人纠纷"]`

### P1 — `tool-game-environment-checklist`

**标题**：博弈环境自检清单：制度面向未来

**理论锚点（v3新增）**：
> 金句7："政治的根本出路在于改善博弈条件。"（7.7）→ 别试图改变人，改变他们面对的收益结构。本工具就是改善博弈条件的操作化。
> 金句16："可信即可行，制度的可信性比制度的道义性更重要。"（5.4）→ 五问中的"信任趋势问"和"可移植问"就是检验可信性。
> 金句18："马基雅维利策略是经不起普遍模仿的。"（6.3）→ 坏人测试的理论基础——如果你的规则在所有人都是"坏人"时崩溃，它就是坏规则。
> 5.3：激励的目标不是奖励好人，而是让好行为成为优势策略。→ 行为导向问的理论来源。

**操作步骤**：1.写下规则 → 2.五问自检（行为导向/坏人测试/信任趋势/自我修正/可移植）→ 3.红牌信号(≥2问负面→重设计)

**反例库**（v2保留+增强）：
- 按项目总价计费 → 外包砍需求减质量 → 看似简单实则激励坏行为
- 利润平分 → 不干活的搭便车 → 看似公平实则鼓励偷懒
- 验收合格后付款 → 双方互相不信任 → 看似保护自己实则摧毁信任

**一人公司场景示例**（v2保留）：
- 内容写手：按篇计费→凑数量 → 改为基础月费+爆款奖金
- 兼职技术：纯分利润→不急 → 改为基础时薪+里程碑股权
