## 背景

出口终审防线现状：欧阳锋 100% 人工逐卡，机器侧只有 lint/复扫/差集等散装工具，**无「机器预审」这一层**——是全自动最大瓶颈。方案：提审单先过机器层，出「预审报告」附在单上，欧阳锋终审从全量逐卡逐步转向审机器拿不准的。判法原型已实证有效：欧阳锋的声称-交付差集（08-24 暴露 37 张漏清单）。

## 任务

1. 机器预审管线：提审（complete）时或提审后自动跑——①声称-交付差集（执行报告声称 vs git diff/文件实测）②lint ③负向判词核查 ④存在性核查锚点检查，汇出一份预审报告附任务单
2. 判据由欧阳锋定（执行前对齐判据清单一节；王语嫣不指定判据内容）
3. 预审报告只做参考层，不自动放行/不自动拦截（阶段 1 纪律：机器预审 vs 欧阳锋终审跑对照，一致率目标 ≥90% 跑 2 周——对照靠 #514 基线数据）
4. 防自动化偏见：机器建议不入档为结论，仅作附件

## 验证（验证分层）

- L1：对历史已终审单回放预审（#469/#481/#499 FAIL 单应被机器预审标出问题点）
