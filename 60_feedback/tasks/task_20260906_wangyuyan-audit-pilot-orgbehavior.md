# #657 暗知识体检试金石（王语嫣亲读）

## 为什么是这件
双三角域=老朱核心方法论（工厂操作系统同源），口述体，有派生卡但**无金矿台账**（旧标准加工 B-A 级风险）——试金石同时回答「历史欠账有多深」和「单件重挖成本多少」。

## 流程（全标准，不降级）
1. 逐字读全文 → 金矿台账（外置工作笔记，逐条行号锚）
2. 对照存量派生卡（case-yihang-dual-triangle-ai-organizational-behavior 等）——五态对账：被印证/被补充/被连接/被修正/无涉
3. 漏挖暗知识 → dk 挂靠或新卡补强
4. 体检报告：素材覆盖率判定 + 新挖清单 + 存量欠账定性
5. 欧阳锋终审（含抽源对照——完备性双签制首次运行）

## 产出
- 金矿台账+体检报告（试金石结论：单件成本/产出密度/存量欠账深度）
- 校准后出全量放量排期表（Phase 1 流水线化，老顽童产/我抽验）
