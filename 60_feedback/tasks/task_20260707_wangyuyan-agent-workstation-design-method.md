# 任务 #120：Agent 工位设计——场景化 Agent 分工 method 卡

## 来源

熙熙分享的第五阶段——多 partner 裂变。4 个 partner 各管一个细分场景：关键词布局/案例替换/评审大师/评论区。"每个 partner 不是工具名，是生产线上的一个岗位。"

## 核心内容

- "工位"概念：把复杂任务拆成多个细分场景，每个场景一个独立 Agent
- 熙熙的 4 工位拆解逻辑：流量入口（关键词）→内容质量（案例替换）→质检（评审）→转化承接（评论区）
- 工位设计原则：不要幻想万能 AI，每个工位只做一件事
- 与 #101 分工拼图的区别：#101 是人的分工，本卡是 Agent 的分工
- 与 #105 Agent 设计元方法的对接：工位 = Agent 画布的场景角具象化

## 验收

- method 卡含工位概念 + 熙熙 4 工位案例
- 含与 #101/#105 的关系说明
