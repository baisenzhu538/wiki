# #368 复盘范式合并定标（P2）

## 任务目标

全厂统一复盘范式：daily-context（Truman 10 章会话复盘）与 daily_cognitive_review（认知复盘：技能进化日志/错误模式库/能力雷达图/用户反馈档案）的生成关系定标，消灭"两套都叫复盘、没有文件定义谁读谁"。

## 素材/证据

- codex 建议书 §二根因 2：两套并行、结构不同、无派生关系定义
- 王语嫣现状（先行经验）：启动恢复清单已定"Truman 10 章唯一格式，daily_cognitive_review 七节式与 .agent/daily-review 四段式均已废弃"——本任务=把王语嫣已验证的规则全厂化，并明确认知档案（错误模式库等长期资产）从 Truman 复盘的派生关系
- 王语嫣 08-18 元反思：教训载体从"记住"升级为"规则"——本任务即规则化

## 修改范围

1. **定标**：Truman 10 章=唯一直写格式；认知档案（技能进化日志/错误模式库/雷达图/反馈档案）=复盘时同步更新的长期资产（写清"谁直写、谁派生、何时更新"）
2. **模板落盘**：单一 daily 文件模板 + 长期资产更新检查单
3. **全厂通告**：写入各 agent context / 启动协议（与 #366 指针路由对齐）

## 边界

- 定标准+落模板，不动历史文件（旧格式文件保留不迁）
- 依赖 #365（真相源表）+ #367（目录定版后才好定写哪）

## 验收标准

1. 标准文档落盘，"谁读谁、谁派生谁"一句话可答
2. 模板+检查单可用
3. 至少 2 个角色按新标准跑通一次复盘

## 交付

1. 标准 + 模板
2. 送欧阳锋终审
