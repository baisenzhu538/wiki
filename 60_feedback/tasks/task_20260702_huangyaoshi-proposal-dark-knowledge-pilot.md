# 黄药师建议书：暗知识补挖试点——Vikki战队 + 大馨战队

> 收件人：王语嫣
> 抄送：欧阳锋、用户
> 背景：用户担心之前消化的素材漏掉了大量暗知识（操作心法、判断口诀、失败模式），导致卡片流于概念表面、无法指导实操。
> 目标：以 Vikki 和大馨两个战队群聊为试点，验证暗知识补挖流程的有效性，有效则推广到全库。

---

## 一、为什么要做这个试点

### 选 Vikki + 大馨的理由

1. **素材已处理过**：#30-#34 完成了卡片生产和 skill 升级，有现成的基线可对比——补挖前后的卡片质量差异一目了然。
2. **暗知识密度高**：群聊是暗知识密度最高的场景——学员在闲聊中说出操作心法、失败案例、判断口诀，这些东西不会出现在结构化笔记里。
3. **和一堂方法论同构**：两人都是一堂学员，说出来的暗知识天然能用一堂框架标注（五步法、需求冰山、刻意练习、单元模型等）。
4. **素材量可控**：Vikki 561条 + 大馨 615条 = 1176条消息，适合试点规模。

### P-31 的教训

P-31 记录过：老顽童只挖结构化笔记，跳过口述稿末尾 Q&A 闲聊——最高价值暗知识被遗漏。这次试点就是要验证"一句话金矿扫描"能不能解决这个问题。

---

## 二、试点任务

### 任务 A：王语嫣暗知识补挖诊断

**目标**：重读 Vikki 和大馨两个群聊的完整聊天记录（不是笔记提取稿，是 `认知精华提炼.md` 原文），按新的"六步诊断法"（含第6步：一句话金矿扫描），找出之前诊断时漏掉的暗知识。

**交付物**：

1. **暗知识提取清单**（格式如下）：

   | # | 原文（一句话） | 说话人 | 一堂映射 | 目标卡片 | 暗知识类型 |
   |:---|:---|:---|:---|:---|:---|
   | 1 | "信息是弹头，情绪是制导系统" | 张若微 | 需求冰山 L4-L6 | concept-需求冰山 | 操作心法 |
   | 2 | "不提价格但处处暗示价值" | 升华 | 单元模型·价值定价 | dk-pricing | 判断口诀 |
   | ... | | | | | |

2. **缺口分析**：哪些暗知识找不到合适的已有卡来承接？→ 标记为"待建新卡"或"待建新域"

3. **与#30-#34 原有卡片的对照表**：哪些暗知识应该补充到哪张已有卡里（作为 Critique / 走偏模式 / 操作心法）

### 任务 B：老顽童执行补卡

**目标**：基于王语嫣的暗知识提取清单，执行两种操作：

1. **补已有卡**：把暗知识写到已有卡片的对应 section 里（Critique 外部反对者、dk 走偏模式、桥接卡操作心法、Constraints 边界条件）。
2. **新建暗知识卡**：如果某条暗知识找不到合适的已有卡承接，新建 `dk-*` 卡。

**预计数量**：10-20 条暗知识提取 → 5-10 张已有卡补充 + 2-4 张新 dk 卡。

### 任务 C：欧阳锋抽检评估

**目标**：欧阳锋抽检补挖前后的卡片，判断暗知识提取是否有效提升了卡片的实操指导能力。

**评估标准**：
- 补挖后的卡片，Constraints/Critique 节里是否出现了"之前没有的操作细节"
- 新 dk 卡是否有具体的失败模式和判断口诀（而非泛泛的"根据情况灵活运用"）
- 补挖后的卡片，用户读完后能否回答"我下一步该做什么"

- [ ] 王语嫣完成 Vikki + 大馨两个群聊的暗知识补挖诊断报告

- [ ] 如果有效，王语嫣写一份"暗知识补挖流程总结"，作为后续全库推广的 SOP

## 五、正确的入队位置

- **优先级**：P1——比 #28 lint 内容债更优先（暗知识缺失比 lint WARNING 对知识库价值的伤害更大）
- **排在**：#40（《吾辈如神》试点卡 + 时间管理桥接卡）之后
- **预计工时**：王语嫣诊断 1 天 + 老顽童补卡 1 天 + 欧阳锋抽检 0.5 天

---

## 六、王语嫣需要特别注意

1. **必须读原始群聊记录**，不能只看笔记提取稿。笔记已经丢了一轮信息（P-31 的教训）。
2. **一句话金矿扫描的目标不是"这一句能不能成卡"**——而是"这一句能不能让现有的某张卡变得更有用"。大部分暗知识应该补充到已有卡里，不是新建卡。
3. **标注"对方没说但隐含的前提"**——这也是暗知识的一种。比如大馨的6维度框架隐含着"适用于 B2C 高客单服务"，这个隐含前提本身就是一条暗知识。
