## 三段式口径块（#433 范围 2 · 供王语嫣并入审查 SOP，本单不改 context）

终审意见书/审计判词凡含负向断言词（无/缺/未/不存在/没有），必须走三段式：

```
**存在性核查**：
- 我查过的形态：[本地 git / 云同步 / 进程 / 配置 / 目录 / 多设备 / bundle / 归档] 逐项 ✓✗
- 结论等级：未发现（默认，弱）/ 确认缺失（强，需清单全查过且全 ✗）
- 反向提问：它还可能以哪些我没查的形式存在？
```

两条硬规则：
- **默认只许说「未发现」，不许说「确认缺失」**——「确认缺失」必须清单全查过且全 ✗
- 下判词前先做「反向存在性提问」：可能形态列全，再对照查了哪些；没列的维度=不许下「确认缺失」

（来源：风清扬建议书 §3.1；门禁只验锚点存在，话术质量靠本口径 + 后续抽查）
