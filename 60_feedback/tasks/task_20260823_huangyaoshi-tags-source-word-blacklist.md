## 背景（欧阳锋 3 例实证）

批次验收正文抽查（升级标准）连续发现**来源形态词被当作内容词写入 tags**：
- dk-ai-prediction-expiry-date：tags 含"逐字稿"（来源形态非内容主题）
- concept-feishu-api-pagination-trap：tags 含"拆书会"（来源活动非内容主题，API/分页/陷阱主题词缺失）

**根因**：来源形态词（逐字稿/拆书会/口述/直播/训练营/开放麦/笔记/分享会/圆桌/对话）在正文/元数据高频出现，被当"标签"顺手写入——描述**来源形态**而非**内容主题**，污染内容词池（检索"拆书会"命中 API 陷阱卡=噪声），挤占主题词位置。

**与已有规则关系**：tags-vocab-design §二已明确"来源名/课程名禁入 tags（source_refs 唯一归宿）"——本建议把**已有规则工具化为检查器**（想犯错也犯不了，B2-4）。

## 任务

### 1. tags-audit.py 加来源形态词黑名单检查（#474 扩展）

- 黑名单词表（可配置，随实证扩充）：`逐字稿/拆书会/口述/直播/训练营/开放麦/笔记/分享会/圆桌/对话`
- 检查：内容词命中黑名单 → 报 warning（卡 ID+词+建议：移除或移入 source 字段/来源轴）
- **第 5 指标**：来源词污染率（命中卡/全库卡），与 #474 四指标（脏词率/来源轴覆盖/有轴域/空值率）并列
- 进 tags-audit 输出 + 健康线（污染率 <1% 目标）

### 2. 边界判断（防误报）
- 黑名单只拦**独立出现**的来源形态词
- 复合词（如"笔记法"、"分享经济"）不拦——需上下文判断
- 实现时定复合词白名单或正则边界

### 3. 单测
- 独立来源词命中报 warning（dk-ai-prediction-expiry-date "逐字稿"）
- 复合词不报（"笔记法"白名单）
- 来源轴词不报（来源轴收录的"拆书会"等不报，因为是来源轴不是内容词池）
