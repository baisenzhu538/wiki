# #265 外部 Agent 反馈→生产深化闭环机制（双驱动固化）

## 背景（用户战略问题 + 试点实证）

用户问："外部 agent 的反馈，同样可以带来 KDO 工厂的生产的深化？"——#252 试点已实证四回路：知识回路（dk 卡）/数据回路（verified 回填）/流程回路（E018 铁律）/模式回路（#263 流水线）。**KDO 进化从"内部驱动"变"内部+外部双驱动"——但机制未固化，目前靠偶尔发现。**

## 任务目标

设计"外部 Agent 反馈 → 生产深化"的显式闭环机制（60_feedback/ 落盘机制文档）。

## 机制设计要点

1. **反馈流入通道**：agent 的踩坑/洞察/验证结果 → 自动流入（60_feedback/ 指定目录或生产深化队列）——不靠偶尔发现
2. **四回路映射**：每条反馈标注回路类型（知识/数据/流程/模式）→ 对应深化动作（dk 卡/verified 回填/纪律升级/流程进化）
3. **与现有机制衔接**：
   - agent 迭代日志（agent-spec 必含）→ 反馈源
   - corrections 文件（60_feedback/corrections/）→ 现有通道
   - 编排反馈闭环（编排复盘）→ 王语嫣侧
4. **触发规则**：什么反馈值得深化（新坑/新洞察/纪律漏洞/模式验证）vs 噪音过滤
5. **试点验证**：用教练的实测反馈（三连坑/质量门禁分析/自举）做机制 dogfooding

## 产出

1. `60_feedback/methods/method-external-agent-feedback-production-loop.md`（机制文档）
2. 反馈流入通道落盘（目录/格式/触发规则）
3. 试点验证记录（教练反馈四回路映射实例）

## 验收标准

1. 机制文档可执行（新 agent 反馈知道往哪流、怎么触发深化）
2. 四回路映射表完整
3. 欧阳锋审查
