# 任务 #117：严格技术域审美建立 dk 卡

## 来源

老朱面对三个严格技术域（电子工程、SaaS 软件、机械结构）的审美建立问题。这些域"对就是对、错就是错"，没有中间地带。武器库的审美元级表（有感觉→粗打分→有维度→有超越）是为开放式域设计的，不适用于此。

## 核心内容

- 严格技术域 vs 开放式创意域的审美区别
- 严格域的审美替代策略：正确性判断 = 审美判断。≥3 个 AI 交叉比对一致 + 真机/实证验证
- 严格域的审美不需要"品位"——需要"验证机制"
- 边界：哪些域是严格域，哪些是混合域
