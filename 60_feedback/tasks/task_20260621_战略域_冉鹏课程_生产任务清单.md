### 1.2 `framework-strategy-six-stages`
```
路径：30_wiki/frameworks/framework-strategy-six-stages.md
类型：framework
一句话：六阶段企业生命周期——不同阶段的核心命题完全不同，不能混用战略工具
素材位置：
  - 📌知识点 §5-9（五阶段奥义）
  - 📌知识点 §32-36（每阶段一句话奥义）
  - 📖逐字稿 §25-30页（阶段展开 + 每个阶段该做什么）
六阶段：
  1. 初创期：拼命试错，快速学习。战略只需明确不做什么 + 最小市场第一
  2. 吃饱期：优化模型，快速复制。先民主后集中
  3. 吃好期：构建优势，布局生态。战略流程驱动，而非创始人独断
  4. 吃撑期：边开车边换引擎。创始人必须亲自领导变革
  5. 吃吐期：及时止损，体面退出
关联已有卡：[[yt-five-step-method]] · [[framework-demand-iceberg]]
```
