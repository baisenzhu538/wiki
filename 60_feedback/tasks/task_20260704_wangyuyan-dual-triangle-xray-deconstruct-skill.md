# 任务 #88：X光拆解 Skill——双三角案例逆向工程

## 来源

口述稿 L2016-2218。Truman 定义了拆解用的核心逻辑：看到一个好案例，条件反射不是问"用了什么工具"，而是"背后的双三角怎么支撑的"。

## 任务目标

产出 1 个 Skill 文件 + 1 张 tool 卡。

## 核心内容

### 1. X光的三个层次

| 层次 | 问法 | 段位 |
|:---|:---|:---|
| 入门 | 用了什么AI工具？ | L1 |
| 进阶 | 用了什么工作流？ | L2-L3 |
| 科学 | 背后的双三角怎么支撑的？审美在哪？体系怎么搭的？数据攒了多少？ | L4+ |

### 2. 操作步骤

1. **锁定目标案例**：一个你"特想学"的 AI 落地成果
2. **六要素拆解**：
   - 审美：做出来以后，什么判断标准决定了它"好"？
   - 体系：用了什么稳定的工作流/里程碑？
   - 创造力：跳出了什么常规假设？
   - 场景：解决的问题边界在哪？为什么这个场景高价值？
   - 数据：背后攒了什么数据资产？
   - 基本功：用了哪些最小技术特性组合？
3. **定位差距**：哪个角是你的短板？哪个角是对方的壁垒？
4. **输出行动计划**：补哪个角→怎么补→多久验证

### 3. 拆自己的特殊用法

口述稿 L2220-2247：做完一个满意的项目→让 AI 用双三角拆自己→输出复盘报告。这是 X光 + AI辅助复盘的组合用法。

### 4. Skill 结构

- `## 拆别人`：案例锁定→六要素拆解→差距分析
- `## 拆自己`：项目完成后→AI辅助复盘
- `## 训练路径`：每周至少拆 1 个案例，直到条件反射选 3

## 验收标准

- Skill 文件完整
- tool 卡 `kdo pre-submit` PASS
- 三个层次表清晰
- 含拆自己和拆别人两种用法
- 欧阳锋终审通过
