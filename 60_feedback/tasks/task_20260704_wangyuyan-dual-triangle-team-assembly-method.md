# 任务 #101：双三角分工拼图 method 卡

## 来源

口述稿 L2908-3096。Truman 推翻"产品+业务+程序员"旧公式，提出双三角驱动的团队组装方法 + 项目经理判断标准。

## 核心内容

### 1. 推翻旧公式

"产品+业务+程序员"三人组不好用。**岗位不重要，双三角覆盖才重要。**

### 2. 新公式：凑齐三个要素

```
项目管理 × 人类三角 × AI三角
```

一个人兼多个角也行，十个人分管也行——关键是三个角不能有短板。

### 3. 项目经理的判断标准

**辩证心态**：战略上乐观（信双三角能成）+ 战术上悲观（承认每个角都难）。

**打赢仗的唯一方法**：精准索取，不是盲目承诺。

```
审美不够 → 找有审美的人补审美
体系不够 → 找人打磨工作流
数据不够 → 要知识库/数据权限
不给 → 做不了，不做虚假承诺
```

Truman 原话："这不是派活给老大，这叫寻求支持。公司有的责任点在我身上，有的在别人身上，只能这么做。"

### 4. 操作信号

- 接到 AI 落地任务 → 先盘一遍双三角 → 每个角够不够？
- 哪个角缺 → 开口要资源 → 要不到就谨慎
- 给资源的判断标准：你能不能说清楚"什么结果需要什么过程支撑"
