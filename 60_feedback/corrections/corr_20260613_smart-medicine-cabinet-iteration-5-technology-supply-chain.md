## 4. 远程审方系统

### 4.1 远程审方模式

远程审方是指执业药师通过互联网后台，远程视频或在线系统为药店消费者/患者提供处方审核、用药指导服务。

### 4.2 已落地案例

| 地区/企业 | 模式 | 关键数据 |
|:----------|:-----|:---------|
| **重庆九龙坡区** | 零售药店与第三方机构合作，全区推行线上服务平台 | 2022 年 3 月实现执业药师远程医学服务平台全覆盖 |
| **湖北襄阳一医互联网医院** | 互联网医院开具电子处方，流转至药店 | 累计服务患者 1500+，上千张处方成功流转 |
| **湖北宜昌夷陵区** | 处方流转平台+零售药店模式 | 258 家零售药店实现处方流转平台全覆盖 |
| **贵州“贵医云”** | 远程电子处方及审方服务 | 患者视频问诊，医生开方，执业药师审方 |
| **北京叮当快药** | 24 小时远程药学服务 | 串联用户端、互联网医院、订单系统、远程药学服务系统、数据监管系统、电子签名系统 |
| **云南** | 执业药师远程药师服务及审方业务监管系统 | AI 人脸识别+视频轮巡+处方数据分析 |

### 4.3 远程审方系统核心模块

| 模块 | 功能 |
|:------|:-----|
| 视频/语音通话 | 药师与患者/店员实时沟通 |
| 处方传输与 OCR 识别 | 处方信息自动抓取 |
| 用药合理性评估 | 基于患者病情、过敏史等评估 |
| 电子签名 | 药师审方后电子签字 |
| 处方存档与追溯 | 处方分类、存储、检索、监管 |
| AI 辅助审方 | 智能提示用药风险（不可替代药师审方） |
| 监管对接 | 与药监部门系统实时连接 |

### 4.4 成本参考

- 早期成都试点：连锁总部远程审方系统前期投入约 **10 万元**（光纤、电子监测仪、扫描器等）。
- 远程审方室人员配置：约 **50 店/6 名执业药师**，每超 10 店增 1 人。

## 5. 药店 ERP 与 O2O 中台系统

### 5.1 为什么需要 O2O 中台？

药店同时入驻美团、饿了么、京东到家、京东健康、阿里健康等多个平台时，面临：
- 多平台库存不同步，超卖/缺货
- 订单分散，处理效率低
- 价格、活动维护繁琐
- 财务对账困难

O2O 中台作为**药店 ERP 与第三方平台之间的桥梁**，实现统一商品、库存、订单、财务、数据分析。

### 5.2 主要供应商

| 供应商 | 产品 | 核心功能 | 特点 |
|:-------|:-----|:---------|:-----|
| **道拓医软** | O2O 中台系统 | 多平台订单聚合、库存同步、财务结算、数据大屏 | 对接美团、饿了么、京东到家、京东健康、阿里健康 |
| **海典 OMS** | 全渠道订单中台 | 聚合全渠道订单、智能报表、线上刷医保 | 上海地区公域线上刷医保订单增长 10%+ |
| **金博医药软件** | 医药电商 ERP+O2O 订单系统 | 采购、批发、连锁、B2B、B2C、O2O、会员、GSP | 全程批号、效期、追溯码管理 |
| **邻医快药** | 天枢 ERP | 符合 GSP 认证，线上线下库存实时同步 | 适合单体药店和中小连锁 |
| **与梦同行** | 医药新零售系统 | B2C、O2O、B2B、ERP、DTP、互联网医疗 | 自有知识产权，代运营+系统 |

### 5.3 O2O 中台核心能力

| 能力 | 说明 |
|:------|:-----|
| 全渠道库存实时同步 | 线上线下库存统一，避免超卖 |
| 多平台订单聚合 | 一个后台处理美团、饿了么、京东等订单 |
| 智能呼叫骑手 | 按优先级轮询呼叫配送平台 |
| 商品同步与价格管理 | 统一上下架、改价、活动配置 |
| 财务对账 | 自动生成多平台结算报表 |
| 数据分析 | 热销品、利润率、动销监控 |
| 医保对接 | 支持线上刷医保订单（需当地政策允许） |

## 6. 医保刷脸终端与药品追溯设备

### 6.1 医保业务综合服务终端

医保业务综合服务终端是国家医保局认证的设备，支持：
- 医保电子凭证激活
- 医保码结算
- 人脸识别结算
- 身份证读取
- 扫码支付

### 6.2 主要供应商

| 供应商 | 产品 | 特点 |
|:-------|:-----|:-----|
| **广东天波** | C10T（桌面式）、H2T（手持式） | 国家首批过检，全国铺设量名列前茅，30+ 服务网点 |
| **支付宝/移动公司** | 医保综合服务终端 | 与地方医保局合作投放 |

### 6.3 应用场景

| 场景 | 设备类型 | 案例 |
|:------|:---------|:-----|
| 药店收银台 | 桌面式 C10T | 贵阳 1300+ 台、鞍山 103 家药店 |
| 村卫生室/基层机构 | 桌面式/手持式 | 江西 1.8 万+ 村卫生室 |
| 上门巡诊/送药 | 手持式 H2T | 移动刷脸结算 |
| 药师实人在岗确认 | 桌面式/手持式 | 大连 2025.8.1 起强制使用 |

### 6.4 药品追溯码

2024 年起，药品追溯码管理趋严。药柜/药房系统需支持：
- 药品入库扫码
- 销售出库扫码
- 追溯码与处方/订单绑定
- 医保结算时上传追溯码

**调研结论**：智能药柜/智慧药房的技术供应链已经相对成熟。零售端药柜设备供应商以**云央智能、巨米智能、诺博医疗**等为代表；医院端以**健庵信息、艾隆科技、芳华智慧医疗**为龙头。远程审方、O2O 中台、医保刷脸等关键系统均有成熟方案。药柜推广的技术风险不在于「找不到供应商」，而在于：**如何根据自身阶段选择最小可行技术栈，避免一次性投入过高、系统过于复杂，同时确保合规对接（GSP、医保、追溯码）**。
