# 通知：新 Ingestion Pipeline 生效

> 致：王语嫣、老顽童  
> 规范文件：`90_control/ingestion-pipeline.md`

## 新流程

**之前**：素材 → 老顽童自己看 → 写卡（容易漏金矿）

**现在**：

```
用户放素材到 inbox
    │
    ├─ P2（碎片/笔记）→ 老顽童直接消化
    │
    └─ P0/P1（课程/录音/报告）→ 王语嫣先把关
                                    │
                                    六层交叉比对、标金矿、标矛盾
                                    │
                                    老顽童精准写卡（框架必须含案例）
```

## 王语嫣的新职责

1. 收到新素材后，执行六层交叉比对
2. 输出"高价值段落索引"——告诉老顽童源材料里哪里是金矿
3. 提取案例素材——标注"建议出 case 卡"
4. 标注 confidence 分层

**产出位置**：`60_feedback/diagnosis/` 或 `60_feedback/corrections/`

## 老顽童的新职责

1. 拿到王语嫣的标注后精准写卡
2. 框架卡必须含至少 1 个真实案例
3. 案例卡必须从源材料提取，不能用通用例子
4. 继承王语嫣的 confidence 评分

**不受王语嫣标记限制时**：发现她漏标的内容 → 自己标注后继续写。有争议写差异原因。
