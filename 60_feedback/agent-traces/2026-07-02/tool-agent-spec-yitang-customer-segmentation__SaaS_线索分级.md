## 线索3：某商场招商经理，管理20+娱乐业态商户

### 1. S/A/B/C 分级建议
- 建议等级：**B 级**
- 分级理由：可能成为渠道型客户，具备一定的规模杠杆（一个商场可带动多家商户），但招商经理并非直接使用者和最终掏钱的人，推动商户统一采购的可行性需验证。
- 置信度：**中**

### 2. 资源与跟进策略
- 建议投入精力：安排一次15–20分钟轻量需求摸底通话。
- 跟进节奏：B 级，3天内完成首次沟通。
- 下一步具体动作：
  1. 了解“商场级解决方案”具体指什么：是需要统一收银、统一会员，还是仅想获得对商户的折扣？
  2. 确认招商经理对商户的控制力和推荐形式（强制入驻还是自愿采纳）。
  3. 若对方有真实推动力，可提供一份面向商户的一页纸介绍材料或合作模式说明。
- 不该做：
  1. 马上按“渠道大客户”定制方案和报价。
  2. 在未明确对方是自付还是转售的情况下，承诺招商经理任何返点或分成（可能涉合规风险）。
  3. 投入大量时间做完整产品演示，当前仅需理解需求。

### 3. 关键假设与验证问题
- 本次分级依赖的关键假设：招商经理有能力且有动机推动商户采纳同一套数字化工具；商户对此有真实需求。
- 需要进一步验证的2–3个问题：
  1. 您提到的“商场级解决方案”是想先给商户推荐工具，还是商场会主导统一部署？
  2. 以前是否帮助商户对接过类似系统？商户的普遍反馈/付费意愿怎样？
  3. 如果推动顺利，第一批可能会有多少家商户愿意试用？
- Contingency：若验证后发现招商经理仅是个人好奇或无法撬动商户，线索等级应下调至C级，转为偶尔内容触达。

### 4. 风险提示
- 招商经理与商户之间的商业关系可能复杂，承诺商户的条款需创始人最终审批。
- 注意避免在未签订合作协议前，向招商经理透露过多可被复制到竞品的业务逻辑。

## 线索4：剧本杀DM个人博主，粉丝5万，申请免费试用做测评

### 1. S/A/B/C 分级建议
- 建议等级：**C 级（可标记为市场合作潜在线索）**
- 分级理由：无付费意愿，直接销售价值极低；5万粉丝在垂直领域可能有一定传播价值，但需评估是否为真实影响者，不能按客户线索对待。
- 置信度：**高**

### 2. 资源与跟进策略
- 建议投入精力：由市场/内容运营判断是否纳入评测合作，创始人不必亲自介入。
- 跟进节奏：C 级，不进入销售跟进流程；若市场团队决定合作，按市场合作流程推进。
- 下一步具体动作：
  1. 检查该博主的内容质量、粉丝互动率、过往评测产品类型，判断影响力真实性。
  2. 若符合低成本合作条件，可提供限时免费试用版（非全功能），并明确合作要求（如产出内容、发布时间）。
  3. 若不符合，则发送礼貌拒绝或引导至公开免费版。
- 不该做：
  1. 当作付费客户进行演示和需求挖掘。
  2. 授予永久免费权限或全功能版本，以免削弱商业价值。
  3. 在未确认博主影响力前，将其推荐给创始人跟进。

### 3. 关键假设与验证问题
- 本次分级依赖的关键假设：该博主对目标付费客群有影响力，且合作ROI为正。
- 需要进一步验证的2–3个问题：
  1. 其粉丝画像与我们的目标客户画像重合度如何？
  2. 过往测评内容平均播放量/阅读量，以及是否有转化案例？
  3. 是否愿意接受非现金权益合作（如免费试用+返链接推广）？
- Contingency：若影响力数据不佳或仅想“白嫖”，则不启动任何合作，按普通C类线索处理。

### 4. 风险提示
- 博主测评内容不可控，合作前需签署协议，约定内容方向与事实基础，避免夸大宣传引发合规风险。
- 提供试用账号时需注意权限范围，防止数据泄露或滥用。

### 5. 方法论溯源
- 直接调用的 KDO 卡：[[tool-yitang-customer-segmentation-4step]]

  - [[tool-yitang-sales-process-decomposition]]：未提供市场合作的标准处理流程。
