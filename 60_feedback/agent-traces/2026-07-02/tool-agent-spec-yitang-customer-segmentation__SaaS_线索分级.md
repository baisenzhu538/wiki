- 分级理由：行业匹配度高、规模可形成标杆，主动约演示表明明确意向，但需确认预算与决策权。
- 置信度：**中**

## 2. 资源与跟进策略
- 建议投入精力：今天内确认演示时间，安排一次 30 分钟线上沟通。
- 跟进节奏：A 级，今天响应。

### 线索 2：独立桌游吧老板

## 1. S/A/B/C 分级建议
- 建议等级：**C 级**
- 分级理由：单店规模太小，付费能力弱；行为数据表明兴趣低（注册后 3 天未登录），不符合要利润或打标杆目标。
- 置信度：**高**

## 2. 资源与跟进策略
- 建议投入精力：放入自动化培育流程，不投入一对一精力。
- 跟进节奏：C 级，放弃或自动培育。
- 下一步具体动作：
  1. 由系统自动发送一封“我们注意到您还没开始使用，需要帮忙吗？”的邮件，附带一个 5 分钟上手视频。
  2. 若 7 天内仍无登录，不再主动接触。
- 不该做：
  1. 创始人亲自打电话或微信跟进。
  2. 手动为其提供 demo 演示。

## 3. 关键假设与验证问题
- 关键假设：该线索的客单价和生命周期价值不足以覆盖一对一跟进的成本。
- 验证问题：无需验证，除非历史数据显示单店转介绍率极高（低概率事件）。
- Contingency：如在自动化培育过程中该用户突然高频使用并主动咨询付费方案，可升级为 B 级，由助理对接。

## 4. 风险提示
- 无显著隐私或合规风险，但需确保自动化邮件符合反垃圾邮件规则。
- 唯一风险是“错失隐藏的连锁老板”，但概率极低，不值得为此投入资源。

## 5. 方法论溯源

- 未调用卡：[[tool-yitang-ideal-customer-profile]]，若有已提炼的 ICP，可直接匹配排除。

### 线索 3：商场招商经理

## 1. S/A/B/C 分级建议
- 建议等级：**B 级**
- 分级理由：需求场景有想象力（商场级方案），但角色并非最终使用者或预算持有者，更像资源整合者，能否落地变数大。
- 置信度：**中**

## 2. 资源与跟进策略
- 建议投入精力：3 天内安排一次电话沟通，了解其具体期望和立项可能性。
- 跟进节奏：B 级，3 天内。
- 下一步具体动作：
  1. 电话中明确“商场级解决方案”的定义：是统一收银？引流？还是商户管理后台？
  2. 探询商场方是否有预算或仅为意向搜集，以及过往是否有与外部 SaaS 合作的项目。
  3. 若能确认有潜在项目，请招商经理引荐其运营负责人或分管副总。
- 不该做：
  1. 立即投入技术资源做定制化方案 demo。
  2. 在没有真实项目立项前，承诺“我们可以和你们商场联名推广”。

## 3. 关键假设与验证问题
- 关键假设：该招商经理能推动内部立项，且商场愿意为娱乐商户数字化买单。
- 验证问题：
  1. 贵商场之前是否上线过面向商户的统一系统？效果如何？
  2. 这个需求是您个人的想法，还是已有商户投诉/管理层要求？
  3. 如果我们要推进，下一步应该和谁正式聊？
- Contingency：若只是招商经理个人想法，无组织支持，则降为 C 级，放入“行业信息储备库”日常关注，不主动追击。

## 4. 风险提示
- 商场类 B2B 项目决策链长、周期长，前期易占用大量精力。
- 任何涉及商场方数据、商户沟通的合作设想，均需创始人最终审核合同条款。
- 置信度中等，因缺少对方真实影响力信息，需通过验证问题澄清。

## 5. 方法论溯源
- 直接调用 KDO 卡：[[tool-yitang-customer-segmentation-4step]]
- 间接使用：[[framework-yitang-decision-chain-analysis]]（推测决策链）
- 未调用卡：[[tool-yitang-partnership-assessment]]，若已有合作评估框架，可更系统判断。
- 补充信息：创始人是否有过与商场 / 业主方合作的经验？若有历史转化率数据，可快速校准。

### 线索 4：剧本杀 DM 个人博主

## 1. S/A/B/C 分级建议
- 建议等级：**C 级**
- 分级理由：无明确付费意愿，仅申请免费试用做测评，属于资源置换（曝光换使用），不适合列为分层跟进对象。
- 置信度：**高**

## 2. 资源与跟进策略
- 建议投入精力：不投入销售精力，转由市场合作负责人判断。
- 跟进节奏：C 级，放弃或转入合作评估队列。
- 下一步具体动作：
  1. 若创始人愿意做等价曝光，可由助理发送一份“媒体 / 博主合作申请表单”，要求对方填写预计曝光量、受众画像及置换方式。
  2. 若无合作意愿，直接回复“目前没有免费测评名额”，结束对话。
- 不该做：
  1. 创始人亲自谈判或提供销售折扣。
  2. 把其当作潜在客户录入销售 CRM，混入销售管道。

## 3. 关键假设与验证问题
- 关键假设：该博主的粉丝量与目标客户重合度很低，付费转化近乎为零。
- 验证问题：如需判断合作价值，应看其粉丝中是否有大量剧本杀店主及能否提供历史带货数据，但这不是销售分层的范畴。
- Contingency：如果对方愿意付费，哪怕低价，也可以转为 B 级线索，由销售助理对接。

## 4. 风险提示
- 注意区分“测评合作”与“恶意索要免费账户”，需设定期限和范围。
- 免费账户中不能开放可导出敏感数据的权限。
- 任何合作承诺需书面确认。

## 5. 方法论溯源
- 直接调用 KDO 卡：[[tool-yitang-customer-segmentation-4step]]（目标导向：不符合要利润要标杆）
- 间接使用：科学销售中的“客户 vs 用户 vs 合作者”区分。
- 未调用卡：[[tool-yitang-influencer-collaboration]]，若已有 KOL 合作评估标准，可直接交此卡处理。
- 补充信息：创始人是否有品牌曝光需求？若有，此线索可转到合作路线而非销售路线。

### 线索 5：同行 SaaS 公司销售

## 1. S/A/B/C 分级建议
- 建议等级：**C 级**
- 分级理由：已识别为伪装客户，无真实购买意向，需立即终止销售流程，转由创始人判断是否需要防情报泄露。
- 置信度：**高**

## 2. 资源与跟进策略
- 建议投入精力：零销售精力。
- 跟进节奏：立即终止。
- 下一步具体动作：
  1. 不提供任何报价单，可回复“请通过官网下载公开资料包”或不予理睬。
  2. 在内部分享线索特征，帮助团队未来更快识别。
  3. 若担心情报泄露，审查近期向外部发送的资料是否包含核心敏感信息。
- 不该做：
  1. 试图“教育”对方或与其辩论。
  2. 继续询问其需求、预算等，浪费时间。

## 3. 关键假设与验证问题
- 无待验证假设，已确认其为非客户。
- Contingency：极少数情况下同行会因自己公司需求而真实考察，但概率极低，不值得为此更改应对方式。

## 4. 风险提示
- 主要风险是核心定价策略、客户案例细节泄露，须确保报价单和敏感方案仅在对真实客户有足够了解后提供。
- 无需法律风险，但提醒创始人统一对外资料分发的安全级别。

## 5. 方法论溯源
- 直接调用 KDO 卡：[[tool-yitang-competitor-intelligence-protocol]]（间接）
- 间接使用：科学销售五步法中“客户甄别”第一关。
- 未调用卡：[[tool-yitang-sales-anti-fraud-checklist]]，若经常遇到此类情况可建立固定检查清单。
- 补充信息：如果此前同类事件频繁发生，建议创始人建立“新线索-非公开信息暴露度”管控规则。
