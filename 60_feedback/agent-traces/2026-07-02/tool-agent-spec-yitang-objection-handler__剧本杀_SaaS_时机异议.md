- **显性异议**：最近淡季，等过完年再考虑系统吧。
- **真实顾虑**：
  1. 短期现金流压力大，对当下投入敏感，想拖延到旺季有钱时再决策。
  2. （可能）对系统的增效价值缺乏具体感知，认为「现在买也用不着」「拖一拖也无所谓」。
- **异议类型**：时机/预算（主）

## 2. 异议优先级排序
- 当前仅提出 **时机/预算** 异议，优先级最高。但需警惕该异议是否只是「拖延借口」，真实问题可能是需求弱或竞品对比。

## 3. 应对策略与禁忌
- **策略 A：把「淡季」转化为「淡季刚好用来布局」**
  - 动作：强调淡季是导入系统、整理剧本库、员工培训的最佳窗口期，避免旺季手忙脚乱；可附 1-2 个小案例或同行使用数据。
  - 目标：让客户意识到「现在不做，等旺季没时间做」，变劣势为优势。
- **策略 B：降低门槛试探真实需求**
  - 动作：提供「极简试用版」「到店指导一局」「淡季特惠锁定名额」等低风险途径，观察客户是否愿意尝试。
  - 目标：如果客户连低成本试都不愿，说明需求可能不强烈；否则是预算卡点，可进一步沟通。
- **禁忌**：
  1. 直接说「不贵」「很便宜」可能刺激客户自尊，忽略其真实资金压力。
  2. 强行催促成交，破坏关系。
  3. 过度承诺「用了系统马上爆满」，不可信。
