## 4. 需要避免的表达
*   ❌ **「行业领先的剧本杀 SaaS」**：客户不关心你是不是领先，只关心你能不能解决他的问题。这是典型的自嗨。
*   ❌ **「保证客户流失率降低 20%」**：过度且绝对的效果承诺。你无法控制客户的经营，这会引发不信任和法律风险。
*   ❌ **「直接替换掉微信群，我们更好」**：「更好」太主观，容易引起客户对改变现有工作模式的抗拒。应该说「提供更高效的替代方案」。

## 5. 关键卡点与 contingency / 验证问题
*   **关键卡点**：店长和核心店员是长期使用微信拼组的，他们可能会抵制新系统，认为增加了学习成本。
*   **Contingency（替代路径）**：强调系统是「辅助而非替代」。核心价值是帮他们从重复性劳动中解放出来（比如自动发公告、自动@所有人），让他们有更多时间提供门店现场服务，从而提升个人业绩。可以提议先让一两家标杆门店作为「样板间」，跑出成功数据后让其他店长眼见为实。
*   **验证问题（试探组织共识与决策链）**：
