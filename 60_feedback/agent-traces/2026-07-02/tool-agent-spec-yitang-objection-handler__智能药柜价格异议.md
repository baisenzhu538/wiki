## 1. 异议类型诊断
- **显性异议**：智能药柜单价 8 万，超出客户预算 60%；客户表示要去看竞品/替代方案。
- **真实顾虑**：
  1. **预算硬约束**：李总用“预算”而非“贵”来表达，暗示内部已有明确财务上限，很可能是一票否决项。
  2. **价值认知未建立**：如果客户充分理解 8 万价格背后对应的独特价值（比如自动效期预警、处方药合规拦截、分时租赁等），价格差异会成为价值讨论，而非直接拒绝。
- **异议类型**：价格（主） + 需求/价值（次）。
- **置信度**：中（孤立一句话缺少决策阶段、历史互动、竞品背景，无法完全排除“用价格当挡箭牌”的可能）。

## 2. 异议优先级排序
1. **预算刚性**（先处理）：需要马上确认预算是年度剩余、专项审批还是随口一说，以及是否有弹性空间；否则继续推进容易做无用功。
2. **价值对比**（再处理）：如果预算确实偏紧，就需要用“价值增量覆盖价格差”的逻辑，把 8 万翻译成“可计量的合规/效率收益”。
3. **竞品/替代方案**（可 defer ）：客户说要“看看别家”，很可能只是想找更低价方案；只要前半部分处理好，比价自然消解。

## 3. 应对策略与禁忌
- **策略 A：把预算异议变成场景验证**
  - 动作：立刻追问“咱们的预算基准对应的是哪一类设备/配置？主要覆盖的是处方药柜、OTC 还是全渠道？”然后用 8 万版的差异化能力去对齐预算背后的真实需求。
  - 目标：判断预算差距是“买不起”还是“不想为多余功能付费”，避免在价格上硬谈。
- **策略 B：用最小化有效配置降低心理阻力**
  - 动作：如果产品支持模块化，可输出一份“基础版够用、升级版可选”的阶梯配置，把第一次交易额控制在预算区间内。
  - 目标：先把客户拉进合作的最小闭环，防止一次性报价吓退。
- **禁忌**：
  1. **未经创始人授权直接降价、赠品或承诺任何形式的价格折让。**
  2. **贬低“别家”方案（极易破坏信任）。**
  3. **在没有确认预算刚性前，持续纠缠“一分钱一分货”逻辑。**
