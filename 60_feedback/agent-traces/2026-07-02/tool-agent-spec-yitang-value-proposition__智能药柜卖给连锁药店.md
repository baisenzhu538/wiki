## 4. 需要避免的表达
- ❌ **“我们的药柜是最先进的智能零售终端”** —— 采购总监关心的是如何向老板汇报成本和合规，不关心技术概念。
- ❌ **“以后夜间售药完全不需要药师了”** —— 过度简化政策风险，远程审方仍需执业药师，表述不当会引发合规部门反感。
- ❌ **“我们保证帮您多赚XX%夜间利润”** —— 涉及未验证的利润承诺，在首次沟通阶段是危险信号，易丧失信任。

- **关键卡点**：当地医保局是否已放开智能药柜的医保扫码结算权限。
