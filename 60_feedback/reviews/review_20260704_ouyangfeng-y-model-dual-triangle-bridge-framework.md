## 必须修复的 🔴/🟡 项

### 🔴 1. 创造力部分必须达到审稿补充五点开掘要求

**位置**：当前第 4 节「六要素：框架性认识 vs 迭代调参器」中对创造力的解释过于单薄（L110 仅一句）。

**必须补全**：

1. **创造力 = 解放思想的具体化身**
   - 创造力 = 敢于跳出原有知识/经验/常规流程，提出新的可能性。
   - 创造力 = 洞悉底层本质和规律，然后在上层做出创新（呼应解放思想课程）。
   - 明确创造力对应 Y模型 中的「解放思想」，而解放思想 = 假设驱动 + 提炼建模。

2. **明确区分「灵感闪现」与「创造力」**
   - 灵感只是创造力的触发器（L0/L1 层级的偶然刺激）。
   - 创造力要把灵感接住、结构化、验证、落地，使其进入 L3/L4 的可迁移框架。

3. **包含未来判断**
   - 审美和体系会逐渐被 Agent 接管。
   - 创造力是人类独有的核心竞争力，必须重点修炼。

4. **引入 L0-L5 认知深度模型**
   - 必须加入如下表格（来自解放思想课程）：

     | 层级 | 名称 | 在双三角创造力中的含义 |
     |:---|:---|:---|
     | L0 | 盲目创新 | 天马行空、无约束、无验证 |
     | L1 | 事实/经验 | 照搬案例或最佳实践，迁移性弱 |
     | L2 | 常识 | 行业共识，往往是隐含假设集中地 |
     | L3 | 方法模型 | 可迁移的底层原理和方法论 |
     | L4 | 本质 | 一句话可推演出整套方法论；双三角六要素本质上是 Y模型 循环沉淀出的 L4 框架性认识 |
     | L5 | 学科经典 | 可推翻商业层常识的最底层规律 |

5. **说明双三角中的创造力不是 L0 的灵感，而是从 L3/L4 出发的「找到更底层规律，在上层突破做创新」**。

### 🔴 2. 必须建立「体系 ≠ 单一模型」的边界意识

**位置**：当前卡片把「体系」解释为「能把复杂任务结构化」（L109），但缺少对「体系」本身的元认知边界。

**必须补全**：

- 体系是围绕真问题，把目标、因果模型、理论、事实、工具、流程整合起来的分层结构。
- **ROI 只是重要决策的评估工具，不是执行体系的全部；用 ROI 本身也要算成本**。
- 每个模型/体系都有内涵和边界，卡片中至少举一个例子说明以下工具各自的适用域：
  - ROI：资源有限时的优先级评估，不适用于探索期、定性判断、长期能力建设。
  - Y模型：从目标出发，迭代升级基础框架认知，不适用于一次性、低风险的简单任务（已在内限 L241 提及，需扩展到边界意识小节）。
  - 关键假设体系：把「我认为」转化为可证伪假设，适用于方向探索期。
  - 验证成本阶梯（常识 → 情报 → 实验 → 全量投入）：用于降低验证成本，不适用于已高度确定的执行环节。
- 明确提醒读者：不要以偏概全，不要用一个决策框架套用所有执行问题。
