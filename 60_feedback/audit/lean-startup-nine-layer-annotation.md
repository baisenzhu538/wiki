## 1. 域级 9 层深挖

### L1：表面业务公式 / 单元模型

精益创业在一堂体系中的价值公式：

```
降低的系统性风险
─────────────────────  =  精益价值
投入的试错成本
```

操作化表达：
- 用最低成本验证工具（FALSE 模型左侧：假营销、假产品、预售、人工 VIP）去验证最高风险假设；
- 每轮验证后将不确定性转化为可量化的“信心指数”或“通过/不通过”信号；
- 避免在方向未验证前进行全量投入（研发、生产、扩张）。

关键单元模型示例（来自素材）：
- 幼儿园监控：19800 ÷ 1920 ≈ 10 个月回本（但漏算售后、资金占用、税收、运费）。
- 电动滑板 D→C→B→A：成本从几十元 → 2 万 → 100 万 → 200-300 万，周期从 1-3 天 → 6-12 个月。
- 视频剪辑课续费：转化率 10%，触达 17000 人，卖 1700 人，收入 500 多万，ROI 1.67→1.88。

### L2：假设审计

一堂课程中的关键假设链（乘法关系）：

```
需求存在 × 产品内核成立 × 商业模式成立 × 增长渠道可扩展 × 壁垒可建立 = 业务成功
```

每个环节都是前置假设：
- 需求不存在 → 后续全部浪费（问题找错）。
- 产品内核不成立 → 商业模式无法跑通（方案做错）。
- 商业模式未验证 → 增长放大是自杀（过早扩张）。
- 增长未验证 → 壁垒建设无意义。

一堂提供的假设拆解工具：
- **五步法**：需求 → 解决方案 → 商业模式 → 增长 → 壁垒。
- **259 工具**：2 阶段（价值验证期/增长扩张期）、5 步拆解、9 要素画布。
- **ABCD 模型**：按宏观/微观 × 成败/效率四象限归类假设。

**审计结论**：课程对“前置假设优先”的强调充分，但对“如何定义关键假设的可证伪标准”交代不够具体，需要老顽童在卡片中补充。

### L3：政策 / 合规 / 监管边界

素材中几乎未提及政策边界，但这是实际应用中的硬约束。标注如下：

| 应用领域 | 合规风险 | 对 FALSE 模型的影响 |
|----------|----------|---------------------|
| 医疗 / 医疗器械 | 二类/三类器械注册、临床试验、数据安全 | 假产品、假营销可能涉嫌虚假宣传；人工替代系统需符合医疗软件监管 |
| 金融 / 支付 / 博彩 | 牌照、反洗钱、消费者保护 | “假购买页”“共享彩票机”直接触碰监管红线 |
| 教育 / 教培 | 办学许可、预付费监管、广告限制 | 预售课程需符合当地教培预付费规定 |
| 消费品 / 食品 | 食品安全、标签法、广告法 | 假包装、假详情页可能违反广告法虚假宣传条款 |
| 数据 / 隐私 | GDPR、个人信息保护法 | 假页面收集用户信息需有合规告知 |

**卡片生产要求**：每张 tool 卡必须在“适用边界”中明确监管敏感领域的限制。

### L4：失败模式库

六宗罪是素材中最系统的失败模式框架：

| 浪费类型 | 核心失败模式 | 预警信号 |
|----------|--------------|----------|
| 问题找错 | 解决了一个不重要/不存在的问题 | 用户说“有意思”但不付费；使用频次极低 |
| 方案做错 | 需求存在但解决方案不够强/不够差异化 | 用户直接选择替代品；转化率低 |
| 过早细化 | 未验证内核就投入细节优化 | 花大量时间打磨 UI/装修/功能；核心指标未验证 |
| 过早扩张 | 未经验证的商业模式被放大 | 看到早期订单就大规模备货/开店/投放 |
| 闭门造车 | 关起门做产品，不接触真实用户 | 团队内部讨论多，用户访谈少；上线后才发现关键场景不匹配 |
| 转型过慢 | 方向错误不愿止损 | 数据持续不佳仍追加投入；没有 kill 条件 |

### L5：隐性成本与替代方案

**隐性成本**：
- 时间成本：反复验证消耗创始人和团队注意力。
- 机会成本：同一笔钱/时间本可验证其他方向。
- 团队信心成本：连续失败导致士气低落。
- 品牌损伤成本：粗糙 MVP 或假页面损害早期用户信任。
- 认知负荷：假设拆解和实验设计本身需要高阶能力。

**替代方案**（张磊 AMA 中更完整）：
- 诚实调研：专家访谈、行业报告、竞品对标。
- 经验验证：时光机理论、行业头部已验证结论。
- 实验验证：FALSE 模型、MVP、灰度/组合/里程碑测试。

优先级：调研 < 经验 < 实验。课程有时过度强调实验，张磊 AMA 纠正为“能用调研竞品的，就不要自己烧钱”。

### L6：人与组织的执行能力

精益方法对组织的要求：
- **一号位亲自下场**：不能授权给基层员工做关键假设验证。
- **默认失败的文化**：接受“这次验证大概率会失败”的心态。
- **假设拆解能力**：能把模糊业务问题拆成可证伪假设。
- **快速决策机制**：达到 kill 条件后能 48 小时内决策。
- **多命思维**：保留足够现金和试错机会。

常见执行障碍：完美主义、害怕抄袭、品牌包袱、恐惧失败。

### L7：市场情绪与叙事

**过度乐观叙事**：
- “AI 让验证成本归零”：AI 降低素材生成和原型成本，但无法替代假设拆解和战略判断。
- “花 3000 块就能验证”：极端案例，不具备普遍可复制性。

**文化阻力**：
- “憋大招”文化：东方面子文化 + 工程师完美主义导致不愿发布粗糙版本。
- “先发优势”迷思：过度担心抄袭而封闭开发。

卡片需保持审慎，不助长工具万能论，也不忽视文化阻力。

### L8：边界案例 / 反例

| 场景 | 为什么精益手段受限 | 素材中的案例 |
|------|--------------------|--------------|
| 强监管行业 | 假页面/假产品可能违法 | 共享彩票机、医疗硬件 |
| 长周期硬件 | 验证周期以月/年计，无法“几天出结果” | 导盲机器狗（1800 万、18 个月、十几位博士） |
| B2B 长决策链 | 假页面价值低，需客户成功故事 | 实验室设备出海、ToB AI 工具 |
| 品牌敏感型产品 | 粗糙 MVP 永久损伤品牌 | 奢侈品、高端服务 |
| 网络效应/双边平台 | 单个 MVP 无法模拟真实密度 | 社区/平台类项目 |

### L9：决策框架 / 可执行结论

综合 9 层深挖，给出可执行框架：

```
1. 阶段判断：预判 → 测试 → 增长
2. 假设拆解：用五步法/259/ABCD 拆出关键假设
3. 优先级排序：前置假设优先，高风险优先
4. 选择验证手段：调研 < 经验 < 实验
5. 设计 MVP：用 FALSE 模型从左到右选最低成本工具
6. 设定通过/不通过标准：必须有 kill 条件
7. 执行 → 学习 → 迭代或 pivot
8. 螺旋上升至下一阶段
```

## 2. 主题级 9 层深挖示例

### 2.1 FALSE / FLESAI 模型

| 层级 | 深挖 |
|------|------|
| L1 | 六阶段成本光谱：F（直接测试）→ A（人工服务）→ L（借用工具/资源）→ S（人工替代系统）→ E（最小版本）→ I（全量投入） |
| L2 | 核心假设：越靠左成本越低，但可验证范围越窄；需要按假设类型匹配工具 |
| L3 | 假营销/假产品/预售在医疗、金融、博彩等领域受限 |
| L4 | 常见失败：把“假页面点击量”当“需求被验证”；忽略后续转化漏斗 |
| L5 | 隐性成本：用户信任损耗、团队“做假”的心理负担、法务风险 |
| L6 | 需要团队接受“未经验证不开发”的纪律 |
| L7 | 被包装为“敏捷”“精益”的流行叙事，但实际执行需要高度自律 |
| L8 | 不适用于强监管、长周期硬件、品牌敏感型产品 |
| L9 | 按假设类型选择工具：测兴趣用 F，测服务体验用 A，测渠道用 L，测系统可用性用 S，测产品形态用 E |

### 2.2 ABCD 关键假设模型

| 层级 | 深挖 |
|------|------|
| L1 | 二维矩阵：宏观/微观 × 成败/效率，对应 A/B/C/D 四象限 |
| L2 | 假设优先级 A >> B > CD；宏观成败问题最应优先验证 |
| L3 | 医疗项目案例显示：A（地图清晰）/C（配准灵活）已完成，B（定位精准）/D（流程便捷）待优化 |
| L4 | 常见失败：把效率问题当成败问题验证，或反之 |
| L5 | 替代方案：直接按五步法拆解，不一定需要 ABCD 框架 |
| L6 | 需要团队能区分“成败”与“效率” |
| L7 | 被包装为“四套操作系统”，本质是问题分类框架 |
| L8 | 对简单业务可能过度复杂化 |
| L9 | 用于判断当前问题该用五步法、ROI 分析、业务公式还是动力阻力触点 |

### 2.3 系统测试曲线（灰度 / 组合 / 里程碑）

| 层级 | 深挖 |
|------|------|
| L1 | X 型幻想曲线（直线上升）vs Y 型真实螺旋上升曲线；三种测试范式 |
| L2 | 核心假设：真实业务进展是试错-调整-突破的螺旋，不是线性 |
| L3 | 医疗器械案例受监管，里程碑设计需符合法规 |
| L4 | 常见失败：在灰度阶段过早固化产品形态；组合测试维度过多导致决策瘫痪；里程碑设计跳步 |
| L5 | 隐性成本：多轮测试消耗团队耐心和管理成本 |
| L6 | 需要一号位能接受模糊数据，有“主观信心”判断能力 |
| L7 | “螺旋上升”被浪漫化，实际过程中团队容易失去信心 |
| L8 | 不适用于窗口期极短的风口业务 |
| L9 | 按风险结构选择范式：单一高风险用灰度；多选项用组合；复杂依赖用里程碑 |

## 3. 对卡片生产的指导

基于 9 层深挖，老顽童在生产每张卡片时应：
1. 明确写出该框架/工具/案例对应的 L1 业务公式或核心模型；
2. 列出 2-3 个关键假设；
3. 说明适用边界（至少 1 个硬约束）；
4. 提取失败模式；
5. 标注隐性成本；
6. 给出可执行结论或决策检查清单。
