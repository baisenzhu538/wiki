## 二、为什么不能全部降级为 `src_unknown`

### 2.1 `src_unknown` 的语义

`src_unknown` 应该表示：**这张卡片的内容来源不明或无法追溯**。

如果把「尚未数字化的一堂课 PPT」也降级为 `src_unknown`，会产生两个问题：

1. **信息丢失**：后人看到 `src_unknown`，会以为这是作者瞎编的；但实际上它来自一堂某次课程，只是还没数字化。
2. **归档优先级丢失**：如果全部降级，我们就失去了「哪些原始素材急需数字化」的清单。

### 2.2 一堂 1/5 录入率的现实

如果一堂有 500 小时的课程/培训素材，目前只数字化了 100 小时，那么：
- 现在指向未录入素材的 source_refs 是 **"预付费债务"**；
- 未来随着录入推进，这些 source_refs 会自动变成 "有效引用"；
- 如果现在就降级为 `src_unknown`，等于提前核销了一笔未来会到账的资产。

## 三、王语嫣建议的分层处理策略

### 3.1 核心原则

**保留来源引用，但标记其可获取状态。** 不要因为有 884 个 lint error 就全部降级，而是让 lint 区分「可修复错误」和「已知数据债」。

### 3.2 具体方案

#### 方案 A：引入 `source_status` 字段（推荐）

在 frontmatter 的 source_refs 中增加状态标记：

```yaml
source_refs:
  - path: 10_raw/sources/src_20260614_一堂-商业预判课-Truman-口述.txt
    status: pending_archive      # 尚未数字化，但已知来源
  - path: 00_inbox/_vlm_reprocess/一堂-单元模型-对抗小抄_vlm_desc.md
    status: available            # 已存在
  - path: src_unknown
    status: unknown              # 来源不明
```

优点：
- 保留完整来源信息；
- lint 可配置为：只把 `available` 路径不存在视为 ERROR，`pending_archive` 视为 WARNING 或忽略；
- 未来数字化完成后，只需改 `status`。

缺点：
- 需要改 lint 规则；
- 需要批量给 884 条 source_refs 打标签（可由黄药师脚本自动批量打 `pending_archive`）。

#### 方案 B：维护一份「待数字化素材清单」

不改卡片 frontmatter，而是生成一个总清单：

```markdown
# 待数字化素材清单（884 条）

| source_ref | 引用卡片数 | 优先级 | 备注 |
|:---|---:|:---|:---|
| 10_raw/sources/src_20260614_一堂-商业预判课-Truman-口述.txt | 23 | P1 | Truman 口述，多卡引用 |
| ... | ... | ... | ... |
```

优点：
- 不改现有卡片；
- 给老顽童/运营团队一份明确的归档任务清单。

缺点：
- 清单与卡片 frontmatter 可能不同步；
- lint error 仍然会报 884 条，噪声大。

#### 方案 C：折中 —— 打 `pending_archive` 标记 + lint 规则调整

1. 黄药师脚本批量检查：884 条 source_refs 中，哪些文件名符合一堂课程命名模式（如 `一堂-*`、`一堂-战略培训-*`、`src_202606*` 等），自动标记为 `pending_archive`。
2. 对不符合已知命名模式的，降级为 `src_unknown` 或 `needs_locating`。
3. 调整 `kdo lint`：
   - `available` 路径不存在 → ERROR
   - `pending_archive` 路径不存在 → WARNING（可配置是否显示）
   - `src_unknown` → INFO

这是王语嫣最推荐的方案。

## 四、对老顽童/归档工作的建议

### 4.1 不要漫无目的地补归档

884 条素材一次性数字化不现实。应该按优先级：

| 优先级 | 标准 | 动作 |
|:---|:---|:---|
| P0 | 被 ≥5 张卡引用，或属于当前 active 域（P0-A/B、science、王欢 AI 2041） | 优先数字化 |
| P1 | 被 2-4 张卡引用，或属于一堂核心课程 | 次优先 |
| P2 | 只被 1 张卡引用，且非核心域 | 按需数字化 |
| P3 | 已确认丢失或无法找回 | 降级为 `src_unknown` |

### 4.2 建立「录入一张，闭环一张」机制

每次一堂新素材数字化后：
1. 放到正确路径；
2. 黄药师脚本自动扫描，把对应 `pending_archive` 改为 `available`；
3. lint error 自动下降。
