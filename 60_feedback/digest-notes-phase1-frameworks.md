## 一、一堂方法论体系的顶层架构

```
                    Y 型创业模型（顶层哲学）
                           |
        实事求是(理论) ↔ 解放思想(验证) → 知行合一 → 解决真正问题
                           |
              无限进步大地图（世界观）
       个人地图 | 管理地图 | 创业地图 | 无限修炼
       天花板    | 段位      | 概率      | 笃定
```

### 核心识别
1. **Y 模型是根**——所有地图底部都是"实事求是 解放思想"，这是一堂方法论的哲学地基
2. **四张地图是干**——从个人到管理到创业到无限，每张地图有不同的核心追求
3. **地图不是线性**——实际中四个方向可以并行，但地图以线性形式呈现（已识别为局限）

## 二、各域框架关键主张

### 【个人修炼域】
| 框架 | 核心主张 | 关键洞察 |
|------|---------|---------|
| 个人地图 | 四层金字塔：时间管理→迭代层→领先层→追求层 | "天花板"不是能力上限，是持续突破的意识 |
| IPO 学习策略 | Input→Process→Output 六要素闭环 | 大多数人停留在1-2个要素，完整闭环执行成本高 |
| 认知升级十步框架 | Bug→Patch 追踪机制 + EVIDENCE 审计三件套 | 阅读价值不在"知道"，在"哪个认知部件被更新"（Burn line） |
| 刻意练习十年指数 | 四要素配比：固定套路+非舒适区+及时反馈+大量重复 | 缺任一个要素，成长速度减半 |
| 深度复盘冰山图 | 五层穿透：主观感受→客观事实→背后原因→底层模型→能力建设 | 大多数人停在第一层""感觉做得好/不好"" |
| 解放思想五层 | L0盲目创新→L1经验层→L2常识层→L3方法模型层→L4本质理解层→L5学科经典层 | 人与人的差距在 L3-L5 的"抽象度"，不是 L1-L2 的"经验量" |
| 双三角竞争力 | 人类三角（创造力、体系、审美）× AI 三角（场景、数据、基本功） | 乘积效应：任一角为零，整体为零 |
| MUSE AI 全景图 | E变革层→S使用层→U创业层→M奇迹层 | 自下而上涌现，自上而下拉动 |
| 提示词工程总框架 | 七层 AI 工作流：背景→选项→假设→反驳→标准→实验→复盘 | 提示词的本质是"管理 AI"，不是"写咒语" |

### 【管理域】
| 框架 | 核心主张 | 关键洞察 |
|------|---------|---------|
| 管理地图 | L1管自己→L2管项目→L3管团队→L4管业务→L5管公司 | "段位"是核心追求，但评估标准缺失（已识别为局限） |
| 科学提问地图 | 四领域×三级难度：业务分析→辅导团队→咨询教练→萃取经验 | 提问是可训练的，不是天赋 |
| 深度复盘冰山图 | 同个框架被个人域和管理域同时引用 | 复盘是跨域通用能力 |

### 【创业域】
| 框架 | 核心主张 | 关键洞察 |
|------|---------|---------|
| 创业地图 | 三阶段：预判→起盘→增长 | "概率"是核心追求，但缺少量化度方法 |
| 五步法画布 | 需求→解决方案→商业模式→增长→壁垒 | 两张画布的关系：五步法是总流程，产品内核画布是其中一步的工具 |
| 预判模型 | N要素→雷达图→Checklist 三级递进 | 预判不是神秘直觉，是结构化过程 |
| 转化率优化 | 动力三曲线 × 十大浪费触点 | 转化 = 动力/阻力，需要同时优化两端 |
| 产品内核十大指标 | 获客→服务→复购→推荐 四环节 | 只监十个指标，不是数据看板 |

### 【泛产品设计域】
| 框架 | 核心主张 | 关键洞察 |
|------|---------|---------|
| 泛产品三大修养 | 用户价值×最佳实践×无限进步 | 三大修养是价值观骨架，不是具体方法 |
| 泛产品36计 | 3组卡牌×3级应用：需求(13)+审美(4)+落地(19) | 需求解决"为谁做"，审美解决"做成什么样"，落地解决"怎么磨出来" |
| 泛产品10年爬山地图 | L1和我无关→L6创新领先 | L3-L4 是分水岭：从"会用工具"到"能自己设计工具" |
| 顶级产品追求 | 品味 = 曝光量 × 迁移力 | 乔布斯："品味不是天赋，是可训练的过程" |
| 审美提升层级 | 从"看不见"到"大胆想象"的进化路径 | 执行力上限 ≤ 最佳实践理解下限 |
| 讲香模型 | 十指讲香：把"价值点"转化为"价值感" | 价值点是食材，价值感是烹饪 |

### 【科学决策域】（已熟悉）
| 框架 | 核心主张 | 关键洞察 |
|------|---------|---------|
| Y 模型决策 | 有意识→写初版→细打磨→有共识→复盘 五阶段 | 决策是 ROI 分析，不是艺术 |
| X→Y 习惯诊断 | X型（指挥型）→Y型（分析型）转换 | Kahneman + Klein 双攻击 |
| 宽度工具 | 列推建查四步法 | 最常见的盲区：只知道自己知道的 |
| 深度梯梯 | L1-L4 停车场模型 + 三点预测 | 不同深度的决策者停在不同楼层 |
| 高度工具 | 上帝视角四维提升法 | 水平越高，看到的范围越广，但危险是"浮在天上" |
| 共识冰山 | 说服挖冰四层法 + 教练式提问 | 表面意见一致 ≠ 底层共识 |
| 决策复盘 | L1-L4 深度复盘法 + 假设验证闭环 | 复盘不是总结，是假设验证 |

## 五、消化方法论反思

### 黄药师的编译风格（从这次消化中学到的）
1. **老卡 vs 新卡的结构差异**：早期卡片（如地图系列）缺少 Summary/Claims 分区，内容更像"精简课堂笔记"；后期卡片（如科学决策域）有完整的 Summary/Claims/Constraints/Synthesis 分区
2. **攻击者质量的差异**：老卡的外部攻击相对模板化，新卡的攻击更具体、更有紧迫感（如科学决策域的 Kahneman+Klein 组合）
3. **图文对照的重要性**：地图系列卡片的内容高度依赖原始图片（webp/jpg），单独看 markdown 会遗失大量信息

### 我之前的问题
1. **只有科学决策素材**：之前写卡只是"精译"——把一堂的课程翻译成卡片格式，但没有把这个知识放进全库的上下文中理解
2. **不知道其他域的工具怎么落地**：比如写科学决策卡时，不知道 IPO 学习、刻意练习、深度复盘这些框架怎么与决策能力互动
3. **缺乏"跨域迁移"的意识**：比如讲香模型是"表达力"的一种落地形式，泛产品设计是"设计力"的一种落地形式，这些关系之前没有在写卡时考虑
