# 羊奶「卖地图」案例：九层深挖诊断

## 触发来源

用户在对话中连续追问羊奶销售模式，最终锁定：羊奶行业普遍采用「卖地图」模式——即卖区域代理/区域包干，而非直营或底薪提成销售团队。用户要求进入 `method-dialogue-driven-kb-evolution` 五环流程，将此案例沉淀为知识库桥接卡。

---

## L1：事实层（What happened?）

羊奶粉行业的渠道模式与常规婴儿奶粉显著不同：

- **常规奶粉**：品牌商控价、控渠道，销售团队底薪+提成，KA/商超/电商直营或分销。
- **羊奶粉**：厂商给底价，把区域/城市「卖」给代理商；代理商自负盈亏，像「小老板」一样经营该区域。
- 行业内称此模式为「卖地图」——画一块区域给代理商，区域内的事由代理商说了算。

来源证据：
- 战略培训案例：「羊奶粉的激励方式全都是合伙，全都是你把这个生意托付给我，我就变成你的阿里巴巴。」
- itingnao 3979746：「羊奶粉的渠道基本上都是阿米巴模式，都是你给底价才行，和其他奶粉模式不同。」

---

## L2：结构层（How is it organized?）

该模式的关键结构要素：

| 要素 | 厂商侧 | 代理商侧 |
|:---|:---|:---|
| **所有权** | 保留品牌 + 供货权 | 拥有区域经营权 + 本地客户资产 |
| **定价权** | 给底价/出厂价 | 自主定价、自主分销 |
| **投入** | 生产、品牌、供货 | 资金、本地团队、地推、客情 |
| **风险** | 库存风险转移给代理商 | 承担库存、资金、本地市场不确定风险 |
| **激励** | 稳定出货 + 轻资产 | 赚经营利润，多劳多得 |
| **控制** | 弱（只控底价/窜货底线） | 强（区域内运营主导权） |

---

## L3：因果层（Why does it happen?）

羊奶必须用「卖地图」模式的根因：

1. **市场太小**：羊奶消费人群远小于牛奶，单城市/单区域销量有限，撑不起厂商直营团队。
2. **教育成本高**：消费者需要被教育「为什么要喝羊奶」，底薪销售只做成交不做教育。
3. **客单价/毛利结构**：羊奶粉毛利空间足够分给代理商，但不足以支撑多级分销+厂商直营双重成本。
4. **地域差异大**：不同城市消费习惯、母婴店关系、医生/营养师资源差异巨大，需要本地人深耕。
5. **现金流压力**：厂商如果直营，要承担铺货、回款、库存；卖给代理商相当于一次性转移资金和库存风险。

---

## L4：模式层（What pattern does it match?）

羊奶「卖地图」不是孤例，而是一种可迁移的渠道-组织模式：

> **小众/非标/高教育成本品类 × 区域合伙人/阿米巴包干**

同类模式：
- 早期保健品（脑白金的地级市代理）
- 地方白酒（区域总经销）
- 部分医疗器械（县域代理）
- 教育培训（城市加盟/校区合伙人）

反例（不适合此模式）：
- 可口可乐（标品、高频、量大）→ 直营/深度分销
- 苹果手机（品牌极强、标品）→ 直营+授权零售

---

## L5：边界层（When does it NOT work?）

「卖地图」模式失败的高发场景：

| 失败场景 | 原因 |
|:---|:---|
| 品牌力极弱时 | 代理商不愿接盘，因为赚不到钱 |
| 产品同质化高 | 代理商只会比价，无法建立本地壁垒 |
| 厂商底价设计失误 | 底价过高代理商没利润，过低厂商失血 |
| 窜货管控缺失 | 代理商互相拆台，价格体系崩盘 |
| 市场快速放量期 | 代理商会成为扩张瓶颈，不如直营可控 |
| 需要强品牌体验 | 代理商服务不一致，伤害品牌 |

---

## L6：价值层（Who gains/loses?）

利益相关方：

- **厂商**：轻资产、低风险、快速铺市；但失去定价权、品牌控制力弱。
- **代理商**：有机会当小老板、利润上限高；但承担库存/资金/本地竞争风险。
- **消费者**：可能得到更本地化的服务；但也可能面临价格混乱、假货/串货。
- **竞品**：如果羊奶模式跑通，牛奶巨头可能用直营+低价打穿代理体系。

---

## L7：方法论层（What framework explains it?）

已有知识库中可对接的框架：

1. **`tool-strategy-profit-model-comparison`**（冉鹏四模式：直营/强类直营/弱类直营/代理加盟）
   - 羊奶属于「代理加盟」极端形态：经营权完全下放，厂商只保留供货和品牌。

2. **`tool-yitang-channel-scoring-matrix`**（渠道预判评分矩阵）
   - 羊奶在「标准化程度」低、「决策复杂度高」、「客单价/毛利中高」、「执行确定性要求本地资源」的维度上，天然指向代理/合伙人模式。

3. **`yt-management-partnership-equity`**（合伙股权）
   - 代理商机制本质是「外部合伙人」：让渡部分利润，换取对方的资金、时间和本地能力投入。

4. **`yt-tool-unit-model-construction`**（单元模型构建）
   - 代理商的单元经济 = 区域内收入 - 进货成本 - 本地运营成本 - 资金成本。厂商的单元经济 = 出厂毛利 × 出货量。

---

## L8：预测层（What happens next?）

羊奶/小众品类渠道模式的演变路径：

- **早期**：卖地图快速铺市，建立代理网络。
- **中期**：头部品牌开始收编核心代理、转为强管控，或培养大经销商。
- **成熟期**：若品类扩容（如羊奶大众化），直营/电商/商超占比上升，代理模式被压缩。
- **风险点**：品类如果始终小众，代理商会老化、流失，厂商增长见顶。

## L9：行动层（So what should we do?）

知识库层面建议产出的桥接卡：

1. **framework-yitang-channel-partnership-map**（小众品类渠道合伙人/区域包干决策框架）
   - 核心主张：小众/非标/高教育成本品类为何需要「卖地图」式区域代理
   - 双向价值：
     - 给渠道增长域：补充「什么情况下不选直营/分销，而选区域包干」
     - 给商业模式/战略域：把冉鹏四模式中的「代理加盟」做厚，给出决策公式
   - 必须包含：决策矩阵、边界条件、失败模式、外部证据

2. **case-yitang-goat-milk-channel-partnership**（羊奶卖地图案例卡）
   - 作为 framework 的落地案例
   - 包含关键证据、数据估算、正反教训

3. **tool-yitang-channel-partnership-design**（区域代理/底价设计工具）
   - 帮助用户设计底价、区域划分、窜货防控、退出机制
