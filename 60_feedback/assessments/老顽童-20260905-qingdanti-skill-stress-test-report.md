# transcript-to-qingdanti skill 压力测试检验报告（#643）

> 老朱 09-05 检验设计：本稿=检验两步法+skill 必要性的试金石。本报告只回答三问——**skill 帮到了什么 / skill 帮不到什么 / 产出 vs 深挖件差距**，去留裁定权在欧阳锋终审+老朱拍板。
> 实测对象：`00_inbox/新录音2-妙记逐字稿.md`（2026-09-03 私董会，2h58m16s，5.1 万字，1622 行，8 个说话人+1 个外部裁定归属口径）。
> 产出：`40_outputs/content/private-board-majingjing-qingdanti-note.md`，rubric 自评 12/12，对源抽查 28 数据点+24 引语全命中。
> 难度增量（相对 Live261 #638 试跑件）：单人口述稿 → **多人会议稿**（8 说话人、三轮话轮结构、外部归属裁定、跨工具续命）。

## 一、skill 帮到的（去掉 skill 这些大概率做不到或做不一致）

| # | skill 条款 | 本次实际贡献（可验证） |
|:--|:--|:--|
| 1 | **红线 1 零创造 + F-077 对账方式** | 交付前机械对账抓出 4 处归源偏差（「无量化体系」无中生有、引语非逐字、「每周」vs「每期」、买入门槛类比方错问答归属）——不带 skill 红线，这 4 处大概率带病交付 |
| 2 | **产出标准六条每条附机械检查法** | 主观「我整理好了」变成可复跑断言：分层超限 0 命中、手工字符编号 0 命中、8 节结论前置、9 处回收句，grep/awk 一条命令复现（见笔记文末对账节） |
| 3 | **红线 3 删留对照表** | 3 小时对话 146KB→22KB（保留 15%）的删留有机械分界（语气词/寒暄/互动组织语言 vs 结论/数字/角色/规则），删了什么留了痕（笔记文末「删留判断留痕」） |
| 4 | **Step 5 rubric 门禁（不过线不交付+每维引锚点）** | 迫使对源抽查在**交付前**完成并落盘命中数——Live261 试跑时自评是事后补评的，本次是门禁前置，流程位次被 skill 修正 |
| 5 | **红线 2 长稿分段防截断** | 1622 行分 3 段逐字读、逐段重组后合并对账；**跨工具续命实际发生**（kimi 403 断 21h 后 claude 接手），分段边界=断点续跑边界，本次没丢前后稿一致性 |
| 6 | **两步法定位（v1.1 自我边界声明）** | 「本 skill 只管第二步、不承诺信息增量」——本次按边界牌不重复深挖（增量已由 #641/#642 承接），skill 的自我限定防止了越界返工 |
| 7 | **失败模式 9 条症状→修复** | 「创作越界」「重点埋没」「只提不收」对号入座即改，无自行发明检查项 |

## 二、skill 帮不到、本次手工补的（skill 的真实边界）

| # | 手工补位 | 为什么 skill 覆盖不了 |
|:--|:--|:--|
| 1 | **多说话人归属**：8 个说话人映射到人名（说话人1=雅琼主持 / 阿海=老朱 / 说话人6=马晶晶 / 说话人9=陈龙…），笔记头声明「阿海=老朱（#642 口径）」 | skill 输入前提=单人口述稿，通篇无说话人规则；妙记 diarization 本身不可靠（同一标签下混段、主持人称呼与系统标签打架——暖场第 4 位发言主持人既谢「荣斌老师」又问候未上线的陈龙家人），归属只能靠上下文人工裁定 |
| 2 | **切轮结构**：私董会七步骨架（暖场→介绍→三轮→收敛→复盘→收获）是本场天然故事线，但「哪句话是轮次边界」要从主持人话轮里切（「咱们就进入到第二轮」「第三轮收敛到 3 分钟」） | skill 的 10 种故事线只给「选哪条」，没给多人会议的**切轮规则**——执行流程线能对号，节点得自己找 |
| 3 | **自述口径标注**：300 场/2分钟90%疼痛/竞品不超5家（案主自认「豆包说的，没核实」）全部带「自述口径/待独立核实」标注 | Producer 铁律（数字自报必须标注待核实）在 skill 之外；skill 的 D2 只管「可回原文」，不管「原文本身可不可信」——**可追溯≠可信** |
| 4 | **长行拆到哪**：机械检查只报「行长悬殊」，逻辑点边界（一个问答单元切几个条目）是编辑判断，6 处长行拆分全手工 | 机械标准给「超没超」，不给「切在哪」——这是 skill 与编辑判断的交界，属于合理留白 |
| 5 | **删留最后一公里**：陈龙茶道师承/河图洛书、罗毅报名没抢到、手机登录闲聊——判「无决策信息量」删除 | 删留对照表判「是不是信息」，「对使用者决策有没有用」是场景判断，表外 |
| 6 | **深挖增量 0**：真问题链 5 条+暗知识 12 条全来自王语嫣深挖件，本 skill 零贡献 | 两步法设计如此——**不是缺陷是分工**。见第三节：这正是去留裁定的关键口径 |

## 三、产出 vs 深挖件的差距

| 维度 | 清单体笔记（本 skill 产出） | 深挖件（王语嫣 diag_20260905） |
|:--|:--|:--|
| 覆盖面 | 1622 行全量重组，是深挖件的**素材超集**——暗知识 12 条中 ≥10 条在笔记有落点（赢在牌桌之外/势能设计/望诊迁移律/角色阶梯/面相指标/定价弹性/火运/化解业力/一堂会员群渠道实证/三阶段论） | 只提增量点（真问题链+暗知识），不追全 |
| 深度 | **零判断**——红线禁创作，罗毅「交付复制不了」只留原话不下结论 | 判断层：真问题链点破「交付复制 > 客群」优先级 |
| 用途 | 可扫读素材层：产卡引用、复习、溯源锚点 | 立项/产卡优先级依据 |
| 关系 | **上下游不是竞品**：第一步深挖（增量）→ 第二步清单体（可达性） | 同左 |

**差距结论**：拿本 skill 单体对标深挖件是错位比较——skill 产出的笔记在「深度」上必然输给深挖件，在「覆盖面+可达性」上必然赢。老朱检验设计的真正对象是**两步法整体**：本次实测=深挖件已就位时，第二步把 5.1 万字压到 22KB 可扫读且 28/28+24/24 对账零走样，**两步法成立**。

## 四、去留证据与建议（供终审，非结论）

**留的证据：**
1. 可归因于 skill 的硬贡献有三项：红线对账（抓出 4 处归源偏差）、六条机械标准（结构断言可复跑）、rubric 门禁（自评前置+锚点化）。去掉这三项，本次交付的 D2（零走样）和可复现性不成立。
2. 两稿实测可分辨：Live261（#638）11/12、私董会（#643）12/12，rubric 档线与实际产出分层一致，评分可复跑。
3. skill 帮不到的 6 项里，5 项属「输入前提声明不足」而非「方法错误」，可用低成本增补解决。

**不建议全员必备的证据：**
1. 多人会议稿必须人工补归属+切轮（第二节 #1/#2），换一个不懂 #642 口径的人来跑，老朱的话会安到「阿海」头上。
2. 无第一步深挖的稿子，skill 只能产出「结构漂亮的信息组织」——D1/D2 达标但无决策增量，skill 自己在定位节承认这一点。

**建议（三选一，裁定权在欧阳锋/老朱）：**
- **A（推荐）**：留，定位收窄为「第二步专用件」，非全员必备；触发条件=已有口述稿/逐字稿且第一步深挖已做或不需要。skill v1.2 增补 3 行「多说话人输入前提」（说话人映射表+归属口径声明+切轮以主持人话轮为准）。
- B：留并升全员必备——反对：多人会议稿的手工补位没有 skill 能兜底，「必备」会制造虚假安全感。
- C：删——反对：本次 4 处归源偏差全靠 skill 红线+机械标准抓出，删掉等于回到凭感觉整理。

## 五、本次压力测试对 skill/rubric 的反向输入（不改文件，仅登记）

1. 妙记 diarization 错乱是常态不是例外（暖场段「说话人4」标签与主持人称呼冲突），任何口述稿 skill 都应声明「说话人标签仅供参考」。
2. rubric D2 只测「可回原文」，不测「原文可信度」——自述数字的「待核实」标注目前靠 Producer 铁律兜底，rubric 可考虑在 D2 锚点里补「自述口径已标注」半分档（是否改由 rubric 维护者定）。
3. 「跨工具续命」场景被红线 2（分段）意外兜住——分段边界=续跑边界，这一条价值在本次实暴，建议写进 SKILL.md 红线 2 的理由栏。
