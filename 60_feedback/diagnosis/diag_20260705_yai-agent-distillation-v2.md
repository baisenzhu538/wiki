# YAI Partner 第二轮蒸馏：新增 Agent 能力模式

## 第一轮已提取（不重复）

- 六要素状态标记体系
- 主挖角/副挖角/贯穿约束优先级
- 0-10 信心打分
- 保底策略
- 备忘录输出结构
- 里程碑计划生成

## 第二轮新增的 7 个能力模式

### 1. 创造力主动生成——从"暂放"到"基于上下文推演"

**触发**：用户说"创造力角一直空着，你帮我想想"

**Partner 的做法**：不是问"你觉得呢"——是基于画布里所有已有信息（10年代码库、单人+AI、不懂代码、强耦合、CAN协议），主动推演出四个方向：
- AI 原生开发平台
- 智能医药 OS
- 可交易资产
- 重新定义业务

四个方向之间有逻辑递进——从工具层到平台层到资产层到范式层。

**对 KDO Agent 的启示**：创造力角不能永远是"暂放"。当其他五个角填得足够密时，Agent 应主动提出"基于目前信息，我帮你推演几个可能的方向，你挑一个有感觉的"。

### 2. 场景边界重新校准——当用户改变前提

**触发**：用户从"不改代码只梳理"切换到"另起炉灶搭新系统替代老系统"

**Partner 的做法**：
- 立刻停下手头工作，先确认新前提（"等一下——你刚才说的其实改变了一件重要的事"）
- 用选择题收窄（A/B/C 三选一确认新旧系统关系）
- 确认后将变化广播到场景/数据/基本功三个角

**对 KDO Agent 的启示**：Agent 必须能识别"用户说的这句话是否改变了画布的前提条件"。如果是，先停下手头深挖，先确认新边界。

### 3. 限时数据源标记——时间窗口驱动优先级重组

**触发**：用户说"开发人员可能 3 个月后离职"

**Partner 的做法**：
- 立刻在数据角新增一个维度："限时数据源"——这个数据源有失效日期
- 将节奏拆成双线并行："抢人线"（3个月窗口）+ "AI梳理线"（稳步推进）
- 每条线有独立优先级和产出物

**对 KDO Agent 的启示**：Agent 应能识别"限时约束"——某个数据源/能力/条件有时效性时，自动提升对应角的优先级。

### 4. 专家级领域知识注入——SVN 考古学

**触发**：用户有 SVN 账号但不知道挖什么

**Partner 的做法**：不只是复述用户的直觉——在用户的 3 条线索上追加了 4 条新角度：提交者地图、提交消息编年史、紧急修复记录、大颗粒提交事件。每一条都有"为什么有价值"的说明。

**对 KDO Agent 的启示**：Agent 在"数据"角上不应只收集用户已知的——应基于场景特征主动注入该领域的专家级挖掘角度。

### 5. 诚实边界声明——"我没看过你的手册"

**触发**：用户让 Partner 分析 EC 手册和 20 条铁律

**Partner 的做法**：直接说"我没看过，不能替你判断"。然后给了筛选框架和判断标准，让用户自己拿着框架去扫。

**对 KDO Agent 的启示**：Agent 不应假装知道。当信息不在上下文中时，给框架和标准，不给具体判断。这是 TCPR 中 C 角色的核心行为。

### 6. 3年视角审美审计——"未来的人会骂什么"

**触发**：用户问"3年后新人+新AI接手会骂什么"

**Partner 的做法**：推演出 5 条"未来抱怨"→ 对应 5 条"现在做什么"→ 按时间敏感性排序。最关键的判断："第 5 条是时间敏感的（开发还在），其他四条随时可以做"。

**对 KDO Agent 的启示**：审美角不只是当下的验收标准——可以用时间维度升级追问。这是 Truman 说的"审美要带时间尺度"的具体操作化。

### 7. M1 到日级的执行脚本——从里程碑到可执行动作

**触发**：用户问"能在这周内跑一轮吗"

**Partner 的做法**：把 M1 拆成 Day 1-5 的日级计划——每天有明确的输入/产出/验证方式/时间预估/卡点应对。每一天都是可独立执行的最小单位。

**对 KDO Agent 的启示**：里程碑计划不是终点——当用户表示"这周能跑吗"，Agent 应能自动压缩到日级可执行脚本。

## 两轮对比：Agent 成熟度进化

| 维度 | 第一轮 | 第二轮 |
|:---|:---|:---|
| 创造力 | 暂放 | 主动基于上下文推演 4 个方向 |
| 场景边界 | 只确认不做范围 | 用户改前提→立刻停下→重新校准→广播到其他角 |
| 数据挖掘 | 只收集用户说的 | 主动注入专家知识（SVN考古7线索） |
| 时间感知 | 无 | 限时数据源驱动双线并行优先级重组 |
| 审美深度 | 当下验收标准 | 3年视角审计——未来的人会骂什么 |
| 执行精度 | M1-M6 里程碑 | 日级执行脚本 |
| 边界诚实 | 无 | "我没看过你的手册" |
