## 1. 为什么立项（现状缺口，实况核查）

- 已建 #118 / #432 / #434 都只到「复盘摘要 + 事件指针」层，**不是全量原文**。
- 全量上下文（老朱↔各 agent 的完整对话流 + 每步工作痕迹）至今无统一采集，散在各工具会话存储里。

## 2. 采集口径（老朱已拍板）

| 类型 | 采什么 | 落地形态（建议） |
|:--|:--|:--|
| 甲 · 会话原文 | 每个 agent 每次 CLI 会话完整对话流（老朱↔agent 对话 + 思考 + 工具调用） | `session.md` 原文 |

- 索引与全文如何分层、如何不重复——属我后续审计口径，本文不展开。
