## 二、L1：业务公式 / 单元模型

### 2.1 这门课的商业公式

```
输入：产品/服务 + 线索 + 销售团队 + 有限资源
处理：提炼卖点 → 拆解过程 → 推进业绩 → 激励团队 → 打造工具
输出：稳定可预测的销售收入 + 可复制的团队能力 + 可沉淀的销售资产
```

### 2.2 关键单元模型

**销售复制 ROI = （稳定成交率 × 客单价 × 人效） / （管理成本 + 人员流失成本 + 试错成本）**

- **稳定成交率**：来自用户分层准确 + 卖点清晰 + 过程拆解到位。
- **客单价**：来自目标客户选择和定价策略。
- **人效**：来自工具箱和标准化动作。
- **管理成本 / 流失成本 / 试错成本**：科学销售要降低的三项核心成本。

**结论**：这门课不是教「怎么把东西卖出去」，而是教「怎么让团队能持续把东西卖出去」。

### 2.2 OPC（一人公司）版公式

对老朱的 OPC 目标而言，公式变形为：

```
OPC 销售复制 ROI = （线索分层准确率 × 关键节点转化率 × 交付物质量） / （个人时间 × AI 调用成本 × 返工风险）
```

- **人**被压缩为「创始人 + AI 智能体军团」。
- **激励团队**被替换为「创始人自我驱动 + AI 提醒/反馈循环」。
- **最大杠杆**：把创始人稀缺的判断力用在关键决策点，把信息处理、初稿生成、提醒预警交给智能体。

## 三、L2：假设审计

| 假设 | 保守 | 中性 | 乐观 | 敏感点 |
|:---|:---|:---|:---|:---|
| 销售能力可以被体系化复制 | 只能复制 60% | 可复制 80% | 可复制 95% | ⚠️ 顶级关系型销售仍有不可复制部分 |
| 科学销售适用于所有业务 | 仅 To B 面销有效 | To B/To C 都有效 | 所有销售场景 | 🔴 电商/直播等海量线索场景颗粒度不同 |
| 用户分层和卖点是源头 | 是重要因素 | 是最重要的起点 | 决定一切 | ⚠️ 产品本身没人要时，分层也救不了 |
| 过程拆解能降低决策成本 | 对长周期有效 | 对多数面销有效 | 对所有销售有效 | ⚠️ 冲动消费场景决策路径极短 |
| 激励组合比单一金钱更有效 | 仅对早期团队 | 对成长期团队 | 对所有团队 | ⚠️ 个体差异大，需动态调整 |
| 销售工具箱能加速新人成长 | 缩短 30% 上手时间 | 缩短 50% | 缩短 70% | 🔴 工具若脱离场景，反而造成负担 |
| 这套方法论可直接用于 OPC | 只能借鉴 30% | 可借鉴 60-70% | 可完整映射 | 🔴 原版假设「有销售团队」，OPC 需改编 |

**最敏感假设**：销售五步法原版为「带团队的管理者」设计，直接移植到 OPC 会水土不服——激励团队、周会三要点、拆目标到个人等模块都需要重新设计。

## 四、L3：合规 / 监管 / 边界

1. **法律边界**：课程中的商标/合同/提成案例涉及法律判断，必须标注「AI/课程只提供公共知识扫盲，最终法律结论需专业机构复核」。
2. **数据隐私边界**：销售过程拆解涉及客户通话、聊天记录分析，OPC 智能体处理这些数据时需符合隐私合规。
3. **适用边界**：
   - ✅ 适用：已有产品价值验证、需要规模化销售的团队；OPC 需要系统化销售能力的创始人。
   - ⚠️ 谨慎：产品价值尚未验证、线索量极少、销售周期极短的冲动消费业务。
   - ❌ 不适用：完全依赖个人关系的顶级顾问式销售（如某些家族办公室、艺术品经纪）。
4. **方法论归属边界**：科学销售五步法是一堂与李蕊共创的体系，需明确来源，不可冒充通用销售理论。
5. **OPC 改编边界**：智能体不能替代关键人际信任建立，只能替代信息处理、初稿生成、提醒预警。

## 五、L4：失败模式库

| 失败模式 | 共因 | 预警信号 | 一堂反打 |
|:---|:---|:---|:---|
| **迷信销冠** | 认为销售靠天赋 | 招不到牛人就做不起来 | 用户分层 + 过程拆解，把销冠经验显性化 |
| **平均分配线索** | 缺乏分层意识 | 所有销售拿同样线索 | SABC 分级，把最好资源砸给最重要客户 |
| **卖点五花八门** | 缺乏统一卖点提炼 | 每个销售讲的不一样 | 卖点提炼四步法，统一价值语言 |
| **过程黑盒** | 只盯结果不盯过程 | 客户卡两个月不知道原因 | 拆解过程三步法，识别关键决策点 |
| **目标拍脑袋** | 缺乏科学拆解 | 月度目标完不成也不知道差距在哪 | 业绩管理三步法：拆目标、定策略、追过程 |
| **只会发钱** | 激励手段单一 | 销售只挖老客户不愿拓新 | 六维激励模型，物质+精神组合 |
| **赤膊上阵** | 没有销售工具 | 新人靠自己摸索 | 销售武器库六维雷达图 |
| **OPC 过度自动化** | 把关键沟通也交给 AI | 客户感觉像在和机器人对话 | 智能体只做信息/初稿/提醒，关键沟通由人做 |

## 六、L5：隐性成本与替代方案

### 6.1 隐性成本

1. **体系建设前期成本**：用户分层、卖点提炼、过程拆解需要 2-4 周集中梳理，早期团队可能等不及。
2. **数据收集成本**：定量验证分层假设需要历史成交数据，很多初创公司数据散乱的。
3. **工具维护成本**：话术、案例、模板需要持续迭代，否则很快过时。
4. **团队学习成本**：从「干就完了」到「按流程做」需要管理习惯改变。
5. **OPC 智能体开发成本**：虽然比雇人便宜，但前期设计智能体协作流程需要投入。

### 6.2 替代方案

| 替代方案 | 成本 | 适用场景 |
|:---|:---|:---|
| 不建体系，继续依赖销冠 | 低（短期） | 极小团队、销售不是瓶颈 |
| 只上一套 CRM | 中 | 已有基本销售流程，需要数字化 |
| 全盘采用科学销售五步法 | 中高 | 销售是瓶颈、团队 ≥3 人、有产品价值验证 |
| OPC 智能体军团 | 中（时间） | 一人公司、创始人时间稀缺、愿意把销售能力代码化 |
| 外包销售团队 | 高 | 需要快速起量但不想自建团队 |

**结论**：对 KDO 知识库而言，6 张高密度卡是覆盖五步法 + OPC 改编的最佳平衡；对 OPC 落地而言，先从「用户分层 + 过程拆解」两个智能体开始。

## 七、L6：人与组织执行能力

### 7.1 团队执行

- **所需能力**：业务拆解、数据分析、假设验证、流程设计、激励设计、工具沉淀。
- **现实能力**：多数创业公司销售总监是从销冠提拔，擅长自己卖，不擅长建体系。
- **关键杠杆**：把「超级销售」变成「体系构建者」。

### 7.2 OPC 执行

- **所需能力**：创始人判断力、AI 协作能力、流程设计能力。
- **现实能力**：创始人通常有业务洞察，但缺乏系统梳理时间。
- **关键杠杆**：用智能体把「信息处理」和「标准化动作」自动化，让创始人只介入关键决策点。

---

## 八、L7：市场情绪 / 骗局信号

1. **销售培训市场鱼龙混杂**：大量课程教「话术技巧」「逼单心理学」，隐含假设是销售靠套路和人性弱点——这是误导。
2. **「找牛逼销售总监」神话**：很多老板认为招对人就能解决一切，忽视了体系建设。
3. **CRM/SaaS 厂商营销**：常把工具当成解决方案，忽略了方法论和流程先行。
4. **AI 销售工具营销**：宣称「AI 替代销售」，隐含假设是销售不需要人际信任——这也是误导。

**结论**：科学销售方法论本身不是骗局，但如果被包装成「听了课就能复制销冠」，就犯了和销售技巧鸡汤同样的错误。

## 九、L8：边界案例与反例

| 看似能做但不能 | 看似不能但可以 |
|:---|:---|
| 用科学销售把所有人都变成顶级销售 | 用科学销售把普通人提升到 60-80 分稳定产出 |
| 跳过产品价值验证，靠销售技巧救活产品 | 在产品价值验证后，用科学销售加速规模化 |
| 用一套流程覆盖所有行业所有客户 | 为每一类客户设计一条成交路径 |
| 用金钱激励解决所有动力问题 | 用六维组合激励匹配不同阶段和个体 |
| 把销售工具当万能药 | 把工具嵌入具体销售环节，持续迭代 |
| OPC 用 AI 完全替代人与人的信任建立 | OPC 用 AI 处理信息，人负责关键沟通和关系 |

### 10.3 缺口识别：什么是真缺口？

上表说明：**框架层面的概念大多能被现有 KDO 卡解释，但缺少把一堂方法论实例化到「销售管理」这一商业能力的专门卡片**。

真正的新增价值有三类：

1. **体系层**：一张完整的科学销售五步法 framework，把销售管理作为独立商业能力组织起来。
2. **工具层**：用户分层/卖点、过程拆解、业绩管理、销售工具箱四张可操作工具。
3. **组织层**：六维激励模型一张 framework，填补激励设计的空白。

剧本杀 SaaS、美容院、快钱支付等案例将作为工具卡和 framework 卡的嵌入式证据，不单独生产 case 卡（已有 `case-yitang-sales-routine-deconstruction` 覆盖刻意练习视角的销售训练）。

## 十二、建议产出的 6 张卡

基于以上诊断，建议产出 **1 framework + 4 tool + 1 framework（激励）**。案例将作为嵌入式证据嵌入工具卡，不单独生产 case 卡。

### Card 1: `framework-yitang-scientific-sales-five-step`

**类型**：framework  
**主域**：sales / yitang  
**定位**：科学销售方法论总览，建立「销售管理是一门科学」的认知地图，并桥接到一堂已有方法论体系。

**必须包含的 section**：
1. **一句话**：科学销售 = 用数据驱动和系统方法让销售能力从依赖个人变成可预测、可复制、可规模化的组织能力。
2. **五步法总图**：提炼卖点 → 拆解过程 → 推进业绩 → 激励团队 → 打造工具。
3. **粗放销售六大通病**：不懂科学销售、缺用户卖点、不拆销售过程、不抓销售过程、不懂激励、没有工具箱。

### Card 2: `tool-yitang-customer-segmentation-and-value-prop`

**类型**：tool  
**主域**：sales / marketing / strategy  
**定位**：Step 1 落地工具，把「用户分层四步法」和「卖点提炼四步法」合并为一张可执行卡。

**必须包含的 section**：
1. **When to Use**：线索多但转化率低、卖点不统一、资源分散。
2. **用户分层四步法**：确定销售目标 → 提出分层假设 → 验证分层假设 → 全面执行分层。
3. **SABC 分级表**：S/A/B/C 定义、分配资源原则、跟进策略。

### Card 4: `tool-yitang-sales-performance-management`

**类型**：tool  
**主域**：sales / management  
**定位**：Step 3 落地工具，让业绩从「过山车」变成「可预测」。

**必须包含的 section**：

### Card 5: `framework-yitang-sales-incentive-6d`

**类型**：framework  
**主域**：sales / management  
**定位**：Step 4 激励设计框架，六维模型 + 50 策略 + 阶段重点。

**必须包含的 section**：
1. **一句话**：激励不是事后奖励，而是事前设计的发动机。
2. **四大常见问题**：忽略激励、无效激励、只靠金钱、标准不科学。
3. **六维激励模型**：目标有渴望、业绩有奖金、同事有竞争、打仗有感情、成长有奔头、岗位有使命。
4. **50 策略速查表**：按六维分类，每维 6-10 个策略。
5. **不同阶段激励重点**：探索期（软性为主）、复制期（使命+感情+初步提成）、快速增长期（金钱大胆）、成熟期（规则细致+多元化）。
6. **发钱三大设计重点**：杠杆点、公平点、感知点。
7. **OPC 改编提示**：六维激励对 OPC 不适用，替换为「目标-行动-反馈」自我驱动循环。
8. **Checklist**：≥8 项。
9. **Anti-patterns**：只发钱、目标拍脑袋、规则不透明、激励与目标割裂。
10. **Critique**：≥3 个外部反对者 + ≥2 个内部局限。

## 十四、OPC 智能体落地特别说明

老朱的 OPC 目标与销售五步法高度匹配，但需做以下改编：

| 原版（带团队） | OPC 版（一人+AI） |
|:---|:---|
| 用户分层四步法 | 用户分层智能体：判断「这个客户值不值得我亲自跟」 |
| 客户意图识别 | 客户意图识别智能体：识别决策阶段/抗拒点/情绪 |
| 销售过程拆解 | 销售过程拆解智能体：追踪里程碑、卡点预警 |
| 业绩管理三步法 | 业绩预测 + 跟进编排智能体：周计划 + Gap 提醒 |
| 六维激励团队 | 替换为创始人自我驱动机制（目标-行动-反馈循环） |
| 销售武器库 | 智能体提示词库 + 提案模板库 + 案例库 |

这些改编已在 `opc-ai-sales-agent-architecture.md` 中记录。本次新产出的 6 张 KDO 卡应成为该架构的底层方法论来源，需在 `opc-ai-sales-agent-architecture` 的 related 中回链。
