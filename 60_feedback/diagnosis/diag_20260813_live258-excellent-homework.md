## 一、全网调研（动态饱和达成，4 查询 3 组主题）

### 组 1：提示词工程 → 原子能力分解（2026 共识）

- **Prompt engineering 作为职业在消失，作为技能是底线**（HuggingFace/Anthropic 转向 context engineering）
- **Atoms→Molecules→Skills→Frameworks 四级分解**：原子=单指令（Task+Constraints+Output Format）；分子=原子+few-shot（结构化任务 +10-30% 准确率）；技能=触发+步骤+资源；框架=组织层——**与 Feature 思维"最小可测试原子单元"高度同构**
- **Minimum viable instruction 四件套 = Goal + Constraints + Definition of Done + Verification**——与作业中"最终意图/负面限制/生成标准/验收清单"一一对应，业界模板与学员自悟完全重合
- Few-shot beats description（贴例子 > 描述）；角色帮助风格不帮助准确；结构化输出/版本化/评测是生产默认

### 组 2：LLM 输出质量评估（rubric 体系）

- Rubric 设计：从用户投诉出发/一次一个标准/序数 1-5/锚定真实例子/先 reason 后 score/定期人机对齐校验
- 迭代式 rubric 优化循环（Microsoft Copilot Studio Kit）：定义→AI 评分→人工评分→对齐→标记好差例→修正→重跑——**与 jeffgirl V1-V5、张丽娜 A/B 版本管理完全同构**
- 生产纪律：一次一变量/镜像生产/多样化测试集/确定性检查先行 LLM-judge 次之/分数全持久化/配置可追溯（prompt_version+model_version+dataset_version）
- 反模式：单指标迷信、无回归测试、忽略用户反馈、无 incident plan

### 组 3：AI 成熟度分层（不能跳层）

- 所有 2026 成熟度模型收敛：**数据准备→模型选择→提示→RAG 上下文→工作流→单 Agent→多 Agent→组织治理**，且**不能跳层**（Arsanjani/KPMG/Zencoder/Hakkoda 共识）
- Arsanjani 六子级 agentic maturity（静态调用→动态工具→ReAct→多 Agent 层级→meta-agent→自进化 swarm）
- 人在环全程核心：最高成熟度下人类转"AI 编排者"角色

### 组 4：幻觉防护/事实约束（与王鹏飞案例强印证）

- **Citation-grounded outputs 是最强幻觉抑制器**："模型找不到来源就必须省略或承认缺口"——自纠正闭环
- 预入库验证协议（Clarity Gate 9 点：hypothesis vs fact 标记/不确定性标记/不可验证走 HITL）
- Confidence gate / fail-closed：低于阈值拒绝回答而非猜测
- 评测区分 faithfulness（生成问题）vs context precision（检索问题）——失败要归因到层

## 三、9 层深挖（L1→L4→L9）

### L1 业务公式

Feature 思维价值 = **输出质量可归因** × **Feature 可迁移复用** × **无意识显性化**。
"AI 输出质量是 Feature 组合的结果"（黄华春总结）——把玄学变工程。

### L2 假设审计

- 假设"AI 输出质量是玄学/运气"→ 被 10 份作业证伪（全部可归因）
- 假设"换工具能解决问题"→ 行知证伪（只换工具不改底层规则）；雍博"换模型试试"vs"科学假设模式"对照
- 假设"AI 改不如自己改"→ 黄华春证伪（没给 AI 迭代的机会）
- 假设"周期表覆盖已足够"→ 部分证伪：作业命中周期表仅 15/100，但**"事实约束/DataPack"类在周期表缺失或学员未认识**（王鹏飞翻车根因）

### L3 边界

- 适用：AI 输出质量可拆解场景（内容/方案/数据/代码）
- 不适用/打折：**创意差异化工件**（农夫三拳认知反差型——"反差很难通过简单系统体系设置制造"）；**高度依赖实时现场信息的任务**（视频工作台 5 关键帧串联失败）；超小团队复杂状态机（黄谦"复杂度高易冗余"）
- Feature 思维不回答"做什么"（方向/审美判断在人），只回答"怎么把输出质量做可控"

### L4 失败模式（KDO 实证 + 业界印证）

| # | 失败模式 | 作业实证 | 业界印证 | 防御 |
|:--|:--|:--|:--|:--|
| F1 | **事实扩散**：AI 不质疑输入错误，只工整扩散 | 王鹏飞 18 桥→四份物料返工 | citation-grounded 最强抑制器 | DataPack 事实包+负面约束+强制引用 |
| F2 | **单意图平均化**：多意图混在一句 prompt → 四不像 | 王鹏飞四物料均 70 分但都不够对 | 一次一变量 | 拆最终意图，一次只出一种交付物 |

## 四、核心洞察（7 条）

1. **事实扩散是最贵的学习**：王鹏飞 18 桥案例是全素材最痛的实证——AI 不会质疑你的口误，只会把它工整地扩散到所有交付物。业界 citation-grounded + Clarity Gate 预入库验证协议，恰好命中周期表的一个真实缺口：**DataPack/事实约束类 Feature 缺失或未被认识**。这不是补一张卡，是补一个 Feature 家族。

2. **验收标准是跨作业第一缺项**：10 人中 8 人缺"最终意图"，7 人缺"验收清单"——与业界"评测是内容运营最重要指标""rubric 从用户投诉出发"完全互证。"没有验收清单，读到最后自己也没标准了"（王鹏飞）是返工失控的根因描述。

3. **无意识→有意识是 Feature 思维的本质价值**：黄华春"知道自己不知道什么" > 学会多少 Feature；王鹏飞"我有一堆散牌却没意识到那是牌"。Feature 思维的最大产出不是新 Feature，而是**让已有实践显性化、可归因、可复用**。

4. **叠加效应不是并列而是链式**：jeffgirl V4 揭示了 1+1+1>3 的机制——**Feature 链（上一个 Feature 的输出成为下一个的输入）**。目标锚定→策略对齐→六层漏斗→货盘分层→一致性诊断：每一步的产物被下一步消费。这解释了为什么"设定角色+参考案例+格式设定"能覆盖身份/风格/结构三个正交维度。

5. **不能跳层是三层印证**：业界成熟度模型（Arsanjani/KPMG/Zencoder）"you cannot skip layers" ↔ 行知"所有短板都在 L1/L2/L3 基础层" ↔ 雍博"下层地基没打好，上层智能体能力完全失效"。KDO 的 L0-L5 分层与业界完全同构——周期表本身就是成熟度模型的 Feature 级实现。

6. **作业是 Feature 思维的"教学法样本"**：10 份作业的共性结构（用/缺/叠加/改进/假设）本身构成可复用的**复盘五步法**——这是素材比单案例更大的价值：一个可教给任何人的方法论模板。

7. **素材补上了域内"非 Truman 案例"空白**：现有 case-truman-* 全是 Truman 本人案例。10 份学员作业是真实多行业实践（内容获客/具身智能/直播复盘/教研/医疗数据/视频生产/冷邮件），让 Feature 域首次拥有"普通人从零到一"的迁移证据链。
