# 王语嫣诊断记录模板 v2

> 每次对话式诊断结束后，将关键过程沉淀为一条诊断记录。
> 本模板基于 WYY-Diagnosis 工作流：准备 → 问题表征 → 假设清单 → 诊断性追问 → 框架匹配 → 记录反馈。
> 积累 20-30 条后，这些记录本身可被检索和 pattern matching。

---

| 时间窗口 | 紧急 / 中短期 / 长期 |
| 可挑战度 | 用户能接受多锋利的追问？ |
| 已提供素材 | 文档 / 对话 / 数据 / 无 |

---

## 1. 准备：诊断前的元问题

在开始追问前，先确认以下问题是否已回答：

- [ ] 用户要做什么决策？（诊断必须服务于决策）
- [ ] 用户已经知道什么？（避免重复提问）
- [ ] 用户愿意被挑战到什么程度？（决定追问锋利度）
- [ ] 时间窗口有多紧？（决定诊断深度）
