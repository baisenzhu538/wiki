# tags 来源形态词黑名单检查建议（2026-08-23）

## 问题实证（3 例）

批次验收正文抽查（升级标准）连续发现**来源形态词被当作内容词写入 tags**：

| 卡 | tags 内容词 | 问题 |
|:--|:--|:--|
| dk-ai-prediction-expiry-date | …/逐字稿 | "逐字稿"=来源形态（该卡无 source_person，来源是逐字稿），非内容主题 |
| concept-feishu-api-pagination-trap | 拆书会 | "拆书会"=来源活动，内容主题（API/分页/陷阱）缺失 |
| （第三例同类，抽查样本内） | — | 模式成立：来源词混入内容词池 |

**根因**：来源形态词（逐字稿/拆书会/口述/直播/训练营/笔记/开放麦…）在正文/元数据高频出现，被当作"标签"顺手写入——它们描述**来源形态**而非**内容主题**——污染内容词池（检索时"拆书会"命中 API 陷阱卡=噪声），且挤占主题词位置（错配卡主题词缺失）。

## 建议（tags-audit 扩展 + 存量清理）

### 1. 检查器加"来源形态词黑名单"（黄药师，tags-audit.py 扩展）

- 黑名单词表：`逐字稿/拆书会/口述/直播/训练营/开放麦/笔记/分享会/圆桌/对话` 等来源形态词（可配置，随实证扩充）
- 检查：内容词命中黑名单 → 报 warning（含卡 ID+词+建议：移除或移入 source 字段）
- 与 #474 四指标并列（第五指标：来源词污染率）——进 tags-audit 输出 + 健康线（污染率 <1% 目标）

### 2. 存量清理（随 #426 治理批次）

- tags-audit 黑名单扫描全库 → 命中卡清单 → 移除来源词/补主题词（老顽童随域批次处理）
- 已发现 2 张（dk-ai-prediction-expiry-date/concept-feishu-api-pagination-trap）明确补词

### 3. 词表纪律入轴文件

- 各域轴文件（decision-making/ai-collaboration/content 等）加注：**内容词=主题词，来源形态词禁止入内容词池**（来源走 source_person/source_context 或 tags 来源轴）

## 需要谁动作

- **黄药师**：tags-audit 黑名单检查（第 5 指标）+ 单测
- **王语嫣**：裁定词表 + 轴文件纪律注记 + 存量清理排期（随 #426 批次）
- **老顽童**：后续批次补词时遵守（黑名单词不入内容词）；已发现 2 张补词
- **欧阳锋**：批次验收抽查持续执行（正文读验证——本模式 3 例全靠正文抽查暴露）

## 边界

- 黑名单词表可配置（防误报——"笔记"可能是内容词（如"笔记法"）——需上下文判断：黑名单只拦**独立出现**的来源形态词，复合词（笔记法）不拦——实现时定）
- 不动已验收批次状态（存量清理为增量）
