# 诊断：冰山六层——外部增强 + Agent 适配

## 一、外部可补充的策略（按层对照）

### L1-L2：穷举展开 → 已有策略够用

一堂的四维穷举（人群/客户/市场/行业 + 场景/问题/需求/痛点）已覆盖。外部无显著增量。

### L3：固定核心任务 → 补充 Switch Interview

| 来源 | 技术 | 补充什么 |
|:---|:---|:---|
| Bob Moesta | **Switch Interview** | "重构购买时间线"——锚定购买时刻→探索挣扎时刻→被动搜索→主动搜索→决定时刻。冰山 L3 只有"固定核心任务"，缺"怎么从用户嘴里掏出真正的任务"。Switch Interview 是 L3 的前置调研策略。 |

### L4：任务地图 → 补充 Outcome-Driven Innovation (ODI)

| 来源 | 技术 | 补充什么 |
|:---|:---|:---|
| Tony Ulwick | **ODI 期望成果矩阵** | 重要性×满意度四象限。冰山的 8 步地图是定性推演，ODI 补充了定量验证——用户对每步的"重要性"和"当前满意度"打分。两者结合：先用冰山 L4 推演出 8 步，再用 ODI 矩阵找出"高重要性×低满意度"的切入机会。 |

### L5：隐藏洞察 → 补充四种力量的"量化权重"方法

一堂的四种力量是定性框架。外部可补充：

| 技术 | 补充什么 |
|:---|:---|
| **力量评分表** | 对推力/拉力/焦虑/习惯各打 1-5 分，只有当(推力+拉力) > (焦虑+习惯)×1.5 时用户才会切换。（1.5 是行为经济学中的"现状偏见系数"——人们高估已有的 50%。） |
| **JTBD Timeline** | 不是"四种力量同时起作用"，而是用户在不同时间点上主导力量不同——推力在"挣扎时刻"最强，焦虑在"决定前夜"最强。 |

### L6：需求假设 → 补充 Opportunity Solution Tree

| 来源 | 技术 | 补充什么 |
|:---|:---|:---|
| Teresa Torres | **Opportunity Solution Tree** | 不是从 L5 直接跳到机会卡片。中间多一步：业务目标→多个机会（基于 L4/L5 洞察）→多个解决方案→实验。OST 让 L6 的机会卡片不只是一次性的，而是持续发现和迭代的。 |

## 二、Agent 原生适配

冰山六层本质是"人分析人"——依赖人的判断力、访谈经验、微观体感。Agent 做需求分析不能用同一套假设。以下是每层的 Agent 增强策略：

### L1-L2 Agent 增强：自动化信号采集

人靠经验和直觉拆用户和场景。Agent 靠**多源数据自动聚合**：

| 信号源 | 能发现什么 | 替代人的什么 |
|:---|:---|:---|
| Reddit/知乎语义分析 | 用户"正在经历但没明说"的痛点 | 替代"你觉得用户有什么问题"的猜测 |
| App Store/电商评论 NLP | 竞品的用户高频抱怨和期望 | 替代手动翻评论 |
| Google Trends + 搜索词分析 | 需求的季节性和地域分布 | 替代"大概感觉" |
| Glassdoor/脉脉员工评价 | 竞对公司内部对产品的评价 | 替代行业打听 |

Agent 的 L1-L2 不是"我想想用户是谁"——是"跑一遍全网数据，告诉我用户是谁"。

### L3 Agent 增强：自动假设生成 + 多假设并行

人的 L3 是"选一个核心任务"。Agent 可以**同时跑 3-5 个核心任务假设**，每个交由不同的分析路径验证。

```
人：L3 选一个核心任务 → L4 推演一个任务地图
Agent：L3 生成 5 个核心任务 → Swarm 模式并行推演 5 个任务地图 → 自动交叉对比选出最优
```

### L4 Agent 增强：案例库自动匹配

人的 L4 依赖分析师的经验填 8 步表。Agent 可以**自动检索案例库中相似任务的 8 步地图**作为起点。

| 第 X 掌 | 用什么工具执行 |
|:---|:---|
| 用户说"我想做一个帮人管理财务的App" → Agent 检索案例库中所有财务/管理类案例 → 提取共性摩擦点 → 以此为基础推演 8 步 |

### L5 Agent 增强：微观体感 → 信号替代

微观体感是冰山六层中最"人"的部分——Agent 没有感官体验。替代方案：

| 人的微观体感 | Agent 的信号替代 |
|:---|:---|
| "用户拿出手机→解锁→打开App→等了3秒白屏→皱眉" | App 评论中"加载慢""白屏""卡顿"的频率和情绪强度 |
| "用户不好意思说自己在用便宜货" | 社交媒体中"性价比"一词后紧跟的掩饰性表述（"其实也挺好的""够用了"） |
| "产品的高级感由无数微观构成" | NPS 评分中"推荐理由"的情感词汇分析——用户提到"质感""细节"的频率 |

Agent 的"微观体感"不是感觉，是**非结构化数据的结构化信号提取**。

### L6 Agent 增强：自动交叉验证

人的 L6 提出假设后需要人工去验证。Agent 可以**自动执行 RAT 的预验证**：

| RAT | Agent 自动验证方法 |
|:---|:---|
| "用户确实有这个痛点且愿意付费" | 搜索竞品的付费用户评价，统计付费意愿词频 |
| "替代方案足够痛苦到愿意切换" | 搜索"怎么解决XX"类问题，统计"还是不行""又出问题了"的频率 |
| "我们的方案比替代方案好到承担切换成本" | 对比竞品的 NPS/评分趋势，判断用户满意度走向 |
