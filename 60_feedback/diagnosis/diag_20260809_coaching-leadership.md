## 三、核心框架提取（两课融合）

**课程-01（Truman）：领导力之"道"**
1. 领导力 = 带领他人**心甘情愿解决难题**的能力（L664）
2. 驱动三角：权力（保底）/ 管理（效率）/**领导力（上限）**，可代偿（L1596/L1618）
3. 领导力敏感性（觉察）是起点：黑盒评价模型 → 观察加/减币（L776/L786）
4. 硬币模型：加币 9 条 / 减币 9 条（PM 整理，L1078），情绪失控 = 高危减币
5. 五阶梯 L0-L5：认同（以身作则/安全氛围/2×5 耐心标准）→ 结果（扛事/稀缺优势）→ 共识（讲道理/提问/出口式咨询）→ 成长（基本功/1v1 反馈/BE FASTER）→ 希望（愿景/文化/社会价值/人生红点）
6. 一堂实践：老板不重要道理大于天（L946/L952）；马拉松案例（L1202）；希望表达库 20+ 条三维度（L3090）

**课程-02（莫非）：教练沟通之"术"**
1. 教练式领导力核心 = 激发对方内在动力（L450）；教练式沟通 = 领导力成长的核心场景（L494）
2. 核心修炼四层级：建立信任 → 达成共识 → 带来成长 → 激发希望（L1270，与五阶梯 L2-L5 呼应）
3. 武器库：倾听卡 6 步 / 提问卡 8 类 / 反馈卡 6 原则（BASIC/冰山/三明治）+ 专家自我修养 Top10 + 初心卡
4. 21 章工具卡（三环图等）+ 案例集（领导力命题作文）
5. 四层级对应 21 章工具卡结构（VLM 武器库完整迭代版）

## 五、9 层深挖（L1→L4→L9）

- **L1 业务公式**：团队产能 = 领导者协调成本 × 成员自驱率；领导力降低协调成本、提升自驱率
- **L2 假设审计**：假设"领导力 = 管理 = 权力"→ 口述证伪（三驱动可代偿但本质不同）；假设"领导力是天赋"→ 口述证伪（刻意练习可提升）
- **L3 边界**：领导力适用于"开放/难/长周期/易退缩"问题（L688）；纯运营 SOP 岗位不需要；教练式领导力重心在领导力不在教练技巧（L1456）
- **L4 失败模式**：情绪失控（高危减币，一次抵消数月积累）；用权威代替道理（口服心不服）；无限安全空间（2×5 给期限）；甩锅/拒绝认错/压制异议（减币清单）
- **L5 用户场景**：老朱带团队（KDO 工厂本身 = 领导力实践场：老顽童/黄药师/欧阳锋都是"心甘情愿解决难题"的成员；2×5 标准可直接用于老朱带人）
- **L6 成本收益**：14 张卡 ≈ 老顽童 2-3 天产能；收益 = 管理域补"上限"维度 + 教练方法可复用（老朱/团队/KDO agent 都受益）
- **L7 时序**：P0 卡组（10 张）→ P1 增量（4 张）→ MOC/补链 → 桥接卡与 Feature 域互链
- **L8 验证方案**：案例卡含真实过程（起点→尝试→转折→结果）；tool 卡可照做（武器库话术可直接引用）；BE FASTER/2×5 可立即在 KDO 试用
- **L9 决策框架**：
  - go/no-go：**go**（一等证据 + 高复用性 + 用户明确要求）
  - 最大风险点：VLM 武器库部分文字待核对（[?] 标注）——tool 卡生产时以口述稿为准核对
  - 最小验证路径：P0 先产 framework×3 + 武器库 tool×3，欧阳锋终审后老朱试用于带团队场景
