本域为**商业经营底层逻辑**新域：围绕赫尔曼·西蒙《True Profit!: No Company Ever Went Broke from Turning a Profit》（中译本《真正的利润》，机械工业出版社 2024）展开，核心命题是**"利润优先"**——利润不是年底剩下的钱，而是产品定价时就必须设计的生存成本。

**诊断结论**：

## 三、9 层深挖

### L1 业务公式

```text
利润 = （价格 × 销量） - （可变成本 × 销量 + 固定成本）
```

核心洞察：**价格是唯一无需预先投资即可撬动利润的杠杆**。价格提高 5% 对利润的影响，通常远大于销量提高 5%——因为多卖的每一件都带着可变成本。

### L2 目标用户与场景

- **主要用户**：年营收 200 万-10 亿的中小企业创始人、产品经理、销售负责人
- **核心场景**：
  1. 产品上市前定价决策
  2. 竞争压力下的涨价/降价决策
  3. 大客户压价时的取舍
  4. 年度经营计划中的利润目标设定

### L3 边界与假设

- **适用边界**：有真实产品/服务、可市场化定价的企业；不适用纯公益、行政定价、垄断管制行业
- **关键假设**：
  - 客户存在差异化支付意愿
  - 企业有能力控制成本或提升价值
  - 市场信息不完全对称（价格可作为质量信号）

### L4 失败模式

| ID | 失败模式 | 案例 | 后果 |
|---|---|---|---|
| F1 | 把利润当"剩下的钱" | 多数初创企业年底算账才发现亏损 | 慢性破产 |
| F2 | 用降价换份额 | 通用汽车 2002 年追求 29% 份额，半年市值跌 40% | 利润崩溃 |
| F3 | 成本加成定价 | 约 80% 企业使用，忽视客户价值 | 利润漏损 |
| F4 | 忽视应收账款 | To B 企业把"应收"当收入 | 现金流断裂 |
| F5 | 规模幻觉 | 独角兽营收增长但亏损扩大 | 坍塌时规模无价值 |

### L5 系统约束

- **组织约束**：员工薪酬与营收挂钩，天然不关注利润；利润是一号位工程
- **心理约束**：创始人对高利润的"耻感"
- **市场约束**：信息不对称导致客户高估企业利润率，价格敏感
- **财务约束**：现金流≠利润；账上"雷打不动可自由支配"的钱才是利润

### L6 关键变量

| 变量 | 影响方向 | 可干预性 |
|---|---|---|
| 价格 | 利润杠杆最高 | 高 |
| 销量 | 受市场与竞争影响 | 中 |
| 可变成本 | 直接影响单位利润 | 中 |
| 固定成本 | 规模效应关键 | 中 |
| 客户结构 | 大客户往往压价 | 高 |
| 产品价值定位 | 决定定价空间 | 高 |

### L7 行动杠杆

1. **定价前置**：产品设计阶段就确定目标利润
2. **价值定价**：按客户感知价值定价，而非成本加成
3. **客户筛选**：砍掉无利润大客户，聚焦高价值客户
4. **折扣管理**：实物折扣 > 价格折扣；反折扣激励销售
5. **成本审视**：区分"该花的成本"与"沉默的浪费"

### L8 度量指标

- 净利润率
- 单位经济模型（单客/单件利润）
- 应收账款周转天数
- 价格实现率（实际成交价/目标价）
- 客户利润率分层

### L9 决策框架（go/no-go）

```text
是否启动利润优先改革？
  ├─ 当前净利润率是否低于行业均值？ → 是 → 高优先级
  ├─ 是否存在无利润大客户/产品线？ → 是 → 立即审计
  ├─ 定价流程是否由销售/产品/财务共创？ → 否 → 建立定价委员会
  ├─ 是否有 6-12 个月利润储备应对风险？ → 否 → 优先止血
  └─ 最小验证路径：选 1 个产品线做价值定价试点
```

**go/no-go**：本素材**值得入库**。它是一个独立商业域（利润/定价），与现有 KDO 方法论（单元模型、需求冰山、刻意练习）可形成桥接，素材本身的权威性与可操作性都足够。

- 与 `framework-kdo-self-attack` 桥接：利润决策前必须跑自攻击

## 五、错误模式与边界条件

### 5.1 素材中需警惕的简化

| 问题 | 说明 | 处理建议 |
|---|---|---|
| 大客户必然压价？ | 素材中"砍掉最大客户"案例是特定情境，非通用规则 | 案例卡需标注"情境：该客户占销售额 10%、压价、服务要求高、无利可图" |
| 高利润 = 有良心？ | 素材有较强价值主张，但存在幸存者偏差 | framework 的 critique 节需引入反方：高利润也可能来自垄断、欺骗或剥削 |
| 所有企业都应利润优先？ | 平台型/垄断预期型企业（亚马逊、京东）可阶段性亏损 | 明确边界条件：有垄断预期或资本持续供血除外 |

### 5.2 数据口径 flag

- **Bosch 价格杠杆**：素材称"提价 1% → 利润增长 34.2%"，但 Simon-Kucher 公开数据显示的是"2% 价格提升 → Bosch 利润增加 34%"。卡片化时必须引用原始研究并说明口径。
- **全球企业平均利润率**：素材中部分数据来自 2019 及更早，需标注年份，避免当作当前数据使用。
