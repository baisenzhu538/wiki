## L1：业务公式 / 单元模型

### 1.1 渠道增长核心公式

```
可持续增长 = Σ(有效渠道_i × 单渠道单元模型_i × 渠道生命周期_i)

单渠道单元模型 = 流量 × 转化率 × 客单价 × 复购率 - 获客成本

增长飞轮效应 = 要素 A ↑ → 要素 B ↑ → ... → 要素 A 进一步 ↑
```

## L3：理论 / 框架 / 边界

### 3.1 三大核心框架

| 框架 | 核心内容 | 类型 |
|:---|:---|:---:|
| **增长飞轮** | 列要素 → 找因果 → 测闭环 → 狂拉动；小飞轮 vs 大飞轮 | framework |
| **渠道工业化生产** | 定义（高不确定 + 持续 + 高质量）；定目标 → 建节点 → 做加法 → 做减法 → 迭代 | framework |
| **渠道探索四步法** | 扫描 → 预判 → 测试 → 建模 | framework |

### 3.2 关键工具/概念

| 工具/概念 | 说明 |
|:---|:---|
| 渠道特性五维度 | 大小、集中度、成本、快慢、持续性 |
| 客户介绍渠道三要素 | 动力（名/利/情）、触点、阻力 |
| 渠道扫描小抄 | 线上获客 / 线下获客 / 获客转化 / 推荐获客 |
| 节点类型 | 门槛节点、检查节点、评审节点、动手节点 |
| 加减法策略 | 加法建选项池，减法用模型/评审/测试筛选 |
| 三环能力聚焦 | 来自刻意练习域，可与增长域交叉 |

### 3.3 适用边界

- ✅ 产品已初步验证，需要规模化获客
- ✅ 需要持续交付的不确定工作
- ✅ 有多个渠道可选，需要科学决策
- ❌ 产品价值未验证前的大规模投放（应先用精益创业）
- ❌ 完全一次性、不需要持续交付的项目
- ❌ 标准化程度极高的流水线工作（用 SOP 即可）

## L4：失败模式库

### 4.1 渠道探索常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 依赖手感碰运气 | 什么火做什么，渠道换来换去 | 用四步法系统扫描 |
| 跳过扫描预判直接测试 | 资源浪费在低效渠道 | 先建 20-50 渠道清单 |
| 单渠道依赖 | 一旦政策变化业务崩塌 | 布局 3-5 个不同类型渠道 |
| 混淆「事不行」和「人不行」 | 过早放弃有潜力的渠道 | 看同行成功率、自身能力拉满度 |
| 忽视渠道生命周期 | 渠道自然下滑后无准备 | 持续建模 + 工业化生产 |
| 把 SOP 当工业化 | 用确定性流程处理不确定工作 | 建立节点 + 加减法机制 |
| 追求天花板忽视确定性 | 早期选大盘但难验证的渠道 | 早期优先确定性高、起盘快 |

### 4.2 增长飞轮常见失败模式

| 失败模式 | 症状 | 修复 |
|:---|:---|:---|
| 强行画圈 | 把线性链条弯成圆，无增强回路 | 验证每个环节的因果强度 |
| 要素过多 | 8-10 个要素，关系复杂易断 | 控制在 4-6 个 |
| 忽视启动点 | 从非稀缺环节开始推 | 找到供需关系中最稀缺环节 |
| 飞轮与业务脱节 | 飞轮漂亮但不指导资源分配 | 每个要素对应具体业务动作 |

## L5：隐性成本与替代方案

### 5.1 隐性成本

| 成本项 | 显性成本 | 隐性成本 |
|:---|:---|:---|
| 渠道扫描 | 时间 | 认知负担、容易遗漏 |
| 渠道测试 | 投放费用/人力 | 机会成本、团队挫败感 |
| 工业化生产 | 流程设计 | 初期效率下降、组织阻力 |
| 飞轮维护 | 持续投入 | 路径依赖、忽视新变量 |
| 多渠道布局 | 资源分散 | 每个渠道都不够深 |

### 5.2 替代方案

| 方案 | 适用场景 | 风险 |
|:---|:---|:---|
| 纯增长黑客 | 互联网产品、数据驱动 | 忽视长期壁垒 |
| 重金买量 | 资金充裕、验证期后 | 不可持续、依赖平台 |
| 创始人销售 | To B 早期 | 难以复制 |
| 品牌驱动 | 长期主义、高客单价 | 见效慢 |

## L7：市场情绪 / 销售话术 / 骗局

### 7.1 需警惕的话术

| 话术 | 风险 | 验证 |
|:---|:---|:---|
| 「找到一条渠道就能活」 | 忽视多渠道布局 | 单一渠道风险高 |
| 「工业化就是 SOP」 | 混淆确定性与不确定性工作 | 看是否满足三条件 |
| 「增长飞轮就是画圈」 | 忽视因果验证 | 必须有增强回路 |
| 「照抄亚马逊飞轮」 | 忽视自身业务特性 | 需重新推导因果 |
| 「24 个行业清单直接抄」 | 忽视行业差异 | 需结合自身产品适配 |

### 7.2 行业真实趋势

- 流量成本持续上升，获客效率成为核心竞争力；
- AI 正在改变渠道探索方式（AI 调研、AI 生成素材、AI 线索筛选）；
- 从「单点爆款」转向「可持续工业化获客」成为主流。

## L8：边界案例与反例

### 8.1 支持案例

- **亚马逊飞轮**：用户体验 → 流量 → 卖家 → 选品 → 规模经济 → 更低价格 → 更好体验
- **小说 app 飞轮**：流量 → 下载 → 用户 → 创作者 → 内容 → SEO 流量
- **一堂做课工业化**：10 环节流程使 NPS 稳定在 80+
- **固体红牛**：加油站渠道 → 司机群体 → 网吧/台球厅复制
- **马毅云电脑**：60+ 渠道扫描 → 矩阵模型 → 年营收 3.7 亿

### 8.2 反例 / 边界

- **过度工业化扼杀创新**：若流程过于 rigid，可能错过非结构化机会；
- **飞轮失效**：当外部环境变化（如平台政策、技术变革）时，原有飞轮可能断裂；
- **小团队资源不足**：无法同时布局多渠道，需更聚焦。
