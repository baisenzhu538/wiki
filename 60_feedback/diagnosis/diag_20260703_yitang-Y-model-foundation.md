# 底层逻辑域诊断：Y模型、实事求是、解放思想

> 诊断范围：一堂「底层逻辑之一：Y模型」课程素材，含口述稿、学习笔记、段王爷整理的同学实操案例合集。

## 二、核心内容提炼

### 2.1 Y模型的四层结构

```
                    ┌─────────────────┐
                    │   无限进步      │
                    │ （持续迭代）    │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
        ┌─────┴─────┐   ┌────┴────┐   ┌────┴────┐
        │ 知行合一  │   │ 实事求是│   │ 解放思想│
        │  （姿势） │   │ （姿势） │   │ （姿势） │
        └─────┬─────┘   └────┬────┘   └────┬────┘
              │              │              │
        ┌─────┴─────┐   ┌────┴────┐   ┌────┴────┐
        │ 定性定量  │   │ 科学类比│   │ 假设驱动│   │ 提炼建模│
        │  （工具） │   │ （工具） │   │ （工具） │   │ （工具） │
        └─────┬─────┘   └────┬────┘   └────┬────┘   └────┬────┘
              │              │              │              │
              └──────────────┼──────────────┼──────────────┘
                             │
                    ┌────────┴────────┐
                    │  客观因果规律    │
                    │   （Y模型之根）  │
                    └─────────────────┘
```

### 2.2 两大进化路径

- **理论端**：借理论、做科学类比、提炼模型。
- **事实端**：定性定量、假设驱动、追求事实。

### 2.3 科学做事的五步法

1. **明确核心问题**：找到真正的「因」，而非表面症状。
2. **拆解变量/业务公式**：把大目标拆成可量化的子变量。
3. **理论端**：借理论、做科学类比、提炼模型。
4. **事实端**：定性定量、假设驱动、追求事实。
5. **知行迭代**：验证 → 复盘 → 调整 → 再验证。

### 2.4 三大姿势与三门课的对应

| 课程 | 对应姿势 | 核心解决 |
|:---|:---|:---|
| 科学理念 = Y模型 | 全部 | 相信并追求客观因果规律 |
| 实事求是 | 姿势之一 | 尊重客观事实，克服愿望思维和主观臆测 |
| 解放思想 | 姿势之一 | 跳出隐含假设，用底层规律指导上层创新 |

## 四、建议产出的 7 张卡

### Card 1: `yt-decision-y-model`

**类型**：framework  
**定位**：一堂最底层元框架，所有其他课程的解码器。

**必须包含的 section**：
1. 一句话：Y模型 = 以客观因果规律为根，通过理论+事实双路径，用三大姿势和四大工具，实现快速入门与无限进步的科学做事系统。
2. Y模型的四层结构图（根 → 双路径 → 三大姿势 → 四大工具）。
3. 科学做事五步法。
4. 与一堂其他课程的关系：五步法、基本功、转化率、业务公式、知识管理等如何被 Y模型解释。
5. 与《实践论》《矛盾论》、王阳明心学的哲学呼应。
6. 如何迁移到非商业领域（子女教育、个人成长、内容创作等）。
7. Critique：≥3 个外部反对者 + ≥2 个内部局限。
8. Related：≥5 条，含跨域。

### Card 4: `tool-yitang-Y-model-application`

**类型**：tool  
**定位**：把 Y模型变成任何具体问题上的操作工作流。

**必须包含的 section**：
1. When to Use：面对复杂问题、需要持续迭代、不知道从哪入手。
2. 五步法操作清单（每步 ≥3 个动作）。
3. 输入：问题描述、已知信息、目标、约束条件。
4. 输出：因果模型图、关键假设清单、验证计划、行动计划。
5. 配套工具：红卡（科学实践姿势）、蓝卡（避坑清单）。
6. 示例：用 Y模型分析「如何提高某产品转化率」。
7. Checklist ≥10 项。
8. Critique + Related。

### Card 5: `dk-yitang-Y-model-pitfalls`

**类型**：dark-knowledge  
**dark_knowledge_type**：pattern  
**定位**：科学做事过程中最常见的反模式。

**必须包含的 6 个反模式**：
1. 经验主义陷阱 — 依赖过往经验，拒绝建模。
2. 理论迷信陷阱 — 盲目套用理论，忽视边界。
3. 主观臆测陷阱 — 拍脑袋决策，忽视数据。
4. 错误类比陷阱 — 把类比当论证。
5. 愿望思维陷阱 — 把希望当事实。
6. 知行分裂陷阱 — 知道不做，做了不想。

**必须包含的 section**：
1. 6 个反模式（症状 + 反打 + 口诀）。
2. 预警信号 ≥6 条。
3. 修复动作：每个陷阱 1 个即时动作 + 1 个长期动作。
4. Critique + Related。

### Card 6: `case-yitang-Y-model-seven-applications`

**类型**：case  
**定位**：跨领域可迁移性的证据集，来自段王爷整理的七位同学作业。

**必须包含的 section**：
1. Background：Y模型火种·科学做事思考合集。
2. Problem：同一套框架能否迁移到完全不同的七个领域？
3. Decision：用 Y模型五步框架对七个案例做逐步骤对标。
4. Process：七位同学案例（子女教育、百度数字人、情绪梳理、职业晋升、CRM 活跃度、财经号涨粉、小说拆解）的 Y模型应用要点。
5. Result：七人合在一起恰好覆盖 Y模型全部环节；共同短板（数据闭环、反例验证、用户反馈）。
6. Lessons：Y模型是可迁移的科学思维方式；案例分析要补数据闭环和反例验证。
7. Failure Modes：只套框架不验证、只看成功不看失败、只做定性不做定量。
8. Synthesis + Related。

### Card 7: `case-yitang-Y-model-advertising-turnaround`

**类型**：case  
**定位**：一堂内部真实商业案例，展示 Y模型如何把一个亏损业务变成核心增长引擎。

**必须包含的 section**：
1. Background：2023 年一堂准备做抖音 AD 投放，早期外包和内部团队都失败。
2. Problem：ROI 0.3-0.6，每周亏一辆小米汽车；依赖外部、依赖爆款模仿、缺乏核心模型。
3. Decision：创始人亲自牵头，用 Y模型构建科学投放体系。
4. Process：
   - 明确目标：顾客规模 + ROI，追求风险可控的规模最大化
   - 拆解四大模型：单视频审美 / 工业化生产 / 测试机制 / 投放策略
   - 理论端：借鉴同行经验，建立 A本/B本 模型
   - 事实端：每周一轮 AB 测试、数据复盘、选题池筛选
   - 知行迭代：持续提出关键假设，绿色保留、红色证伪
5. Result：付费流量占一半，收入翻四倍，跑通抖音、视频号、小红书、百度。
6. Lessons：核心难题必须创始人牵头建模；每周咬碎牙复盘；小模型叠加成大模型。
7. Failure Modes：依赖外包、抄爆款、不建模、不复盘。
8. Synthesis + Related。

## 五、关键纠偏与边界

1. **科学理念 ≠ 另一张独立卡**：它就是 Y模型本身，不单独建 `concept-yitang-scientific-idea`。
2. **实事求是 / 解放思想 不是平行于 Y模型**：它们是从 Y模型生长出来的两层能力，必须在 framework 卡中明确这一演化关系。
3. **旧卡处理**：三张旧卡重写升级后，原文件保留但标记为 deprecated，正文指向新卡。
4. **案例卡不重复建设**：口述中的时间管理、起名字等例子作为嵌入式证据放进 framework/tool 卡，不单独建 case；只有投放转型和七人合集两个案例独立成卡。
5. **数字降级**：口述中「每周亏一辆小米汽车」「翻四倍」等描述为项目经验，不当作普适真理。
6. **OPC 改编**：每张 framework/tool 卡必须包含「OPC 智能体适配」小节，说明可映射成哪种 Agent。
7. **哲学引用**：引用《实践论》《矛盾论》、王阳明心学时要明确「用于说明内在联系，不构成学术结论」。
