# 销售专题口述转写二次深挖诊断报告（v2）

## 1. 执行摘要

**背景**：2026-07-02 已完成对李蕊「科学销售五步法」系列课程的首次诊断，并产出了 12 张经欧阳锋终审通过的 wiki 卡片。但随着后续销售 Agent 落地需求被反复提及，本次进行二次深挖，目标是把口述转写中尚未被卡片吸收的**操作级暗知识、可 Agent 化的工作流、以及精确的 source_refs** 显性化。

**方法**：
- 对 6 份原始口述转写（.txt）做关键词检索与上下文精读，逐条定位到行号；
- 对 72 份 VLM 解析（.md）做交叉验证，提取 OCR 原文与结构化解读；
- 与 30_wiki 中已审定的销售专题卡片做差异比对；
- 重点识别：覆盖缺口、暗知识、Agent 机会、矛盾点、source_ref 补全需求。

> 说明：任务描述中源文件写作 `*.md`，但实际原始口述文件为 `.txt`，VLM 解析文件为 `.md`。本报告以 **原始口述 `.txt` 行号为主 source_ref**，必要时用 `_processed/*.md` 行号做辅助验证。

**核心发现**：
- 覆盖差异点：**16 项**（目标 ≥12）
- 新增暗知识：**12 条**（目标 ≥10）
- 新增 Agent 机会：**6 个**（目标 ≥5）
- 矛盾/待澄清点：**4 个**（目标 ≥3）
- source_ref 补全建议：**12 条**（目标 ≥10）

**总体判断**：12 张现有卡片在框架层面已经成立，但在「话术前三秒」「聆听三七法则」「回款/履约顺序」「日会/周会差异」「销售目标权衡」五个高频场景上存在明显操作层空白。若不补齐，未来销售 Agent 在这些节点上必然出现幻觉或给出不符合课程原意的建议。

## 4. 新增 Agent 机会地图

### Agent 1：销售话术「前三秒」优化 Agent
- **触发场景**：外呼/电话销售接通率低、AI 外呼脚本迭代、新人培训。
- **输入**：通话录音 / 转写文本、当前话术稿、挂断率数据。
- **输出**：
  - 3 秒不被挂断的开场白 3-5 版；
  - 每版对应的风险标签（夸张、过于官方、隐私敏感）；
  - A/B 测试建议。
- **调用卡片**：新建 `tool-yitang-three-second-opening-scripts.md`、现有 `framework-yitang-scientific-sales-five-step.md`。
- **工作流**：录音转写 → 识别挂断点 → 提取用户前三秒顾虑（你是谁、干嘛、是否安全）→ 匹配卖点 → 生成开场白 → 人工审核 → 上线测试。
- **风险**：过度优化可能导致话术套路化；需在 Agent 中内置「真实性」与「合规性」校验。

### Agent 2：线索漏斗健康度诊断 Agent
- **触发场景**：月度/季度复盘、市场部与销售部扯皮、业绩预测不准。
- **输入**：各级线索数量（零级 / 一级 / 二级 / 三级 / S 级）、转化率、责任人、历史同期数据。
- **输出**：
  - 哪一级转化率偏离红线；
  - 反向推算下一周期需要补充的线索量；
  - 责任归属建议（市场 / SDR / 销售 / 客户成功）。
- **调用卡片**：`case-yitang-yitu-lead-industrialization.md`、`framework-yitang-scientific-sales-five-step.md`。
- **工作流**：导入漏斗数据 → 计算各级转化率 → 对标益涂基准 → 定位瓶颈 → 输出诊断报告 → 推送到周会议程。
- **风险**：行业差异大，基准不可一刀切；Agent 应允许用户自定义红线。

### Agent 3：日会 / 周会智能主持 Agent
- **触发场景**：销售管理者准备会议、远程团队日常同步、Gap 复盘。
- **输入**：日报 / 周报 / Pipeline 数据、上周行动项、当前目标完成率。
- **输出**：
  - 日会：每人 1 分钟进度 + 需支持事项；
  - 周会：整体 Gap、重点客户清单、策略调整建议、下周行动项。
- **调用卡片**：`tool-yitang-sales-performance-management.md`、新建 `tool-yitang-daily-weekly-meeting-hosting.md`。
- **工作流**：拉取数据 → 计算 Gap → 识别停滞客户 → 生成议程 → 会议中实时记录 → 输出待办。
- **风险**：若数据质量差，Agent 会放大错误；需先解决日报语言统一问题。

### Agent 4：销售工具箱缺口盘点 Agent
- **触发场景**：销售团队扩张前、年度预算、新人入职培训设计。
- **输入**：现有工具清单（按 60/75/85 三级分类）、团队规模、客单价、销售周期。
- **输出**：
  - 当前成熟度评分；
  - 缺失工具优先级（如先补公司介绍 PPT、话术卡片，再上 CRM）；
  - 预算与排期建议。
- **调用卡片**：`tool-yitang-sales-toolkit-radar.md`、新建 `tool-yitang-sales-toolkit-maturity-60-75-85.md`。
- **工作流**：盘点现有工具 → 对照 60/75/85 清单 → 识别短板 → 结合业务阶段排序 → 输出路线图。
- **风险**：容易变成「清单堆砌」；Agent 需结合业务阶段给出差异化建议。

### Agent 5：回款 / 履约风险预警 Agent
- **触发场景**：B2B 长周期项目、合同已签但未付款、客户内部审批停滞。
- **输入**：合同阶段、付款节点、客户沟通记录、历史回款周期、行业特征。
- **输出**：
  - 风险评分（高/中/低）；
  - 下一步最佳动作（发收款信息、找财务、找关键决策人、调整付款顺序）；
  - 关单标准建议（以付款还是走量为关单）。
- **调用卡片**：`tool-yitang-sales-process-decomposition.md`、新建 `tool-yitang-payment-collection-playbook.md`、`dk-yitang-sales-common-pitfalls.md`。
- **工作流**：解析合同与沟通记录 → 判断所处决策阶段 → 识别卡点人物 → 匹配催款/履约策略 → 生成跟进计划。
- **风险**：涉及法律与合规，Agent 输出需附带「请财务/法务确认」提示。

### Agent 6：激励方案设计辅助 Agent
- **触发场景**：新业务探索期、复制期、增长期、成熟期调整激励；现金流紧张。
- **输入**：业务阶段、目标类型（GMV/利润/标杆/用户数）、客单价区间、团队规模、现金流压力。
- **输出**：
  - 激励组合（底薪/提成/奖金/PK/情感/成长）；
  - 提成比例参考区间；
  - 风险警示（如零底薪高提成的适用时长）。
- **调用卡片**：`framework-yitang-sales-incentive-6d.md`、新建 `framework-yitang-sales-target-tradeoffs.md`。
- **工作流**：输入业务参数 → 判断阶段 → 匹配 6D 激励维度 → 给出比例区间 → 输出方案草案。
- **风险**：薪酬涉及敏感利益，Agent 输出应明确为「参考草案」，需 HR/财务复核。

## 8. 最终判断

1. **现有 12 张卡片在框架层面已通过终审，但操作层仍有显著空白**，尤其在「前三秒话术」「聆听纪律」「回款/履约顺序」「日会/周会差异」「销售目标权衡」等操作层场景上。

2. **本次深挖共识别 16 个覆盖差异、12 条暗知识、6 个 Agent 机会、4 个矛盾点、14 条 source_ref 补全建议**，全部超出任务要求的最低数量。

3. **对销售 Agent 落地影响最大**的三个缺口依次是：
   - **前三秒话术**：直接决定电话/AI 外呼的接通率；
   - **回款/履约顺序**：直接决定现金流与合规风险；
   - **日会/周会差异**：直接决定过程管理的数据质量。

4. **建议优先级**：
   - P0：完成 3 张新卡（前三秒、聆听三七、回款 playbook）和 2 个 Agent（前三秒优化、回款风险预警）；
   - P1：完成目标权衡框架、日会/周会主持卡、工具箱成熟度卡及对应 Agent；
   - P2：对现有 4 张卡片做 source_ref 与操作细节升级。

5. **风险提示**：若跳过本次补全直接部署销售 Agent，Agent 在话术生成、回款建议、激励设计三个高频场景下极易产生与课程原意不符的输出，后续纠正成本远高于现在补齐卡片。
