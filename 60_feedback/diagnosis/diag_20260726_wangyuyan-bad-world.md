## 二、素材核心

七步逻辑推演链：

坏世界(人自利+资源稀缺) → 他者悖论(他人=利益源+冲突源) → 合作创造收益·分配必然冲突 → 规则产生·投票≠正确(公益悖论) → 权力需要正当性 → 制度有漏洞(系统内无法自修复) → 解法：创造好的长期博弈环境→天下体系·和而不同

8个可操作概念：坏世界假设 / 政治人(人不只算钱) / 他者悖论 / 公正≠公平≠平等 / 地位互换原则 / 正当性 / 制度面向未来(博弈环境) / 和而不同

## 五、一人公司实操映射

> 这是用户强调的核心场景：一人公司如何与他人合作、处理好关系。

| 哲学概念 | 一人公司直译 |
|:---|:---|
| **坏世界假设** | 别指望合伙人/外包/渠道会天然跟你一条心。接受自利是正常的——不叫"人品差" |
| **政治人** | 你没钱给市场价时，必须给对方别的：自主权、归属感、作品署名、学习机会。人不只算钱 |
| **他者悖论** | 外包出问题别第一反应是"换人"。对方既是问题来源（交付延迟），也是价值来源（你一个人做不了那些活）。解法是改造关系，不是消灭关系 |
| **地位互换** | 任何协议写完后，坐到对方椅子上问：如果我是他，我会觉得这协议在防我还是在保我？ |
| **正当性** | 你没有老板头衔、没有KPI权——你让对方"听你的"的理由是什么？先把这个理由说清楚，再谈具体协作 |
| **博弈环境** | 和自由职业者合作，不是签一份完美的单次合同，是设计一种让他愿意长期跟你干的游戏规则 |
| **和而不同** | 外包设计师、兼职技术、内容写手——不要把他们改造成"像你一样想问题"。容得下差异的规则比追求统一的标准更重要 |
