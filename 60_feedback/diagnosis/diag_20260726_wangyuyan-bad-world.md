## 二、核心结构（来自逐字稿 §1-4）

### 2.1 七层悖论链（逐字稿版——比口述版更精炼）

```
① 现实起点：自利+稀缺+差异+力量不平等 → 自我中心
② 他者悖论：他者限制我，又是利益/幸福/意义来源 → 不能消灭只能改造关系
③ 合作悖论：必须合作，但收益分配制造冲突 → 制度通过"分"配置利益与权力
④ 公议悖论：共同决定需公共表达，但被接受的意见未必正确 → 公正优先于投票
⑤ 权力悖论：合作需权力执行规则，但权力也能破坏合作 → 制度化
⑥ 制度悖论：制度限制坏行为，但行为者会学习利用侵蚀制度 → 博弈环境+普遍模仿
⑦ 边界悖论→世界悖论：边界保护也制造排斥 → 天下体系·和而不同
```

### 2.2 三个最有操作性的关键词（逐字稿 §3）

- **坏世界**（L137-140）：不是"人人邪恶"，是自利+稀缺两条件同时成立=冲突必然。必须经过他者才能获得利益。
- **政治人**（L151-156）：不只算钱，还算权力/荣誉/尊严/归属/精神控制。文化冲突不能只靠物质补偿。
- **政治作为第一哲学**（L144-148）：政治不是公共事务管理，是"决定哪些生活能够存在"的命运结构。

## 四、§5 对一堂同学的借鉴——直接可用的实操

这是逐字稿独有的高价值内容（口述版完全没有）：

| 节 | 核心主张 | 一人公司直译 |
|:--|:---|:---|
| 5.1 规则既要正当也要可信 | 正当=分配理由；可信=是否稳定执行 | 合作协议写得再漂亮没用——看你是不是每次都按协议付款 |
| 5.2 不要把表决当成充分讨论 | 投票结束分歧≠判断方案真伪 | 小团队决策：先让所有人说清楚，再拍板。别拿"我们投票了"当免思考盾牌 |
| 5.3 激励的目标是让好行为成为优势策略 | 口头赞美合作，实际奖励抢功→被模仿的是抢功 | 你的分钱规则真的在奖励你嘴上说的那个行为吗？ |
| 5.4 组织文化需要"和"不是"同" | 所有人说一样的话→失去识别错误的能力 | 外包/自由职业者——不要改造成和你想法一样的人 |
| 5.5 权力的价值是形成合作 | 团队安静≠没异议，可能是异议退出了公共领域 | 你的权威不应该来自"你说了算"——来自"跟你合作确实更划算" |
| 5.6 应用边界 | **不能把"天下"直接类比成集团管控** | 这些哲学工具用于规则设计+关系判断，不是控制手段 |
