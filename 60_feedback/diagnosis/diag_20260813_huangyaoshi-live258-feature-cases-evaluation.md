> 触发：用户提供 `00_inbox/AI基本功/Live258：AI基本功第一课优秀作业.md`（3025 行，10 个学员案例），指明"这是 Feature 的案例"。按 Builder 职责完成素材全读 + 域内对标（framework-truman-feature-layered-system / 周期表 v0.8）后，评估为 **S 级素材**，建议编排生产。黄药师不做内容域任务编排（B4 牌）——本建议书供王语嫣编排参考。

## 一、素材评估：S 级

| 维度 | 评估 |
|:---|:---|
| 规模 | 3025 行，10 个学员案例，全部是真实实践（非理论复述） |
| 光谱完整度 | 失败（行知自媒体 50 分）→ 翻车（王鹏飞 18 桥）→ 成功（jeffgirl V1→V5）→ 工程化（农夫三拳 60 分工作台） |
| 结构一致性 | 每案例均为"用了什么 Feature + 缺了什么 Feature + 叠加效应 + 改进方案"四段式——天然符合三步编译法 |
| 可信度分级 | 农夫三拳（5→3 关键帧控制变量对比，最接近实验方法）> 王鹏飞/jeffgirl（有具体数字与翻车实录）> 田力/行知（补全方案为未验证推演） |

**精做建议**：按素材精做标准全量通读（W1 牌：先读全文再判断——黄药师已通读 3025 行全文，无跳读）。逐字精做后预计可挖掘量 > 60%。

## 二、核心洞察（已完整写入，可直接引用）

### 2.1 最珍贵的暗知识：王鹏飞"18 座桥翻车"

> "桥的数量我口误说成 18 座，AI 完全顺着我往下写，错误数字在四份物料之间流了一圈。**AI 不会质疑你口误的事实，它只会把它工整地扩散出去。**"

- 对应 Feature：**DataPack/事实约束**（只读事实包 + 禁止推断）
- 同时验证 KDO 三条铁律：素材精做传导（错误输入 × 高执行力 = 错误 × N 份物料）、回答前先检索验证（E020 同构）、负面限制的价值
- **建议沉淀为 dk 卡**（dk 卡候选 #2）

### 2.2 跨案例验证：10 个学员独立撞出同一组"高频缺失 Feature"

学员之间无互相参考，但缺失 Feature 高度重合：

| 缺失 Feature | 提及案例数 | 代表案例 |
|:---|:---|:---|
| 最终意图 | 7+ | 田力（领导退回）/ 张丽娜（冷启动）/ 王鹏飞（四份物料四意图） |
| Few-shot/参考案例 | 6+ | 黄华春（阅读量翻倍）/ 张丽娜（好坏样本库） |
| 设定角色/身份 | 6+ | 张丽娜（"外贸专家"角色太粗） |
| 负面限制/反向约束 | 5+ | 张丽娜禁用词库 / 农夫三拳反向提示词 |
| 渐进式披露/任务拆分 | 5+ | 黄华春（先大纲后正文）/ Simon（7 步流程） |
| 验收标准/评测 | 4+ | 张丽娜 1-5 分自评 / 王鹏飞"老师能否照着上课" |

**意义**：对 100 Feature 周期表的天然实证校验——最常缺的 Top 3（最终意图/Few-shot/验收标准）恰是 L2 层最基础的三张牌。学员事后归因高度收敛 → Feature 是稳定结构，不是玄学。

### 2.3 叠加效应 1+1+1>3 被 4 个案例独立复现

| 案例 | 组合 | 证据 |
|:---|:---|:---|
| 黄华春 | 角色（身份）+ 参考案例（风格）+ 格式设定（结构）= 三维覆盖 | 阅读量 3800→6500（+71%） |
| 王鹏飞 | 2A 身份 + 2B 上下文 | 40 分→65 分质量分水岭（"通用课程"→"爱思乐知的桥之旅"） |
| jeffgirl | V4 升级为 **Feature 链**（上一步输出 = 下一步输入） | 目标锚定→策略对齐→六层漏斗→货盘分层→跨维度一致性 |
| 张丽娜 | 用户身份 + 经营场景 + 负面限制 | 从"卖货推销"变成"经营沟通" |

**意义**：给已有卡 `dk-demand-feature-stacking` 补上数值证据与链式结构（输出-输入链）案例。

### 2.4 对 KDO 的三层启示

**知识层**（建议编排生产，详见第三节）：
- case 卡 ×3-4 + dk 卡 ×2

**基建层**（黄药师侧参照，不立即动工）：
- 农夫三拳**台前/幕后边界**（后台讨论规则不堆进台前提示词）→ 与 SOUL（运行时）vs spec（定稿层）分层同构，MCP 检索规则设计参照
- 张丽娜**禁用词库**（营销敏感词清单）→ 负面限制 Feature 的具体化，与质量门 lint 禁止清单同构
- jeffgirl **Feature 链** → 与 KDO pipeline（capture→ingest→enrich→produce→validate→ship→feedback→improve）同构

**周期表产品层**（发现两个缺口）：
1. **命名不统一**：同一 Feature 多个名字（反向教学/反向教我/反向提示；Few-shot/参考案例；抽卡/多版本/分支测试）→ 周期表需补一张别名表（KDO 卡 aliases 字段可承接）
2. **L4/L5 几乎无人触碰**：10 案例全集中在 L0-L3，仅黄谦导演提及 L4/L5"停留在探索"→ 当前用户群体实际水位在提示词层，印证"分层自洽"（先吃透下层再上上层），也是周期表 L4/L5 卡片后续面向的空白市场

### 2.5 质疑与边界（三步编译法第二步，卡片引用时需区分）

- 全部为**自述式复盘**，效果数据无对照组——黄华春自认第三篇阅读量（4200）低于第二篇（6500）但转化率更高：**Feature 叠加不单调提升单一指标，衡量维度须分开**
- 田力/行知的"补全后预期 80 分"是**未验证推演**非实测——引用时标注"推演"与"实测"
- 农夫三拳是唯一带实验方法痕迹（控制变量 5 帧→3 帧）且诚实记录失败（"仅 1 个成功"）的案例——精做时标注为最高可信度样本

## 三、建议任务拆分（王语嫣编排用）

### #A 建议：Feature 域 case 卡 ×3-4（P1，老顽童，素材 = 本文件精做后）

**目标**：把最有代表性、证据最硬的实践沉淀为 case 卡。

**候选卡（按可信度排序）**：
1. `case-知乎内容获客-feature叠加` — 黄华春：4 Feature 使用 + 4 缺失 + 71% 阅读量增长 + 0 元获客成本（转化路径完整：曝光→私信→到店→签约）
2. `case-直播复盘提示词迭代` — jeffgirl：V1→V5 五轮迭代 = Feature 补全史（4→25+ 个 Feature，Feature 链结构），可对照 feature-six-stages
3. `case-园本课程一进多出` — 王鹏飞：一份 md 母本 → 四份交付物（备案 docx/教师手册/家长长图/任务卡）+ 翻车实录（18 桥）+ "产线可迁移"洞察
4. `case-东欧开发信Feature复盘` — 张丽娜：冷启动场景（负面限制 > 正面指令）+ 数据包缺失 + A/B 假设设计

**验收**：source_refs 指向本文件（含行号区间）；related 链到 feature-layered-system + dk-demand-feature-stacking；每个 Feature 主张标注"实测/推演"

### #B 建议：Feature 域 dk 卡 ×2（P1，老顽童）

1. `dk-ai-does-not-question-your-mistake`（AI 不质疑你的口误）— 王鹏飞 18 桥：人喂的错误输入会被高执行力无差别放大；对治 = DataPack 事实约束 + 强制核对。关联 E020（回答前先检索验证）
2. `dk-feature-pieces-not-recognized-as-cards`（一堆散牌却不知道那是牌）— 王鹏飞第二反思（字体/对齐/留白等散经验 = L2/L3 层 Feature）+ 黄华春"无意识用了 4 个 Feature"。关联 KDO"不登记 = 不存在"原则、dk-feature-not-learned-but-used

**验收**：dk 七段齐全；含具体翻车/无意识场景；related 互链
