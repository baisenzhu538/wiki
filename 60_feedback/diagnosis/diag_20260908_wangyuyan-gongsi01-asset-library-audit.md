## 风险清单（按严重度）

1. **【高·安全】`Desktop\recon_tools\get_database.bat` 硬编码 MySQL root 明文密码**（已抽验实锤），同目录还有全盘扫 web.config 提连接串的脚本。与素材库无关但属凭据裸露——建议删除或改写（动作小，风险敞口大）。
2. **【高·单点】全套资产只存在 gongsi-01 一台机器**：tags 库 9 个备份 + catalog 备份全在本机同一目录，且 Disk0 一块物理盘承载 D-J 七个盘符（有过供电掉线史）。一块盘挂=数据+索引全悬。**建议：sqlite 双库+备份拷一份到异机（jia-01 或 NAS），半小时的事**。
3. **【中】词表兜底值偏高**：scene_type 23.5%「散图」、action 21.4%「其他」、location 88.9%「未知」——能查的部分很准，但约四分之一素材语义接近没有。追加打标预算前先认清这个天花板。
4. **【中】MCP 双实例僵尸进程**（两个 python 同跑 design_assets_server.py，只有一个绑上端口）——重启策略起了重复实例，建议清理+加单实例守卫。
5. **【中·文档债】00 号入口文档过时**（8 轴→10 轴、audience 标未落库实际已落）——它是所有 agent 的必读第一份，误导后来人。
6. 【低】action 轴营销线覆盖率 0.2%（4/2338），跨线组合检索对营销物料仍不可用。
7. 【低】catalog 停在 09-01，六天未增量更新。
8. 【低】F 盘 yinyin 451GB 版权归属未决（P0.5 清理时已跳过 152 个/36.7GB）。
