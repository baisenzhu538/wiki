## 二、全网调研

### 核心主张外部验证

| 素材主张 | 外部验证结果 | 来源 |
|:---|:---|:---|
| 项目管理是公司最小管理单元 | ✅ 已确认 | PMBOK定义一致：Project is temporary endeavor |
| ABCD复杂度分类（单人→公司级） | 🆕 原创简化 | PMBOK按行业/规模分类，无直接对应ABCD简化版 |
| 四基本功：定方案/拆计划/管执行/做复盘 | ⚠️ 与PMBOK五过程组有交叉但不同 | PMBOK五过程组：启动/规划/执行/监控/收尾。一堂四步合并了启动+规划为"定方案"，监控+收尾为"管执行+复盘" |
| 方案评估三角形（ROI/风险/资源） | ✅ 与经典项目评估三角一致 | PMI铁三角：范围/时间/成本。一堂增加"ROI"维度 |
| RASCI角色分工模型 | ✅ 已确认 | 源自RACI矩阵（PMBOK标准工具），一堂增加S(Support) |
| 深度复盘四步法 | 🆕 原创 | PMBOK Lessons Learned偏文档化，一堂复盘侧重"还原过程→差距分析→根因→提炼" |
| 敏感度模型（六维） | 🆕 原创方法论 | 未找到外部对标，属于一堂自研工具 |

### 外部框架对标

- 素材方法论「ABCD复杂度」↔ PMBOK项目分类：一堂版更简化，砍掉了不适合初创公司的复杂流程
- 素材方法论「方案评估三角形」↔ PMI铁三角+Scrum评估：一堂版增加ROI财务维度
- 素材方法论「深度复盘」↔ PMBOK Lessons Learned + AAR(After Action Review)：一堂版强调"还原过程"而非"记录结论"
- 素材方法论「武器库V1.8」↔ 无外部对标 → 🔑 原创，重点关注
