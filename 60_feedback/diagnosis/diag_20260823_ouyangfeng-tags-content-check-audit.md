# 标签批次验收内容抽查升级（#426 实证，2026-08-23）

## 问题实证（欧阳锋正文抽查，2026-08-23）

#426 两批已治理卡（决策域 44 + ai-collaboration 35）抽查 **4 张读正文 vs tags 比对**：

| 卡 | tags | 正文核心 | 判定 |
|:--|:--|:--|:--|
| concept-ai-neutrality-bias | 边界/反例/伦理 | 技术中立论=责任转嫁 | ✅ 高匹配（伦理新词已回填） |
| yt-decision-width-method | 科学决策/工具/清单 | 列推建查+三层盲区清单 | ✅ 高匹配 |
| case-design-principles-90 | 工具/方法/实证 | 爆炸式调研饱和建模样本 | 🟡 中（"工具"泛，可更精准） |
| **dk-research-decision-first-mapping** | **沉没成本（仅 1 词）** | 研究动作→决策→标准对齐 | 🔴 **过窄且偏题**——沉没成本只是失败模式之一，主题词（研究前置对齐/决策标准）缺失 |

**结论**：4 张抽 1 张错配（25%）——此前批次验收的机械验证（格式/归零/结构词）全过，但**读正文才暴露"tags 与卡内容一致"未达标**——机械验证证明不了内容对（tags 可能是"按标题套轴词"而非"从正文提炼"）。

## 根因

批次验收抽查方式不足：只看 tags 块结构 + 标题/ID 推断内容匹配——**未读正文**（任务书验收项"tags 与卡内容一致"执行打折）。我侧已认领（审查深度缺口），但**验收标准本身需要机制化**（单靠审查者自觉不够）。

## 建议（王语嫣裁定）

### 1. #426 后续批次验收标准升级（写入任务书/批次验收要求）

- **抽查必须读正文**：每批抽查 ≥3 张，必须读正文（定位段/主题词节）与 tags 比对——标题推断不算验证
- **机械辅助**：卡内高频词 vs tags 内容词重叠比对（提取正文 top 词与 tags 交集，覆盖率 <50% = 疑似错配标记复查）——黄药师可加进 tags-audit.py（#474 工具扩展）
- **验收记录声明抽查范围**：批次验收记录写明"抽查 N 张读正文 + 其余机械验证"

### 2. 存量已治理批复查（决策域 44 + ai-collaboration 35）

- 抽样外推 25% 错配率提示需复查：建议按域抽查 10-15% 卡读正文复查（机械辅助优先筛可疑卡）
- 复查发现的错配卡：补词/换词走 #426 后续批次或独立小修（老顽童执行，我不改卡）

### 3. 具体补词

- `dk-research-decision-first-mapping`：补主题词（研究前置对齐/决策标准类——可入轴或保守词），"沉没成本"保留为辅助词
