# 三、审计发现（按重要性）

## F1（结构性）胶囊事件层太薄，只有「复盘登记簿」

- `activity_log.db` 16 条全部 `review_saved`；无 queue_transition / decision / friction / error 事件。
- 影响：靠「提取记忆胶囊」只能还原「谁落了复盘」，不能还原「谁领单/提审/拍板/踩坑」。真正的全量上下文在 L1-full 原文，但事件索引缺工作流语义。
- 建议：立项给黄药师（P2）——事件层补 4 类关键事件：queue_transition、decision、friction、error。

## F2（系统性认知模式）「基于旧快照行动、行动前不复核最新态」三角色同日复现

- 黄药师 #491：任务书执行中收紧未重读，首轮交付旧范围（补做后闭环）。
- 王语嫣 E050/E052：扫 pattern 不全 + 共享文件 commit 竞态（反向变体 ×3）。
- 欧阳锋：被点破 7 次「只记 TODO 不写建议书」——把「记录」当「处理」。
- 共同根因：可变状态（任务书/队列/共享文件）被当静态，行动前不复核。
- 建议（P1，王语嫣/老朱拍板）：提炼为通用铁律入 charter 通用条款或 spec G 系列——「涉及共享/可变状态，行动前先复核最新态」。
