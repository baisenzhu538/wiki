# KDO 记忆胶囊四层架构建议

> 学习输入：老朱 08-22 提供的外部实践《建设者工作成果_记忆胶囊与方法论与基建_2026-08-21.md》（巨米归档库四角色治理链）。
> 本建议书把该实践的四层记忆模型映射到 KDO，并对齐已拍板的 B3-1 / B3-2。
> 定位：观察者记忆维护职责的架构建议（不产卡、不写脚本；脚本实现归黄药师）。

## 0. 一句话结论

KDO 记忆现状是 **L3 最强、L0 最缺、L1 有瑕、L2 刚起步**。王语嫣 08-22 重启失忆、过程层找不回，就是 **L0 全量留痕缺失**的实锤——锚点只能恢复摘要，恢复不了全量上下文。修复方向 = 按巨米四层模型把 L0 补上、L1 定上界、L2 机制化、L3 保持，并把消费端做成每次会话自动注入的「胶囊精华段」。

## 1. 学习输入：巨米四层记忆模型（L0-L3）

| 层 | 定义 | 巨米实现 |
|:--|:--|:--|
| L0 原始事件流 | 全量留痕，不删，审计用 | `activity_log.db`（已有） |
| L1 胶囊摘要 | 事件类型加权：高价值全保留、低价值仅计数，输出设**确定上界** | `memory_capsule.py`（#185 落地） |
| L2 洞察提炼 | 自动提炼周期模式/教训/delta，带溯源锚点 | 待建（缓议） |
| L3 方法论沉淀 | 洞察转正 → 案例/亲测律（审查链 + 用户拍板） | 已有 |

**核心洞察（案例 94）**：全量搬运 ≠ 记忆；记忆 = 分层 + 精选 + 洞察 + 消费闭环；资产生而不用 = 僵尸资产。

**两个关键工程细节（直接可抄）**：
- L1 加权细则：narrative/decision/review_rejected 全保留；review_passed/task_completed 截断 Top 20；backlog/suspended **仅计数不列明细**。实测 179 事件 → 30 行 + 计数段。
- 消费端上界：`session_boot ⑥ 记忆胶囊精华段` **≤1KB**（叙事+决策各最近 3 条 + 本周期计数），每次会话自动注入——重启恢复从三件套升级为四件套。

## 2. 纠偏：为什么「快照」不够——王语嫣失忆事件解剖

上一轮我给王语嫣的恢复路径（失忆锚点 §4 + LATEST_SESSION + 08-21 复盘）**全是 L1/L3 摘要层**。老朱纠正得对：**上下文不是快照，而是全量**。

失忆后事实是：锚点 §4 恢复了「结论」（会诊 30 条已拍板），但「过程」（今天怎么一步步拍的）**没有 L0 全量兜底，所以永远找不回**。这暴露 KDO 记忆体系的断层——只有上层摘要，没有底层全量，摘要断了就真断了。

## 3. KDO 现状四层对照

| 层 | 巨米 | KDO 现状 | 判定 |
|:--|:--|:--|:--|
| L0 全量事件流 | activity_log.db | **无**（无会话事件流留痕） | ❌ 缺失（王语嫣失忆实锤） |
| L1 胶囊摘要 | 加权+上界 | daily-context 复盘（有 append 拼贴病）+ 失忆锚点（人工更新，停在 08-21） | ⚠️ 有瑕：无上界、无加权、靠人工 |
| L2 洞察提炼 | 自动周期洞察 | 风清扬审计报告（手动，周度机制刚提） | 🟡 起步 |
| L3 方法论沉淀 | 案例/亲测律 | 错误模式库 E001-E041 + 铁律 + PROTOCOL | ✅ 成熟（最强一层） |

## 4. KDO L0-L3 落地映射（对齐已拍板 B3-1/B3-2）

| 层 | KDO 落地 | 拍板条款 | 归属 |
|:--|:--|:--|:--|
| L0 | SQLite 快照（30min 频次，git 外 + 备份/恢复路径同步定义） | B3-1 | 黄药师技术方案 |
| L1 | 7d 转摘要 / 30d 归档 / 锚点由摘要自动生成 + 消费端 ≤1KB 胶囊精华段 + 治 append 拼贴（M1 同日 merge） | B3-2 + M1/M2 | 黄药师脚本 |
| L2 | 观察者定期洞察报告（周度审计四件套：五步门禁+五维雷达+四态+根因） | B3-2 老朱补充② | 风清扬 |
| L3 | 现有 E 库/铁律；补「案例转正链」：候选 → 审查 → 老朱拍板 → 转正（对照巨米双签制） | 现有机制 | 全员 |

**消费端（本次新增，最关键的补齐）**：把 KDO 失忆锚点 §4 升级为「胶囊精华段」——由 L0/L1 自动生成、≤1KB、每次会话启动注入，不再依赖人工更新（这是它停在 08-21 的根本原因）。

## 5. 记忆维护职责升级（风清扬自我认领）

- 从「维护锚点 + 诊断报告」升级为「**四层记忆维护者**」：
  - L0：监督全量留痕是否断流（每周查 activity_log 连续性）；
  - L1：审计胶囊摘要质量（上界 / 拼贴 / 停更）；
  - L2：生产洞察报告（周度，消费 KDO 全量上下文）；
  - L3：把洞察中可转正的教训提交转正链，不自行转正。
- 边界不变：不产卡、不终审、不派活、不改 KB 正文与看板；脚本实现归黄药师。
