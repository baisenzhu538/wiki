## 五、9 层深挖（L1→L4→L9）

- **L1 业务公式**：会议产出 = 目标清晰度 × 原则匹配度 × 流程效率；ROI = 价值产出 ÷（人数 × 时间 × 时薪）
- **L2 假设审计**：假设"流程最佳实践 = 好会议"→ A/B 同学案例证伪（抄最佳实践失败）；假设"人越多越好"→ 证伪（ROI 反算）；假设"会议是管理标配"→ Truman 砍周会证伪
- **L3 边界**：科学开会适用"深度讨论/多方决策"型会议；同步信息/单向推动型用替代方案；小团队短平快；物质激励三短板（成本高/失效/上去容易下来难）
- **L4 失败模式**（素材+已有卡实证）：复盘会变表扬会（B 同学 1.0）；启动会走形式（A 同学 1.0）；周例会报喜不报忧；会议变梦境（有讨论没结论）；老板一言堂压制民主；头脑风暴冷场/质量低；变脸侠（会后不认账）；会议无限长话题无限发散；编故事（高管不务实案例）
- **L5 用户场景**：老朱/团队/工厂自身——KDO 内部就有磨课会/选题会/复盘会/周例会（管理层本身是素材的实践场）；工厂的 queue 状态流转会议 = 落实原则的实战
- **L6 成本收益**：14 张卡（2 framework + 1 concept 升级 + 3 tool + 1 case + 1 bridge + 6 dk）≈ 老顽童 2-3 天；收益 = 管理域 L3"会开会"子域补全 + 与复盘域/领导力域桥接
- **L7 时序**：concept 升级 + framework ×2 先行（认知地基）→ tool 武器库（落地）→ case/bridge/dk（深化）
- **L8 验证方案**：tool 卡话术可直接照抄（口述稿逐字引用）；案例卡含完整三次觉醒过程；升级卡 source_refs 补齐可追溯
- **L9 决策框架**：
  - go/no-go：**go**（L1 证据 + 已有卡对照防重复 + 用户明确要求）
  - 最大风险点：与已有卡边界模糊（启动会/例会/复盘）——任务单写死"不新建重叠卡，只补链"
  - 最小验证路径：concept 升级 + framework 十大原则先行，欧阳锋终审后老朱/团队试用于真实会议
