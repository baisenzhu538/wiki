# 专项审计：半自动→全自动的质量保障与分阶段方案

> 触发：老朱 08-25 令——「对全库基础建设做专项审计。终极目标：我只管输入和最终成果审核。不能一步实现就给分阶段执行方案」。
> 证据基础：基建资产总表（#488，27 项）、schtasks 实测、08-24 五角色晚场复盘并置、近两日 L1/L2 审计链。

## 一、结论先行

1. **本厂全自动的最大风险不是「做错」，是「做错了没人知道」**——三份实证：#444 锁半套修改静默失效 24h 零告警；C-10 批量清空 71 卡；08-24 晚 3 个 FAIL 全为「声称-交付不符」。因此**全自动的前提不是先把人撤掉，而是先补齐「可观测 + 可熔断 + 可回放」三件套**。
2. **现状分层**：机械层（采集/巡检/登记）已全自动；流转层半自动（脚本+门禁但靠人会话触发）；判断层（编排裁定/终审/生产）全人工。终极目标要自动化的正是判断层——这也是质量风险最集中的层。
3. **质量保障四层防线已有两层半机器化**（入口门禁✅、过程留痕半✅、出口终审❌人工、事后审计半✅）。缺口明确、可补，不需要推翻重建。
4. **路径：四阶段，每阶段有「可进可退」的量化门禁**——质量指标先建基线，自动化逐档降人工比例，指标跌破阈值自动回退。人不能一步撤，但每一步都可验证。

## 二、现状分层盘点（实测，非转述）

| 层 | 环节 | 自动化现状 | 证据 |
|:--|:--|:--|:--|
| **已全自动**（无人值守在跑） | L1 采集 / 健康巡检 9 项 / 探针登记通知 / inbox 监工 / 视频号监测 / 复盘机器判级 | 6 个计划任务运行中 | schtasks 实测：kdo-l1-capture 30min、kdo-conveyor-probe 10min、kdo-inbox-watch 10min、kdo-health-daily、KDO-Health-Check、wechat-link-monitor |
| **半自动**（机器辅助+人触发） | 队列流转（状态机+门禁族 10 项）/ 批次验收四步一体 / 看板生成 / 复盘保存判级 | 脚本齐全，但 claim/complete/验收靠 agent 会话手动执行 | queue_transition 78 tests passed；queue_batch_accept #479 |
| **全人工**（机器零参与或薄） | **王语嫣编排裁定 / 欧阳锋终审逐卡 / 老顽童生产编译 / 段王爷发布决策 / 复盘写作 / 风清扬审计判断** | 全在 CLI/飞书会话里 | 08-24 晚：欧阳锋 9 单逐卡终审；王语嫣 6 份建议书逐份裁定 |
| **老朱** | 方向 / 拍板 / 纠偏 / 触发 | 每环都在场 | 终极目标=只保留「输入+成果审核」两项 |

**关键断点**：判断层三环（编排→生产→终审）每个环节都卡在一个人的会话上——王语嫣不裁定就堆积、欧阳锋不终审就阻塞（#504 审查空窗实证：37 分钟 4 单绕审查）。**全自动的本质 = 把这三环从「人驱动」改造成「机器驱动 + 人抽检」。**

## 三、质量保障机制审计（四层防线）

| 防线 | 现状 | 能否撑全自动 | 缺口 |
|:--|:--|:--|:--|
| ① 入口门禁（结构层） | F-034 五字段 / 意见书 / 负向判词 #433 / 处置结构化，全机器拦截，连审查者自己都拦 | ✅ 能 | 无大缺口；门禁词表需持续维护（机制已建） |
| ② 过程留痕（可回放） | L1 全量原文✅；**但事件库 26 条全是 review_saved**——claim/complete/review/decision/error 零记录 | ❌ 不能 | **全自动下没有工作流事件 = 无法回放「谁何时做了什么」= 审计瞎掉**。凌晨 F1 建议（P2）在全自动语境下必须升 P1 |
| ③ 出口终审（质量守门） | 欧阳锋 100% 人工逐卡；机器侧只有 lint/复扫/差集等散装工具，**无「机器预审」这一层** | ❌ 最大瓶颈 | 缺机器预审管线；缺质量指标（FAIL 率/打回率/误判率无基线） |
| ④ 事后审计（独立复核） | 风清扬 L2 审计有效（两日挖 3 个家族病）；但触发靠老朱一句话；抽数 digest 脚本已立项未建 | 🟡 半能 | digest 落地（已 P1）+ 审计节奏化（每日一轮建议书已提） |

**审计判断**：防线 ①④ 已基本就绪；②③ 是全自动的硬前提——**没有事件层，全自动就是黑箱；没有机器预审+质量基线，撤掉人工终审就是裸奔。**

## 四、分阶段执行方案

### 阶段 0：补地基（全自动的前提条件，1-2 周）

| # | 动作 | 对象 | 理由 |
|:--|:--|:--|:--|
| 0-1 | **事件层补 4 类工作流事件**（queue_transition/decision/friction/error 进 activity_log）——凌晨 F1 由 P2 升 P1 | 黄药师 | 可观测性前提，无此全自动=黑箱 |
| 0-2 | **质量指标基线**：FAIL 率 / 打回率 / 门禁拦截率 / 误判率先跑 2 周纯统计（不改动任何流程），出基线数 | 黄药师建表，风清扬定口径 | 没有基线就无法证明「自动化后质量不降」 |
| 0-3 | 静默失效防护：关键机制（锁/门禁/映射）写读对账进每日健康检查 | 黄药师（#503 任务 6 已在案） | #444 类事故在全自动下无人会发现 |
| 0-4 | daily-audit-digest 落地（06:00 抽数，已立项 P1） | 黄药师 | 审计层无人化抽数 |

**阶段 0 出口门禁**：事件层 4 类事件在流 + 质量基线报告 v1 + 健康检查含写读对账。

### 阶段 1：机械层收口 + 终审机器预审（2-4 周）

| # | 动作 | 对象 |
|:--|:--|:--|
| 1-1 | **机器预审管线**：提审单先过机器层——声称-交付差集（欧阳锋实证有效的判法）+ lint + 负向判词 + 存在性核查，机器出「预审报告」附在单上 | 黄药师建，欧阳锋定判据 |
| 1-2 | 批次线（#426 型）全自动：batch_accept + 差集 + 自动验收报告，欧阳锋只抽 10% | 老顽童+黄药师 |
| 1-3 | 复盘触发自动化：会话结束 hook 自动落盘+判级（现在靠自觉，C 级返工率高——老顽童 6 分钟 8 次重打实证） | 黄药师 |

**阶段 1 出口门禁**：机器预审报告与欧阳锋终审结论一致率 ≥ 90%（跑 2 周对照）。

### 阶段 2：判断层人抽检化（1-2 月）

| # | 动作 |
|:--|:--|
| 2-1 | 终审降档：机器预审 PASS 的单，欧阳锋抽检 100%→30%→10% 逐档递减；**每档门槛 = 抽检误判率 < 2%，跌破自动升档回 100%** |
| 2-2 | 编排辅助：建议书机器预分类（结构校验 + 历史裁定模式匹配）→ 王语嫣只裁「机器拿不准的」；机器建议仅作参考不入档（防自动化偏见） |
| 2-3 | 生产侧：标准卡型（工具卡/框架卡）模板化程度提高，老顽童精力转向复合编译与新材料 |
| 2-4 | 风清扬审计：digest 自动 + 每日一审节奏化；机器出「候选异常清单」（指标突变/门禁拦截聚类），我负责判断层 |

**阶段 2 出口门禁**：连续 4 周质量指标不低于基线（FAIL 率不升、漏检率不升）。

### 阶段 3：全自动闭环（老朱只管输入+成果审核）

- 素材进（inbox/采集）→ 编排预分类 → 生产 → 机器预审 + 低比例抽检 → 成品，**全链无人值守**；
- **老朱界面收敛为两样**：①每日成果简报（机器产：产量/质量指标/异常）；②发布前最终审核（段王爷线保留人工确认——对外发布是品牌风险，建议永久保留人审）；
- 异常上浮通道：质量指标跌破阈值 / 门禁拦截聚类异常 / 静默失效探针报警 → 自动上报老朱+王语嫣，**不等老朱问**。

## 五、红线条款（任何阶段不得回退）

1. **抽检永不归零**（哪怕 5%）——零抽检 = 质量漂移必然发生且无人发现；这是审计铁律，不接受效率理由豁免。
2. **每档降人工先 dry-run + 小批验证**（C-10 / F-KDO-013 纪律），单点验证通过 ≠ 批量安全。
3. **L1 全量留痕不可撤**——全自动越彻底，「崩盘可复刻」越重要；留痕是唯一的后悔药。
4. **误判成本不对称原则**：宁可机器多拦（人工放行成本低），不可机器少拦（漏放成本不可逆）。门禁调优永远偏向「误拦」一侧。
5. **熔断自动化**：质量指标跌破阈值 → 自动升档回人工，不依赖人发现（#444 教训：静默失效不会自曝）。
6. **对外发布（段王爷线）永久保留人工确认**——内部流转可全自动，对外出口是品牌风险不可逆面。
