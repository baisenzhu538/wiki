# 一堂机会预判 / 终局光谱域深挖诊断报告（#147 候选）

## 执行摘要

机会预判是 Truman 定义的一堂课程体系**第一阶段「预判篇」第一节课**，定位是「CEO/业务负责人最重要的工作之一」（`口述.txt:40-46`）。本域素材是一堂体系里**最丰富、最自洽**的一批：1 份 3466 行口述稿主线 + 1 份结构化笔记 + **实测 18 张 OCR 模型图**（用户口径 17 张，疑为计数差，已用 Glob 逐张核实，详见第三节）。

但 wiki 现状与素材丰度**严重不匹配**：8 张 `yt-foresight-*` 概念卡 + 3 张 AI/三维模型卡 + 几张 case 卡，**全部停留在「单点模型/单点案例」层**；缺三样承重结构——

1. 没有把口述稿主线（**预判段位差 → 15字诀 → 终局光谱七段 → 保A争B → 加法/减法 → 五步法预判**）串起来的**总框架卡**；
2. 没有**终局光谱图解读卡**（5 条解读、质变点、保A争B区间、3-10 年终局）——这是全课的方法论眼，目前只有光谱「框架」没有「读法」；
3. 没有**案例预判方法卡**（如何给任意一个 idea 跑七段光谱、定保A争B）——现有 case 卡是结果，不是可复用方法；
4. 没有**机会预判教练 Agent Spec**，也没有本域诊断报告（本报告为首次）。

**评级：A-（深挖价值中-高；素材最丰富，理论承重，建议尽快入队 #147）。**

> 王语嫣校准：用户称「17 张 OCR 未充分萃取」。实测 18 张中，**3 张已被充分萃取**（AI趋势12→`yt-ai-trend-12-signals`、20高风险→`yt-ai-startup-20-risky-hypotheses`、三维→`yt-three-dimension-opportunity-matrix`），**3 张案例已部分萃取为 case 卡**（咖啡/陪诊/AI时间管理）。真正缺口集中在「**解读层 + 方法层 + 总框架层**」，而非简单补图。本诊断不照搬「全量补图」，而是精准补承重结构。

## 七、机会预判专属 Agent 设计：`agent-一堂-机会预判教练`（建议）

- **定位**：预判篇总入口。先定段位与终局区间（保A争B），再驱动加法拆选项、减法排硬伤，最后落到五步法逐格预判并转交 #141。
- **默认 TCPR**：C（Coach，先定段位/区间）；问「怎么拆/怎么排」→T；一起梳理→P；要行业/AI 趋势数据→R。
- **触发场景**：①「有个创业想法，帮我预判终局」②「我该保几争几」③「这个方向有什么硬伤」④「AI 时代有哪些新机会适合我」⑤「终局定了，下一步怎么进五步法」。
- **工作流**：边界声明 → 段位定位 → 终局区间（保A争B）→ 加法拆选项池 → 减法排三类硬伤 → 五步法逐格预判 → 转交 #141 五步法教练 / 各子域 Agent → 输出终局区间+硬伤清单+下一步。
- **边界**：不替代商业决策/投资判断；不预测未来；预判≠验证（须接需求/产品内核验证）；不替用户定人生目标。
