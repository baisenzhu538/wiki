# 知识库暗知识体检计划（老朱 09-06 晨令，独立判断方案）

## 一、问题判定（回应老朱之问：你的理解正确）

**欧阳锋的盲区是结构性的**：终审只能度量「已产出的质量」（保真度），无法度量「未产出的遗漏」（完备度）。完备性这道关历史上没有独立守门人——靠编排者自觉（W5 牌/金矿扫描），而 W5/金矿扫描是 08 月才固化的，此前加工的素材没有这层保障。前科实证：E024（口述稿逐字读红线三次复发）、P-35（某域诊断覆盖率 ~10%）。

## 二、规模与密度信号

| 项 | 数 |
|:--|:--|
| 口述类原始素材 | **540 件**（含 _pdf_pages 87/ processed 87/双份重复，实质口述估 250-350 件） |
| 全库卡 | 2981 张 |
| **dk 暗知识卡** | **327 张**（≈0.6 张/素材） |
| 对照：昨晚一个域 | 3 份口述 → 200 金矿 → 12 卡 + 10 dk 挂靠 |

密度差距是信号不是定罪（历史素材有轻有重），定罪靠逐件体检。

## 三、三阶段方案（独立判断）

**Phase 0——素材-卡覆盖台账（我做，先预先处理）**：
对 540 件建台账：素材 → source_refs 反查派生卡 → 处理方式证据（有无金矿台账/深度诊断/逐字读记录）→ 风险分级：
- 🔴 A 级（高遗漏风险）：有口述稿但无深度诊断痕迹、或产自旧标准（汇编/笔记加工时代）
- 🟡 B 级：已产卡但早于金矿扫描固化（08 月前）
- 🟢 C 级：已逐字读+金矿扫描处理（08 月后新标准件）

**Phase 1——试金石先行，流水线放量**：
选 A 级中价值最高域先跑一件全流程（逐字读→金矿台账→王语嫣门禁→存量卡补强/新卡→欧阳锋终审），校准「单件成本×产出密度」，再按 价值×风险 排序流水线分批（老顽童产/我抽验/欧阳锋审）。首批候选：「人机协作双三角」域（26 件主目录，老朱核心方法论）或 yitang-lectures（9 件大课）。

**Phase 2——机制固化**：
①提审新增必备件「金矿台账」——producer 必附，欧阳锋抽源对照，完备性从自觉变门禁
②存量按批次消化进队列，例行化（新素材已走协议 7/8，本计划只管存量）

## 四、边界

- 540 件不可能一夜消化——按 价值×风险 排序分批，本轮先台账+试金石
- 隐私素材（个人聊天记录等）不入体检，等老朱指令
- 每批产出经欧阳锋终审，完备性由编排者金矿台账+抽源对照双签
