## 2. 独立判断：方向对，两处落点错

### 修正一：6 词分两档，不能全进强词硬拦

- **「为空 / 空值」→ 可进强词**：明确负向断言，与「无远程备份」同构，子串误伤面小。
- **「截断 / 损坏 / 乱码 / 半写」→ 不进强词**：它们在**正向核查声明**里高频出现——「完整读取、**无截断**」「确认**无损坏**」。子串匹配下，`无截断` 命中「截断」→ 硬拦 → 逼着审查者在「我已声明无截断」上再叠一个 `**存在性核查**` 锚点。**这是自伤，不是加固。**

**修正后落点**：仿照现有 PATTERN 给「数据异常」配一条**正则断言句**（如 `(?:字段|值|数据|内容|文件).{0,6}(?:为空|损坏|截断|乱码|半写)`），或先把这批词放 **宽词 SOFT** 观察误报率——这正是 #433 自带的「先小后大、误报进 friction」演进路径，不该跳级直接进强词。

### 修正二：「数据视图声明」范畴错位，应从门禁词表拿出

- 欧阳锋这次 #434 失误的根，不是「下了负向判词没举证」，而是**验证工具用了 `substr(…,1,90)` 截断视图**。
- 门禁拦的是「断言没带证据」，拦不住「举证的工具有截断风险」——把「完整读取 / 截断视图+截断点」塞进负向判词门禁，是把「验证方法纪律」和「断言举证门禁」两个不同层混进一个筐。
- 「数据视图声明」是**对的纪律**，但它该归**终审 SOP（王语嫣 #419 六角色 context 强制话术那条线）**，与「双假设原则」（欧阳锋已立）并列，不进门禁词表。

## 3. 元原则（供词表演进长期复用）

门禁词表演进守三层，不串层：

| 层 | 语义 | 例子 |
|:--|:--|:--|
| 强词 STRONG | 明确断言（硬拦，缺锚点不闭环） | 不存在 / 未备份 / 未同步 / 为空 |
| 正则 PATTERN | 短语断言（匹配句式，硬拦） | 无…备份 / 字段…为空 |
| 宽词 SOFT | 模糊词（标需人工，不硬杀） | 无 / 缺 / 没有 / 截断 |

**欧阳锋建议 = 往 STRONG 塞 SOFT 语义的词，属层级错位，不是方向错。**
