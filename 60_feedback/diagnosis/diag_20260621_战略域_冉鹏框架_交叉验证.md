## 一、BRM 框架溯源（Attacker A · 逻辑）

### 发现 ⚡

**"BRM"在英语战略文献中完全不是冉鹏的意思。**

| BRM 含义 | 来源 | 与冉鹏关系 |
|:---|:---|:---|
| **Benefits Realisation Management** | 英国政府 MSP 框架 (1995) | ❌ 无关——这是项目管理方法论 |
| **Business Relationship Management** | BRM Institute (全球研究所) | ❌ 无关——这是IT部门与业务部门的关系管理 |
| **冉鹏的 BRM** | 差距分析→战略规划→战略执行 | 🔮 冉鹏原创/IBM BLM 改编 |

### 推断

冉鹏曾在 IBM 担任咨询总监。IBM 的战略方法论是 **BLM (Business Leadership Model)** ——差距分析→战略→执行，这正是冉鹏 BRM 的三段结构。华为的"五看三定"就是 BLM 的中国版本。

**结论**：冉鹏的 BRM ≈ IBM BLM 的中国实战改编。**建议生产卡片时标注为"冉鹏版 BRM（源于 IBM BLM 方法论）"，而非让 Agent 误以为是国际通行的 BRM 框架。**

## 二、数据验证（Attacker B · 证据）

### 2.1 "30年前世界500强90%已消失"

| 数据源 | 实际数据 | 与冉鹏对比 |
|:---|:---|:---|
| Innosight 2021 | S&P 500 平均在榜年限从1964年的33年降至2021年的约18年 | ⚠️ 冉鹏说"90%消失"偏夸张 |
| Apollo Academy 2026 | S&P 500 平均在榜年限已降至 **15年** | ⚠️ 15年转手≈约50%替换，30年≈75-80%替换 |
| Fortune 历史数据 | 1955年的500强，到2025年仅剩约 **52家**（约10.4%）仍在独立运营（其余被并购/破产/退市） | ✅ 如果算"消失/被并购"，90%基本成立 |

**结论**：冉鹏的数字方向正确但表述需细化。"90%已消失" = 包括并购和退市。如果指"仍在独立运营且保持500强地位"，则约50家/500=10%存活，90%消失**基本成立**。但建议在卡片中区分"消失=破产/退市/被并购"三种路径。

### 2.2 过去30年中国企业靠红利驱动

| 验证点 | 数据 |
|:---|:---|
| 中国GDP增长 | 1995-2025：年均约8.5%（前20年）→ 2025年5.0%——增速腰斩，红利确实在消退 |
| 制造业转型 | 2025年制造业增加值34.7万亿，占全球30%+——规模红利仍存在，但增长模式已从规模→创新 |
| 研发投入 | 2025年R&D强度2.8%，首次超过OECD平均——验证冉鹏"从红利驱动→战略驱动"的判断 |
| 高技术制造业占比 | 2025年升至17.1%，智能设备制造业+28.1%——验证转型方向 |

**结论**：冉鹏"过去靠红利，现在靠战略"的判断与宏观数据**高度一致**。但需补充："红利消退≠没有红利"——新能源汽车、AI制药、低空经济仍存在新红利。

### 2.3 Gucci 起死回生案例

| 冉鹏描述 | 公开验证 |
|:---|:---|
| "2015年前后" | ✅ Marco Bizzarri 2015年1月就任CEO，Alessandro Michele 同月任创意总监 |
| "砍低价产品" | ✅ 砍掉折扣渠道，停止奥特莱斯低价品 |
| "收回授权" | ✅ 从授权模式转直营，收回渠道控制 |
| "聚焦时尚人群" | ✅ 主攻千禧一代，2019年千禧一代贡献超50%销售额 |
| "收入从39亿→83亿欧元" | ✅ 2015年€39亿→2018年€83亿（实际为4年翻倍） |

**结论**：Gucci 案例✅完全验证。唯一差异——冉鹏描述的是3年翻倍，实际是4年。

### 2.4 飞机制造公司（波音737 MAX）

| 冉鹏描述 | 公开验证 |
|:---|:---|
| "安全问题→根因是激励偏财务" | ✅ NTSB/Harvard/Stanford 调查一致指向：成本进度压力>安全 |
| "激励机制背离战略底线" | ✅ Boeing 将大量 FAA 认证权限内部化，MCAS 系统单传感器设计被多次批评为成本妥协 |
| "表面是质量问题，实际是战略问题" | ✅ Harvard 研究总结为"organizational, leadership, and cultural breakdowns" |

**结论**：波音案例✅验证。冉鹏的"激励机制背离战略底线"诊断与NTSB/Harvard/Stanford的结论**高度一致**。

## 三、完整性检查 —— 冉鹏没讲但战略领域公认的核心（Attacker C）

| 缺失框架 | 为什么重要 | 与冉鹏框架的关系 |
|:---|:---|:---|
| **波特五力** | 行业竞争结构分析的全球标准 | 冉鹏未明确提及——但他的"选择赛道"隐含了五力的逻辑 |
| **VRIO（资源基础观）** | 判断竞争优势能否持续的黄金标准（Value/Rarity/Imitability/Organization） | 冉鹏未提及——他的"竞争优势三层"覆盖了一部分但不够系统化 |
| **蓝海战略（ERRC）** | 创造新市场的框架（Eliminate/Reduce/Raise/Create） | 冉鹏未提及——但"价值曲线""差异化价值点"暗含相似逻辑 |
| **PESTLE** | 宏观环境分析（政治/经济/社会/技术/法律/环境） | 冉鹏未系统讲解——但"行业景气"暗含宏观分析 |
| **Greiner成长模型** | 企业生命周期+每次阶段的危机驱动转型 | ⚡ 冉鹏六阶段与Greiner六阶段结构相似但命名完全不同。冉鹏版更"中国化"——用"吃饱吃好吃撑吃吐"代替"创造力→方向→授权→协调→合作" |
| **BCG矩阵/GE矩阵** | 业务组合管理 | 冉鹏的"三个地平线"可以替代——基本够用 |
| **核心竞争力理论（Prahalad & Hamel）** | 1990年提出的经典战略理论 | 冉鹏未提及——但他的"争气=竞争优势"有一定重叠 |

### ⚡ 重要发现：冉鹏六阶段 vs Greiner六阶段

| Greiner (1972/1998) | 冉鹏 (2026) | 对应关系 |
|:---|:---|:---|
| Phase 1: 创造力 → 领导力危机 | 初创期：拼命试错 | ✅ 对应 |
| Phase 2: 方向 → 自主权危机 | — | ❌ 冉鹏跳过——直接到"吃饱期" |
| Phase 3: 授权 → 控制危机 | 吃饱期：优化模型快速复制 | ⚠️ 部分对应 |
| Phase 4: 协调 → 红带危机 | 吃好期：构建优势布局生态 | ⚠️ 部分对应 |
| Phase 5: 合作 → ?危机 | 吃撑期：边开车边换引擎 | ⚠️ 部分对应 |
| Phase 6: 外部联盟 → 增长危机 | 吃吐期：及时止损退出 | ❌ 完全不同——Greiner第6阶段是扩张，冉鹏第6阶段是退出 |

**结论**：冉鹏的六阶段模型**不是Greiner的翻译版，是他自己的实战提炼**。Greiner关注组织管理危机，冉鹏关注**商业生命周期+战略重心转移**。两者互补，不应混淆。建议在卡中加 Critique 节注明此差异。

### 4.2 2024-2026 战略领域新变化（冉鹏未覆盖）

| 新趋势 | 说明 |
|:---|:---|
| **AI 驱动的战略决策** | LLM 辅助战略分析——冉鹏课程未提及 |
| **地缘政治对战略的影响** | 脱钩/供应链重构/芯片禁令——冉鹏课程未系统覆盖 |
| **ESG 与碳中和战略** | 2025年中国碳市场扩容——冉鹏课程未提及 |
| **生成式AI 的商业影响** | 2024-2026年AI Agent产业爆发——冉鹏课程未覆盖 |

**结论**：冉鹏的内容核心扎实但**2024-2026的AI/地缘政治/ESG三个新变量缺失**。建议在为KDO写卡时增加"2024-2026外部补充"小节。
