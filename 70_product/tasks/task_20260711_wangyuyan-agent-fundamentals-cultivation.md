## 一、目标产出（1 卡 + 1 回链）

### 产出 1：`30_wiki/concepts/concept-一堂-Agent基本功修炼.md`（新）

**核心内容**：

1. **定义**：agent 基本功 = 针对具体场景的独立可检验原子能力（课程基本功定义套用到 agent）。例：王语嫣的 6 层交叉验证/证据分级/行号锚定；老顽童的 pre-submit 自检/wikilink 闭环；洪七公的 OCR+VLM 交叉校验；欧阳锋的终审 checklist。
2. **三环筛选 agent 基本功**：务实（有无 input/output spec）/可练（有无独立验证脚本）/价值（是否高频复利）——**与 #151 B-2 `tool-three-ring-capability-filter` 同构**：cap_hub 三环过滤器的本质就是"agent 基本功准入"。
3. **拆建推练 × KDO 映射表**：
   - 拆：任务→原子能力（各 agent 拆自己的原子动作）
   - 建：建模成 30_wiki 卡 / cap_hub Skill（固定套路）
   - 推：军团共识（#143 分诊注册，新 agent 按协议调用）
   - 练：复盘 + 刻意练习 + 终审考核（重复形成复利）
4. **练二十法 × KDO**（摘对应）：cap_hub=手边武器库；pre-submit + 欧阳锋终审=考核评估；复盘目录/`zhu-feedback-patterns`=复盘记录；agent-spec=培训。
5. **两个实证案例**：
   - 课程侧：**春萍·花总**——拆研发能力→培养实习生→AI 替代基础→AI+基本功；实习生是 agent 的预演（先把基本功拆出建模，再让 AI 在拆好的基本功上干活）；数字降级「课程案例口径」（算法评估 1 周→1 天）；行号锚定春萍口述稿（以 #150 spec #19 卡口径为准）。
   - 我们侧：**王语嫣角色锚定事故（2026-07-10）**——越界生产 #149 三案例卡；根因="只编排不写 30_wiki 方法论卡"的角色锚定基本功**未建模、未练**，长上下文/压缩后丢失；补救=立规写入 `zhu-feedback-patterns`（事后补"建"）；教训=agent 基本功必须建模成卡/机制，否则靠记忆守不住。
6. **边界/Failure Modes**：本卡不主张 agent 取代人的基本功修炼（AI 是外骨骼，肌肉靠苦练——引 #15 卡命题）；不替 #150 总纲/教练 agent-spec 重复造内容。
7. **frontmatter**：`domain: management`（随 #150 子域归属）+ 六要素辅标签（AI-基本功 + 体系）；`reviewed_by: 欧阳锋`；`status: draft`（待终审）；related 双向。
