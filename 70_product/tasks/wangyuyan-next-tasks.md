### 任务 1：KDO 概念卡地图

盘点全库概念卡的分布，回答三个问题：

1. 知识库当前有多少张 framework / tool / case / concept 卡？按域分布如何？
2. 哪些域之间已经有桥接（wikilink / related），哪些域还是孤岛？
3. 基于你的诊断经验，哪几个域之间最该桥接但还没桥接？

**铁律**：
- ❌ 不碰 `30_wiki/` 下的任何文件
- ✅ 只读，只写 `60_feedback/diagnosis/`
- 工具：`kdo cards` / `kdo query` / 直接读卡片

### 任务 2：自迭代机制设计文档

做概念卡地图的过程中一定会发现新的缺口和问题。把这些发现沉淀为一份机制设计文档，写清楚：

| 问题 | 你的建议 |
|:-----|:---------|
| 什么时间触发迭代？ | 每天？每周？卡变更后？ |
| 扫描什么？ | 新增卡？诊断记录中的 gap？孤立域？ |
| 产出什么？ | 迭代报告？gap 清单？桥接建议？ |
| 谁来消费？ | 你自动读？推给欧阳锋？ |

你只做**设计**，不写代码。黄药师看了你的设计文档后实施。
