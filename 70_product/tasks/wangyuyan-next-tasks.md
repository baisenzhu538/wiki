## 任务 2：概念 Gap 标注

你在诊断中如果发现"这个场景应该触发某张卡，但知识库里没有"，按以下格式写入诊断记录的 Gap 节：

```yaml
Gap: <概念中文名>
建议卡名: <id>
类型: framework / tool / concept
来源: Author, I. (Year). *Title*. Publisher. Chapter/Section.
桥接: <关联已有卡的 ID>
优先级: P0 / P1
```

### 要点

- **不需要自己做卡**——那是老顽童的活
- **来源锚点必须写**——至少写清楚出自哪本书哪个章节。这是 pipeline 的 capture 环节
- **桥接关系想清楚再写**——"这个新概念和知识库里哪张卡有关系？什么关系？"这是你最重要的增量价值
- **优先级判断标准**：P0 = 用户高频问到 or 诊断时频繁需要用到 that 卡 / P1 = 有价值的补充但不 urgent
