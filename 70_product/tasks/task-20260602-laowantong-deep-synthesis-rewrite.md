## 四步编译法

```
Condense → Question → Synthesize → Judge（独立判断）
                                      ↑ 新加的
```

前三步你已经熟悉了。第四步 **Judge** 是这次的重点。

### Judge 环节的三个强制问题

写完前三步后，问自己这三个问题。每个问题至少产出一段话写入文章：

| # | 问题 | 段落开头参考 | 防止的惰性 |
|:--:|------|------------|-----------|
| 1 | **自我应用**：用"数据五层次"反照 KDO 自身，发现了什么缺口？ | `"按照这个标准反照 KDO 自身……""KDO 的实践表明……"` | 只分析别人，不分析自己 |
| 2 | **边界判断**：Truman 的观点在什么场景下不成立？你不同意哪个点？ | `"我不同意……""与 Truman 不同，我的判断是……""这个框架在 XX 场景下可能失效，因为……"` | 忠实转述，没有立场 |
| 3 | **转换叙事**：你自己对"AI 数据"的认知在哪个瞬间发生了不可逆的改变？ | `"在读到这一段之前我以为……后来发现……""这个框架改变了我对 XX 的判断"` | 只有结论，没有故事 |

## 模板

用 `90_control/templates/deep-synthesis-article.md`，不是标准文章模板。

关键差异：

| 标准模板 | 深度合成模板 |
|:---------|:------------|
| `## Audience` → `## Core Thesis` → `## Draft` → `## Feedback Path` | `## 那个让我…的问题` → `## 旧认知→新认知` → `## 反照 KDO 自身` → `## 我不同意的点` → `## 如果你只做一件事` |
| 第三人称，笔记体 | 第一人称，有立场的叙事 |
| 框架列表 + Critique（外部攻击） | 框架藏在叙事里 + Judge（独立判断） |

## 门禁：D1-D4

| # | 维度 | 判定标准 | 不通过→退回 |
|:--:|:-----|:---------|:-----------|
| D1 | **独立观点存在** | 至少一段以"我认为""KDO 的实践表明""我的判断是"开头 | 全文无第一人称判断句 |
| D2 | **自我应用** | 至少一处用框架分析 KDO 自身（指出缺口/矛盾） | 只说"对应"不说"缺什么" |
| D3 | **张力暴露** | 至少一处框架内部的矛盾、边界、或"还没想清楚"的问题 | 说明书体 |
| D4 | **转换叙事** | 至少一个 before→after 认知转变 | 全是"Truman 提出""Truman 认为" |

**四维全过 → 审查通过。缺任一 → 退回重修。**
