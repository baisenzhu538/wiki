## 执行

### Step 1：看图 + 理解 OCR

每张图 → Read 原图 → 如有 `_paddle_ocr.txt` 则辅助理解图中文字 → 做 VA。

### Step 2：写 VA（四维法，不含颜色）

```
## Visual Analysis

原图为[类型描述]，整体呈[布局结构]。
主体分为[N]个区域：[区域1→区域2→区域3]。
分组逻辑：[边框/留白/线框语义]。阅读路径：[F形/Z形/中心辐射]。
视觉强调：[字号/位置/图标权重]。留白运用：[分隔/呼吸/未完成]。
```

### Step 3：写入卡片

VA 写入对应 OCR 卡片的 `## Visual Analysis` 节。

⚠️ 注意：有些卡片可能已被黄药师编译为 `yt-unit-model-*.md`。**先检查目标卡片是否存在，存在就写入，不存在就记下来。不要创建新卡片——那是老顽童的活。**

## 规则

- **只做 VA，不碰 Critique/Synthesis**
- **不做颜色分析**
- **原图优先于 OCR 文本**——OCR 可能有错，以图为真相源
- 每做完 5 张 → 通知欧阳锋抽检

## 验收

| # | 验收项 | 判定 |
|:--:|------|:--:|
| 1 | ≥15 张单元模型图有 `## Visual Analysis` 节 | grep + 抽检 |
| 2 | 四维法全覆盖（空间层级/分组逻辑/阅读路径/视觉强调+留白） | 抽检 3 张 |
| 3 | 无颜色分析 | 人工确认 |
| 4 | 未创建新卡片 | git diff 验证 |

## 估时

~20 张图 × ~5min/张 ≈ 1.5-2h
