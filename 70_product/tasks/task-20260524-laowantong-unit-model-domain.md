# 老顽童任务：单元模型域全量编译

## 背景

新到仓一个完整域：

```
00_inbox/单元模型/ (24MB, 36件)
├── 口述稿 ×5 (01-04 系列课 + AI+单元模型)    ~770KB
└── 知识地图/框架图/案例图 ×31                   ~23MB
```

单元模型是一堂的核心方法论——从单订单、单用户、单门店到单城市，逐层抽象商业模型，用基准值、象限分析、动态预测做 ROI 判断。与已有科学决策域有交叉但不重叠。

## 做什么

从头走完 KDO 全管线：转录稿清理 → OCR 图片 → ingest → enrich（三步编译），产出本域全部概念卡。

## 执行步骤（不许跳）

### Step 1：读素材（~30min）

1. 通读 5 份口述稿，理解单元模型方法论全景
2. 看一遍 31 张图片（不需要 VA，理解图表内容即可）
3. 用 `kdo query "单元模型"` 拉取已有相关卡

### Step 2：设计 Card Map（~20min）

规划本域卡片结构。参考科学决策域的 F2+T5 模式：
- Framework 卡（概述方法论全景的，2-3 张）
- Tool 卡（具体工具/框架的，如单订单模型、基准值、象限分析法等）

输出 Card Map 到我这里审批，不要在没审批前开工。

### Step 3：编译卡片（每张 ~30-45min）

调用 `kdo clean-transcript` 清理口述稿 → `kdo ingest` → 手动三步编译。

**Critical：Critique 标准**

每个 Critique 必须包含：
- 攻击者姓名 + 攻击角度标题（H4 格式）
- 具体场景（什么类型的业务、什么条件下失效）
- 失效机制（为什么失效——是线性假设？是信息不足？是生态位锁定？）
- 来源引用（学者 + 著作/论文，非虚构）

禁止：
- "不适用于危机决策"式万能废话
- 只有攻击者名字没有论证
- Kahneman+Taleb 双禁组合（同域出现 5 次以上封禁）

**Critical：案例区分度**

如果卡片声称有案例，检查：
- 案例是否写入正文（不是只在源文件里）
- 案例类型是否 ≥2（成功 + 失败/边界/反常识）
- 案例是否有具体数值/场景（不是"某公司"式空壳）

**Critical：Synthesis 关联说明**

每个 wikilink 后必须有 ≥30 字的关联说明（互补/矛盾/延伸），不是只放一个链接。

### Step 4：欧阳锋审查（每做完 5 张）

每 5 张汇报一次。不批不继续。
