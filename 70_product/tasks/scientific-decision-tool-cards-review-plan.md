## 三、审查要点（逐卡）

### 02 yt-decision-width-method

**核心内容**：列推建查四步法 + 个人/团队/企业三层盲区清单
**素材来源**：ROI决策宽度实操课口述02 + 4张PNG图
**已知风险**：
1. 三层盲区清单基于一堂创业圈经验，对非标准创业场景覆盖不足（已在 Constraints 标注）
2. "列推建查"对低价值决策不经济，需配合决策阈值使用

**审查重点**：
- [ ] 四步法流程图是否清晰（口述稿中有图，是否需要在卡中用文字还原？）
- [ ] 三层盲区清单的表格是否完整（个人9+7项 / 团队6+9项 / 企业7+8项）
- [ ] Simon 和 Taleb 的攻击是否打到"让用工具的人睡不着觉"
- [ ] Action Triggers 的进入标准是否足够具体

### 03 yt-decision-depth-ladder

**核心内容**：L1-L4 四级深度阶梯 + 停车场机制 + 三点预测法
**素材来源**：ROI决策深度实操课口述03
**已知风险**：
1. "该停在哪一层"的判断本身需要预判能力，新手容易摇摆
2. L3/L4 严重依赖 benchmark，新业务缺乏数据时公式只是"拍脑袋的数学伪装"

**审查重点**：
- [ ] 四级阶梯的"停车信号"是否可操作（当前定义较抽象）
- [ ] 三点预测法的示例是否足够（当前只有电话外呼一个案例）
- [ ] Kahneman 的"噪声乘法放大"攻击是否够尖锐
- [ ] Hayek 的"知识分散"攻击是否与 height-toolkit 中的 Foucault 攻击有重复感

### 04 yt-decision-height-toolkit

**核心内容**：上帝视角四维拔升（长期/公司/机会成本/时间窗口）+ 高水平共识曲线
**素材来源**：ROI决策高度实操课口述04 + 共识曲线PNG
**已知风险**：
1. "上帝视角"实质是 CEO 视角的伪装（Foucault 攻击已覆盖）
2. 长期预测准确率极低，3年以上预测可信度大幅下降

**审查重点**：
- [ ] 共识曲线的 L4→L1 四层定义是否与 consensus-iceberg 重叠？两张卡如何分工？
- [ ] Keynes 的"长期来看我们都死了"攻击是否足够紧迫
- [ ] 四维度的案例覆盖是否均衡（当前长期视角4个、公司视角2个、机会成本2个、时间窗口5个）

### 05 yt-decision-consensus-iceberg

**核心内容**：决策爬山（L4→L1）+ 说服挖冰（L1→L4）+ 教练式提问
**素材来源**：ROI决策实践实操课口述05 + 共识曲线PNG
**已知风险**：
1. 与 height-toolkit 中的"共识曲线"有内容重叠——需确认分工
2. 教练式提问在高压文化中可能被理解为测试/陷阱

**审查重点**：
- [ ] 与 height-toolkit 的共识曲线重叠问题——建议 height-toolkit 聚焦"对齐什么内容"，consensus-iceberg 聚焦"如何操作对齐"
- [ ] Janis 的群体盲思攻击是否让"团队共识"的使用者感到不安
- [ ] March 的垃圾桶模型攻击是否足够颠覆（当前版本已较强）
- [ ] "一堂共识文化"段落是否过于组织特定，需要弱化品牌露出？

### 05 yt-decision-review（第二张05卡）

**核心内容**：L1-L4 四层复盘 + 假设验证闭环
**素材来源**：ROI决策实践实操课口述05
**已知风险**：
1. 复盘前提是"预判快照"，但大多数人做不到
2. 复盘时间窗口极窄（1周内），超过即"山寨复盘"

**审查重点**：
- [ ] 与 yt-personal-deep-review（五层复盘模型）的关联是否清晰
- [ ] Popper 的"归纳法陷阱"攻击是否打到"复盘产出的规律都是可被推翻的"这一核心
- [ ] Taleb 的"黑天鹅虚无主义"攻击是否与 width-method 中 Taleb 的攻击过于相似？
- [ ] Action Triggers 中"1周内完成复盘"的时限是否过于刚性

### yt-decision-full-process（框架，P2）

**核心内容**：五阶段全景流程（有意识→写初版→细打磨↔有共识→复盘）
**素材来源**：ROI决策实践实操课口述05
**已知风险**：
1. 五阶段执行成本极高（2-5天），对日常决策不现实
2. 阶段三和阶段四的循环可能无限延伸，无强制终止机制

**审查重点**：
- [ ] 作为"最后做"的框架卡，是否充分串联了前面所有子工具？
- [ ] 新手/高手两条路径的定义是否过于模糊？
- [ ] Mintzberg 的"涌现战略"攻击是否需要从绝对表述改为条件性表述（老朱此前纠正过）
- [ ] 此卡无独立"外部攻击者"板块，攻击放在 Critique 内——是否符合 tool 卡格式规范？

## 四、跨卡一致性问题

1. **共识曲线重叠**：height-toolkit 和 consensus-iceberg 都包含 L4→L1 四层模型。建议：
   - height-toolkit 中保留"共识曲线"作为高度维度之一（用于诊断"高度不同导致的分歧"）
   - consensus-iceberg 中保留完整的四层操作法（用于"如何结构化对齐"）
   - 两张卡在正文中互相引用，明确分工

2. **Taleb 重复**：width-method 和 review 都用 Taleb 做攻击者。虽然攻击角度不同（前者打"盲区清单方向错了"，后者打"复盘迁移虚假"），但需确认欧阳锋是否接受同一攻击者出现在多张卡中。

3. **Simon 重复**：width-method 和 full-process 都用 Simon。前者打"有限理性/列不全"，后者打"满意化/流程不可能走完"。角度不同，但同样需确认。
