# AI设计Prompt工程

## 1. 核心心智：从"许愿"到"指挥"

### 1.1 "拜拜"隐喻

把AI当成许愿池的神明，但有一个前提：
**你得清楐你在拜什么。**

向神明求什么、怎么求，就是把需求变成AI能准确执行的表述。

不同神仙管不同事：
- 求婚姻 → 找月老
- 求事业 → 找财神
- 求健康 → 找药王

**同理**：不同模型管不同场景（见Skill 1 模型选型矩阵）。

### 1.2 三步转变：口喷 → 写下来 → 喂给AI

```
脑子里想 → 嘴上说出来 → 纸上写下来 → AI执行
```

- **说出来**：脑子跟嘴同步，检验自己是否真的清楐需求
- **写下来**：把模糊的想法变成精确的文字
- **喂给AI**：把文字变成AI能理解的提示词结构

> **核心认知**：AI听得懂人话的前提是——**你自己知道你想要什么**。

## 2. 提示词够用原则

### 2.1 不是越长越好

| 场景 | 建议长度 | 原因 |
|------|----------|------|
| **简单修改** | 1句话 | 关键提示词不容易被水化 |
| **标准生成** | 100-200字 | 结构清晰，重点突出 |
| **复杂场景** | 200-500字 | 需要多维度描述时 |
| **超长提示词** | 不推荐 | 关键信息被水化，AI捕捉不到重点 |

> **极梦限制**：超过800字会强制截断，所以极梦场景下必须精简。

### 2.2 什么时候用短提示词

**场景1：修复文字错误**
```
用最高分辨率重新生成这张图，修改中文中的文字错误。
```

**场景2：电商白底图**
```
精修，这个产品达到极高质量电商白底背景主图标准，
产品需完美无瑕般精致呈现。
```

> **原则**：能用一句话解决的，不要写两句。

## 3. 行业提示词模板

### 3.1 使用方法

1. 复制下方模板
2. 替换蓝色标注部分为自己的信息
3. 直接喂给AI（豆包/巨米/GPT均可）
4. 生成后不满意就说"再生成10张"

### 3.2 五大行业模板

#### 模板A：教培行业
```
设计一张[XX培训]的推广海报。

信息要求：
- 主标题：[XX提分/成为XX达人]
- 副标题：[XX科学方法/XX天见效]
- 品牌色：[主色调，如蓝色体系]
- 目标人群：[XX岁学生/家长]
- 风格：[专业/活泼/温馨]
- 尺寸：[小红书3:4 / 朋友圈1:1]

要求：
- 标题突出，字体大且易读
- 配色专业，符合教育行业审美
- 加入学习元素（书本/笔/灯泡）
- 高清，适合线上传播
```

#### 模板B：零售行业
```
设计一张[XX产品]的电商主图。

信息要求：
- 产品名称：[XX]
- 核心卖点：[XX功能/XX成分]
- 品牌色：[主色调]
- 背景：[白底/场景图/渐变色]
- 尺寸：[800x800 / 1200x1200]

要求：
- 产品突出，占画面60%以上
- 光影自然，有质感
- 适合淘宝/天猫/拼多多首图
- 高清，支持放大查看细节
```

#### 模板C：本地生活
```
设计一张[XX店/服务]的推广海报。

信息要求：
- 店铺名称：[XX]
- 服务内容：[XX服务/XX特色]
- 地址/联系方式：[XX]
- 风格：[本地特色/时尚简约/温馨亲切]
- 尺寸：[朋友圈1:1 / 抖音9:16]

要求：
- 信息层级清晰，主次分明
- 加入本地元素（地标/特产/环境）
- 适合线下打印和线上传播
```

#### 模板D：餐饮行业
```
设计一张[XX餐厅]的菜品/活动海报。

信息要求：
- 餐厅名称：[XX]
- 主打菜品：[XX]
- 活动主题：[新品上市/节日促销/限时优惠]
- 风格：[食欲感强/高级感/亲民感]
- 尺寸：[朋友圈1:1 / 门头招牌]

要求：
- 食物色彩鲜艳，有食欲
- 配色温暖，符合餐饮审美
- 可加入餐具/餐帝等氛围元素
- 同时提供菜品图（现拍或参考图）给AI参考
```

#### 模板E：新媒体/知识IP
```
设计一张知识类/个人IP海报。

信息要求：
- 标题：[XX金句/XX观点]
- 说话人：[XX/角色定位]
- 风格：[专业感/质感/亲和力]
- 配色：[主色+辅助色]
- 尺寸：[小红书3:4 / 知乎方图 / 视频封面]

要求：
- 金句突出，字体大且有设计感
- 背景简洁，不抢内容风头
- 适合多平台传播（小红书/知乎/视频号）
- 高清，支持品牌化使用
```

## 4. 逆向推导技巧

### 4.1 什么时候用

看到一张很好的参考图，想让AI生成同类型时使用。

### 4.2 逆向提示词

```
从以下维度描述这张图片内容，生成一个可以指导AIGC生成类似图片的文本提示：
- 风格限定
- 角色构图
- 主体描述
- 背景设定
- 细节
- 色调
- 对焦
- 物品质感
- 画面构图
- 画面尺寸
```

### 4.3 操作步骤

1. 保存参考图到本地
2. 上传给AI（支持图片输入的模型）
3. 粘贴上方逆向提示词
4. AI生成提示词后，循环使用：用新提示词生成新图 → 对比调整 → 再逆向

## 6. 约束与陷阱（Constraints & Pitfalls）

| # | 陷阱/约束 | 说明 | 应对 |
|---|-----------|------|------|
| C1 | **提示词超长** | 超过500字关键信息被水化 | 先写核心描述，再补充细节；先测试再扩充 |
| C2 | **模板盲目复制** | 蓝色部分忘记替换，生成模板内容 | 替换时使用"查找替换"确认无遗漏 |
| C3 | **追求一抽流** | 期望一次生成就完美 | 一次生成10张筛选是正常流程，不是失败 |
| C4 | **模型不匹配** | 用豆包生成艺术风格，用Nano做电商图 | 先看Skill 1的选型矩阵，再写提示词 |
| C5 | **迹象描述** | "高级感"“好看”等模糊词 | 具体化："莫兰迪色调+无衬线字体+左对齐版式" |
| C6 | **忽视负面描述** | 只说要什么，不说不要什么 | 加入排除词："不要塑料感““不要复杂背景" |
| C7 | **语言混用干扰** | 中英混杂导致部分模型输出英文 | 明确指定"所有文字必须是中文" |
| C8 | **逆向后盲目复制** | 逆向出来的提示词直接用，不做调整 | 逆向是起点，不是终点；必须根据自己需求修改 |
