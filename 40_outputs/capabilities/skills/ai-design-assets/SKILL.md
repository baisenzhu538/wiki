# 设计资产管理规范

## Purpose
为AI时代的设计团队建立可复用的资产管理体系，通过文件命名规范、PS分层标准、风格库沉淀等手段，确保AI生成的素材能够被高效管理和复用，而不是每次重头开始。

## When to Use
- 需要为设计团队建立文件管理规范时
- 需要沉淀设计师个人/团队资产时
- 需要制定PS分层与模板标准时
- 需要搭建设计风格库/Moodboard时

## When NOT to Use
- 个人自由职业者的临时项目（建立资产体系需要前期投入，短期项目ROI为负）
- 没有固定设计流程的团队（先有流程再有资产管理）
- 需要立即出活的紧急场景（资产沉淀是长期工程，不能解决当下问题）

## Protocol

## 1. 核心认知：AI降本增效的起点是资产管理

### 1.1 为什么先整理资产

AI降本增效的起点不是打开AI，而是**整理资产**。

- 文件乱=AI结果乱，AI需要一个干净的家
- 设计师的最后护城城不是提示词，而是**版式、配色、字体**等基础理论
- 你不会写提示词能叫AI写，但你的理论沉淀AI没有

### 1.2 资产管理三层次

```
第一层：文件体系（命名、归类、存储）
        ↓
第二层：设计资产（风格、模板、提示词、理论）
        ↓
第三层：协作规范（输出端、接收端、版本管理）
```

## 2. 文件体系8要素命名法

### 2.1 8要素命名框架

```
[项目]_[渠道]_[用途]_[尺寸]_[版本]_[输出端]_[接收端]_[时间]
```

| 要素 | 说明 | 示例 |
|------|------|------|
| **项目** | 品牌/活动名称 | 茶叶品牌升级 / 618大促 |
| **渠道** | 线上/线下/私域/公域 | 线上电商 / 线下门店 |
| **用途** | 具体用法 | 主图 / 详情页 / 朋友圈海报 |
| **尺寸** | 像素或物理尺寸 | 1080x1080 / 40x60cm |
| **版本** | 内容平台差异 | 淘宝版 / 拼多多版 / 小红书版 |
| **输出端** | 谁下的单 | 新媒体部 / 策划部 / 客户 |
| **接收端** | 谁在用 | 门店展示 / 电商首页 |
| **时间** | 制作日期 | 20260519 |

> **注意**："版本"不是修改次数（V1/V2），而是**平台内容差异**。淘宝的货可能跟拼多多不同，必须分开。

### 2.2 管理者降本增效四步

```
步骤1: 整理文件体系（8要素命名）
        ↓
步骤2: 整理风格边界（我们有哪些设计风格）
        ↓
步骤3: 风格转为AI模板
        ↓
步骤4: 降本增效真正落地
```

### 2.3 文件体系检查清单

- [ ] 所有历史设计文档已重新命名
- [ ] 命名符合8要素框架
- [ ] 文件已按项目/品牌分类存放
- [ ] PSD/源文件与导出图分开存放
- [ ] 版本历史可追溯（不是覆盖，是新建）

## 3. 设计师四类资产沉淀

### 3.1 四类资产清单

| 类别 | 沉淀内容 | 工具/方法 | 更新频率 |
|------|----------|-----------|----------|
| **提示词库** | 跑出的好用提示词，分类整理 | 飞书文档/语雀/专业笔记软件 | 每次项目后 |
| **风格流派** | 行业设计语言（莫兰迪、赛博朋克、日系等） | 花瓣画板/专属风格文档 | 每月更新 |
| **理论体系** | 版式、配色、字体、编排理论 | 设计专业书籍/在线课程 | 持续学习 |
| **PS模板** | 背景、标题、主体、辅助四大图层组 | PSD/智能对象/分层文件 | 每季度审查 |

### 3.2 风格流派沉淀框架

每个设计师/团队应该有自己的**风格知识库**：

```
风格名称
├── 视觉特征（配色、字体、图形元素）
├── 适用场景
├── 不适用场景
├── 关键提示词（用于AI生成同类风格）
└── 参考案例链接
```

示例：
- **莫兰迪色调**：低饱和度、灰粉色系、温柔感
- **赛博朋克**：高饱和度、霓虹光影、科技感
- **日系清新**：大面积留白、细线条、自然光

## 4. PS模板核心标准

### 4.1 四层分类强制规范

一个规范的设计文件，必须只有四个图层组：

```
├── 背景 (Background)
├── 标题 (Text)
├── 主体 (Subject)
└── 辅助 (Auxiliary)
```

### 4.2 单独导出检查清单

每个图层组必须能**单独导出**：

- [ ] 能否单独导出背景图层？
- [ ] 能否单独导出主体智能对象？
- [ ] 能否单独导出光影/质感图层？
- [ ] 能否单独导出标题文字图层？

> **核心原则**：**图层不规范=AI无法精准输入=AI协作崩溃**

### 4.3 模板文件存储规范

- 模板文件存放于独立目录：`Templates/`
- 每个模板命名：`[项目]_[用途]_Template.psd`
- 模板文件只包含图层结构，不包含具体内容
- 定期审查（每季度），删除过期模板

## 5. 风格库与Moodboard搭建

### 5.1 什么是Moodboard

Moodboard（情绪板）是设计前期的参考图收集，用于确认视觉方向。

### 5.2 搭建步骤

```
步骤1: 确定设计方向（先知道你要什么）
        ↓
步骤2: 按五维度搜图（配色/版式/质感/Mockup/风格）
        ↓
步骤3: 建立画板，分类存放
        ↓
步骤4: 筛选最佳实践，形成风格定义
        ↓
步骤5: 转为AI风格提示词，开始生成
```

### 5.3 工具推荐

- **花瓣网/Pinterest**：图片收集与分类
- **自建共享盘**：团队协作版Moodboard
- **飞书/语雀**：文档化风格定义

## 6. 团队协作规范

### 6.1 跨部门协作流

```
需求方（策划/运营） → 下单单
        ↓
设计部接单 → 检查资产库 → 确认风格方向
        ↓
AI生成初稿 → 确认方向 → PS精修
        ↓
交付给需求方 → 收集反馈 → 归档存储
```

### 6.2 协作卡点解决

| 卡点 | 原因 | 解决方案 |
|------|------|----------|
| 设计部不知道风格方向 | 没有风格库 | 建立品牌风格手册 |
| 文件找不到 | 命名不规范 | 强制执行8要素命名 |
| 反复做同类图 | 没有模板 | 建立模板库，复用而非重做 |
| 设计师离职资产丢失 | 个人资产没有团队化 | 定期团队资产备份与归档 |

---

## 7. 约束与陷阱（Constraints & Pitfalls）

| # | 陷阱/约束 | 说明 | 应对 |
|---|-----------|------|------|
| C1 | **文件命名不规范** | 协作时找不到文件，AI训练语料混乱 | 从起点就用8要素命名，不要后补 |
| C2 | **图层不分组** | 无法单独导出元素给AI修改 | 四层分类强制执行：背景/标题/主体/辅助 |
| C3 | **个人资产不团队化** | 设计师离职后资产丢失 | 定期团队资产归档，建立共享库 |
| C4 | **风格库不更新** | 用老风格做新项目，脱离潮流 | 每季度审查风格库，删除过期内容 |
| C5 | **模板过度累胠** | 模板越来越多，找不到合适的 | 每季度清理，只保留高频使用的模板 |
| C6 | **只沉淀不复用** | 收集了很多，但没有整理成可用的 | 每次沉淀后必须生成可复用的模板/提示词 |
| C7 | **忽视理论学习** | 什么都靠AI，自己的理论体系为零 | 每月至少沉淀1个新理论/风格 |

## Examples

### 案例：新媒体运营团队资产体系搭建

**场景**：某新媒体运营团队（5人）每天需要生成 10-20 张社交媒体配图，但文件杂乱、模板不统一，每次都从零开始。

**实施前状态**：
- 文件名称：`图片 1.jpg`、`未标题-2.png`、`final_final_v3.psd`
- PS图层：全部在一层，修改时全图重画
- 风格不统一：今天混搭风、明天日式风，无法形成品牌识别

**实施步骤**（按本技能 Protocol）：
1. **文件命名规范**：强制执行 8 要素命名法
   - 示例：`20260415_新媒体_春季招生_公众号配图_温馨风_v2_待审.psd`
2. **PS分层标准**：四层分类
   - 背景层：素材/渐变
   - 标题层：文字/标语
   - 主体层：产品/人物/主视觉
   - 辅助层：装饰/图标/水印
3. **模板沉淀**：每周生成 3 个高频场景的 PS 模板
   - 示例：公众号封面模板、小红书配图模板、朋友圈海报模板
4. **风格库搭建**：团队共享文件夹，沉淀 5 种品牌风格的 Moodboard
   - 温馨专业风、科技简约风、活力青春风等
5. **理论库**：每月团队分享会，沉淀1个新理论或风格
   - 示例："莫兰迪色调的应用场景"、"左对齐 vs 居中对齐的阅读动线"

**关键收益**（实施 1 个月后）：
- 单张配图制作时间从 45 分钟→ 15 分钟
- 团队成员离职后，新人 3 天内可接手现有项目
- 品牌视觉一致性显著提升，识别度增强
