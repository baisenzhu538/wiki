# Deep Image Parser → Wiki 卡片整合模板

## 整合流程

1. 对图片执行深度解析（见 SKILL.md 方式一）
2. 对照现有卡片内容，确定差异点
3. 将差异点整合进卡片对应小节
4. 更新 `source_refs` 和 `updated_at`

## 差异点映射表

| 解析输出类型 | 卡片目标小节 | 整合方式 |
|:---|:---|:---|
| 表格 | `## Claims` 下的现有表格 | 补充缺失列/行，校正错误内容 |
| 清单/条目 | `## Claims` 或 `## Action Triggers` | 展开为有序/无序列表 |
| 公式 | `公式相关小节` | 用 LaTeX $$...$$ 格式插入 |
| 对比维度 | `新增对比分析小节` | 新建 Markdown 表格 |
| 视觉标记 | `## Visual Analysis` | 补充高亮/框线/颜色的语义解读 |
| 逻辑关系 | `## Claims` 下的核心逻辑 | 补充递进链/对比维度分析 |

## 整合示例

### 示例：表格整合

```markdown
### 五要素模型（更正版）

| 能力 | 资源 | 进步方式 | 路径 | 人生红点 |
|:---|:---|:---|:---|:---|
| 1. 懂教育 | 1. 头部关系 | • 最佳实践 | 1. 靠谱产品经理 | 作品存世型：用产品创新的方式， |
| 2. 泛产品创新 | 2. 创业圈关系 | • 高效IPO | 2. 优秀业务负责人 | 不断推动这个世界的边界。 |
| 3. 懂商业操盘 | 3. 优秀团队 | • 刻意练习 | 3. 成熟创业者 | 教育优先，涵盖其他 |
| 4. 体系建模 | | | 4. 自由创新者 | |
```

### 示例：视觉标记整合

```markdown
## Visual Analysis

...

**视觉标记语义**：
- 「泛产品创新」**黄色高亮 + 红色虚线框**：当前阶段核心聚焦能力，与人生红点中"用产品创新的方式"形成首尾呼应
- 「人生红点」**整列红色虚线框**：整个框架的终极目标与意义归宿
```

### 示例：对比维度整合

```markdown
### 横向对比维度

| 对比维度 | 左列（起点） | 右列（终点） | 关系说明 |
|:---|:---|:---|:---|
| 抽象 vs 具象 | 能力、资源（抽象要素） | 路径、人生红点（具象成果） | 从左至右逐渐落地 |
| 内部 vs 外部 | 能力、进步方式（内部可控） | 资源、路径（外部互动） | 内外结合 |
| 短期 vs 长期 | 懂教育、靠谱产品经理（当下可执行） | 自由创新者、作品存世（长期愿景） | 时间轴递进 |
| 手段 vs 目的 | 能力、资源、进步方式、路径（手段集合） | 人生红点（终极目的） | 目的论结构 |
```
