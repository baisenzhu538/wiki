# Deep Image Parser 深度图像解析

## 概述

本 skill 解决传统 OCR 只能提取平铺文字、丢失表格/公式/逻辑结构的痛点。
通过多模态 AI 视觉理解，实现从图片到结构化知识的完整管线。

---

## 能力对比

| 能力 | 旧 image-ocr (PaddleOCR.js) | 本 deep-image-parser |
|:---|:---|:---|
| 普通文字 | ✅ | ✅ |
| 密集/小号文字 | ❌ 易丢失 | ✅ 高精度识别 |
| 表格结构 | ❌ 完全丢失 | ✅ Markdown 表格完美还原 |
| 公式（LaTeX） | ❌ 不支持 | ✅ LaTeX 语法输出 |
| 清单/条目 | ❌ 混乱平铺 | ✅ 有序/无序列表分类 |
| 视觉标记 | ❌ 完全丢失 | ✅ 高亮/红框/颜色语义解读 |
| 逻辑关系 | ❌ 不可见 | ✅ 递进链/对比维度分析 |
| 布局理解 | ❌ 无 | ✅ 多栏/层级/区块识别 |

## 引擎架构

```
输入图片
    ┌────────────────────┐
    │  判断任务复杂度   │
    └────────────────────┘
           │
    ┌───────┐    │    ┌──────────────┐
    │ 简单文字 │──┼──│ 复杂结构/表格/公式 │
    └───────┘    │    └──────────────┘
       │           │           │
       ▼           ▼           ▼
  PaddleOCR.js   多模态AI视觉分析   多模态AI视觉分析
  (本地ONNX)   (默认主引擎)     (默认主引擎)
       │           │           │
       └─────────┼─────────┘
                  ▼
          结构化输出
    ┌────────────────────────┐
    │  • Markdown 正文      │
    │  • JSON 元数据        │
    │  • 卡片整合模板      │
    └────────────────────────┘
```

### 主引擎：多模态 AI 视觉分析
- 零安装，即开即用
- 支持表格、公式、密集文字、多栏布局、视觉标记
- 输出 Markdown 或 JSON 结构化数据

### Fallback 引擎：本地 PaddleOCR.js
- 存量：Windows 主机 `C:\Users\Administrator\ocr-pipeline\`
- 无网络依赖，离线可用
- 适合简单文字、快速检索场景

## 使用方式

### 方式一：深度解析单张图片（主推荐）

对图片执行以下 prompt 模板：

```
请深度解析这张图片中的全部内容。要求：
1. 识别所有文字，包括小字号和密集文字；
2. 如果发现表格，用 Markdown 表格格式还原；
3. 如果发现公式，用 LaTeX 格式标注；
4. 如果发现清单/步骤/条目，用有序或无序列表还原；
5. 如果发现对比关系，说明对比维度；
6. 识别视觉标记（高亮、红框、颜色等）的语义含义；
7. 最终输出一份完整的结构化 Markdown 文档，保留原始层级和逻辑关系。
```

### 方式二：批量处理目录下所有图片

```bash
# 在 Hermes 中执行 Python 脚本
python scripts/batch_parse.py --input-dir "00_inbox/screenshots/" --output-dir "10_raw/parsed/"
```

### 方式三：整合进知识卡片

1. 获取解析结果 Markdown
2. 打开目标知识卡片 `30_wiki/concepts/<target>.md`
3. 将提取的表格、公式、清单、对比维度整合进卡片正文
4. 添加 `source_refs` 指向原始图片路径
5. 更新 `updated_at` 时间戳

## 故障排查

| 现象 | 原因 | 解决 |
|:---|:---|:---|
| 识别结果为空 | 图片过暗/模糊 | 提供更高清图片 |
| 表格列对齐错乱 | 复杂合并单元格 | 手动校对 Markdown 表格 |
| 公式识别不准 | 手写体/非标准符号 | 对照原图修正 LaTeX |
| 视觉标记未识别 | 颜色过淡 | 补充描述性 prompt |

---

## 限制

- 主引擎依赖网络连接（API 调用）
- 极复杂手写体识别率下降
- 超大图片（>4K）建议先裁切后识别
- 印刷体缺失字符可能被替换为近似字符
