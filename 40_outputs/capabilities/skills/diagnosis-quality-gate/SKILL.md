# KDO 诊断报告质量门控

> 方法论来源：小红书定位 skill（30→80分的核心不是"打分"——是每步硬约束+质量门控自检）

---

## ⚠️ Gotchas 前置（执行前必读）

在开始任何诊断之前，先加载 `references/diagnosis-common-pitfalls.md` 全文。这些是反复出现的错误模式——不是"可能犯"，是"已经犯过多次"。

速览：
1. 只看笔记不看口述稿 → 漏掉操作演示段落
2. 标注代替深挖 → 标记"case候选"≠理解了案例逻辑
3. 没有行号引用 → 结论无法溯源
4. 概念抽象不还原过程 → "人在环"写成术语而非 Truman 原话
5. 门禁通过=质量合格 → 七步法做完≠诊断完成

---

## 七步质量门控

⚠️ **硬约束：以下 7 步必须按顺序执行，不可跳过。每步末尾有质量门控，不通过则返回上一步重做。**

---

### Step 0：口述稿优先 + 操作演示扫描（2026-08-09 E024 升级 + 证据等级确立）

**证据等级（2026-08-09 用户确立）**：
- **一等·第一手**：口述稿（唯一第一手资料）
- **二等·二手解读**：笔记 / OCR / VLM / 汇编（全部是二手——VLM 的"校对"只是把截图读得更准，不是第一手）
- **规则**：①内容来源以口述稿行号为唯一主锚 ②OCR/VLM/笔记仅辅助定位与校对，不得作为内容主要来源 ③与口述冲突时以口述为准 ④口述无法核验的 VLM 内容 → 标注"二手来源"并降置信度

**动作**：
1. **逐字读口述稿全文**（分多次 Read 读完，含末尾 Q&A/闲聊）——**这是唯一路径，不可替代**
2. 跑 `python kdo-tools/scan-demo-sections.py <口述稿路径>` **仅用于索引定位**高价值段落，**不替代阅读**
3. 再读笔记对照补漏（笔记/OCR/VLM 只做"口述没有的东西"的补充线索，发现线索后回口述验证）

**⚠️ 质量门控 Step 0：**
- [ ] 口述稿**逐字全文**已读？（不是汇编/抽样——汇编是二次加工与笔记同级，E024 实证漏 40%+ 素材）
- [ ] scan-demo-sections.py 已执行（索引用）？
- [ ] 诊断报告里有没有至少一处"笔记没写但口述稿里有"的关键信息？
- [ ] 汇编内容与逐字读冲突时，以逐字读为准？

**不通过 → 重做 Step 0。**

---

### Step 1：全量素材目录 + 叙事段落扫描

**动作**：
1. 列出素材文件夹的完整文件清单
2. 扫描口述稿中所有"比如""举个例子""实操中"段落→标记为 case 候选
3. 操作演示段落（已标红）→最高优先级标注

**⚠️ 质量门控 Step 1：**
- [ ] 素材目录完整列出？
- [ ] 操作演示段落全部标注（对照 scan-demo-sections.py 输出）？
- [ ] 对照 `references/diagnosis-common-pitfalls.md` 第1条自检：有没有只看笔记的段落？

**不通过 → 返回 Step 0。**

---

### Step 2：跨课程同构映射

**动作**：
输出一张映射表：口述稿概念→一堂方法论来源→已有KDO卡→是否真缺口。

**⚠️ 质量门控 Step 2：**
- [ ] 映射表每一项都有关联的已有KDO卡？
- [ ] "真缺口"标记前已经验证了同构关系？
- [ ] 是否跳过了某个概念（只标了"框架概念"没标"操作演示"）？

**不通过 → 返回重做映射。**

---

### Step 3：自攻击逻辑

**动作**：
调用 self-attack framework，四路攻击后交付。

**⚠️ 质量门控 Step 3：**
- [ ] 四路攻击全部执行？
- [ ] 攻击报告里的🔴🟡问题已修复或标注为已知债务？
- [ ] 不能只攻击"概念"——攻击"标签是否合理""卡片数量是否恰当"？

---

### Step 4：一句话金矿扫描（暗知识）

**动作**：
通读口述稿全文，标记所有"停了一下"的句子。

**⚠️ 质量门控 Step 4：**
- [ ] 扫描结果按类型分类（操作心法/判断口诀/失败模式/反例/边界条件）？
- [ ] 每条暗知识都分配了已有卡或标记为"待建新域"？
- [ ] 对照 `references/diagnosis-common-pitfalls.md` 第4条自检：概念有没有还原到原素材里的人物和故事？

---

### Step 5：Before-After 对照 + 可复用模板抽象

**动作**：
1. 对每个操作演示段落，提取 Before（旧做法）、After（新做法）、为什么更好
2. 追问：通用部分能不能变成可复用的模板/skill/workflow？

**⚠️ 质量门控 Step 5：**
- [ ] Before-After 对照完整（缺一条=没深挖）？
- [ ] 有没有"看到龙虾，提取7步配置模板，而不是记住龙虾"？
- [ ] 对照 `references/diagnosis-common-pitfalls.md` 第3条自检：结论有没有附口述稿行号？

---

### Step 6：填空模板验证

用以下模板自检诊断报告的完整性：

> 本素材的核心洞察是___，和已有方法论___的关系是___，最容易被漏掉的暗知识是___，可迭代为 skill/workflow/agent 的是___。

**⚠️ 质量门控 Step 6：**
- [ ] 四个空全部非空，且各有≥2句实质内容？
- [ ] "核心洞察"不能是"这个素材讲了双三角"——必须是"这个素材在X处发现了Y的新模式"
- [ ] "最容易被漏掉"必须有口述稿行号支撑？

---

### Step 7：最终自检

**⚠️ 最终门控（提交前必过，缺一不可）：**

- [ ] 口述稿全文已读？（Step 0）
- [ ] 所有操作演示段落已标出？（Step 1）
- [ ] 行号引用完整？（Step 5）
- [ ] 每条结论可溯源到口述稿？
- [ ] 填空模板四空全部非空？（Step 6）
- [ ] Gotchas 全程对照自查？

**不通过 → 不得提交。返回失败步骤重做。**

---

## 使用方式

王语嫣在诊断报告提交前，加载本 skill，按七步质量门控逐项自检。不通过=不得提交。
