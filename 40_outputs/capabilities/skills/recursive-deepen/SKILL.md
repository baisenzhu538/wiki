# 递归深挖法 — 三反馈飞轮与辩证收敛

> **实战验证**：黄药师 2026-06-02 用八小时完成四次认知跃迁——从"KDO 80%完成度"到"四个死刑"到"Sprint 6方案"到"写给欧阳锋的技术提案"。每一轮深挖的产出成为下一轮深挖的起点。
>
> **核心洞见**：不是所有真理都在表面。多次迭代的自我解剖，比单次分析深至少一个数量级。

---

## 什么时候用

| 适用场景 | 不适用场景 |
|:---------|:-----------|
| 需要独立判断的复杂问题（不是转述已有知识） | 已有明确标准答案的问题（查文档即可） |
| 系统性诊断——"为什么做得不对" | 纯执行型任务（照着 SOP 做就行） |
| 框架反照自身——"用这个框架看我们自己" | 纯信息提取（三步编译法已够） |
| 争议/张力/边界不清的话题 | 已被充分论证的老话题 |

---

## 核心模式：三反馈飞轮

每一轮深挖分三步：

```
[触发] 一个话题/问题/框架
   ↓
[反馈×3] 从三个不同角度解剖
   ├── 反馈1：某维度
   ├── 反馈2：另一维度
   └── 反馈3：再一维度
   ↓
[深挖] 对每条反馈追问"所以呢？这意味着什么？根因是什么？"
   ↓
[产出] 本轮结论（成为下一轮的触发）
   ↓
[检查] 还有没有新东西？有→回到[反馈×3]。没有→收敛，停止。
```

---

## 五种反馈框架（选一个即可）

递归深挖需要"每一轮用不同角度切同一个问题"。以下是几个经过验证的反馈框架：

### 框架 A：三层解剖法（黄药师专用）

对任何问题，拆三层：

```
证据层：事实是什么？（数据、文件、代码行）
根因层：为什么会这样？（系统结构、流程设计、假设前提）
修复层：怎么修？（具体动作、成本、优先级）
```

### 框架 B：四死刑法（Truman 五层映射）

把任意框架映射到自己身上，逐层问"我们做到第几层了"：

```
和我自己的系统逐层对仗
  → 哪几层活着？（能跑）
  → 哪几层残废？（能跑但只做了一半）
  → 哪几层死亡？（不存在或断裂）
  → 最致命的那一层根因是什么？
```

### 框架 C：Judge 三问（深度合成产线）

来自四步编译法的 Judge 环节：

```
自我应用：用这个框架反照自己，发现了什么缺口或矛盾？
边界判断：这个框架在什么场景下不成立？我不同意原作者的哪个观点？
转换叙事：从旧认知到新认知的过程中，哪个瞬间让我的判断发生了不可逆的改变？
```

### 框架 D：ADUCIT 逐环诊断

```
A（预判）→ D（识别）→ U（收集）→ C（分类）→ I（加工）→ T（追踪/反馈）
逐环问：这一环在我们系统里是活着、残废、还是死亡？
```

### 框架 E：辩证对偶

找出话题的核心张力，在两端之间摆动：

```
肯定（它的正确之处）←→ 否定（它的错误之处）←→ 综合（新的判断）
每一轮综合成为下一轮肯定的起点
```

## 收敛条件

递归不能无限深下去。满足以下任一条件即可收敛：

| # | 条件 | 示例 |
|:-:|:-----|:------|
| 1 | 下一轮深挖产出的新信息量 < 上一轮的 10% | "这个根因已经在上一轮说过了" |
| 2 | 修复路径已经具体到可执行级别 | "2h，零件已就绪，只需串起来" |
| 3 | 已经用框架反照自身完成至少一次 | "KDO 的 424 张卡没有一个问过'AI 未来怎么用'" |
| 4 | 明确知道"再往下挖需要新信息进来" | "需要等 Pilot 跑完才知道 9 维在生产中的表现" |

---

## 收敛后的产出规范

收敛后，产出必须包含：

```markdown
## 诊断
[核心发现——一句话穿透]

## 三层证据
- 证据层：[具体事实]
- 根因层：[为什么]
- 修复层：[怎么办 + 成本]

## 开放问题（可选）
[哪些问题需要新信息才能回答——作为下一轮深挖的触发条件]
```

## 典型迭代轨迹

| 轮次 | 触发 | 反馈框架 | 产出 | 驱动源 |
|:----:|:-----|:---------|:-----|:-------|
| 1 | 一个话题/问题 | 任选反馈框架 | 表面分析 | 外部触发 |
| 2 | 轮1的产出 | 同一或不同框架 | 根因分析 | 半自驱 |
| 3 | 轮2的产出 | 反照自身 | 自我诊断 | 自驱 |
| 4 | 轮3的产出 | 工程化提案 | 可执行方案 | 完全自驱 |

**关键跃迁**发生在第 3 轮——当分析对象从"外部问题"变成"自己"的时候。在那之前，产出的是笔记；在那之后，产出的是判断。

---

## 禁止事项

| # | 禁止行为 | 原因 |
|:-:|:---------|:------|
| 1 | 用这个方法来分析已有标准答案的问题 | 浪费递归能力。三步编译法就够了 |
| 2 | 收敛前把中间产出发给决策者 | 中间产出是思考过程，不是结论。收敛后的才是 |
| 3 | 一个话题飞了 5 轮以上还不收敛 | 要么框架选错了，要么话题本身不清晰。强制收敛 |
| 4 | 只分析别人，不分析自己 | 第 3 轮的反照自身是整条方法论的灵魂。跳过它 = 笔记不是判断 |
