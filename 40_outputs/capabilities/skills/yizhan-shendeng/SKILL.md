# 一盏神灯（小白友好的蒸馏术）

> 复刻自袋鼠帝视频《蒸馏就是AI时代的合法抢劫》（2026-08-19 偶遇采集入库，`case-wechat-e7536bf1d8f1a7b1`）。
> 定位：**仓颉 cangjie-skill 的新手适配版**——仓颉适合已读懂原书的人（重型 RIA-TV++ 七阶段流水线）；
> 一盏神灯增加"AI 帮你阅读、整理、总结"前置环节，并简化为 WorkBuddy 小白可直接使用的流程。

## 何时用我 vs 用仓颉

| 你的状态 | 用哪个 |
|:--|:--|
| 还没读懂这本书 / 没时间精读 | **一盏神灯**（先带读，再蒸馏） |
| 已读完且有相当认知，要最重质量的蒸馏 | 仓颉 `cangjie-skill`（全流水线+压力测试） |

## 工作流程

### 阶段 0 · AI 带读（一盏神灯独有加法）

不假设用户读过原书。先产出三样东西帮用户建立认知：
1. **结构地图**：全书/全文的章节结构与主线逻辑（一页纸）
2. **核心概念表**：关键术语逐个一句话解释
3. **章节要点**：每章一条"这章解决什么问题"

带读产出先给用户过目，再继续——用户看不懂的章节可以追问，AI 讲到懂为止。

### 阶段 1 · 分型定向

| 原材料类型 | 蒸什么 | 蒸馏目的 |
|:--|:--|:--|
| 工具书（方法论导向） | **方法论** | 遇到问题时，直接用书里的方法解决 |
| 非工具书（认知导向） | **作者的思维框架** | 遇到问题时，用作者的框架思考找办法 |
| 论文/会议记录/访谈/课程 | 同理——能提供方法论或思维框架的都可蒸 | 同上 |

### 阶段 2 · 提炼候选

从原文提取候选单元（参考仓颉 extractors 五路）：**框架 / 原则 / 案例 / 反例 / 术语**。
轻验证两条（仓颉三重验证的简化版）：
- 原文中至少有依据（不编造，出处可溯到章节）
- 不是常识（"要努力"这种不算技能）

### 阶段 3 · 构造技能包

每个高价值候选 = 一个独立 Skill，结构：
- **使用场景**（什么时候该用它——最重要，用户只关心这个）
- 输入 → 步骤/框架 → 输出模板 → 常见误用与边界
- 末尾标注来源原材料与章节

### 阶段 4 · 安装与交付

1. 写入 `~/.workbuddy/skills/<主题>-<方法>/SKILL.md`
2. 向用户交付**使用指南**：蒸出了几个技能包、分别是什么、**什么时候用哪个**——
   用户不读 Skill 全文也能选对技能，做不到这一点 = 蒸馏不合格
3. 后续使用：新建任务直接描述需求即可自动匹配；也可在 + 号 → 技能 里手动指定

## 重要规则

- 蒸馏 ≠ 抄书：只保留可操作的精华，禁止大段复制原文
- 每个技能包可独立使用，不依赖用户读过原书
- 出处可溯：每条方法论标注原材料章节位置
- 原材料不足以支撑蒸馏时如实告知，不硬凑数量
- 复杂/大部头/高价值原材料：主动建议升级走仓颉全流水线（带压力测试）
