来源：XS01-5小时吃透小红书（厦九九 著）

## 模型M01：SPRM模型（优势能力定位模型）— B级

**四要素交集找优势能力圈：**

| 要素 | 含义 |
|------|------|
| S - Strengths（能力） | 知识、技能或通用能力。大S=天赋，小S=后天培养 |
| P - Passion（热情） | 特别感兴趣、哪怕不赚钱也愿意做的事 |
| R - Resources（资源） | 人际关系、渠道、环境、地域等 |
| M - Market（市场） | 市场需求大小、变现能力强弱 |

**操作四步：**

1. **盘点SPR**：将能力(S)、热情(P)、资源(R)分别写在三个圆圈中（"优势能力三叶草"）
2. **转动三叶草取交集**：从能力出发，用热情收敛→划掉没热情的能力 → 用资源收敛→划掉没资源支撑的能力 → 三者交集=优势能力圈
3. **市场验证**：三个检验问题——是否与趋势一致？是否有成功案例？需求是否未被满足？
4. **形成定位结论**：填空模板——

> 基于我的___优势能力，我为___（用户）提供___（内容/产品/服务），让他们在___情境下，解决___痛点，获得___（收益）。

**注意事项：**
- 能力型人：S→(P→R)，从能力出发；资源型人：(S←P)←R，从资源出发
- 大S（天赋）优先于小S（后天学习）
- M验证不通过则换方向

**作者示例（厦九九）：**
> 基于我8年跨行业品牌营销和6年自媒体运营经验，我为职场人、宝妈、创业者提供自媒体和个人品牌打造课程，让他们在想通过自媒体变现时，解决不会做内容、没流量、无法变现等问题。

## 模型M02：人设定位公式（五要素模型）— ⭐A级核心

**五要素：**

| 要素 | 定义 | 关键问题 |
|------|------|----------|
| ①身份定位 | 职业身份或生活身份 | 你是做什么的？ |
| ②价值定位 | 输出什么内容、为谁提供什么价值 | 你提供什么价值？ |
| ③形式定位 | 图文还是视频，什么呈现形式 | 你用什么形式表达？ |
| ④人格定位 | 呈现出的人格特质 | 你给人的印象是什么？ |
| ⑤记忆点 | 独特的品牌符号 | 用户凭什么记住你？ |

**一句话定位模板：**
> 一个___（人格）___（身份）用___（形式）分享___（价值），我的记忆点是___。

**记忆点的6种设置方法：**
1. 个人形象与服道化：固定风格、特定场景物品
2. 语言动作：口头禅/口号+固定手势
3. 人物：固定配角/双胞胎出镜
4. 音乐：固定出场音乐
5. 主题/系列：系列化内容主题
6. 内容模式：固定的内容架构和剪辑节奏

**操作步骤：**
1. 先用SPRM模型确定价值定位
2. 从身份、价值出发推导其他要素
3. 检查五要素是否互不矛盾（尤其身份与价值是否契合）
4. 填空形成一句话定位
5. 将定位落地到IP人设五件套（名字/头像/简介/背景图/资料）

**验证标准：**
- 能否用一句话清晰描述？
- 用户听完能否立刻知道你是做什么的？
- 五要素之间是否有冲突？
- 记忆点是否独特到能在同类博主中脱颖而出？

## 模型M03：号设一体原则 — B级

**核心定义：** 号设一体 = 账号分享的内容与博主要传递的人设相符

**核心逻辑链：**
```
人设定位(设计) → 账号内容(执行) → 用户感知(认知)
     ↑                                      ↓
     └──────── 一致性反馈环 ←──────────────┘
```

一致性高 → 信任建立 → 关注+变现
一致性低 → 信任崩塌 → 流失用户

**验证清单：**

| 检查项 | 通过标准 |
|--------|----------|
| 身份定位 vs 价值定位 | 身份是否为价值提供背书？ |
| 内容方向 vs 人设定位 | 所有内容是否围绕人设展开？ |
| 封面风格 vs 人格定位 | 视觉调性是否统一？ |
| 简介信息 vs 实际输出 | 承诺的内容是否在持续输出？ |
| 五件套 vs 整体品牌 | 名字/头像/简介/背景图/资料是否协调？ |

**新手 vs 高手：**

| | 新手 | 高手 |
|---|------|------|
| 内容 | 杂乱 | 垂直聚焦 |
| 人设 | 单一/模糊 | 真实丰富 |
| 信任感 | 弱 | 强 |
| 可持续性 | 低 | 高 |

## 模型M04：人设洋葱模型 — C级

**三层由内而外：**

```
    ┌─────────────────────────┐
    │     外在形象（最外层）      │ ← 用户直接看到的内容和形象
    │  ┌───────────────────┐  │
    │  │  能力资源（中间层）  │  │ ← 你凭什么提供这些价值
    │  │  ┌───────────┐    │  │
    │  │  │ 核心价值  │    │  │ ← 你提供什么价值
    │  │  │ （最内层） │    │  │
    │  │  └───────────┘    │  │
    │  └───────────────────┘  │
    └─────────────────────────┘
```

| 层次 | 内容 | 作用 |
|------|------|------|
| 核心价值（最内层） | 你为用户提供什么价值 | 决定内容方向和变现空间 |
| 能力资源（中间层） | 经验、技能、背书、资源 | 支撑核心价值的可信度 |
| 外在形象（最外层） | 用户看到的内容、形象、调性 | 用户感知的第一触点 |

**验证方法：** 从外到内追问——外在形象是否准确传达了核心价值？能力资源是否足以支撑核心价值的承诺？三层之间是否有断裂或矛盾？

> 只有能击穿三层的人设，才是真实靠谱、有巨大商业价值的IP人设。
