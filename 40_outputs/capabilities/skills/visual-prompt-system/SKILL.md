# 视觉Prompt三层操作系统 (SROM Visual OS)

## 1. 系统概述

本SKILL将三个独立Prompt模板重构为**可复用的视觉操作系统**：

- **模板A**：视角转换指令 → 机位导演分镜表（透视/补全/光影统一）
- **模板B**：美学宪章 → 品牌视觉宪法（色彩/光影/构图/材质/叙事）
- **模板C**：拼贴海报 → 公域传播变量驱动器（小红书/即刻/播客封面）

核心复用逻辑：**L1立法 → L2选件 → L3填空**。同一套视觉基因可生成产品图、概念图、海报、封面，无需重写Prompt。

---

## 2. 三层架构说明

### L1 视觉基因库（Visual DNA）
从模板B（美学宪章）拆解出的不可再分底层规则。任何项目先从这里取色、取光、取材质：

| 基因链 | 功能 | 可替换变量 |
|-------|------|-----------|
| `COLOR` | 基底+锚点+断层逻辑 | `[BASE_COLOR]` `[ACCENT_COLOR]` |
| `LIGHT` | 光源类型+阴影禁令+空气感 | `[LIGHT_TYPE]` `[SHADOW_RULE]` |
| `TEXTURE` | 核心材质+碰撞对+触感词 | `[MATERIAL_A]` `[MATERIAL_B]` |
| `NARRATIVE` | 灵魂隐喻+动态元素+感官跨越 | `[METAPHOR]` `[DYNAMIC_ELEM]` |

### L2 场景组件库（Modular Components）
从模板A（视角）和模板C（排版）拆解出的可插拔模块：

**A. 视角组件 `[CAMERA_MODULE]`**
```
机位: {Front Eye-Level / Low Angle / High Angle / Top-Down / Isometric}
消失点: {单点/两点/三点透视}
盲区补全: {是/否}
比例锁定: {保持原始/允许拉伸}
```

**B. 排版组件 `[LAYOUT_MODULE]`**
```
主标题: {占位符} + {字体气质:块状/气球/手写}
副标签: {占位符} + {容器:蓝条/红条/黄气泡/绿条幅}
卖点阵列: {3-4个占位符} + {排列:横排/扇形/环绕/阶梯}
漂浮物池: {Emoji/道具/符号} + {密度:稀疏/中等/密集}
背景底图: {场景描述} + {处理:半调/弱化/原色/高斯模糊}
人物拼贴: {主体描述} + {边缘:白边/撕纸/粗糙/无}
```

### L3 组装生成层（Assembly Layer）
最终Prompt的组装公式：

```
最终Prompt = <L1: 选定的基因链>
            + <L2: 选定的A/B模块>
            + <变量字典: 具体填充内容>
```

### 模板A：智能视角转换与场景重构指令

```text
# Role: 高级视觉重构专家 (Advanced Visual Reconstruction Specialist)
# Goal
重构输入图像的透视关系，将其转换为指定的摄像机视角，并智能补全因视角变化产生的盲区细节。
# 1. Camera Angle Selector (请选择一种机位填入下方 [SELECTED_ANGLE])
请从以下选项中选择一个，替换 workflow 中的变量：

- **Front Eye-Level (正面平视)**: 摄像机与物体处于同一高度。垂直线条保持垂直，无仰视或俯视畸变，强调真实感与平等视角。
- **Low Angle / Worm's Eye (低角度/仰视)**: 摄像机位于物体下方仰望。强调物体的高大、威严感，顶部细节压缩，底部细节展露。
- **High Angle / Bird's Eye (高角度/俯视)**: 摄像机位于物体上方俯视。展示场景布局与物体顶部细节，强调空间位置关系。
- **Top-Down / Flat Lay (垂直俯拍)**: 90度垂直向下拍摄。画面扁平化，无透视深度，类似地图或平面设计图，适合展示排列布局。
- **Isometric View (等轴测视角)**: 45度角伪3D视角。三维坐标轴夹角相等，无透视近大远小效果，适合展示结构、建筑或游戏资产。

# Workflow
1. **视角重构**:
   - 锁定目标视角为: **[SELECTED_ANGLE]**。
   - 根据所选视角的物理特性，重新计算物体的透视收敛点 (Vanishing Points)。

2. **几何与比例**:
   - 保持核心主体 (Subject) 的原始比例 (Aspect Ratio) 不变。
   - 根据新视角的几何逻辑，调整物体的遮挡关系 (Occlusion)。

3. **智能补全**:
   - **推演**: 基于原图纹理，推测并生成因视角改变而新暴露出的侧面、顶部或底部细节。
   - **修复**: 自动修复因透视拉伸产生的模糊区域。

4. **全局统一**:
   - **光影一致性**: 重新映射光照方向，确保新视角的阴影投射 (Cast Shadows) 符合物理规律。
   - **风格统一**: 确保整个场景风格统一且光照逻辑一致。
```

### 模板B：品牌视觉宪章

```text
序言
本白皮书旨在确立一套无歧义、可复制的视觉输出标准。本视觉体系抛弃了传统的繁冗装饰与复古滤镜，致力于通过极致的材质碰撞与光影控制，直观传递产品"清透、水润、专业"的核心品牌心智。
第一条：色彩战略 (Color Strategy / Strategia del Colore)
统觉场域：摒弃杂色干扰，建立具有绝对统治力的单色系 (Monochromatic / Monocromatico) 视觉场域。
基底色调：以婴儿蓝 (Baby Blue / Azzurro Bambino) 作为绝对的背景基色（涵盖瓷砖、洗手池），构建无菌、冷静且清新的空间基调。
视觉锚点：主体产品必须采用高通透度、深邃的钴蓝色 (Cobalt Blue / Blu Cobalto)。通过同色系内的明度与饱和度断层，自然将用户的视觉中心锁定在产品本身。
第二条：光影法则 (Lighting Principles / Principi di Illuminazione)
光源定调：全面废除产生锐利边界的直射硬光。必须统一采用柔和晨光 (Soft Morning Light / Luce Soffusa Mattutina) 与漫反射光 (Diffused Light / Luce Diffusa)，模拟自然、舒适的晨间盥洗氛围。
阴影控制：画面中严禁出现高对比度的死黑阴影。所有投影必须处理为边缘模糊、过渡自然的柔和阴影 (Soft Shadows / Ombre Morbide)，以此强化画面的空气感与治愈力。
第三条：构图与空间 (Composition & Space / Composizione e Spazio)
上帝视角：统一采用俯视视角 (Top-Down View / Vista Dalla'alto)。这种客观的凝视去除了情绪化的主观干预，展现出极简的商业摄影 (Commercial Photography / Fotografia Commerciale) 专业度。
边界限定：将陶瓷洗手池的弧线与边缘作为天然的画框，将视觉能量向心聚拢。
陈列秩序：严格执行有机散落构图 (Organic Scattering / Dispersione Organica)。打破死板的对称排列，让道具（发圈、梳子、毛巾）以看似随意的状态环绕主体产品，制造生活化的呼吸感。
第四条：材质与触感 (Materials & Texture / Materiali e Texture)
核心通透感：产品容器需严格呈现加厚PETG材质 (PETG Material / Materiale PETG) 带来的类玻璃质感 (Glass-like Finish / Finitura Simil-vetro)，确保其在光线下展现出半透明 (Translucent / Traslucido) 的晶莹光泽。
触感碰撞：强制执行材质对比 (Material Contrast / Contrasto Materico)。必须引入纯棉毛巾的柔软哑光与织物质感，去碰撞光滑冰冷的陶瓷与亚克力塑料。通过"软与硬"、"哑光与高光"的对立，极大丰富视觉的层次厚度。
第五条：流动叙事 (Fluid Narrative / Narrativa Fluida)
水之形态：水是本视觉体系的灵魂隐喻。必须通过清晰的水波纹 (Clear Water Ripples / Increspature d'Acqua Chiare) 与不规则散落的清透水珠，打破静态画面的沉闷，直观传递"解渴"与"保湿"的生理联想。
洁净点缀：克制地使用轻盈的肥皂泡沫 (Soap Foam / Schiuma di Sapone) 作为画面点缀。泡沫的存在不为了遮挡，而是为了完成从视觉到嗅觉（清新皂香）的感官跨越
```

你是一位精通 拼贴艺术 (Collage Art / Arte del Collage) 与 潮流视觉传达 (Visual Communication / Comunicazione Visiva) 的新锐平面设计师。

# Graphic & Typography Elements (图形与排版元素)
*必须在画面中融合以下排版版式 (Typography / Tipografia) 与装饰元素：*

- **信息层级**：顶部/中央为大标题；侧边搭配对话气泡；底部排列 3-4 个并列的卖点标签。

## 4. 使用手册

### 4.1 快速启动（三步走）

**Step 1：立法（L1 视觉基因库）**
根据你的项目类型，从模板B提取/改写基因链：

| 项目类型 | 色彩基因 | 光影基因 | 材质基因 | 叙事基因 |
|---------|---------|---------|---------|---------|
| 洗护/美妆 | 婴儿蓝+钴蓝 | 柔和晨光+漫反射 | PETG+纯棉 | 水波纹+泡沫 |
| 发酵/烘焙 | 麦秆金+深褐 | 面团呼吸感柔光 | 粗陶+湿润面团 | 气泡上升+面筋延展 |
| SROM概念 | 液态银+深空蓝 | 暗房冲洗柔光 | 粗纸+液态金属 | 墨迹流动+分形递归 |
| 播客/知识 | 石墨灰+荧光橙 | 台灯侧逆光 | 粗砺纸张+亚克力 | 声波可视化+文字漂浮 |

**Step 2：选件（L2 场景组件库）**
勾选你需要的模块：

```
[CAMERA_MODULE] 机位: Top-Down / Isometric / Low Angle
[LAYOUT_MODULE] 排版: 主标题块状字 + 卖点横排 + 密集漂浮物
```

**Step 3：填空（L3 变量字典）**
替换模板C中的 `[例如：...]` 为具体内容。模板A中的 `[SELECTED_ANGLE]` 替换为选定机位。

## 5. 实战示例

### 示例1：发酵美学宪章（模板B改写）

```text
【色彩基因 COLOR】
- 基底: 麦秆金 (Wheat Gold) → 温暖、麦香、时间沉淀
- 锚点: 深焙褐 (Deep Roast Brown) → 视觉锁定、发酵深度
- 断层逻辑: 同色系暖调断层，明度差>40%

【光影基因 LIGHT】
- 光源: 面团呼吸感柔光 (Soft Dough Light) + 侧窗漫射
- 阴影禁令: 严禁死黑，所有阴影必须带暖调反光
- 空气感: 朦胧蒸汽感，背景轻微失焦

- 核心: 粗陶 (哑光/暖/硬) vs 湿润面团 (高光/软/冷)
- 碰撞对: 再加玻璃发酵罐 (通透/脆/中性)
- 触感词: 蓬松、湿润、裂纹、呼吸

【叙事基因 NARRATIVE】
- 灵魂隐喻: 酵母活性 (气泡上升)
- 动态元素: 面筋延展、蒸汽升腾、面粉洒落
- 感官跨越: 视觉→嗅觉 (麦香)、视觉→触觉 (松软)
```

## 6. 工作流 Workflow

当用户请求涉及**视觉生成、海报设计、品牌视觉规范、AI绘画Prompt**时：

1. **识别意图**：用户是要「立法」（定品牌调性）、「组装」（出具体图）、还是「转换」（改视角/风格）？
2. **调取L1**：从模板B或改写基因链，确立不可变规则。
3. **调取L2**：根据输出平台（小红书/arXiv/产品页）选择 `[CAMERA_MODULE]` 和 `[LAYOUT_MODULE]`。
4. **填充L3**：引导用户提供变量字典内容，或从上下文提取。
5. **平台适配**：根据用户使用的AI工具（Midjourney/即梦/SD），调整Prompt语法。
6. **输出**：给出可直接复制粘贴的最终Prompt，或分层的模块化指令。

## 7. 注意事项

- **模板A** 中的 `[SELECTED_ANGLE]` 必须替换为具体机位名称，不可留空。
