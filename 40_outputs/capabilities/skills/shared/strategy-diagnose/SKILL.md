# 战略九问题诊断

冉鹏总结——战略最常见的九个失败原因。不是"战略不好"，是卡在了某个具体问题上。

## 九问题速查

| # | 问题 | 症状 | 经典案例 |
|:--|:--|:--|:--|
| 1 | **方向迷失** | 不知道往哪走 | 长尾化妆品公司——天花板低但继续投营销，应拓展新品类 |
| 2 | **目标错误** | 定了错的目标 | 精品超市O——高速增长期追求利润而非增长 |
| 3 | **定位模糊** | 不知道为谁服务 | 清洁用品公司——盲目高端定位丢失低端市场 |
| 4 | **路径错误** | 路选错了 | 家电公司G——重渠道轻研发导致非空调业务失败 |
| 5 | **共识不足** | 高层各想各的 | IT公司H——多方向反复横跳，市值下降 |
| 6 | **组织僵化** | 组织不适应新战略 | 手机公司N——传统工业组织难应对互联网化 |
| 7 | **能力缺失** | 没能力执行 | 国产手机L——缺乏软件生态能力 |
| 8 | **资源短缺** | 钱/人/时间不够 | 视频平台B——内容版权少导致转型失败 |
| 9 | **机制背离** | 激励和战略相反 | 飞机制造公司——重进度成本轻安全，背离战略底线 |

## 诊断流程

```
战略推不下去？
  ↓
逐项过九问题（一个一个排除——不是"都有点"，是"最主要的是哪个"）
  ↓
找到主因 → 对症下药
  ↓
找不到主因？→ 回 `/strategy-brm` Step 1：先做差距分析
```

## 常见症状 → 根因映射

| 你看到的现象 | 最可能的根因 |
|:--|:--|
| "定了战略但没人执行" | #6 组织僵化 或 #9 机制背离 |
| "团队对方向有分歧" | #5 共识不足 |
| "执行了但效果不好" | #4 路径错误 或 #7 能力缺失 |
| "不知道问题在哪" | #1 方向迷失 → 回 BRM 差距分析 |
| "战略很好但资源不够" | #8 资源短缺 或 #2 目标错误（目标太大） |

## 90% 公司无战略部——那谁来诊断？

冉鹏指出三个悖论之一：90% 公司无战略部。这意味着战略诊断通常由一号位自己或外部咨询顾问完成。本诊断卡可以作为一号位的自检清单——不需要战略部，逐项过一遍就能定位大多数战略问题。
