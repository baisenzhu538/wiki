# 五步法 Step 5: 壁垒

验证壁垒是否存在、多深、能守多久。

## 核心框架

### 壁垒类型
| 类型 | 示例 | 可持续性 |
|:--|:--|:--|
| **网络效应** | 微信/淘宝——用户越多价值越大 | 🔵 极强 |
| **规模经济** | 制造业——规模大成本低 | 🟡 中 |
| **品牌/信任** | 奢侈品/医疗 | 🟡 中 |
| **切换成本** | 企业软件/银行 | 🔵 强 |
| **数据壁垒** | 搜索引擎/推荐系统 | 🟡 中 |
| **政策/牌照** | 金融/医疗/教育 | 🔵 强但不稳定 |
| **技术专利** | 制药/芯片 | 🔵 强但有时限 |

### 壁垒测试
1. 如果竞对拿 1 亿来打你，能守住吗？
2. 如果大厂做了同样的产品，用户会走吗？
3. 你的壁垒随时间变强还是变弱？

### 假壁垒识别
| 假壁垒 | 为什么不成立 |
|:--|:--|
| "我们先发优势" | 先发不一定是优势——后来者可以抄 |
| "我们团队强" | 团队可以被挖 |
| "我们有数据" | 数据壁垒需要规模+独家+积累时间 |
| "我们技术好" | 技术差距随时间缩小 |

## 关键判断

| 信号 | 结论 |
|:--|:--|
| 3 个测试 2 个答不上 | 壁垒弱 |
| 壁垒随时间变弱 | 需要持续投入维持 |
| 只有一个壁垒 | 脆弱——需要多个壁垒叠加 |

## 产出
壁垒评估报告：壁垒类型+深度+可持续性+竞对威胁评估+综合结论
