# 挖掘式调研流程（穷尽手段+单点狙击行为化）

> 解决的核心问题：面对"这个信息太重要了，必须拿到"的单点关键情报（竞品真实成本、水下数据、核心假设验证），agent 不知道**该不该上挖掘式、手段从哪层开始、何时升级、合规红线在哪**。本 skill 是流程编排层——具体渠道工具在 research-core 武器库（OSINT/Dorking/爬虫/专家访谈），本 skill 不重复。
>
> 核心原则一句话：**穷尽手段不是"不择手段"，而是"在合法合规的底线之上，穷尽所有可用手段，拿到最高质量情报"。**

## 触发条件（何时进入本流程）

| 信号 | 示例请求 |
|:--|:--|
| 单点情报价值极高 | 「竞品的真实成本是多少」「这个数据必须拿到」 |
| 投资尽调 | 「帮我尽调这家公司」「风险画像」 |
| 核心假设验证 | 「用户到底愿不愿意付费，验证一下」 |
| 公开信息不够 | 「网上查不到，怎么办」「水下情报」 |
| 关键决策卡在一个数上 | 「拿不到这个数，决策做不了」 |

## 操作步骤（四步）

### 第零步（前置）：值不值得挖——决策重要性 × 手段层次矩阵

先回答：这个情报值多少钱？错过的代价多大？再选手段层次，**投入与信息价值必须匹配**：

| 决策重要性 | 建议手段层次 | 时间投入 | 成本投入 |
|:---|:---|:---:|:---:|
| 低（<10 万） | 第一层（公开信息） | 1-2 天 | 低 |
| 中（10-100 万） | 第一+第二层 | 3-5 天 | 中 |
| 高（100-1000 万） | 第一至第四层 | 1-2 周 | 高 |
| 极高（>1000 万） | 所有层次 | 2-4 周 | 极高 |

> 判定不划算 → 不进本流程：要么降级为简单查询，要么改走爆炸式/系统式建全景。

### 第一步：单点狙击——识别关键点

资源有限时不面面俱到，聚焦**最关键的一个问题**。四种识别方法：

| 方法 | 问题 | 示例 |
|:---|:---|:---|
| 假设排序 | 哪个假设最危险（错了项目直接失败）？ | 「用户不需要，项目直接失败」 |
| 影响评估 | 哪个问题影响最大？ | 「市场规模决定是否值得进入」 |
| 信息缺口 | 哪个信息最缺失？ | 「不知道竞品真实成本」 |
| 验证成本 | 哪个验证成本最低？ | 「用户访谈比技术验证快」 |

产出：关键点清单（影响程度×信息缺口×验证成本→优先级），**只选 top 1 作为狙击目标**。

### 第二步：设计狙击方案

五要素缺一不可（写进调研文档）：

1. **狙击目标**：要验证的具体问题（一句话）
2. **验证方法**：用哪 2-3 种**独立**方法交叉验证
3. **验证标准**：什么结果算通过（如">60% 用户愿意付费"——必须可判定，不写"看看情况"）
4. **时间计划**：多长时间完成
5. **资源需求**：需要什么人力/资金/工具

### 第三步：穷尽手段——五层升级逻辑

**从低难度层开始，信息不足才升级，不跳层、不提前上高风险手段**：

| 层 | 手段类别 | 典型手段 | 合规风险 |
|:--|:--|:--|:--:|
| 1 | 公开信息 | 官网/财报/新闻/报告/专利/招聘 | 低 |
| 2 | 半公开信息 | 招投标/工商信息/法院公告/融资披露/员工社交动态/用户评价 | 低-中 |
| 3 | 专家访谈 | 行业专家/从业者/前员工/供应商/竞品客户 | 中（注意保密义务） |
| 4 | 逆向工程 | 产品拆解/数据分析/ID 规律/爬虫抓取/API 分析 | 中-高（看清 robots/ToS/反爬法规） |
| 5 | 社会工程 | 假装客户/假装求职者/潜入社群/信息交换 | **高——最后一层，默认不启用** |

**升级判据（防"看过 3 份报告就说不足"）**：当前层已穷尽（该层主要渠道全查过+换过 ≥3 组关键词）且缺口仍在 → 才升一层。升级时在文档里记一句"第 N 层已穷尽，缺口是 X，升第 N+1 层"。

**第五层红线**：涉商业秘密获取、欺骗性身份接触、违反 ToS 的入侵性手段——默认不执行；确需执行前必须用户显式批准并留痕。合法合规（底线）永远优先于穷尽（努力拉满）。

### 第四步：交叉验证 + 全程记录

1. 每条核心情报 **≥2 个独立来源**交叉验证（走 `research-core` 第二层纪律 1，信源标 L1-L6）
2. 全程记录：怎么拿到的、来源可信度、可能偏差——"这个信息哪来的？"答不上来 = 记录缺失
3. 主动找反例：只看支持证据 = 验证不足；强制问"什么证据能推翻这个结论"
4. 拿到的数字标注验证状态：实测/引用/推演，不混写

## 反例黑名单（When NOT to Use）

| 场景 | 判词 | 改走 |
|:--|:--|:--|
| 简单查询（公开信息足够） | 浪费资源，第一层就能解决 | 直接搜，不进本流程 |
| 紧急决策（没有时间穷尽） | 只能用最快手段 | 快速查 + 标注信息风险 |
| 成本过高（穷尽成本>决策价值） | 投入产出比不成立 | 设成本上限或放弃，改用代理指标 |
| 法律风险（手段可能违法） | **立即停止升级** | 只用合法合规手段 |
| 道德风险（手段合法但不道德） | 声誉损失>信息价值 | 不执行，维护长期关系 |
| 要建全景认知（"完全不了解这个领域"） | 单点狙击解决不了宽度问题 | `research-explosion-five-step`（爆炸式） |
| 复杂决策需系统分析（多维度整合） | 无法单点突破 | OSCAR（`research-core` 第一层·系统式线） |

## 失败模式表

| 失败模式 | 真实信号 | 修复动作 |
|:--|:--|:--|
| 手段单一 | 只用公开信息、"看了几篇报告"就下结论 | 按矩阵对决策重要性，强制升到对应层次 |
| 关键点选错 | 完美验证了 A，但致命的是 B | 先快速扫描全部关键假设再排序，不直接跳进验证 |
| 过早升级 | 第 1 层没查透就上高风险手段 | 升级判据写进文档：当前层穷尽证据 + 缺口陈述 |
| 合规越线 | "这个手段有点灰色" | 立即停；第五层默认不启用，需用户显式批准 |
| 成本失控 | "调研花了 10 万"还没结论 | 回第零步矩阵核对投入上限，超限即止损 |
| 标准不清 | 验证标准写"看看情况" | 第二步五要素缺一不可，标准必须可判定 |
| 验证不足 | "根据 XX 报道..."单一来源下结论 | 强制 ≥2 独立来源 + 主动找反例 |
| 记录缺失 | "这个信息哪来的？"答不上 | 每条情报带来源+获取方式+可信度，可追溯 |
| 忽视时效 | 用 3 年前的数据支撑当期决策 | 核对时效：AI/监管/融资 ≤30 天，行业报告 ≤12 个月 |
| 团队能力不足 | "这个我们没做过"却硬上第 4/5 层 | 能力不够就停在能力内层次，或外包给专业方 |
