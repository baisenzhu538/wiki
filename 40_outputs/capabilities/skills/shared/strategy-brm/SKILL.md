# BRM 战略框架

冉鹏战略方法论的核心闭环：差距分析→战略规划→执行。

## 三步闭环

```
差距分析 ──→ 战略规划 ──→ 执行
   ↑                        │
   └────── 反馈修正 ←────────┘
```

## Step 1: 差距分析

**两种差距**：

| 类型 | 定义 | 示例 |
|:--|:--|:--|
| **业绩差距** | 内部目标 vs 实际结果的差 | 目标增长30%→实际15%=15%差距 |
| **机会差距** | 我们 vs 对手的差 | 竞对市占率25%→我们10%=15%差距 |

**分析顺序铁律**：先对事（业务指标）后对人（管理组织）。避免先归咎于人。

### 鱼骨图拆解

销售下降，按不同维度拆：
- 按单店×规模
- 按品类相加
- 按客户分类相加

利润下降，先看销售是否下降→再看成本是否上升。

### 组织问题分析顺序
能力结构→人手数量→意愿→架构→流程规则

### 管理问题分析顺序
流程规则→管理工具→文化→领导力

## Step 2: 战略规划

**战略五基本功**：

| 基本功 | 做什么 |
|:--|:--|
| **定式** | 使用 BRM 框架建立战略思考的定式 |
| **洞察** | 模型+图表+假设验证——速度+视野 |
| **布局** | 现金流业务/增长型业务/种子型业务/撤退/突破——五个方向 |
| **体系** | 构建完整生态系统，避免局部优化 |
| **变革** | 应对负面反馈，管理变革过程 |

**战略布局的五件事**：
1. 现金流业务（现在赚钱的）
2. 增长型业务（正在增长的）
3. 种子型业务（未来可能的）
4. 撤退（该放弃的）
5. 突破（跨越式机会）

## Step 3: 执行

**战略执行的最大挑战是变革管理，而非简单的任务分解。**

| 阶段 | 核心挑战 |
|:--|:--|
| 启动 | 高层共识——方向不一致后面全错 |
| 推进 | 组织形态适应——新战略需要新组织 |
| 持续 | 机制不背离——激励机制必须对齐战略目标 |

**转型的三种方式**：
1. **加外挂**：如 ERP 系统——不改核心，加能力层
2. **换路**：换客户/换市场——同一能力换场景
3. **换轮子**：进化商业模式——从根本上改变赚钱方式
