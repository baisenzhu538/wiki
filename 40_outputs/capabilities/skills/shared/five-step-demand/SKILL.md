# 五步法 Step 1: 需求分析

验证需求是否真实、市场是否足够大、用户是否愿意付费。

## 核心框架

### 需求三维度
| 维度 | 要回答的问题 | 工具 |
|:--|:--|:--|
| **真伪** | 这是真需求还是伪需求？ | 需求层次模型 |
| **大小** | 市场多大？天花板在哪？ | 市场规模估算四种方法 |
| **紧迫** | 用户现在就需要吗？ | 需求评估三角形 |

### 需求层次模型
```
真需求（愿意付费）> 伪需求（嘴上说要但不付费）> 衍生需求（其他需求的副产品）
```

### 市场规模估算
1. 自上而下：行业报告 → 细分市场
2. 自下而上：单客价值 × 潜在用户数
3. 对标法：类似公司/产品的市场规模
4. 替代法：替代品的市场有多大

## 关键判断

| 信号 | 结论 |
|:--|:--|
| 用户说"挺好的"但不付费 | 伪需求 |
| 市场 < 10 亿且增长 < 10% | 天花板低 |
| 用户现在在用替代方案 | 需求真实（有付费意愿） |
| 用户说"早就想要了" | 注意——可能只是礼貌 |

## 产出
需求验证报告：需求定义 + 用户画像 + 市场规模估算 + 真假判断 + 置信度
