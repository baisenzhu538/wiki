# BITCOE 提示词框架

基于王欢方法论。六要素写出高质量 AI 提示词。

## BITCOE 六要素

| 要素 | 含义 | 示例 |
|:--|:--|:--|
| **B**ackground | 背景：为什么要做这个？上下文是什么？ | "我是一个创业者，正在评估是否进入XX市场" |
| **I**nstruction | 指令：核心任务是什么？ | "请分析这个市场的竞争格局" |
| **T**ask | 任务：具体要完成什么？分几步？ | "第一步列出主要玩家，第二步对比他们的优劣势" |
| **C**onstraint | 约束：有什么限制？不要做什么？ | "只引用2024年后的公开数据，不要推测" |
| **O**utput | 输出格式：期望什么格式？ | "用 Markdown 表格，每个玩家一行，对比维度为列" |
| **E**xample | 示例：给一个参考范例 | "像这样：\| 公司 \| 市场份额 \| 优势 \| 劣势 \|" |

## 要素权重

不是所有要素都同等重要。按场景分配：

| 场景 | 重点要素 |
|:--|:--|
| 创意任务 | B(背景) > I(指令) > C(约束). E(示例)可选——太具体的示例会限制创意 |
| 分析任务 | I(指令) > C(约束) > O(输出). B 简明即可 |
| 执行任务 | T(任务) > O(输出) > E(示例). 越具体越好 |
| 写代码 | C(约束) > O(输出) > E(示例). 技术约束最关键 |

## 对比：好 vs 坏提示词

| 维度 | ❌ 坏 | ✅ 好 |
|:--|:--|:--|
| 背景 | "帮我分析一下市场" | "我是一家连锁药房的运营负责人，正在考虑是否进入线上药品零售" |
| 指令 | "写个方案" | "对比京东健康和阿里健康的线上药品零售模式" |
| 约束 | 无 | "只分析 OTC 药品，不含处方药。引用 2024-2025 年财报数据" |
| 输出 | 无 | "用表格对比：用户规模/品类数量/配送时效/客单价/复购率 五个维度" |

## 常见失败

| 症状 | 根因 | 修复 |
|:--|:--|:--|
| AI 输出太泛 | 缺 B(背景)或 C(约束) | 加背景上下文+具体约束 |
| AI 输出格式不对 | 缺 O(输出) | 明确指定输出格式 |
| AI 理解偏差 | 缺 E(示例) | 给一个参考范例 |
| 提示词太长 | 六要素全写了不分主次 | 按场景权重精简 |
