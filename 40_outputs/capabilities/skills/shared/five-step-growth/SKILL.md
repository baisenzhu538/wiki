# 五步法 Step 4: 增长

定义增长引擎——从 0 到 1 再 到 100 的路径。

## 核心框架

### 增长周期模型
```
启动期（0→1）  → 验证增长假设
成长期（1→10） → 找到可复制的增长模式
扩张期（10→100）→ 规模化增长引擎
```

### 增长引擎类型
| 引擎 | 驱动因素 | 适用 |
|:--|:--|:--|
| **付费增长** | 广告投放 ROI | CAC < LTV/3 |
| **内容增长** | SEO/社交媒体/内容营销 | 长尾关键词 + 复利 |
| **病毒增长** | 用户邀请用户 | 病毒系数 > 1 |
| **销售增长** | 销售团队扩张 | B2B 高客单价 |
| **产品增长** | 产品本身驱动（Slack/Zoom） | PLG 模式 |

### 增长飞轮
```
更多用户 → 更多数据 → 更好的产品 → 更多用户
```

## 关键判断

| 信号 | 结论 |
|:--|:--|
| 北极星指标不明确 | 增长无方向 |
| 单一渠道依赖度 > 80% | 渠道风险 |
| 用户留存率 < 40%（月） | 漏桶——先修留存再拉新 |

## 产出
增长策略：北极星指标 + 增长引擎选择 + 渠道组合 + 里程碑
