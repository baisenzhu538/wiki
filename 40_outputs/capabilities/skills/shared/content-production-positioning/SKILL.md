# 内容差异化定位（Step 1-2）

Candy 九步法第 1-2 步。先建参考系，再回答"凭什么存在"。

## Step 1: 搭参考系（不要急着写）

| 动作 | 具体做法 |
|:--|:--|
| 找同类内容 | 别人怎么写这个主题的？ |
| 找原始素材 | 原文、译本、数据源 |
| 找相邻内容 | 相近主题的已有内容 |
| 找讨论记录 | 相关讨论、反馈、提问 |

**输出**：参考系文档——列出所有关键来源 + 核心观点。

**自检**：是不是遗漏了关键来源？

## Step 2: 差异化定位（四象限画布）

### 定位四问
1. 已经有谁写过同类内容？
2. 他们覆盖了什么？没覆盖什么？
3. 我能提供什么他们没提供的？
4. 如果听众只记住一句话，是这句吗？

### 四象限画布
```
           相同点
             ↑
  已有内容   |  我的内容
   ←————————+————————→
             |
             ↓
           差异点
```

| 象限 | 问自己 |
|:--|:--|
| 左上 | 已有内容在哪些方面做得不错？ |
| 左下 | 已有内容在哪些方面有缺失？→ **这是你的机会** |
| 右上 | 我的内容和已有内容在哪些方面一致？（不是差异化） |
| 右下 | 我在哪些方面能提供独特的价值？→ **核心竞争力** |

### 定位一句话
```
这篇内容的核心差异是：[一句话]
它不是 [已有内容A]，也不是 [已有内容B]。
它独特在 [X]。
```

## 常见失败

| 症状 | 根因 | 修复 |
|:--|:--|:--|
| 写了一半发现和别人撞车 | 跳过 Step 1 参考系 | 回 Step 1：先看别人写了什么 |
| 内容没特色 | Step 2 定位模糊 | 重做四象限——差异点要具体 |
| 写完了不知道给谁看 | 没做定位一句话 | 用一句话说清"对谁有用" |
