# 需求盲区扫描

用 2B/2C 全量字典逐维扫描——防止"我以为我拆完了但其实漏了关键视角"。

## 2B 盲区检查清单

### 用户维度

| L | 维度 | 检查项 |
|:--|:--|:--|
| L1 | 业务类型 | 面向客户(2B/2C/2G)？产品型/服务型？线上/线下？是否连锁？ |
| L2 | 规模性质 | 行业细分？传统/新兴？市场份额？企业营收？员工数？企业性质？地域？ |
| L3 | 标准程度 | 数字化水平？标准化程度？供应链标准？ |
| L4 | 决策文化 | 个人决策/部门决策/委员会？决策角色6类？切换成本？组织文化类型？ |
| L5 | 财务特征 | 预算周期？预算额度？支付条件？ |

### 场景维度

| L | 维度 | 检查项 |
|:--|:--|:--|
| L1 | 流程环节 | 生产/采购/研发/销售/客服/招聘——哪个环节？ |
| L2 | 操作地点 | 内部(车间/办公室/会议室)/外部(户外/远程)？ |
| L3 | 人物协作 | 内部(跨部门/上下级)/外部(供应商/渠道/政府)？ |
| L4 | 时间节点 | 经营节点(起步/扩张/受阻)/事件节点(新品/系统/合规)？ |
| L5 | 重大事件 | 融资并购/战略转型/上市准备/危机公关/政策法规？ |

### 问题维度

| L | 维度 | 检查项 |
|:--|:--|:--|
| L1 | 业务问题 | 增长/成本/效率/质量/客户流失？ |
| L2 | 技术问题 | 系统落后/数据难题/技术债务？ |
| L3 | 管理问题 | 协作/人才/流程？ |
| L4 | 战略问题 | 方向模糊/竞争压力/创新乏力/资源错配？ |
| L5 | 风险管控 | 合规/安全/财务/税务/数据泄露？ |

## 2C 盲区检查清单

### 用户维度

| L | 检查项 |
|:--|:--|
| L1 | 年龄/代际/性别/地域/收入/职业/住房？ |
| L2 | 家庭结构/社会角色/特定身份(宝妈/铲屎官/二次元)？ |
| L3 | 健康程度/能力水平/特殊阶段(孕期/产后/更年期)？ |
| L4 | 生活/工作/兴趣/决策/消费习惯？ |
| L5 | 价值偏好(氛围/效率/颜值)/生活哲学(自律/躺平/极简)？ |

### 场景维度

| L | 检查项 |
|:--|:--|
| L1 | 时间(早/中/晚/工作日/周末)/状态(碎片/整块)？ |
| L2 | 地点/路上/社交状态/环境条件(手机/电脑/嘈杂/安静)？ |
| L3 | 情绪(正/负)/身体状态(熬夜/久坐/失眠)？ |
| L4 | 个人时刻(求职/保险/生理期)/公司时刻/送礼时刻？ |
| L5 | 重大决策/意外偶发/关键前期/关键后期？ |

### 问题维度

| L | 检查项 |
|:--|:--|
| L1 | 缺信息/缺工具/缺能力？ |
| L2 | 要更便宜/更快/更简单/更舒适/更有趣？ |
| L3 | 体面/陪伴/社交货币/维护关系？ |
| L4 | 人设塑造/自我补偿/自我实现？ |
| L5 | 能赚钱/能省钱？ |

## 使用方式

需求分析完成后，逐维过一遍清单。每勾选一个维度——"我考虑过这个了吗？"

如果有 ≥3 个检查项从未考虑过 → 回到 `/demand-analysis-iceberg` 补 L1-L2。
