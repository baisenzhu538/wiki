# 战略六阶段模型

冉鹏"吃"系列——企业在不同阶段，核心命题完全不同。用错阶段的战略，越努力越错。

## 六阶段速查

| 阶段 | 核心命题 | 战略奥义 | 关键动作 |
|:--|:--|:--|:--|
| **初创期** | 活下来 | **拼命试错，快速学习** | 一根独木桥——明确不做什么，聚焦最小市场第一（300米内品类第一） |
| **吃饱期** | 长大 | **优化模型，快速复制** | 先民主后集中——团队出谋划策+创始人拍板 |
| **吃好期** | 变强 | **构建优势，布局生态** | 战略流程化——不能靠创始人独断 |
| **吃撑期** | 转型 | **边开车边换引擎** | 创始人必须亲自领导变革，敢于自我否定 |
| **吃吐期** | 退出 | **及时止损，体面退出** | 引入变革专家或创始人果断决策 |

**关键判断：高速增长期应追求规模而非利润。** 精品超市 O 在高速增长期追求盈利目标→反而盈利下滑。

## 阶段判断自测

| 问题 | 你的答案指向 |
|:--|:--|
| 公司有稳定现金流吗？ | 是→吃饱+ / 否→初创 |
| 增长在减速吗？ | 是→吃好 / 否→吃饱 |
| 原有模式明显到天花板了吗？ | 是→吃撑 / 否→吃好 |
| 继续投入还会更亏吗？ | 是→吃吐 / 否→吃撑 |

## 各阶段高频错误

| 阶段 | 常见错误 | 后果 |
|:--|:--|:--|
| 初创 | 过早追求规模，没验证 PMF | 烧完钱才发现需求不成立 |
| 吃饱 | 追求利润而非增长 | 错失扩张窗口（精品超市O） |
| 吃好 | 躺在功劳本上不建壁垒 | 竞对追上来时没有护城河 |
| 吃撑 | 创始人不敢否定自己 | 错过转型窗口 |
| 吃吐 | 不甘心退出，继续烧钱 | 损失扩大 |
