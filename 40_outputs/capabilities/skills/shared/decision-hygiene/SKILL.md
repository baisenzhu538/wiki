# 决策卫生五步法

基于 Kahneman《噪声》+ 一堂方法论。团队对同一问题做出独立判断时，用五步减少判断噪声。

## Constraints

<hard_limits>
- 五步必须按顺序：独立→聚合→讨论→修正→记录
- 第一步严禁成员之间交流——各自独立判断
- 最后一步必须记录判断过程和修正原因——否则噪声无法追溯
</hard_limits>

## 核心概念

> **偏差(bias)** = 大家都朝同一个方向错
> **噪声(noise)** = 不同的人对同一问题给出不同的判断
> 决策卫生解决的是噪声，不是偏差。

## 五步流程

### Step 1: 独立判断（Decompose & Independent）

| 动作 | 要点 |
|:--|:--|
| 拆解问题 | 把模糊问题拆成可独立判断的子问题 |
| 各自独立填 | 每个成员独立给出判断 + 置信度 + 关键假设 |
| 严禁交流 | 在所有人完成前不讨论 |

**独立判断模板**：
```
问题: [一句话]
我的判断: [具体数值/选择]
置信度: [高/中/低]
关键假设: [支撑判断的3-5个关键假设]
如果错了最可能是因为: [一句话]
```

### Step 2: 聚合（Aggregate）

| 动作 | 要点 |
|:--|:--|
| 收集所有独立判断 | 不做筛选，全量收集 |
| 计算分布 | 中位数/范围/离散度 |
| 标记异常值 | 偏离中位数 >2σ 的判断 |

**聚合输出**：
```
中位数: X
范围: Y-Z
离散度: 标准差=σ
异常值: 成员A的判断偏离中位数 2.3σ
```

### Step 3: 结构化讨论（Discuss）

| 动作 | 要点 |
|:--|:--|
| 异常值先发言 | 为什么你的判断偏离最多？有什么别人没看到的信息？ |
| 讨论关键假设差异 | 不是讨论判断本身，是讨论假设为什么不同 |
| 找"隐藏信息" | 谁有别人没有的信息？ |

**禁止**：直接争论"谁对谁错"——讨论假设，不讨论结论。

### Step 4: 修正（Revise）

| 动作 | 要点 |
|:--|:--|
| 各自独立修正 | 基于讨论中获得的新信息，各自修正判断 |
| 只改一次 | 避免来回修改 |
| 标注修改原因 | "因为我从成员B那里了解到XX，所以把估值从Y调整为Z" |

### Step 5: 记录（Record）

| 动作 | 要点 |
|:--|:--|
| 记录初始判断 | 每个人最初的判断 + 假设 |
| 记录修正过程 | 谁因为什么信息修改了什么 |
| 最终判断 | 团队聚合结果 |
| 回头验证 | 3个月/6个月后回头看，谁的初始判断更准 |

## 常见失败

| 症状 | 根因 | 修复 |
|:--|:--|:--|
| 讨论后判断反而更分散 | 权威人物影响了其他人（锚定效应） | 回 Step 4：独立修正，不在会议上当场改 |
| 异常值被忽视 | 少数意见没被认真讨论 | Step 3 强制异常值先发言 |
| 跳过记录 | 觉得"讨论完了就完了" | 至少记录最终判断 + 关键假设 |
