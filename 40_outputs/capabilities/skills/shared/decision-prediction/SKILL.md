# 预判模型

基于一堂方法论——从最糙版到复杂版的三种预判范式。

## Constraints

<hard_limits>
- 预判不是算命——每个预判必须标注：假设、置信度、"如果错了最可能是因为"
- 越复杂的预判模型越容易 overfitting——从最糙版开始，只在不满足时升级
</hard_limits>

## 三种预判范式

### 范式 1: 最糙版（15 秒出判断）

**何时用**：快速决策、信息极少、只需要方向感。

**15 字诀**：
- 看供给（供给端有没有结构性变化？）
- 看需求（需求端有没有被压抑的刚需？）
- 看政策（监管是推动还是阻碍？）
- 看竞争（有没有巨头在疯狂烧钱？）
- 看自己（你有什么别人没有的？）

**输出**：一句话方向判断 + 置信度。

### 范式 2: 结构化版（30 分钟出判断）

**何时用**：需要说服他人、需要量化分析。

**步骤**：
1. 列出影响结果的关键变量（≤5 个）
2. 对每个变量给出"乐观/中性/悲观"三种情景
3. 判断每种情景的概率
4. 加权综合 → 期望结果

**模板**：
| 变量 | 乐观(30%) | 中性(50%) | 悲观(20%) | 加权 |
|:--|:--|:--|:--|:--|
| 变量1 | X | Y | Z | = |
| 变量2 | ... | ... | ... | = |
| **综合** | | | | = |

### 范式 3: 复杂版（数小时-数天）

**何时用**：投资决策、重大战略、需要精确预测。

**步骤**：
1. 范式 2 结构化 +
2. 找 ≥3 个历史对标案例（相似情境下发生了什么）
3. 找 ≥2 个外部视角（行业专家/报告）
4. 做 Pre-Mortem："3 年后回头看，这个预测为什么错了？"
5. 设置验证节点：什么时候回头看预测对不对？

## 范式选择决策树

```
预测需求
├── 只需方向感？ → 范式 1（15 秒）
├── 需要说服他人？ → 范式 2（30 分钟）
├── 涉及重大资源决策？ → 范式 3（数小时-数天）
└── 不确定？ → 先用范式 1 出方向 → 不满足再升级
```

## 升级条件

什么时候从范式 1 升级到 2？
- 预测结果会直接影响 >10 万元的资源分配
- 需要说服 ≥3 个利益相关者
- 你自己对范式 1 的判断信心 <60%

什么时候从范式 2 升级到 3？
- 涉及不可逆的重大决策
- 有信心的人和不看好的人分歧巨大
- 有足够时间和资源

## 常见失败

| 症状 | 根因 | 修复 |
|:--|:--|:--|
| 范式 3 做了一周，结论和范式 1 一样 | over-engineering | 从范式 1 开始是正确——但不要"为了用而用"升级 |
| 预判太自信 | 没做 Pre-Mortem | 每个预测配一个"为什么可能会错" |
| 只看支持自己预判的证据 | 确认偏差 | 强制找 ≥2 个否定性证据 |
