# 冰山六层需求深挖

L1→L6 Pipeline。每层产出驱动下一层——不可跳步。

## Pipeline

```
L1 粗拆用户  → L2 粗拆场景  → L3 核心任务 → L4 任务地图 → L5 隐藏洞察 → L6 需求假设
     ↓              ↓              ↓              ↓              ↓              ↓
  用户画像卡    场景标签卡    任务陈述卡    摩擦点地图    四种力量表    机会卡片
```

## 六层详解

### L1: 粗拆用户标签

**回答**：谁在使用？谁在付费？谁是影响者？

**产出**：用户画像卡——身份/角色 + 3项关键属性（年龄/地域/行为习惯）

**工具卡**：`tool-demand-iceberg-l1-user`

### L2: 粗拆场景问题

**回答**：在什么时间/空间/情绪下？触发了什么表面痛点？

**产出**：场景标签卡——时间+空间+触发条件+使用频率+表面痛点

**工具卡**：`tool-demand-iceberg-l2-scenario`

### L3: 圈定核心任务

**回答**：用户"雇佣"产品要完成什么任务？（方案中立——不准提产品功能）

**产出**：任务陈述——"在[场景]下，用户希望[核心结果]，而非[表面操作]"

**工具卡**：`tool-demand-iceberg-l3-core-job`

### L4: 分解任务地图

**回答**：核心任务拆为哪8个步骤？每步的现有方案和摩擦点是什么？

**产出**：摩擦点地图——高摩擦+高重要性环节 → 切入机会

**8步**：定义→定位→准备→执行→监控→调整→结束→总结

**工具卡**：`tool-demand-iceberg-l4-job-map`

### L5: 挖掘隐藏洞察

**回答**：什么力量推着用户改变？什么力量拉着用户不动？

**四种力量**：
| 力量 | 问题 |
|:--|:--|
| 推力 | 现有方案最让用户痛苦的2个点？ |
| 拉力 | 你的方案超出现有方案的2个收益？ |
| 焦虑 | 用户用你的方案最担心的2个点？ |
| 习惯 | 用户对现有方案的惯性依赖？ |

**三种任务**：功能任务 + 情感任务 + 社交任务

**工具卡**：`tool-demand-iceberg-l5-forces`、`tool-demand-four-forces`

### L6: 提炼需求假设

**回答**：最关键的机会是什么？必须验证的风险是什么？

**产出**：机会卡片——机会名称/逻辑来源/建议MVP形态/最危险假设(RAT)×3

**工具卡**：`tool-demand-iceberg-l6-hypothesis`

## 评估三角形（贯穿L3-L6）

每层产出用评估三角形校验：

| 维度 | 问题 |
|:--|:--|
| **普遍性** | 这个问题影响多少人？ |
| **频次** | 这个问题多久出现一次？ |
| **刚性** | 用户愿意付多少钱解决？ |

**工具卡**：`tool-demand-assessment-triangle`

## 常见失败

| 症状 | 根因 | 修复 |
|:--|:--|:--|
| L3 写成产品功能 | 违反方案中立原则 | 剥离方案词——只留动词+对象+语境 |
| L5 四种力量全是功能性的 | 忽略了情感和社交驱动力 | 追加"用户完成任务时想感受什么？想让别人看到什么？" |
| L6 假设不可验证 | "市场很大"不是可验证假设 | 改成"假设XX用户群愿意为YY付费≥ZZ元/月" |
