# 五步法 Step 3: 商业模式

验证怎么赚钱、单元模型是否成立、能否持续。

## 核心框架

### 单元模型（Unit Economics）
```
单客价值（LTV） vs 单客成本（CAC）
LTV/CAC ≥ 3 → 健康
```

### 商业模式画布
| 维度 | 要回答的问题 |
|:--|:--|
| 收入来源 | 谁付钱？付多少？频率？ |
| 成本结构 | 固定成本 vs 可变成本？ |
| 毛利 | 毛利率多少？行业基准？ |
| 现金流 | 多久回本？需要多少启动资金？ |
| 规模化 | 规模扩大后单位成本下降吗？ |

### 三工具：斧子·尺子·梯子
| 工具 | 用途 |
|:--|:--|
| **斧子** | 砍掉不赚钱的产品线/客户群 |
| **尺子** | 度量每个单元的成本和收益 |
| **梯子** | 找到从亏损到盈利的路径（规模/效率/定价） |

## 关键判断

| 信号 | 结论 |
|:--|:--|
| LTV/CAC < 1 | 不可持续 |
| 毛利率 < 行业平均 50% | 成本结构有问题 |
| 回本周期 > 12 个月 | 现金流风险 |
| 规模扩大单位成本上升 | 反规模经济——危险 |

## 产出
商业模式画布 + 单元模型计算 + 盈利路径
