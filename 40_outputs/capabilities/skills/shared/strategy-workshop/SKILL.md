# Strategy Workshop（战略会议准备包）

输入公司基本信息 → 输出完整战略会议包：议程 + 预诊断 + 工作坊模板 + 外部对标 + 执行方针。

## Pipeline

```
公司信息
  ↓
Step 1: 阶段判断     → /strategy-lifecycle   → 公司处于什么阶段？核心命题是什么？
Step 2: 差距诊断     → /strategy-brm          → 业绩差距+机会差距分析
Step 3: 九问题排查   → /strategy-diagnose     → 最可能卡在哪个问题上？
Step 4: 外部对标     → /research              → 竞对/行业最佳实践
Step 5: 工作坊模板   → framework-strategy-business-design → 六要素×三步骤空白表
Step 6: 执行方针     → 综合步骤1-5            → 可执行的战略行动计划
  ↓
战略会议包
```

## Step 1: 阶段判断

调用 `/strategy-lifecycle` 判断公司所处阶段。

| 阶段 | 核心命题 | 会议重点 |
|:--|:--|:--|
| 初创期 | 活下来 | 讨论：我们的独木桥是什么？什么不做？ |
| 吃饱期 | 长大 | 讨论：怎么优化模型？怎么快速复制？ |
| 吃好期 | 变强 | 讨论：壁垒在哪？怎么构建生态？ |
| 吃撑期 | 转型 | 讨论：否定什么？边开车边换什么引擎？ |
| 吃吐期 | 退出 | 讨论：怎么体面退出？止损线在哪？ |

## Step 2: 差距诊断

调用 `/strategy-brm` Step 1——差距分析。

输出：业绩差距表 + 机会差距表 + 鱼骨图拆解。

## Step 3: 九问题排查

调用 `/strategy-diagnose`——逐项排除。

输出：九问题自检表 + 最可能的 1-3 个根因。

## Step 4: 外部对标

调用 `/research` 搜索：
- 竞对最新动态（财报/融资/新品）
- 行业趋势（市场规模变化/监管变化）
- 最佳实践（同阶段公司的成功/失败案例）

输出：外部对标简报（每项标注来源+时效）。

## Step 5: 工作坊模板

基于 Step 1-4 的发现，**预填**六要素×三步骤工作坊模板：

| 六要素 | 预填诊断（基于步骤1-4） | 会议讨论 | 执行挑战 |
|:--|:--|:--|:--|
| 客户选择 | [预填] | → 会议确认/修正 | → 会议识别 |
| 价值主张 | [预填] | → | → |
| 价值获取 | [预填] | → | → |
| 活动范围 | [预填] | → | → |
| 战略控制 | [预填] | → | → |
| 风险管理 | [预填] | → | → |

**预填不是替代会议——是给会议一个"开场基线"。** 会议讨论的不是"从零开始想"，是"这个预填对不对、哪里需要修正"。

## Step 6: 执行方针

基于六要素的工作坊结论，输出战略行动计划：

```
90天关键行动:
  1. [最紧急的一件事] — 负责人: ___ — 成功标准: ___
  2. [第二件] — 负责人: ___ — 成功标准: ___
  3. [第三件] — 负责人: ___ — 成功标准: ___

6个月里程碑:
  - [可量化的里程碑1]
  - [可量化的里程碑2]

资源需求:
  - 人: ___
  - 钱: ___
  - 时间: ___

风险预案:
  - 如果 [最危险假设] 被验证为错 → [预案]
```

## 会议议程建议

基于冉鹏方法论的标准战略会议程：

```
09:00-09:30  开场：Pre-Mortem——"如果3年后公司死了，最可能是因为什么？"
09:30-10:30  差距分析：业绩差距+机会差距汇报（Step 2）
10:30-12:00  业务设计工作坊（Step 5，六要素×三步骤）
12:00-13:00  午餐
13:00-14:00  外部对标简报（Step 4）
14:00-15:30  战略选择讨论——九问题排查+关键决策点（Step 3）
15:30-16:30  执行方针制定（Step 6）
16:30-17:00  收束：90天行动承诺 + 下次复盘时间
```

## 使用示例

```
用户: "我下周要开战略会，公司在吃饱期，做社区生鲜配送，增长放缓了"

Agent:
  1. /strategy-lifecycle → 确认：吃饱期，核心命题是"优化模型快速复制"
  2. /strategy-brm → 差距分析：增长从80%降到30%，竞对拿了3个城市
  3. /strategy-diagnose → 九问题排查：主要卡在"路径错误"（扩张城市选错了）
  4. /research → 外部对标：叮咚买菜/朴朴超市最新策略
  5. 预填六要素×三步骤模板 → 输出战略会议包
```
