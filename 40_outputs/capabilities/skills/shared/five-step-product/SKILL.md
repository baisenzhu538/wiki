# 五步法 Step 2: 产品内核

定义产品的"最小不可分割价值单元"——用户为什么选你而不是别人。

## 核心框架

### 产品内核三问
1. **解决什么问题？** — 对应 Step 1 的需求
2. **怎么解决？** — 你的方案 vs 替代方案
3. **为什么是你？** — 你的独特优势

### 产品内核画布
| 维度 | 内容 |
|:--|:--|
| 目标用户 | 第一步识别的具体用户 |
| 核心痛点 | 他们最痛的 1-2 个问题 |
| 你的方案 | 一句话说清你怎么解决 |
| 替代方案 | 用户现在用什么？ |
| 差异化 | 为什么选你而不是替代方案？ |
| 最小验证 | 最小的可验证版本是什么？ |

### 产品内核修炼段位
```
L1: 能说清做什么
L2: 能说清为谁做
L3: 能说清为什么是你
L4: 有独立验证的用户证据
L5: 产品内核成为团队共识
```

## 关键判断

| 信号 | 结论 |
|:--|:--|
| 说不清"为什么是你" | 产品内核不清晰 |
| 用户不比较直接选你 | 强内核 |
| 用户要比价/比功能 | 内核弱 |

## 产出
产品内核画布：用户+痛点+方案+替代+差异化+最小验证
