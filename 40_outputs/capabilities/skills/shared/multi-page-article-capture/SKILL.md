# 多页文章自动抓取拼接

> "截图 OCR 是笨办法——人家 Kimi WebBridge 直接读 DOM，一页页点过去，跟真人翻书一样。" — 洪七公

## 定位

解决「文章无法复制、分页太多、只能截图」的痛点——**不截图，直接操控浏览器抓 DOM 文本**。

```
旧路子（截图OCR）:
  第1页截图 → OCR → 文字1 ─┐
  第2页截图 → OCR → 文字2 ─┼→ 拼接 → 有 OCR 误差
  第3页截图 → OCR → 文字3 ─┘

新路子（WebBridge 模式）:
  浏览器打开目录页
    → 点击第1条 → 抓 DOM 文本
    → 点击第2条 → 抓 DOM 文本
    → ...
    → 去重拼接 → 完整文章（零 OCR 误差）
```

## 触发词

- "把这个目录下的文章全扒下来"
- "这个系列有 N 页，帮我抓成一篇"
- "这篇文章分页了，拼成完整的"
- "扒这个网站的内容" / "抓取这个连载"
- "这个页面没法复制，帮我提取"
- "把这几页拼接成完整文章"

## 决策树

```
丢给我的 URL 是——
│
├── 有目录页（章节列表）→ 🟢 模式 A：目录遍历（最优）
│     可预知总数，逐章汇报进度
│
├── 有"下一页"按钮   → 🟢 模式 B：分页遍历（次优）
│     可预知页数，逐页汇报进度
│
├── 只有滚动加载      → 🟡 模式 C：无限滚动（先探底再分批）
│     不可预知终点，必须先滚到底摸底 → 分批提取+里程碑通知
│     每 5 段存一次中间文件防丢
│
└── 根本无法复制/只有图片 → 🔴 走截图 OCR 流程
      → vlm-image-describe-pipeline / batch-paddleocr-js
```

## 模式 A：目录遍历（有目录页）

```
Step 1: 打开目录URL
Step 2: 识别所有文章链接 → 回报："共 N 章，开始抓取"
Step 3: 逐个: 点击链接 → 提取正文 → 回报进度"[i/N] ✅"
Step 4: 去重拼接 → 保存 {系列名}.md

适用：课程目录、连载文章、知识库索引
```

## 模式 B：分页遍历（有"下一页"）

```
Step 1: 打开第1页URL
Step 2: 提取正文 → 回报"[i/N] ✅"
Step 3: 点击"下一页" → 重复 Step 2
Step 4: 直到无"下一页" → 拼接保存

适用：分页文章、论坛长帖、帮助文档
```

## 模式 C：滚动加载（先探底再分批）

```
阶段一：探底摸底（10秒）
  打开URL → 滚到底
  → 回报用户："全文约 X 字，预计 N 轮提取，每轮 ~2 分钟"

阶段二：分批提取 + 里程碑通知
  回到顶部 → 分段提取
  → 每段通知："[1/4] 已提取前 2000 字 ✅"
  → 直到全文提取完成

阶段三：拼接保存
  → 通知用户："全文 X 字，已保存"

适用：Medium、公众号、动态加载页面
⚠️ 无限滚动必须「先探底再分批」，不让用户干等。
```

## 分批汇报机制

> 来自实战教训：用户丢 URL 后去忙别的，不能让他不知道进度。

| 阶段 | 通知内容 | 时机 |
|:--|:--|:--|
| **开工** | "开始抓取 {标题}，{模式}模式，预计 {条数/页数}" | 第一条/第一页开始前 |
| **里程碑** | "[3/12] {章节标题} ✅ ({字数}字)" | 每条/每页完成后 |
| **交付** | "全文 {总字数} 字，已保存至 {路径}" | 拼接完成后 |

### 异常中断通知

```
⚠️ 抓取中断
- 已完成: 5/12
- 失败位置: 第6章 (链接失效/需要登录/超时)
- 已保存: 前5章 → partial_抓取_日期.md
- 建议: [具体修复建议]
```

### 长任务回血策略

```
抓取超过 10 页/条:
  → 每 5 条存一次中间文件（防会话中断丢数据）
  → 中间文件命名: {系列名}_WIP_N.md
  → 全部完成后合并删除中间文件
```

## 核心处理逻辑

### 正文提取（去噪）

去掉导航、页脚、广告等噪音，保留纯净正文。

### 相邻页去重

自动检测相邻页重叠部分（如页眉、上一页末句=下一页首句），去除重复。

### 标题层级修复

统一 Markdown 标题层级，保持文档结构一致。

## 输出规范

```markdown
# 文章标题

> 来源: [原始URL]
> 抓取时间: YYYY-MM-DD
> 方式: WebBridge 模式 · DOM提取
> 页数: N页

---

[正文内容...]
```

## 与截图 OCR 的对比

| 维度 | 截图 OCR | 本技能（WebBridge模式） |
|:--|:--|:--|
| 准确性 | 95-99% | **100%**（DOM直取） |
| 格式保留 | 仅纯文本 | 保留标题/列表/表格 |
| 速度 | 10-15秒/页 | **3-5秒/页** |
| 登录态 | 不需要 | 需要浏览器已登录 |
| 适用 | 图片/PDF/扫描件 | 网页文章/分页内容 |

## 常见坑点

- `browser_snapshot` 必须用 `full=true` 模式才能抓全文
- 动态加载内容需先 `browser_scroll` 到底触发懒加载
- 弹窗/登录墙需先关闭再提取
- 同一页面 DOM 中重复内容需选唯一容器
