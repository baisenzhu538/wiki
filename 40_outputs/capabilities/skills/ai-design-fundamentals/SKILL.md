# AI设计基础认知

## Purpose
帮助使用者在 5 分钟内建立AI生图技术的正确认知，掌握GPT-2o/巨米4.0/Nano Banana的选型逻辑，明确AI设计的能力边界，避免"模型越新越好"的误区。

## When to Use
- 需要向团队/客户解释AI生图技术原理时
- 需要为具体设计任务选择合适的AI模型时
- 需要评估AI能不能做某个设计任务时
- 需要识别"去油腻"效果的适用范围时

## When NOT to Use
- 已经熟悉Diffusion原理和各模型特点的高级用户（过于基础）
- 需要立即生成具体设计素材的场景（本技能不含操作指令和提示词模板）
- 需要深度定制模型微调或训练的技术场景（本技能不涉及工程化细节）

## Protocol

## 1. AI生图技术演进三段论

### 1.1 GAN（对抗生成网络，2014-2018）

- **原理**：两个网络对抗——一个负责生成（Generator），一个负责鉴别（Discriminator）
- **逻辑**：生成器画得越好，鉴别器挑毛病越精准，形成训练收敛
- **局限**：容易画着画着就卡住（模式崩溃），多样性不够
- **现状**：已被主流生成方案淘汰，仅在特定研究场景使用

### 1.2 VAE（变分自编码器，早期-2019）

- **原理**：把图片压缩成数学空间的点（潜在空间），再把点往外扩张
- **逻辑**：像切片一样将图片压缩成低维表示，再重建
- **优点**：稳定性强，让做什么就做什么
- **局限**：细节度不够精致，画面模糊，基本上无法商用

### 1.3 Diffusion（扩散模型，2020-至今）

- **原理**：从完全噪声中逆向还原图像
- **逻辑**：
  1. 先学习如何把清水变成浑水（加噪声）
  2. 再学习如何把浑水变成清水（去噪声/生成）
  3. 生成时从纯噪声出发，逐步净化成目标图像
- **优点**：画质高，可控性提升，商用可行
- **当家产品**：豆包、巨米（极梦）、GPT-2o、Midjourney等均基于Diffusion架构，只是语料不同

> **核心认知**：AI生图的本质是"从噪声中逆向还原图像"，而不是"从零开始绘制"。这就是为什么调整局部细节时AI经常出错——它不是在"修改"，而是在"重新生成"。

## 2. 当下AI设计模型选型矩阵

### 2.1 三大主流模型对比

| 维度 | GPT-2o（豆包/云巨米） | 巨米4.0（极梦） | Nano Banana（谷歌） |
|------|----------------------|----------------|-------------------|
| **最大优势** | 去油腻：真实世界质感理解深 | 均衡性强，通用场景表现稳 | 艺术人文风格质感最佳 |
| **文字直出** | 成功率高 | 一般 | 一般 |
| **真实摄影类** | 表现极强 | 良好 | 一般 |
| **艺术风格** | 一般 | 良好 | 最强 |
| **特定艺术家风格** | 弱 | 良好 | 最强 |
| **中文场景** | 免费、交互好 | 有字数限制（800字） | 需外部访问 |
| **适合人群** | 普通用户/管理者 | 设计师/高级用户 | 艺术创作者 |

### 2.2 选型决策树

```
你的需求是什么？
┌──→ 真实摄影/产品白底图/海报文字 → 用GPT-2o（豆包免费足够）
│
├──→ 通用设计/品牌海报/社媒素材 → 用巨米4.0
│
└──→ 艺术创作/模仿特定画家/动漫风格 → 用Nano Banana
```

> **核心原则**：选模型不要一味求新，要选择合适的。豆包可以满足80%的平铺场景。

## 3. "去油腻"概念与局限

### 3.1 什么是"去油腻"

- AIGC（特指GPT-2o类模型）对真实世界的质感理解更深
- 生成图片更自然，少了以往AI的"塑料感"和"油腻感"
- 拍照级真实感：兩光、材质、空间关系更自然

### 3.2 去油腻的边界

- **有效场景**：真实摄影、产品图、生活场景
- **失效场景**：艺术风格化创作、推理风格、超现实主义设计
- **原因**：这类模型用了大量现实照片训练，艺术语料占比不足

## 4. AI设计的能力天花板

### 4.1 组合已知 ≠ 创造未知

- AI能做的：把你说清楚的事情做好
- AI做不到的：
  - 创造完全未知的风格
  - 复杂的空间逻辑关系
  - 情绪表达和意图传递（如"孤独的海报"）

### 4.2 AI不能替代设计师的核心原因

- AI出的是**选项**，人做的是**选择**
- 选择需要**审美策略 × 商业理解**
- 100张海报 ≠ 高ROI，关键是哪张能解决商业问题

## 5. 不同人群的入门路径

| 人群 | 第一步 | 核心原则 |
|------|--------|----------|
| **普通人/小白** | 抄最佳实践提示词，先解决具体问题 | 能解决问题比图多炫重要 |
| **管理者/企业一号位** | 先整理文件体系，再搭AI | 文件乱=AI结果乱 |
| **设计师** | 沉淀四类资产（提示词/风格/理论/PS模板） | 基础动作没做清楐=AI效能低下 |

## 6. 约束与陷阱（Constraints & Pitfalls）

| # | 陷阱/约束 | 说明 | 应对 |
|---|-----------|------|------|
| C1 | **抽卡属性** | Diffusion从随机噪声出发，每次生成结果不确定 | 预留抽卡时间，一次生成10张以上筛选 |
| C2 | **局部修改易崩** | 调整局部细节时经常全图重画 | 先确认整体OK再进PS精修，不要依赖AI做局调 |
| C3 | **模型迭代快** | 今天的最佳模型明天可能被超越 | 季度性复盘选型表，不要锁死单一模型 |
| C4 | **无万能模型** | 不存在一个模型通吃所有场景 | 建立自己的"模型武器库"，不同场景切换 |
| C5 | **"去油腻"有边界** | 仅在真实摄影类场景显著，艺术风格可能倒退 | 艺术创作项目仍需Nano Banana等专门模型 |
| C6 | **创造天花板** | AI只能组合已知，不能创造未知 | 创意方向必须人来控，AI只做执行 |
| C7 | **提示词误区** | 越长越好是误区，关键提示词容易被水化 | 提示词"够用就好"，重点突出（见Skill 3） |

## Examples

### 案例：电商品牌海报选型

**场景**：某电商品牌需要为新品发布会制作主视觉海报，要求"真实摄影感+产品细节"。

**误区**：团队直接用Nano Banana生成，结果艺术感过强、产品质感不足，被责任打回。

**正确做法**：
1. 根据本技能选型矩阵："真实摄影"→ GPT-2o（豆包）
2. 生成 10-20 张抽卡，筛选最佳
3. 进PS微调文字和布局（不依赖AI做局部修改）
4. 季度复盘时检查：豆包仍然是最佳选择吗？

**关键收益**：避免了"Nano Banana最强所以什么都用它"的误区，节省了 2-3 轮迭代时间。
