# 提案质量检查单

> 使用方式：`kdo checklist proposal` 输出此清单。

## 问题定义

- [ ] 现状一句话说清
- [ ] 痛点明确（谁在疼？不解决会怎样？）
- [ ] 四要素验证通过（Before-After/真实锚点/受益人/可解性）

## 方案清晰

- [ ] 核心动作一句话说清
- [ ] 步骤 ≤5 步
- [ ] 不做什么已明确标注

## 规模诚实

- [ ] 代码量/时间有预估值（不是"大概几天"）
- [ ] 依赖已列出

## 验收可测

- [ ] 验收项 ≥2 条
- [ ] 每条有可二值判断的标准（"能做到/不能做到"，不是"做好"这种模糊词）
- [ ] 每条有验证方法

## 风险与影响

- [ ] 最大风险已列出
- [ ] 缓解方案已想好
- [ ] 对现有 KDO 系统的影响已评估

## 自检通过标准

5 个类别全部 ✅ → 可提交审批。任何 ❌ → 回去补。
