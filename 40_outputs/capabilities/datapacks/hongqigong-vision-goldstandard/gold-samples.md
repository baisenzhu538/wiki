# 金标准样本（好的识别长什么样）

> 用法：识别产出后对照本页判定「做到什么程度算好」。样本原件在 `00_inbox/`，本库只存对照与判定，不复制原件（输入只读纪律）。
> 所有数字均附落盘锚点，可复核。

---

## G1 · 数字型 PDF 逐字保真：三源校勘（2026-09-06 首件）

| 项 | 内容 |
|:--|:--|
| 输入特征 | 《AI组织行为学的口述.pdf》3 页，**数字型 PDF（有完好嵌入文本层，非扫描件）**【实证：文本层 878/1045/244 字符/页，码点为完好中文】 |
| 三源 | ① PyMuPDF 原生文本层（基线）② hongqigong 实例视觉逐字转录页图 ③ MiniMax-M3 VLM 前轮产出 |
| 量化判定 | ① vs ② = **2087/2087 字符零差异**【实证，脚本 diff】；① vs ③ = 2084/2087（VLM 漏 3 字"我/就/我"，0 添错）【实证】 |
| 正确输出形态 | frontmatter 带 `ocr_confidence` 置信声明 + 页码锚【第N页】保留 + `[?]` 0 处 + U+200B 零宽字符清除并声明（见 pitfall-cases.md P2） |
| 来源锚 | `00_inbox/人机协作双三角/AI组织行为学的口述-ocr.md`（frontmatter ocr_confidence 行） |
| 可复用点 | **逐字保真任务的引擎优先级：文档自有文本层 > 实例视觉 > VLM 转录**。VLM 单源必漏字（本例漏字率 ≈0.14%），不可单独用于逐字任务 |

## G2 · 截图批量 OCR+VLM 零失败基线（47 图 173/173）

| 项 | 内容 |
|:--|:--|
| 输入特征 | 47 张 PNG 课程截图（2 张 md5 重复、3 对同内容两次截屏 → 内容级独立约 42 张）——交付前先去重 |
| 量化判定 | **173/173 段成功，零失败**【实证：建议书表格原文】 |
| 正确输出形态 | 每图一个 `OCR_*.md` 直接落素材目录（Obsidian 可见），识别正文在前、人工纠偏节追加在尾部（纠偏不改原始识别文本，见 P6） |
| 来源锚 | `00_inbox/爆炸式调研/任务编排建议书_爆炸式调研_20260816.md:17` |
| 可复用点 | 批量任务计数用**段级**不用图级（一图可多段）；产出必须落盘素材目录而非 /tmp（E021 教训） |

## G3 · 密集表格图还原：300DPI + 已知锚点注入

| 项 | 内容 |
|:--|:--|
| 输入特征 | 策略小抄三列表（动嘴/动手/动钱）、爬山地图六段——密集小字 + 缩略图页 |
| 失败对照 | 同内容 150DPI 下 10 个标题错 7 个（详见 pitfall-cases.md P5） |
| 正确输出形态 | 300DPI 渲染重跑 + PROMPT 注入已知正确锚点（12 种阻力权威名 / 爬山地图六段名）+ "严禁编造，只识别图中实际内容"禁令 + 表格还原 Markdown（单元格换行 `<br>`） |
| 来源锚 | `00_inbox/Handle the business/conversion rate/rerun_hires.py`（PROMPT 全文可读） |
| 可复用点 | 密集小字默认 300DPI；有已知正确名词可注入 prompt，**但注入必须防术语渗入**（联动 P6） |
