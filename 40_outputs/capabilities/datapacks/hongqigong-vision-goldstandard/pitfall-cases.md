# 踩坑实录（反例：失败样本与原因）

> 每例 = 现象 / 根因 / 检测 / 修复 / 规则 / 锚点。病例来源：洪七公错误模式库 E001-E027（`桌面/agent复盘/hongqigong/错误模式库.md`，vault 外复盘目录）+ 2026-09-06 当日病例。

---

## P1 · 丢中文族：上游落盘只剩 ASCII 碎片桩（2026-09-06）

- **现象**：同名旧桩 `AI组织行为学的口述.md` 仅 **286 字节**，正文只剩零散 "AI" ASCII 碎片；真实内容是 2087 字中文逐字稿【实证：两文件 head + wc -c，见锚点】。
- **根因**【推断】：上游落盘链路丢中文——**PDF 本体文本层完好**（878/1045/244 字符/页），非扫描件问题、非 OCR 问题。
- **检测**：`wc -c` 对比字节数；中文文档里出现纯 ASCII 正文 = 红旗。
- **修复**：重走 PDF 文本层提取（产出 `AI组织行为学的口述-ocr.md` 9164 字节，见 gold-samples.md G1）。
- **规则**：见到 0 字节/纯 ASCII 的中文 .md，**先查上游格式与落盘链路，别急着重跑 OCR，更别判"原文缺失"**。
- **锚点**：`00_inbox/人机协作双三角/AI组织行为学的口述.md`（286B 桩）vs `AI组织行为学的口述-ocr.md`（9164B 交付稿）。

## P2 · 零宽字符 U+200B 混入正文（2026-09-06）

- **现象**：PDF 原生文本层提取结果含 U+200B 零宽字符——PDF 原生杂质，非口述内容【实证：交付稿 frontmatter notes 行原文】。
- **根因**：文本层直提 ≠ 干净文本；不可见码点肉眼不可见、下游检索/计数全被污染。
- **检测**：对提取文本跑不可见码点扫描（U+200B/U+FEFF/U+00AD）。
- **修复**：清除，并在 frontmatter `notes` 显式声明"U+200B 零宽字符已清除（PDF 原生杂质，非口述内容）"。
- **规则**：**不可见码点必须显式清理 + 声明**，静默处理等于没处理。
- **锚点**：`00_inbox/人机协作双三角/AI组织行为学的口述-ocr.md` frontmatter notes 行。

## P3 · API 格式软失败：HTTP 200 掩盖格式错误（E019+E020，2026-07-26，10+ 次）

- **现象**：用 Anthropic 格式 `type:image + source.base64` 调 MiniMax M3 Vision，返回 **200 + "没看到图片"**，连续 10+ 次；期间在换 key/压缩图片/换域名上空转【复盘记录】。
- **根因**：MiniMax Vision 实际用 OpenAI 格式 `image_url + url(data:)`；HTTP 200 + 友好错误消息极具误导性，从未质疑请求格式本身。
- **检测**：用已知极简图做快速验证；诊断顺序固化为 **格式 → Key → 域名 → 图片 → 模型**。
- **修复**：改用正确格式；同一报错 3 次以上 → 第一件事查官方文档确认请求格式。
- **规则**：**"模型说没看到图"的第一反应是请求格式对不对**，不被 200 掩盖的软失败误导。
- **锚点**：`桌面/agent复盘/hongqigong/错误模式库.md` E019/E020 行（vault 外）。

## P4 · VLM 编造：先验知识填坑（E013，2026-07-12）

- **现象**：识别"参数挖掘武器库"时，原图只有 "GMV" 一词，VLM 却补全出 **3 个不存在的公式**（"GMV = 流量 × 转化率 × 客单价"等）【复盘记录】。
- **根因**：VLM 是"看图写话"而非纯 OCR——训练数据里的高频关联知识会被当成图片内容输出，语气自信无标记。
- **检测**：①对照原图抽查 ②脚本关键词校验（如 grep "流量 × 转化率"）确认无编造。
- **修复**：Prompt 禁令"严禁编造、推断、补充图片里没有的公式/数据/内容"，并拿它刚犯的错当反面例子写进 prompt。
- **规则**：**识别 ≠ 生成**；重要内容必须对照原图抽查。
- **锚点**：`桌面/agent复盘/hongqigong/错误模式库.md` E013 行；涉案产出目录 `00_inbox/Handle the business/Business formula/_vlm_output/`。

## P5 · 密集小字：低分辨率不可逆丢失（E016，2026-07-12）

- **现象**：默认 150DPI 渲染密集小字/缩略图页（阻力消除小抄、爬山地图），VLM **系统性乱码**："动嘴/动手/动钱"三列全错、10 个标题错 7 个、爬山地图 14 处错【复盘记录】。
- **根因**：渲染分辨率一刀切 150DPI，没按文字密度分级；小字在低分辨率下信息丢失**不可逆**，VLM 只能瞎猜。
- **检测**：交付前对照原图抽查密集页；错字成片出现 = 先查 DPI 不是先查模型。
- **修复**：300DPI 重跑（`rerun_hires.py`）+ PROMPT 注入已知正确锚点稳定识别。
- **规则**：**渲染前按文字密度分级选 DPI：正文页 150；密集小字/缩略图/密集表格页 300——宁可慢不可错**。
- **锚点**：`桌面/agent复盘/hongqigong/错误模式库.md` E016 行；修复脚本 `00_inbox/Handle the business/conversion rate/rerun_hires.py`。

## P6 · 上下文注入导致术语渗入（E025，2026-08-16）

- **现象**：给 VLM prompt 注入课程术语表（本为防误读），结果①全局图箭头标注"如何判断"被编成课程术语"知行分离"；②矩阵图原标题"不同类型经销商的关键挑战分析"被替换成口述稿术语"经销商生存状况图"；③配色归属错（原图 红=A、F，OCR 写成红 A/B/F）；④把完整图误判为"下方内容被截断"【实证：纠偏记录原文四条】。
- **根因**：注入的先验是双刃剑——不确定区域模型会拿上下文里的词"填坑"，且语气自信无标记。
- **检测**：**人工对照原图抽核关键框架图**，重点三处：标题 / 箭头标注 / 颜色归属。
- **修复**：①注入词表时明示"仅供辨词，禁止替换图中标题"②纠偏以追加记录落在原 OCR 文件尾部，**不改原始识别文本**。
- **规则**：**注入过上下文的输出，置信度自动降一档，必抽核**。
- **锚点**：`00_inbox/爆炸式调研/OCR_一堂DOC-20260816001643.md:69-74`（「⚠️ 人工核验纠偏（2026-08-16 洪七公对照原图）」节全文）。

## P7 · 形近字校验清单凭记忆不全（E014，2026-07-12）

- **现象**：校验只 grep 了记忆里的 "一莹/一望/Yitanq"，漏了"一棠"——**3 个文件 19 处**"一棠"（应为一堂）错误漏到整合阶段才被发现【复盘记录】。
- **根因**：形近字清单凭记忆列，不系统、不进版本管理。
- **检测/修复**：建立品牌名形近字全量校验表（堂/棠/莹/望/湶…），批量识别后全量扫描；6 层交叉验证兜底。
- **规则**：**校验清单进文件不进脑子**；专名类识别完成后跑形近字全表。
- **锚点**：`桌面/agent复盘/hongqigong/错误模式库.md` E014 行。

## P8 · 低置信误归因模型能力（E005，2026-06-19）

- **现象**：王欢 AI 专题 4 张图置信 0.3，归因为"图难/模型不行"；实际是 **JSON 解析失败（_parse_error）**【复盘记录】。
- **根因**：没先读原始输出确认根因，直接归因最显眼的变量。
- **检测/修复**：看到 0.3 / `_parse_error` → **先检查原始 JSON 块**再下结论。
- **规则**：**先诊断后归因**——置信分低 ≠ 图难。
- **锚点**：`桌面/agent复盘/hongqigong/错误模式库.md` E005 行。

## P9 · 通道单点失效：一个 key 断全链路（2026-09-06）

- **现象**：MiniMax 额度耗尽（`api.minimaxi.com` 返 `1008 insufficient balance`），仓内 `describe-images-minimax.py` / `cap_hub.vlm` / `long-image-ocr` / `run_vlm_extract.py` **全部走同一 key，一次失效 = 视觉管线全断**【实证：原始 API 响应，见建议书】。
- **修复**：实例自身视觉升格为第二引擎（实证见 gold-samples.md G1：2087/2087 零差异）；充值/换 key 决策在老朱。
- **规则**：**单 key = 单点故障**；逐字保真任务有降级序列：文本层 > 实例视觉 > VLM。
- **锚点**：`60_feedback/diagnosis/建议书_20260906_minimax额度耗尽多模态管线.md`。
