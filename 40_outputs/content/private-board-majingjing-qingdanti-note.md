## 一、暖场：状态打卡+心情分

**结论前置：暖场=每人本周状态+心情分，多位幕僚自述靠一堂课/心力模型获得笃定——暖场本身成了「心力需求真实存在」的现场证据。**

1. 雅琼（主持）：烦躁时打开一堂录播/直播/拆书课看20分钟心就笃定，心情7分
2. 徐丽：开学送孩子+公司烦心事，靠心力模型调节情绪，「以前会更生气，现在好多了」
3. 罗毅：工作细致化拆解陷入自我纠结——对照同行业最佳实践总觉得不够
4. 荣斌：陪家人看病被传染，生理盐水洗鼻+温盐水漱口恢复，心情6分
5. 柳青：朋友借出的实验室收拾完毕，心情8分
6. 老朱：继续深入 AI 实践、用 AI 跑通工作各方面，心情8分

**回收：六人暖场两个8分，「心力/笃定」在开场就已成高频词。**

## 二、案主介绍：德扑商业决策营是什么

**结论前置：项目=用德扑高频决策场做壳、以传统文化识人用人（五行+家传望诊+应用心理学）为核的企业决策培训，已在一堂体系内跑通约70人小样本验证。**

1. 案主背景
   1. 马晶晶，北京；2015年心理学会年度突出贡献讲师；方法组合=传统文化（五行）+家传中医望诊+应用心理学
   2. 授课累计300场+（全球500强/国央企/中央人民广播电台）——案主自述口径
   3. 家传疼痛处理技术：2分钟内处理90%疼痛，靠望诊判断病根；迁移律=人身体哪里有问题，他的企业哪里有问题
2. 课程起源与一堂之路
   1. 2023年与朋友在湖畔创研中心（原湖畔大学）讲谈判课→演化为德扑决策课
   2. 湖畔CEO班入池门槛：企业要有全产业链构成才能报课（阿里系优秀企业为主，T0/T1级、1号位减1人群）——案主自述
   3. 湖畔CEO班最受欢迎的选修课，18人/场要抢；湖畔人群约60人（不在私域，行业规范不越界深聊）
   4. toB价值的来路：每场活动后与湖畔工作人员复盘，把高潜对象观察反馈给他们——「这个是他们真正需要的」
   5. 2026年3月受一堂上海主理人邀请→5场公开课+4场工作坊，辐射约70人（北上深杭宁，上海人群状态最好）
3. 为什么是德扑
   1. 规则简单、无限循环、高频决策：一个周末全员累计约上万次决策
   2. 牌桌即江湖：从线性思考到系统思考、被动应对到主动布局、单点最优到全局最优
   3. 两层价值：toC=自我观察/自我觉醒/心力修复；toB=识人用人（筛选高潜、判断状态、排兵布阵）
4. 选址上海：北京严谨（「朝阳群众特别伟大，得躲着点」）、深圳状态不对、上海=东西交互+消费力强+交通友好，辐射江浙沪

**回收：项目=德扑壳+识人核+心力修复果，70人小样本已验证「到场即有提升」，案主自述缺的是人群触达与扩展方向。**

## 三、第一轮：幕僚提问·挖背景

**结论前置：第一轮挖出四个关键底数——70人从哪来（湖畔60+一堂域70）、课程天生有门槛、产品阶梯99→3000→3万、复购70出10，外加一个执行细节：效果验证指标=面相。**

1. 雅琼三问
   1. 70人从哪来：湖畔邀约约60人（不在群里）+一堂域五城公开课约70人；上海参与者30岁往上居多，管理团队/独立投资人/人力总监为主，还有技术转业务的转型人群
   2. 课程门槛：有门槛——明确的上升意愿、非纯学知识目的、愿在高竞争环境中竞争，最后才是高学识（高学识=消化能力强）；对人敏感的人群（投资人/猎头）同样适配
   3. 效果如何量化（雅琼问）：案主未给出量化指标，答「超值交付」+结果导向（德扑一轮一两分钟、现场教的东西一用就知道输赢）
2. 产品阶梯（雅琼追问带出）
   1. 99元讲座→3000元工作坊（限18人，必须上场体验，「知识纯教授的时代已经过去」）→3万年度会员（今年至少6次工作坊+每月指导）
   2. 工作坊设计：5场战斗规则各不同+案主现场搅局（软性设置）
   3. 势能设计实例：让复旦大二学生第一天赢、第二天输——人获得势能必须上下起伏；「人一直觉得自己聪明，他不会思考」
   4. 技术导向人群的入口价值：没经历过牌桌语境的技术人，可借游戏提前熟悉沟通语境、环境、角色特点，为转业务做准备
3. 荣斌四问
   1. 竞品：全国不超5家（豆包说的，案主未独立核实）；朋友认识的老师10万/天；湖畔报价20-25万/天（toB）；本案价格优势明显
   2. 定价弹性：不同人群不同价、不单纯以时间定义价格（全老板局定价更高）
   3. 教学入口：先教规则再上桌；打牌目的不是成为赌王，是练听之以耳/听之以心/听之以气三层决策模式
   4. 合规设计：小额奖池（每人10/20/50元凑池），不拿现金对赌；牌桌=投标环境模拟（筹码=资源、前注=制作标书的人）
4. 柳青两问
   1. 复购率：70人中年卡6位、3次以上复购10位以上
   2. 直觉有技术含量：能力模型构建——眼镜/穿着/头发/手势对应思维模式（象思维+望诊+「观」），案主自称90%以上可在生活中找对应
5. 老朱三问
   1. 年度会员画像：30岁以上、男女各半、有管理权限或独立独当一面（除一个复旦大二学生）；转化时间点有两个（第一期或第二期就有、第四期又有）；样本少不敢说规律
   2. 留下与没留下的区别：没留下的人反馈多为时间问题；有人不懂「赢在牌桌之外」；举办次数不够多，不能确认中途停下的人未来绝对不来
   3. 谁在打德扑（案主答）：大老板（马云级别）肯定打；美团副总裁望京牌局输赢上限约10万一场；销售导向培训师、猎头、律师、投资行业等高人际敏感度岗位；中科大金融校友会曾常打（政策收紧后收敛）
   4. 人群画线：非低收入人群；最好在企业有一定身份权力；可按年收入画线（如50万起）——与德扑买入门槛同构（100美元→100万美元买入，各选各的门槛），不同人群定价不同
   5. 需求真、形式存疑+获客成本：识人用人+心力+自我认知的需求人群很大，但为什么一定是德扑？很多人不会打也没兴趣；获客成本案主答「还没有办法算出来」
6. 罗毅四问
   1. 学员怎么看见自己变了：破冰望诊直断（按穿着形象直断思维模式，讲师风险自担）+牌桌动态解析（何时崩/何时冲动/肢体语言/精力起伏）+输赢结果打破自我认知（望诊之外还看微信头像，穿插在游戏化教学里）
   2. 成年人怎么改：发现天赋+扬长避短，不取长补短；让他看见自己在不擅长环境的输——「不擅长的环境，你不要介入」
   3. 交付能否脱离马老师：Michael（范德堡大学统计学博士，第一次上完课写18页A4总结，进步最快）已能承担40-50%的功能；目标是案主逐步只服务年度会员
   4. 只留一个指标证明人变了：面相——前后拍照对比（面相=定力/决心/态度的变化，「可量化又不太可量化」）
7. Vivian 用户视角插叙（轮间上线）
   1. 账算得清楚：参加三期、每期2天×每天10小时=60小时，折算每小时约150元，对比运动康复1000+/小时=超值
   2. 最大收获：心力循环+观之以气/观之以心；课程里的锦囊直接用在工作决策上；来源=一堂域会员群

**回收：第一轮底数喜忧参半——交付侧动作清晰（望诊直断+牌局解析+输赢拉扯），商业侧底数模糊（获客成本算不出、效果无量化体系）。**

## 四、第二轮：快问快答·围绕目标收敛

**结论前置：第二轮把模糊点全部逼到明面——转化周期1-2个月、到课率80%「模糊知道」、线下仅1人交钱没来；陈龙四连问把「一句话定位/人群锚定/动力阻力/产品内核」摆上桌面。**

1. 雅琼两问
   1. 市场教育之问：财富流/沙盘/一堂课都是替代方案，你在和很多解决方案抢市场？案主答三阶段论——知识付费→体验→训练，我们做的是与真实环境对接的训练，「不追求第一，追求唯一」
   2. 最终验证=面相：周围的人看见他就愿意跟他在一起=能量场；时代进入20年火运，火运看这个人能不能聚合别人、气足不足
   3. 打卡天数/作业量只是过程性指标，「真正能刻在脸上的东西，那是高价值的」
   2. 规模预期：第一阶段100-200名年度会员即可；规模警惕=68万财商老师翻车事件，「不要让贪念和自负吞噬过去积累的口碑」；内部强链接的产品不追求规模
2. 陈龙四连问（本场最犀利）
   1. 一句话定位逼问：「解决组织关键人的心力修复问题，在游戏化过程中完成」（逼问过程：产品解决什么人什么问题→提供什么方案→本质是心力问题）
   2. 获客渠道：目前主要依托一堂；其他渠道（长江等）在拓展，没有结果先不讲
   3. 转化链条：案主主要介入99→3000→3万段；转化周期1-2个月（月开一场）；99元讲座到课率模糊知道约80%，流失的20%没问过；线下工作坊至今仅1人交钱没来（不退钱，挂着）
   4. 阻力主因：时间问题（月更频率导致情绪与工作节奏浮动，第二次体验隔一个月）+心理修复迫切程度
3. 老朱：人群错位质疑——听下来一堂学员大部分不一定是目标客户，长江商学院等垂直高净值圈子可能更准；建议对现有年卡学员做一次结构化访谈
4. 罗毅追问
   1. 面相变化时点：第一天下午第二场（5秒决策局，压缩决策时间）开始有浅变化；第一天晚上嘉宾局+老手耐力局（已知环境vs未知环境的竞争策略不同）再洗礼，第二天微调
   2. 零基础可参加：德扑半天能教会；先99再3000有小梯度，直接进工作坊现场也教
   3. 荷官角色：发牌人=真正掌控节奏和全局的关键人+公共信息平台（央行央妈发政策信息的出口）——案主从荷官角度培养下一代培训师
   4. 角色阶梯：学员→荷官（年度会员必须当，学会操盘）→商业间谍（学会观察、收集信息，打引号）→商业智囊（改名后口径）；Michael 荷官已能做、商业智囊还没开始
5. 柳青两问
   1. 玄学门槛：无要求——象思维不是玄学，是没打通与生活的链接（横条纹=追求公平；上边框眼镜=喜欢跟比自己强的人聊天，加微信介绍要写得详细一点）
   2. 执着学员怎么辅导：就让他输——撞南墙不回头是因为撞得不够疼（美国计算机专业学生连输两天后说「以后你的课我都来」，反省出「Every single I'm not is creation」）
6. 荣斌四问
   1. toB还是toC：核心是toC「大C」（每个C在公司有固定角色，可成为推荐者）；toC做到100-200人，toB不成问题
   2. 年卡续费设计：初步定义三年周期，之后以授课或个人顾问方式停留
   3. 其他城市：杭州/南京/深圳/北京做过，聚焦上海+江浙沪（初期不希望搞太大、体力精力考量）
   4. 《对赌》书籍流量：案主没接触过，可作思路；中国人打牌为聊事不为赢钱——「赢不在牌桌之上，而在牌桌之外」=阴阳思维=成全性思维

**回收：第二轮把模糊点全部逼到明面——一句话定位被逼出来了，但数据面（到课率/流失/获客成本）全线模糊，人群锚定被老朱和陈龙双向质疑。**

## 五、第三轮：共创加法

**结论前置：第三轮幕僚从「挑问题」转向「给方案」，产出五路可执行建议——圈子合作换转介绍、邀请制工作坊、聚焦上海+需求三性分层、商会渠道、「老事套新壳」假设。**

1. 雅琼：特定圈子合作模式——免费半天工作坊体验换转介绍资源（IP公司/猎头圈子/海归群体：对晋升与人生阶段有更高追求的人）
2. 罗毅四答（与案主对谈）
   1. 获客成本：案主时间不算成本——背后有宏大愿景，是必须要做的事
   2. 获客渠道：倾向线下（「听半天不如来半天」，现场不做预设、冲击力大、转化效率高）
   3. 地域扩展：江浙沪之外最想切北京顶级商学院（长江/中欧=「店中店」模式）；企业家俱乐部在谈，先拿一个标的再推别的
   4. 邀请制工作坊在计划：周五做一天（半天体会不到那么深刻）
3. 老朱三补
   1. 需求三性（刚性/频次/普遍性）可做分层分析
   2. 全部交付仍是马老师亲自做，精力时间是大问题——要聚焦（案主答：只跑上海）；老朱附议：上海不适合民营经济早期创业，适合有一定规模层次后去扬名立万（老朱自述上海创业未成、后回广东）
   3. 不选广东/深圳的原因（案主）：广东是他学玄学的地方、广州与政府国央企有深度顾问合作、深圳有长期企业家朋友——希望每个地方工作性质单纯一点
   4. 火运追问：2024-2043火运主心力，心理咨询/能源（一部分）/航天（一部分）属火，设备制造看应用行业；行业地图会后发群（55班共享），老朱加微信请教
4. 柳青：企业家在商会里——江浙沪商会渠道建议（案主：北京人没有北京商会，商会接触少，欢迎介绍）
5. 陈龙四大挑战（建议轮）
   1. 人群重新筛选：锚定想象中的人群是经验主义——最容易成交的往往是你没考虑到的群体；先干能拿到正向反馈的事，人群筛选不断迭代
   2. 宣传聚焦点：心力宽泛性太大，公域宣传的聚焦点不够聚焦
   3. 动力阻力触点：转化率/动力/阻力/触点全部要具象化；商业咨询与实际落地是两码事
   4. 产品内核是否经验主义：案主答四层内核（德州壳→识人用人决策模式→中国人决策模式+心力修复→五行/易经/毛选）
      1. 案主立场：德州模拟系统环境、元素量小、实践检验快速反馈——现阶段介入模式，暂不替换
      2. 陈龙建议「老事套新壳」：知识付费6年经验——认知付费已渐饱和，套新壳可能3个月起量更快、正面反馈更快；案主答「我再考虑一下」
6. 荣斌三补
   1. 非目标人群处置：案主参照治病业务——擅长处赚钱、不擅长处在二十几个城市义诊「化解业力」；德扑项目还没想过
   2. 赌徒型人群要筛掉：只对输赢/牌技感兴趣的人有合规+品牌风险（案主答：北京还缺一个主理人）
   3. 「德扑」标签来源：原名「沟通决策与共赢——在德州扑克中理解和运用谈判策略」；上海主理人建议凸显德扑，拍脑袋定的；改名效果无数据支撑（商学院选修课环境无法验证市场）

**回收：第三轮方向收敛到两条——获客走「圈子/店中店」的线下信任链路；产品端「德扑」标签是否弱化，成了全场最大的未决假设。**

## 六、幕僚收敛轮：六人各一段判断

**结论前置：收敛轮在不一致中达成共识——事是好事，但「真问题不是客群」第一次被点破：交付能不能脱离马老师。**

1. 雅琼：问题=获客成本+人群匹配+承接能力（团队4人，定位小而美高端）；建议toB再toC链路（大厂一天免费工作坊做钩子，或嵌入MBA课程发展C端）
2. 罗毅：真问题不是客群，是交付能不能脱离马老师——「店中店是放大器，交付复制不了，谈得越多交付不了」
3. 老朱：真正的问题还是客户分层和价值提炼——德扑只是工具，识人用人+心力修复+认知自己的思维模式才是价值组装（老朱自证：「你说德扑，我对打牌是一点兴趣也没有」）
4. 柳青：包装建议——极限环境下、信息不完全时必须做出正确反应并执行到位的高管培训
5. 荣斌：项目已跑通最小闭环；现阶段不想线上获客，就在一堂同学里多发展
6. 陈龙：C端需求=确定性（3000块到底买什么），B端需求=价值点和定位；公域获客=价值观+明确解决问题的聚焦点，渠道=视频号/小红书等；私域=案例+用户证言（稳定性和确定性）；目标社群（商学院/一堂群）直接杀

**回收：收敛轮把全场交锋拧成一股绳——前端（人群/聚焦点/证言）要补，但罗毅一句话把优先级钉死：交付复制先于人群扩大。**

## 七、案主团复盘：三人自认的功课

**结论前置：案主团复盘=SOP卡未覆盖的本场增量设计——徐丽自证「德扑」标签的进入障碍，Vivian证言模型的包容性，马晶晶认下需求端功课缺口。**

1. 徐丽（案主团成员，HR的PBP）：第一次参加时犹豫过——「德州扑克好像跟我没什么关系」，因「商业决策」的好奇心才来；德扑可能限制了一些人的进入；年度会员值得再深度分析
2. Vivian（年卡会员，IT行业）：模型包容性很强——创业者/出海项目/公司高管/HR各取所需；年度会员用户特征比较离散、没有呈现出特别一致的用户特征；后端交付能力很强，前端面对不同领域不同标签的客户怎么做交付，是后面要思考的
3. 马晶晶（案主）认下四条功课
   1. 需求端功课太少，客户触达思路和方式不灵活
   2. 「德扑」是否限制了商业决策的内容认知和参与兴趣，回去认真研究
   3. 以茶入道/颂钵等其他入门模式（陈龙提示），考虑是否接入
   4. 做需求调研，夯实基础再谈交付调整和转化效率

**回收：案主团复盘印证幕僚判断——前端（需求/标签/调研）是案主自认的第一缺口。**

## 八、30秒收获+收尾

**结论前置：收尾每人30秒收获，王菲定调「事情本身没问题，难在商业模式再设计」；全场在超时与合照中结束。**

   2. 金句两条：「时代淘汰你的时候，连一句再见都不会说」「把这个事玩得好好玩，你永远不会输」
   3. 德州体感：要善于放弃，最后一轮 all in 前要算赌的成本/理性成本/感性成本——1% 的概率因素可以把全部干死

**收尾定调与流程**

7. 王菲（后半场加入，收尾定调）
   1. 定调：事情本身没有任何问题、最直观——「所有人听完都想试一下」
   2. 本质价值：给寻找意义感的人提供场景化筛选+陪伴观察机制
   3. 真正的难点：定价与人群细分后的商业模式再设计——体验课好做，599/899一开就可能没人来

**回收：收尾定调与收敛轮互证——事没问题、人群和模式要再设计，本场以「共识+功课清单」收场。**

**总回收：这场私董会的表面议题是「目标人群+宣传转化」，三个小时挖出的真问题链是——交付复制（Michael 40-50%）、需求三性未拆、数据面全模糊（获客成本算不出/到课率80%模糊/流失20%没问过）、产品内核四层与「德扑」标签的自我设限、规模警惕（100-200人足矣，别让贪念吞噬口碑）；案主认下的第一步功课=需求调研+年卡学员结构化访谈。**
