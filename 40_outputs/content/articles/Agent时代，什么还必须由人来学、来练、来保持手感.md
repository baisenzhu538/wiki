# Agent 时代，什么还必须由人来学、来练、来保持手感

## Core Thesis

> **Agent 能做的是"把想好的东西切清楔"，人必须做的是"想清楔"——这两者之间的差距，就是 Agent 时代人的核心竞争力。**

## Audience

- **主要读者**：正在用 AI 提效、但担心自己被替代的知识工作者、创业者、管理者
- **次要读者**：设计 AI Agent 产品的产品经理和技术负责人，需要理解"人机边界"在哪里
- **不适合读的人**：寻找"如何用 AI 完全替代人”的读者——本文不是教你放弃，而是教你拥有

## 一、一次被 Agent “骗了”的经历

上周我把自己写的一段复盘感想扔给 AI，让它整理成清单体笔记。两分钟后，我收到了一份结构完美的答案：六大模块、每模块四条分点、关键词标题清晰、逻辑严密。我看着这份笔记，第一反应是“这也太快了”。

第二反应是恐惧。

因为我发现自己看完后，脑子里并没有比之前更清楔——我只是"切清楔了"，但没有"想清楔”。Agent 把我散乱的感想切成了齐整的块，但每个块里装的还是我原来那些未经深思的素材。结构是对的，但结构里的东西没有被检验过。

这就像一个人把一堆没洗过的蔬菜交给厨师，厨师切得很漂亮，但切出来的东西还是没洗过的。你以为自己拥有了一盘精致的沙拉，其实只是拥有了一盘精致的泥沙。

这次经历让我重新理解了 [[yt-note-p-c-role-boundary-realworld]] 里提到的一个核心警报：**当你该用 C 角色（教练模式）时用了 P 角色（执行模式），你会获得一份“结构完整但思考不成熟”的产物**，而你自己还以为已经解决了问题。

## 二、我的选择：结构化思考不能交给 Agent

我选的这件事是**以清单体笔记为载体的结构化思考**。

很多人说，Agent 时代还练什么笔记？直接让 AI 帮你整理不就行了吗？我之前也这么觉得，直到我在两个场景里发现了问题。

**第一个场景是开会。** 一场三十分钟的会议，如果我边听边让 AI 记笔记，它会还原出一份完整的会议纪要。但这份纪要里有一个大坑：AI 不知道**什么对你重要**。它会把每个人说的话都记下来，但你当时脑子里闪过的那个"这句话得记住"的判断，只有你自己知道。AI 记的是"说了什么”，人记的是"哪些值得记”——这两者之间的差距，就是人的价值。

**第二个场景是做决策。** 有一次我要判断产品方向，先开了一篇笔记把动力、阻力、竞品都列上去。如果让 AI 帮我整理，它会把这些信息切得很漂亮，但它不会帮我做一件事：**判断哪个信息是噪声、哪个是信号**。这个判断依赖的不是信息量，而是你对行业的理解、对团队能力的估算、对时间窗口的感觉——这些东西不能被结构化，只能被体验。

所以我的结论是：Agent 可以做笔记的"切工”，但不能做笔记的"开采工”。它能切菜，但不能决定什么菜值得进厨房。这也是 [[yt-skill-checklist-as-ai-protocol]] 里强调的原则：清单体笔记是人与 AI 的协作协议，但协议的“内容”必须来自人的判断，不能来自模板的填充。

## 三、人和 Agent 的差距在哪里

我把这个差距分成三层。

**第一层是"品味”。** 什么值得记、什么不值得记，这不是一个可以被编码的规则。它依赖于你的经验、你的失败、你的疑惑。同样一段话，一个初入行的人和一个做了十年的人，记下来的东西完全不一样。这种"品味"不是天赋，是**反复训练的产物**——每次你做出"这个不重要”的判断，都是在锻炼你的品味肌肉。

**第二层是"分层”。** 一篇好的清单体笔记不是平铺的，它有维度。有的信息是“必须知道的”，有的是“了解即可的”，有的是“可以忽略的”。这种分层的能力来自于你对这个话题的**理解深度**。Agent 可以按一套规则做分层，但它不知道"今天这个会议里，第三点比第一点重要十倍"。

**第三层是"纠结”。** 真正的思考不是顺滑的，它充满纠结、矛盾、自我怀疑。这些纠结在原始输入中是"毛边”——你写了一句话，然后又打了一个破折号，补充了另一个观点。Agent 整理时会把这些纠结平滑掉，因为它追求的是"结构清晰”。但这些纠结正是思考的精华——**你在纠结中探索，而不是在清晰中探索**。

三层合起来，就是一个词：**手感**。这种手感不是你手里握着笔的感觉，而是你**对信息的敏感度**——你知道哪里有金子，哪里是沙子。这正是 [[yt-note-l4-internalization]] 里说的“内化”水平：不是"写完了再改成清单体”，而是一开始就用清单体的逻辑在思考。

## 四、Kahneman 的规律：System 1 的品味无法外包

Daniel Kahneman 在《思考，快与慢》里说，人类有两个系统：System 1 （快速、直觉、自动）和 System 2 （慢速、逻辑、工作）。

Agent 时代有一个误区：人们以为 AI 取代的是 System 2 （逻辑、结构、分析），人只需要保留 System 1 （直觉、感觉、品味）。但实际上刚好相反——**真正应该保留给人的是 System 2 的"监督权"，而不是 System 1 的获得权**。

为什么？因为 System 1 的“直觉”其实是被训练过的——你看到一份笔记，第一眼就能判断“这个人是真懂还是假懂”，这不是天赋，是**上千次练习的底层模式识别**。当你把所有结构化工作都交给 Agent 时，你的 System 1 也在衰退——你开始失去"这个结构有没有说到点子上"的直觉。

Agent 是 System 2 的增强器：它能帮你做逻辑检查、做结构优化、做信息梳理。但它不能做的是：在梳理完之后，用 System 1 呼一口气，说一句“对了，就是这个感觉”。这口气，只有人能呼。

换句话说：Agent 时代人的价值不是“做得更快”，而是“判断得更准”。判断依赖的不是知识量，而是**手感的密度**。这也是 [[yt-skill-storyline-target-tradeoff]] 里说的原则：任何决策都有代价，但只有人能判断"这个代价我愿不愿意付”。

## 五、我怎么练？

我把自己的练习分成三个层次。

**第一层是"嵌入流程”。** 我不等“有空了再记笔记”，而是把清单体笔记当成工作流的必须节点：开会前必开笔记、做决策前必建笔记、复盘时必用笔记。不是“记笔记”这件事要坚持，而是“这件事本来就是工作的一部分”。

**第二层是"四要素刻意练习”。** 我用 [[yt-note-deliberate-practice-four-elements]] 里的固定套路、非舒适区、及时反馈、大量重复这四个要素来追踪自己的笔记进步。特别是“非舒适区”——每次记笔记，都不求"记完”，而求"记到最好"。这个“最好”不是一个固定标准，而是每次都比上次多做一步——多分一层、多提一个问题、多画一张表。

**第三层是"人机分工”。** 我不让 Agent 做所有事，而是明确划分：**我做 C 角色，Agent 做 P 角色**。我自己做诊断、做判断、做选择，把结果交给 Agent 去整理、去格式化、去迭代。这样一来，Agent 没有取代我，而是把我解放出来去做更难的事——想清楔。

这三层合起来，就是一个原则：**让人做人该做的事，让 Agent 做 Agent 善长的事**。具体到笔记这件事，就是 [[yt-skill-p-role-prompt-design]] 里说的：设计一个完善的 P 角色提示词，让 Agent 只做"结构化转换"，而不做"思考诊断"。

## 六、不能这么用的情况

这个方法不是万能的。如果你每天的工作只是"收集信息"而不是"处理信息"，那么结构化思考对你可能不重要。如果你的工作是重复性的、模板化的，那么让 Agent 做就行了，不需要人去练。

这个方法只适合那些**需要在不确定性中做决策**的人。创业者、管理者、产品经理、战略分析师——你们每天面对的不是"信息不足”，而是"信息过载但判断力不足"。这种判断力，Agent 给不了你，只能自己练。

## 结语

Agent 时代最可怕的不是 AI 替代了人，而是人们以为 AI 已经替代了自己，于是放弃了练习。

你以为自己在用 AI 提效，其实可能只是在用 AI 掩盖自己的懒惰。当你把所有结构化工作都交给 Agent 时，你不是在节省时间——你是在花费时间去丢失一种**永不可复制的能力**。

所以我的答案是：Agent 是杠杆，但握杠杆的手必须是人的。杠杆可以让你攀得更高，但如果你不练手臂，等到有一天需要自己攀的时候，你会发现自己连攀的力气都没有了。

**Agent 时代，最值得练的不是“怎么用好 AI”，而是“怎么不被 AI 废了”。**
