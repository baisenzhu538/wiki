# 《AI知识库-从长文到可调用卡片》实操手册

> 目标：30 分钟内，把一篇 PDF/长文变成 AI 可检索、可调用的知识卡片。拿到就能用。

## 一、五步流程总览

```
PDF/长文 → ①转 Markdown → ②按语义拆分 → ③补 YAML 标签 → ④入库 → ⑤验证可检索
```

每步一个加工动作，让知识的「机器可读性」提升一阶。本手册对应 A 档卡《知识卡片公式》《原子化拆分》的操作展开——卡讲认知，本手册讲怎么动手。

## 二、分步操作

### 第 1 步：转 Markdown（结构化整理）

**动作**：把 PDF/Word/网页转为 Markdown 纯文本。

| 工具 | 用法 |
|:--|:--|
| PDF 转 Markdown | MinerU / marker / 复制粘贴后清理 |
| 网页转 Markdown | 浏览器插件 / 复制粘贴清理 |

**标准**：保留层级结构——`# 标题` / `## 小标题` / 列表 / `> 引用` / `` `代码块` ``。
**判断**：转完后能看出文档骨架（标题层级完整），而不是一大坨文字。

### 第 2 步：按语义拆分（原子化）

**动作**：把长文拆成独立的语义单元，每个单元 = 一个「知识点」。

**原子化判定**（往下拆出现歧义 = 到底；语义完整 = 原子）：
- 能再拆出独立语义单元 → 继续拆
- 再拆就出现歧义/碎片 → 到底，这就是一张卡

**例 1（黄芪水）**：
```
原长文：黄芪水的功效与禁忌（一整段）
拆成：
  ✓ 卡片A：黄芪水对气虚的改善（功效+适用人群）
  ✓ 卡片B：黄芪水的禁忌人群与注意事项
  ✗ 不要拆：「黄芪」「10g」「煮水」——失去意义
```

**例 2（膳食指南）**：把「常见食物的份量换算」单独成卡（标签示例.yaml 就是这张卡），不混入其他膳食建议。

**判断标准**：每个候选单元能独立回答一个问题。

### 第 3 步：补 YAML 标签（给 AI 看）

**动作**：每张卡头部写 YAML 元数据——AI 只看前十几行就知道相不相关，不相关就跳过，效率极高（口述 L528-548）。

**最小四字段**（图 8 重点模板）：

```yaml
---
title: <这张卡讲什么，一句话>
source: <原始出处，可追溯>
topic: <主题关键词>
tags: [<关键词1>, <关键词2>]
audience: <给谁用>
created: <YYYY-MM-DD>
---
```

**参考完整范本**（标签示例.yaml，膳食指南卡）：

```yaml
---
title: "常见食物的份量换算"
type: knowledge_card
topic: 中国居民膳食指南
source: "中国居民膳食指南（2022）"
author: 中国营养学会
created: 2022-04
tags:
  - 膳食指南
  - 食物份量
  - 量化
---
```

**判断标准**：AI 看完前十几行能判断「这篇跟我相不相关」。

### 第 4 步：入库（分库组织）

**动作**：卡片按业务领域归入对应库，库间用映射表联动。

- 专业领域库（如：健康营养）
- 业务运营库（如：营销推广）
- 人设表达库（如：话术）

**判断标准**：同一主题的知识在同一个库能找到；跨库知识有映射表/回链。

### 第 5 步：验证可检索（调试）

**动作**：用 AI 实际检索测试。

```text
测试 1：能搜到吗？        → 输入关键词，卡片出现
测试 2：答得准吗？        → AI 引用卡片内容回答，不泛化
测试 3：不越界吗？        → AI 只答卡片范围内，不乱编
```

**判断标准**：三个测试全过 = 卡片可调用；不过 → 回到第 2/3 步补拆分或补标签。

## 三、常见坑

| 坑 | 症状 | 解法 |
|:--|:--|:--|
| 按字数拆 | 一张卡讲三件事，检索命中一半 | 按语义拆（第 2 步判定） |
| 不打标签 | AI 搜不到、乱答 | 补 YAML 最小四字段 |
| 资料越多越乱 | 垃圾进垃圾出 | 先清洗再入库，不相关的直接不入 |
| 追求完美 | 一张卡打磨一天 | 60 分原则：先能用，再细化 |

## 四、黄芪水实操示例（完整走一遍）

**输入**：一篇讲黄芪水的养生文章（PDF）

1. **转 Markdown**：清理格式，保留标题层级
2. **拆分**：
   - 卡片 A：黄芪水对气虚的改善（功效/适用人群/用法）
   - 卡片 B：黄芪水的禁忌与注意事项
3. **打标签**（卡片 A 示例）：
   ```yaml
   ---
   title: "黄芪水对气虚的改善"
   topic: 中医食疗
   source: 养生文章《黄芪水怎么喝》
   audience: 气虚人群
   tags: [黄芪, 气虚, 食疗]
   created: 2026-08-23
   ---
   ```
4. **入库**：归入「健康营养」库
5. **验证**：问 AI「气虚的人喝黄芪水有用吗」→ AI 引用卡片 A 回答
