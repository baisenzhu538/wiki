# 《AI知识库-YAML标签上手》实操手册

> 目标：学会打标签，更学会「标什么颗粒度」——这是半肥猫课程真正的难点（「真正难的不是打标签动作，而是知道标什么颗粒度」）。拿到就能用。

## 一、先理解：标签是给 AI 看的

> 口述 L528-548：YAML 标签在上（给 AI 看），正文在下（给人看）——AI 读文章速度极快，开头十几行讲清楚「主题/关键词/版本/来源」，AI 就能判断相不相关，不相关直接跳过，效率极高。

```
标签（YAML）→ AI 索引用：主题/来源/适用场景/调用岗位
正文（Markdown）→ 人阅读用：内容完整、语义独立
```

**核心认知**：打标签动作很机械，真正难的是**知道标什么、标什么颗粒度**（口述 L558-560）。

## 二、YAML 标签基础（字段模板）

### 最小四字段（图 8 模板，先够用）

```yaml
---
title: <这张卡讲什么>
source: <出处，可追溯>
topic: <主题>
tags: [<关键词1>, <关键词2>]
audience: <给谁用>
created: <YYYY-MM-DD>
---
```

### 完整字段模板（图 5 胆囊结石卡，10 字段）

```yaml
---
title: <主题｜副标题（基于来源）>
slug: <kebab-case 英文短标识>
category: <所属大类：特定人群/疾病/技能/项目>
tags: [<关键词1>, <关键词2>, <核心方法>, <适用场景>]
version: "<源资料版本>"
source: <权威出处全称>
created: "<YYYY-MM-DD>"
audience: <目标人群（含细分场景）>
kb_id: <与 slug 一致的唯一 ID>
lang: <语言码，如 zh>
---
```

## 三、核心教学：五维标注深挖法（标什么颗粒度）

> 半肥猫课程真正的难点。不是「要不要打标签」，而是「打到什么颗粒度」——答案：**从五个维度深挖，颗粒度由业务决定**（口述 L564-598）。

### 五维标注模板（图 17 批注，可直接套）

```yaml
product_annotation:
  layer_1_professional:   # 专业维度（知识深度）
    tcm_theory: ""        # 中医原理
    western_science: ""   # 西医营养学
    suitable_for: []      # 适宜人群
    unsuitable_for: []    # 不适宜人群
    calorie: ""           # 热量算法

  layer_2_risk_control:   # 平台风控（合规）
    sensitive_words:      # 敏感词映射
      - raw: "便秘"
        replacement: "噗噗"

  layer_3_rhetoric:       # 受众话术（沟通适配）
    tcm_audience: ""      # 中医受众讲"经络温补"
    western_audience: ""  # 西医受众讲"有效成分"

  layer_4_visual:         # 视觉维度（多模态前置）
    color_tone: ""        # 色调
    image_prompt: ""      # 配图提示词

  layer_5_experience:     # 经验边界（隐性经验）
    cooking_tips: []      # 制作技巧
    timing_rules: []      # 火候规则："当归要后下十分钟"
```

### 五层从显到隐

| 层 | 内容 | 可学性 |
|:--|:--|:--|
| 专业维度 | 原理/适用/禁忌 | 显性可学 |
| 平台风控 | 敏感词映射 | 显性可学 |
| 受众话术 | 多种表达分支 | 半显性 |
| 视觉维度 | 配色/提示词 | 半显性 |
| 经验边界 | 火候/技巧/时机 | **隐性难获**（人蹲出来的，AI 搜不到） |

> 金句（图 17 收尾）：**标注的质量取决于你对行业的理解深度**——越往下越依赖行业经验。

## 四、颗粒度判断标准三问（手册核心教学点）

打标签前先问三个问题，回答完就知道标什么颗粒度：

| 三问 | 判断 |
|:--|:--|
| ① **这个内容我要怎么用？** | 只查资料（基础标注够）→ 要做营销/多受众（五维深挖） |
| ② **给谁看？** | 专家也看 → 补话术层；要做图 → 补视觉层；要发平台 → 补风控层 |
| ③ **行业里最怕什么？** | 平台限流 → 风控映射词；误用出事 → 经验边界+禁忌 |

**例（口述 L568-598）**：普通人打「食材克重+步骤」就够；半肥猫做营销推广、多用户群体 → 必须五维（专业+风控+话术+视觉+经验）。

## 五、常见坑

| 坑 | 症状 | 解法 |
|:--|:--|:--|
| 只打主题词 | AI 搜得到但答不准 | 五维深挖（补话术/边界） |
| 追求 29 字段 | 过度设计，入库卡住 | 最小四字段先跑，业务需要再扩展 |
| 敏感词直接写 | 平台限流/封号 | 风控层映射词前置（标注时就埋好） |
| 标签与正文漂移 | 改正文忘改标签 | 每次改卡同步检查 YAML |
